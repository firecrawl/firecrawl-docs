# Firecrawl Java Agent Quickstart

This file is the canonical quickstart for external agents integrating with Firecrawl using the Java SDK. It is generated from SDK source plus OpenAPI.

## Install

### Gradle

```groovy
implementation "com.firecrawl:firecrawl-java:1.18.7"
```

### Maven

```xml
<dependency>
    <groupId>com.firecrawl</groupId>
    <artifactId>firecrawl-java</artifactId>
    <version>1.18.7</version>
</dependency>
```

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient firecrawl = FirecrawlClient.builder()
    .apiKey("fc-YOUR_API_KEY")
    .build();
```

Or use the environment variable `FIRECRAWL_API_KEY`:

```java
FirecrawlClient firecrawl = FirecrawlClient.fromEnv();
```

## When To Use What

- **search** — Use when you start with a query and need to discover relevant URLs and content across the web.
- **scrape** — Use when you already have a URL and want to extract page content in structured formats.
- **interact** — Use when the page needs post-scrape browser actions like clicking, typing, or running code in the browser session.

## Search

### Why use it

Search combines web search with optional scraping of each result. It returns structured results from multiple sources and can scrape each result page in the same call.

### Preferred SDK method

```java
firecrawl.search(query)
firecrawl.search(query, options)
```

### Example

```java
import com.firecrawl.models.SearchOptions;
import com.firecrawl.models.SearchData;

SearchOptions options = SearchOptions.builder()
    .limit(5)
    .build();

SearchData results = firecrawl.search("firecrawl web scraping", options);
```

### Parameters

`SearchOptions.Builder` methods:

| Method | Type | Description |
|---|---|---|
| `limit(Integer)` | `Integer` | Max results per source type. Default: `10`, max: `100`. |
| `sources(List<Object>)` | `List<Object>` | Sources: `"web"`, `"news"`, `"images"`, `"alexandria"` as strings or `{type: "web"}` maps. Default: `["web"]`. |
| `categories(List<Object>)` | `List<Object>` | Filter by category: `"developer"`, `"research"`, `"pdf"`, `"gov"`. |
| `includeDomains(List<String>)` | `List<String>` | Restrict to these domains. Cannot combine with `excludeDomains`. |
| `excludeDomains(List<String>)` | `List<String>` | Exclude these domains. Cannot combine with `includeDomains`. |
| `tbs(String)` | `String` | Time-based filter. E.g., `"qdr:d"` (past day), `"qdr:w"` (past week). |
| `location(String)` | `String` | Location string for geo-targeted results. |
| `country(String)` | `String` | ISO country code. Default: `"US"`. |
| `ignoreInvalidURLs(Boolean)` | `Boolean` | Exclude invalid URLs. Default: `false`. |
| `timeout(Integer)` | `Integer` | Timeout in milliseconds. Default: `60000`. |
| `highlights(Boolean)` | `Boolean` | Generate query-relevant highlights. Default: `true`. |
| `scrapeOptions(ScrapeOptions)` | `ScrapeOptions` | Options applied to scraping each result page. |

## Scrape

### Why use it

Scrape fetches a single URL and returns page content in one or more formats. Use it when you already know which page you need.

### Preferred SDK method

```java
firecrawl.scrape(url)
firecrawl.scrape(url, options)
```

### Example

```java
import com.firecrawl.models.ScrapeOptions;
import com.firecrawl.models.Document;
import java.util.List;

ScrapeOptions options = ScrapeOptions.builder()
    .formats(List.of("markdown", "links"))
    .onlyMainContent(true)
    .build();

Document doc = firecrawl.scrape("https://example.com", options);
System.out.println(doc.getMarkdown());
```

### Parameters

`ScrapeOptions.Builder` methods:

| Method | Type | Description |
|---|---|---|
| `formats(List<Object>)` | `List<Object>` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"screenshot"`, `"json"`, `"images"`, `"audio"`, `"video"`, `"summary"`, etc. Also accepts format config objects. |
| `onlyMainContent(Boolean)` | `Boolean` | Strip headers, navs, footers. Default: `true`. |
| `includeTags(List<String>)` | `List<String>` | HTML tags to exclusively include. |
| `excludeTags(List<String>)` | `List<String>` | HTML tags to exclude. |
| `timeout(Integer)` | `Integer` | Timeout in ms. Default: `60000`. Min: `1000`, max: `300000`. |
| `waitFor(Integer)` | `Integer` | Extra delay in ms after page load. Default: `0`. |
| `mobile(Boolean)` | `Boolean` | Emulate a mobile device. Default: `false`. |
| `headers(Map<String, String>)` | `Map<String, String>` | Custom HTTP headers. |
| `parsers(List<Object>)` | `List<Object>` | Parser configs: `"pdf"`, `"image"`, or PdfParser objects with maxPages, pages, blocks, pageMarkers. |
| `actions(List<Map<String, Object>>)` | `List<Map<String, Object>>` | Browser actions before scraping. |
| `location(LocationConfig)` | `LocationConfig` | Proxy location config. Default: `"US"`. |
| `skipTlsVerification(Boolean)` | `Boolean` | Skip TLS verification. Default: `true`. |
| `removeBase64Images(Boolean)` | `Boolean` | Remove base64 images from markdown. Default: `true`. |
| `blockAds(Boolean)` | `Boolean` | Block ads and cookie popups. Default: `true`. |
| `proxy(String)` | `String` | Proxy type: `"basic"`, `"enhanced"`, `"auto"`. Default: `"auto"`. |
| `maxAge(Long)` | `Long` | Accept cached content younger than this (ms). Default: `172800000` (2 days). |
| `storeInCache(Boolean)` | `Boolean` | Cache the result. Default: `true`. |
| `lockdown(Boolean)` | `Boolean` | Serve only from cache. Default: `false`. |
| `checkPromptInjection(Boolean)` | `Boolean` | Scan for prompt injection. Adds 4 credits. Default: `false`. |
| `redactPII(Boolean)` | `Boolean` | Redact PII from content. |

## Interact

### Why use it

Interact lets you execute code in the browser session that was used for a scrape. Use it for post-scrape browser automation.

### Preferred SDK method

```java
firecrawl.interact(jobId, code)
firecrawl.interact(jobId, code, language, timeout)
firecrawl.interact(jobId, code, language, timeout, origin)
```

### Example

```java
import com.firecrawl.models.BrowserExecuteResponse;

BrowserExecuteResponse result = firecrawl.interact(
    "scrape-job-uuid",
    "document.querySelector('button').click();",
    "node",
    30
);

System.out.println(result.getStdout());
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `String` | **Required.** The scrape job ID (UUID). |
| `code` | `String` | **Required.** Code to execute in the browser sandbox (1–100,000 chars). |
| `language` | `String` | Language: `"python"`, `"node"`, or `"bash"`. Default: `"node"`. |
| `timeout` | `Integer` | Execution timeout in seconds. Min: `1`, max: `300`, default: `30`. |
| `origin` | `String` | Optional origin tag for request attribution. |

## Notes

- **Naming style:** Builder methods use camelCase. JSON serialization to the API uses camelCase.
- **Overloads:** `scrape()`, `search()`, and `interact()` have convenience overloads that accept fewer parameters.
- **Deprecated aliases:** `scrapeExecute()` is deprecated — use `interact()`. `deleteScrapeBrowser()` is deprecated — use `stopInteractiveBrowser()`.
- **Builder pattern:** All option classes use the builder pattern: `ScrapeOptions.builder().formats(...).build()`.
