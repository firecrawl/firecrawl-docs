# Firecrawl Java Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl-java` **1.18.5**) and the v2 OpenAPI spec.

## Install

Maven:

```xml
<dependency>
  <groupId>com.firecrawl</groupId>
  <artifactId>firecrawl-java</artifactId>
  <version>1.18.5</version>
</dependency>
```

Gradle:

```gradle
implementation("com.firecrawl:firecrawl-java:1.18.5")
```

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey(System.getenv("FIRECRAWL_API_KEY"))
    .build();

// Or from env directly:
// FirecrawlClient client = FirecrawlClient.fromEnv();
```

## When To Use What

- **`search`**: use when you start with a query and need discovery. Returns relevant pages you can then scrape or interact with.
- **`scrape`**: use when you already have a URL and want page content in one or more formats (markdown, HTML, JSON extraction, screenshots, etc.).
- **`interact`**: use when the page needs clicks, forms, or post-scrape browser actions. Requires a scrape job ID from a prior scrape.

## Search

### Why use it

Discover relevant pages from a natural-language query. Constrain to a site with `site:` syntax (e.g. `site:docs.firecrawl.dev crawl webhooks`). Returns categorized results across web, news, and images.

### Preferred SDK method

- `client.search(query)` → `SearchData`
- `client.search(query, options)` → `SearchData`

### Example

```java
import com.firecrawl.models.SearchData;
import java.util.List;
import java.util.Map;

SearchData results = client.search("site:docs.firecrawl.dev webhook retries");
List<Map<String, Object>> web = results.getWeb();
```

### Parameters

All parameters use `SearchOptions.builder()` with camelCase names.

| Parameter | Type | Description |
|---|---|---|
| `query` | `String` | The search query. Use `site:example.com` to limit to a domain. |
| `sources` | `List<Object>` | Which sources to search: `"web"`, `"news"`, `"images"`. |
| `categories` | `List<Object>` | Filter by category: `"github"`, `"research"`, `"pdf"`. |
| `includeDomains` | `List<String>` | Restrict results to these domains. |
| `excludeDomains` | `List<String>` | Exclude results from these domains. |
| `limit` | `Integer` | Maximum number of results. |
| `tbs` | `String` | Time-based filter (e.g. `qdr:d` for past day). |
| `location` | `String` | Location string for localized results. |
| `country` | `String` | Country code for geo-targeting. |
| `ignoreInvalidURLs` | `Boolean` | Drop URLs that cannot be scraped by other endpoints. |
| `timeout` | `Integer` | Request timeout in milliseconds. |
| `highlights` | `Boolean` | Generate query-relevant highlights. |
| `scrapeOptions` | `ScrapeOptions` | Scrape each search result (see Scrape parameters). |
| `integration` | `String` | Integration identifier. |

**Return value**: `SearchData`. Access results via `getWeb()`, `getNews()`, `getImages()` (each is `List<Map<String, Object>>` and may be null).

## Scrape

### Why use it

Extract structured content from a URL in one or more formats. Supports markdown, HTML, JSON extraction, screenshots, change tracking, and more.

### Preferred SDK method

- `client.scrape(url)` → `Document`
- `client.scrape(url, options)` → `Document`

### Example

```java
import com.firecrawl.models.ScrapeOptions;
import com.firecrawl.models.Document;

Document doc = client.scrape(
    "https://docs.firecrawl.dev",
    ScrapeOptions.builder()
        .formats(List.of("markdown"))
        .onlyMainContent(true)
        .build()
);

System.out.println(doc.getMarkdown());
```

### Parameters

All parameters use `ScrapeOptions.builder()` with camelCase names.

| Parameter | Type | Description |
|---|---|---|
| `url` | `String` | The URL to scrape. |
| `formats` | `List<Object>` | Output formats. Strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"audio"`, `"video"`. Objects: `JsonFormat.builder().prompt(...).build()`. |
| `headers` | `Map<String, String>` | Custom HTTP request headers. |
| `includeTags` | `List<String>` | Only include content from these HTML tags. |
| `excludeTags` | `List<String>` | Exclude content from these HTML tags. |
| `onlyMainContent` | `Boolean` | Strip nav, footer, and boilerplate. |
| `timeout` | `Integer` | Request timeout in milliseconds. |
| `waitFor` | `Integer` | Wait for page rendering (milliseconds). |
| `mobile` | `Boolean` | Use a mobile viewport. |
| `parsers` | `List<Object>` | File parsers: `"pdf"` or `Map.of("type", "pdf", "maxPages", n)`. |
| `actions` | `List<Map<String, Object>>` | Pre-scrape browser actions: `wait`, `click`, `write`, `press`, `scroll`, `scrape`, `executeJavascript`, `screenshot`, `pdf`. |
| `location` | `LocationConfig` | Geo settings via `LocationConfig.builder().country(...).languages(...).build()`. |
| `skipTlsVerification` | `Boolean` | Skip TLS verification. |
| `removeBase64Images` | `Boolean` | Drop base64 images from markdown output. |
| `blockAds` | `Boolean` | Block ads and cookie popups. |
| `proxy` | `String` | Proxy mode: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. |
| `maxAge` | `Long` | Use cached data up to this age (milliseconds). |
| `storeInCache` | `Boolean` | Cache the result. |
| `lockdown` | `Boolean` | Serve only cached results. |
| `checkPromptInjection` | `Boolean` | Scan page for prompt injection. Adds 4 credits. |
| `redactPII` | `Boolean` | Redact personally identifiable information. |
| `integration` | `String` | Integration identifier. |

## Interact

### Why use it

Control the browser session tied to a scrape job via code execution. Use for clicks, form fills, navigation, and other post-scrape browser actions.

### Preferred SDK method

- `client.interact(jobId, code)` — default language `"node"`
- `client.interact(jobId, code, language, timeout)` — with language and timeout

### Example

```java
import com.firecrawl.models.BrowserExecuteResponse;

BrowserExecuteResponse result = client.interact(
    "<scrapeJobId>",
    "console.log(await page.title());",
    "node",
    60
);

System.out.println(result.getStdout());
```

### Parameters

Parameters are positional (not a builder pattern).

| Parameter | Type | Default | Description |
|---|---|---|---|
| `jobId` | `String` | | Scrape job ID from a prior scrape. |
| `code` | `String` | | Code to execute in the browser session. |
| `language` | `String` | `"node"` | Runtime: `"python"`, `"node"`, `"bash"`. |
| `timeout` | `Integer` | `null` | Execution timeout in seconds (1–300). `null` uses API default (30s). |

**Stop session**: `client.stopInteractiveBrowser(jobId)` ends the browser session. Returns `BrowserDeleteResponse` with `isSuccess()`, `getSessionDurationMs()`, `getCreditsBilled()`, `getError()`.

## Notes

- The Java SDK exposes code-based interactions only. There is no `prompt` parameter on `interact` (unlike Node.js and Python SDKs).
- Deprecated aliases: `scrapeExecute` → `interact`; `deleteScrapeBrowser` → `stopInteractiveBrowser`.
- Async variants available: `searchAsync`, `scrapeAsync`, `interactAsync`, `stopInteractiveBrowserAsync`.
- Java 11+ required.
