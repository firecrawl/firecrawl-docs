# Firecrawl Java Agent Quickstart

This is the canonical quickstart for external agents using the Firecrawl Java SDK. It covers `search`, `scrape`, and `interact` — the three endpoints agents need most. Generated from SDK source (`firecrawl-java` v1.x) and the Firecrawl OpenAPI spec.

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey("fc-YOUR-API-KEY")
    .build();

// Or from environment (reads FIRECRAWL_API_KEY env var):
// FirecrawlClient client = FirecrawlClient.fromEnv();

// Keyless free tier (rate-limited per IP):
// FirecrawlClient client = FirecrawlClient.builder().build();
```

Builder options: `apiKey(String)`, `apiUrl(String)`, `timeoutMs(long)` (default: 300000), `maxRetries(int)` (default: 3), `backoffFactor(double)` (default: 0.5), `asyncExecutor(Executor)`, `httpClient(OkHttpClient)`.

## When To Use What

- **`search`** — Start here when you have a query and need to discover relevant URLs and content from the web.
- **`scrape`** — Use when you already have a specific URL and want its page content as markdown, HTML, structured JSON, or other formats.
- **`interact`** — Use after a scrape when the page needs further browser actions: running code in the live browser session.

## Search

### Why use it

Search the web with a natural-language query and get back structured results with URLs, titles, descriptions, and optionally full scraped content for each result.

### Preferred SDK method

```java
client.search(query, options)
```

### Example

```java
import com.firecrawl.models.SearchOptions;
import com.firecrawl.models.SearchData;

SearchData results = client.search("firecrawl web scraping API",
    SearchOptions.builder()
        .limit(5)
        .build()
);

for (var result : results.getWeb()) {
    System.out.println(result.get("url") + " " + result.get("title"));
}
```

### Parameters

All fields on `SearchOptions` are nullable and use a builder pattern.

| Parameter | Type | Description |
|---|---|---|
| `sources` | `List<Object>` | Sources to search: `"web"`, `"news"`, `"images"`. Default: `["web"]`. |
| `categories` | `List<Object>` | Filter by category: `"github"`, `"research"`, `"pdf"`. |
| `includeDomains` | `List<String>` | Restrict results to these domains. |
| `excludeDomains` | `List<String>` | Exclude results from these domains. |
| `limit` | `Integer` | Maximum number of results. |
| `tbs` | `String` | Time-based filter (e.g. `"qdr:d"` for past day). |
| `location` | `String` | Geographic location for results. |
| `country` | `String` | ISO country code for geo-targeting. |
| `ignoreInvalidURLs` | `Boolean` | Exclude invalid URLs from results. |
| `timeout` | `Integer` | Timeout in milliseconds. |
| `highlights` | `Boolean` | Generate query-relevant highlights. Default: `true`. |
| `scrapeOptions` | `ScrapeOptions` | Options applied when scraping each result page. |
| `integration` | `String` | Integration identifier for telemetry. |

**Return type:** `SearchData` with `.getWeb()`, `.getNews()`, `.getImages()` (each returns `List<Map<String, Object>>`).

## Scrape

### Why use it

Fetch a single URL and get back clean markdown, HTML, structured JSON, screenshots, or other formats.

### Preferred SDK method

```java
client.scrape(url, options)
```

### Example

```java
import com.firecrawl.models.ScrapeOptions;
import com.firecrawl.models.Document;
import java.util.List;

Document doc = client.scrape("https://example.com",
    ScrapeOptions.builder()
        .formats(List.of("markdown"))
        .build()
);

System.out.println(doc.getMarkdown());
```

### Parameters

All fields on `ScrapeOptions` are nullable and use a builder pattern.

| Parameter | Type | Description |
|---|---|---|
| `formats` | `List<Object>` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"json"`, `"audio"`, `"video"`. Also accepts format config objects (`JsonFormat`, `QuestionFormat`, `HighlightsFormat`). |
| `headers` | `Map<String, String>` | Custom HTTP headers. |
| `includeTags` | `List<String>` | Only include content from these HTML tags. |
| `excludeTags` | `List<String>` | Exclude content from these HTML tags. |
| `onlyMainContent` | `Boolean` | Strip headers, navs, footers. Default: `true` (API). |
| `timeout` | `Integer` | Timeout in milliseconds. Default: `60000`. |
| `waitFor` | `Integer` | Delay in milliseconds before fetching. |
| `mobile` | `Boolean` | Emulate a mobile device. |
| `actions` | `List<Map<String, Object>>` | Browser actions before content grab. |
| `location` | `LocationConfig` | Proxy location with `country` and `languages`. |
| `skipTlsVerification` | `Boolean` | Skip TLS certificate verification. |
| `removeBase64Images` | `Boolean` | Remove base64 images from markdown. |
| `blockAds` | `Boolean` | Block ads and cookie popups. |
| `proxy` | `String` | Proxy type: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. |
| `maxAge` | `Long` | Return cached content if younger than this (milliseconds). |
| `storeInCache` | `Boolean` | Store the result in Firecrawl's cache. |
| `lockdown` | `Boolean` | Only serve cached results. |
| `parsers` | `List<Object>` | File processing controls (e.g. `PdfParser`). |
| `redactPII` | `Boolean` | Redact personally identifiable information. |
| `auditMetadata` | `AuditMetadata` | User attribution for SIEM logging (`username`). |
| `integration` | `String` | Integration identifier. |

## Interact

### Why use it

Continue interacting with the same browser state from a previous scrape. Execute code in the live browser session — useful for clicking buttons, filling forms, navigating SPAs, or extracting data that requires interaction.

### Preferred SDK method

```java
client.interact(jobId, code)
client.interact(jobId, code, language, timeout)
client.interact(jobId, code, language, timeout, origin)
```

### Example

```java
import com.firecrawl.models.BrowserExecuteResponse;

// First, scrape a page
Document doc = client.scrape("https://example.com",
    ScrapeOptions.builder()
        .formats(List.of("markdown"))
        .build()
);
String jobId = (String) doc.getMetadata().get("scrapeId");

// Then interact with the live browser session
BrowserExecuteResponse result = client.interact(
    jobId,
    "const title = await page.title(); JSON.stringify({ title });",
    "node",
    30
);

System.out.println(result.getResult());

// Clean up when done
client.stopInteractiveBrowser(jobId);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `String` | **Required.** The scrape job ID from `doc.getMetadata().get("scrapeId")`. |
| `code` | `String` | **Required.** Code to execute in the browser sandbox. |
| `language` | `String` | Language for code execution: `"python"`, `"node"`, `"bash"`. Default: `"node"`. |
| `timeout` | `Integer` | Execution timeout in seconds (1–300). Default: `30` (API). |
| `origin` | `String` | Origin label for telemetry. |

**Stop method:** `client.stopInteractiveBrowser(jobId)` — call this to end the browser session when done.

**Async variants:** All methods have `*Async` counterparts that return `CompletableFuture<T>`.

## Notes

- All parameter names use **camelCase** (e.g. `onlyMainContent`, `includeTags`, `scrapeOptions`).
- The Java SDK's `interact` method takes `code` as a required positional parameter. Unlike the JS/Python/Rust SDKs, there is no separate `prompt` parameter — to use the AI browser agent, pass the prompt string as the `code` field with the API directly via HTTP, or use another SDK.
- `SearchData` returns `List<Map<String, Object>>` for results rather than typed result objects.
- **Deprecated aliases** (use the preferred names instead):
  - `scrapeExecute()` → `interact()`
  - `deleteScrapeBrowser()` → `stopInteractiveBrowser()`
