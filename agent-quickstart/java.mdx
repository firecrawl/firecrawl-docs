# Firecrawl Java Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl-java` v1.18.4) and the v2 OpenAPI spec. Method names, parameters, and types match the SDK public API. All parameter names use camelCase.

## Install

### Gradle

```groovy
implementation 'com.firecrawl:firecrawl-java:1.18.4'
```

### Maven

```xml
<dependency>
    <groupId>com.firecrawl</groupId>
    <artifactId>firecrawl-java</artifactId>
    <version>1.18.4</version>
</dependency>
```

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey("your-api-key")
    .build();

// Or from environment variable FIRECRAWL_API_KEY:
FirecrawlClient client = FirecrawlClient.fromEnv();
```

## When To Use What

- **`search`**: use when you start with a query and need discovery. Returns ranked results from web, news, or images.
- **`scrape`**: use when you already have a URL and want page content in one or more formats (markdown, HTML, JSON extraction, screenshots, etc.).
- **`interact`**: use when the page needs clicks, forms, or other browser actions after a scrape has created a session.

## Search

### Why use it

Discover relevant pages from a query, then pick URLs to scrape or interact with.

### Preferred SDK method

`client.search(query)` → `SearchData`
`client.search(query, options)` → `SearchData`

### Example

```java
import com.firecrawl.models.SearchOptions;
import com.firecrawl.models.SearchData;
import com.firecrawl.models.ScrapeOptions;

SearchData results = client.search("firecrawl webhook docs", SearchOptions.builder()
    .limit(10)
    .scrapeOptions(ScrapeOptions.builder()
        .formats(List.of("markdown"))
        .onlyMainContent(true)
        .build())
    .build());

for (Map<String, Object> item : results.getWeb()) {
    System.out.println(item.get("url") + ": " + item.get("title"));
}
```

### Parameters

`SearchOptions` uses the builder pattern. All fields are nullable (default `null` unless noted).

| Parameter | Type | Description |
|---|---|---|
| `sources` | `List<Object>` | Sources: `"web"`, `"news"`, `"images"`, or typed maps. |
| `categories` | `List<Object>` | Categories: `"github"`, `"research"`, `"pdf"`. |
| `includeDomains` | `List<String>` | Restrict to these domains. |
| `excludeDomains` | `List<String>` | Exclude these domains. |
| `limit` | `Integer` | Max results per source type. |
| `tbs` | `String` | Time-based filter (e.g. `"qdr:d"`, `"qdr:w"`). |
| `location` | `String` | Localized results. |
| `country` | `String` | ISO country code (e.g. `"us"`). |
| `ignoreInvalidURLs` | `Boolean` | Drop URLs that cannot be scraped. |
| `timeout` | `Integer` | Timeout in ms. |
| `highlights` | `Boolean` | Generate query-relevant highlights. Default: `true`. |
| `scrapeOptions` | `ScrapeOptions` | Apply scrape options to each result. |
| `integration` | `String` | Integration identifier. |

### Return value

`SearchData` fields: `web` (list of maps), `news` (list of maps), `images` (list of maps). Each map entry contains result fields like `url`, `title`, `description`, or full document fields when `scrapeOptions` hydrated the hit.

## Scrape

### Why use it

Fetch structured content from a URL in one or more formats.

### Preferred SDK method

`client.scrape(url)` → `Document`
`client.scrape(url, options)` → `Document`

### Example

```java
import com.firecrawl.models.ScrapeOptions;
import com.firecrawl.models.JsonFormat;
import com.firecrawl.models.Document;

Document doc = client.scrape("https://example.com/pricing", ScrapeOptions.builder()
    .formats(List.of(
        "markdown",
        JsonFormat.builder()
            .prompt("Extract plan names and prices.")
            .build()
    ))
    .onlyMainContent(true)
    .build());

System.out.println(doc.getMarkdown());
System.out.println(doc.getJson());
```

### Parameters

`ScrapeOptions` uses the builder pattern. All fields are nullable.

| Parameter | Type | Description |
|---|---|---|
| `formats` | `List<Object>` | Output formats. Strings or format objects. Default: `["markdown"]`. |
| `headers` | `Map<String, String>` | Custom HTTP headers. |
| `includeTags` | `List<String>` | Only include these HTML tags. |
| `excludeTags` | `List<String>` | Exclude these HTML tags. |
| `onlyMainContent` | `Boolean` | Strip nav, footer, boilerplate. |
| `timeout` | `Integer` | Timeout in ms. |
| `waitFor` | `Integer` | Delay in ms before fetching. |
| `mobile` | `Boolean` | Emulate mobile device. |
| `parsers` | `List<Object>` | File parsing controls (e.g. `PdfParser`). |
| `actions` | `List<Map<String, Object>>` | Pre-scrape browser actions. |
| `location` | `LocationConfig` | Geo/language settings. |
| `skipTlsVerification` | `Boolean` | Skip TLS verification. |
| `removeBase64Images` | `Boolean` | Drop base64 images. |
| `blockAds` | `Boolean` | Block ads and cookie popups. |
| `proxy` | `String` | `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`, or custom URL. |
| `maxAge` | `Long` | Use cached result if younger (ms). |
| `storeInCache` | `Boolean` | Cache the result. |
| `lockdown` | `Boolean` | Serve from cache only. |
| `redactPII` | `Boolean` | Redact PII. |
| `auditMetadata` | `AuditMetadata` | User attribution for SIEM (`new AuditMetadata("username")`). |
| `integration` | `String` | Integration identifier. |

#### Format types

Plain strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"audio"`, `"video"`.

Builder objects:

| Format class | Fields | Notes |
|---|---|---|
| `JsonFormat` | `prompt`, `schema`, `checkPromptInjection` | At least one of `prompt` or `schema` required. |
| `QuestionFormat` | `question` | Ask a question about the page. |
| `HighlightsFormat` | `query` | Find relevant source text. |

#### Action types

Actions are `List<Map<String, Object>>` with `type` as the discriminator:

| Action | Required fields | Optional fields |
|---|---|---|
| `wait` | `milliseconds` or `selector` | |
| `click` | `selector` | |
| `write` | `text` | |
| `press` | `key` | |
| `scroll` | `direction` | `selector` |
| `scrape` | (none) | |
| `screenshot` | | `fullPage`, `quality`, `viewport` |
| `executeJavascript` | `script` | |
| `pdf` | | `format`, `landscape`, `scale` |

## Interact

### Why use it

Execute code in the browser session tied to a scrape job. Use for multi-step flows like filling forms, navigating tabs, or extracting dynamic content.

### Preferred SDK method

`client.interact(jobId, code)` → `BrowserExecuteResponse`
`client.interact(jobId, code, language, timeout)` → `BrowserExecuteResponse`
`client.interact(jobId, code, language, timeout, origin)` → `BrowserExecuteResponse`

### Example

```java
import com.firecrawl.models.Document;
import com.firecrawl.models.BrowserExecuteResponse;

Document doc = client.scrape("https://example.com", ScrapeOptions.builder()
    .formats(List.of("markdown"))
    .build());

String jobId = (String) doc.getMetadata().get("scrapeId");

BrowserExecuteResponse result = client.interact(
    jobId,
    "console.log(await page.title());",
    "node",
    60
);
System.out.println(result.getStdout());

client.stopInteractiveBrowser(jobId);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `String` | Scrape job ID from `document.metadata.scrapeId`. |
| `code` | `String` | Code to execute in the browser sandbox. |
| `language` | `String` | `"python"`, `"node"`, or `"bash"`. Default: `"node"`. |
| `timeout` | `Integer` | Execution timeout in seconds (1–300). Default: 30. |
| `origin` | `String` | Origin label for telemetry. |

### Return value

`BrowserExecuteResponse` fields: `success`, `stdout`, `result`, `stderr`, `exitCode`, `killed`, `error`.

### Stop session

`client.stopInteractiveBrowser(jobId)` → `BrowserDeleteResponse`

Response fields: `success`, `sessionDurationMs`, `creditsBilled`, `error`.

## Notes

- Deprecated aliases: `scrapeExecute` → `interact`; `deleteScrapeBrowser` → `stopInteractiveBrowser`.
- All sync methods have async counterparts with an `Async` suffix (e.g. `scrapeAsync`, `interactAsync`), returning `CompletableFuture<T>`.
- Builder defaults: `apiUrl` = `"https://api.firecrawl.dev"`, `timeoutMs` = 300000, `maxRetries` = 3, `backoffFactor` = 0.5.
- Java 11+ compatible.
- The Java SDK's `interact` method takes `code` as a required positional parameter (no separate `prompt` parameter). To use natural-language prompts, pass the prompt text as the `code` argument — the API interprets the request based on the content.
