# Firecrawl Java Agent Quickstart

Canonical quickstart for external agents. Generated from `firecrawl-java` **v1.18.4** SDK source and the v2 OpenAPI spec. Method names, parameters, and types match the SDK public API.

## Install

Maven:

```xml
<dependency>
  <groupId>com.firecrawl</groupId>
  <artifactId>firecrawl-java</artifactId>
  <version>1.18.4</version>
</dependency>
```

Gradle:

```gradle
implementation("com.firecrawl:firecrawl-java:1.18.4")
```

Requires Java 11+.

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey(System.getenv("FIRECRAWL_API_KEY"))
    .build();

// Or from environment automatically:
// FirecrawlClient client = FirecrawlClient.fromEnv();
```

Builder options: `apiKey` (falls back to `FIRECRAWL_API_KEY` env or `firecrawl.apiKey` system property), `apiUrl` (default `https://api.firecrawl.dev`), `timeoutMs` (default 300000), `maxRetries` (default 3), `backoffFactor` (default 0.5), `asyncExecutor`, `httpClient`.

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions. Requires a scrape job ID.

## Search

### Why use it

Discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain to a domain with `site:`, e.g. `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`client.search(query)` or `client.search(query, options)` → `SearchData`

### Example

```java
import com.firecrawl.models.SearchData;
import java.util.List;
import java.util.Map;

SearchData results = client.search("site:docs.firecrawl.dev webhook retries");
List<Map<String, Object>> web = results.getWeb();
```

### Return value

`SearchData` has `getWeb()`, `getNews()`, `getImages()` — each is `List<Map<String, Object>>` and may be null. Do not treat it as a directly iterable list.

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | String (first arg) | Search query. Use `site:example.com` for domain-scoped results. |
| `options.sources` | List of strings or maps | `"web"`, `"news"`, `"images"`. |
| `options.categories` | List of strings or maps | `"github"`, `"research"`, `"pdf"`. |
| `options.limit` | Integer | Max results. |
| `options.tbs` | String | Time-based filter (e.g. `"qdr:d"`). |
| `options.location` | String | Localized results. |
| `options.country` | String | Country code for geo-targeted results. |
| `options.ignoreInvalidURLs` | Boolean | Drop URLs that cannot be scraped. |
| `options.timeout` | Integer | Request timeout in milliseconds. |
| `options.highlights` | Boolean | Include highlight snippets. Default: true. |
| `options.scrapeOptions` | ScrapeOptions | Scrape each search result. |
| `options.includeDomains` | List&lt;String&gt; | Only include these domains. |
| `options.excludeDomains` | List&lt;String&gt; | Exclude these domains. |

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK method

`client.scrape(url)` or `client.scrape(url, options)` → `Document`

### Example

```java
import com.firecrawl.models.Document;
import com.firecrawl.models.ScrapeOptions;

Document doc = client.scrape(
    "https://docs.firecrawl.dev",
    ScrapeOptions.builder().formats(List.of("markdown")).build()
);
System.out.println(doc.getMarkdown());
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | String (first arg) | URL to scrape. |
| `options.formats` | List of strings or format objects | Output formats (see below). |
| `options.headers` | Map&lt;String, String&gt; | Custom request headers. |
| `options.includeTags` | List&lt;String&gt; | Only include specific HTML tags. |
| `options.excludeTags` | List&lt;String&gt; | Exclude specific HTML tags. |
| `options.onlyMainContent` | Boolean | Strip nav, footer, and boilerplate. |
| `options.timeout` | Integer | Timeout in milliseconds. |
| `options.waitFor` | Integer | Wait for page render (ms). |
| `options.mobile` | Boolean | Use mobile viewport. |
| `options.parsers` | List | `"pdf"` or `PdfParser.builder()...build()`. |
| `options.actions` | List&lt;Map&lt;String, Object&gt;&gt; | Pre-scrape browser actions. |
| `options.location` | LocationConfig | `{ country, languages }` for geo-aware scraping. |
| `options.skipTlsVerification` | Boolean | Skip TLS verification. |
| `options.removeBase64Images` | Boolean | Drop base64 images from markdown. |
| `options.blockAds` | Boolean | Block ads and cookie popups. |
| `options.proxy` | String | `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`, or custom URL. |
| `options.maxAge` | Long | Max cache age (ms). |
| `options.storeInCache` | Boolean | Cache the result. |
| `options.lockdown` | Boolean | Serve only cached results. |
| `options.checkPromptInjection` | Boolean | Scan for prompt injection (adds 4 credits). |
| `options.redactPII` | Boolean | Redact PII from output. |
| `options.auditMetadata` | AuditMetadata | `new AuditMetadata(username)` for audit trail. |

### Format strings

`"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"audio"`, `"video"`

### Format objects

| Class | Required fields | Description |
|---|---|---|
| `JsonFormat.builder().prompt(...).build()` | `prompt` or `schema` | JSON extraction. |
| `QuestionFormat.builder().question(...).build()` | `question` | Question-answer extraction. |
| `HighlightsFormat.builder().query(...).build()` | `query` | Relevant source-text extraction. |

### Action types (as Map entries)

| Type | Required fields | Description |
|---|---|---|
| `wait` | `milliseconds` or `selector` | Wait for time or element. |
| `click` | `selector` | Click an element. |
| `write` | `text` | Type text. |
| `press` | `key` | Press a keyboard key. |
| `scroll` | `direction` (`"up"` / `"down"`) | Scroll page or element. |
| `scrape` | — | Capture page content mid-action. |
| `screenshot` | — | Take a screenshot mid-action. |
| `executeJavascript` | `script` | Run JavaScript. |
| `pdf` | — | Generate PDF. |

### PDF parser options

`PdfParser.builder().mode("auto").maxPages(5).pages(true).blocks(true).pageMarkers(true).build()`

## Interact

### Why use it

Control the browser session tied to a scrape job. The Java SDK supports **code-based interactions only** — there is no `prompt` parameter.

### Preferred SDK method

- `client.interact(jobId, code)` — uses default language `"node"`
- `client.interact(jobId, code, language, timeout)` — `timeout` is seconds (1–300)
- `client.interact(jobId, code, language, timeout, origin)` — optional origin string

### Example

```java
import com.firecrawl.models.BrowserExecuteResponse;

BrowserExecuteResponse result = client.interact(
    "<scrapeJobId>",
    "console.log(await page.title());",
    "node",
    60
);
System.out.println(result.getStdout());
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | String (first arg) | Scrape job ID. |
| `code` | String (second arg) | Code to execute in the browser session. |
| `language` | String | `"python"`, `"node"`, `"bash"`. Default: `"node"`. |
| `timeout` | Integer | Execution timeout in seconds (1–300). Default: 30. |
| `origin` | String | Optional origin label for request attribution. |

### Stop session

`client.stopInteractiveBrowser(jobId)` ends the browser session. Returns `BrowserDeleteResponse` with `isSuccess()`, `getSessionDurationMs()`, `getCreditsBilled()`, `getError()`.

## Notes

- Deprecated aliases: `scrapeExecute` → `interact`; `deleteScrapeBrowser` → `stopInteractiveBrowser`.
- The Java SDK exposes **code-based interactions only**: there is no `prompt` parameter on `interact` (unlike Node.js, Python, and Rust SDKs).
- All methods have `*Async` variants returning `CompletableFuture`.
- Deprecated: `QueryFormat` → use `QuestionFormat` or `HighlightsFormat`; `JsonFormat.checkPromptInjection` → use `ScrapeOptions.checkPromptInjection`.
