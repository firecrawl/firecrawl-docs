# Firecrawl Java Agent Quickstart

Canonical Firecrawl Java quickstart for external agents. Aligned with `firecrawl-java` **1.18.7** and the v2 OpenAPI spec. Method names and parameters match the SDK public API.

## Install

Maven:

```xml
<dependency>
  <groupId>com.firecrawl</groupId>
  <artifactId>firecrawl-java</artifactId>
  <version>1.18.7</version>
</dependency>
```

Gradle:

```gradle
implementation("com.firecrawl:firecrawl-java:1.18.7")
```

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey(System.getenv("FIRECRAWL_API_KEY"))
    .build();

// Or load from FIRECRAWL_API_KEY env var / firecrawl.apiKey system property:
// FirecrawlClient client = FirecrawlClient.fromEnv();
```

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or other browser actions after a scrape has created a session.

## Search

### Why use it

Use search to discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:`, for example `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`client.search(query, options)` → `SearchData`

### Example

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey(System.getenv("FIRECRAWL_API_KEY"))
    .build();

// Simple search
SearchData results = client.search("site:docs.firecrawl.dev webhook retries");

// Search with options
SearchData results = client.search("firecrawl crawl webhooks",
    SearchOptions.builder()
        .limit(10)
        .timeout(60000)
        .highlights(true)
        .build()
);
```

### Parameters

- `query`
  - Type: `String`
  - Required. The search query. Use `site:example.com` to limit results to a domain.

- `options` (optional, `SearchOptions` via builder pattern)

- `options.sources`
  - Type: `List<Object>`
  - Source types to search. Confirmed values: `"web"`, `"news"`, `"images"`, or typed source maps.

- `options.categories`
  - Type: `List<Object>`
  - Category filters. Confirmed values: `"github"`, `"research"`, `"pdf"`, `"developer"`, `"gov"`.

- `options.includeDomains`
  - Type: `List<String>`
  - Restrict results to these domains. Cannot combine with `excludeDomains`.

- `options.excludeDomains`
  - Type: `List<String>`
  - Exclude results from these domains. Cannot combine with `includeDomains`.

- `options.limit`
  - Type: `Integer`
  - Maximum number of results to return.

- `options.tbs`
  - Type: `String`
  - Time-based search filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week).

- `options.location`
  - Type: `String`
  - Location for geo-targeted results (e.g. `"San Francisco,California,United States"`).

- `options.country`
  - Type: `String`
  - ISO country code for geo-targeting (e.g. `"us"`).

- `options.ignoreInvalidURLs`
  - Type: `Boolean`
  - Exclude URLs that are invalid for other Firecrawl endpoints.

- `options.timeout`
  - Type: `Integer`
  - Timeout in milliseconds.

- `options.highlights`
  - Type: `Boolean`
  - Generate query-relevant highlights. Default: `true`.

- `options.scrapeOptions`
  - Type: `ScrapeOptions`
  - Scrape options applied to each search result page. See Scrape parameters.

- `options.integration`
  - Type: `String`
  - Integration identifier.

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK method

`client.scrape(url, options)` → `Document`

### Example

```java
// Simple scrape
Document doc = client.scrape("https://docs.firecrawl.dev");

// Scrape with options
Document doc = client.scrape("https://example.com/pricing",
    ScrapeOptions.builder()
        .formats(List.of("markdown", "links"))
        .onlyMainContent(true)
        .timeout(60000)
        .build()
);
```

### Parameters

- `url`
  - Type: `String`
  - Required. The URL to scrape.

- `options` (optional, `ScrapeOptions` via builder pattern)

- `options.formats`
  - Type: `List<Object>`
  - Output formats. Plain string formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"screenshot"`, `"audio"`, `"video"`. Object formats for structured extraction: `JsonFormat` (with `prompt` and/or `schema`), `QuestionFormat` (with `question`), `HighlightsFormat` (with `query`).

- `options.headers`
  - Type: `Map<String, String>`
  - Custom HTTP headers.

- `options.includeTags`
  - Type: `List<String>`
  - Only include content from these HTML tags.

- `options.excludeTags`
  - Type: `List<String>`
  - Exclude content from these HTML tags.

- `options.onlyMainContent`
  - Type: `Boolean`
  - Only return main content, excluding navbars and footers.

- `options.timeout`
  - Type: `Integer`
  - Timeout in milliseconds.

- `options.waitFor`
  - Type: `Integer`
  - Wait time in milliseconds before scraping (for JS-rendered pages).

- `options.mobile`
  - Type: `Boolean`
  - Scrape as a mobile device.

- `options.parsers`
  - Type: `List<Object>`
  - Parsers to use (e.g. `"pdf"` or `PdfParser` with mode/maxPages).

- `options.actions`
  - Type: `List<Map<String, Object>>`
  - Browser actions to execute before/during scraping. Action types: `wait`, `screenshot`, `click`, `write`, `press`, `scroll`, `scrape`, `executeJavascript`, `pdf`.

- `options.location`
  - Type: `LocationConfig`
  - Geolocation configuration with `country` and `languages`.

- `options.skipTlsVerification`
  - Type: `Boolean`
  - Skip TLS certificate verification.

- `options.removeBase64Images`
  - Type: `Boolean`
  - Remove base64-encoded images from output.

- `options.blockAds`
  - Type: `Boolean`
  - Block advertisements and cookie popups.

- `options.proxy`
  - Type: `String`
  - Proxy mode: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`, or a custom proxy URL.

- `options.maxAge`
  - Type: `Long`
  - Use cached result if younger than this many milliseconds. `0` to bypass cache.

- `options.storeInCache`
  - Type: `Boolean`
  - Whether to cache the result.

- `options.lockdown`
  - Type: `Boolean`
  - Serve only previously cached results, never make outbound requests.

- `options.checkPromptInjection`
  - Type: `Boolean`
  - Scan content for prompt injection before LLM-backed formats run. Adds 4 credits.

- `options.redactPII`
  - Type: `Boolean`
  - Redact personally identifiable information from output.

- `options.auditMetadata`
  - Type: `AuditMetadata`
  - User attribution for SIEM logging (e.g. `{ username: "..." }`).

- `options.integration`
  - Type: `String`
  - Integration identifier.

## Interact

### Why use it

Use `interact` to execute code in the browser session tied to a prior scrape job (via `metadata.scrapeId`). For flows that go beyond quick pre-scrape tweaks, prefer `interact` over scrape-time `actions`.

### Preferred SDK method

`client.interact(jobId, code, language, timeout)` → `BrowserExecuteResponse`

### Example

```java
Document doc = client.scrape("https://example.com",
    ScrapeOptions.builder().formats(List.of("markdown")).build()
);
String jobId = (String) doc.getMetadata().get("scrapeId");

// Simple interact
BrowserExecuteResponse result = client.interact(jobId,
    "console.log(await page.title());"
);

// With language and timeout
BrowserExecuteResponse result = client.interact(jobId,
    "console.log(await page.title());",
    "node",
    60
);

// Stop the session when done
client.stopInteractiveBrowser(jobId);
```

### Parameters

- `jobId`
  - Type: `String`
  - Required. The scrape job ID from `document.metadata.scrapeId`.

- `code`
  - Type: `String`
  - Required. Code to execute in the browser session.

- `language`
  - Type: `String`
  - Runtime language. Confirmed values: `"python"`, `"node"`, `"bash"`. Default: `"node"`.

- `timeout`
  - Type: `Integer`
  - Execution timeout in seconds. Range: 1–300. Default: `30`.

- `origin`
  - Type: `String`
  - Optional origin tag for request attribution (available in the 5-parameter overload).

### Return value

`BrowserExecuteResponse` fields:

- `success`: `boolean`
- `stdout`: `String`
- `result`: `String`
- `stderr`: `String`
- `exitCode`: `Integer`
- `killed`: `Boolean`
- `error`: `String`

### Stop session

`client.stopInteractiveBrowser(jobId)` → `BrowserDeleteResponse`

## Notes

- Java `interact` only accepts `code`. It does not support `prompt` (natural-language instruction) unlike the Node.js, Python, and Rust SDKs.
- All option classes use the builder pattern (e.g. `SearchOptions.builder().limit(10).build()`).
- Deprecated aliases: `scrapeExecute` → `interact`; `deleteScrapeBrowser` → `stopInteractiveBrowser`.
- The client falls back to `FIRECRAWL_API_KEY` env var or `firecrawl.apiKey` system property when no explicit key is provided.
