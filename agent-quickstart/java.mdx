# Firecrawl Java Agent Quickstart

Canonical quickstart for external agents. Generated from `firecrawl-java` v1.18.0 source (`firecrawl/apps/java-sdk`) and the v2 OpenAPI spec. Method names and parameters match the SDK public API.

## Install

Maven:

```xml
<dependency>
    <groupId>com.firecrawl</groupId>
    <artifactId>firecrawl-java</artifactId>
    <version>1.18.0</version>
</dependency>
```

Gradle:

```groovy
implementation 'com.firecrawl:firecrawl-java:1.18.0'
```

Requires Java 11+.

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey("fc-your-api-key")
    .build();

// Or read from FIRECRAWL_API_KEY env var / firecrawl.apiKey system property:
FirecrawlClient client = FirecrawlClient.fromEnv();
```

Builder options: `apiKey` (String), `apiUrl` (String, default `"https://api.firecrawl.dev"`), `timeoutMs` (long, default 300000), `maxRetries` (int, default 3), `backoffFactor` (double, default 0.5), `httpClient` (OkHttpClient), `asyncExecutor` (Executor).

## When To Use What

- `search` — start with a query, discover relevant pages, then scrape or interact with the results.
- `scrape` — you already have a URL and want structured page content.
- `interact` — the page needs clicks, form fills, or post-scrape browser actions via code execution.

## Search

### Why use it

Discover relevant pages from a text query. Supports `site:` scoping, source filtering, category narrowing, and inline scraping of results.

### Preferred SDK method

`client.search(query, options)` → `SearchData`

### Example

```java
import com.firecrawl.models.SearchOptions;
import com.firecrawl.models.SearchData;
import com.firecrawl.models.ScrapeOptions;
import java.util.List;

SearchData results = client.search("site:docs.firecrawl.dev webhook retries",
    SearchOptions.builder()
        .sources(List.of("web"))
        .limit(5)
        .scrapeOptions(ScrapeOptions.builder()
            .formats(List.of("markdown"))
            .onlyMainContent(true)
            .build())
        .build());

for (var hit : results.getWeb()) {
    System.out.println(hit.get("url") + " " + hit.get("title"));
}
```

### Parameters

`SearchOptions` fields (built via `SearchOptions.builder()`):

| Field | Type | Description |
|---|---|---|
| `sources` | `List<Object>` | Sources: `"web"`, `"news"`, `"images"`. |
| `categories` | `List<Object>` | Filter: `"github"`, `"research"`, `"pdf"`. |
| `includeDomains` | `List<String>` | Only include these domains. |
| `excludeDomains` | `List<String>` | Exclude these domains. |
| `limit` | `Integer` | Max results. |
| `tbs` | `String` | Time-based filter (e.g. `"qdr:d"`). |
| `location` | `String` | Location for geo-targeted results. |
| `country` | `String` | Country code (e.g. `"us"`). |
| `ignoreInvalidURLs` | `Boolean` | Drop unscrappable URLs. |
| `timeout` | `Integer` | Timeout in milliseconds. |
| `highlights` | `Boolean` | Query-relevant highlights (default true on server). |
| `scrapeOptions` | `ScrapeOptions` | Scrape each result (see Scrape parameters). |
| `integration` | `String` | Integration identifier. |

### Return value

`SearchData` with `getWeb()`, `getNews()`, `getImages()` returning `List<Map<String, Object>>`.

## Scrape

### Why use it

Get structured content from a URL in one or more formats: markdown, HTML, JSON extraction, screenshots, and more.

### Preferred SDK method

`client.scrape(url, options)` → `Document`

Overloads: `client.scrape(url)` (no options), `client.scrapeAsync(url, options)` → `CompletableFuture<Document>`.

### Example

```java
import com.firecrawl.models.ScrapeOptions;
import com.firecrawl.models.Document;
import java.util.List;
import java.util.Map;

Document doc = client.scrape("https://example.com/pricing",
    ScrapeOptions.builder()
        .formats(List.of(
            "markdown",
            Map.of("type", "json", "prompt", "Extract plan names and prices.")
        ))
        .onlyMainContent(true)
        .build());

System.out.println(doc.getMarkdown());
System.out.println(doc.getJson());
```

### Parameters

`ScrapeOptions` fields (built via `ScrapeOptions.builder()`):

| Field | Type | Description |
|---|---|---|
| `formats` | `List<Object>` | Output formats. Strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"screenshot"`, `"json"`, `"audio"`, `"video"`. Object forms via `Map`: `{"type": "json", "prompt": ..., "schema": ...}`, etc. |
| `headers` | `Map<String, String>` | Custom HTTP headers. |
| `includeTags` | `List<String>` | Include only these HTML tags. |
| `excludeTags` | `List<String>` | Exclude these HTML tags. |
| `onlyMainContent` | `Boolean` | Strip nav, footer, boilerplate. |
| `timeout` | `Integer` | Timeout in milliseconds. |
| `waitFor` | `Integer` | Wait for page render (ms). |
| `mobile` | `Boolean` | Use mobile viewport. |
| `parsers` | `List<Object>` | File parsing (e.g. `"pdf"` or `PdfParser`). |
| `actions` | `List<Map<String, Object>>` | Pre-scrape browser actions. |
| `location` | `LocationConfig` | Geo/language: `.country(String)`, `.languages(List)`. |
| `skipTlsVerification` | `Boolean` | Skip TLS verification. |
| `removeBase64Images` | `Boolean` | Drop base64 images. |
| `blockAds` | `Boolean` | Block ads and cookie popups. |
| `proxy` | `String` | `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. |
| `maxAge` | `Long` | Cached data max age (ms). |
| `storeInCache` | `Boolean` | Cache the result. |
| `lockdown` | `Boolean` | Only serve cached results. |
| `redactPII` | `Boolean` | Redact PII. |
| `auditMetadata` | `AuditMetadata` | SIEM logging: takes `username`. |
| `integration` | `String` | Integration identifier. |

## Interact

### Why use it

Execute code in the browser session tied to a scrape job for post-scrape automation.

### Preferred SDK method

`client.interact(jobId, code)` → `BrowserExecuteResponse`

Overloads:
- `interact(jobId, code)` — defaults: language `"node"`, no timeout.
- `interact(jobId, code, language, timeout)` — specify language and timeout.
- `interact(jobId, code, language, timeout, origin)` — full control.

Async: `client.interactAsync(...)` → `CompletableFuture<BrowserExecuteResponse>`.

### Example

```java
import com.firecrawl.models.Document;
import com.firecrawl.models.ScrapeOptions;
import com.firecrawl.models.BrowserExecuteResponse;
import java.util.List;

Document doc = client.scrape("https://example.com",
    ScrapeOptions.builder().formats(List.of("markdown")).build());

String jobId = (String) doc.getMetadata().get("scrapeId");

BrowserExecuteResponse result = client.interact(jobId,
    "console.log(await page.title());",
    "node",
    60);
System.out.println(result.getStdout());

// Stop the session:
client.stopInteractiveBrowser(jobId);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `String` | Scrape job ID from `document.metadata.scrapeId`. |
| `code` | `String` | Code to execute in the browser session. |
| `language` | `String` | Runtime: `"python"`, `"node"`, `"bash"` (default `"node"`). |
| `timeout` | `Integer` | Execution timeout in seconds (1-300, default 30 on API). |
| `origin` | `String` | Origin label for telemetry. |

### Stop session

`client.stopInteractiveBrowser(jobId)` → `BrowserDeleteResponse`

## Notes

- The Java SDK uses `camelCase` parameter names matching the API directly.
- Deprecated aliases: `scrapeExecute` → `interact`, `deleteScrapeBrowser` → `stopInteractiveBrowser`.
- The Java SDK's `interact` method requires `code`; it does not support `prompt`-based natural-language interaction.
- All sync methods have `*Async` counterparts returning `CompletableFuture`.
- `SearchData` returns `List<Map<String, Object>>` rather than typed model objects for search results.
