# Firecrawl Java Agent Quickstart

This file is the canonical quickstart for external agents building with Firecrawl in Java. It is generated from SDK source and the OpenAPI spec.

## Install

### Gradle

```groovy
implementation 'com.firecrawl:firecrawl-java:1.18.0'
```

### Maven

```xml
<dependency>
  <groupId>com.firecrawl</groupId>
  <artifactId>firecrawl-java</artifactId>
  <version>1.18.0</version>
</dependency>
```

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey("fc-YOUR-API-KEY")
    .build();
```

Or use environment variables / system properties:

```java
FirecrawlClient client = FirecrawlClient.fromEnv();
```

The API key is resolved in order: explicit `apiKey()` → `FIRECRAWL_API_KEY` env var → `firecrawl.apiKey` system property. The key is optional — omitting it falls back to a keyless free tier (rate-limited per IP) for scrape, search, and interact.

### Builder options

| Option | Type | Default | Description |
|---|---|---|---|
| `apiKey` | `String` | env/system property | API key. |
| `apiUrl` | `String` | `"https://api.firecrawl.dev"` | API base URL. Falls back to `FIRECRAWL_API_URL` env var. |
| `timeoutMs` | `int` | `300000` | Per-request timeout in milliseconds. |
| `maxRetries` | `int` | `3` | Max auto-retries for transient failures. |
| `backoffFactor` | `double` | `0.5` | Exponential backoff factor. |

## When To Use What

- **`search`** — you start with a query and need to discover pages. Returns ranked web results with optional full-page scraping.
- **`scrape`** — you already have a URL and want its content as markdown, HTML, JSON, or other formats.
- **`interact`** — the page needs post-scrape browser actions: clicking buttons, filling forms, navigating, or extracting dynamic content.

## Search

### Why use it

Search the web with a query and get structured results. Optionally scrape each result page for full content in one call.

### Preferred SDK method

```
client.search(query)
client.search(query, options)
```

### Example

```java
import com.firecrawl.models.SearchOptions;
import com.firecrawl.models.SearchData;

SearchData results = client.search("firecrawl web scraping",
    SearchOptions.builder().limit(5).build());

for (var result : results.getWeb()) {
    System.out.println(result.get("title") + " " + result.get("url"));
}
```

### Parameters

`SearchOptions` — all fields default to `null` (omitted from JSON when null).

| Parameter | Type | Description |
|---|---|---|
| `sources` | `List<Object>` | Source types: `"web"`, `"news"`, `"images"` as strings or maps. |
| `categories` | `List<Object>` | Categories: `"github"`, `"research"`, `"pdf"`. |
| `includeDomains` | `List<String>` | Restrict results to these domains. |
| `excludeDomains` | `List<String>` | Exclude results from these domains. |
| `limit` | `Integer` | Maximum number of results. |
| `tbs` | `String` | Time-based search filter (e.g. `"qdr:d"` for past day). |
| `location` | `String` | Location for geo-targeting (e.g. `"US"`). |
| `country` | `String` | Country code (e.g. `"us"`). |
| `ignoreInvalidURLs` | `Boolean` | Ignore invalid URLs in results. |
| `timeout` | `Integer` | Timeout in milliseconds. |
| `highlights` | `Boolean` | Generate query-relevant highlights. Default: `true` (server-side). |
| `scrapeOptions` | `ScrapeOptions` | Scrape options for each result page. |
| `integration` | `String` | Integration identifier. |

### Response

Returns `SearchData` with:

- `getWeb()` — `List<Map<String, Object>>` of web results
- `getNews()` — `List<Map<String, Object>>` of news results
- `getImages()` — `List<Map<String, Object>>` of image results

## Scrape

### Why use it

Fetch a single URL and get its content as markdown, HTML, JSON extract, screenshot, or other formats.

### Preferred SDK method

```
client.scrape(url)
client.scrape(url, options)
```

### Example

```java
import com.firecrawl.models.Document;
import com.firecrawl.models.ScrapeOptions;

Document doc = client.scrape("https://example.com",
    ScrapeOptions.builder()
        .formats(List.of("markdown"))
        .build());

System.out.println(doc.getMarkdown());
```

### Parameters

`ScrapeOptions` — all fields default to `null` (omitted from JSON when null).

| Parameter | Type | Description |
|---|---|---|
| `formats` | `List<Object>` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"screenshot"`, `"json"`, `"audio"`, `"video"`. Can also be config objects (`JsonFormat`, `QuestionFormat`, `HighlightsFormat`). |
| `headers` | `Map<String, String>` | Custom HTTP request headers. |
| `includeTags` | `List<String>` | HTML tags to include exclusively. |
| `excludeTags` | `List<String>` | HTML tags to exclude. |
| `onlyMainContent` | `Boolean` | Strip boilerplate (navbars, footers). |
| `timeout` | `Integer` | Timeout in milliseconds. |
| `waitFor` | `Integer` | Wait time in ms before scraping. |
| `mobile` | `Boolean` | Emulate a mobile device. |
| `parsers` | `List<Object>` | Parsers (e.g. `"pdf"` or `PdfParser` object). |
| `actions` | `List<Map<String, Object>>` | Browser actions: maps with `type` key (`"wait"`, `"click"`, `"write"`, `"press"`, `"scroll"`, `"scrape"`, `"executeJavascript"`, `"screenshot"`, `"pdf"`). |
| `location` | `LocationConfig` | Proxy routing (`country`, `languages`). |
| `skipTlsVerification` | `Boolean` | Skip TLS certificate verification. |
| `removeBase64Images` | `Boolean` | Remove base64 images from output. |
| `blockAds` | `Boolean` | Block advertisements. |
| `proxy` | `String` | Proxy mode: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. |
| `maxAge` | `Long` | Use cached result if younger than this (ms). |
| `storeInCache` | `Boolean` | Cache the scrape result. |
| `lockdown` | `Boolean` | Serve only cached results. |
| `redactPII` | `Boolean` | Redact personally identifiable information. |
| `auditMetadata` | `AuditMetadata` | User attribution for SIEM logging (`username`). |
| `integration` | `String` | Integration identifier. |

## Interact

### Why use it

After scraping a page, interact with the live browser session — execute Playwright code to click buttons, fill forms, navigate, or extract dynamic content.

### Preferred SDK method

```
client.interact(jobId, code)
client.interact(jobId, code, language, timeout)
client.interact(jobId, code, language, timeout, origin)
```

To stop a session:

```
client.stopInteractiveBrowser(jobId)
```

### Example

```java
import com.firecrawl.models.Document;
import com.firecrawl.models.BrowserExecuteResponse;

Document doc = client.scrape("https://www.amazon.com",
    ScrapeOptions.builder().formats(List.of("markdown")).build());

String scrapeId = (String) doc.getMetadata().get("scrapeId");

BrowserExecuteResponse response = client.interact(scrapeId,
    "await page.fill('input[name=\"field-keywords\"]', 'iPhone 16 Pro Max');\n"
    + "await page.click('input[type=\"submit\"]');");

System.out.println(response.getStdout());

client.stopInteractiveBrowser(scrapeId);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `String` | **Required.** The `scrapeId` from the scrape response's metadata. |
| `code` | `String` | **Required.** Code to execute in the browser sandbox. |
| `language` | `String` | Execution language: `"python"`, `"node"`, `"bash"`. Default: `"node"`. |
| `timeout` | `Integer` | Execution timeout in seconds (1–300). Default: `30`. |
| `origin` | `String` | Request attribution label. Auto-set to `"java-sdk@{version}"`. |

### Response

Returns `BrowserExecuteResponse` with fields:

- `success` — whether execution succeeded
- `stdout` / `result` — standard output from code execution
- `stderr` — standard error from code execution
- `exitCode` — process exit code
- `killed` — whether the process was killed due to timeout
- `error` — error message if an exception was raised

## Notes

- **Naming style**: camelCase for all parameters (e.g. `onlyMainContent`, `includeTags`).
- **Interact difference**: The Java SDK's `interact()` requires `code` (not `prompt`). To use natural-language prompts, pass a prompt string as the `code` field via the HTTP API directly, or write Playwright code.
- **Deprecated aliases**: `scrapeExecute()` → use `interact()`. `deleteScrapeBrowser()` → use `stopInteractiveBrowser()`.
- **Async**: All methods have async variants returning `CompletableFuture` (e.g. `scrapeAsync`, `searchAsync`, `interactAsync`).
- **Keyless mode**: `scrape`, `search`, and `interact` work without an API key at a rate-limited free tier.
