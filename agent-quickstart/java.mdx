# Firecrawl Java Agent Quickstart

Canonical quickstart for external agents. Generated from `firecrawl-java` SDK source (v1.18.4) and the v2 OpenAPI spec.

## Install

Maven:

```xml
<dependency>
  <groupId>com.firecrawl</groupId>
  <artifactId>firecrawl-java</artifactId>
  <version>1.18.4</version>
</dependency>
```

Gradle:

```gradle
implementation("com.firecrawl:firecrawl-java:1.18.4")
```

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey(System.getenv("FIRECRAWL_API_KEY"))
    .build();
```

## When To Use What

- **search**: use when you start with a query and need discovery.
- **scrape**: use when you already have a URL and want page content.
- **interact**: use when the page needs clicks, forms, or post-scrape browser actions.

## Search

### Why use it

Discover relevant pages from a query. Constrain to a domain with `site:`, e.g. `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`client.search(query)` or `client.search(query, options)` → `SearchData`

### Example

```java
import com.firecrawl.models.SearchData;
import java.util.List;
import java.util.Map;

SearchData results = client.search("site:docs.firecrawl.dev webhook retries");
List<Map<String, Object>> web = results.getWeb();
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `String` | Search query. Use `site:example.com` to limit to a domain. |
| `sources` | `List<Object>` | Sources: `"web"`, `"news"`, `"images"` or `{type: "web"}` maps. |
| `categories` | `List<Object>` | Filter by category: `"github"`, `"research"`, `"pdf"`. |
| `includeDomains` | `List<String>` | Only include results from these domains. |
| `excludeDomains` | `List<String>` | Exclude results from these domains. |
| `limit` | `Integer` | Max results. |
| `tbs` | `String` | Time-based filter, e.g. `qdr:d`, `qdr:w`. |
| `location` | `String` | Location string for localized results. |
| `country` | `String` | Country code for geo-targeting. |
| `ignoreInvalidURLs` | `Boolean` | Drop URLs that cannot be scraped. |
| `highlights` | `Boolean` | Generate query-relevant highlights. Defaults to `true`. |
| `timeout` | `Integer` | Request timeout in milliseconds. |
| `scrapeOptions` | `ScrapeOptions` | Options for scraping each search result. See Scrape parameters. |

### Return value

`SearchData` has `getWeb()`, `getNews()`, `getImages()` — each `List<Map<String, Object>>` (may be null).

## Scrape

### Why use it

Get structured content from a URL in one or more formats.

### Preferred SDK method

`client.scrape(url)` or `client.scrape(url, options)` → `Document`

### Example

```java
import com.firecrawl.models.Document;
import com.firecrawl.models.ScrapeOptions;

Document doc = client.scrape(
    "https://docs.firecrawl.dev",
    ScrapeOptions.builder().formats(List.of("markdown")).build()
);
System.out.println(doc.getMarkdown());
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `String` | URL to scrape. |
| `formats` | `List<Object>` | Output formats. Strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"json"`, `"summary"`, `"changeTracking"`, `"attributes"`, `"branding"`, `"audio"`, `"video"`. Also accepts `JsonFormat.builder().prompt("...").build()` and format config maps. |
| `headers` | `Map<String, String>` | Custom HTTP headers. |
| `includeTags` | `List<String>` | Only include content from these HTML tags. |
| `excludeTags` | `List<String>` | Exclude content from these HTML tags. |
| `onlyMainContent` | `Boolean` | Strip nav, footer, and boilerplate. |
| `timeout` | `Integer` | Server-side timeout in milliseconds. |
| `waitFor` | `Integer` | Wait ms before scraping (for JS rendering). |
| `mobile` | `Boolean` | Use mobile viewport. |
| `parsers` | `List<Object>` | File parsers: `"pdf"` or `{type: "pdf", maxPages: n}`. |
| `actions` | `List<Map<String, Object>>` | Browser actions: `wait`, `click`, `write`, `press`, `scroll`, `screenshot`, `scrape`, `executeJavascript`, `pdf`. |
| `location` | `LocationConfig` | Geo targeting: `.country("US").languages(List.of("en-US")).build()`. |
| `skipTlsVerification` | `Boolean` | Skip TLS verification. |
| `removeBase64Images` | `Boolean` | Drop base64 images from markdown. |
| `blockAds` | `Boolean` | Block ads and cookie popups. |
| `proxy` | `String` | Proxy mode: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`, or custom URL. |
| `maxAge` | `Long` | Use cached data up to this age in ms. |
| `storeInCache` | `Boolean` | Cache the result. |
| `lockdown` | `Boolean` | Serve only cached results; 404 on cache miss. |
| `checkPromptInjection` | `Boolean` | Scan for prompt injection. Adds 4 credits. |
| `redactPII` | `Boolean` | Redact personally identifiable information. |
| `auditMetadata` | `AuditMetadata` | User attribution for SIEM logging: `username` field. |
| `profile` | `{ name, saveChanges }` | Persistent browser profile. |

## Interact

### Why use it

Run code in the browser session tied to a scrape job. For multi-step flows, prefer `interact` over scrape-time `actions`.

### Preferred SDK method

- `client.interact(jobId, code)` — defaults to `"node"` language
- `client.interact(jobId, code, language, timeout)` — timeout in seconds (1–300)

### Example

```java
import com.firecrawl.models.BrowserExecuteResponse;

BrowserExecuteResponse result = client.interact(
    "<scrapeJobId>",
    "console.log(await page.title());",
    "node",
    60
);
System.out.println(result.getStdout());
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `String` | Scrape job ID. |
| `code` | `String` | Code to execute in the browser session. |
| `language` | `String` | Execution runtime: `"python"`, `"node"`, `"bash"`. Defaults to `"node"`. |
| `timeout` | `Integer` | Execution timeout in seconds (1–300). Default 30. |

### Stop session

`client.stopInteractiveBrowser(jobId)` ends the browser session. Returns `BrowserDeleteResponse`.

## Notes

- The Java SDK exposes code-based interactions only — there is no `prompt` parameter on `interact` (unlike JS, Python, and Rust SDKs).
- Deprecated aliases: `scrapeExecute` → `interact`, `deleteScrapeBrowser` → `stopInteractiveBrowser`.
- Async variants available: `scrapeAsync`, `searchAsync`, `interactAsync`, `stopInteractiveBrowserAsync`.
- Uses camelCase parameter names (Java convention).
