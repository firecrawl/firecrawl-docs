# Firecrawl Java Agent Quickstart

This file is the canonical quickstart for external agents integrating Firecrawl with Java. It is generated from SDK source plus OpenAPI and covers every confirmed parameter.

## Install

**Gradle:**

```groovy
implementation("com.firecrawl:firecrawl-java:1.18.0")
```

**Maven:**

```xml
<dependency>
  <groupId>com.firecrawl</groupId>
  <artifactId>firecrawl-java</artifactId>
  <version>1.18.0</version>
</dependency>
```

Requires Java 11+.

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey("fc-YOUR-API-KEY")
    .build();
```

Or with options:

```java
FirecrawlClient client = FirecrawlClient.builder()
    .apiKey("fc-YOUR-API-KEY")
    .apiUrl("https://api.firecrawl.dev") // optional, override for self-hosted
    .timeoutMs(300_000L)                 // optional, HTTP timeout in ms (default 300000)
    .maxRetries(3)                       // optional
    .backoffFactor(0.5)                  // optional
    .build();
```

From environment variables:

```java
FirecrawlClient client = FirecrawlClient.fromEnv();
// reads FIRECRAWL_API_KEY env var, then firecrawl.apiKey system property
```

Omitting the API key enables a keyless free tier with IP-based rate limiting.

## When To Use What

- **`search`**: Use when you start with a query and need to discover relevant pages across the web.
- **`scrape`**: Use when you already have a URL and want the page content in a structured format.
- **`interact`**: Use when the page requires clicks, form fills, or other post-scrape browser actions.

## Search

### Why use it

Search the web for a query and get structured results with optional full-page content. Ideal for discovery workflows where you don't yet know which URLs matter.

### Preferred SDK method

```java
client.search(query)
client.search(query, options)
```

### Example

```java
import com.firecrawl.models.SearchOptions;
import com.firecrawl.models.SearchData;

SearchData results = client.search("firecrawl web scraping",
    SearchOptions.builder()
        .limit(5)
        .build()
);

for (var result : results.getWeb()) {
    System.out.println(result);
}
```

### Parameters

`SearchOptions` uses a builder pattern. All fields are nullable.

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `query` | `String` | Search query (first positional argument, required). | Always. |
| `limit` | `Integer` | Max number of results. | Control result count. |
| `sources` | `List<Object>` | Source types: `"web"`, `"news"`, `"images"`. | Filter to specific source types. |
| `categories` | `List<Object>` | Narrow web search: `"github"`, `"research"`, `"pdf"`. | Target specific content types. |
| `includeDomains` | `List<String>` | Restrict results to these domains. | Scope search to known sources. |
| `excludeDomains` | `List<String>` | Exclude results from these domains. | Filter out unwanted sources. |
| `tbs` | `String` | Time-based search filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week). | Restrict to recent content. |
| `location` | `String` | Location string for geo-targeting. | Get location-specific results. |
| `country` | `String` | Country code for geo-targeting (e.g. `"us"`). | Geo-target results by country. |
| `ignoreInvalidURLs` | `Boolean` | Skip invalid URLs instead of failing. | Increase robustness. |
| `timeout` | `Integer` | Timeout in milliseconds. | Override default timeout. |
| `highlights` | `Boolean` | Generate query-relevant highlights. Default: `true` server-side. | Disable if you only need URLs/titles. |
| `scrapeOptions` | `ScrapeOptions` | Options applied when scraping each result page. | Get full page content alongside search results. |

### Async variant

```java
CompletableFuture<SearchData> future = client.searchAsync(query, options);
```

### Return type

`SearchData` with fields: `web`, `news`, `images`.

## Scrape

### Why use it

Fetch a single URL and get its content as markdown, HTML, screenshots, or structured data. The core building block for content extraction.

### Preferred SDK method

```java
client.scrape(url)
client.scrape(url, options)
```

### Example

```java
import com.firecrawl.models.ScrapeOptions;
import com.firecrawl.models.Document;
import java.util.List;

Document doc = client.scrape("https://example.com",
    ScrapeOptions.builder()
        .formats(List.of("markdown"))
        .build()
);

System.out.println(doc.getMarkdown());
```

### Parameters

`ScrapeOptions` uses a builder pattern. All fields are nullable.

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `url` | `String` | URL to scrape (first positional argument, required). | Always. |
| `formats` | `List<Object>` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"screenshot"`, `"json"`, `"audio"`, `"video"`. Also accepts format config objects. | Control what data you get back. |
| `headers` | `Map<String, String>` | Custom HTTP headers. | Set cookies, auth tokens, or user-agent. |
| `includeTags` | `List<String>` | Only include content from these HTML tags. | Extract specific page sections. |
| `excludeTags` | `List<String>` | Exclude content from these HTML tags. | Remove unwanted elements. |
| `onlyMainContent` | `Boolean` | Strip navigation, headers, and footers. | Get clean article content. |
| `timeout` | `Integer` | Timeout in milliseconds. | Override default timeout. |
| `waitFor` | `Integer` | Wait N milliseconds before scraping. | Handle dynamic content. |
| `mobile` | `Boolean` | Emulate a mobile device viewport. | Get mobile version of pages. |
| `parsers` | `List<Object>` | File parser config (e.g. `"pdf"` or `PdfParser` with `maxPages`, `pages`, `blocks`, `pageMarkers`). | Control PDF parsing behavior. |
| `actions` | `List<Map<String, Object>>` | Browser actions to execute before/during scraping. | Automate interactions before scraping. |
| `location` | `LocationConfig` | Geolocation config. | Get geo-specific content. |
| `skipTlsVerification` | `Boolean` | Skip TLS certificate verification. | Scrape sites with self-signed certs. |
| `removeBase64Images` | `Boolean` | Strip base64-encoded images. | Reduce response size. |
| `blockAds` | `Boolean` | Block advertisements. | Get cleaner content. |
| `proxy` | `String` | Proxy type: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. | Bypass blocks or access geo-restricted content. |
| `maxAge` | `Long` | Max cache age in milliseconds. | Control content freshness. |
| `storeInCache` | `Boolean` | Store result in cache. | Enable caching for repeated scrapes. |
| `lockdown` | `Boolean` | Only serve cached results. | Use only cached data. |
| `redactPII` | `Boolean` | Redact personally identifiable information. | Handle sensitive content. |
| `auditMetadata` | `AuditMetadata` | User attribution for SIEM logging. | Enterprise audit trails. |

### Async variant

```java
CompletableFuture<Document> future = client.scrapeAsync(url, options);
```

### Return type

`Document` with fields: `markdown`, `html`, `rawHtml`, `json`, `summary`, `metadata`, `links`, `images`, `screenshot`, `audio`, `video`, and more.

## Interact

### Why use it

Execute code in a live browser session bound to a prior scrape job. Use it for clicking buttons, filling forms, navigating SPAs, or extracting dynamic content that requires interaction.

### Preferred SDK method

```java
client.interact(jobId, code)
client.interact(jobId, code, language, timeout)
client.interact(jobId, code, language, timeout, origin)
```

### Example

```java
Document doc = client.scrape("https://www.amazon.com",
    ScrapeOptions.builder()
        .formats(List.of("markdown"))
        .build()
);

String jobId = (String) doc.getMetadata().get("scrapeId");

var response = client.interact(jobId,
    "Search for iPhone 16 Pro Max",
    "bash",   // language
    30,       // timeout in seconds
    null      // origin
);

System.out.println(response.getStdout());

client.stopInteractiveBrowser(jobId);
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `jobId` | `String` | Scrape job ID from a prior scrape. Required. | Always. |
| `code` | `String` | Code to execute in the browser sandbox. Required. | Always. |
| `language` | `String` | Language: `"python"`, `"node"`, `"bash"`. Default: `"node"`. | Match your code's language. |
| `timeout` | `Integer` | Execution timeout in seconds (1–300). Default: `30` server-side. | Increase for long-running interactions. |
| `origin` | `String` | Origin tag for request attribution. | Request tracking. |

### Stop interaction

```java
client.stopInteractiveBrowser(jobId);
```

Stops the browser session and releases resources. Maps to `DELETE /scrape/{jobId}/interact`.

### Async variants

```java
CompletableFuture<BrowserExecuteResponse> future = client.interactAsync(jobId, code);
CompletableFuture<BrowserDeleteResponse> future = client.stopInteractiveBrowserAsync(jobId);
```

### Return type

`BrowserExecuteResponse` with fields: `success`, `stdout`, `result`, `stderr`, `exitCode`, `killed`, `error`.

## Notes

- **Naming style**: All parameters use camelCase. Builder pattern for options.
- **Deprecated aliases**: `scrapeExecute()` → use `interact()`. `deleteScrapeBrowser()` → use `stopInteractiveBrowser()`.
- **Async support**: All methods have `*Async` variants returning `CompletableFuture`.
- **Keyless mode**: Omitting the API key enables a free tier with IP-based rate limiting.
- **Java interact**: Unlike other SDKs, the Java `interact` method does not accept a `prompt` parameter — use `code` with `language: "bash"` for agent-style interactions.
- **Environment config**: `FirecrawlClient.fromEnv()` reads `FIRECRAWL_API_KEY` env var, then `firecrawl.apiKey` system property.
