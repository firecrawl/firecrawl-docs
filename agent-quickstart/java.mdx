# Firecrawl Java Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`com.firecrawl:firecrawl-java`) and the v2 OpenAPI spec. Method names, parameters, and types match the `FirecrawlClient` public API.

## Install

Maven:

```xml
<dependency>
  <groupId>com.firecrawl</groupId>
  <artifactId>firecrawl-java</artifactId>
  <version>1.18.4</version>
</dependency>
```

Gradle:

```gradle
implementation("com.firecrawl:firecrawl-java:1.18.4")
```

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey(System.getenv("FIRECRAWL_API_KEY"))
    .build();

// or read FIRECRAWL_API_KEY from env / firecrawl.apiKey system property:
// FirecrawlClient client = FirecrawlClient.fromEnv();
```

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs code execution in the browser session after a scrape has created a session.

## Search

### Why use it

Use search to discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:`, for example `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`client.search(query)` or `client.search(query, options)` → `SearchData`

### Example

```java
import com.firecrawl.models.SearchData;
import com.firecrawl.models.SearchOptions;
import java.util.List;
import java.util.Map;

SearchOptions options = SearchOptions.builder()
    .sources(List.of("web", "news"))
    .limit(10)
    .tbs("qdr:m")
    .build();

SearchData results = client.search("site:docs.firecrawl.dev webhook retries", options);
List<Map<String, Object>> web = results.getWeb();
```

### Parameters

- `query`
  - Type: String
  - The search query. Use `site:example.com` to limit results to a domain.

- `options.sources`
  - Type: `List<Object>`
  - Which sources to search. Confirmed values: `"web"`, `"news"`, `"images"`.

- `options.categories`
  - Type: `List<Object>`
  - Filter results by category. Confirmed values: `"github"`, `"research"`, `"pdf"`.

- `options.includeDomains`
  - Type: `List<String>`
  - Restrict results to these domains.

- `options.excludeDomains`
  - Type: `List<String>`
  - Exclude results from these domains. Mutually exclusive with `includeDomains`.

- `options.limit`
  - Type: Integer
  - Maximum number of results.

- `options.tbs`
  - Type: String
  - Time-based search filter (for example `qdr:d` for past day, `qdr:w` for past week).

- `options.location`
  - Type: String
  - Localized search results (for example `"San Francisco,California,United States"`).

- `options.country`
  - Type: String
  - ISO 3166-1 alpha-2 country code for geo-targeting (for example `"us"`).

- `options.ignoreInvalidURLs`
  - Type: Boolean
  - Drop URLs that cannot be scraped by other endpoints.

- `options.highlights`
  - Type: Boolean
  - Generate query-relevant highlights. Defaults to true.

- `options.timeout`
  - Type: Integer
  - Request timeout in milliseconds.

- `options.scrapeOptions`
  - Type: `ScrapeOptions`
  - Scrape each search result page. See Scrape parameters for fields.

- `options.integration`
  - Type: String
  - Integration identifier for server-side tracking.

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK method

`client.scrape(url)` or `client.scrape(url, options)` → `Document`

### Example

```java
import com.firecrawl.models.Document;
import com.firecrawl.models.ScrapeOptions;

Document doc = client.scrape(
    "https://docs.firecrawl.dev",
    ScrapeOptions.builder().formats(List.of("markdown")).build()
);

System.out.println(doc.getMarkdown());
```

### Parameters

- `url`
  - Type: String
  - The URL to scrape.

- `options.formats`
  - Type: `List<Object>`
  - Output formats. Confirmed string values: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"audio"`, `"video"`.
  - Object form for JSON extraction: `JsonFormat.builder().prompt("...").build()`
  - Object form for screenshots: `Map.of("type", "screenshot", "fullPage", true)`
  - Object form for change tracking: `Map.of("type", "changeTracking", "modes", List.of("git-diff"))`

- `options.headers`
  - Type: `Map<String, String>`
  - Custom HTTP headers for the request.

- `options.includeTags`
  - Type: `List<String>`
  - Only include content from these HTML tags.

- `options.excludeTags`
  - Type: `List<String>`
  - Exclude content from these HTML tags.

- `options.onlyMainContent`
  - Type: Boolean
  - Strip nav, footer, and other boilerplate.

- `options.timeout`
  - Type: Integer
  - Timeout in milliseconds.

- `options.waitFor`
  - Type: Integer
  - Wait for page rendering in milliseconds.

- `options.mobile`
  - Type: Boolean
  - Use a mobile viewport.

- `options.parsers`
  - Type: `List<Object>`
  - File parsing controls. Confirmed values: `"pdf"` or `Map.of("type", "pdf", "maxPages", 5)`.

- `options.actions`
  - Type: `List<Map<String, Object>>`
  - Browser actions before scraping. Confirmed types: `wait`, `screenshot`, `click`, `write`, `press`, `scroll`, `scrape`, `executeJavascript`, `pdf`.

- `options.location`
  - Type: `LocationConfig`
  - Geo or language-aware scraping. Fields: `country`, `languages`.

- `options.skipTlsVerification`
  - Type: Boolean
  - Skip TLS certificate verification.

- `options.removeBase64Images`
  - Type: Boolean
  - Drop base64 images from markdown output.

- `options.blockAds`
  - Type: Boolean
  - Block ads and cookie popups.

- `options.proxy`
  - Type: String
  - Proxy control. Confirmed values: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`, or a custom proxy URL.

- `options.maxAge`
  - Type: Long
  - Use cached data up to this age in milliseconds.

- `options.storeInCache`
  - Type: Boolean
  - Cache the result on Firecrawl's side.

- `options.lockdown`
  - Type: Boolean
  - Serve only previously cached results.

- `options.checkPromptInjection`
  - Type: Boolean
  - Scan content for prompt injection attempts. Adds 4 credits per scrape.

- `options.redactPII`
  - Type: Boolean
  - Redact personally identifiable information from output.

- `options.auditMetadata`
  - Type: `AuditMetadata`
  - User attribution for SIEM logging. Field: `username`.

- `options.integration`
  - Type: String
  - Integration identifier for server-side tracking.

## Interact

### Why use it

Use `interact` for code execution in the browser session tied to a scrape job (via `document.getMetadata().get("scrapeId")`). The Java SDK supports code-based interactions only — there is no `prompt` parameter.

### Preferred SDK method

`client.interact(jobId, code)` → `BrowserExecuteResponse`

Overloads:

- `client.interact(jobId, code)` — defaults to language `"node"`
- `client.interact(jobId, code, language, timeout)` — timeout is seconds (1–300), null uses API default
- `client.interact(jobId, code, language, timeout, origin)` — optional origin for request attribution

### Example

```java
import com.firecrawl.models.Document;
import com.firecrawl.models.ScrapeOptions;
import com.firecrawl.models.BrowserExecuteResponse;

Document doc = client.scrape(
    "https://example.com",
    ScrapeOptions.builder().formats(List.of("markdown")).build()
);
String jobId = (String) doc.getMetadata().get("scrapeId");

BrowserExecuteResponse result = client.interact(
    jobId,
    "console.log(await page.title());",
    "node",
    60
);

System.out.println(result.getStdout());

// End the session when done
client.stopInteractiveBrowser(jobId);
```

### Parameters

- `jobId`
  - Type: String
  - The scrape job ID from `document.getMetadata().get("scrapeId")`.

- `code`
  - Type: String
  - Code to execute in the browser session (for example Playwright `page` methods in the `node` runtime).

- `language`
  - Type: String
  - Execution runtime. Confirmed values: `"python"`, `"node"`, `"bash"`. Defaults to `"node"`.

- `timeout`
  - Type: Integer
  - Execution timeout in seconds (1–300). Null uses the API default (30 seconds).

- `origin`
  - Type: String
  - Optional origin label for request attribution.

## Notes

- The Java SDK exposes code-based interactions only: there is no `prompt` parameter on `interact` (unlike Node.js, Python, and Rust SDKs).
- Deprecated aliases: `scrapeExecute` → `interact`, `deleteScrapeBrowser` → `stopInteractiveBrowser`.
- Async variants are available: `interactAsync(...)`, `stopInteractiveBrowserAsync(...)` return `CompletableFuture<...>`.
- `SearchData` results: access `getWeb()`, `getNews()`, `getImages()` — each is `List<Map<String, Object>>` and may be null. Do not treat `SearchData` as a directly iterable list.
- Builder defaults: `timeoutMs` = 300000, `maxRetries` = 3, `backoffFactor` = 0.5.
