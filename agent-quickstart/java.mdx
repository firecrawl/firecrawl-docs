# Firecrawl Java Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl-java`) and the v2 OpenAPI spec.

## Install

Maven:

```xml
<dependency>
  <groupId>com.firecrawl</groupId>
  <artifactId>firecrawl-java</artifactId>
  <version>1.2.0</version>
</dependency>
```

Gradle:

```gradle
implementation("com.firecrawl:firecrawl-java:1.2.0")
```

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey(System.getenv("FIRECRAWL_API_KEY"))
    .build();
```

## When To Use What

- `search`: use when you start with a query and need discovery. Returns web, news, and image results.
- `scrape`: use when you already have a URL and want page content in one or more formats.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions. Requires a scrape job ID from a prior scrape.

## Search

### Why use it

Discover relevant pages from a query, then pick URLs to scrape or interact with. Use `site:example.com` to constrain results to a single domain.

### Preferred SDK method

`client.search(query)` or `client.search(query, options)`

### Example

```java
import com.firecrawl.models.SearchData;
import com.firecrawl.models.SearchOptions;
import com.firecrawl.models.ScrapeOptions;

SearchOptions options = SearchOptions.builder()
    .sources(List.of("web"))
    .limit(5)
    .scrapeOptions(
        ScrapeOptions.builder()
            .formats(List.of("markdown"))
            .onlyMainContent(true)
            .build()
    )
    .build();

SearchData results = client.search("site:docs.firecrawl.dev crawl webhooks", options);
List<Map<String, Object>> web = results.getWeb();
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `query` | String | Search query. Use `site:domain` to scope. | Always required. |
| `options.sources` | List | `"web"`, `"news"`, `"images"`, or typed maps. | Control result buckets. |
| `options.categories` | List | `"developer"`, `"research"`, `"pdf"`, or typed maps. | Filter by category. |
| `options.limit` | Integer | Maximum number of results. | Cap result count. |
| `options.tbs` | String | Time-based filter (e.g. `"qdr:d"`). | Filter by recency. |
| `options.location` | String | Localized results string. | Geo-targeted search. |
| `options.ignoreInvalidURLs` | Boolean | Drop URLs that cannot be scraped. | Clean up results. |
| `options.timeout` | Integer | Request timeout in milliseconds. | Long-running searches. |
| `options.scrapeOptions` | ScrapeOptions | Scrape each search result (same fields as scrape options). | Hydrate search hits with content. |

**Return type:** `SearchData` with `getWeb()`, `getNews()`, `getImages()` (each `List<Map<String, Object>>`, may be null).

## Scrape

### Why use it

Fetch structured content from a known URL in one or more formats (markdown, HTML, JSON extraction, screenshots, etc.).

### Preferred SDK method

`client.scrape(url)` or `client.scrape(url, options)`

### Example

```java
import com.firecrawl.models.ScrapeOptions;
import com.firecrawl.models.JsonFormat;
import com.firecrawl.models.Document;

ScrapeOptions options = ScrapeOptions.builder()
    .formats(List.of(
        "markdown",
        JsonFormat.builder().prompt("Extract plan names and prices.").build()
    ))
    .onlyMainContent(true)
    .waitFor(1000)
    .build();

Document doc = client.scrape("https://example.com/pricing", options);
System.out.println(doc.getMarkdown());
System.out.println(doc.getJson());
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `url` | String | Page URL to scrape. | Always required. |
| `options.formats` | List | Format strings or format maps. Strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"audio"`, `"video"`. Object forms: `JsonFormat.builder().prompt(...).build()`, or maps for screenshot/changeTracking/attributes. | Choose output formats. |
| `options.headers` | `Map<String, String>` | Custom HTTP headers. | Auth or custom user-agent. |
| `options.includeTags` | `List<String>` | Only include these HTML tags. | Narrow content extraction. |
| `options.excludeTags` | `List<String>` | Exclude these HTML tags. | Remove boilerplate elements. |
| `options.onlyMainContent` | Boolean | Strip nav, footer, and boilerplate. | Cleaner output. |
| `options.timeout` | Integer | Timeout in milliseconds. | Long-loading pages. |
| `options.waitFor` | Integer | Wait for page to render (ms). | JS-heavy pages. |
| `options.mobile` | Boolean | Use mobile viewport. | Mobile-specific content. |
| `options.parsers` | `List<Object>` | Parser controls. E.g. `"pdf"` or `Map.of("type", "pdf", "maxPages", 5)`. | PDF or file parsing. |
| `options.actions` | `List<Map<String, Object>>` | Pre-scrape browser actions. Types: `wait`, `click`, `write`, `press`, `scroll`, `screenshot`, `scrape`, `executeJavascript`, `pdf`. | Cookie banners, login flows. |
| `options.location` | LocationConfig | `LocationConfig.builder().country("US").languages(List.of("en-US")).build()`. | Localized content. |
| `options.skipTlsVerification` | Boolean | Skip TLS verification. | Self-signed certs. |
| `options.removeBase64Images` | Boolean | Drop base64 images from markdown. | Reduce output size. |
| `options.blockAds` | Boolean | Block ads and cookie popups. | Cleaner pages. |
| `options.proxy` | String | `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`, or custom URL. | Geo-restricted or bot-protected sites. |
| `options.maxAge` | Long | Use cached data up to this age (ms). | Reduce API calls. |
| `options.storeInCache` | Boolean | Cache the result. | Enable future cache hits. |

## Interact

### Why use it

Control the browser session tied to a scrape job. Use it for code execution in the browser. Requires a scrape job ID from a prior scrape.

### Preferred SDK method

- `client.interact(jobId, code)` — defaults to language `"node"`
- `client.interact(jobId, code, language, timeout)` — `timeout` is seconds (1–300), or null for API default

### Example

```java
import com.firecrawl.models.BrowserExecuteResponse;
import com.firecrawl.models.Document;
import com.firecrawl.models.ScrapeOptions;

Document doc = client.scrape("https://example.com",
    ScrapeOptions.builder().formats(List.of("markdown")).build());
String jobId = (String) doc.getMetadata().get("scrapeId");

BrowserExecuteResponse result = client.interact(
    jobId,
    "console.log(await page.title());",
    "node",
    60
);

System.out.println(result.getStdout());

// When done, stop the session
client.stopInteractiveBrowser(jobId);
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `jobId` | String | Scrape job ID. | Always required. |
| `code` | String | Code to run in the browser session (e.g. Playwright `page` usage). | Programmatic browser control. |
| `language` | String | Runtime: `"python"`, `"node"`, `"bash"`. Default: `"node"`. | Choose execution runtime. |
| `timeout` | Integer | Execution timeout in seconds (1–300). Null uses API default (30s). | Long-running interactions. |

The Java SDK exposes code-based interactions only — there is no `prompt` parameter (unlike some other SDKs).

**Stop session:** `client.stopInteractiveBrowser(jobId)` ends the browser session.

## Notes

- Deprecated aliases: `scrapeExecute` → `interact`; `deleteScrapeBrowser` → `stopInteractiveBrowser`.
- The Java SDK uses camelCase for all parameter names.
- No `prompt` parameter on `interact` — use `code` with Playwright page methods.
- Builder pattern is used for options: `ScrapeOptions.builder()...build()`.
