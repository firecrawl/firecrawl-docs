# Firecrawl Java Agent Quickstart

This file is the canonical quickstart for external agents integrating with Firecrawl using the Java SDK. It is generated from the SDK source (`com.firecrawl:firecrawl-java`) and the OpenAPI spec.

## Install

### Gradle

```groovy
implementation 'com.firecrawl:firecrawl-java:1.18.1'
```

### Maven

```xml
<dependency>
    <groupId>com.firecrawl</groupId>
    <artifactId>firecrawl-java</artifactId>
    <version>1.18.1</version>
</dependency>
```

Requires Java 11+.

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient app = FirecrawlClient.builder()
    .apiKey("fc-YOUR-API-KEY")
    .build();
```

The API key is resolved from: builder `apiKey` > `FIRECRAWL_API_KEY` env var > `firecrawl.apiKey` system property. Omitting the key enables a keyless free tier (rate-limited per IP). Use `FirecrawlClient.fromEnv()` as a convenience when the env var is set.

## When To Use What

- **`search`** — Start with a query, get web results with optional scraping. Use when you need discovery.
- **`scrape`** — Start with a URL, get page content as markdown, HTML, JSON, etc. Use when you already know the page.
- **`interact`** — Execute code in a live browser session bound to a prior scrape. Use when the page needs clicks, forms, or post-scrape browser actions.

## Search

### Why use it

Search the web for a query and get back results with optional page content. Combines discovery and scraping in one call.

### Preferred SDK method

```java
app.search(query)
app.search(query, options)
```

### Example

```java
import com.firecrawl.models.SearchOptions;
import com.firecrawl.models.SearchData;

SearchData results = app.search("firecrawl web scraping",
    SearchOptions.builder()
        .limit(5)
        .build()
);

if (results.getWeb() != null) {
    for (var page : results.getWeb()) {
        System.out.println(page.get("url") + " " + page.get("title"));
    }
}
```

### Parameters

All fields on `SearchOptions` (via builder) are optional and default to `null` (omitted from the request).

| Parameter | Type | Description |
|---|---|---|
| `query` | `String` | **Required** (method arg). The search query. |
| `limit` | `Integer` | Max number of results. |
| `sources` | `List<Object>` | Sources to query: `"web"`, `"news"`, `"images"`, or object form. |
| `categories` | `List<Object>` | Narrow results: `"github"`, `"research"`, `"pdf"`. |
| `includeDomains` | `List<String>` | Only return results from these domains. |
| `excludeDomains` | `List<String>` | Exclude results from these domains. |
| `tbs` | `String` | Time-based filter (e.g. `"qdr:d"` for past day). |
| `location` | `String` | Geographic location string for geo-targeting. |
| `country` | `String` | ISO country code for geo-targeting. |
| `highlights` | `Boolean` | Generate query-relevant highlights. Defaults to `true` server-side. |
| `timeout` | `Integer` | Timeout in milliseconds. |
| `ignoreInvalidURLs` | `Boolean` | Skip invalid URLs in results. |
| `scrapeOptions` | `ScrapeOptions` | Options applied when scraping each result page. |
| `integration` | `String` | Integration identifier. |

## Scrape

### Why use it

Scrape a single URL and get back clean content in your chosen formats — markdown, HTML, structured JSON, screenshots, and more.

### Preferred SDK method

```java
app.scrape(url)
app.scrape(url, options)
```

### Example

```java
import com.firecrawl.models.ScrapeOptions;
import com.firecrawl.models.Document;
import java.util.List;

Document doc = app.scrape("https://example.com",
    ScrapeOptions.builder()
        .formats(List.of("markdown", "html"))
        .onlyMainContent(true)
        .build()
);

System.out.println(doc.getMarkdown());
```

### Parameters

All fields on `ScrapeOptions` (via builder) are optional and default to `null` (omitted from the request).

| Parameter | Type | Description |
|---|---|---|
| `url` | `String` | **Required** (method arg). The URL to scrape. |
| `formats` | `List<Object>` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"screenshot"`, `"json"`, `"audio"`, `"video"`. Also accepts `JsonFormat`, `QuestionFormat`, `HighlightsFormat` objects. |
| `onlyMainContent` | `Boolean` | Extract only main content, excluding navs/footers. |
| `includeTags` | `List<String>` | HTML tags to include in output. |
| `excludeTags` | `List<String>` | HTML tags to exclude from output. |
| `headers` | `Map<String, String>` | Custom HTTP headers for the request. |
| `timeout` | `Integer` | Timeout in milliseconds. |
| `waitFor` | `Integer` | Wait time in ms before scraping (for JS rendering). |
| `mobile` | `Boolean` | Emulate a mobile device. |
| `actions` | `List<Map<String, Object>>` | Browser actions as maps with `type` key and action-specific fields. |
| `location` | `LocationConfig` | Proxy location with `country` and `languages`. |
| `proxy` | `String` | Proxy type: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. |
| `blockAds` | `Boolean` | Block ads and cookie popups. |
| `skipTlsVerification` | `Boolean` | Skip TLS certificate verification. |
| `removeBase64Images` | `Boolean` | Strip base64 images from output. |
| `parsers` | `List<Object>` | Document parsers: `"pdf"` string or `PdfParser` objects. |
| `maxAge` | `Long` | Max cache age in milliseconds. |
| `storeInCache` | `Boolean` | Store the result in Firecrawl's index. |
| `lockdown` | `Boolean` | Only serve cached results; no outbound requests. |
| `redactPII` | `Boolean` | Redact personally identifiable information. |
| `auditMetadata` | `AuditMetadata` | User attribution for SIEM logging. |
| `integration` | `String` | Integration identifier. |

## Interact

### Why use it

Execute code in a live browser session that was opened by a prior scrape. Use it for clicking buttons, filling forms, navigating, or any post-scrape browser automation.

### Preferred SDK method

```java
app.interact(jobId, code)
app.interact(jobId, code, language, timeout)
```

### Example

```java
import com.firecrawl.models.BrowserExecuteResponse;
import com.firecrawl.models.BrowserDeleteResponse;

Document doc = app.scrape("https://www.amazon.com",
    ScrapeOptions.builder()
        .formats(List.of("markdown"))
        .build()
);

String scrapeId = (String) doc.getMetadata().get("scrapeId");

app.interact(scrapeId, "Search for iPhone 16 Pro Max", "bash", null);
BrowserExecuteResponse response = app.interact(
    scrapeId,
    "Click on the first result and tell me the price",
    "bash",
    null
);
System.out.println(response.getResult());

BrowserDeleteResponse stopped = app.stopInteractiveBrowser(scrapeId);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `String` | **Required.** The scrape job ID from metadata. |
| `code` | `String` | **Required.** Code to execute in the browser sandbox. |
| `language` | `String` | Language: `"python"`, `"node"`, or `"bash"`. Default: `"node"`. |
| `timeout` | `Integer` | Execution timeout in seconds (1-300). Default: `30`. |
| `origin` | `String` | Origin tag for request attribution. |

**Stop the session** when done:

```java
app.stopInteractiveBrowser(jobId);
```

## Notes

- **Naming style**: All parameter names are camelCase (Java convention).
- **Deprecated aliases**: `scrapeExecute` → `interact`, `deleteScrapeBrowser` → `stopInteractiveBrowser`. Use the preferred names.
- **Async variants**: Every sync method has an async counterpart returning `CompletableFuture<T>`: `scrapeAsync`, `searchAsync`, `interactAsync`, `stopInteractiveBrowserAsync`.
- **Builder pattern**: `ScrapeOptions`, `SearchOptions`, `LocationConfig`, `JsonFormat`, `QuestionFormat`, `HighlightsFormat`, `PdfParser`, and `AuditMetadata` all use builders.
- **Java interact limitation**: The Java SDK's `interact` method takes `code` as a required parameter. To use natural-language prompts, pass them as `code` with `language` set to `"bash"` (the API accepts prompts in the `code` field when the server-side agent is enabled).
