# Firecrawl Java Agent Quickstart

This is the canonical quickstart for external agents integrating with Firecrawl using the Java SDK. Generated from SDK source and OpenAPI spec.

## Install

Maven:

```xml
<dependency>
    <groupId>com.firecrawl</groupId>
    <artifactId>firecrawl-java</artifactId>
    <version>1.18.7</version>
</dependency>
```

Gradle:

```groovy
implementation 'com.firecrawl:firecrawl-java:1.18.7'
```

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey("fc-YOUR_API_KEY")
    .build();

// Or from environment variable (reads FIRECRAWL_API_KEY):
FirecrawlClient client = FirecrawlClient.fromEnv();
```

### Builder options

| Option | Default | Description |
|--------|---------|-------------|
| `apiKey(String)` | env `FIRECRAWL_API_KEY` | API key for authentication. |
| `apiUrl(String)` | `https://api.firecrawl.dev` | API base URL. Also reads `FIRECRAWL_API_URL` env var. |
| `timeoutMs(long)` | `300000` (5 min) | Request timeout in milliseconds. |
| `maxRetries(int)` | `3` | Maximum number of retries. |
| `backoffFactor(double)` | `0.5` | Exponential backoff factor. |

## When To Use What

- **search** — start with a query and discover relevant URLs with optional page content. Use when you don't have a URL yet.
- **scrape** — start with a known URL and extract page content in various formats. Use when you already know which page you need.
- **interact** — execute code in a browser session bound to a prior scrape. Use when the page needs post-scrape browser interaction like clicking, typing, or navigating.

## Search

### Why use it

Search finds pages matching a query across web, news, and image sources, and optionally returns their scraped content. Use it for discovery when you need to find relevant URLs.

### Preferred SDK method

```java
client.search(query)
client.search(query, options)
```

Async variant: `client.searchAsync(query, options)` returns `CompletableFuture<SearchData>`.

### Example

```java
import com.firecrawl.client.FirecrawlClient;
import com.firecrawl.client.models.SearchOptions;
import com.firecrawl.client.models.ScrapeOptions;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey("fc-YOUR_API_KEY")
    .build();

SearchData result = client.search("firecrawl web scraping API",
    SearchOptions.builder()
        .limit(5)
        .scrapeOptions(ScrapeOptions.builder()
            .formats(List.of("markdown"))
            .build())
        .build());

for (var item : result.getWeb()) {
    System.out.println(item.get("url"));
}
```

### Parameters

`SearchOptions` builder fields:

| Parameter | Type | Description |
|-----------|------|-------------|
| `sources` | `List<Object>` | Sources: `"web"`, `"news"`, `"images"`, or map objects. Default: `["web"]`. |
| `categories` | `List<Object>` | Filter: `"github"`, `"research"`, `"pdf"`. |
| `includeDomains` | `List<String>` | Restrict results to these domains. |
| `excludeDomains` | `List<String>` | Exclude results from these domains. |
| `limit` | `Integer` | Max results per source type. |
| `tbs` | `String` | Time-based search filter (e.g. `"qdr:d"` for past day). |
| `location` | `String` | Location for geo-targeted results. |
| `country` | `String` | ISO country code (e.g. `"US"`). |
| `ignoreInvalidURLs` | `Boolean` | Exclude invalid URLs. |
| `timeout` | `Integer` | Timeout in milliseconds. |
| `highlights` | `Boolean` | Generate query-relevant highlights. Default: `true`. |
| `scrapeOptions` | `ScrapeOptions` | Options for scraping each result page. |

## Scrape

### Why use it

Scrape extracts structured content from a single URL. Returns markdown, HTML, links, screenshots, structured JSON, and more depending on the formats you request.

### Preferred SDK method

```java
client.scrape(url)
client.scrape(url, options)
```

Async variant: `client.scrapeAsync(url, options)` returns `CompletableFuture<Document>`.

### Example

```java
import com.firecrawl.client.models.ScrapeOptions;

Document result = client.scrape("https://example.com",
    ScrapeOptions.builder()
        .formats(List.of("markdown", "links"))
        .onlyMainContent(true)
        .timeout(30000)
        .build());

System.out.println(result.getMarkdown());
System.out.println(result.getLinks());
```

### Parameters

`ScrapeOptions` builder fields:

| Parameter | Type | Description |
|-----------|------|-------------|
| `formats` | `List<Object>` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"screenshot"`, `"json"`, `"audio"`, `"video"`, etc. Default: `["markdown"]`. |
| `onlyMainContent` | `Boolean` | Strip navs, footers, and boilerplate. Default: `true`. |
| `includeTags` | `List<String>` | HTML tags to include (allowlist). |
| `excludeTags` | `List<String>` | HTML tags to exclude (blocklist). |
| `headers` | `Map<String, String>` | Custom HTTP headers. |
| `waitFor` | `Integer` | Delay in ms before fetching. Max 60000. |
| `timeout` | `Integer` | Timeout in milliseconds. Min 1000, max 300000. Default: 60000. |
| `mobile` | `Boolean` | Emulate a mobile device. |
| `skipTlsVerification` | `Boolean` | Skip TLS certificate verification. Default: `true`. |
| `removeBase64Images` | `Boolean` | Strip base64-encoded images. Default: `true`. |
| `blockAds` | `Boolean` | Block ads and cookie popups. Default: `true`. |
| `proxy` | `String` | Proxy mode: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. Default: `"auto"`. |
| `actions` | `List<Map<String, Object>>` | Browser actions before scraping. |
| `location` | `LocationConfig` | Location: `country`, `languages`. |
| `parsers` | `List<Object>` | File parsers (e.g. PDF). |
| `maxAge` | `Long` | Max cache age in ms. Default: 172800000 (2 days). |
| `storeInCache` | `Boolean` | Store result in cache. Default: `true`. |
| `lockdown` | `Boolean` | Serve from cache only. |
| `checkPromptInjection` | `Boolean` | Scan for prompt injection. Adds 4 credits. |
| `redactPII` | `Boolean` | Redact PII from markdown. |
| `auditMetadata` | `AuditMetadata` | SIEM logging attribution. |

## Interact

### Why use it

Interact lets you execute code in the browser session that was opened by a prior scrape. You write JavaScript, Python, or Bash code that runs in the browser sandbox — use it to click buttons, fill forms, navigate pages, or extract dynamic content that requires post-scrape interaction.

### Preferred SDK method

```java
client.interact(jobId, code)
client.interact(jobId, code, language, timeout)
```

Async variant: `client.interactAsync(jobId, code, language, timeout)` returns `CompletableFuture<BrowserExecuteResponse>`.

### Example

```java
// First scrape a page — the browser session stays open
Document scrapeResult = client.scrape("https://example.com/app",
    ScrapeOptions.builder()
        .formats(List.of("markdown"))
        .build());

String jobId = scrapeResult.getMetadata().getJobId();

// Execute code in the browser session
BrowserExecuteResponse result = client.interact(jobId,
    """
    await page.click('#login-button');
    await page.fill('#username', 'user@example.com');
    await page.fill('#password', 'secret');
    await page.click('#submit');
    await page.waitForSelector('.dashboard');
    return await page.content();
    """,
    "node",  // language
    30       // timeout in seconds
);

System.out.println(result.getOutput());

// Stop the browser session when done
client.stopInteractiveBrowser(jobId);
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `jobId` | `String` | The scrape job ID from a prior scrape (required). |
| `code` | `String` | Code to execute in the browser sandbox (required). Max 100000 chars. |
| `language` | `String` | Runtime language: `"python"`, `"node"`, `"bash"`. Default: `"node"`. |
| `timeout` | `Integer` | Execution timeout in seconds. Min 1, max 300. Default: 30. |
| `origin` | `String` | Optional origin tag for request attribution. |

**Related methods:**

| Method | Description |
|--------|-------------|
| `client.stopInteractiveBrowser(jobId)` | Stops the interactive browser session. |

## Notes

- All parameter names use camelCase, matching Java conventions.
- Uses the builder pattern for request construction.
- The client is created via `FirecrawlClient.builder()` or `FirecrawlClient.fromEnv()`.
- Deprecated aliases: `scrapeExecute()` → use `interact()`, `deleteScrapeBrowser()` → use `stopInteractiveBrowser()`.
- Java 11+ is required.
