# Firecrawl Java Agent Quickstart

Canonical quickstart for agents using the Firecrawl Java SDK. Generated from SDK source and OpenAPI spec.

## Install

Maven:

```xml
<dependency>
    <groupId>com.firecrawl</groupId>
    <artifactId>firecrawl-java</artifactId>
    <version>1.18.0</version>
</dependency>
```

Gradle:

```groovy
implementation "com.firecrawl:firecrawl-java:1.18.0"
```

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey("fc-YOUR_API_KEY")
    .build();

// Or read from FIRECRAWL_API_KEY env var or firecrawl.apiKey system property:
FirecrawlClient client = FirecrawlClient.fromEnv();
```

No API key is required for `scrape`, `search`, and `interact` on the keyless free tier (rate-limited per IP).

## When To Use What

- **`search`**: Start with a query and get back relevant web pages. Use when you need discovery: finding URLs, getting search results with optional full-page scraping.
- **`scrape`**: Start with a URL and get page content back. Use when you already know the page you want and need its markdown, HTML, structured data, or screenshots.
- **`interact`**: Execute code in a live browser session bound to a prior scrape. Use when the page needs clicks, form fills, or post-scrape browser automation.

## Search

### Why use it

Search the web through Firecrawl and optionally scrape each result page in a single call. Returns grouped results by source type (web, news, images).

### Preferred SDK method

```java
client.search(query)
client.search(query, options)
```

### Example

```java
import com.firecrawl.models.SearchOptions;
import com.firecrawl.models.ScrapeOptions;
import com.firecrawl.models.SearchData;

SearchData results = client.search("firecrawl web scraping API",
    SearchOptions.builder()
        .limit(5)
        .scrapeOptions(ScrapeOptions.builder()
            .formats(List.of("markdown"))
            .build())
        .build()
);

for (var page : results.getWeb()) {
    System.out.println(page.get("url") + " " + page.get("title"));
}
```

### Parameters

`SearchOptions` uses a builder pattern. All fields are optional:

| Parameter | Type | Description |
|---|---|---|
| `query` | `String` (required, method arg) | The search query string. |
| `sources` | `List<Object>` | Source types: `"web"`, `"news"`, `"images"`, or config maps. |
| `categories` | `List<Object>` | Categories: `"github"`, `"research"`, `"pdf"`. |
| `includeDomains` | `List<String>` | Only include results from these domains. |
| `excludeDomains` | `List<String>` | Exclude results from these domains. |
| `limit` | `Integer` | Maximum number of results. |
| `tbs` | `String` | Time-based search filter (e.g. `"qdr:d"` for past day). |
| `location` | `String` | Location string for geographic targeting. |
| `country` | `String` | Country code for geo-targeted results. |
| `ignoreInvalidURLs` | `Boolean` | Skip invalid URLs in results. |
| `timeout` | `Integer` | Timeout in milliseconds. |
| `highlights` | `Boolean` | Generate query-relevant highlights. Default: `true`. |
| `scrapeOptions` | `ScrapeOptions` | Scrape options applied to each result page. |
| `integration` | `String` | Integration identifier. |

Async variant: `client.searchAsync(query, options)` returns `CompletableFuture<SearchData>`.

## Scrape

### Why use it

Scrape a single URL and get back structured page data: markdown, HTML, screenshots, extracted JSON, and more.

### Preferred SDK method

```java
client.scrape(url)
client.scrape(url, options)
```

### Example

```java
import com.firecrawl.models.ScrapeOptions;
import com.firecrawl.models.Document;

Document doc = client.scrape("https://example.com",
    ScrapeOptions.builder()
        .formats(List.of("markdown", "screenshot"))
        .onlyMainContent(true)
        .build()
);

System.out.println(doc.getMarkdown());
System.out.println(doc.getScreenshot());
```

### Parameters

`ScrapeOptions` uses a builder pattern. All fields are optional:

| Parameter | Type | Description |
|---|---|---|
| `url` | `String` (required, method arg) | The URL to scrape. |
| `formats` | `List<Object>` | Output formats. Strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"screenshot"`, `"json"`, `"audio"`, `"video"`. Also accepts format config objects (`JsonFormat`, `QuestionFormat`, `HighlightsFormat`). |
| `headers` | `Map<String, String>` | Custom HTTP headers. |
| `includeTags` | `List<String>` | HTML tags to include. |
| `excludeTags` | `List<String>` | HTML tags to exclude. |
| `onlyMainContent` | `Boolean` | Strip headers, navs, footers. |
| `timeout` | `Integer` | Request timeout in milliseconds. |
| `waitFor` | `Integer` | Wait this many ms after page load before scraping. |
| `mobile` | `Boolean` | Emulate a mobile device viewport. |
| `parsers` | `List<Object>` | Parsers to use (e.g. `"pdf"` or `PdfParser` config). |
| `actions` | `List<Map<String, Object>>` | Browser actions before scraping. |
| `location` | `LocationConfig` | Proxy routing: `{ country, languages }`. |
| `skipTlsVerification` | `Boolean` | Skip TLS certificate verification. |
| `removeBase64Images` | `Boolean` | Strip base64-encoded images from output. |
| `blockAds` | `Boolean` | Block ads and cookie popups. |
| `proxy` | `String` | Proxy mode: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`, or a custom URL. |
| `maxAge` | `Long` | Use cached result if younger than this many ms. |
| `storeInCache` | `Boolean` | Cache the scrape result. |
| `lockdown` | `Boolean` | Only serve cached results. |
| `redactPII` | `Boolean` | Redact personally identifiable information. |
| `auditMetadata` | `AuditMetadata` | SIEM logging: `{ username }`. |
| `integration` | `String` | Integration identifier. |

Async variant: `client.scrapeAsync(url, options)` returns `CompletableFuture<Document>`.

## Interact

### Why use it

Execute code in a live browser session that was opened by a prior `scrape` call. Use this for clicks, form fills, or arbitrary code execution.

### Preferred SDK method

```java
client.interact(jobId, code)
client.interact(jobId, code, language, timeout)
client.interact(jobId, code, language, timeout, origin)
```

### Example

```java
import com.firecrawl.models.BrowserExecuteResponse;

// Interact with a prior scrape session
BrowserExecuteResponse result = client.interact(
    "job-id-from-scrape",
    "document.querySelector('button.load-more').click();",
    "node",   // language
    30        // timeout in seconds
);

System.out.println(result.getStdout());
System.out.println(result.getResult());

// Stop the session when done
client.stopInteractiveBrowser(jobId);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `String` (required) | The scrape job ID from a prior scrape call. |
| `code` | `String` (required) | Code to execute in the browser sandbox. |
| `language` | `String` | Execution language: `"python"`, `"node"`, `"bash"`. Default: `"node"`. |
| `timeout` | `Integer` | Execution timeout in seconds (1–300). Default: server-side 30. |
| `origin` | `String` | Origin tag for attribution. Default: `"java-sdk@{version}"`. |

Stop the browser session when done:

```java
client.stopInteractiveBrowser(jobId);
```

Async variants: `client.interactAsync(...)` and `client.stopInteractiveBrowserAsync(jobId)` return `CompletableFuture`.

## Notes

- **camelCase parameters**: The Java SDK uses camelCase for all option names (`onlyMainContent`, `includeTags`, etc.).
- **Builder pattern**: `ScrapeOptions` and `SearchOptions` use builder pattern: `ScrapeOptions.builder().formats(...).build()`.
- **Deprecated aliases**: `scrapeExecute` / `scrapeExecuteAsync` → `interact` / `interactAsync`, `deleteScrapeBrowser` / `deleteScrapeBrowserAsync` → `stopInteractiveBrowser` / `stopInteractiveBrowserAsync`. Use the modern names.
- **Async support**: Every method has an async variant returning `CompletableFuture<T>`.
- **Return types**: `scrape()` returns `Document`, `search()` returns `SearchData` (with `getWeb()`, `getNews()`, `getImages()` lists), `interact()` returns `BrowserExecuteResponse`.
