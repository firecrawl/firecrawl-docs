# Firecrawl Java Agent Quickstart

Canonical quickstart for external agents. Generated from Java SDK source (`com.firecrawl:firecrawl-java` **1.18.7**) and the v2 OpenAPI spec. Method names, parameters, and types match the SDK public API.

## Install

Maven:

```xml
<dependency>
  <groupId>com.firecrawl</groupId>
  <artifactId>firecrawl-java</artifactId>
  <version>1.18.7</version>
</dependency>
```

Gradle:

```gradle
implementation("com.firecrawl:firecrawl-java:1.18.7")
```

## Authenticate

```java
import com.firecrawl.client.FirecrawlClient;

FirecrawlClient client = FirecrawlClient.builder()
    .apiKey(System.getenv("FIRECRAWL_API_KEY"))
    .build();

// Or read FIRECRAWL_API_KEY from the environment automatically:
// FirecrawlClient client = FirecrawlClient.fromEnv();
```

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions. The Java SDK supports code-based interactions only (no `prompt` parameter).

## Search

### Why use it

Use search to discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:`, for example `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`client.search(query)` or `client.search(query, options)` → `SearchData`

### Example

```java
import com.firecrawl.models.SearchData;
import com.firecrawl.models.SearchOptions;
import com.firecrawl.models.ScrapeOptions;
import java.util.List;
import java.util.Map;

// Simple
SearchData results = client.search("site:docs.firecrawl.dev webhook retries");
List<Map<String, Object>> web = results.getWeb();

// With options
SearchOptions options = SearchOptions.builder()
    .sources(List.of("web", "news"))
    .categories(List.of("research"))
    .limit(10)
    .tbs("qdr:m")
    .location("San Francisco,California,United States")
    .ignoreInvalidURLs(true)
    .timeout(60000)
    .scrapeOptions(
        ScrapeOptions.builder()
            .formats(List.of("markdown", "links"))
            .onlyMainContent(true)
            .build()
    )
    .build();

SearchData filtered = client.search("site:docs.firecrawl.dev crawl webhooks", options);
```

**Return value:** `SearchData` with `getWeb()`, `getNews()`, `getImages()`. Each is `List<Map<String, Object>>` and may be null. Do not treat `SearchData` as a flat list — access results through the typed getters.

### Parameters

- `query`
  - Type: String
  - The search query. Use `site:example.com` to limit results to a domain.

- `options.sources`
  - Type: `List<Object>`
  - Which sources to search.
  - Confirmed values: `"web"`, `"news"`, `"images"`

- `options.categories`
  - Type: `List<Object>`
  - Filter results by category.
  - Confirmed values: `"github"`, `"research"`, `"pdf"`

- `options.includeDomains`
  - Type: `List<String>`
  - Restrict results to these domains.

- `options.excludeDomains`
  - Type: `List<String>`
  - Exclude results from these domains.

- `options.limit`
  - Type: Integer
  - Cap the number of results.

- `options.tbs`
  - Type: String
  - Time-based filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week).

- `options.location`
  - Type: String
  - Localized results (e.g. `"San Francisco,California,United States"`).

- `options.country`
  - Type: String
  - ISO country code for geo-targeting (e.g. `"us"`).

- `options.ignoreInvalidURLs`
  - Type: Boolean
  - Drop URLs that cannot be scraped by other endpoints.

- `options.timeout`
  - Type: Integer
  - Request timeout in milliseconds.

- `options.highlights`
  - Type: Boolean
  - Generate query-relevant highlights.

- `options.scrapeOptions`
  - Type: `ScrapeOptions`
  - Scrape each search result inline. See Scrape parameters below.

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK method

`client.scrape(url)` or `client.scrape(url, options)` → `Document`

### Example

```java
import com.firecrawl.models.Document;
import com.firecrawl.models.ScrapeOptions;
import com.firecrawl.models.JsonFormat;
import com.firecrawl.models.LocationConfig;
import java.util.List;
import java.util.Map;

// Simple
Document doc = client.scrape(
    "https://docs.firecrawl.dev",
    ScrapeOptions.builder().formats(List.of("markdown")).build()
);
System.out.println(doc.getMarkdown());

// With options
ScrapeOptions options = ScrapeOptions.builder()
    .formats(List.of(
        "markdown",
        "links",
        JsonFormat.builder().prompt("Extract plan names and prices.").build()
    ))
    .onlyMainContent(true)
    .waitFor(1000)
    .actions(List.of(
        Map.of("type", "click", "selector", "#accept"),
        Map.of("type", "wait", "milliseconds", 750),
        Map.of("type", "scrape")
    ))
    .location(LocationConfig.builder().country("US").languages(List.of("en-US")).build())
    .blockAds(true)
    .proxy("auto")
    .build();

Document detailed = client.scrape("https://example.com/pricing", options);
```

### Parameters

- `url`
  - Type: String
  - The URL to scrape.

- `options.formats`
  - Type: `List<Object>`
  - Output formats to request.
  - Confirmed string values: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"audio"`, `"video"`
  - Use `JsonFormat.builder().prompt("...").build()` for structured JSON extraction.

- `options.headers`
  - Type: `Map<String, String>`
  - Custom HTTP request headers.

- `options.includeTags`
  - Type: `List<String>`
  - Include only content from these HTML tags.

- `options.excludeTags`
  - Type: `List<String>`
  - Exclude content from these HTML tags.

- `options.onlyMainContent`
  - Type: Boolean
  - Strip nav, footer, and other boilerplate.

- `options.timeout`
  - Type: Integer
  - Timeout in milliseconds.

- `options.waitFor`
  - Type: Integer
  - Wait for the page to render before scraping (milliseconds).

- `options.mobile`
  - Type: Boolean
  - Emulate a mobile viewport.

- `options.parsers`
  - Type: `List<Object>`
  - File parsing controls.
  - Confirmed values: `"pdf"`, `Map.of("type", "pdf", "maxPages", 5)`

- `options.actions`
  - Type: `List<Map<String, Object>>`
  - Pre-scrape browser actions.
  - Confirmed types: `wait`, `screenshot`, `click`, `write`, `press`, `scroll`, `scrape`, `executeJavascript`, `pdf`

- `options.location`
  - Type: `LocationConfig`
  - Geo or language-aware scraping. Builder fields: `country`, `languages`.

- `options.skipTlsVerification`
  - Type: Boolean
  - Skip TLS certificate verification.

- `options.removeBase64Images`
  - Type: Boolean
  - Drop base64 images from markdown output.

- `options.blockAds`
  - Type: Boolean
  - Block ads and cookie popups.

- `options.proxy`
  - Type: String
  - Proxy control.
  - Confirmed values: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`

- `options.maxAge`
  - Type: Long
  - Use cached data up to this age (milliseconds).

- `options.storeInCache`
  - Type: Boolean
  - Cache the scrape result.

- `options.lockdown`
  - Type: Boolean
  - Serve only previously cached results.

- `options.checkPromptInjection`
  - Type: Boolean
  - Scan scraped content for prompt injection (adds 4 credits).

## Interact

### Why use it

Use interact for code-based control of the browser session tied to a scrape job (via `metadata.scrapeId`). The Java SDK supports code execution only — there is no `prompt` parameter.

### Preferred SDK method

- `client.interact(jobId, code)` — uses default language `"node"`
- `client.interact(jobId, code, language, timeout)` — specify language and timeout

### Example

```java
import com.firecrawl.models.BrowserExecuteResponse;
import com.firecrawl.models.BrowserDeleteResponse;

// Scrape first to get a job ID
Document doc = client.scrape(
    "https://example.com",
    ScrapeOptions.builder().formats(List.of("markdown")).build()
);
String jobId = (String) doc.getMetadata().get("scrapeId");

// Execute code in the browser session
BrowserExecuteResponse result = client.interact(
    jobId,
    "console.log(await page.title());",
    "node",
    60
);
System.out.println(result.getStdout());

// Stop the session when done
BrowserDeleteResponse stopped = client.stopInteractiveBrowser(jobId);
```

### Parameters

- `jobId`
  - Type: String
  - The scrape job ID from `document.getMetadata().get("scrapeId")`.

- `code`
  - Type: String
  - Code to execute in the browser session.

- `language`
  - Type: String
  - Runtime for code execution.
  - Confirmed values: `"python"`, `"node"`, `"bash"`
  - Default: `"node"`

- `timeout`
  - Type: Integer
  - Execution timeout in seconds (1–300). Pass `null` to use the API default (30 seconds).

- `origin`
  - Type: String
  - Optional origin label for request attribution. Only available on the five-argument overload.

## Notes

- The Java SDK exposes code-based interactions only: there is no `prompt` parameter on `interact` (unlike some other SDKs that support natural-language browser instructions).
- Deprecated aliases: `scrapeExecute` → `interact`, `deleteScrapeBrowser` → `stopInteractiveBrowser` (and their `*Async` counterparts).
- Async variants available: `scrapeAsync`, `searchAsync`, `interactAsync`, `stopInteractiveBrowserAsync`.
- `SearchData` results are accessed via `getWeb()`, `getNews()`, `getImages()` — not a flat list.
