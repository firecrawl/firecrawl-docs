# Firecrawl Rust Agent Quickstart

Canonical quickstart for external agents using the Firecrawl Rust SDK. Generated from SDK source (`firecrawl` crate) and the v2 OpenAPI spec. Method names, parameters, and types match the public API.

## Install

```bash
cargo add firecrawl
```

Crate: **`firecrawl`** on crates.io.

## Authenticate

```rust
use firecrawl::Client;

let client = Client::new("fc-your-api-key")?;
// Self-hosted:
// let client = Client::new_selfhosted("http://localhost:3002", Some("fc-your-api-key"))?;
```

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions.

## Search

### Why use it

Use search to discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:`, for example `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`client.search(query, options)` → `Result<SearchResponse, FirecrawlError>`

### Example

```rust
use firecrawl::{Client, SearchOptions, SearchSource, SearchCategory, ScrapeOptions, Format};

let client = Client::new("fc-your-api-key")?;

// Simple
let results = client.search("site:docs.firecrawl.dev webhook retries", None).await?;

// With options
let options = SearchOptions {
    sources: Some(vec![SearchSource::Web, SearchSource::News]),
    categories: Some(vec![SearchCategory::Research]),
    limit: Some(10),
    tbs: Some("qdr:m".to_string()),
    location: Some("San Francisco,California,United States".to_string()),
    ignore_invalid_urls: Some(true),
    timeout: Some(60000),
    scrape_options: Some(ScrapeOptions {
        formats: Some(vec![Format::Markdown, Format::Links]),
        only_main_content: Some(true),
        ..Default::default()
    }),
    ..Default::default()
};

let results = client.search("site:docs.firecrawl.dev crawl webhooks", options).await?;
```

### Parameters

- `query`
  - Type: `impl AsRef<str>`
  - The search query string. Use `site:example.com` to limit results to a domain.

- `options` (optional `SearchOptions`, all fields `Option` with `Default` derived)

- `options.limit`
  - Type: `Option<u32>`
  - Max number of results. Default: 5, max: 20.

- `options.sources`
  - Type: `Option<Vec<SearchSource>>`
  - Which sources to search. Values: `Web`, `News`, `Images`, `Alexandria`.

- `options.categories`
  - Type: `Option<Vec<SearchCategory>>`
  - Filter results by category. Values: `Github`, `Research`, `Pdf`.

- `options.include_domains`
  - Type: `Option<Vec<String>>`
  - Restrict results to these domains.

- `options.exclude_domains`
  - Type: `Option<Vec<String>>`
  - Exclude results from these domains.

- `options.tbs`
  - Type: `Option<String>`
  - Time-based filter (e.g. `qdr:d` for past day, `qdr:w` for past week).

- `options.location`
  - Type: `Option<String>`
  - Geographic location for localized results.

- `options.country`
  - Type: `Option<String>`
  - ISO 3166-1 alpha-2 country code for geo-targeting.

- `options.ignore_invalid_urls`
  - Type: `Option<bool>`
  - Drop URLs that cannot be scraped by other endpoints.

- `options.timeout`
  - Type: `Option<u32>`
  - Request timeout in milliseconds.

- `options.highlights`
  - Type: `Option<bool>`
  - Generate query-relevant highlights. Default: true.

- `options.scrape_options`
  - Type: `Option<ScrapeOptions>`
  - Scrape each search result with these options. See Scrape parameters.

- `options.domain_tools`
  - Type: `Option<bool>`
  - Include domain-matched Alexandria tool contracts.

- `options.tool_detail`
  - Type: `Option<ToolDetail>`
  - Tool contract verbosity. Values: `Compact`, `Summary`, `Full`.

- `options.integration`
  - Type: `Option<String>`
  - Integration identifier for server-side tracking.

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK method

`client.scrape(url, options)` → `Result<Document, FirecrawlError>`

### Example

```rust
use firecrawl::{Client, ScrapeOptions, Format, JsonOptions, Action, ProxyType};

let client = Client::new("fc-your-api-key")?;

// Simple
let doc = client
    .scrape("https://docs.firecrawl.dev", ScrapeOptions {
        formats: Some(vec![Format::Markdown]),
        ..Default::default()
    })
    .await?;

// With options
let doc = client
    .scrape("https://example.com/pricing", ScrapeOptions {
        formats: Some(vec![Format::Markdown, Format::Links, Format::Json]),
        json_options: Some(JsonOptions {
            prompt: Some("Extract plan names and prices.".to_string()),
            ..Default::default()
        }),
        only_main_content: Some(true),
        actions: Some(vec![
            Action::Click { selector: "#accept".to_string() },
            Action::Wait { milliseconds: Some(750), selector: None },
            Action::Scrape,
        ]),
        proxy: Some(ProxyType::Auto),
        block_ads: Some(true),
        ..Default::default()
    })
    .await?;
```

### Parameters

- `url`
  - Type: `impl AsRef<str>`
  - The URL to scrape.

- `options` (`ScrapeOptions`, all fields `Option` with `Default` derived)

- `options.formats`
  - Type: `Option<Vec<Format>>`
  - Output formats. Values: `Markdown`, `Html`, `RawHtml`, `Links`, `Images`, `Screenshot`, `Summary`, `ChangeTracking`, `Json`, `Attributes`, `Branding`, `Product`, `Menu`, `Audio`, `Video`, `Question(QuestionFormat)`, `Highlights(HighlightsFormat)`.

- `options.headers`
  - Type: `Option<HashMap<String, String>>`
  - Custom HTTP headers sent with the request.

- `options.include_tags`
  - Type: `Option<Vec<String>>`
  - Only include content from these HTML tags.

- `options.exclude_tags`
  - Type: `Option<Vec<String>>`
  - Exclude content from these HTML tags.

- `options.only_main_content`
  - Type: `Option<bool>`
  - Strip nav, footer, and other boilerplate.

- `options.timeout`
  - Type: `Option<u32>`
  - Timeout in milliseconds.

- `options.wait_for`
  - Type: `Option<u32>`
  - Wait for the page to render (milliseconds).

- `options.mobile`
  - Type: `Option<bool>`
  - Emulate a mobile viewport.

- `options.parsers`
  - Type: `Option<Vec<ParserConfig>>`
  - File parsing controls. Use `ParserConfig::Simple("pdf".to_string())` or `ParserConfig::Pdf { parser_type, max_pages }`.

- `options.actions`
  - Type: `Option<Vec<Action>>`
  - Browser actions to execute before scraping. Variants: `Wait`, `Screenshot`, `Click`, `Write`, `Press`, `Scroll`, `Scrape`, `ExecuteJavascript`, `Pdf`.

- `options.location`
  - Type: `Option<LocationConfig>`
  - Geo/language-aware scraping. Fields: `country`, `languages`.

- `options.skip_tls_verification`
  - Type: `Option<bool>`
  - Skip TLS certificate verification.

- `options.remove_base64_images`
  - Type: `Option<bool>`
  - Drop base64 images from markdown output.

- `options.fast_mode`
  - Type: `Option<bool>`
  - Faster scrapes with reduced fidelity.

- `options.block_ads`
  - Type: `Option<bool>`
  - Block advertisements and cookie popups.

- `options.proxy`
  - Type: `Option<ProxyType>`
  - Proxy mode. Values: `Basic`, `Stealth`, `Enhanced`, `Auto`.

- `options.max_age`
  - Type: `Option<u32>`
  - Use cached data up to this age (milliseconds).

- `options.min_age`
  - Type: `Option<u32>`
  - Use cached data only if at least this old (milliseconds).

- `options.store_in_cache`
  - Type: `Option<bool>`
  - Cache the result for future requests.

- `options.lockdown`
  - Type: `Option<bool>`
  - Serve only from cache; never hit the target.

- `options.check_prompt_injection`
  - Type: `Option<bool>`
  - Scan scraped content for prompt injection attempts.

- `options.redact_pii`
  - Type: `Option<bool>`
  - Redact personally identifiable information from output.

- `options.profile`
  - Type: `Option<ProfileConfig>`
  - Persistent browser profile shared across scrapes and interactions. Fields: `name`, `save_changes`.

- `options.json_options`
  - Type: `Option<JsonOptions>`
  - JSON extraction configuration. Fields: `schema`, `system_prompt`, `prompt`.

- `options.screenshot_options`
  - Type: `Option<ScreenshotOptions>`
  - Screenshot configuration. Fields: `full_page`, `quality`, `viewport`.

- `options.change_tracking_options`
  - Type: `Option<ChangeTrackingOptions>`
  - Change tracking configuration. Fields: `modes` (`GitDiff`, `Json`), `schema`, `prompt`, `tag`.

- `options.attribute_selectors`
  - Type: `Option<Vec<AttributeSelector>>`
  - Attribute extraction targets. Fields: `selector`, `attribute`.

- `options.domain_tools`
  - Type: `Option<bool>`
  - Include domain-matched Alexandria tool contracts.

- `options.tool_detail`
  - Type: `Option<ToolDetail>`
  - Discovery detail level. Values: `Compact`, `Summary`, `Full`.

- `options.integration`
  - Type: `Option<String>`
  - Integration identifier for server-side tracking.

## Interact

### Why use it

Use `interact` for code or natural-language control of the browser session tied to a scrape job (via `metadata.scrape_id`). For flows that go beyond quick pre-scrape tweaks, prefer `interact` over scrape-time `actions`.

### Preferred SDK method

`client.interact(job_id, options)` → `Result<ScrapeExecuteResponse, FirecrawlError>`

### Example

```rust
use firecrawl::{Client, ScrapeOptions, ScrapeExecuteOptions, ScrapeExecuteLanguage, Format};

let client = Client::new("fc-your-api-key")?;

// First scrape to get a job ID
let doc = client
    .scrape("https://example.com", ScrapeOptions {
        formats: Some(vec![Format::Markdown]),
        ..Default::default()
    })
    .await?;
let job_id = doc.metadata.as_ref().and_then(|m| m.scrape_id.as_deref())
    .expect("Missing scrapeId from scrape response");

// Interact with natural language
let result = client
    .interact(job_id, ScrapeExecuteOptions {
        prompt: Some("Click the pricing tab and summarize the plans.".to_string()),
        ..Default::default()
    })
    .await?;

// Interact with code
let result = client
    .interact(job_id, ScrapeExecuteOptions {
        code: Some("console.log(await page.title());".to_string()),
        language: Some(ScrapeExecuteLanguage::Node),
        timeout: Some(60),
        ..Default::default()
    })
    .await?;

// Stop the session when done
let stopped = client.stop_interaction(job_id).await?;
```

### Parameters

- `job_id`
  - Type: `impl AsRef<str>`
  - The scrape job ID from `document.metadata.scrape_id`.

- `options` (`ScrapeExecuteOptions`, all fields `Option` with `Default` derived)

- `options.code`
  - Type: `Option<String>`
  - Code to execute in the browser session (e.g. Playwright `page` usage).

- `options.prompt`
  - Type: `Option<String>`
  - Natural-language instruction for the browser agent.

- At least one of `code` or `prompt` must be non-empty. The SDK returns `FirecrawlError::Misuse` otherwise.

- `options.language`
  - Type: `Option<ScrapeExecuteLanguage>`
  - Runtime for code execution. Values: `Python`, `Node`, `Bash`. Defaults to `Node` when omitted.

- `options.timeout`
  - Type: `Option<u32>`
  - Execution timeout in seconds.

### Stop session

`client.stop_interaction(job_id)` → `Result<ScrapeBrowserDeleteResponse, FirecrawlError>`

Ends the scrape-bound browser session. Response fields: `success`, optional `session_duration_ms`, `credits_billed`, `error`.

## Notes

- Deprecated aliases: `scrape_execute` → `interact`; `stop_interactive_browser` and `delete_scrape_browser` → `stop_interaction`.
- The v2 SDK exports all types at the crate root: `use firecrawl::Client` (not `use firecrawl::v2::Client`).
- `ScrapeOptions` uses dedicated `json_options`, `screenshot_options`, and `change_tracking_options` fields for advanced format configuration, rather than inline format objects.
- `search_and_scrape(query, limit)` is a convenience helper that calls `search` with default `ScrapeOptions` and returns `Vec<Document>`.
