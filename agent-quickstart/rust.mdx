# Firecrawl Rust Agent Quickstart

This file is the canonical quickstart for external agents integrating with Firecrawl using the Rust SDK. It is generated from the SDK source (`firecrawl` crate) and the OpenAPI spec.

## Install

Add to your `Cargo.toml`:

```toml
[dependencies]
firecrawl = "2"
```

## Authenticate

```rust
use firecrawl::Client;

let app = Client::new("fc-YOUR-API-KEY")?;
```

For self-hosted instances:

```rust
let app = Client::new_selfhosted("https://your-instance.com", Some("fc-YOUR-API-KEY"))?;
```

Omitting or passing `None` for the API key enables a keyless free tier (rate-limited per IP).

## When To Use What

- **`search`** — Start with a query, get web results with optional scraping. Use when you need discovery.
- **`scrape`** — Start with a URL, get page content as markdown, HTML, JSON, etc. Use when you already know the page.
- **`interact`** — Execute code or natural-language prompts in a live browser session bound to a prior scrape. Use when the page needs clicks, form fills, or post-scrape browser actions.

## Search

### Why use it

Search the web for a query and get back results with optional page content. Combines discovery and scraping in one call.

### Preferred SDK method

```rust
app.search(query, options).await
```

### Example

```rust
use firecrawl::{Client, SearchOptions};

let app = Client::new("fc-YOUR-API-KEY")?;

let response = app.search("firecrawl web scraping", SearchOptions {
    limit: Some(5),
    ..Default::default()
}).await?;

if let Some(web) = &response.data.web {
    for result in web {
        println!("{:?}", result);
    }
}
```

### Parameters

All fields on `SearchOptions` are `Option` and default to `None` (omitted from the request).

| Parameter | Type | Description |
|---|---|---|
| `limit` | `Option<u32>` | Max number of results. Default: 5, max: 20. |
| `sources` | `Option<Vec<SearchSource>>` | Sources to query: `Web`, `News`, `Images`, `Alexandria`. |
| `categories` | `Option<Vec<SearchCategory>>` | Narrow results: `Github`, `Research`, `Pdf`. |
| `include_domains` | `Option<Vec<String>>` | Only return results from these domains. |
| `exclude_domains` | `Option<Vec<String>>` | Exclude results from these domains. |
| `tbs` | `Option<String>` | Time-based filter (e.g. `"qdr:d"` for past day). |
| `location` | `Option<String>` | Geographic location string for geo-targeting. |
| `country` | `Option<String>` | ISO country code for geo-targeting. |
| `highlights` | `Option<bool>` | Generate query-relevant highlights. Defaults to `true` server-side. |
| `timeout` | `Option<u32>` | Timeout in milliseconds. |
| `ignore_invalid_urls` | `Option<bool>` | Skip invalid URLs in results. |
| `scrape_options` | `Option<ScrapeOptions>` | Options applied when scraping each result page. |
| `domain_tools` | `Option<bool>` | Include domain-matched Alexandria tools in results. |
| `tool_detail` | `Option<ToolDetail>` | Detail level: `Compact`, `Summary`, `Full`. |
| `integration` | `Option<String>` | Integration identifier. |

## Scrape

### Why use it

Scrape a single URL and get back clean content in your chosen formats — markdown, HTML, structured JSON, screenshots, and more.

### Preferred SDK method

```rust
app.scrape(url, options).await
```

### Example

```rust
use firecrawl::{Client, ScrapeOptions, Format};

let app = Client::new("fc-YOUR-API-KEY")?;

let doc = app.scrape("https://example.com", ScrapeOptions {
    formats: Some(vec![Format::Markdown, Format::Html]),
    only_main_content: Some(true),
    ..Default::default()
}).await?;

println!("{}", doc.markdown.unwrap_or_default());
```

### Parameters

All fields on `ScrapeOptions` are `Option` and default to `None` (omitted from the request).

| Parameter | Type | Description |
|---|---|---|
| `formats` | `Option<Vec<Format>>` | Output formats: `Markdown`, `Html`, `RawHtml`, `Links`, `Images`, `Screenshot`, `Summary`, `Json`, `Attributes`, `Branding`, `Product`, `Menu`, `Audio`, `Video`, `Question(QuestionFormat)`, `Highlights(HighlightsFormat)`. |
| `only_main_content` | `Option<bool>` | Extract only main content, excluding navs/footers. |
| `include_tags` | `Option<Vec<String>>` | HTML tags to include in output. |
| `exclude_tags` | `Option<Vec<String>>` | HTML tags to exclude from output. |
| `headers` | `Option<HashMap<String, String>>` | Custom HTTP headers for the request. |
| `timeout` | `Option<u32>` | Timeout in milliseconds. |
| `wait_for` | `Option<u32>` | Wait time in ms before scraping. |
| `mobile` | `Option<bool>` | Emulate a mobile device. |
| `actions` | `Option<Vec<Action>>` | Browser actions: `Wait`, `Click`, `Write`, `Press`, `Scroll`, `Scrape`, `Screenshot`, `ExecuteJavascript`, `Pdf`. |
| `location` | `Option<LocationConfig>` | Proxy location with `country` and `languages`. |
| `proxy` | `Option<ProxyType>` | Proxy type: `Basic`, `Stealth`, `Enhanced`, `Auto`. |
| `block_ads` | `Option<bool>` | Block ads and cookie popups. |
| `skip_tls_verification` | `Option<bool>` | Skip TLS certificate verification. |
| `remove_base64_images` | `Option<bool>` | Strip base64 images from output. |

## Interact

### Why use it

Execute code or natural-language prompts in a live browser session that was opened by a prior scrape. Use it for clicking buttons, filling forms, navigating, or any post-scrape browser automation.

### Preferred SDK method

```rust
app.interact(job_id, options).await
```

### Example

```rust
use firecrawl::{Client, ScrapeOptions, ScrapeExecuteOptions, Format};

let app = Client::new("fc-YOUR-API-KEY")?;

let doc = app.scrape("https://www.amazon.com", ScrapeOptions {
    formats: Some(vec![Format::Markdown]),
    ..Default::default()
}).await?;

let scrape_id = doc.metadata
    .and_then(|m| m.get("scrapeId").and_then(|v| v.as_str().map(String::from)))
    .expect("scrapeId missing");

app.interact(&scrape_id, ScrapeExecuteOptions {
    prompt: Some("Search for iPhone 16 Pro Max".into()),
    ..Default::default()
}).await?;

let response = app.interact(&scrape_id, ScrapeExecuteOptions {
    prompt: Some("Click on the first result and tell me the price".into()),
    ..Default::default()
}).await?;

println!("{}", response.output.unwrap_or_default());

app.stop_interaction(&scrape_id).await?;
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `impl AsRef<str>` | **Required.** The scrape job ID from metadata. |
| `prompt` | `Option<String>` | Natural-language instruction for the browser agent. Provide either `prompt` or `code`. |
| `code` | `Option<String>` | Code to execute in the browser sandbox. Provide either `prompt` or `code`. |
| `language` | `Option<ScrapeExecuteLanguage>` | Runtime language: `Python`, `Node`, `Bash`. Default: `Node`. |
| `timeout` | `Option<u32>` | Execution timeout in seconds. |

**Stop the session** when done:

```rust
app.stop_interaction(job_id).await?;
```

## Notes

- **Naming style**: All struct fields are snake_case. The SDK serializes them to the camelCase JSON keys the API expects.
- **Deprecated aliases**: `scrape_execute` → `interact`, `stop_interactive_browser` / `delete_scrape_browser` → `stop_interaction`. Use the preferred names.
- **Async**: All methods are async and return `Result<T, FirecrawlError>`.
- **Convenience methods**: `scrape_with_schema(url, schema, prompt)` for JSON extraction, `search_and_scrape(query, limit)` for search with full document results.
- **Format options**: Unlike JS/TS and Python where format-specific options are embedded in the format array, the Rust SDK uses separate top-level fields (`json_options`, `screenshot_options`, `change_tracking_options`, `attribute_selectors`).
