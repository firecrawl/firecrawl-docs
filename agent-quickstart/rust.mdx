# Firecrawl Rust Agent Quickstart

This file is the canonical quickstart for external agents building with Firecrawl in Rust. It is generated from SDK source and the OpenAPI spec.

## Install

Add to your `Cargo.toml`:

```toml
[dependencies]
firecrawl = "2"
```

## Authenticate

```rust
use firecrawl::Client;

let client = Client::new("fc-YOUR-API-KEY")?;
```

For self-hosted instances:

```rust
let client = Client::new_selfhosted("https://your-instance.com", Some("fc-YOUR-API-KEY"))?;
```

The API key is optional — omitting it falls back to a keyless free tier (rate-limited per IP) for scrape, search, and interact.

## When To Use What

- **`search`** — you start with a query and need to discover pages. Returns ranked web results with optional full-page scraping.
- **`scrape`** — you already have a URL and want its content as markdown, HTML, JSON, or other formats.
- **`interact`** — the page needs post-scrape browser actions: clicking buttons, filling forms, navigating, or extracting dynamic content.

## Search

### Why use it

Search the web with a query and get structured results. Optionally scrape each result page for full content in one call.

### Preferred SDK method

```
client.search(query, options).await
```

### Example

```rust
use firecrawl::{Client, SearchOptions};

let client = Client::new("fc-YOUR-API-KEY")?;
let response = client.search(
    "firecrawl web scraping",
    SearchOptions { limit: Some(5), ..Default::default() },
).await?;

if let Some(web_results) = response.data.web {
    for result in web_results {
        println!("{:?}", result);
    }
}
```

### Parameters

`SearchOptions` — all fields are `Option`, struct derives `Default`.

| Field | Type | Description |
|---|---|---|
| `limit` | `Option<u32>` | Max results to return. Default: `5`, max: `20`. |
| `sources` | `Option<Vec<SearchSource>>` | Sources to query: `Web`, `News`, `Images`, `Alexandria`. |
| `categories` | `Option<Vec<SearchCategory>>` | Category filters: `Github`, `Research`, `Pdf`. |
| `include_domains` | `Option<Vec<String>>` | Restrict results to these domains. |
| `exclude_domains` | `Option<Vec<String>>` | Exclude results from these domains. |
| `tbs` | `Option<String>` | Time-based filter (e.g. `"qdr:d"` for past day). |
| `location` | `Option<String>` | Geographic location string. |
| `country` | `Option<String>` | Country code (e.g. `"US"`). |
| `timeout` | `Option<u32>` | Timeout in milliseconds. |
| `highlights` | `Option<bool>` | Generate query-relevant highlights. Default: `true` (server-side). |
| `ignore_invalid_urls` | `Option<bool>` | Ignore invalid URLs in results. |
| `scrape_options` | `Option<ScrapeOptions>` | Scrape options for each result page. |
| `domain_tools` | `Option<bool>` | Alexandria domain-tool discovery. |
| `integration` | `Option<String>` | Integration identifier. |
| `origin` | `Option<String>` | Request attribution (auto-set to `"rust-sdk@{version}"` if `None`). |

### Response

Returns `SearchResponse { success, data, warning }` where `data: SearchData` contains:

- `web` — `Option<Vec<SearchResultOrDocument>>`
- `news` — `Option<Vec<SearchResultNews>>`
- `images` — `Option<Vec<SearchResultImage>>`
- `tools` — `Option<Vec<DiscoveredTool>>`

## Scrape

### Why use it

Fetch a single URL and get its content as markdown, HTML, JSON extract, screenshot, or other formats.

### Preferred SDK method

```
client.scrape(url, options).await
```

### Example

```rust
use firecrawl::{Client, ScrapeOptions, Format};

let client = Client::new("fc-YOUR-API-KEY")?;
let doc = client.scrape(
    "https://example.com",
    ScrapeOptions { formats: Some(vec![Format::Markdown]), ..Default::default() },
).await?;

println!("{}", doc.markdown.unwrap_or_default());
```

### Parameters

`ScrapeOptions` — all fields are `Option`, struct derives `Default`.

| Field | Type | Description |
|---|---|---|
| `formats` | `Option<Vec<Format>>` | Output formats: `Markdown`, `Html`, `RawHtml`, `Links`, `Images`, `Screenshot`, `Summary`, `ChangeTracking`, `Json`, `Attributes`, `Branding`, `Product`, `Menu`, `Audio`, `Video`. Also `Question(QuestionFormat)`, `Highlights(HighlightsFormat)`. |
| `headers` | `Option<HashMap<String, String>>` | Custom HTTP request headers. |
| `include_tags` | `Option<Vec<String>>` | HTML tags to include exclusively. |
| `exclude_tags` | `Option<Vec<String>>` | HTML tags to exclude. |
| `only_main_content` | `Option<bool>` | Strip boilerplate (navbars, footers). |
| `timeout` | `Option<u32>` | Timeout in milliseconds. |
| `wait_for` | `Option<u32>` | Wait time in ms before scraping. |
| `mobile` | `Option<bool>` | Emulate a mobile device. |
| `parsers` | `Option<Vec<ParserConfig>>` | Parser configs (e.g. PDF with `max_pages`). |
| `actions` | `Option<Vec<Action>>` | Browser actions: `Wait`, `Click`, `Write`, `Press`, `Scroll`, `Scrape`, `ExecuteJavascript`, `Screenshot`, `Pdf`. |
| `location` | `Option<LocationConfig>` | Proxy routing with `country` and `languages`. |
| `skip_tls_verification` | `Option<bool>` | Skip TLS certificate verification. |
| `remove_base64_images` | `Option<bool>` | Remove base64 images from output. |
| `fast_mode` | `Option<bool>` | Faster scraping, may reduce accuracy. |
| `block_ads` | `Option<bool>` | Block advertisements. |
| `proxy` | `Option<ProxyType>` | Proxy mode: `Basic`, `Stealth`, `Enhanced`, `Auto`. |
| `max_age` | `Option<u32>` | Max age of cached content (seconds). |
| `min_age` | `Option<u32>` | Min age of cached content (seconds). |
| `store_in_cache` | `Option<bool>` | Cache the scrape result. |
| `lockdown` | `Option<bool>` | Serve only cached results. |

## Interact

### Why use it

After scraping a page, interact with the live browser session — click buttons, fill forms, navigate, or extract dynamic content. Use a natural-language prompt or execute Playwright code directly.

### Preferred SDK method

```
client.interact(job_id, options).await
```

To stop a session:

```
client.stop_interaction(job_id).await
```

### Example

```rust
use firecrawl::{Client, ScrapeOptions, ScrapeExecuteOptions, Format};

let client = Client::new("fc-YOUR-API-KEY")?;
let doc = client.scrape(
    "https://www.amazon.com",
    ScrapeOptions { formats: Some(vec![Format::Markdown]), ..Default::default() },
).await?;

let scrape_id = doc.metadata
    .and_then(|m| m.get("scrapeId").and_then(|v| v.as_str().map(String::from)))
    .expect("scrapeId required");

let response = client.interact(&scrape_id, ScrapeExecuteOptions {
    prompt: Some("Search for iPhone 16 Pro Max".into()),
    ..Default::default()
}).await?;
println!("{}", response.output.unwrap_or_default());

client.stop_interaction(&scrape_id).await?;
```

### Parameters

`ScrapeExecuteOptions` — all fields are `Option`, struct derives `Default`.

| Field | Type | Description |
|---|---|---|
| `code` | `Option<String>` | Code to execute. Provide `code` or `prompt` (one is required). |
| `prompt` | `Option<String>` | Natural-language instruction for the browser agent. |
| `language` | `Option<ScrapeExecuteLanguage>` | Execution language: `Python`, `Node`, `Bash`. Default: `Node`. |
| `timeout` | `Option<u32>` | Execution timeout in seconds (1–300). Default: `30`. |
| `origin` | `Option<String>` | Request attribution (auto-set if `None`). |

### Response

Returns `ScrapeExecuteResponse` with fields:

- `success` — whether execution succeeded
- `output` — AI agent's response (when using `prompt`)
- `stdout` / `result` — standard output from code execution
- `stderr` — standard error from code execution
- `exit_code` — process exit code
- `live_view_url` — read-only live view of the browser
- `interactive_live_view_url` — interactive live view

## Notes

- **Naming style**: snake_case for struct fields (e.g. `only_main_content`, `include_tags`). Enum variants are PascalCase (e.g. `Format::Markdown`, `ProxyType::Stealth`).
- **Deprecated aliases**: `scrape_execute()` → use `interact()`. `stop_interactive_browser()` / `delete_scrape_browser()` → use `stop_interaction()`.
- **Async**: All methods are `async`. The SDK uses `reqwest` under the hood.
- **Convenience methods**: `scrape_with_schema(url, schema, prompt)` for JSON extraction. `search_and_scrape(query, limit)` for search + scrape in one call.
