# Firecrawl Rust Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl` crate v2.20.0) and the v2 OpenAPI spec.

## Install

```bash
cargo add firecrawl
```

## Authenticate

```rust
use firecrawl::Client;

let client = Client::new("fc-your-api-key")?;
// Self-hosted:
// let client = Client::new_selfhosted("http://localhost:3002", Some("fc-your-api-key"))?;
```

No API key is required for the keyless free tier (rate-limited per IP). All types are exported at the crate root.

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions.

## Search

### Why use it

Use search to discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:` in the query.

### Preferred SDK method

`client.search(query, options)` → `Result<SearchResponse, FirecrawlError>`

### Example

```rust
use firecrawl::{Client, SearchOptions, ScrapeOptions, Format};

let options = SearchOptions {
    limit: Some(10),
    scrape_options: Some(ScrapeOptions {
        formats: Some(vec![Format::Markdown]),
        only_main_content: Some(true),
        ..Default::default()
    }),
    ..Default::default()
};

let results = client
    .search("site:docs.firecrawl.dev webhook retries", options)
    .await?;

if let Some(web) = results.data.web {
    for item in web {
        // item is SearchResultOrDocument::WebResult or ::Document
    }
}
```

### Return type

`SearchResponse` with:
- `success: bool`
- `data: SearchData` — contains `web`, `news`, `images`, `tools` (each `Option<Vec<...>>`)
- `warning: Option<String>`

`web` items are `SearchResultOrDocument::WebResult(SearchResultWeb)` or `SearchResultOrDocument::Document(Document)`.

### Parameters

- `query`
  - Type: `impl AsRef<str>` (required)
  - The search query. Use `site:example.com` to limit results to a domain.

- `options.sources`
  - Type: `Option<Vec<SearchSource>>`
  - Which sources to search. Values: `Web`, `News`, `Images`, `Alexandria`.

- `options.categories`
  - Type: `Option<Vec<SearchCategory>>`
  - Filter by category. Values: `Github`, `Research`, `Pdf`.

- `options.include_domains`
  - Type: `Option<Vec<String>>`
  - Restrict results to these domains. Cannot be used with `exclude_domains`.

- `options.exclude_domains`
  - Type: `Option<Vec<String>>`
  - Exclude results from these domains. Cannot be used with `include_domains`.

- `options.limit`
  - Type: `Option<u32>`
  - Max results. Default: 5, max: 20.

- `options.tbs`
  - Type: `Option<String>`
  - Time-based filter (e.g. `"qdr:d"` for past day).

- `options.location`
  - Type: `Option<String>`
  - Location for localized results.

- `options.country`
  - Type: `Option<String>`
  - ISO country code (e.g. `"de"`).

- `options.ignore_invalid_urls`
  - Type: `Option<bool>`
  - Drop URLs that cannot be scraped by other endpoints.

- `options.timeout`
  - Type: `Option<u32>`
  - Request timeout in milliseconds.

- `options.highlights`
  - Type: `Option<bool>`
  - Generate query-relevant highlights. Default: `true`.

- `options.scrape_options`
  - Type: `Option<ScrapeOptions>`
  - Scrape each search result. See Scrape parameters.

- `options.domain_tools`
  - Type: `Option<bool>`
  - Include domain-matched Alexandria contracts in `tools`.

- `options.integration`
  - Type: `Option<String>`
  - Integration identifier.

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK method

`client.scrape(url, options)` → `Result<Document, FirecrawlError>`

### Example

```rust
use firecrawl::{Client, ScrapeOptions, Format, JsonOptions};

let doc = client
    .scrape("https://example.com/pricing", ScrapeOptions {
        formats: Some(vec![Format::Markdown, Format::Links, Format::Json]),
        json_options: Some(JsonOptions {
            prompt: Some("Extract plan names and prices.".to_string()),
            ..Default::default()
        }),
        only_main_content: Some(true),
        wait_for: Some(1000),
        ..Default::default()
    })
    .await?;
```

### Parameters

- `url`
  - Type: `impl AsRef<str>` (required)
  - The URL to scrape.

- `options.formats`
  - Type: `Option<Vec<Format>>`
  - Output formats. Values: `Markdown`, `Html`, `RawHtml`, `Links`, `Images`, `Screenshot`, `Summary`, `ChangeTracking`, `Json`, `Attributes`, `Branding`, `Product`, `Menu`, `Audio`, `Video`. Rich format variants: `Question(QuestionFormat)`, `Highlights(HighlightsFormat)`.

- `options.headers`
  - Type: `Option<HashMap<String, String>>`
  - Custom HTTP headers.

- `options.include_tags`
  - Type: `Option<Vec<String>>`
  - Include only specific HTML tags.

- `options.exclude_tags`
  - Type: `Option<Vec<String>>`
  - Exclude specific HTML tags.

- `options.only_main_content`
  - Type: `Option<bool>`
  - Strip nav, footer, and boilerplate. Default: `true`.

- `options.timeout`
  - Type: `Option<u32>`
  - Timeout in milliseconds.

- `options.wait_for`
  - Type: `Option<u32>`
  - Wait time in ms before fetching content.

- `options.mobile`
  - Type: `Option<bool>`
  - Emulate mobile viewport.

- `options.parsers`
  - Type: `Option<Vec<ParserConfig>>`
  - File parsing controls. `ParserConfig::Simple("pdf")` or `ParserConfig::Pdf { parser_type, mode, max_pages, pages, blocks, page_markers }`.

- `options.actions`
  - Type: `Option<Vec<Action>>`
  - Browser actions. Variants: `Wait`, `Screenshot`, `Click`, `Write`, `Press`, `Scroll`, `Scrape`, `ExecuteJavascript`, `Pdf`.

- `options.location`
  - Type: `Option<LocationConfig>`
  - Geo or language-aware scraping. Fields: `country`, `languages`.

- `options.skip_tls_verification`
  - Type: `Option<bool>`
  - Skip TLS certificate verification.

- `options.remove_base64_images`
  - Type: `Option<bool>`
  - Drop base64 images from markdown output.

- `options.fast_mode`
  - Type: `Option<bool>`
  - Faster scrapes with reduced fidelity.

- `options.block_ads`
  - Type: `Option<bool>`
  - Ad and cookie popup blocking.

- `options.proxy`
  - Type: `Option<ProxyType>`
  - Proxy control. Values: `Basic`, `Stealth`, `Enhanced`, `Auto`.

- `options.max_age`
  - Type: `Option<u32>`
  - Use cached data if younger than this (ms).

- `options.min_age`
  - Type: `Option<u32>`
  - Only check cache, never trigger fresh scrape (ms).

- `options.store_in_cache`
  - Type: `Option<bool>`
  - Cache the result.

- `options.lockdown`
  - Type: `Option<bool>`
  - Serve from cache only, never make outbound requests.

- `options.redact_pii`
  - Type: `Option<bool>`
  - Redact personally identifiable information.

- `options.profile`
  - Type: `Option<ProfileConfig>`
  - Persistent browser profile. Fields: `name`, `save_changes`.

- `options.audit_metadata`
  - Type: `Option<AuditMetadata>`
  - User attribution for SIEM logging. Field: `username`.

- `options.domain_tools`
  - Type: `Option<bool>`
  - Include domain-matched Alexandria contracts.

- `options.integration`
  - Type: `Option<String>`
  - Integration identifier.

- `options.json_options`
  - Type: `Option<JsonOptions>`
  - JSON extraction config. Fields: `schema`, `system_prompt`, `prompt`, `check_prompt_injection`.

- `options.screenshot_options`
  - Type: `Option<ScreenshotOptions>`
  - Screenshot config. Fields: `full_page`, `quality`, `viewport`.

- `options.change_tracking_options`
  - Type: `Option<ChangeTrackingOptions>`
  - Change tracking config. Fields: `modes` (`GitDiff`, `Json`), `schema`, `prompt`, `tag`.

- `options.attribute_selectors`
  - Type: `Option<Vec<AttributeSelector>>`
  - Attribute extraction. Fields: `selector`, `attribute`.

## Interact

### Why use it

Use interact when a page requires browser actions or code execution after a scrape starts.

### Preferred SDK method

`client.interact(job_id, options)` → `Result<ScrapeExecuteResponse, FirecrawlError>`

### Example

```rust
use firecrawl::{Client, ScrapeExecuteOptions};

let result = client
    .interact(
        "<scrapeJobId>",
        ScrapeExecuteOptions {
            prompt: Some("Click the pricing tab and summarize the plans.".to_string()),
            ..Default::default()
        },
    )
    .await?;

// Stop the session when done
client.stop_interaction("<scrapeJobId>").await?;
```

### Parameters

- `job_id`
  - Type: `impl AsRef<str>` (required)
  - Scrape job ID.

- `options.code`
  - Type: `Option<String>`
  - Code to execute in the browser session. Required if `prompt` is not set.

- `options.prompt`
  - Type: `Option<String>`
  - Natural-language instruction for the browser agent. Required if `code` is not set.

- `options.language`
  - Type: `Option<ScrapeExecuteLanguage>`
  - Execution runtime. Values: `Python`, `Node`, `Bash`. Default: `Node`.

- `options.timeout`
  - Type: `Option<u32>`
  - Execution timeout in seconds.

### Stop session

`client.stop_interaction(job_id)` → `Result<ScrapeBrowserDeleteResponse, FirecrawlError>`

Response fields: `success`, `session_duration_ms`, `credits_billed`, `error`.

## Notes

- Deprecated aliases: `scrape_execute` → `interact`; `stop_interactive_browser` and `delete_scrape_browser` → `stop_interaction`.
- `search_and_scrape(query, limit)` is a convenience helper that calls `search` with default `ScrapeOptions`.
- All types exported at crate root: `use firecrawl::Client` (not `use firecrawl::v2::Client`).
- All `ScrapeOptions` fields use `Option<T>` and derive `Default`.
- `origin` is auto-set to `"rust-sdk@{version}"` on every request.
