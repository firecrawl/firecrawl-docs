# Firecrawl Rust Agent Quickstart

Canonical quickstart for external agents. Generated from `firecrawl` crate **v2.21.5** SDK source and the v2 OpenAPI spec. Method names, parameters, and types match the SDK public API.

## Install

```bash
cargo add firecrawl
```

## Authenticate

```rust
use firecrawl::Client;

let client = Client::new("fc-your-api-key")?;

// Self-hosted:
// let client = Client::new_selfhosted("http://localhost:3002", Some("fc-your-api-key"))?;
```

All types are exported from the crate root: `use firecrawl::{Client, ScrapeOptions, Format, ...}`.

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions. Requires a `scrape_id` from a prior scrape.

## Search

### Why use it

Discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain to a domain with `site:`, e.g. `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`client.search(query, options)` → `Result<SearchResponse, FirecrawlError>`

### Example

```rust
use firecrawl::Client;

let results = client.search("site:docs.firecrawl.dev webhook retries", None).await?;
for item in results.data.web.unwrap_or_default() {
    // Each item is SearchResultOrDocument::WebResult or ::Document
}
```

### Return value

`SearchResponse { success, data: SearchData, warning }`. `SearchData` has optional `web`, `news`, `images`, `tools` fields. Web entries are `SearchResultOrDocument::WebResult(SearchResultWeb)` or `SearchResultOrDocument::Document(Document)` when scrape options hydrated the result.

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `impl AsRef<str>` (first arg) | Search query. Use `site:example.com` for domain-scoped results. |
| `options.sources` | `Vec<SearchSource>` | `Web`, `News`, `Images`, `Alexandria`. |
| `options.categories` | `Vec<SearchCategory>` | `Github`, `Research`, `Pdf`. |
| `options.limit` | u32 | Max results. Default: 5, Max: 20. |
| `options.tbs` | String | Time-based filter (e.g. `"qdr:d"`). |
| `options.location` | String | Localized results. |
| `options.country` | String | ISO 3166-1 alpha-2 country code. |
| `options.ignore_invalid_urls` | bool | Drop URLs that cannot be scraped. |
| `options.timeout` | u32 | Request timeout in milliseconds. |
| `options.highlights` | bool | Include highlight snippets. Default: true. |
| `options.scrape_options` | `ScrapeOptions` | Scrape each search result. |
| `options.include_domains` | `Vec<String>` | Only include these domains. |
| `options.exclude_domains` | `Vec<String>` | Exclude these domains. |
| `options.domain_tools` | bool | Include domain-matched Alexandria tools. |
| `options.tool_detail` | `ToolDetail` | `Compact`, `Summary`, `Full`. |

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK method

`client.scrape(url, options)` → `Result<Document, FirecrawlError>`

### Example

```rust
use firecrawl::{Client, ScrapeOptions, Format};

let doc = client.scrape("https://docs.firecrawl.dev", ScrapeOptions {
    formats: Some(vec![Format::Markdown]),
    ..Default::default()
}).await?;
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `impl AsRef<str>` (first arg) | URL to scrape. |
| `options.formats` | `Vec<Format>` | Output formats (see below). |
| `options.headers` | `HashMap<String, String>` | Custom request headers. |
| `options.include_tags` | `Vec<String>` | Only include specific HTML tags. |
| `options.exclude_tags` | `Vec<String>` | Exclude specific HTML tags. |
| `options.only_main_content` | bool | Strip nav, footer, and boilerplate. |
| `options.timeout` | u32 | Timeout in milliseconds. |
| `options.wait_for` | u32 | Wait for page render (ms). |
| `options.mobile` | bool | Use mobile viewport. |
| `options.parsers` | `Vec<ParserConfig>` | File parsing controls. |
| `options.actions` | `Vec<Action>` | Pre-scrape browser actions. |
| `options.location` | `LocationConfig` | `{ country, languages }` for geo-aware scraping. |
| `options.skip_tls_verification` | bool | Skip TLS verification. |
| `options.remove_base64_images` | bool | Drop base64 images from markdown. |
| `options.fast_mode` | bool | Faster scrapes with reduced fidelity. |
| `options.block_ads` | bool | Block ads and cookie popups. |
| `options.proxy` | `ProxyType` | `Basic`, `Stealth`, `Enhanced`, `Auto`. |
| `options.max_age` | u32 | Max cache age (seconds). |
| `options.min_age` | u32 | Min cache age (seconds). |
| `options.store_in_cache` | bool | Cache the result. |
| `options.lockdown` | bool | Serve only cached results. |
| `options.check_prompt_injection` | bool | Scan for prompt injection (adds 4 credits). |
| `options.redact_pii` | bool | Redact PII from output. |
| `options.audit_metadata` | `AuditMetadata` | `{ username }` for audit trail. |
| `options.profile` | `ProfileConfig` | `{ name, save_changes }` for persistent browser profile. |
| `options.domain_tools` | bool | Include domain-matched Alexandria tools. |
| `options.tool_detail` | `ToolDetail` | `Compact`, `Summary`, `Full`. |
| `options.json_options` | `JsonOptions` | `{ schema, system_prompt, prompt }`. |
| `options.screenshot_options` | `ScreenshotOptions` | `{ full_page, quality, viewport }`. |
| `options.change_tracking_options` | `ChangeTrackingOptions` | `{ modes, schema, prompt, tag }`. |
| `options.attribute_selectors` | `Vec<AttributeSelector>` | `{ selector, attribute }`. |

### Format enum values

`Markdown`, `Html`, `RawHtml`, `Links`, `Images`, `Screenshot`, `Summary`, `ChangeTracking`, `Json`, `Attributes`, `Branding`, `Product`, `Menu`, `Audio`, `Video`, `Question(QuestionFormat)`, `Highlights(HighlightsFormat)`

### Action enum variants

| Variant | Required fields | Description |
|---|---|---|
| `Wait` | `milliseconds` or `selector` | Wait for time or element. |
| `Click` | `selector` | Click an element. |
| `Write` | `text` | Type text. |
| `Press` | `key` | Press a keyboard key. |
| `Scroll` | `direction` (`Up` / `Down`) | Scroll page or element. |
| `Scrape` | — | Capture page content mid-action. |
| `Screenshot` | — | Take a screenshot mid-action. |
| `ExecuteJavascript` | `script` | Run JavaScript. |
| `Pdf` | — | Generate PDF. Options: `format`, `landscape`, `scale`. |

### Parser config

`ParserConfig::Simple("pdf".to_string())` or `ParserConfig::Pdf { parser_type, mode, max_pages, pages, blocks, page_markers }`.

## Interact

### Why use it

Control the browser session tied to a scrape job. Use for clicks, form fills, or code execution after an initial scrape. Requires at least `code` or `prompt`.

### Preferred SDK method

`client.interact(job_id, options)` → `Result<ScrapeExecuteResponse, FirecrawlError>`

### Example

```rust
use firecrawl::{Client, ScrapeExecuteOptions};

let result = client.interact(
    "<scrapeJobId>",
    ScrapeExecuteOptions {
        prompt: Some("Click the pricing tab and summarize the plans.".to_string()),
        ..Default::default()
    },
).await?;
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `impl AsRef<str>` (first arg) | Scrape job ID from `document.metadata.scrape_id`. |
| `options.code` | `Option<String>` | Run code in the browser session. |
| `options.prompt` | `Option<String>` | Natural-language instruction for the browser agent. |
| `options.language` | `ScrapeExecuteLanguage` | `Python`, `Node`, `Bash`. Default: `Node`. |
| `options.timeout` | u32 | Execution timeout in seconds. |

At least one of `code` or `prompt` must be non-empty; otherwise returns `FirecrawlError::Misuse`.

### Stop session

`client.stop_interaction(job_id)` ends the browser session. Returns `ScrapeBrowserDeleteResponse { success, session_duration_ms, credits_billed, error }`.

## Notes

- Deprecated aliases: `scrape_execute` → `interact`; `stop_interactive_browser`, `delete_scrape_browser` → `stop_interaction`.
- `ScrapeOptions` has dedicated sub-option structs: `json_options`, `screenshot_options`, `change_tracking_options` for advanced format configs.
- Convenience method: `search_and_scrape(query, limit)` calls search with default scrape options and returns `Vec<Document>`.
- Convenience method: `scrape_with_schema(url, schema, prompt)` wraps JSON extraction.
