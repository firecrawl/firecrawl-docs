# Firecrawl Rust Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl` crate) and the v2 OpenAPI spec. Method names and parameter types match the public API surface.

## Install

```bash
cargo add firecrawl
```

## Authenticate

```rust
use firecrawl::Client;

let client = Client::new("fc-your-api-key")?;

// Self-hosted:
// let client = Client::new_selfhosted("http://localhost:3002", Some("fc-your-api-key"))?;
```

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions.

## Search

### Why use it

Discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:` in the query string.

### Preferred SDK method

`client.search(query, options)` → `Result<SearchResponse, FirecrawlError>`

### Example

```rust
use firecrawl::{Client, SearchOptions, ScrapeOptions, Format};

let client = Client::new("fc-your-api-key")?;

let results = client
    .search("site:docs.firecrawl.dev webhook retries", SearchOptions {
        sources: Some(vec![SearchSource::Web]),
        limit: Some(5),
        scrape_options: Some(ScrapeOptions {
            formats: Some(vec![Format::Markdown]),
            only_main_content: Some(true),
            ..Default::default()
        }),
        ..Default::default()
    })
    .await?;
```

### Parameters

- `query` — Type: `impl AsRef<str>`. The search query. Use `site:example.com` to scope results.

- `options.sources` — Type: `Option<Vec<SearchSource>>`. Which sources to search. Values: `Web`, `News`, `Images`, `Alexandria`.

- `options.categories` — Type: `Option<Vec<SearchCategory>>`. Filter results by category. Values: `Github`, `Research`, `Pdf`.

- `options.include_domains` — Type: `Option<Vec<String>>`. Restrict results to these domains.

- `options.exclude_domains` — Type: `Option<Vec<String>>`. Exclude results from these domains. Mutually exclusive with `include_domains`.

- `options.limit` — Type: `Option<u32>`. Maximum number of results.

- `options.tbs` — Type: `Option<String>`. Time-based filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week).

- `options.location` — Type: `Option<String>`. Geographic location string for localized results.

- `options.country` — Type: `Option<String>`. ISO 3166-1 alpha-2 country code for geo-targeting.

- `options.ignore_invalid_urls` — Type: `Option<bool>`. Drop URLs that cannot be scraped.

- `options.timeout` — Type: `Option<u32>`. Request timeout in milliseconds.

- `options.highlights` — Type: `Option<bool>`. Generate query-relevant highlights. Default: true.

- `options.scrape_options` — Type: `Option<ScrapeOptions>`. Scrape each search result with these options (see Scrape parameters).

- `options.domain_tools` — Type: `Option<bool>`. Enable Alexandria domain-tool discovery on results.

- `options.tool_detail` — Type: `Option<ToolDetail>`. Detail level for domain tools. Values: `Compact`, `Summary`, `Full`.

- `options.integration` — Type: `Option<String>`. Integration identifier for server-side tracking.

## Scrape

### Why use it

Fetch structured content from a URL in one or more formats. Returns a `Document` with fields matching the requested formats.

### Preferred SDK method

`client.scrape(url, options)` → `Result<Document, FirecrawlError>`

### Example

```rust
use firecrawl::{Client, ScrapeOptions, Format};

let client = Client::new("fc-your-api-key")?;

let doc = client
    .scrape("https://docs.firecrawl.dev", ScrapeOptions {
        formats: Some(vec![Format::Markdown]),
        only_main_content: Some(true),
        ..Default::default()
    })
    .await?;
```

### Parameters

- `url` — Type: `impl AsRef<str>`. The URL to scrape.

- `options.formats` — Type: `Option<Vec<Format>>`. Output formats. Values: `Markdown`, `Html`, `RawHtml`, `Links`, `Images`, `Screenshot`, `Summary`, `ChangeTracking`, `Json`, `Attributes`, `Branding`, `Product`, `Menu`, `Audio`, `Video`. Object-only variants: `Question(String)`, `Highlights(String)`, `Query(String)`.

- `options.headers` — Type: `Option<HashMap<String, String>>`. Custom HTTP headers for the request.

- `options.include_tags` — Type: `Option<Vec<String>>`. Only include content from these HTML tags or CSS selectors.

- `options.exclude_tags` — Type: `Option<Vec<String>>`. Exclude content from these HTML tags or CSS selectors.

- `options.only_main_content` — Type: `Option<bool>`. Strip nav, footer, and other boilerplate.

- `options.timeout` — Type: `Option<u32>`. Timeout in milliseconds.

- `options.wait_for` — Type: `Option<u32>`. Wait for page rendering in milliseconds.

- `options.mobile` — Type: `Option<bool>`. Use a mobile viewport.

- `options.parsers` — Type: `Option<Vec<ParserConfig>>`. File parsing controls. Use `ParserConfig::Simple("pdf".to_string())` or `ParserConfig::Pdf { parser_type, max_pages }`.

- `options.actions` — Type: `Option<Vec<Action>>`. Browser actions before scraping. Variants: `Wait` (`milliseconds` or `selector`), `Screenshot` (`full_page`, `quality`, `viewport`), `Click` (`selector`), `Write` (`text`), `Press` (`key`), `Scroll` (`direction`: `Up`/`Down`, optional `selector`), `Scrape`, `ExecuteJavascript` (`script`), `Pdf` (`format`, `landscape`, `scale`).

- `options.location` — Type: `Option<LocationConfig>`. Geo and language-aware scraping. Fields: `country`, `languages`.

- `options.skip_tls_verification` — Type: `Option<bool>`. Skip TLS certificate verification.

- `options.remove_base64_images` — Type: `Option<bool>`. Drop base64-encoded images from markdown output.

- `options.fast_mode` — Type: `Option<bool>`. Faster scrapes with reduced fidelity.

- `options.block_ads` — Type: `Option<bool>`. Block ads and cookie popups.

- `options.proxy` — Type: `Option<ProxyType>`. Proxy mode. Values: `Basic`, `Stealth`, `Enhanced`, `Auto`.

- `options.max_age` — Type: `Option<u32>`. Use cached data up to this age in milliseconds.

- `options.min_age` — Type: `Option<u32>`. Use cached data only if at least this old in milliseconds.

- `options.store_in_cache` — Type: `Option<bool>`. Cache the scrape result.

- `options.lockdown` — Type: `Option<bool>`. Serve only previously cached results.

- `options.check_prompt_injection` — Type: `Option<bool>`. Scan page for prompt injection. Adds 4 credits.

- `options.redact_pii` — Type: `Option<bool>`. Redact personally identifiable information from output.

- `options.audit_metadata` — Type: `Option<AuditMetadata>`. User attribution for SIEM logging.

- `options.profile` — Type: `Option<ProfileConfig>`. Persistent browser profile. Fields: `name`, `save_changes`.

- `options.domain_tools` — Type: `Option<bool>`. Enable Alexandria domain-tool discovery.

- `options.tool_detail` — Type: `Option<ToolDetail>`. Detail level for domain tools. Values: `Compact`, `Summary`, `Full`.

- `options.json_options` — Type: `Option<JsonOptions>`. Configure JSON extraction. Fields: `schema`, `system_prompt`, `prompt`.

- `options.screenshot_options` — Type: `Option<ScreenshotOptions>`. Configure screenshot output. Fields: `full_page`, `quality`, `viewport`.

- `options.change_tracking_options` — Type: `Option<ChangeTrackingOptions>`. Configure change tracking. Fields: `modes` (`GitDiff`, `Json`), `schema`, `prompt`, `tag`.

- `options.attribute_selectors` — Type: `Option<Vec<AttributeSelector>>`. Extract element attributes. Fields: `selector`, `attribute`.

- `options.integration` — Type: `Option<String>`. Integration identifier.

## Interact

### Why use it

Run code or natural-language instructions in the browser session tied to a scrape job. Use it for clicks, form fills, navigation, or any post-scrape browser control. Requires at least one of `code` or `prompt`.

### Preferred SDK method

`client.interact(job_id, options)` → `Result<ScrapeExecuteResponse, FirecrawlError>`

### Example

```rust
use firecrawl::{Client, ScrapeOptions, ScrapeExecuteOptions, Format};

let client = Client::new("fc-your-api-key")?;

// First scrape to get a session
let doc = client
    .scrape("https://example.com", ScrapeOptions {
        formats: Some(vec![Format::Markdown]),
        ..Default::default()
    })
    .await?;

let job_id = doc.metadata
    .and_then(|m| m.scrape_id)
    .expect("Missing scrapeId from scrape response");

// Interact with the page
let result = client
    .interact(&job_id, ScrapeExecuteOptions {
        prompt: Some("Click the pricing tab and summarize the plans.".to_string()),
        ..Default::default()
    })
    .await?;

// Stop session when done
client.stop_interaction(&job_id).await?;
```

### Parameters

- `job_id` — Type: `impl AsRef<str>`. The scrape job ID from `document.metadata.scrape_id`.

- `options.code` — Type: `Option<String>`. Code to execute in the browser session (e.g. Playwright `page` methods). Required if `prompt` is not set.

- `options.prompt` — Type: `Option<String>`. Natural-language instruction for the browser agent. Required if `code` is not set.

- `options.language` — Type: `Option<ScrapeExecuteLanguage>`. Execution runtime. Values: `Python`, `Node`, `Bash`. Default: `Node`.

- `options.timeout` — Type: `Option<u32>`. Execution timeout in seconds.

At least one of `code` or `prompt` must be non-empty. Both empty returns `FirecrawlError::Misuse`.

## Notes

- All `Options` structs derive `Default`, so use `..Default::default()` to fill unset fields.
- Rust field names are `snake_case`; the SDK serializes them to `camelCase` on the wire via `#[serde(rename_all = "camelCase")]`.
- Deprecated aliases: `scrape_execute` → `interact`, `stop_interactive_browser` and `delete_scrape_browser` → `stop_interaction`.
- Convenience helper: `search_and_scrape(query, limit)` calls `search` with default `ScrapeOptions` and returns `Vec<Document>`.
- v2 SDK exports all types at the crate root: `use firecrawl::Client` (not `use firecrawl::v2::Client`).
