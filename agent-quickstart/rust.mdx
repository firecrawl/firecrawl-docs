# Firecrawl Rust Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl` crate **2.21.6**) and the v2 OpenAPI spec. Method names, parameters, and types match the SDK public API.

## Install

```bash
cargo add firecrawl
```

## Authenticate

```rust
use firecrawl::Client;

let client = Client::new("fc-your-api-key")?;

// Self-hosted:
// let client = Client::new_selfhosted("http://localhost:3002", Some("fc-your-api-key"))?;
```

## When To Use What

- **`search`**: use when you start with a query and need discovery. Returns relevant pages you can then scrape or interact with.
- **`scrape`**: use when you already have a URL and want page content in one or more formats (markdown, HTML, JSON extraction, screenshots, etc.).
- **`interact`**: use when the page needs clicks, forms, or post-scrape browser actions. Requires a scrape job ID from a prior scrape.

## Search

### Why use it

Discover relevant pages from a natural-language query. Constrain to a site with `site:` syntax (e.g. `site:docs.firecrawl.dev crawl webhooks`). Returns categorized results across web, news, and images.

### Preferred SDK method

`client.search(query, options)` → `Result<SearchResponse, FirecrawlError>`

### Example

```rust
use firecrawl::{Client, SearchOptions};

let results = client
    .search("site:docs.firecrawl.dev webhook retries", None)
    .await?;
```

### Parameters

All fields on `SearchOptions` are `Option` and use `#[serde(rename_all = "camelCase")]`.

| Parameter | Type | Description |
|---|---|---|
| `query` | `impl AsRef<str>` | The search query. Use `site:example.com` to limit to a domain. |
| `sources` | `Vec<SearchSource>` | Which sources to search: `Web`, `News`, `Images`, `Alexandria`. |
| `categories` | `Vec<SearchCategory>` | Filter by category: `Github`, `Research`, `Pdf`. |
| `include_domains` | `Vec<String>` | Restrict results to these domains. |
| `exclude_domains` | `Vec<String>` | Exclude results from these domains. |
| `limit` | `u32` | Maximum number of results. Default: 5, max: 20. |
| `tbs` | `String` | Time-based filter (e.g. `qdr:d` for past day). |
| `location` | `String` | Location string for localized results. |
| `country` | `String` | Country code for geo-targeting. |
| `ignore_invalid_urls` | `bool` | Drop URLs that cannot be scraped by other endpoints. |
| `timeout` | `u32` | Request timeout in milliseconds. |
| `highlights` | `bool` | Generate query-relevant highlights. Default: `true`. |
| `scrape_options` | `ScrapeOptions` | Scrape each search result (see Scrape parameters). |
| `domain_tools` | `bool` | Include Alexandria tool contracts matching result domains. |
| `tool_detail` | `ToolDetail` | Detail level: `Compact`, `Summary`, `Full`. |
| `integration` | `String` | Integration identifier. |

**Return value**: `SearchResponse { success, data: SearchData, warning }`. `SearchData` contains `web: Option<Vec<SearchResultOrDocument>>`, `news`, `images`, `tools`.

## Scrape

### Why use it

Extract structured content from a URL in one or more formats. Supports markdown, HTML, JSON extraction, screenshots, change tracking, and more.

### Preferred SDK method

`client.scrape(url, options)` → `Result<Document, FirecrawlError>`

### Example

```rust
use firecrawl::{Client, ScrapeOptions, Format};

let doc = client
    .scrape("https://docs.firecrawl.dev", ScrapeOptions {
        formats: Some(vec![Format::Markdown]),
        only_main_content: Some(true),
        ..Default::default()
    })
    .await?;
```

### Parameters

All fields on `ScrapeOptions` are `Option` and use `#[serde(rename_all = "camelCase")]`.

| Parameter | Type | Description |
|---|---|---|
| `url` | `impl AsRef<str>` | The URL to scrape. |
| `formats` | `Vec<Format>` | Output formats: `Markdown`, `Html`, `RawHtml`, `Links`, `Images`, `Screenshot`, `Summary`, `ChangeTracking`, `Json`, `Attributes`, `Branding`, `Audio`, `Video`. |
| `headers` | `HashMap<String, String>` | Custom HTTP request headers. |
| `include_tags` | `Vec<String>` | Only include content from these HTML tags. |
| `exclude_tags` | `Vec<String>` | Exclude content from these HTML tags. |
| `only_main_content` | `bool` | Strip nav, footer, and boilerplate. |
| `timeout` | `u32` | Request timeout in milliseconds. |
| `wait_for` | `u32` | Wait for page rendering (milliseconds). |
| `mobile` | `bool` | Use a mobile viewport. |
| `parsers` | `Vec<ParserConfig>` | File parsers. `ParserConfig::Pdf { parser_type, max_pages }`. |
| `actions` | `Vec<Action>` | Pre-scrape browser actions: `Wait`, `Click`, `Write`, `Press`, `Scroll`, `Scrape`, `ExecuteJavascript`, `Screenshot`, `Pdf`. |
| `location` | `LocationConfig` | Geo settings: `country`, `languages`. |
| `skip_tls_verification` | `bool` | Skip TLS verification. |
| `remove_base64_images` | `bool` | Drop base64 images from markdown output. |
| `fast_mode` | `bool` | Faster scrapes with reduced fidelity. |
| `block_ads` | `bool` | Block ads and cookie popups. |
| `proxy` | `ProxyType` | Proxy mode: `Basic`, `Stealth`, `Enhanced`, `Auto`. |
| `max_age` | `u32` | Use cached data up to this age (seconds). |
| `min_age` | `u32` | Use cached data only if at least this old (seconds). |
| `store_in_cache` | `bool` | Cache the result. |
| `lockdown` | `bool` | Serve only cached results. |
| `check_prompt_injection` | `bool` | Scan page for prompt injection. Adds 4 credits. |
| `redact_pii` | `bool` | Redact personally identifiable information. |
| `profile` | `ProfileConfig` | Persistent browser profile: `name`, `save_changes`. |
| `json_options` | `JsonOptions` | JSON extraction config: `schema`, `system_prompt`, `prompt`. |
| `screenshot_options` | `ScreenshotOptions` | Screenshot config: `full_page`, `quality`, `viewport`. |
| `change_tracking_options` | `ChangeTrackingOptions` | Change tracking config: `modes` (`GitDiff`, `Json`), `schema`, `prompt`, `tag`. |
| `attribute_selectors` | `Vec<AttributeSelector>` | Attribute extraction: `selector`, `attribute`. |
| `domain_tools` | `bool` | Include domain-matched Alexandria tool contracts. |
| `tool_detail` | `ToolDetail` | Detail level: `Compact`, `Summary`, `Full`. |
| `integration` | `String` | Integration identifier. |

## Interact

### Why use it

Control the browser session tied to a scrape job via code or natural-language prompts. Use for clicks, form fills, navigation, and other post-scrape browser actions.

### Preferred SDK method

`client.interact(job_id, options)` → `Result<ScrapeExecuteResponse, FirecrawlError>`

### Example

```rust
use firecrawl::{Client, ScrapeExecuteOptions};

let result = client
    .interact(
        "<scrapeJobId>",
        ScrapeExecuteOptions {
            prompt: Some("Click the pricing tab and summarize the plans.".to_string()),
            ..Default::default()
        },
    )
    .await?;
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `impl AsRef<str>` | Scrape job ID from a prior scrape. |
| `code` | `Option<String>` | Code to execute in the browser session. |
| `prompt` | `Option<String>` | Natural-language instruction for the browser agent. |
| `language` | `ScrapeExecuteLanguage` | Runtime: `Python`, `Node`, `Bash`. Defaults to `Node`. |
| `timeout` | `u32` | Execution timeout in seconds (1–300). |

At least one of `code` or `prompt` must be provided. The SDK returns `FirecrawlError::Misuse` if both are empty.

**Stop session**: `client.stop_interaction(job_id)` ends the browser session. Returns `ScrapeBrowserDeleteResponse { success, session_duration_ms, credits_billed, error }`.

## Notes

- Deprecated aliases: `scrape_execute` → `interact`; `stop_interactive_browser` and `delete_scrape_browser` → `stop_interaction`.
- The Rust SDK has dedicated `json_options`, `screenshot_options`, and `change_tracking_options` fields on `ScrapeOptions` for advanced format configuration, rather than embedding them in the `formats` array.
- Convenience method: `client.search_and_scrape(query, limit)` searches and returns `Vec<Document>`.
- All types are exported at the crate root: `use firecrawl::Client`.
