# Firecrawl Python Agent Quickstart

Canonical quickstart for external agents using the Firecrawl Python SDK. Generated from SDK source (`firecrawl-py`) and the v2 OpenAPI spec. Method names, parameters, and types match the public API surface.

## Install

```bash
pip install firecrawl-py
```

## Authenticate

```python
import os
from firecrawl import Firecrawl

client = Firecrawl(api_key=os.environ.get("FIRECRAWL_API_KEY"))
# Optional: client = Firecrawl(api_key="fc-...", api_url="https://api.firecrawl.dev")
```

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions.

## Search

### Why use it

Use search to discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:`, for example `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`client.search(query, **options)` → `SearchData`

### Example

```python
results = client.search("site:docs.firecrawl.dev webhook retries")
for item in results.web or []:
    print(getattr(item, "url", None), getattr(item, "title", None))
```

```python
results = client.search(
    "site:docs.firecrawl.dev crawl webhooks",
    sources=["web", "news"],
    categories=["research"],
    limit=10,
    tbs="qdr:m",
    location="San Francisco,California,United States",
    ignore_invalid_urls=True,
    timeout=300000,
    scrape_options=ScrapeOptions(
        formats=["markdown", "links"],
        only_main_content=True,
    ),
)
```

### Parameters

- `query`
  - Type: str (required, positional)
  - The search query. Use `site:example.com` to limit results to a domain.

- `sources`
  - Type: list of str or Source objects
  - Which result buckets to search.
  - Confirmed values: `"web"`, `"news"`, `"images"`, `"alexandria"`

- `categories`
  - Type: list of str or Category objects
  - Filter results by category.
  - Confirmed values: `"github"`, `"research"`, `"pdf"`, `"developer"`, `"gov"`

- `include_domains`
  - Type: list of str
  - Restrict results to these domains.

- `exclude_domains`
  - Type: list of str
  - Exclude results from these domains.

- `limit`
  - Type: int
  - Max number of results. Default: `5`.

- `tbs`
  - Type: str
  - Time-based filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week).

- `location`
  - Type: str
  - Localized results string.

- `country`
  - Type: str
  - ISO 3166-1 alpha-2 country code for geo-targeting.

- `ignore_invalid_urls`
  - Type: bool
  - Drop URLs that cannot be scraped by other endpoints.

- `timeout`
  - Type: int
  - Request timeout in milliseconds. Default: `300000`.

- `highlights`
  - Type: bool
  - Generate query-relevant highlights. Defaults to `true`.

- `scrape_options`
  - Type: ScrapeOptions
  - Scrape each search result. See Scrape parameters for fields.

- `domain_tools`
  - Type: bool
  - Include domain-matched Alexandria tool contracts.

- `tool_detail`
  - Type: `"compact"` | `"summary"` | `"full"`
  - Tool contract verbosity level.

- `enterprise`
  - Type: list of str
  - Enterprise options. Confirmed values: `"zdr"` (zero data retention), `"anon"` (anonymized).

- `integration`
  - Type: str
  - Integration identifier for server-side tracking.

- `threat_protection`
  - Type: ThreatProtectionOptions
  - Enterprise per-request threat protection override.

**Return value:** `SearchData` with optional lists — `web`, `news`, `images`. Do not access `result.data`; web results are in `result.web`.

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK method

`client.scrape(url, **options)` → `Document`

### Example

```python
doc = client.scrape("https://docs.firecrawl.dev", formats=["markdown"])
print(doc.markdown)
```

```python
doc = client.scrape(
    "https://example.com/pricing",
    formats=[
        "markdown",
        "links",
        {"type": "json", "prompt": "Extract plan names and prices."},
        {"type": "screenshot", "full_page": True, "quality": 80},
    ],
    only_main_content=True,
    wait_for=1000,
    actions=[
        {"type": "click", "selector": "#accept"},
        {"type": "wait", "milliseconds": 750},
        {"type": "scrape"},
    ],
    block_ads=True,
    proxy="auto",
)
```

### Parameters

- `url`
  - Type: str (required, positional)
  - The URL to scrape.

- `formats`
  - Type: list of format strings or format dicts
  - Output formats to request.
  - Confirmed string formats: `"markdown"`, `"html"`, `"rawHtml"` / `"raw_html"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"` / `"change_tracking"`, `"attributes"`, `"branding"`, `"audio"`, `"video"`
  - Object-only format types:
    - `{"type": "json", "prompt": str, "schema": dict}` — at least one of `prompt` or `schema` required
    - `{"type": "question", "question": str}` — question-answer extraction
    - `{"type": "highlights", "query": str}` — relevant source-text extraction
  - Object format variants with options:
    - `{"type": "screenshot", "full_page": bool, "quality": int, "viewport": {"width": int, "height": int}}`
    - `{"type": "changeTracking", "modes": ["git-diff" | "json"], "tag": str, "schema": dict, "prompt": str}`
    - `{"type": "attributes", "selectors": [{"selector": str, "attribute": str}]}`

- `headers`
  - Type: dict of str to str
  - Custom HTTP request headers.

- `include_tags`
  - Type: list of str
  - Include only content from these HTML tags.

- `exclude_tags`
  - Type: list of str
  - Exclude content from these HTML tags.

- `only_main_content`
  - Type: bool
  - Strip nav, footer, and other boilerplate.

- `timeout`
  - Type: int
  - Timeout in milliseconds.

- `wait_for`
  - Type: int
  - Wait for page to render (milliseconds).

- `mobile`
  - Type: bool
  - Emulate a mobile viewport.

- `parsers`
  - Type: list of str or parser dicts
  - File parsing controls.
  - Confirmed values: `"pdf"`, `{"type": "pdf", "mode": "fast" | "auto" | "ocr", "max_pages": int}`

- `actions`
  - Type: list of action dicts
  - Browser actions to execute before scraping.
  - Confirmed action types:
    - `wait`: `milliseconds` or `selector` required
    - `screenshot`: `full_page`, `quality`, `viewport` optional
    - `click`: `selector` required
    - `write`: `text` required (click to focus the input first)
    - `press`: `key` required
    - `scroll`: `direction` (`"up"` or `"down"`) required, `selector` optional
    - `scrape`: no additional fields
    - `executeJavascript`: `script` required
    - `pdf`: `format`, `landscape`, `scale` optional

- `location`
  - Type: dict or Location
  - Geo/language-aware scraping. Fields: `country`, `languages`.

- `skip_tls_verification`
  - Type: bool
  - Skip TLS certificate verification.

- `remove_base64_images`
  - Type: bool
  - Drop base64-encoded images from markdown output.

- `fast_mode`
  - Type: bool
  - Faster scrapes with reduced fidelity.

- `block_ads`
  - Type: bool
  - Block advertisements and cookie popups.

- `proxy`
  - Type: str
  - Proxy control. Confirmed values: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`.

- `max_age`
  - Type: int
  - Use cached data up to this age (milliseconds).

- `store_in_cache`
  - Type: bool
  - Cache the result on Firecrawl's side.

- `lockdown`
  - Type: bool
  - Serve only previously cached results; 404 on cache miss.

- `check_prompt_injection`
  - Type: bool
  - Scan page content for prompt injection attempts. Adds 4 credits.

- `profile`
  - Type: dict
  - Persistent browser profile. Fields: `name` (str), `saveChanges` (bool).

- `domain_tools`
  - Type: bool
  - Include domain-matched Alexandria tool contracts.

- `tool_detail`
  - Type: `"compact"` | `"summary"` | `"full"`
  - Tool contract verbosity level.

- `integration`
  - Type: str
  - Integration identifier for server-side tracking.

## Interact

### Why use it

Use `interact` for code or natural-language control of the browser session tied to a scrape job (via `metadata.scrape_id`). At least one of `code` or `prompt` must be provided. For flows beyond quick pre-scrape tweaks, prefer `interact` over scrape-time `actions`.

### Preferred SDK method

`client.interact(job_id, code=None, *, prompt=None, language="node", timeout=None)`

### Example

```python
doc = client.scrape("https://example.com", formats=["markdown"])
job_id = doc.metadata.scrape_id if doc.metadata else None
if not job_id:
    raise RuntimeError("Missing scrape_id from scrape response")

result = client.interact(job_id, prompt="Click the pricing tab and summarize the plans.")
```

```python
result = client.interact(
    "<scrapeJobId>",
    code="print(await page.title())",
    language="python",
    timeout=60,
)
```

### Parameters

- `job_id`
  - Type: str (required, positional)
  - Scrape job ID from `document.metadata.scrape_id`.

- `code`
  - Type: str
  - Code to run in the browser session. Optional if `prompt` is set.

- `prompt`
  - Type: str (keyword-only)
  - Natural-language instruction for the browser agent. Optional if `code` is set.

- `language`
  - Type: str
  - Runtime language for code execution.
  - Confirmed values: `"python"`, `"node"`, `"bash"`
  - Default: `"node"`

- `timeout`
  - Type: int
  - Execution timeout in seconds.

**Stop session:** `client.stop_interaction(job_id)` → `BrowserDeleteResponse` with `success`, optional `session_duration_ms`, `credits_billed`, `error`.

## Notes

- Deprecated aliases: `scrape_execute` → `interact`; `stop_interactive_browser` / `delete_scrape_browser` → `stop_interaction`.
- The top-level `Firecrawl` client exposes v2 methods directly; v1 remains under `client.v1`.
- Python uses `snake_case` parameter names (e.g. `only_main_content`, `ignore_invalid_urls`).
- `search()` returns `result.web`, `result.news`, `result.images` — not `result.data`.
