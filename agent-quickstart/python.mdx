# Firecrawl Python Agent Quickstart

This file is the canonical quickstart for external agents integrating with Firecrawl using the Python SDK. It is generated from SDK source and the OpenAPI spec.

## Install

```bash
pip install firecrawl-py
```

## Authenticate

```python
from firecrawl import Firecrawl

# Pass the key directly
firecrawl = Firecrawl(api_key="fc-YOUR_API_KEY")

# Or set the FIRECRAWL_API_KEY environment variable and omit the key
firecrawl = Firecrawl()
```

Constructor parameters:
- `api_key` (str) — API key. Falls back to `FIRECRAWL_API_KEY` env var. Omit for keyless free tier (rate-limited).
- `api_url` (str) — Base URL. Defaults to `https://api.firecrawl.dev`. Falls back to `FIRECRAWL_API_URL` env var.
- `timeout` (float) — Request timeout in seconds.
- `max_retries` (int) — Max automatic retries. Default: `3`.
- `backoff_factor` (float) — Exponential backoff factor. Default: `0.5`.
- `origin` (str) — Attribution string sent with requests.

## When To Use What

- **`search`** — Use when you start with a query and need discovery. Returns web, news, image, and tool results without needing a specific URL.
- **`scrape`** — Use when you already have a URL and want page content. Returns markdown, HTML, structured data, screenshots, and more.
- **`interact`** — Use when the page needs clicks, form fills, or post-scrape browser actions. Runs code or a natural-language prompt in the browser session opened by a prior scrape.

## Search

### Why use it

Search finds relevant pages across the web, news, images, and Alexandria tool catalogs from a text query. Use it when you do not already have a URL.

### Preferred SDK method

```python
firecrawl.search(query, **kwargs)
```

Returns `SearchData` with `.web`, `.news`, `.images`, `.tools` fields.

### Example

```python
results = firecrawl.search(
    "firecrawl web scraping API",
    limit=5,
    scrape_options={"formats": ["markdown"]},
)

for page in results.web:
    print(page.url, page.title)
```

### Parameters

- `query` (str, **required**) — The search query string.
- `sources` (list[SourceOption]) — Search sources to use. Values: `"web"`, `"news"`, `"images"`, `"alexandria"`.
- `categories` (list[CategoryOption]) — Filter by category. Values: `"github"`, `"research"`, `"pdf"`, `"developer"`, `"gov"`.
- `include_domains` (list[str]) — Restrict results to these domains.
- `exclude_domains` (list[str]) — Exclude results from these domains.
- `limit` (int) — Max number of results. Default: `5`.
- `tbs` (str) — Time-based search filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week).
- `location` (str) — Location string for geo-targeting (e.g. `"San Francisco,California,United States"`).
- `country` (str) — ISO 3166-1 alpha-2 country code for geo-targeting.
- `ignore_invalid_urls` (bool) — Skip invalid URLs instead of failing.
- `timeout` (int) — Request timeout in milliseconds. Default: `300000`.
- `highlights` (bool) — Generate query-relevant highlights. Default: `true` server-side.
- `scrape_options` (ScrapeOptions) — Options for scraping individual result pages. Accepts the same parameters as `scrape`.
- `integration` (str) — Integration identifier tag.
- `enterprise` (list[str]) — Enterprise options: `["zdr"]` for Zero Data Retention, `["anon"]` for anonymized search.
- `threat_protection` (ThreatProtectionOptions) — Per-request threat protection override (enterprise).
- `domain_tools` (bool) — Include Alexandria domain-tool discovery alongside results.
- `tool_detail` (`"compact"` | `"summary"` | `"full"`) — Level of tool metadata to return.

## Scrape

### Why use it

Scrape fetches and processes a single URL, returning clean markdown, HTML, structured JSON, screenshots, or other formats. Use it when you already know the URL you need.

### Preferred SDK method

```python
firecrawl.scrape(url, **kwargs)
```

Returns `Document`.

### Example

```python
doc = firecrawl.scrape(
    "https://docs.firecrawl.dev",
    formats=["markdown", "html"],
    only_main_content=True,
)

print(doc.markdown)
```

### Parameters

- `url` (str, **required**) — The URL to scrape.
- `formats` (list[FormatOption]) — Output formats. Values: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`, `"query"`, `"question"`, `"highlights"`. Can also pass format config dicts (e.g. `{"type": "json", "schema": {...}}`).
- `headers` (dict[str, str]) — Custom HTTP headers to send with the request.
- `include_tags` (list[str]) — HTML tags to include in output.
- `exclude_tags` (list[str]) — HTML tags to exclude from output.
- `only_main_content` (bool) — Only return the main content, excluding navbars and footers.
- `timeout` (int) — Timeout in milliseconds.
- `wait_for` (int) — Wait time in milliseconds before scraping (for JS rendering).
- `mobile` (bool) — Emulate a mobile device.
- `parsers` (list) — File parsers to use (e.g. `"pdf"`, `"image"`, or config dicts with options like `mode`, `max_pages`).
- `actions` (list[Action]) — Browser actions to perform before scraping. Types: `wait`, `click`, `write`, `press`, `scroll`, `screenshot`, `scrape`, `executeJavascript`, `pdf`.
- `location` (Location) — Location config: `{"country": "US", "languages": ["en"]}`.
- `skip_tls_verification` (bool) — Skip TLS certificate verification.
- `remove_base64_images` (bool) — Remove base64 images from output.
- `fast_mode` (bool) — Enable fast mode for quicker, less detailed scraping.
- `block_ads` (bool) — Block ads and cookie popups.
- `proxy` (str) — Proxy mode: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`.
- `max_age` (int) — Max age of cached content in milliseconds. Set to `0` to bypass cache.
- `store_in_cache` (bool) — Store the result in Firecrawl's cache.
- `lockdown` (bool) — Serve only previously cached results, never make outbound requests.
- `check_prompt_injection` (bool) — Scan page for prompt injection before LLM-backed formats. Adds 4 credits.
- `redact_pii` (bool or dict) — Redact PII from returned content. Pass `True` or a dict with `mode` (`"accurate"`, `"aggressive"`, `"fast"`), `entities`, `replace_style`.
- `threat_protection` (ThreatProtectionOptions) — Per-request threat protection override (enterprise).
- `profile` (dict) — Browser profile for persistent storage: `{"name": "my-profile", "save_changes": True}`.
- `audit_metadata` (AuditMetadata) — User attribution for SIEM logging: `{"username": "agent-x"}`.
- `integration` (str) — Integration identifier tag.
- `domain_tools` (bool) — Include Alexandria domain-tool discovery for the scraped page's domain.
- `tool_detail` (`"compact"` | `"summary"` | `"full"`) — Level of tool metadata to return.
- `auto_resume` (bool) — SDK-only. Auto-resume large documents that outlive the request window.
- `alexandria` (AlexandriaCall | dict | list) — Execute catalogued provider tools instead of scraping a URL.
- `use_mock` (str) — Use mock response (testing).

## Interact

### Why use it

Interact runs code or a natural-language prompt in the live browser session opened by a prior scrape. Use it when you need to click buttons, fill forms, navigate, or perform any post-scrape browser action.

### Preferred SDK method

```python
firecrawl.interact(job_id, code=None, *, prompt=None, language="node", timeout=None, origin=None)
```

Returns `BrowserExecuteResponse`.

To stop the browser session:

```python
firecrawl.stop_interaction(job_id)
```

### Example

```python
doc = firecrawl.scrape(
    "https://example.com/login",
    formats=["markdown"],
)
job_id = doc.metadata.get("jobId")

result = firecrawl.interact(
    job_id,
    code='document.querySelector("#username").value = "agent";',
    language="node",
    timeout=30,
)
print(result.stdout)

firecrawl.stop_interaction(job_id)
```

### Parameters

- `job_id` (str, **required**) — The scrape job ID from a prior `scrape` call (found in `doc.metadata["jobId"]`).
- `code` (str) — Code to execute in the browser session. One of `code` or `prompt` is required.
- `prompt` (str) — Natural-language instruction for the browser agent. One of `code` or `prompt` is required.
- `language` (`"python"` | `"node"` | `"bash"`) — Language for code execution. Default: `"node"`.
- `timeout` (int) — Execution timeout in seconds (1–300).
- `origin` (str) — Origin tag for request attribution.

## Notes

- All parameter names use **snake_case** in the Python SDK, matching Python conventions.
- `FirecrawlApp` is a deprecated alias for `Firecrawl`. Use `Firecrawl` for new code.
- `scrape_execute(job_id, code, ...)` is deprecated — use `interact(job_id, code, ...)`.
- `delete_scrape_browser(job_id)` and `stop_interactive_browser(job_id)` are deprecated — use `stop_interaction(job_id)`.
- Legacy v1 method aliases (`scrape_url`, `crawl_url`, `map_url`, etc.) still work but are deprecated. Use the modern names (`scrape`, `crawl`, `map`).
