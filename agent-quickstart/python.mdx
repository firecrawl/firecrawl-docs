# Firecrawl Python Agent Quickstart

This file is the canonical quickstart for external agents integrating Firecrawl via the Python SDK. It is generated from SDK source (`apps/python-sdk`) plus the OpenAPI spec (`api-reference/v2-openapi.json`).

## Install

```bash
pip install firecrawl-py
```

## Authenticate

```python
from firecrawl import Firecrawl

app = Firecrawl(api_key="fc-YOUR-API-KEY")
```

Or use the `FIRECRAWL_API_KEY` environment variable:

```python
app = Firecrawl()
```

### Constructor parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `api_key` | `str` | `FIRECRAWL_API_KEY` env var | API key. Omit for keyless free tier (rate-limited per IP). |
| `api_url` | `str` | `"https://api.firecrawl.dev"` | API base URL. |
| `timeout` | `float` | `None` | Default request timeout in seconds. |
| `max_retries` | `int` | `3` | Max automatic retries for transient failures. |
| `backoff_factor` | `float` | `0.5` | Exponential backoff factor. |

## When To Use What

- **`search`** — Use when you start with a query and need to discover relevant pages. Returns search results with optional full-page scraping.
- **`scrape`** — Use when you already have a URL and want page content (markdown, HTML, screenshots, structured JSON, etc.).
- **`interact`** — Use when the page needs clicks, form fills, or other post-scrape browser actions. Requires a `scrape_id` from a prior scrape.

## Search

### Why use it

Search the web (and optionally news, images, or Alexandria) with a query and get structured results. Each result can optionally include full scraped page content.

### Preferred SDK method

```
app.search(query, **options)
```

### Example

```python
from firecrawl import Firecrawl

app = Firecrawl(api_key="fc-YOUR-API-KEY")
results = app.search("firecrawl web scraping", limit=5)

for result in results.web:
    print(result.title, result.url)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `str` | **(required, first arg)** The search query. |
| `sources` | `list[str \| Source]` | Which sources to query: `"web"`, `"news"`, `"images"`, `"alexandria"`. |
| `categories` | `list[str \| Category]` | Category filters: `"github"`, `"research"`, `"pdf"`, `"developer"`. |
| `include_domains` | `list[str]` | Only include results from these domains. Cannot combine with `exclude_domains`. |
| `exclude_domains` | `list[str]` | Exclude results from these domains. Cannot combine with `include_domains`. |
| `limit` | `int` | Max number of results. Model default: `5`. |
| `tbs` | `str` | Time-based search filter (e.g. `"qdr:d"` for past day). |
| `location` | `str` | Geographic location for search results. |
| `country` | `str` | ISO country code for geo-targeting. |
| `ignore_invalid_urls` | `bool` | Ignore invalid URLs in results. |
| `timeout` | `int` | Timeout in milliseconds. Model default: `300000`. |
| `highlights` | `bool` | Generate query-relevant highlights. Server default: `True`. |
| `scrape_options` | `ScrapeOptions` | Options applied when scraping each result page. |
| `domain_tools` | `bool` | Include domain-matched Alexandria contracts in `tools`. |
| `enterprise` | `list[str]` | Enterprise options: `["zdr"]` for Zero Data Retention, `["anon"]` for anonymized. |
| `threat_protection` | `ThreatProtectionOptions` | Enterprise threat protection settings. |
| `integration` | `str` | Integration identifier. |

### Response shape

```python
SearchData:
  .warning: str | None
  .web: list[SearchResultWeb | Document] | None
  .news: list[SearchResultNews | Document] | None
  .images: list[SearchResultImages | Document] | None
  .tools: list[DiscoveredTool] | None
```

Access results via `.web`, `.news`, `.images`, or `.tools` — accessing `.data` raises a helpful `AttributeError`.

## Scrape

### Why use it

Fetch a single URL and get back clean content in your chosen formats: markdown, HTML, screenshots, structured JSON extraction, and more.

### Preferred SDK method

```
app.scrape(url, **options)
```

### Example

```python
result = app.scrape("https://example.com", formats=["markdown", "links"])

print(result.markdown)
print(result.links)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `str` | **(required, first arg)** The URL to scrape. |
| `formats` | `list[FormatOption]` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`. Also accepts dict/object forms for `json`, `screenshot`, `changeTracking`, `attributes`, `question`, `highlights`. |
| `headers` | `dict[str, str]` | Custom HTTP headers sent with the request. |
| `include_tags` | `list[str]` | Only include content from these HTML tags. |
| `exclude_tags` | `list[str]` | Exclude content from these HTML tags. |
| `only_main_content` | `bool` | Strip navbars, footers, and sidebars. |
| `timeout` | `int` | Timeout in milliseconds. |
| `wait_for` | `int` | Wait time in ms after page load before extracting. |
| `mobile` | `bool` | Emulate a mobile device. |
| `parsers` | `list[str \| PDFParser]` | File parser config (e.g. for PDFs). |
| `actions` | `list[Action]` | Browser actions to run before extraction (WaitAction, ClickAction, WriteAction, PressAction, ScrollAction, ScrapeAction, ScreenshotAction, ExecuteJavascriptAction, PDFAction). |
| `location` | `Location` | Location config with `country` and `languages`. |
| `skip_tls_verification` | `bool` | Skip TLS certificate verification. |
| `remove_base64_images` | `bool` | Remove base64-encoded images from output. |
| `fast_mode` | `bool` | Faster scrapes with reduced accuracy. |
| `block_ads` | `bool` | Block ads and cookie popups. |
| `proxy` | `str` | Proxy mode: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. |
| `max_age` | `int` | Max age (ms) of cached content to reuse. |
| `store_in_cache` | `bool` | Store the result in cache. |
| `lockdown` | `bool` | Only serve previously cached results. |
| `redact_pii` | `bool` | Redact personally identifiable information. |
| `threat_protection` | `ThreatProtectionOptions` | Enterprise threat protection. |
| `audit_metadata` | `AuditMetadata` | SIEM audit attribution (`username` field). |
| `profile` | `dict` | Persistent browser profile (`name`, `save_changes`). |
| `integration` | `str` | Integration identifier. |
| `domain_tools` | `bool` | Include domain-matched Alexandria contracts. |

## Interact

### Why use it

After scraping a page, use `interact` to take actions in the live browser session: click buttons, fill forms, navigate, or extract dynamic content. You can send a natural-language prompt or execute code directly.

### Preferred SDK method

```
app.interact(job_id, code=None, *, prompt=None, language="node", timeout=None)
```

Stop the session when done:

```
app.stop_interaction(job_id)
```

### Example

```python
result = app.scrape("https://www.amazon.com", formats=["markdown"])
scrape_id = result.metadata.get("scrapeId")

app.interact(scrape_id, prompt="Search for iPhone 16 Pro Max")
response = app.interact(scrape_id, prompt="Click on the first result and tell me the price")
print(response.output)

app.stop_interaction(scrape_id)
```

### Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `job_id` | `str` | — | **(required, first arg)** The `scrapeId` from a prior scrape's metadata. |
| `code` | `str` | `None` | Code to execute in the browser sandbox. Provide `code` or `prompt` (or both). |
| `prompt` | `str` | `None` | Natural-language instruction for the browser agent. Provide `code` or `prompt` (or both). |
| `language` | `Literal["python", "node", "bash"]` | `"node"` | Runtime language for `code`. |
| `timeout` | `int` | `None` | Execution timeout in seconds (1–300). |
| `origin` | `str` | `None` | Request attribution label. |

### Response shape

```python
BrowserExecuteResponse:
  .success: bool
  .output: str | None       # Agent output when prompt was used
  .stdout: str | None       # Stdout from code execution
  .result: str | None       # Return value from code
  .stderr: str | None
  .exit_code: int | None
  .killed: bool | None
  .error: str | None
  .live_view_url: str | None
  .interactive_live_view_url: str | None
```

## Notes

- **Naming**: All parameters use `snake_case`. The SDK converts to camelCase for the API.
- **Async**: An `AsyncFirecrawl` class is available with the same interface for async usage.
- **Deprecated aliases**: `scrape_url` → `scrape`, `scrape_execute` → `interact`, `delete_scrape_browser` / `stop_interactive_browser` → `stop_interaction`, `FirecrawlApp` → `Firecrawl`. Always use the preferred names.
- **Search results**: Access via `.web`, `.news`, `.images`, `.tools` — accessing `.data` raises an `AttributeError`.
