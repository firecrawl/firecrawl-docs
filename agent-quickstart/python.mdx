# Firecrawl Python Agent Quickstart

This file is the canonical quickstart for external agents integrating with Firecrawl using the Python SDK. It is generated from the SDK source (`firecrawl-py`) and the OpenAPI spec.

## Install

```bash
pip install firecrawl-py
```

## Authenticate

```python
from firecrawl import Firecrawl

app = Firecrawl(api_key="fc-YOUR-API-KEY")
```

The API key is resolved from: constructor `api_key` > `FIRECRAWL_API_KEY` env var. Omitting the key enables a keyless free tier (rate-limited per IP). For self-hosted instances, pass `api_url`. An async client is available as `AsyncFirecrawl`.

## When To Use What

- **`search`** — Start with a query, get web results with optional scraping. Use when you need discovery.
- **`scrape`** — Start with a URL, get page content as markdown, HTML, JSON, etc. Use when you already know the page.
- **`interact`** — Execute code or natural-language prompts in a live browser session bound to a prior scrape. Use when the page needs clicks, form fills, or post-scrape browser actions.

## Search

### Why use it

Search the web for a query and get back results with optional page content. Combines discovery and scraping in one call.

### Preferred SDK method

```python
app.search(query, **options)
```

### Example

```python
results = app.search(
    "firecrawl web scraping",
    limit=5,
    scrape_options={"formats": ["markdown"]},
)

for page in results.web or []:
    print(page.url, page.title)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `str` | **Required.** The search query. |
| `limit` | `int` | Max number of results. Default: `5`. |
| `sources` | `list[str]` | Which sources to query: `"web"`, `"news"`, `"images"`, `"alexandria"`. |
| `categories` | `list[str]` | Narrow results by category: `"github"`, `"research"`, `"pdf"`, `"developer"`. |
| `include_domains` | `list[str]` | Only return results from these domains. Mutually exclusive with `exclude_domains`. |
| `exclude_domains` | `list[str]` | Exclude results from these domains. Mutually exclusive with `include_domains`. |
| `tbs` | `str` | Time-based filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week). |
| `location` | `str` | Geographic location string for geo-targeting. |
| `country` | `str` | ISO 3166-1 alpha-2 country code for geo-targeting. |
| `highlights` | `bool` | Generate query-relevant highlights. Defaults to `True`. |
| `timeout` | `int` | Timeout in milliseconds. Default: `300000`. |
| `ignore_invalid_urls` | `bool` | Skip invalid URLs in results. |
| `scrape_options` | `ScrapeOptions` | Options applied when scraping each result page. |
| `enterprise` | `list[str]` | Enterprise search: `["zdr"]` for Zero Data Retention, `["anon"]` for anonymized. |
| `threat_protection` | `ThreatProtectionOptions` | Per-request threat protection override (enterprise). |
| `domain_tools` | `bool` | Include domain-matched Alexandria tools in results. |
| `tool_detail` | `"compact" \| "summary" \| "full"` | Detail level for discovered tools. Default: `"compact"`. |
| `integration` | `str` | Integration identifier. |

## Scrape

### Why use it

Scrape a single URL and get back clean content in your chosen formats — markdown, HTML, structured JSON, screenshots, and more.

### Preferred SDK method

```python
app.scrape(url, **options)
```

### Example

```python
doc = app.scrape(
    "https://example.com",
    formats=["markdown", "html"],
    only_main_content=True,
)

print(doc.markdown)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `str` | **Required.** The URL to scrape. |
| `formats` | `list` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"json"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`. Also accepts dicts for `json`, `screenshot`, `question`, `highlights`, `changeTracking`, and `attributes`. |
| `only_main_content` | `bool` | Extract only main content, excluding navs/footers. |
| `include_tags` | `list[str]` | HTML tags to include in output. |
| `exclude_tags` | `list[str]` | HTML tags to exclude from output. |
| `headers` | `dict[str, str]` | Custom HTTP headers for the request. |
| `timeout` | `int` | Timeout in milliseconds. |
| `wait_for` | `int` | Wait time in ms before scraping (for JS rendering). |
| `mobile` | `bool` | Emulate a mobile device. |
| `actions` | `list[dict]` | Browser actions: `wait`, `click`, `write`, `press`, `scroll`, `scrape`, `screenshot`, `executeJavascript`, `pdf`. |
| `location` | `Location` | Proxy location with `country` and `languages`. |
| `proxy` | `str` | Proxy type: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. |
| `block_ads` | `bool` | Block ads and cookie popups. |
| `skip_tls_verification` | `bool` | Skip TLS certificate verification. |
| `remove_base64_images` | `bool` | Strip base64 images from output. |
| `fast_mode` | `bool` | Faster scraping with reduced accuracy. |
| `parsers` | `list` | Document parsers. Default includes `"pdf"`. |
| `max_age` | `int` | Max age in ms of cached content to reuse. `0` bypasses cache. |
| `store_in_cache` | `bool` | Store the result in Firecrawl's index. |
| `lockdown` | `bool` | Only serve cached results; no outbound requests. |
| `redact_pii` | `bool \| RedactPIIOptions` | Redact personally identifiable information. |
| `profile` | `dict` | Persistent browser profile, e.g. `{"name": "my-profile", "saveChanges": True}`. |
| `audit_metadata` | `AuditMetadata` | User attribution for SIEM logging (`{"username": "..."`}). |
| `threat_protection` | `ThreatProtectionOptions` | Per-request threat protection override (enterprise). |
| `domain_tools` | `bool` | Include domain-matched Alexandria tools. |
| `tool_detail` | `"compact" \| "summary" \| "full"` | Detail level for discovered tools. |
| `integration` | `str` | Integration identifier. |

## Interact

### Why use it

Execute code or natural-language prompts in a live browser session that was opened by a prior scrape. Use it for clicking buttons, filling forms, navigating, or any post-scrape browser automation.

### Preferred SDK method

```python
app.interact(job_id, code=None, *, prompt=None, language="node", timeout=None)
```

### Example

```python
doc = app.scrape("https://www.amazon.com", formats=["markdown"])
scrape_id = doc.metadata.scrape_id

app.interact(scrape_id, prompt="Search for iPhone 16 Pro Max")
response = app.interact(
    scrape_id,
    prompt="Click on the first result and tell me the price",
)
print(response.output)

app.stop_interaction(scrape_id)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `str` | **Required.** The scrape job ID from `metadata.scrape_id`. |
| `prompt` | `str` | Natural-language instruction for the browser agent. Provide either `prompt` or `code`. |
| `code` | `str` | Code to execute in the browser sandbox. Provide either `prompt` or `code`. |
| `language` | `"python" \| "node" \| "bash"` | Language for code execution. Default: `"node"`. |
| `timeout` | `int` | Execution timeout in seconds (1-300). |

**Stop the session** when done:

```python
app.stop_interaction(job_id)
```

## Notes

- **Naming style**: All parameter names are snake_case.
- **Deprecated aliases**: `scrape_url` → `scrape`, `scrape_execute` → `interact`, `stop_interactive_browser` / `delete_scrape_browser` → `stop_interaction`. Use the preferred names.
- **Async client**: Use `AsyncFirecrawl` for async/await support with identical method signatures.
- **Search return shape**: `search()` returns `SearchData` with `.web`, `.news`, `.images`, and `.tools` lists. Accessing `.data` raises `AttributeError` with guidance.
- **Search defaults**: `limit` defaults to `5`, `timeout` defaults to `300000` ms.
