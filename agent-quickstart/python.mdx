# Firecrawl Python Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl-py`) and the v2 OpenAPI spec. Method names and parameters use snake_case as exposed by the v2 client.

## Install

```bash
pip install firecrawl-py
```

## Authenticate

```py
import os
from firecrawl import Firecrawl

client = Firecrawl(api_key=os.environ.get("FIRECRAWL_API_KEY"))
```

## When To Use What

- `search`: use when you start with a query and need discovery. Returns web, news, and image results.
- `scrape`: use when you already have a URL and want page content in one or more formats.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions. Requires a `scrape_id` from a prior scrape.

## Search

### Why use it

Discover relevant pages from a query, then pick URLs to scrape or interact with. Use `site:example.com` to constrain results to a single domain.

### Preferred SDK method

`client.search(query, **options)` → `SearchData`

### Example

```py
results = client.search(
    "site:docs.firecrawl.dev crawl webhooks",
    sources=["web"],
    limit=5,
    scrape_options={"formats": ["markdown"], "only_main_content": True},
)

for hit in results.web or []:
    print(getattr(hit, "url", None), getattr(hit, "title", None))
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `query` | str | Search query. Use `site:domain` to scope. | Always required. |
| `sources` | list | `"web"`, `"news"`, `"images"`, or `Source(type=...)` objects. | Control result buckets. |
| `categories` | list | `"developer"`, `"research"`, `"pdf"`, or `Category(type=...)` objects. | Filter by category. |
| `limit` | int | Maximum number of results. Default: `5`. | Cap result count. |
| `tbs` | str | Time-based filter (e.g. `"qdr:d"`, `"qdr:w"`). | Filter by recency. |
| `location` | str | Localized results string. | Geo-targeted search. |
| `country` | str | ISO 3166-1 alpha-2 country code. | Country-level targeting. |
| `ignore_invalid_urls` | bool | Drop URLs that cannot be scraped. | Clean up results. |
| `timeout` | int | Request timeout in milliseconds. Default: `300000`. | Long-running searches. |
| `scrape_options` | ScrapeOptions or dict | Scrape each search result (same fields as scrape options). | Hydrate search hits with content. |
| `include_domains` | list[str] | Only include results from these domains. | Domain allowlist. |
| `exclude_domains` | list[str] | Exclude results from these domains. | Domain blocklist. |
| `highlights` | bool | Include highlights. Default: `True`. | Toggle highlight snippets. |

**Return value:** `SearchData` has optional lists — `web`, `news`, `images`. Do not access `result.data`; results are in `result.web`, etc.

## Scrape

### Why use it

Fetch structured content from a known URL in one or more formats (markdown, HTML, JSON extraction, screenshots, etc.).

### Preferred SDK method

`client.scrape(url, **options)` → `Document`

### Example

```py
doc = client.scrape(
    "https://example.com/pricing",
    formats=[
        "markdown",
        {"type": "json", "prompt": "Extract plan names and prices."},
    ],
    only_main_content=True,
    wait_for=1000,
)

print(doc.markdown)
print(doc.json)
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `url` | str | Page URL to scrape. | Always required. |
| `formats` | list | Output formats. Plain strings: `"markdown"`, `"html"`, `"rawHtml"` / `"raw_html"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"` / `"change_tracking"`, `"attributes"`, `"branding"`, `"audio"`, `"video"`. Object forms: `{"type": "json", "prompt": ..., "schema": ...}`, `{"type": "question", "question": ...}`, `{"type": "highlights", "query": ...}`, `{"type": "screenshot", "full_page": ..., "quality": ..., "viewport": ...}`, `{"type": "changeTracking", "modes": [...], "tag": ...}`, `{"type": "attributes", "selectors": [...]}`. Use the dict form for `"json"` — not the plain string. | Choose output formats. |
| `headers` | dict | Custom HTTP headers. | Auth or custom user-agent. |
| `include_tags` | list[str] | Only include these HTML tags. | Narrow content extraction. |
| `exclude_tags` | list[str] | Exclude these HTML tags. | Remove boilerplate elements. |
| `only_main_content` | bool | Strip nav, footer, and boilerplate. | Cleaner output. |
| `timeout` | int | Timeout in milliseconds. | Long-loading pages. |
| `wait_for` | int | Wait for page to render (ms). | JS-heavy pages. |
| `mobile` | bool | Use mobile viewport. | Mobile-specific content. |
| `parsers` | list | Parser controls. E.g. `"pdf"` or `{"type": "pdf", "mode": "auto", "max_pages": 5}`. | PDF or file parsing. |
| `actions` | list | Pre-scrape browser actions. Types: `wait`, `click`, `write`, `press`, `scroll`, `screenshot`, `scrape`, `executeJavascript`, `pdf`. | Cookie banners, login flows. |
| `location` | dict | `{"country": ..., "languages": [...]}` for geo-aware scraping. | Localized content. |
| `skip_tls_verification` | bool | Skip TLS verification. | Self-signed certs. |
| `remove_base64_images` | bool | Drop base64 images from markdown. | Reduce output size. |
| `fast_mode` | bool | Faster scrapes, reduced fidelity. | Speed over completeness. |
| `block_ads` | bool | Block ads and cookie popups. | Cleaner pages. |
| `proxy` | str | `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. | Geo-restricted or bot-protected sites. |
| `max_age` | int | Use cached data up to this age (ms). | Reduce API calls. |
| `store_in_cache` | bool | Cache the result. | Enable future cache hits. |
| `profile` | dict | `{"name": ..., "save_changes": True}` for persistent browser profile. | Maintain login state across scrapes. |

## Interact

### Why use it

Control the browser session tied to a scrape job. Use it for clicks, form fills, code execution, or natural-language browser instructions. Requires a `scrape_id` from a prior scrape response.

### Preferred SDK method

`client.interact(job_id, code=None, *, prompt=None, language="node", timeout=None)`

Note: `prompt` is keyword-only.

### Example

```py
doc = client.scrape("https://example.com", formats=["markdown"])
job_id = doc.metadata.scrape_id if doc.metadata else None
if not job_id:
    raise RuntimeError("Missing scrape_id")

result = client.interact(job_id, prompt="Click the pricing tab and summarize the plans.")

print(result.output)

# When done, stop the session
client.stop_interaction(job_id)
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `job_id` | str | Scrape job ID from `document.metadata.scrape_id`. | Always required. |
| `code` | str | Code to run in the browser session. | Programmatic browser control. |
| `prompt` | str | Natural-language instruction for the browser agent. Keyword-only. | Describe what to do in plain English. |
| `language` | str | Runtime: `"python"`, `"node"`, `"bash"`. Default: `"node"`. | Choose execution runtime. |
| `timeout` | int | Execution timeout in seconds. | Long-running interactions. |

At least one of `code` or `prompt` must be provided (SDK validates this).

**Stop session:** `client.stop_interaction(job_id)` ends the browser session.

## Notes

- Deprecated aliases: `scrape_execute` → `interact`; `stop_interactive_browser` / `delete_scrape_browser` → `stop_interaction`.
- The top-level `Firecrawl` client exposes v2 methods directly.
- `search()` returns `SearchData` with `web`, `news`, `images` attributes — not a flat `data` list.
- Both snake_case and camelCase format strings are accepted (e.g. `"rawHtml"` and `"raw_html"`).
