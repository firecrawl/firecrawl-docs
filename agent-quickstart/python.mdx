# Firecrawl Python Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl-py`) and the v2 OpenAPI spec. Method names, parameters, and types match the SDK public API. All parameter names use snake_case.

## Install

```bash
pip install firecrawl-py
```

## Authenticate

```python
from firecrawl import Firecrawl

client = Firecrawl(api_key="your-api-key")
# Or use the FIRECRAWL_API_KEY environment variable
```

## When To Use What

- **`search`**: use when you start with a query and need discovery. Returns ranked results from web, news, or images.
- **`scrape`**: use when you already have a URL and want page content in one or more formats (markdown, HTML, JSON extraction, screenshots, etc.).
- **`interact`**: use when the page needs clicks, forms, or post-scrape browser actions. Operates on the browser session tied to a prior scrape job.

## Search

### Why use it

Discover relevant pages from a query, then pick URLs to scrape or interact with. Supports `site:` prefix to limit results to a domain.

### Preferred SDK method

`client.search(query, **kwargs)` → `SearchData`

### Example

```python
results = client.search(
    "site:docs.firecrawl.dev webhook retries",
    limit=10,
    scrape_options=ScrapeOptions(
        formats=["markdown"],
        only_main_content=True,
    ),
)

for item in results.web or []:
    print(item.url, item.title)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `str` | The search query. Use `site:example.com` to scope results. |
| `sources` | `list[str \| Source]` | Sources to search: `"web"`, `"news"`, `"images"`, `"alexandria"`. Default: `["web"]`. |
| `categories` | `list[str \| Category]` | Filter by category: `"github"`, `"research"`, `"pdf"`, `"developer"`, `"gov"`. |
| `include_domains` | `list[str]` | Restrict to these domains. Cannot combine with `exclude_domains`. |
| `exclude_domains` | `list[str]` | Exclude these domains. Cannot combine with `include_domains`. |
| `limit` | `int` | Max results per source type. Default in types: 5. |
| `tbs` | `str` | Time-based filter (e.g. `qdr:d`, `qdr:w`, `sbd:1`). |
| `location` | `str` | Localized results (e.g. `"San Francisco,California,United States"`). |
| `country` | `str` | ISO 3166-1 alpha-2 code (e.g. `"US"`). |
| `ignore_invalid_urls` | `bool` | Drop URLs that cannot be scraped. |
| `timeout` | `int` | Timeout in ms. Default in types: 300000. |
| `highlights` | `bool` | Generate query-relevant highlights. Default: `True`. |
| `scrape_options` | `ScrapeOptions` | Apply scrape options to each result (see Scrape parameters). |
| `domain_tools` | `bool` | Include Alexandria tool contracts matched to result domains. |
| `tool_detail` | `"compact" \| "summary" \| "full"` | Tool contract detail level. |
| `enterprise` | `list[str]` | Enterprise ZDR options: `["zdr"]` or `["anon"]`. |
| `threat_protection` | `ThreatProtectionOptions` | Per-request threat protection override. |
| `integration` | `str` | Integration identifier. |

### Return value

`SearchData` contains optional lists:

- `web` — web index hits (`SearchResultWeb` or `Document`)
- `news` — news hits (`SearchResultNews` or `Document`)
- `images` — image hits (`SearchResultImages`)
- `tools` — discovered Alexandria tool contracts

**Do not** access `result.data` — it raises `AttributeError`. Use `result.web`, `result.news`, `result.images`.

## Scrape

### Why use it

Fetch structured content from a URL in one or more formats. Supports markdown, HTML, JSON extraction, screenshots, change tracking, and more.

### Preferred SDK method

`client.scrape(url, **kwargs)` → `Document`

### Example

```python
doc = client.scrape(
    "https://example.com/pricing",
    formats=[
        "markdown",
        {"type": "json", "prompt": "Extract plan names and prices."},
    ],
    only_main_content=True,
)

print(doc.markdown)
print(doc.json)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `str` | The URL to scrape. |
| `formats` | `list[FormatOption]` | Output formats. Default: `["markdown"]`. See format types below. |
| `headers` | `dict[str, str]` | Custom HTTP headers. |
| `include_tags` | `list[str]` | Only include content from these HTML tags. |
| `exclude_tags` | `list[str]` | Exclude content from these HTML tags. |
| `only_main_content` | `bool` | Strip nav, footer, boilerplate. Default: `True`. |
| `timeout` | `int` | Timeout in ms. Default: 60000. Max: 300000. |
| `wait_for` | `int` | Delay in ms before fetching (for JS rendering). |
| `mobile` | `bool` | Emulate mobile device. |
| `parsers` | `list[str \| PDFParser \| ImageParser]` | File parsing controls (e.g. `[PDFParser(mode="auto")]`). |
| `actions` | `list[ActionOption]` | Pre-scrape browser actions. See action types below. |
| `location` | `Location` | Geo/language-aware scraping (`country`, `languages`). |
| `skip_tls_verification` | `bool` | Skip TLS verification. |
| `remove_base64_images` | `bool` | Drop base64 images from output. |
| `fast_mode` | `bool` | Faster scrapes with reduced fidelity. |
| `block_ads` | `bool` | Block ads and cookie popups. |
| `proxy` | `"basic" \| "stealth" \| "enhanced" \| "auto"` | Proxy mode. |
| `max_age` | `int` | Use cached result if younger than this (ms). Default: 172800000 (2 days). |
| `store_in_cache` | `bool` | Cache the result. |
| `lockdown` | `bool` | Serve from cache only, never make outbound requests. |
| `redact_pii` | `bool \| RedactPIIOptions` | Redact personally identifiable information. |
| `profile` | `dict` | Persistent browser profile (`{"name": "...", "save_changes": True}`). |
| `audit_metadata` | `AuditMetadata` | User attribution for SIEM logging (`AuditMetadata(username="...")`). |
| `domain_tools` | `bool` | Include Alexandria tool contracts matched to the domain. |
| `tool_detail` | `"compact" \| "summary" \| "full"` | Tool contract detail level. |
| `threat_protection` | `ThreatProtectionOptions` | Per-request threat protection override. |
| `integration` | `str` | Integration identifier. |

#### Format types

Plain strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`.

Python also accepts snake_case aliases: `"raw_html"`, `"change_tracking"`.

Object formats (dicts with at least `type`):

| Format | Fields | Notes |
|---|---|---|
| `json` | `prompt?`, `schema?`, `checkPromptInjection?` | At least one of `prompt` or `schema` required. |
| `question` | `question` (required) | Ask a question about the page. |
| `highlights` | `query` (required) | Find relevant source text. |
| `screenshot` | `fullPage?`, `quality?`, `viewport?` | |
| `changeTracking` | `modes` (required), `schema?`, `prompt?`, `tag?` | |
| `attributes` | `selectors` (required) | |

#### Action types

| Action | Required fields | Optional fields |
|---|---|---|
| `WaitAction` | `milliseconds` or `selector` | |
| `ClickAction` | `selector` | |
| `WriteAction` | `text` | |
| `PressAction` | `key` | |
| `ScrollAction` | `direction` (`"up"` / `"down"`) | `selector` |
| `ScrapeAction` | (none) | |

## Interact

### Why use it

Run code or natural-language prompts in the browser session tied to a scrape job. Use for multi-step flows like filling forms, navigating tabs, or extracting dynamic content.

### Preferred SDK method

`client.interact(job_id, code=None, *, prompt=None, language="node", timeout=None)` → `BrowserExecuteResponse`

### Example

```python
doc = client.scrape("https://example.com", formats=["markdown"])
job_id = doc.metadata.scrape_id if doc.metadata else None

result = client.interact(
    job_id,
    code="console.log(await page.title());",
    language="node",
    timeout=60,
)
print(result.stdout)

client.stop_interaction(job_id)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `str` | Scrape job ID from `document.metadata.scrape_id`. |
| `code` | `str` | Code to execute in the browser sandbox. |
| `prompt` | `str` | Natural-language instruction for the browser agent. |
| `language` | `"python" \| "node" \| "bash"` | Runtime language. Default: `"node"`. |
| `timeout` | `int` | Execution timeout in seconds (1–300). API default: 30. |

At least one of `code` or `prompt` must be provided.

### Return value

`BrowserExecuteResponse` fields: `success`, `stdout`, `result`, `stderr`, `exit_code`, `killed`, `output`, `error`.

### Stop session

`client.stop_interaction(job_id)` → `BrowserDeleteResponse`

Response fields: `success`, `session_duration_ms`, `credits_billed`, `error`.

## Notes

- Deprecated aliases: `scrape_url` → `scrape`; `scrape_execute` → `interact`; `delete_scrape_browser` / `stop_interactive_browser` → `stop_interaction`; `FirecrawlApp` → `Firecrawl`; `AsyncFirecrawlApp` → `AsyncFirecrawl`; `ParseOptions` → `ScrapeOptions`.
- Async client is available as `AsyncFirecrawl` with the same method signatures.
- Constructor options: `api_key`, `api_url` (default `"https://api.firecrawl.dev"`), `timeout`, `max_retries` (default 3), `backoff_factor` (default 0.5), `origin`.
