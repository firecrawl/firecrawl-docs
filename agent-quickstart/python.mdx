# Firecrawl Python Agent Quickstart

This is the canonical quickstart for external agents using the Firecrawl Python SDK. It covers `search`, `scrape`, and `interact` — the three endpoints agents need most. Generated from SDK source (`firecrawl-py` v4.x) and the Firecrawl OpenAPI spec.

## Install

```bash
pip install firecrawl-py
```

## Authenticate

```python
from firecrawl import Firecrawl

client = Firecrawl(api_key="fc-YOUR-API-KEY")
# Or omit the key for keyless free tier (rate-limited per IP):
# client = Firecrawl()
```

The API key can also be set via the `FIRECRAWL_API_KEY` environment variable. The base URL defaults to `https://api.firecrawl.dev` and can be overridden with `api_url`.

An async client is also available:

```python
from firecrawl import AsyncFirecrawl

client = AsyncFirecrawl(api_key="fc-YOUR-API-KEY")
```

## When To Use What

- **`search`** — Start here when you have a query and need to discover relevant URLs and content from the web.
- **`scrape`** — Use when you already have a specific URL and want its page content as markdown, HTML, structured JSON, or other formats.
- **`interact`** — Use after a scrape when the page needs further browser actions: clicking buttons, filling forms, or running code in the live browser session.

## Search

### Why use it

Search the web with a natural-language query and get back structured results with URLs, titles, descriptions, and optionally full scraped content for each result.

### Preferred SDK method

```python
client.search(query, **options)
```

### Example

```python
results = client.search("firecrawl web scraping API", limit=5)

for result in results.web or []:
    print(result.url, result.title)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `str` | **Required.** The search query. |
| `limit` | `int` | Maximum number of results. Default: `5` (SDK), `10` (API). |
| `sources` | `list[str]` | Sources to search: `"web"`, `"news"`, `"images"`, `"alexandria"`. Default: `["web"]`. |
| `include_domains` | `list[str]` | Restrict results to these domains. |
| `exclude_domains` | `list[str]` | Exclude results from these domains. |
| `tbs` | `str` | Time-based filter. `"qdr:h"` (past hour), `"qdr:d"` (past day), `"qdr:w"` (past week), `"qdr:m"` (past month), `"qdr:y"` (past year). |
| `location` | `str` | Geographic location for results (e.g. `"San Francisco,California,United States"`). |
| `country` | `str` | ISO country code for geo-targeting (e.g. `"US"`). Default: `"US"`. |
| `highlights` | `bool` | Generate query-relevant highlights. Default: `True`. |
| `timeout` | `int` | Timeout in milliseconds. Default: `300000` (SDK). |
| `ignore_invalid_urls` | `bool` | Exclude invalid URLs from results. |
| `categories` | `list[str]` | Filter by category: `"github"`, `"research"`, `"pdf"`, `"developer"`. |
| `scrape_options` | `ScrapeOptions` | Options applied when scraping each result page. |
| `domain_tools` | `bool` | Include tool contracts matched to result domains. |
| `tool_detail` | `str` | Detail level for discovered tools: `"compact"`, `"summary"`, `"full"`. |
| `enterprise` | `list[str]` | Enterprise ZDR options: `["zdr"]` or `["anon"]`. |
| `threat_protection` | `ThreatProtectionOptions` | Threat protection configuration. |
| `integration` | `str` | Integration identifier for telemetry. |

**Return type:** `SearchData` with properties `.web`, `.news`, `.images`, `.tools` (each an optional list). Note: there is no `.data` property — access results by source type.

## Scrape

### Why use it

Fetch a single URL and get back clean markdown, HTML, structured JSON, screenshots, or other formats. The SDK handles retries and auto-resume for large documents.

### Preferred SDK method

```python
client.scrape(url, **options)
```

### Example

```python
doc = client.scrape("https://example.com", formats=["markdown"])

print(doc.markdown)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `str` | **Required.** The URL to scrape. |
| `formats` | `list` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"json"`, `"audio"`, `"video"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"changeTracking"`. Also accepts format objects like `JsonFormat` for structured extraction. |
| `headers` | `dict[str, str]` | Custom HTTP headers (cookies, user-agent, etc.). |
| `include_tags` | `list[str]` | Only include content from these HTML tags. |
| `exclude_tags` | `list[str]` | Exclude content from these HTML tags. |
| `only_main_content` | `bool` | Strip headers, navs, footers. Default: `True` (API). |
| `timeout` | `int` | Timeout in milliseconds. Default: `60000`. Min: `1000`. |
| `wait_for` | `int` | Delay in milliseconds before fetching, for JS-rendered pages. |
| `mobile` | `bool` | Emulate a mobile device. |
| `actions` | `list` | Browser actions to run before content grab (click, scroll, type, wait, screenshot, scrape, execute JS). |
| `location` | `Location` | Proxy location settings with `country` and `languages` fields. |
| `skip_tls_verification` | `bool` | Skip TLS certificate verification. |
| `remove_base64_images` | `bool` | Remove base64 images from markdown. Default: `True` (API). |
| `fast_mode` | `bool` | Faster scraping with reduced accuracy. |
| `block_ads` | `bool` | Block ads and cookie popups. Default: `True` (API). |
| `proxy` | `str` | Proxy type: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. Default: `"auto"` (API). |
| `max_age` | `int` | Return cached content if younger than this (milliseconds). Default: `172800000`. |
| `store_in_cache` | `bool` | Store the result in Firecrawl's cache. Default: `True` (API). |
| `lockdown` | `bool` | Only serve cached results, never make outbound request. |
| `parsers` | `list` | File processing controls (e.g. PDF parsing mode). |
| `redact_pii` | `bool \| RedactPIIOptions` | Redact personally identifiable information. |
| `threat_protection` | `ThreatProtectionOptions` | Threat protection settings. |
| `audit_metadata` | `AuditMetadata` | User attribution for SIEM logging. |
| `profile` | `dict` | Persistent browser storage across sessions (`name` required, `save_changes` optional). |
| `domain_tools` | `bool` | Include tool contracts matched to the scraped domain. |
| `tool_detail` | `str` | Detail level for discovered tools: `"compact"`, `"summary"`, `"full"`. |
| `integration` | `str` | Integration identifier. |

**SDK-only option:**

| Parameter | Type | Description |
|---|---|---|
| `auto_resume` | `bool` | Auto-retry on `processing_continues` timeout responses for large documents. Default: `True`. |

## Interact

### Why use it

Continue interacting with the same browser state from a previous scrape. Execute code or send a natural-language prompt to an AI agent that controls the browser. Useful for clicking buttons, filling forms, navigating SPAs, or extracting data that requires interaction.

### Preferred SDK method

```python
client.interact(job_id, code=None, *, prompt=None, language="node", timeout=None, origin=None)
```

### Example

```python
# First, scrape a page
doc = client.scrape("https://example.com", formats=["markdown"])
job_id = doc.metadata.scrape_id

# Then interact with the live browser session
result = client.interact(
    job_id,
    code='const title = await page.title(); JSON.stringify({ title });',
    language="node",
    timeout=30,
)

print(result.result)

# Or use a natural-language prompt
ai_result = client.interact(
    job_id,
    prompt="Click the pricing tab and tell me the Pro plan price",
    timeout=60,
)

print(ai_result.output)

# Clean up when done
client.stop_interaction(job_id)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `str` | **Required.** The scrape job ID from `doc.metadata.scrape_id`. |
| `code` | `str` | Code to execute in the browser sandbox. Required if `prompt` is not set. |
| `prompt` | `str` | Natural-language task for the AI browser agent. Required if `code` is not set. |
| `language` | `str` | Language for `code` execution: `"python"`, `"node"`, `"bash"`. Default: `"node"`. |
| `timeout` | `int` | Execution timeout in seconds (1–300). Default: `30`. |
| `origin` | `str` | Origin label for telemetry. |

**Stop method:** `client.stop_interaction(job_id)` — call this to end the browser session when done.

## Notes

- All parameter names use **snake_case** (e.g. `only_main_content`, `include_tags`, `scrape_options`).
- The Pydantic models accept both snake_case and camelCase from the API via `populate_by_name`.
- `SearchData` has no `.data` property — access results via `.web`, `.news`, `.images`, or `.tools`.
- The `scrape` method also supports Alexandria tool execution (pass `alexandria` instead of `url`) for provider-catalogued tools.
- **Deprecated aliases** (use the preferred names instead):
  - `scrape_execute()` → `interact()`
  - `stop_interactive_browser()` / `delete_scrape_browser()` → `stop_interaction()`
  - `scrape_url()` → `scrape()`
  - `FirecrawlApp` → `Firecrawl`
  - `AsyncFirecrawlApp` → `AsyncFirecrawl`
