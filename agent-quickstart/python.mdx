# Firecrawl Python Agent Quickstart

This is the canonical quickstart for external agents integrating with Firecrawl using the Python SDK. Generated from SDK source and OpenAPI spec.

## Install

```bash
pip install firecrawl-py
```

## Authenticate

```python
from firecrawl import Firecrawl

client = Firecrawl(api_key="fc-YOUR_API_KEY")

# Or with a custom API URL:
client = Firecrawl(
    api_key="fc-YOUR_API_KEY",
    api_url="https://api.firecrawl.dev",  # optional, also reads FIRECRAWL_API_URL env var
)
```

The API key can also be set via the `FIRECRAWL_API_KEY` environment variable.

## When To Use What

- **search** — start with a query and discover relevant URLs with optional page content. Use when you don't have a URL yet.
- **scrape** — start with a known URL and extract page content in various formats. Use when you already know which page you need.
- **interact** — execute code in a browser session bound to a prior scrape. Use when the page needs post-scrape browser interaction like clicking, typing, or navigating.

## Search

### Why use it

Search finds pages matching a query across web, news, and image sources, and optionally returns their scraped content. Use it for discovery when you need to find relevant URLs.

### Preferred SDK method

```python
client.search(query, **kwargs)
```

### Example

```python
results = client.search(
    "firecrawl web scraping API",
    limit=5,
    scrape_options={"formats": ["markdown"]},
)

for item in results.web or []:
    print(item.url, (item.markdown or "")[:100])
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `query` | `str` | Search query string (required, passed as first argument). Max 500 chars. |
| `limit` | `int` | Max results to return per source type. Min 1, max 100. Default: 10. |
| `sources` | `list` | Sources to search: `"web"`, `"news"`, `"images"`, `"alexandria"`. Default: `["web"]`. |
| `categories` | `list` | Filter by category: `"developer"`, `"gov"`, `"research"`, `"pdf"`. |
| `include_domains` | `list[str]` | Restrict results to these domains. Cannot combine with `exclude_domains`. |
| `exclude_domains` | `list[str]` | Exclude results from these domains. Cannot combine with `include_domains`. |
| `tbs` | `str` | Time-based search filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week). |
| `location` | `str` | Location for geo-targeted results (e.g. `"San Francisco,California,United States"`). |
| `country` | `str` | ISO country code for geo-targeting (e.g. `"US"`). Default: `"US"`. |
| `ignore_invalid_urls` | `bool` | Exclude URLs invalid for other Firecrawl endpoints. Default: `False`. |
| `timeout` | `int` | Timeout in milliseconds. Default: 60000. |
| `highlights` | `bool` | Generate query-relevant highlights. Default: `True`. |
| `scrape_options` | `dict` | Options for scraping each result page (see Scrape parameters, minus `url`). |
| `enterprise` | `list[str]` | Enterprise options: `["zdr"]` for zero data retention, `["anon"]` for anonymized. |
| `domain_tools` | `bool` | Include tool contracts matching returned domains. |
| `tool_detail` | `str` | Tool contract detail level: `"compact"`, `"summary"`, `"full"`. |

## Scrape

### Why use it

Scrape extracts structured content from a single URL. Returns markdown, HTML, links, screenshots, structured JSON, and more depending on the formats you request.

### Preferred SDK method

```python
client.scrape(url, **kwargs)
```

### Example

```python
result = client.scrape(
    "https://example.com",
    formats=["markdown", "links"],
    only_main_content=True,
    timeout=30000,
)

print(result.markdown)
print(result.links)
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `url` | `str` | The URL to scrape (required, passed as first argument). |
| `formats` | `list` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"json"`, `"summary"`, `"changeTracking"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`. Some accept sub-options (e.g. json with `schema`/`prompt`). Default: `["markdown"]`. |
| `only_main_content` | `bool` | Strip navs, footers, and boilerplate. Default: `True`. |
| `include_tags` | `list[str]` | HTML tags to include (allowlist). |
| `exclude_tags` | `list[str]` | HTML tags to exclude (blocklist). |
| `headers` | `dict[str, str]` | Custom HTTP headers (cookies, user-agent, etc.). |
| `wait_for` | `int` | Delay in ms before fetching content. Max 60000. Default: 0. |
| `timeout` | `int` | Request timeout in milliseconds. Min 1000, max 300000. Default: 60000. |
| `mobile` | `bool` | Emulate a mobile device. Default: `False`. |
| `skip_tls_verification` | `bool` | Skip TLS certificate verification. Default: `True`. |
| `remove_base64_images` | `bool` | Strip base64-encoded images from output. Default: `True`. |
| `block_ads` | `bool` | Block ads and cookie popups. Default: `True`. |
| `proxy` | `str` | Proxy mode: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. Default: `"auto"`. |
| `actions` | `list` | Browser actions to perform before scraping: `wait`, `click`, `write`, `press`, `scroll`, `screenshot`, `scrape`, `executeJavascript`, `pdf`. |
| `location` | `Location` | Location settings: `Location(country="US", languages=["en"])`. |
| `parsers` | `list` | File parsers (e.g. PDF with `max_pages`, `pages`, `mode`). Default: `["pdf", "image"]`. |
| `max_age` | `int` | Max cache age in ms. Default: 172800000 (2 days). Set 0 to bypass cache. |
| `store_in_cache` | `bool` | Store result in Firecrawl cache. Default: `True`. |
| `lockdown` | `bool` | Serve from cache only, never make outbound request. Default: `False`. |
| `check_prompt_injection` | `bool` | Scan for prompt injection before LLM formats. Adds 4 credits. Default: `False`. |
| `profile` | `dict` | Persistent browser profile: `{"name": "my-profile", "save_changes": True}`. |
| `audit_metadata` | `AuditMetadata` | SIEM logging attribution: requires `username`. |
| `domain_tools` | `bool` | List tool contracts for the scraped domain. |
| `tool_detail` | `str` | Tool contract detail: `"compact"`, `"summary"`, `"full"`. |
| `fast_mode` | `bool` | Use fast mode for quicker scraping. |
| `auto_resume` | `bool` | Auto-resume large documents that time out. |

## Interact

### Why use it

Interact lets you execute code in the browser session that was opened by a prior scrape. You write JavaScript, Python, or Bash code that runs in the browser sandbox — use it to click buttons, fill forms, navigate pages, or extract dynamic content that requires post-scrape interaction.

### Preferred SDK method

```python
client.interact(job_id, code=None, *, prompt=None, language="node", timeout=None)
```

### Example

```python
# First scrape a page — the browser session stays open
scrape_result = client.scrape("https://example.com/app", formats=["markdown"])
job_id = scrape_result.metadata.get("jobId")

# Execute code in the browser session
result = client.interact(
    job_id,
    code="""
        await page.click('#login-button');
        await page.fill('#username', 'user@example.com');
        await page.fill('#password', 'secret');
        await page.click('#submit');
        await page.waitForSelector('.dashboard');
        return await page.content();
    """,
    language="node",
    timeout=30,
)

print(result.output)

# Stop the browser session when done
client.stop_interaction(job_id)
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `job_id` | `str` | The scrape job ID from a prior scrape (required, passed as first argument). |
| `code` | `str` | Code to execute in the browser sandbox. Required if `prompt` is not provided. Max 100000 chars. |
| `prompt` | `str` | Natural-language instruction for the browser agent. Required if `code` is not provided. |
| `language` | `str` | Runtime language: `"python"`, `"node"`, `"bash"`. Default: `"node"`. |
| `timeout` | `int` | Execution timeout in seconds. Min 1, max 300. Default: 30. |

At least one of `code` or `prompt` must be provided.

**Related methods:**

| Method | Description |
|--------|-------------|
| `client.stop_interaction(job_id)` | Stops the interactive browser session. |

## Notes

- The package name is `firecrawl-py`. Import as `from firecrawl import Firecrawl`.
- All parameter names use snake_case.
- The scrape method accepts parameters as keyword arguments directly (not as a dict).
- Deprecated aliases: `scrape_url()` → use `scrape()`, `scrape_execute()` → use `interact()`, `stop_interactive_browser()` / `delete_scrape_browser()` → use `stop_interaction()`.
- `FirecrawlApp` is a deprecated alias for `Firecrawl`.
- An async client is available as `AsyncFirecrawl` (alias `AsyncFirecrawlApp`).
