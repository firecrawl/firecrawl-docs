# Firecrawl Python Agent Quickstart

This file is the canonical quickstart for external agents integrating with Firecrawl using the Python SDK. It is generated from SDK source plus OpenAPI.

## Install

```bash
pip install firecrawl-py
```

## Authenticate

```python
from firecrawl import FirecrawlApp

firecrawl = FirecrawlApp(api_key="fc-YOUR_API_KEY")
```

## When To Use What

- **search** — Use when you start with a query and need to discover relevant URLs and content across the web.
- **scrape** — Use when you already have a URL and want to extract page content in structured formats.
- **interact** — Use when the page needs post-scrape browser actions like clicking, typing, or running code in the browser session.

## Search

### Why use it

Search combines web search with optional scraping of each result. It returns structured results from multiple sources (web, news, images) and can scrape each result page in the same call.

### Preferred SDK method

```python
firecrawl.search(query, **kwargs)
```

### Example

```python
results = firecrawl.search(
    "firecrawl web scraping",
    limit=5,
    scrape_options=ScrapeOptions(formats=["markdown"]),
)

for item in results.data.get("web", []):
    print(item["url"], item["title"])
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `str` | **Required.** The search query (max 500 chars). |
| `limit` | `int` | Max results per source type. Default: `10`, max: `100`. |
| `sources` | `list[SourceOption]` | Sources to search: `"web"`, `"news"`, `"images"`, `"alexandria"`. Default: `["web"]`. |
| `categories` | `list[CategoryOption]` | Filter by category: `"developer"`, `"research"`, `"pdf"`, `"gov"`. |
| `include_domains` | `list[str]` | Restrict results to these domains (hostnames only). Cannot combine with `exclude_domains`. |
| `exclude_domains` | `list[str]` | Exclude results from these domains. Cannot combine with `include_domains`. |
| `tbs` | `str` | Time-based filter. E.g., `"qdr:d"` (past day), `"qdr:w"` (past week). |
| `location` | `str` | Location string, e.g., `"San Francisco,California,United States"`. |
| `country` | `str` | ISO country code for geo-targeting, e.g., `"US"`. Default: `"US"`. |
| `ignore_invalid_urls` | `bool` | Exclude URLs invalid for other Firecrawl endpoints. Default: `false`. |
| `timeout` | `int` | Timeout in milliseconds. Default: `60000`. |
| `highlights` | `bool` | Generate query-relevant highlights. Default: `true`. |
| `scrape_options` | `ScrapeOptions` | Options applied to scraping each result page. |
| `domain_tools` | `bool` | Include domain-matched tool contracts alongside results. |
| `tool_detail` | `"compact" \| "summary" \| "full"` | Detail level for tool contracts. Default: `"compact"`. |
| `enterprise` | `list[str]` | Enterprise ZDR options: `["zdr"]` or `["anon"]`. Must be enabled for your team. |

## Scrape

### Why use it

Scrape fetches a single URL and returns page content in one or more formats (markdown, HTML, JSON extraction, screenshots, etc.). Use it when you already know which page you need.

### Preferred SDK method

```python
firecrawl.scrape(url, **kwargs)
```

### Example

```python
doc = firecrawl.scrape(
    "https://example.com",
    formats=["markdown", "links"],
    only_main_content=True,
)

print(doc.markdown)
print(doc.links)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `str` | **Required.** The URL to scrape. |
| `formats` | `list[FormatOption]` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"screenshot"`, `"json"`, `"images"`, `"audio"`, `"video"`, `"summary"`, `"changeTracking"`, `"attributes"`, etc. |
| `only_main_content` | `bool` | Strip headers, navs, footers. Default: `true`. |
| `include_tags` | `list[str]` | HTML tags to exclusively include. |
| `exclude_tags` | `list[str]` | HTML tags to exclude. |
| `timeout` | `int` | Timeout in ms. Default: `60000`. Min: `1000`, max: `300000`. |
| `wait_for` | `int` | Extra delay in ms after page load. Default: `0`, max: `60000`. |
| `mobile` | `bool` | Emulate a mobile device. Default: `false`. |
| `headers` | `dict[str, str]` | Custom HTTP headers (cookies, user-agent, etc.). |
| `parsers` | `list` | Parser configs: `"pdf"`, `"image"`, or dicts like `{"type": "pdf", "mode": "ocr", "maxPages": 50}`. |
| `actions` | `list` | Browser actions before scraping: `wait`, `click`, `write`, `press`, `scroll`, `screenshot`, `scrape`, `executeJavascript`, `pdf`. |
| `location` | `Location` | Proxy location. E.g., `Location(country="DE")`. Default: `"US"`. |
| `skip_tls_verification` | `bool` | Skip TLS verification. Default: `true`. |
| `remove_base64_images` | `bool` | Remove base64 images from markdown. Default: `true`. |
| `block_ads` | `bool` | Block ads and cookie popups. Default: `true`. |
| `proxy` | `str` | Proxy type: `"basic"`, `"enhanced"`, `"auto"`. Default: `"auto"`. |
| `max_age` | `int` | Accept cached content younger than this (ms). Default: `172800000` (2 days). Set to `0` to bypass cache. |
| `store_in_cache` | `bool` | Cache the result for future requests. Default: `true`. |
| `lockdown` | `bool` | Serve only from cache, never make outbound requests. Default: `false`. |
| `check_prompt_injection` | `bool` | Scan for prompt injection before LLM formats. Adds 4 credits. Default: `false`. |

## Interact

### Why use it

Interact lets you execute code in the browser session that was used for a scrape. Use it when you need to click buttons, fill forms, navigate, or run arbitrary browser-side code after the initial scrape.

### Preferred SDK method

```python
firecrawl.interact(job_id, code=None, *, prompt=None, language="node", timeout=None)
```

### Example

```python
# First, scrape to get a job ID
doc = firecrawl.scrape("https://example.com", formats=["markdown"])

# Use the scrape job ID to interact with the browser
result = firecrawl.interact(
    doc.metadata.get("scrapeId"),
    code="document.querySelector('button.load-more').click();",
    language="node",
    timeout=30,
)

print(result.stdout)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `str` | **Required.** The scrape job ID (UUID) from the scrape response. |
| `code` | `str` | Code to execute in the browser sandbox (1–100,000 chars). Optional if `prompt` is provided. |
| `prompt` | `str` | Natural-language instruction for the browser agent. Optional if `code` is provided. |
| `language` | `"python" \| "node" \| "bash"` | Language of the code. Default: `"node"`. |
| `timeout` | `int` | Execution timeout in seconds. Min: `1`, max: `300`, default: `30`. |

## Notes

- **Naming style:** All parameters use snake_case.
- **Deprecated aliases:** `scrape_execute()` is deprecated — use `interact()`. `stop_interactive_browser()` is deprecated — use `stop_interaction()`. `delete_scrape_browser()` is deprecated — use `stop_interaction()`. `scrape_url()` is a v1 alias for `scrape()`.
- **Format options:** The `formats` list accepts strings for simple formats or dicts with additional config (e.g., `{"type": "json", "schema": {...}, "prompt": "..."}` for JSON extraction).
- **Alexandria:** The `scrape()` method also accepts an `alexandria` parameter for executing catalogued provider tools instead of scraping a URL. Alternatively, use `scrape_alexandria()` directly.
- **Keyword arguments:** All parameters after `url` (for `scrape`) or `query` (for `search`) are keyword-only.
