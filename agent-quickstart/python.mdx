# Firecrawl Python Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl-py`) and the v2 OpenAPI spec. Method names, parameters, and types match the public API.

## Install

```bash
pip install firecrawl-py
```

Requires Python 3.8+. The package is `firecrawl-py` on PyPI; the import is `firecrawl`.

## Authenticate

```python
import os
from firecrawl import Firecrawl

client = Firecrawl(api_key=os.environ.get("FIRECRAWL_API_KEY"))
```

You can also pass `api_url` for self-hosted instances and `api_key=None` for keyless free-tier access.

## When To Use What

- **search**: use when you start with a query and need discovery. Returns ranked results you can then scrape or interact with.
- **scrape**: use when you already have a URL and want page content in one or more formats.
- **interact**: use when the page needs clicks, form fills, or other browser actions after a scrape has created a session.

## Search

### Why use it

Search discovers relevant pages from a query. Use it to find URLs before scraping or interacting. Constrain to a domain with `site:`, for example `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`client.search(query, **options)` → `SearchData`

### Example

```python
results = client.search("site:docs.firecrawl.dev webhook retries", limit=5)

for item in results.web or []:
    print(item.url, item.title)
```

Results are in `results.web`, `results.news`, and `results.images`. Do **not** access `results.data` — it does not exist and raises an error.

### Parameters

- `query`
  - Type: str (positional)
  - The search query string. Use `site:example.com` to limit results to a domain.

- `sources`
  - Type: list of str
  - Which sources to search. Values: `"web"`, `"news"`, `"images"`.

- `categories`
  - Type: list of str
  - Filter results by category. Values: `"developer"`, `"gov"`, `"research"`, `"pdf"`.

- `include_domains`
  - Type: list of str
  - Only include results from these domains. Mutually exclusive with `exclude_domains`.

- `exclude_domains`
  - Type: list of str
  - Exclude results from these domains.

- `limit`
  - Type: int
  - Maximum number of results. Default: `5`.

- `tbs`
  - Type: str
  - Time-based filter. Examples: `"qdr:d"` (past day), `"qdr:w"` (past week), `"qdr:m"` (past month).

- `location`
  - Type: str
  - Location string for geo-targeted results. Example: `"San Francisco,California,United States"`.

- `country`
  - Type: str
  - ISO 3166-1 alpha-2 country code for geo-targeting. Example: `"US"`.

- `ignore_invalid_urls`
  - Type: bool
  - Drop URLs that cannot be scraped by other endpoints.

- `timeout`
  - Type: int
  - Request timeout in milliseconds. Default: `300000`.

- `highlights`
  - Type: bool
  - Generate query-relevant highlights. Default: `true` server-side.

- `scrape_options`
  - Type: ScrapeOptions
  - Scrape each search result with the given options. See Scrape parameters for fields.

- `domain_tools`
  - Type: bool
  - Enable Alexandria domain-tool discovery alongside results.

- `tool_detail`
  - Type: str
  - Level of tool contract detail. Values: `"compact"`, `"summary"`, `"full"`.

## Scrape

### Why use it

Scrape extracts structured content from a URL in one or more formats. Use it when you already have the URL and want markdown, HTML, JSON, screenshots, or other outputs.

### Preferred SDK method

`client.scrape(url, **options)` → `Document`

### Example

```python
doc = client.scrape("https://example.com", formats=["markdown"])
print(doc.markdown)
```

For JSON extraction:

```python
doc = client.scrape(
    "https://example.com/pricing",
    formats=[{"type": "json", "prompt": "Extract plan names and prices."}],
)
print(doc.json)
```

### Parameters

- `url`
  - Type: str (positional)
  - The URL to scrape.

- `formats`
  - Type: list of str or dict
  - Output formats. String values: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"attributes"`, `"branding"`, `"audio"`, `"video"`.
  - Object-only formats: `{"type": "json", "prompt": ..., "schema": ...}`, `{"type": "question", "question": ...}`, `{"type": "highlights", "query": ...}`, `{"type": "screenshot", "full_page": ..., "quality": ..., "viewport": ...}`, `{"type": "changeTracking", "modes": [...], "tag": ...}`, `{"type": "attributes", "selectors": [...]}`.

- `headers`
  - Type: dict
  - Custom HTTP headers sent with the scrape request.

- `include_tags`
  - Type: list of str
  - Only include content from these HTML tags or CSS selectors.

- `exclude_tags`
  - Type: list of str
  - Exclude content from these HTML tags or CSS selectors.

- `only_main_content`
  - Type: bool
  - Strip nav, footer, and other boilerplate.

- `timeout`
  - Type: int
  - Server-side scrape timeout in milliseconds.

- `wait_for`
  - Type: int
  - Wait this many milliseconds for the page to render before scraping.

- `mobile`
  - Type: bool
  - Emulate a mobile viewport.

- `parsers`
  - Type: list
  - File parsers. Values: `"pdf"` or `{"type": "pdf", "mode": "fast" | "auto" | "ocr", "max_pages": int}`.

- `actions`
  - Type: list of dict
  - Pre-scrape browser actions. Types: `wait` (`milliseconds` or `selector`), `click` (`selector`), `write` (`text`), `press` (`key`), `scroll` (`direction`: `"up"` or `"down"`), `screenshot`, `scrape`, `executeJavascript` (`script`), `pdf`.

- `location`
  - Type: dict
  - Geo or language-aware scraping. Fields: `country` (str), `languages` (list of str).

- `skip_tls_verification`
  - Type: bool
  - Skip TLS certificate verification.

- `remove_base64_images`
  - Type: bool
  - Drop base64-encoded images from markdown output.

- `fast_mode`
  - Type: bool
  - Faster scrape with reduced fidelity.

- `block_ads`
  - Type: bool
  - Block ads and cookie popups.

- `proxy`
  - Type: str
  - Proxy mode. Values: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`.

- `max_age`
  - Type: int
  - Use cached data if younger than this many milliseconds. `0` bypasses cache.

- `store_in_cache`
  - Type: bool
  - Store the result in Firecrawl's cache for future reuse.

- `lockdown`
  - Type: bool
  - Only serve previously cached results; return 404 on a cache miss.

- `check_prompt_injection`
  - Type: bool
  - Scan scraped content for prompt injection attempts. Adds 4 credits.

- `profile`
  - Type: dict
  - Persistent browser profile. Fields: `name` (str), `saveChanges` (bool).

## Interact

### Why use it

Interact gives you code or natural-language control of the browser session tied to a prior scrape (via `doc.metadata.scrape_id`). Use it for multi-step flows: clicking through pages, filling forms, or extracting dynamic content. At least one of `code` or `prompt` is required.

### Preferred SDK method

`client.interact(job_id, code=None, *, prompt=None, language="node", timeout=None)`

To end the session: `client.stop_interaction(job_id)` → `BrowserDeleteResponse`

### Example

```python
doc = client.scrape("https://example.com", formats=["markdown"])
job_id = doc.metadata.scrape_id

result = client.interact(job_id, prompt="Click the pricing tab and summarize the plans.")
print(result.output)
```

With code execution:

```python
result = client.interact(
    job_id,
    code="print(await page.title())",
    language="python",
    timeout=60,
)
print(result.stdout)
```

### Parameters

- `job_id`
  - Type: str (positional)
  - The scrape job ID from `doc.metadata.scrape_id`.

- `code`
  - Type: str (optional positional)
  - Code to execute in the browser session. Optional if `prompt` is provided.

- `prompt`
  - Type: str (keyword-only)
  - Natural-language instruction for the browser agent. Optional if `code` is provided.

- `language`
  - Type: str
  - Runtime for code execution. Values: `"python"`, `"node"`, `"bash"`. Default: `"node"`.

- `timeout`
  - Type: int
  - Execution timeout in seconds (1–300).

## Notes

- The package is `firecrawl-py` on PyPI; the import is `from firecrawl import Firecrawl`. `FirecrawlApp` is a deprecated alias for `Firecrawl`.
- All parameters use **snake_case** (e.g. `only_main_content`, `ignore_invalid_urls`).
- Deprecated method aliases: `scrape_execute` → `interact`; `stop_interactive_browser` and `delete_scrape_browser` → `stop_interaction`.
- The top-level `Firecrawl` client exposes v2 methods directly; v1 remains under `client.v1`.
- `prompt` on `interact` is keyword-only: call `client.interact(job_id, prompt="...")`, not `client.interact(job_id, "...")` when using prompt without code.
- `search()` returns `SearchData` with `.web`, `.news`, `.images`. Do **not** access `.data` — it raises an error with guidance.
