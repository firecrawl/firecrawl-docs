# Firecrawl Python Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl-py`) and the v2 OpenAPI spec. Method names and parameters match the public API surface.

## Install

```bash
pip install firecrawl-py
```

## Authenticate

```py
import os
from firecrawl import Firecrawl

client = Firecrawl(api_key=os.environ.get("FIRECRAWL_API_KEY"))
```

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions.

## Search

### Why use it

Use search to discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:`, for example `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`client.search(query, **options)` → `SearchData`

### Example

```py
results = client.search("site:docs.firecrawl.dev webhook retries")
for item in results.web or []:
    print(getattr(item, "url", None), getattr(item, "title", None))
```

### Parameters

- `query`
  - Type: str (required)
  - The search query. Use `site:example.com` to limit results to a domain.

- `sources`
  - Type: list of str or `Source` objects
  - Control which sources are searched. Values: `"web"`, `"news"`, `"images"`, `"alexandria"`.

- `categories`
  - Type: list of str or `Category` objects
  - Filter results by category. Values: `"developer"`, `"gov"`, `"research"`, `"pdf"`, `"github"`.

- `include_domains`
  - Type: list of str
  - Restrict results to these domains. Mutually exclusive with `exclude_domains`.

- `exclude_domains`
  - Type: list of str
  - Exclude results from these domains. Mutually exclusive with `include_domains`.

- `limit`
  - Type: int
  - Maximum number of results. Default: `5`.

- `tbs`
  - Type: str
  - Time-based search filter (e.g. `qdr:d` for past day, `qdr:w` for past week).

- `location`
  - Type: str
  - Location string for localized results.

- `country`
  - Type: str
  - ISO 3166-1 alpha-2 country code for geo-targeting (e.g. `"US"`).

- `ignore_invalid_urls`
  - Type: bool
  - Drop URLs that cannot be scraped by other endpoints.

- `highlights`
  - Type: bool
  - Generate query-relevant highlights. Default: `True`.

- `timeout`
  - Type: int
  - Request timeout in milliseconds. Default: `300000`.

- `scrape_options`
  - Type: `ScrapeOptions`
  - Scrape each search result with these options (see Scrape parameters).

- `domain_tools`
  - Type: bool
  - Enable Alexandria domain-tool discovery on results.

- `tool_detail`
  - Type: `"compact"` | `"summary"` | `"full"`
  - Detail level for domain-tool contracts. Default: `"compact"` for search.

- `enterprise`
  - Type: list of str
  - Enterprise search controls. Values: `"zdr"` (zero data retention), `"anon"` (anonymized).

- `threat_protection`
  - Type: `ThreatProtectionOptions`
  - Per-request threat protection override.

- `integration`
  - Type: str
  - Integration identifier for server-side tracking.

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK method

`client.scrape(url, **options)` → `Document`

### Example

```py
doc = client.scrape("https://docs.firecrawl.dev", formats=["markdown"])
print(doc.markdown)
```

### Parameters

- `url`
  - Type: str (required)
  - The URL to scrape.

- `formats`
  - Type: list of format strings or format dicts
  - Requested output formats.
  - String values: `"markdown"`, `"html"`, `"rawHtml"` (or `"raw_html"`), `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"` (or `"change_tracking"`), `"attributes"`, `"branding"`, `"audio"`, `"video"`.
  - Dict-only formats: `{"type": "json", "prompt": "..."}`, `{"type": "question", "question": "..."}`, `{"type": "highlights", "query": "..."}`.
  - Dict format fields: `type`, `prompt`, `schema`, `question`, `query`, `modes`, `tag`, `full_page`, `quality`, `viewport`, `selectors`.

- `headers`
  - Type: dict of str to str
  - Custom HTTP request headers.

- `include_tags`
  - Type: list of str
  - Include only content from these HTML tags/selectors.

- `exclude_tags`
  - Type: list of str
  - Exclude content from these HTML tags/selectors.

- `only_main_content`
  - Type: bool
  - Strip nav, footer, and other boilerplate.

- `timeout`
  - Type: int
  - Timeout in milliseconds.

- `wait_for`
  - Type: int
  - Wait for page rendering in milliseconds.

- `mobile`
  - Type: bool
  - Use a mobile viewport.

- `parsers`
  - Type: list of str or parser dicts
  - File parsing controls. Values: `"pdf"`, `{"type": "pdf", "mode": "fast" | "auto" | "ocr", "max_pages": int}`.

- `actions`
  - Type: list of action dicts
  - Browser actions before scraping. Types: `wait`, `screenshot`, `click`, `write`, `press`, `scroll`, `scrape`, `executeJavascript`, `pdf`.

- `location`
  - Type: dict with `country` and `languages`
  - Geo or language-aware scraping.

- `skip_tls_verification`
  - Type: bool
  - Skip TLS certificate verification.

- `remove_base64_images`
  - Type: bool
  - Drop base64 images from markdown output.

- `fast_mode`
  - Type: bool
  - Faster scrapes with reduced fidelity.

- `block_ads`
  - Type: bool
  - Block ads and cookie popups.

- `proxy`
  - Type: str
  - Proxy control. Values: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`.

- `max_age`
  - Type: int
  - Use cached data up to this age in milliseconds.

- `store_in_cache`
  - Type: bool
  - Cache the scrape result.

- `lockdown`
  - Type: bool
  - Serve only previously cached results.

- `check_prompt_injection`
  - Type: bool
  - Scan content for prompt injection attempts. Adds 4 credits.

- `redact_pii`
  - Type: bool
  - Redact personally identifiable information from output.

- `threat_protection`
  - Type: `ThreatProtectionOptions`
  - Per-request threat protection override.

- `audit_metadata`
  - Type: `AuditMetadata`
  - User attribution for SIEM logging (e.g. `AuditMetadata(username="...")`).

- `profile`
  - Type: dict with `name` and optional `save_changes`
  - Persistent browser profile shared across scrapes and interactions.

- `domain_tools`
  - Type: bool
  - Enable Alexandria domain-tool discovery.

- `tool_detail`
  - Type: `"compact"` | `"summary"` | `"full"`
  - Detail level for domain-tool contracts. Default: `"summary"` when `domain_tools` is enabled.

- `integration`
  - Type: str
  - Integration identifier for server-side tracking.

## Interact

### Why use it

Use `interact` for code or natural-language control of the browser session tied to a scrape job (via `metadata.scrape_id`). At least one of `code` or `prompt` must be provided.

### Preferred SDK method

`client.interact(job_id, code=None, *, prompt=None, language="node", timeout=None)` → `BrowserExecuteResponse`

### Example

```py
doc = client.scrape("https://example.com", formats=["markdown"])
job_id = doc.metadata.scrape_id if doc.metadata else None
if not job_id:
    raise RuntimeError("Missing scrape_id from scrape response")

result = client.interact(job_id, prompt="Click the pricing tab and summarize the plans.")
```

### Parameters

- `job_id`
  - Type: str (required)
  - Scrape job ID from `document.metadata.scrape_id`.

- `code`
  - Type: str
  - Code to run in the browser session. Optional if `prompt` is set.

- `prompt`
  - Type: str (keyword-only)
  - Natural-language instruction for the browser agent. Optional if `code` is set.

- `language`
  - Type: str
  - Runtime language. Values: `"python"`, `"node"`, `"bash"`. Default: `"node"`.

- `timeout`
  - Type: int
  - Execution timeout in seconds (1–300).

To end the browser session: `client.stop_interaction(job_id)`.

## Notes

- Deprecated aliases: `scrape_execute` → `interact`; `stop_interactive_browser` and `delete_scrape_browser` → `stop_interaction`.
- The top-level `Firecrawl` client exposes v2 methods directly; v1 remains under `client.v1`.
- `FirecrawlApp` is an alias for `Firecrawl`. `AsyncFirecrawl` / `AsyncFirecrawlApp` provide async variants with the same interface.
- Search returns `SearchData` with `.web`, `.news`, `.images` lists. Do not access `.data` — it does not exist.
