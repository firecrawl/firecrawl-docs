# Firecrawl Python Agent Quickstart

Canonical quickstart for agents using the Firecrawl Python SDK. Generated from SDK source and OpenAPI spec.

## Install

```bash
pip install firecrawl-py
```

## Authenticate

```python
from firecrawl import Firecrawl

firecrawl = Firecrawl(api_key="fc-YOUR_API_KEY")
# or set FIRECRAWL_API_KEY env var and omit the key:
# firecrawl = Firecrawl()
```

Constructor parameters:

```python
firecrawl = Firecrawl(
    api_key="fc-YOUR_API_KEY",                    # or set FIRECRAWL_API_KEY env var
    api_url="https://api.firecrawl.dev",          # optional
    timeout=60.0,                                  # optional default timeout in seconds
    max_retries=3,                                 # optional
    backoff_factor=0.5,                            # optional
)
```

No API key is required for `scrape`, `search`, and `interact` on the keyless free tier (rate-limited per IP).

An async client is also available:

```python
from firecrawl import AsyncFirecrawl

firecrawl = AsyncFirecrawl(api_key="fc-YOUR_API_KEY")
```

## When To Use What

- **`search`**: Start with a query and get back relevant web pages. Use when you need discovery: finding URLs, getting search results with optional full-page scraping.
- **`scrape`**: Start with a URL and get page content back. Use when you already know the page you want and need its markdown, HTML, structured data, or screenshots.
- **`interact`**: Execute code in a live browser session bound to a prior scrape. Use when the page needs clicks, form fills, or post-scrape browser automation.

## Search

### Why use it

Search the web through Firecrawl and optionally scrape each result page in a single call. Returns grouped results by source type (web, news, images).

### Preferred SDK method

```python
firecrawl.search(query, **kwargs)
```

### Example

```python
results = firecrawl.search(
    "firecrawl web scraping API",
    limit=5,
    scrape_options={"formats": ["markdown"]},
)

for page in results.web or []:
    print(page.url, page.title)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `str` (required) | The search query string. |
| `sources` | `list[str]` | Source types: `"web"`, `"news"`, `"images"`, `"alexandria"`. Default: `["web"]`. |
| `categories` | `list[str]` | Filter by category: `"github"`, `"research"`, `"pdf"`, `"developer"`. |
| `include_domains` | `list[str]` | Only include results from these domains. |
| `exclude_domains` | `list[str]` | Exclude results from these domains. |
| `limit` | `int` | Maximum number of results. Default: 5, max: 100. |
| `tbs` | `str` | Time-based search filter (e.g. `"qdr:d"` for past day). |
| `location` | `str` | Location string for geographic targeting. |
| `country` | `str` | ISO country code (e.g. `"US"`). |
| `ignore_invalid_urls` | `bool` | Skip invalid URLs in results. |
| `timeout` | `int` | Timeout in milliseconds. Default: 300000. |
| `highlights` | `bool` | Generate query-relevant highlights. Default: `True`. |
| `scrape_options` | `dict \| ScrapeOptions` | Scrape options applied to each result page. |
| `enterprise` | `list[str]` | Enterprise options: `["zdr"]` for zero data retention, `["anon"]` for anonymized search. |
| `integration` | `str` | Integration identifier for attribution. |

## Scrape

### Why use it

Scrape a single URL and get back structured page data: markdown, HTML, screenshots, extracted JSON, and more. The SDK handles retries and auto-resumes large documents.

### Preferred SDK method

```python
firecrawl.scrape(url, **kwargs)
```

### Example

```python
doc = firecrawl.scrape(
    "https://example.com",
    formats=["markdown", "screenshot"],
    only_main_content=True,
)

print(doc.markdown)
print(doc.screenshot)
```

With structured JSON extraction:

```python
doc = firecrawl.scrape(
    "https://example.com/pricing",
    formats=[{
        "type": "json",
        "schema": {"type": "object", "properties": {"plans": {"type": "array"}}},
        "prompt": "Extract the pricing plans.",
    }],
)

print(doc.json)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `str` (required) | The URL to scrape. |
| `formats` | `list` | Output formats. Strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`. Also accepts format config dicts (`JsonFormat`, `ScreenshotFormat`, etc.). |
| `headers` | `dict[str, str]` | Custom HTTP headers. |
| `include_tags` | `list[str]` | CSS selectors — only include content matching these. |
| `exclude_tags` | `list[str]` | CSS selectors — exclude content matching these. |
| `only_main_content` | `bool` | Strip headers, navs, footers. |
| `timeout` | `int` | Request timeout in milliseconds. |
| `wait_for` | `int` | Wait this many ms after page load before scraping. |
| `mobile` | `bool` | Emulate a mobile device viewport. |
| `parsers` | `list` | File parsers to use (e.g. `"pdf"`, or `PDFParser`/`ImageParser` objects). |
| `actions` | `list` | Browser actions before scraping: `WaitAction`, `ClickAction`, `WriteAction`, `PressAction`, `ScrollAction`, `ScrapeAction`, `ExecuteJavascriptAction`, `ScreenshotAction`, `PDFAction`. |
| `location` | `Location` | Proxy routing: `{"country": "US", "languages": ["en"]}`. |
| `skip_tls_verification` | `bool` | Skip TLS certificate verification. |
| `remove_base64_images` | `bool` | Strip base64-encoded images from markdown. |
| `block_ads` | `bool` | Block ads and cookie popups. |
| `proxy` | `str` | Proxy mode: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. |
| `max_age` | `int` | Use cached result if younger than this many ms. |
| `store_in_cache` | `bool` | Cache the scrape result. |
| `lockdown` | `bool` | Only serve cached results, never make an outbound request. |
| `redact_pii` | `bool` | Redact personally identifiable information. |
| `audit_metadata` | `AuditMetadata` | User attribution for SIEM logging: `{"username": "agent-name"}`. |
| `profile` | `dict` | Persistent browser profile: `{"name": "my-profile", "saveChanges": True}`. |
| `integration` | `str` | Integration identifier. |

## Interact

### Why use it

Execute code in a live browser session that was opened by a prior `scrape` call. Use this when you need to click buttons, fill forms, navigate, or run arbitrary code in the browser context.

### Preferred SDK method

```python
firecrawl.interact(job_id, code=None, *, prompt=None, language="node", timeout=None)
```

### Example

```python
# First, scrape to get a job ID
doc = firecrawl.scrape("https://example.com", formats=["markdown"])
job_id = doc.metadata.get("jobId") if doc.metadata else None

# Then interact with the live browser session
result = firecrawl.interact(
    job_id,
    code='document.querySelector("button.load-more").click();',
    language="node",
    timeout=30,
)

print(result.stdout)
print(result.result)

# Stop the session when done
firecrawl.stop_interaction(job_id)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `str` (required) | The scrape job ID from a prior scrape call. |
| `code` | `str` | Code to execute in the browser sandbox. Required if `prompt` is not provided. |
| `prompt` | `str` | Natural-language instruction for the browser agent. Required if `code` is not provided. |
| `language` | `"python" \| "node" \| "bash"` | Execution language. Default: `"node"`. |
| `timeout` | `int` | Execution timeout in seconds (1–300). |

Stop the browser session when done:

```python
firecrawl.stop_interaction(job_id)
```

## Notes

- **snake_case parameters**: The Python SDK uses snake_case for all parameter names (`only_main_content`, `include_tags`, etc.). These are converted to camelCase internally.
- **Deprecated aliases**: `scrape_url` → `scrape`, `scrape_execute` → `interact`, `delete_scrape_browser` / `stop_interactive_browser` → `stop_interaction`. Use the modern names.
- **`FirecrawlApp` alias**: `FirecrawlApp` is an alias for `Firecrawl` for backward compatibility.
- **Async client**: Use `AsyncFirecrawl` (aliased as `AsyncFirecrawlApp`) for async/await support. All methods have the same signatures.
- **Return types**: `scrape()` returns a `Document` with attributes like `.markdown`, `.html`, `.json`, `.metadata`. `search()` returns a `SearchData` with `.web`, `.news`, `.images` lists.
