# Firecrawl Python Agent Quickstart

This file is the canonical quickstart for external agents integrating with Firecrawl using the Python SDK. It is generated from SDK source and the OpenAPI spec.

## Install

```bash
pip install firecrawl-py
```

Requires Python >= 3.8.

## Authenticate

```python
from firecrawl import Firecrawl

firecrawl = Firecrawl(api_key="fc-YOUR_API_KEY")
```

Constructor parameters:

```python
firecrawl = Firecrawl(
    api_key="fc-YOUR_API_KEY",             # or set FIRECRAWL_API_KEY env var
    api_url="https://api.firecrawl.dev",   # or set FIRECRAWL_API_URL env var
    timeout=None,                           # default request timeout in seconds
    max_retries=3,
    backoff_factor=0.5,
)
```

Omitting `api_key` falls back to the `FIRECRAWL_API_KEY` environment variable, then to a keyless free tier (rate-limited per IP).

An async client is also available: `from firecrawl import AsyncFirecrawl`.

## When To Use What

- **`search`**: Use when you start with a query and need to discover relevant pages. Returns URLs, snippets, and optionally scraped content for each result.
- **`scrape`**: Use when you already have a URL and want its content. Returns markdown, HTML, screenshots, extracted JSON, and more.
- **`interact`**: Use when a page requires post-scrape browser actions — clicking, filling forms, or running code in the browser session that `scrape` opened.

## Search

### Why use it

Search lets you discover relevant pages from a query. It returns web, news, and image results, and can optionally scrape each result page inline.

### Preferred SDK method

```python
firecrawl.search(query, **options)
```

### Example

```python
results = firecrawl.search(
    "firecrawl web scraping API",
    limit=5,
    scrape_options={"formats": ["markdown"]},
)

for item in results.web or []:
    print(item.title, item.url)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `str` | **(required, first arg)** The search query. |
| `sources` | `list[str \| Source]` | Sources to search: `"web"`, `"news"`, `"images"`, `"alexandria"`. Default: `["web"]`. |
| `categories` | `list[str \| Category]` | Narrow web search: `"github"`, `"research"`, `"pdf"`, `"developer"`. |
| `include_domains` | `list[str]` | Restrict results to these domains. Cannot combine with `exclude_domains`. |
| `exclude_domains` | `list[str]` | Exclude results from these domains. Cannot combine with `include_domains`. |
| `limit` | `int` | Max number of results. Default: 10 (API). |
| `tbs` | `str` | Time-based search filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week). |
| `location` | `str` | Location string for geo-targeting. |
| `country` | `str` | ISO country code (e.g. `"US"`). |
| `ignore_invalid_urls` | `bool` | Ignore invalid URLs in results. |
| `timeout` | `int` | Timeout in milliseconds. |
| `highlights` | `bool` | Generate query-relevant highlights. Default: `True`. |
| `scrape_options` | `ScrapeOptions \| dict` | Options for scraping each result page. See Scrape parameters below. |
| `enterprise` | `list[str]` | Enterprise options: `["zdr"]` for Zero Data Retention, `["anon"]` for anonymized. |
| `threat_protection` | `ThreatProtectionOptions` | Per-request threat protection override (enterprise). |
| `domain_tools` | `bool` | Include Alexandria tool contracts matched to result domains. |
| `tool_detail` | `"compact" \| "summary" \| "full"` | Tool detail level. Default: `"compact"`. |
| `integration` | `str` | Integration identifier. |

**Returns:** `SearchData` with optional `.web`, `.news`, `.images`, and `.tools` lists. Accessing `.data` raises `AttributeError` directing you to the grouped properties.

## Scrape

### Why use it

Scrape extracts content from a single URL. You get markdown by default, and can request HTML, screenshots, structured JSON extraction, and more.

### Preferred SDK method

```python
firecrawl.scrape(url, **options)
```

### Example

```python
doc = firecrawl.scrape(
    "https://example.com",
    formats=["markdown", "links"],
    only_main_content=True,
)

print(doc.markdown)
print(doc.links)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `str` | **(required, first arg)** The URL to scrape. |
| `formats` | `list[FormatOption]` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"json"`, `"changeTracking"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`, or typed format objects. Default: `["markdown"]`. |
| `only_main_content` | `bool` | Only return main content, excluding navbars/footers. Default: `True` (API). |
| `include_tags` | `list[str]` | HTML tags to exclusively include. |
| `exclude_tags` | `list[str]` | HTML tags to exclude. |
| `headers` | `dict[str, str]` | Custom HTTP headers to send with the request. |
| `timeout` | `int` | Timeout in milliseconds. Default: `60000`. Min: 1000, Max: 300000. |
| `wait_for` | `int` | Wait time in ms before scraping (for JS rendering). |
| `mobile` | `bool` | Use mobile user agent. |
| `parsers` | `list[str \| PDFParser \| ImageParser]` | Document parsers (e.g. `"pdf"`). PDF parser supports `mode`, `max_pages`, `pages`, `blocks`, `page_markers`. |
| `actions` | `list[Action]` | Browser actions: `WaitAction`, `ClickAction`, `WriteAction`, `PressAction`, `ScrollAction`, `ScreenshotAction`, `ScrapeAction`, `ExecuteJavascriptAction`, `PDFAction`. |
| `location` | `Location` | Location config with `country` and `languages`. |
| `skip_tls_verification` | `bool` | Skip TLS verification. Default: `True` (API). |
| `remove_base64_images` | `bool` | Remove base64 images from output. Default: `True` (API). |
| `block_ads` | `bool` | Block ads and cookie popups. Default: `True` (API). |
| `proxy` | `str` | Proxy mode: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. Default: `"auto"` (API). |
| `max_age` | `int` | Max cache age in ms. Use cached result if younger. Default: `172800000` (2 days). |
| `store_in_cache` | `bool` | Store result in cache. Default: `True` (API). |
| `lockdown` | `bool` | Serve only cached results, never make outbound requests. |
| `fast_mode` | `bool` | Enable fast mode. |
| `redact_pii` | `bool \| RedactPIIOptions` | Redact PII from markdown. |
| `profile` | `dict` | Persistent browser profile (e.g. `{"name": "my-profile", "saveChanges": True}`). |
| `audit_metadata` | `AuditMetadata` | User attribution for SIEM logging. Has `username: str`. |
| `threat_protection` | `ThreatProtectionOptions` | Per-request threat protection override (enterprise). |
| `domain_tools` | `bool` | Include Alexandria tool contracts matched to the scraped domain. |
| `tool_detail` | `"compact" \| "summary" \| "full"` | Tool detail level. Default: `"summary"`. |
| `integration` | `str` | Integration identifier. |
| `auto_resume` | `bool` | SDK-only. Auto-resume for large documents. Default: `True` (implicitly). Never sent to API. |

**Returns:** `Document` with fields like `markdown`, `html`, `raw_html`, `links`, `screenshot`, `metadata`, `json`, `actions`, etc.

## Interact

### Why use it

After scraping a page, the browser session stays alive. Use `interact` to execute code or natural-language prompts against that session — click buttons, fill forms, navigate, or extract additional data.

### Preferred SDK method

```python
firecrawl.interact(job_id, code=None, *, prompt=None, language="node", timeout=None, origin=None)
```

To stop the session:

```python
firecrawl.stop_interaction(job_id)
```

### Example

```python
doc = firecrawl.scrape("https://example.com", formats=["markdown"])

job_id = doc.metadata.get("scrapeId")

result = firecrawl.interact(
    job_id,
    code='document.querySelector("button.load-more").click();',
    language="node",
    timeout=30,
)

print(result.stdout)

firecrawl.stop_interaction(job_id)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `str` | **(required, first arg)** The scrape job ID from `metadata["scrapeId"]` of a prior `scrape()` response. |
| `code` | `str` | Code to execute in the browser session. Provide either `code` or `prompt`. |
| `prompt` | `str` | Natural-language instruction for the browser agent. Provide either `code` or `prompt`. |
| `language` | `"python" \| "node" \| "bash"` | Language for code execution. Default: `"node"`. |
| `timeout` | `int` | Execution timeout in seconds. Min: 1, Max: 300. Default: `30` (API). |
| `origin` | `str` | Origin identifier. |

**Returns:** `BrowserExecuteResponse` with `success`, `stdout`, `result`, `stderr`, `exit_code`, `killed`, `error`, `output` (for prompt mode), `live_view_url`, `interactive_live_view_url`, `cdp_url`.

## Notes

- All parameter names use **snake_case**. The SDK converts them to camelCase for the API wire format.
- Both snake_case and camelCase are accepted as input for `ScrapeOptions` fields.
- `FirecrawlApp` is an alias for `Firecrawl`. `AsyncFirecrawlApp` is an alias for `AsyncFirecrawl`.
- **Deprecated aliases** (use the preferred names above):
  - `scrape_execute()` → `interact()`
  - `stop_interactive_browser()` / `delete_scrape_browser()` → `stop_interaction()`
  - `scrape_url()` → `scrape()`
