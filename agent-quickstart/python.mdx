# Firecrawl Python Agent Quickstart

This file is the canonical quickstart for external agents integrating Firecrawl with Python. It is generated from SDK source plus OpenAPI and covers every confirmed parameter.

## Install

```bash
pip install firecrawl-py
```

## Authenticate

```python
from firecrawl import Firecrawl

app = Firecrawl(api_key="fc-YOUR-API-KEY")
```

Or with options:

```python
app = Firecrawl(
    api_key="fc-YOUR-API-KEY",
    api_url="https://api.firecrawl.dev",  # optional, override for self-hosted
    timeout=None,                          # optional, default request timeout in seconds
    max_retries=3,                         # optional
    backoff_factor=0.5,                    # optional
)
```

Set `FIRECRAWL_API_KEY` as an environment variable to skip passing it directly:

```python
app = Firecrawl()
```

An async client is also available:

```python
from firecrawl import AsyncFirecrawl

app = AsyncFirecrawl(api_key="fc-YOUR-API-KEY")
```

## When To Use What

- **`search`**: Use when you start with a query and need to discover relevant pages across the web.
- **`scrape`**: Use when you already have a URL and want the page content in a structured format.
- **`interact`**: Use when the page requires clicks, form fills, or other post-scrape browser actions.

## Search

### Why use it

Search the web for a query and get structured results with optional full-page content. Ideal for discovery workflows where you don't yet know which URLs matter.

### Preferred SDK method

```python
app.search(query, **kwargs)
```

### Example

```python
results = app.search("firecrawl web scraping", limit=5)

for result in results.web:
    print(result.title, result.url)
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `query` | `str` | Search query (first positional argument, required). | Always. |
| `limit` | `int` | Max number of results. Default: `5`. Max: `100`. | Control result count. |
| `sources` | `list[str]` | Which result types: `"web"`, `"news"`, `"images"`, `"alexandria"`. | Filter to specific source types. |
| `categories` | `list[str]` | Narrow web search: `"github"`, `"research"`, `"pdf"`, `"developer"`. `"research"` filters to ~14 academic domains. | Target specific content types. |
| `include_domains` | `list[str]` | Restrict results to these domains. Mutually exclusive with `exclude_domains`. | Scope search to known sources. |
| `exclude_domains` | `list[str]` | Exclude results from these domains. | Filter out unwanted sources. |
| `tbs` | `str` | Time-based search filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week). | Restrict to recent content. |
| `location` | `str` | Location string for geo-targeting. | Get location-specific results. |
| `country` | `str` | ISO 3166-1 alpha-2 country code. | Geo-target results by country. |
| `ignore_invalid_urls` | `bool` | Skip invalid URLs instead of failing. | Increase robustness. |
| `timeout` | `int` | Timeout in milliseconds. Default: `300000`. | Override default timeout. |
| `highlights` | `bool` | Generate query-relevant highlights. Default: `True` server-side. | Disable if you only need URLs/titles. |
| `scrape_options` | `ScrapeOptions` | Options applied when scraping each result page (same shape as scrape parameters). | Get full page content alongside search results. |

### Return type

`SearchData` with properties: `.web`, `.news`, `.images`, `.tools`, `.warning`.

## Scrape

### Why use it

Fetch a single URL and get its content as markdown, HTML, screenshots, or structured data. The core building block for content extraction.

### Preferred SDK method

```python
app.scrape(url, **kwargs)
```

### Example

```python
doc = app.scrape("https://example.com", formats=["markdown"])
print(doc.markdown)
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `url` | `str` | URL to scrape (first positional argument, required). | Always. |
| `formats` | `list[str]` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`. Also accepts format config objects. | Control what data you get back. |
| `headers` | `dict[str, str]` | Custom HTTP headers sent with the scrape request. | Set cookies, auth tokens, or user-agent. |
| `include_tags` | `list[str]` | Only include content from these HTML tags. | Extract specific page sections. |
| `exclude_tags` | `list[str]` | Exclude content from these HTML tags. | Remove unwanted elements. |
| `only_main_content` | `bool` | Strip navigation, headers, and footers. | Get clean article content. |
| `timeout` | `int` | Timeout in milliseconds. | Override default timeout. |
| `wait_for` | `int` | Wait N milliseconds before scraping (for JS rendering). | Handle dynamic content. |
| `mobile` | `bool` | Emulate a mobile device viewport. | Get mobile version of pages. |
| `parsers` | `list` | File parser config. Accepts `"pdf"` string or `PDFParser`/`ImageParser` objects. | Control PDF/image parsing behavior. |
| `actions` | `list` | Browser actions: `WaitAction`, `ScreenshotAction`, `ClickAction`, `WriteAction`, `PressAction`, `ScrollAction`, `ScrapeAction`, `ExecuteJavascriptAction`, `PDFAction`. | Automate interactions before scraping. |
| `location` | `Location` | Geolocation config with `country` and `languages` fields. | Get geo-specific content. |
| `skip_tls_verification` | `bool` | Skip TLS certificate verification. | Scrape sites with self-signed certs. |
| `remove_base64_images` | `bool` | Strip base64-encoded images from output. | Reduce response size. |
| `block_ads` | `bool` | Block advertisements and cookie popups. | Get cleaner content. |
| `proxy` | `str` | Proxy type: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. | Bypass blocks or access geo-restricted content. |
| `max_age` | `int` | Max cache age in ms. `0` bypasses cache. | Control content freshness. |
| `store_in_cache` | `bool` | Store the result in Firecrawl's cache. | Enable caching for repeated scrapes. |
| `lockdown` | `bool` | Only serve cached results; no outbound requests. | Use only cached data. |
| `redact_pii` | `bool` | Redact personally identifiable information. | Handle sensitive content. |
| `profile` | `dict` | Persistent browser profile, e.g. `{"name": "my-profile", "saveChanges": True}`. | Maintain login sessions across scrapes. |
| `audit_metadata` | `AuditMetadata` | User attribution for SIEM logging. `username` field required. | Enterprise audit trails. |
| `auto_resume` | `bool` | SDK-only. Auto-retry on server-side processing timeouts. Set `False` to surface timeout errors immediately. | Control retry behavior for large pages. |

### Return type

`Document` with fields: `markdown`, `html`, `raw_html`, `json`, `summary`, `metadata`, `links`, `images`, `screenshot`, `audio`, `video`, `actions`, `warning`, and more.

## Interact

### Why use it

Execute code or natural-language prompts in a live browser session bound to a prior scrape job. Use it for clicking buttons, filling forms, navigating SPAs, or extracting dynamic content that requires interaction.

### Preferred SDK method

```python
app.interact(job_id, code=None, *, prompt=None, language="node", timeout=None)
```

### Example

```python
doc = app.scrape("https://www.amazon.com", formats=["markdown"])
job_id = doc.metadata.scrape_id

response = app.interact(job_id, prompt="Search for iPhone 16 Pro Max")
print(response.output)

app.stop_interaction(job_id)
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `job_id` | `str` | Scrape job ID from a prior scrape (from `metadata.scrape_id`). Required, first positional argument. | Always. |
| `code` | `str` | Code to execute in the browser sandbox. At least one of `code` or `prompt` is required. | Run specific browser automation code. |
| `prompt` | `str` | Natural-language instruction for the browser agent. At least one of `code` or `prompt` is required. | Describe what you want in plain English. |
| `language` | `str` | Language for `code` execution: `"python"`, `"node"`, `"bash"`. Default: `"node"`. | Match your code's language. |
| `timeout` | `int` | Execution timeout in seconds (1–300). | Increase for long-running interactions. |

### Stop interaction

```python
app.stop_interaction(job_id)
```

Stops the browser session and releases resources. Maps to `DELETE /scrape/{jobId}/interact`.

### Return type

`BrowserExecuteResponse` with fields: `success`, `output`, `stdout`, `result`, `stderr`, `exit_code`, `killed`, `error`.

## Notes

- **Naming style**: All parameters use snake_case.
- **Deprecated aliases**: `scrape_url()` → use `scrape()`. `scrape_execute()` → use `interact()`. `delete_scrape_browser()` / `stop_interactive_browser()` → use `stop_interaction()`. `FirecrawlApp` → use `Firecrawl`. `AsyncFirecrawlApp` → use `AsyncFirecrawl`.
- **Async support**: Use `AsyncFirecrawl` for async/await workflows. Same method signatures.
- **Keyless mode**: Omitting the API key enables a free tier with IP-based rate limiting.
- **Search `.data` removed**: Access results via `.web`, `.news`, `.images`, or `.tools` — not `.data`.
- **Metadata field names**: Python uses snake_case for response fields (e.g. `scrape_id`, `raw_html`, `exit_code`).
