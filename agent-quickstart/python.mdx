# Firecrawl Python Agent Quickstart

This file is the canonical quickstart for external agents building with Firecrawl in Python. It is generated from SDK source and the OpenAPI spec.

## Install

```bash
pip install firecrawl
```

## Authenticate

```python
from firecrawl import Firecrawl

app = Firecrawl(api_key="fc-YOUR-API-KEY")
```

Or set the `FIRECRAWL_API_KEY` environment variable and omit `api_key`:

```python
app = Firecrawl()
```

### Constructor options

| Option | Type | Default | Description |
|---|---|---|---|
| `api_key` | `str` | `FIRECRAWL_API_KEY` env var | API key. Omit for keyless free tier (rate-limited per IP). |
| `api_url` | `str` | `"https://api.firecrawl.dev"` | API base URL. |
| `timeout` | `float` | `None` | Per-request timeout in seconds. |
| `max_retries` | `int` | `3` | Max auto-retries for transient failures. |
| `backoff_factor` | `float` | `0.5` | Exponential backoff factor. |

## When To Use What

- **`search`** — you start with a query and need to discover pages. Returns ranked web results with optional full-page scraping.
- **`scrape`** — you already have a URL and want its content as markdown, HTML, JSON, or other formats.
- **`interact`** — the page needs post-scrape browser actions: clicking buttons, filling forms, navigating, or extracting dynamic content.

## Search

### Why use it

Search the web with a query and get structured results. Optionally scrape each result page for full content in one call.

### Preferred SDK method

```
app.search(query, **kwargs)
```

### Example

```python
results = app.search("firecrawl web scraping", limit=5)

for result in results.web:
    print(result.title, result.url)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `str` | **Required.** The search query string. |
| `limit` | `int` | Max results to return. Default: `5` on the model, server default `10`. |
| `sources` | `list[str \| Source]` | Which result sources: `"web"`, `"news"`, `"images"`, `"alexandria"`. Default: `["web"]`. |
| `categories` | `list[str \| Category]` | Narrow results: `"github"`, `"research"`, `"pdf"`, `"developer"`. |
| `include_domains` | `list[str]` | Restrict results to these domains. Mutually exclusive with `exclude_domains`. |
| `exclude_domains` | `list[str]` | Exclude results from these domains. Mutually exclusive with `include_domains`. |
| `tbs` | `str` | Time-based search filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week). |
| `location` | `str` | Geo-target string (e.g. `"San Francisco,California,United States"`). |
| `country` | `str` | ISO 3166-1 alpha-2 country code (e.g. `"US"`). |
| `timeout` | `int` | Timeout in milliseconds. Default: `300000`. |
| `highlights` | `bool` | Generate query-relevant highlights. Default: `True`. |
| `ignore_invalid_urls` | `bool` | Exclude URLs invalid for other Firecrawl endpoints. |
| `scrape_options` | `ScrapeOptions` | Full scrape options applied to each result page. |
| `domain_tools` | `bool` | Include Alexandria domain-matched contracts. |
| `enterprise` | `list[str]` | Enterprise options: `["zdr"]` for Zero Data Retention, `["anon"]` for anonymized search. |
| `threat_protection` | `ThreatProtectionOptions` | Enterprise threat protection override. |
| `integration` | `str` | Integration identifier. |

### Response

Returns `SearchData` with fields:

- `web` — list of web results (or `Document` if `scrape_options` was set)
- `news` — list of news results
- `images` — list of image results
- `tools` — list of discovered Alexandria tools

## Scrape

### Why use it

Fetch a single URL and get its content as markdown, HTML, JSON extract, screenshot, or other formats.

### Preferred SDK method

```
app.scrape(url, **kwargs)
```

### Example

```python
result = app.scrape("https://example.com", formats=["markdown"])

print(result.markdown)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `str` | **Required.** The URL to scrape. |
| `formats` | `list[str \| FormatConfig]` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`. Can also be config objects (e.g. `JsonFormat`, `ScreenshotFormat`). |
| `headers` | `dict[str, str]` | Custom HTTP request headers. |
| `include_tags` | `list[str]` | HTML tags to include exclusively. |
| `exclude_tags` | `list[str]` | HTML tags to exclude. |
| `only_main_content` | `bool` | Strip boilerplate (navbars, footers). |
| `timeout` | `int` | Timeout in milliseconds. |
| `wait_for` | `int` | Wait time in ms before scraping (for JS rendering). |
| `mobile` | `bool` | Emulate a mobile device. |
| `parsers` | `list[str \| PDFParser \| ImageParser]` | Parser configs (e.g. PDF parser with `max_pages`). |
| `actions` | `list[Action]` | Browser actions: `WaitAction`, `ClickAction`, `WriteAction`, `PressAction`, `ScrollAction`, `ScrapeAction`, `ExecuteJavascriptAction`, `ScreenshotAction`, `PDFAction`. |
| `location` | `Location` | Proxy routing location with `country` and `languages`. |
| `skip_tls_verification` | `bool` | Skip TLS certificate verification. |
| `remove_base64_images` | `bool` | Remove base64 images from output. |
| `fast_mode` | `bool` | Faster scraping, may reduce accuracy. |
| `block_ads` | `bool` | Block advertisements. |
| `proxy` | `str` | Proxy mode: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`. |
| `max_age` | `int` | Use cached result if younger than this (ms). |
| `store_in_cache` | `bool` | Cache the scrape result. |
| `lockdown` | `bool` | Serve only cached results; never make outbound requests. |
| `threat_protection` | `ThreatProtectionOptions` | Enterprise threat protection override. |
| `profile` | `dict` | Persistent browser profile, e.g. `{"name": "my-profile", "saveChanges": True}`. |
| `audit_metadata` | `AuditMetadata` | User attribution for SIEM logging (`username` field). |
| `domain_tools` | `bool` | Include Alexandria domain-tool contracts in `tools` field. |
| `integration` | `str` | Integration identifier. |
| `auto_resume` | `bool` | SDK-only. Auto-retry on `processing_continues` for large documents. |

## Interact

### Why use it

After scraping a page, interact with the live browser session — click buttons, fill forms, navigate, or extract dynamic content. Use a natural-language prompt or execute Playwright code directly.

### Preferred SDK method

```
app.interact(job_id, code=None, *, prompt=None, language="node", timeout=None)
```

To stop a session:

```
app.stop_interaction(job_id)
```

### Example

```python
scrape_result = app.scrape("https://www.amazon.com", formats=["markdown"])
scrape_id = scrape_result.metadata.get("scrapeId")

response = app.interact(scrape_id, prompt="Search for iPhone 16 Pro Max")
print(response.output)

price_response = app.interact(
    scrape_id, prompt="Click on the first result and tell me the price"
)
print(price_response.output)

app.stop_interaction(scrape_id)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `str` | **Required.** The `scrapeId` from the scrape response's metadata. |
| `code` | `str` | Code to execute. Provide `code` or `prompt` (one is required). |
| `prompt` | `str` | Natural-language instruction for the browser agent. Provide `prompt` or `code`. |
| `language` | `Literal["python", "node", "bash"]` | Execution language. Default: `"node"`. |
| `timeout` | `int` | Execution timeout in seconds (1–300). Default: `30`. |
| `origin` | `str` | Request attribution label. |

### Response

Returns `BrowserExecuteResponse` with fields:

- `success` — whether execution succeeded
- `output` — AI agent's response (when using `prompt`)
- `stdout` / `result` — standard output from code execution
- `stderr` — standard error from code execution
- `exit_code` — process exit code
- `live_view_url` — read-only live view of the browser
- `interactive_live_view_url` — interactive live view
- `cdp_url` — Chrome DevTools Protocol WebSocket URL

## Notes

- **Naming style**: snake_case for all parameters (e.g. `only_main_content`, `include_tags`, `scrape_options`).
- **Deprecated aliases**: `scrape_url()` → use `scrape()`. `scrape_execute()` → use `interact()`. `stop_interactive_browser()` / `delete_scrape_browser()` → use `stop_interaction()`.
- **Async support**: Use `AsyncFirecrawl` (or `AsyncFirecrawlApp`) for async/await usage with the same method signatures.
- **Keyless mode**: `scrape`, `search`, and `interact` work without an API key at a rate-limited free tier. Other methods require a key.
