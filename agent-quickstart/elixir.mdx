# Firecrawl Elixir Agent Quickstart

Canonical quickstart for external agents using the Firecrawl Elixir SDK. Generated from SDK source (`:firecrawl` v1.12.6, Hex) and the v2 OpenAPI spec. Function names are auto-generated from the OpenAPI spec and used exactly as exported.

## Install

Add to your `mix.exs` dependencies:

```elixir
defp deps do
  [
    {:firecrawl, "~> 1.12"}
  ]
end
```

Then run:

```bash
mix deps.get
```

## Authenticate

Set your API key in `config/runtime.exs`:

```elixir
config :firecrawl, api_key: System.get_env("FIRECRAWL_API_KEY")
```

Or pass `api_key` per call:

```elixir
{:ok, res} = Firecrawl.search_and_scrape(
  [query: "firecrawl web scraping"],
  api_key: "fc-YOUR-API-KEY"
)
```

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions via code execution.

## Search

### Why use it

Use search to discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:` in the query.

### Preferred SDK method

`Firecrawl.search_and_scrape(params \\ [], opts \\ [])` — returns `{:ok, %Req.Response{}}` or `{:error, exception}`.

Bang variant: `Firecrawl.search_and_scrape!/2` raises on error.

### Example

```elixir
{:ok, res} = Firecrawl.search_and_scrape(
  query: "site:docs.firecrawl.dev webhook retries",
  limit: 5
)

web_results = res.body["web"] || []

for item <- web_results do
  IO.puts("#{item["title"]} — #{item["url"]}")
end
```

### Parameters

- `query`
  - Type: string (required)
  - The search query. Use `site:example.com` to limit results to a domain.

- `limit`
  - Type: integer
  - Use when you want to cap the number of results per source type.

- `sources`
  - Type: list of atoms or strings
  - Use when you want to control which sources are searched.
  - Confirmed values: `:web`, `:news`, `:images`

- `categories`
  - Type: list of atoms or strings
  - Use when you want to filter results by category.
  - Confirmed values: `:developer`, `:research`, `:pdf`

- `include_domains`
  - Type: list of strings
  - Use when you want to restrict results to specific domains.

- `exclude_domains`
  - Type: list of strings
  - Use when you want to exclude specific domains from results.

- `tbs`
  - Type: string
  - Use when you need a time-based filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week).

- `location`
  - Type: string
  - Use when you want localized results (e.g. `"San Francisco,California,United States"`).

- `country`
  - Type: string
  - Use when you want ISO 3166-1 alpha-2 geo-targeting (e.g. `"US"`).

- `ignore_invalid_urls`
  - Type: boolean
  - Use when you want to drop URLs that cannot be scraped by other endpoints.

- `timeout`
  - Type: integer
  - Use when you need a request timeout in milliseconds.

- `highlights`
  - Type: boolean
  - Use when you want query-relevant highlights in results.

- `safe`
  - Type: boolean
  - Use when you want SafeSearch filtering.

- `scrape_options`
  - Type: keyword list
  - Use when you want to scrape each search result (see Scrape parameters for fields).

- `domain_tools`
  - Type: boolean
  - Use when you want Alexandria domain-tool discovery.

- `tool_detail`
  - Type: `:compact` | `:summary` | `:full`
  - Use when you need to control the level of tool contract detail.

- `enterprise`
  - Type: list of strings
  - Use when you need enterprise search controls.
  - Confirmed values: `"zdr"` (zero data retention), `"anon"` (anonymized)

- `threat_protection`
  - Type: keyword list
  - Use when you need per-request enterprise threat protection override.

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK method

`Firecrawl.scrape_and_extract_from_url(params \\ [], opts \\ [])` — returns `{:ok, %Req.Response{}}` or `{:error, exception}`.

Bang variant: `Firecrawl.scrape_and_extract_from_url!/2` raises on error.

### Example

```elixir
{:ok, res} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com",
  formats: ["markdown"]
)

IO.puts(res.body["markdown"])
```

### Parameters

- `url`
  - Type: string (required)
  - The URL to scrape.

- `formats`
  - Type: list of format strings or format maps
  - Use when you want multiple output formats.
  - Confirmed format strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"branding"`, `"audio"`, `"video"`
  - Map forms: `%{type: "json", prompt: "..."}`, `%{type: "screenshot", fullPage: true}`, `%{type: "changeTracking", modes: ["git-diff"]}`, `%{type: "attributes", selectors: [%{selector: "a", attribute: "href"}]}`

- `headers`
  - Type: map
  - Use when you need custom request headers.

- `include_tags`
  - Type: list of strings
  - Use when you want to include only specific HTML tags.

- `exclude_tags`
  - Type: list of strings
  - Use when you want to exclude specific HTML tags.

- `only_main_content`
  - Type: boolean
  - Use when you want to strip nav, footer, and other boilerplate.

- `timeout`
  - Type: integer
  - Use when you need a timeout in milliseconds.
  - Default: 60000. Range: 1000–300000.

- `wait_for`
  - Type: integer
  - Use when you need to wait for the page to render (milliseconds).

- `mobile`
  - Type: boolean
  - Use when you want a mobile viewport.

- `parsers`
  - Type: list of parser strings or maps
  - Use when you need file parsing controls.
  - Confirmed values: `"pdf"`, `%{type: "pdf", mode: "auto", maxPages: 5}`

- `actions`
  - Type: list of action maps
  - Use when you need pre-scrape browser actions.
  - Confirmed action types: `wait`, `screenshot`, `click`, `write`, `press`, `scroll`, `scrape`, `executeJavascript`, `pdf`

- `location`
  - Type: keyword list
  - Use when you need geo or language-aware scraping.
  - Example: `[country: "US", languages: ["en-US"]]`

- `skip_tls_verification`
  - Type: boolean
  - Use when you need to skip TLS verification.

- `remove_base64_images`
  - Type: boolean
  - Use when you want to drop base64 images from markdown output.

- `block_ads`
  - Type: boolean
  - Use when you want ad and cookie popup blocking.

- `proxy`
  - Type: atom
  - Use when you need proxy control.
  - Confirmed values: `:basic`, `:enhanced`, `:auto`

- `max_age`
  - Type: integer
  - Use when you want cached data up to a maximum age (milliseconds).

- `min_age`
  - Type: integer
  - Use when you want cached data only if it is at least this old (milliseconds).

- `store_in_cache`
  - Type: boolean
  - Use when you want Firecrawl to cache the result.

- `lockdown`
  - Type: boolean
  - Use when you want to serve only cached results (404 on cache miss).

- `check_prompt_injection`
  - Type: boolean
  - Use when you want to scan scraped content for prompt injection (adds 4 credits).

- `profile`
  - Type: keyword list
  - Use when you want a persistent browser profile.
  - Example: `[name: "my-session", save_changes: true]`

- `zero_data_retention`
  - Type: boolean
  - Use when you want zero data retention for this scrape.

## Interact

### Why use it

Use `interact` for code execution in the browser session tied to a scrape job. Get the job ID from the scrape response metadata. The Elixir SDK supports code-based interactions only (no `prompt` parameter).

### Preferred SDK method

`Firecrawl.interact_with_scrape_browser_session(job_id, params \\ [], opts \\ [])` — returns `{:ok, %Req.Response{}}` or `{:error, exception}`.

Bang variant: `Firecrawl.interact_with_scrape_browser_session!/3` raises on error.

To end the session: `Firecrawl.stop_interactive_scrape_browser_session(job_id, opts \\ [])`

### Example

```elixir
{:ok, scrape_res} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com",
  formats: ["markdown"]
)

job_id = get_in(scrape_res.body, ["metadata", "scrapeId"])

{:ok, interact_res} = Firecrawl.interact_with_scrape_browser_session(
  job_id,
  code: "console.log(await page.title());",
  language: :node,
  timeout: 60
)

IO.puts(interact_res.body["stdout"])

{:ok, _} = Firecrawl.stop_interactive_scrape_browser_session(job_id)
```

### Parameters

- `job_id`
  - Type: string (first argument, required)
  - The scrape job ID from the scrape response metadata (`scrapeId`).

- `code`
  - Type: string (required)
  - The code to execute in the browser session.

- `language`
  - Type: atom or string
  - Use when you need a specific runtime.
  - Confirmed values: `:python`, `:node`, `:bash`

- `timeout`
  - Type: integer
  - Use when you need an execution timeout in seconds.

- `origin`
  - Type: string
  - Use when you want an optional origin label for execution telemetry.

## Notes

- The Elixir SDK is auto-generated from the OpenAPI spec. Function names match the spec operation IDs directly.
- All parameters use snake_case keyword lists. The SDK maps them to camelCase JSON on the wire.
- Every public function has a bang (`!`) variant that raises on error instead of returning `{:error, _}`.
- This SDK supports code-based interactions only. Unlike the Node.js, Python, and Rust SDKs, there is no `prompt` parameter on `interact_with_scrape_browser_session`.
- `search_github/2` is deprecated in favor of `search_developer/2`.
- A nil or empty API key falls back to the keyless free tier (rate-limited per IP).
