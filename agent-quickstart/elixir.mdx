# Firecrawl Elixir Agent Quickstart

This file is the canonical quickstart for external agents integrating with Firecrawl using the Elixir SDK. It is generated from the SDK source (`:firecrawl` hex package) and the OpenAPI spec.

## Install

Add to your `mix.exs`:

```elixir
defp deps do
  [
    {:firecrawl, "~> 1.11"}
  ]
end
```

## Authenticate

```elixir
# Option 1: Set in application config
config :firecrawl, api_key: "fc-YOUR-API-KEY"

# Option 2: Pass per-request
Firecrawl.search_and_scrape([query: "test"], api_key: "fc-YOUR-API-KEY")
```

The API key is resolved from: per-request `api_key` opt > `Application.get_env(:firecrawl, :api_key)`. Omitting the key enables a keyless free tier (rate-limited per IP). For self-hosted instances, set `base_url`.

## When To Use What

- **`search_and_scrape`** — Start with a query, get web results with optional scraping. Use when you need discovery.
- **`scrape_and_extract_from_url`** — Start with a URL, get page content as markdown, HTML, JSON, etc. Use when you already know the page.
- **`interact_with_scrape_browser_session`** — Execute code in a live browser session bound to a prior scrape. Use when the page needs clicks, forms, or post-scrape browser actions.

## Search

### Why use it

Search the web for a query and get back results with optional page content. Combines discovery and scraping in one call.

### Preferred SDK function

```elixir
Firecrawl.search_and_scrape(params, opts \\ [])
Firecrawl.search_and_scrape!(params, opts \\ [])
```

### Example

```elixir
{:ok, response} = Firecrawl.search_and_scrape(
  query: "firecrawl web scraping",
  limit: 5
)

IO.inspect(response.body)
```

### Parameters

Parameters are a keyword list. All are optional except `query`.

| Parameter | Type | Description |
|---|---|---|
| `query` | `:string` | **Required.** The search query. |
| `limit` | `:integer` | Max number of results. |
| `sources` | `{:list, :any}` | Sources to query: `"web"`, `"news"`, `"images"`, `"alexandria"`. |
| `categories` | `{:list, :any}` | Narrow results: `"github"`, `"research"`, `"pdf"`, `"developer"`. |
| `include_domains` | `{:list, :string}` | Only return results from these domains. |
| `exclude_domains` | `{:list, :string}` | Exclude results from these domains. |
| `tbs` | `:string` | Time-based filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week). |
| `location` | `:string` | Geographic location string for geo-targeting. |
| `country` | `:string` | ISO country code for geo-targeting. |
| `highlights` | `:boolean` | Generate query-relevant highlights. Defaults to `true` server-side. |
| `timeout` | `:integer` | Timeout in milliseconds. |
| `ignore_invalid_urls` | `:boolean` | Skip invalid URLs in results. |
| `scrape_options` | `:keyword_list` | Options applied when scraping each result page. |
| `enterprise` | `{:list, :string}` | Enterprise search: `["zdr"]` for Zero Data Retention, `["anon"]` for anonymized. |

## Scrape

### Why use it

Scrape a single URL and get back clean content in your chosen formats — markdown, HTML, structured JSON, screenshots, and more.

### Preferred SDK function

```elixir
Firecrawl.scrape_and_extract_from_url(params, opts \\ [])
Firecrawl.scrape_and_extract_from_url!(params, opts \\ [])
```

### Example

```elixir
{:ok, response} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com",
  formats: ["markdown", "html"],
  only_main_content: true
)

IO.inspect(response.body)
```

### Parameters

Parameters are a keyword list. All are optional except `url`.

| Parameter | Type | Description |
|---|---|---|
| `url` | `:string` | **Required.** The URL to scrape. |
| `formats` | `{:list, :any}` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"json"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`. Also accepts maps for format-specific options. |
| `only_main_content` | `:boolean` | Extract only main content, excluding navs/footers. |
| `include_tags` | `{:list, :string}` | HTML tags to include in output. |
| `exclude_tags` | `{:list, :string}` | HTML tags to exclude from output. |
| `headers` | `:any` | Custom HTTP headers for the request. |
| `timeout` | `:integer` | Timeout in ms. Min 1000, default 60000, max 300000. |
| `wait_for` | `:integer` | Wait time in ms before scraping (for JS rendering). |
| `mobile` | `:boolean` | Emulate a mobile device. |
| `actions` | `{:list, :any}` | Browser actions to perform before grabbing content. |
| `location` | `:keyword_list` | Proxy location with `country` and `languages`. |
| `proxy` | `{:in, [:basic, :enhanced, :auto]}` | Proxy type. |
| `block_ads` | `:boolean` | Block ads and cookie popups. |
| `skip_tls_verification` | `:boolean` | Skip TLS certificate verification. |
| `remove_base64_images` | `:boolean` | Strip base64 images from output. |
| `parsers` | `{:list, :any}` | Document parsers. Default includes `"pdf"`. |
| `max_age` | `:integer` | Max cache age in milliseconds. |
| `min_age` | `:integer` | Cache-only mode; value is min age in ms. |
| `store_in_cache` | `:boolean` | Store the result in Firecrawl's index. |
| `lockdown` | `:boolean` | Only serve cached results; no outbound requests. |
| `redact_pii` | `:boolean` | Redact personally identifiable information. |
| `profile` | `:keyword_list` | Persistent browser profile with `name` and `save_changes`. |
| `audit_metadata` | `:keyword_list` | User attribution for SIEM logging (`username` required). |
| `zero_data_retention` | `:boolean` | Enable zero data retention. |

## Interact

### Why use it

Execute code in a live browser session that was opened by a prior scrape. Use it for clicking buttons, filling forms, navigating, or any post-scrape browser automation.

### Preferred SDK function

```elixir
Firecrawl.interact_with_scrape_browser_session(job_id, params, opts \\ [])
Firecrawl.interact_with_scrape_browser_session!(job_id, params, opts \\ [])
```

### Example

```elixir
{:ok, scrape_response} = Firecrawl.scrape_and_extract_from_url(
  url: "https://www.amazon.com",
  formats: ["markdown"]
)

scrape_id = scrape_response.body["data"]["metadata"]["scrapeId"]

Firecrawl.interact_with_scrape_browser_session(scrape_id,
  code: "Search for iPhone 16 Pro Max",
  language: :bash
)

{:ok, response} = Firecrawl.interact_with_scrape_browser_session(scrape_id,
  code: "Click on the first result and tell me the price",
  language: :bash
)

IO.inspect(response.body)

Firecrawl.stop_interactive_scrape_browser_session(scrape_id)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `String.t()` | **Required** (first arg). The scrape job ID from metadata. |
| `code` | `:string` | **Required.** Code to execute in the browser sandbox. |
| `language` | `{:in, [:python, :node, :bash]}` | Language for code execution. Default: `:node`. |
| `timeout` | `:integer` | Execution timeout in seconds. |

**Stop the session** when done:

```elixir
Firecrawl.stop_interactive_scrape_browser_session(job_id)
```

## Notes

- **Naming style**: All parameter keys are snake_case atoms. The SDK serializes them to the camelCase JSON keys the API expects.
- **OpenAPI-generated**: The Elixir SDK is auto-generated from the OpenAPI spec. Function names match the OpenAPI operation IDs, not shortened aliases.
- **Bang variants**: Every function has a `!` variant that raises `Firecrawl.Error` on HTTP errors instead of returning `{:error, ...}`.
- **Return type**: All functions return `{:ok, %Req.Response{}}` or `{:error, exception}`. The response body is in `response.body`.
- **Per-request overrides**: Every function accepts trailing `opts` for `:api_key`, `:base_url`, and any `Req` options.
- **No `prompt` parameter**: Unlike the JS/TS, Python, and Rust SDKs, the Elixir SDK's interact function does not have a separate `prompt` parameter. Use `code` with `language: :bash` for natural-language instructions.
