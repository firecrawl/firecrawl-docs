# Firecrawl Elixir Agent Quickstart

This file is the canonical quickstart for external agents integrating with Firecrawl using the Elixir SDK. It is generated from SDK source plus OpenAPI.

## Install

Add to your `mix.exs`:

```elixir
defp deps do
  [
    {:firecrawl, "~> 0.1"}
  ]
end
```

## Authenticate

```elixir
# Set the API key in your application config
config :firecrawl,
  api_key: "fc-YOUR_API_KEY"
```

Or pass it per-call via the `opts` keyword list:

```elixir
Firecrawl.scrape_and_extract_from_url([url: "https://example.com"], api_key: "fc-YOUR_API_KEY")
```

## When To Use What

- **search** — Use when you start with a query and need to discover relevant URLs and content across the web.
- **scrape** — Use when you already have a URL and want to extract page content in structured formats.
- **interact** — Use when the page needs post-scrape browser actions like clicking, typing, or running code in the browser session.

## Search

### Why use it

Search combines web search with optional scraping of each result. It returns structured results from multiple sources (web, news, images) and can scrape each result page in the same call.

### Preferred SDK method

```elixir
Firecrawl.search_and_scrape(params \\ [], opts \\ [])
Firecrawl.search_and_scrape!(params \\ [], opts \\ [])
```

### Example

```elixir
{:ok, %Req.Response{body: body}} =
  Firecrawl.search_and_scrape(
    query: "firecrawl web scraping",
    limit: 5,
    scrape_options: [formats: ["markdown"]]
  )

for result <- body["data"]["web"] || [] do
  IO.puts(result["url"])
end
```

### Parameters

|---|---|---|
| `query` | `string` | **Required.** The search query (max 500 chars). |
| `limit` | `integer` | Max results per source type. Default: `10`, max: `100`. |
| `sources` | `list(any)` | Sources: `"web"`, `"news"`, `"images"`, `"alexandria"`. Default: `["web"]`. |
| `categories` | `list(any)` | Filter by category: `"developer"`, `"research"`, `"pdf"`, `"gov"`. |
| `include_domains` | `list(string)` | Restrict to these domains. Cannot combine with `exclude_domains`. |
| `exclude_domains` | `list(string)` | Exclude these domains. Cannot combine with `include_domains`. |
| `tbs` | `string` | Time-based filter. E.g., `"qdr:d"` (past day), `"qdr:w"` (past week). |
| `location` | `string` | Location string for geo-targeted results. |
| `country` | `string` | ISO country code. Default: `"US"`. |
| `ignore_invalid_urls` | `boolean` | Exclude invalid URLs. Default: `false`. |
| `timeout` | `integer` | Timeout in milliseconds. Default: `60000`. |
| `highlights` | `boolean` | Generate query-relevant highlights. Default: `true`. |
| `scrape_options` | `keyword` | Options applied to scraping each result page. |
| `domain_tools` | `boolean` | Include domain-matched tool contracts alongside results. |
| `tool_detail` | `:compact \| :summary \| :full` | Detail level for tool contracts. Default: `:compact`. |

## Scrape

### Why use it

Scrape fetches a single URL and returns page content in one or more formats. Use it when you already know which page you need.

### Preferred SDK method

```elixir
Firecrawl.scrape_and_extract_from_url(params \\ [], opts \\ [])
Firecrawl.scrape_and_extract_from_url!(params \\ [], opts \\ [])
```

### Example

```elixir
{:ok, %Req.Response{body: body}} =
  Firecrawl.scrape_and_extract_from_url(
    url: "https://example.com",
    formats: ["markdown", "links"],
    only_main_content: true
  )

IO.puts(body["data"]["markdown"])
```

### Parameters

Keyword list validated by `NimbleOptions`. Use snake_case keys:

| Parameter | Type | Description |
|---|---|---|
| `url` | `string` | **Required.** The URL to scrape. |
| `formats` | `list(any)` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"screenshot"`, `"json"`, `"images"`, `"audio"`, `"video"`, `"summary"`, `"changeTracking"`, `"attributes"`, etc. |
| `only_main_content` | `boolean` | Strip headers, navs, footers. Default: `true`. |
| `include_tags` | `list(string)` | HTML tags to exclusively include. |
| `exclude_tags` | `list(string)` | HTML tags to exclude. |

| `wait_for` | `integer` | Extra delay in ms after page load. Default: `0`. |

| `parsers` | `list(any)` | Parser configs: `"pdf"`, `"image"`, or keyword lists with type, mode, max_pages. |
| `actions` | `list(any)` | Browser actions before scraping. |
| `location` | `keyword` | Proxy location config. Default: `"US"`. |

## Interact

### Why use it

Interact lets you execute code in the browser session that was used for a scrape. Use it for post-scrape browser automation.

### Preferred SDK method

```elixir
Firecrawl.interact_with_scrape_browser_session(job_id, params \\ [], opts \\ [])
Firecrawl.interact_with_scrape_browser_session!(job_id, params \\ [], opts \\ [])
```

### Example

```elixir
{:ok, %Req.Response{body: body}} =
  Firecrawl.interact_with_scrape_browser_session(
    "scrape-job-uuid",
    code: "document.querySelector('button').click();",
    language: :node,
    timeout: 30
  )

IO.puts(body["stdout"])
```

### Parameters

Keyword list validated by `NimbleOptions`:

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `String.t()` | **Required.** First positional argument. The scrape job ID (UUID). |
| `code` | `string` | **Required.** Code to execute in the browser sandbox (1–100,000 chars). |
| `language` | `:python \| :node \| :bash` | Language of the code. Default: `:node`. |
| `timeout` | `integer` | Execution timeout in seconds. Min: `1`, max: `300`, default: `30`. |
| `origin` | `string` | Optional origin label for telemetry. |

## Notes

- **Naming style:** All parameters use snake_case as keyword list keys. The SDK maps them to camelCase for the API.
- **OpenAPI-shaped:** The Elixir SDK is generated from the OpenAPI spec. Function names match operation IDs: `scrape_and_extract_from_url`, `search_and_scrape`, `interact_with_scrape_browser_session`.
- **Bang variants:** Every function has a `!` variant (e.g., `search_and_scrape!`) that raises on error instead of returning `{:error, ...}`.
- **Responses:** Functions return `{:ok, %Req.Response{}}` or `{:error, exception}`. The response body is a decoded map.
- **Stop interaction:** Use `Firecrawl.stop_interactive_scrape_browser_session(job_id)` to end a browser session (maps to `DELETE /scrape/{jobId}/interact`).
