Canonical Firecrawl Elixir quickstart for agents. Generated from SDK source (`:firecrawl` **v1.12.0**) and the v2 OpenAPI spec. Function names and parameter keys are generated from the spec and used as-is.

## Install

Add to `mix.exs`:

```elixir
{:firecrawl, "~> 1.12"}
```

## Authenticate

```elixir
# config/runtime.exs or config.exs
config :firecrawl, api_key: System.get_env("FIRECRAWL_API_KEY")

# or pass api_key per call
{:ok, res} = Firecrawl.search_and_scrape([query: "site:docs.firecrawl.dev webhook retries"], api_key: "fc-your-api-key")
```

The `opts` keyword list also accepts `:base_url` to override the default API base URL (`"https://api.firecrawl.dev/v2"`).

## When To Use What

- **`search`**: use when you start with a query and need discovery.
- **`scrape`**: use when you already have a URL and want page content.
- **`interact`**: use when the page needs clicks, forms, or post-scrape browser actions.

## Search

### Why use it

Use search to discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:`, for example `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`Firecrawl.search_and_scrape(params \\ [], opts \\ [])`

### Example

```elixir
{:ok, res} = Firecrawl.search_and_scrape(query: "site:docs.firecrawl.dev webhook retries")
```

```elixir
{:ok, res} = Firecrawl.search_and_scrape(
  query: "site:docs.firecrawl.dev crawl webhooks",
  sources: [:web, :news],
  categories: [:research],
  limit: 10,
  tbs: "qdr:m",
  location: "San Francisco,California,United States",
  country: "US",
  ignore_invalid_urls: true,
  timeout: 60000,
  scrape_options: [
    formats: [
      "markdown",
      "links",
      %{type: "json", prompt: "Extract title and key endpoints."}
    ],
    only_main_content: true,
    include_tags: ["main", "article"],
    exclude_tags: ["nav", "footer"],
    wait_for: 1000
  ]
)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `string` | Search query (required). Use `site:example.com` to limit results to a domain. |
| `sources` | `list(atom \| string \| map)` | Sources: `:web`, `:news`, `:images`, `:alexandria`. |
| `categories` | `list(atom \| string \| map)` | Categories: `:developer`, `:research`, `:pdf`, `:gov`. |
| `include_domains` | `list(string)` | Restrict results to these domains. Cannot combine with `exclude_domains`. |
| `exclude_domains` | `list(string)` | Exclude results from these domains. |
| `limit` | `integer` | Cap results. |
| `tbs` | `string` | Time-based filter (e.g. `qdr:d`, `qdr:w`). |
| `location` | `string` | Localized results. |
| `country` | `string` | ISO 3166-1 alpha-2 country code. |
| `safe` | `boolean` | Filter explicit content (SafeSearch). |
| `ignore_invalid_urls` | `boolean` | Drop URLs that cannot be scraped. |
| `timeout` | `integer` | Request timeout in milliseconds. |
| `highlights` | `boolean` | Generate query-relevant highlights. |
| `enterprise` | `list(string)` | Enterprise ZDR: `"zdr"`, `"anon"`. |
| `scrape_options` | `keyword` | Scrape each search result (see Scrape parameters). |
| `threat_protection` | `keyword` | Per-request threat protection override. |
| `domain_tools` | `boolean` | Include domain-matched Alexandria tool contracts. |
| `tool_detail` | `:compact \| :summary \| :full` | How much of each tool contract to return. |

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK method

`Firecrawl.scrape_and_extract_from_url(params \\ [], opts \\ [])`

### Example

```elixir
{:ok, res} = Firecrawl.scrape_and_extract_from_url(
  url: "https://docs.firecrawl.dev",
  formats: ["markdown"]
)
```

```elixir
{:ok, res} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com/pricing",
  formats: [
    "markdown",
    "links",
    %{type: "json", prompt: "Extract plan names and prices."},
    %{type: "screenshot", fullPage: true, quality: 80},
    %{type: "changeTracking", modes: ["git-diff"], tag: "pricing"}
  ],
  headers: %{"User-Agent" => "MyAgent/1.0"},
  only_main_content: true,
  wait_for: 1000,
  parsers: [%{type: "pdf", mode: "auto", maxPages: 5}],
  actions: [
    %{type: "click", selector: "#accept"},
    %{type: "wait", milliseconds: 750},
    %{type: "scrape"}
  ],
  location: [country: "US", languages: ["en-US"]],
  remove_base64_images: true,
  block_ads: true,
  proxy: :auto,
  max_age: 86400000,
  store_in_cache: true,
  profile: [name: "my-session", save_changes: true]
)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `string` | URL to scrape (required). |
| `formats` | `list(string \| map)` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"branding"`, `"audio"`, `"video"`, or format maps. |
| `headers` | `map` | Custom request headers. |
| `include_tags` | `list(string)` | Include only specific HTML tags. |
| `exclude_tags` | `list(string)` | Exclude specific HTML tags. |
| `only_main_content` | `boolean` | Strip nav, footer, and other boilerplate. |
| `only_clean_content` | `boolean` | Beta. LLM-based pass to remove residual boilerplate. |
| `timeout` | `integer` | Timeout in milliseconds. Min 1000, default 60000, max 300000. |
| `wait_for` | `integer` | Wait for page to render (milliseconds). |
| `mobile` | `boolean` | Use a mobile viewport. |
| `parsers` | `list(string \| map)` | File parsing controls (e.g. `"pdf"` or `%{type: "pdf", mode: "auto", maxPages: 5}`). |
| `actions` | `list(map)` | Pre-scrape browser actions. |
| `location` | `keyword` | Geo config (`country:`, `languages:`). |
| `skip_tls_verification` | `boolean` | Skip TLS verification. |
| `remove_base64_images` | `boolean` | Drop base64 images from markdown output. |
| `block_ads` | `boolean` | Ad and cookie popup blocking. |
| `proxy` | `atom \| string` | `:basic`, `:enhanced`, `:auto`. |
| `max_age` | `integer` | Max age for cached data (milliseconds). |
| `min_age` | `integer` | Min age for cached data (milliseconds). |
| `store_in_cache` | `boolean` | Cache the result. |
| `lockdown` | `boolean` | Serve from cache only. |
| `check_prompt_injection` | `boolean` | Scan for prompt injection. Adds 4 credits. |
| `redact_pii` | `any` | Redact PII. Pass `true` for defaults or a map for tuning. |
| `threat_protection` | `keyword` | Per-request threat protection override. |
| `audit_metadata` | `keyword` | User attribution for SIEM logging (`username:` required). |
| `profile` | `keyword` | Persistent browser profile (`name:`, `save_changes:`). |
| `zero_data_retention` | `boolean` | Enable zero data retention. |
| `domain_tools` | `boolean` | Include domain-matched Alexandria tool contracts. |

## Interact

### Why use it

Use interact when a page requires browser actions or code execution after a scrape starts. The Elixir SDK exposes code-based interactions only (no `prompt` parameter on the scrape-bound interact).

### Preferred SDK method

`Firecrawl.interact_with_scrape_browser_session(job_id, params \\ [], opts \\ [])`

### Example

```elixir
{:ok, res} = Firecrawl.interact_with_scrape_browser_session(
  "<scrapeJobId>",
  code: "console.log(await page.title());",
  language: :node,
  timeout: 60
)
```

### Stop session

`Firecrawl.stop_interactive_scrape_browser_session(job_id, opts \\ [])` tears down the browser session.

```elixir
{:ok, res} = Firecrawl.stop_interactive_scrape_browser_session("<scrapeJobId>")
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `string` | Scrape job ID. |
| `code` | `string` | Code to run in the browser session (required). |
| `language` | `atom \| string` | Runtime: `:python`, `:node`, `:bash`. |
| `timeout` | `integer` | Execution timeout in seconds. |

### Standalone interact sessions

The Elixir SDK also exposes standalone interact endpoints (not tied to a scrape job):

- `Firecrawl.create_browser_session(params, opts)` — `POST /interact`. Params: `ttl`, `activity_ttl`, `block_ads`, `location`, `profile`, `stream_web_view`.
- `Firecrawl.execute_browser_code(session_id, params, opts)` — `POST /interact/{sessionId}/execute`. Params: `code` (required), `language`, `timeout`.
- `Firecrawl.delete_browser_session(session_id, opts)` — `DELETE /interact/{sessionId}`.
- `Firecrawl.list_browser_sessions(params, opts)` — `GET /interact`. Params: `status` (`:active` or `:destroyed`).

## Notes

- The Elixir client is OpenAPI-shaped; function names and parameter keys are generated from the spec.
- Each public function has a bang (`!`) variant that raises on error instead of returning `{:error, _}`.
- All non-bang functions return `{:ok, Req.Response.t()} | {:error, Exception.t() | Firecrawl.Error.t()}`.
- No default values are set SDK-side; all defaults are applied by the server.
- An `"origin"` field (`"elixir-sdk@{version}"`) is automatically injected into every request body.
