# Firecrawl Elixir Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`:firecrawl` v1.12.0) and the v2 OpenAPI spec. Function names and parameter keys are auto-generated from the OpenAPI spec.

## Install

Add to `mix.exs`:

```elixir
{:firecrawl, "~> 1.12"}
```

## Authenticate

```elixir
# config/runtime.exs or config.exs
config :firecrawl, api_key: System.get_env("FIRECRAWL_API_KEY")

# Or pass api_key per call:
{:ok, res} = Firecrawl.search_and_scrape([query: "firecrawl webhooks"], api_key: "fc-...")
```

All functions accept an optional trailing keyword list with `:api_key` and `:base_url` overrides.

## When To Use What

- **`search_and_scrape`**: use when you start with a query and need discovery. Returns ranked results you can then scrape.
- **`scrape_and_extract_from_url`**: use when you already have a URL and want page content in one or more formats.
- **`interact_with_scrape_browser_session`**: use when the page needs code execution in a scrape-bound browser session.

## Search

### Why use it

Discover relevant pages from a query. Pick URLs from the results to scrape or interact with. Constrain to a site with `site:` in the query.

### Preferred SDK method

`Firecrawl.search_and_scrape(params \\ [], opts \\ [])` → `{:ok, %Req.Response{}} | {:error, term()}`

### Example

```elixir
{:ok, res} = Firecrawl.search_and_scrape(
  query: "site:docs.firecrawl.dev webhook retries",
  limit: 5,
  scrape_options: [
    formats: ["markdown"],
    only_main_content: true
  ]
)

web_results = res.body["data"]["web"]
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `string` (required) | Search query. Use `site:example.com` to limit to a domain. |
| `sources` | `list` | Sources to search: `"web"`, `"news"`, `"images"`, `"alexandria"`, or atoms. |
| `categories` | `list` | Filter by category: `"developer"`, `"research"`, `"pdf"`, or atoms. |
| `include_domains` | `list(string)` | Restrict to these domains. Cannot combine with `exclude_domains`. |
| `exclude_domains` | `list(string)` | Exclude these domains. |
| `limit` | `integer` | Max results to return. |
| `tbs` | `string` | Time-based filter (e.g., `"qdr:d"` for past day). |
| `location` | `string` | Location string for geo-targeting. |
| `country` | `string` | ISO country code (e.g., `"US"`). |
| `ignore_invalid_urls` | `boolean` | Drop URLs that cannot be scraped. |
| `timeout` | `integer` | Timeout in milliseconds. |
| `highlights` | `boolean` | Generate query-relevant highlights. |
| `safe` | `boolean` | Enable SafeSearch. |
| `scrape_options` | `keyword` | Options for scraping each result (see Scrape parameters). |
| `enterprise` | `list(string)` | Enterprise options: `"zdr"`, `"anon"`. |
| `tool_detail` | `:compact \| :summary \| :full` | Detail level for discovered tools. |

## Scrape

### Why use it

Get structured content from a URL in one or more formats. Use when you already know the page you want.

### Preferred SDK method

`Firecrawl.scrape_and_extract_from_url(params \\ [], opts \\ [])` → `{:ok, %Req.Response{}} | {:error, term()}`

### Example

```elixir
{:ok, res} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com/pricing",
  formats: [
    "markdown",
    "links",
    %{type: "json", prompt: "Extract plan names and prices."}
  ],
  only_main_content: true
)

markdown = res.body["data"]["markdown"]
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `string` (required) | URL to scrape. |
| `formats` | `list` | Output formats. Strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"branding"`, `"audio"`, `"video"`. Objects: `%{type: "json", prompt: ..., schema: ...}`, `%{type: "screenshot", fullPage: true}`, `%{type: "changeTracking", modes: ["git-diff"]}`. |
| `headers` | `map` | Custom HTTP headers. |
| `include_tags` | `list(string)` | HTML tags to include. |
| `exclude_tags` | `list(string)` | HTML tags to exclude. |
| `only_main_content` | `boolean` | Strip nav, footer, and other boilerplate. |
| `timeout` | `integer` | Timeout in milliseconds. Min: 1000, max: 300000. |
| `wait_for` | `integer` | Wait for page to render (milliseconds). |
| `mobile` | `boolean` | Use mobile viewport. |
| `parsers` | `list` | Document parsers: `"pdf"` or `%{type: "pdf", mode: "auto", maxPages: 5}`. |
| `actions` | `list(map)` | Pre-scrape browser actions: `wait`, `screenshot`, `click`, `write`, `press`, `scroll`, `scrape`, `executeJavascript`, `pdf`. |
| `location` | `keyword` | Geo-targeting: `country:` and `languages:`. |
| `skip_tls_verification` | `boolean` | Skip TLS verification. |
| `remove_base64_images` | `boolean` | Drop base64 images from markdown. |
| `block_ads` | `boolean` | Block ads and cookie popups. |
| `proxy` | `:basic \| :enhanced \| :auto \| string` | Proxy configuration. |
| `max_age` | `integer` | Max age in ms of cached content. |
| `min_age` | `integer` | Min age in ms for cached data. Set to `1` for any cached data. |
| `store_in_cache` | `boolean` | Cache the result. |
| `check_prompt_injection` | `boolean` | Scan for prompt injection. Adds 4 credits. |
| `profile` | `keyword` | Persistent browser profile: `name:` and `save_changes:`. |
| `zero_data_retention` | `boolean` | Enable zero data retention. |

## Interact

### Why use it

Execute code in the browser session tied to a scrape job. Use for programmatic browser control after a scrape creates a session.

### Preferred SDK method

`Firecrawl.interact_with_scrape_browser_session(job_id, params \\ [], opts \\ [])` → `{:ok, %Req.Response{}} | {:error, term()}`

### Example

```elixir
{:ok, scrape_res} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com",
  formats: ["markdown"]
)
job_id = scrape_res.body["data"]["metadata"]["scrapeId"]

{:ok, res} = Firecrawl.interact_with_scrape_browser_session(
  job_id,
  code: "console.log(await page.title());",
  language: :node,
  timeout: 60
)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `string` (required, positional) | Scrape job ID. |
| `code` | `string` (required) | Code to run in the browser session. |
| `language` | `:python \| :node \| :bash` | Runtime for code execution. Default: `:node`. |
| `timeout` | `integer` | Execution timeout in seconds. |

The Elixir SDK exposes code-based interactions only. There is no `prompt` parameter (unlike Node.js, Python, and Rust SDKs).

### Stop session

`Firecrawl.stop_interactive_scrape_browser_session(job_id)` ends the browser session.

## Notes

- The Elixir client is OpenAPI-generated; function names and parameter keys come from the spec.
- Every public function has a bang (`!`) variant: `scrape_and_extract_from_url!` raises on error instead of returning `{:error, _}`.
- Parameter keys use `snake_case` in Elixir and are converted to `camelCase` for the API.
- No deprecated aliases exist in this SDK.
