# Firecrawl Elixir Agent Quickstart

This is the canonical quickstart for external agents integrating with Firecrawl using the Elixir SDK. Generated from SDK source and OpenAPI spec.

## Install

Add to your `mix.exs`:

```elixir
defp deps do
  [
    {:firecrawl, "~> 1.12"}
  ]
end
```

## Authenticate

```elixir
# Via application config:
config :firecrawl, api_key: "fc-YOUR_API_KEY"

# Or per-call via opts:
Firecrawl.scrape_and_extract_from_url([url: "https://example.com"], api_key: "fc-YOUR_API_KEY")
```

All functions accept a trailing `opts` keyword list with `:api_key` and `:base_url` overrides. Omitting the API key falls back to keyless free-tier access.

## When To Use What

- **search** — start with a query and discover relevant URLs with optional page content. Use when you don't have a URL yet.
- **scrape** — start with a known URL and extract page content in various formats. Use when you already know which page you need.
- **interact** — execute code in a browser session bound to a prior scrape. Use when the page needs post-scrape browser interaction like clicking, typing, or navigating.

## Search

### Why use it

Search finds pages matching a query across web, news, and image sources, and optionally returns their scraped content. Use it for discovery when you need to find relevant URLs.

### Preferred SDK method

```elixir
Firecrawl.search_and_scrape(params, opts \\ [])
```

Bang variant: `Firecrawl.search_and_scrape!(params, opts)`

### Example

```elixir
{:ok, results} = Firecrawl.search_and_scrape(
  query: "firecrawl web scraping API",
  limit: 5,
  scrape_options: [formats: ["markdown"]]
)

for item <- results["web"] || [] do
  IO.puts("#{item["url"]}: #{String.slice(item["markdown"] || "", 0, 100)}")
end
```

### Parameters

Keyword list params (snake_case, mapped to camelCase on the wire):

| Parameter | Type | Description |
|-----------|------|-------------|
| `query` | `string` | Search query string (required). Max 500 chars. |
| `limit` | `integer` | Max results per source type. Min 1, max 100. Default: 10. |
| `sources` | `list` | Sources: `"web"`, `"news"`, `"images"`, `"alexandria"`. Default: `["web"]`. |
| `categories` | `list` | Filter: `"developer"`, `"gov"`, `"research"`, `"pdf"`. |
| `include_domains` | `list(string)` | Restrict results to these domains. |
| `exclude_domains` | `list(string)` | Exclude results from these domains. |
| `tbs` | `string` | Time-based search filter (e.g. `"qdr:d"` for past day). |
| `location` | `string` | Location for geo-targeted results. |
| `country` | `string` | ISO country code (e.g. `"US"`). Default: `"US"`. |
| `safe` | `boolean` | SafeSearch filter. |
| `ignore_invalid_urls` | `boolean` | Exclude invalid URLs. |
| `timeout` | `integer` | Timeout in milliseconds. Default: 60000. |
| `highlights` | `boolean` | Generate query-relevant highlights. Default: `true`. |
| `scrape_options` | `keyword` | Options for scraping each result (see Scrape parameters, minus `url`). |
| `enterprise` | `list(string)` | Enterprise options: `["zdr"]` or `["anon"]`. |
| `domain_tools` | `boolean` | Include tool contracts matching returned domains. |
| `tool_detail` | `atom \| string` | Tool contract detail: `:compact`, `:summary`, `:full`. |

## Scrape

### Why use it

Scrape extracts structured content from a single URL. Returns markdown, HTML, links, screenshots, structured JSON, and more depending on the formats you request.

### Preferred SDK method

```elixir
Firecrawl.scrape_and_extract_from_url(params, opts \\ [])
```

Bang variant: `Firecrawl.scrape_and_extract_from_url!(params, opts)`

### Example

```elixir
{:ok, result} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com",
  formats: ["markdown", "links"],
  only_main_content: true,
  timeout: 30000
)

IO.puts(result["markdown"])
IO.inspect(result["links"])
```

### Parameters

Keyword list params (snake_case, mapped to camelCase on the wire):

| Parameter | Type | Description |
|-----------|------|-------------|
| `url` | `string` | The URL to scrape (required). |
| `formats` | `list` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"json"`, `"summary"`, `"changeTracking"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`. Default: `["markdown"]`. |
| `only_main_content` | `boolean` | Strip navs, footers, and boilerplate. Default: `true`. |
| `only_clean_content` | `boolean` | Beta. LLM-based pass to remove residual boilerplate. |
| `include_tags` | `list(string)` | HTML tags to include (allowlist). |
| `exclude_tags` | `list(string)` | HTML tags to exclude (blocklist). |
| `headers` | `any` | Custom HTTP headers. |
| `wait_for` | `integer` | Delay in ms before fetching. Max 60000. |
| `timeout` | `integer` | Timeout in ms. Min 1000, max 300000. Default: 60000. |
| `mobile` | `boolean` | Emulate a mobile device. |
| `skip_tls_verification` | `boolean` | Skip TLS certificate verification. Default: `true`. |
| `remove_base64_images` | `boolean` | Strip base64-encoded images. Default: `true`. |
| `block_ads` | `boolean` | Block ads and cookie popups. Default: `true`. |
| `proxy` | `atom \| string` | Proxy mode: `:basic`, `:enhanced`, `:auto`. Default: `:auto`. |
| `actions` | `list` | Browser actions before scraping. |
| `location` | `keyword` | Location: `country`, `languages`. |
| `parsers` | `list` | File parsers (e.g. PDF). Default: `["pdf", "image"]`. |
| `max_age` | `integer` | Max cache age in ms. Default: 172800000 (2 days). |
| `min_age` | `integer` | Min cache age in ms. 1 = accept any cached data. |
| `store_in_cache` | `boolean` | Store result in cache. Default: `true`. |
| `lockdown` | `boolean` | Serve from cache only. |
| `check_prompt_injection` | `boolean` | Scan for prompt injection. Adds 4 credits. |
| `redact_pii` | `any` | Redact PII from markdown. |
| `profile` | `keyword` | Persistent browser profile: `name` (required), `save_changes`. |
| `audit_metadata` | `keyword` | SIEM logging: `username`. |
| `domain_tools` | `boolean` | List tool contracts for the domain. |
| `tool_detail` | `atom \| string` | Tool contract detail level. |

## Interact

### Why use it

Interact lets you execute code in the browser session that was opened by a prior scrape. You write JavaScript, Python, or Bash code that runs in the browser sandbox — use it to click buttons, fill forms, navigate pages, or extract dynamic content that requires post-scrape interaction.

### Preferred SDK method

```elixir
Firecrawl.interact_with_scrape_browser_session(job_id, params, opts \\ [])
```

Bang variant: `Firecrawl.interact_with_scrape_browser_session!(job_id, params, opts)`

### Example

```elixir
# First scrape a page — the browser session stays open
{:ok, scrape_result} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com/app",
  formats: ["markdown"]
)

job_id = scrape_result["metadata"]["jobId"]

# Execute code in the browser session
{:ok, result} = Firecrawl.interact_with_scrape_browser_session(job_id,
  code: """
  await page.click('#login-button');
  await page.fill('#username', 'user@example.com');
  await page.fill('#password', 'secret');
  await page.click('#submit');
  return await page.content();
  """,
  language: :node,
  timeout: 30
)

IO.puts(result["output"])

# Stop the browser session when done
Firecrawl.stop_interactive_scrape_browser_session(job_id)
```

### Parameters

Keyword list params:

| Parameter | Type | Description |
|-----------|------|-------------|
| `code` | `string` | Code to execute in the browser sandbox (required). Max 100000 chars. |
| `language` | `atom \| string` | Runtime: `:python`, `:node`, `:bash`. Default: `:node`. |
| `timeout` | `integer` | Execution timeout in seconds. Min 1, max 300. Default: 30. |
| `origin` | `string` | Optional origin label for telemetry. |

**Related functions:**

| Function | Description |
|----------|-------------|
| `Firecrawl.stop_interactive_scrape_browser_session(job_id)` | Stops the scrape-bound browser session. |

### Standalone interact sessions

The Elixir SDK also supports standalone interactive browser sessions (not bound to a prior scrape):

| Function | Description |
|----------|-------------|
| `Firecrawl.create_browser_session(params, opts)` | Creates a standalone session. Params: `ttl`, `activity_ttl`, `stream_web_view`, `block_ads`, `profile`, `location`. |
| `Firecrawl.execute_browser_code(session_id, params, opts)` | Executes code in a standalone session. Params: `code`, `language`, `timeout`. |
| `Firecrawl.delete_browser_session(session_id, opts)` | Destroys a standalone session. |

## Notes

- The Elixir SDK is auto-generated from the OpenAPI spec. Function names are verbose and match OpenAPI operation IDs.
- All parameter names use snake_case atoms in keyword lists. They are automatically mapped to camelCase JSON.
- Results are returned as `{:ok, result}` or `{:error, reason}` tuples. Bang variants raise on error.
- The `origin` header is set automatically to `"elixir-sdk@<version>"`.
- There is no `Firecrawl.search()` or `Firecrawl.scrape()` shorthand — use the full function names above.
