# Firecrawl Elixir Agent Quickstart

This file is the canonical quickstart for external agents integrating Firecrawl with Elixir. It is generated from SDK source plus OpenAPI and covers every confirmed parameter.

## Install

Add to your `mix.exs` dependencies:

```elixir
defp deps do
  [
    {:firecrawl, "~> 1.11"}
  ]
end
```

Then run:

```bash
mix deps.get
```

## Authenticate

Configure via application config:

```elixir
# config/config.exs
config :firecrawl, api_key: "fc-YOUR-API-KEY"
```

Or pass the API key per-call:

```elixir
Firecrawl.search_and_scrape([query: "firecrawl"], api_key: "fc-YOUR-API-KEY")
```

Set `base_url:` in opts to override the default `https://api.firecrawl.dev/v2` for self-hosted instances. Omitting the API key enables a keyless free tier with IP-based rate limiting.

## When To Use What

- **`search_and_scrape`**: Use when you start with a query and need to discover relevant pages across the web.
- **`scrape_and_extract_from_url`**: Use when you already have a URL and want the page content in a structured format.
- **`interact_with_scrape_browser_session`**: Use when the page requires clicks, form fills, or other post-scrape browser actions.

## Search

### Why use it

Search the web for a query and get structured results with optional full-page content. Ideal for discovery workflows where you don't yet know which URLs matter.

### Preferred SDK method

```elixir
Firecrawl.search_and_scrape(params, opts \\ [])
```

### Example

```elixir
{:ok, response} = Firecrawl.search_and_scrape(
  query: "firecrawl web scraping",
  limit: 5
)

IO.inspect(response.body)
```

### Parameters

Parameters are passed as a keyword list. Validated by NimbleOptions.

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `query` | `:string` | Search query. **Required.** | Always. |
| `limit` | `:integer` | Max number of results. | Control result count. |
| `sources` | `{:list, :any}` | Source types: `"web"`, `"news"`, `"images"`. | Filter to specific source types. |
| `categories` | `{:list, :any}` | Narrow web search: `"github"`, `"research"`, `"pdf"`. | Target specific content types. |
| `include_domains` | `{:list, :string}` | Restrict results to these domains. | Scope search to known sources. |
| `exclude_domains` | `{:list, :string}` | Exclude results from these domains. | Filter out unwanted sources. |
| `tbs` | `:string` | Time-based search filter (e.g. `"qdr:d"` for past day). | Restrict to recent content. |
| `location` | `:string` | Location string for geo-targeting. | Get location-specific results. |
| `country` | `:string` | ISO country code for geo-targeting. | Geo-target results by country. |
| `ignore_invalid_urls` | `:boolean` | Skip invalid URLs instead of failing. | Increase robustness. |
| `timeout` | `:integer` | Timeout in milliseconds. | Override default timeout. |
| `highlights` | `:boolean` | Generate query-relevant highlights. Default: `true` server-side. | Disable if you only need URLs/titles. |
| `scrape_options` | `:keyword_list` | Options applied when scraping each result page (same keys as scrape parameters). | Get full page content alongside search results. |
| `enterprise` | `{:list, :string}` | Enterprise options: `["zdr"]` for Zero Data Retention, `["anon"]` for anonymized search. | Enterprise compliance. |

### Bang variant

```elixir
response = Firecrawl.search_and_scrape!(params, opts)
```

Raises on error instead of returning `{:error, ...}`.

### Return type

`{:ok, %Req.Response{}}` or `{:error, exception}`. The response body contains `web`, `news`, `images` result lists.

## Scrape

### Why use it

Fetch a single URL and get its content as markdown, HTML, screenshots, or structured data. The core building block for content extraction.

### Preferred SDK method

```elixir
Firecrawl.scrape_and_extract_from_url(params, opts \\ [])
```

### Example

```elixir
{:ok, response} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com",
  formats: ["markdown"]
)

IO.puts(response.body["data"]["markdown"])
```

### Parameters

Parameters are passed as a keyword list. Validated by NimbleOptions.

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `url` | `:string` | URL to scrape. **Required.** | Always. |
| `formats` | `{:list, :any}` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"json"`, `"audio"`, `"video"`, etc. | Control what data you get back. |
| `headers` | `:any` | Custom HTTP headers (cookies, user-agent, etc.). | Set cookies, auth tokens, or user-agent. |
| `include_tags` | `{:list, :string}` | Only include content from these HTML tags. | Extract specific page sections. |
| `exclude_tags` | `{:list, :string}` | Exclude content from these HTML tags. | Remove unwanted elements. |
| `only_main_content` | `:boolean` | Strip navigation, headers, and footers. | Get clean article content. |
| `timeout` | `:integer` | Timeout in milliseconds (1000–300000). | Override default timeout. |
| `wait_for` | `:integer` | Wait N milliseconds before scraping. | Handle dynamic content. |
| `mobile` | `:boolean` | Emulate a mobile device viewport. | Get mobile version of pages. |
| `parsers` | `{:list, :any}` | File parser config (PDF). | Control PDF parsing behavior. |
| `actions` | `{:list, :any}` | Browser actions to perform before grabbing content. | Automate interactions before scraping. |
| `location` | `:keyword_list` | Geolocation settings. | Get geo-specific content. |
| `skip_tls_verification` | `:boolean` | Skip TLS certificate verification. | Scrape sites with self-signed certs. |
| `remove_base64_images` | `:boolean` | Strip base64-encoded images. | Reduce response size. |
| `block_ads` | `:boolean` | Block advertisements and cookie popups. | Get cleaner content. |
| `proxy` | `:basic \| :enhanced \| :auto` | Proxy type. | Bypass blocks or access geo-restricted content. |
| `max_age` | `:integer` | Max cache age in milliseconds. | Control content freshness. |
| `min_age` | `:integer` | Min age in ms for cache-only mode. | Prefer cached results. |
| `store_in_cache` | `:boolean` | Store result in cache. | Enable caching for repeated scrapes. |
| `lockdown` | `:boolean` | Only serve cached results. | Use only cached data. |
| `redact_pii` | `:boolean` | Redact personally identifiable information. | Handle sensitive content. |
| `zero_data_retention` | `:boolean` | Enable zero data retention. | Compliance requirements. |
| `profile` | `:keyword_list` | Persistent browser profile. | Maintain login sessions. |
| `audit_metadata` | `:keyword_list` | User attribution for SIEM logging. Keys: `username` (string, required). | Enterprise audit trails. |

### Bang variant

```elixir
response = Firecrawl.scrape_and_extract_from_url!(params, opts)
```

### Return type

`{:ok, %Req.Response{}}` or `{:error, exception}`. The response body contains `data` with the scraped document.

## Interact

### Why use it

Execute code in a live browser session bound to a prior scrape job. Use it for clicking buttons, filling forms, navigating SPAs, or extracting dynamic content that requires interaction.

### Preferred SDK method

```elixir
Firecrawl.interact_with_scrape_browser_session(job_id, params \\ [], opts \\ [])
```

### Example

```elixir
{:ok, scrape_response} = Firecrawl.scrape_and_extract_from_url(
  url: "https://www.amazon.com",
  formats: ["markdown"]
)

job_id = scrape_response.body["data"]["metadata"]["scrapeId"]

{:ok, response} = Firecrawl.interact_with_scrape_browser_session(job_id,
  code: ~s(console.log("Hello from browser")),
  language: :node
)

IO.inspect(response.body)

Firecrawl.stop_interactive_scrape_browser_session(job_id)
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `job_id` | `String.t()` | Scrape job ID from a prior scrape. Required, first positional argument. | Always. |
| `code` | `:string` | Code to execute in the browser sandbox. **Required.** | Always. |
| `language` | `:python \| :node \| :bash` | Language for code execution. `node` for JavaScript, `bash` for agent-browser CLI. | Match your code's language. |
| `timeout` | `:integer` | Execution timeout in seconds. | Increase for long-running interactions. |
| `origin` | `:string` | Origin label for execution telemetry. | Request tracking. |

### Stop interaction

```elixir
Firecrawl.stop_interactive_scrape_browser_session(job_id, opts \\ [])
```

Stops the browser session and releases resources. Maps to `DELETE /scrape/{jobId}/interact`.

### Bang variants

```elixir
Firecrawl.interact_with_scrape_browser_session!(job_id, params, opts)
Firecrawl.stop_interactive_scrape_browser_session!(job_id, opts)
```

### Return type

`{:ok, %Req.Response{}}` or `{:error, exception}`. The response body contains execution results.

## Notes

- **Naming style**: All parameter keys use snake_case atoms. The SDK converts to camelCase JSON keys automatically.
- **OpenAPI-generated**: The Elixir SDK is auto-generated from the OpenAPI spec via `mix run generate.exs`. Function names follow the OpenAPI operation IDs directly.
- **Return pattern**: All functions return `{:ok, %Req.Response{}}` or `{:error, exception}`. Use bang variants (e.g. `search_and_scrape!`) to raise on error.
- **Keyless mode**: Omitting the API key enables a free tier with IP-based rate limiting.
- **Dependencies**: Uses `Req` for HTTP and `NimbleOptions` for parameter validation.
- **Proxy types**: Proxy values are atoms (`:basic`, `:enhanced`, `:auto`), not strings.
