# Firecrawl Elixir Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`:firecrawl` hex package v1.12.0) and the v2 OpenAPI spec. Function names match the auto-generated OpenAPI client exactly. Parameters use snake_case keyword lists.

## Install

```elixir
# mix.exs
defp deps do
  [
    {:firecrawl, "~> 1.12"}
  ]
end
```

## Authenticate

```elixir
# Pass api_key as an option to any function call:
Firecrawl.scrape_and_extract_from_url([url: "https://example.com"], api_key: "your-api-key")

# Or set the base_url for self-hosted:
Firecrawl.scrape_and_extract_from_url([url: "https://example.com"],
  api_key: "your-api-key",
  base_url: "https://your-instance.com"
)
```

## When To Use What

- **`search_and_scrape`**: use when you start with a query and need discovery. Returns ranked results from web, news, or images.
- **`scrape_and_extract_from_url`**: use when you already have a URL and want page content in one or more formats (markdown, HTML, JSON extraction, screenshots, etc.).
- **`interact_with_scrape_browser_session`**: use when the page needs clicks, forms, or post-scrape browser actions. Operates on the browser session tied to a prior scrape job.

## Search

### Why use it

Discover relevant pages from a query, then pick URLs to scrape or interact with.

### Preferred SDK method

`Firecrawl.search_and_scrape(params, opts \\ [])` → `{:ok, Req.Response.t()} | {:error, Exception.t()}`

Bang variant: `Firecrawl.search_and_scrape!(params, opts \\ [])` → `Req.Response.t()`

### Example

```elixir
{:ok, response} = Firecrawl.search_and_scrape(
  [
    query: "firecrawl webhook docs",
    limit: 10,
    scrape_options: [
      formats: ["markdown"],
      only_main_content: true
    ]
  ],
  api_key: "your-api-key"
)

for item <- response.body["data"]["web"] || [] do
  IO.puts("#{item["url"]}: #{item["title"]}")
end
```

### Parameters

Parameters are a keyword list validated by NimbleOptions.

| Parameter | Type | Description |
|---|---|---|
| `query` | `:string` (required) | The search query. |
| `sources` | `{:list, :any}` | Sources: `"web"`, `"news"`, `"images"`, `"alexandria"`. Default: `["web"]`. |
| `categories` | `{:list, :any}` | Categories to filter by. |
| `include_domains` | `{:list, :string}` | Restrict to these domains. |
| `exclude_domains` | `{:list, :string}` | Exclude these domains. |
| `limit` | `:integer` | Max results per source type. |
| `tbs` | `:string` | Time-based filter (e.g. `"qdr:d"`, `"qdr:w"`). |
| `location` | `:string` | Localized results. |
| `country` | `:string` | ISO country code. |
| `ignore_invalid_urls` | `:boolean` | Drop URLs that cannot be scraped. |
| `timeout` | `:integer` | Timeout in ms. |
| `highlights` | `:boolean` | Generate query-relevant highlights. |
| `scrape_options` | `:keyword_list` | Apply scrape options to each result. |
| `domain_tools` | `:boolean` | Include Alexandria tool contracts. |
| `tool_detail` | `:compact \| :summary \| :full` | Tool contract detail level. |
| `safe` | `:boolean` | SafeSearch filter. |
| `enterprise` | `{:list, :string}` | Enterprise ZDR options. |
| `threat_protection` | `:keyword_list` | Per-request threat protection override. |

### Return value

The response body contains `data` with `web`, `news`, `images`, and `tools` arrays.

## Scrape

### Why use it

Fetch structured content from a URL in one or more formats.

### Preferred SDK method

`Firecrawl.scrape_and_extract_from_url(params, opts \\ [])` → `{:ok, Req.Response.t()} | {:error, Exception.t()}`

Bang variant: `Firecrawl.scrape_and_extract_from_url!(params, opts \\ [])` → `Req.Response.t()`

### Example

```elixir
{:ok, response} = Firecrawl.scrape_and_extract_from_url(
  [
    url: "https://example.com/pricing",
    formats: ["markdown", %{"type" => "json", "prompt" => "Extract plan names and prices."}],
    only_main_content: true
  ],
  api_key: "your-api-key"
)

IO.puts(response.body["data"]["markdown"])
IO.inspect(response.body["data"]["json"])
```

### Parameters

Parameters are a keyword list validated by NimbleOptions.

| Parameter | Type | Description |
|---|---|---|
| `url` | `:string` (required) | The URL to scrape. |
| `formats` | `{:list, :any}` | Output formats. Strings or maps. Default: `["markdown"]`. |
| `headers` | `:any` | Custom HTTP headers. |
| `include_tags` | `{:list, :string}` | Only include these HTML tags. |
| `exclude_tags` | `{:list, :string}` | Exclude these HTML tags. |
| `only_main_content` | `:boolean` | Strip nav, footer, boilerplate. |
| `timeout` | `:integer` | Timeout in ms. Default: 60000. Max: 300000. |
| `wait_for` | `:integer` | Delay in ms before fetching. |
| `mobile` | `:boolean` | Emulate mobile device. |
| `parsers` | `{:list, :any}` | File parsing controls. |
| `actions` | `{:list, :any}` | Pre-scrape browser actions. |
| `location` | `:keyword_list` | Geo/language settings. |
| `skip_tls_verification` | `:boolean` | Skip TLS verification. |
| `remove_base64_images` | `:boolean` | Drop base64 images. |
| `block_ads` | `:boolean` | Block ads and cookie popups. |
| `proxy` | `:basic \| :enhanced \| :auto \| string` | Proxy mode. |
| `max_age` | `:integer` | Use cached result if younger (ms). Default: 2 days. |
| `min_age` | `:integer` | Cache-only check, minimum age (ms). |
| `store_in_cache` | `:boolean` | Cache the result. |
| `lockdown` | `:boolean` | Serve from cache only. |
| `redact_pii` | `:any` | Redact PII. |
| `profile` | `:keyword_list` | Persistent browser profile. |
| `audit_metadata` | `:keyword_list` | User attribution (`[username: "..."]`). |
| `domain_tools` | `:boolean` | Include Alexandria tool contracts. |
| `threat_protection` | `:keyword_list` | Per-request threat protection override. |
| `alexandria` | `:any` | Execute catalogued provider tools instead of scraping. |

### Return value

The response body contains `data` with fields like `markdown`, `html`, `json`, `screenshot`, `links`, `images`, `metadata`, etc.

## Interact

### Why use it

Execute code in the browser session tied to a scrape job. Use for multi-step flows like filling forms, navigating tabs, or extracting dynamic content.

### Preferred SDK method

`Firecrawl.interact_with_scrape_browser_session(job_id, params, opts \\ [])` → `{:ok, Req.Response.t()} | {:error, Exception.t()}`

Bang variant: `Firecrawl.interact_with_scrape_browser_session!(job_id, params, opts \\ [])` → `Req.Response.t()`

### Example

```elixir
{:ok, scrape_response} = Firecrawl.scrape_and_extract_from_url(
  [url: "https://example.com", formats: ["markdown"]],
  api_key: "your-api-key"
)

job_id = scrape_response.body["data"]["metadata"]["scrapeId"]

{:ok, result} = Firecrawl.interact_with_scrape_browser_session(
  job_id,
  [
    code: "console.log(await page.title());",
    language: :node,
    timeout: 60
  ],
  api_key: "your-api-key"
)

IO.puts(result.body["stdout"])

Firecrawl.stop_interactive_scrape_browser_session(job_id, api_key: "your-api-key")
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `job_id` | `String.t()` (path param) | Scrape job ID from response metadata. |
| `code` | `:string` (required) | Code to execute in the browser sandbox. |
| `language` | `:python \| :node \| :bash` | Runtime language. Default: `:node`. |
| `timeout` | `:integer` | Execution timeout in seconds (1–300). |
| `origin` | `:string` | Origin label for telemetry. |

### Return value

The response body contains: `success`, `stdout`, `result`, `stderr`, `exitCode`, `killed`, `output`, `liveViewUrl`, `interactiveLiveViewUrl`, `error`.

### Stop session

`Firecrawl.stop_interactive_scrape_browser_session(job_id, opts \\ [])`

### Standalone interact sessions

The Elixir SDK also supports standalone browser sessions (not tied to a scrape job):

- `Firecrawl.create_browser_session(params, opts)` — create a session
- `Firecrawl.execute_browser_code(session_id, params, opts)` — execute code
- `Firecrawl.delete_browser_session(session_id, opts)` — destroy the session
- `Firecrawl.list_browser_sessions(params, opts)` — list sessions

## Notes

- The Elixir SDK is auto-generated from the OpenAPI spec. Function names follow the OpenAPI operation IDs directly (e.g. `scrape_and_extract_from_url` instead of `scrape`).
- Every function has a bang (`!`) variant that raises on error instead of returning `{:error, ...}`.
- No deprecated aliases exist in the Elixir SDK.
- All functions accept trailing keyword opts for `:api_key`, `:base_url`, and pass-through `Req` options.
- A nil/empty API key is allowed (keyless free tier).
- Parameters are validated by NimbleOptions before the request is sent.
- Responses are raw `Req.Response` structs — access data via `response.body`.
