# Firecrawl Elixir Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl` **1.12.6** on Hex) and the v2 OpenAPI spec. Function names, parameters, and types match the public API surface of `Firecrawl` in `lib/firecrawl.ex`.

## Install

Add to `mix.exs`:

```elixir
{:firecrawl, "~> 1.12"}
```

## Authenticate

```elixir
# config/runtime.exs or config/config.exs
config :firecrawl, api_key: System.get_env("FIRECRAWL_API_KEY")

# or pass api_key per call
{:ok, res} = Firecrawl.search_and_scrape([query: "firecrawl webhooks"], api_key: "fc-your-api-key")
```

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions.

## Search

### Why use it

Use search to discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:`, for example `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK function

`Firecrawl.search_and_scrape(params \\ [], opts \\ [])` — returns `{:ok, result}` or `{:error, reason}`.

Bang variant: `Firecrawl.search_and_scrape!(params, opts)` raises on error.

### Example

```elixir
{:ok, res} = Firecrawl.search_and_scrape(
  query: "site:docs.firecrawl.dev crawl webhooks",
  sources: [:web, :news],
  categories: [:research],
  limit: 10,
  tbs: "qdr:m",
  location: "San Francisco,California,United States",
  ignore_invalid_urls: true,
  timeout: 60000,
  scrape_options: [
    formats: [
      "markdown",
      "links",
      %{type: "json", prompt: "Extract title and key endpoints."}
    ],
    only_main_content: true,
    include_tags: ["main", "article"],
    exclude_tags: ["nav", "footer"],
    wait_for: 1000
  ]
)
```

### Parameters

- `query`
  - Type: string (required)
  - Use when: you need a search query.
  - Notes: use `site:example.com` to limit results to a domain.

- `limit`
  - Type: integer
  - Use when: you want to cap results.

- `sources`
  - Type: list of atoms, strings, or maps
  - Use when: you want to control which sources are searched.
  - Confirmed values: `:web`, `:news`, `:images`, or `%{type: "web" | "news" | "images"}`

- `categories`
  - Type: list of atoms, strings, or maps
  - Use when: you want to filter results by category.
  - Confirmed values: `:developer`, `:research`, `:pdf`, or `%{type: "developer" | "research" | "pdf"}`

- `include_domains`
  - Type: list of strings
  - Use when: you want to restrict results to specific domains.

- `exclude_domains`
  - Type: list of strings
  - Use when: you want to exclude results from specific domains.

- `tbs`
  - Type: string
  - Use when: you need a time-based filter (for example `qdr:d`, `qdr:w`, `sbd:1,qdr:m`).

- `location`
  - Type: string
  - Use when: you want localized results.

- `country`
  - Type: string
  - Use when: you want ISO 3166-1 alpha-2 targeting (for example `"US"`).

- `highlights`
  - Type: boolean
  - Use when: you want query-relevant highlights in results. Defaults to true.

- `ignore_invalid_urls`
  - Type: boolean
  - Use when: you want to drop URLs that cannot be scraped by other endpoints.

- `safe`
  - Type: boolean
  - Use when: you want SafeSearch to filter explicit content.

- `timeout`
  - Type: integer
  - Use when: you need a request timeout in milliseconds.

- `enterprise`
  - Type: list of strings
  - Use when: you need enterprise search controls.
  - Confirmed values: `"zdr"` (zero data retention), `"anon"` (anonymized zero data retention)

- `scrape_options`
  - Type: keyword list
  - Use when: you want to scrape each search result (see Scrape parameters for fields).

- `threat_protection`
  - Type: keyword list
  - Use when: you need a per-request threat protection override.

- `domain_tools`
  - Type: boolean
  - Use when: you want tool contracts matched to result domains included in the response.

- `tool_detail`
  - Type: `:compact` | `:summary` | `:full`
  - Use when: you want to control how much detail tool contracts include.

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK function

`Firecrawl.scrape_and_extract_from_url(params \\ [], opts \\ [])` — returns `{:ok, result}` or `{:error, reason}`.

Bang variant: `Firecrawl.scrape_and_extract_from_url!(params, opts)` raises on error.

### Example

```elixir
{:ok, doc} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com/pricing",
  formats: [
    "markdown",
    "links",
    %{type: "json", prompt: "Extract plan names and prices."},
    %{type: "screenshot", fullPage: true, quality: 80}
  ],
  only_main_content: true,
  wait_for: 1000,
  actions: [
    %{type: "click", selector: "#accept"},
    %{type: "wait", milliseconds: 750},
    %{type: "scrape"}
  ],
  block_ads: true,
  proxy: :auto
)
```

### Parameters

- `url`
  - Type: string (required)
  - Use when: you want to scrape a specific page.

- `formats`
  - Type: list of format strings or format maps
  - Use when: you want multiple output formats.
  - Confirmed format strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"branding"`, `"audio"`, `"video"`
  - Format map fields:
    - `type`: one of the format strings above
    - `prompt`, `schema`: JSON extraction options for `type: "json"`
    - `modes`, `schema`, `prompt`, `tag`: change tracking options for `type: "changeTracking"`
    - `fullPage`, `quality`, `viewport`: screenshot options for `type: "screenshot"`

- `headers`
  - Type: map
  - Use when: you need custom request headers.

- `include_tags`
  - Type: list of strings
  - Use when: you want to include only specific HTML tags.

- `exclude_tags`
  - Type: list of strings
  - Use when: you want to exclude specific HTML tags.

- `only_main_content`
  - Type: boolean
  - Use when: you want to strip nav, footer, and other boilerplate.

- `only_clean_content`
  - Type: boolean
  - Use when: you want an extra LLM pass to remove residual boilerplate (beta).

- `timeout`
  - Type: integer
  - Use when: you need a timeout in milliseconds (min 1000, default 60000, max 300000).

- `wait_for`
  - Type: integer
  - Use when: you need to wait for the page to render (milliseconds).

- `mobile`
  - Type: boolean
  - Use when: you want a mobile viewport.

- `parsers`
  - Type: list of parser strings or maps
  - Use when: you need file parsing controls.
  - Confirmed values: `"pdf"`, `%{type: "pdf", mode: "fast" | "auto" | "ocr", maxPages: integer}`

- `actions`
  - Type: list of action maps
  - Use when: you need lightweight pre-scrape actions.
  - Confirmed action types: `wait` (`milliseconds` or `selector`), `screenshot`, `click` (`selector`, optional `all`), `write` (`text`), `press` (`key`), `scroll` (`direction`: `up`/`down`), `scrape`, `executeJavascript` (`script`), `pdf`

- `location`
  - Type: keyword list (for example `country: "US"`, `languages: ["en-US"]`)
  - Use when: you need geo or language-aware scraping.

- `skip_tls_verification`
  - Type: boolean
  - Use when: you need to skip TLS certificate verification.

- `remove_base64_images`
  - Type: boolean
  - Use when: you want to drop base64 images from markdown output.

- `block_ads`
  - Type: boolean
  - Use when: you want ad and cookie popup blocking.

- `proxy`
  - Type: atom or string
  - Use when: you need proxy control.
  - Confirmed values: `:basic`, `:enhanced`, `:auto`

- `max_age`
  - Type: integer
  - Use when: you want cached data up to a maximum age (milliseconds).

- `min_age`
  - Type: integer
  - Use when: you want cached data only if it is at least this old (milliseconds).

- `lockdown`
  - Type: boolean
  - Use when: you want to serve from cache only, never hitting the target URL.

- `store_in_cache`
  - Type: boolean
  - Use when: you want Firecrawl to cache the result.

- `profile`
  - Type: keyword list with `name:` and optional `save_changes:`
  - Use when: you want a persistent browser profile shared across scrapes and interactions.

- `zero_data_retention`
  - Type: boolean
  - Use when: you want zero data retention for this scrape.

- `check_prompt_injection`
  - Type: boolean
  - Use when: you want to scan for prompt injection before LLM formats run.

- `redact_pii`
  - Type: boolean or options
  - Use when: you want to redact personally identifiable information from output.

- `audit_metadata`
  - Type: keyword list
  - Use when: you need user attribution for SIEM logging.

- `threat_protection`
  - Type: keyword list
  - Use when: you need a per-request threat protection override.

- `domain_tools`
  - Type: boolean
  - Use when: you want tool contracts matched to the scraped domain.

- `tool_detail`
  - Type: `:compact` | `:summary` | `:full`
  - Use when: you want to control how much detail tool contracts include.

## Interact

### Why use it

Use interact when a page requires browser actions or code execution after a scrape starts. The Elixir SDK supports code-based interactions only (no `prompt` parameter).

### Preferred SDK function

`Firecrawl.interact_with_scrape_browser_session(job_id, params \\ [], opts \\ [])` — returns `{:ok, result}` or `{:error, reason}`.

Bang variant: `Firecrawl.interact_with_scrape_browser_session!(job_id, params, opts)` raises on error.

### Example

```elixir
{:ok, doc} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com",
  formats: ["markdown"]
)

job_id = get_in(doc, ["metadata", "scrapeId"])

{:ok, result} = Firecrawl.interact_with_scrape_browser_session(
  job_id,
  code: "console.log(await page.title());",
  language: :node,
  timeout: 60
)

# Stop the session when done
{:ok, _} = Firecrawl.stop_interactive_scrape_browser_session(job_id)
```

### Parameters

- `job_id`
  - Type: string (required, first positional argument)
  - Use when: you have a scrape job ID from the scrape response metadata.

- `code`
  - Type: string (required)
  - Use when: you want to run code in the browser session.

- `language`
  - Type: atom or string
  - Use when: you need a specific runtime.
  - Confirmed values: `:python`, `:node`, `:bash`

- `timeout`
  - Type: integer
  - Use when: you need an execution timeout in seconds.

- `origin`
  - Type: string
  - Use when: you want an optional origin label for execution telemetry.

### Stop session

`Firecrawl.stop_interactive_scrape_browser_session(job_id, opts \\ [])` ends the browser session. Bang variant also available.

## Notes

- The Elixir client is **auto-generated from the OpenAPI spec** via `generate.exs`. Function names map directly to OpenAPI operation IDs (for example `scrape_and_extract_from_url`, not just `scrape`).
- All parameters use **snake_case** keyword lists; they are converted to camelCase JSON internally.
- Uses `NimbleOptions` for validation — invalid parameters are caught before the request.
- Every function has a bang (`!`) variant that raises on error instead of returning `{:error, _}`.
- The SDK sends an `origin` header (`elixir-sdk@{version}`) automatically for SDK identification.
- This SDK exposes code-based interactions only: there is no `prompt` parameter on `interact_with_scrape_browser_session` (unlike the Node.js and Python SDKs).
- Standalone browser sessions are also available via `Firecrawl.create_browser_session/2`, `Firecrawl.execute_browser_code/3`, `Firecrawl.delete_browser_session/2`, and `Firecrawl.list_browser_sessions/2`.
