# Firecrawl Elixir Agent Quickstart

This file is the canonical quickstart for external agents building with Firecrawl in Elixir. It is generated from SDK source and the OpenAPI spec.

## Install

Add to your `mix.exs` dependencies:

```elixir
defp deps do
  [
    {:firecrawl, "~> 1.11"}
  ]
end
```

## Authenticate

Pass `api_key` as an option to any function call:

```elixir
Firecrawl.search_and_scrape([query: "firecrawl"], api_key: "fc-YOUR-API-KEY")
```

Or configure it application-wide in `config.exs`:

```elixir
config :firecrawl, api_key: "fc-YOUR-API-KEY"
```

The API key is optional — omitting it falls back to a keyless free tier (rate-limited per IP) for scrape, search, and interact.

### Common options (available on every function)

| Option | Type | Default | Description |
|---|---|---|---|
| `api_key` | `string` | `Application.get_env(:firecrawl, :api_key)` | API key. |
| `base_url` | `string` | `"https://api.firecrawl.dev/v2"` | API base URL. |

## When To Use What

- **`search_and_scrape`** — you start with a query and need to discover pages. Returns ranked web results with optional full-page scraping.
- **`scrape_and_extract_from_url`** — you already have a URL and want its content as markdown, HTML, JSON, or other formats.
- **`interact_with_scrape_browser_session`** — the page needs post-scrape browser actions: clicking buttons, filling forms, navigating, or extracting dynamic content.

## Search

### Why use it

Search the web with a query and get structured results. Optionally scrape each result page for full content in one call.

### Preferred SDK function

```
Firecrawl.search_and_scrape(params, opts)
```

Bang variant: `Firecrawl.search_and_scrape!(params, opts)`

### Example

```elixir
{:ok, %Req.Response{body: body}} =
  Firecrawl.search_and_scrape(
    [query: "firecrawl web scraping", limit: 5],
    api_key: "fc-YOUR-API-KEY"
  )

for result <- body["data"]["web"] do
  IO.puts("#{result["title"]} #{result["url"]}")
end
```

### Parameters

All parameters are passed as a keyword list (first argument). All optional except `query`.

| Parameter | Type | Description |
|---|---|---|
| `query` | `:string` | **Required.** The search query string. |
| `limit` | `:integer` | Max results to return. |
| `sources` | `list(any)` | Sources to search: `"web"`, `"news"`, `"images"`. Default: `["web"]`. |
| `categories` | `list(any)` | Category filters. |
| `include_domains` | `list(string)` | Restrict results to these domains. |
| `exclude_domains` | `list(string)` | Exclude results from these domains. |
| `tbs` | `:string` | Time-based search filter (e.g. `"qdr:d"`, `"sbd:1,qdr:w"`). |
| `location` | `:string` | Geo-target string (e.g. `"San Francisco,California,United States"`). |
| `country` | `:string` | ISO country code (e.g. `"US"`). |
| `timeout` | `:integer` | Timeout in milliseconds. |
| `highlights` | `:boolean` | Generate query-relevant highlights. Default: `true`. |
| `ignore_invalid_urls` | `:boolean` | Exclude invalid URLs from results. |
| `scrape_options` | `keyword` | Nested scrape options for each result page. |
| `enterprise` | `list(string)` | Enterprise options: `["zdr"]` or `["anon"]`. |

### Response

Returns `{:ok, %Req.Response{}}` with body containing:

- `data.web` — list of web results
- `data.news` — list of news results
- `data.images` — list of image results

## Scrape

### Why use it

Fetch a single URL and get its content as markdown, HTML, JSON extract, screenshot, or other formats.

### Preferred SDK function

```
Firecrawl.scrape_and_extract_from_url(params, opts)
```

Bang variant: `Firecrawl.scrape_and_extract_from_url!(params, opts)`

### Example

```elixir
{:ok, %Req.Response{body: body}} =
  Firecrawl.scrape_and_extract_from_url(
    [url: "https://example.com", formats: ["markdown"]],
    api_key: "fc-YOUR-API-KEY"
  )

IO.puts(body["data"]["markdown"])
```

### Parameters

All parameters are passed as a keyword list (first argument). All optional except `url`.

| Parameter | Type | Description |
|---|---|---|
| `url` | `:string` | **Required.** The URL to scrape. |
| `formats` | `list(any)` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"json"`, etc. |
| `headers` | `any` | Custom HTTP request headers (cookies, user-agent). |
| `include_tags` | `list(string)` | HTML tags to include exclusively. |
| `exclude_tags` | `list(string)` | HTML tags to exclude. |
| `only_main_content` | `:boolean` | Strip boilerplate (navbars, footers). |
| `timeout` | `:integer` | Timeout in milliseconds. Default: `60000`. Min: `1000`, max: `300000`. |
| `wait_for` | `:integer` | Wait time in ms before scraping. |
| `mobile` | `:boolean` | Emulate a mobile device. |
| `parsers` | `list(any)` | Parser configs (e.g. PDF). |
| `actions` | `list(any)` | Browser actions before content grab. |
| `location` | `keyword` | Proxy routing with `country` and `languages`. |
| `skip_tls_verification` | `:boolean` | Skip TLS certificate verification. |
| `remove_base64_images` | `:boolean` | Remove base64 images from output. |
| `block_ads` | `:boolean` | Block advertisements. |
| `proxy` | `:basic \| :enhanced \| :auto` | Proxy mode. |
| `max_age` | `:integer` | Use cached result if younger than this (ms). Default: 2 days. |
| `min_age` | `:integer` | Cache-only mode minimum age (ms). |
| `store_in_cache` | `:boolean` | Cache the scrape result. |
| `lockdown` | `:boolean` | Serve only cached results. |
| `redact_pii` | `:boolean` | Redact personally identifiable information. |
| `profile` | `keyword` | Persistent browser profile (`name`, `save_changes`). |
| `audit_metadata` | `keyword` | User attribution for SIEM logging (`username`). |
| `zero_data_retention` | `:boolean` | Enable ZDR for this scrape. |

## Interact

### Why use it

After scraping a page, interact with the live browser session — execute Playwright code to click buttons, fill forms, navigate, or extract dynamic content.

### Preferred SDK function

```
Firecrawl.interact_with_scrape_browser_session(job_id, params, opts)
```

Bang variant: `Firecrawl.interact_with_scrape_browser_session!(job_id, params, opts)`

To stop a session:

```
Firecrawl.stop_interactive_scrape_browser_session(job_id, opts)
```

### Example

```elixir
{:ok, %Req.Response{body: scrape_body}} =
  Firecrawl.scrape_and_extract_from_url(
    [url: "https://www.amazon.com", formats: ["markdown"]],
    api_key: "fc-YOUR-API-KEY"
  )

scrape_id = scrape_body["data"]["metadata"]["scrapeId"]

{:ok, %Req.Response{body: interact_body}} =
  Firecrawl.interact_with_scrape_browser_session(
    scrape_id,
    [code: ~s(await page.fill('input[name="field-keywords"]', 'iPhone 16 Pro Max'))],
    api_key: "fc-YOUR-API-KEY"
  )

IO.puts(interact_body["stdout"])

Firecrawl.stop_interactive_scrape_browser_session(
  scrape_id,
  api_key: "fc-YOUR-API-KEY"
)
```

### Parameters

`job_id` is the first positional argument (string). Parameters are passed as a keyword list (second argument).

| Parameter | Type | Description |
|---|---|---|
| `code` | `:string` | **Required.** Code to execute in the browser sandbox. |
| `language` | `:python \| :node \| :bash` | Execution language. Default: `:node`. |
| `timeout` | `:integer` | Execution timeout in seconds (1–300). Default: `30`. |
| `origin` | `:string` | Request attribution label. |

### Response

Returns `{:ok, %Req.Response{}}` with body containing:

- `success` — whether execution succeeded
- `stdout` / `result` — standard output from code execution
- `stderr` — standard error from code execution
- `exitCode` — process exit code
- `liveViewUrl` — read-only live view of the browser
- `interactiveLiveViewUrl` — interactive live view
- `killed` — whether the process was killed due to timeout
- `error` — error message if an exception was raised

## Notes

- **Naming style**: The Elixir SDK uses OpenAPI-generated function names. Functions use snake_case with descriptive names (e.g. `scrape_and_extract_from_url`, `search_and_scrape`, `interact_with_scrape_browser_session`).
- **Bang variants**: Every function has a `!` variant that raises on error instead of returning `{:error, ...}`.
- **Response format**: Functions return `{:ok, %Req.Response{}}` or `{:error, exception}`. The response body is a decoded JSON map.
- **Keyless mode**: `scrape`, `search`, and `interact` work without an API key at a rate-limited free tier.
- **Origin**: The SDK automatically injects `"elixir-sdk@{version}"` as the `origin` field in every request body.
