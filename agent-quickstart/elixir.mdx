# Firecrawl Elixir Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl` hex package) and the v2 OpenAPI spec. The Elixir SDK is auto-generated from the OpenAPI spec; function names are spec-derived, not idiomatic aliases.

## Install

Add to `mix.exs`:

```elixir
{:firecrawl, "~> 1.0"}
```

## Authenticate

```elixir
# config/runtime.exs or config.exs
config :firecrawl, api_key: System.get_env("FIRECRAWL_API_KEY")

# or pass api_key per call
{:ok, res} = Firecrawl.search_and_scrape([query: "firecrawl docs"], api_key: "fc-your-api-key")
```

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions.

## Search

### Why use it

Use search to discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:`, for example `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`Firecrawl.search_and_scrape(params \\ [], opts \\ [])`

### Example

```elixir
{:ok, res} = Firecrawl.search_and_scrape(
  query: "site:docs.firecrawl.dev webhook retries",
  limit: 5,
  scrape_options: [
    formats: ["markdown"],
    only_main_content: true
  ]
)
```

### Parameters

- `query` — string (required). The search query. Use `site:example.com` to limit results to a domain.
- `sources` — list of atoms, strings, or maps. Controls which sources are searched. Confirmed values: `:web`, `:news`, `:images`, `:alexandria`.
- `categories` — list of atoms, strings, or maps. Filters results by category. Confirmed values: `:developer`, `:research`, `:pdf`.
- `include_domains` — list of strings. Restrict results to specified domains. Mutually exclusive with `exclude_domains`.
- `exclude_domains` — list of strings. Exclude results from specified domains.
- `limit` — integer. Maximum number of results to return per source type.
- `tbs` — string. Time-based search filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week).
- `location` — string. Geographic location for localized results.
- `country` — string. ISO 3166-1 alpha-2 code for geo-targeting (e.g. `"US"`).
- `ignore_invalid_urls` — boolean. Drop URLs that cannot be scraped by other endpoints.
- `timeout` — integer. Request timeout in milliseconds.
- `highlights` — boolean. Generate query-relevant highlights from results.
- `safe` — boolean. Filter explicit content from results.
- `domain_tools` — boolean. Include tool contracts matched to result domains.
- `tool_detail` — `:compact`, `:summary`, or `:full`. Controls tool contract detail level.
- `enterprise` — list of strings. Enterprise search controls. Confirmed values: `"zdr"` (zero data retention), `"anon"` (anonymized).
- `threat_protection` — keyword list. Per-request threat protection override.
- `scrape_options` — keyword list. Options for scraping each search result (see Scrape parameters).

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK method

`Firecrawl.scrape_and_extract_from_url(params \\ [], opts \\ [])`

### Example

```elixir
{:ok, doc} = Firecrawl.scrape_and_extract_from_url(
  url: "https://docs.firecrawl.dev",
  formats: ["markdown"],
  only_main_content: true
)
```

### Parameters

- `url` — string (required). The URL to scrape.
- `formats` — list of format strings or format maps. Confirmed string values: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"audio"`, `"video"`. Object-only formats: `%{type: "json", prompt: "..."}`, `%{type: "screenshot", fullPage: true}`, `%{type: "changeTracking", modes: ["git-diff"]}`, `%{type: "attributes", selectors: [%{selector: "a", attribute: "href"}]}`.
- `headers` — map. Custom HTTP request headers.
- `include_tags` — list of strings. HTML tags to include in output.
- `exclude_tags` — list of strings. HTML tags to exclude from output.
- `only_main_content` — boolean. Strip nav, footer, and other boilerplate.
- `only_clean_content` — boolean. LLM-based boilerplate removal.
- `timeout` — integer. Request timeout in milliseconds.
- `wait_for` — integer. Wait for page to render (milliseconds).
- `mobile` — boolean. Emulate mobile viewport.
- `parsers` — list of parser strings or maps. File processing controls. Confirmed: `"pdf"`, `%{type: "pdf", mode: "fast" | "auto" | "ocr", maxPages: integer}`.
- `actions` — list of action maps. Browser actions before scraping. Confirmed types: `wait` (`milliseconds` or `selector`), `click` (`selector`, optional `all`), `write` (`text`), `press` (`key`), `scroll` (`direction`: `"up"` or `"down"`, optional `selector`), `screenshot`, `scrape`, `executeJavascript` (`script`), `pdf` (`format`, `landscape`, `scale`).
- `location` — keyword list. Geo or language-aware scraping. Keys: `country:`, `languages:`.
- `skip_tls_verification` — boolean. Skip TLS certificate verification.
- `remove_base64_images` — boolean. Remove base64 images from markdown output.
- `block_ads` — boolean. Enable ad-blocking and cookie popup blocking.
- `proxy` — atom or string. Proxy control. Confirmed values: `:basic`, `:enhanced`, `:auto`.
- `max_age` — integer. Cache age limit in milliseconds.
- `min_age` — integer. Minimum cache age in milliseconds.
- `store_in_cache` — boolean. Store result in Firecrawl cache.
- `lockdown` — boolean. Serve only previously cached results.
- `check_prompt_injection` — boolean. Scan scraped content for prompt injection attempts.
- `redact_pii` — any. Redact personally identifiable information from markdown.
- `audit_metadata` — keyword list. User attribution for SIEM logging. Keys: `username:`.
- `profile` — keyword list. Persistent browser profile. Keys: `name:`, `save_changes:`.
- `zero_data_retention` — boolean. Enable zero data retention for this scrape.
- `domain_tools` — boolean. List tool contracts matched to scraped domain.
- `threat_protection` — keyword list. Per-request threat protection override.

## Interact

### Why use it

Use `interact` for code-based control of the browser session tied to a scrape job. The Elixir SDK supports code execution only (no `prompt` parameter). Get the job ID from the scrape response metadata.

### Preferred SDK method

`Firecrawl.interact_with_scrape_browser_session(job_id, params \\ [], opts \\ [])`

### Example

```elixir
{:ok, doc} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com",
  formats: ["markdown"]
)

job_id = get_in(doc, ["metadata", "scrapeId"])

{:ok, result} = Firecrawl.interact_with_scrape_browser_session(
  job_id,
  code: "console.log(await page.title());",
  language: :node,
  timeout: 60
)

# Stop the session when done
{:ok, _} = Firecrawl.stop_interactive_scrape_browser_session(job_id)
```

### Parameters

- `job_id` — string (required, first positional argument). The scrape job ID from the scrape response metadata.
- `code` — string (required). Code to execute in the browser session.
- `language` — atom or string. Runtime language. Confirmed values: `:python`, `:node`, `:bash`.
- `timeout` — integer. Execution timeout in seconds.
- `origin` — string. Optional origin label for execution telemetry.

## Notes

- The Elixir SDK is auto-generated from the OpenAPI spec via `generate.exs`. Function names are spec-derived, not idiomatic aliases.
- Every public function has a bang (`!`) variant (e.g. `search_and_scrape!`) that raises on error instead of returning `{:error, _}`.
- This SDK exposes code-based interactions only: there is no `prompt` parameter on `interact_with_scrape_browser_session`.
- All parameters use snake_case keyword lists in Elixir; they are automatically mapped to camelCase JSON keys via internal key mappings.
- The `origin` header is automatically set to `"elixir-sdk@<version>"` on every request body.
- A nil or empty API key falls back to the keyless free tier (rate-limited per IP) for scrape, search, and interact.
