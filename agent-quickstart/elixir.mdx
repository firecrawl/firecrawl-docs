# Firecrawl Elixir Agent Quickstart

This file is the canonical quickstart for external agents using the Firecrawl Elixir SDK. It is generated from SDK source and OpenAPI spec. The Elixir SDK is auto-generated from the OpenAPI definition, so function names map directly to API operation IDs.

## Install

```bash
mix deps.get
```

Add to `mix.exs`:

```elixir
defp deps do
  [
    {:firecrawl, "~> 0.1"}
  ]
end
```

## Authenticate

Configure the API key globally or per-call:

```elixir
# In config/config.exs or config/runtime.exs:
config :firecrawl, api_key: "fc-YOUR_API_KEY"

# Or pass per-call:
Firecrawl.search_and_scrape([query: "firecrawl"], api_key: "fc-YOUR_API_KEY")
```

Omitting the API key enables the keyless free tier (rate-limited per IP).

You can also override the base URL for self-hosted instances:

```elixir
config :firecrawl, base_url: "https://your-instance.example.com/v2"
```

## When To Use What

- **search** (`Firecrawl.search_and_scrape/2`): Use when you start with a query and need to discover relevant pages. Returns search results with optional scraping of each result.
- **scrape** (`Firecrawl.scrape_and_extract_from_url/2`): Use when you already have a URL and want its content as markdown, HTML, structured JSON, or other formats.
- **interact** (`Firecrawl.interact_with_scrape_browser_session/3`): Use when the page needs clicks, form fills, or post-scrape browser actions. Requires a prior scrape job ID.

## Search

### Why use it

Search discovers pages matching a query across web, news, images, and Alexandria tool sources. Optionally scrapes each result so you get content in a single call.

### Preferred SDK method

```elixir
Firecrawl.search_and_scrape(params, opts \\ [])
Firecrawl.search_and_scrape!(params, opts \\ [])  # raises on error
```

### Example

```elixir
{:ok, results} = Firecrawl.search_and_scrape(
  query: "web scraping best practices",
  limit: 5,
  scrape_options: [formats: ["markdown"]]
)
```

### Parameters

All parameters are passed as a keyword list. Snake_case keys are auto-converted to camelCase JSON.

- **`query`** (string, required) — The search query.
- **`limit`** (integer) — Maximum number of results to return per source type.
- **`sources`** (list) — Sources to search. Values: `"web"`, `"news"`, `"images"`, `"alexandria"`. Defaults to `["web"]`.
- **`categories`** (list) — Filter results by category. Values: `"developer"`, `"gov"`, `"research"`, `"pdf"`.
- **`include_domains`** (list of strings) — Restrict results to these domains (hostnames only). Cannot combine with `exclude_domains`.
- **`exclude_domains`** (list of strings) — Exclude results from these domains. Cannot combine with `include_domains`.
- **`tbs`** (string) — Time-based search filter. Values: `"qdr:h"` (past hour), `"qdr:d"` (past day), `"qdr:w"` (past week), `"qdr:m"` (past month), `"qdr:y"` (past year), `"sbd:1"` (sort by date), or custom date ranges.
- **`location`** (string) — Location string for geo-targeting (e.g. `"San Francisco,California,United States"`).
- **`country`** (string) — ISO 3166-1 alpha-2 country code for geo-targeting (e.g. `"US"`).
- **`timeout`** (integer) — Timeout in milliseconds.
- **`highlights`** (boolean) — Generate query-relevant highlights for search results.
- **`safe`** (boolean) — SafeSearch filter for explicit content.
- **`ignore_invalid_urls`** (boolean) — Exclude invalid URLs from results.
- **`scrape_options`** (keyword list) — Options for scraping each result page. Accepts the same parameters as the scrape endpoint.
- **`enterprise`** (list of strings) — Enterprise search options. Values: `"zdr"` (Zero Data Retention), `"anon"` (anonymized).
- **`threat_protection`** (keyword list) — Per-request Threat Protection override.
- **`domain_tools`** (boolean) — Include tool contracts matching result domains. Free.
- **`tool_detail`** (atom or string) — How much of each tool contract to return. Values: `:compact`, `:summary`, `:full`.

## Scrape

### Why use it

Scrape fetches a single URL and returns its content in one or more formats: markdown, HTML, structured JSON, screenshots, and more. Use it when you already have the URL.

### Preferred SDK method

```elixir
Firecrawl.scrape_and_extract_from_url(params, opts \\ [])
Firecrawl.scrape_and_extract_from_url!(params, opts \\ [])  # raises on error
```

### Example

```elixir
{:ok, doc} = Firecrawl.scrape_and_extract_from_url(
  url: "https://docs.firecrawl.dev/introduction",
  formats: ["markdown", "links"],
  only_main_content: true
)

IO.puts(doc["data"]["markdown"])
```

### Parameters

All parameters are passed as a keyword list.

- **`url`** (string, required) — The URL to scrape.
- **`formats`** (list) — Output formats. Values: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"json"`, `"changeTracking"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`, `"question"`, `"highlights"`. Defaults to `["markdown"]`.
- **`only_main_content`** (boolean) — Only return main content, excluding headers, navs, footers.
- **`only_clean_content`** (boolean) — Beta. Additional LLM-based pass to remove residual boilerplate.
- **`include_tags`** (list of strings) — HTML tags to include in output.
- **`exclude_tags`** (list of strings) — HTML tags to exclude from output.
- **`headers`** (map/keyword list) — Custom HTTP headers to send with the request (cookies, user-agent, etc.).
- **`timeout`** (integer) — Timeout in milliseconds. Min 1000, default 60000, max 300000.
- **`wait_for`** (integer) — Delay in milliseconds before fetching content.
- **`mobile`** (boolean) — Emulate a mobile device.
- **`actions`** (list) — Browser actions to perform before grabbing content. Types: `"wait"`, `"screenshot"`, `"click"`, `"write"`, `"press"`, `"scroll"`, `"scrape"`, `"executeJavascript"`, `"pdf"`.
- **`location`** (keyword list) — Location settings. Keys: `country` (ISO alpha-2), `languages` (list).
- **`parsers`** (list) — Controls file processing. Values: `"pdf"`, `"image"`, or config objects with options.
- **`block_ads`** (boolean) — Enable ad-blocking and cookie popup blocking.
- **`proxy`** (atom or string) — Proxy type. Values: `:basic`, `:enhanced`, `:auto`, or a custom string. `auto` retries with enhanced if basic fails.
- **`remove_base64_images`** (boolean) — Remove base64 images from markdown output.
- **`skip_tls_verification`** (boolean) — Skip TLS certificate verification.
- **`max_age`** (integer) — Max cache age in milliseconds. Defaults to 2 days. Set to 0 to bypass cache.
- **`min_age`** (integer) — Cache-only mode. Minimum age of cached data in milliseconds. Set to 1 for any cached data.
- **`store_in_cache`** (boolean) — Store page in Firecrawl index and cache.
- **`lockdown`** (boolean) — Serve from cache only, never make outbound request.
- **`check_prompt_injection`** (boolean) — Scan page for prompt injection before LLM-backed formats. Adds 4 credits.
- **`redact_pii`** (boolean or keyword list) — Redact PII from returned markdown. Pass `true` for defaults or a keyword list with keys: `mode` (`"accurate"`, `"aggressive"`, `"fast"`), `entities`, `replace_style`.
- **`zero_data_retention`** (boolean) — Enable zero data retention for this scrape.
- **`profile`** (keyword list) — Persistent browser storage. Keys: `name` (string, required), `save_changes` (boolean).
- **`audit_metadata`** (keyword list) — User attribution for SIEM logging. Keys: `username` (required).
- **`threat_protection`** (keyword list) — Per-request Threat Protection override.
- **`alexandria`** (map or list) — Execute catalogued provider tools instead of scraping a URL. Cannot combine with URL scrape options.
- **`domain_tools`** (boolean) — List tool contracts matched to the scraped page's domain. Free.

## Interact

### Why use it

Interact lets you run code or natural-language prompts in the browser session from a prior scrape. Use it when the page needs clicks, form fills, JavaScript execution, or multi-step browser automation after the initial scrape.

### Preferred SDK method

```elixir
Firecrawl.interact_with_scrape_browser_session(job_id, params, opts \\ [])
Firecrawl.interact_with_scrape_browser_session!(job_id, params, opts \\ [])  # raises on error
```

To stop the session:

```elixir
Firecrawl.stop_interactive_scrape_browser_session(job_id, opts \\ [])
```

### Example

```elixir
# First, scrape a page to get a job ID
{:ok, doc} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com/login",
  formats: ["markdown"]
)

job_id = doc["data"]["metadata"]["jobId"]

# Execute code in the browser session
{:ok, result} = Firecrawl.interact_with_scrape_browser_session(
  job_id,
  code: """
  await page.fill('#username', 'demo');
  await page.fill('#password', 'password');
  await page.click('#login-button');
  await page.waitForNavigation();
  const content = await page.content();
  console.log(content);
  """,
  language: "node",
  timeout: 60
)

IO.puts(result["stdout"])

# Stop the browser session when done
Firecrawl.stop_interactive_scrape_browser_session(job_id)
```

### Parameters

The `job_id` is the first positional argument. All other parameters are passed as a keyword list.

- **`job_id`** (string, required) — The scrape job ID (first positional argument, not in the keyword list).
- **`code`** (string, required) — Code to execute in the browser sandbox.
- **`language`** (atom or string) — Language of the code. Values: `:python`, `:node`, `:bash`. Default: `"node"`. Use `"bash"` for agent-browser CLI commands.
- **`timeout`** (integer) — Execution timeout in seconds (1–300).
- **`origin`** (string) — Origin label for execution telemetry.

### Standalone Interact Sessions

The Elixir SDK also supports standalone interact sessions (not bound to a scrape):

```elixir
# Create a standalone browser session
{:ok, session} = Firecrawl.create_browser_session(
  ttl: 300,
  block_ads: true,
  location: [country: "US"]
)

session_id = session["id"]

# Execute code in the session
{:ok, result} = Firecrawl.execute_browser_code(
  session_id,
  code: "await page.goto('https://example.com'); console.log(await page.title());",
  language: "node"
)

# List active sessions
{:ok, sessions} = Firecrawl.list_browser_sessions(status: "active")

# Delete the session
Firecrawl.delete_browser_session(session_id)
```

Standalone session parameters for `create_browser_session/2`:

- **`ttl`** (integer) — Total time-to-live in seconds (30–3600). Default: 300.
- **`activity_ttl`** (integer) — Inactivity timeout in seconds (10–3600).
- **`stream_web_view`** (boolean) — Stream a live view of the browser. Default: true.
- **`block_ads`** (boolean) — Enable ad and cookie popup blocking. Default: true.
- **`profile`** (keyword list) — Persistent storage. Keys: `name` (required), `save_changes` (boolean).
- **`location`** (keyword list) — Country the session browses from. Keys: `country` (ISO alpha-2).

## Notes

- The Elixir SDK is **auto-generated from the OpenAPI spec** via `generate.exs`. Function names map directly to API operation IDs and are intentionally verbose (e.g. `scrape_and_extract_from_url` rather than `scrape`).
- All parameter names use **snake_case** in Elixir keyword lists. The SDK auto-converts to camelCase JSON when sending requests.
- Every function has a **bang variant** (e.g. `search_and_scrape!`) that raises on error instead of returning `{:error, ...}`.
- There are **no deprecated aliases** in the Elixir SDK.
- Per-call options (`opts`) accept `:api_key` and `:base_url` to override global config, plus any additional options passed through to the underlying `Req` HTTP client.
- The SDK ships its own `Firecrawl.ApiOrigin` module that auto-tags each request with `"elixir-sdk@VERSION"` as the origin.
