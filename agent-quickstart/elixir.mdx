# Firecrawl Elixir Agent Quickstart

Canonical quickstart for external agents. Generated from Elixir SDK source (`firecrawl` **1.12.6** on Hex) and the v2 OpenAPI spec. The Elixir SDK is auto-generated from the OpenAPI spec, so function names match operation IDs and parameters use snake_case (mapped to camelCase for the JSON body). Every public function has a bang (`!`) variant that raises on error instead of returning `{:error, _}`.

## Install

Add to `mix.exs`:

```elixir
{:firecrawl, "~> 1.12"}
```

## Authenticate

```elixir
# config/runtime.exs or config.exs
config :firecrawl, api_key: System.get_env("FIRECRAWL_API_KEY")

# or pass api_key per call
{:ok, res} = Firecrawl.search_and_scrape([query: "firecrawl webhooks"], api_key: "fc-your-api-key")
```

A nil or empty key is allowed for the keyless free tier (rate-limited per IP).

All functions accept an optional keyword list as the last argument with:
- `:api_key` — override the configured API key
- `:base_url` — override the default API base URL (useful for self-hosted)

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions.

## Search

### Why use it

Use search to discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:`, for example `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`Firecrawl.search_and_scrape(params \\ [], opts \\ [])` &rarr; `{:ok, response}` or `{:error, error}`

Bang variant: `Firecrawl.search_and_scrape!(params, opts)`

### Example

```elixir
{:ok, res} = Firecrawl.search_and_scrape(query: "site:docs.firecrawl.dev webhook retries")
```

### Complex Example

```elixir
{:ok, res} = Firecrawl.search_and_scrape(
  query: "site:docs.firecrawl.dev crawl webhooks",
  sources: [:web, :news],
  categories: [:research],
  limit: 10,
  tbs: "qdr:m",
  location: "San Francisco,California,United States",
  country: "US",
  ignore_invalid_urls: true,
  timeout: 60000,
  scrape_options: [
    formats: [
      "markdown",
      "links",
      %{type: "json", prompt: "Extract title and key endpoints."}
    ],
    only_main_content: true,
    include_tags: ["main", "article"],
    exclude_tags: ["nav", "footer"],
    wait_for: 1000
  ]
)
```

### Parameters

- `query`
  - Type: string
  - Use when: you need a search query. Use `site:example.com` to limit results to a domain.

- `limit`
  - Type: integer
  - Use when: you want to cap results per source type.

- `sources`
  - Type: list of atoms, strings, or maps
  - Use when: you want to control which sources are searched.
  - Confirmed values: `:web`, `:news`, `:images`, `:alexandria`, or `%{type: "web"}` map form.

- `categories`
  - Type: list of atoms, strings, or maps
  - Use when: you want to filter results by category.
  - Confirmed values: `:developer`, `:gov`, `:research`, `:pdf`, or `%{type: "developer"}` map form.

- `include_domains`
  - Type: list of strings
  - Use when: you want to restrict results to specific domains. Cannot combine with `exclude_domains`.

- `exclude_domains`
  - Type: list of strings
  - Use when: you want to exclude specific domains from results. Cannot combine with `include_domains`.

- `tbs`
  - Type: string
  - Use when: you need a time-based filter (for example `qdr:d`, `qdr:w`, `sbd:1,qdr:m`).

- `location`
  - Type: string
  - Use when: you want localized results (for example `"San Francisco,California,United States"`).

- `country`
  - Type: string
  - Use when: you want ISO 3166-1 alpha-2 geo-targeting (for example `"US"`).

- `safe`
  - Type: boolean
  - Use when: you want to filter explicit content (SafeSearch).

- `highlights`
  - Type: boolean
  - Use when: you want query-relevant highlights in results. Defaults to true.

- `ignore_invalid_urls`
  - Type: boolean
  - Use when: you want to drop URLs that cannot be scraped by other endpoints.

- `timeout`
  - Type: integer
  - Use when: you need a request timeout in milliseconds.

- `domain_tools`
  - Type: boolean
  - Use when: you want tool contracts matching domains of returned web results.

- `tool_detail`
  - Type: `:compact`, `:summary`, or `:full`
  - Use when: you want to control how much of each tool contract is returned.

- `enterprise`
  - Type: list of strings
  - Use when: you need enterprise Zero Data Retention.
  - Confirmed values: `"zdr"`, `"anon"`.

- `threat_protection`
  - Type: keyword list
  - Use when: you need per-request Threat Protection overrides (enterprise).

- `scrape_options`
  - Type: keyword list
  - Use when: you want to scrape each search result (see Scrape parameters for fields).

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK method

`Firecrawl.scrape_and_extract_from_url(params \\ [], opts \\ [])` &rarr; `{:ok, response}` or `{:error, error}`

Bang variant: `Firecrawl.scrape_and_extract_from_url!(params, opts)`

### Example

```elixir
{:ok, res} = Firecrawl.scrape_and_extract_from_url(
  url: "https://docs.firecrawl.dev",
  formats: ["markdown"]
)
```

### Complex Example

```elixir
{:ok, res} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com/pricing",
  formats: [
    "markdown",
    "links",
    %{type: "json", prompt: "Extract plan names and prices."},
    %{type: "screenshot", fullPage: true, quality: 80, viewport: %{width: 1280, height: 720}},
    %{type: "changeTracking", modes: ["git-diff"], tag: "pricing"}
  ],
  headers: %{"User-Agent" => "FirecrawlDocsBot/1.0"},
  only_main_content: true,
  wait_for: 1000,
  parsers: [%{type: "pdf", mode: "auto", maxPages: 5}],
  actions: [
    %{type: "click", selector: "#accept"},
    %{type: "wait", milliseconds: 750},
    %{type: "scrape"}
  ],
  location: [country: "US", languages: ["en-US"]],
  remove_base64_images: true,
  block_ads: true,
  proxy: :auto,
  max_age: 86400000,
  store_in_cache: true,
  profile: [name: "docs-session", save_changes: true]
)
```

### Parameters

- `url`
  - Type: string
  - Use when: you want to scrape a specific page.

- `formats`
  - Type: list of format strings or format maps
  - Use when: you want multiple output formats.
  - Confirmed format strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"audio"`, `"video"`.
  - Format map fields: `type` plus format-specific options (`prompt`/`schema` for json, `modes`/`tag` for changeTracking, `fullPage`/`quality`/`viewport` for screenshot, `selectors` for attributes).

- `headers`
  - Type: map
  - Use when: you need custom request headers.

- `include_tags`
  - Type: list of strings
  - Use when: you want to include only specific HTML tags.

- `exclude_tags`
  - Type: list of strings
  - Use when: you want to exclude specific HTML tags.

- `only_main_content`
  - Type: boolean
  - Use when: you want to strip nav, footer, and other boilerplate.

- `only_clean_content`
  - Type: boolean
  - Use when: you want an additional LLM-based pass to remove residual boilerplate (beta).

- `timeout`
  - Type: integer
  - Use when: you need a timeout in milliseconds. Min 1000, default 60000, max 300000.

- `wait_for`
  - Type: integer
  - Use when: you need to wait for the page to render (milliseconds).

- `mobile`
  - Type: boolean
  - Use when: you want a mobile viewport.

- `parsers`
  - Type: list of parser strings or maps
  - Use when: you need file parsing controls.
  - Confirmed values: `"pdf"`, `"image"`, `%{type: "pdf", mode: "fast" | "auto" | "ocr", maxPages: integer}`.

- `actions`
  - Type: list of action maps
  - Use when: you need browser actions before scraping.
  - Confirmed action types: `wait`, `screenshot`, `click`, `write`, `press`, `scroll`, `scrape`, `executeJavascript`, `pdf`.

- `location`
  - Type: keyword list with `country:` and `languages:`
  - Use when: you need geo or language-aware scraping.

- `skip_tls_verification`
  - Type: boolean
  - Use when: you need to skip TLS verification.

- `remove_base64_images`
  - Type: boolean
  - Use when: you want to drop base64 images from markdown output.

- `block_ads`
  - Type: boolean
  - Use when: you want ad and cookie popup blocking.

- `proxy`
  - Type: atom or string
  - Use when: you need proxy control.
  - Confirmed values: `:basic`, `:enhanced`, `:auto`.

- `max_age`
  - Type: integer
  - Use when: you want cached data up to a maximum age (milliseconds). Default is 2 days.

- `min_age`
  - Type: integer
  - Use when: you want cache-only mode with a minimum age in milliseconds. Set `1` to accept any cached data.

- `store_in_cache`
  - Type: boolean
  - Use when: you want Firecrawl to cache the result.

- `lockdown`
  - Type: boolean
  - Use when: you want to serve from cache only, never making an outbound request.

- `check_prompt_injection`
  - Type: boolean
  - Use when: you want to scan for prompt injection before LLM-backed formats run. Adds 4 credits.

- `redact_pii`
  - Type: boolean or map
  - Use when: you want to redact personally identifiable information from markdown.

- `profile`
  - Type: keyword list with `name:` and optional `save_changes:`
  - Use when: you want a persistent browser profile shared across scrapes and interactions.

- `zero_data_retention`
  - Type: boolean
  - Use when: you want zero data retention for this scrape.

- `audit_metadata`
  - Type: keyword list with `username:` required
  - Use when: you need user attribution for SIEM logging.

- `threat_protection`
  - Type: keyword list
  - Use when: you need per-request Threat Protection overrides (enterprise).

- `alexandria`
  - Type: map or list
  - Use when: you want to execute catalogued provider tools instead of scraping. Cannot combine with URL scrape options.

- `domain_tools`
  - Type: boolean
  - Use when: you want tool contracts matched to the scraped page's domain.

- `tool_detail`
  - Type: `:compact`, `:summary`, or `:full`
  - Use when: you want to control how much of each tool contract is returned.

## Interact

### Why use it

Use interact when a page requires browser actions or code execution after a scrape starts. The Elixir SDK supports code-based interactions only (no `prompt` parameter).

### Preferred SDK method (scrape-bound)

`Firecrawl.interact_with_scrape_browser_session(job_id, params \\ [], opts \\ [])` &rarr; `{:ok, response}` or `{:error, error}`

Bang variant: `Firecrawl.interact_with_scrape_browser_session!(job_id, params, opts)`

### Example

```elixir
{:ok, scrape_res} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com",
  formats: ["markdown"]
)

job_id = get_in(scrape_res, ["metadata", "scrapeId"])

{:ok, result} = Firecrawl.interact_with_scrape_browser_session(
  job_id,
  code: "console.log(await page.title());",
  language: :node,
  timeout: 60
)
```

### Standalone interact

For sessions not bound to a scrape job, use `create_browser_session` then `execute_browser_code`:

```elixir
{:ok, session} = Firecrawl.create_browser_session(
  ttl: 300,
  block_ads: true,
  location: [country: "US"]
)

session_id = session["id"]

{:ok, result} = Firecrawl.execute_browser_code(
  session_id,
  code: "console.log(await page.title());",
  language: :node,
  timeout: 60
)

# Clean up
{:ok, _} = Firecrawl.delete_browser_session(session_id)
```

### Parameters (scrape-bound interact)

- `job_id`
  - Type: string (path parameter)
  - Use when: you have a scrape job ID from a prior scrape.

- `code`
  - Type: string
  - Use when: you want to run code in the browser session.

- `language`
  - Type: `:python`, `:node`, or `:bash` (or string equivalents)
  - Use when: you need a specific runtime. Defaults to `:node`.

- `timeout`
  - Type: integer
  - Use when: you need an execution timeout in seconds.

- `origin`
  - Type: string
  - Use when: you want an optional origin label for execution telemetry.

### Parameters (standalone session creation)

- `ttl`
  - Type: integer
  - Use when: you need a total time-to-live in seconds (min 30, max 3600, default 300).

- `activity_ttl`
  - Type: integer
  - Use when: you want the session destroyed after inactivity (min 10, max 3600).

- `block_ads`
  - Type: boolean
  - Use when: you want ad and cookie popup blocking.

- `location`
  - Type: keyword list with `country:` required
  - Use when: you want to set the country the session browses from. Defaults to US.

- `profile`
  - Type: keyword list
  - Use when: you want persistent storage across interact sessions.

- `stream_web_view`
  - Type: boolean
  - Use when: you want to stream a live view of the browser. Defaults to true.

### Stop session

Scrape-bound: `Firecrawl.stop_interactive_scrape_browser_session(job_id, opts \\ [])`

Standalone: `Firecrawl.delete_browser_session(session_id, opts \\ [])`

```elixir
{:ok, _} = Firecrawl.stop_interactive_scrape_browser_session(job_id)
```

## Notes

- The Elixir client is auto-generated from the OpenAPI spec. Function names match operation IDs (for example `scrape_and_extract_from_url` rather than `scrape`).
- All parameter names use snake_case (Elixir convention); they are mapped to camelCase for the JSON body.
- Each public function has a bang (`!`) variant that raises on error instead of returning `{:error, _}`.
- Deprecated: `search_github/2` &rarr; use `search_developer/2` instead. `search_github` stops responding after 2026-11-03.
- The SDK also provides `list_browser_sessions/2` to list active or destroyed standalone interact sessions.
