# Firecrawl Elixir Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl` hex package) and the v2 OpenAPI spec. Function names are OpenAPI-generated and match the SDK public surface exactly.

## Install

Add to `mix.exs`:

```elixir
{:firecrawl, "~> 1.0.0"}
```

## Authenticate

```elixir
# config/runtime.exs or config.exs
config :firecrawl, api_key: System.get_env("FIRECRAWL_API_KEY")

# or pass api_key per call
{:ok, res} = Firecrawl.search_and_scrape([query: "example"], api_key: "fc-your-api-key")
```

## When To Use What

- `search`: use when you start with a query and need discovery. Returns web, news, and image results.
- `scrape`: use when you already have a URL and want page content in one or more formats.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions. Requires a scrape job ID from a prior scrape.

## Search

### Why use it

Discover relevant pages from a query, then pick URLs to scrape or interact with. Use `site:example.com` to constrain results to a single domain.

### Preferred SDK method

`Firecrawl.search_and_scrape(params \\ [], opts \\ [])`

### Example

```elixir
{:ok, res} = Firecrawl.search_and_scrape(
  query: "site:docs.firecrawl.dev crawl webhooks",
  sources: [:web],
  limit: 5,
  scrape_options: [
    formats: ["markdown"],
    only_main_content: true
  ]
)
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `query` | string | Search query. Use `site:domain` to scope. | Always required. |
| `sources` | list | `:web`, `:news`, `:images` (atoms or strings), or maps `%{type: "web"}`. | Control result buckets. |
| `categories` | list | `:developer`, `:research`, `:pdf` (atoms or strings), or maps. | Filter by category. |
| `limit` | integer | Maximum number of results. | Cap result count. |
| `tbs` | string | Time-based filter (e.g. `"qdr:d"`). | Filter by recency. |
| `location` | string | Localized results string. | Geo-targeted search. |
| `country` | string | ISO 3166-1 alpha-2 country code. | Country-level targeting. |
| `ignore_invalid_urls` | boolean | Drop URLs that cannot be scraped. | Clean up results. |
| `timeout` | integer | Request timeout in milliseconds. | Long-running searches. |
| `enterprise` | list | Enterprise controls: `"zdr"` (zero data retention), `"anon"` (anonymized). | Enterprise compliance. |
| `scrape_options` | keyword list | Scrape each search result (same fields as scrape params). | Hydrate search hits with content. |

## Scrape

### Why use it

Fetch structured content from a known URL in one or more formats (markdown, HTML, JSON extraction, screenshots, etc.).

### Preferred SDK method

`Firecrawl.scrape_and_extract_from_url(params \\ [], opts \\ [])`

### Example

```elixir
{:ok, res} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com/pricing",
  formats: [
    "markdown",
    %{type: "json", prompt: "Extract plan names and prices."}
  ],
  only_main_content: true,
  wait_for: 1000
)
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `url` | string | Page URL to scrape. | Always required. |
| `formats` | list | Format strings or maps. Strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"branding"`, `"audio"`, `"video"`. Map forms: `%{type: "json", prompt: ...}`, `%{type: "screenshot", fullPage: true}`, `%{type: "changeTracking", modes: ["git-diff"]}`. | Choose output formats. |
| `headers` | map | Custom HTTP headers. | Auth or custom user-agent. |
| `include_tags` | list | Only include these HTML tags. | Narrow content extraction. |
| `exclude_tags` | list | Exclude these HTML tags. | Remove boilerplate elements. |
| `only_main_content` | boolean | Strip nav, footer, and boilerplate. | Cleaner output. |
| `timeout` | integer | Timeout in milliseconds. | Long-loading pages. |
| `wait_for` | integer | Wait for page to render (ms). | JS-heavy pages. |
| `mobile` | boolean | Use mobile viewport. | Mobile-specific content. |
| `parsers` | list | Parser controls. E.g. `"pdf"` or `%{type: "pdf", mode: "auto", maxPages: 5}`. | PDF or file parsing. |
| `actions` | list | Pre-scrape browser actions as maps. Types: `wait`, `click`, `write`, `press`, `scroll`, `screenshot`, `scrape`, `executeJavascript`, `pdf`. | Cookie banners, login flows. |
| `location` | keyword list | `[country: "US", languages: ["en-US"]]` for geo-aware scraping. | Localized content. |
| `skip_tls_verification` | boolean | Skip TLS verification. | Self-signed certs. |
| `remove_base64_images` | boolean | Drop base64 images from markdown. | Reduce output size. |
| `block_ads` | boolean | Block ads and cookie popups. | Cleaner pages. |
| `proxy` | atom or string | `:basic`, `:enhanced`, `:auto`. | Geo-restricted or bot-protected sites. |
| `max_age` | integer | Use cached data up to this age (ms). | Reduce API calls. |
| `min_age` | integer | Cached data must be at least this old (ms). | Stale data preference. |
| `store_in_cache` | boolean | Cache the result. | Enable future cache hits. |
| `profile` | keyword list | `[name: "session", save_changes: true]` for persistent browser profile. | Maintain login state across scrapes. |
| `zero_data_retention` | boolean | Zero data retention for this scrape. | Data compliance. |

## Interact

### Why use it

Control the browser session tied to a scrape job. Use it for code execution in the browser. Requires a scrape job ID from a prior scrape.

### Preferred SDK method

`Firecrawl.interact_with_scrape_browser_session(job_id, params \\ [], opts \\ [])`

### Example

```elixir
{:ok, doc} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com",
  formats: ["markdown"]
)
job_id = get_in(doc, ["metadata", "scrapeId"])

{:ok, result} = Firecrawl.interact_with_scrape_browser_session(
  job_id,
  code: "console.log(await page.title());",
  language: :node,
  timeout: 60
)

# When done, stop the session
{:ok, _} = Firecrawl.stop_interactive_scrape_browser_session(job_id)
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `job_id` | string | Scrape job ID. | Always required. |
| `code` | string | Code to run in the browser session. | Programmatic browser control. |
| `language` | atom or string | `:python`, `:node`, `:bash`. | Choose execution runtime. |
| `timeout` | integer | Execution timeout in seconds. | Long-running interactions. |
| `origin` | string | Optional origin label for telemetry. | Attribution. |

The Elixir SDK exposes code-based interactions only — there is no `prompt` parameter.

**Stop session:** `Firecrawl.stop_interactive_scrape_browser_session(job_id)` ends the browser session. A bang variant `stop_interactive_scrape_browser_session!/2` raises on error.

## Notes

- The Elixir client is OpenAPI-generated; function names are derived from the spec.
- Each public function has a bang (`!`) variant that raises on error instead of returning `{:error, _}`.
- Parameters use snake_case keyword lists, but some nested map keys use camelCase to match the API contract (e.g. `fullPage`, `maxPages`).
- This SDK exposes code-based interactions only (no `prompt` parameter on interact).
