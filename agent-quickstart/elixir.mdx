# Firecrawl Elixir Agent Quickstart

Canonical Firecrawl Elixir quickstart for agents. Generated from SDK source (`:firecrawl` **1.12.4**) and the v2 OpenAPI spec. Function names and parameters match the SDK public API.

The Elixir SDK is auto-generated from the OpenAPI spec. Function names are OpenAPI operation IDs converted to `snake_case`. Parameters are `snake_case` keyword lists validated by NimbleOptions before the HTTP request is made.

## Install

Add to `mix.exs`:

```elixir
defp deps do
  [
    {:firecrawl, "~> 1.12"}
  ]
end
```

Requires `req ~> 0.5` and `nimble_options ~> 1.1` (pulled as transitive deps).

## Authenticate

```elixir
# config/runtime.exs or config/config.exs
config :firecrawl, api_key: System.get_env("FIRECRAWL_API_KEY")
```

Or pass `api_key:` per request:

```elixir
{:ok, res} = Firecrawl.search_and_scrape(
  [query: "firecrawl webhooks"],
  api_key: "fc-your-api-key"
)
```

All functions accept `:api_key` and `:base_url` (default `https://api.firecrawl.dev/v2`) as trailing keyword options.

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions.

## Search

### Why use it

Use search to discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:`, for example `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK function

`Firecrawl.search_and_scrape(params \\ [], opts \\ [])` — returns `{:ok, %Req.Response{}}` or `{:error, exception}`.

Bang variant: `Firecrawl.search_and_scrape!(params \\ [], opts \\ [])` — raises on error.

### Example

```elixir
{:ok, res} = Firecrawl.search_and_scrape(
  query: "site:docs.firecrawl.dev webhook retries",
  limit: 5,
  sources: ["web", "news"],
  scrape_options: [formats: ["markdown"], only_main_content: true]
)

# res.body contains the parsed JSON response
web_results = res.body["data"]["web"]
```

### Parameters

All parameters are keyword list entries. Required parameters are marked.

- `query` (**required**)
  - Type: string
  - The search query. Use `site:example.com` to limit results to a domain.

- `limit`
  - Type: integer
  - Maximum number of results to return per source type.
  - JSON key: `limit`

- `sources`
  - Type: list of strings or maps
  - Which sources to search. Values: `"web"`, `"news"`, `"images"`, `"alexandria"`.
  - JSON key: `sources`

- `categories`
  - Type: list of strings or maps
  - Filter by category. Values: `"developer"`, `"gov"`, `"research"`, `"pdf"`.
  - JSON key: `categories`

- `include_domains`
  - Type: list of strings
  - Restrict results to these domains. Cannot be combined with `exclude_domains`.
  - JSON key: `includeDomains`

- `exclude_domains`
  - Type: list of strings
  - Exclude results from these domains. Cannot be combined with `include_domains`.
  - JSON key: `excludeDomains`

- `tbs`
  - Type: string
  - Time-based search filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week).
  - JSON key: `tbs`

- `location`
  - Type: string
  - Location for localized results (e.g. `"San Francisco,California,United States"`).
  - JSON key: `location`

- `country`
  - Type: string
  - ISO country code for geo-targeting (e.g. `"US"`).
  - JSON key: `country`

- `timeout`
  - Type: integer
  - Timeout in milliseconds.
  - JSON key: `timeout`

- `safe`
  - Type: boolean
  - When true, filters explicit content (SafeSearch).
  - JSON key: `safe`

- `highlights`
  - Type: boolean
  - Generate query-relevant highlights for search results.
  - JSON key: `highlights`

- `ignore_invalid_urls`
  - Type: boolean
  - Exclude URLs that are invalid for other Firecrawl endpoints.
  - JSON key: `ignoreInvalidURLs`

- `scrape_options`
  - Type: keyword list
  - Options for scraping each search result (see Scrape parameters).
  - JSON key: `scrapeOptions`

- `enterprise`
  - Type: list of strings
  - Enterprise options. Values: `"zdr"` (Zero Data Retention), `"anon"` (anonymized).
  - JSON key: `enterprise`

- `threat_protection`
  - Type: keyword list
  - Per-request Threat Protection override (enterprise).
  - JSON key: `threatProtection`

- `domain_tools`
  - Type: boolean
  - Include tool contracts matching domains of returned results.
  - JSON key: `domainTools`

- `tool_detail`
  - Type: `:compact` | `:summary` | `:full` or string
  - How much tool contract detail to return.
  - JSON key: `toolDetail`

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK function

`Firecrawl.scrape_and_extract_from_url(params \\ [], opts \\ [])` — returns `{:ok, %Req.Response{}}` or `{:error, exception}`.

Bang variant: `Firecrawl.scrape_and_extract_from_url!(params \\ [], opts \\ [])` — raises on error.

### Example

```elixir
{:ok, res} = Firecrawl.scrape_and_extract_from_url(
  url: "https://docs.firecrawl.dev",
  formats: ["markdown"],
  only_main_content: true
)

doc = res.body["data"]
markdown = doc["markdown"]
```

### Parameters

All parameters are keyword list entries. Required parameters are marked.

- `url` (**required**)
  - Type: string
  - The URL to scrape.

- `formats`
  - Type: list of strings or maps
  - Output formats. String values: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`.
  - Object format types: `%{type: "json", schema: ..., prompt: ...}`, `%{type: "question", question: ...}`, `%{type: "highlights", query: ...}`, `%{type: "screenshot", full_page: true}`, `%{type: "changeTracking", modes: ["git-diff"]}`.
  - JSON key: `formats`

- `only_main_content`
  - Type: boolean
  - Strip headers, navs, and footers.
  - JSON key: `onlyMainContent`

- `only_clean_content`
  - Type: boolean
  - Beta. Additional LLM-based pass to remove residual boilerplate.
  - JSON key: `onlyCleanContent`

- `include_tags`
  - Type: list of strings
  - HTML tags to include in output.
  - JSON key: `includeTags`

- `exclude_tags`
  - Type: list of strings
  - HTML tags to exclude from output.
  - JSON key: `excludeTags`

- `headers`
  - Type: map
  - Custom HTTP headers to send with the request.
  - JSON key: `headers`

- `timeout`
  - Type: integer
  - Timeout in milliseconds. Min: 1000, Max: 300000.
  - JSON key: `timeout`

- `wait_for`
  - Type: integer
  - Delay in milliseconds before fetching content.
  - JSON key: `waitFor`

- `mobile`
  - Type: boolean
  - Emulate a mobile device.
  - JSON key: `mobile`

- `actions`
  - Type: list of maps
  - Browser actions to perform before scraping. Action types: `wait`, `screenshot`, `click`, `write`, `press`, `scroll`, `scrape`, `executeJavascript`, `pdf`.
  - JSON key: `actions`

- `location`
  - Type: keyword list
  - Location settings. Keys: `:country` (ISO code), `:languages` (list of strings).
  - JSON key: `location`

- `skip_tls_verification`
  - Type: boolean
  - Skip TLS certificate verification.
  - JSON key: `skipTlsVerification`

- `remove_base64_images`
  - Type: boolean
  - Remove base64 images from markdown output.
  - JSON key: `removeBase64Images`

- `block_ads`
  - Type: boolean
  - Enable ad and cookie popup blocking.
  - JSON key: `blockAds`

- `proxy`
  - Type: `:basic` | `:enhanced` | `:auto` or string
  - Proxy type for the request.
  - JSON key: `proxy`

- `store_in_cache`
  - Type: boolean
  - Store the result in Firecrawl's cache.
  - JSON key: `storeInCache`

- `max_age`
  - Type: integer
  - Max age of cached content in milliseconds.
  - JSON key: `maxAge`

- `min_age`
  - Type: integer
  - Minimum age for cache-only check in milliseconds. Set to `1` for any cached data.
  - JSON key: `minAge`

- `lockdown`
  - Type: boolean
  - Serve only from cache, never make an outbound request.
  - JSON key: `lockdown`

- `zero_data_retention`
  - Type: boolean
  - Enable zero data retention.
  - JSON key: `zeroDataRetention`

- `check_prompt_injection`
  - Type: boolean
  - Scan content for prompt injection before LLM formats run. Adds 4 credits.
  - JSON key: `checkPromptInjection`

- `parsers`
  - Type: list of strings or maps
  - Parser configurations. Values: `"pdf"`, `"image"`, or `%{type: "pdf", mode: "auto", max_pages: 5}`.
  - JSON key: `parsers`

- `profile`
  - Type: keyword list
  - Enable persistent browser storage across scrapes. Keys: `:name`, `:save_changes`.
  - JSON key: `profile`

- `redact_pii`
  - Type: boolean or map
  - Redact personally identifiable information from output.
  - JSON key: `redactPII`

- `audit_metadata`
  - Type: keyword list
  - User attribution for SIEM logging. Key: `:username`.
  - JSON key: `auditMetadata`

- `threat_protection`
  - Type: keyword list
  - Per-request Threat Protection override (enterprise).
  - JSON key: `threatProtection`

- `alexandria`
  - Type: map or list
  - Execute catalogued provider tools instead of scraping. Mutually exclusive with `url`.
  - JSON key: `alexandria`

- `domain_tools`
  - Type: boolean
  - Include tool contracts matched to the scraped page domain.
  - JSON key: `domainTools`

- `tool_detail`
  - Type: `:compact` | `:summary` | `:full` or string
  - Tool contract detail level.
  - JSON key: `toolDetail`

## Interact

### Why use it

Use interact for programmatic control of the browser session tied to a scrape job (via the `scrapeId` in scrape response metadata). For flows that go beyond quick pre-scrape actions, prefer interact over scrape-time `actions`.

### Preferred SDK function

`Firecrawl.interact_with_scrape_browser_session(job_id, params \\ [], opts \\ [])` — returns `{:ok, %Req.Response{}}` or `{:error, exception}`.

Bang variant: `Firecrawl.interact_with_scrape_browser_session!(job_id, params \\ [], opts \\ [])` — raises on error.

### Example

```elixir
{:ok, scrape_res} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com",
  formats: ["markdown"]
)

job_id = scrape_res.body["data"]["metadata"]["scrapeId"]

{:ok, interact_res} = Firecrawl.interact_with_scrape_browser_session(
  job_id,
  code: ~s|console.log(await page.title());|,
  language: :node,
  timeout: 30
)

IO.puts(interact_res.body["stdout"])
```

### Parameters

First argument is the `job_id` (string, required). Remaining parameters are a keyword list.

- `code` (**required**)
  - Type: string
  - Code to execute in the scrape-bound browser sandbox.

- `language`
  - Type: `:python` | `:node` | `:bash` or string
  - Language for code execution. Default: `"node"`.
  - JSON key: `language`

- `timeout`
  - Type: integer
  - Execution timeout in seconds. Min: 1, Max: 300.
  - JSON key: `timeout`

- `origin`
  - Type: string
  - Optional origin label for telemetry.
  - JSON key: `origin`

### Stop session

`Firecrawl.stop_interactive_scrape_browser_session(job_id, opts \\ [])` — stops the scrape-bound browser session.

### Standalone interact sessions

The Elixir SDK also supports standalone interact sessions (not tied to a scrape job):

- `Firecrawl.create_browser_session(params, opts)` — creates a standalone browser session (`POST /interact`). Parameters: `ttl`, `activity_ttl`, `block_ads`, `location`, `profile`, `stream_web_view`.
- `Firecrawl.execute_browser_code(session_id, params, opts)` — executes code in a standalone session (`POST /interact/{sessionId}/execute`). Parameters: `code` (required), `language`, `timeout`.
- `Firecrawl.delete_browser_session(session_id, opts)` — deletes a standalone session.
- `Firecrawl.list_browser_sessions(params, opts)` — lists active sessions. Filter by `:status`.

## Notes

- The Elixir SDK is auto-generated from the OpenAPI spec via `generate.exs`. Function names are OpenAPI operation IDs in `snake_case` — they are not idiomatic Elixir helpers.
- All parameters use `snake_case` in Elixir. They are converted to `camelCase` JSON keys before the HTTP request.
- All functions return `{:ok, %Req.Response{}}` or `{:error, exception}`. Use bang variants (`!`) to raise on error instead.
- Parameters are validated locally via NimbleOptions before the HTTP request is made.
- A `nil` or empty API key falls back to the keyless free tier (rate-limited per IP).
- The Elixir `interact` only supports `code`, not `prompt` (natural-language instruction). To use natural-language interaction, use a different SDK.
- Deprecated: `search_github/2` → use `search_developer/2`. The `search_github` endpoint stops responding after 2026-11-03.
