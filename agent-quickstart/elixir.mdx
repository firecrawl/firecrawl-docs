# Firecrawl Elixir Agent Quickstart

Canonical quickstart for agents using the Firecrawl Elixir SDK. Generated from SDK source and OpenAPI spec.

The Elixir SDK is auto-generated from the OpenAPI spec. Function names match the OpenAPI operation IDs rather than short verbs.

## Install

Add to your `mix.exs` dependencies:

```elixir
defp deps do
  [
    {:firecrawl, "~> 1.11"}
  ]
end
```

## Authenticate

Configure the API key in your application config:

```elixir
config :firecrawl, api_key: "fc-YOUR_API_KEY"
```

Or pass per-call:

```elixir
Firecrawl.scrape_and_extract_from_url([url: "https://example.com"], api_key: "fc-YOUR_API_KEY")
```

No API key is required for scrape, search, and interact on the keyless free tier (rate-limited per IP).

All functions also accept a `:base_url` option to override the default `https://api.firecrawl.dev/v2`.

## When To Use What

- **`search_and_scrape`**: Start with a query and get back relevant web pages. Use when you need discovery: finding URLs, getting search results with optional full-page scraping.
- **`scrape_and_extract_from_url`**: Start with a URL and get page content back. Use when you already know the page you want and need its markdown, HTML, structured data, or screenshots.
- **`interact_with_scrape_browser_session`**: Execute code in a live browser session bound to a prior scrape. Use when the page needs clicks, form fills, or post-scrape browser automation.

## Search

### Why use it

Search the web through Firecrawl and optionally scrape each result page in a single call. Returns grouped results by source type.

### Preferred SDK method

```elixir
Firecrawl.search_and_scrape(params \\ [], opts \\ [])
Firecrawl.search_and_scrape!(params \\ [], opts \\ [])
```

### Example

```elixir
{:ok, response} = Firecrawl.search_and_scrape(
  query: "firecrawl web scraping API",
  limit: 5,
  scrape_options: [formats: ["markdown"]]
)

for result <- response.body["data"]["web"] || [] do
  IO.puts("#{result["url"]} #{result["title"]}")
end
```

### Parameters

All parameters are passed as a keyword list. Use snake_case keys; they are mapped to camelCase JSON automatically.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `query` | `:string` | **Yes** | The search query string. |
| `sources` | `{:list, :any}` | No | Source types: `"web"`, `"news"`, `"images"`. Default: `["web"]`. |
| `categories` | `{:list, :any}` | No | Categories: `"github"`, `"research"`, `"pdf"`. |
| `include_domains` | `{:list, :string}` | No | Only include results from these domains. |
| `exclude_domains` | `{:list, :string}` | No | Exclude results from these domains. |
| `limit` | `:integer` | No | Maximum number of results. |
| `tbs` | `:string` | No | Time-based search filter (e.g. `"qdr:d"` for past day). |
| `location` | `:string` | No | Location for search results (e.g. `"San Francisco,California,United States"`). |
| `country` | `:string` | No | ISO country code (e.g. `"US"`). |
| `ignore_invalid_urls` | `:boolean` | No | Skip invalid URLs. Mapped to `ignoreInvalidURLs`. |
| `timeout` | `:integer` | No | Timeout in milliseconds. |
| `highlights` | `:boolean` | No | Generate query-relevant highlights. Default: `true`. |
| `scrape_options` | `:keyword_list` | No | Scrape options applied to each result page. |
| `enterprise` | `{:list, :string}` | No | Enterprise options: `["zdr"]` for zero data retention, `["anon"]` for anonymized search. |

## Scrape

### Why use it

Scrape a single URL and get back structured page data: markdown, HTML, screenshots, extracted JSON, and more.

### Preferred SDK method

```elixir
Firecrawl.scrape_and_extract_from_url(params \\ [], opts \\ [])
Firecrawl.scrape_and_extract_from_url!(params \\ [], opts \\ [])
```

### Example

```elixir
{:ok, response} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com",
  formats: ["markdown", "screenshot"],
  only_main_content: true
)

IO.puts(response.body["data"]["markdown"])
```

### Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `url` | `:string` | **Yes** | The URL to scrape. |
| `formats` | `{:list, :any}` | No | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"json"`, `"audio"`, `"video"`, etc. |
| `headers` | `:any` | No | Custom HTTP headers. |
| `include_tags` | `{:list, :string}` | No | HTML tags to include. |
| `exclude_tags` | `{:list, :string}` | No | HTML tags to exclude. |
| `only_main_content` | `:boolean` | No | Strip headers, navs, footers. |
| `timeout` | `:integer` | No | Timeout in ms. Min 1000, default 60000, max 300000. |
| `wait_for` | `:integer` | No | Wait this many ms after page load before scraping. |
| `mobile` | `:boolean` | No | Emulate a mobile device viewport. |
| `parsers` | `{:list, :any}` | No | File parsers (e.g. PDF parser config). |
| `actions` | `{:list, :any}` | No | Browser actions before scraping. |
| `location` | `:keyword_list` | No | Proxy routing: `[country: "US", languages: ["en"]]`. |
| `skip_tls_verification` | `:boolean` | No | Skip TLS certificate verification. |
| `remove_base64_images` | `:boolean` | No | Strip base64-encoded images from markdown. |
| `block_ads` | `:boolean` | No | Block ads and cookie popups. |
| `proxy` | `:basic \| :enhanced \| :auto` | No | Proxy mode. |
| `max_age` | `:integer` | No | Use cached result if younger than this many ms. |
| `min_age` | `:integer` | No | Only check cache, never scrape fresh. |
| `store_in_cache` | `:boolean` | No | Cache the scrape result. |
| `lockdown` | `:boolean` | No | Only serve cached results. |
| `redact_pii` | `:boolean` | No | Redact personally identifiable information. |
| `audit_metadata` | `:keyword_list` | No | SIEM logging: `[username: "agent-name"]`. |
| `profile` | `:keyword_list` | No | Persistent browser profile. |
| `zero_data_retention` | `:boolean` | No | Enable zero data retention. |
| `integration` | `:string` | No | Integration identifier. |

## Interact

### Why use it

Execute code in a live browser session that was opened by a prior `scrape_and_extract_from_url` call. Use this for clicks, form fills, or arbitrary code execution.

### Preferred SDK method

```elixir
Firecrawl.interact_with_scrape_browser_session(job_id, params \\ [], opts \\ [])
Firecrawl.interact_with_scrape_browser_session!(job_id, params \\ [], opts \\ [])
```

### Example

```elixir
# Interact with a prior scrape session
{:ok, response} = Firecrawl.interact_with_scrape_browser_session(
  "job-id-from-scrape",
  code: ~s(document.querySelector("button.load-more").click();),
  language: :node,
  timeout: 30
)

IO.puts(response.body["stdout"])
IO.puts(response.body["result"])

# Stop the session when done
Firecrawl.stop_interactive_scrape_browser_session("job-id-from-scrape")
```

### Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `job_id` | `String.t()` (required, first positional arg) | **Yes** | The scrape job ID from a prior scrape call. |
| `code` | `:string` | **Yes** | Code to execute in the browser sandbox. |
| `language` | `:python \| :node \| :bash` | No | Execution language. Default: `:node`. |
| `timeout` | `:integer` | No | Execution timeout in seconds. |

Stop the browser session when done:

```elixir
Firecrawl.stop_interactive_scrape_browser_session(job_id)
```

## Notes

- **OpenAPI-generated names**: The Elixir SDK uses auto-generated function names from the OpenAPI spec:
  - `search_and_scrape` (not `search`)
  - `scrape_and_extract_from_url` (not `scrape`)
  - `interact_with_scrape_browser_session` (not `interact`)
  - `stop_interactive_scrape_browser_session` (not `stop_interaction`)
- **Bang variants**: Every function has a `!` variant (e.g. `search_and_scrape!`) that raises `Firecrawl.Error` on failure instead of returning `{:error, _}`.
- **snake_case parameters**: Use snake_case in keyword lists. The SDK maps them to camelCase JSON keys automatically.
- **Proxy as atom**: The `proxy` parameter uses atoms: `:basic`, `:enhanced`, `:auto`.
- **Response shape**: Functions return `{:ok, %Req.Response{}}` or `{:error, %Firecrawl.Error{}}`. Access data via `response.body["data"]`.
- **Telemetry origin**: An `origin` field (`"elixir-sdk@{version}"`) is auto-injected into every request body.
