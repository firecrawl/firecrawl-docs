# Firecrawl Elixir Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl` hex package **v1.11.3**) and the v2 OpenAPI spec. Function names and parameter keys are generated from the OpenAPI spec.

## Install

Add to `mix.exs`:

```elixir
{:firecrawl, "~> 1.11"}
```

## Authenticate

```elixir
# config/runtime.exs or config.exs
config :firecrawl, api_key: System.get_env("FIRECRAWL_API_KEY")

# or pass api_key per call
{:ok, res} = Firecrawl.search_and_scrape(
  [query: "site:docs.firecrawl.dev webhooks"],
  api_key: "fc-your-api-key"
)
```

All functions accept an optional trailing keyword list (`opts`) with `:api_key` and `:base_url` overrides.

## When To Use What

- **`search`**: use when you start with a query and need discovery. Returns URLs, titles, and optionally scraped content.
- **`scrape`**: use when you already have a URL and want page content in one or more formats.
- **`interact`**: use when the page needs code execution in the browser session after a scrape. Requires a scrape job ID.

## Search

### Why use it

Discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain results to a site with `site:`, e.g. `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`Firecrawl.search_and_scrape(params \\ [], opts \\ [])`

### Example

```elixir
{:ok, res} = Firecrawl.search_and_scrape(
  query: "site:docs.firecrawl.dev webhook retries",
  sources: [:web, :news],
  limit: 10,
  scrape_options: [
    formats: ["markdown"],
    only_main_content: true
  ]
)
```

### Parameters

| Parameter | Type | When to use |
|---|---|---|
| `query` | `string` | Always required. Use `site:example.com` to limit results to a domain. |
| `sources` | `list` | Control sources. Values: `:web`, `:news`, `:images`, or string/map equivalents. |
| `categories` | `list` | Narrow results. Values: `:developer`, `:research`, `:pdf`, or string/map equivalents. |
| `include_domains` | `list of string` | Only include results from these domains. |
| `exclude_domains` | `list of string` | Exclude results from these domains. |
| `limit` | `integer` | Cap the number of results. |
| `tbs` | `string` | Time-based filter (e.g. `qdr:d`, `qdr:w`). |
| `location` | `string` | Localized results. |
| `country` | `string` | ISO country code for geo-targeting. |
| `ignore_invalid_urls` | `boolean` | Drop URLs that cannot be scraped. |
| `highlights` | `boolean` | Generate query-relevant highlights. |
| `safe` | `boolean` | SafeSearch filter. |
| `timeout` | `integer` | Request timeout in milliseconds. |
| `scrape_options` | `keyword list` | Scrape each search result (see Scrape parameters). |
| `enterprise` | `list of string` | Enterprise options. Values: `"zdr"`, `"anon"`. |
| `threat_protection` | `keyword list` | Per-request threat protection override. |
| `domain_tools` | `boolean` | Enable Alexandria domain-tool discovery. |
| `tool_detail` | `:compact \| :summary \| :full` | Tool detail level. |

## Scrape

### Why use it

Retrieve structured content from a URL in one or more formats (markdown, HTML, JSON extraction, screenshots, etc.).

### Preferred SDK method

`Firecrawl.scrape_and_extract_from_url(params \\ [], opts \\ [])`

### Example

```elixir
{:ok, res} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com/pricing",
  formats: [
    "markdown",
    "links",
    %{type: "json", prompt: "Extract plan names and prices."}
  ],
  only_main_content: true,
  wait_for: 1000
)
```

### Parameters

| Parameter | Type | When to use |
|---|---|---|
| `url` | `string` | Always required. The page to scrape. |
| `formats` | `list` | Output formats. Strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"branding"`, `"audio"`, `"video"`. Maps: `%{type: "json", prompt: ..., schema: ...}`, `%{type: "screenshot", fullPage: ..., quality: ..., viewport: ...}`, `%{type: "changeTracking", modes: [...], tag: ...}`. |
| `headers` | `map` | Custom request headers. |
| `include_tags` | `list of string` | Include only specific HTML tags. |
| `exclude_tags` | `list of string` | Exclude specific HTML tags. |
| `only_main_content` | `boolean` | Strip nav, footer, and boilerplate. |
| `only_clean_content` | `boolean` | Beta. LLM-based boilerplate removal. |
| `timeout` | `integer` | Timeout in milliseconds. Min: 1000, Max: 300000. |
| `wait_for` | `integer` | Wait for the page to render (milliseconds). |
| `mobile` | `boolean` | Use a mobile viewport. |
| `parsers` | `list` | File parsing controls. E.g. `"pdf"` or `%{type: "pdf", mode: "auto", maxPages: 5}`. |
| `actions` | `list of map` | Pre-scrape browser actions: `wait`, `screenshot`, `click`, `write`, `press`, `scroll`, `scrape`, `executeJavascript`, `pdf`. |
| `location` | `keyword list` | Geo-aware scraping. Keys: `country:`, `languages:`. |
| `skip_tls_verification` | `boolean` | Skip TLS verification. |
| `remove_base64_images` | `boolean` | Drop base64 images from markdown. |
| `block_ads` | `boolean` | Ad and cookie popup blocking. |
| `proxy` | `:basic \| :enhanced \| :auto \| string` | Proxy control. |
| `max_age` | `integer` | Max age of cached data (milliseconds). |
| `min_age` | `integer` | Min age of cached data (milliseconds). |
| `store_in_cache` | `boolean` | Cache the result. |
| `lockdown` | `boolean` | Serve only cached results. |
| `redact_pii` | `any` | PII redaction. |
| `profile` | `keyword list` | Persistent browser profile. Keys: `name:`, `save_changes:`. |
| `threat_protection` | `keyword list` | Per-request threat protection override. |
| `audit_metadata` | `keyword list` | SIEM logging metadata. Key: `username:`. |
| `zero_data_retention` | `boolean` | Zero data retention. |
| `domain_tools` | `boolean` | Enable Alexandria domain-tool discovery. |

## Interact

### Why use it

Execute code in the browser session tied to a scrape job. Use for multi-step flows that require programmatic browser control.

### Preferred SDK method

`Firecrawl.interact_with_scrape_browser_session(job_id, params \\ [], opts \\ [])`

### Example

```elixir
{:ok, doc} = Firecrawl.scrape_and_extract_from_url(
  url: "https://example.com",
  formats: ["markdown"]
)

job_id = get_in(doc, ["metadata", "scrapeId"])

{:ok, result} = Firecrawl.interact_with_scrape_browser_session(
  job_id,
  code: "console.log(await page.title());",
  language: :node,
  timeout: 60
)

# End the session:
{:ok, _} = Firecrawl.stop_interactive_scrape_browser_session(job_id)
```

### Parameters

| Parameter | Type | When to use |
|---|---|---|
| `job_id` | `string` | Always required. Scrape job ID. |
| `code` | `string` | Always required. Code to execute in the browser session. |
| `language` | `:python \| :node \| :bash` | Runtime. Default: `:node`. |
| `timeout` | `integer` | Execution timeout in seconds. |
| `origin` | `string` | Optional origin label for telemetry. |

### Stop session

`Firecrawl.stop_interactive_scrape_browser_session(job_id)` → ends the browser session.

## Notes

- The Elixir SDK is **OpenAPI-generated**: function names and parameter keys come from the spec.
- This SDK exposes **code-based interactions only**: there is no `prompt` parameter on `interact_with_scrape_browser_session` (unlike Node.js and Python SDKs).
- Each public function has a bang (`!`) variant that raises on error instead of returning `{:error, _}`.
- No deprecated function aliases exist in the Elixir SDK.
