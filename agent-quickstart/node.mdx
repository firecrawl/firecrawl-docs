# Firecrawl Node.js Agent Quickstart

This is the canonical quickstart for external agents integrating with Firecrawl using the Node.js/TypeScript SDK. Generated from SDK source and OpenAPI spec.

## Install

```bash
npm install @mendable/firecrawl-js
```

## Authenticate

```typescript
import Firecrawl from "@mendable/firecrawl-js";

const client = new Firecrawl("fc-YOUR_API_KEY");

// Or with options:
const client = new Firecrawl({
  apiKey: "fc-YOUR_API_KEY",
  apiUrl: "https://api.firecrawl.dev", // optional, also reads FIRECRAWL_API_URL env var
});
```

The API key can also be set via the `FIRECRAWL_API_KEY` environment variable.

## When To Use What

- **search** — start with a query and discover relevant URLs with optional page content. Use when you don't have a URL yet.
- **scrape** — start with a known URL and extract page content in various formats. Use when you already know which page you need.
- **interact** — execute code in a browser session bound to a prior scrape. Use when the page needs post-scrape browser interaction like clicking, typing, or navigating.

## Search

### Why use it

Search finds pages matching a query across web, news, and image sources, and optionally returns their scraped content. Use it for discovery when you need to find relevant URLs.

### Preferred SDK method

```typescript
client.search(query, options?)
```

### Example

```typescript
const results = await client.search("firecrawl web scraping API", {
  limit: 5,
  scrapeOptions: {
    formats: ["markdown"],
  },
});

for (const item of results.web ?? []) {
  console.log(item.url, item.markdown?.substring(0, 100));
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `query` | `string` | Search query string (required, passed as first argument). Max 500 chars. |
| `limit` | `number` | Max results to return per source type. Min 1, max 100. Default: 10. |
| `sources` | `Array<string \| object>` | Sources to search: `"web"`, `"news"`, `"images"`, `"alexandria"`. Default: `["web"]`. |
| `categories` | `Array<string>` | Filter by category: `"developer"`, `"gov"`, `"research"`, `"pdf"`. |
| `includeDomains` | `string[]` | Restrict results to these domains. Cannot combine with `excludeDomains`. |
| `excludeDomains` | `string[]` | Exclude results from these domains. Cannot combine with `includeDomains`. |
| `tbs` | `string` | Time-based search filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week). |
| `location` | `string` | Location for geo-targeted results (e.g. `"San Francisco,California,United States"`). |
| `country` | `string` | ISO country code for geo-targeting (e.g. `"US"`). Default: `"US"`. |
| `ignoreInvalidURLs` | `boolean` | Exclude URLs invalid for other Firecrawl endpoints. Default: `false`. |
| `timeout` | `number` | Timeout in milliseconds. Default: 60000. |
| `highlights` | `boolean` | Generate query-relevant highlights. Default: `true`. |
| `scrapeOptions` | `ScrapeOptions` | Options for scraping each result page (see Scrape parameters, minus `url`). |
| `enterprise` | `Array<string>` | Enterprise options: `["zdr"]` for zero data retention, `["anon"]` for anonymized. |
| `domainTools` | `boolean` | Include tool contracts matching returned domains. |
| `toolDetail` | `string` | Tool contract detail level: `"compact"`, `"summary"`, `"full"`. |

## Scrape

### Why use it

Scrape extracts structured content from a single URL. Returns markdown, HTML, links, screenshots, structured JSON, and more depending on the formats you request.

### Preferred SDK method

```typescript
client.scrape(url, options?)
```

### Example

```typescript
const result = await client.scrape("https://example.com", {
  formats: ["markdown", "links"],
  onlyMainContent: true,
  timeout: 30000,
});

console.log(result.markdown);
console.log(result.links);
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `url` | `string` | The URL to scrape (required, passed as first argument). |
| `formats` | `FormatOption[]` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"json"`, `"summary"`, `"changeTracking"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`. Some accept sub-options (e.g. json with `schema`/`prompt`). Default: `["markdown"]`. |
| `onlyMainContent` | `boolean` | Strip navs, footers, and boilerplate. Default: `true`. |
| `includeTags` | `string[]` | HTML tags to include (allowlist). |
| `excludeTags` | `string[]` | HTML tags to exclude (blocklist). |
| `headers` | `Record<string, string>` | Custom HTTP headers (cookies, user-agent, etc.). |
| `waitFor` | `number` | Delay in ms before fetching content. Max 60000. Default: 0. |
| `timeout` | `number` | Request timeout in milliseconds. Min 1000, max 300000. Default: 60000. |
| `mobile` | `boolean` | Emulate a mobile device. Default: `false`. |
| `skipTlsVerification` | `boolean` | Skip TLS certificate verification. Default: `true`. |
| `removeBase64Images` | `boolean` | Strip base64-encoded images from output. Default: `true`. |
| `blockAds` | `boolean` | Block ads and cookie popups. Default: `true`. |
| `proxy` | `string` | Proxy mode: `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`, or a custom proxy URL. Default: `"auto"`. |
| `actions` | `ActionOption[]` | Browser actions to perform before scraping: `wait`, `click`, `write`, `press`, `scroll`, `screenshot`, `scrape`, `executeJavascript`, `pdf`. |
| `location` | `object` | Location settings: `{ country?: string, languages?: string[] }`. |
| `parsers` | `Array` | File parsers (e.g. PDF with `maxPages`, `pages`, `mode`). Default: `["pdf", "image"]`. |
| `maxAge` | `number` | Max cache age in ms. Default: 172800000 (2 days). Set 0 to bypass cache. |
| `storeInCache` | `boolean` | Store result in Firecrawl cache. Default: `true`. |
| `lockdown` | `boolean` | Serve from cache only, never make outbound request. Default: `false`. |
| `checkPromptInjection` | `boolean` | Scan for prompt injection before LLM formats. Adds 4 credits. Default: `false`. |
| `redactPII` | `boolean \| object` | Redact personally identifiable information from markdown. Default: `false`. |
| `profile` | `object` | Persistent browser profile: `{ name: string, saveChanges?: boolean }`. |
| `auditMetadata` | `object` | SIEM logging attribution: `{ username: string }`. |
| `domainTools` | `boolean` | List tool contracts for the scraped domain. |
| `toolDetail` | `string` | Tool contract detail: `"compact"`, `"summary"`, `"full"`. |
| `fastMode` | `boolean` | Use fast mode for quicker scraping. |
| `autoResume` | `boolean` | SDK-only. Auto-resume large documents that time out. Enabled by default. |

## Interact

### Why use it

Interact lets you execute code in the browser session that was opened by a prior scrape. You write JavaScript, Python, or Bash code that runs in the browser sandbox — use it to click buttons, fill forms, navigate pages, or extract dynamic content that requires post-scrape interaction.

### Preferred SDK method

```typescript
client.interact(jobId, request)
```

### Example

```typescript
// First scrape a page — the browser session stays open
const scrapeResult = await client.scrape("https://example.com/app", {
  formats: ["markdown"],
});
const jobId = scrapeResult.metadata.jobId;

// Execute code in the browser session
const result = await client.interact(jobId, {
  code: `
    await page.click('#login-button');
    await page.fill('#username', 'user@example.com');
    await page.fill('#password', 'secret');
    await page.click('#submit');
    await page.waitForSelector('.dashboard');
    return await page.content();
  `,
  language: "node",
  timeout: 30,
});

console.log(result.output);

// Stop the browser session when done
await client.stopInteraction(jobId);
```

### Parameters

`ScrapeExecuteRequest` fields:

| Parameter | Type | Description |
|-----------|------|-------------|
| `code` | `string` | Code to execute in the browser sandbox. Required if `prompt` is not provided. Max 100000 chars. |
| `prompt` | `string` | Natural-language instruction for the browser agent. Required if `code` is not provided. |
| `language` | `string` | Runtime language: `"python"`, `"node"`, `"bash"`. Default: `"node"`. |
| `timeout` | `number` | Execution timeout in seconds. Min 1, max 300. Default: 30. |

At least one of `code` or `prompt` must be provided.

**Related methods:**

| Method | Description |
|--------|-------------|
| `client.stopInteraction(jobId)` | Stops the interactive browser session. |

## Notes

- The package name is `@mendable/firecrawl-js`. The top-level export is the `Firecrawl` class.
- All parameter names use camelCase.
- Deprecated aliases: `scrapeUrl()` → use `scrape()`, `scrapeExecute()` → use `interact()`, `deleteScrapeBrowser()` / `stopInteractiveBrowser()` → use `stopInteraction()`.
- The constructor accepts either a string (API key) or an options object with `apiKey`, `apiUrl`, `timeoutMs`, `maxRetries`, `backoffFactor`.
