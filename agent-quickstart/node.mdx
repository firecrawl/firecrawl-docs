# Firecrawl Node.js Agent Quickstart

This file is the canonical quickstart for external agents integrating with Firecrawl using the JavaScript/TypeScript SDK. It is generated from the SDK source (`@mendable/firecrawl-js`) and the OpenAPI spec.

## Install

```bash
npm install @mendable/firecrawl-js
```

Requires Node.js >= 22.

## Authenticate

```ts
import Firecrawl from '@mendable/firecrawl-js';

const app = new Firecrawl({ apiKey: 'fc-YOUR-API-KEY' });
```

The API key is resolved from: constructor `apiKey` > `FIRECRAWL_API_KEY` env var > empty string (keyless free tier, rate-limited per IP). For self-hosted instances, pass `apiUrl`.

## When To Use What

- **`search`** — Start with a query, get web results with optional scraping. Use when you need discovery.
- **`scrape`** — Start with a URL, get page content as markdown, HTML, JSON, etc. Use when you already know the page.
- **`interact`** — Execute code or natural-language prompts in a live browser session bound to a prior scrape. Use when the page needs clicks, form fills, or post-scrape browser actions.

## Search

### Why use it

Search the web for a query and get back results with optional page content. Combines discovery and scraping in one call.

### Preferred SDK method

```ts
app.search(query, options?)
```

### Example

```ts
const results = await app.search('firecrawl web scraping', {
  limit: 5,
  scrapeOptions: { formats: ['markdown'] },
});

for (const page of results.web ?? []) {
  console.log(page.url, page.title);
}
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `string` | **Required.** The search query. |
| `limit` | `number` | Max number of results. |
| `sources` | `Array<"web" \| "news" \| "images" \| "alexandria">` | Which sources to query. |
| `categories` | `Array<"github" \| "research" \| "pdf" \| "developer">` | Narrow results by category. `"research"` filters by academic domains, not the paper index. |
| `includeDomains` | `string[]` | Only return results from these domains. |
| `excludeDomains` | `string[]` | Exclude results from these domains. |
| `tbs` | `string` | Time-based filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week). |
| `location` | `string` | Geographic location string for geo-targeting. |
| `country` | `string` | ISO 3166-1 alpha-2 country code for geo-targeting. |
| `highlights` | `boolean` | Generate query-relevant highlights. Defaults to `true`. |
| `timeout` | `number` | Timeout in milliseconds. |
| `ignoreInvalidURLs` | `boolean` | Skip invalid URLs in results. |
| `scrapeOptions` | `ScrapeOptions` | Options applied when scraping each result page. |
| `enterprise` | `Array<"default" \| "anon" \| "zdr">` | Enterprise search: `["zdr"]` for Zero Data Retention, `["anon"]` for anonymized. |
| `threatProtection` | `ThreatProtectionOptions` | Per-request threat protection override (enterprise). |
| `domainTools` | `boolean` | Include domain-matched Alexandria tools in results. |
| `toolDetail` | `"compact" \| "summary" \| "full"` | Detail level for discovered tools. Default: `"compact"`. |
| `integration` | `string` | Integration identifier. |

## Scrape

### Why use it

Scrape a single URL and get back clean content in your chosen formats — markdown, HTML, structured JSON, screenshots, and more.

### Preferred SDK method

```ts
app.scrape(url, options?)
```

### Example

```ts
const doc = await app.scrape('https://example.com', {
  formats: ['markdown', 'html'],
  onlyMainContent: true,
});

console.log(doc.markdown);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `string` | **Required.** The URL to scrape. |
| `formats` | `FormatOption[]` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"json"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`. Also accepts objects for `json`, `screenshot`, `question`, `highlights`, `changeTracking`, and `attributes`. |
| `onlyMainContent` | `boolean` | Extract only main content, excluding navs/footers. |
| `includeTags` | `string[]` | HTML tags to include in output. |
| `excludeTags` | `string[]` | HTML tags to exclude from output. |
| `headers` | `Record<string, string>` | Custom HTTP headers for the request. |
| `timeout` | `number` | Timeout in milliseconds. |
| `waitFor` | `number` | Wait time in ms before scraping (for JS rendering). |
| `mobile` | `boolean` | Emulate a mobile device. |
| `actions` | `ActionOption[]` | Browser actions: `wait`, `click`, `write`, `press`, `scroll`, `scrape`, `screenshot`, `executeJavascript`, `pdf`. |
| `location` | `{ country?: string; languages?: string[] }` | Proxy location. |
| `proxy` | `"basic" \| "stealth" \| "enhanced" \| "auto"` | Proxy type. |
| `blockAds` | `boolean` | Block ads and cookie popups. |
| `skipTlsVerification` | `boolean` | Skip TLS certificate verification. |
| `removeBase64Images` | `boolean` | Strip base64 images from output. |
| `fastMode` | `boolean` | Faster scraping with reduced accuracy. |
| `parsers` | `Array<string \| PDFParser \| ImageParser>` | Document parsers. Default includes `"pdf"`. |
| `maxAge` | `number` | Max age in ms of cached content to reuse. `0` bypasses cache. |
| `storeInCache` | `boolean` | Store the result in Firecrawl's index. |
| `lockdown` | `boolean` | Only serve cached results; no outbound requests. |
| `redactPII` | `boolean \| RedactPIIOptions` | Redact personally identifiable information. |
| `profile` | `{ name: string; saveChanges?: boolean }` | Persistent browser profile across sessions. |
| `auditMetadata` | `{ username: string }` | User attribution for SIEM logging. |
| `threatProtection` | `ThreatProtectionOptions` | Per-request threat protection override (enterprise). |
| `domainTools` | `boolean` | Include domain-matched Alexandria tools. |
| `toolDetail` | `"compact" \| "summary" \| "full"` | Detail level for discovered tools. |
| `integration` | `string` | Integration identifier. |

## Interact

### Why use it

Execute code or natural-language prompts in a live browser session that was opened by a prior scrape. Use it for clicking buttons, filling forms, navigating, or any post-scrape browser automation.

### Preferred SDK method

```ts
app.interact(jobId, args)
```

### Example

```ts
const doc = await app.scrape('https://www.amazon.com', { formats: ['markdown'] });
const scrapeId = doc.metadata?.scrapeId;

await app.interact(scrapeId, { prompt: 'Search for iPhone 16 Pro Max' });
const response = await app.interact(scrapeId, {
  prompt: 'Click on the first result and tell me the price',
});
console.log(response.output);

await app.stopInteraction(scrapeId);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `string` | **Required.** The scrape job ID from `metadata.scrapeId`. |
| `prompt` | `string` | Natural-language instruction for the browser agent. Provide either `prompt` or `code`. |
| `code` | `string` | Code to execute in the browser sandbox. Provide either `prompt` or `code`. |
| `language` | `"python" \| "node" \| "bash"` | Language for code execution. Default: `"node"`. |
| `timeout` | `number` | Execution timeout in seconds. |

**Stop the session** when done:

```ts
await app.stopInteraction(jobId);
```

## Notes

- **Naming style**: All parameter names are camelCase.
- **Deprecated aliases**: `scrapeUrl` → `scrape`, `scrapeExecute` → `interact`, `stopInteractiveBrowser` / `deleteScrapeBrowser` → `stopInteraction`. Use the preferred names.
- **Auto-resume**: `scrape()` accepts an SDK-only `autoResume` option (default: `true`) that auto-resumes large documents across multiple request windows.
- **Search return shape**: `search()` returns `SearchData` with `.web`, `.news`, `.images`, and `.tools` arrays. Accessing `.data` throws with guidance.
