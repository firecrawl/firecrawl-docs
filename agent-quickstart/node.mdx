# Firecrawl Node.js Agent Quickstart

This file is the canonical quickstart for external agents integrating with Firecrawl using the Node.js/TypeScript SDK. It is generated from SDK source and OpenAPI spec.

## Install

```bash
npm install @mendable/firecrawl-js
```

## Authenticate

```ts
import Firecrawl from "@mendable/firecrawl-js";

const firecrawl = new Firecrawl("fc-YOUR_API_KEY");
```

Or use the `FIRECRAWL_API_KEY` environment variable:

```ts
const firecrawl = new Firecrawl();
```

Constructor also accepts an options object:

```ts
const firecrawl = new Firecrawl({
  apiKey: "fc-YOUR_API_KEY",
  apiUrl: "https://api.firecrawl.dev",
  timeoutMs: 30000,
  maxRetries: 3,
  backoffFactor: 0.5,
});
```

## When To Use What

- **search**: Use when you start with a query and need to discover relevant pages. Returns ranked results with optional scraping of each result.
- **scrape**: Use when you already have a URL and want page content in a specific format (markdown, HTML, structured JSON, etc.).
- **interact**: Use when the page needs post-scrape browser actions — clicking buttons, filling forms, or running code in the live browser session.

## Search

### Why use it

Search takes a natural-language query and returns ranked web results. You can optionally scrape each result page inline by passing `scrapeOptions`. Use it for discovery when you don't have a specific URL.

### Preferred SDK method

```ts
firecrawl.search(query, options?)
```

### Example

```ts
const results = await firecrawl.search("firecrawl web scraping API", {
  limit: 5,
  scrapeOptions: { formats: ["markdown"] },
});

for (const page of results.web ?? []) {
  console.log(page.url, page.title);
  console.log(page.markdown);
}
```

### Parameters

- **query** (string, required): The search query.
- **sources** (`Array<"web" | "news" | "images" | "alexandria" | { type: ... }>`): Result sources to include. Default: `["web"]`.
- **categories** (`Array<"github" | "research" | "pdf" | "developer" | "gov" | CategoryOption>`): Narrow web search by category.
- **includeDomains** (string[]): Only include results from these domains.
- **excludeDomains** (string[]): Exclude results from these domains.
- **limit** (number): Max number of results. Default: 10.
- **tbs** (string): Time-based search parameter (Google tbs format, e.g. `"qdr:d"` for past day).
- **location** (string): Geo-location for search results.
- **country** (string): ISO 3166-1 alpha-2 country code for geo-targeting.
- **ignoreInvalidURLs** (boolean): Ignore invalid URLs in results.
- **timeout** (number): Timeout in milliseconds. Default: 60000.
- **highlights** (boolean): Generate query-relevant highlights. Default: true.
- **scrapeOptions** (ScrapeOptions): Options to apply when scraping each result page (same shape as `scrape` options, minus `toolDetail`).
- **enterprise** (`Array<"default" | "anon" | "zdr">`): Enterprise search options (Zero Data Retention, anonymized).
- **threatProtection** (ThreatProtectionOptions): Per-request threat protection override (enterprise).
- **domainTools** (boolean): Include domain-matched Alexandria tool contracts alongside results.
- **toolDetail** (`"compact" | "summary" | "full"`): Tool contract detail level. Default: `"compact"`.
- **integration** (string): Integration identifier.
- **origin** (string): Origin identifier.

## Scrape

### Why use it

Scrape fetches a single URL and returns its content in one or more formats: markdown, HTML, structured JSON, screenshot, and more. Use it when you already know the URL you need.

### Preferred SDK method

```ts
firecrawl.scrape(url, options?)
```

### Example

```ts
const doc = await firecrawl.scrape("https://example.com", {
  formats: ["markdown", "links"],
  onlyMainContent: true,
  timeout: 30000,
});

console.log(doc.markdown);
console.log(doc.links);
```

### Parameters

- **url** (string, required): The URL to scrape.
- **formats** (FormatOption[]): Requested output formats. String values: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`. Object variants: `{ type: "json", prompt?, schema? }`, `{ type: "screenshot", fullPage?, quality?, viewport? }`, `{ type: "changeTracking", modes, schema?, prompt?, tag? }`, `{ type: "attributes", selectors: [{ selector, attribute }] }`, `{ type: "question", question }`, `{ type: "highlights", query }`. Default: `["markdown"]`.
- **headers** (Record<string, string>): Custom HTTP headers to send with the request.
- **includeTags** (string[]): HTML tags to include in output.
- **excludeTags** (string[]): HTML tags to exclude from output.
- **onlyMainContent** (boolean): Only return the main content of the page. Default: true.
- **timeout** (number): Request timeout in milliseconds. Default: 60000.
- **waitFor** (number): Wait time in milliseconds before scraping (for JS rendering). Max: 60000.
- **mobile** (boolean): Emulate mobile device.
- **parsers** (`Array<string | PDFParser | ImageParser>`): File parsers (e.g. `"pdf"`, `"image"`, or config objects with `mode`, `maxPages`, etc.). Default: `["pdf", "image"]`.
- **actions** (ActionOption[]): Browser actions to perform before scraping. Types: `wait`, `screenshot`, `click`, `write`, `press`, `scroll`, `scrape`, `executeJavascript`, `pdf`.
- **location** (`{ country?: string, languages?: string[] }`): Location config for proxy routing. Default country: `"US"`.
- **skipTlsVerification** (boolean): Skip TLS certificate verification.
- **removeBase64Images** (boolean): Remove base64 images from output. Default: true.
- **fastMode** (boolean): Enable fast mode (quicker, less accurate).
- **blockAds** (boolean): Block ads and cookie popups. Default: true.
- **proxy** (`"basic" | "stealth" | "enhanced" | "auto" | string`): Proxy mode. Default: `"auto"`.
- **maxAge** (number): Max age of cached content in milliseconds. Set to 0 to bypass cache. Default: 172800000 (2 days).
- **minAge** (number): Minimum age of cached content in milliseconds. Set to 1 for any cached data.
- **storeInCache** (boolean): Store result in cache. Default: true.
- **lockdown** (boolean): Serve from cache only, never make outbound request.
- **checkPromptInjection** (boolean): Scan page for prompt injection before LLM-backed formats. Adds 4 credits.
- **redactPII** (boolean | RedactPIIOptions): Redact PII from output. When object: `{ mode: "accurate" | "aggressive" | "fast", entities?: RedactPIIEntity[], replaceStyle?: "tag" | "mask" | "remove" }`.
- **threatProtection** (ThreatProtectionOptions): Per-request threat protection override (enterprise). Fields: `mode`, `riskScoreThreshold`, `blacklist`, `whitelist`, `blockedTlds`, `failurePolicy`.
- **auditMetadata** (`{ username: string }`): Audit metadata for SIEM logging.
- **profile** (`{ name: string, saveChanges?: boolean }`): Persistent browser profile.
- **integration** (string): Integration identifier.
- **origin** (string): Origin identifier.
- **domainTools** (boolean): Include domain-matched Alexandria tool contracts.
- **toolDetail** (`"compact" | "summary" | "full"`): Tool contract detail level.
- **autoResume** (boolean, SDK-only): Auto-resume large documents that outlive the request window. Default: on. Set to `false` to surface timeout error immediately.

## Interact

### Why use it

Interact lets you run code or a natural-language prompt in the live browser session from a prior scrape. Use it for clicking buttons, filling forms, navigating multi-step flows, or extracting data that requires post-load interaction.

### Preferred SDK method

```ts
firecrawl.interact(jobId, args)
```

### Example

```ts
const doc = await firecrawl.scrape("https://example.com", {
  formats: ["markdown"],
});

const jobId = doc.metadata.jobId;

const result = await firecrawl.interact(jobId, {
  code: `document.querySelector("button.load-more").click();`,
  language: "node",
  timeout: 30,
});

console.log(result.stdout);

await firecrawl.stopInteraction(jobId);
```

### Parameters

- **jobId** (string, required): The scrape job ID from a prior `scrape` call (found in `doc.metadata.jobId`).
- **code** (string): Code to execute in the browser session. One of `code` or `prompt` is required.
- **prompt** (string): Natural language prompt to execute. One of `code` or `prompt` is required.
- **language** (`"python" | "node" | "bash"`): Execution language. Default: `"node"`.
- **timeout** (number): Execution timeout in seconds (1–300). Default: 30.
- **origin** (string): Origin identifier.

### Stop session

```ts
await firecrawl.stopInteraction(jobId);
```

Stops the interactive browser session and frees resources.

## Notes

- All parameter names use **camelCase** (e.g. `onlyMainContent`, `includeTags`, `scrapeOptions`).
- The SDK sets `origin` automatically to `"js-sdk@VERSION"` if not provided.
- Keyless usage is supported for scrape, search, and interact (rate-limited per IP).
- Async methods are the default — all SDK methods return Promises.

### Deprecated aliases

| Deprecated | Use instead |
|---|---|
| `scrapeExecute(jobId, args)` | `interact(jobId, args)` |
| `stopInteractiveBrowser(jobId)` | `stopInteraction(jobId)` |
| `deleteScrapeBrowser(jobId)` | `stopInteraction(jobId)` |
| `scrapeUrl(url, options)` | `scrape(url, options)` |
