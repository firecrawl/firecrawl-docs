# Firecrawl Node.js Agent Quickstart

Canonical quickstart for external agents. Generated from `@mendable/firecrawl-js` **v4.46.0** SDK source and the v2 OpenAPI spec. Method names, parameters, and types match the SDK public API.

## Install

```bash
npm install firecrawl
```

## Authenticate

```ts
import { Firecrawl } from "firecrawl";

const client = new Firecrawl({
  apiKey: process.env.FIRECRAWL_API_KEY,
});
```

Constructor options: `apiKey` (falls back to `FIRECRAWL_API_KEY` env), `apiUrl` (falls back to `FIRECRAWL_API_URL` or `https://api.firecrawl.dev`), `timeoutMs`, `maxRetries`, `backoffFactor`.

## When To Use What

- `search`: use when you start with a query and need discovery.
- `scrape`: use when you already have a URL and want page content.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions. Requires a `scrapeId` from a prior scrape.

## Search

### Why use it

Discover relevant pages from a query, then pick URLs to scrape or interact with. Constrain to a domain with `site:`, e.g. `site:docs.firecrawl.dev crawl webhooks`.

### Preferred SDK method

`client.search(query, options?)` → `Promise<SearchData>`

### Example

```ts
const results = await client.search("site:docs.firecrawl.dev webhook retries");
for (const item of results.web ?? []) {
  console.log(item.url, item.title);
}
```

### Return value

`SearchData` has optional arrays — `web`, `news`, `images`, `tools`. Each entry is either a lightweight result or a full `Document` when `scrapeOptions` hydrated the hit.

**Do not** access `result.data` — it does not exist. Web results are in `result.web`.

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | string (first arg) | Search query. Use `site:example.com` for domain-scoped results. |
| `options.sources` | `("web" \| "news" \| "images" \| "alexandria")[]` | Which sources to search. |
| `options.categories` | `("developer" \| "gov" \| "research" \| "pdf" \| "github")[]` | Filter results by category. |
| `options.limit` | number | Max number of results. |
| `options.tbs` | string | Time-based filter (e.g. `"qdr:d"`, `"qdr:w"`). |
| `options.location` | string | Localized results (e.g. `"San Francisco,California,United States"`). |
| `options.country` | string | ISO 3166-1 alpha-2 country code. |
| `options.ignoreInvalidURLs` | boolean | Drop URLs that cannot be scraped. |
| `options.timeout` | number | Request timeout in milliseconds. |
| `options.highlights` | boolean | Include highlight snippets. |
| `options.scrapeOptions` | `ScrapeOptions` | Scrape each search result (see Scrape parameters). |
| `options.includeDomains` | string[] | Only include these domains. |
| `options.excludeDomains` | string[] | Exclude these domains. |
| `options.enterprise` | `("default" \| "anon" \| "zdr")[]` | Enterprise controls. |
| `options.threatProtection` | ThreatProtectionOptions | Threat protection config. |
| `options.domainTools` | boolean | Include domain-matched Alexandria tools. |
| `options.toolDetail` | `"compact" \| "summary" \| "full"` | Tool description detail level. |

## Scrape

### Why use it

Use scrape when you already have a URL and want structured content in one or more formats.

### Preferred SDK method

`client.scrape(url, options?)` → `Promise<Document>`

### Example

```ts
const doc = await client.scrape("https://docs.firecrawl.dev", {
  formats: ["markdown"],
});
console.log(doc.markdown);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | string (first arg) | URL to scrape. |
| `options.formats` | FormatOption[] | Output formats (see below). |
| `options.headers` | Record&lt;string, string&gt; | Custom request headers. |
| `options.includeTags` | string[] | Only include specific HTML tags. |
| `options.excludeTags` | string[] | Exclude specific HTML tags. |
| `options.onlyMainContent` | boolean | Strip nav, footer, and boilerplate. |
| `options.timeout` | number | Timeout in milliseconds. |
| `options.waitFor` | number | Wait for page render (ms). |
| `options.mobile` | boolean | Use mobile viewport. |
| `options.parsers` | (string \| PDFParser \| ImageParser)[] | File parsing controls. |
| `options.actions` | ActionOption[] | Pre-scrape browser actions (see below). |
| `options.location` | `{ country?: string; languages?: string[] }` | Geo/language-aware scraping. |
| `options.skipTlsVerification` | boolean | Skip TLS verification. |
| `options.removeBase64Images` | boolean | Drop base64 images from markdown. |
| `options.fastMode` | boolean | Faster scrapes with reduced fidelity. |
| `options.blockAds` | boolean | Block ads and cookie popups. |
| `options.proxy` | `"basic" \| "stealth" \| "enhanced" \| "auto"` | Proxy control. |
| `options.maxAge` | number | Max cache age (ms). 0 = bypass. |
| `options.minAge` | number | Min cache age (ms). |
| `options.storeInCache` | boolean | Cache the result. |
| `options.profile` | `{ name: string; saveChanges?: boolean }` | Persistent browser profile. |
| `options.checkPromptInjection` | boolean | Scan for prompt injection (adds 4 credits). |
| `options.redactPII` | boolean \| RedactPIIOptions | Redact PII from output. |
| `options.threatProtection` | ThreatProtectionOptions | Threat protection config. |
| `options.auditMetadata` | `{ username: string }` | Audit trail metadata. |
| `options.lockdown` | boolean | Lockdown mode. |
| `options.domainTools` | boolean | Include domain-matched Alexandria tools. |
| `options.toolDetail` | `"compact" \| "summary" \| "full"` | Tool description detail level. |

### Format strings

`"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`

### Format objects

| Type | Required fields | Description |
|---|---|---|
| `{ type: "json", prompt?, schema? }` | At least `prompt` or `schema` | JSON extraction. Do not use `"json"` as a plain string — SDK rejects it. |
| `{ type: "question", question }` | `question` | Question-answer extraction. |
| `{ type: "highlights", query }` | `query` | Relevant source-text extraction. |
| `{ type: "screenshot", fullPage?, quality?, viewport? }` | — | Screenshot with options. |
| `{ type: "changeTracking", modes, schema?, prompt?, tag? }` | `modes` (`"git-diff"` / `"json"`) | Change tracking. |
| `{ type: "attributes", selectors }` | `selectors: [{ selector, attribute }]` | HTML attribute extraction. |

### Action types

| Type | Required fields | Description |
|---|---|---|
| `wait` | `milliseconds` or `selector` | Wait for time or element. |
| `click` | `selector` | Click an element. |
| `write` | `text` | Type text (click input first). |
| `press` | `key` | Press a keyboard key. |
| `scroll` | `direction` (`"up"` / `"down"`) | Scroll page or element. |
| `scrape` | — | Capture page content mid-action. |
| `screenshot` | — | Take a screenshot mid-action. |
| `executeJavascript` | `script` | Run JavaScript. |
| `pdf` | — | Generate PDF. Options: `format`, `landscape`, `scale`. |

### PDF parser options

`{ type: "pdf", mode?: "fast" | "auto" | "ocr", maxPages?, pages?, blocks?, pageMarkers? }`

## Interact

### Why use it

Control the browser session tied to a scrape job (via `metadata.scrapeId`). Use for clicks, form fills, or code execution after an initial scrape. Requires at least `code` or `prompt`.

### Preferred SDK method

`client.interact(jobId, args)` → `Promise<ScrapeExecuteResponse>`

### Example

```ts
const doc = await client.scrape("https://example.com", { formats: ["markdown"] });
const jobId = doc.metadata?.scrapeId;
if (!jobId) throw new Error("Missing scrapeId");

const result = await client.interact(jobId, {
  prompt: "Click the pricing tab and summarize the plans.",
});
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | string (first arg) | Scrape job ID from `document.metadata.scrapeId`. |
| `args.code` | string | Run code in the browser session (Playwright `page`). |
| `args.prompt` | string | Natural-language instruction for the browser agent. |
| `args.language` | `"python" \| "node" \| "bash"` | Runtime. Default: `"node"`. |
| `args.timeout` | number | Execution timeout in seconds. |

At least one of `code` or `prompt` must be non-empty.

### Stop session

`client.stopInteraction(jobId)` ends the browser session. Returns `{ success, sessionDurationMs?, creditsBilled?, error? }`.

## Notes

- Deprecated aliases: `scrapeExecute` → `interact`; `stopInteractiveBrowser`, `deleteScrapeBrowser` → `stopInteraction`.
- The default `Firecrawl` export is the v2 client; v1 is under `client.v1`.
- Zod schemas in `formats` are auto-converted to JSON Schema by the SDK.
- The package declares **Node.js >= 22** in `engines`.
