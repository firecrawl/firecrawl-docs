# Firecrawl Node.js Agent Quickstart

This file is the canonical quickstart for external agents building with Firecrawl in Node.js/TypeScript. It is generated from SDK source and the OpenAPI spec.

## Install

```bash
npm install firecrawl
```

## Authenticate

```javascript
import { Firecrawl } from 'firecrawl';

const app = new Firecrawl({ apiKey: "fc-YOUR-API-KEY" });
```

Or set the `FIRECRAWL_API_KEY` environment variable and omit `apiKey`:

```javascript
const app = new Firecrawl();
```

### Constructor options

| Option | Type | Default | Description |
|---|---|---|---|
| `apiKey` | `string` | `FIRECRAWL_API_KEY` env var | API key. Omit for keyless free tier (rate-limited per IP). |
| `apiUrl` | `string` | `"https://api.firecrawl.dev"` | API base URL. Falls back to `FIRECRAWL_API_URL` env var. |
| `timeoutMs` | `number` | — | Per-request timeout in milliseconds. |
| `maxRetries` | `number` | — | Max auto-retries for transient failures. |
| `backoffFactor` | `number` | — | Exponential backoff factor. |

## When To Use What

- **`search`** — you start with a query and need to discover pages. Returns ranked web results with optional full-page scraping.
- **`scrape`** — you already have a URL and want its content as markdown, HTML, JSON, or other formats.
- **`interact`** — the page needs post-scrape browser actions: clicking buttons, filling forms, navigating, or extracting dynamic content.

## Search

### Why use it

Search the web with a query and get structured results. Optionally scrape each result page for full content in one call.

### Preferred SDK method

```
app.search(query, options?)
```

### Example

```javascript
const results = await app.search("firecrawl web scraping", { limit: 5 });

for (const result of results.web) {
  console.log(result.title, result.url);
}
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `string` | **Required.** The search query string. |
| `limit` | `number` | Max results to return. Server default: `10`. |
| `sources` | `Array<"web" \| "news" \| "images" \| "alexandria" \| SourceObject>` | Which result sources to include. Default: `["web"]`. |
| `categories` | `Array<"github" \| "research" \| "pdf" \| "developer" \| CategoryObject>` | Narrow results by category. |
| `includeDomains` | `string[]` | Restrict results to these domains. Mutually exclusive with `excludeDomains`. |
| `excludeDomains` | `string[]` | Exclude results from these domains. Mutually exclusive with `includeDomains`. |
| `tbs` | `string` | Time-based search filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week). |
| `location` | `string` | Geo-target string (e.g. `"San Francisco,California,United States"`). |
| `country` | `string` | ISO 3166-1 alpha-2 country code (e.g. `"US"`). |
| `timeout` | `number` | Timeout in milliseconds. |
| `highlights` | `boolean` | Generate query-relevant highlights. Default: `true`. |
| `ignoreInvalidURLs` | `boolean` | Exclude URLs invalid for other Firecrawl endpoints. |
| `scrapeOptions` | `ScrapeOptions` | Full scrape options applied to each result page. |
| `domainTools` | `boolean` | Include Alexandria domain-matched contracts. |
| `enterprise` | `Array<"default" \| "anon" \| "zdr">` | Enterprise options. `"zdr"` for Zero Data Retention, `"anon"` for anonymized search. |
| `threatProtection` | `ThreatProtectionOptions` | Enterprise threat protection override. |
| `integration` | `string` | Integration identifier. |
| `origin` | `string` | Request attribution label. |

### Response

Returns `SearchData` with fields:

- `web` — array of web results (or `Document` if `scrapeOptions` was set)
- `news` — array of news results
- `images` — array of image results
- `tools` — array of discovered Alexandria tools

## Scrape

### Why use it

Fetch a single URL and get its content as markdown, HTML, JSON extract, screenshot, or other formats.

### Preferred SDK method

```
app.scrape(url, options?)
```

### Example

```javascript
const result = await app.scrape("https://example.com", {
  formats: ["markdown"],
});

console.log(result.markdown);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `string` | **Required.** The URL to scrape. |
| `formats` | `FormatOption[]` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`. Can also be config objects (e.g. `JsonFormat`, `ScreenshotFormat`). |
| `headers` | `Record<string, string>` | Custom HTTP request headers. |
| `includeTags` | `string[]` | HTML tags to include exclusively. |
| `excludeTags` | `string[]` | HTML tags to exclude. |
| `onlyMainContent` | `boolean` | Strip boilerplate (navbars, footers). |
| `timeout` | `number` | Timeout in milliseconds. |
| `waitFor` | `number` | Wait time in ms before scraping (for JS rendering). |
| `mobile` | `boolean` | Emulate a mobile device. |
| `parsers` | `Array<string \| PDFParser \| ImageParser>` | Parser configs (e.g. PDF parser with `maxPages`). |
| `actions` | `ActionOption[]` | Browser actions: `wait`, `click`, `write`, `press`, `scroll`, `scrape`, `executeJavascript`, `screenshot`, `pdf`. |
| `location` | `{ country?: string; languages?: string[] }` | Proxy routing location. |
| `skipTlsVerification` | `boolean` | Skip TLS certificate verification. |
| `removeBase64Images` | `boolean` | Remove base64 images from output. |
| `fastMode` | `boolean` | Faster scraping, may reduce accuracy. |
| `blockAds` | `boolean` | Block advertisements. |
| `proxy` | `"basic" \| "stealth" \| "enhanced" \| "auto" \| string` | Proxy mode. |
| `maxAge` | `number` | Use cached result if younger than this (ms). `0` bypasses cache. |
| `minAge` | `number` | Cache-only mode minimum age (ms). |
| `storeInCache` | `boolean` | Cache the scrape result. |
| `lockdown` | `boolean` | Serve only cached results; never make outbound requests. |
| `redactPII` | `boolean \| RedactPIIOptions` | Redact personally identifiable information. |
| `profile` | `{ name: string; saveChanges?: boolean }` | Persistent browser profile for session state. |
| `auditMetadata` | `{ username: string }` | User attribution for SIEM logging. |
| `domainTools` | `boolean` | Include Alexandria domain-tool contracts in `tools` field. |
| `threatProtection` | `ThreatProtectionOptions` | Enterprise threat protection override. |
| `integration` | `string` | Integration identifier. |
| `origin` | `string` | Request attribution label. |
| `autoResume` | `boolean` | SDK-only. Auto-retry on `processing_continues` for large documents. Default: `true`. |

## Interact

### Why use it

After scraping a page, interact with the live browser session — click buttons, fill forms, navigate, or extract dynamic content. Use a natural-language prompt or execute Playwright code directly.

### Preferred SDK method

```
app.interact(jobId, options)
```

To stop a session:

```
app.stopInteraction(jobId)
```

### Example

```javascript
const scrapeResult = await app.scrape("https://www.amazon.com", {
  formats: ["markdown"],
});
const scrapeId = scrapeResult.metadata?.scrapeId;

const response = await app.interact(scrapeId, {
  prompt: "Search for iPhone 16 Pro Max",
});
console.log(response.output);

const priceResponse = await app.interact(scrapeId, {
  prompt: "Click on the first result and tell me the price",
});
console.log(priceResponse.output);

await app.stopInteraction(scrapeId);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `string` | **Required.** The `scrapeId` from the scrape response's `metadata`. |
| `code` | `string` | Code to execute. Provide `code` or `prompt` (one is required). |
| `prompt` | `string` | Natural-language instruction for the browser agent. Provide `prompt` or `code`. |
| `language` | `"python" \| "node" \| "bash"` | Execution language. Default: `"node"`. |
| `timeout` | `number` | Execution timeout in seconds (1–300). Default: `30`. |
| `origin` | `string` | Request attribution label. |

### Response

Returns `ScrapeExecuteResponse` with fields:

- `success` — whether execution succeeded
- `output` — AI agent's response (when using `prompt`)
- `stdout` / `result` — standard output from code execution
- `stderr` — standard error from code execution
- `exitCode` — process exit code
- `liveViewUrl` — read-only live view of the browser
- `interactiveLiveViewUrl` — interactive live view (viewers can control the browser)
- `cdpUrl` — Chrome DevTools Protocol WebSocket URL

## Notes

- **Naming style**: camelCase for all parameters (e.g. `onlyMainContent`, `includeTags`).
- **Deprecated aliases**: `scrapeUrl()` → use `scrape()`. `scrapeExecute()` → use `interact()`. `stopInteractiveBrowser()` / `deleteScrapeBrowser()` → use `stopInteraction()`.
- **Keyless mode**: `scrape`, `search`, and `interact` work without an API key at a rate-limited free tier. Other methods require a key.
- **Auto-resume**: The SDK automatically retries scrape requests that return `processing_continues` for large documents (up to 5 retries / 20 min). Set `autoResume: false` to disable.
