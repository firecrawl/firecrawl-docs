# Firecrawl Node.js Agent Quickstart

This file is the canonical quickstart for external agents integrating with Firecrawl using the JavaScript/TypeScript SDK. It is generated from SDK source and the OpenAPI spec.

## Install

```bash
npm install @mendable/firecrawl-js
```

Requires Node.js >= 22.0.0.

## Authenticate

```typescript
import Firecrawl from "@mendable/firecrawl-js";

const firecrawl = new Firecrawl("fc-YOUR_API_KEY");
```

You can also pass an options object:

```typescript
const firecrawl = new Firecrawl({
  apiKey: "fc-YOUR_API_KEY",   // or set FIRECRAWL_API_KEY env var
  apiUrl: "https://api.firecrawl.dev", // or set FIRECRAWL_API_URL env var
  timeoutMs: 60000,
  maxRetries: 3,
  backoffFactor: 0.5,
});
```

Omitting `apiKey` falls back to the `FIRECRAWL_API_KEY` environment variable, then to a keyless free tier (rate-limited per IP).

## When To Use What

- **`search`**: Use when you start with a query and need to discover relevant pages. Returns URLs, snippets, and optionally scraped content for each result.
- **`scrape`**: Use when you already have a URL and want its content. Returns markdown, HTML, screenshots, extracted JSON, and more.
- **`interact`**: Use when a page requires post-scrape browser actions — clicking, filling forms, or running code in the browser session that `scrape` opened.

## Search

### Why use it

Search lets you discover relevant pages from a query. It returns web, news, and image results, and can optionally scrape each result page inline.

### Preferred SDK method

```typescript
firecrawl.search(query, options?)
```

### Example

```typescript
const results = await firecrawl.search("firecrawl web scraping API", {
  limit: 5,
  scrapeOptions: { formats: ["markdown"] },
});

for (const item of results.web ?? []) {
  console.log(item.title, item.url);
}
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `string` | **(required, first arg)** The search query. |
| `sources` | `Array<"web" \| "news" \| "images" \| "alexandria" \| SourceObject>` | Sources to search. Default: `["web"]`. |
| `categories` | `Array<"github" \| "research" \| "pdf" \| "developer" \| CategoryObject>` | Narrow web search by category. |
| `includeDomains` | `string[]` | Restrict results to these domains. Cannot combine with `excludeDomains`. |
| `excludeDomains` | `string[]` | Exclude results from these domains. Cannot combine with `includeDomains`. |
| `limit` | `number` | Max number of results. Default: 10 (API). |
| `tbs` | `string` | Time-based search filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week). |
| `location` | `string` | Location string for geo-targeting (e.g. `"San Francisco,California,United States"`). |
| `country` | `string` | ISO 3166-1 alpha-2 country code (e.g. `"US"`). |
| `ignoreInvalidURLs` | `boolean` | Ignore invalid URLs in results. |
| `timeout` | `number` | Timeout in milliseconds. |
| `highlights` | `boolean` | Generate query-relevant highlights. Default: `true`. |
| `scrapeOptions` | `ScrapeOptions` | Options for scraping each result page. See Scrape parameters below. |
| `enterprise` | `Array<"default" \| "anon" \| "zdr">` | Enterprise search options (Zero Data Retention, anonymized). |
| `threatProtection` | `ThreatProtectionOptions` | Per-request threat protection override (enterprise). |
| `domainTools` | `boolean` | Include Alexandria tool contracts matched to result domains. |
| `toolDetail` | `"compact" \| "summary" \| "full"` | Tool detail level. Default: `"compact"`. |
| `integration` | `string` | Integration identifier. |
| `origin` | `string` | Origin identifier. |

**Returns:** `SearchData` with optional `.web`, `.news`, `.images`, and `.tools` arrays. Accessing `.data` throws an error directing you to the grouped properties.

## Scrape

### Why use it

Scrape extracts content from a single URL. You get markdown by default, and can request HTML, screenshots, structured JSON extraction, and more.

### Preferred SDK method

```typescript
firecrawl.scrape(url, options?)
```

### Example

```typescript
const doc = await firecrawl.scrape("https://example.com", {
  formats: ["markdown", "links"],
  onlyMainContent: true,
});

console.log(doc.markdown);
console.log(doc.links);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `string` | **(required, first arg)** The URL to scrape. |
| `formats` | `FormatOption[]` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"json"`, `"changeTracking"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`, or typed format objects (`JsonFormat`, `ScreenshotFormat`, `QuestionFormat`, `HighlightsFormat`, etc.). Default: `["markdown"]`. |
| `onlyMainContent` | `boolean` | Only return main content, excluding navbars/footers. Default: `true` (API). |
| `includeTags` | `string[]` | HTML tags to exclusively include. |
| `excludeTags` | `string[]` | HTML tags to exclude. |
| `headers` | `Record<string, string>` | Custom HTTP headers to send with the request. |
| `timeout` | `number` | Timeout in milliseconds. Default: `60000`. Min: 1000, Max: 300000. |
| `waitFor` | `number` | Wait time in ms before scraping (for JS rendering). |
| `mobile` | `boolean` | Use mobile user agent. |
| `parsers` | `Array<string \| PDFParser \| ImageParser>` | Document parsers (e.g. `"pdf"`). PDF parser supports `mode`, `maxPages`, `pages`, `blocks`, `pageMarkers`. |
| `actions` | `ActionOption[]` | Browser actions to perform: `wait`, `click`, `write`, `press`, `scroll`, `screenshot`, `scrape`, `executeJavascript`, `pdf`. |
| `location` | `LocationConfig` | Location config with `country` and `languages`. |
| `skipTlsVerification` | `boolean` | Skip TLS verification. Default: `true` (API). |
| `removeBase64Images` | `boolean` | Remove base64 images from output. Default: `true` (API). |
| `blockAds` | `boolean` | Block ads and cookie popups. Default: `true` (API). |
| `proxy` | `"basic" \| "stealth" \| "enhanced" \| "auto" \| string` | Proxy mode. Default: `"auto"` (API). |
| `maxAge` | `number` | Max cache age in ms. Use cached result if younger. Default: `172800000` (2 days). |
| `minAge` | `number` | Min cache age in ms. Set to `1` for any cache. |
| `storeInCache` | `boolean` | Store result in cache. Default: `true` (API). |
| `lockdown` | `boolean` | Serve only cached results, never make outbound requests. |
| `fastMode` | `boolean` | Enable fast mode. |
| `redactPII` | `boolean \| RedactPIIOptions` | Redact PII from markdown. Options: `mode` (`"accurate"`, `"aggressive"`, `"fast"`), `entities`, `replaceStyle` (`"tag"`, `"mask"`, `"remove"`). |
| `profile` | `{ name: string; saveChanges?: boolean }` | Persistent browser profile for state across sessions. |
| `auditMetadata` | `{ username: string }` | User attribution for SIEM logging. |
| `threatProtection` | `ThreatProtectionOptions` | Per-request threat protection override (enterprise). |
| `domainTools` | `boolean` | Include Alexandria tool contracts matched to the scraped domain. |
| `toolDetail` | `"compact" \| "summary" \| "full"` | Tool detail level. Default: `"summary"`. |
| `integration` | `string` | Integration identifier. |
| `origin` | `string` | Origin identifier. |
| `autoResume` | `boolean` | SDK-only. Auto-resume for large documents that outlive the request window. Default: `true` (implicitly). Never sent to API. |

**Returns:** `Document` with fields like `markdown`, `html`, `rawHtml`, `links`, `screenshot`, `metadata`, `json`, `actions`, etc.

## Interact

### Why use it

After scraping a page, the browser session stays alive. Use `interact` to execute code or natural-language prompts against that session — click buttons, fill forms, navigate, or extract additional data.

### Preferred SDK method

```typescript
firecrawl.interact(jobId, args)
```

To stop the session:

```typescript
firecrawl.stopInteraction(jobId)
```

### Example

```typescript
const doc = await firecrawl.scrape("https://example.com", {
  formats: ["markdown"],
});

const jobId = doc.metadata?.scrapeId;

const result = await firecrawl.interact(jobId, {
  code: 'document.querySelector("button.load-more").click();',
  language: "node",
  timeout: 30,
});

console.log(result.stdout);

await firecrawl.stopInteraction(jobId);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `string` | **(required, first arg)** The scrape job ID from `metadata.scrapeId` of a prior `scrape()` response. |
| `code` | `string` | Code to execute in the browser session. Provide either `code` or `prompt`. |
| `prompt` | `string` | Natural-language instruction for the browser agent. Provide either `code` or `prompt`. |
| `language` | `"python" \| "node" \| "bash"` | Language for code execution. Default: `"node"`. |
| `timeout` | `number` | Execution timeout in seconds. Min: 1, Max: 300. Default: `30` (API). |
| `origin` | `string` | Origin identifier. |

**Returns:** `ScrapeExecuteResponse` with `success`, `stdout`, `result`, `stderr`, `exitCode`, `killed`, `error`, `output` (for prompt mode), `liveViewUrl`, `interactiveLiveViewUrl`, `cdpUrl`.

## Notes

- All parameter names use **camelCase**.
- The `search` response groups results under `.web`, `.news`, `.images`, `.tools` — accessing `.data` throws a migration error.
- The `interact` method requires a `scrapeId` from a prior `scrape()` call's `metadata`.
- **Deprecated aliases** (use the preferred names above):
  - `scrapeExecute()` → `interact()`
  - `stopInteractiveBrowser()` / `deleteScrapeBrowser()` → `stopInteraction()`
  - `scrapeUrl()` → `scrape()`
