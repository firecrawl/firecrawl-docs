# Firecrawl Node.js Agent Quickstart

This file is the canonical quickstart for external agents integrating Firecrawl with Node.js/TypeScript. It is generated from SDK source plus OpenAPI and covers every confirmed parameter.

## Install

```bash
npm install @mendable/firecrawl-js
```

## Authenticate

```typescript
import Firecrawl from "@mendable/firecrawl-js";

const app = new Firecrawl("fc-YOUR-API-KEY");
```

Or with options:

```typescript
const app = new Firecrawl({
  apiKey: "fc-YOUR-API-KEY",
  apiUrl: "https://api.firecrawl.dev", // optional, override for self-hosted
  timeoutMs: 30000,                    // optional, per-request timeout in ms
  maxRetries: 3,                       // optional
  backoffFactor: 2,                    // optional, exponential backoff factor
});
```

Set `FIRECRAWL_API_KEY` as an environment variable to skip passing it directly:

```typescript
const app = new Firecrawl();
```

## When To Use What

- **`search`**: Use when you start with a query and need to discover relevant pages across the web.
- **`scrape`**: Use when you already have a URL and want the page content in a structured format.
- **`interact`**: Use when the page requires clicks, form fills, or other post-scrape browser actions.

## Search

### Why use it

Search the web for a query and get structured results with optional full-page content. Ideal for discovery workflows where you don't yet know which URLs matter.

### Preferred SDK method

```typescript
app.search(query, options?)
```

### Example

```typescript
const results = await app.search("firecrawl web scraping", { limit: 5 });

for (const result of results.web ?? []) {
  console.log(result.title, result.url);
}
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `query` | `string` | Search query (first positional argument, required). | Always. |
| `limit` | `number` | Max number of results. | Control result count. |
| `sources` | `("web" \| "news" \| "images" \| "alexandria")[]` | Which result types to include. | Filter to news, images, or Alexandria tool results. |
| `categories` | `("github" \| "research" \| "pdf" \| "developer")[]` | Narrow web search to specific categories. `"research"` filters to ~14 academic domains. | Target specific content types. |
| `includeDomains` | `string[]` | Restrict results to these domains. Mutually exclusive with `excludeDomains`. | Scope search to known sources. |
| `excludeDomains` | `string[]` | Exclude results from these domains. | Filter out unwanted sources. |
| `tbs` | `string` | Time-based search filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week). | Restrict to recent content. |
| `location` | `string` | Location string for geo-targeting. | Get location-specific results. |
| `country` | `string` | ISO 3166-1 alpha-2 country code. | Geo-target results by country. |
| `ignoreInvalidURLs` | `boolean` | Skip invalid URLs instead of failing. | Increase robustness. |
| `timeout` | `number` | Timeout in milliseconds. | Override default timeout. |
| `highlights` | `boolean` | Generate query-relevant highlights for results. Default: `true`. | Disable if you only need URLs/titles. |
| `scrapeOptions` | `ScrapeOptions` | Options applied when scraping each result page (same shape as scrape parameters). | Get full page content alongside search results. |

### Return type

`SearchData` with properties: `web`, `news`, `images`, `tools`, `warning`.

## Scrape

### Why use it

Fetch a single URL and get its content as markdown, HTML, screenshots, or structured data. The core building block for content extraction.

### Preferred SDK method

```typescript
app.scrape(url, options?)
```

### Example

```typescript
const doc = await app.scrape("https://example.com", {
  formats: ["markdown"],
});
console.log(doc.markdown);
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `url` | `string` | URL to scrape (first positional argument, required). | Always. |
| `formats` | `FormatOption[]` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`. Also accepts format config objects like `JsonFormat`, `ScreenshotFormat`. | Control what data you get back. |
| `headers` | `Record<string, string>` | Custom HTTP headers sent with the scrape request. | Set cookies, auth tokens, or user-agent. |
| `includeTags` | `string[]` | Only include content from these HTML tags. | Extract specific page sections. |
| `excludeTags` | `string[]` | Exclude content from these HTML tags. | Remove unwanted elements. |
| `onlyMainContent` | `boolean` | Strip navigation, headers, and footers. | Get clean article content. |
| `timeout` | `number` | Timeout in milliseconds. | Override default timeout. |
| `waitFor` | `number` | Wait N milliseconds before scraping (for JS rendering). | Handle dynamic content. |
| `mobile` | `boolean` | Emulate a mobile device viewport. | Get mobile version of pages. |
| `parsers` | `(string \| PDFParser \| ImageParser)[]` | File parser config. PDFParser supports `mode`, `maxPages`, `pages`, `blocks`, `pageMarkers`. | Control PDF/image parsing behavior. |
| `actions` | `ActionOption[]` | Browser actions: `wait`, `screenshot`, `click`, `write`, `press`, `scroll`, `scrape`, `executeJavascript`, `pdf`. | Automate interactions before scraping. |
| `location` | `{ country?: string; languages?: string[] }` | Geolocation config for proxy routing. | Get geo-specific content. |
| `skipTlsVerification` | `boolean` | Skip TLS certificate verification. | Scrape sites with self-signed certs. |
| `removeBase64Images` | `boolean` | Strip base64-encoded images from output. | Reduce response size. |
| `blockAds` | `boolean` | Block advertisements and cookie popups. | Get cleaner content. |
| `proxy` | `"basic" \| "stealth" \| "enhanced" \| "auto"` | Proxy type. | Bypass blocks or access geo-restricted content. |
| `maxAge` | `number` | Max cache age in ms. `0` bypasses cache. | Control content freshness. |
| `minAge` | `number` | Min age in ms for cache-only mode. | Prefer cached results. |
| `storeInCache` | `boolean` | Store the result in Firecrawl's cache. | Enable caching for repeated scrapes. |
| `lockdown` | `boolean` | Only serve cached results; no outbound requests. | Use only cached data. |
| `redactPII` | `boolean \| RedactPIIOptions` | Redact personally identifiable information. Options: `mode`, `entities`, `replaceStyle`. | Handle sensitive content. |
| `profile` | `{ name: string; saveChanges?: boolean }` | Persistent browser profile for cookies/state. | Maintain login sessions across scrapes. |
| `auditMetadata` | `{ username: string }` | User attribution for SIEM logging. | Enterprise audit trails. |
| `autoResume` | `boolean` | SDK-only. Auto-resume large documents that time out. Default: `true`. Set `false` to surface timeout errors immediately. | Control retry behavior for large pages. |

### Return type

`Document` with fields: `markdown`, `html`, `rawHtml`, `json`, `summary`, `metadata`, `links`, `images`, `screenshot`, `audio`, `video`, `actions`, `warning`, and more.

## Interact

### Why use it

Execute code or natural-language prompts in a live browser session bound to a prior scrape job. Use it for clicking buttons, filling forms, navigating SPAs, or extracting dynamic content that requires interaction.

### Preferred SDK method

```typescript
app.interact(jobId, args)
```

### Example

```typescript
const doc = await app.scrape("https://www.amazon.com", {
  formats: ["markdown"],
});
const jobId = doc.metadata.scrapeId;

const response = await app.interact(jobId, {
  prompt: "Search for iPhone 16 Pro Max",
});
console.log(response.output);

await app.stopInteraction(jobId);
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `jobId` | `string` | Scrape job ID from a prior scrape (from `metadata.scrapeId`). Required, first positional argument. | Always. |
| `code` | `string` | Code to execute in the browser sandbox. At least one of `code` or `prompt` is required. | Run specific browser automation code. |
| `prompt` | `string` | Natural-language instruction for the browser agent. At least one of `code` or `prompt` is required. | Describe what you want in plain English. |
| `language` | `"python" \| "node" \| "bash"` | Language for `code` execution. Default: `"node"`. | Match your code's language. |
| `timeout` | `number` | Execution timeout in seconds (1–300). | Increase for long-running interactions. |

### Stop interaction

```typescript
await app.stopInteraction(jobId);
```

Stops the browser session and releases resources. Maps to `DELETE /scrape/{jobId}/interact`.

### Return type

`ScrapeExecuteResponse` with fields: `success`, `output`, `stdout`, `result`, `stderr`, `exitCode`, `killed`, `error`.

## Notes

- **Naming style**: All parameters use camelCase.
- **Deprecated aliases**: `scrapeUrl()` → use `scrape()`. `scrapeExecute()` → use `interact()`. `stopInteractiveBrowser()` / `deleteScrapeBrowser()` → use `stopInteraction()`.
- **Async only**: All methods return Promises.
- **Auto-resume**: The `scrape()` method automatically retries when the server needs more processing time (up to 5 retries / 20 min). Disable with `autoResume: false`.
- **Keyless mode**: Omitting the API key enables a free tier with IP-based rate limiting.
- **Search `.data` removed**: Access results via `.web`, `.news`, `.images`, or `.tools` — not `.data`.
