# Firecrawl Node Agent Quickstart

This is the canonical quickstart for external agents using the Firecrawl Node/TypeScript SDK. It covers `search`, `scrape`, and `interact` — the three endpoints agents need most. Generated from SDK source (`@mendable/firecrawl-js` v4.x) and the Firecrawl OpenAPI spec.

## Install

```bash
npm install @mendable/firecrawl-js
```

## Authenticate

```typescript
import Firecrawl from "@mendable/firecrawl-js";

const client = new Firecrawl("fc-YOUR-API-KEY");
// Or omit the key for keyless free tier (rate-limited per IP):
// const client = new Firecrawl();
```

The API key can also be set via the `FIRECRAWL_API_KEY` environment variable. The base URL defaults to `https://api.firecrawl.dev` and can be overridden with `FIRECRAWL_API_URL` or via the options object.

## When To Use What

- **`search`** — Start here when you have a query and need to discover relevant URLs and content from the web.
- **`scrape`** — Use when you already have a specific URL and want its page content as markdown, HTML, structured JSON, or other formats.
- **`interact`** — Use after a scrape when the page needs further browser actions: clicking buttons, filling forms, or running code in the live browser session.

## Search

### Why use it

Search the web with a natural-language query and get back structured results with URLs, titles, descriptions, and optionally full scraped content for each result.

### Preferred SDK method

```typescript
client.search(query, options?)
```

### Example

```typescript
const results = await client.search("firecrawl web scraping API", {
  limit: 5,
});

for (const result of results.web ?? []) {
  console.log(result.url, result.title);
}
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `string` | **Required.** The search query. |
| `limit` | `number` | Maximum number of results to return. Default: `10`. |
| `sources` | `Array<"web" \| "news" \| "images" \| "alexandria">` | Sources to search. Default: `["web"]`. |
| `includeDomains` | `string[]` | Restrict results to these domains. |
| `excludeDomains` | `string[]` | Exclude results from these domains. |
| `tbs` | `string` | Time-based filter. `"qdr:h"` (past hour), `"qdr:d"` (past day), `"qdr:w"` (past week), `"qdr:m"` (past month), `"qdr:y"` (past year). |
| `location` | `string` | Geographic location for results (e.g. `"San Francisco,California,United States"`). |
| `country` | `string` | ISO country code for geo-targeting (e.g. `"US"`). Default: `"US"`. |
| `highlights` | `boolean` | Generate query-relevant highlights. Default: `true`. |
| `timeout` | `number` | Timeout in milliseconds. Default: `60000`. |
| `ignoreInvalidURLs` | `boolean` | Exclude URLs that are invalid for other Firecrawl endpoints. |
| `categories` | `Array<"github" \| "research" \| "pdf" \| "developer">` | Filter results by category. |
| `scrapeOptions` | `ScrapeOptions` | Options applied when scraping each search result page. |
| `domainTools` | `boolean` | Include tool contracts matched to result domains. |
| `toolDetail` | `"compact" \| "summary" \| "full"` | Detail level for discovered tools. |
| `enterprise` | `Array<"default" \| "anon" \| "zdr">` | Enterprise options for Zero Data Retention. |
| `threatProtection` | `ThreatProtectionOptions` | Threat protection configuration. |
| `integration` | `string` | Integration identifier for telemetry. |
| `origin` | `string` | Origin label for telemetry. |

**Return type:** `SearchData` with properties `.web`, `.news`, `.images`, `.tools` (each an optional array). Note: there is no `.data` property — access results by source type.

## Scrape

### Why use it

Fetch a single URL and get back clean markdown, HTML, structured JSON, screenshots, or other formats. The SDK handles retries and auto-resume for large documents.

### Preferred SDK method

```typescript
client.scrape(url, options?)
```

### Example

```typescript
const doc = await client.scrape("https://example.com", {
  formats: ["markdown"],
});

console.log(doc.markdown);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `string` | **Required.** The URL to scrape. |
| `formats` | `FormatOption[]` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"json"`, `"audio"`, `"video"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"changeTracking"`. Also accepts format objects like `JsonFormat` for structured extraction. |
| `headers` | `Record<string, string>` | Custom HTTP headers (cookies, user-agent, etc.). |
| `includeTags` | `string[]` | Only include content from these HTML tags. |
| `excludeTags` | `string[]` | Exclude content from these HTML tags. |
| `onlyMainContent` | `boolean` | Strip headers, navs, footers. Default: `true` (API). |
| `timeout` | `number` | Timeout in milliseconds. Default: `60000`. Min: `1000`. |
| `waitFor` | `number` | Delay in milliseconds before fetching, for JS-rendered pages. |
| `mobile` | `boolean` | Emulate a mobile device. |
| `actions` | `ActionOption[]` | Browser actions to run before content grab (click, scroll, type, wait, screenshot, scrape, execute JS). |
| `location` | `{ country?: string; languages?: string[] }` | Proxy location and language settings. |
| `skipTlsVerification` | `boolean` | Skip TLS certificate verification. |
| `removeBase64Images` | `boolean` | Remove base64 images from markdown. Default: `true` (API). |
| `fastMode` | `boolean` | Faster scraping with reduced accuracy. |
| `blockAds` | `boolean` | Block ads and cookie popups. Default: `true` (API). |
| `proxy` | `"basic" \| "stealth" \| "enhanced" \| "auto"` | Proxy type. Default: `"auto"` (API). |
| `maxAge` | `number` | Return cached content if younger than this (milliseconds). Default: `172800000`. |
| `storeInCache` | `boolean` | Store the result in Firecrawl's cache. Default: `true` (API). |
| `lockdown` | `boolean` | Only serve cached results, never make outbound request. |
| `parsers` | `Array<string \| PDFParser \| ImageParser>` | File processing controls (e.g. PDF parsing mode). |
| `redactPII` | `boolean \| RedactPIIOptions` | Redact personally identifiable information. |
| `threatProtection` | `ThreatProtectionOptions` | Threat protection settings. |
| `auditMetadata` | `{ username: string }` | User attribution for SIEM logging. |
| `profile` | `{ name: string; saveChanges?: boolean }` | Persistent browser storage across sessions. |
| `domainTools` | `boolean` | Include tool contracts matched to the scraped domain. |
| `toolDetail` | `"compact" \| "summary" \| "full"` | Detail level for discovered tools. |
| `integration` | `string` | Integration identifier. |
| `origin` | `string` | Origin label for telemetry. |

**SDK-only option:**

| Parameter | Type | Description |
|---|---|---|
| `autoResume` | `boolean` | Auto-retry on `processing_continues` timeout responses for large documents. Default: `true`. |

## Interact

### Why use it

Continue interacting with the same browser state from a previous scrape. Execute code or send a natural-language prompt to an AI agent that controls the browser. Useful for clicking buttons, filling forms, navigating SPAs, or extracting data that requires interaction.

### Preferred SDK method

```typescript
client.interact(jobId, options)
```

### Example

```typescript
// First, scrape a page
const doc = await client.scrape("https://example.com", {
  formats: ["markdown"],
});
const jobId = doc.metadata?.scrapeId;

// Then interact with the live browser session
const result = await client.interact(jobId, {
  code: 'const title = await page.title(); JSON.stringify({ title });',
  language: "node",
  timeout: 30,
});

console.log(result.result);

// Or use a natural-language prompt
const aiResult = await client.interact(jobId, {
  prompt: "Click the pricing tab and tell me the Pro plan price",
  timeout: 60,
});

console.log(aiResult.output);

// Clean up when done
await client.stopInteraction(jobId);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `string` | **Required.** The scrape job ID from `data.metadata.scrapeId` in the scrape response. |
| `code` | `string` | Code to execute in the browser sandbox. Required if `prompt` is not set. |
| `prompt` | `string` | Natural-language task for the AI browser agent. Required if `code` is not set. |
| `language` | `"python" \| "node" \| "bash"` | Language for `code` execution. Default: `"node"`. |
| `timeout` | `number` | Execution timeout in seconds (1–300). Default: `30`. |
| `origin` | `string` | Origin label for telemetry. |

**Stop method:** `client.stopInteraction(jobId)` — call this to end the browser session when done.

## Notes

- All parameter names use **camelCase** (e.g. `onlyMainContent`, `includeTags`, `scrapeOptions`).
- `SearchData` has no `.data` property — access results via `.web`, `.news`, `.images`, or `.tools`.
- The `scrape` method also supports Alexandria tool execution (pass `alexandria` instead of `url`) for provider-catalogued tools.
- **Deprecated aliases** (use the preferred names instead):
  - `scrapeExecute()` → `interact()`
  - `stopInteractiveBrowser()` / `deleteScrapeBrowser()` → `stopInteraction()`
  - `scrapeUrl()` → `scrape()`
