# Firecrawl Node.js Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`firecrawl` JS SDK) and the v2 OpenAPI spec. Method names, parameters, and types match the SDK public API.

## Install

```bash
npm install firecrawl
```

## Authenticate

```ts
import { Firecrawl } from "firecrawl";

const client = new Firecrawl({
  apiKey: process.env.FIRECRAWL_API_KEY,
});
```

## When To Use What

- `search`: use when you start with a query and need discovery. Returns web, news, and image results.
- `scrape`: use when you already have a URL and want page content in one or more formats.
- `interact`: use when the page needs clicks, forms, or post-scrape browser actions. Requires a `scrapeId` from a prior scrape.

## Search

### Why use it

Discover relevant pages from a query, then pick URLs to scrape or interact with. Use `site:example.com` to constrain results to a single domain.

### Preferred SDK method

`client.search(query, options?)` → `Promise<SearchData>`

### Example

```ts
const results = await client.search("site:docs.firecrawl.dev crawl webhooks", {
  sources: ["web"],
  limit: 5,
  scrapeOptions: {
    formats: ["markdown"],
    onlyMainContent: true,
  },
});

for (const hit of results.web ?? []) {
  console.log(hit.url, hit.title);
}
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `query` | string | Search query. Use `site:domain` to scope. | Always required. |
| `options.sources` | array | `"web"`, `"news"`, `"images"`, or typed objects like `{ type: "web" }` | Control which result buckets are returned. |
| `options.categories` | array | `"developer"`, `"research"`, `"pdf"`, or typed objects | Filter results by category. |
| `options.limit` | number | Maximum number of results. | Cap result count. |
| `options.tbs` | string | Time-based filter (e.g. `"qdr:d"`, `"qdr:w"`). | Filter by recency. |
| `options.location` | string | Localized results (e.g. `"San Francisco,California,United States"`). | Geo-targeted search. |
| `options.country` | string | ISO 3166-1 alpha-2 country code. | Country-level targeting. |
| `options.ignoreInvalidURLs` | boolean | Drop URLs that cannot be scraped. | Clean up results. |
| `options.timeout` | number | Request timeout in milliseconds. | Long-running searches. |
| `options.scrapeOptions` | ScrapeOptions | Scrape each search result (same fields as scrape `options`). | Hydrate search hits with content. |
| `options.includeDomains` | string[] | Only include results from these domains. | Domain allowlist. |
| `options.excludeDomains` | string[] | Exclude results from these domains. | Domain blocklist. |
| `options.highlights` | boolean | Include highlights. Default `true`. | Toggle highlight snippets. |

**Return value:** `SearchData` has optional arrays — `web`, `news`, `images`. Do not access `result.data`; results are in `result.web`, etc.

## Scrape

### Why use it

Fetch structured content from a known URL in one or more formats (markdown, HTML, JSON extraction, screenshots, etc.).

### Preferred SDK method

`client.scrape(url, options?)` → `Promise<Document>`

### Example

```ts
const doc = await client.scrape("https://example.com/pricing", {
  formats: [
    "markdown",
    { type: "json", prompt: "Extract plan names and prices." },
  ],
  onlyMainContent: true,
  waitFor: 1000,
});

console.log(doc.markdown);
console.log(doc.json);
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `url` | string | Page URL to scrape. | Always required. |
| `options.formats` | array | Output formats. Plain strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"attributes"`, `"branding"`, `"audio"`, `"video"`. Object forms: `{ type: "json", prompt?, schema? }`, `{ type: "question", question }`, `{ type: "highlights", query }`, `{ type: "screenshot", fullPage?, quality?, viewport? }`, `{ type: "changeTracking", modes, schema?, prompt?, tag? }`, `{ type: "attributes", selectors: [{ selector, attribute }] }`. Note: plain `"json"` string is rejected by the SDK — use the object form. | Choose output formats. |
| `options.headers` | Record<string, string> | Custom HTTP headers. | Auth or custom user-agent. |
| `options.includeTags` | string[] | Only include these HTML tags. | Narrow content extraction. |
| `options.excludeTags` | string[] | Exclude these HTML tags. | Remove boilerplate elements. |
| `options.onlyMainContent` | boolean | Strip nav, footer, and boilerplate. | Cleaner output. |
| `options.timeout` | number | Timeout in milliseconds. | Long-loading pages. |
| `options.waitFor` | number | Wait for page to render (ms). | JS-heavy pages. |
| `options.mobile` | boolean | Use mobile viewport. | Mobile-specific content. |
| `options.parsers` | array | Parser controls. E.g. `"pdf"` or `{ type: "pdf", mode: "auto", maxPages: 5 }`. | PDF or file parsing. |
| `options.actions` | array | Pre-scrape browser actions. Types: `wait`, `click`, `write`, `press`, `scroll`, `screenshot`, `scrape`, `executeJavascript`, `pdf`. | Cookie banners, login flows. |
| `options.location` | object | `{ country, languages }` for geo-aware scraping. | Localized content. |
| `options.skipTlsVerification` | boolean | Skip TLS verification. | Self-signed certs. |
| `options.removeBase64Images` | boolean | Drop base64 images from markdown. | Reduce output size. |
| `options.fastMode` | boolean | Faster scrapes, reduced fidelity. | Speed over completeness. |
| `options.blockAds` | boolean | Block ads and cookie popups. | Cleaner pages. |
| `options.proxy` | string | `"basic"`, `"stealth"`, `"enhanced"`, `"auto"`, or a custom URL. | Geo-restricted or bot-protected sites. |
| `options.maxAge` | number | Use cached data up to this age (ms). | Reduce API calls. |
| `options.storeInCache` | boolean | Cache the result. | Enable future cache hits. |
| `options.profile` | object | `{ name, saveChanges? }` for persistent browser profile. | Maintain login state across scrapes. |

## Interact

### Why use it

Control the browser session tied to a scrape job. Use it for clicks, form fills, code execution, or natural-language browser instructions. Requires a `scrapeId` from a prior scrape response.

### Preferred SDK method

`client.interact(jobId, args)` → `Promise<ScrapeExecuteResponse>`

### Example

```ts
const doc = await client.scrape("https://example.com", { formats: ["markdown"] });
const jobId = doc.metadata?.scrapeId;
if (!jobId) throw new Error("Missing scrapeId");

const result = await client.interact(jobId, {
  prompt: "Click the pricing tab and summarize the plans.",
});

console.log(result.output);

// When done, stop the session
await client.stopInteraction(jobId);
```

### Parameters

| Parameter | Type | Description | When to use |
|---|---|---|---|
| `jobId` | string | Scrape job ID from `document.metadata.scrapeId`. | Always required. |
| `args.code` | string | Code to run in the browser session (e.g. Playwright `page` usage). | Programmatic browser control. |
| `args.prompt` | string | Natural-language instruction for the browser agent. | Describe what to do in plain English. |
| `args.language` | string | Runtime: `"python"`, `"node"`, `"bash"`. Default: `"node"`. | Choose execution runtime. |
| `args.timeout` | number | Execution timeout in seconds. | Long-running interactions. |

At least one of `code` or `prompt` must be provided (SDK throws otherwise).

**Stop session:** `client.stopInteraction(jobId)` ends the browser session and returns billing info.

## Notes

- Deprecated aliases: `scrapeExecute` → `interact`; `stopInteractiveBrowser` / `deleteScrapeBrowser` → `stopInteraction`.
- The default `Firecrawl` export is the v2 client.
- Zod schemas passed to `formats` (for `json` or `changeTracking`) are converted to JSON Schema by the SDK.
- `search()` returns `SearchData` with `web`, `news`, `images` arrays — not a flat `data` array.
