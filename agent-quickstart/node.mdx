# Firecrawl Node.js Agent Quickstart

This file is the canonical quickstart for external agents integrating with Firecrawl using the Node.js/TypeScript SDK. It is generated from SDK source plus OpenAPI.

## Install

```bash
npm install @mendable/firecrawl-js
```

## Authenticate

```typescript
import FirecrawlApp from "@mendable/firecrawl-js";

const firecrawl = new FirecrawlApp({ apiKey: "fc-YOUR_API_KEY" });
```

## When To Use What

- **search** — Use when you start with a query and need to discover relevant URLs and content across the web.
- **scrape** — Use when you already have a URL and want to extract page content in structured formats.
- **interact** — Use when the page needs post-scrape browser actions like clicking, typing, or running code in the browser session.

## Search

### Why use it

Search combines web search with optional scraping of each result. It returns structured results from multiple sources (web, news, images) and can scrape each result page in the same call.

### Preferred SDK method

```typescript
firecrawl.search(query, options?)
```

### Example

```typescript
const results = await firecrawl.search("firecrawl web scraping", {
  limit: 5,
  scrapeOptions: { formats: ["markdown"] },
});

for (const item of results.data?.web ?? []) {
  console.log(item.url, item.title);
}
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `string` | **Required.** The search query (max 500 chars). |
| `limit` | `number` | Max results to return per source type. Default: `10`, max: `100`. |
| `sources` | `Array<string \| object>` | Sources to search: `"web"`, `"news"`, `"images"`, `"alexandria"`. Default: `["web"]`. |
| `categories` | `Array<string \| CategoryOption>` | Filter results by category: `"developer"`, `"research"`, `"pdf"`, `"gov"`. |
| `includeDomains` | `string[]` | Restrict results to these domains (hostnames only). Cannot combine with `excludeDomains`. |
| `excludeDomains` | `string[]` | Exclude results from these domains (hostnames only). Cannot combine with `includeDomains`. |
| `tbs` | `string` | Time-based filter. E.g., `"qdr:d"` (past day), `"qdr:w"` (past week), `"qdr:m"` (past month). |
| `location` | `string` | Location for search results, e.g., `"San Francisco,California,United States"`. |
| `country` | `string` | ISO country code for geo-targeting, e.g., `"US"`. Default: `"US"`. |
| `ignoreInvalidURLs` | `boolean` | Exclude URLs invalid for other Firecrawl endpoints. Default: `false`. |
| `timeout` | `number` | Timeout in milliseconds. Default: `60000`. |
| `highlights` | `boolean` | Generate query-relevant highlights. Default: `true`. |
| `scrapeOptions` | `ScrapeOptions` | Options applied to scraping each result page. |
| `domainTools` | `boolean` | Include domain-matched tool contracts alongside results. |
| `toolDetail` | `"compact" \| "summary" \| "full"` | Detail level for tool contracts. Default: `"compact"`. |
| `enterprise` | `Array<"anon" \| "zdr">` | Enterprise ZDR options. Must be enabled for your team. |

## Scrape

### Why use it

Scrape fetches a single URL and returns page content in one or more formats (markdown, HTML, JSON extraction, screenshots, etc.). Use it when you already know which page you need.

### Preferred SDK method

```typescript
firecrawl.scrape(url, options?)
```

### Example

```typescript
const doc = await firecrawl.scrape("https://example.com", {
  formats: ["markdown", "links"],
  onlyMainContent: true,
});

console.log(doc.markdown);
console.log(doc.links);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `string` | **Required.** The URL to scrape. |
| `formats` | `FormatOption[]` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"screenshot"`, `"json"`, `"images"`, `"audio"`, `"video"`, `"summary"`, `"changeTracking"`, `"attributes"`, etc. |
| `onlyMainContent` | `boolean` | Strip headers, navs, footers. Default: `true`. |
| `includeTags` | `string[]` | HTML tags to exclusively include. |
| `excludeTags` | `string[]` | HTML tags to exclude. |
| `timeout` | `number` | Timeout in ms. Default: `60000`. Min: `1000`, max: `300000`. |
| `waitFor` | `number` | Extra delay in ms after page load. Default: `0`, max: `60000`. |
| `mobile` | `boolean` | Emulate a mobile device. Default: `false`. |
| `headers` | `Record<string, string>` | Custom HTTP headers (cookies, user-agent, etc.). |
| `parsers` | `Array<string \| object>` | Parser configs: `"pdf"`, `"image"`, or objects with options like `{ type: "pdf", mode: "ocr", maxPages: 50 }`. |
| `actions` | `ActionOption[]` | Browser actions before scraping: `wait`, `click`, `write`, `press`, `scroll`, `screenshot`, `scrape`, `executeJavascript`, `pdf`. |
| `location` | `LocationConfig` | Proxy location. E.g., `{ country: "DE" }`. Default: `"US"`. |
| `skipTlsVerification` | `boolean` | Skip TLS verification. Default: `true`. |
| `removeBase64Images` | `boolean` | Remove base64 images from markdown. Default: `true`. |
| `blockAds` | `boolean` | Block ads and cookie popups. Default: `true`. |
| `proxy` | `string` | Proxy type: `"basic"`, `"enhanced"`, `"auto"`. Default: `"auto"`. |
| `maxAge` | `number` | Accept cached content younger than this (ms). Default: `172800000` (2 days). Set to `0` to bypass cache. |
| `minAge` | `number` | Cache-only mode: return cached data at least this old (ms), never scrape fresh. |
| `storeInCache` | `boolean` | Cache the result for future requests. Default: `true`. |
| `lockdown` | `boolean` | Serve only from cache, never make outbound requests. Default: `false`. |
| `checkPromptInjection` | `boolean` | Scan for prompt injection before LLM formats. Adds 4 credits. Default: `false`. |

## Interact

### Why use it

Interact lets you execute code in the browser session that was used for a scrape. Use it when you need to click buttons, fill forms, navigate, or run arbitrary browser-side code after the initial scrape.

### Preferred SDK method

```typescript
firecrawl.interact(jobId, args)
```

### Example

```typescript
// First, scrape with actions to keep the browser session alive
const doc = await firecrawl.scrape("https://example.com", {
  formats: ["markdown"],
});

// Use the scrape job ID to interact with the browser
const result = await firecrawl.interact(doc.metadata.scrapeId, {
  code: "document.querySelector('button.load-more').click();",
  language: "node",
  timeout: 30,
});

console.log(result.stdout);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `string` | **Required.** The scrape job ID (UUID) from the scrape response. |
| `code` | `string` | Code to execute in the browser sandbox (1–100,000 chars). Optional if `prompt` is provided. |
| `prompt` | `string` | Natural-language instruction for the browser agent. Optional if `code` is provided. |
| `language` | `"python" \| "node" \| "bash"` | Language of the code. Default: `"node"`. |
| `timeout` | `number` | Execution timeout in seconds. Min: `1`, max: `300`, default: `30`. |

## Notes

- **Naming style:** All parameters use camelCase.
- **Deprecated aliases:** `scrapeExecute()` is deprecated — use `interact()`. `stopInteractiveBrowser()` is deprecated — use `stopInteraction()`. `scrapeUrl()` is a v1 alias for `scrape()`.
- **Format options:** The `formats` array accepts strings for simple formats or objects with additional config (e.g., `{ type: "json", schema: {...}, prompt: "..." }` for JSON extraction).
- **Alexandria:** The `scrape()` method also accepts an `AlexandriaScrapeRequest` object (with `alexandria` field) for executing catalogued provider tools instead of scraping a URL.
