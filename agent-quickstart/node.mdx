# Firecrawl Node.js Agent Quickstart

Canonical quickstart for external agents. Generated from SDK source (`@mendable/firecrawl-js` v4.45.0) and the v2 OpenAPI spec. Method names, parameters, and types match the SDK public API.

## Install

```bash
npm install firecrawl
```

## Authenticate

```ts
import { Firecrawl } from "firecrawl";

const client = new Firecrawl({
  apiKey: process.env.FIRECRAWL_API_KEY,
});
```

## When To Use What

- **`search`**: use when you start with a query and need discovery. Returns ranked results from web, news, or images.
- **`scrape`**: use when you already have a URL and want page content in one or more formats (markdown, HTML, JSON extraction, screenshots, etc.).
- **`interact`**: use when the page needs clicks, forms, or post-scrape browser actions. Operates on the browser session tied to a prior scrape job.

## Search

### Why use it

Discover relevant pages from a query, then pick URLs to scrape or interact with. Supports `site:` prefix to limit results to a domain (e.g. `site:docs.firecrawl.dev webhook retries`).

### Preferred SDK method

`client.search(query, options?)` → `Promise<SearchData>`

### Example

```ts
const results = await client.search("site:docs.firecrawl.dev webhook retries", {
  limit: 10,
  scrapeOptions: {
    formats: ["markdown"],
    onlyMainContent: true,
  },
});

for (const item of results.web ?? []) {
  console.log(item.url, item.title);
}
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `string` | The search query. Use `site:example.com` to scope results. |
| `options.sources` | `Array<"web" \| "news" \| "images" \| "alexandria" \| {type: ...}>` | Sources to search. Default: `["web"]`. |
| `options.categories` | `Array<"github" \| "research" \| "pdf" \| "developer" \| "gov" \| {type: ...}>` | Filter by category. |
| `options.includeDomains` | `string[]` | Restrict to these domains. Cannot combine with `excludeDomains`. |
| `options.excludeDomains` | `string[]` | Exclude these domains. Cannot combine with `includeDomains`. |
| `options.limit` | `number` | Max results per source type. API default: 10. |
| `options.tbs` | `string` | Time-based filter (e.g. `qdr:d` past day, `qdr:w` past week, `sbd:1` sort by date). |
| `options.location` | `string` | Localized results (e.g. `"San Francisco,California,United States"`). |
| `options.country` | `string` | ISO 3166-1 alpha-2 code (e.g. `"US"`). |
| `options.ignoreInvalidURLs` | `boolean` | Drop URLs that cannot be scraped. |
| `options.timeout` | `number` | Request timeout in milliseconds. API default: 60000. |
| `options.highlights` | `boolean` | Generate query-relevant highlights. Default: `true`. |
| `options.scrapeOptions` | `ScrapeOptions` | Apply scrape options to each result (see Scrape parameters). |
| `options.domainTools` | `boolean` | Include Alexandria tool contracts matched to result domains. |
| `options.toolDetail` | `"compact" \| "summary" \| "full"` | Tool contract detail level. Default: `"compact"`. |
| `options.enterprise` | `Array<"anon" \| "zdr">` | Enterprise ZDR options. |
| `options.threatProtection` | `ThreatProtectionOptions` | Per-request threat protection override. |
| `options.integration` | `string` | Integration identifier. |

### Return value

`SearchData` contains optional arrays — each entry is either a lightweight result or a full `Document` when `scrapeOptions` hydrated the hit:

- `web` — web index hits
- `news` — news hits
- `images` — image hits
- `tools` — discovered Alexandria tool contracts

**Do not** access `result.data`. Web results are in `result.web`, news in `result.news`, images in `result.images`.

## Scrape

### Why use it

Fetch structured content from a URL in one or more formats. Supports markdown, HTML, JSON extraction, screenshots, change tracking, and more.

### Preferred SDK method

`client.scrape(url, options?)` → `Promise<Document>`

### Example

```ts
const doc = await client.scrape("https://example.com/pricing", {
  formats: [
    "markdown",
    { type: "json", prompt: "Extract plan names and prices." },
  ],
  onlyMainContent: true,
});

console.log(doc.markdown);
console.log(doc.json);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `string` | The URL to scrape. |
| `options.formats` | `FormatOption[]` | Output formats. Default: `["markdown"]`. See format types below. |
| `options.headers` | `Record<string, string>` | Custom HTTP headers. |
| `options.includeTags` | `string[]` | Only include content from these HTML tags. |
| `options.excludeTags` | `string[]` | Exclude content from these HTML tags. |
| `options.onlyMainContent` | `boolean` | Strip nav, footer, boilerplate. Default: `true`. |
| `options.timeout` | `number` | Timeout in ms. Default: 60000. Max: 300000. |
| `options.waitFor` | `number` | Delay in ms before fetching (for JS rendering). |
| `options.mobile` | `boolean` | Emulate mobile device. |
| `options.parsers` | `Array<string \| PDFParser \| ImageParser>` | File parsing controls (e.g. `[{type: "pdf", mode: "auto"}]`). |
| `options.actions` | `ActionOption[]` | Pre-scrape browser actions. See action types below. |
| `options.location` | `{country?: string, languages?: string[]}` | Geo/language-aware scraping. |
| `options.skipTlsVerification` | `boolean` | Skip TLS verification. |
| `options.removeBase64Images` | `boolean` | Drop base64 images from output. Default: `true`. |
| `options.fastMode` | `boolean` | Faster scrapes with reduced fidelity. |
| `options.blockAds` | `boolean` | Block ads and cookie popups. Default: `true`. |
| `options.proxy` | `"basic" \| "stealth" \| "enhanced" \| "auto"` | Proxy mode. Default: `"auto"`. |
| `options.maxAge` | `number` | Use cached result if younger than this (ms). Default: 172800000 (2 days). |
| `options.minAge` | `number` | Cache-only check; minimum age in ms. |
| `options.storeInCache` | `boolean` | Cache the result. Default: `true`. |
| `options.lockdown` | `boolean` | Serve from cache only, never make outbound requests. |
| `options.redactPII` | `boolean \| RedactPIIOptions` | Redact personally identifiable information. |
| `options.profile` | `{name: string, saveChanges?: boolean}` | Persistent browser profile across scrapes and interactions. |
| `options.auditMetadata` | `{username: string}` | User attribution for SIEM logging. |
| `options.domainTools` | `boolean` | Include Alexandria tool contracts matched to the domain. |
| `options.toolDetail` | `"compact" \| "summary" \| "full"` | Tool contract detail level. |
| `options.threatProtection` | `ThreatProtectionOptions` | Per-request threat protection override. |
| `options.integration` | `string` | Integration identifier. |

#### Format types

Plain strings: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`.

Object formats (require at least `type`):

| Format | Fields | Notes |
|---|---|---|
| `json` | `prompt?`, `schema?`, `checkPromptInjection?` | At least one of `prompt` or `schema` required. `schema` accepts JSON Schema or Zod. |
| `question` | `question` (required, max 10000 chars) | Ask a question about the page. |
| `highlights` | `query` (required, max 10000 chars) | Find relevant source text. |
| `screenshot` | `fullPage?`, `quality?`, `viewport?` | `viewport` is `{width, height}`. |
| `changeTracking` | `modes` (required: `"git-diff"` / `"json"`), `schema?`, `prompt?`, `tag?` | Track page changes. |
| `attributes` | `selectors` (required: `Array<{selector, attribute}>`) | Extract element attributes. |

#### Action types

| Action | Required fields | Optional fields |
|---|---|---|
| `wait` | `milliseconds` or `selector` | |
| `click` | `selector` | |
| `write` | `text` | |
| `press` | `key` | |
| `scroll` | `direction` (`"up"` / `"down"`) | `selector` |
| `scrape` | (none) | |
| `screenshot` | | `fullPage`, `quality`, `viewport` |
| `executeJavascript` | `script` | |
| `pdf` | | `format`, `landscape`, `scale` |

## Interact

### Why use it

Run code or natural-language prompts in the browser session tied to a scrape job. Use for multi-step flows like filling forms, navigating tabs, or extracting dynamic content — anything beyond what pre-scrape `actions` can handle.

### Preferred SDK method

`client.interact(jobId, args)` → `Promise<ScrapeExecuteResponse>`

### Example

```ts
const doc = await client.scrape("https://example.com", {
  formats: ["markdown"],
});
const jobId = doc.metadata?.scrapeId;

const result = await client.interact(jobId, {
  code: "console.log(await page.title());",
  language: "node",
  timeout: 60,
});
console.log(result.stdout);

await client.stopInteraction(jobId);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `string` | Scrape job ID from `document.metadata.scrapeId`. |
| `args.code` | `string` | Code to execute in the browser sandbox. |
| `args.prompt` | `string` | Natural-language instruction for the browser agent. |
| `args.language` | `"python" \| "node" \| "bash"` | Runtime language. Default: `"node"`. |
| `args.timeout` | `number` | Execution timeout in seconds (1–300). API default: 30. |

At least one of `code` or `prompt` must be non-empty.

### Return value

`ScrapeExecuteResponse` fields: `success`, `stdout`, `result`, `stderr`, `exitCode`, `killed`, `output` (AI agent response when using `prompt`), `liveViewUrl`, `interactiveLiveViewUrl`, `error`.

### Stop session

`client.stopInteraction(jobId)` → `Promise<ScrapeBrowserDeleteResponse>`

Response fields: `success`, `sessionDurationMs`, `creditsBilled`, `error`.

## Notes

- Deprecated aliases: `scrapeUrl` → `scrape`; `scrapeExecute` → `interact`; `stopInteractiveBrowser` / `deleteScrapeBrowser` → `stopInteraction`.
- The default `Firecrawl` export is the v2 client; v1 is available via `client.v1`.
- Zod schemas in `formats` are automatically converted to JSON Schema by the SDK.
- The package declares **Node.js >= 22** in `engines`.
- The SDK auto-resumes large document responses by default (`autoResume: true`).
