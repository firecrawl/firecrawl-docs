# Firecrawl Node.js Agent Quickstart

This file is the canonical quickstart for external agents integrating Firecrawl via the Node.js/TypeScript SDK. It is generated from SDK source (`apps/js-sdk/firecrawl`) plus the OpenAPI spec (`api-reference/v2-openapi.json`).

## Install

```bash
npm install firecrawl
```

## Authenticate

```javascript
import { Firecrawl } from 'firecrawl';

const app = new Firecrawl({ apiKey: "fc-YOUR-API-KEY" });
```

Or use the `FIRECRAWL_API_KEY` environment variable:

```javascript
const app = new Firecrawl();
```

### Constructor options

| Option | Type | Default | Description |
|---|---|---|---|
| `apiKey` | `string` | `FIRECRAWL_API_KEY` env var | API key. Omit for keyless free tier (rate-limited per IP). |
| `apiUrl` | `string` | `"https://api.firecrawl.dev"` | API base URL. Falls back to `FIRECRAWL_API_URL` env var. |
| `timeoutMs` | `number` | — | Per-request timeout in milliseconds. |
| `maxRetries` | `number` | — | Max automatic retries for transient failures. |
| `backoffFactor` | `number` | — | Exponential backoff factor for retries. |

## When To Use What

- **`search`** — Use when you start with a query and need to discover relevant pages. Returns search results with optional full-page scraping.
- **`scrape`** — Use when you already have a URL and want page content (markdown, HTML, screenshots, structured JSON, etc.).
- **`interact`** — Use when the page needs clicks, form fills, or other post-scrape browser actions. Requires a `scrapeId` from a prior scrape.

## Search

### Why use it

Search the web (and optionally news, images, or Alexandria) with a query and get structured results. Each result can optionally include full scraped page content.

### Preferred SDK method

```
app.search(query, options?)
```

### Example

```javascript
import { Firecrawl } from 'firecrawl';

const app = new Firecrawl({ apiKey: "fc-YOUR-API-KEY" });
const results = await app.search("firecrawl web scraping", { limit: 5 });

for (const result of results.web) {
  console.log(result.title, result.url);
}
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `string` | **(required, first arg)** The search query. |
| `sources` | `Array<"web" \| "news" \| "images" \| "alexandria">` | Which sources to query. |
| `categories` | `Array<"github" \| "research" \| "pdf" \| "developer">` | Category filters for web results. |
| `includeDomains` | `string[]` | Only include results from these domains. Cannot combine with `excludeDomains`. |
| `excludeDomains` | `string[]` | Exclude results from these domains. Cannot combine with `includeDomains`. |
| `limit` | `number` | Max number of results. Must be positive. |
| `tbs` | `string` | Time-based search filter (e.g. `"qdr:d"` for past day, `"qdr:w"` for past week). |
| `location` | `string` | Geographic location for search results. |
| `country` | `string` | ISO 3166-1 alpha-2 country code for geo-targeting. |
| `ignoreInvalidURLs` | `boolean` | Ignore invalid URLs in results. |
| `timeout` | `number` | Timeout in milliseconds. Must be positive. |
| `highlights` | `boolean` | Generate query-relevant highlights. Server default: `true`. |
| `scrapeOptions` | `ScrapeOptions` | Options applied when scraping each result page. |
| `domainTools` | `boolean` | Include domain-matched Alexandria contracts in `tools`. |
| `enterprise` | `Array<"default" \| "anon" \| "zdr">` | Enterprise options (Zero Data Retention, anonymized). |
| `threatProtection` | `ThreatProtectionOptions` | Enterprise threat protection settings. |
| `integration` | `string` | Integration identifier. |
| `origin` | `string` | Request attribution label. |

### Response shape

```typescript
{
  warning?: string;
  web?: Array<SearchResultWeb | Document>;
  news?: Array<SearchResultNews | Document>;
  images?: Array<SearchResultImages | Document>;
  tools?: DiscoveredTool[];
}
```

Access results via `.web`, `.news`, `.images`, or `.tools` — not `.data`.

## Scrape

### Why use it

Fetch a single URL and get back clean content in your chosen formats: markdown, HTML, screenshots, structured JSON extraction, and more.

### Preferred SDK method

```
app.scrape(url, options?)
```

### Example

```javascript
const result = await app.scrape("https://example.com", {
  formats: ["markdown", "links"],
});

console.log(result.markdown);
console.log(result.links);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `url` | `string` | **(required, first arg)** The URL to scrape. |
| `formats` | `FormatOption[]` | Output formats: `"markdown"`, `"html"`, `"rawHtml"`, `"links"`, `"images"`, `"screenshot"`, `"summary"`, `"changeTracking"`, `"json"`, `"attributes"`, `"branding"`, `"product"`, `"menu"`, `"audio"`, `"video"`. Also accepts object forms for `json`, `screenshot`, `changeTracking`, `attributes`, `question`, `highlights`. |
| `headers` | `Record<string, string>` | Custom HTTP headers sent with the request. |
| `includeTags` | `string[]` | Only include content from these HTML tags. |
| `excludeTags` | `string[]` | Exclude content from these HTML tags. |
| `onlyMainContent` | `boolean` | Strip navbars, footers, and sidebars. |
| `timeout` | `number` | Timeout in milliseconds. |
| `waitFor` | `number` | Wait time in ms after page load before extracting. |
| `mobile` | `boolean` | Emulate a mobile device. |
| `parsers` | `Array<string \| PDFParser>` | File parser config (e.g. for PDFs). |
| `actions` | `ActionOption[]` | Browser actions to run before extraction. |
| `location` | `{ country?: string; languages?: string[] }` | Geolocation and language settings. |
| `skipTlsVerification` | `boolean` | Skip TLS certificate verification. |
| `removeBase64Images` | `boolean` | Remove base64-encoded images from output. |
| `fastMode` | `boolean` | Faster scrapes with reduced accuracy. |
| `blockAds` | `boolean` | Block ads and cookie popups. |
| `proxy` | `"basic" \| "stealth" \| "enhanced" \| "auto" \| string` | Proxy routing mode. |
| `maxAge` | `number` | Max age (ms) of cached content to reuse. 0 = always fresh. |
| `minAge` | `number` | Min age (ms) for cache-only mode. |
| `storeInCache` | `boolean` | Store the result in cache. |
| `lockdown` | `boolean` | Only serve previously cached results. |
| `redactPII` | `boolean \| RedactPIIOptions` | Redact personally identifiable information. |
| `threatProtection` | `ThreatProtectionOptions` | Enterprise threat protection. |
| `auditMetadata` | `{ username: string }` | SIEM audit attribution. |
| `profile` | `{ name: string; saveChanges?: boolean }` | Persistent browser profile for session reuse. |
| `integration` | `string` | Integration identifier. |
| `origin` | `string` | Request attribution label. |
| `domainTools` | `boolean` | Include domain-matched Alexandria contracts. |

**SDK-only option (not sent to API):**

| Parameter | Type | Description |
|---|---|---|
| `autoResume` | `boolean` | Auto-retry on large-document 408 timeouts. Default: enabled. Bounded to 5 resumes / 20 min. |

## Interact

### Why use it

After scraping a page, use `interact` to take actions in the live browser session: click buttons, fill forms, navigate, or extract dynamic content. You can send a natural-language prompt or execute code directly.

### Preferred SDK method

```
app.interact(jobId, options)
```

Stop the session when done:

```
app.stopInteraction(jobId)
```

### Example

```javascript
const result = await app.scrape("https://www.amazon.com", { formats: ["markdown"] });
const scrapeId = result.metadata?.scrapeId;

await app.interact(scrapeId, { prompt: "Search for iPhone 16 Pro Max" });
const response = await app.interact(scrapeId, {
  prompt: "Click on the first result and tell me the price",
});
console.log(response.output);

await app.stopInteraction(scrapeId);
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `jobId` | `string` | **(required, first arg)** The `scrapeId` from a prior scrape's `metadata`. |
| `code` | `string` | Code to execute in the browser sandbox. Provide `code` or `prompt` (or both). |
| `prompt` | `string` | Natural-language instruction for the browser agent. Provide `code` or `prompt` (or both). |
| `language` | `"python" \| "node" \| "bash"` | Runtime language for `code`. SDK default: `"node"`. |
| `timeout` | `number` | Execution timeout. |
| `origin` | `string` | Request attribution label. |

### Response shape

```typescript
{
  success: boolean;
  output?: string;       // Agent output when prompt was used
  stdout?: string;       // Stdout from code execution
  result?: string;       // Return value from code
  stderr?: string;
  exitCode?: number;
  killed?: boolean;
  error?: string;
  liveViewUrl?: string;
  interactiveLiveViewUrl?: string;
}
```

## Notes

- **Import style**: Use `import { Firecrawl } from 'firecrawl'` (named export) or `import Firecrawl from 'firecrawl'` (default export).
- **Naming**: All parameters use camelCase.
- **Deprecated aliases**: `scrapeUrl` → `scrape`, `scrapeExecute` → `interact`, `stopInteractiveBrowser` / `deleteScrapeBrowser` → `stopInteraction`. Always use the preferred names.
- **Search results**: Access via `.web`, `.news`, `.images`, `.tools` — accessing `.data` throws a helpful error.
- **Node version**: Requires Node.js 22+.
