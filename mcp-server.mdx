## Sign in

Point your client at the OAuth server URL. Your client opens a browser window where you sign in to Firecrawl and approve a team:

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

No API key or headers are needed. Review and revoke connections from [MCP settings](https://www.firecrawl.dev/app/settings?tab=mcp).

<Note>
This is a server URL for your MCP client, not a page to open directly in a browser. API-key connections use `https://mcp.firecrawl.dev/v2/mcp` with a bearer token instead; see [Add an API key](/mcp-server/keyless#add-an-api-key).
</Note>

## What's new in v3 {#whats-new-in-v3}

Firecrawl MCP v3 is the current hosted server. The server URLs stay the same: the `/v2/` in `https://mcp.firecrawl.dev/v2/mcp` and `https://mcp.firecrawl.dev/v2/mcp-oauth` is the Firecrawl API version, not the MCP release.

- **3,000+ tools from one connection.** Search, Scrape, and Parse sit next to the full [Alexandria](/features/alexandria) catalog of company, people, research, and government data. Your agent explores the catalog with `alexandria_library_search` and runs a tool with `alexandria_library_read`. Provider discovery is about 8x faster than in v2.
- **Automatic provider waterfalls.** `people_company_enrich` and `people_company_search` try one provider after another until one finds the record, so your agent makes one call and gets one answer.
- **Higher rate limits.** Rate limits are up to 60x higher than in v2, and search through MCP is about 2x faster.
- **More usage.** Every plan includes free MCP usage that refreshes daily. Hosted MCP calls draw on that daily allowance before your plan credits, which gives you 4x more usage through MCP. Tool prices do not change.
- **Subtasks.** Your agent can hand work off to subtasks that run in parallel in the background while it keeps working.

Alexandria tools and the waterfalls need a signed-in or API-key connection. Keyless access stays limited to Search, Scrape, and Parse. See [Tools](/mcp-server/tools) for the full tool list.
