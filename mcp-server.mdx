Firecrawl MCP gives AI clients access to live web data through the Model Context Protocol. It is available as a hosted service or as an open-source local server.

## Start here

For the fastest setup, connect with OAuth. Use an API key for unattended workloads, or try the keyless server without creating an account. Credentials belong in the OAuth flow or an Authorization header, never in the URL itself.
