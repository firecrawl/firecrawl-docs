  ## 试用免密钥模式
</div>

<McpClientSelector variant="agent" showSeeAll={false} />

免密钥 MCP 会受到限流，仅提供 Search、Scrape 和 Parse。添加 API 密钥即可解锁完整工具集并获得更高限额。

<div id="add-an-api-key">
  ## 添加 API 密钥
</div>

[创建 Firecrawl API 密钥](https://www.firecrawl.dev/app/api-keys)，然后将其作为 Bearer 令牌发送至同一端点：

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

<Warning>
API 密钥必须由用户或系统管理员在代理对话之外配置。切勿将密钥粘贴到聊天、MCP URL 或项目文件中。
</Warning>

<div id="verify-your-connection">
  ## 验证连接
</div>

打开客户端的 MCP 状态或工具列表，确认 `firecrawl` 已连接。免密钥连接会显示 `firecrawl_search`、`firecrawl_scrape` 和 `firecrawl_parse`；使用 API 密钥的连接可提供[完整工具集](/zh/mcp-server/tools)，具体取决于套餐、部署和团队策略。

<div id="try">
  ## 试用
</div>

```text
进行网页搜索，查找最新的 Firecrawl 版本说明，并总结这些来源。
```

如果未显示 Firecrawl 工具，请在保存 MCP 配置后重启或重新加载客户端。
