---
title: 连接 Firecrawl MCP
description: "选择账户 OAuth、无人值守 API 密钥或免密钥 Firecrawl MCP 配置。"
sidebarTitle: '连接'
---

托管的 Firecrawl MCP 服务提供三种使用模式。请根据是否有人可登录，以及客户端能否安全存储 API 密钥进行选择。

<div id="connect-an-account">
  ## 连接账户
</div>

此模式适用于 Claude 或 Codex 等支持 OAuth 的交互式客户端。将此 URL 添加到客户端后，它会发现 Firecrawl&#39;s 授权元数据、打开浏览器，并要求你批准要使用的团队。

```text
https://mcp.firecrawl.dev/v2/mcp-oauth
```

客户端获得的是短期有效、与资源绑定的令牌，而非您的 Firecrawl API 密钥。您可以在 [MCP 设置](https://www.firecrawl.dev/app/settings?tab=mcp)中查看和撤销访问权限。

<Tip>
  如果客户端要求提供 OAuth Client ID 或 Client Secret，请将两者留空。兼容的客户端会使用 Client ID Metadata Documents 或 Dynamic Client Registration。
</Tip>

<div id="run-unattended">
  ## 无人值守运行
</div>

此模式适用于 CI、服务器、脚本或任何没有浏览器的运行时。请将 API 密钥存储在环境变量或密钥存储中，并通过 Authorization 请求头发送。

```text
https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

这将使用完整的 Firecrawl MCP 工具集。新的配置不应将 API 密钥放在 URL 中，也不应将其提交到项目配置文件。

<div id="try-keyless">
  ## 试用免密钥模式
</div>

使用此模式，无需账户或 API 密钥即可试用 Firecrawl：

```text
https://mcp.firecrawl.dev/v2/mcp
```

免密钥 MCP 按 IP 限流，符合条件时仅提供 **Search、Scrape 和 Parse**。如需使用完整工具集或更高限额，请连接账户或使用 API 密钥。

<div id="pick-the-right-mode">
  ## 选择合适的模式
</div>

| 模式   | 端点              | 可用工具                      | 最适合                      | 凭据                                          |
| ---- | --------------- | ------------------------- | ------------------------ | ------------------------------------------- |
| 账户   | `/v2/mcp-oauth` | 完整的 MCP 工具集，具体取决于套餐和功能可用性 | 可在浏览器中完成 OAuth 流程的交互式客户端 | 由客户端管理的 OAuth 令牌                            |
| 无人值守 | `/v2/mcp`       | 完整的 MCP 工具集，具体取决于套餐和功能可用性 | CI、服务器和脚本                | `Authorization: Bearer <FIRECRAWL_API_KEY>` |
| 免密钥  | `/v2/mcp`       | 仅限 Search、Scrape 和 Parse  | 有限试用                     | 无                                           |

有关当前工具清单及本地/自托管可用性说明，请参见[工具和操作](/zh/mcp-server/tools)。

<div id="client-specific-help">
  ## 客户端专属帮助
</div>

配置示例请参见[客户端设置](/zh/mcp-server/clients)。如果您的客户端无法完成远程 OAuth 流程，请改用基于请求头的无人值守配置或免密钥模式。如果也无法发送自定义请求头，请参见下方的旧版备用方案。

<div id="legacy-api-key-url-support">
  ## 旧版 API 密钥 URL 支持
</div>

<Warning>
  此旧版形式仅适用于无法完成 OAuth 流程或无法发送自定义 Authorization 请求头的现有配置和客户端。不建议新集成采用此设置。
</Warning>

```text
https://mcp.firecrawl.dev/<FIRECRAWL_API_KEY>/v2/mcp
```

API 密钥包含在 URL 中，因此请将完整 URL 视为密码。只要客户端支持，应优先使用账户 OAuth 或由环境变量提供的 `Authorization: Bearer` 请求头。如果此 URL 泄露，请轮换 API 密钥。切勿将其粘贴到聊天记录、截图、问题单或共享配置中。

此备用方案仅适用于完整的 `/v2/mcp` 接口。它不适用于仅支持 OAuth 的搜索资源。

<div id="compatibility-during-migration">
  ## 迁移期间的兼容性
</div>

迁移至专用账户端点期间，现有的 `/v2/mcp` OAuth 连接仍然受支持。新的交互式账户连接应使用 `/v2/mcp-oauth`；为该账户资源新生成的令牌无法被 `/v2/mcp` 接受。
