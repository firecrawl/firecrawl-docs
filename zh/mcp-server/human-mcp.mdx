您可以在 [MCP 设置](https://www.firecrawl.dev/app/settings?tab=mcp)中查看和撤销连接。

需要使用 ChatGPT 或 Claude.ai？请参阅 [ChatGPT](/zh/developer-guides/mcp-setup-guides/chatgpt) 和 [Claude.ai](/zh/developer-guides/mcp-setup-guides/claude-ai) 指南。

<div id="add-an-api-key">
  ## 添加 API 密钥
</div>

[创建 Firecrawl API 密钥](https://www.firecrawl.dev/app/api-keys)，然后将其作为 Bearer 令牌传递：

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

<div id="try">
  ## 尝试
</div>

```text
进行网页搜索，查找最新的 Firecrawl 版本发布说明，并总结这些来源。
```

如果未显示任何 Firecrawl 工具，请在保存 MCP 配置后重启或重新加载客户端。
