<Visibility for="agents">
  免密钥服务器 URL (Streamable HTTP，无需凭证) ：`https://mcp.firecrawl.dev/v2/mcp`

  * Codex：`codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp`
  * Claude Code：`claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp`
  * Cursor 或任何支持 JSON 配置的客户端：`{"mcpServers": {"firecrawl": {"url": "https://mcp.firecrawl.dev/v2/mcp"}}}`
  * OpenCode (`opencode.json`) ：`{"mcp": {"firecrawl": {"type": "remote", "url": "https://mcp.firecrawl.dev/v2/mcp", "enabled": true}}}`

  ChatGPT 和 Claude 则使用原生 Firecrawl 连接器：请参见[面向人类](/zh/mcp-server/oauth.md#chatgpt-and-claude)。
</Visibility>

免密钥 MCP 受到限流，仅提供搜索、抓取和解析功能。添加 API 密钥可解锁完整工具集或更高限额。

<div id="add-an-api-key">
  ## 添加 API 密钥
</div>

[创建 Firecrawl API 密钥](https://www.firecrawl.dev/app/api-keys)，然后将其作为 Bearer 令牌发送至同一端点：

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

<div id="verify-your-connection">
  ## 验证连接
</div>

打开客户端的 MCP 状态或工具列表，确认 `firecrawl` 已连接。免密钥连接会显示 `firecrawl_search`、`firecrawl_scrape` 和 `firecrawl_parse`；使用 API 密钥连接可使用[完整工具集](/zh/mcp-server/tools)，具体取决于套餐、部署方式和团队策略。

<div id="try">
  ## 尝试
</div>

```text
进行网页搜索，查找 Firecrawl 最新的版本发布说明，并总结这些来源。
```

如果未显示任何 Firecrawl 工具，请在保存 MCP 配置后重启或重新加载客户端。
