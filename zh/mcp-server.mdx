<div id="add-an-api-key">
  ## 添加 API 密钥
</div>

[创建 Firecrawl API 密钥](https://www.firecrawl.dev/app/api-keys)，然后将其作为 Bearer 令牌发送：

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

请通过环境变量或客户端的密钥存储配置密钥，切勿将密钥放在 MCP URL 中。

<Note>
  这是 MCP 客户端使用的服务器 URL，并非可直接在浏览器中打开的页面。登录连接请使用 `https://mcp.firecrawl.dev/v2/mcp-oauth`，客户端会启动浏览器登录流程。
</Note>
