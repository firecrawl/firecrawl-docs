Firecrawl MCP 通过模型上下文协议让 AI 客户端访问实时网页数据。它既可作为托管服务使用，也可作为开源的本地服务器运行。

<div id="start-here">
  ## 从这里开始
</div>

请选择与 Firecrawl 运行环境相匹配的连接模式。托管端点为免凭据 URL：凭据应通过 OAuth 流程或 Authorization 标头提供，切勿直接放在 URL 中。

<CardGroup cols={3}>
  <Card title="连接账户" icon="user" href="/zh/mcp-server/connect">
    为交互式 MCP 客户端使用基于浏览器的 OAuth，解锁完整的 Firecrawl 工具集。
  </Card>

  <Card title="无人值守运行" icon="server" href="/zh/mcp-server/connect#run-unattended">
    适用于 CI、服务器和脚本：通过 Authorization 标头携带 Firecrawl API 密钥，使用 `/v2/mcp`。
  </Card>

  <Card title="试用免密钥 MCP" icon="sparkles" href="/zh/mcp-server/connect#try-keyless">
    无需 API 密钥即可开始使用限流的 Search、Scrape 和 Parse 功能。
  </Card>
</CardGroup>
