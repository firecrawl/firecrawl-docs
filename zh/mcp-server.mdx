<div id="sign-in">
  ## 登录
</div>

将客户端指向 OAuth 服务器 URL。客户端会打开一个浏览器窗口，你在其中登录 Firecrawl 并授权某个团队：

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

无需 API 密钥或 header。可在 [MCP 设置](https://www.firecrawl.dev/app/settings?tab=mcp)中查看并撤销连接。

<Note>
  这是供 MCP 客户端使用的服务器 URL，并非可直接在浏览器中打开的页面。使用 API 密钥连接时，请改用 `https://mcp.firecrawl.dev/v2/mcp` 并附带 Bearer 令牌；请参见[添加 API 密钥](/zh/mcp-server/keyless#add-an-api-key)。
</Note>
