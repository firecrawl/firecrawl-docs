请选择与连接运行方式相匹配的设置。无需区分您是人类还是代理。

<CardGroup cols={3}>
  <Card title="立即试用" icon="bolt" href="/zh/mcp-server/keyless-api-key#try-instantly" cta="开始免密钥设置" arrow>
    无需账户或密钥。可使用 Search、Scrape 和 Parse；每日限额由使用同一公共 IP 的用户共享。
  </Card>

  <Card title="使用账户登录" icon="right-to-bracket" href="/zh/mcp-server/oauth" cta="连接账户" arrow>
    可通过浏览器从 ChatGPT、Claude.ai、Codex、Claude Code 等交互式客户端登录 (OAuth) ，并访问更多工具。
  </Card>

  <Card title="使用 API 密钥" icon="key" href="/zh/mcp-server/keyless-api-key#add-an-api-key" cta="配置 API 密钥" arrow>
    为代理、CI 和后端提供稳定访问。请勿在聊天记录或源代码控制中存放密钥。
  </Card>
</CardGroup>

托管的免密钥和 API 密钥服务器 URL 为：

```text
https://mcp.firecrawl.dev/v2/mcp
```

<Note>
  这是 MCP 客户端使用的服务器 URL，不是可在浏览器中直接打开的页面。OAuth 使用不同的服务器 URL，客户端会启动浏览器登录流程。
</Note>

如果您选择使用 API 密钥，切勿将其放入 MCP URL、代理对话或已提交的项目文件中。请通过环境变量或客户端的密钥存储进行配置。

<div id="fix-a-broken-connection">
  ## 修复连接问题
</div>

当 Firecrawl 报错中出现 `KEYLESS_QUOTA_EXHAUSTED`、`KEYLESS_TOOL_NOT_AVAILABLE`、`KEYLESS_ACCESS_NOT_AVAILABLE`、`KEYLESS_ELIGIBILITY_UNAVAILABLE`、`CREDENTIAL_INVALID`、`OAUTH_CONNECTION_INVALID`，或提示凭据“无效或已撤销”时，请参阅本节。

* **已达到免密钥限制：**等待错误中指定的 `retry_after_seconds` (如有) ，或请人工操作员通过 OAuth 连接或配置 API 密钥。限制重置后，Search、Scrape 和 Parse 仍可使用。
* **免密钥访问不可用：**对于 `KEYLESS_ELIGIBILITY_UNAVAILABLE`，请在指定时间间隔后重试。如果问题仍然存在，或错误为 `KEYLESS_ACCESS_NOT_AVAILABLE`，请人工操作员通过 OAuth 连接或配置 API 密钥。
* **免密钥模式下工具不可用 (`KEYLESS_TOOL_NOT_AVAILABLE`) ：**该工具存在，但不属于免密钥工具集。请通过 OAuth 连接或配置 API 密钥后再使用；Search、Scrape 和 Parse 在免密钥模式下仍可正常使用。
* **API 密钥无效或已撤销：**人工或系统操作员必须在现有服务器配置中替换该密钥，且需在代理对话之外完成此操作。
* **`/v2/mcp` 上的 OAuth 连接无效：**请为该现有服务器添加 API 密钥，或将其 URL 改为 `https://mcp.firecrawl.dev/v2/mcp-oauth`，然后通过客户端登录。请勿直接在浏览器中打开该 URL。
* **`/v2/mcp-oauth` 上的 OAuth 连接无效：**请通过客户端的账户连接流程重新登录。

更改凭据或服务器 URL 后，请确保仅保留一个 `firecrawl` 服务器条目，启动新的客户端会话后重试。有关具体步骤，请参见 [OAuth 连接](/zh/mcp-server/oauth#switch-an-existing-keyless-connection) 或 [API 密钥设置](/zh/mcp-server/keyless-api-key#add-an-api-key)。
