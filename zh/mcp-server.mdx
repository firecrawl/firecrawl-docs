根据连接的运行方式选择设置，无需先判断自己是“人”还是“代理”。

<Card title="立即试用" icon="bolt" href="/zh/mcp-server/agent-mcp">
  无需账户或密钥即可使用 Search、Scrape 和 Parse。限额由同一公网 IP 的用户共享。
</Card>

<Card title="使用 OAuth 连接" icon="right-to-bracket" href="/zh/mcp-server/human-mcp">
  从交互式客户端登录，选择团队并批准连接。
</Card>

<Card title="使用 API 密钥" icon="key" href="/zh/mcp-server/agent-mcp">
  为代理、CI 和后端服务配置稳定访问，不要把密钥放入聊天或源代码。
</Card>

查看[可用工具](/zh/mcp-server/tools)，或[在本地运行 MCP](/zh/mcp-server/local)。
