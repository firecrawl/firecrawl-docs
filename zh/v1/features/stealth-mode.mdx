</Warning>

Firecrawl 提供多种代理类型，帮助你抓取复杂程度不同的网站。可通过 `proxy` 参数指定代理类型。

<div id="proxy-types">
  ### 代理类型
</div>

* **basic**：适用于抓取大多数网站的代理。
* **enhanced**：适用于在保护隐私的前提下抓取复杂网站的增强代理。
* **auto**：推荐使用。如果 basic 代理失败，Firecrawl 将自动使用增强代理重试抓取。

如果未指定代理，Firecrawl 默认为 basic。
