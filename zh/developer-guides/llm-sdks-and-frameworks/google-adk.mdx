通过模型上下文协议 (MCP) 将 Google 的 Agent Development Kit (ADK) 连接到 Firecrawl，让你的智能体能够对网页进行搜索、抓取、爬取和映射，获取干净的上下文。

<div id="overview">
  ## 概览 {#overview}
</div>

Firecrawl 提供一个 MCP 服务器，可与 Google 的 ADK 无缝集成，使你的智能体能够高效地对任意网站进行抓取、爬取，并提取结构化数据。该集成同时支持云端与自托管的 Firecrawl 实例，并通过可流式传输的 HTTP 实现最佳性能。

<div id="features">
  ## 功能 {#features}
</div>

* 高效完成任意网站的网页抓取、爬取与内容发现
* 高级搜索与智能内容提取
* 借助 Firecrawl 智能体自主开展网页研究
* 浏览器交互、文件解析与变更监控
* 灵活部署 (云端或自托管)
* 针对现代 Web 环境优化，支持 Streamable HTTP

## 前置条件 {#prerequisites}

* 从 [firecrawl.dev](https://firecrawl.dev) 获取 Firecrawl 的 API 密钥
* 安装支持 MCP 的 Google ADK：`pip install "google-adk[mcp]"`

## 设置 {#setup}

<CodeGroup>
  ```python 远程 MCP 服务器
  import os

  from google.adk.agents.llm_agent import Agent
  from google.adk.tools.mcp_tool.mcp_session_manager import StreamableHTTPConnectionParams
  from google.adk.tools.mcp_tool.mcp_toolset import MCPToolset

  FIRECRAWL_API_KEY = os.environ["FIRECRAWL_API_KEY"]

  root_agent = Agent(
      model="gemini-3.8-flash",
      name="firecrawl_agent",
      description='使用 Firecrawl 抓取网站的智能助手',
      instruction='帮助用户搜索网站内容',
      tools=[
          MCPToolset(
              connection_params=StreamableHTTPConnectionParams(
                  url="https://mcp.firecrawl.dev/v2/mcp",
                  headers={"Authorization": f"Bearer {FIRECRAWL_API_KEY}"},
              ),
          )
      ],
  )
  ```

  ```python 本地 MCP 服务器
  import os

  from google.adk.agents.llm_agent import Agent
  from google.adk.tools.mcp_tool.mcp_session_manager import StdioConnectionParams
  from google.adk.tools.mcp_tool.mcp_toolset import MCPToolset
  from mcp import StdioServerParameters

  root_agent = Agent(
      model='gemini-3.8-flash',
      name='firecrawl_agent',
      description='使用 Firecrawl 抓取网站的智能助手',
      instruction='帮助用户搜索网站内容',
      tools=[
          MCPToolset(
              connection_params=StdioConnectionParams(
                  server_params = StdioServerParameters(
                      command='npx',
                      args=[
                          "-y",
                          "firecrawl-mcp@3.33.2",
                      ],
                      env={
                          "FIRECRAWL_API_KEY": os.environ["FIRECRAWL_API_KEY"],
                      }
                  ),
                  timeout=30,
              ),
          )
      ],
  )
  ```
</CodeGroup>

在启动 ADK 的环境中设置 `FIRECRAWL_API_KEY`。请勿将其值放入智能体 prompt、源代码控制或 MCP URL 中。本地 MCP 软件包需要 Node.js 22 或更高版本。

## 可用工具 {#available-tools}

| 工具        | 名称                                              | 描述                             |
| --------- | ----------------------------------------------- | ------------------------------ |
| Scrape 工具 | `firecrawl_scrape`                              | 抓取单个 URL 的内容，或以 JSON 格式提取结构化数据 |
| Map 工具    | `firecrawl_map`                                 | 映射网站以发现站点上所有已索引的 URL           |
| Search 工具 | `firecrawl_search`                              | 搜索全网，并可选地从搜索结果中提取内容            |
| Crawl 工具  | `firecrawl_crawl`                               | 爬取整个站点或其中某个部分，并返回相应页面          |
| 爬取状态检查    | `firecrawl_check_crawl_status`                  | 查看爬取任务状态                       |
| 解析工具      | `firecrawl_parse`                               | 从 PDF、文档、电子表格或 HTML 文件中提取内容    |
| 智能体工具     | `firecrawl_agent`, `firecrawl_agent_status`     | 基于多个信息来源开展自主研究，并查看任务状态         |
| 交互工具      | `firecrawl_interact`, `firecrawl_interact_stop` | 在实时页面上点击、填写表单和导航，完成后释放会话       |
| 监控工具      | `firecrawl_monitor_*`                           | 创建并运行定期检查，支持 Webhook 或电子邮件通知   |

完整列表请参见 [MCP 工具](/zh/mcp-server/tools)。

<div id="configuration">
  ## 配置 {#configuration}
</div>

### 身份验证 {#authentication}

**FIRECRAWL&#95;API&#95;KEY**：你的 Firecrawl API 密钥

* 使用云端 API (默认) 时为可选：未提供密钥时，抓取和搜索会在免费额度内以免密钥方式运行；使用其他工具或获取更高额度则需要密钥
* 在配合 FIRECRAWL&#95;API&#95;URL 的自托管实例中为可选

### 可选配置 {#optional-configuration}

**Firecrawl API URL (用于自托管实例)&#x20;**：

* `FIRECRAWL_API_URL`：自定义 API 端点
* 示例：`https://firecrawl.your-domain.com`
* 如未配置，将使用云端 API

## 示例：网页研究智能体 {#example-web-research-agent}

```python
import asyncio
import os

from google.adk.agents.llm_agent import Agent
from google.adk.runners import InMemoryRunner
from google.adk.tools.mcp_tool.mcp_session_manager import StreamableHTTPConnectionParams
from google.adk.tools.mcp_tool.mcp_toolset import MCPToolset

FIRECRAWL_API_KEY = os.environ["FIRECRAWL_API_KEY"]

# 创建研究代理
research_agent = Agent(
    model="gemini-3.8-flash",
    name="research_agent",
    description='An AI agent that researches topics by scraping and analyzing web content',
    instruction='''You are a research assistant. When given a topic or question:
    1. Use the search tool to find relevant websites
    2. Scrape the most relevant pages for detailed information
    3. Extract structured data when needed
    4. Provide comprehensive, well-sourced answers''',
    tools=[
        MCPToolset(
            connection_params=StreamableHTTPConnectionParams(
                url="https://mcp.firecrawl.dev/v2/mcp",
                headers={"Authorization": f"Bearer {FIRECRAWL_API_KEY}"},
            ),
        )
    ],
)

# 运行代理并打印其回复
async def main():
    runner = InMemoryRunner(agent=research_agent)
    await runner.run_debug("What are the latest features in Python 3.13?")
    await runner.close()

asyncio.run(main())
```

<div id="best-practices">
  ## 最佳实践 {#best-practices}
</div>

1. **为任务选择合适的工具**：
   * 当你需要先找到相关页面时，使用 `firecrawl_search`
   * 抓取单个页面时，使用 `firecrawl_scrape`
   * 需要发现并抓取整站时，使用 `firecrawl_crawl`
   * 当你已经有一份简短的已知 URL 列表时，重复调用 `firecrawl_scrape`

2. **监控使用情况**：使用你的 Firecrawl Dashboard 和 API 响应来跟踪额度使用情况。

3. **妥善处理错误**：向用户显示 MCP/API 错误，并且仅在你的代理工作流能够安全执行时才进行重试。

4. **优化性能**：当代理需要发现相关 URL 时，在抓取前先使用 `firecrawl_map`。
