---
title: "在 ChatGPT 中使用 Firecrawl MCP"
description: "通过原生插件将 Firecrawl 添加到 ChatGPT"
---

通过原生 Firecrawl 插件将 Firecrawl 添加到 ChatGPT，即可直接在聊天中对网页进行搜索、抓取、爬取、交互和监控。无需创建自定义 MCP 连接器或粘贴服务器 URL。

## 添加到 ChatGPT {#add-to-chatgpt}

<Card title="添加到 ChatGPT" icon="/images/agent-clients/chatgpt.svg" href="https://chatgpt.com/plugins/plugin_asdk_app_6a314a73f8ac819195b0d55e36b9c609?q=firecrawl" cta="在 ChatGPT 中打开" arrow>
  在 ChatGPT 中打开 Firecrawl 插件并完成安装。
</Card>

1. 打开 [ChatGPT 中的 Firecrawl 插件](https://chatgpt.com/plugins/plugin_asdk_app_6a314a73f8ac819195b0d55e36b9c609?q=firecrawl)，或在 ChatGPT 中打开 **Plugins** 并搜索 **Firecrawl**。
2. 选择 **Install**。ChatGPT 会在浏览器中打开 Firecrawl，请登录、选择团队并授权访问。
3. 新建一个对话，以便 ChatGPT 加载该插件，然后让它使用 Firecrawl。

该插件同样适用于 Codex。详情及故障排查请参见 [ChatGPT &amp; Codex](/zh/integrations/chatgpt-codex)。

请勿将 Firecrawl API 密钥放在服务器 URL 中。如需撤销访问权限，可随时前往 [MCP 设置](https://www.firecrawl.dev/app/settings?tab=mcp)。

## 尝试 {#try}

启用 Firecrawl 后，试试：

```text
进行网页搜索，查找最新的 Firecrawl 版本发布说明，并总结这些来源。
```

```text
Scrape firecrawl.dev and tell me what it does
```
