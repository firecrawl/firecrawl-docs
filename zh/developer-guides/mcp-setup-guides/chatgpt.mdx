---
title: "在 ChatGPT 中使用 Firecrawl MCP"
description: "通过原生连接器将 Firecrawl 添加到 ChatGPT"
---

通过原生 Firecrawl 应用将 Firecrawl 添加到 ChatGPT。无需创建自定义 MCP 连接器或粘贴服务器 URL。

<div id="add-to-chatgpt">
  ## 添加到 ChatGPT
</div>

<Card title="添加到 ChatGPT" icon="/images/agent-clients/chatgpt.svg" href="https://chatgpt.com/plugins?q=firecrawl" cta="在 ChatGPT 中打开" arrow>
  在 ChatGPT 中打开 Firecrawl 应用并进行连接。
</Card>

1. 打开 [ChatGPT 中的 Firecrawl 应用](https://chatgpt.com/plugins?q=firecrawl)。
2. 选择 **Firecrawl** 并连接。ChatGPT 在浏览器中打开 Firecrawl 后，登录、选择团队并授权访问。
3. 在聊天中发送 prompt 前，打开 **+** 菜单并启用 **Firecrawl**。必须将连接器添加到对话中。

请勿在服务器 URL 中填入 Firecrawl API 密钥。如需稍后撤销访问权限，请前往 [MCP 设置](https://www.firecrawl.dev/app/settings?tab=mcp)。

<div id="try">
  ## 尝试
</div>

启用 Firecrawl 后，试试：

```text
进行网页搜索，查找最新的 Firecrawl 版本发布说明，并总结这些来源。
```

```text
Scrape firecrawl.dev and tell me what it does
```
