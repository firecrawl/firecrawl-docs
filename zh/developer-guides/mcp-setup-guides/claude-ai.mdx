---
title: "在 Claude 中使用 Firecrawl MCP"
description: "通过原生连接器将 Firecrawl 添加到 Claude.ai"
---

通过原生 Firecrawl 连接器将 Firecrawl 添加到 Claude.ai。无需添加自定义连接器或粘贴服务器 URL。

<Note>
  想找 Claude Code 的设置方法？请参见 [Claude Code
  指南](/zh/quickstarts/claude-code)。
</Note>

<div id="add-to-claude">
  ## 添加到 Claude
</div>

<Card title="添加到 Claude" icon="/images/agent-clients/claude-ai.svg" href="https://claude.ai/directory/connectors/firecrawl" cta="在 Claude 中打开" arrow>
  在 Claude.ai 中打开 Firecrawl 连接器并完成连接。
</Card>

1. 在 [Claude.ai 中打开 Firecrawl 连接器](https://claude.ai/directory/connectors/firecrawl)。
2. 连接 Firecrawl。Claude 在浏览器中打开 Firecrawl 后，登录、选择团队并授权访问。
3. 在对话中，打开 **+** 菜单，进入 **连接器**，然后启用 Firecrawl。

对于 Team 或 Enterprise 套餐，组织所有者可能需要先允许使用该连接器，成员才能连接。

通过此连接器发出的请求将使用你登录时所选团队的额度和套餐。你可以随时在 [MCP 设置](https://www.firecrawl.dev/app/settings?tab=mcp)中查看或撤销连接。

<div id="try">
  ## 试用
</div>

启用 Firecrawl 后，试试：

```text
Search the web for the latest Firecrawl release notes and summarize the sources.
```

```text
Scrape firecrawl.dev and tell me what it does
```
