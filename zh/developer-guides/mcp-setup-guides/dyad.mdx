---
title: "在 Dyad 中使用 Firecrawl MCP"
description: "一键为 Dyad 添加网络搜索、抓取、爬取和映射功能"
---

将 Firecrawl 添加到 [Dyad](https://www.dyad.sh)，让应用构建器中的 AI 能够搜索、抓取网页并与网页进行交互。

<Note>
  使用 “Add to Dyad” 链接需要 Dyad v0.25 或更高版本。
</Note>

## 1. 获取 API 键 {#1-get-your-api-key}

在 [firecrawl.dev/app/api-keys](https://www.firecrawl.dev/app/api-keys) 创建键。键需在 Dyad 中填写，不要放在链接里。

## 2. 将 Firecrawl 添加到 Dyad {#2-add-firecrawl-to-dyad}

选择一种传输方式。

点击链接后，Dyad 会打开 **Plugins** 页面并自动填好表单。点击 **Add**，然后根据所选传输方式完成 API 键的配置步骤。

### 托管 (HTTP) {#hosted-http}

1. 在表单中关闭 **Use OAuth**。
2. 添加完成后，打开新建的插件并添加以下标头：

   | 标头              | 值                               |
   | --------------- | ------------------------------- |
   | `Authorization` | `Bearer YOUR_FIRECRAWL_API_KEY` |

### 本地 (npx) {#local-npx}

添加后，打开新插件并添加以下环境变量：

| 变量                  | 值                        |
| ------------------- | ------------------------ |
| `FIRECRAWL_API_KEY` | `YOUR_FIRECRAWL_API_KEY` |

## 3. 试用 {#3-try-it}

在 Dyad 聊天中，试着输入：

```text
进行网页搜索，查找最新的 Next.js 版本发布说明，并对各信息来源进行总结。
```

```text
抓取 https://firecrawl.dev，并介绍该页面提供了哪些内容。
```

## 手动添加 {#add-it-by-hand}

打开 **Plugins**，点击 **Add Plugin**，然后填写以下任意一组配置值。

| 传输方式    | 字段                                                                                       |
| ------- | ---------------------------------------------------------------------------------------- |
| `http`  | URL `https://mcp.firecrawl.dev/v2/mcp`，标头 `Authorization: Bearer YOUR_FIRECRAWL_API_KEY` |
| `stdio` | 命令 `npx`，参数 `-y firecrawl-mcp`，环境变量 `FIRECRAWL_API_KEY=YOUR_FIRECRAWL_API_KEY`           |

完整工具列表请参见 [MCP 服务器参考](/zh/mcp-server)。
