使用 Firecrawl MCP 为 Factory AI 接入网页爬取与搜索功能。

<div id="quick-setup">
  ## 快速开始 {#quick-setup}
</div>

<div id="1-get-your-api-key">
  ### 1. 获取你的 API 密钥 {#1-get-your-api-key}
</div>

在 [firecrawl.dev/app](https://firecrawl.dev/app) 注册并复制你的 API 密钥。

### 2. 安装 Factory AI CLI {#2-install-factory-ai-cli}

如果尚未安装，请先安装 [Factory Droid CLI](https://docs.factory.ai/droid-cli/quickstart)：

**macOS/Linux：**

```bash
curl -fsSL https://app.factory.ai/cli | sh
```

**Windows：**

```powershell
irm https://app.factory.ai/cli/windows | iex
```

### 3. 添加 Firecrawl MCP 服务器 {#3-add-firecrawl-mcp-server}

在终端中运行 `droid mcp add`，添加托管的 Firecrawl MCP 服务器：

```bash
droid mcp add firecrawl https://mcp.firecrawl.dev/v2/mcp --type http \
  --header "Authorization: Bearer your-api-key-here" --no-oauth
```

将 `your-api-key-here` 替换为你的实际 Firecrawl API 密钥。

如果想改为在本地运行服务器，可将其添加为 stdio 服务器：

```bash
droid mcp add firecrawl "npx -y firecrawl-mcp@3.33.2" --env FIRECRAWL_API_KEY=your-api-key-here
```

你也可以在 Droid 中输入 `/mcp`，检查服务器状态并查看其提供的工具。

### 4. 完成！ {#4-done}

现在，你的 Factory AI 会话中已可使用 Firecrawl 工具！

## 快速演示 {#quick-demo}

在 Factory AI 中试试以下操作：

**搜索全网：**

```
搜索最新的 Next.js 版本发布说明
```

**抓取页面：**

```
抓取 firecrawl.dev 并告诉我它是做什么的
```

**查看文档：**

```
查找并抓取 Stripe API 文档中的 Payment Intents 部分
```

Factory 将自动借助 Firecrawl 的搜索与抓取工具获取信息。
