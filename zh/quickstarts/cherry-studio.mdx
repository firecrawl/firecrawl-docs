通过远程托管的 MCP 服务器，将 Firecrawl 的搜索、抓取等网页工具添加到 [Cherry Studio](https://cherry-ai.com) 中。

Cherry Studio 支持带自定义标头的远程 Streamable HTTP 服务器，因此你可以直接使用 Firecrawl API 密钥进行连接。

## 快速配置 {#quick-setup}

1. [创建 Firecrawl API 密钥](https://www.firecrawl.dev/app/api-keys)。
2. 在 Cherry Studio 中，打开 **设置 → MCP → MCP 服务器**，然后点击 **Add**。
3. 选择 **Import from JSON**，粘贴以下内容，并将 `<FIRECRAWL_API_KEY>` 替换为你的密钥：

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "streamableHttp",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

4. 启用该服务器，等待其状态变为健康，然后打开服务器详情，确认列表中包含 `firecrawl_search` 和 `firecrawl_scrape`。
5. 打开 **Work**，编辑你的智能体，进入 **MCP**，启用 Firecrawl 服务器，让智能体可以使用它。

你也可以使用 **Quick Create**：将类型设为 **Streamable HTTP**，URL 设为 `https://mcp.firecrawl.dev/v2/mcp`，并添加标头 `Authorization=Bearer <FIRECRAWL_API_KEY>`。

如需改用本地服务器，请将类型设为 `stdio`，命令设为 `npx`，参数设为 `-y` 和 `firecrawl-mcp`，并设置环境变量 `FIRECRAWL_API_KEY`。请参见[本地 MCP 服务器指南](/zh/mcp-server/local)。

如果未设置 `Authorization` 标头，Cherry Studio 也可以通过 OAuth 登录远程服务器。有关 Firecrawl OAuth 端点，请参见 [For Humans](/zh/mcp-server/oauth)。

## 故障排查 {#troubleshooting}

* **服务器无法连接：** 确认类型为 Streamable HTTP，URL 与 `https://mcp.firecrawl.dev/v2/mcp` 完全一致，且标头为 `Authorization: Bearer <FIRECRAWL_API_KEY>`。可在服务器详情页中查看服务器日志。
* **聊天中未显示工具：** 服务器必须处于运行状态，并已为该智能体启用。请检查 **Work → 智能体 → Edit → MCP**。
* **缺少某个工具：** 打开服务器详情，查看其提供了哪些工具，并确认你的 API 密钥有效。
