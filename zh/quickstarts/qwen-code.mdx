将 Firecrawl 作为远程 HTTP MCP 服务器连接到 Qwen Code，让 Qwen Code 能够进行网页搜索并读取网页内容。

## 前提条件 {#requirements}

* Qwen Code 0.25 或更高版本。
* [Firecrawl API 键](https://www.firecrawl.dev/app/api-keys)，并导出为环境变量 `FIRECRAWL_API_KEY`。

## 快速配置 {#quick-setup}

1. 在用于启动 Qwen Code 的 shell 中导出你的 API 键：

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

2. 添加服务器。使用单引号可防止 shell 展开变量，这样设置文件中保存的是变量引用，而不是你的键：

```bash
qwen mcp add --scope user --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp \
  --header 'Authorization: Bearer $FIRECRAWL_API_KEY'
```

3. 确认服务器已连接：

```bash
qwen mcp list
```

4. 启动 Qwen Code，运行 `/mcp` 查看 Firecrawl 工具，然后让它执行搜索或抓取。

<Accordion title="想直接编辑设置文件？">
  将该服务器添加到 `~/.qwen/settings.json`，或项目中的 `.qwen/settings.json`：

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "httpUrl": "https://mcp.firecrawl.dev/v2/mcp",
        "headers": {
          "Authorization": "Bearer $FIRECRAWL_API_KEY"
        }
      }
    }
  }
  ```
</Accordion>

有关键的更多信息，请参见[配置 API 键](/zh/mcp-server/keyless#add-an-api-key)。

## 故障排除 {#troubleshooting}

* **正在运行的会话中找不到该服务器：** 添加服务器后，请在同一项目中重新启动 Qwen Code。
* **服务器显示未连接：** 运行 `qwen mcp list`，并检查启动 Qwen Code 的 shell 中是否已导出 `FIRECRAWL_API_KEY`。
* **工具调用因键无效而被拒绝：** 确认标头值为 `Bearer $FIRECRAWL_API_KEY`，且该变量中存放的是有效的键。
* **工具未被调用：** 不同模型调用 MCP 工具的稳定性有所差异，请尝试换用其他模型。
