Claude Desktop、Cowork 和 Code 标签页都会从你的 Claude 账户读取连接器。只需以服务器名称 `firecrawl` 连接一次 Firecrawl，即可在所有标签页中使用。

| 设置         | 值                                                                     |
| ---------- | --------------------------------------------------------------------- |
| 服务器名称      | `firecrawl`                                                           |
| 自定义连接器 URL | `https://mcp.firecrawl.dev/v2/mcp-oauth` (仅在添加自定义连接器、而非使用名录中的连接器时需要)  |
| 登录         | 在浏览器中登录 Firecrawl，然后选择并批准一个团队                                         |

`https://mcp.firecrawl.dev/v2/mcp-oauth` 是客户端配置值，并非用于在浏览器中直接打开的页面。

## 1. 添加 Firecrawl 连接器 {#1-add-the-firecrawl-connector}

1. 在 Claude 连接器名录中打开 [Firecrawl 连接器](https://claude.ai/directory/connectors/firecrawl)，或在 Claude Desktop 中前往 **Customize &gt; 连接器** 并搜索 Firecrawl。
2. 点击 **Connect**，Claude 会在浏览器中打开 Firecrawl。
3. 登录 Firecrawl，选择一个团队，然后授权访问。

如果使用 Team 或企业版套餐，可能需要组织 Owner 先允许该连接器，成员才能连接。

<Accordion title="无法使用名录中的连接器？添加自定义连接器">
  1. 在 Claude Desktop 中，前往 **Customize &gt; 连接器**。
  2. 点击 **Add**，然后添加自定义连接器。
  3. 名称填写 `firecrawl`，远程 MCP 服务器 URL 填写 `https://mcp.firecrawl.dev/v2/mcp-oauth`。
  4. 保留自动检测到的登录设置，添加连接器，然后点击 **Connect** 并在浏览器中完成登录。

  组织 Owner 则需在 **Organization settings &gt; 连接器** 中添加自定义连接器。
</Accordion>

## 2. 在 Cowork 和聊天中使用 {#2-use-it-in-cowork-and-chat}

在 Cowork 或 Chat 标签页中，点击 prompt 输入框旁的 **+** 菜单，进入 **连接器**，确认已启用 Firecrawl。然后试试以下示例：

```text
使用 Firecrawl 搜索最新的 Next.js 版本发布说明，并总结信息来源。
```

```text
抓取 https://firecrawl.dev，并介绍它的功能。
```

## 3. 在 Code 标签页中使用 {#3-use-it-in-the-code-tab}

本地 Code 标签页会话也可以使用同一个连接器。点击 prompt 输入框旁的 **+** 按钮，选择 **连接器**，然后启用 Firecrawl。

Code 标签页还会加载你添加到 Claude Code 中的 MCP 服务器，例如通过 `claude mcp add` 添加的服务器。如果你已按照 [Claude Code 指南](/zh/quickstarts/claude-code)在 Claude Code 中配置了 Firecrawl，请保留服务器名称 `firecrawl`，并确认会话中只启用了一个 Firecrawl 服务器。

## 故障排除 {#troubleshooting}

* **Firecrawl 工具未显示。** 连接后请开启新的对话或会话，并检查 **连接器** 菜单中是否已启用 Firecrawl。
* **Firecrawl 重复出现。** 删除多余的条目，只保留一个名为 `firecrawl` 的连接器。在 **Customize &gt; 连接器** 中添加的连接器可在 Cowork 中使用，而 `claude_desktop_config.json` 中配置的本地服务器则无法使用，因此建议优先使用连接器。
* **团队选择错误。** 在 [MCP 设置](https://www.firecrawl.dev/app/settings?tab=mcp)中查看或撤销该连接，然后重新连接并选择正确的团队。
