在 JetBrains IDE 和 VS Code 中将 Firecrawl 添加到 Zencoder。JetBrains 支持通过 OAuth2 连接远程服务器，因此你可以直接使用 Firecrawl 账户登录。VS Code 则使用 API 密钥在本地启动服务器。

## 前置要求 {#requirements}

* 已在 JetBrains IDE 或 VS Code 中安装 Zencoder 插件。
* 若使用 VS Code 配置方式：需要 Node.js 22 或更高版本，以及 [Firecrawl API 密钥](https://www.firecrawl.dev/app/api-keys)。

## 快速配置 {#quick-setup}

<Tabs>
  <Tab title="JetBrains">
    1. 依次打开 **设置** → **Tools** → **Zencoder** → **MCP 服务器**。
    2. 添加以下服务器并应用更改：

    ```json
    {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth",
        "auth": "oauth2"
      }
    }
    ```

    3. 在浏览器中完成 Firecrawl 登录，然后确认这些工具已出现在智能体的工具列表中。
  </Tab>

  <Tab title="VS Code">
    1. 打开用户级或工作区级的 `settings.json`。
    2. 在 `zencoder.mcpServers` 下添加 Firecrawl：

    ```json
    {
      "zencoder.mcpServers": {
        "firecrawl": {
          "command": "npx",
          "args": ["-y", "firecrawl-mcp@3.33.2"],
          "env": {
            "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
          }
        }
      }
    }
    ```

    3. 重启 VS Code，然后确认 Firecrawl 工具已出现在 **智能体工具** 下。
  </Tab>
</Tabs>

根据 Zencoder 文档，VS Code 对 HTTP 和 OAuth2 服务器的支持仍在逐步推出，因此在你的版本支持之前，请先使用本地配置方式。更多详情请参见 [OAuth 连接指南](/zh/mcp-server/oauth) 和 [在本地运行 MCP](/zh/mcp-server/local)。

## 故障排除 {#troubleshooting}

* **服务器未出现在智能体工具中：** 检查 JSON 语法，然后重启 IDE。MCP 服务器在启动时加载。
* **JetBrains 登录失败：** 清除该服务器的缓存令牌，然后重新登录。
* **VS Code 提示缺少命令：** 确认 `npx` 能在终端中正常运行，且 `node --version` 输出的版本为 22 或更高。
* **工具无法运行：** Zencoder 会在工具调用前请求权限。请为 Firecrawl 工具选择 **Allow once** 或 **Always allow**。
