通过远程托管的 MCP 服务器，将 Firecrawl 连接到 [Google Antigravity](https://antigravity.google/)，然后使用你的 Firecrawl 账户登录。

## 快速配置 {#quick-setup}

1. 在 Antigravity 中，点击智能体侧边栏顶部的 **…**，然后选择 **MCP Servers**。
2. 点击 **Manage MCP Servers**，再点击 **View raw config**，打开 `mcp_config.json` (全局配置位于 `~/.gemini/config/mcp_config.json`，工作区配置位于 `.agents/mcp_config.json`) 。
3. 添加 Firecrawl 服务器并保存：

```json
{
  "mcpServers": {
    "firecrawl": {
      "serverUrl": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

4. 打开 Agent 设置 (`Cmd/Ctrl + ,`) ，进入 **Customizations**，然后点击 `firecrawl` 旁边的 **Authenticate**。
5. 在浏览器中登录 Firecrawl 并选择要授权的团队，然后将授权码粘贴回 Antigravity，点击 **Submit**。
6. 确认 Firecrawl 的工具 (例如 `firecrawl_search` 和 `firecrawl_scrape`) 已可用。

对于远程服务器，Antigravity 要求使用 `serverUrl` 键，使用 `url` 或 `httpUrl` 的条目将无法注册。Antigravity CLI 读取的是同一个文件；在 CLI 中输入 `/mcp` 即可检查服务器状态。

<Accordion title="更想使用 API 密钥？">
  如需无人值守运行，请[创建 Firecrawl API 密钥](https://www.firecrawl.dev/app/api-keys)，并将其作为标头发送，无需登录。详情请参见[添加 API 密钥](/zh/mcp-server/keyless#add-an-api-key)。

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "serverUrl": "https://mcp.firecrawl.dev/v2/mcp",
        "headers": {
          "Authorization": "Bearer fc-YOUR-API-KEY"
        }
      }
    }
  }
  ```
</Accordion>

更多详情请参见 [OAuth 连接指南](/zh/mcp-server/oauth)。


## 故障排查 {#troubleshooting}

* **服务器显示为失败：** 确认该条目使用的是 `serverUrl`，且值完全为 `https://mcp.firecrawl.dev/v2/mcp-oauth`，然后在 **Manage MCP Servers** 或 CLI 的 `/mcp` 管理器中重新加载该服务器。
* **提示需要登录或登录已过期：** 在 **Customizations** 中再次点击 `firecrawl` 旁的 **Authenticate**。
* **已存在其他 Firecrawl 连接：** 将现有服务器更新为 OAuth URL 并登录，确保只有一个 Firecrawl 服务器处于启用状态。
