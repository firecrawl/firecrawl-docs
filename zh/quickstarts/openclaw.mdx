将 Firecrawl 集成到 OpenClaw 中，为你的智能体提供抓取、搜索、爬取以及与网页交互的能力，还能运行智能体任务——全部通过 [Firecrawl CLI](/zh/sdks/cli) 完成。

## 为什么选择 Firecrawl + OpenClaw {#why-firecrawl-openclaw}

* **无需本地浏览器** —— 每个会话都在远程、隔离的沙箱中运行。无需安装 Chromium、无需处理驱动冲突，也不会给你的机器带来内存压力。
* **真正的并行能力** —— 可同时运行多个浏览器会话，而不会争抢本地资源。Agent 可以成批并行浏览多个站点。
* **默认即安全** —— 导航、DOM 评估和内容抽取都在可丢弃的沙箱环境中完成，而不是在你的工作站上。
* **更优的 Token 使用效率** —— Agent 获取的是干净的结果产物 (快照、抽取字段) ，而不是把巨大的 DOM 和驱动日志放入上下文窗口。
* **完整的 Web 工具集** —— 通过一个你的 Agent 已经会用的单一 CLI 完成抓取、搜索和浏览器自动化。

## 设置 {#setup}

让你的 智能体 安装 Firecrawl CLI，完成身份验证，并通过以下命令初始化该技能：

```bash
npx -y firecrawl-cli init --browser --all
```

* `--all` 会跳过 智能体 选择，直接初始化所有已检测到的 智能体
* `--browser` 会自动打开浏览器以完成 Firecrawl 身份验证

或者分别安装所有组件：

```bash
npm install -g firecrawl-cli
firecrawl setup skills
firecrawl login --browser
# 或者，跳过浏览器，直接提供您的 API 密钥：
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

验证一切是否已正确配置：

```bash
firecrawl --status
```

<Tip>
  安装该技能后，你的 OpenClaw 智能体会自动识别并使用 Firecrawl 命令，无需任何额外配置。
</Tip>

## 抓取 {#scrape}

抓取单个页面并提取其中的内容：

```bash
firecrawl https://example.com --only-main-content
```

获取指定格式：

```bash
firecrawl https://example.com --format markdown,links --pretty
```

## 搜索 {#search}

在网上搜索，并可选择抓取搜索结果：

```bash
firecrawl search "latest AI funding rounds" --limit 10

# 搜索并抓取结果
firecrawl search "OpenClaw documentation" --scrape --scrape-formats markdown
```

## 交互 {#interact}

先抓取网页，再在实时浏览器会话中继续操作该页面。每个会话都在隔离的沙箱中远程运行，无需在本地安装 Chromium。`interact` 默认使用最近一次抓取的结果。

```bash
firecrawl scrape https://news.ycombinator.com
firecrawl interact "What are the titles of the top 3 stories?"
firecrawl interact "Click the More link at the bottom of the page and list the first 3 story titles"
firecrawl interact stop
```

直接在实时页面上运行代码，而不是使用 prompt：

```bash
firecrawl interact -c "await page.title()"
firecrawl interact -c "print(await page.title())" --python
```

<Note>
  你的智能体只需发出意图层面的 prompt 或简短的 Playwright 代码片段，无需自行管理本地浏览器。用完后运行 `firecrawl interact stop` 释放会话。旧的 `firecrawl browser` 命令已废弃，请改为先运行 `scrape`，再运行 `interact`。
</Note>

## 示例：告诉你的 智能体 {#example-tell-your-agent}

以下是一些你可以给 OpenClaw 智能体 的提示词：

* *「使用 Firecrawl 抓取 https://example.com，并总结主要内容。」*
* *「搜索最新的 OpenAI 新闻，并给我前 5 条结果的摘要。」*
* *「使用 Firecrawl 的 interact 打开 Hacker News，获取排名前 5 的帖子，以及每个帖子的前 10 条评论。」*
* *「爬取 https://docs.firecrawl.dev 上的文档，并将其保存到文件中。」*
