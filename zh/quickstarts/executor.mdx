将 Firecrawl 远程托管的 MCP 服务器添加到 [Executor](https://executor.sh)，即可让所有连接到 Executor 的智能体通过同一个端点搜索和抓取网页。

<Note>
  以下步骤适用于 Executor 1.x (`npm install -g executor`) 。Executor 2 (测试版) 以应用和账户的形式组织 MCP 服务器，相关流程请参见 [Executor 文档](https://executor.sh/docs)。
</Note>

## 快速配置 {#quick-setup}

[创建 Firecrawl API 密钥](https://www.firecrawl.dev/app/api-keys)，然后启动 Executor：

```bash
npm install -g executor
executor web
```

在 Web UI 中添加集成，并从目录中选择 **Firecrawl**，或自行输入 MCP URL：

```text
https://mcp.firecrawl.dev/v2/mcp
```

Executor 会检测到该 MCP 服务器并为其工具建立索引。当提示输入凭据时，请输入您的 Firecrawl API 密钥，这样请求就会带上 `Authorization: Bearer <key>` 标头。

您可以先在命令行中检查该服务器：

```bash
executor call executor mcp probeEndpoint '{"endpoint":"https://mcp.firecrawl.dev/v2/mcp","headers":{"Authorization":"Bearer '"$FIRECRAWL_API_KEY"'"}}'
```

然后将你的智能体连接到 Executor 自带的 MCP 端点 (本地服务器为 `http://127.0.0.1:4788/mcp`) ：

```bash
npx add-mcp http://127.0.0.1:4788/mcp --transport http --name executor
```

运行 `executor tools integrations`，确认列表中包含 `firecrawl`，且其工具数量大于 0。

## 故障排除 {#troubleshooting}

* **工具数量为 0：** Executor 按账户创建工具，因此请先用你的 API 密钥完成 Firecrawl 账户连接，再刷新该来源。
* **添加服务器的命令处于暂停状态：** Executor 会请求你批准添加 MCP 服务器；运行 `executor resume --execution-id <id> --action accept --content '{}'` 即可批准。
* **智能体看不到这些工具：** 大多数客户端仅在启动时加载 MCP 服务器，因此添加 Executor 后，请重启客户端或开启新会话。
