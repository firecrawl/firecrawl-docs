通过远程托管的 MCP 服务器将 Firecrawl 添加到 Rovo Dev CLI。Rovo Dev CLI 通过请求标头读取远程服务器配置，因此该配置方式需使用 Firecrawl API 密钥。

## 前提条件 {#requirements}

* 已安装 Rovo Dev CLI (作为 Atlassian CLI `acli` 的扩展) ，并已通过 `acli rovodev auth login` 登录。
* 一个 [Firecrawl API 密钥](https://www.firecrawl.dev/app/api-keys)。

## 快速配置 {#quick-setup}

1. 运行 `acli rovodev mcp`，在默认编辑器中打开 `~/.rovodev/mcp.json`。
2. 添加 Firecrawl 配置，替换为你的密钥，然后保存：

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "transport": "http",
      "headers": {
        "Authorization": "Bearer fc-YOUR-API-KEY"
      }
    }
  }
}
```

3. 运行 `acli rovodev run` 启动 Rovo Dev，输入 `/mcp`，确认列表中已显示 `firecrawl` 及其工具。

<Accordion title="想使用本地服务器？">
  Rovo Dev CLI 也支持启动 stdio 服务器。请参见[在本地运行 MCP](/zh/mcp-server/local)，并在同一文件中定义启动命令：

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "command": "npx",
        "args": ["-y", "firecrawl-mcp@3.33.2"],
        "env": {
          "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
        },
        "transport": "stdio"
      }
    }
  }
  ```
</Accordion>

该文件包含你的密钥，请妥善保管，切勿公开。有关基于密钥的连接的更多信息，请参见[配置 API 密钥](/zh/mcp-server/keyless#add-an-api-key)。

## 故障排查 {#troubleshooting}

* **`/mcp` 中未列出 Firecrawl：**&#x68C0;查 JSON 是否有效，并确认远程托管 URL 对应的 `transport` 为 `"http"`。
* **服务器显示 `401`：**&#x66FF;换 `mcp.json` 中的键，然后重新启动 `acli rovodev run`。
* **Firecrawl 已列出但处于禁用状态：**&#x6253;开 `/mcp` 将其启用，并检查 `~/.rovodev/config.yml` 中的 `disabledMcpServers` 下是否列有它。
* **不需要服务器指令：**&#x5728; Firecrawl 条目中设置 `"enable_instructions": false`。
