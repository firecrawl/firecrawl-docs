## 前提条件 {#prerequisites}

* Node.js 22.13+
* 一个 Firecrawl API 密钥——[免费获取一个](https://www.firecrawl.dev/app/api-keys)
* 来自受支持的 [Mastra 模型提供商](https://mastra.ai/models)的 API 密钥
* 一个现有的 Mastra 项目——按照 [Mastra 快速开始](https://mastra.ai/guides/getting-started/quickstart) 进行创建

## 安装 SDK {#install-the-sdk}

```bash
npm install firecrawl
```

## 设置 API 密钥 {#set-your-api-key}

将 API 密钥添加到 `.env` 中：

```bash
FIRECRAWL_API_KEY=fc-YOUR-API-KEY
```

## 构建 Firecrawl 工具 {#build-the-firecrawl-tools}

创建 `src/mastra/tools/firecrawl.ts`，将 search 和 抓取 暴露为 Mastra 工具：

```typescript
import { Firecrawl } from "firecrawl";
import { createTool } from "@mastra/core/tools";
import { z } from "zod";

const firecrawl = new Firecrawl();

export const firecrawlSearch = createTool({
  id: "firecrawl-search",
  description: "Search the web and return top results.",
  inputSchema: z.object({ query: z.string().min(1) }),
  outputSchema: z.object({
    results: z.array(
      z.object({
        title: z.string().nullable(),
        url: z.string(),
      }),
    ),
  }),
  execute: async ({ query }) => {
    const results = await firecrawl.search(query, { limit: 3 });
    return {
      results: (results.web ?? []).flatMap((item) =>
        "url" in item ? [{ title: item.title ?? null, url: item.url }] : [],
      ),
    };
  },
});

export const firecrawlScrape = createTool({
  id: "firecrawl-scrape",
  description: "Scrape a URL and return markdown content.",
  inputSchema: z.object({ url: z.string().url() }),
  outputSchema: z.object({ markdown: z.string() }),
  execute: async ({ url }) => {
    const result = await firecrawl.scrape(url, {
      formats: ["markdown"],
      onlyMainContent: true,
    });
    return { markdown: result.markdown ?? "" };
  },
});
```

## 创建代理 {#create-the-agent}

创建 `src/mastra/agents/web-agent.ts`，并为其添加 Firecrawl 工具：

```typescript
import { Agent } from "@mastra/core/agent";
import { firecrawlSearch, firecrawlScrape } from "../tools/firecrawl";

export const webAgent = new Agent({
  id: "web-agent",
  name: "Web Agent",
  instructions:
    "Use Firecrawl tools to search and scrape web pages, then summarize the results.",
  model: "openai/gpt-5.4",
  tools: { firecrawlSearch, firecrawlScrape },
});
```

## 注册代理 {#register-the-agent}

在 `src/mastra/index.ts` 中向你的 Mastra 实例注册代理：

```typescript
import { Mastra } from "@mastra/core";
import { webAgent } from "./agents/web-agent";

export const mastra = new Mastra({
  agents: { webAgent },
});
```

## 在 Studio 中测试 {#test-in-studio}

运行开发服务器，并在 `http://localhost:4111` 打开 [Mastra Studio](https://mastra.ai/docs/studio/overview)：

```bash
npm run dev
```

打开 **网页代理**，尝试以下 prompt：

* &quot;查找最新的 Firecrawl 更新日志，并总结最近一次发布的内容。&quot;
* &quot;搜索 Firecrawl 的定价，并提取各套餐档位。&quot;

## 为智能体提供托管浏览器 {#give-the-agent-a-hosted-browser}

对于需要点击、输入或滚动的页面，Mastra 的 [`@mastra/browser-firecrawl`](https://mastra.ai/integrations/browsers/firecrawl) 包会在 Firecrawl 浏览器会话中运行智能体的浏览器工具，无需在本地安装 Chromium。

```bash
npm install @mastra/browser-firecrawl agent-browser@0.19.0
```

<Note>
  请将 `agent-browser` 的版本锁定为 0.19.0。之后的版本仅提供 CLI，会导致 `@mastra/browser-firecrawl` 导入失败，并报错 `Cannot find package .../agent-browser/index.js`。
</Note>

创建 `src/mastra/agents/browser-agent.ts`，然后参照 `webAgent` 的方式，在 Mastra 实例上注册 `browserAgent`：

```typescript
import { Agent } from "@mastra/core/agent";
import { FirecrawlBrowser } from "@mastra/browser-firecrawl";

export const browserAgent = new Agent({
  id: "browser-agent",
  name: "Browser Agent",
  instructions:
    "Use the browser tools to open pages, click, and type. Take a snapshot after each action to check the result.",
  model: "openai/gpt-5.4",
  browser: new FirecrawlBrowser({ apiKey: process.env.FIRECRAWL_API_KEY }),
});
```

默认情况下，每个对话会话都有各自独立的浏览器会话。如需了解共享会话、会话超时以及已保存的配置文件，请参见 [Mastra Firecrawl 浏览器文档](https://mastra.ai/integrations/browsers/firecrawl)。

## 自托管 Firecrawl {#self-hosted-firecrawl}

如果你自行部署运行 Firecrawl，请将 `FIRECRAWL_API_URL` 添加到 `.env` 中。SDK 会从环境变量中读取该值，因此上述工具无需任何变更：

```bash
FIRECRAWL_API_URL=http://localhost:3002
```
