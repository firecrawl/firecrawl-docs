## 可选：设置 Claude Code {#optional-set-up-claude-code}

通过远程托管的 MCP 服务器连接 Claude Code。运行以下命令，然后在浏览器中登录。

### 1. 添加 Firecrawl {#1-add-firecrawl}

运行：

```bash
claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

`https://mcp.firecrawl.dev/v2/mcp-oauth` 是客户端配置值，不是可直接在浏览器中打开的页面。

### 2. 登录并验证 {#2-sign-in-and-verify}

在 Claude Code 中输入 `/mcp`，选择 `firecrawl`，然后在浏览器中完成登录。如果你修改了现有的 Firecrawl 连接，请新建一个 Claude Code 会话。

确认只有一个 `firecrawl` 服务器处于活跃状态，然后尝试：

```text
搜索最新的 Next.js 版本发布说明，并总结这些来源。
```

```text
抓取 https://firecrawl.dev 并说明它的用途。
```

## 其他连接方式 {#other-connection-modes}

* 使用[免密钥 MCP](/zh/mcp-server/keyless#try-keyless)，无需账户或密钥即可使用网页搜索、抓取 和 Parse。
* 如需无人值守运行，请[配置 API 密钥](/zh/mcp-server/keyless#add-an-api-key)。请勿在代理聊天中透露密钥，改用环境变量引用。
* 仅当需要本地进程或自托管 Firecrawl API 时，才[在本地运行 MCP](/zh/mcp-server/local)。本地软件包要求 Node.js 22 或更高版本。

## 可选：文献研究 {#optional-literature-research}

处理论文和文献相关任务时，research-index 技能会将这些查询转发至 `firecrawl_research_*` 工具和[研究索引](/zh/features/research)，而非通用网页搜索：

```bash
npx skills add firecrawl/skills@firecrawl-research-index
```

## 故障排除 {#troubleshooting}

* **Firecrawl 服务器已存在：**运行 `claude mcp remove firecrawl`，添加所需的连接一次，然后开启新会话。
* **浏览器未打开：**输入 `/mcp`，选择 `firecrawl`，然后在客户端发起身份验证。
* **服务器显示 `401`：**通过 `/mcp` 重新登录；请勿将 API 密钥粘贴到对话或 OAuth URL 中。
