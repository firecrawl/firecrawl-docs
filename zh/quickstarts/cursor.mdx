title: "在 Cursor 中使用 MCP 实现网页搜索与抓取"
description: "用 2 分钟为 Cursor 接入网页抓取与搜索功能"
---

通过远程托管的 MCP 服务器，将 Firecrawl 的免密钥 Search、Scrape 和 Parse 工具添加到 Cursor。

<div id="quick-setup">
  ## 快速设置
</div>

打开 Cursor 的设置，选择 **MCP**，然后添加：

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

重启 Cursor，然后确认 `firecrawl_search`、`firecrawl_scrape` 和 `firecrawl_parse` 可用。

免密钥访问的限额由同一公共 IP 下的用户共享。请通过交互式客户端使用 [For Humans](/zh/mcp-server/oauth) 登录，或[添加 API 密钥](/zh/mcp-server/keyless#add-an-api-key)以供无人值守使用。

<div id="troubleshooting">
  ## 故障排除
</div>

* **服务器无法连接：**确认 URL 是否准确为 `https://mcp.firecrawl.dev/v2/mcp`，并检查 Cursor 的 MCP 状态。
* **缺少 Crawl 或其他工具：**免密钥模式仅提供 Search、Scrape 和 Parse。使用 OAuth 或 API 密钥连接，以使用更完整的工具集。
