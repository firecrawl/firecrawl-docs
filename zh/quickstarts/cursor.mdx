通过远程托管的 MCP 服务器，将 Firecrawl 连接到 Cursor，然后使用你的 Firecrawl 账户登录。

<CursorInstallButton />

## 快速配置 {#quick-setup}

1. 点击上方的 **Add to Cursor**，在 Cursor 中打开安装对话框。
2. 确认安装 Firecrawl MCP 服务器。
3. 在 Cursor 中通过该服务器的登录选项连接你的 Firecrawl 账户，并授予访问权限。
4. 确认 Cursor 中已可使用 Firecrawl 的工具。

<Accordion title="想手动添加配置？">
  打开 Cursor Settings，选择 **MCP**，然后添加以下内容：

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
      }
    }
  }
  ```

  保存配置，然后在 Cursor 中完成浏览器登录。
</Accordion>

更多详情请参见 [OAuth 连接指南](/zh/mcp-server/oauth)。如需在无人值守的场景下使用，请[配置 API 密钥](/zh/mcp-server/keyless#add-an-api-key)。

## 故障排除 {#troubleshooting}

* **服务器无法连接：**确认 URL 是否准确为 `https://mcp.firecrawl.dev/v2/mcp-oauth`，并检查 Cursor 的 MCP 状态。
* **提示需要登录或登录已过期：**在 Cursor 的 MCP 设置中重新发起身份验证。
* **已存在另一个 Firecrawl 连接：**将现有服务器更新为 OAuth URL 并登录，确保只有一个 Firecrawl 服务器处于启用状态。
