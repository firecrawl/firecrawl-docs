通过远程托管的 MCP 服务器，将 Firecrawl 的搜索、抓取、爬取和映射工具添加到[腾讯 WorkBuddy](https://www.workbuddy.ai) 中。

## 快速配置 {#quick-setup}

[创建 Firecrawl API 键](https://www.firecrawl.dev/app/api-keys)，然后在 WorkBuddy 中添加该服务器：

1. 打开 **Experts · Skills · Connectors**，切换到 **Connectors** 选项卡，然后选择 **Custom connectors**。
2. 选择 **Configure MCP**，打开 MCP 配置编辑器。
3. 将 Firecrawl 添加到 `mcpServers` 中并保存：

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

将 `<FIRECRAWL_API_KEY>` 替换为你的 API 键。如果你已配置其他服务器，只需添加 `firecrawl` 条目，其余内容保持不变。

WorkBuddy 会将该配置保存在 `~/.workbuddy/mcp.json` 中。如果只想用于单个项目，请改用 `<project>/.workbuddy/mcp.json`。

回到 MCP 列表，开启 **firecrawl**；如果 WorkBuddy 弹出提示，请选择信任。状态显示为绿色即表示已连接，此时可以使用 `firecrawl_search`、`firecrawl_scrape` 等工具。

WorkBuddy 还支持 MCP OAuth。如需通过登录而非 API 键进行认证，请参见 [面向人类](/zh/mcp-server/oauth)。

## 故障排查 {#troubleshooting}

* **状态显示为红色：** 检查 JSON 是否有效，并确认 URL 与 `https://mcp.firecrawl.dev/v2/mcp` 完全一致。
* **401 未授权：** 确认 API 键无误，并在 `Authorization` 标头中保留 `Bearer ` 前缀。
* **工具未显示：** 将服务器关闭后重新开启，让 WorkBuddy 刷新工具列表。
