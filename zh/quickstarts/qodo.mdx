将 Firecrawl 添加到 Qodo Command，让你的 Qodo 智能体能够进行网页搜索并读取页面内容。Qodo Command 会使用你的 API 密钥，以本地进程的形式启动 Firecrawl MCP 服务器。

<Note>
  Qodo 将于 2026 年 10 月 30 日停用其 IDE 插件，并将本地工作流迁移到你正在使用的编程代理中。本页介绍的是 Qodo Command，它会从项目文件中读取 MCP 服务器配置。
</Note>

## 前提条件 {#requirements}

* Qodo Command：使用 `npm install -g @qodo/command` 安装，并通过 `qodo login` 登录。
* Node.js 22 或更高版本。
* [Firecrawl API 密钥](https://www.firecrawl.dev/app/api-keys)。

## 快速设置 {#quick-setup}

1. 在项目根目录下创建 `mcp.json`：

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp@3.33.2"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
      }
    }
  }
}
```

2. 创建 `agents/research.toml`，并按名称为该智能体授予该服务器的访问权限：

```toml
version = "1.0"

[commands.research]
description = "Research a topic on the web with Firecrawl"
instructions = """
Use the Firecrawl tools to search the web and read pages, then summarize the sources.
"""
tools = ["firecrawl"]
execution_strategy = "act"
```

3. 从项目根目录的 `agent.toml` 导入智能体：

```toml
version = "1.0"

imports = ["agents/research.toml"]
```

4. 运行智能体并列出可用工具：

```bash
qodo list-mcp
qodo research "Find the latest release notes for Node.js"
```

请勿将 `mcp.json` 提交到版本控制系统，因为其中包含你的 API 键。完整的环境变量列表请参见 [在本地运行 MCP](/zh/mcp-server/local)。

## 故障排查 {#troubleshooting}

* **`list-mcp` 未显示 Firecrawl 条目：** 确认 `mcp.json` 位于项目根目录，或传入 `--mcp-file=path`。
* **智能体始终不调用 Firecrawl：** 检查智能体文件中的 `tools` 是否包含 `"firecrawl"`，且与 `mcp.json` 中的键一致。
* **服务器无法启动：** 运行 `node --version`，确认输出的版本为 22 或更高。
* **服务器返回 `401`：** 替换 `mcp.json` 中 `FIRECRAWL_API_KEY` 的值。
