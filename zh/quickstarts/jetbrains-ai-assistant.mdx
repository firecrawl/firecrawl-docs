将 Firecrawl 添加到 IntelliJ IDEA、PyCharm、WebStorm 及其他 JetBrains IDE 的 AI Assistant 中。AI Assistant 会使用你的 API 密钥，以本地进程的方式启动 Firecrawl MCP 服务器。

## 前提条件 {#requirements}

* 安装了 AI Assistant 2025.1 或更高版本的 JetBrains IDE。MCP 客户端支持从该版本开始提供。
* `PATH` 中可用的 Node.js 22 或更高版本，因为该服务器通过 `npx` 运行。
* 一个 [Firecrawl API 密钥](https://www.firecrawl.dev/app/api-keys)。

## 快速配置 {#quick-setup}

1. 依次打开 **设置** &gt; **Tools** &gt; **AI Assistant** &gt; **模型上下文协议 (MCP)&#x20;**。
2. 点击 **Add**。
3. 粘贴以下 JSON，替换其中的键，并将 **Server level** 设为全局或当前项目：

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp@3.33.2"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
      }
    }
  }
}
```

4. 选择 **OK**，然后选择 **Apply**。**Status** 列会显示该连接，点击其工具图标可查看 Firecrawl 提供的工具列表。
5. 如果希望服务器自动启动，请启用 **Automatically enable new and changed MCP servers**。

<Accordion title="改用远程连接">
  当前的 AI Assistant 文档还列出了 Streamable HTTP 服务器，可在同一 JSON 中通过 `url` 条目进行配置。但该文档并未说明请求标头或浏览器登录流程，因此除非你的 IDE 提供了这些选项，否则请使用上述本地配置方式连接 Firecrawl。
</Accordion>

有关环境变量的完整列表，请参见 [在本地运行 MCP](/zh/mcp-server/local)。

## 故障排查 {#troubleshooting}

* **状态一直显示为红色：** 在终端中运行 `node --version`，确认输出的版本为 22 或更高。安装 Node.js 后请重启 IDE，使其识别新的 `PATH`。
* **`spawn npx ENOENT`：** IDE 找不到 `npx`。请在能正常运行 `npx` 的 shell 中启动 IDE，或将 `npx` 的完整路径用作命令。
* **服务器显示 `401`：** 替换 `FIRECRAWL_API_KEY` 的值，然后再次点击 **Apply**。
* **日志：** MCP 设置页面提供了日志文件夹的链接，每个服务器对应一个日志文件。
