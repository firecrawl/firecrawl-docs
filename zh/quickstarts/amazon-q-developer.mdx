通过远程托管的 MCP 服务器，将 Firecrawl 连接到 VS Code、JetBrains 及其他受支持 IDE 中的 Amazon Q Developer。Q Developer 会打开浏览器，供你使用 Firecrawl 账户登录。

<Note>
  Amazon Q Developer CLI 现已更名为 Kiro CLI。如需在终端中使用，请参阅 [Kiro 设置指南](/zh/quickstarts/kiro)。
</Note>

## 快速设置 {#quick-setup}

1. 打开 IDE，依次进入 Q Developer 面板和 **Chat** 面板。
2. 点击工具图标，然后点击加号 (+) 按钮。
3. 选择作用域：**global** 会将服务器配置保存在 `~/.aws/amazonq/default.json` 中，**local** 则保存在项目内的 `.amazonq/default.json` 中。
4. 输入 `firecrawl` 作为名称，选择 **http** 作为传输方式，然后输入以下 URL：

```text
https://mcp.firecrawl.dev/v2/mcp-oauth
```

5. 选择 **Save**。Q Developer 会打开一个浏览器页面，供您授权访问。登录 Firecrawl 并批准连接。
6. 保存后，在弹出的面板中检查每个工具的权限 (**Ask**、**Always allow** 或 **Deny**) 。

<Accordion title="想直接编辑配置文件？">
  Q Developer 还会从 `~/.aws/amazonq/mcp.json` (全局) 和 `.amazonq/mcp.json` (项目级) 读取 MCP 服务器配置：

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
      }
    }
  }
  ```

  是否支持 `mcp.json` 文件由 `default.json` 中的 `useLegacyMcpJson` 字段控制，该字段默认为 `true`。
</Accordion>

<Accordion title="想改用 API 密钥？">
  在同一对话框中，添加名为 `Authorization` 的标头，值为 `Bearer fc-YOUR-API-KEY`，并将 URL 设置为 `https://mcp.firecrawl.dev/v2/mcp`。请参见[配置 API 密钥](/zh/mcp-server/keyless#add-an-api-key)。
</Accordion>

更多详情，请参见 [OAuth 连接指南](/zh/mcp-server/oauth)。

## 故障排查 {#troubleshooting}

* **出现“Fix Configuration”告警：**&#x70B9;击该告警返回表单，检查 URL 是否正确。
* **浏览器页面未打开：**&#x4E3A;该服务器选择 **Edit setup**，重新保存，并在页面打开后完成授权。
* **服务器已列出，但其工具无法运行：**&#x5728; MCP 服务器 面板中打开该服务器，确认其已启用，且工具未设置为 **Deny**。
* **出现两个 Firecrawl 条目：**`.amazonq/default.json` 中的服务器优先于全局服务器。请删除不需要的那个重复条目。
