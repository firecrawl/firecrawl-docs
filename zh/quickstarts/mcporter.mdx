[MCPorter](https://mcporter.sh) 是一款面向 MCP 服务器的 TypeScript 运行时与 CLI。你可以通过远程托管的 MCP 服务器将其连接到 Firecrawl。

## 快速设置 {#quick-setup}

[创建 Firecrawl API 密钥](https://www.firecrawl.dev/app/api-keys)，然后将其导出为环境变量：

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

将 Firecrawl 添加到项目的 `config/mcporter.json` 中；如需全局使用，则添加到 `~/.mcporter/mcporter.json`：

```json
{
  "mcpServers": {
    "firecrawl": {
      "baseUrl": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": { "Authorization": "Bearer ${FIRECRAWL_API_KEY}" }
    }
  }
}
```

MCPorter 会用环境变量中的值替换 `${FIRECRAWL_API_KEY}`，因此密钥不会写入文件。确认连接是否正常：

```bash
npx mcporter list firecrawl
```

想使用本地进程？请改用 stdio 方式：

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": { "FIRECRAWL_API_KEY": "${FIRECRAWL_API_KEY}" }
    }
  }
}
```

## 试一试 {#try-it}

```bash
npx mcporter call firecrawl.firecrawl_scrape url=https://firecrawl.dev 'formats=["markdown"]'
```

该命令会以 markdown 格式输出页面内容。在代码中也可以通过 `createRuntime` 使用同一配置条目 (请参见 [MCPorter 文档](https://mcporter.sh)) 。

## 故障排查 {#troubleshooting}

* **找不到服务器：**&#x8FD0;行 `npx mcporter config list`，查看 MCPorter 加载了哪个配置文件；`--config <file>` 或 `MCPORTER_CONFIG` 只能指定一个文件。
* **身份验证错误：**&#x4D;CPorter 不支持 `${env:VAR}` 写法；请将占位符写为 `${FIRECRAWL_API_KEY}`，并检查该变量是否已在同一 shell 中导出。
* **工具参数被拒绝：**&#x4F20;入 JSON 值时，请按所用 shell 的规则加引号，参见上文的 `formats` 示例。
