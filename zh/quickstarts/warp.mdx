通过远程托管的 MCP 服务器将 Firecrawl 连接到 Warp 的本地智能体，然后使用你的 Firecrawl 账户登录。

## 快速配置 {#quick-setup}

1. 在 Warp 中，依次打开 **Settings** → **Agents** → **MCP 服务器**。也可以在命令面板中搜索 **Open MCP Servers**。
2. 点击 **+ Add**，然后粘贴以下配置：

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

3. 启动服务器。Warp 会打开浏览器页面进行 Firecrawl 登录。批准访问后，Warp 会将凭据保存在你的设备上。
4. 确认 `firecrawl` 在 MCP 服务器列表中显示为运行中，然后让智能体执行搜索或抓取。

<Accordion title="想使用基于文件的配置？">
  Warp 还会从 `~/.warp/.mcp.json` 加载适用于所有项目的服务器，或从项目根目录下的 `.warp/.mcp.json` 加载服务器。使用与上文相同的 JSON 即可。项目文件中的服务器需经你批准后才会启动。
</Accordion>

<Accordion title="想使用 API 密钥？">
  Warp 支持为 URL 服务器设置自定义标头。将 URL 设为 `https://mcp.firecrawl.dev/v2/mcp`，并添加 `"headers": { "Authorization": "Bearer fc-YOUR-API-KEY" }`。请参见[配置 API 密钥](/zh/mcp-server/keyless#add-an-api-key)。
</Accordion>

更多详情，请参见 [OAuth 连接指南](/zh/mcp-server/oauth)。

## 故障排除 {#troubleshooting}

* **登录页面无法打开：**&#x5728; MCP 服务器页面重新启动该服务器。
* **登录反复失败：**&#x8FD0;行 `rm -rf ~/.mcp-auth` 清除已存储的 MCP 令牌，然后重新启动服务器。此操作会清除所有 MCP 服务器的令牌。
* **服务器无法启动：**&#x5728;该服务器上选择 **查看日志**，查看错误信息。
* **工具未被调用：**&#x4E0D;同模型调用 MCP 工具的可靠性有所差异。请在智能体选择器中换用其他模型。
