通过远程托管的 MCP 服务器，为 [Amp](https://ampcode.com) 添加 Firecrawl 的免密钥 Search、抓取 和 Parse Tool。

## 快速设置 {#quick-setup}

将以下内容添加到 Amp 设置文件中 (`~/.config/amp/settings.json`；可运行 `amp config edit` 打开) ：

```json
{
  "amp.mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

或者让 CLI 自动帮你写入：

```bash
amp mcp add firecrawl https://mcp.firecrawl.dev/v2/mcp
```

重启 Amp，并确认 `firecrawl_search`、`firecrawl_scrape` 和 `firecrawl_parse` 可用。

免密钥访问的限额由同一公共 IP 的用户共享。请通过交互式客户端使用 [For Humans](/zh/mcp-server/oauth) 登录，或为无人值守使用[添加 API 密钥](/zh/mcp-server/keyless#add-an-api-key)。


## 故障排除 {#troubleshooting}

* **服务器无法连接：**&#x786E;认 URL 是否准确为 `https://mcp.firecrawl.dev/v2/mcp`，并运行 `amp mcp doctor` 检查服务器状态。
* **缺少 Crawl 或其他工具：**&#x514D;密钥模式仅提供 Search、抓取 和 Parse。请通过 OAuth 或 API 密钥连接，以使用更完整的工具集。
