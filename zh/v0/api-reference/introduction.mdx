<div id="base-url">
  ## 基础 URL {#base-url}
</div>

所有请求都使用以下基础 URL：

```bash
https://api.firecrawl.dev 
```

## 身份验证 {#authentication}

进行身份验证时，必须包含 Authorization 请求头，其值应为 `Bearer fc_123456789`，其中 `fc_123456789` 即你的 API 密钥。

```bash
Authorization: Bearer fc_123456789
```

​

## 响应代码 {#response-codes}

Firecrawl 使用标准的 HTTP 状态码来表示请求的结果。

通常，2xx 状态码表示成功，4xx 状态码表示用户侧的错误，5xx 状态码则表示基础设施问题。

| 状态码 | 描述                  |
| --- | ------------------- |
| 200 | 请求成功。               |
| 400 | 请检查参数是否正确。          |
| 401 | 未提供 API 密钥。         |
| 402 | 需要付费                |
| 404 | 未找到请求的资源。           |
| 429 | 已超出限流上限。            |
| 5xx | 表示 Firecrawl 服务器错误。 |

如需了解所有可能的 API 错误的详细说明，请参阅 Error Codes 部分。

<div id="rate-limit">
  ## 速率限制 {#rate-limit}
</div>

Firecrawl API 采用速率限制机制，以确保服务的稳定性与可靠性。该限制适用于所有端点，并根据在特定时间窗口内发起的请求数量进行计算。

当你超出速率限制时，将收到 429 响应码。
