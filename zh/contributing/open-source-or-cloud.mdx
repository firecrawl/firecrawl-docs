当您需要掌控源代码或基础设施时，请选择开源版。当您想在无需运维整套技术栈的情况下开始抓取时，请选择 Firecrawl Cloud。两种方式都提供 Firecrawl 的核心 API；区别在于由谁配置、保护和运行配套服务。

<Note>
  为产品开发运行 Firecrawl 与运维自行托管部署是两项不同的
  任务。修改 Firecrawl 代码时，请使用[本地运行](/zh/contributing/guide)。
  如果您想在自己掌控的基础设施上运行 API，请使用[自行托管
  指南](/zh/contributing/self-host)。
</Note>

<div id="choose-your-firecrawl-deployment">
  ## 选择 Firecrawl 部署方式
</div>

<div id="use-open-source-when">
  ### 适合使用开源版的情况
</div>

* **您需要掌控源代码或基础设施。** 您可以查看代码、选择技术栈的部署位置，并接入自己的服务提供商。
* **您已准备好自行运维。** 您的团队需要负责身份验证、TLS、持久化、监控、容量规划、升级和恢复。
* **您可以有针对性地扩展功能。** 默认技术栈支持核心抓取；基于 LLM 的 formats、高级抓取服务和专用提取流程则需要额外配置。

<div id="use-firecrawl-cloud-when">
  ### 以下情况适合使用 Firecrawl Cloud
</div>

* **您希望以最快、受支持的方式投入生产。** Firecrawl 负责运行基础设施和托管服务。
* **您需要仅 Cloud 提供的产品工具集。** 代理、浏览器、托管 Dashboard、增强型代理路径和企业级控制功能均通过 Cloud 提供。
* **您希望通过一个账户管理使用方式和获取支持。** API 密钥、额度、限制和运营支持均由托管服务统一提供。

**我们的建议：**除非源代码访问权限或基础设施控制权值得额外的运维投入，否则建议从 Firecrawl Cloud 开始。如果选择自行托管，请先验证一次抓取，并仅在用例需要时添加服务。

<div id="compare-the-operating-model">
  ## 对比运营模式
</div>

| 决策项                              | 开源版                      | Firecrawl Cloud   |
| -------------------------------- | ----------------------- | ----------------- |
| 核心 抓取、crawl、map 和 search API | 已包含                     | 已包含并由平台管理         |
| Fetch 和 Playwright 处理            | 包含在默认技术栈中               | 由平台管理             |
| 基于 LLM 的提取和 formats              | 连接 OpenAI 兼容提供商或 Ollama | 提供托管的服务商接入路径      |
| 高级反爬或专用提取服务                      | 单独运行并配置所需服务             | Cloud 产品支持时由平台管理  |
| 代理、浏览器、交互、Dashboard 和企业级控制功能     | 默认技术栈不包含                | 是否包含取决于产品和套餐      |
| 安全性、持久化、可用性和升级                   | 由您负责                    | 由 Firecrawl 负责    |
| 使用方式、限制和计费                       | 您的基础设施和服务商成本            | Firecrawl 套餐和额度模型 |

<div id="start-with-the-path-you-chose">
  ## 从你选择的方式开始
</div>

* **自行托管 Firecrawl：**按照 [Docker Compose 自行托管指南](/zh/contributing/self-host)，从固定版本部署到完成一次已验证的抓取。
* **修改 Firecrawl 代码：**使用[本地运行](/zh/contributing/guide)搭建贡献者开发环境。
* **使用 Firecrawl Cloud：**[创建账户](https://firecrawl.dev)，然后按照[快速入门](/zh/quickstart)操作。

开源版让核心引擎可供审查和定制。Firecrawl Cloud 为这项工作提供资金支持，同时为构建者提供托管方案，以及更多产品和基础设施能力。
