## 概述 {#overview}

Lovable 应用可在构建过程中及已发布的应用中，通过 Firecrawl 在聊天中将网站抓取和爬取为干净的 Markdown 或结构化数据。Firecrawl 可作为应用和聊天连接器使用。

## 快速开始 {#quick-start}

1. 在 Lovable 中打开 **连接器**，然后选择 **Firecrawl**
2. 选择 **由 Lovable 管理**以添加连接 (无需 Firecrawl 账户) ，或选择 **使用你自己的凭据**并提供自己的 Firecrawl API 密钥
3. 将该连接关联到你的项目，然后让 Lovable 使用 Firecrawl 进行抓取或爬取

## 您可以构建的应用 {#what-you-can-build}

| 功能        | 用例                              |
| --------- | ------------------------------- |
| **搜索**    | 进行网页搜索，并获取搜索结果中各页面的内容           |
| **映射**    | 在爬取网站之前，列出站内的所有 URL             |
| **抓取**    | 将 URL 转换为干净的 Markdown 或结构化 JSON |
| **爬取**    | 获取网站中的页面，包括子页面                  |
| **结构化数据** | 借助抓取的 JSON 格式，提取产品详情、表格和元数据等字段  |
