  通过 Composio 工具包将 Firecrawl 连接到代理和应用程序
</Note>

<div id="overview">
  ## 概述
</div>

Composio 将 Firecrawl 以工具包形式提供，让你的代理无需自定义 API 集成即可进行搜索、抓取、爬取、映射和提取。该工具包使用 Firecrawl API 密钥进行身份验证。

<div id="quick-start">
  ## 快速入门
</div>

1. 在 [Composio Dashboard](https://dashboard.composio.dev) 中使用您的 Firecrawl API 密钥连接 Firecrawl
2. 在 [Firecrawl 工具包文档](https://docs.composio.dev/toolkits/firecrawl) 中查看可用工具
3. 在由 Composio 驱动的代理或工作流中调用 Firecrawl 工具

<div id="what-you-can-do">
  ## 可执行的操作
</div>

| 功能       | 使用场景                |
| -------- | ------------------- |
| **搜索**   | 在提取前查找信息来源          |
| **抓取**   | 获取页面内容，供代理作为上下文使用   |
| **批量抓取** | 在一个任务中获取多个 URL      |
| **爬取**   | 收集网站多个页面的数据         |
| **映射**   | 在决定抓取哪些内容前列出网站的 URL |
| **提取**   | 返回结构化字段，而非原始文本      |
