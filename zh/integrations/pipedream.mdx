## 概述 {#overview}

使用 Firecrawl Pipedream 应用，将页面抓取、网站爬取、网页搜索、URL 映射和结构化数据提取作为工作流中的 actions。

## 快速入门 {#quick-start}

1. 打开 [Pipedream 上的 Firecrawl 应用](https://pipedream.com/apps/firecrawl/)
2. 关联您的 Firecrawl API 密钥
3. 将 Firecrawl actions 添加到新的或现有的工作流

## 功能概览 {#what-you-can-do}

| actions               | 使用场景                                                      |
| ---------------- | --------------------------------------------------------- |
| **Scrape Page**  | 在 Webhook 或调度计划触发时抓取页面内容                                  |
| **Crawl URL**    | 启动多页面爬取任务 (通过 **Get Crawl Data** 轮询结果)                    |
| **Search**       | 在执行后续步骤前查找信息来源                                            |
| **Map URL**      | 列出站点上的 URL，可按搜索词过滤                                        |
| **Extract Data** | 从一个或多个 URL 中提取结构化数据 (通过 **Get Extract Status** 检查运行中的任务)  |
