<div id="firecrawl-actions">
  ## Firecrawl Actions
</div>

| 操作                 | 使用场景                       |
| ------------------ | -------------------------- |
| **/Scrape Page**   | 快速采集单个页面的数据                |
| **/Crawl Website** | 抓取整个网站的多个页面                |
| **/Extract Data**  | 使用自定义 schema 进行 AI 驱动的数据提取 |
| **/Search Data**   | 结合搜索和抓取实现研究自动化             |
| **/Map Data**      | SEO 分析和网站结构映射              |

<div id="quick-reference">
  ## 快速参考
</div>

<CardGroup cols={2}>
  <Card title="快速入门" icon="play">
    1. 前往 [firecrawl.dev](https://firecrawl.dev) 注册
    2. 获取 API 密钥
    3. 在 Zapier 中创建 Zap
    4. 使用 API 密钥连接 Firecrawl
    5. 选择工作流并启用
  </Card>

  <Card title="最佳实践" icon="lightbulb">
    * 对单个页面使用 `/Scrape Page` (速度更快)
    * 合理设置执行频率 (每小时/每天/每周)
    * 先在 Firecrawl playground 中测试
    * 为抓取失败添加错误处理
    * 使用筛选条件避免不必要的运行
  </Card>
</CardGroup>

<div id="zapier-vs-n8n">
  ## Zapier 与 n8n
</div>

| 功能        | Zapier      | n8n           |
| --------- | ----------- | ------------- |
| **部署方式**  | 无代码、云端      | 自托管或云端        |
| **定价**    | 按任务计费       | 按执行次数计费       |
| **集成**    | 9,000+ 个应用  | 1,000+ 个应用和服务 |
| **最适用场景** | 快速自动化、非技术用户 | 自定义逻辑、开发者     |
