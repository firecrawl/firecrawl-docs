列出你在过去 24 小时内的近期 API 活动。你可以用它查找任务 ID，然后通过对应的 GET 端点获取结果。

| 端点             | 获取端点                        |
| -------------- | --------------------------- |
| `scrape`       | `GET /v2/scrape/{id}`       |
| `crawl`        | `GET /v2/crawl/{id}`        |
| `batch_scrape` | `GET /v2/batch/scrape/{id}` |
| `agent`        | `GET /v2/agent/{jobId}`     |
