---
title: "搜索 Firecrawl 政府索引"
openapi: "/zh/api-reference/v2-openapi.json GET /search/gov"
---

搜索来自美国联邦、州和地方政府来源的基础法律与监管资料，包括成文法、法规、法典、法院判决及其他政府出版物。结果以标准的 `web` 分组返回，结构与 [`/search`](/zh/api-reference/endpoint/search) 返回的网页结果相同。

同一路径也支持 `POST`，字段相同，以 JSON 请求体传入。包含未知字段的请求将被拒绝，并返回 `400`。

<CodeGroup>
  ```bash cURL
  # 无需 API 密钥即可开始使用；添加 -H "Authorization: Bearer $FIRECRAWL_API_KEY" 可获得更高的限流额度：
  curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
  ```

  ```bash cURL (POST)
  curl -X POST https://api.firecrawl.dev/v2/search/gov \
    -H "Authorization: Bearer $FIRECRAWL_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "query": "food labeling requirements for allergens",
      "k": 10
    }'
  ```
</CodeGroup>

工作流概览请参见[政府索引指南](/zh/features/gov)。
