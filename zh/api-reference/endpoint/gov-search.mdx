title: "搜索政府索引"
openapi: "/zh/api-reference/v2-openapi.json GET /search/gov"
---

搜索来自美国联邦、州和地方政府来源的基础法律与监管资料，包括成文法、法规、法典、法院判决及其他政府出版物。结果以标准的 `web` 分组返回，结构与 [`/search`](/zh/api-reference/endpoint/search) 返回的网页结果相同。

同一路径也支持 `POST`，字段相同，以 JSON 请求体传入。包含未知字段的请求将被拒绝，并返回 `400`。

`query` 为必填项。如已知，请在其中注明司法管辖区、机构或引用编号以及相关日期。`k` 表示返回结果数量，取值范围为 1 到 100，默认值为 10；通用的 `/search` 则使用 `limit`。

返回结果为匹配的摘录，可能包含历史版本、法案文本、指导文件或第三方转载内容。在将其作为现行有效法律引用之前，请核实发布机构、司法管辖区、颁布/生效状态及版本。如果 snippet 提供的信息不足，请查阅匹配结果所对应的原始来源。该索引以美国资料为主；未检索到结果并不代表不存在适用的法律。

## 筛选条件 {#filters}

所有筛选条件均为可选，多个条件之间按 AND 语义组合。

| 字段             | 仅保留满足以下条件的页面                                                                                                                                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `jurisdiction` | 属于某一司法管辖区：`us` 表示联邦，或 `us-` 加上两个字母的州或领地代码，例如 `us-ca` 或 `us-dc`。                                                                                                                                                  |
| `court`        | 被标注为某一法院，以 CourtListener 法院 id 表示，例如 `scotus`、`ca9` 或 `nysd`。                                                                                                                                                    |
| `courtType`    | 来自某一类型的法院：`federal-supreme`、`federal-appellate`、`federal-district`、`federal-bankruptcy`、`federal-special`、`military`、`state-supreme`、`state-appellate`、`state-trial`、`state-special` 或 `state-attorney-general`。 |
| `cites`        | 引用了某一法律或案例，可使用印刷格式的引用 (例如 `42 U.S.C. § 1983` 或 `5 U.S. 137`) ，也可使用引用 id (例如 `us:usc:42:1983`) 。                                                                                                                  |
| `domain`       | 来自某一站点，例如 `irs.gov`。                                                                                                                                                                                             |

筛选条件仅保留已被索引标注的页面，因此使用筛选条件的搜索可能会遗漏相关页面，未返回结果也不代表不存在相关内容。联邦法院和判例法合集的法院标注最为完整。

<CodeGroup>
  ```bash cURL
  # 无需 API 密钥即可开始使用；添加 -H "Authorization: Bearer $FIRECRAWL_API_KEY" 可获得更高的限流额度：
  curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
  ```

  ```bash cURL (POST)
  curl -X POST https://api.firecrawl.dev/v2/search/gov \
    -H "Authorization: Bearer $FIRECRAWL_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "query": "food labeling requirements for allergens",
      "k": 10
    }'
  ```
</CodeGroup>
