title: '解析格式'

列出 [`/parse`](/zh/api-reference/endpoint/parse) 支持的所有文件格式，及其对应的文件扩展名和 MIME 类型。该列表基于 `/parse` 校验上传文件时所用的同一套规则生成，因此你可以在发送文件前先行检查，无需自行维护一份支持类型清单。

每个条目都包含 `kind` 字段，取值为 `document` 或 `image`。图像格式会经过 OCR 处理；若未启用图像 OCR，这些格式会标记为 `available: false`，在启用之前，上传此类格式的文件将被拒绝并返回 `UNSUPPORTED_FILE_TYPE`。

该列表很少变动。响应带有 `Cache-Control: private, max-age=3600` 头，因此可以放心地将其缓存最多一小时。
