  `proxy` 参数已弃用。建议使用默认值 `auto`，由 Firecrawl 自动选择代理。
</Warning>

Firecrawl 提供不同类型的代理服务，帮助你抓取不同复杂程度的网站。设置 `proxy` 参数，以控制请求使用哪种代理策略。

<div id="proxy-types">
  ## 代理类型
</div>

| 类型         | 描述                                      |
| ---------- | --------------------------------------- |
| `basic`    | 适用于大多数网站的标准代理                           |
| `enhanced` | 适用于复杂网站的增强代理                            |
| `auto`     | **推荐。**先尝试 `basic`，失败后再使用 `enhanced` 重试 |

如果未指定代理，Firecrawl 默认使用 `auto`。
