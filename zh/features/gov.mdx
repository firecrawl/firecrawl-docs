Firecrawl Government Index 可搜索美国联邦、州及地方的成文法、法规、法典、法院判决及其他政府出版物，帮助代理找到某个问题背后的法律或监管文本。排序靠前的匹配结果也可能包括历史版本、法案文本、机构指南以及第三方转载内容；匹配到的内容不一定是现行有效的法律。

* 查找规定标签、报告或许可要求的法规
* 阅读合规问题背后的成文法或法典条款
* 定位对某项规则作出解释的法院判决
* 获取政府机构就某一主题发布的出版物

## 选择并核实来源 {#choose-and-verify-sources}

如已知，请注明司法管辖区、机构或引用出处以及相关日期。如果缺少司法管辖区，应先询问用户，再确定适用的规则。如果用户提供了来源 URL，请直接使用 [`scrape`](/zh/features/scrape) 读取，不要重新搜索。

回答有关现行法律的问题前，请核实来源的发布机构、司法管辖区、颁布/生效状态及版本。如果 snippet 不足以确定规则，请阅读匹配结果对应的原始来源。应核查法案的状态和生效日期，而不是根据其标题或摘要推断。请引用具有决定效力的条款及支持性段落，并且只提供有证据支持的页码、条款或生效日期等细节。

该索引以美国资料为主。对于其他司法管辖区或索引未覆盖的内容，请使用通用搜索；没有搜索结果并不代表不存在适用的法律。

## 搜索 Government Index {#search-the-government-index}

发送一个自然语言问题，即可获得来自法律和监管来源、按相关性排序的结果。结果以标准的 `web` 分组返回，每条结果包含 `url`、`title`、`description` 和 `position`，结构与 [`/search`](/zh/features/search) 返回的网页结果相同。

Government Index 搜索完全免费，不消耗任何额度，无论是否启用零数据保留。无需 API 密钥即可上手；添加 API 密钥可获得更宽松的限流。

SDK 示例使用 `firecrawl@4.44.1` 和 `firecrawl-py==4.49.2` 中提供的 Gov 方法。运行需要身份验证的 SDK 示例时，请设置 `FIRECRAWL_API_KEY`；如需发起免密钥请求，请使用 HTTP 示例。如果已安装的客户端中没有该方法，请升级 SDK。在 Python 中，请在已初始化的客户端实例上调用 `gov_search`；仅对类进行反射时，可能无法列出在初始化期间才赋值的方法。

<CodeGroup>
  ```bash cURL
  # 无需 API 密钥即可上手；添加 -H "Authorization: Bearer $FIRECRAWL_API_KEY" 可获得更宽松的限流：
  curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
  ```

  ```bash CLI
  firecrawl gov "food labeling requirements for allergens" --limit 10
  ```

  ```python Python
  import os
  from firecrawl import Firecrawl

  client = Firecrawl(api_key=os.environ["FIRECRAWL_API_KEY"])

  result = client.gov_search("food labeling requirements for allergens", k=10)
  print(result)
  ```

  ```js Node
  import { Firecrawl } from "firecrawl";

  const client = new Firecrawl({
    apiKey: process.env.FIRECRAWL_API_KEY,
  });

  const result = await client.govSearch(
    "food labeling requirements for allergens",
    {
      k: 10,
    },
  );
  console.log(result);
  ```
</CodeGroup>

同一路径也支持 `POST` 请求，以 JSON 请求体传入相同的字段：

```bash cURL
# 无需 API 密钥即可开始使用；如需更高的限流额度，请添加 -H "Authorization: Bearer $FIRECRAWL_API_KEY"：
curl -X POST https://api.firecrawl.dev/v2/search/gov \
  -H "Content-Type: application/json" \
  -d '{
    "query": "food labeling requirements for allergens",
    "k": 10
  }'
```

`query` 为必填项。`k` 用于设置返回结果的数量，取值范围为 1 到 100，默认值为 10。传入未知字段时，请求会被拒绝并返回 `400`。完整的请求和响应 schema 请参见 [Government Index 搜索参考](/zh/api-reference/endpoint/gov-search)。

也可以通过 [`/search`](/zh/features/search#gov-category-search) 并指定 `categories: ["gov"]` 执行相同的搜索，结果位于 `data.web` 中。

<Note>
  托管的 [MCP 服务器](/zh/mcp-server) 通过

</Note>
