Firecrawl Government Index收录了来自美国联邦、州及地方政府来源的原始法律和监管资料，包括成文法、法规、法典、法院判决及其他政府出版物。借助该索引，代理可以直接依据政府来源本身回答法律或合规问题，而无需依赖一般网页。

* 查找规定标签、报告或许可要求的法规
* 阅读合规问题背后的成文法或法典条款
* 定位对某项规则作出解释的法院判决
* 获取政府机构就某一主题发布的出版物

| 任务                  | 端点                                                               |

| 搜索 Government Index | [`GET` 或 `POST /search/gov`](/zh/api-reference/endpoint/gov-search) |

## 搜索 Government Index {#search-the-government-index}

发送一个自然语言问题，即可获得来自法律和监管来源、按相关性排序的结果。结果以标准的 `web` 分组返回，每条结果包含 `url`、`title`、`description` 和 `position`，结构与 [`/search`](/zh/features/search) 返回的网页结果相同。

Government Index 搜索完全免费，不消耗任何额度，无论是否启用零数据保留。无需 API 密钥即可上手；添加 API 密钥可获得更宽松的限流。

<CodeGroup>
  ```bash cURL
  # 无需 API 密钥即可上手；添加 -H "Authorization: Bearer $FIRECRAWL_API_KEY" 可获得更宽松的限流：
  curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
  ```

  ```bash CLI
  firecrawl gov "food labeling requirements for allergens" --limit 10
  ```

  ```python Python
  from firecrawl import Firecrawl

  firecrawl = Firecrawl(
    # 无需 API 密钥即可上手；添加 API 密钥可获得更宽松的限流：
    # api_key="fc-YOUR-API-KEY",
  )

  result = firecrawl.gov_search("food labeling requirements for allergens", k=10)
  print(result)
  ```

  ```js Node
  import { Firecrawl } from "firecrawl";

  const firecrawl = new Firecrawl({
    // 无需 API 密钥即可上手；添加 API 密钥可获得更宽松的限流：
    // apiKey: "fc-YOUR-API-KEY",
  });

  const result = await firecrawl.govSearch(
    "food labeling requirements for allergens",
    {
      k: 10,
    },
  );
  console.log(result);
  ```
</CodeGroup>

同一路径也支持 `POST` 请求，以 JSON 请求体传入相同的字段：

```bash cURL
# 无需 API 密钥即可开始使用；如需更高的限流额度，请添加 -H "Authorization: Bearer $FIRECRAWL_API_KEY"：
curl -X POST https://api.firecrawl.dev/v2/search/gov \
  -H "Content-Type: application/json" \
  -d '{
    "query": "food labeling requirements for allergens",
    "k": 10
  }'
```

`query` 为必填项。`k` 用于设置返回结果的数量，取值范围为 1 到 100，默认值为 10。传入未知字段时，请求会被拒绝并返回 `400`。完整的请求和响应 schema 请参见 [Government Index 搜索参考](/zh/api-reference/endpoint/gov-search)。

也可以通过 [`/search`](/zh/features/search#gov-category-search) 并指定 `categories: ["gov"]` 执行相同的搜索，结果位于 `data.web` 中。

<Note>
  托管的 [MCP 服务器](/zh/mcp-server) 通过
  `firecrawl_gov_search` 提供此索引，[CLI](/zh/sdks/cli#government) 则通过 `firecrawl
        gov` 提供。两者均为只读操作，不会写入任何内容。
</Note>
