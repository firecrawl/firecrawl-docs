Ajoutez à [Google Gemini CLI](https://github.com/google-gemini/gemini-cli) les outils Firecrawl sans clé de recherche, de scraping et de parsing via le serveur MCP hébergé.

<div id="quick-setup">
  ## Configuration rapide
</div>

Ajoutez ceci à `~/.gemini/settings.json` ou à `.gemini/settings.json` dans votre projet :

```json
{
  "mcpServers": {
    "firecrawl": {
      "httpUrl": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Redémarrez Gemini CLI, exécutez `/mcp list` et vérifiez que `firecrawl_search`, `firecrawl_scrape` et `firecrawl_parse` sont disponibles.

L’accès sans clé est soumis à des limites partagées entre les utilisateurs ayant la même adresse IP publique. Connectez-vous depuis un client interactif avec [Pour les humains](/fr/mcp-server/oauth), ou [ajoutez une clé API](/fr/mcp-server/keyless#add-an-api-key) pour une utilisation sans intervention.

<div id="try-it">
  ## Essayez
</div>

```text
Use Firecrawl to search the web for "Gemini context window" and summarize the sources.
```

```text
Scrape https://ai.google.dev/gemini-api/docs and outline the sections.
```

<div id="troubleshooting">
  ## Dépannage
</div>

* **Les outils n’apparaissent pas :** redémarrez Gemini CLI après avoir modifié `settings.json` ; les serveurs MCP sont chargés au démarrage.
* **Crawl ou un autre outil est absent :** le mode sans clé n’expose que recherche, scraping et parsing. Connectez-vous avec OAuth ou une clé API pour accéder à un ensemble d’outils plus étendu.
