Connectez [OpenAI Codex CLI](https://github.com/openai/codex) à Firecrawl via le serveur MCP OAuth hébergé.

<div id="quick-setup">
  ## Configuration rapide
</div>

<div id="1-add-firecrawl">
  ### 1. Ajouter Firecrawl
</div>

```bash
codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth
codex mcp login firecrawl
```

L’URL est une valeur de configuration du client, et non une page à ouvrir directement dans un Browser. Codex ouvre le processus de connexion à Firecrawl, où vous choisissez une Équipe et autorisez la connexion.

<div id="2-start-codex-and-verify">
  ### 2. Démarrez Codex et vérifiez
</div>

```bash
codex
```

Saisissez `/mcp` et confirmez que `firecrawl` est connecté. Si vous avez modifié une connexion Firecrawl existante, démarrez une nouvelle session Codex avant de réessayer.

Essayez :

```text
Search the web for the latest Next.js App Router release notes and summarize the sources.
```

```text
Scrape https://docs.firecrawl.dev and list the top-level sections.
```

<div id="other-connection-modes">
  ## Autres modes de connexion
</div>

* [Essayez MCP sans clé](/fr/mcp-server/keyless#try-keyless) pour la recherche, le scraping et l’analyse, sans compte ni clé.
* [Configurez une clé API](/fr/mcp-server/keyless#add-an-api-key) avec `bearer_token_env_var` pour une utilisation sans intervention. Ne stockez pas le secret dans le chat de l’agent ni dans le contrôle de version.
* [Exécutez MCP localement](/fr/mcp-server/local) uniquement si vous avez besoin d’un processus local ou d’une API Firecrawl auto-hébergée. Le package local nécessite Node.js 22 ou une version ultérieure.

<div id="troubleshooting">
  ## Dépannage
</div>

* **Codex ne détecte pas les outils :** exécutez `codex mcp list`, vérifiez qu’il n’existe qu’une seule entrée `firecrawl`, puis redémarrez Codex.
* **OAuth renvoie `401` :** exécutez `codex mcp login firecrawl` et connectez-vous. Une requête non authentifiée au serveur OAuth doit renvoyer `401` avant l’authentification.
* **Une connexion avec une clé API renvoie `401` :** remplacez la clé dans l’environnement qui lance Codex, puis démarrez une nouvelle session.
