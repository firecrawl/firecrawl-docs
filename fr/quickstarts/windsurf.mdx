Ajoutez à Windsurf les outils de recherche, d’extraction et de parsing sans clé de Firecrawl via le serveur MCP hébergé.

Windsurf s&#39;appelle désormais [Devin Desktop](https://devin.ai/desktop). Son agent Devin Local et l&#39;ancien agent Cascade lisent tous deux les serveurs MCP depuis le même fichier de configuration.

## Configuration rapide {#quick-setup}

Modifiez `~/.config/devin/mcp_config.json` (`%APPDATA%\devin\mcp_config.json` sous Windows) :

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Ou ajoutez-le avec la CLI Devin :

```bash
devin mcp add -s user firecrawl https://mcp.firecrawl.dev/v2/mcp
```

Redémarrez Devin Desktop et vérifiez que `firecrawl_search`, `firecrawl_scrape` et `firecrawl_parse` sont disponibles.

L’accès sans clé est soumis à des limites partagées entre les utilisateurs d’une même adresse IP publique. Connectez-vous depuis un client interactif avec [For Humans](/fr/mcp-server/oauth), ou [ajoutez une clé API](/fr/mcp-server/keyless#add-an-api-key) pour une utilisation sans intervention.

## Dépannage {#troubleshooting}

* **Le serveur ne se connecte pas :** vérifiez l’URL hébergée, puis contrôlez le serveur dans la liste MCP de l’agent ou exécutez `devin mcp list`.
* **Crawl ou un autre outil est absent :** le mode sans clé expose uniquement recherche, extraction et parsing. Connectez-vous avec OAuth ou une clé API pour accéder à un ensemble d’outils plus complet.
