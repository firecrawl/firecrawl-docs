Ajoutez à Windsurf les outils de recherche, de scraping et de parsing sans clé de Firecrawl via le serveur MCP hébergé.

<div id="quick-setup">
  ## Configuration rapide
</div>

Ouvrez **Paramètres → Outils → Paramètres de Windsurf → Ajouter un serveur** ou modifiez `~/.codeium/windsurf/mcp_config.json` :

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Redémarrez Windsurf et vérifiez que `firecrawl_search`, `firecrawl_scrape` et `firecrawl_parse` sont disponibles.

L’accès sans clé est soumis à des limites partagées entre les utilisateurs d’une même adresse IP publique. Connectez-vous depuis un client interactif avec [For Humans](/fr/mcp-server/oauth), ou [ajoutez une clé API](/fr/mcp-server/keyless#add-an-api-key) pour une utilisation sans intervention.

<div id="try-it">
  ## Essayez
</div>

```text
Rechercher les dernières notes de version de Tailwind CSS et résumer les sources.
```

```text
Scraper https://firecrawl.dev et expliquer ce que c'est.
```

<div id="troubleshooting">
  ## Dépannage
</div>

* **Le serveur ne se connecte pas :** vérifiez l’URL hébergée et consultez l’état MCP de Windsurf.
* **Crawl ou un autre outil est absent :** le mode sans clé expose uniquement recherche, scraping et parsing. Connectez-vous avec OAuth ou une clé API pour accéder à un ensemble d’outils plus complet.
