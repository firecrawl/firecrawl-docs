Connectez Firecrawl à Crush en tant que serveur MCP HTTP distant pour permettre à Crush d&#39;effectuer des recherches sur le web et de lire des pages.

## Prérequis {#requirements}

* Crush 0.98 ou version ultérieure.
* Une [clé API Firecrawl](https://www.firecrawl.dev/app/api-keys), exportée dans la variable d&#39;environnement `FIRECRAWL_API_KEY`.

## Configuration rapide {#quick-setup}

1. Exportez votre clé API dans le shell depuis lequel vous lancez Crush :

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

2. Ajoutez le serveur au fichier `crush.json` de votre projet, ou à `~/.config/crush/crush.json` pour l&#39;appliquer à tous vos projets :

```json
{
  "$schema": "https://charm.land/crush.json",
  "mcp": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer $FIRECRAWL_API_KEY"
      }
    }
  }
}
```

3. Démarrez Crush et demandez-lui d&#39;effectuer une recherche ou une extraction.

<Accordion title="Vous utilisez un fichier crushrc ?">
  Les versions récentes de Crush peuvent lire un fichier `crushrc` de style Bash, dans lequel un serveur MCP se déclare en une seule commande :

  ```bash
  mcp add firecrawl \
    --type http \
    --url "https://mcp.firecrawl.dev/v2/mcp" \
    --header Authorization "Bearer $FIRECRAWL_API_KEY"
  ```

  Exécutez `crush dirs` pour savoir où Crush cherche sa configuration sur votre machine.
</Accordion>

Voir [Configurer une clé API](/fr/mcp-server/keyless#add-an-api-key) pour en savoir plus sur les clés.

## Dépannage {#troubleshooting}

* **Le serveur ne démarre pas :** vérifiez que `FIRECRAWL_API_KEY` est bien exportée dans le shell qui lance Crush et que l&#39;URL est exactement `https://mcp.firecrawl.dev/v2/mcp`.
* **L&#39;en-tête est ignoré :** Crush supprime tout en-tête dont la valeur se résout en une string vide. Cela se produit notamment lorsque `FIRECRAWL_API_KEY` n&#39;est pas définie.
* **Les outils ne sont pas utilisés :** certains modèles appellent les outils MCP de manière plus fiable que d&#39;autres. Essayez un autre modèle.
