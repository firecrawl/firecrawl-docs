Connectez Firecrawl à Amazon Q Developer dans VS Code, JetBrains et les autres IDE pris en charge grâce au serveur MCP hébergé. Q Developer ouvre un navigateur pour que vous puissiez vous connecter avec votre compte Firecrawl.

<Note>
  Amazon Q Developer CLI s&#39;appelle désormais Kiro CLI. Pour une utilisation dans le terminal, suivez la [configuration de Kiro](/fr/quickstarts/kiro).
</Note>

## Configuration rapide {#quick-setup}

1. Ouvrez votre IDE, puis le panneau Q Developer, puis le panneau **Chat**.
2. Sélectionnez l’icône des outils, puis le bouton plus (+).
3. Choisissez une portée : **global** enregistre le serveur dans `~/.aws/amazonq/default.json`, tandis que **local** l’enregistre dans le fichier `.amazonq/default.json` du projet.
4. Saisissez `firecrawl` comme nom, choisissez **http** comme transport, puis saisissez l’URL suivante :

```text
https://mcp.firecrawl.dev/v2/mcp-oauth
```

5. Sélectionnez **Save**. Q Developer ouvre une page dans votre navigateur pour vous permettre d&#39;autoriser l&#39;accès. Connectez-vous à Firecrawl et approuvez la connexion.
6. Dans le panneau qui s&#39;affiche après l&#39;enregistrement, vérifiez l&#39;autorisation de chaque outil (**Ask**, **Always allow** ou **Deny**).

<Accordion title="Vous préférez modifier le fichier de configuration ?">
  Q Developer lit également les serveurs MCP définis dans `~/.aws/amazonq/mcp.json` (global) et `.amazonq/mcp.json` (projet) :

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
      }
    }
  }
  ```

  La prise en charge des fichiers `mcp.json` est contrôlée par le champ `useLegacyMcpJson` de `default.json`, défini sur `true` par défaut.
</Accordion>

<Accordion title="Vous préférez une clé API ?">
  Dans la même boîte de dialogue, ajoutez un en-tête nommé `Authorization` avec la valeur `Bearer fc-VOTRE-CLÉ-API` et utilisez `https://mcp.firecrawl.dev/v2/mcp` comme URL. Voir [Configurer une clé API](/fr/mcp-server/keyless#add-an-api-key).
</Accordion>

Pour plus de détails, consultez le [guide de connexion OAuth](/fr/mcp-server/oauth).

## Dépannage {#troubleshooting}

* **Une alerte « Fix Configuration » s&#39;affiche :** sélectionnez-la pour revenir au formulaire et vérifier l&#39;URL.
* **La page du navigateur ne s&#39;ouvre pas :** choisissez **Edit setup** pour le serveur, enregistrez de nouveau, puis terminez l&#39;autorisation lorsque la page s&#39;ouvre.
* **Le serveur apparaît dans la liste, mais ses outils ne s&#39;exécutent pas :** ouvrez le serveur dans le panneau Serveurs MCP et vérifiez qu&#39;il est activé et que ses outils ne sont pas définis sur **Deny**.
* **Deux entrées Firecrawl :** un serveur défini dans `.amazonq/default.json` est prioritaire sur le serveur global. Supprimez le doublon que vous ne souhaitez pas conserver.
