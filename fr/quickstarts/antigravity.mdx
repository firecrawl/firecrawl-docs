Reliez Firecrawl à [Google Antigravity](https://antigravity.google/) via le serveur MCP hébergé, puis connectez-vous avec votre compte Firecrawl.

## Configuration rapide {#quick-setup}

1. Dans Antigravity, cliquez sur **…** en haut du panneau latéral de l&#39;agent, puis sélectionnez **MCP Servers**.
2. Cliquez sur **Manage MCP Servers**, puis sur **View raw config** pour ouvrir `mcp_config.json` (fichier global situé dans `~/.gemini/config/mcp_config.json`, ou `.agents/mcp_config.json` dans votre espace de travail).
3. Ajoutez le serveur Firecrawl et enregistrez :

```json
{
  "mcpServers": {
    "firecrawl": {
      "serverUrl": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

4. Ouvrez les paramètres de l’Agent (`Cmd/Ctrl + ,`), accédez à **Customizations**, puis cliquez sur **Authenticate** à côté de `firecrawl`.
5. Connectez-vous à Firecrawl dans votre navigateur et approuvez une équipe, puis collez le code d’autorisation dans Antigravity et cliquez sur **Submit**.
6. Vérifiez que les outils de Firecrawl, comme `firecrawl_search` et `firecrawl_scrape`, sont bien disponibles.

Antigravity exige la clé `serverUrl` pour les serveurs distants. Les entrées qui utilisent `url` ou `httpUrl` ne sont pas enregistrées. Antigravity CLI lit le même fichier ; saisissez `/mcp` dans la CLI pour vérifier l’état du serveur.

<Accordion title="Vous préférez une clé API ?">
  Pour une utilisation sans intervention, [créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys) et transmettez-la dans un en-tête au lieu de vous connecter. Voir [Ajouter une clé API](/fr/mcp-server/keyless#add-an-api-key) pour plus de détails.

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "serverUrl": "https://mcp.firecrawl.dev/v2/mcp",
        "headers": {
          "Authorization": "Bearer fc-YOUR-API-KEY"
        }
      }
    }
  }
  ```
</Accordion>

Voir le [guide de connexion OAuth](/fr/mcp-server/oauth) pour plus de détails.

## Essayez {#try-it}

```text
Use Firecrawl to search for the latest Vercel AI SDK release notes, scrape the two most relevant results, and summarize what changed with a link to each source.
```

```text
Search with Firecrawl for the official docs of three popular Python HTTP client libraries, scrape each docs homepage, and compare their async support in a table.
```

## Dépannage {#troubleshooting}

* **Le serveur est indiqué en échec :** vérifiez que l&#39;entrée utilise `serverUrl` avec exactement `https://mcp.firecrawl.dev/v2/mcp-oauth`, puis rechargez le serveur depuis **Manage MCP Servers** ou depuis le gestionnaire `/mcp` de la CLI.
* **Une connexion est requise ou a expiré :** cliquez de nouveau sur **Authenticate** à côté de `firecrawl` dans **Customizations**.
* **Une autre connexion Firecrawl existe déjà :** remplacez l&#39;URL du serveur existant par l&#39;URL OAuth, puis connectez-vous afin qu&#39;un seul serveur Firecrawl soit actif.
