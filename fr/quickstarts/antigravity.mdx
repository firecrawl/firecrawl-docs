Ajoutez à [Google Antigravity](https://antigravity.google/) les outils sans clé Search, Scrape et Parse de Firecrawl via le serveur MCP hébergé.

<div id="quick-setup">
  ## Configuration rapide
</div>

Ouvrez les paramètres d’Antigravity (`Cmd/Ctrl + ,`), recherchez **Serveurs MCP** et ajoutez :

```json
{
  "mcpServers": {
    "firecrawl": {
      "serverUrl": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Actualisez la fenêtre et vérifiez que `firecrawl_search`, `firecrawl_scrape` et `firecrawl_parse` sont disponibles.

L’accès sans clé est soumis à des limites partagées entre les utilisateurs d’une même adresse IP publique. Connectez-vous depuis un client interactif avec [For Humans](/fr/mcp-server/oauth), ou [ajoutez une clé API](/fr/mcp-server/keyless#add-an-api-key) pour une utilisation sans intervention.

<div id="try-it">
  ## Essayez
</div>

```text
Use Firecrawl to search for the latest Vercel AI SDK release notes and summarize the sources.
```

```text
Scrape https://docs.firecrawl.dev/ai-onboarding and list the linked guides.
```

<div id="troubleshooting">
  ## Dépannage
</div>

* **Le serveur est signalé comme ayant échoué :** vérifiez l’URL hébergée et consultez le panneau de sortie MCP.
* **Crawl ou un autre outil est absent :** le mode sans clé propose uniquement Search, Scrape et Parse. Connectez-vous via OAuth ou avec une clé API pour accéder à un ensemble d’outils plus complet.
