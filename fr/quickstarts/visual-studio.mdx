Connectez Firecrawl au mode agent de GitHub Copilot dans Visual Studio via le serveur MCP hébergé, puis identifiez-vous avec votre compte Firecrawl.

## Prérequis {#requirements}

* Visual Studio 2022 version 17.14 ou ultérieure, ou Visual Studio 2026.
* Être connecté à GitHub Copilot, avec Copilot Chat en mode **Agent**.

## Configuration rapide {#quick-setup}

1. Créez `%USERPROFILE%\.mcp.json` pour rendre Firecrawl disponible dans toutes vos solutions, ou `<SOLUTIONDIR>\.mcp.json` pour le restreindre à une seule solution et le partager via le contrôle de version.
2. Ajoutez cette configuration, puis enregistrez le fichier :

```json
{
  "servers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

3. Dans le fichier, sélectionnez **Authentication Required** dans le CodeLens au-dessus du serveur, puis finalisez la connexion à Firecrawl dans votre navigateur. Si le CodeLens n&#39;apparaît pas, activez-le dans **Tools**, **Options**, **Text Editor**, **CodeLens**.
4. Dans Copilot Chat, passez en mode **Agent**, ouvrez **Tools** et activez les outils Firecrawl. Visual Studio désactive les nouveaux outils MCP tant que vous ne les avez pas activés.

<Accordion title="Vous préférez ajouter le serveur depuis le chat ?">
  Dans Copilot Chat, passez en mode **Agent**, ouvrez **Tools**, sélectionnez le bouton +, puis **Add custom MCP server**. Saisissez `firecrawl` comme nom et `https://mcp.firecrawl.dev/v2/mcp-oauth` comme URL.
</Accordion>

<Accordion title="Vous préférez un serveur local avec une clé API ?">
  Visual Studio peut aussi exécuter des serveurs locaux. Suivez [Exécuter MCP en local](/fr/mcp-server/local) et définissez la commande dans le même fichier :

  ```json
  {
    "servers": {
      "firecrawl": {
        "command": "npx",
        "args": ["-y", "firecrawl-mcp@3.33.2"],
        "env": {
          "FIRECRAWL_API_KEY": "fc-VOTRE-CLÉ-API"
        }
      }
    }
  }
  ```
</Accordion>

Voir le [guide de connexion OAuth](/fr/mcp-server/oauth) pour plus de détails. Pour une utilisation sans intervention, [configurez une clé API](/fr/mcp-server/keyless#add-an-api-key).

## Dépannage {#troubleshooting}

* **Aucun outil Firecrawl dans le sélecteur :** ouvrez le sélecteur d&#39;outils et activez-les. Visual Studio réinitialise les approbations d&#39;outils chaque fois que la liste des outils d&#39;un serveur change.
* **Une nouvelle connexion est demandée :** dans `.mcp.json`, sélectionnez **Manage Authentication** dans le CodeLens du serveur `firecrawl`.
* **Le fichier est ignoré :** dans les fichiers Visual Studio, la clé de premier niveau est `servers`, et non `mcpServers`.
* **Il existe une autre définition de `firecrawl` :** Visual Studio lit également `.vscode\mcp.json` et `.cursor\mcp.json` dans le dossier de la solution. Ne conservez qu&#39;une seule entrée Firecrawl.
