Claude Desktop, Cowork et l&#39;onglet Code lisent tous les connecteurs de votre compte Claude. Connectez Firecrawl une seule fois, sous le nom de serveur `firecrawl`, et il sera disponible dans tous les onglets.

| Paramètre                      | Valeur                                                                                                                              |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| Nom du serveur                 | `firecrawl`                                                                                                                         |
| URL du connecteur personnalisé | `https://mcp.firecrawl.dev/v2/mcp-oauth` (uniquement si vous ajoutez un connecteur personnalisé plutôt que celui de l&#39;annuaire) |
| Connexion                      | Connexion à Firecrawl dans le navigateur, puis approbation d&#39;une équipe                                                         |

`https://mcp.firecrawl.dev/v2/mcp-oauth` est une valeur de configuration du client, et non une page à ouvrir directement dans un navigateur.

1. Ouvrez le [connecteur Firecrawl](https://claude.ai/directory/connectors/firecrawl) dans l&#39;annuaire des connecteurs de Claude, ou accédez à **Customize &gt; Connecteurs** dans Claude Desktop et recherchez Firecrawl.
2. Cliquez sur **Connect**. Claude ouvre Firecrawl dans votre navigateur.
3. Connectez-vous à Firecrawl, choisissez une équipe et approuvez l&#39;accès.

Avec les offres Team ou Enterprise, il se peut qu&#39;un Owner de l&#39;organisation doive autoriser le connecteur avant que les membres puissent se connecter.

<Accordion title="Impossible d'utiliser le connecteur de l'annuaire ? Ajoutez un connecteur personnalisé">
  1. Dans Claude Desktop, accédez à **Customize &gt; Connecteurs**.
  2. Cliquez sur **Add**, puis ajoutez un connecteur personnalisé.
  3. Saisissez `firecrawl` comme nom et `https://mcp.firecrawl.dev/v2/mcp-oauth` comme URL du serveur MCP distant.
  4. Conservez les paramètres de connexion détectés, ajoutez le connecteur, puis cliquez sur **Connect** et finalisez la connexion dans le navigateur.

  Les Owners de l&#39;organisation, eux, ajoutent les connecteurs personnalisés depuis **Organization settings &gt; Connecteurs**.
</Accordion>

## 2. L&#39;utiliser dans Cowork et dans le chat {#2-use-it-in-cowork-and-chat}

Dans l&#39;onglet Cowork ou Chat, ouvrez le menu **+** à côté de la zone de saisie du prompt, accédez à **Connecteurs** et vérifiez que Firecrawl est activé. Essayez ensuite :

```text
Utilise Firecrawl pour rechercher les dernières notes de release de Next.js, puis résume les sources.
```

```text
Extrais le contenu de https://firecrawl.dev et explique ce que fait ce site.
```

## 3. Utilisez-le dans l&#39;onglet Code {#3-use-it-in-the-code-tab}

Les sessions locales de l&#39;onglet Code peuvent utiliser le même connecteur. Cliquez sur le bouton **+** à côté de la zone de prompt, sélectionnez **Connecteurs**, puis activez Firecrawl.

L&#39;onglet Code charge également les serveurs MCP que vous avez ajoutés à Claude Code, par exemple avec `claude mcp add`. Si vous y avez déjà configuré Firecrawl en suivant le [guide Claude Code](/fr/quickstarts/claude-code), conservez le nom de serveur `firecrawl` et vérifiez qu&#39;un seul serveur Firecrawl est actif dans la session.

## Dépannage {#troubleshooting}

* **Les outils Firecrawl n&#39;apparaissent pas.** Après la connexion, démarrez une nouvelle conversation ou session, puis vérifiez que Firecrawl est activé dans le menu **Connecteurs**.
* **Firecrawl apparaît plusieurs fois.** Supprimez les entrées en double pour ne conserver qu&#39;un seul connecteur nommé `firecrawl`. Les connecteurs ajoutés dans **Customize &gt; Connecteurs** fonctionnent dans Cowork, contrairement aux serveurs locaux définis dans `claude_desktop_config.json` : privilégiez donc le connecteur.
* **Mauvaise équipe.** Consultez ou révoquez la connexion depuis les [Paramètres MCP](https://www.firecrawl.dev/app/settings?tab=mcp), puis reconnectez-vous en choisissant la bonne équipe.
