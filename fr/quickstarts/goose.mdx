Connectez Firecrawl à Goose en tant qu&#39;extension distante pour permettre à Goose d&#39;effectuer des recherches sur le web et de lire des pages via le serveur MCP hébergé.

## Prérequis {#requirements}

* Goose 1.55 ou version ultérieure.
* Une [clé API Firecrawl](https://www.firecrawl.dev/app/api-keys), exportée dans la variable `FIRECRAWL_API_KEY`.

## Configuration rapide {#quick-setup}

1. Exportez votre clé API dans le shell depuis lequel vous démarrez Goose :

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

2. Ajoutez l&#39;extension à la section `extensions` du fichier `~/.config/goose/config.yaml` :

```yaml
extensions:
  firecrawl:
    type: streamable_http
    name: firecrawl
    enabled: true
    uri: https://mcp.firecrawl.dev/v2/mcp
    headers:
      Authorization: "Bearer $FIRECRAWL_API_KEY"
    env_keys:
      - FIRECRAWL_API_KEY
    timeout: 300
```

3. Démarrez une session et demandez à Goose d&#39;effectuer une recherche ou une extraction :

```bash
goose session
```

<Warning>
  Écrivez l&#39;en-tête sous la forme `$FIRECRAWL_API_KEY`, sans accolades, et laissez `env_keys` en place. Avec des accolades, Goose envoie `${FIRECRAWL_API_KEY}` tel quel, sous forme de texte littéral, et le serveur rejette alors la requête.
</Warning>

Voir [Configurer une clé API](/fr/mcp-server/keyless#add-an-api-key) pour en savoir plus sur les clés.

## Dépannage {#troubleshooting}

* **La clé est signalée comme invalide ou révoquée :** vérifiez que l’en-tête utilise `$FIRECRAWL_API_KEY` sans accolades et que `FIRECRAWL_API_KEY` est bien exportée dans le shell depuis lequel vous démarrez Goose.
* **L’extension n’apparaît pas :** relancez `goose session` après avoir enregistré le fichier, puis vérifiez la présence de `enabled: true`.
* **Les appels expirent :** augmentez la valeur de `timeout`. Le scraping d’une page volumineuse peut prendre plus de temps que le délai par défaut.
* **Les outils ne sont pas utilisés :** certains modèles appellent les outils MCP de manière plus fiable que d’autres. Essayez un autre modèle.
