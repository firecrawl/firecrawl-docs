Ajoutez à [Cherry Studio](https://cherry-ai.com) les outils web de Firecrawl, dont la recherche et l&#39;extraction, grâce au serveur MCP hébergé.

Cherry Studio prend en charge les serveurs Streamable HTTP distants avec en-têtes personnalisés : il vous suffit donc de vous connecter avec votre clé API Firecrawl.

## Configuration rapide {#quick-setup}

1. [Créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys).
2. Dans Cherry Studio, ouvrez **Paramètres → MCP → Serveurs MCP** et sélectionnez **Ajouter**.
3. Choisissez **Importer depuis JSON** et collez le contenu suivant, en remplaçant `<FIRECRAWL_API_KEY>` par votre clé :

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "streamableHttp",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

4. Activez le serveur, attendez que son état passe à « healthy », puis ouvrez ses détails et vérifiez que `firecrawl_search` et `firecrawl_scrape` figurent dans la liste.
5. Ouvrez **Work**, modifiez votre Agent, accédez à **MCP** et activez le serveur Firecrawl pour que l’Agent puisse l’utiliser.

Vous pouvez aussi utiliser **Quick Create** et définir le type sur **Streamable HTTP**, l’URL sur `https://mcp.firecrawl.dev/v2/mcp` et l’en-tête `Authorization=Bearer <FIRECRAWL_API_KEY>`.

Pour utiliser plutôt un serveur local, choisissez le type `stdio` avec la commande `npx`, les arguments `-y` et `firecrawl-mcp`, ainsi que la variable d’environnement `FIRECRAWL_API_KEY`. Voir le [guide du serveur MCP local](/fr/mcp-server/local).

Cherry Studio peut également se connecter aux serveurs distants via OAuth lorsqu’aucun en-tête `Authorization` n’est défini. Voir [Pour les humains](/fr/mcp-server/oauth) pour connaître le point de terminaison OAuth de Firecrawl.

## Dépannage {#troubleshooting}

* **Le serveur ne se connecte pas :** vérifiez que le type est Streamable HTTP, que l&#39;URL est exactement `https://mcp.firecrawl.dev/v2/mcp` et que l&#39;en-tête est `Authorization: Bearer <FIRECRAWL_API_KEY>`. Consultez le journal du serveur depuis sa page de détails.
* **Les outils n&#39;apparaissent pas dans une conversation :** un serveur doit être démarré et activé pour l&#39;Agent. Vérifiez **Work → Agent → Edit → MCP**.
* **Un outil est manquant :** ouvrez les détails du serveur pour voir les outils qu&#39;il expose, puis vérifiez que votre clé API est valide.
