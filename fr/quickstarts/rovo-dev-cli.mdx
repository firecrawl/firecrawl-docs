Ajoutez Firecrawl à Rovo Dev CLI via le serveur MCP hébergé. Rovo Dev CLI se connecte aux serveurs distants à l&#39;aide d&#39;en-têtes de requête : cette configuration utilise donc une clé API Firecrawl.

## Prérequis {#requirements}

* Rovo Dev CLI, installé en tant qu&#39;extension de l&#39;Atlassian CLI (`acli`), avec une session ouverte via `acli rovodev auth login`.
* Une [clé API Firecrawl](https://www.firecrawl.dev/app/api-keys).

## Configuration rapide {#quick-setup}

1. Exécutez `acli rovodev mcp` pour ouvrir `~/.rovodev/mcp.json` dans votre éditeur par défaut.
2. Ajoutez Firecrawl, remplacez la clé, puis enregistrez :

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "transport": "http",
      "headers": {
        "Authorization": "Bearer fc-YOUR-API-KEY"
      }
    }
  }
}
```

3. Démarrez Rovo Dev avec `acli rovodev run`, saisissez `/mcp`, puis vérifiez que `firecrawl` apparaît dans la liste avec ses outils.

<Accordion title="Vous préférez un serveur local ?">
  Rovo Dev CLI prend également en charge les serveurs stdio. Suivez le guide [Exécuter MCP en local](/fr/mcp-server/local) et définissez la commande dans le même fichier :

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "command": "npx",
        "args": ["-y", "firecrawl-mcp@3.33.2"],
        "env": {
          "FIRECRAWL_API_KEY": "fc-VOTRE-CLÉ-API"
        },
        "transport": "stdio"
      }
    }
  }
  ```
</Accordion>

Ne partagez pas ce fichier : il contient votre clé. Voir [Configurer une clé API](/fr/mcp-server/keyless#add-an-api-key) pour en savoir plus sur les connexions avec clé.

## Dépannage {#troubleshooting}

* **`/mcp` ne répertorie pas Firecrawl :** vérifiez que le JSON est valide et que `transport` est défini sur `"http"` pour l&#39;URL hébergée.
* **Le serveur renvoie une erreur `401` :** remplacez la clé dans `mcp.json` et redémarrez `acli rovodev run`.
* **Firecrawl est répertorié mais désactivé :** ouvrez `/mcp` pour l&#39;activer, puis vérifiez qu&#39;il ne figure pas sous `disabledMcpServers` dans `~/.rovodev/config.yml`.
* **Vous ne souhaitez pas les instructions du serveur :** définissez `"enable_instructions": false` dans l&#39;entrée Firecrawl.
