Ajoutez Firecrawl à AI Assistant dans IntelliJ IDEA, PyCharm, WebStorm et les autres IDE JetBrains. AI Assistant démarre le serveur MCP Firecrawl sous forme de processus local, en utilisant votre clé API.

## Prérequis {#requirements}

* Un IDE JetBrains avec AI Assistant 2025.1 ou version ultérieure. La prise en charge des clients MCP a été introduite dans cette version.
* Node.js 22 ou version ultérieure dans votre `PATH`, car le serveur s&#39;exécute via `npx`.
* Une [clé API Firecrawl](https://www.firecrawl.dev/app/api-keys).

## Configuration rapide {#quick-setup}

1. Ouvrez **Paramètres**, puis **Tools**, **AI Assistant** et enfin **Model Context Protocol (MCP)**.
2. Sélectionnez **Add**.
3. Collez ce JSON, remplacez la clé et définissez **Server level** sur global ou sur le projet en cours :

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp@3.33.2"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
      }
    }
  }
}
```

4. Sélectionnez **OK**, puis **Apply**. La colonne **Status** affiche la connexion, et son icône d&#39;outil liste les outils Firecrawl.
5. Activez **Automatically enable new and changed MCP servers** si vous souhaitez que le serveur démarre automatiquement.

## Dépannage {#troubleshooting}

* **L&#39;état reste rouge :** exécutez `node --version` dans un terminal et vérifiez que la version affichée est 22 ou supérieure. Redémarrez l&#39;IDE après avoir installé Node.js pour qu&#39;il prenne en compte le nouveau `PATH`.
* **`spawn npx ENOENT` :** l&#39;IDE ne trouve pas `npx`. Démarrez l&#39;IDE depuis un shell où `npx` fonctionne, ou indiquez le chemin complet de `npx` comme commande.
* **Le serveur affiche `401` :** remplacez la valeur de `FIRECRAWL_API_KEY`, puis sélectionnez de nouveau **Apply**.
* **Journaux :** la page des Paramètres MCP fournit un lien vers le dossier des journaux, qui comporte un journal par serveur.
