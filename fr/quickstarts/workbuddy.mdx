Ajoutez les outils Search, extraction, Crawl et Map de Firecrawl à [Tencent WorkBuddy](https://www.workbuddy.ai) grâce au serveur MCP hébergé.

## Configuration rapide {#quick-setup}

[Créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys), puis ajoutez le serveur dans WorkBuddy :

1. Ouvrez **Experts · Compétences · Connecteurs**, accédez à l&#39;onglet **Connecteurs**, puis sélectionnez **Connecteurs personnalisés**.
2. Sélectionnez **Configure MCP** pour ouvrir l&#39;éditeur de configuration MCP.
3. Ajoutez Firecrawl à `mcpServers`, puis enregistrez :

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

Remplacez `<FIRECRAWL_API_KEY>` par votre clé. Si vous avez déjà d&#39;autres serveurs, ajoutez uniquement l&#39;entrée `firecrawl` et conservez le reste.

WorkBuddy enregistre cette configuration dans `~/.workbuddy/mcp.json`. Pour un seul projet, utilisez plutôt `<project>/.workbuddy/mcp.json`.

De retour dans la liste MCP, activez **firecrawl** et approuvez-le si WorkBuddy vous le demande. Un état vert indique que le serveur est connecté et que des outils comme `firecrawl_search` et `firecrawl_scrape` sont disponibles.

WorkBuddy prend également en charge MCP OAuth. Pour vous connecter sans clé, voir [Pour les humains](/fr/mcp-server/oauth).

## Essayer {#try-it}

```text
Recherche sur le Web les dernières annonces de Tencent Cloud et résume les sources.
```

```text
Extrais le contenu de https://firecrawl.dev et explique ce qu’il fait.
```

## Dépannage {#troubleshooting}

* **L&#39;état est rouge :** vérifiez que le JSON est valide et que l&#39;URL correspond exactement à `https://mcp.firecrawl.dev/v2/mcp`.
* **401 Non autorisé :** vérifiez la clé et conservez le préfixe `Bearer ` dans l&#39;en-tête `Authorization`.
* **Les outils n&#39;apparaissent pas :** désactivez puis réactivez le serveur pour que WorkBuddy actualise la liste des outils.
