Intégrez Firecrawl à OpenClaw pour donner à vos agents la capacité d’effectuer de l’extraction, de la recherche, du crawl, d’interagir avec le web et d’exécuter des tâches d’Agent, le tout via la [CLI Firecrawl](/fr/sdks/cli).

## Pourquoi Firecrawl + OpenClaw {#why-firecrawl-openclaw}

* **Aucun navigateur local nécessaire** — chaque session s’exécute dans un bac à sable distant et isolé. Pas d’installation de Chromium, pas de conflits de pilotes, pas de pression mémoire sur votre machine.
* **Véritable parallélisme** — exécutez de nombreuses sessions de navigateur en parallèle sans conflit sur les ressources locales. Les agents peuvent explorer plusieurs sites en parallèle, par lots.
* **Sécurisé par défaut** — la navigation, l’évaluation du DOM et l’extraction se font entièrement dans des bacs à sable jetables, et non sur votre station de travail.
* **Meilleure utilisation des tokens** — les agents reçoivent des artefacts propres (instantanés, champs extraits) au lieu de faire entrer d’énormes DOM et journaux de pilotes dans la fenêtre de contexte.
* **Boîte à outils web complète** — scraping, recherche et automatisation du navigateur, le tout via une seule CLI que votre agent sait déjà utiliser.

## Configuration {#setup}

Demandez à votre agent d’installer le CLI Firecrawl, de s’authentifier, puis d’initialiser la compétence avec cette commande :

```bash
npx -y firecrawl-cli init --browser --all
```

* `--all` ignore la sélection d’agent et initialise chaque agent détecté
* `--browser` ouvre automatiquement le navigateur pour l’authentification Firecrawl

ou installez tout séparément :

```bash
npm install -g firecrawl-cli
firecrawl setup skills
firecrawl login --browser
# Ou, ignorez le navigateur et fournissez votre clé API directement :
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

Assurez-vous que tout est correctement configuré :

```bash
firecrawl --status
```

<Tip>
  Une fois la compétence installée, votre agent OpenClaw découvre et utilise automatiquement les commandes Firecrawl — aucune configuration supplémentaire n’est requise.
</Tip>

## Extraction {#scrape}

Effectuer une extraction d&#39;une seule page et en extraire le contenu :

```bash
firecrawl https://example.com --only-main-content
```

Obtenir des formats spécifiques :

```bash
firecrawl https://example.com --format markdown,links --pretty
```

## Recherche {#search}

Recherchez sur le Web et, si besoin, effectuez une extraction des résultats :

```bash
firecrawl search "latest AI funding rounds" --limit 10

# Rechercher et extraire les résultats
firecrawl search "OpenClaw documentation" --scrape --scrape-formats markdown
```

## Interact {#interact}

Effectuez une extraction du contenu d’une page, puis continuez à l’exploiter dans une session de navigateur en direct. Chaque session s’exécute à distance dans un bac à sable isolé : aucune installation locale de Chromium n’est donc obligatoire. Par défaut, `interact` utilise l’extraction la plus récente.

```bash
firecrawl scrape https://news.ycombinator.com
firecrawl interact "What are the titles of the top 3 stories?"
firecrawl interact "Click the More link at the bottom of the page and list the first 3 story titles"
firecrawl interact stop
```

Exécutez du code sur la page en direct au lieu d&#39;envoyer un prompt :

```bash
firecrawl interact -c "await page.title()"
firecrawl interact -c "print(await page.title())" --python
```

<Note>
  Votre agent envoie des prompts exprimant une intention, ou de courts extraits de code Playwright, au lieu de piloter un navigateur local. Exécutez `firecrawl interact stop` une fois la tâche terminée pour libérer la session. L&#39;ancienne commande `firecrawl browser` est obsolète ; utilisez plutôt `scrape` suivi de `interact`.
</Note>

## Exemple : donner des instructions à votre agent {#example-tell-your-agent}

Voici quelques prompts que vous pouvez donner à votre agent OpenClaw :

* *« Utilise Firecrawl pour effectuer une extraction de https://example.com et résume le contenu principal. »*
* *« Recherche les dernières actualités d’OpenAI et donne-moi un résumé des 5 principaux résultats. »*
* *« Utilise Firecrawl pour ouvrir Hacker News avec interact, récupère les 5 principaux articles et les 10 premiers commentaires de chacun. »*
* *« Effectue un crawl de la documentation sur https://docs.firecrawl.dev et enregistre-la dans un fichier. »*
