Ajoutez le serveur MCP hébergé de Firecrawl à un [portail de serveurs MCP Cloudflare One](https://developers.cloudflare.com/cloudflare-one/access-controls/ai-controls/mcp-portals/) pour que votre équipe accède aux outils de recherche et de scraping de Firecrawl via une URL de portail unique, en appliquant vos politiques Access.

## Configuration rapide {#quick-setup}

[Créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys). Ajoutez ensuite Firecrawl comme serveur MCP dans Cloudflare Access via l&#39;API du portail, en utilisant la clé comme jeton bearer :

```bash
export CLOUDFLARE_ACCOUNT_ID=your-cloudflare-account-id
export CLOUDFLARE_API_TOKEN=your-cloudflare-api-token
export FIRECRAWL_API_KEY=fc-YOUR_API_KEY

curl -X POST "https://api.cloudflare.com/client/v4/accounts/$CLOUDFLARE_ACCOUNT_ID/access/ai-controls/mcp/servers" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Firecrawl",
    "hostname": "https://mcp.firecrawl.dev/v2/mcp",
    "auth_type": "bearer",
    "auth_credentials": "'"$FIRECRAWL_API_KEY"'"
  }'
```

Le portail transmet `auth_credentials` à Firecrawl sous la forme `Authorization: Bearer <key>`. Vous pouvez également ajouter le serveur depuis le tableau de bord Cloudflare, sous **Zero Trust** &gt; **Access controls** &gt; **MCP Portals** &gt; **MCP servers** &gt; **Add MCP server**, en utilisant la même URL.

Ajoutez ensuite le serveur à un portail, associez-lui des politiques Access qui déterminent qui peut le voir, puis choisissez les outils à exposer. Pour créer le portail, consultez le [guide des portails de serveurs MCP](https://developers.cloudflare.com/cloudflare-one/access-controls/ai-controls/mcp-portals/) de Cloudflare.

## Essayer {#try-it}

Connectez un client MCP à l&#39;URL de votre portail (`https://<subdomain>.<domain>/mcp`), puis posez la question suivante :

```text
Recherche sur le Web les dernières notes de version de Cloudflare Workers et résume les sources.
```

```text
Extrais le contenu de https://firecrawl.dev et explique ce que fait ce site.
```

## Dépannage {#troubleshooting}

* **Le serveur affiche une erreur de synchronisation ou d&#39;authentification :** vérifiez que la clé est valide et que `auth_type` vaut `bearer` ; si vous avez renouvelé la clé, mettez à jour les identifiants du serveur.
* **Les outils de Firecrawl n&#39;apparaissent pas dans le portail :** le portail n&#39;expose que les outils qu&#39;un administrateur y a sélectionnés ; vérifiez donc la liste des outils du portail.
* **Les utilisateurs ne voient pas Firecrawl :** le lien vers le serveur n&#39;apparaît que pour les utilisateurs qui correspondent à une politique Allow définie sur le serveur.
