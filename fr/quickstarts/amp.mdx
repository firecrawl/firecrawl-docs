Ajoutez à [Amp](https://ampcode.com), via le serveur MCP hébergé, les outils de recherche, de scrape et de parsing sans clé de Firecrawl.

## Configuration rapide {#quick-setup}

Ajoutez ceci à votre fichier de paramètres d’Amp (`~/.config/amp/settings.json` ; la commande `amp config edit` permet de l’ouvrir) :

```json
{
  "amp.mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Ou laissez la CLI l’écrire pour vous :

```bash
amp mcp add firecrawl https://mcp.firecrawl.dev/v2/mcp
```

Redémarrez Amp et confirmez que `firecrawl_search`, `firecrawl_scrape` et `firecrawl_parse` sont disponibles.

L’accès sans clé est soumis à des limites partagées par les utilisateurs ayant la même adresse IP publique. Connectez-vous depuis un client interactif avec [For Humans](/fr/mcp-server/oauth) ou [ajoutez une clé API](/fr/mcp-server/keyless#add-an-api-key) pour une utilisation sans intervention.

## Essayez-le {#try-it}

```text
Search the web for the latest Amp release notes and summarize the sources.
```

```text
Scrape https://docs.firecrawl.dev and list the core endpoints.
```

## Dépannage {#troubleshooting}

* **Le serveur ne se connecte pas :** assurez-vous que l’URL est exactement `https://mcp.firecrawl.dev/v2/mcp` et exécutez `amp mcp doctor` pour vérifier l’état du serveur.
* **Crawl ou un autre outil est absent :** le mode sans clé donne accès uniquement à recherche, scrape et parsing. Connectez-vous via OAuth ou avec une clé API pour accéder à davantage d’outils.
