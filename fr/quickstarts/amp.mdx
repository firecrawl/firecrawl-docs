Ajoutez à [Sourcegraph Amp](https://ampcode.com), via le serveur MCP hébergé, les outils de recherche, de scrape et de parsing sans clé de Firecrawl.

<div id="quick-setup">
  ## Configuration rapide
</div>

Ouvrez les paramètres d’Amp et ajoutez ce serveur MCP distant :

```json
{
  "amp.mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Rechargez Amp et confirmez que `firecrawl_search`, `firecrawl_scrape` et `firecrawl_parse` sont disponibles.

L’accès sans clé est soumis à des limites partagées par les utilisateurs ayant la même adresse IP publique. Connectez-vous depuis un client interactif avec [For Humans](/fr/mcp-server/oauth) ou [ajoutez une clé API](/fr/mcp-server/keyless#add-an-api-key) pour une utilisation sans intervention.

<div id="try-it">
  ## Essayez-le
</div>

```text
Search the web for "Sourcegraph Cody vs Amp" and summarize the sources.
```

```text
Scrape https://docs.firecrawl.dev and list the core endpoints.
```

<div id="troubleshooting">
  ## Dépannage
</div>

* **Le serveur ne se connecte pas :** vérifiez que l’URL est exactement `https://mcp.firecrawl.dev/v2/mcp` et consultez les journaux MCP d’Amp.
* **Crawl ou un autre outil est absent :** le mode sans clé donne accès uniquement à recherche, scrape et parsing. Connectez-vous via OAuth ou avec une clé API pour accéder à davantage d’outils.
