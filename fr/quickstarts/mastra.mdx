## Prérequis {#prerequisites}

* Node.js 22.13+
* Une clé API Firecrawl — [en obtenir une gratuitement](https://www.firecrawl.dev/app/api-keys)
* Une clé API d’un [fournisseur de modèles Mastra](https://mastra.ai/models) pris en charge
* Un projet Mastra existant — suivez le [démarrage rapide de Mastra](https://mastra.ai/guides/getting-started/quickstart) pour en configurer un

## Installez le SDK {#install-the-sdk}

```bash
npm install firecrawl
```

## Configurez votre clé API {#set-your-api-key}

Ajoutez votre clé API dans `.env` :

```bash
FIRECRAWL_API_KEY=fc-YOUR-API-KEY
```

## Créer les outils Firecrawl {#build-the-firecrawl-tools}

Créez `src/mastra/tools/firecrawl.ts` pour exposer la recherche et le scraping comme outils Mastra :

```typescript
import { Firecrawl } from "firecrawl";
import { createTool } from "@mastra/core/tools";
import { z } from "zod";

const firecrawl = new Firecrawl();

export const firecrawlSearch = createTool({
  id: "firecrawl-search",
  description: "Search the web and return top results.",
  inputSchema: z.object({ query: z.string().min(1) }),
  outputSchema: z.object({
    results: z.array(
      z.object({
        title: z.string().nullable(),
        url: z.string(),
      }),
    ),
  }),
  execute: async ({ query }) => {
    const results = await firecrawl.search(query, { limit: 3 });
    return {
      results: (results.web ?? []).flatMap((item) =>
        "url" in item ? [{ title: item.title ?? null, url: item.url }] : [],
      ),
    };
  },
});

export const firecrawlScrape = createTool({
  id: "firecrawl-scrape",
  description: "Scrape a URL and return markdown content.",
  inputSchema: z.object({ url: z.string().url() }),
  outputSchema: z.object({ markdown: z.string() }),
  execute: async ({ url }) => {
    const result = await firecrawl.scrape(url, {
      formats: ["markdown"],
      onlyMainContent: true,
    });
    return { markdown: result.markdown ?? "" };
  },
});
```

## Créer l’agent {#create-the-agent}

Créez `src/mastra/agents/web-agent.ts` et ajoutez-y les outils Firecrawl :

```typescript
import { Agent } from "@mastra/core/agent";
import { firecrawlSearch, firecrawlScrape } from "../tools/firecrawl";

export const webAgent = new Agent({
  id: "web-agent",
  name: "Web Agent",
  instructions:
    "Use Firecrawl tools to search and scrape web pages, then summarize the results.",
  model: "openai/gpt-5.4",
  tools: { firecrawlSearch, firecrawlScrape },
});
```

## Enregistrer l’agent {#register-the-agent}

Enregistrez l’agent dans votre instance Mastra, dans `src/mastra/index.ts` :

```typescript
import { Mastra } from "@mastra/core";
import { webAgent } from "./agents/web-agent";

export const mastra = new Mastra({
  agents: { webAgent },
});
```

## Tester dans Studio {#test-in-studio}

Lancez le serveur de développement et ouvrez [Mastra Studio](https://mastra.ai/docs/studio/overview) à l’adresse `http://localhost:4111` :

```bash
npm run dev
```

Ouvrez le **Web Agent** et essayez des prompts comme :

* &quot;Trouvez le dernier changelog de Firecrawl et résumez la dernière version.&quot;
* &quot;Recherchez la tarification de Firecrawl et extrayez les différents niveaux d’offre.&quot;

## Fournir un navigateur hébergé à l&#39;agent {#give-the-agent-a-hosted-browser}

Pour les pages qui nécessitent des clics, de la saisie ou du défilement, le package [`@mastra/browser-firecrawl`](https://mastra.ai/integrations/browsers/firecrawl) de Mastra exécute les outils de navigateur de l&#39;agent dans une session de navigateur Firecrawl, ce qui vous évite d&#39;installer Chromium en local.

```bash
npm install @mastra/browser-firecrawl agent-browser@0.19.0
```

<Note>
  Fixez `agent-browser` à la version 0.19.0. Les versions ultérieures ne fournissent que la CLI : l&#39;import de `@mastra/browser-firecrawl` échoue alors avec l&#39;erreur `Cannot find package .../agent-browser/index.js`.
</Note>

Créez `src/mastra/agents/browser-agent.ts`, puis enregistrez `browserAgent` dans votre instance Mastra de la même manière que `webAgent` :

```typescript
import { Agent } from "@mastra/core/agent";
import { FirecrawlBrowser } from "@mastra/browser-firecrawl";

export const browserAgent = new Agent({
  id: "browser-agent",
  name: "Browser Agent",
  instructions:
    "Use the browser tools to open pages, click, and type. Take a snapshot after each action to check the result.",
  model: "openai/gpt-5.4",
  browser: new FirecrawlBrowser({ apiKey: process.env.FIRECRAWL_API_KEY }),
});
```

Chaque fil de conversation dispose par défaut de sa propre session de navigateur. Consultez la [documentation Mastra sur le navigateur Firecrawl](https://mastra.ai/integrations/browsers/firecrawl) pour en savoir plus sur les sessions partagées, les délais d’expiration de session et les profils enregistrés.

## Firecrawl auto-hébergé {#self-hosted-firecrawl}

Si vous exécutez Firecrawl vous-même, ajoutez `FIRECRAWL_API_URL` à `.env`. Le SDK lit cette variable depuis l&#39;environnement : les outils ci-dessus ne nécessitent donc aucune modification :

```bash
FIRECRAWL_API_URL=http://localhost:3002
```
