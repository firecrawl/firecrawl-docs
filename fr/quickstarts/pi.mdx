Ajoutez les outils recherche, extraction, Crawl et Map de Firecrawl à [Pi](https://pi.dev) via le serveur MCP hébergé.

## Configuration rapide {#quick-setup}

[Créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys), puis exportez-la afin que Pi puisse la lire :

```bash
export FIRECRAWL_API_KEY=fc-YOUR_API_KEY
```

Ajoutez le serveur avec la commande MCP intégrée de Pi :

```bash
pi mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp --bearer-token-env-var FIRECRAWL_API_KEY
```

Cette commande ajoute l&#39;entrée dans `~/.pi/agent/mcp.json`. Vous pouvez aussi la coller vous-même, ou la placer dans `.pi/mcp.json` pour la limiter à un seul projet :

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer ${FIRECRAWL_API_KEY}"
      }
    }
  }
}
```

Exécutez `pi mcp list` et vérifiez que `firecrawl` apparaît bien comme connecté, avec ses outils, par exemple `firecrawl_search` et `firecrawl_scrape`. Démarrez ensuite `pi` ; si une session était déjà ouverte, exécutez `/reload`.

Si vous utilisez [pi-mcp-adapter](https://github.com/nicobailon/pi-mcp-adapter), ajoutez la même entrée dans `~/.config/mcp/mcp.json` (ou dans `.mcp.json` au niveau d’un projet), puis exécutez `pi-mcp-adapter doctor` pour vérifier la connexion.

### Exécuter le serveur en local {#run-it-locally-instead}

Pour exécuter le serveur MCP sur votre machine, ajoutez-le en tant que serveur stdio :

```bash
pi mcp add firecrawl --env FIRECRAWL_API_KEY='${FIRECRAWL_API_KEY}' -- npx -y firecrawl-mcp
```

## Essayer {#try-it}

Recherche sur le Web les dernières notes de version de Bun et résume les sources.
```

Extrais le contenu de https://firecrawl.dev et explique ce que fait ce site.
```

## Dépannage {#troubleshooting}

* **Le serveur apparaît en échec :** exécutez `pi mcp list` et vérifiez que `FIRECRAWL_API_KEY` est bien exportée dans le shell à partir duquel vous démarrez Pi.
* **Les outils n&#39;apparaissent pas dans une session ouverte :** exécutez `/reload` après avoir ajouté ou modifié un serveur en dehors de la session.
* **La commande MCP de Pi est introuvable :** mettez Pi à jour vers une version récente, ou utilisez pi-mcp-adapter avec la configuration ci-dessus.
