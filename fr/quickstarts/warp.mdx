Connectez Firecrawl aux agents locaux de Warp via le serveur MCP hébergé, puis connectez-vous avec votre compte Firecrawl.

## Configuration rapide {#quick-setup}

1. Dans Warp, ouvrez **Paramètres**, puis **Agents**, puis **Serveurs MCP**. Vous pouvez aussi rechercher **Open MCP Servers** dans la palette de commandes.
2. Cliquez sur **+ Add** et collez la configuration suivante :

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

3. Démarrez le serveur. Warp ouvre une page dans le navigateur pour vous connecter à Firecrawl. Approuvez l&#39;accès : Warp enregistre alors les identifiants sur votre appareil.
4. Vérifiez que `firecrawl` s&#39;affiche comme en cours d&#39;exécution dans la liste des serveurs MCP, puis demandez à un agent d&#39;effectuer une recherche ou une extraction.

<Accordion title="Vous préférez une configuration par fichier ?">
  Warp charge également les serveurs depuis `~/.warp/.mcp.json` pour tous les projets, ou depuis `.warp/.mcp.json` à la racine d&#39;un projet. Utilisez le même JSON que ci-dessus. Les serveurs définis dans le fichier du projet doivent être approuvés par vous avant de démarrer.
</Accordion>

<Accordion title="Vous préférez une clé API ?">
  Warp prend en charge les en-têtes personnalisés pour les serveurs définis par URL. Utilisez `https://mcp.firecrawl.dev/v2/mcp` comme URL et ajoutez `"headers": { "Authorization": "Bearer fc-VOTRE-CLÉ-API" }`. Voir [Configurer une clé API](/fr/mcp-server/keyless#add-an-api-key).
</Accordion>

Voir le [guide de connexion OAuth](/fr/mcp-server/oauth) pour plus de détails.

## Dépannage {#troubleshooting}

* **La page de connexion ne s&#39;ouvre pas :** redémarrez le serveur depuis la page des serveurs MCP.
* **La connexion échoue systématiquement :** exécutez `rm -rf ~/.mcp-auth` pour effacer les tokens MCP enregistrés, puis redémarrez le serveur. Attention : cette commande supprime les tokens de tous les serveurs MCP.
* **Le serveur ne démarre pas :** sélectionnez **Afficher le journal** sur le serveur pour consulter l&#39;erreur.
* **Les outils ne sont pas utilisés :** certains modèles appellent les outils MCP de manière plus fiable que d&#39;autres. Essayez un autre modèle dans le sélecteur d&#39;agent.
