Ajoutez les outils recherche, extraction et d&#39;autres outils web de Firecrawl à [Kimi Code CLI](https://www.kimi.com/code/docs/en/kimi-code-cli/getting-started.html) grâce au serveur MCP hébergé.

## Configuration rapide {#quick-setup}

[Créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys), puis ajoutez ce qui suit à `~/.kimi-code/mcp.json` (ou à `.kimi-code/mcp.json` dans un projet) :

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

Pour ne pas inscrire la clé en dur dans le fichier, exportez-la et faites référence à la variable au lieu de `headers` :

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "bearerTokenEnvVar": "FIRECRAWL_API_KEY"
    }
  }
}
```

Vous pouvez également ajouter le serveur de manière interactive avec `/mcp-config`. Démarrez une nouvelle session Kimi Code, exécutez `/mcp`, puis vérifiez que `firecrawl` est bien connecté et que ses outils, comme `firecrawl_search` et `firecrawl_scrape`, apparaissent dans la liste.

Pour vous connecter via votre navigateur plutôt qu&#39;avec une clé API, utilisez `https://mcp.firecrawl.dev/v2/mcp-oauth` comme URL, sans `headers`, puis exécutez `/mcp-config login firecrawl`. Voir [Pour les humains](/fr/mcp-server/oauth).

## Dépannage {#troubleshooting}

* **Les outils n&#39;apparaissent pas :** les serveurs MCP sont chargés au démarrage d&#39;une session ; ouvrez donc une nouvelle session après avoir modifié `mcp.json`. Un serveur ajouté en cours de session ne sera disponible que dans les sessions suivantes.
* **Le serveur ne se connecte pas :** exécutez `/mcp` pour afficher l&#39;état, puis vérifiez l&#39;URL et la validité de la clé API. Avec `bearerTokenEnvVar`, la variable doit être définie dans le shell qui lance `kimi`.
* **La configuration au niveau du projet est ignorée :** dans les dossiers non approuvés, les serveurs définis dans le fichier `.kimi-code/mcp.json` du projet restent désactivés. Approuvez le dossier, ou définissez `KIMI_CODE_TRUST_WORKSPACE=1` pour les exécutions en mode headless.
* **Vous préférez un serveur local :** Kimi Code peut aussi exécuter `npx -y firecrawl-mcp` avec `FIRECRAWL_API_KEY` dans `env`. Voir [Exécuter en local](/fr/mcp-server/local).
