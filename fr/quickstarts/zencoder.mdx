Ajoutez Firecrawl à Zencoder dans les IDE JetBrains et dans VS Code. JetBrains prend en charge les serveurs distants avec OAuth2 : vous vous connectez donc avec votre compte Firecrawl. VS Code, lui, démarre le serveur en local à l&#39;aide d&#39;une clé API.

## Prérequis {#requirements}

* Le plugin Zencoder pour un IDE JetBrains ou pour VS Code.
* Pour la configuration sous VS Code : Node.js 22 ou version ultérieure, ainsi qu&#39;une [clé API Firecrawl](https://www.firecrawl.dev/app/api-keys).

## Configuration rapide {#quick-setup}

<Tabs>
  <Tab title="JetBrains">
    1. Ouvrez **Paramètres**, puis **Tools**, puis **Zencoder**, puis **Serveurs MCP**.
    2. Ajoutez ce serveur et appliquez la modification :

    ```json
    {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth",
        "auth": "oauth2"
      }
    }
    ```

    3. Finalisez la connexion à Firecrawl dans votre navigateur, puis vérifiez que les outils figurent dans la liste des outils de l’agent.
  </Tab>

  <Tab title="VS Code">
    1. Ouvrez le fichier `settings.json` de votre utilisateur ou de votre espace de travail.
    2. Ajoutez Firecrawl sous `zencoder.mcpServers` :

    ```json
    {
      "zencoder.mcpServers": {
        "firecrawl": {
          "command": "npx",
          "args": ["-y", "firecrawl-mcp@3.33.2"],
          "env": {
            "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
          }
        }
      }
    }
    ```

    3. Redémarrez VS Code, puis vérifiez que les outils Firecrawl apparaissent sous **Outils d’agent**.
  </Tab>
</Tabs>

D’après la documentation de Zencoder, la prise en charge des serveurs HTTP et OAuth2 dans VS Code est en cours de déploiement : utilisez donc la configuration locale tant que votre version ne la propose pas. Pour plus de détails, consultez le [guide de connexion OAuth](/fr/mcp-server/oauth) et la page [Exécuter MCP en local](/fr/mcp-server/local).

## Dépannage {#troubleshooting}

* **Le serveur n’apparaît pas dans les outils d’agent :** vérifiez la syntaxe JSON, puis redémarrez l’IDE. Les serveurs MCP sont chargés au démarrage.
* **La connexion JetBrains échoue :** supprimez le jeton mis en cache pour le serveur, puis relancez la connexion.
* **VS Code signale une commande introuvable :** vérifiez que `npx` fonctionne dans un terminal et que `node --version` affiche la version 22 ou supérieure.
* **Les outils ne s’exécutent pas :** Zencoder demande une autorisation avant chaque appel d’outil. Choisissez **Allow once** ou **Always allow** pour les outils Firecrawl.
