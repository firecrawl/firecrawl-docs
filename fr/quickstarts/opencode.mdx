Ajoutez à [OpenCode](https://opencode.ai), via le serveur MCP hébergé, les outils de recherche, de scraping et de parsing sans clé de Firecrawl.

<div id="quick-setup">
  ## Configuration rapide
</div>

Ajoutez ce qui suit à `~/.config/opencode/opencode.json` ou au fichier `opencode.json` de votre projet :

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "firecrawl": {
      "type": "remote",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "enabled": true
    }
  }
}
```

Redémarrez OpenCode, saisissez `/mcp`, puis vérifiez que `firecrawl_search`, `firecrawl_scrape` et `firecrawl_parse` sont disponibles.

L&#39;accès sans clé est soumis à des limites partagées entre les utilisateurs d&#39;une même adresse IP publique. Connectez-vous depuis un client interactif avec [For Humans](/fr/mcp-server/oauth), ou [ajoutez une clé API](/fr/mcp-server/keyless#add-an-api-key) pour une utilisation sans intervention.

<div id="try-it">
  ## Essayez
</div>

```text
recherche the web for the latest Bun release notes and summarize the sources.
```

```text
scraping https://docs.firecrawl.dev/introduction and list the code examples.
```

<div id="troubleshooting">
  ## Dépannage
</div>

* **Le serveur ne se connecte pas :** exécutez `opencode doctor` et vérifiez l’URL distante.
* **Crawl ou un autre outil est manquant :** le mode sans clé n’expose que recherche, scraping et parsing. Connectez-vous via OAuth ou avec une clé API pour accéder à davantage d’outils.
