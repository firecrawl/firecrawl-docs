Connectez Firecrawl à Qwen Code en tant que serveur MCP HTTP distant pour permettre à Qwen Code d&#39;effectuer des recherches sur le web et de lire des pages.

## Prérequis {#requirements}

* Qwen Code 0.25 ou version ultérieure.
* Une [clé API Firecrawl](https://www.firecrawl.dev/app/api-keys), exportée dans la variable `FIRECRAWL_API_KEY`.

## Configuration rapide {#quick-setup}

1. Exportez votre clé API dans le shell depuis lequel vous démarrez Qwen Code :

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

2. Ajoutez le serveur. Les guillemets simples empêchent le shell de développer la variable : le fichier de paramètres enregistre ainsi la référence et non votre clé :

```bash
qwen mcp add --scope user --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp \
  --header 'Authorization: Bearer $FIRECRAWL_API_KEY'
```

3. Vérifiez que le serveur se connecte correctement :

```bash
qwen mcp list
```

4. Démarrez Qwen Code, exécutez `/mcp` pour afficher les outils Firecrawl, puis demandez-lui d&#39;effectuer une recherche ou une extraction.

<Accordion title="Vous préférez modifier le fichier de paramètres ?">
  Ajoutez le serveur à `~/.qwen/settings.json`, ou à `.qwen/settings.json` dans un projet :

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "httpUrl": "https://mcp.firecrawl.dev/v2/mcp",
        "headers": {
          "Authorization": "Bearer $FIRECRAWL_API_KEY"
        }
      }
    }
  }
  ```
</Accordion>

Voir [Configurer une clé API](/fr/mcp-server/keyless#add-an-api-key) pour en savoir plus sur les clés.

## Dépannage {#troubleshooting}

* **Le serveur n’apparaît pas dans une session en cours :** après l’avoir ajouté, redémarrez Qwen Code dans le même projet.
* **Le serveur apparaît comme non connecté :** exécutez `qwen mcp list`, puis vérifiez que `FIRECRAWL_API_KEY` est bien exportée dans le shell depuis lequel vous démarrez Qwen Code.
* **Les appels d’outils sont rejetés en raison d’une clé invalide :** vérifiez que la valeur de l’en-tête est `Bearer $FIRECRAWL_API_KEY` et que la variable contient une clé valide.
* **Les outils ne sont pas utilisés :** certains modèles appellent les outils MCP de manière plus fiable que d’autres. Essayez un autre modèle.
