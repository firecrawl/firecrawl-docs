Connectez [MCPorter](https://mcporter.sh), un environnement d’exécution et une CLI en TypeScript pour les serveurs MCP, à Firecrawl via le serveur MCP hébergé.

## Configuration rapide {#quick-setup}

[Créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys) et exportez-la :

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

Ajoutez Firecrawl au fichier `config/mcporter.json` de votre projet, ou au fichier `~/.mcporter/mcporter.json` pour l&#39;utiliser partout :

```json
{
  "mcpServers": {
    "firecrawl": {
      "baseUrl": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": { "Authorization": "Bearer ${FIRECRAWL_API_KEY}" }
    }
  }
}
```

MCPorter substitue à `${FIRECRAWL_API_KEY}` la valeur définie dans votre environnement : la clé n&#39;apparaît donc pas dans le fichier. Vérifiez la connexion :

```bash
npx mcporter list firecrawl
```

Vous préférez un processus local ? Utilisez plutôt la variante stdio :

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": { "FIRECRAWL_API_KEY": "${FIRECRAWL_API_KEY}" }
    }
  }
}
```

## Essayer {#try-it}

```bash
npx mcporter call firecrawl.firecrawl_scrape url=https://firecrawl.dev 'formats=["markdown"]'
```

La commande affiche la page au format markdown. Pour utiliser la même entrée depuis votre code, passez par `createRuntime` (voir la [documentation MCPorter](https://mcporter.sh)).

## Dépannage {#troubleshooting}

* **Serveur introuvable :** exécutez `npx mcporter config list` pour voir quel fichier de configuration MCPorter a chargé ; `--config <file>` ou `MCPORTER_CONFIG` ne permet de sélectionner qu&#39;un seul fichier.
* **Erreurs d&#39;authentification :** MCPorter refuse la syntaxe `${env:VAR}` ; écrivez l&#39;espace réservé sous la forme `${FIRECRAWL_API_KEY}` et vérifiez que la variable est bien exportée dans le même shell.
* **Arguments de l&#39;outil rejetés :** passez les valeurs JSON entre guillemets, en respectant la syntaxe de votre shell, comme dans l&#39;exemple `formats` ci-dessus.
