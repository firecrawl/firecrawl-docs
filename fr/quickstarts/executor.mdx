Ajoutez le serveur MCP hébergé de Firecrawl à [Executor](https://executor.sh) pour que tous les agents connectés à Executor puissent effectuer des recherches sur le web et en extraire des données via un point de terminaison unique.

<Note>
  Ces étapes s&#39;appliquent à Executor 1.x (`npm install -g executor`). Executor 2 (bêta) organise les serveurs MCP en applications et en comptes ; pour cette procédure, consultez la [documentation d&#39;Executor](https://executor.sh/docs).
</Note>

## Configuration rapide {#quick-setup}

[Créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys), puis démarrez Executor :

```bash
npm install -g executor
executor web
```

Dans l&#39;interface web, ajoutez une intégration et choisissez **Firecrawl** dans le catalogue, ou saisissez vous-même l&#39;URL MCP :

```text
https://mcp.firecrawl.dev/v2/mcp
```

Executor détecte le serveur MCP et indexe ses outils. Lorsqu&#39;il vous demande vos identifiants, saisissez votre clé API Firecrawl afin que les requêtes incluent un en-tête `Authorization: Bearer <key>`.

Vous pouvez d&#39;abord vérifier le serveur en ligne de commande :

```bash
executor call executor mcp probeEndpoint '{"endpoint":"https://mcp.firecrawl.dev/v2/mcp","headers":{"Authorization":"Bearer '"$FIRECRAWL_API_KEY"'"}}'
```

Connectez ensuite votre agent au point de terminaison MCP d&#39;Executor lui-même (`http://127.0.0.1:4788/mcp` pour un serveur local) :

```bash
npx add-mcp http://127.0.0.1:4788/mcp --transport http --name executor
```

Exécutez `executor tools integrations` et vérifiez que `firecrawl` apparaît dans la liste avec un nombre d&#39;outils supérieur à zéro.

## Dépannage {#troubleshooting}

* **Le nombre d’outils est de 0 :** Executor crée les outils compte par compte. Terminez donc la connexion du compte Firecrawl avec votre clé API, puis actualisez la source.
* **La commande d’ajout de serveur reste en pause :** Executor vous demande d’approuver l’ajout d’un serveur MCP ; validez-le avec `executor resume --execution-id <id> --action accept --content '{}'`.
* **Votre agent ne voit pas les outils :** la plupart des clients chargent les serveurs MCP au démarrage. Après avoir ajouté Executor, redémarrez donc le client ou ouvrez une nouvelle session.
