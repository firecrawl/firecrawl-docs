Connectez le client MCP du [Vercel AI SDK](https://ai-sdk.dev) au serveur MCP hébergé de Firecrawl et utilisez les outils de Firecrawl dans `generateText` et `streamText`.

<Note>
  Vous cherchez les outils Firecrawl sous forme d’outils AI SDK plutôt que via une connexion MCP ? Consultez le [guide Vercel AI SDK](/fr/developer-guides/llm-sdks-and-frameworks/vercel-ai-sdk).
</Note>

## Configuration rapide {#quick-setup}

[Créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys), puis installez l&#39;AI SDK et son package MCP :

```bash
npm install ai @ai-sdk/mcp
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

Créez le client avec le transport HTTP, en plaçant votre clé dans l&#39;en-tête `Authorization` :

```typescript
import { createMCPClient } from '@ai-sdk/mcp';

const mcpClient = await createMCPClient({
  transport: {
    type: 'http',
    url: 'https://mcp.firecrawl.dev/v2/mcp',
    headers: { Authorization: `Bearer ${process.env.FIRECRAWL_API_KEY}` },
  },
});

const tools = await mcpClient.tools();
console.log(Object.keys(tools));
```

La liste comprend `firecrawl_scrape`, `firecrawl_search`, `firecrawl_map` et `firecrawl_crawl`. Passez `tools` à `generateText` ou `streamText` comme indiqué dans le [guide MCP de l&#39;AI SDK](https://ai-sdk.dev/docs/ai-sdk-core/mcp-tools), puis fermez le client avec `await mcpClient.close()` une fois la réponse terminée.

Vous préférez un processus local ? Utilisez le transport stdio de l&#39;AI SDK avec `npx -y firecrawl-mcp` et `FIRECRAWL_API_KEY` dans `env` ; l&#39;AI SDK recommande toutefois HTTP en production.

## Essayez {#try-it}

Appelez directement un outil pour vérifier la connexion :

```typescript
const result = await tools.firecrawl_scrape.execute(
  { url: 'https://firecrawl.dev', formats: ['markdown'], onlyMainContent: true },
  { toolCallId: 'test', messages: [] },
);
console.log(result.content[0].text.slice(0, 300));
await mcpClient.close();
```

Fournissez ensuite les outils à un modèle avec un prompt comme celui-ci :

```text
Recherche sur le Web les dernières notes de version de Next.js et résume les sources.
```

## Dépannage {#troubleshooting}

* **Erreurs d&#39;authentification :** vérifiez que `FIRECRAWL_API_KEY` est bien défini dans le processus qui exécute le client et que l&#39;en-tête a la forme `Bearer <key>`.
* **Erreurs de redirection :** par défaut, le client AI SDK refuse les redirections ; utilisez l&#39;URL exacte `https://mcp.firecrawl.dev/v2/mcp`.
* **Handles restés ouverts à la fin d&#39;un script :** appelez `mcpClient.close()` une fois que vous n&#39;avez plus besoin des outils.
