Connectez Firecrawl à Cursor via le serveur MCP hébergé, puis effectuez une connexion avec votre compte Firecrawl.

<CursorInstallButton />

## Configuration rapide {#quick-setup}

1. Cliquez sur **Add to Cursor** ci-dessus pour ouvrir la boîte de dialogue d&#39;installation dans Cursor.
2. Confirmez l&#39;installation du serveur MCP Firecrawl.
3. Dans Cursor, utilisez l&#39;option de connexion du serveur pour associer votre compte Firecrawl et autoriser l&#39;accès.
4. Vérifiez que les outils Firecrawl sont bien disponibles dans Cursor.

<Accordion title="Vous préférez ajouter la configuration manuellement ?">
  Ouvrez les paramètres de Cursor, sélectionnez **MCP**, puis ajoutez :

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
      }
    }
  }
  ```

  Enregistrez la configuration, puis finalisez la connexion dans le navigateur depuis Cursor.
</Accordion>

Pour en savoir plus, consultez le [guide de connexion OAuth](/fr/mcp-server/oauth). Pour une utilisation sans intervention, [configurez une clé API](/fr/mcp-server/keyless#add-an-api-key).

## Dépannage {#troubleshooting}

* **Le serveur ne se connecte pas :** vérifiez que l’URL est exactement `https://mcp.firecrawl.dev/v2/mcp-oauth` et consultez l’état MCP dans Cursor.
* **Une connexion est requise ou a expiré :** relancez l’authentification depuis les paramètres MCP de Cursor.
* **Une autre connexion Firecrawl existe déjà :** remplacez l’URL du serveur existant par l’URL OAuth, puis effectuez une connexion afin qu’un seul serveur Firecrawl soit actif.
