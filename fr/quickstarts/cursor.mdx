Ajoutez les outils sans clé recherche, Scrape et Parse de Firecrawl à Cursor via le serveur MCP hébergé.

<div id="quick-setup">
  ## Configuration rapide
</div>

Ouvrez les paramètres de Cursor, sélectionnez **MCP**, puis ajoutez :

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Redémarrez Cursor et vérifiez que `firecrawl_search`, `firecrawl_scrape` et `firecrawl_parse` sont disponibles.

L’accès sans clé est soumis à des limites partagées entre les utilisateurs ayant la même adresse IP publique. Connectez-vous depuis un client interactif via [Pour les humains](/fr/mcp-server/oauth), ou [ajoutez une clé API](/fr/mcp-server/keyless#add-an-api-key) pour une utilisation sans intervention.

<div id="try-it">
  ## Essayez
</div>

```text
Recherche les notes de la dernière release de TypeScript et résume les sources.
```

```text
Scrape https://firecrawl.dev et explique ce que fait ce site.
```

<div id="troubleshooting">
  ## Dépannage
</div>

* **Le serveur ne se connecte pas :** vérifiez que l’URL est exactement `https://mcp.firecrawl.dev/v2/mcp` et consultez l’état MCP dans Cursor.
* **Crawl ou un autre outil est indisponible :** le mode sans clé donne accès uniquement à recherche, Scrape et Parse. Connectez-vous via OAuth ou avec une clé API pour accéder à davantage d’outils.
