description: "Ajoutez le scraping et la recherche web à Claude Code en 2 minutes"
---

Connectez Claude Code à Firecrawl via le serveur MCP hébergé. OAuth est la configuration interactive recommandée, car la clé n&#39;apparaît jamais dans la ligne de commande, les fichiers du projet ou la conversation.

<div id="quick-setup">
  ## Configuration rapide
</div>

<div id="1-add-firecrawl">
  ### 1. Ajouter Firecrawl
</div>

Exécutez :

```bash
claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

`https://mcp.firecrawl.dev/v2/mcp-oauth` est une valeur de configuration côté client, et non une page à ouvrir directement dans un Browser.

<div id="2-sign-in-and-verify">
  ### 2. Connectez-vous et vérifiez
</div>

Saisissez `/mcp` dans Claude Code, choisissez `firecrawl`, puis connectez-vous dans le Browser. Démarrez une nouvelle session Claude Code si vous avez modifié une connexion Firecrawl existante.

Vérifiez qu’un seul serveur `firecrawl` est actif, puis essayez :

```text
Recherche les dernières notes de release de Next.js et résume les sources.
```

```text
Scrape https://firecrawl.dev et explique ce que fait ce site.
```

<div id="other-connection-modes">
  ## Autres modes de connexion
</div>

* [Essayez MCP sans clé](/fr/mcp-server/keyless#try-keyless) pour effectuer des recherches, scraper et parser, sans compte ni clé.
* [Configurez une clé API](/fr/mcp-server/keyless#add-an-api-key) pour une utilisation sans intervention. Gardez le secret en dehors du chat de l’agent et utilisez une référence à une variable d’environnement.
* [Exécutez MCP localement](/fr/mcp-server/local) uniquement si vous avez besoin d’un processus local ou d’une API Firecrawl auto-hébergée. Le package local nécessite Node.js 22 ou une version ultérieure.

<div id="troubleshooting">
  ## Résolution des problèmes
</div>

* **Un serveur Firecrawl existe déjà :** exécutez `claude mcp remove firecrawl`, ajoutez la connexion souhaitée une seule fois, puis démarrez une nouvelle session.
* **Le Browser ne s&#39;ouvre pas :** saisissez `/mcp`, sélectionnez `firecrawl` et lancez l&#39;authentification depuis le client.
* **Le serveur renvoie `401` :** reconnectez-vous via `/mcp` ; ne collez pas de clé API dans la conversation ni dans l&#39;URL OAuth.
