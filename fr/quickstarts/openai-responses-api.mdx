Connectez les modèles OpenAI à Firecrawl en ajoutant le serveur MCP hébergé en tant qu&#39;outil `mcp` distant dans l&#39;API Responses. OpenAI récupère la liste des outils Firecrawl, que le modèle appelle ensuite pour effectuer des recherches sur le web et lire des pages.

<Note>
  D&#39;après la documentation d&#39;OpenAI, l&#39;arrêt d&#39;Agent Builder est prévu pour le 30 novembre 2026. L&#39;outil MCP distant présenté sur cette page ne dépend pas d&#39;Agent Builder.
</Note>

## Prérequis {#requirements}

* Une clé API OpenAI dans `OPENAI_API_KEY` et le package Python `openai`.
* Une [clé API Firecrawl](https://www.firecrawl.dev/app/api-keys) dans `FIRECRAWL_API_KEY`.

## Configuration rapide {#quick-setup}

Ajoutez le serveur Firecrawl à la liste `tools`. Le champ `authorization` contient votre clé API Firecrawl, tandis que `allowed_tools` restreint les outils que le modèle peut appeler :

```python
import os
from openai import OpenAI

client = OpenAI()

response = client.responses.create(
    model="gpt-6-astra",
    tools=[
        {
            "type": "mcp",
            "server_label": "firecrawl",
            "server_description": "Search the web and read pages as Markdown.",
            "server_url": "https://mcp.firecrawl.dev/v2/mcp",
            "authorization": os.environ["FIRECRAWL_API_KEY"],
            "allowed_tools": ["firecrawl_search", "firecrawl_scrape"],
            "require_approval": "never",
        }
    ],
    input="Search the web for the latest Next.js release notes and summarize the sources.",
)

print(response.output_text)
```

OpenAI ne conserve pas la valeur `authorization` : vous devez donc l’envoyer à chaque requête. Définissez `require_approval` sur `"always"` si vous souhaitez vérifier chaque appel d’outil avant que les données ne soient envoyées au serveur.

Voir [Configurer une clé API](/fr/mcp-server/keyless#add-an-api-key) pour en savoir plus sur les connexions par clé. Avec cette configuration, votre code n’effectue aucun appel direct à l’API Firecrawl, car OpenAI se connecte au serveur MCP à votre place.

## Dépannage {#troubleshooting}

* **La requête échoue lors de la récupération de la liste des outils :** vérifiez que `server_url` vaut exactement `https://mcp.firecrawl.dev/v2/mcp` et que `FIRECRAWL_API_KEY` est défini dans l&#39;environnement qui exécute le script.
* **Le serveur renvoie `401` :** remplacez la clé et renvoyez la requête, car OpenAI ne conserve pas la valeur `authorization` d&#39;une requête à l&#39;autre.
* **Un outil est manquant :** ajoutez son nom à `allowed_tools`, ou supprimez `allowed_tools` pour importer tous les outils exposés par le serveur.
* **Le modèle répond sans utiliser Firecrawl :** indiquez le nom de l&#39;outil dans votre prompt, par exemple « Utilise firecrawl&#95;search pour trouver... ».
