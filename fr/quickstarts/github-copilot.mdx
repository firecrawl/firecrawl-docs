Connectez [GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli) ou [Copilot dans VS Code](https://code.visualstudio.com/docs/copilot/overview) à Firecrawl via le serveur MCP hébergé, puis connectez-vous avec votre compte Firecrawl. L&#39;[agent de codage Copilot](#copilot-coding-agent), lui, se connecte à l&#39;aide d&#39;une clé API.

Les URL de serveur ci-dessous sont des valeurs à renseigner dans la configuration du client : il ne s&#39;agit pas de pages à ouvrir directement dans un navigateur.

## Copilot CLI {#copilot-cli}

### 1. Ajouter Firecrawl {#1-add-firecrawl}

```bash
copilot mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

Cette commande ajoute le serveur à `~/.copilot/mcp-config.json`. Vous pouvez également exécuter `/mcp add` dans une session interactive et choisir le type **HTTP**, ou modifier directement le fichier :

```json ~/.copilot/mcp-config.json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth",
      "tools": ["*"]
    }
  }
}
```

### 2. Connexion et vérification {#2-sign-in-and-verify}

```bash
copilot
```

Lors de la première connexion, Copilot CLI ouvre la page de connexion Firecrawl dans votre navigateur : choisissez une équipe, puis approuvez la connexion. Saisissez `/mcp` pour vérifier que `firecrawl` est bien connecté.

### Utiliser une clé API à la place {#use-an-api-key-instead}

Pour une utilisation sans intervention, [créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys), exportez-la sous le nom `FIRECRAWL_API_KEY`, puis ajoutez le point de terminaison prévu pour l&#39;authentification par clé API, avec un en-tête bearer :

```bash
copilot mcp add --transport http \
  --header "Authorization: Bearer $FIRECRAWL_API_KEY" \
  firecrawl https://mcp.firecrawl.dev/v2/mcp
```

La clé est stockée dans `~/.copilot/mcp-config.json` : veillez donc à exclure ce fichier du contrôle de version.

## VS Code {#vs-code}

### 1. Ajouter Firecrawl {#1-add-firecrawl-2}

Exécutez **MCP: Add Server** depuis la palette de commandes et choisissez **HTTP**, ou créez le fichier `.vscode/mcp.json` dans votre espace de travail :

```json .vscode/mcp.json
{
  "servers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

Pour rendre le serveur disponible dans tous vos espaces de travail, exécutez **MCP: Open User Configuration** et ajoutez-y la même entrée.

### 2. Se connecter et vérifier {#2-sign-in-and-verify-2}

Démarrez le serveur depuis l’éditeur `mcp.json` ou avec **MCP: List Servers**. Lorsque VS Code vous demande de vous authentifier, autorisez l’accès et finalisez la connexion à Firecrawl dans votre navigateur. Ouvrez ensuite Copilot Chat en mode **Agent** et cliquez sur l’icône des outils pour vérifier que les outils de Firecrawl figurent bien dans la liste.

### Utiliser plutôt une clé API {#use-an-api-key-instead-2}

Utilisez le point de terminaison avec clé API et laissez VS Code vous demander la clé : elle sera ainsi stockée de manière sécurisée au lieu d&#39;être écrite en clair dans le fichier :

```json .vscode/mcp.json
{
  "inputs": [
    {
      "type": "promptString",
      "id": "firecrawl-api-key",
      "description": "Firecrawl API key",
      "password": true
    }
  ],
  "servers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer ${input:firecrawl-api-key}"
      }
    }
  }
}
```

## Agent de codage Copilot {#copilot-coding-agent}

L&#39;agent de codage Copilot (également appelé agent cloud Copilot) traite les issues et les pull requests sur GitHub. Ses paramètres MCP au niveau du dépôt ne prennent pas en charge les serveurs distants utilisant OAuth : cette configuration stocke donc une clé API Firecrawl en tant que secret Agents et l&#39;envoie dans un en-tête.

### Prérequis {#requirements}

* Une offre GitHub Copilot payante, avec l&#39;agent de codage activé pour le dépôt.
* Un accès administrateur au dépôt, nécessaire pour modifier les paramètres MCP et les secrets Agents.
* Une [clé API Firecrawl](https://www.firecrawl.dev/app/api-keys).

### Configuration {#set-it-up}

1. Dans votre dépôt, ouvrez **Settings**, puis **Secrets and variables**, puis **Agents**.
2. Sélectionnez **New repository secret**, nommez-le `COPILOT_MCP_FIRECRAWL_API_KEY`, collez votre clé API Firecrawl, puis enregistrez. Copilot ne transmet aux serveurs MCP que les secrets Agents dont le nom commence par `COPILOT_MCP_`.
3. Ouvrez **Settings**, puis **Copilot**, puis **MCP servers**.
4. Collez cette configuration dans **MCP configuration**, puis sélectionnez **Save MCP configuration** :

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer $COPILOT_MCP_FIRECRAWL_API_KEY"
      },
      "tools": ["firecrawl_search", "firecrawl_scrape", "firecrawl_map"]
    }
  }
}
```

5. Assignez un ticket à Copilot. Lorsque sa pull request apparaît, choisissez **View session**, ouvrez l&#39;étape **Start MCP Servers** dans le journal, puis vérifiez que les outils Firecrawl y figurent.

<Warning>
  Copilot utilise les outils de la liste `tools` sans demander d&#39;approbation. Limitez cette liste aux seuls outils dont l&#39;agent a besoin. N&#39;utilisez `"*"` que si vous souhaitez mettre à disposition tous les outils Firecrawl.
</Warning>

## Essayer {#try-it}

```text
Recherche sur le Web les dernières notes de release de l'App Router de Next.js et résume les sources.
```

```text
Extrais https://docs.firecrawl.dev et liste les sections de premier niveau.
```

Voir [choisir un outil](/fr/mcp-server/tools) pour la liste complète des outils de Firecrawl MCP.

## Dépannage {#troubleshooting}

* **Les outils n&#39;apparaissent pas :** vérifiez qu&#39;un seul serveur `firecrawl` est configuré, puis redémarrez Copilot CLI, ou exécutez **MCP: List Servers** dans VS Code et redémarrez le serveur.
* **La connexion est à nouveau demandée ou renvoie `401` :** redémarrez le serveur et finalisez la connexion dans le navigateur. Il est normal qu&#39;une requête brute vers le serveur OAuth renvoie `401` avant l&#39;authentification.
* **Une connexion par clé API renvoie `401` :** vérifiez que l&#39;URL est bien `https://mcp.firecrawl.dev/v2/mcp` (et non `/v2/mcp-oauth`) et que l&#39;en-tête est `Authorization: Bearer <FIRECRAWL_API_KEY>`.
* **Stratégie d&#39;organisation :** si votre organisation GitHub restreint les serveurs MCP dans Copilot, un administrateur doit autoriser Firecrawl pour que la connexion soit possible.
* **Agent de codage : les outils Firecrawl n&#39;apparaissent pas dans le journal de session :** vérifiez que le nom du secret est exactement `COPILOT_MCP_FIRECRAWL_API_KEY` et qu&#39;il s&#39;agit bien d&#39;un secret Agents, et non d&#39;un secret Actions.
