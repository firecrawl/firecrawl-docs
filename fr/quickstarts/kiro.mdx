Connectez Firecrawl à Kiro via le serveur MCP hébergé. Kiro gère pour vous la connexion dans le navigateur : vous n&#39;avez donc rien à enregistrer manuellement. L&#39;IDE Kiro et la CLI Kiro utilisent le même fichier de configuration.

<Note>
  La CLI Kiro remplace la CLI Amazon Q Developer. Si vous utilisiez `q` auparavant, cette page vous concerne.
</Note>

## Configuration rapide {#quick-setup}

1. Ouvrez le fichier de configuration utilisateur `~/.kiro/settings/mcp.json`. Dans l&#39;IDE, exécutez **Kiro: Open user MCP config (JSON)** depuis la palette de commandes. Pour un projet spécifique, utilisez plutôt le fichier `.kiro/settings/mcp.json` de l&#39;espace de travail.
2. Ajoutez Firecrawl, puis enregistrez le fichier :

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

3. Kiro se reconnecte dès que vous enregistrez et ouvre la page d&#39;autorisation de Firecrawl dans votre navigateur. Connectez-vous et autorisez l&#39;accès.
4. Ouvrez l&#39;onglet des serveurs MCP dans le panneau Kiro, ou exécutez `kiro-cli mcp status --name firecrawl`, puis vérifiez que les outils de Firecrawl sont bien disponibles.

<Accordion title="Vous préférez une clé API ?">
  Dans Kiro, les serveurs distants acceptent les en-têtes. Exportez `FIRECRAWL_API_KEY` dans votre shell, puis utilisez :

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp",
        "headers": {
          "Authorization": "Bearer ${FIRECRAWL_API_KEY}"
        }
      }
    }
  }
  ```

  Kiro ne développe que les variables d&#39;environnement que vous avez approuvées. Lorsqu&#39;il affiche l&#39;avertissement de sécurité concernant `FIRECRAWL_API_KEY`, approuvez-la ou ajoutez-la sous **Mcp Approved Env Vars** dans les paramètres.
</Accordion>

<Accordion title="Vous préférez la CLI ?">
  ```bash
  kiro-cli mcp add --name firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth --scope global
  ```
</Accordion>

Voir le [guide de connexion OAuth](/fr/mcp-server/oauth) pour plus de détails. Pour une utilisation sans intervention, [configurez une clé API](/fr/mcp-server/keyless#add-an-api-key).

## Dépannage {#troubleshooting}

* **La prise en charge de MCP est désactivée :** dans l&#39;IDE, ouvrez les paramètres avec `Cmd/Ctrl + ,`, recherchez « MCP » et activez la prise en charge.
* **Le serveur ne se connecte pas :** vérifiez que l&#39;URL est exactement `https://mcp.firecrawl.dev/v2/mcp-oauth`, puis enregistrez de nouveau le fichier pour forcer une reconnexion.
* **Une erreur de scope OAuth s&#39;affiche :** ajoutez `"oauth": { "oauthScopes": [] }` à l&#39;entrée du serveur.
* **Le fichier de l&#39;espace de travail et celui de l&#39;utilisateur définissent tous deux `firecrawl` :** Kiro les fusionne et c&#39;est le fichier de l&#39;espace de travail qui prévaut. Ne conservez qu&#39;une seule entrée.
