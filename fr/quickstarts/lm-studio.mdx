Ajoutez les outils Search, Scrape et Crawl de Firecrawl à [LM Studio](https://lmstudio.ai) via le serveur MCP hébergé, pour permettre à vos modèles locaux de consulter le web en temps réel.

À partir de la version 0.3.17, LM Studio fait office d&#39;hôte MCP et lit la configuration des serveurs depuis un fichier `mcp.json`, selon la même notation que Cursor.

## Configuration rapide {#quick-setup}

1. [Créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys).
2. Dans LM Studio, ouvrez l’onglet **Program** dans la barre latérale droite, puis choisissez **Install &gt; Edit mcp.json**.
3. Ajoutez Firecrawl dans `mcpServers`, puis enregistrez :

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

Si `mcp.json` répertorie déjà d’autres serveurs, copiez uniquement l’entrée `"firecrawl": { ... }` dans l’objet `mcpServers` existant.

LM Studio charge le serveur dès que vous enregistrez le fichier. Ouvrez une conversation avec un modèle prenant en charge l’utilisation d’outils et vérifiez que `firecrawl_search` et `firecrawl_scrape` figurent dans la liste des outils de la conversation.

Veillez à ce que la clé API n’apparaisse ni dans les captures d’écran partagées ni dans le contrôle de version. LM Studio conserve `mcp.json` dans son dossier de données, au sein de votre répertoire personnel (`~/.lmstudio/mcp.json`).

## Se connecter au lieu d&#39;utiliser une clé {#sign-in-instead-of-using-a-key}

LM Studio prend en charge MCP OAuth pour les serveurs distants. Ajoutez `https://mcp.firecrawl.dev/v2/mcp-oauth` comme `url` du serveur, sans `headers`, puis suivez la procédure de connexion dans le navigateur. Voir [Pour les humains](/fr/mcp-server/oauth).

## Exécuter plutôt le serveur local {#run-the-local-server-instead}

Pour exécuter Firecrawl sur votre propre machine, remplacez l&#39;entrée `url` par une entrée `command` qui démarre le package npm. Voir le [guide du serveur MCP local](/fr/mcp-server/local) pour connaître la commande et les options à jour.

## Dépannage {#troubleshooting}

* **Les outils n’apparaissent pas :** assurez-vous que le modèle prend en charge l’utilisation d’outils, puis vérifiez que `mcp.json` est un JSON valide et que l’entrée `firecrawl` se trouve bien dans `mcpServers`.
* **L’authentification échoue :** vérifiez que l’en-tête contient `Bearer` suivi de votre clé, séparés par un seul espace, et que la clé est active dans votre [tableau de bord Firecrawl](https://www.firecrawl.dev/app/api-keys).
* **Le modèle ralentit ou manque de contexte :** les outils Firecrawl peuvent renvoyer des pages volumineuses. Demandez des URL précises, utilisez un modèle doté d’une fenêtre de contexte plus large ou n’activez que les outils dont vous avez besoin.
* **Contrôlez les appels d’outils :** par défaut, LM Studio demande une confirmation avant d’exécuter des outils MCP. N’installez que des serveurs MCP provenant de sources de confiance.
