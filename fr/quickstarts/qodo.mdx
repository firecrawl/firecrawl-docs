Ajoutez Firecrawl à Qodo Command pour permettre à vos agents Qodo d&#39;effectuer des recherches sur le web et de lire des pages. Qodo Command démarre le serveur MCP Firecrawl en tant que processus local, à l&#39;aide de votre clé API.

<Note>
  Qodo abandonne son plugin d&#39;IDE le 30 octobre 2026 et intègre les flux de travail locaux aux agents de programmation que vous utilisez déjà. Cette page porte sur Qodo Command, qui lit la configuration des serveurs MCP à partir d&#39;un fichier de projet.
</Note>

## Prérequis {#requirements}

* Qodo Command, installé via `npm install -g @qodo/command`, avec une session ouverte via `qodo login`.
* Node.js 22 ou version ultérieure.
* Une [clé API Firecrawl](https://www.firecrawl.dev/app/api-keys).

## Configuration rapide {#quick-setup}

1. À la racine de votre projet, créez le fichier `mcp.json` :

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp@3.33.2"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
      }
    }
  }
}
```

2. Créez `agents/research.toml` et donnez à l&#39;agent l&#39;accès au serveur en le désignant par son nom :

```toml
version = "1.0"

[commands.research]
description = "Research a topic on the web with Firecrawl"
instructions = """
Use the Firecrawl tools to search the web and read pages, then summarize the sources.
"""
tools = ["firecrawl"]
execution_strategy = "act"
```

3. Importez l’agent depuis le fichier `agent.toml` situé à la racine du projet :

```toml
version = "1.0"

imports = ["agents/research.toml"]
```

4. Lancez l&#39;agent et affichez la liste des outils disponibles :

```bash
qodo list-mcp
qodo research "Find the latest release notes for Node.js"
```

Ne versionnez pas `mcp.json` : il contient votre clé. Voir [Exécuter MCP en local](/fr/mcp-server/local) pour la liste complète des variables d&#39;environnement.

## Dépannage {#troubleshooting}

* **`list-mcp` n&#39;affiche aucune entrée Firecrawl :** vérifiez que `mcp.json` se trouve à la racine du projet, ou passez `--mcp-file=path`.
* **L&#39;agent n&#39;appelle jamais Firecrawl :** vérifiez que le champ `tools` du fichier de l&#39;agent contient `"firecrawl"`, qui doit correspondre à la clé définie dans `mcp.json`.
* **Le serveur ne démarre pas :** exécutez `node --version` et vérifiez que la version affichée est 22 ou supérieure.
* **Le serveur renvoie une erreur `401` :** remplacez la valeur de `FIRECRAWL_API_KEY` dans `mcp.json`.
