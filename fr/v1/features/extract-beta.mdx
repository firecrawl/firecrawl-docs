<div id="introducing-extract-beta">
  ## Présentation de /extract (bêta) {#introducing-extract-beta}
</div>

<Warning>
  [Veuillez utiliser la nouvelle documentation Open Beta de /extract en cliquant ici 🔥](/fr/features/extract)
</Warning>

Extrayez des données structurées à partir d’une URL, de plusieurs URL ou de sites entiers à l’aide de grands modèles de langage (LLMs). Notre nouveau point de terminaison `/extract` vous permet de :

* Extraire en une fois des données structurées de sites complets
* Connecter ou créer des applications d’enrichissement de données nécessitant des données structurées issues de sites web
* Développer des applications d’IA qui ont besoin de données propres provenant de plusieurs sites web

<div id="considerations">
  ## Considérations {#considerations}
</div>

Le point de terminaison `/extract` offre une extraction de données flexible avec des schémas personnalisables. Les résultats peuvent être améliorés en ajustant le prompt. Il est actuellement en version bêta et nous accueillons volontiers vos retours.

<div id="extract-endpoint">
  ### point de terminaison /extract {#extract-endpoint}
</div>

Permet d’extraire des données structurées à partir de sites web entiers.

Lors de la spécification des URL, vous pouvez ajouter `/*` à l’URL pour extraire des informations sur l’ensemble du chemin du site plutôt que sur une seule page.

Par exemple, `https://firecrawl.dev/*` tentera d’extraire des données de toutes les pages du domaine firecrawl.dev. Le `/*` est encore en test ; signalez tout problème à help@firecrawl.com.

<div id="pending-response">
  #### Réponse en attente {#pending-response}
</div>

Les tâches d’extraction peuvent avoir l’un des états suivants :

* `completed` : la tâche d’extraction s’est terminée avec succès.
* `processing` : la tâche d’extraction est toujours en cours.
* `failed` : la tâche d’extraction a rencontré une erreur et n’a pas abouti.
* `cancelled` : la tâche d’extraction a été annulée par l’utilisateur.

<div id="improving-results-with-web-search-external-links">
  ### Améliorer les résultats avec la recherche web et les liens externes {#improving-results-with-web-search-external-links}
</div>

Si vous souhaitez améliorer les résultats de l’extraction, vous pouvez transmettre le paramètre `enableWebSearch` au point de terminaison. Cela lui permettra de tenter de trouver les données via des liens externes — en dehors du périmètre des URL fournies.

<div id="billing">
  ### Facturation {#billing}
</div>

Tant que `/extract` est en bêta, nous facturons 5 crédits par URL analysée utilisée pour générer la réponse finale, afin de prévenir les abus. Cela évoluera à l’avenir.
