<div id="introducing-llmstxt-generator-endpoint-alpha">
  ## Présentation du point de terminaison générateur LLMs.txt (Alpha) 📃 {#introducing-llmstxt-generator-endpoint-alpha}
</div>

Le point de terminaison `/llmstxt` vous permet de convertir n’importe quel site web en [fichiers texte prêts pour les LLM](https://www.firecrawl.dev/blog/How-to-Create-an-llms-txt-File-for-Any-Website). Fournissez simplement une URL, et Firecrawl explorera le site pour générer les fichiers `llms.txt` et `llms-full.txt`, utilisables pour l’entraînement ou l’analyse avec n’importe quel LLM.

<div id="how-it-works">
  ## Comment ça fonctionne {#how-it-works}
</div>

Le générateur LLMs.txt :

1. Explore l’URL de site fournie ainsi que les pages liées
2. Extrait un texte propre et pertinent
3. Génère deux formats :
   * `llms.txt` : Résumés concis et informations clés
   * `llms-full.txt` : Contenu intégral avec davantage de détails

**Paramètres clés :**

* **url** : l’URL du site web à partir duquel générer les fichiers LLMs.txt
* **maxUrls** (optionnel) : nombre maximal de pages à explorer (1–100, par défaut : 10)
* **showFullText** (optionnel) : générer llms-full.txt en plus de llms.txt (par défaut : false)

Voir la [référence de l’API](/fr/api-reference/endpoint/llmstxt) pour plus de détails.

<div id="known-limitations-alpha">
  ## Limitations connues (alpha) {#known-limitations-alpha}
</div>

1. **Restrictions d’accès**\
   Seules les pages accessibles publiquement peuvent être traitées. Le contenu protégé par authentification ou par un paywall n’est pas pris en charge.

2. **Taille du site**\
   Pendant la phase alpha, le traitement est limité à 5 000 URL.

3. **État alpha**\
   En tant que fonctionnalité en alpha, le format de sortie et le processus de traitement peuvent évoluer en fonction des retours.

## Facturation et utilisation {#billing-and-usage}

La facturation est basée sur le nombre d’URL traitées :

- Coût de base : 1 crédit par URL traitée
- Maîtrisez le coût des URL avec le paramètre `maxUrls`
