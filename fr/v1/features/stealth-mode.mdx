  Le paramètre `proxy` est obsolète. Nous recommandons `auto`, qui permet à Firecrawl de gérer la sélection du proxy pour vous.
</Warning>

Firecrawl propose différents types de proxy pour vous aider à extraire des données depuis des sites web offrant des niveaux variables de complexité. Le type de proxy peut être défini via le paramètre `proxy`.

<div id="proxy-types">
  ### Types de proxy
</div>

* **basic** : Proxys pour l’extraction de la plupart des sites.
* **avancé** : Proxys avancés pour l’extraction de sites complexes tout en préservant la confidentialité.
* **auto** : Recommandé. Firecrawl réessaiera automatiquement l’extraction avec des proxys avancés si le proxy basic échoue.

Si vous ne spécifiez pas de proxy, Firecrawl utilisera basic par défaut.
