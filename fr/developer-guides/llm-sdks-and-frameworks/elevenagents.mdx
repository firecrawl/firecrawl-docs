Donnez à vos agents vocaux et conversationnels [ElevenAgents](https://elevenlabs.io/agents) un contexte propre issu du web en direct, en utilisant Firecrawl pour la recherche et l&#39;extraction. Ce guide couvre deux approches d&#39;intégration :

1. **serveur MCP** — connectez le serveur MCP Firecrawl hébergé pour une configuration sans code.
2. **outil webhook côté serveur** — faites pointer un outil personnalisé vers l&#39;API REST de Firecrawl pour un contrôle total sur les requêtes.

## Prérequis {#prerequisites}

* Un compte [ElevenLabs](https://elevenlabs.io) avec accès à ElevenAgents
* Une clé API Firecrawl depuis le [dashboard firecrawl.dev](https://firecrawl.dev)

## Option 1 : serveur MCP Firecrawl {#option-1-firecrawl-mcp-server}

Le moyen le plus rapide de donner à un agent l’accès au web. ElevenAgents prend en charge les serveurs MCP distants, et Firecrawl fournit un point de terminaison MCP hébergé.

### Ajouter le serveur MCP {#add-the-mcp-server}

1. Ouvrez la [page Integrations](https://elevenlabs.io/app/agents/integrations) dans ElevenLabs et cliquez sur **Add Custom MCP Server**. La première fois qu’un membre de votre espace de travail ajoute un serveur MCP, ElevenLabs vous demande d’accepter ses conditions d’utilisation des serveurs MCP, ce qui active MCP pour l’ensemble de l’espace de travail.
2. Renseignez les champs suivants :

| Champ                         | Valeur                                                               |
| ----------------------------- | -------------------------------------------------------------------- |
| **Name**                      | Firecrawl                                                            |
| **Description**               | Recherche, extraction et analyse de contenu web avec Firecrawl.        |
| **Server type**               | Streamable HTTP                                                      |
| **Server URL**                | `https://mcp.firecrawl.dev/v2/mcp`                                   |
| **Secret Token** (facultatif) | `Bearer fc-YOUR_API_KEY`, stocké comme secret de l’espace de travail |

Le MCP sans clé expose exactement recherche, extraction et Parse, avec des limites partagées. [Connectez-vous](/fr/mcp-server/oauth) ou [ajoutez une clé API](/fr/mcp-server/keyless#add-an-api-key) pour accéder à un ensemble d’outils plus étendu. Conservez les clés API dans une variable d’environnement ou un magasin de secrets, jamais dans une URL.

<Note>
  Vous devez sélectionner **Streamable HTTP** comme type de serveur. L’option SSE par défaut ne fonctionne pas avec le point de terminaison MCP de Firecrawl.
</Note>

3. Dans **Tool Approval Mode**, choisissez un niveau d’approbation :
   * **No Approval** — l’agent utilise les outils librement. Convient pour l’extraction en lecture seule.
   * **Fine-Grained Tool Approval** — permet de présélectionner les outils qui peuvent s’exécuter automatiquement et ceux qui nécessitent une approbation.
   * **Always Ask** (par défaut) — l’agent demande une autorisation avant chaque appel d’outil.

4. Cliquez sur **Add Integration**. ElevenLabs enregistre le serveur et teste la connexion.

ElevenLabs se connectera au serveur sans clé et affichera recherche, extraction et Parse. Si un Secret Token est défini, elle affiche l’ensemble d’outils complet de Firecrawl MCP.

### L’associer à un agent {#attach-it-to-an-agent}

1. Créez ou ouvrez un agent dans le [tableau de bord ElevenAgents](https://elevenlabs.io/app/agents/agents).
2. Accédez à l’onglet **Tools**, puis sélectionnez le sous-onglet **MCP**.
3. Cliquez sur **Add server** et sélectionnez l’intégration **Firecrawl** dans le menu déroulant.

### Mettez à jour le prompt système {#update-the-system-prompt}

Dans l’onglet **Agent**, ajoutez des instructions au **prompt système** afin que l’agent sache quand utiliser Firecrawl. Par exemple :

```text
Vous êtes un assistant de recherche serviable. Lorsque l'utilisateur pose une question sur un site web,
une entreprise ou tout sujet nécessitant des informations à jour, utilisez les
outils Firecrawl pour rechercher sur le web ou scraper la page concernée, puis
résumez les résultats.
```

### Testez-le {#test-it}

Cliquez sur **Preview** dans la barre de navigation supérieure. Vous pouvez le tester via le champ de chat textuel ou en lançant un appel vocal. Essayez avec un prompt comme :

> &quot;Que fait firecrawl.dev ? Va sur le site et résume-le-moi.&quot;

L’agent appellera l’outil MCP Firecrawl `firecrawl_scrape`, récupérera le markdown de la page et répondra avec un résumé.

## Option 2 : Outil Webhook côté serveur {#option-2-server-webhook-tool}

Utilisez cette approche lorsque vous avez besoin d&#39;une maîtrise précise des paramètres de requête (formats, en-têtes, délais d’expiration, etc.) ou que vous souhaitez appeler un point de terminaison Firecrawl spécifique sans exposer l’ensemble des outils MCP.

### Outil de scraping {#scrape-tool}

Créez un outil qui scrape une seule URL et renvoie son contenu au format markdown.

1. Ouvrez votre agent, puis accédez à l’onglet **Tools**.
2. Cliquez sur **Add tool**, puis sélectionnez **Webhook**.
3. Configurez l’outil :

| Champ           | Valeur                                                        |
| --------------- | ------------------------------------------------------------- |
| **Name**        | scrape&#95;website                                            |
| **Description** | Scrape le contenu d’une URL et le renvoie en markdown propre. |
| **Method**      | POST                                                          |
| **URL**         | `https://api.firecrawl.dev/v2/scrape`                         |

<Note>
  Le champ **Method** est défini sur GET par défaut — veillez à le remplacer par **POST**.
</Note>

4. Faites défiler jusqu’à la section **Headers**, puis cliquez sur **Add header** pour configurer l’authentification :

| En-tête         | Valeur                          |
| --------------- | ------------------------------- |
| `Authorization` | `Bearer YOUR_FIRECRAWL_API_KEY` |

Sinon, si des connexions d’authentification de l’espace de travail sont configurées, vous pouvez utiliser le menu déroulant **Authentication** à la place.

5. Ajoutez des **paramètres du corps** :

| Paramètre     | Type   | Description                                                                                                                                                | Obligatoire |
| ------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| `url`         | string | L’URL à scraper                                                                                                                                            | Oui         |
| `integration` | string | Valeur constante `_elevenlabs`. Définissez-la comme constante pour que le LLM ne la renseigne jamais. Elle indique que la requête provient d’ElevenAgents. | Non         |

6. Cliquez sur **Add tool**.

L’API Firecrawl renvoie par défaut le contenu de la page au format markdown. L’agent reçoit la réponse JSON et peut utiliser le champ `markdown` pour répondre aux questions.

### Outil de recherche {#search-tool}

Créez un outil qui effectue une recherche sur le web et renvoie le titre, l’URL et la description de chaque résultat.

1. Cliquez à nouveau sur **Add tool** → **Webhook** et configurez :

| Champ           | Valeur                                                                                                                      |
| --------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Name**        | search&#95;web                                                                                                              |
| **Description** | Effectuer une recherche sur le web à partir d’une requête et renvoyer le titre, l’URL et la description de chaque résultat. |
| **Method**      | POST                                                                                                                        |
| **URL**         | `https://api.firecrawl.dev/v2/search`                                                                                       |

2. Ajoutez le même en-tête `Authorization` que ci-dessus.

3. Ajoutez des **paramètres du corps** :

| Paramètre     | Type   | Description                                                                                                                                                | Obligatoire |
| ------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| `query`       | string | La requête de recherche                                                                                                                                    | Oui         |
| `limit`       | number | Nombre maximal de résultats à renvoyer (10 par défaut)                                                                                                     | Non         |
| `integration` | string | Valeur constante `_elevenlabs`. Définissez-la comme constante pour que le LLM ne la renseigne jamais. Elle indique que la requête provient d’ElevenAgents. | Non         |

4. Cliquez sur **Add tool**.

### Mettre à jour le prompt système {#update-the-system-prompt-2}

Dans l’onglet **Agent**, mettez à jour le **prompt système** :

```text
Vous êtes un assistant compétent ayant accès à des outils web.

- Utilisez `scrape_website` lorsque l'utilisateur vous fournit une URL spécifique à lire.
- Utilisez `search_web` lorsque l'utilisateur pose une question générale nécessitant
  de trouver des informations en ligne. Appelez ensuite `scrape_website` sur l'URL
  du résultat le plus pertinent pour lire la page complète.

Résumez toujours les informations de manière concise et citez l'URL source.
```

### Essayez-le {#test-it-2}

Cliquez sur **Preview** et essayez de demander :

> &quot;Recherchez les dernières fonctionnalités de Next.js et faites-m’en un résumé.&quot;

L’agent appellera `search_web`, recevra les résultats de Firecrawl et répondra par un résumé des informations trouvées.

## Conseils {#tips}

* **Choix du modèle** : Pour des appels d’outils fiables, utilisez un modèle performant comme GPT-4o, Claude Sonnet 5 ou Gemini 2.5 Flash. Les modèles plus petits peuvent avoir du mal à extraire les bons paramètres.
* **Gardez des prompts précis** : Indiquez à l’agent exactement quand utiliser chaque outil. Des instructions vagues entraînent des appels d’outils manqués ou erronés.
* **Limitez la taille des réponses** : Pour les agents vocaux, de longues pages extraites peuvent saturer le contexte du LLM. Par défaut, l’extraction ne renvoie déjà que le contenu principal (`onlyMainContent: true`) ; demandez donc également à l’agent de résumer de façon très concise pour garder des réponses courtes.
* **Sons d’appel d’outil** : Dans les paramètres de l’outil webhook ou MCP, vous pouvez configurer un **son d’appel d’outil** pour diffuser un son d’ambiance pendant l’exécution d’un outil. Cela indique à l’utilisateur que l’agent est en train de travailler.
