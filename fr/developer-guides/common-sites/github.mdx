Découvrez comment utiliser les fonctionnalités principales de Firecrawl pour scraper des dépôts, des tickets et de la documentation sur GitHub.

<Info>
  Il existe deux façons d&#39;obtenir des données GitHub avec Firecrawl. Vous pouvez **scraper, effectuer une cartographie ou effectuer un crawl** une URL `github.com` spécifique (ce que couvre le reste de cette page), ou utiliser le [Developer Index](/fr/features/developer) pour découvrir de manière sémantique des tickets, des pull requests fusionnées et des README pertinents sur l&#39;ensemble de GitHub, sans connaître l&#39;URL exacte.
</Info>

<div id="setup">
  ## Configuration
</div>

```bash
npm install firecrawl zod
```

<div id="scrape-with-json-mode">
  ## Scrape en mode JSON
</div>

Extraire des données structurées à partir de dépôts en utilisant des schémas Zod.

```typescript
import { Firecrawl } from 'firecrawl';
import { z } from 'zod';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const result = await firecrawl.scrape('https://github.com/firecrawl/firecrawl', {
    formats: [{
        type: 'json',
        schema: z.object({
            name: z.string(),
            description: z.string(),
            stars: z.number(),
            forks: z.number(),
            language: z.string(),
            topics: z.array(z.string())
        })
    }]
});

console.log(result.json);
```

<div id="search">
  ## Search
</div>

Rechercher des dépôts, des tickets ou de la documentation sur GitHub.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const searchResult = await firecrawl.search('machine learning site:github.com', {
    limit: 10,
    sources: [{ type: 'web' }], // { type: 'news' }, { type: 'images' }
    scrapeOptions: {
        formats: ['markdown']
    }
});

console.log(searchResult);
```

<div id="search-github-with-the-developer-index">
  ## Recherche GitHub avec le Developer Index
</div>

Le [Developer Index](/fr/features/developer) de Firecrawl effectue une recherche sémantique parmi les tickets GitHub publics indexés, les pull requests fusionnées et les README de dépôts, ainsi que dans une sélection de sites de documentation. Il permet de trouver des détails d’implémentation et des solutions techniques existantes lorsque vous ne connaissez pas le dépôt ou l’URL exacts, et renvoie les passages correspondants plutôt qu’un simple snippet.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const result = await firecrawl.search(
    'how to handle rate limit retries with exponential backoff',
    { categories: ['developer'], limit: 10 }
);

console.log(result.developer);
```

Pour obtenir des résultats classés avec les passages correspondants, ainsi que pour filtrer par dépôt et par type de résultat, appelez le point de terminaison dédié :

```bash
# Aucune API key nécessaire pour démarrer ; ajoutez -H "Authorization: Bearer $FIRECRAWL_API_KEY" pour des rate limits plus élevées :
curl -s "https://api.firecrawl.dev/v2/search/developer?query=how%20to%20handle%20rate%20limit%20retries%20with%20exponential%20backoff&types=issue,pull_request&k=10"
```

Vous pouvez également effectuer des recherches sur GitHub via les résultats web classiques à l’aide du point de terminaison général [`/search`](/fr/features/search) et de la catégorie `github`, qui restreint la recherche web à ce site plutôt que d’interroger l’index.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const searchResult = await firecrawl.search('exponential backoff retry', {
    categories: ['github'],
    limit: 10
});

console.log(searchResult);
```

Consultez le [guide du Developer Index](/fr/features/developer) pour savoir comment l’utiliser avec Python, cURL, la CLI et MCP.

<div id="scrape">
  ## Scrape
</div>

Extraire une seule page GitHub – dépôt, ticket ou fichier.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const result = await firecrawl.scrape('https://github.com/firecrawl/firecrawl', {
    formats: ['markdown'] // par ex. html, links, etc.
});

console.log(result);
```

<div id="map">
  ## Map
</div>

Découvrez toutes les URL disponibles dans un dépôt ou un site de documentation. Remarque : Map ne renvoie que les URL, sans contenu.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const mapResult = await firecrawl.map('https://github.com/vercel/next.js/tree/canary/docs');

console.log(mapResult.links);
// Retourne un tableau d'URL sans contenu
```

<div id="crawl">
  ## Crawl
</div>

Parcourir plusieurs pages d’un dépôt ou d’une documentation.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const crawlResult = await firecrawl.crawl('https://github.com/facebook/react/wiki', {
    limit: 10,
    scrapeOptions: {
        formats: ['markdown']
    }
});

console.log(crawlResult.data);
```

<div id="batch-scrape">
  ## Extraction par lot
</div>

Extraire plusieurs URL GitHub simultanément.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

// Attendre la fin
const job = await firecrawl.batchScrape([
    'https://github.com/vercel/next.js',
    'https://github.com/facebook/react',
    'https://github.com/microsoft/typescript'],
    {
        options: {
            formats: ['markdown']
        },
        pollInterval: 2,
        timeout: 120
    }
);


console.log(job.status, job.completed, job.total);

console.log(job);
```

<div id="batch-scrape-with-json-mode">
  ## Extraction par lot avec le mode JSON
</div>

Extrayez des données structurées à partir de plusieurs dépôts en une seule opération.

```typescript
import { Firecrawl } from 'firecrawl';
import { z } from 'zod';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

// Attendre la fin
const job = await firecrawl.batchScrape([
    'https://github.com/vercel/next.js',
    'https://github.com/facebook/react'],
    {
        options: {
            formats: [{
                type: 'json',
                schema: z.object({
                    name: z.string(),
                    description: z.string(),
                    stars: z.number(),
                    language: z.string()
                })
            }]
        },
        pollInterval: 2,
        timeout: 120
    }
);


console.log(job.status, job.completed, job.total);

console.log(job);
```
