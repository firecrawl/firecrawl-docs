Ajoutez Firecrawl à Claude.ai avec le connecteur Firecrawl natif. Vous n’avez pas besoin d’ajouter un connecteur personnalisé ni de coller l’URL d’un serveur.

<Note>
  Vous cherchez comment configurer Claude Code ? Consultez plutôt le [guide
  Claude Code](/fr/quickstarts/claude-code).
</Note>

<div id="add-to-claude">
  ## Ajouter à Claude
</div>

<Card title="Ajouter à Claude" icon="/images/agent-clients/claude-ai.svg" href="https://claude.ai/directory/connectors/firecrawl" cta="Ouvrir dans Claude" arrow>
  Ouvrez le connecteur Firecrawl dans Claude.ai et connectez-le.
</Card>

1. Ouvrez le [connecteur Firecrawl dans Claude.ai](https://claude.ai/directory/connectors/firecrawl).
2. Connectez Firecrawl. Lorsque Claude ouvre Firecrawl dans votre navigateur, connectez-vous, sélectionnez une Équipe et autorisez l’accès.
3. Dans une conversation, ouvrez le menu **+**, accédez à **Connectors** et activez Firecrawl.

Avec les offres Équipe ou Enterprise, un propriétaire de l’organisation devra peut-être autoriser le connecteur avant que les membres puissent se connecter.

Les requêtes effectuées via ce connecteur utilisent les crédits et l’offre de l’Équipe sélectionnée lors de la connexion. Vous pouvez consulter ou révoquer la connexion à tout moment dans les [paramètres MCP](https://www.firecrawl.dev/app/settings?tab=mcp).

<div id="try">
  ## Essayer
</div>

Avec Firecrawl activé, essayez :

```text
Search the web for the latest Firecrawl release notes and summarize the sources.
```

```text
Scrape firecrawl.dev and tell me what it does
```
