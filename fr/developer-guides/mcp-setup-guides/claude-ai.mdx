Ajoutez des fonctionnalités Firecrawl à Claude avec un connecteur de compte distant.

<Note>
  Vous cherchez comment configurer Claude Code ? Consultez plutôt le [guide
  Claude Code](/fr/quickstarts/claude-code).
</Note>

<div id="quick-setup">
  ## Configuration rapide
</div>

<div id="1-add-a-custom-connector">
  ### 1. Ajouter un connecteur personnalisé
</div>

Accédez à [Settings &gt; Connectors](https://claude.ai/settings/connectors) dans Claude.ai, puis cliquez sur **Add custom connector**. Avec les offres Équipe ou Enterprise, un propriétaire de l’organisation doit d’abord ajouter le connecteur (Organization Settings &gt; Connectors) avant que les membres puissent se connecter individuellement.

Renseignez les informations du connecteur :

* **URL :** `https://mcp.firecrawl.dev/v2/mcp-oauth`
* **OAuth Client ID :** laissez vide
* **OAuth Client Secret :** laissez vide

Cliquez sur **Add** pour enregistrer le connecteur.

Claude ouvre Firecrawl dans votre navigateur. Connectez-vous, choisissez l’équipe à utiliser et approuvez l’accès. Votre clé API brute n’est jamais incluse dans l’URL du connecteur. Consultez le [guide OAuth](/fr/mcp-server/oauth) pour connaître le contrat du point de terminaison et les autres modes pris en charge.

<div id="2-enable-in-conversation">
  ### 2. Activer dans la conversation
</div>

Dans n’importe quelle conversation sur Claude.ai, cliquez sur le bouton **+** en bas à gauche, ouvrez **Connectors**, puis activez le connecteur Firecrawl.

<Note>
  **Ce dont bénéficie votre équipe :** les requêtes effectuées via ce connecteur utilisent les crédits et l’offre de l’équipe que vous avez sélectionnée lors de la connexion. Toute personne qui se connecte associe son propre compte. Vous pouvez consulter ou révoquer la connexion à tout moment depuis les [paramètres MCP](https://www.firecrawl.dev/app/settings?tab=mcp).
</Note>

<div id="quick-demo">
  ## Démo rapide
</div>

Avec le connecteur Firecrawl activé, essayez les prompts suivants :

**Rechercher sur le web :**

```
Search for the latest Next.js 15 features
```

**Scraper une page :**

```
Scrape firecrawl.dev and tell me what it does
```

**Obtenir la documentation :**

```
Find and scrape the Stripe API docs for payment intents
```

Claude utilisera automatiquement les outils de recherche et de scraping de Firecrawl pour obtenir les informations.
