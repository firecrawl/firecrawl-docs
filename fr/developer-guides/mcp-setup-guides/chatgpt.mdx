---
title: "Utiliser Firecrawl MCP dans ChatGPT"
description: "Ajoutez Firecrawl à ChatGPT avec le connecteur natif"
---

Ajoutez Firecrawl à ChatGPT avec l’application Firecrawl intégrée. Vous n’avez pas besoin de créer un connecteur MCP personnalisé ni de saisir l’URL d’un serveur.

<div id="add-to-chatgpt">
  ## Ajouter à ChatGPT
</div>

<Card title="Ajouter à ChatGPT" icon="/images/agent-clients/chatgpt.svg" href="https://chatgpt.com/plugins?q=firecrawl" cta="Ouvrir dans ChatGPT" arrow>
  Ouvrez l’application Firecrawl dans ChatGPT et connectez-vous.
</Card>

1. Ouvrez l’[application Firecrawl dans ChatGPT](https://chatgpt.com/plugins?q=firecrawl).
2. Sélectionnez **Firecrawl** et connectez-vous. Lorsque ChatGPT ouvre Firecrawl dans votre Browser, connectez-vous, choisissez une équipe et autorisez l’accès.
3. Dans une conversation, ouvrez le menu **+** et activez **Firecrawl** avant d’envoyer un prompt. Le connecteur doit être associé à la conversation.

N’insérez pas de clé API Firecrawl dans l’URL d’un serveur. Pour révoquer l’accès ultérieurement, utilisez les [paramètres MCP](https://www.firecrawl.dev/app/settings?tab=mcp).

<div id="try">
  ## Essayer
</div>

Avec Firecrawl activé, essayez :

```text
Recherche sur le web les dernières notes de release de Firecrawl et résume les sources.
```

```text
Scrape firecrawl.dev and tell me what it does
```
