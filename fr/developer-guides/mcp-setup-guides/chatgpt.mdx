title: "Utiliser Firecrawl MCP dans ChatGPT"

---

Ajoutez Firecrawl à ChatGPT avec le plugin Firecrawl intégré pour rechercher, effectuer une extraction, crawler et surveiller le web, et interagir avec lui, directement depuis vos conversations. Vous n’avez pas besoin de créer un connecteur MCP personnalisé ni de saisir l’URL d’un serveur.

## Ajouter à ChatGPT {#add-to-chatgpt}

<Card title="Ajouter à ChatGPT" icon="/images/agent-clients/chatgpt.svg" href="https://chatgpt.com/plugins/plugin_asdk_app_6a314a73f8ac819195b0d55e36b9c609?q=firecrawl" cta="Ouvrir dans ChatGPT" arrow>
  Ouvrez le plugin Firecrawl dans ChatGPT et installez-le.
</Card>

1. Ouvrez le [plugin Firecrawl dans ChatGPT](https://chatgpt.com/plugins/plugin_asdk_app_6a314a73f8ac819195b0d55e36b9c609?q=firecrawl), ou ouvrez **Plugins** dans ChatGPT et recherchez **Firecrawl**.
2. Sélectionnez **Install**. Lorsque ChatGPT ouvre Firecrawl dans votre navigateur, connectez-vous, choisissez une équipe et autorisez l’accès.
3. Démarrez une nouvelle conversation pour que ChatGPT charge le plugin, puis demandez-lui d’utiliser Firecrawl.

Le même plugin fonctionne dans Codex. Voir [ChatGPT &amp; Codex](/fr/integrations/chatgpt-codex) pour plus de détails et des conseils de dépannage.

N’insérez jamais de clé API Firecrawl dans l’URL du serveur. Pour révoquer l’accès ultérieurement, utilisez les [Paramètres MCP](https://www.firecrawl.dev/app/settings?tab=mcp).

## Essayer {#try}

Avec Firecrawl activé, essayez :

```text
Recherche sur le web les dernières notes de release de Firecrawl et résume les sources.
```

```text
Scrape firecrawl.dev and tell me what it does
```
