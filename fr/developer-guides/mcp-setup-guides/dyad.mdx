Ajoutez Firecrawl à [Dyad](https://www.dyad.sh) pour permettre à l&#39;IA de votre générateur d&#39;applications d&#39;effectuer des recherches, d&#39;extraire des données et d&#39;interagir avec le web.

<Note>
  Les liens Add to Dyad nécessitent Dyad v0.25 ou une version ultérieure.
</Note>

## 1. Obtenir votre clé API {#1-get-your-api-key}

Créez une clé sur [firecrawl.dev/app/api-keys](https://www.firecrawl.dev/app/api-keys). Elle se saisit dans Dyad, et non dans le lien.

## 2. Ajouter Firecrawl à Dyad {#2-add-firecrawl-to-dyad}

Choisissez un mode de transport.

Le lien ouvre Dyad sur la page **Plugins**, avec le formulaire déjà prérempli. Cliquez sur **Add**, puis effectuez l&#39;étape de configuration de la clé propre à votre transport.

### Hébergé (HTTP) {#hosted-http}

1. Dans le formulaire, désactivez **Use OAuth**.
2. Une fois le plugin ajouté, ouvrez-le et ajoutez cet en-tête :

   | En-tête         | Valeur                          |
   | --------------- | ------------------------------- |
   | `Authorization` | `Bearer YOUR_FIRECRAWL_API_KEY` |

### Local (npx) {#local-npx}

Après l&#39;ajout, ouvrez le nouveau plugin et ajoutez la variable d&#39;environnement suivante :

| Variable            | Valeur                   |
| ------------------- | ------------------------ |
| `FIRECRAWL_API_KEY` | `YOUR_FIRECRAWL_API_KEY` |

## 3. Faites un essai {#3-try-it}

Dans une conversation Dyad, essayez par exemple :

```text
Recherche sur le Web les dernières notes de version de Next.js et résume les sources.
```

```text
Extrais le contenu de https://firecrawl.dev et décris ce que propose la page.
```

## Ajouter manuellement {#add-it-by-hand}

Ouvrez **Plugins**, cliquez sur **Add Plugin**, puis renseignez l&#39;un des deux jeux de valeurs suivants.

| Transport | Champs                                                                                                                |
| --------- | --------------------------------------------------------------------------------------------------------------------- |
| `http`    | URL `https://mcp.firecrawl.dev/v2/mcp`, en-tête `Authorization: Bearer YOUR_FIRECRAWL_API_KEY`                        |
| `stdio`   | Commande `npx`, arguments `-y firecrawl-mcp`, variable d&#39;environnement `FIRECRAWL_API_KEY=YOUR_FIRECRAWL_API_KEY` |

Voir la [référence du serveur MCP](/fr/mcp-server) pour la liste complète des outils.
