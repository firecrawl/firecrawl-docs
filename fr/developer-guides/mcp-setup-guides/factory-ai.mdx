Ajoutez des capacités de scraping et de recherche web à Factory AI avec Firecrawl MCP.

<div id="quick-setup">
  ## Configuration rapide {#quick-setup}
</div>

<div id="1-get-your-api-key">
  ### 1. Récupérer votre clé d’API {#1-get-your-api-key}
</div>

Inscrivez-vous sur [firecrawl.dev/app](https://firecrawl.dev/app) et copiez votre clé d’API.

### 2. Installer la CLI Factory AI {#2-install-factory-ai-cli}

Installez la [CLI Factory Droid](https://docs.factory.ai/droid-cli/quickstart) si ce n’est pas déjà fait :

**macOS/Linux :**

```bash
curl -fsSL https://app.factory.ai/cli | sh
```

**Windows :**

```powershell
irm https://app.factory.ai/cli/windows | iex
```

### 3. Ajouter le serveur MCP Firecrawl {#3-add-firecrawl-mcp-server}

Depuis votre terminal, ajoutez le serveur MCP Firecrawl hébergé avec `droid mcp add` :

```bash
droid mcp add firecrawl https://mcp.firecrawl.dev/v2/mcp --type http \
  --header "Authorization: Bearer your-api-key-here" --no-oauth
```

Remplacez `your-api-key-here` par votre clé API Firecrawl.

Pour exécuter plutôt le serveur en local, ajoutez-le en tant que serveur stdio :

```bash
droid mcp add firecrawl "npx -y firecrawl-mcp@3.33.2" --env FIRECRAWL_API_KEY=your-api-key-here
```

Vous pouvez également saisir `/mcp` dans Droid pour vérifier l&#39;état du serveur et afficher ses outils.

### 4. Terminé ! {#4-done}

Les outils Firecrawl sont désormais disponibles dans votre session Factory AI !

## Démo rapide {#quick-demo}

Essayez ceci dans Factory AI :

**Rechercher sur le Web :**

```
Recherchez les dernières notes de release de Next.js
```

**Extraire une page :**

```
Scrape firecrawl.dev et dis-moi ce que c'est
```

**Accéder à la documentation :**

```
Trouve et scrape la documentation de l'API Stripe pour les intentions de paiement
```

Factory utilisera automatiquement les outils de recherche et de scraping de Firecrawl pour obtenir les informations.
