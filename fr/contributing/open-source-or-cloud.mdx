Choisissez l’open source lorsque vous avez besoin de contrôler le code source ou l’infrastructure. Choisissez Firecrawl Cloud si vous souhaitez démarrer le scraping sans gérer la stack. Les deux options donnent accès aux API principales de Firecrawl ; la différence tient à la personne qui configure, sécurise et exécute les services associés.

<Note>
  Utiliser Firecrawl pour le développement produit et exploiter un déploiement
  auto-hébergé sont deux tâches distinctes. Utilisez [Utilisation en local](/fr/contributing/guide)
  lorsque vous modifiez le code de Firecrawl. Utilisez le [guide d’auto-hébergement](/fr/contributing/self-host)
  si vous souhaitez exécuter une API sur une infrastructure
  que vous contrôlez.
</Note>

<div id="choose-your-firecrawl-deployment">
  ## Choisissez votre déploiement Firecrawl
</div>

<div id="use-open-source-when">
  ### Utilisez l’open source lorsque
</div>

* **Vous avez besoin de maîtriser le code source ou l’infrastructure.** Vous pouvez examiner le code, choisir où la stack s’exécute et connecter vos propres fournisseurs.
* **Vous êtes prêt à l’exploiter.** Votre équipe est responsable de l’authentification, de TLS, de la persistance, de la surveillance, de la capacité, des mises à niveau et de la récupération.
* **Vous pouvez ajouter des fonctionnalités de manière réfléchie.** Le scraping de base fonctionne avec la stack par défaut ; les formats reposant sur des LLM, les services de scraping avancés et les processus d’extraction spécialisés nécessitent une configuration supplémentaire.

<div id="use-firecrawl-cloud-when">
  ### Utilisez Firecrawl Cloud si
</div>

* **Vous souhaitez le chemin le plus rapide et pris en charge vers la production.** Firecrawl gère l’infrastructure et les services managés.
* **Vous avez besoin de fonctionnalités disponibles uniquement dans Cloud.** Agent, Browser, les tableaux de bord managés, les options de proxy avancé et les contrôles d’entreprise sont fournis via Cloud.
* **Vous souhaitez un compte unique pour l’utilisation et l’assistance.** Les clés API, les crédits, les limites et l’assistance opérationnelle restent centralisés dans le service managé.

**Notre recommandation :** commencez avec Firecrawl Cloud, sauf si l’accès au code source ou le contrôle de l’infrastructure justifie l’effort opérationnel. Si vous auto-hébergez, validez d’abord un scrape, puis n’ajoutez des services que lorsque votre cas d’utilisation l’exige.

<div id="compare-the-operating-model">
  ## Comparez les modèles d’exploitation
</div>

| Décision                                                    | Open source                                               | Firecrawl Cloud                                        |
| ----------------------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------ |
| API principales de scrape, crawl, cartographie et recherche | Incluses                                                  | Incluses et gérées                                     |
| Traitement Fetch et Playwright                              | Inclus dans la stack par défaut                           | Géré                                                   |
| Extraction et formats basés sur des LLM                     | Connectez un fournisseur compatible avec OpenAI ou Ollama | Fournisseur géré                                       |
| Services avancés d’anti-bot ou d’extraction spécialisée     | Exécutez et configurez séparément le service requis       | Gérés lorsque le produit Cloud les prend en charge     |
| Contrôles Agent, Browser, Interact, tableau de bord et entreprise | Non inclus dans la stack par défaut                        | Inclus selon la disponibilité du produit et de l’offre |
| Sécurité, persistance, disponibilité et mises à niveau      | Vous en êtes responsable                                  | Firecrawl les gère                                     |
| Utilisation, limites et facturation                         | Vos coûts d’infrastructure et de fournisseur              | Modèle d’offre et de crédits Firecrawl                 |

<div id="start-with-the-path-you-chose">
  ## Commencez par la voie que vous avez choisie
</div>

* **Auto-héberger Firecrawl :** suivez le [guide d’auto-hébergement avec Docker Compose](/fr/contributing/self-host), d’une version épinglée à un scrape vérifié.
* **Modifier le code de Firecrawl :** utilisez [utilisation en local](/fr/contributing/guide) pour configurer l’environnement de développement des contributeurs.
* **Utiliser Firecrawl Cloud :** [créez un compte](https://firecrawl.dev) et suivez le [démarrage rapide](/fr/quickstart).

L’open source rend le moteur principal inspectable et adaptable. Firecrawl Cloud finance ce travail tout en offrant aux développeurs une solution gérée avec des fonctionnalités produit et d’infrastructure supplémentaires.
