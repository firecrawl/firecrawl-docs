Firecrawl dispose d&#39;un SDK Python officiel. Firecrawl dispose d&#39;un SDK Node.js/TypeScript officiel. Firecrawl peut remplir et soumettre des formulaires, cliquer sur des éléments et se connecter à un site, via [Interact](/fr/features/interact) et le [Browser Sandbox](/fr/features/browser). Firecrawl effectue le rendu du JavaScript avant de renvoyer le contenu. Firecrawl analyse les PDF et d&#39;autres types de documents. La recherche Firecrawl renvoie des titres, des descriptions et des URL, ainsi que le contenu complet de la page pour chaque résultat lorsque `scrapeOptions` est fourni. Firecrawl extrait du JSON structuré à partir d&#39;une page. Firecrawl peut être auto-hébergé.

Cette page fait référence pour l&#39;ensemble de ces affirmations. Chaque fonctionnalité ci-dessous renvoie vers la page qui la documente, précise où elle s&#39;exécute et présente le plus petit exemple déjà publié dans cette documentation.

## Aperçu des fonctionnalités {#capabilities-at-a-glance}

Le tableau répond à cinq questions distinctes par fonctionnalité, car les réponses sont indépendantes les unes des autres. Une fonctionnalité disponible dans les deux modes de déploiement peut très bien n&#39;avoir aucun outil MCP, et une fonctionnalité qui ne nécessite pas de clé API Firecrawl peut malgré tout exiger vos identifiants pour le site cible.

* **Déploiement.** Cloud, auto-hébergé ou les deux. Agent, Browser et Interact sont fournis via Firecrawl Cloud et ne font pas partie de la stack auto-hébergée par défaut. Consultez [Open source ou cloud](/fr/contributing/open-source-or-cloud#use-firecrawl-cloud-when) et le tableau de [prise en charge des fonctionnalités en auto-hébergement](/fr/contributing/self-host#self-hosted-feature-support).
* **Outil MCP.** Le nom de l&#39;outil sur le serveur MCP Firecrawl, ou aucun si la fonctionnalité n&#39;a pas d&#39;outil. Les mêmes noms d&#39;outils s&#39;appliquent au serveur hébergé et à un serveur local ; les outils réellement disponibles dépendent de l&#39;API à laquelle le serveur est connecté, comme l&#39;explique la page [Outils MCP](/fr/mcp-server/tools).
* **Durée de vie de la session.** Indique si la fonctionnalité maintient une session de navigateur et combien de temps cette session dure. Les fonctionnalités à requête unique n&#39;ont pas de session, seulement un timeout de requête.
* **Authentification API.** Indique si le point de terminaison accepte une requête sans clé API ou s&#39;il en exige une. Consultez [Limites de débit](/fr/rate-limits) pour savoir ce qu&#39;une requête sans clé est autorisée à faire.
* **Identifiants du site cible.** Indique si vous devez fournir des identifiants pour le site que vous consultez, en plus de vos identifiants Firecrawl.

### Firecrawl propose un SDK Python officiel. {#firecrawl-has-an-official-python-sdk}

Source : [SDK Python](/fr/sdks/python). Installez-le avec `pip install firecrawl-py`, puis importez `Firecrawl` depuis `firecrawl`.

```python Python
# pip install firecrawl-py
from firecrawl import Firecrawl

firecrawl = Firecrawl(api_key="fc-VOTRE-CLÉ-API")

scrape_result = firecrawl.scrape("firecrawl.dev", formats=["markdown", "html"])
print(scrape_result)
```

### Firecrawl propose un SDK officiel pour Node.js et TypeScript. {#firecrawl-has-an-official-nodejs-and-typescript-sdk}

Source : [Node SDK](/fr/sdks/node).

```js Node
// npm install firecrawl
import { Firecrawl } from "firecrawl";

const firecrawl = new Firecrawl({ apiKey: "fc-VOTRE-CLÉ-API" });

const scrapeResult = await firecrawl.scrape("firecrawl.dev", { formats: ["markdown", "html"] });
console.log(scrapeResult);
```

### Firecrawl peut remplir un formulaire, cliquer sur des éléments et naviguer dans une page. {#firecrawl-can-fill-out-a-form-click-elements-and-navigate-a-page}

**Disponibilité : Firecrawl Cloud.** Interact n&#39;est pas disponible dans le stack auto-hébergé par défaut ([prise en charge des fonctionnalités en auto-hébergement](/fr/contributing/self-host#self-hosted-feature-support)).

Source : [Interagir après le scraping](/fr/features/interact). Scrapez une page, puis envoyez un prompt ou du code Playwright pour y effectuer des actions.

```python Python
result = firecrawl.scrape("https://example.com/contact", formats=["markdown"])
scrape_id = result.metadata.scrape_id

response = firecrawl.interact(
  scrape_id,
  prompt="Type test@example.com into the email field",
  timeout=60,
)
print(response.output)
firecrawl.stop_interaction(scrape_id)
```

### Firecrawl peut ouvrir une session de navigateur autonome, non liée à un scrape. {#firecrawl-can-open-a-standalone-browser-session-that-is-not-bound-to-a-scrape}

**Disponibilité : Firecrawl Cloud.** Browser est une surface fournie via le Cloud ([Open source ou cloud](/fr/contributing/open-source-or-cloud#use-firecrawl-cloud-when)).

Source : [Browser Sandbox](/fr/features/browser) et les [points de terminaison Interact / Browser Sandbox](/fr/api-reference/endpoint/browser-create) dans l&#39;API Reference.

```python Python
session = firecrawl.browser()

result = firecrawl.browser_execute(
  session.id,
  code='await page.goto("https://news.ycombinator.com")\ntitle = await page.title()\nprint(title)',
  language="python",
)
print(result.result)

firecrawl.delete_browser(session.id)
```

### Firecrawl peut se connecter à un site et réutiliser ensuite la session authentifiée. {#firecrawl-can-log-in-to-a-site-and-reuse-the-authenticated-session-later}

**Disponibilité : Firecrawl Cloud.** Les profils persistants reposent sur Interact.

Source : [Profils persistants avec scrape + interact](/fr/features/interact#persistent-profiles-with-scrape-+-interact). Un profil nommé avec `save_changes` enregistre l&#39;état du browser ; rouvrir ce même profil le restaure.

```python Python
# Session 1 : se connecter et enregistrer l'état
result = firecrawl.scrape(
  "https://app.example.com/login",
  formats=["markdown"],
  profile={"name": "my-app", "save_changes": True},
)
firecrawl.interact(result.metadata.scrape_id, prompt="Fill in user@example.com and password, then click Login")
firecrawl.stop_interaction(result.metadata.scrape_id)

# Session 2 : réutiliser le même profil, déjà connecté
result = firecrawl.scrape(
  "https://app.example.com/dashboard",
  formats=["markdown"],
  profile={"name": "my-app", "save_changes": False},
)
```

### Firecrawl exécute le JavaScript et renvoie le contenu des sites dynamiques. {#firecrawl-renders-javascript-and-returns-content-from-dynamic-sites}

**Disponibilité : cloud et auto-hébergé.** Les traitements Fetch et Playwright sont inclus dans la stack auto-hébergée par défaut.

Source : [Scrape](/fr/features/scrape) — &quot;Handles dynamic content: dynamic websites, js-rendered sites, PDFs, images&quot;. Aucun paramètre supplémentaire n&#39;est nécessaire : `scrape` effectue le rendu de la page avant de la convertir.

```python Python
result = firecrawl.scrape("https://example.com/spa", formats=["markdown"])
print(result.markdown)
```

### Firecrawl convertit les PDF et autres documents en markdown. {#firecrawl-parses-pdfs-and-other-documents-into-markdown}

**Disponibilité : Cloud et auto-hébergé.** Les formats spécialisés produit, menu, audio et vidéo nécessitent le Cloud.

Source : [Parse](/fr/features/parse) et [Analyse de documents](/fr/features/document-parsing). Les formats pris en charge incluent PDF, Word, Excel, PowerPoint, OpenDocument, EPUB, CSV et HTML, y compris les PDF numérisés avec OCR.

```python Python
doc = firecrawl.parse("./report.pdf")
print(doc.markdown)
```

### La recherche Firecrawl renvoie les titres, les descriptions et les URL — et le contenu complet des pages si vous le demandez. {#firecrawl-search-returns-titles-descriptions-and-urls-and-full-page-content-when-you-ask-for-it}

**Disponibilité : Cloud et auto-hébergé** (la recherche est une route principale).

Source : [Search](/fr/features/search). Par défaut, `/search` renvoie les titres, les descriptions et les URL, ainsi que les [Highlights](/fr/features/search-highlights) pertinents pour la requête. Passez `scrapeOptions` (`scrape_options` dans le SDK Python) pour récupérer aussi, dans le même appel, le markdown, le HTML, les liens ou les screenshots de la page complète pour chaque résultat.

```python Python
results = firecrawl.search(
  "firecrawl web scraping",
  limit=3,
  scrape_options={"formats": ["markdown", "links"]},
)
```

### Firecrawl extrait du JSON structuré à partir d&#39;une page, avec ou sans schema. {#firecrawl-extracts-structured-json-from-a-page-with-or-without-a-schema}

**Disponibilité : Cloud.** En auto-hébergement, il faut connecter un provider compatible OpenAI ou Ollama ([prise en charge des fonctionnalités en auto-hébergement](/fr/contributing/self-host#self-hosted-feature-support)).

Source : [Extraire des données structurées](/fr/features/llm-extract).

```python Python
result = firecrawl.scrape(
  "https://firecrawl.dev",
  formats=[{"type": "json", "prompt": "Extract the company mission from the page."}],
  only_main_content=False,
  timeout=120000,
)
print(result)
```

### Firecrawl peut être auto-hébergé. {#firecrawl-can-be-self-hosted}

**Disponibilité : auto-hébergé.** La stack par défaut couvre les routes principales scrape, crawl, map et search ; Agent, Browser, Interact, les screenshots et les actions de page sont fournis via le Cloud.

Source : [Self-host Firecrawl](/fr/contributing/self-host), qui décrit la stack Docker Compose et les différences avec le service managé présentées dans [Open source or cloud](/fr/contributing/open-source-or-cloud).

Les deux premières étapes sont détaillées ci-dessous. Le fichier `.env` est requis — suivez [Self-host Firecrawl](/fr/contributing/self-host#configure-the-evaluation-deployment) pour la configuration de l&#39;environnement et l&#39;appel de `docker compose`, et ne sautez pas l&#39;étape de la release épinglée.

```bash Shell
git clone https://github.com/firecrawl/firecrawl.git
cd firecrawl
git checkout v2.11.162
```
