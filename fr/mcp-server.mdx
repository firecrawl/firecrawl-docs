Firecrawl MCP permet aux clients IA d&#39;accéder à des données web en temps réel via le Model Context Protocol. Il est disponible sous la forme d&#39;un service hébergé ou d&#39;un serveur local open source.

<div id="start-here">
  ## Commencez ici
</div>

Choisissez le mode de connexion adapté à l’environnement dans lequel Firecrawl sera exécuté. Les routes hébergées sont des URL sans identifiants : les identifiants doivent être fournis via le flux OAuth ou un en-tête Authorization, jamais dans l’URL elle-même.
