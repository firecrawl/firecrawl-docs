<div id="add-an-api-key">
  ## Ajouter une clé API
</div>

[Créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys), puis envoyez-la comme jeton Bearer :

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

Configurez la clé via une variable d’environnement ou le stockage sécurisé de votre client, jamais dans l’URL MCP.

<Note>
  Il s’agit d’une URL de serveur pour votre client MCP, et non d’une page à ouvrir directement dans un navigateur. Les connexions avec authentification utilisent plutôt `https://mcp.firecrawl.dev/v2/mcp-oauth`, et votre client lance le flux du navigateur.
</Note>
