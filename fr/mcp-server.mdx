title: Connecter Firecrawl avec MCP
description: Choisissez un accès sans clé, une connexion OAuth ou une clé API pour votre client MCP.
sidebarTitle: Configuration MCP

Choisissez la configuration selon le fonctionnement de la connexion. Vous n'avez pas à décider si vous êtes un humain ou un agent.

<Card title="Essayer immédiatement" icon="bolt" href="/fr/mcp-server/agent-mcp">
  Utilisez Search, Scrape et Parse sans compte ni clé. Les limites sont partagées par adresse IP publique.
</Card>

<Card title="Se connecter avec OAuth" icon="right-to-bracket" href="/fr/mcp-server/human-mcp">
  Connectez-vous depuis un client interactif, choisissez une équipe et approuvez la connexion.
</Card>

<Card title="Utiliser une clé API" icon="key" href="/fr/mcp-server/agent-mcp">
  Configurez un accès stable pour les agents, la CI et les services backend sans placer le secret dans le chat ou le code source.
</Card>

Consultez les [outils disponibles](/fr/mcp-server/tools) ou [exécutez MCP en local](/fr/mcp-server/local).
