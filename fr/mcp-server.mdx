## Connexion {#sign-in}

Pointez votre client vers l&#39;OAuth serveur URL. Votre client ouvre une fenêtre de Browser dans laquelle vous vous connectez à Firecrawl et approuvez une équipe :

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

Aucune clé API ni aucun header n&#39;est nécessaire. Consultez et révoquez les connexions depuis les [MCP settings](https://www.firecrawl.dev/app/settings?tab=mcp).

<Note>
  Il s&#39;agit d&#39;une URL de serveur destinée à votre client MCP, et non d&#39;une page à ouvrir directement dans un Browser. Les connexions par clé API utilisent quant à elles `https://mcp.firecrawl.dev/v2/mcp` avec un bearer token ; voir [Ajouter une clé API](/fr/mcp-server/keyless#add-an-api-key).
</Note>
