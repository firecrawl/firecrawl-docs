Choisissez la configuration correspondant au mode d&#39;exécution de la connexion. Vous n&#39;avez pas besoin de déterminer si vous êtes un humain ou un agent.

L&#39;URL du serveur en mode hébergé sans clé et avec clé API est :

```text
https://mcp.firecrawl.dev/v2/mcp
```

<Note>
  Il s’agit de l’URL d’un serveur pour votre client MCP, et non d’une page à ouvrir directement dans un Browser. OAuth utilise une URL de serveur différente, et votre client lance son flux de connexion dans le Browser.
</Note>

Si vous choisissez une clé API, ne l’incluez jamais dans une URL MCP, une conversation avec un agent ou un fichier de projet validé. Configurez-la via une variable d’environnement ou le stockage des secrets de votre client.

<div id="fix-a-broken-connection">
  ## Corriger une connexion défaillante
</div>

Utilisez cette section lorsqu&#39;une erreur Firecrawl mentionne `KEYLESS_QUOTA_EXHAUSTED`, `KEYLESS_TOOL_NOT_AVAILABLE`, `KEYLESS_ACCESS_NOT_AVAILABLE`, `KEYLESS_ELIGIBILITY_UNAVAILABLE`, `CREDENTIAL_INVALID`, `OAUTH_CONNECTION_INVALID` ou des identifiants « non valides ou révoqués ».

* **Limite sans clé atteinte :** attendez le délai `retry_after_seconds` indiqué par l&#39;erreur (s&#39;il est présent), ou demandez à l&#39;opérateur humain de se connecter via OAuth ou de configurer une clé API. Search, Scrape et Parse restent disponibles une fois la limite réinitialisée.
* **Accès sans clé indisponible :** pour `KEYLESS_ELIGIBILITY_UNAVAILABLE`, réessayez après le délai indiqué. Si le problème persiste ou si l&#39;erreur est `KEYLESS_ACCESS_NOT_AVAILABLE`, demandez à l&#39;opérateur humain de se connecter via OAuth ou de configurer une clé API.
* **Outil non disponible sans clé (`KEYLESS_TOOL_NOT_AVAILABLE`) :** l&#39;outil existe, mais n&#39;est pas disponible via l&#39;accès sans clé. Connectez-vous via OAuth ou configurez une clé API pour l&#39;utiliser ; Search, Scrape et Parse continuent de fonctionner sans clé.
* **Clé API non valide ou révoquée :** l&#39;opérateur humain ou système doit remplacer la clé dans la configuration existante du serveur, en dehors de la conversation avec l&#39;agent.
* **Connexion OAuth non valide sur `/v2/mcp` :** ajoutez une clé API à ce serveur existant ou remplacez son URL par `https://mcp.firecrawl.dev/v2/mcp-oauth`, puis connectez-vous via le client. N&#39;ouvrez pas cette URL directement dans un navigateur.
* **Connexion OAuth non valide sur `/v2/mcp-oauth` :** reconnectez-vous via le processus de connexion au compte du client.

Après toute modification des identifiants ou de l&#39;URL du serveur, conservez une seule entrée de serveur `firecrawl`, démarrez une nouvelle session client et réessayez. Consultez [Connexion OAuth](/fr/mcp-server/oauth#switch-an-existing-keyless-connection) ou [configuration de la clé API](/fr/mcp-server/keyless-api-key#add-an-api-key) pour connaître les étapes exactes.
