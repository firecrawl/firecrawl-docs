Firecrawl Government Index permet de rechercher parmi les lois, règlements, codes, décisions de justice et autres publications gouvernementales américaines, au niveau fédéral, des États et local. Il aide un agent à trouver le texte juridique ou réglementaire qui sous-tend une question. Les résultats classés peuvent également inclure des versions historiques, des textes de projets de loi, des orientations publiées par des agences et des reproductions par des tiers ; un résultat ne garantit pas qu&#39;il s&#39;agit du droit actuellement en vigueur.

* Trouver le règlement qui impose une exigence d&#39;étiquetage, de déclaration ou de licence
* Consulter la loi ou l&#39;article de code sur lequel repose une question de conformité
* Retrouver une décision de justice qui interprète une règle
* Récupérer la publication d&#39;une agence gouvernementale sur un sujet donné

## Choisir et vérifier les sources {#choose-and-verify-sources}

Indiquez la juridiction, l&#39;agence ou la référence, ainsi que la date pertinente lorsqu&#39;elle est connue. Demandez la juridiction si elle manque avant d&#39;identifier la règle applicable. Si l&#39;utilisateur fournit l&#39;URL d&#39;une source, lisez-la directement avec [`scrape`](/fr/features/scrape) au lieu de relancer une recherche.

Avant de répondre à une question sur le droit en vigueur, vérifiez l&#39;émetteur de la source, sa juridiction, son état (adopté ou en vigueur) ainsi que sa version. Consultez la source derrière un résultat lorsque le snippet ne suffit pas à établir la règle. Vérifiez l&#39;état d&#39;un projet de loi et sa date d&#39;entrée en vigueur plutôt que de les déduire de son titre ou de son résumé. Citez l&#39;article déterminant et le passage qui l&#39;étaye, et ne mentionnez une page, un article ou une date d&#39;entrée en vigueur que si les éléments disponibles le confirment.

L&#39;index porte principalement sur des documents américains. Utilisez la recherche générale pour les autres juridictions ou lorsque l&#39;état de couverture est incomplet ; l&#39;absence de résultats ne prouve pas qu&#39;aucune loi applicable n&#39;existe.

## Rechercher dans le Government Index {#search-the-government-index}

Envoyez une question en langage naturel et obtenez des résultats classés par pertinence, issus de sources juridiques et réglementaires. Les résultats sont renvoyés dans le groupe standard `web`, chacun avec `url`, `title`, `description` et `position`, soit la même structure qu&#39;un résultat web de [`/search`](/fr/features/search).

Les recherches dans le Government Index sont gratuites et ne consomment aucun crédit, avec ou sans conservation zéro des données. Aucune clé API n&#39;est nécessaire pour démarrer ; ajoutez-en une pour bénéficier de limites de débit plus élevées.

Les exemples de SDK utilisent les méthodes Gov disponibles dans `firecrawl@4.44.1` et `firecrawl-py==4.49.2`. Définissez `FIRECRAWL_API_KEY` pour les exemples de SDK authentifiés ; utilisez les exemples HTTP pour les requêtes sans clé. Si la méthode est absente du client installé, mettez à niveau le SDK. En Python, appelez `gov_search` sur l&#39;instance initialisée du client : l&#39;introspection de la seule classe peut ne pas lister les méthodes définies lors de l&#39;initialisation.

<CodeGroup>
  ```bash cURL
  # Aucune clé API nécessaire pour démarrer ; ajoutez -H "Authorization: Bearer $FIRECRAWL_API_KEY" pour des limites de débit plus élevées :
  curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
  ```

  ```bash CLI
  firecrawl gov "food labeling requirements for allergens" --limit 10
  ```

  ```python Python
  import os
  from firecrawl import Firecrawl

  client = Firecrawl(api_key=os.environ["FIRECRAWL_API_KEY"])

  result = client.gov_search("food labeling requirements for allergens", k=10)
  print(result)
  ```

  ```js Node
  import { Firecrawl } from "firecrawl";

  const client = new Firecrawl({
    apiKey: process.env.FIRECRAWL_API_KEY,
  });

  const result = await client.govSearch(
    "food labeling requirements for allergens",
    {
      k: 10,
    },
  );
  console.log(result);
  ```
</CodeGroup>

`POST` est également disponible sur le même chemin, avec les mêmes champs transmis dans un corps JSON :

```bash cURL
# Aucune clé API n'est nécessaire pour démarrer ; ajoutez -H "Authorization: Bearer $FIRECRAWL_API_KEY" pour bénéficier de limites de débit plus élevées :
curl -X POST https://api.firecrawl.dev/v2/search/gov \
  -H "Content-Type: application/json" \
  -d '{
    "query": "food labeling requirements for allergens",
    "k": 10
  }'
```

`query` est obligatoire. `k` définit le nombre de résultats renvoyés, de 1 à 100 (10 par défaut). Tout champ inconnu est rejeté avec une erreur `400`. Consultez la [référence de la recherche dans le Government Index](/fr/api-reference/endpoint/gov-search) pour le schéma complet de la requête et de la réponse.

La même recherche est également disponible sur [`/search`](/fr/features/search#gov-category-search) avec `categories: ["gov"]`, les résultats étant renvoyés dans `data.web`.
