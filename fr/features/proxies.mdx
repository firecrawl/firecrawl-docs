Firecrawl propose différents types de proxy pour vous aider à scraper des sites web présentant des niveaux de complexité variés. Le type de proxy peut être spécifié à l&#39;aide du paramètre `proxy`.

> Par défaut, Firecrawl achemine toutes les requêtes via des proxy afin d’assurer la fiabilité et l’accessibilité, même si vous ne spécifiez pas de type de proxy ni de localisation.

<div id="how-to-specify-proxy-location">
  ## Comment spécifier la localisation du proxy
</div>

Vous pouvez demander une localisation de proxy spécifique en définissant le paramètre `location.country` dans votre requête. Par exemple, pour utiliser un proxy allemand, définissez `location.country` sur `DE`.

Pour plus de détails, consultez la [référence de l’API pour `location.country`](https://docs.firecrawl.dev/api-reference/endpoint/scrape#body-location).

<div id="proxy-types">
  ## Types de proxies
</div>

<Warning>
  Le paramètre `proxy` est obsolète. Nous recommandons `auto` — la valeur par défaut — qui permet à Firecrawl de gérer la sélection du proxy pour vous.
</Warning>

* **basic** : Proxies pour le scraping de la plupart des sites.
* **enhanced** : Proxies avancés pour le scraping de sites complexes tout en préservant la confidentialité. [En savoir plus sur le mode avancé →](/fr/features/enhanced-mode)
* **auto** : Recommandé. Firecrawl réessaiera automatiquement le scraping avec des proxies avancés si le proxy basic échoue.
