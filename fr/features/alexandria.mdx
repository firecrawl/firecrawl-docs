Alexandria donne aux agents accès à des données structurées via Firecrawl. Découvrez un outil, inspectez ses entrées, puis exécutez-le. La découverte est gratuite ; l&#39;exécution consomme les crédits indiqués sur l&#39;outil.

[Parcourir les providers](https://www.firecrawl.dev/app/alexandria) · [Gérer les conditions des providers](https://www.firecrawl.dev/app/settings?tab=data-sources)

## Conçu pour les agents {#built-for-agents}

Installez le [CLI](/fr/sdks/cli) ou connectez le [serveur MCP](/fr/mcp-server).

<Tabs>
  <Tab title="CLI Firecrawl">
    ```bash
    # Trouvez des outils en plus des résultats web.
    firecrawl search "podcast conversations about AI agents" --sources web,alexandria --domain-tools --limit 2

    # Inspectez les entrées et la tarification.
    firecrawl find-tools --providers particle --level tools --expand options,response

    # Exécutez l'outil.
    firecrawl scrape particle/podcasts/episodes/search --options '{"keyword_search":"AI agents","limit":2}'
    ```

    Installez-le avec `npm install -g firecrawl-cli` et connectez-vous avec `firecrawl login`.
  </Tab>

  <Tab title="MCP">
    Demandez à votre agent : « Trouve les outils de podcast de Particle, inspecte les entrées et la tarification de la recherche d&#39;épisodes, puis trouve des conversations sur les agents IA. »

    L&#39;agent utilise `firecrawl_search` pour découvrir les outils, `firecrawl_find_tools` pour les inspecter et `firecrawl_scrape` pour les exécuter.
  </Tab>
</Tabs>

## Utiliser Alexandria depuis les SDK et l&#39;API {#use-it-from-the-sdks-and-api}

<Steps>
  <Step title="Trouver le bon outil">
    Décrivez votre besoin. Alexandria renvoie les outils pertinents en plus de vos résultats web.

    <CodeGroup>
      ```javascript JavaScript
      const result = await firecrawl.search(
        "podcast conversations about AI agents",
        {
          sources: ["web", "alexandria"],
          limit: 2,
        },
      );
      ```

      ```python Python
      result = firecrawl.search(
          "podcast conversations about AI agents",
          sources=["web", "alexandria"],
          limit=2,
      )
      ```

      ```bash cURL
      curl https://api.firecrawl.dev/v2/search \
        -H "Authorization: Bearer $FIRECRAWL_API_KEY" \
        -H "Content-Type: application/json" \
        -d '{
        "query": "podcast conversations about AI agents",
        "sources": [
          "web",
          "alexandria"
        ],
        "limit": 2
      }'
      ```
    </CodeGroup>

    Les résultats contiennent des pages `web` et des `tools` classés par pertinence. Chaque outil précise son provider, sa fonctionnalité, ses entrées, son contrat de response et son prix.
  </Step>

  <Step title="Vérifier ce dont il a besoin">
    Consultez les `options`, la `response` et le prix d&#39;exécution de l&#39;outil sélectionné avant de l&#39;appeler. Voir [Find Tools](#find-tools) pour plus de détails.
  </Step>

  <Step title="Obtenir les données">
    Utilisez `scrape` pour appeler l&#39;outil avec les entrées définies dans son contrat. Indiquez le provider et la fonctionnalité sous `alexandria` ; aucune URL de page n&#39;est nécessaire.

    <CodeGroup>
      ```javascript JavaScript
      const episodes = await firecrawl.scrape({
        alexandria: {
          provider: "particle",
          capability: "podcasts/episodes/search",
          options: {
            semantic_search: "AI agents",
            limit: 2,
          },
        },
      });

      console.log(episodes.alexandria[0].data);
      ```

      ```python Python
      episodes = firecrawl.scrape(
          alexandria={
              "provider": "particle",
              "capability": "podcasts/episodes/search",
              "options": {
                  "semantic_search": "AI agents",
                  "limit": 2,
              },
          },
      )

      print(episodes.alexandria[0].data)
      ```

      ```bash cURL
      REQUEST_ID="$(uuidgen)"

      curl https://api.firecrawl.dev/v2/scrape \
        -H "Authorization: Bearer $FIRECRAWL_API_KEY" \
        -H "Content-Type: application/json" \
        -H "x-request-id: $REQUEST_ID" \
        -d '{
        "alexandria": {
          "provider": "particle",
          "capability": "podcasts/episodes/search",
          "options": {
            "semantic_search": "AI agents",
            "limit": 2
          }
        }
      }'
      ```
    </CodeGroup>

    Lisez le résultat dans `episodes.alexandria[0].data`. Vérifiez la présence d&#39;erreurs dans chaque résultat d&#39;outil avant d&#39;en exploiter les données. Les réponses HTTP brutes encapsulent le résultat du SDK dans `data`.
  </Step>
</Steps>

## Find Tools {#find-tools}

Utilisez `findTools` / `find_tools` pour parcourir les providers et inspecter leurs outils gratuitement. Suivez la requête `next` d&#39;un élément pour obtenir plus de détails ; le `next` de premier niveau pagine le catalogue.

<CodeGroup>
  ```javascript JavaScript
  const catalogue = await firecrawl.findTools({
    providers: ["particle"],
    limit: 2,
  });

  // Chaque requête next dévoile une autre partie du catalogue.
  const next = catalogue.items[0]?.next;
  if (next) {
    const details = await firecrawl.scrape({ alexandria: next });
    console.log(details.alexandria[0].data);
  }
  ```

  ```python Python
  catalogue = firecrawl.find_tools(providers=["particle"], limit=2)

  if catalogue.items and catalogue.items[0].get("next"):
      details = firecrawl.scrape(alexandria=catalogue.items[0]["next"])
      print(details.alexandria[0].data)
  ```
</CodeGroup>

## Tarification et accès {#pricing-and-access}

* **Découverte des outils :** gratuite. Utilisez `sources: ["alexandria"]` pour les outils uniquement, ou `["web", "alexandria"]` pour inclure les résultats web payants.
* **Exécution :** facturée au prix indiqué de l&#39;outil.
* **Conditions du provider :** une erreur `THIRD_PARTY_DATA_TERMS_REQUIRED` contient `requiresAction.url`. Un administrateur de l&#39;organisation doit y consulter et accepter les conditions. Les agents doivent obtenir une autorisation explicite de l&#39;utilisateur avant d&#39;accepter ces conditions.

<AccordionGroup>
  <Accordion title="Trouver des outils pour un site web">
    Ajoutez `domainTools: true` à une recherche ou à un scrape d&#39;URL classique pour inclure les outils associés au site web. La mise en correspondance est gratuite ; la recherche web ou le scrape de page est facturé normalement. Les résultats incluent `matchedBy` et `matchedUrls`.

    La recherche active la correspondance par domaine par défaut lorsque `sources` inclut `alexandria` ; définissez `domainTools: false` pour la désactiver. Pour les scrapes d&#39;URL, la correspondance par domaine est désactivée par défaut.
  </Accordion>
</AccordionGroup>
