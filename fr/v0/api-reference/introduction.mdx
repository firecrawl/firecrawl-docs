<div id="base-url">
  ## URL de base {#base-url}
</div>

Toutes les requêtes contiennent l’URL de base suivante :

```bash
https://api.firecrawl.dev 
```

## Authentication {#authentication}

Pour l&#39;authentification, il est nécessaire d&#39;inclure un header Authorization. Ce header doit contenir `Bearer fc_123456789`, où `fc_123456789` correspond à votre clé API.

```bash
Authorization: Bearer fc_123456789
```

​

## Codes de réponse {#response-codes}

Firecrawl utilise les codes d&#39;état HTTP standard pour indiquer le résultat de vos requêtes.

En règle générale, les codes d&#39;état HTTP 2xx signalent un succès, les codes 4xx des erreurs liées à l&#39;utilisateur et les codes 5xx des problèmes d&#39;infrastructure.

| État | Description                                |
| ---- | ------------------------------------------ |
| 200  | La requête a abouti.                       |
| 400  | Vérifiez l&#39;exactitude des paramètres.  |
| 401  | La clé API n&#39;a pas été fournie.        |
| 402  | Paiement requis                            |
| 404  | La ressource demandée est introuvable.     |
| 429  | La limite de débit a été dépassée.         |
| 5xx  | Indique une erreur serveur côté Firecrawl. |

Consultez la section Codes d&#39;erreur pour une explication détaillée de toutes les erreurs d&#39;API possibles.

​

<div id="rate-limit">
  ## Limite de débit {#rate-limit}
</div>

L’API Firecrawl impose une limite de débit afin d’assurer la stabilité et la fiabilité du service. Cette limite s’applique à tous les points de terminaison et se base sur le nombre de requêtes effectuées dans une période donnée.

Si vous dépassez cette limite, vous recevrez un code de réponse 429.
