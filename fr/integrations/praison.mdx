## Vue d’ensemble {#overview}

Praison AI peut utiliser Firecrawl comme outil pour permettre aux agents de scraper des pages web et d’utiliser le contenu nettoyé lors de leurs exécutions.

## Démarrage rapide {#quick-start}

1. Installez l’extra `tools` :

```bash
pip install "praisonai[tools]"
```

2. Configurez `FIRECRAWL_API_KEY` pour Firecrawl Cloud
3. Transmettez un outil Firecrawl à votre agent :

```python
from praisonaiagents import Agent
from praisonai_tools import FirecrawlTool

agent = Agent(
    name="WebScraper",
    instructions="You are a web scraping assistant. Use Firecrawl to extract content.",
    tools=[FirecrawlTool()],
)

print(agent.chat("Scrape the content from https://praison.ai/docs"))
```

## Ce que vous pouvez faire {#what-you-can-do}

| Fonctionnalité | Cas d’utilisation                                                                            |
| -------------- | -------------------------------------------------------------------------------------------- |
| **Scrape**     | Récupérer le contenu nettoyé d’une page dans le contexte de l’agent (`FirecrawlTool.scrape`) |
| **Crawl**      | Collecter les pages d’un site (`FirecrawlTool.crawl(url, limit=10)`)                         |
