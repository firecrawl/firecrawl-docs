<Note>
  **Application officielle Pipedream :** [pipedream.com/apps/firecrawl](https://pipedream.com/apps/firecrawl/)

  Ajoutez des étapes Firecrawl aux workflows Pipedream déclenchés par des planifications, des webhooks ou d’autres applications.
</Note>

<div id="overview">
  ## Vue d’ensemble
</div>

Utilisez l’application Firecrawl pour Pipedream afin de scraper des pages, crawl des sites, effectuer une cartographie des URL et extraire des données structurées dans vos workflows.

<div id="quick-start">
  ## Démarrage rapide
</div>

1. Ouvrez l&#39;[application Firecrawl sur Pipedream](https://pipedream.com/apps/firecrawl/)
2. Connectez votre clé API Firecrawl
3. Ajoutez des actions Firecrawl à un workflow nouveau ou existant

<div id="what-you-can-do">
  ## Ce que vous pouvez faire
</div>

| Fonctionnalité | Cas d&#39;utilisation                                                                       |
| -------------- | ------------------------------------------------------------------------------------------- |
| **Scrape**     | Récupérer le contenu d&#39;une page lorsqu&#39;un webhook ou une planification se déclenche |
| **Crawl**      | Démarrer un crawl de plusieurs pages (interroger avec Get Crawl Data)                       |
| **Recherche**  | Découvrir des sources avant les étapes suivantes                                            |
| **Cartographie** | Lister les URL d&#39;un site, éventuellement filtrées par un terme de recherche             |
| **Extract**    | Récupérer des données structurées à partir d&#39;une ou plusieurs URL                       |
