## Vue d’ensemble {#overview}

Utilisez l’application Firecrawl pour Pipedream afin de scraper des pages, crawl des sites, effectuer une cartographie des URL et extraire des données structurées dans vos workflows.

## Démarrage rapide {#quick-start}

1. Ouvrez l&#39;[application Firecrawl sur Pipedream](https://pipedream.com/apps/firecrawl/)
2. Connectez votre clé API Firecrawl
3. Ajoutez des actions Firecrawl à un workflow nouveau ou existant

## Ce que vous pouvez faire {#what-you-can-do}

| Action                    | Cas d’utilisation                                                                                                                       |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **Extraction d’une page**     | Récupérer le contenu d’une page lorsqu’un webhook ou une planification se déclenche                                                     |
| **Crawler une URL**       | Démarrer une tâche d’exploration sur plusieurs pages (à interroger avec **Obtenir les données du crawl**)                               |
| **Recherche**             | Identifier des sources avant les étapes suivantes                                                                                       |
| **Cartographier une URL** | Lister les URL d’un site, avec un filtre facultatif par terme de recherche                                                              |
| **Extraire des données**  | Récupérer des données structurées à partir d’une ou plusieurs URL (vérifiez une tâche en cours avec **Obtenir l’état de l’extraction**) |
