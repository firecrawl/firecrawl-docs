</Note>

<div id="overview">
  ## Vue d’ensemble
</div>

Composio propose Firecrawl sous forme de kit d’outils, permettant à vos agents d’effectuer des recherches, de scraper, de crawler, de cartographier et d’extraire des données sans intégration d’API personnalisée. Le kit d’outils s’authentifie à l’aide d’une clé API Firecrawl.

<div id="quick-start">
  ## Démarrage rapide
</div>

1. Connectez Firecrawl dans le [tableau de bord Composio](https://dashboard.composio.dev) à l’aide de votre clé API Firecrawl
2. Consultez les outils disponibles dans la [documentation du kit d’outils Firecrawl](https://docs.composio.dev/toolkits/firecrawl)
3. Appelez les outils Firecrawl depuis vos agents ou workflows propulsés par Composio

<div id="what-you-can-do">
  ## Ce que vous pouvez faire
</div>

| Fonctionnalité         | Cas d’utilisation                                             |
| ---------------------- | ------------------------------------------------------------- |
| **Recherche**          | Découvrir des sources avant l’extraction                      |
| **Scrape**             | Récupérer le contenu d’une page pour le contexte d’un agent   |
| **Extraction par lot** | Extraire de nombreuses URL en une seule tâche                 |
| **Crawl**              | Collecter des données de plusieurs pages d’un site            |
| **Cartographie**       | Lister les URL d’un site avant de décider lesquelles extraire |
| **Extract**            | Renvoyer des champs structurés plutôt que du texte brut       |
