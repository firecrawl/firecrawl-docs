## Présentation {#overview}

[Neuron AI](https://neuron-ai.dev) est un framework agentique pour PHP. Il intègre un kit d’outils Firecrawl qui permet à un agent Neuron d’effectuer des recherches sur le web et de lire n’importe quelle page sous forme de Markdown propre au cours d’une exécution.

## Démarrage rapide {#quick-start}

1. Installez Neuron AI 4.1.3 ou une version ultérieure :

```bash
composer require neuron-core/neuron-ai:^4.1.3
```

2. Obtenez une clé API depuis votre [tableau de bord Firecrawl](https://www.firecrawl.dev/app/api-keys) et définissez-la dans `FIRECRAWL_API_KEY`
3. Ajoutez le kit d’outils à votre agent :

```php
namespace App\Neuron;

use NeuronAI\Agent\Agent;
use NeuronAI\Tools\Toolkits\Firecrawl\FirecrawlToolkit;

class ResearchAgent extends Agent
{
    ...

    protected function tools(): array
    {
        return [
            FirecrawlToolkit::make(
                key: getenv('FIRECRAWL_API_KEY')
            ),
        ];
    }
}
```

## Outils {#tools}

| Outil                 | Nom vu par l&#39;agent | Rôle                                                                                                                       |
| --------------------- | ---------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `FirecrawlSearchTool` | `web_search`           | Effectue une recherche sur le web, ou dans les actualités si l&#39;agent le demande, avec une plage temporelle facultative |
| `FirecrawlScrapeTool` | `url_reader`           | Renvoie le contenu principal d&#39;une page au format Markdown                                                             |

Vous pouvez aussi ajouter un seul de ces outils, par exemple `FirecrawlSearchTool::make(key: getenv('FIRECRAWL_API_KEY'))`.

## Obtenir le contenu de la page avec chaque résultat de recherche {#get-page-content-with-each-search-result}

Par défaut, une recherche renvoie le titre, l&#39;URL et la description de chaque résultat. Si vous passez `scrapeOptions`, chaque résultat inclut aussi la page complète au format Markdown : l&#39;agent n&#39;a donc pas besoin d&#39;un second appel pour la lire :

```php
use NeuronAI\Tools\Toolkits\Firecrawl\FirecrawlSearchTool;

FirecrawlSearchTool::make(key: getenv('FIRECRAWL_API_KEY'))->withOptions([
    'limit' => 5,
    'scrapeOptions' => [
        'formats' => ['markdown'],
        'onlyMainContent' => true,
    ],
]);
```

`withOptions()` remplace les valeurs par défaut et accepte tous les [paramètres de recherche](/fr/api-reference/endpoint/search). La requête de recherche est toujours fournie par l&#39;agent.
