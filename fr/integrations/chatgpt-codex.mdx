## Installer Firecrawl {#install-firecrawl}

<Steps>
  <Step title="Ouvrir le plugin Firecrawl">
    Cliquez sur **Add to ChatGPT &amp; Codex** ci-dessus pour ouvrir la fiche officielle de Firecrawl dans le répertoire de plugins partagé. Dans ChatGPT &amp; Codex, vous pouvez aussi ouvrir **Plugins** et rechercher **Firecrawl**.
  </Step>

  <Step title="Installer et connecter">
    Sélectionnez **Install**, puis connectez-vous à Firecrawl et autorisez la connexion lorsque vous y êtes invité.
  </Step>

  <Step title="Démarrer une nouvelle conversation">
    Démarrez une nouvelle conversation dans ChatGPT &amp; Codex pour que le plugin puisse être chargé. Demandez-lui ensuite d&#39;utiliser Firecrawl à l&#39;aide du prompt ci-dessous.
  </Step>
</Steps>

Le plugin inclut les outils et les skills Firecrawl. Inutile de configurer un serveur MCP ou d&#39;installer les skills séparément.

## Essayez-le dans ChatGPT &amp; Codex {#try-it-in-chatgpt-codex}

Demandez à Firecrawl de trouver et de lire des sources récentes :

```text
Utilise Firecrawl pour trouver les dernières notes de version de Next.js.
Lis les sources officielles et résume les nouveautés, liens à l'appui.
```

## Si Firecrawl n&#39;apparaît pas {#if-firecrawl-does-not-appear}

* Démarrez une nouvelle conversation ou redémarrez ChatGPT &amp; Codex après avoir installé le plugin.
* Vérifiez que Firecrawl est bien installé et activé dans **Plugins**.
* Si la connexion n&#39;a pas abouti, ouvrez le plugin et reconnectez votre compte Firecrawl.
