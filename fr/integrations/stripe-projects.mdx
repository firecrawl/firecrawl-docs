<Note>
  **Documentation officielle Stripe :** [docs.stripe.com/projects](https://docs.stripe.com/projects) · [Firecrawl dans l&#39;annuaire des providers](https://projects.dev/providers/)

  Firecrawl est un provider Stripe Projects. Ajoutez-le à n&#39;importe quel projet avec `stripe projects add firecrawl/api`.
</Note>

<div id="overview">
  ## Aperçu
</div>

[Stripe Projects](https://projects.dev) provisionne des services tiers depuis le terminal et synchronise leurs credentials dans votre fichier `.env`. Firecrawl fait partie des providers disponibles : une seule commande crée un compte Firecrawl, inscrit une clé API dans votre projet et vous permet de choisir une offre. Les offres payantes sont facturées via le mode de paiement associé à votre compte Stripe.

| Ce que vous obtenez | Détail                                                                                                                                            |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Compte**          | Un compte Firecrawl rattaché à l&#39;e-mail de votre compte Stripe. Si cet e-mail est déjà associé à un compte Firecrawl, celui-ci est réutilisé. |
| **clé API**         | Une clé API de workspace inscrite dans votre `.env`. Une seule key couvre l&#39;ensemble des points de terminaison Firecrawl.                     |
| **Offre**           | Free par défaut. Passez à Hobby, Standard ou Growth, en mensuel ou en annuel, depuis la CLI.                                                      |
| **Tableau de bord** | `stripe projects open firecrawl` vous connecte au tableau de bord Firecrawl.                                                                      |

<div id="quick-start">
  ## Démarrage rapide
</div>

```bash
stripe plugin install projects
stripe projects init
stripe projects add firecrawl/api --name firecrawl
stripe projects env --pull
```

`--name firecrawl` définit le nom local de la ressource, qui devient le préfixe des variables écrites par la CLI. Avec cette option, la clé est enregistrée dans `FIRECRAWL_API_KEY`, que les [SDKs](/fr/sdks/overview) et la [CLI](/fr/sdks/cli) Firecrawl lisent automatiquement. Sans elle, la ressource s&#39;appelle `firecrawl-api` et la clé est enregistrée dans `FIRECRAWL_API_API_KEY`.

La CLI écrit également `FIRECRAWL_API_BASE_URL` et `FIRECRAWL_DOCUMENTATION_URL`. Ces deux variables sont purement informatives. Les SDKs lisent `FIRECRAWL_API_URL`, et uniquement pour les déploiements auto-hébergés ; un compte provisionné via Stripe utilise l&#39;API hébergée, qui est l&#39;option par défaut : laissez donc `FIRECRAWL_API_URL` non définie.

À partir de là, suivez le démarrage rapide [Node.js](/fr/quickstarts/nodejs) ou [Python](/fr/quickstarts/python), ou l&#39;[aperçu des SDKs](/fr/sdks/overview) pour les autres langages. La clé fonctionne avec tous les points de terminaison : [search](/fr/features/search), [scrape](/fr/features/scrape), [crawl](/fr/features/crawl), [map](/fr/features/map), [extract](/fr/features/extract), [interact](/fr/features/interact), [parse](/fr/features/parse) et [monitor](/fr/features/monitoring).

<div id="catalog">
  ## Catalogue
</div>

Exécutez `stripe projects catalog firecrawl` pour obtenir la liste à jour. La CLI affiche le prix final avant toute confirmation.

| Slug                 | Type    | Description                                                                       |
| -------------------- | ------- | --------------------------------------------------------------------------------- |
| `firecrawl/api`      | Service | L&#39;API Firecrawl. Provisionne le compte et la clé API. Palier Free par défaut. |
| `firecrawl/free`     | Offre   | L&#39;offre Free. Aucune carte bancaire requise.                                  |
| `firecrawl/hobby`    | Offre   | L&#39;offre Hobby. Demande `Monthly` ou `Yearly`.                                 |
| `firecrawl/standard` | Offre   | L&#39;offre Standard. Demande `Monthly` ou `Yearly`.                              |
| `firecrawl/growth`   | Offre   | L&#39;offre Growth. Demande `Monthly` ou `Yearly`.                                |

Les offres et les tarifs correspondent à [firecrawl.dev/pricing](https://www.firecrawl.dev/pricing). Les offres Scale et Enterprise ne sont pas proposées via Stripe Projects ; pour celles-ci, [contactez-nous](https://www.firecrawl.dev/enterprise).

<div id="manage-the-resource">
  ## Gérer la ressource
</div>

```bash
# Ajoutez une seule fois un mode de paiement à votre compte Stripe
stripe projects billing add

# Passez à une offre payante ; la CLI demande quelle offre et quel intervalle de facturation
stripe projects upgrade firecrawl

# Effectuez la rotation de la clé API, puis récupérez la nouvelle valeur dans .env
stripe projects rotate firecrawl
stripe projects env --pull

# Retirez Firecrawl de ce projet
stripe projects remove firecrawl
```

Les mises à niveau utilisent un [Shared Payment Token](https://docs.stripe.com/agentic-commerce/concepts/shared-payment-tokens) Stripe : Firecrawl n&#39;a donc jamais accès aux informations de votre carte. L&#39;offre apparaît dans votre tableau de bord Firecrawl comme n&#39;importe quel autre abonnement. Pour revenir à l&#39;offre Free, exécutez `stripe projects upgrade firecrawl` et choisissez `free`, ou modifiez l&#39;offre depuis [Facturation](https://www.firecrawl.dev/app/settings?tab=billing) dans le tableau de bord.

<div id="accounts-and-billing">
  ## Comptes et facturation
</div>

* **Un compte Stripe, un compte Firecrawl.** Firecrawl recherche l&#39;e-mail de votre compte Stripe. Un nouvel e-mail donne lieu à un nouveau compte Firecrawl, déjà vérifié, doté d&#39;une équipe et d&#39;une clé API par défaut. Un e-mail disposant déjà d&#39;un compte Firecrawl réutilise l&#39;équipe précédemment liée via Stripe ; la première fois, une nouvelle équipe nommée `via stripe` est créée dans sa propre organisation, afin que la facturation Stripe reste distincte de vos autres équipes Firecrawl.
* **Toute personne rattachée au compte Stripe peut agir sur le compte Firecrawl lié** via Projects, conformément au modèle de Stripe. Le tableau de bord Firecrawl affiche le compte sous l&#39;e-mail du compte Stripe.
* **Les offres payantes sont des abonnements Firecrawl**, réglés avec votre Shared Payment Token et déclarés par `stripe projects spend`. Les crédits, les limites de débit et les fonctionnalités sont identiques à ceux de la même offre achetée sur firecrawl.dev.
* **Supprimer la ressource annule son offre.** Le compte et la clé API sont conservés.

<div id="coding-agents">
  ## Agents de codage
</div>

Stripe Projects est conçu autant pour les agents que pour les humains. Stripe publie un [skill](https://docs.stripe.com/projects#coding-agent) qui apprend à Claude Code, Cursor, Codex et aux autres agents à utiliser la CLI Projects, et `stripe projects llm-context` regroupe cette page avec les instructions de tous les autres providers du projet.

```bash
npx skills add https://docs.stripe.com --skill stripe-projects -g -y
```

Lorsqu&#39;un agent provisionne Firecrawl : copiez le slug renvoyé par `stripe projects catalog firecrawl --json` plutôt que de le deviner, passez `--name firecrawl`, exécutez `stripe projects env --pull` et utilisez `FIRECRAWL_API_KEY` depuis l&#39;environnement plutôt que de modifier `.env`, et laissez les mises à niveau payantes à l&#39;humain, car elles débitent la carte associée au compte Stripe. `--accept-tos` accepte les [conditions d&#39;utilisation de Firecrawl](https://www.firecrawl.dev/terms-of-service) au nom de l&#39;humain : demandez-lui donc confirmation au préalable. Le reste de la configuration de l&#39;agent est décrit dans [Build with AI](/fr/ai-onboarding).

<div id="troubleshooting">
  ## Dépannage
</div>

| Ce que vous voyez                                | Que faire                                                                                                                                                                                |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Provider connection requires re-authentication` | Exécutez `stripe projects link firecrawl`, puis réessayez.                                                                                                                               |
| `Unknown provider or category: firecrawl`        | Exécutez `stripe plugin upgrade projects`, puis `stripe projects catalog firecrawl --refresh`.                                                                                           |
| Le provisionnement payant échoue                 | Exécutez `stripe projects billing add` pour confirmer un mode de paiement. Si votre compte Firecrawl est déjà associé à une offre payante, modifiez-la plutôt depuis le tableau de bord. |
| La clé se retrouve dans `FIRECRAWL_API_API_KEY`  | Vous avez effectué le provisionnement sans `--name`. Exportez-la sous `FIRECRAWL_API_KEY`, ou supprimez la ressource puis ajoutez-la de nouveau avec `--name firecrawl`.                 |

Toujours bloqué ? Écrivez à [help@firecrawl.com](mailto:help@firecrawl.com) en indiquant l&#39;identifiant de requête Stripe figurant dans l&#39;erreur.
