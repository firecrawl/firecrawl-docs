<div id="sync-web-data-in-flowise-workflows">
  ## Synchroniser des données web dans des workflows Flowise {#sync-web-data-in-flowise-workflows}
</div>

Firecrawl peut être utilisé dans [Flowise, le constructeur de Chatflows](https://flowiseai.com/). Cette page présente la configuration et l’utilisation d’un bloc Firecrawl dans Flowise.

<img
  className="block"
  src="/images/fc_flowise_block.png"
  alt="Bloc Firecrawl pour Flowise"
/>

### Exploration avec les blocs Firecrawl {#crawling-with-firecrawl-blocks}

1. Connectez-vous à votre compte Firecrawl, récupérez votre clé API, puis ajoutez-la au bloc en tant qu’identifiant **FireCrawl API**.
2. (Facultatif) Connectez Text Splitter.
3. Définissez **Type** sur **Crawl** pour récupérer les pages situées sous l’URL cible.
4. Saisissez l’URL cible à explorer. Utilisez **Limit**, **Include Paths** et **Exclude Paths** pour limiter l’ampleur du crawl.
5. Utilisez les documents obtenus dans vos workflows.

<div id="scraping-with-firecrawl-blocks">
  ### Extraction avec les blocs Firecrawl {#scraping-with-firecrawl-blocks}
</div>

1. Connectez-vous à votre compte Firecrawl, récupérez votre clé API, puis ajoutez-la au bloc en tant qu’identifiant **FireCrawl API**.
2. (Facultatif) Connectez Text Splitter.
3. Définissez **Type** sur **Scrape** pour récupérer une seule page.
4. Saisissez l’URL cible à extraire.
5. Utilisez les documents générés dans vos workflows.

### Recherche et extraction avec les blocs Firecrawl {#searching-and-extracting-with-firecrawl-blocks}

Définissez **Type** sur **Search** pour convertir en documents les résultats de recherche web correspondant à une **Query**, ou sur **Extract** pour obtenir des données structurées à partir d&#39;une URL à l&#39;aide d&#39;un **Schema** et d&#39;un **Prompt**.
