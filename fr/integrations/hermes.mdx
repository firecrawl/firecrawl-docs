</Note>

<div id="overview">
  ## Vue d’ensemble
</div>

Hermes Agent est un agent open source pour terminal et ordinateur de bureau développé par Nous Research. Il inclut des outils web :

| Outil             | Description                                           |
| ----------------- | ----------------------------------------------------- |
| **`web_search`**  | Recherche sur le web et renvoie des résultats classés |
| **`web_extract`** | Récupère et extrait du contenu lisible depuis des URL |

Firecrawl est le fournisseur **par défaut** pour la recherche et l’extraction. Configurez `FIRECRAWL_API_KEY`, utilisez une `FIRECRAWL_API_URL` auto-hébergée ou Nous Tool Gateway. Si vous disposez d’identifiants pour plusieurs fournisseurs, sélectionnez Firecrawl dans `hermes tools` ou `config.yaml`. L’automatisation du Browser via le mode cloud de Firecrawl est facultative.

<div id="quick-start">
  ## Démarrage rapide
</div>

1. Installez Hermes Agent depuis [hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com/)
2. Ajoutez votre clé Firecrawl :

```bash
# ~/.hermes/.env
FIRECRAWL_API_KEY=fc-your-key-here
```

Obtenez une clé sur [firecrawl.dev](https://www.firecrawl.dev/app/api-keys).

3. Ou configurez interactivement :

```bash
hermes tools
```

Choisissez **Web Search &amp; Extract** → **Firecrawl**.

4. Vérifiez :

```bash
hermes setup
```

<div id="capabilities">
  ## Fonctionnalités
</div>

| Fonctionnalité            | Dans Hermes                                         |
| ------------------------- | --------------------------------------------------- |
| **Recherche**             | Backend `web_search` par défaut                     |
| **Extraction / scraping** | Backend `web_extract` par défaut                    |
| **Browser**               | Fournisseur de navigateur cloud Firecrawl en option |

<div id="use-firecrawl-for-one-capability-only">
  ### Utiliser Firecrawl pour une seule fonctionnalité
</div>

Hermes vous permet de choisir indépendamment les backends de recherche et d’extraction, afin d’associer un backend de recherche gratuit à l’extraction Firecrawl (ou inversement) :

```yaml
# ~/.hermes/config.yaml
web:
  search_backend: "searxng"
  extract_backend: "firecrawl"
```

Lorsque ces clés sont vides, les deux se replient sur `web.backend`, puis Hermes détecte automatiquement les identifiants disponibles. Les identifiants d’autres fournisseurs peuvent être prioritaires sur Firecrawl lors de cette détection. Définissez donc explicitement `search_backend`, `extract_backend` ou `web.backend` si vous voulez garantir l’utilisation de Firecrawl.

<div id="browser-cloud-mode">
  ### Mode cloud du Browser
</div>

Pour utiliser Firecrawl pour automatiser le navigateur :

```bash
# ~/.hermes/.env
FIRECRAWL_API_KEY=fc-your-key-here
```

```bash
hermes setup tools
# → Browser Automation → Firecrawl
```

Facultatif :

```bash
# Firecrawl auto-hébergé (sinon, cloud API par défaut)
FIRECRAWL_API_URL=http://localhost:3002

# TTL de session en secondes (par défaut : 300)
FIRECRAWL_BROWSER_TTL=600
```

<div id="nous-portal-managed-firecrawl">
  ## Nous Portal (Firecrawl géré)
</div>

Avec un abonnement payant à [Nous Portal](https://portal.nousresearch.com/), vous pouvez effectuer des recherches sur le Web et des extractions via la **Tool Gateway** d’Hermes avec Firecrawl géré. Aucune clé Firecrawl distincte n’est requise :

```bash
hermes setup --portal
```

Les installations existantes peuvent activer les outils web avec `hermes tools`.

<div id="self-hosted-firecrawl">
  ## Firecrawl auto-hébergé
</div>

```bash
# ~/.hermes/.env
FIRECRAWL_API_URL=http://localhost:3002
```

Lorsque `FIRECRAWL_API_URL` est défini, la clé API est facultative si l’authentification du serveur Firecrawl est désactivée (`USE_DB_AUTHENTICATION=false` sur l’instance Firecrawl).
