<div id="firecrawl-actions">
  ## Actions Firecrawl
</div>

| Action             | Cas d’utilisation                                            |
| ------------------ | ------------------------------------------------------------ |
| **/Scrape Page**   | Capture rapide de données sur une page unique                |
| **/Crawl Website** | Scraping complet d’un site sur plusieurs pages               |
| **/Extract Data**  | Extraction optimisée par l’IA avec des schémas personnalisés |
| **/Search Data**   | Automatisation de la recherche avec recherche + scraping     |
| **/Map Data**      | Analyse SEO et cartographie de la structure du site          |

<div id="quick-reference">
  ## Référence rapide
</div>

<CardGroup cols={2}>
  <Card title="Premiers pas" icon="play">
    1. Inscrivez-vous sur [firecrawl.dev](https://firecrawl.dev)
    2. Obtenez votre clé API
    3. Créez un Zap dans Zapier
    4. Connectez Firecrawl avec votre clé API
    5. Choisissez votre workflow et activez-le
  </Card>

  <Card title="Bonnes pratiques" icon="lightbulb">
    * Utilisez `/Scrape Page` pour les pages individuelles (plus rapide)
    * Planifiez les exécutions de façon stratégique (toutes les heures, tous les jours ou toutes les semaines)
    * Testez d&#39;abord dans le playground de Firecrawl
    * Ajoutez une gestion des erreurs pour les scrapes qui échouent
    * Utilisez des filtres pour éviter les exécutions inutiles
  </Card>
</CardGroup>

<div id="zapier-vs-n8n">
  ## Zapier vs n8n
</div>

| Fonctionnalité    | Zapier                                               | n8n                                    |
| ----------------- | ---------------------------------------------------- | -------------------------------------- |
| **Configuration** | Sans code, dans le cloud                             | Auto-hébergé ou dans le cloud          |
| **Tarification**  | Par tâche                                            | Basée sur le nombre d&#39;exécutions   |
| **Intégrations**  | Plus de 9 000 applications                           | Plus de 1 000 applications et services |
| **Idéal pour**    | Automatisations rapides, utilisateurs non techniques | Logique personnalisée, développeurs    |
