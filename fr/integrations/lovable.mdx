</Note>

<div id="overview">
  ## Vue d’ensemble
</div>

Les applications Lovable peuvent utiliser Firecrawl pour scraper et crawler des sites web afin d’obtenir du contenu propre et structuré dans le chat, pendant leur création comme après leur publication. Firecrawl est disponible sous forme d’application et de connecteur de chat.

<div id="quick-start">
  ## Démarrage rapide
</div>

1. Ouvrez **Connectors** dans Lovable et sélectionnez **Firecrawl**
2. Ajoutez une connexion avec **Managed by Lovable** (aucun compte Firecrawl n’est requis) ou **Use your own credentials** avec votre propre clé API Firecrawl
3. Liez la connexion à votre projet, puis demandez à Lovable d’effectuer un scrape ou un crawl avec Firecrawl

<div id="what-you-can-build">
  ## Ce que vous pouvez créer
</div>

| Fonctionnalité | Cas d’usage                                                                            |
| -------------- | -------------------------------------------------------------------------------------- |
| **Scrape**     | Transformez des URL en Markdown propre ou en JSON structuré                            |
| **Crawl**      | Collectez les pages d’un site, y compris les sous-pages                                |
| **Extract**    | Extrayez des champs tels que les informations produit, les tableaux et les métadonnées |
