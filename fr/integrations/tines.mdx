## Vue d’ensemble {#overview}

Les stories Tines peuvent appeler n’importe quelle API REST via l’action HTTP Request. En configurant cette action pour qu’elle cible l’API Firecrawl, une story peut rechercher sur le web, extraire le contenu d’une page au format markdown, récupérer des données structurées, cartographier un site ou le crawler, puis transmettre le résultat à l’action suivante de la story.

## Démarrage rapide {#quick-start}

1. [Créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys)
2. Dans Tines, ouvrez **Identifiants**, créez un identifiant de type **Text** nommé `firecrawl` et collez-y la clé comme valeur
3. Ajoutez une action **HTTP Request** à votre story et configurez-la comme indiqué ci-dessous

En référençant la clé sous la forme `<<CREDENTIAL.firecrawl>>`, vous évitez qu’elle apparaisse dans la configuration de l’action.

## Extraire le contenu d’une page {#scrape-a-page}

Cette action envoie une requête de scraping et renvoie la page au format markdown :

```json
{
  "url": "https://api.firecrawl.dev/v2/scrape",
  "method": "post",
  "content_type": "json",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  },
  "payload": {
    "url": "https://example.com",
    "formats": ["markdown"],
    "integration": "_tines"
  }
}
```

Remplacez `https://example.com` par une URL issue d&#39;un événement en amont, par exemple `<<receive_event.body.url>>`. Le champ facultatif `integration` permet d&#39;identifier les requêtes provenant de Tines.

## Ce que vous pouvez faire {#what-you-can-do}

| Fonctionnalité    | Point de terminaison                    | Cas d’utilisation                                                                                     |
| ----------------- | --------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **Recherche**     | `POST /v2/search`                       | Trouver des sources sur une question ou une alerte avant d’enchaîner d’autres actions                 |
| **Extraire**      | `POST /v2/scrape`                       | Convertir une URL en markdown ou en JSON structuré                                                    |
| **Extraire**      | `POST /v2/scrape` avec un format `json` | Récupérer des champs, comme un titre ou les détails d’un produit, à l’aide d’un prompt et d’un schéma |
| **Cartographier** | `POST /v2/map`                          | Lister les URL d’un site                                                                              |
| **Crawl**         | `POST /v2/crawl`                        | Collecter les pages de tout un site, puis interroger l’API pour obtenir le résultat                   |

Tous les points de terminaison utilisent l’URL de base `https://api.firecrawl.dev`, le même en-tête `Authorization` et un corps JSON.

## Rechercher sur le Web {#search-the-web}

```json
{
  "url": "https://api.firecrawl.dev/v2/search",
  "method": "post",
  "content_type": "json",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  },
  "payload": {
    "query": "firecrawl web scraping",
    "limit": 5,
    "sources": ["web"],
    "integration": "_tines"
  }
}
```

## Extraire des données structurées {#extract-structured-data}

Dans `formats`, définissez une entrée de type `json` avec un prompt et un schéma JSON :

```json
{
  "url": "https://api.firecrawl.dev/v2/scrape",
  "method": "post",
  "content_type": "json",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  },
  "payload": {
    "url": "https://example.com",
    "formats": [
      {
        "type": "json",
        "prompt": "Extract the page title",
        "schema": {
          "type": "object",
          "properties": { "title": { "type": "string" } }
        }
      }
    ],
    "integration": "_tines"
  }
}
```

## Crawler un site {#crawl-a-site}

Un crawl s&#39;exécute de manière asynchrone : une première action permet de le démarrer, une seconde d&#39;en lire le résultat.

**Démarrez le crawl** avec `POST /v2/crawl` :

```json
{
  "url": "https://api.firecrawl.dev/v2/crawl",
  "method": "post",
  "content_type": "json",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  },
  "payload": {
    "url": "https://example.com",
    "limit": 10,
    "integration": "_tines"
  }
}
```

La réponse contient un `id`. **Vérifiez l&#39;état** à l&#39;aide d&#39;une deuxième action HTTP Request qui récupère le crawl correspondant à cet `id`, et répétez-la jusqu&#39;à ce que `status` vaille `completed` :

```json
{
  "url": "https://api.firecrawl.dev/v2/crawl/<<start_crawl.body.id>>",
  "method": "get",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  }
}
```

Ici, `start_crawl` est le nom de l&#39;action qui a démarré le crawl.
