<div id="getting-started">
  ## Prise en main
</div>

<Steps>
  <Step title="Inscrivez-vous à Firecrawl">
    Obtenez votre clé API sur [firecrawl.dev](https://firecrawl.dev)
  </Step>

  <Step title="Créez un scénario dans Make">
    Connectez-vous à [Make](https://make.com) et cliquez sur « Créer un nouveau scénario »
  </Step>

  <Step title="Ajoutez le module Firecrawl">
    Recherchez « Firecrawl » et sélectionnez l’action souhaitée
  </Step>

  <Step title="Connectez-vous avec votre clé API">
    Ajoutez votre clé API Firecrawl pour vous authentifier
  </Step>

  <Step title="Configurez et testez">
    Configurez les paramètres de votre workflow et exécutez un test
  </Step>
</Steps>

<div id="make-vs-zapier-vs-n8n">
  ## Make vs Zapier vs n8n
</div>

| Fonctionnalité             | Make                                              | Zapier                     | n8n                                    |
| -------------------------- | ------------------------------------------------- | -------------------------- | -------------------------------------- |
| **Configuration**          | Éditeur visuel, cloud                             | Sans code, cloud           | Auto-hébergé ou cloud                  |
| **Tarification**           | Selon le nombre d’opérations                      | Par tâche                  | Selon le nombre d’exécutions           |
| **Intégrations**           | Plus de 3 000 applications                        | Plus de 9 000 applications | Plus de 1 000 applications et services |
| **Complexité**             | Workflows avancés                                 | Workflows simples          | Workflows complexes                    |
| **Idéal pour**             | Automatisation visuelle, complexité intermédiaire | Automatisation rapide      | Contrôle pour les développeurs         |
| **Courbe d’apprentissage** | Modérée                                           | Facile                     | Modérée à avancée                      |

<Tip>
  **Conseil de pro :** Make excelle dans la conception visuelle de workflows et les automatisations complexes. Idéal pour les équipes qui ont besoin de plus de contrôle que Zapier, mais préfèrent une approche visuelle à l’approche axée sur le code de n8n.
</Tip>
