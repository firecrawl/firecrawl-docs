<div id="run-locally">
  ## Exécuter en local
</div>

```bash
env FIRECRAWL_API_KEY=VOTRE_CLÉ_API npx -y firecrawl-mcp@3.22.4
```

<div id="install-globally">
  ## Installation globale
</div>

```bash
npm install -g firecrawl-mcp
```

<div id="environment-variables">
  ### Variables d’environnement
</div>

<div id="cloud-and-self-hosted-api">
  #### API cloud et auto-hébergée
</div>

* `FIRECRAWL_API_KEY` : votre clé API Firecrawl
  * Requise pour utiliser l’API cloud (par défaut)
  * Facultative pour utiliser une instance auto-hébergée avec `FIRECRAWL_API_URL`
* `FIRECRAWL_API_URL` (facultatif) : point de terminaison d’API personnalisé pour les instances auto-hébergées
  * Exemple : `https://firecrawl.your-domain.com`
  * Si elle n’est pas fournie, l’API cloud est utilisée (clé API requise)

<div id="configuration-examples">
  ### Exemples de configuration
</div>

Pour utiliser l’API cloud :

```bash
export FIRECRAWL_API_KEY=your-api-key
```

Pour une instance auto-hébergée :

```bash
export FIRECRAWL_API_URL=https://firecrawl.your-domain.com
export FIRECRAWL_API_KEY=your-api-key  # Si votre instance requiert une authentification
```

<div id="custom-configuration-with-claude-desktop">
  ### Configuration personnalisée avec Claude Desktop
</div>

Ajoutez ceci à votre fichier `claude_desktop_config.json` :

```json
{
  "mcpServers": {
    "mcp-server-firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "YOUR_API_KEY_HERE"
      }
    }
  }
}
```

<div id="hosted-mcp-vs-local-mcp">
  ### MCP hébergé ou local
</div>

Le serveur MCP hébergé est optimisé pour une utilisation distante sécurisée. Certaines options disponibles lors de l’exécution locale du serveur MCP sont restreintes ou indisponibles à distance :

* Le mode keyless hébergé n’expose que les outils compatibles avec ce mode et est limité en débit par adresse IP.
* La lecture de fichiers locaux n’est disponible que lorsque vous exécutez le serveur MCP localement.
* Les Webhooks et les chemins de fichiers locaux doivent être configurés depuis un serveur MCP local ou auto-hébergé lorsque l’agent doit accéder à des ressources locales.

<div id="rate-limiting">
  ### Limites de débit
</div>

Firecrawl applique des limites de débit. Utilisez une clé API pour bénéficier de limites plus élevées et accéder à l’ensemble complet d’outils.
