Vous pouvez consulter et révoquer les connexions dans les [paramètres MCP](https://www.firecrawl.dev/app/settings?tab=mcp).

Vous avez besoin de ChatGPT ou de Claude.ai ? Consultez les guides [ChatGPT](/fr/developer-guides/mcp-setup-guides/chatgpt) et [Claude.ai](/fr/developer-guides/mcp-setup-guides/claude-ai).

<div id="add-an-api-key">
  ## Ajouter une clé API
</div>

[Créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys), puis envoyez-la sous forme de jeton porteur :

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

<div id="try">
  ## Essayer
</div>

```text
Recherche sur le web les dernières notes de release de Firecrawl et résume les sources.
```

Si aucun outil Firecrawl n’apparaît, redémarrez ou rechargez le client après avoir enregistré sa configuration MCP.
