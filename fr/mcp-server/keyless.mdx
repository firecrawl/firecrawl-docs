<Visibility for="agents">
  URL du serveur sans clé (Streamable HTTP, sans identifiants) : `https://mcp.firecrawl.dev/v2/mcp`

  * Codex : `codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp`
  * Claude Code : `claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp`
  * Cursor ou tout client configuré en JSON : `{"mcpServers": {"firecrawl": {"url": "https://mcp.firecrawl.dev/v2/mcp"}}}`
  * OpenCode (`opencode.json`) : `{"mcp": {"firecrawl": {"type": "remote", "url": "https://mcp.firecrawl.dev/v2/mcp", "enabled": true}}}`

  ChatGPT et Claude utilisent plutôt le connecteur Firecrawl natif : consultez [Pour les humains](/fr/mcp-server/oauth.md#chatgpt-and-claude).
</Visibility>

Le MCP sans clé est soumis à des limites de débit et donne accès à la recherche, au scraping et à l&#39;analyse. Ajoutez une clé API pour accéder à l&#39;ensemble complet d&#39;outils ou à des limites plus élevées.

<div id="add-an-api-key">
  ## Ajouter une clé API
</div>

[Créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys), puis envoyez-la sous forme de jeton Bearer au même point de terminaison :

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

<div id="verify-your-connection">
  ## Vérifiez votre connexion
</div>

Ouvrez l’état MCP ou la liste des outils de votre client et vérifiez que `firecrawl` est connecté. Une connexion sans clé donne accès à `firecrawl_search`, `firecrawl_scrape` et `firecrawl_parse` ; une connexion avec une clé API peut donner accès à l’[ensemble complet des outils](/fr/mcp-server/tools), selon l’offre, le déploiement et la politique de l’équipe.

<div id="try">
  ## Essayez
</div>

```text
Recherche sur le web les dernières notes de version de Firecrawl et résume les sources.
```

Si aucun outil Firecrawl n’apparaît, redémarrez ou rechargez le client après avoir enregistré sa configuration MCP.
