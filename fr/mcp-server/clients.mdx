Commencez par [Connecter Firecrawl MCP](/fr/mcp-server/connect) pour choisir entre l’authentification OAuth du compte, l’accès non supervisé par clé API ou l’accès sans clé. Ces exemples propres à chaque client utilisent le même mécanisme adapté au mode choisi.

  ## Utilisation avec Cursor
</div>

Installez le serveur hébergé sans clé en un clic (aucune clé API requise) :

<a href="cursor://anysphere.cursor-deeplink/mcp/install?name=firecrawl&config=eyJ1cmwiOiJodHRwczovL21jcC5maXJlY3Jhd2wuZGV2L3YyL21jcCJ9">

  <span className="fc-sr-only">Installer Firecrawl MCP dans Cursor</span>
</a>

Vous pouvez également l&#39;ajouter manuellement à `~/.cursor/mcp.json` :

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

<div id="running-locally-with-an-api-key">
  ### Exécution locale avec une clé API
</div>

Remarque : nécessite Cursor version 0.45.6 ou ultérieure.
Pour les instructions de configuration les plus récentes, consultez la documentation officielle de Cursor sur la configuration des serveurs MCP :
[Guide de configuration des serveurs MCP de Cursor](https://cursor.com/docs/context/mcp)

Pour configurer Firecrawl MCP dans Cursor **v0.48.6**

1. Ouvrez les paramètres de Cursor
2. Accédez à Fonctionnalités &gt; Serveurs MCP
3. Cliquez sur « + Ajouter un nouveau serveur MCP global »
4. Saisissez le code suivant :
   ```json
   {
     "mcpServers": {
       "firecrawl-mcp": {
         "command": "npx",
         "args": ["-y", "firecrawl-mcp"],
         "env": {
           "FIRECRAWL_API_KEY": "YOUR-API-KEY"
         }
       }
     }
   }
   ```

Pour configurer Firecrawl MCP dans Cursor **v0.45.6**

1. Ouvrez les paramètres de Cursor
2. Accédez à Fonctionnalités &gt; Serveurs MCP
3. Cliquez sur « + Ajouter un nouveau serveur MCP »
4. Saisissez les informations suivantes :
   * Nom : &quot;firecrawl-mcp&quot; (ou le nom de votre choix)
   * Type : &quot;command&quot;
   * Commande : `env FIRECRAWL_API_KEY=your-api-key npx -y firecrawl-mcp@3.23.0`

> Si vous utilisez Windows et rencontrez des problèmes, essayez `cmd /c "set FIRECRAWL_API_KEY=your-api-key && npx -y firecrawl-mcp@3.23.0"`

Remplacez `your-api-key` par votre clé API Firecrawl. Si vous n&#39;en avez pas encore, vous pouvez créer un compte et l&#39;obtenir sur https://www.firecrawl.dev/app/api-keys

Après l&#39;ajout, actualisez la liste des serveurs MCP pour voir les nouveaux outils. L’Agent Composer utilisera automatiquement Firecrawl MCP lorsque nécessaire, mais vous pouvez le demander explicitement en décrivant vos besoins en données web. Accédez à Composer avec Command+L (Mac), sélectionnez « Agent » à côté du bouton d’envoi, puis saisissez votre requête.

<div id="running-with-streamable-http-mode">
  ## Exécuter le serveur avec le mode Streamable HTTP
</div>

Pour exécuter le serveur localement avec le transport HTTP Streamable plutôt qu’avec le transport stdio par défaut :

```bash
env HTTP_STREAMABLE_SERVER=true FIRECRAWL_API_KEY=fc-YOUR_API_KEY npx -y firecrawl-mcp@3.23.0
```

Utilisez `http://localhost:3000/mcp` pour le serveur local. La route `/v2/mcp` correspond au service hébergé à l’adresse `https://mcp.firecrawl.dev/v2/mcp`.

Vérifiez que le processus local est prêt avant de connecter un client :

```bash
curl http://localhost:3000/health
```

La vérification de l’état renvoie `ok`. Consultez [Exécuter Firecrawl MCP localement](/fr/mcp-server/local#run-with-streamable-http) pour connaître les prérequis et la configuration.

  ## Utilisation avec VS Code
</div>

Pour une installation en un clic, cliquez sur l’un des boutons d’installation ci-dessous...

Pour une installation manuelle, ajoutez le bloc JSON suivant au fichier User Settings (JSON) de VS Code. Pour l’ouvrir, appuyez sur `Ctrl + Shift + P`, puis saisissez `Preferences: Open User Settings (JSON)`.

```json
{
  "mcp": {
    "inputs": [
      {
        "type": "promptString",
        "id": "apiKey",
        "description": "Firecrawl API Key",
        "password": true
      }
    ],
    "servers": {
      "firecrawl": {
        "command": "npx",
        "args": ["-y", "firecrawl-mcp"],
        "env": {
          "FIRECRAWL_API_KEY": "${input:apiKey}"
        }
      }
    }
  }
}
```

Vous pouvez également l’ajouter à un fichier nommé `.vscode/mcp.json` dans votre espace de travail. Vous pourrez ainsi partager la configuration avec d’autres :

```json
{
  "inputs": [
    {
      "type": "promptString",
      "id": "apiKey",
      "description": "Firecrawl API Key",
      "password": true
    }
  ],
  "servers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "${input:apiKey}"
      }
    }
  }
}
```

**Remarque :** Certains utilisateurs ont rencontré des problèmes lors de l’ajout du serveur MCP à VS Code, en raison de la manière dont celui-ci valide le JSON avec un format de schéma obsolète ([microsoft/vscode#155379](https://github.com/microsoft/vscode/issues/155379)).
Cela affecte plusieurs outils MCP, dont Firecrawl.

**Solution de contournement :** Désactivez la validation JSON dans VS Code pour permettre au serveur MCP de se charger correctement.
Voir la référence : [directus/directus#25906 (commentaire)](https://github.com/directus/directus/issues/25906#issuecomment-3369169513).

Le serveur MCP fonctionne toujours correctement lorsqu’il est appelé via d’autres extensions, mais le problème survient spécifiquement lorsqu’il est enregistré directement dans la liste des serveurs MCP. Nous ajouterons des instructions lorsque VS Code aura mis à jour la validation de ses schémas.

<div id="running-on-claude-desktop">
  ## Utilisation avec Claude Desktop
</div>

Pour connecter un compte de manière interactive, ajoutez le point de terminaison du compte et suivez le flux OAuth dans le Browser :

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

Pour une configuration sans interaction ou basée sur une clé API, utilisez plutôt `https://mcp.firecrawl.dev/v2/mcp` avec l’en-tête `Authorization: Bearer <FIRECRAWL_API_KEY>`.

Si vous obtenez l’erreur &quot;Impossible de joindre le serveur MCP&quot;, votre version de Claude Desktop ne prend peut-être pas en charge le transport HTTP Streamable. Utilisez plutôt l’approche locale avec npx (nécessite [Node.js](https://nodejs.org)) :

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "VOTRE_CLÉ_API"
      }
    }
  }
}
```

Si l’erreur `spawn npx ENOENT` s’affiche, Node.js n’est pas installé ou ne figure pas dans le PATH de votre système. Installez Node.js depuis [nodejs.org](https://nodejs.org) (version LTS), puis redémarrez complètement Claude Desktop. Sous Windows, vous pouvez également exécuter `where npx` dans l’Invite de commandes et utiliser le chemin complet (par exemple, `C:\\Program Files\\nodejs\\npx.cmd`) comme valeur de `command`.

<div id="running-on-claude-code">
  ## Utilisation avec Claude Code
</div>

Ajoutez le serveur MCP Firecrawl à l’aide de l’interface en ligne de commande de Claude Code. Vous pouvez utiliser l’URL hébergée à distance ou l’exécuter localement :

```bash
# Connexion interactive du compte (recommandé)
claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth

# Pour une configuration par clé d'API sans intervention, utilisez un en-tête Authorization
claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp --header "Authorization: Bearer <FIRECRAWL_API_KEY>"

# Ou exécutez en local via npx
claude mcp add firecrawl -e FIRECRAWL_API_KEY=fc-your-api-key -- npx -y firecrawl-mcp@3.23.0
```

<div id="running-on-google-antigravity">
  ## Utilisation avec Google Antigravity
</div>

Google Antigravity vous permet de configurer des serveurs MCP directement depuis son interface Agent.

<img src="/images/guides/mcp/antigravity-mcp-installation.gif" alt="Installation du MCP Antigravity" />

1. Ouvrez la barre latérale Agent dans l’éditeur ou la vue Agent Manager
2. Cliquez sur le menu &quot;...&quot; (Autres actions), puis sélectionnez **Serveurs MCP**
3. Sélectionnez **View raw config** pour ouvrir votre fichier local `mcp_config.json`
4. Ajoutez la configuration suivante :

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "YOUR_FIRECRAWL_API_KEY"
      }
    }
  }
}
```

5. Enregistrez le fichier, puis cliquez sur **Actualiser** dans l’interface MCP d’Antigravity pour voir les nouveaux outils.

Remplacez `YOUR_FIRECRAWL_API_KEY` par votre clé API disponible sur [https://firecrawl.dev/app/api-keys](https://www.firecrawl.dev/app/api-keys).

<div id="running-on-n8n">
  ## Utilisation avec n8n
</div>

Pour connecter le serveur MCP Firecrawl à n8n :

1. Obtenez votre clé API Firecrawl sur [https://firecrawl.dev/app/api-keys](https://www.firecrawl.dev/app/api-keys)
2. Dans votre workflow n8n, ajoutez un nœud **agent IA**
3. Dans la configuration de l’agent IA, ajoutez un nouvel **outil**
4. Sélectionnez **MCP Client Tool** comme type d’outil
5. Saisissez le point de terminaison du serveur MCP :

```
  https://mcp.firecrawl.dev/v2/mcp
```

6. Réglez **Server Transport** sur **HTTP Streamable**
7. Choisissez l’authentification :
   * Réglez **Authentication** sur **Bearer** et collez votre clé API Firecrawl pour bénéficier de l’ensemble complet des outils MCP.
   * Laissez **Authentication** sur **None** pour utiliser l’offre gratuite sans clé, qui expose uniquement recherche, scrape et parse.
8. Pour **Tools to include**, choisissez **All**, **Selected** ou **All Except** parmi les outils proposés pour votre mode d’authentification.

Pour les déploiements auto-hébergés, exécutez le serveur MCP avec npx et activez le mode de transport HTTP :

```bash
env HTTP_STREAMABLE_SERVER=true \
    FIRECRAWL_API_KEY=fc-YOUR_API_KEY \
    FIRECRAWL_API_URL=YOUR_FIRECRAWL_INSTANCE \
    npx -y firecrawl-mcp@3.23.0
```

Cette commande démarre le serveur sur `http://localhost:3000/mcp`, que vous pouvez utiliser comme point de terminaison n8n. La variable d’environnement `HTTP_STREAMABLE_SERVER=true` est requise, car n8n nécessite le transport HTTP.
