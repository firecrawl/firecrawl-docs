  ## Connexion
</div>

<Visibility for="humans">
  <McpClientSelector variant="human" showSeeAll={false} />
</Visibility>

<Visibility for="agents">
  URL du serveur OAuth (Streamable HTTP ; le client lance la connexion dans le Browser) : `https://mcp.firecrawl.dev/v2/mcp-oauth`

  * Codex : `codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth` puis `codex mcp login firecrawl`
  * Claude Code : `claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth` puis terminez la connexion via `/mcp`
  * Cursor ou tout client avec une configuration JSON : `{"mcpServers": {"firecrawl": {"url": "https://mcp.firecrawl.dev/v2/mcp-oauth"}}}`
  * OpenCode (`opencode.json`) : `{"mcp": {"firecrawl": {"type": "remote", "url": "https://mcp.firecrawl.dev/v2/mcp-oauth", "enabled": true}}}`
  * ChatGPT ou Claude.ai : utilisez le connecteur Firecrawl natif — [ChatGPT](https://chatgpt.com/plugins?q=firecrawl) ou [Claude](https://claude.ai/directory/connectors/firecrawl).

  Une personne doit terminer la connexion dans le Browser et approuver une équipe. N’ouvrez pas directement l’URL du serveur dans un Browser.
</Visibility>

<Note>
  `https://mcp.firecrawl.dev/v2/mcp-oauth` est une URL de serveur destinée à votre client MCP. Il ne s’agit pas d’une page à ouvrir directement dans un Browser. Votre client lance le flux de connexion dans le Browser.
</Note>

Vous pouvez consulter et révoquer les connexions depuis les [paramètres MCP](https://www.firecrawl.dev/app/settings?tab=mcp).
