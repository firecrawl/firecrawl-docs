<div id="development">
  ## Développement
</div>

```bash
# Installer les dépendances
npm install

# Créer le build
npm run build

# Lancer les tests
npm test
```

<div id="contributing">
  ### Contribuer
</div>

1. Forkez le dépôt
2. Créez une branche pour votre fonctionnalité
3. Exécutez les tests : `npm test`
4. Soumettez une pull request
