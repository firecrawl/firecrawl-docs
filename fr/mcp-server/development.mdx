<div id="prerequisites">
  ## Prérequis
</div>

* [Git](https://git-scm.com/downloads)
* Node.js 22 ou version ultérieure
* npm, inclus avec Node.js

Vérifiez la version de Node.js avant d’installer les dépendances :

```bash
node --version
```

<div id="clone-and-test-the-server">
  ## Cloner et tester le serveur
</div>

```bash
git clone https://github.com/firecrawl/firecrawl-mcp-server.git
cd firecrawl-mcp-server
npm install
npm run build
npm test
```

Exécutez le linter avant de soumettre vos modifications :

```bash
npm run lint
```

<div id="contributing">
  ## Contribuer
</div>

1. Forkez le [dépôt du serveur MCP Firecrawl](https://github.com/firecrawl/firecrawl-mcp-server).
2. Clonez votre fork et créez une branche de fonctionnalité.
3. Exécutez `npm run lint` et `npm test`.
4. Soumettez une pull request décrivant le comportement et accompagnée des éléments de vérification.
