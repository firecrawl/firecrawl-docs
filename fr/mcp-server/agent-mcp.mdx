<div id="try-keyless">
  ## Essayer le mode sans clé
</div>

<McpClientSelector variant="agent" showSeeAll={false} />

Le MCP sans clé est soumis à des limites de débit et donne accès à la recherche, au scrape et au parse. Ajoutez une clé API pour débloquer l’ensemble des outils ou des limites plus élevées.

<div id="add-an-api-key">
  ## Ajouter une clé API
</div>

[Créez une clé API Firecrawl](https://www.firecrawl.dev/app/api-keys), puis envoyez-la sous forme de jeton porteur au même point de terminaison :

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

<div id="verify-your-connection">
  ## Vérifiez votre connexion
</div>

Ouvrez l’état MCP ou la liste des outils de votre client et vérifiez que `firecrawl` est connecté. Une connexion sans clé affiche `firecrawl_search`, `firecrawl_scrape` et `firecrawl_parse` ; une connexion avec une clé API peut donner accès à l’[ensemble complet des outils](/fr/mcp-server/tools), selon l’offre, le déploiement et les règles de l’équipe.

<div id="try">
  ## Essayer
</div>

```text
Recherche sur le web les dernières notes de release de Firecrawl et résume les sources.
```

Si aucun outil Firecrawl n’apparaît, redémarrez ou rechargez le client après avoir enregistré sa configuration MCP.
