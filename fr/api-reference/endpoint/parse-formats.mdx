---
title: 'Formats de Parse'
openapi: '/fr/api-reference/v2-openapi.json GET /parse/formats'
---

Liste tous les formats de fichiers acceptés par [`/parse`](/fr/api-reference/endpoint/parse), avec leurs extensions et leurs types MIME. Cette liste repose sur les mêmes règles que celles utilisées par `/parse` pour valider les fichiers envoyés : vous pouvez donc vérifier un fichier avant de l&#39;envoyer, sans avoir à tenir à jour votre propre liste des types pris en charge.

Chaque entrée possède un champ `kind` valant `document` ou `image`. Les formats d&#39;image sont traités par OCR et portent `available: false` lorsque l&#39;OCR d&#39;images n&#39;est pas activé ; les fichiers dans ces formats sont alors rejetés avec `UNSUPPORTED_FILE_TYPE` tant qu&#39;il ne l&#39;est pas.

Cette liste change rarement. Les réponses incluent l&#39;en-tête `Cache-Control: private, max-age=3600` : vous pouvez donc les mettre en cache sans risque pendant une heure au maximum.
