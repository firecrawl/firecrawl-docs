---
title: "Rechercher dans l’index développeur"
openapi: "/fr/api-reference/v2-openapi.json GET /search/developer"
---

Recherchez les tickets GitHub, les pull requests fusionnées, les README de dépôts et les sites de documentation sélectionnés. Les résultats sont classés par pertinence et incluent les passages correspondants au format Markdown.

`POST` est disponible sur le même chemin pour transmettre des filtres de tableau au format JSON.

Pour une vue d’ensemble du workflow, consultez le [guide de l’index développeur](/fr/features/developer).
