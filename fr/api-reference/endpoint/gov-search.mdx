title: "Rechercher dans l'index gouvernemental"

Recherchez des textes de droit primaire et des documents réglementaires issus de sources gouvernementales américaines (fédérales, étatiques et locales) : lois, règlements, codes, décisions de justice et autres publications officielles. Les résultats sont renvoyés dans le groupe standard `web`, avec la même structure qu&#39;un résultat web de [`/search`](/fr/api-reference/endpoint/search).

`POST` est disponible sur le même chemin, avec les mêmes champs transmis dans un corps JSON. Les champs inconnus sont rejetés avec une erreur `400`.

`query` est obligatoire. Indiquez la juridiction, l&#39;organisme ou la citation, ainsi que la date pertinente si vous la connaissez. `k` correspond au nombre de résultats, de 1 à 100, avec une valeur par défaut de 10 ; le point de terminaison général `/search` utilise `limit` à la place.

Les résultats sont des extraits correspondants et peuvent inclure des versions historiques, des textes de projets de loi, des documents d&#39;orientation ou des reproductions par des tiers. Vérifiez l&#39;émetteur, la juridiction, l&#39;état d&#39;adoption ou d&#39;entrée en vigueur et la version avant de citer le droit actuellement applicable. Consultez la source à l&#39;origine d&#39;une correspondance lorsque le snippet ne suffit pas. L&#39;index porte principalement sur des documents américains ; l&#39;absence de résultats ne prouve pas l&#39;absence de loi applicable.

## Filtres {#filters}

Tous les filtres sont facultatifs et se combinent selon une logique AND.

| Champ          | Conserve uniquement les pages qui                                                                                                                                                                                                                              |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `jurisdiction` | relèvent d&#39;une seule juridiction : `us` pour le niveau fédéral, ou `us-` suivi d&#39;un code d&#39;État ou de territoire à deux lettres, comme `us-ca` ou `us-dc`.                                                                                         |
| `court`        | sont associées à un tribunal donné, identifié par son identifiant CourtListener, comme `scotus`, `ca9` ou `nysd`.                                                                                                                                              |
| `courtType`    | proviennent d&#39;un type de tribunal donné : `federal-supreme`, `federal-appellate`, `federal-district`, `federal-bankruptcy`, `federal-special`, `military`, `state-supreme`, `state-appellate`, `state-trial`, `state-special` ou `state-attorney-general`. |
| `cites`        | citent une loi ou une affaire donnée, sous forme de citation imprimée comme `42 U.S.C. § 1983` ou `5 U.S. 137`, ou d&#39;identifiant de citation comme `us:usc:42:1983`.                                                                                       |
| `domain`       | proviennent d&#39;un seul site, comme `irs.gov`.                                                                                                                                                                                                               |

Les filtres ne conservent que les pages que l&#39;index a étiquetées : une recherche filtrée peut donc omettre des pages pertinentes, et l&#39;absence de résultats ne signifie pas qu&#39;il n&#39;en existe aucun. Les étiquettes de tribunal sont plus complètes pour les tribunaux fédéraux et les recueils de jurisprudence.

<CodeGroup>
  ```bash cURL
  # Aucune clé API n'est nécessaire pour démarrer ; ajoutez -H "Authorization: Bearer $FIRECRAWL_API_KEY" pour bénéficier de limites de débit plus élevées :
  curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
  ```

  ```bash cURL (POST)
  curl -X POST https://api.firecrawl.dev/v2/search/gov \
    -H "Authorization: Bearer $FIRECRAWL_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "query": "food labeling requirements for allergens",
      "k": 10
    }'
  ```
</CodeGroup>
