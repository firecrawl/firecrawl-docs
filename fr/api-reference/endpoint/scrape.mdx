## Fonctionnalités {#capabilities}

[fonctionnalité](/fr/capabilities) est la page unique qui recense ce qu&#39;un scrape peut faire sur une page, lesquelles de ces fonctionnalités s&#39;exécutent dans un déploiement self-hosted et quels points de terminaison acceptent une requête sans clé API.

## Interactions {#interactions}

Pour les interactions avec le navigateur (clic, saisie, navigation, extraction de contenu dynamique), utilisez le [point de terminaison Interact](/fr/features/interact). Effectuez d’abord le scrape d’une page, puis appelez `POST /v2/scrape/{scrapeId}/interact` avec un prompt en langage naturel ou du code Playwright pour effectuer des actions sur la page.

Consultez la [documentation Interact](/fr/features/interact) pour tous les détails et des exemples.

Vous pouvez aussi utiliser le paramètre `actions`, mais son usage n’est pas recommandé pour des interactions complexes.
