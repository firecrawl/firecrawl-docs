L&#39;endpoint de recherche combine la recherche web avec les capacités de scraping de Firecrawl pour renvoyer le contenu complet des pages pour n&#39;importe quelle requête.

Incluez `scrapeOptions` avec `formats: [{"type": "markdown"}]` pour obtenir le contenu markdown complet pour chaque résultat de recherche ; sinon, vous recevrez par défaut les résultats (URL, title, description). Vous pouvez également utiliser d&#39;autres formats comme `{"type": "summary"}` pour un contenu condensé.

<div id="supported-query-operators">
  ## Opérateurs de requête pris en charge {#supported-query-operators}
</div>

Nous prenons en charge une variété d’opérateurs de requête qui vous permettent de mieux filtrer vos recherches.

| Opérateur | Fonctionnalité | Exemples |
---|-|-|
| `""` | Correspondance exacte (non floue) d’une chaîne de texte | `"Firecrawl"`
| `-` | Exclut certains mots-clés ou annule d’autres opérateurs | `-bad`, `-site:firecrawl.dev`
| `site:` | Ne renvoie que les résultats d’un site web spécifié | `site:firecrawl.dev`
| `filetype:` | Ne renvoie que les résultats avec une extension de fichier spécifique | `filetype:pdf`, `-filetype:pdf`
| `inurl:` | Ne renvoie que les résultats qui incluent un mot dans l’URL | `inurl:firecrawl`
| `allinurl:` | Ne renvoie que les résultats qui incluent plusieurs mots dans l’URL | `allinurl:git firecrawl`
| `intitle:` | Ne renvoie que les résultats qui incluent un mot dans le titre de la page | `intitle:Firecrawl`
| `allintitle:` | Ne renvoie que les résultats qui incluent plusieurs mots dans le titre de la page | `allintitle:firecrawl playground`
| `related:` | Ne renvoie que les résultats liés à un domaine spécifique | `related:firecrawl.dev`
| `imagesize:` | Ne renvoie que les images avec des dimensions exactes | `imagesize:1920x1080`
| `larger:` | Ne renvoie que les images plus grandes que les dimensions spécifiées | `larger:1920x1080`

<div id="location-parameter">
  ## Paramètre location {#location-parameter}
</div>

Utilisez le paramètre `location` pour obtenir des résultats de recherche géociblés. Format : `"string"`. Exemples : `"Germany"`, `"San Francisco,California,United States"`.

Consultez la [liste complète des emplacements pris en charge](https://firecrawl.dev/search_locations.json) pour tous les pays et langues disponibles.

<div id="country-parameter">
  ## Paramètre country {#country-parameter}
</div>

Utilisez le paramètre `country` pour définir le pays des résultats de recherche à l’aide des codes de pays ISO. Valeur par défaut : `"US"`.

Exemples : `"US"`, `"DE"`, `"FR"`, `"JP"`, `"UK"`, `"CA"`.

```json
{
  "query": "restaurants",
  "country": "DE"
}
```

## Paramètre categories {#categories-parameter}

Filtrez les résultats de recherche par catégories spécifiques à l&#39;aide du paramètre `categories` :

* **`research`** : restreint la recherche web aux sites universitaires et de recherche (arxiv.org, nature.com, pubmed.ncbi.nlm.nih.gov et similaires). À partir du 2026-11-16, cette catégorie interrogera le [Research Index](/fr/features/research) et renverra des enregistrements de publications ; voir l&#39;avertissement ci-dessous
* **`pdf`** : recherche des PDF
* **`developer`** : interroge le [Developer Index](/fr/features/developer) — tickets, pull requests fusionnées et README de dépôts de code publics, ainsi que des sites de documentation sélectionnés

<Warning>
  **La catégorie `research` change le 2026-11-16.** Elle interrogera le [Research Index](/fr/features/research) (PubMed, bioRxiv, medRxiv, arXiv) au lieu de restreindre les résultats web à 14 sites universitaires. Les résultats passeront de `data.web` à `data.research` et seront renvoyés sous forme d&#39;enregistrements de publications : `paperId`, `primaryId`, `ids`, `title`, `abstract`, `score`. D&#39;ici là, chaque réponse qui l&#39;utilise comporte une entrée `warnings`.

  Si vous souhaitez obtenir des enregistrements de publications, adaptez votre parsing avant cette date ou appelez dès aujourd&#39;hui [`GET /search/research/papers`](/fr/api-reference/endpoint/research-search-papers). Si vous souhaitez des pages web issues de sites universitaires, basculez sur [`includeDomains`](#domain-filters).
</Warning>

### Exemple d’utilisation {#example-usage}

```json
{
  "query": "apprentissage automatique",
  "categories": ["research", "pdf"],
  "limit": 10
}
```

## Filtres de domaine {#domain-filters}

Utilisez `includeDomains` pour limiter les résultats à des domaines spécifiques, ou `excludeDomains` pour exclure certains domaines de la recherche. Les domaines doivent être uniquement des noms d’hôte, sans protocole ni chemin.

`includeDomains` et `excludeDomains` sont mutuellement exclusifs.

### Exemple de domaines à inclure {#include-domains-example}

```json
{
  "query": "web scraping",
  "includeDomains": ["firecrawl.dev", "docs.firecrawl.dev"],
  "limit": 10
}
```

### Exemple de domaines à exclure {#exclude-domains-example}

```json
{
  "query": "web scraping tools",
  "excludeDomains": ["example.com"],
  "limit": 10
}
```

### Catégories de la réponse {#category-response}

Chaque résultat inclut un champ `category` indiquant sa source :

```json
{
  "success": true,
  "data": {
    "web": [
      {
        "url": "https://arxiv.org/abs/2024.12345",
        "title": "ML Research Paper",
        "description": "Latest advances in machine learning",
        "category": "research"
      },
      {
        "url": "https://example.com/ml-survey.pdf",
        "title": "ML Survey",
        "description": "A survey of machine learning methods",
        "category": "pdf"
      }
    ]
  }
}
```

## Recherche basée sur le temps {#time-based-search}

Utilisez le paramètre `tbs` pour filtrer les résultats par périodes, y compris avec des intervalles de dates personnalisés. Consultez la [documentation de la fonctionnalité de recherche](https://docs.firecrawl.dev/features/search#time-based-search) pour des exemples détaillés et les formats pris en charge.
