The `proxy` parameter no longer changes behavior. Every request runs in `auto` mode, so Firecrawl handles enhanced escalation for you automatically.
</Note>

Firecrawl automatically uses enhanced proxies when a site needs them. Every request runs in `auto` mode, regardless of the `proxy` value you send.

### Proxy Types

- **auto**: The behavior for every request. Firecrawl starts on a basic proxy and automatically retries with enhanced proxies if it fails.
- **basic** / **enhanced**: Accepted for backward compatibility, but both behave identically to `auto`.

The `proxy` parameter is optional and no longer needs to be set — all values resolve to `auto`.
