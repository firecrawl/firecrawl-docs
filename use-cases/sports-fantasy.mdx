Firecrawl Alexandria gives AI agents structured sports data through the same Firecrawl API key they use for search and scrape. Your agent finds a sports tool with a free search, then calls it with `/scrape` and gets JSON back: scores and schedules, official NFL injury reports, weekly fantasy projections and rankings, and public league data from Sleeper and Yahoo.

Use it to build fantasy apps, sports chatbots, and research agents that answer "who should I start this week?" from this week's projections and injury reports.

## What sports data can your agent get?

Firecrawl Alexandria covers league data, fantasy projections, fantasy league data, pitch-level baseball data, and prediction markets. Each provider exposes capabilities your agent calls by name, and each provider has a public page that lists every capability.

## How does Firecrawl Alexandria return sports data?

Firecrawl Alexandria runs in three calls. A `/search` with `sources: ["alexandria"]` returns matching tools for free, Find Tools returns a tool's inputs and price for free, and `/scrape` with an `alexandria` body runs the tool and bills its listed credits.

<Steps>
  <Step title="Find a tool">
    Describe the data in plain words. Firecrawl Alexandria returns ranked tools, each with a provider, a capability, and a description.
  </Step>
  <Step title="Check its inputs">
    Read the tool's options and credit cost with `find_tools` / `findTools`. Inspection is free.
  </Step>
  <Step title="Run it">
    Call `scrape` with the provider, capability, and options. No page URL is needed.
  </Step>
</Steps>

`find_tools` and `scrape(alexandria=...)` need the Python or Node SDK at version 4.48.0 or later. Firecrawl Alexandria needs an [API key](https://www.firecrawl.dev/app/api-keys); it doesn't run keyless.

### Find sports tools with a free search

<CodeGroup>
```python Python
import os
from firecrawl import Firecrawl

firecrawl = Firecrawl(api_key=os.environ.get("FIRECRAWL_API_KEY"))

result = firecrawl.search(
    "weekly fantasy football projections in PPR",
    sources=["alexandria"],
    limit=5,
)

for tool in result.tools:
    print(tool.provider, tool.capability)
```

```javascript JavaScript
import { Firecrawl } from "firecrawl";

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const result = await firecrawl.search("weekly fantasy football projections in PPR", {
  sources: ["alexandria"],
  limit: 5,
});

for (const tool of result.tools ?? []) {
  console.log(tool.provider, tool.capability);
}
```

```bash cURL
curl -s https://api.firecrawl.dev/v2/search \
  -H "Authorization: Bearer $FIRECRAWL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "query": "weekly fantasy football projections in PPR",
  "sources": ["alexandria"],
  "limit": 5
}'
```
</CodeGroup>

### Get this week's fantasy projections

This call asks StartWho for the top three quarterbacks in PPR scoring for the current NFL week. StartWho builds each projection from sportsbook player props and returns the props behind the number.

<CodeGroup>
```python Python
import os
from firecrawl import Firecrawl

firecrawl = Firecrawl(api_key=os.environ.get("FIRECRAWL_API_KEY"))

doc = firecrawl.scrape(
    alexandria={
        "provider": "startwho-com",
        "capability": "fantasy-sports-rankings/projections",
        "options": {"position": "QB", "scoring": "PPR", "limit": 3},
    },
)

result = doc.alexandria[0]
for player in result.data["players"]:
    print(player["name"], player["team"], player["opponent"], player["projected_points"])
```

```javascript JavaScript
import { Firecrawl } from "firecrawl";

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const doc = await firecrawl.scrape({
  alexandria: {
    provider: "startwho-com",
    capability: "fantasy-sports-rankings/projections",
    options: { position: "QB", scoring: "PPR", limit: 3 },
  },
});

const result = doc.alexandria[0];
for (const p of result.data.players) {
  console.log(p.name, p.team, p.opponent, p.projected_points);
}
```

```bash cURL

}'
```

### List a provider's tools and prices

Find Tools lists every capability a provider offers with its credit cost, for free. This example lists the Sleeper tools.

<CodeGroup>
```python Python
import os
from firecrawl import Firecrawl

firecrawl = Firecrawl(api_key=os.environ.get("FIRECRAWL_API_KEY"))

catalogue = firecrawl.find_tools(providers=["sleeper-com"], limit=10)

for tool in catalogue.items:
    print(tool["capability"], tool["creditsCost"])
```

## How do you combine sports providers in one agent?

A waiver-wire assistant takes the players most added across Sleeper leagues and attaches this week's StartWho projection to each one, using two providers on one API key.

<CodeGroup>
```python Python
import os
from firecrawl import Firecrawl

firecrawl = Firecrawl(api_key=os.environ.get("FIRECRAWL_API_KEY"))


def run(provider, capability, options):
    result = firecrawl.scrape(
        alexandria={"provider": provider, "capability": capability, "options": options}
    ).alexandria[0]
    if result.error:
        raise RuntimeError(f"{provider}/{capability}: {result.error}")
    return result.data


trending = run(
    "sleeper-com",
    "fantasy-football-leagues/trending_players",
    {"type": "add", "limit": 10},
)
projections = run(
    "startwho-com",
    "fantasy-sports-rankings/projections",
    {"position": "FLX", "scoring": "PPR"},
)

points = {p["name"]: p["projected_points"] for p in projections["players"]}

for player in trending["players"]:
    projected = points.get(player["name"], "-")
    flags = ",".join(player["flags"]) or "-"
    print(f'{player["name"]:<20} {player["position"]:<3} {player["count"]:>7} adds  proj {projected:<5} flags {flags}')
```

```javascript JavaScript
import { Firecrawl } from "firecrawl";

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

async function run(provider, capability, options) {
  const doc = await firecrawl.scrape({ alexandria: { provider, capability, options } });
  const result = doc.alexandria[0];
  if (result.error) throw new Error(`${provider}/${capability}: ${JSON.stringify(result.error)}`);
  return result.data;
}

const [trending, projections] = await Promise.all([
  run("sleeper-com", "fantasy-football-leagues/trending_players", { type: "add", limit: 10 }),
  run("startwho-com", "fantasy-sports-rankings/projections", { position: "FLX", scoring: "PPR" }),
]);

const points = new Map(projections.players.map((p) => [p.name, p.projected_points]));

for (const p of trending.players) {
  const flags = p.flags.join(",") || "-";
  console.log(p.name, p.position, `${p.count} adds`, `proj ${points.get(p.name) ?? "-"}`, `flags ${flags}`);
}
```
</CodeGroup>

Seth McGowan         RB   466504 adds  proj -     flags locked
Caleb Douglas        WR   273088 adds  proj -     flags locked
Kaelon Black         RB   256354 adds  proj -     flags locked
KC Concepcion Jr.    WR   233577 adds  proj -     flags locked

Sleeper marks a player `locked` once his game has kicked off, and its flags also mark players who are out, on bye, or injured. Have your agent read the flags before it suggests a start, sit, add, or drop. A dash under `proj` means StartWho had no prop-based projection for that player that week.

## How do you use sports data from the CLI or an MCP client?

The [Firecrawl CLI](/sdks/cli) and the [MCP server](/mcp-server) expose the same three steps, so coding agents and chat assistants can run them without code.

<Tabs>
  <Tab title="Firecrawl CLI">
```bash
# Find tools.
firecrawl search "weekly fantasy football projections in PPR" --sources alexandria --limit 5

# List a provider's tools and prices.
firecrawl find-tools --options '{"providers":["sleeper-com"],"level":"tools"}'

# Run a tool.
firecrawl scrape --alexandria startwho-com/fantasy-sports-rankings/projections --options '{"position":"QB","scoring":"PPR","limit":3}'
```
    Install with `npm install -g firecrawl-cli` and sign in with `firecrawl login`.
  </Tab>
  <Tab title="MCP">
    Ask your agent: "Use Firecrawl to find this week's PPR projections for my running backs, check the NFL.com injury report for each one, and tell me who to start."

    The agent uses `firecrawl_search` to discover tools, `firecrawl_find_tools` to inspect them, and `firecrawl_scrape` to run them.
  </Tab>
</Tabs>

## What does sports data cost?

Discovery and Find Tools are free. Running a tool bills the credits listed in its `creditsCost` field, which Find Tools shows before you call it, and each result repeats `creditsCost` in the response. See [pricing and access](/features/alexandria#pricing-and-access) for provider terms.

## FAQs

<AccordionGroup>
  <Accordion title="Is there an API for fantasy football projections?">
    Yes. Firecrawl Alexandria returns weekly fantasy football projections and rankings from StartWho, CBS Sports, FFToday, FantasyData, Draft Sharks, and Fantasy Football Calculator through one Firecrawl API key, in standard, half-PPR, or PPR scoring depending on the source.
  </Accordion>

  <Accordion title="Can my agent read a Sleeper league?">
    Yes. The Sleeper capabilities read public league settings, rosters with starters, weekly matchups, transactions, and trending adds and drops. Pass the league ID to the league tools.
  </Accordion>

  <Accordion title="Does Firecrawl have the official NFL injury report?">
    Yes. The NFL.com injury report capability returns each listed player's practice participation by day and game status designation (OUT, DOUBTFUL, QUESTIONABLE), league-wide or for one club.
  </Accordion>

  <Accordion title="Which sports does Firecrawl Alexandria cover?">
    Fantasy tools focus on the NFL, with Yahoo and CBS Sports adding fantasy basketball. ESPN adds scores, rosters, standings, and injuries for the NBA, WNBA, MLB, NHL, college sports, and soccer. Baseball Savant adds MLB Statcast data, and World Table Tennis adds table tennis results and rankings.
  </Accordion>

  <Accordion title="Do I need an account with each sports provider?">
    No. Every call runs on your Firecrawl API key and credits. If a provider requires its data terms to be accepted, the response says so and includes a link for an org admin.
  </Accordion>

  <Accordion title="Can I use sports data in ChatGPT or Claude?">
    Yes. Firecrawl Alexandria is live in Claude, ChatGPT, Codex, and other agent tools through the Firecrawl plugin and MCP server. Ask for the data in plain words and the agent finds and runs the right tool.
  </Accordion>
</AccordionGroup>
