## Overview

An agent can call Firecrawl through Treg using one team credential. For example, a documentation assistant can map a site to discover its URLs, batch scrape selected pages, or start a bounded crawl and retrieve the results by job ID.

## What you can do

| Treg endpoint | What it does |
| --- | --- |
| [`firecrawl.web.crawl`](https://treg.to/catalog/endpoints/firecrawl.web.crawl) | Start a bounded crawl and pay for pages processed. |
| [`firecrawl.web.batch-scrape`](https://treg.to/catalog/endpoints/firecrawl.web.batch-scrape) | Start a bounded batch scrape of up to ten URLs. |
| [`firecrawl.web.map`](https://treg.to/catalog/endpoints/firecrawl.web.map) | Discover URLs on a website without scraping their content. |
| [`firecrawl.web.scrape`](https://treg.to/catalog/endpoints/firecrawl.web.scrape) | Fetch one page as Markdown, HTML or links. |
| [`firecrawl.web.search`](https://treg.to/catalog/endpoints/firecrawl.web.search) | Find up to ten web results without scraping their full pages. |
| [`firecrawl.web.batch-scrape.status`](https://treg.to/catalog/endpoints/firecrawl.web.batch-scrape.status) | Read an owned batch's status, result pages and credit usage. |
| [`firecrawl.web.crawl.status`](https://treg.to/catalog/endpoints/firecrawl.web.crawl.status) | Read an owned crawl's status, result pages and credit usage. |

## Quick start

To read one page, ask Firecrawl for Markdown. This example uses the Treg CLI.

1. Install the CLI using the [Treg setup guide](https://treg.to/llms.txt).
2. Sign in, confirm the active team and balance, and inspect the endpoint.

```bash
treg login
treg
treg catalog get firecrawl.web.scrape
```

3. Run one scrape with the example URL, then replace it with your own.

```bash
treg call firecrawl.web.scrape --method POST --data '{"url":"https://example.com","formats":["markdown"],"maxAge":0,"parsers":[]}'
```

### Read the result

The catalog’s example response includes the following fields. Read `data.markdown` for the page content.

```json
{
  "success": true,
  "data": {
    "markdown": "# Example Domain\n\nThis domain is for use in documentation examples."
  }
}
```

## Scrape formats

| Format | What your agent gets |
| --- | --- |
| `markdown` | Readable page text for summarizing or quoting. |
| `html` | Page markup for a parser. |
| `links` | URLs to use in a follow-up step. |

## Accounts and billing

With Treg-managed credentials, Treg supplies the Firecrawl key and bills the team's prepaid balance. Check the endpoint’s quote before starting a request. For a backend, send the team token in `X-Treg-Token` and set `X-Treg-Route-Max-Cost` to your maximum USD cost per call.

## Troubleshooting

| What you see | What to check |
| --- | --- |
| The CLI is signed out or shows the wrong team | Run `treg login`, then `treg` to check the active team. |
| HTTP 402 with `insufficient_balance` | Check the team's prepaid balance before retrying. |
| HTTP 402 with `route_max_cost` | Compare the current quote with the limit your backend sent. |
