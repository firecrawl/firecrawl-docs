## Buy through Google Cloud Marketplace

Firecrawl is listed on [Google Cloud Marketplace](https://console.cloud.google.com/marketplace/product/firecrawl-public/firecrawl) and sold there through private offers. Google handles the billing, so Firecrawl charges appear on your Google Cloud bill. A Marketplace purchase can also draw down your Google Cloud spend commitment; confirm the terms of your agreement with your Google account team.

## Get an API key

Gemini CLI and Antigravity can start keyless through the hosted MCP server, which exposes Search, Scrape, and Parse. For the Gemini and ADK guides, and for the broader tool surface, get an API key from your [Firecrawl dashboard](https://www.firecrawl.dev/app/api-keys). Set it as `FIRECRAWL_API_KEY` in the environment your code runs in.

For a product overview, see [Firecrawl for Google Cloud](https://www.firecrawl.dev/integrations/google-cloud) on firecrawl.dev.
