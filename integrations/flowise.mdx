## Sync web data in Flowise workflows

Firecrawl can be used inside of [Flowise the Chatflow builder](https://flowiseai.com/). This page introduces how to configure and use a Firecrawl block inside of Flowise.

<img
  className="block"
  src="/images/fc_flowise_block.png"
  alt="Firecrawl Flowise block"
/>

### Crawling with Firecrawl blocks

1. Log in to your Firecrawl account and get your API Key, and then add it to the block as a **FireCrawl API** credential.
2. (Optional) Connect Text Splitter.
3. Set **Type** to **Crawl** to pick up the pages below the target URL.
4. Input target URL to be crawled. Use **Limit**, **Include Paths**, and **Exclude Paths** to keep the crawl small.
5. Use the resulting documents in your workflows.

### Scraping with Firecrawl blocks

1. Log in to your Firecrawl account and get your API Key, and then add it to the block as a **FireCrawl API** credential.
2. (Optional) Connect Text Splitter.
3. Set **Type** to **Scrape** to pick up a single page.
4. Input target URL to be scraped.
5. Use the resulting documents in your workflows.

### Searching and extracting with Firecrawl blocks

Set **Type** to **Search** to turn web search results for a **Query** into documents, or to **Extract** to return structured data from a URL using a **Schema** and **Prompt**.
