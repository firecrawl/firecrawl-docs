## Using Firecrawl with CrewAI

Firecrawl is the context API for AI agents, and [CrewAI, the framework for orchestrating AI agents](https://www.crewai.com/), ships three Firecrawl tools: FirecrawlSearchTool, FirecrawlScrapeWebsiteTool and FirecrawlCrawlWebsiteTool. Use them to let your crews search, scrape, and crawl the web for clean context.

### Installing Firecrawl Tools inside of CrewAI

- Get an API key from your [firecrawl.dev dashboard](https://www.firecrawl.dev/app/api-keys) and set it in environment variables (`FIRECRAWL_API_KEY`).
- Install the [Firecrawl SDK](https://github.com/firecrawl/firecrawl) along with `crewai[tools]` package:

```
pip install firecrawl-py 'crewai[tools]'
```

Each tool takes its Firecrawl options in a `config` dict at construction time. The URL or query comes from the agent when it calls the tool, so you only pass options up front.

## Tools

### FirecrawlCrawlWebsiteTool

#### Example

Utilize the FirecrawlCrawlWebsiteTool as follows to allow your agent to crawl websites:

```python
from crewai_tools import FirecrawlCrawlWebsiteTool

tool = FirecrawlCrawlWebsiteTool(config={"limit": 5})

# Agents call the tool with a URL. You can also run it directly:
result = tool.run(url="https://firecrawl.dev")
print(result.status, len(result.data))
```

#### Arguments

- `api_key`: Optional. Specifies Firecrawl API key. Defaults is the `FIRECRAWL_API_KEY` environment variable.
- `config`: Optional. [Crawl parameters](/api-reference/endpoint/crawl-post) in snake_case. Passing `config` replaces the defaults below.
  - `limit`: Maximum number of pages to crawl. Default: `10`.
  - `max_discovery_depth`: Maximum depth for discovering pages. Default: `2`.
  - `ignore_sitemap`: Whether to ignore the sitemap. Default: `True`.
  - `allow_external_links`: Allow crawling external links. Default: `False`.
  - `allow_subdomains`: Allow crawling subdomains. Default: `False`.
  - `delay`: Delay between requests in milliseconds. Default: `None`.
  - `scrape_options`: Options for each crawled page. Default: `{"formats": ["markdown"], "only_main_content": True, "timeout": 10000}`.

### FirecrawlScrapeWebsiteTool

#### Example

Utilize the FirecrawlScrapeWebsiteTool as follows to allow your agent to load websites:

```python
from crewai_tools import FirecrawlScrapeWebsiteTool

tool = FirecrawlScrapeWebsiteTool(config={"formats": ["markdown"], "only_main_content": True})

result = tool.run(url="https://firecrawl.dev")
print(result.markdown)
```

#### Arguments

- `api_key`: Optional. Specifies Firecrawl API key. Defaults is the `FIRECRAWL_API_KEY` environment variable.
- `config`: Optional. [Scrape parameters](/api-reference/endpoint/scrape) in snake_case. Passing `config` replaces the defaults below.
  - `formats`: Output formats, such as `"markdown"`, `"html"`, `"links"`, or a JSON format object for structured extraction. Default: `["markdown"]`.
  - `only_main_content`: Only return the main content of the page excluding headers, navs, footers, etc. Default: `True`.
  - `include_tags` / `exclude_tags`: HTML tags to include or exclude. Default: `[]`.
  - `max_age`: Return a cached version if it is younger than this many milliseconds. Default: `172800000` (2 days).
  - `wait_for`: Delay in milliseconds before fetching content. Default: `0`.
  - `mobile`: Emulate a mobile device. Default: `False`.
  - `timeout`: Timeout in milliseconds for the request. Default: `None`.

### FirecrawlSearchTool

#### Example

Utilize the FirecrawlSearchTool as follows to allow your agent to search the web:

```python
from crewai_tools import FirecrawlSearchTool

tool = FirecrawlSearchTool(config={"limit": 3})

result = tool.run(query="what is firecrawl?")
print([item.url for item in result.web])
```

#### Arguments

- `api_key`: Optional. Specifies Firecrawl API key. Defaults is the `FIRECRAWL_API_KEY` environment variable.
- `config`: Optional. [Search parameters](/api-reference/endpoint/search) in snake_case. Passing `config` replaces the defaults below.
  - `limit`: Maximum number of search results to return. Default: `5`.
  - `tbs`: Time-based search filter, for example `"qdr:d"` for the past day. Default: `None`.
  - `location`: Location for search results. Default: `None`.
  - `timeout`: Timeout in milliseconds for the request. Default: `None`.
  - `scrape_options`: Scrape each result and return its content. Default: `{"formats": ["markdown"], "only_main_content": True}`. Leave it out to get only titles, URLs, and descriptions.
