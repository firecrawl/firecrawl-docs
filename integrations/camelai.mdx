<Note>
**Official CAMEL docs:** [docs.camel-ai.org/key_modules/loaders](https://docs.camel-ai.org/key_modules/loaders)

Firecrawl ships as a CAMEL loader that lets your agents search, scrape, crawl, and map the web, returning clean context as Markdown or structured data.
</Note>

## Installation

```bash
pip install "camel-ai[web-tools]"
```

The `web-tools` extra installs the Firecrawl SDK version the loader supports. A plain `pip install camel-ai` doesn't include it, and the current CAMEL release fails with `firecrawl-py` 4.x, so don't upgrade `firecrawl-py` separately in the same environment.

Set your Firecrawl key so the loader picks it up automatically:

```bash
export FIRECRAWL_API_KEY="fc-your-api-key"
```

## Usage

With Camel AI and Firecrawl you can quickly build multi-agent systems that use data from the web.

### Using Firecrawl to Gather an Entire Website

`crawl` returns once the job finishes. Check `status`, then read the markdown from `data`.

```python
from camel.loaders import Firecrawl

firecrawl = Firecrawl()

response = firecrawl.crawl(url="https://www.camel-ai.org/about")
print(response["status"])  # "completed" when the crawl has finished

print(response["data"][0]["markdown"])
```

### Using Firecrawl to Gather a Single Page

```python
from camel.loaders import Firecrawl

firecrawl = Firecrawl()

response = firecrawl.scrape(url="https://www.camel-ai.org/about")
print(response["markdown"])
```

### Mapping a Site and Extracting Structured Data

`map_site` lists a site's URLs, and `structured_scrape` returns fields that match a Pydantic model.

```python
from pydantic import BaseModel
from camel.loaders import Firecrawl


class About(BaseModel):
    mission: str


firecrawl = Firecrawl()

print(firecrawl.map_site(url="https://www.camel-ai.org")["links"][:5])
print(firecrawl.structured_scrape(url="https://www.camel-ai.org/about", response_format=About))
```

<Tip>
`Firecrawl()` reads `FIRECRAWL_API_KEY` from the environment. Pass `api_key=...` to override it, or `api_url=...` to point at a [self-hosted](/contributing/self-host) instance.
</Tip>
