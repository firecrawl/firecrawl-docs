## Install Firecrawl

<Steps>
  <Step title="Open the Firecrawl plugin">
    Click **Add to ChatGPT & Codex** above to open the official Firecrawl listing in the shared plugin directory. In ChatGPT & Codex, you can also open **Plugins** and search for **Firecrawl**.
  </Step>
  <Step title="Install and connect">
    Select **Install**, then sign in to Firecrawl and approve the connection when prompted.
  </Step>
  <Step title="Start a new chat">
    Start a new chat in ChatGPT & Codex so it can load the plugin. Ask it to use Firecrawl with the prompt below.
  </Step>
</Steps>

The plugin includes Firecrawl tools and skills. You do not need to configure an MCP server or install skills separately.

## Try it in ChatGPT & Codex

Ask Firecrawl to find and read current sources:

```text
Use Firecrawl to find the latest Next.js release notes.
Read the official sources and summarize what changed, with links.
```

## If Firecrawl does not appear

- Start a new chat or restart ChatGPT & Codex after installing the plugin.
- Check that Firecrawl is installed and enabled in **Plugins**.
- If sign-in did not finish, open the plugin and reconnect your Firecrawl account.
