## Install Firecrawl

<Steps>
  <Step title="Open the Firecrawl plugin">
    Click **Add to ChatGPT** or **Add to Codex** above. Both open the official Firecrawl listing in the shared plugin directory. In the Codex app, you can also open **Plugins** and search for **Firecrawl**.
  </Step>
  <Step title="Install and connect">
    Select **Install**, then sign in to Firecrawl and approve the connection when prompted.
  </Step>
  <Step title="Start a new chat">
    Open a new ChatGPT conversation or Codex session so it can load the plugin. Ask it to use Firecrawl with one of the prompts below.
  </Step>
</Steps>

The plugin includes Firecrawl tools and skills. You do not need to configure an MCP server or install skills separately.

## Try it in ChatGPT

Research a topic, compare products, or turn a page into useful data. Ask for Firecrawl by name:

```text
Use Firecrawl to compare the current pricing of three hosted vector databases.
Read their official pricing pages and cite the sources.
```

```text
Use Firecrawl to scrape https://news.ycombinator.com and give me the top
10 stories with their links and scores.
```

## Try it in Codex

Bring current documentation and examples into your coding session:

```text
Use Firecrawl to find and read the latest migration guide for this project's
framework, then update the code and run the relevant checks.
```

```text
Use Firecrawl to search the official docs and GitHub issues for this error.
Explain what you found before fixing it in this repo.
```

## Prefer the Codex CLI?

For a direct MCP connection, run:

```bash
codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth
codex mcp login firecrawl
```

Complete the browser sign-in, then start a new Codex session. See the [Codex CLI guide](/quickstarts/codex-cli) for verification and troubleshooting, or [keyless MCP](/mcp-server/keyless) to try Search, Scrape, and Parse without an account.

## If Firecrawl does not appear

- Start a new chat or restart Codex after installing the plugin.
- Check that Firecrawl is installed and enabled in **Plugins**.
- If sign-in did not finish, open the plugin and reconnect your Firecrawl account.
