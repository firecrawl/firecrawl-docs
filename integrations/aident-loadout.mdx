## Overview

[Aident Loadout](https://aident.ai) is a remote MCP server that connects Codex, Claude Code, Cursor, ChatGPT and other MCP clients to 1,000+ apps, Firecrawl among them, through one setup. Your agent searches for the Firecrawl action it needs by intent, reads the live schema, checks the cost, and runs it. Every call is recorded in Loadout's Audit log.

## Quick start

1. Add the Loadout MCP server to your agent. In Claude Code:

   ```bash
   claude mcp add --transport http aident https://loadout.aident.ai/mcp
   ```

   In ChatGPT or Claude Desktop, add a custom connector with the URL `https://loadout.aident.ai/mcp`. For other coding agents, paste the setup prompt `Follow https://aident.ai/SETUP.md`.

2. Sign in to Aident in the browser when your agent first connects (OAuth).

3. Ask your agent to use Firecrawl, for example: *"Use Firecrawl through Aident to scrape https://docs.firecrawl.dev and summarize the main features."*

4. Open Audit in [Loadout](https://loadout.aident.ai) to see what ran, from which agent, and what it cost.

## What you can do

| Capability | Use case |
|------------|----------|
| **Search** | Search the web and scrape the top results in one call |
| **Scrape** | Fetch a page as clean markdown for agent context |
| **Batch scrape** | Pull many URLs in one job |
| **Crawl** | Gather multi-page site data, then check status or cancel the job |
| **Map** | List a site's URLs before deciding what to pull |
| **Extract** | Return structured fields that match a JSON schema |
| **Agent** | Start an agentic extraction job that navigates across pages |
