## Overview

Lovable apps can use Firecrawl to scrape and crawl websites into clean Markdown or structured data in chat while you build and in published apps. Firecrawl is available as an app and chat connector.

## Quick start

1. Open **Connectors** in Lovable and select **Firecrawl**
2. Add a connection with **Managed by Lovable** (no Firecrawl account needed), or **Use your own credentials** with your own Firecrawl API key
3. Link the connection to your project, then ask Lovable to scrape or crawl with Firecrawl

## What you can build

| Capability | Use case |
|------------|----------|
| **Search** | Search the web and get the content of the pages it finds |
| **Map** | List every URL on a site before you crawl it |
| **Scrape** | Turn URLs into clean markdown or structured JSON |
| **Crawl** | Gather pages across a site, including subpages |
| **Structured data** | Pull fields like product details, tables, and metadata with Scrape's JSON format |
