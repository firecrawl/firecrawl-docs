```python Python
from firecrawl import Firecrawl

app = Firecrawl(api_key="fc-YOUR_API_KEY")

# Spark 2 es el predeterminado — todas las ejecuciones se realizan con él
result = app.agent(
    prompt="Find the pricing of Firecrawl",
    model="spark-2"
)

# Obsoleto: los nombres de modelo de Spark 1 se siguen aceptando, pero se redirigen a "spark-2".

print(result.data)
```
