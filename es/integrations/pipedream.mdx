## Descripción general {#overview}

Usa la aplicación de Firecrawl para Pipedream para hacer scraping de páginas, rastrear sitios, buscar en la web, mapear URL y extraer datos estructurados como acciones en tus flujos de trabajo.

## Inicio rápido {#quick-start}

1. Abre la [aplicación de Firecrawl en Pipedream](https://pipedream.com/apps/firecrawl/)
2. Conecta tu clave de API de Firecrawl
3. Añade acciones de Firecrawl a un flujo de trabajo nuevo o existente

## Qué puedes hacer {#what-you-can-do}

| Acción           | Caso de uso                                                                                              |
| ---------------- | -------------------------------------------------------------------------------------------------------- |
| **Scrape Page**  | Obtén el contenido de una página cuando se dispara un webhook o una programación                         |
| **Crawl URL**    | Inicia una tarea de rastreo de varias páginas (consulta su estado con **Get Crawl Data**)                |
| **Search**       | Descubre fuentes antes de los pasos posteriores                                                          |
| **Map URL**      | Enumera las URL de un sitio, con la opción de filtrarlas por un término de búsqueda                      |
| **Extract Data** | Obtén datos estructurados de una o varias URL (comprueba un trabajo en curso con **Get Extract Status**) |
