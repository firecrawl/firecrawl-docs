<div id="overview">
  ## Descripción general
</div>

Usa la aplicación de Firecrawl para Pipedream para hacer scraping de páginas, rastrear sitios, buscar en la web, mapear URL y extraer datos estructurados como acciones en tus flujos de trabajo.

<div id="quick-start">
  ## Inicio rápido
</div>

1. Abre la [aplicación de Firecrawl en Pipedream](https://pipedream.com/apps/firecrawl/)
2. Conecta tu clave de API de Firecrawl
3. Añade acciones de Firecrawl a un flujo de trabajo nuevo o existente

<div id="what-you-can-do">
  ## Lo que puedes hacer
</div>

| Capacidad   | Caso de uso                                                                     |
| ----------- | ------------------------------------------------------------------------------- |
| **Scrape**  | Obtén el contenido de una página cuando se active un webhook o una programación |
| **Crawl**   | Inicia un trabajo de crawl de varias páginas (consulta con Get Crawl Data)      |
| **Search**  | Descubre fuentes antes de los pasos posteriores                                 |
| **Map**     | Enumera las URL de un sitio, opcionalmente filtradas por un término de búsqueda |
| **Extract** | Extrae datos estructurados de una o más URL                                     |
