<div id="firecrawl-actions">
  ## Acciones de Firecrawl
</div>

| Acción             | Caso de uso                                             |
| ------------------ | ------------------------------------------------------- |
| **/Scrape Page**   | Captura rápida de datos de una sola página              |
| **/Crawl Website** | Scraping completo de sitios web con varias páginas      |
| **/Extract Data**  | Extracción con IA mediante esquemas personalizados      |
| **/Search Data**   | Automatización de investigación con búsqueda + scraping |
| **/Map Data**      | Análisis SEO y mapeo de la estructura del sitio         |

<div id="quick-reference">
  ## Referencia rápida
</div>

<CardGroup cols={2}>
  <Card title="Primeros pasos" icon="play">
    1. Regístrate en [firecrawl.dev](https://firecrawl.dev)
    2. Obtén tu clave de API
    3. Crea un Zap en Zapier
    4. Conecta Firecrawl con tu clave de API
    5. Selecciona y activa tu flujo de trabajo
  </Card>

  <Card title="Prácticas recomendadas" icon="lightbulb">
    * Usa `/Scrape Page` para páginas individuales (es más rápido)
    * Programa las ejecuciones estratégicamente (cada hora, día o semana)
    * Primero prueba en el playground de Firecrawl
    * Añade manejo de errores para scrapings fallidos
    * Usa filtros para evitar ejecuciones innecesarias
  </Card>
</CardGroup>

<div id="zapier-vs-n8n">
  ## Zapier vs n8n
</div>

| Característica    | Zapier                                                      | n8n                                    |
| ----------------- | ----------------------------------------------------------- | -------------------------------------- |
| **Configuración** | Sin código y basado en la nube                              | Autogestionado o basado en la nube     |
| **Precios**       | Por tarea                                                   | Por ejecución                          |
| **Integraciones** | Más de 9.000 aplicaciones                                   | Más de 1.000 aplicaciones y servicios  |
| **Ideal para**    | Automatización rápida y usuarios sin conocimientos técnicos | Lógica personalizada y desarrolladores |

  **Consejo:** Empieza con las plantillas prediseñadas de Zapier y personalízalas según sea necesario. ¡Perfecto para automatizaciones rápidas sin código!
