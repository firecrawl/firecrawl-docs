## Descripción general {#overview}

Las aplicaciones de Lovable pueden usar Firecrawl para hacer extracción de datos web y realizar rastreo de sitios web, convirtiéndolos en Markdown limpio o datos estructurados en el chat durante el desarrollo y en las aplicaciones publicadas. Firecrawl está disponible como aplicación y conector de chat.

## Inicio rápido {#quick-start}

1. Abre **Connectors** en Lovable y selecciona **Firecrawl**
2. Añade una conexión con **Managed by Lovable** (no necesitas una cuenta de Firecrawl) o **Use your own credentials** con tu propia clave de API de Firecrawl
3. Vincula la conexión a tu proyecto y pídele a Lovable que haga scraping o rastreo con Firecrawl

## Lo que puedes crear {#what-you-can-build}

| Capacidad               | Caso de uso                                                                                |
| ----------------------- | ------------------------------------------------------------------------------------------ |
| **Búsqueda**            | Busca en la web y obtén el contenido de las páginas que encuentres                         |
| **Mapeo**               | Enumera todas las URL de un sitio antes de rastrearlo                                      |
| **extracción de datos web**            | Convierte URL en Markdown limpio o JSON estructurado                                       |
| **rastreo**             | Recopila páginas de un sitio, incluidas sus subpáginas                                     |
| **Datos estructurados** | Extrae campos como detalles de productos, tablas y metadatos con el formato JSON de extracción de datos web |
