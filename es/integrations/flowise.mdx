  ## Sincroniza datos web en flujos de trabajo de Flowise {#sync-web-data-in-flowise-workflows}
</div>

Firecrawl puede usarse dentro de [Flowise, el generador de Chatflows](https://flowiseai.com/). Esta página explica cómo configurar y usar un bloque de Firecrawl en Flowise.

<img
  className="block"
  src="/images/fc_flowise_block.png"
  alt="Bloque de Firecrawl en Flowise"
/>

### Rastreo con bloques de Firecrawl {#crawling-with-firecrawl-blocks}

1. Inicia sesión en tu cuenta de Firecrawl, obtén tu clave de API y agrégala al bloque como credencial de **FireCrawl API**.
2. (Opcional) Conecta Text Splitter.
3. Establece **Type** en **Crawl** para capturar las páginas que están por debajo de la URL de destino.
4. Introduce la URL de destino a rastrear. Usa **Limit**, **Include Paths** y **Exclude Paths** para limitar el alcance del rastreo.
5. Usa los documentos resultantes en tus flujos de trabajo.

### Extracción con bloques de Firecrawl {#scraping-with-firecrawl-blocks}

1. Inicia sesión en tu cuenta de Firecrawl, obtén tu clave de API y añádela en el bloque como credencial de **FireCrawl API**.
2. (Opcional) Conecta Text Splitter.
3. Establece **Type** en **Scrape** para procesar una sola página.
4. Ingresa la URL de destino que se va a extraer.
5. Usa los documentos resultantes en tus flujos de trabajo.

### Búsqueda y extracción con bloques de Firecrawl {#searching-and-extracting-with-firecrawl-blocks}

Configura **Type** como **Search** para convertir en documentos los resultados de búsqueda web de una consulta (**Query**), o como **Extract** para obtener datos estructurados de una URL con un **Schema** y un **Prompt**.
