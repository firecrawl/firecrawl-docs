<div id="overview">
  ## Descripción general
</div>

Praison AI puede invocar Firecrawl como herramienta para que los agentes hagan scraping de páginas web y usen el contenido depurado durante las ejecuciones.

<div id="quick-start">
  ## Inicio rápido
</div>

1. Instala el extra `tools`:

```bash
pip install "praisonai[tools]"
```

2. Configura `FIRECRAWL_API_KEY` para Firecrawl Cloud
3. Pasa una herramienta de Firecrawl a tu agente:

```python
from praisonaiagents import Agent
from praisonai_tools import FirecrawlTool

agent = Agent(
    name="WebScraper",
    instructions="You are a web scraping assistant. Use Firecrawl to extract content.",
    tools=[FirecrawlTool()],
)

print(agent.chat("Scrape the content from https://praison.ai/docs"))
```

<div id="what-you-can-do">
  ## Lo que puedes hacer
</div>

| Funcionalidad | Caso de uso                                                                                |
| ------------- | ------------------------------------------------------------------------------------------ |
| **Scraping**  | Obtén el contenido limpio de una página en el contexto del agente (`FirecrawlTool.scrape`) |
| **Crawl**     | Recopila páginas de un sitio (`FirecrawlTool.crawl(url, limit=10)`)                        |
