## Descripción general {#overview}

Las stories de Tines pueden llamar a cualquier API REST mediante la action HTTP Request. Si configuras esa action para que apunte a la API de Firecrawl, una story puede buscar en la web, extraer el contenido de una página en markdown, obtener datos estructurados, mapear un sitio o rastrearlo, y pasar el resultado a la siguiente action de la story.

## Inicio rápido {#quick-start}

1. [Crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys)
2. En Tines, abre **credenciales**, crea una credencial de tipo **Text** llamada `firecrawl` y pega la clave como valor
3. Añade una action **HTTP Request** a tu story y configúrala como se muestra a continuación

Al hacer referencia a la clave como `<<CREDENTIAL.firecrawl>>`, esta no queda expuesta en la configuración de la action.

## Extraer datos de una página {#scrape-a-page}

Esta action envía una solicitud de extracción de datos web y devuelve la página en formato markdown:

```json
{
  "url": "https://api.firecrawl.dev/v2/scrape",
  "method": "post",
  "content_type": "json",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  },
  "payload": {
    "url": "https://example.com",
    "formats": ["markdown"],
    "integration": "_tines"
  }
}
```

Sustituye `https://example.com` por una URL de un evento upstream, por ejemplo, `<<receive_event.body.url>>`. El campo opcional `integration` identifica las solicitudes que proceden de Tines.

## Qué puedes hacer {#what-you-can-do}

| Capacidad      | Punto de conexión                       | Caso de uso                                                                               |
| -------------- | --------------------------------------- | ----------------------------------------------------------------------------------------- |
| **Búsqueda**   | `POST /v2/search`                       | Encuentra fuentes para una pregunta o alerta antes de realizar otras actions             |
| **Scraping**   | `POST /v2/scrape`                       | Convierte una URL en markdown o JSON estructurado                                         |
| **Extracción** | `POST /v2/scrape` con el formato `json` | Obtén campos como un título o los detalles de un producto mediante un prompt y un esquema |
| **Mapeo**      | `POST /v2/map`                          | Enumera las URL de un sitio                                                               |
| **Rastreo**    | `POST /v2/crawl`                        | Recopila páginas de todo un sitio y luego consulta el resultado                           |

Todos los endpoints usan la URL base `https://api.firecrawl.dev`, la misma cabecera `Authorization` y un cuerpo JSON.

## Buscar en la web {#search-the-web}

```json
{
  "url": "https://api.firecrawl.dev/v2/search",
  "method": "post",
  "content_type": "json",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  },
  "payload": {
    "query": "firecrawl web scraping",
    "limit": 5,
    "sources": ["web"],
    "integration": "_tines"
  }
}
```

## Extraer datos estructurados {#extract-structured-data}

Configura la entrada de `formats` con el tipo `json`, junto con un prompt y un esquema JSON:

```json
{
  "url": "https://api.firecrawl.dev/v2/scrape",
  "method": "post",
  "content_type": "json",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  },
  "payload": {
    "url": "https://example.com",
    "formats": [
      {
        "type": "json",
        "prompt": "Extract the page title",
        "schema": {
          "type": "object",
          "properties": { "title": { "type": "string" } }
        }
      }
    ],
    "integration": "_tines"
  }
}
```

## Rastrear un sitio {#crawl-a-site}

Un rastreo se ejecuta de forma asincrónica. Usa una action para iniciarlo y otra para leer el resultado.

**Inicia el rastreo** con `POST /v2/crawl`:

```json
{
  "url": "https://api.firecrawl.dev/v2/crawl",
  "method": "post",
  "content_type": "json",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  },
  "payload": {
    "url": "https://example.com",
    "limit": 10,
    "integration": "_tines"
  }
}
```

La respuesta incluye un `id`. **Comprueba el estado** con una segunda action HTTP Request que consulte el rastreo por ese `id` y repítela hasta que el `status` sea `completed`:

```json
{
  "url": "https://api.firecrawl.dev/v2/crawl/<<start_crawl.body.id>>",
  "method": "get",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  }
}
```

Aquí, `start_crawl` es el nombre de la action que inició el rastreo.
