## Descripción general {#overview}

[Neuron AI](https://neuron-ai.dev) es un framework agéntico para PHP. Incluye un toolkit de Firecrawl que permite a un agente de Neuron buscar en la web y leer cualquier página como Markdown limpio durante una ejecución.

## Inicio rápido {#quick-start}

1. Instala Neuron AI 4.1.3 o una versión posterior:

```bash
composer require neuron-core/neuron-ai:^4.1.3
```

2. Obtén una clave de API desde tu [Dashboard de Firecrawl](https://www.firecrawl.dev/app/api-keys) y configúrala como `FIRECRAWL_API_KEY`
3. Añade el toolkit a tu agente:

```php
namespace App\Neuron;

use NeuronAI\Agent\Agent;
use NeuronAI\Tools\Toolkits\Firecrawl\FirecrawlToolkit;

class ResearchAgent extends Agent
{
    ...

    protected function tools(): array
    {
        return [
            FirecrawlToolkit::make(
                key: getenv('FIRECRAWL_API_KEY')
            ),
        ];
    }
}
```

## Herramientas {#tools}

| Herramienta           | Nombre que ve el agente | Qué hace                                                                                 |
| --------------------- | ----------------------- | ---------------------------------------------------------------------------------------- |
| `FirecrawlSearchTool` | `web_search`            | Busca en la web, o en noticias si el agente lo pide, con un intervalo de tiempo opcional |
| `FirecrawlScrapeTool` | `url_reader`            | Devuelve el contenido principal de una página en Markdown                                |

También puedes añadir cualquiera de las dos herramientas por separado, por ejemplo, `FirecrawlSearchTool::make(key: getenv('FIRECRAWL_API_KEY'))`.

## Obtén el contenido de la página con cada resultado de búsqueda {#get-page-content-with-each-search-result}

De forma predeterminada, una búsqueda devuelve el título, la URL y la descripción de cada resultado. Si pasas `scrapeOptions`, cada resultado incluye además la página completa en Markdown, así que el agente no necesita hacer una segunda llamada para leerla:

```php
use NeuronAI\Tools\Toolkits\Firecrawl\FirecrawlSearchTool;

FirecrawlSearchTool::make(key: getenv('FIRECRAWL_API_KEY'))->withOptions([
    'limit' => 5,
    'scrapeOptions' => [
        'formats' => ['markdown'],
        'onlyMainContent' => true,
    ],
]);
```

`withOptions()` sustituye los valores predeterminados y acepta cualquier [parámetro de búsqueda](/es/api-reference/endpoint/search). La consulta de búsqueda siempre la proporciona el agente.
