<Note>
  **Documentación oficial de Stripe:** [docs.stripe.com/projects](https://docs.stripe.com/projects) · [Firecrawl en el directorio de proveedores](https://projects.dev/providers/)

  Firecrawl es un proveedor de Stripe Projects. Agrégalo a cualquier proyecto con `stripe projects add firecrawl/api`.
</Note>

<div id="overview">
  ## Descripción general
</div>

[Stripe Projects](https://projects.dev) aprovisiona servicios de terceros desde la terminal y sincroniza sus credenciales con tu `.env`. Firecrawl es uno de los proveedores, así que basta un comando para crear una cuenta de Firecrawl, escribir una clave de API en tu proyecto y elegir un plan. Los planes de pago se cobran con el método de pago de tu cuenta de Stripe.

| Qué obtienes     | Detalle                                                                                                                          |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **Cuenta**       | Una cuenta de Firecrawl asociada al correo de tu cuenta de Stripe. Si ese correo ya tiene una cuenta de Firecrawl, se reutiliza. |
| **Clave de API** | Una clave de API del workspace escrita en tu `.env`. Una sola clave cubre todos los endpoints de Firecrawl.                      |
| **Plan**         | Free de forma predeterminada. Cambia a Hobby, Standard o Growth, con facturación mensual o anual, desde la CLI.                  |
| **Dashboard**    | `stripe projects open firecrawl` inicia tu sesión en el Dashboard de Firecrawl.                                                  |

<div id="quick-start">
  ## Inicio rápido
</div>

```bash
stripe plugin install projects
stripe projects init
stripe projects add firecrawl/api --name firecrawl
stripe projects env --pull
```

`--name firecrawl` define el nombre del recurso local, que pasa a ser el prefijo de las variables que escribe la CLI. Con esta opción, la clave queda en `FIRECRAWL_API_KEY`, que los [SDKs](/es/sdks/overview) y la [CLI](/es/sdks/cli) de Firecrawl leen automáticamente. Sin ella, el recurso se llama `firecrawl-api` y la clave queda en `FIRECRAWL_API_API_KEY`.

La CLI también escribe `FIRECRAWL_API_BASE_URL` y `FIRECRAWL_DOCUMENTATION_URL`. Ambas son informativas. Los SDKs leen `FIRECRAWL_API_URL`, y solo en despliegues autogestionados; una cuenta aprovisionada mediante Stripe usa la API alojada, que es la opción predeterminada, así que deja `FIRECRAWL_API_URL` sin definir.

A partir de aquí, sigue el inicio rápido de [Node.js](/es/quickstarts/nodejs) o [Python](/es/quickstarts/python), o la [descripción general de los SDKs](/es/sdks/overview) para otros lenguajes. La clave funciona con todos los endpoints: [search](/es/features/search), [scrape](/es/features/scrape), [crawl](/es/features/crawl), [map](/es/features/map), [extract](/es/features/extract), [interact](/es/features/interact), [parse](/es/features/parse) y [monitor](/es/features/monitoring).

<div id="catalog">
  ## Catálogo
</div>

Ejecuta `stripe projects catalog firecrawl` para ver la lista actualizada. La CLI muestra el precio final antes de que confirmes nada.

| Slug                 | Tipo     | Qué es                                                                                            |
| -------------------- | -------- | ------------------------------------------------------------------------------------------------- |
| `firecrawl/api`      | Servicio | La API de Firecrawl. Aprovisiona la cuenta y la clave de API. Nivel Free de forma predeterminada. |
| `firecrawl/free`     | Plan     | El plan Free. No requiere tarjeta.                                                                |
| `firecrawl/hobby`    | Plan     | El plan Hobby. Pide elegir `Monthly` o `Yearly`.                                                  |
| `firecrawl/standard` | Plan     | El plan Standard. Pide elegir `Monthly` o `Yearly`.                                               |
| `firecrawl/growth`   | Plan     | El plan Growth. Pide elegir `Monthly` o `Yearly`.                                                 |

Los planes y precios coinciden con [firecrawl.dev/pricing](https://www.firecrawl.dev/pricing). Scale y Enterprise no se ofrecen a través de Stripe Projects; para esos casos, [habla con nosotros](https://www.firecrawl.dev/enterprise).

<div id="manage-the-resource">
  ## Gestionar el recurso
</div>

```bash
# Agrega un método de pago a tu cuenta de Stripe (solo una vez)
stripe projects billing add

# Cambia a un plan de pago; la CLI te pregunta qué plan y qué intervalo de facturación
stripe projects upgrade firecrawl

# Rota la clave de API y luego trae el nuevo valor a .env
stripe projects rotate firecrawl
stripe projects env --pull

# Elimina Firecrawl de este proyecto
stripe projects remove firecrawl
```

Las mejoras de plan usan un [Shared Payment Token](https://docs.stripe.com/agentic-commerce/concepts/shared-payment-tokens) de Stripe, por lo que Firecrawl nunca ve los datos de tu tarjeta. El plan aparece en tu Dashboard de Firecrawl como cualquier otra suscripción. Para volver a Free, ejecuta `stripe projects upgrade firecrawl` y elige `free`, o cambia el plan desde [Billing](https://www.firecrawl.dev/app/settings?tab=billing) en el Dashboard.

<div id="accounts-and-billing">
  ## Cuentas y facturación
</div>

* **Una cuenta de Stripe, una cuenta de Firecrawl.** Firecrawl consulta el correo de tu cuenta de Stripe. Un correo nuevo obtiene una cuenta de Firecrawl nueva, ya verificada, con un equipo y una clave de API predeterminada. Un correo que ya tiene una cuenta de Firecrawl reutiliza el equipo que vinculó antes mediante Stripe; la primera vez, obtiene un equipo nuevo llamado `via stripe` en su propia organización, de modo que la facturación de Stripe se mantiene separada de tus demás equipos de Firecrawl.
* **Cualquier persona de la cuenta de Stripe puede operar sobre la cuenta de Firecrawl vinculada** a través de Projects, conforme al modelo de Stripe. El Dashboard de Firecrawl muestra la cuenta bajo el correo de la cuenta de Stripe.
* **Los planes de pago son suscripciones de Firecrawl**, se pagan con tu Shared Payment Token y se reportan en `stripe projects spend`. Los créditos, los límites de tasa y las funciones coinciden con los del mismo plan comprado en firecrawl.dev.

<div id="coding-agents">
  ## Agentes de programación
</div>

Stripe Projects está pensado tanto para agentes como para personas. Stripe publica una [skill](https://docs.stripe.com/projects#coding-agent) que enseña la CLI de Stripe Projects a Claude Code, Cursor, Codex y otros agentes, y `stripe projects llm-context` reúne esta página junto con las indicaciones de todos los demás proveedores del proyecto.

```bash
npx skills add https://docs.stripe.com --skill stripe-projects -g -y
```

Cuando un agente aprovisiona Firecrawl: copia el slug que devuelve `stripe projects catalog firecrawl --json` en lugar de adivinarlo, pasa `--name firecrawl`, ejecuta `stripe projects env --pull` y usa `FIRECRAWL_API_KEY` desde el entorno en lugar de editar `.env`, y deja las mejoras de plan de pago en manos de la persona, ya que se cobran a la tarjeta de la cuenta de Stripe. `--accept-tos` acepta los [Términos de servicio de Firecrawl](https://www.firecrawl.dev/terms-of-service) en nombre de la persona, así que confírmalo con ella antes. El resto de la configuración del agente está en [Crear con IA](/es/ai-onboarding).

<div id="troubleshooting">
  ## Solución de problemas
</div>

| Qué ves                                          | Qué hacer                                                                                                                                                |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Provider connection requires re-authentication` | Ejecuta `stripe projects link firecrawl` y vuelve a intentarlo.                                                                                          |
| `Unknown provider or category: firecrawl`        | Ejecuta `stripe plugin upgrade projects` y luego `stripe projects catalog firecrawl --refresh`.                                                          |
| Falla el aprovisionamiento de pago               | Ejecuta `stripe projects billing add` para confirmar un método de pago. Si tu cuenta de Firecrawl ya tiene un plan de pago, cámbialo desde el Dashboard. |
| La clave termina en `FIRECRAWL_API_API_KEY`      | Aprovisionaste sin `--name`. Expórtala como `FIRECRAWL_API_KEY` o elimina el recurso y vuelve a añadirlo con `--name firecrawl`.                         |

¿Sigues sin resolverlo? Envía un correo a [help@firecrawl.com](mailto:help@firecrawl.com) con el id de solicitud de Stripe que aparece en el error.
