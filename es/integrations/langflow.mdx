  ## Sincroniza datos web en flujos de trabajo de Langflow {#sync-web-data-in-langflow-workflows}

Firecrawl puede usarse dentro de [Langflow, el constructor de flujos de trabajo de IA](https://www.langflow.org/). Esta página explica cómo configurar y usar un bloque de Firecrawl dentro de Langflow.

### Instalación del paquete de Firecrawl {#installing-the-firecrawl-bundle}

Los bloques de Firecrawl se incluyen en el paquete `lfx-firecrawl`, que no forma parte de la instalación predeterminada de Langflow. Instálalo en el mismo entorno que Langflow y, después, reinicia Langflow:

```bash
uv pip install lfx-firecrawl
```

El paquete añade cuatro bloques: **Firecrawl Scrape API**, **Firecrawl Crawl API**, **Firecrawl Map API** y **Firecrawl Search API**. Cada uno devuelve la respuesta de la API de Firecrawl como `Data`. Consulta la [documentación del paquete de Firecrawl para Langflow](https://docs.langflow.org/bundles-firecrawl) para ver la lista completa de parámetros.

### Scraping con bloques de Firecrawl {#scraping-with-firecrawl-blocks}

1. Inicia sesión en tu cuenta de Firecrawl y obtén tu clave de API; luego ingrésala en el bloque o pásala desde otra parte del flujo de trabajo.
2. Agrega el bloque **Firecrawl Scrape API** para capturar una sola página.
3. Ingresa la URL de destino a extraer o pásala desde otra parte del flujo de trabajo.
4. Configura las opciones de extracción según el sitio web y los datos que necesitas, como los formatos de salida y si se debe devolver solo el contenido principal. También puedes pasarlas desde otra parte del flujo de trabajo.
5. (Opcional) Configura las **Opciones del Extractor** para obtener JSON estructurado de la página.
6. Usa los datos en tus flujos de trabajo.

### Rastreo, mapeo y búsqueda {#crawling-mapping-and-searching}

* **Firecrawl Crawl API** rastrea una URL y sus subpáginas. Define los límites y las rutas en **Crawler Options** (opciones del rastreador) y la configuración per-page en **Scrape Options** (opciones de extracción).
* **Firecrawl Map API** devuelve las URL de uno o varios sitios.
* **Firecrawl Search API** busca en la web a partir de una query, con un **Limit** de resultados y una **Location** (ubicación) opcionales.
