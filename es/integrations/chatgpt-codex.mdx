## Instalar Firecrawl {#install-firecrawl}

<Steps>
  <Step title="Abre el plugin de Firecrawl">
    Haz clic en **Add to ChatGPT &amp; Codex** (arriba) para abrir el listado oficial de Firecrawl en el directorio compartido de plugins. En ChatGPT &amp; Codex, también puedes abrir **Plugins** y buscar **Firecrawl**.
  </Step>

  <Step title="Instala y conecta">
    Selecciona **Install**, inicia sesión en Firecrawl y aprueba la conexión cuando se te pida.
  </Step>

  <Step title="Inicia un nuevo chat">
    Inicia un nuevo chat en ChatGPT &amp; Codex para que se cargue el plugin. Pídele que use Firecrawl con el siguiente prompt.
  </Step>
</Steps>

El plugin incluye herramientas y skills de Firecrawl. No necesitas configurar un MCP Server ni instalar skills por separado.

## Pruébalo en ChatGPT y Codex {#try-it-in-chatgpt-codex}

Pídele a Firecrawl que busque y lea fuentes actualizadas:

```text
Usa Firecrawl para encontrar las notas de la versión más reciente de Next.js.
Lee las fuentes oficiales y resume los cambios, con enlaces.
```

## Si Firecrawl no aparece {#if-firecrawl-does-not-appear}

* Inicia un chat nuevo o reinicia ChatGPT y Codex después de instalar el plugin.
* Comprueba que Firecrawl esté instalado y habilitado en **Plugins**.
* Si no se completó el inicio de sesión, abre el plugin y vuelve a conectar tu cuenta de Firecrawl.
