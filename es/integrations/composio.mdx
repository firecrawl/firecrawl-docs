<div id="overview">
  ## Descripción general
</div>

Composio ofrece Firecrawl como un kit de herramientas para que tus agentes puedan buscar, realizar scraping, rastrear, realizar mapeo y extraer datos sin necesidad de integrar la API manualmente. El kit de herramientas se autentica con una clave de API de Firecrawl.

<div id="quick-start">
  ## Inicio rápido
</div>

1. Conecta Firecrawl en el [panel de control de Composio](https://dashboard.composio.dev) con tu clave de API de Firecrawl
2. Consulta las herramientas disponibles en la [documentación del kit de herramientas de Firecrawl](https://docs.composio.dev/toolkits/firecrawl)
3. Llama a las herramientas de Firecrawl desde tus agentes o flujos de trabajo basados en Composio

<div id="what-you-can-do">
  ## Qué puedes hacer
</div>

| Funcionalidad    | Caso de uso                                                  |
| ---------------- | ------------------------------------------------------------ |
| **buscar**       | Descubre fuentes antes de realizar una extracción            |
| **scraping**     | Obtén el contenido de una página para el contexto del agente |
| **Batch scrape** | Extrae muchas URL en un solo trabajo                         |
| **Crawl**        | Recopila datos de sitios con varias páginas                  |
| **mapeo**        | Enumera las URL de un sitio antes de decidir qué extraer     |
| **extrae**       | Devuelve campos estructurados en lugar de texto sin procesar |
