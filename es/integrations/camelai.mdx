<Note>
  **Documentación oficial de CAMEL:** [docs.camel-ai.org/key&#95;modules/loaders](https://docs.camel-ai.org/key_modules/loaders)

  Firecrawl se ofrece como un cargador de CAMEL y convierte cualquier sitio en markdown preparado para LLM y tus agentes
</Note>

<div id="installation">
  ## Instalación
</div>

```bash
pip install camel-ai
```

Configura tu clave de Firecrawl para que el cargador la detecte automáticamente:

```bash
export FIRECRAWL_API_KEY="fc-your-api-key"
```

<div id="usage">
  ## Uso
</div>

Con Camel AI y Firecrawl puedes crear rápidamente sistemas multiagente que utilizan datos de la web.

<div id="using-firecrawl-to-gather-an-entire-website">
  ### Uso de Firecrawl para recopilar todo un sitio web
</div>

`crawl` devuelve el resultado cuando finaliza el trabajo. Comprueba `status` y luego lee el markdown de `data`.

```python
from camel.loaders import Firecrawl

firecrawl = Firecrawl()

response = firecrawl.crawl(url="https://www.camel-ai.org/about")
print(response["status"])  # "completed" cuando el crawl ha finalizado

print(response["data"][0]["markdown"])
```

<div id="using-firecrawl-to-gather-a-single-page">
  ### Usar Firecrawl para recopilar una sola página
</div>

```python
from camel.loaders import Firecrawl

firecrawl = Firecrawl()

response = firecrawl.scrape(url="https://www.camel-ai.org/about")
print(response["markdown"])
```

<Tip>
  `Firecrawl()` lee `FIRECRAWL_API_KEY` del entorno. Pasa `api_key=...` para sobrescribirla o `api_url=...` para usar una instancia [autogestionada](/es/contributing/self-host).
</Tip>
