</Warning>

Firecrawl ofrece distintos tipos de proxy para ayudarte a extraer datos de sitios web con diversos niveles de complejidad. El tipo de proxy puede especificarse con el parámetro `proxy`.

<div id="proxy-types">
  ### Tipos de proxy
</div>

* **basic**: Proxies para extraer datos de la mayoría de los sitios.
* **mejorado**: Proxies mejorados para extraer datos de sitios complejos manteniendo la privacidad.
* **auto**: Recomendado. Firecrawl reintentará automáticamente la extracción con proxies mejorado si el proxy basic falla.

Si no especificas un proxy, Firecrawl usará basic por defecto.
