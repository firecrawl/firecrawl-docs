<div id="introducing-llmstxt-generator-endpoint-alpha">
  ## Presentamos el punto de conexión generador de LLMs.txt (Alpha) 📃 {#introducing-llmstxt-generator-endpoint-alpha}
</div>

El punto de conexión `/llmstxt` te permite convertir cualquier sitio web en [archivos de texto listos para LLM](https://www.firecrawl.dev/blog/How-to-Create-an-llms-txt-File-for-Any-Website) y limpios. Solo tienes que proporcionar una URL y Firecrawl rastreará el sitio para generar los archivos `llms.txt` y `llms-full.txt`, utilizables para entrenamiento o análisis con cualquier LLM.

<div id="how-it-works">
  ## Cómo funciona {#how-it-works}
</div>

El generador de LLMs.txt:

1. Rastrea la URL del sitio web proporcionada y sus páginas vinculadas
2. Extrae contenido de texto limpio y relevante
3. Genera dos formatos:
   * `llms.txt`: Resúmenes concisos e información clave
   * `llms-full.txt`: Texto completo con más detalle

**Parámetros clave:**

* **url**: URL del sitio web del que generar los archivos LLMs.txt
* **maxUrls** (Opcional): Número máximo de páginas a rastrear (1-100; valor predeterminado: 10)
* **showFullText** (Opcional): Genera llms-full.txt además de llms.txt (valor predeterminado: false)

Consulta la [referencia de la API](/es/api-reference/endpoint/llmstxt) para más detalles.

<div id="known-limitations-alpha">
  ## Limitaciones conocidas (Alpha) {#known-limitations-alpha}
</div>

1. **Restricciones de acceso**\
   Solo se pueden procesar páginas de acceso público. No se admite contenido protegido por inicio de sesión o detrás de un muro de pago.

2. **Tamaño del sitio**\
   Durante la fase Alpha, solo permitimos procesar hasta 5000 URL.

3. **Estado Alpha**\
   Como función en Alpha, el formato de salida y el procesamiento pueden evolucionar según los comentarios.

## Facturación y uso {#billing-and-usage}

La facturación se basa en la cantidad de URLs procesadas:

- Costo base: 1 crédito por URL procesada
- Controla los costos de las URL con el parámetro `maxUrls`
