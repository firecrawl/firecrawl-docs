Conecta el Kit de desarrollo de agentes (ADK) de Google con Firecrawl mediante el Model Context Protocol (MCP) para que tus agentes puedan realizar búsquedas, scraping, rastreo y mapeo de la web y obtener contexto limpio.

<div id="overview">
  ## Descripción general {#overview}
</div>

Firecrawl ofrece un servidor MCP que se integra sin fricciones con el ADK de Google, permitiendo que tus agentes realicen scraping, crawling y extracción de datos estructurados de cualquier sitio web de manera eficiente. La integración es compatible tanto con instancias de Firecrawl en la nube como autogestionadas, con HTTP en streaming para un rendimiento óptimo.

## Funcionalidades {#features}

* web scraping, rastreo y descubrimiento de contenido eficientes en cualquier sitio
* Búsqueda avanzada y extracción inteligente de contenido
* Investigación web autónoma con el agente de Firecrawl
* Interacción con el navegador, análisis sintáctico de archivos y monitorización de cambios
* Despliegue flexible (en la nube o autogestionado)
* Optimizado para entornos web modernos con soporte Streamable HTTP

<div id="prerequisites">
  ## Requisitos previos {#prerequisites}
</div>

* Obtén una clave de API para Firecrawl en [firecrawl.dev](https://firecrawl.dev)
* Instala Google ADK con soporte para MCP: `pip install "google-adk[mcp]"`

## Configuración {#setup}

<CodeGroup>
  ```python Remote MCP Server
  import os

  from google.adk.agents.llm_agent import Agent
  from google.adk.tools.mcp_tool.mcp_session_manager import StreamableHTTPConnectionParams
  from google.adk.tools.mcp_tool.mcp_toolset import MCPToolset

  FIRECRAWL_API_KEY = os.environ["FIRECRAWL_API_KEY"]

  root_agent = Agent(
      model="gemini-3.8-flash",
      name="firecrawl_agent",
      description='Un asistente útil para extraer contenido de sitios web con Firecrawl',
      instruction='Ayuda al usuario a buscar contenido en sitios web',
      tools=[
          MCPToolset(
              connection_params=StreamableHTTPConnectionParams(
                  url="https://mcp.firecrawl.dev/v2/mcp",
                  headers={"Authorization": f"Bearer {FIRECRAWL_API_KEY}"},
              ),
          )
      ],
  )
  ```

  ```python Local MCP Server
  import os

  from google.adk.agents.llm_agent import Agent
  from google.adk.tools.mcp_tool.mcp_session_manager import StdioConnectionParams
  from google.adk.tools.mcp_tool.mcp_toolset import MCPToolset
  from mcp import StdioServerParameters

  root_agent = Agent(
      model='gemini-3.8-flash',
      name='firecrawl_agent',
      description='Un asistente útil para extraer contenido de sitios web con Firecrawl',
      instruction='Ayuda al usuario a buscar contenido en sitios web',
      tools=[
          MCPToolset(
              connection_params=StdioConnectionParams(
                  server_params = StdioServerParameters(
                      command='npx',
                      args=[
                          "-y",
                          "firecrawl-mcp@3.33.2",
                      ],
                      env={
                          "FIRECRAWL_API_KEY": os.environ["FIRECRAWL_API_KEY"],
                      }
                  ),
                  timeout=30,
              ),
          )
      ],
  )
  ```
</CodeGroup>

Configura `FIRECRAWL_API_KEY` en el entorno desde el que se inicia ADK. No incluyas su valor en los prompts del agente, el control de código fuente ni la URL del MCP. El paquete MCP local requiere Node.js 22 o una versión posterior.

## Herramientas disponibles {#available-tools}

| Herramienta                  | Nombre                                          | Descripción                                                                                  |
| ---------------------------- | ----------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Herramienta de scraping      | `firecrawl_scrape`                              | Extrae contenido de una única URL o datos estructurados en formato JSON                      |
| Herramienta de mapeo         | `firecrawl_map`                                 | Genera el mapa de un sitio para descubrir todas las URL indexadas                            |
| Herramienta de búsqueda      | `firecrawl_search`                              | Busca en la web y, opcionalmente, extrae contenido de los resultados                         |
| Herramienta de rastreo       | `firecrawl_crawl`                               | Rastrea un sitio o una sección y devuelve sus páginas                                        |
| Consultar estado del rastreo | `firecrawl_check_crawl_status`                  | Consulta el estado de un trabajo de rastreo                                                  |
| Herramienta de Análisis      | `firecrawl_parse`                               | Extrae contenido de un archivo PDF, documento, hoja de cálculo o HTML                        |
| Herramientas del agente      | `firecrawl_agent`, `firecrawl_agent_status`     | Ejecuta una investigación autónoma en múltiples fuentes y comprueba el estado del trabajo    |
| Herramientas de interacción  | `firecrawl_interact`, `firecrawl_interact_stop` | Haz clic, rellena formularios y navega por una página en vivo y, después, libera la sesión   |
| Herramientas de supervisión  | `firecrawl_monitor_*`                           | Crea y ejecuta comprobaciones periódicas con notificaciones por webhook o correo electrónico |

Consulta [herramientas de MCP](/es/mcp-server/tools) para ver la lista completa.

### Autenticación {#authentication}

**FIRECRAWL&#95;API&#95;KEY**: Tu clave de API de Firecrawl

* Opcional con la API en la nube (por defecto): si no se proporciona una clave, el scraping y la búsqueda funcionan sin clave dentro de los límites de uso gratuito; las demás herramientas y los límites más altos requieren una clave
* Opcional al usar una instancia autogestionada con FIRECRAWL&#95;API&#95;URL

### Configuración opcional {#optional-configuration}

**URL de la API de Firecrawl (para instancias autogestionadas)**:

* `FIRECRAWL_API_URL`: Endpoint de API personalizado
* Ejemplo: `https://firecrawl.your-domain.com`
* Si no se especifica, se usará la API en la nube

## Ejemplo: agente de investigación web {#example-web-research-agent}

```python
import asyncio
import os

from google.adk.agents.llm_agent import Agent
from google.adk.runners import InMemoryRunner
from google.adk.tools.mcp_tool.mcp_session_manager import StreamableHTTPConnectionParams
from google.adk.tools.mcp_tool.mcp_toolset import MCPToolset

FIRECRAWL_API_KEY = os.environ["FIRECRAWL_API_KEY"]

# Crear un agente de investigación
research_agent = Agent(
    model="gemini-3.8-flash",
    name="research_agent",
    description='An AI agent that researches topics by scraping and analyzing web content',
    instruction='''You are a research assistant. When given a topic or question:
    1. Use the search tool to find relevant websites
    2. Scrape the most relevant pages for detailed information
    3. Extract structured data when needed
    4. Provide comprehensive, well-sourced answers''',
    tools=[
        MCPToolset(
            connection_params=StreamableHTTPConnectionParams(
                url="https://mcp.firecrawl.dev/v2/mcp",
                headers={"Authorization": f"Bearer {FIRECRAWL_API_KEY}"},
            ),
        )
    ],
)

# Ejecutar el agente e imprimir sus respuestas
async def main():
    runner = InMemoryRunner(agent=research_agent)
    await runner.run_debug("What are the latest features in Python 3.13?")
    await runner.close()

asyncio.run(main())
```

## Mejores prácticas {#best-practices}

1. **Usa la herramienta adecuada para cada tarea**:
   * `firecrawl_search` cuando primero necesites encontrar páginas relevantes
   * `firecrawl_scrape` para páginas individuales
   * `firecrawl_crawl` para descubrir y extraer sitios completos
   * llamadas repetidas a `firecrawl_scrape` cuando ya tengas una lista corta de URL conocidas

2. **Supervisa tu uso**: Usa tu panel de Firecrawl y las respuestas de la API para hacer seguimiento del consumo de créditos.

3. **Gestiona los errores de forma adecuada**: Muestra al usuario los errores de MCP/API y reintenta solo cuando tu flujo de trabajo del agente pueda hacerlo de forma segura.

4. **Optimiza el rendimiento**: Usa `firecrawl_map` antes de hacer scraping cuando el agente necesite descubrir URL relevantes.
