Integra Firecrawl con LlamaIndex para crear aplicaciones de IA con búsqueda vectorial y embeddings basados en contenido web.

## Configuración {#setup}

```bash
npm install llamaindex @llamaindex/openai firecrawl
```

Crea un archivo `.env`:

```bash
FIRECRAWL_API_KEY=your_firecrawl_key
OPENAI_API_KEY=your_openai_key
```

> **Nota:** Si usas Node &lt; 20, instala `dotenv` y agrega `import 'dotenv/config'` a tu código.

## RAG con búsqueda vectorial {#rag-with-vector-search}

Este ejemplo muestra cómo usar LlamaIndex con Firecrawl para rastrear un sitio web, crear embeddings y consultar el contenido mediante RAG.

```typescript
import { Firecrawl } from 'firecrawl';
import { Document, VectorStoreIndex, Settings } from 'llamaindex';
import { OpenAI, OpenAIEmbedding } from '@llamaindex/openai';

Settings.llm = new OpenAI({ model: "gpt-4o" });
Settings.embedModel = new OpenAIEmbedding({ model: "text-embedding-3-small" });

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });
const crawlResult = await firecrawl.crawl('https://firecrawl.dev', {
  limit: 10,
  scrapeOptions: { formats: ['markdown'] }
});
console.log(`Crawled ${crawlResult.data.length } pages`);

const documents = crawlResult.data.map((page: any, i: number) =>
  new Document({
    text: page.markdown,
    id_: `page-${i}`,
    metadata: { url: page.metadata?.sourceURL }
  })
);

const index = await VectorStoreIndex.fromDocuments(documents);
console.log('Vector index created with embeddings');

const queryEngine = index.asQueryEngine();
const response = await queryEngine.query({ query: 'What is Firecrawl and how does it work?' });

console.log('\nAnswer:', response.toString());
```

## Python: FireCrawlWebReader {#python-firecrawlwebreader}

En Python, el `FireCrawlWebReader` de LlamaIndex carga los resultados de Firecrawl como documentos de LlamaIndex. Asigna a `mode` el valor `scrape`, `crawl`, `map` o `search`, y pasa las opciones de Firecrawl en `params`.

```bash
pip install llama-index-readers-web firecrawl-py
```

```python
import os

from llama_index.readers.web import FireCrawlWebReader

reader = FireCrawlWebReader(
    api_key=os.environ["FIRECRAWL_API_KEY"],
    mode="crawl",
    params={"limit": 10, "scrape_options": {"formats": ["markdown"]}},
)

documents = reader.load_data(url="https://firecrawl.dev")
print(f"Loaded {len(documents)} documents")
```

Usa `load_data(url=...)` para `scrape`, `crawl` y `map`, y `load_data(query=...)` para `search`. Consulta la [referencia de FireCrawlWebReader](https://developers.llamaindex.ai/python/framework-api-reference/readers/web/#llama_index.readers.web.FireCrawlWebReader) para más detalles.

Para ver más ejemplos, consulta la [documentación de LlamaIndex](https://developers.llamaindex.ai/typescript/framework/).
