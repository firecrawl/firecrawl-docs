Proporciona a tus agentes de voz y chat de [ElevenAgents](https://elevenlabs.io/agents) contexto limpio de la web en tiempo real mediante la búsqueda y la extracción de datos web con Firecrawl. Esta guía cubre dos opciones de integración:

1. **Servidor MCP** — conecta el Servidor MCP alojado de Firecrawl para una configuración sin código.
2. **Herramienta de webhook del servidor** — dirige una herramienta personalizada a la API REST de Firecrawl para tener control total sobre las solicitudes.

## Requisitos previos {#prerequisites}

* Una cuenta en [ElevenLabs](https://elevenlabs.io) con acceso a ElevenAgents
* Una clave de API de Firecrawl desde tu [panel de control de firecrawl.dev](https://firecrawl.dev)

## Opción 1: Firecrawl MCP Server {#option-1-firecrawl-mcp-server}

La forma más rápida de dar acceso web a un agente. ElevenAgents admite servidores MCP remotos y Firecrawl proporciona un endpoint MCP alojado.

### Añade el Servidor MCP {#add-the-mcp-server}

1. Abre la [página de integraciones](https://elevenlabs.io/app/agents/integrations) en ElevenLabs y haz clic en **Add Custom Servidor MCP**. La primera vez que alguien de tu espacio de trabajo añade un servidor MCP, ElevenLabs te pide que aceptes sus términos de uso de servidores MCP, lo que activa MCP en todo el espacio de trabajo.
2. Completa los siguientes campos:

| Campo                       | Valor                                                                  |
| --------------------------- | ---------------------------------------------------------------------- |
| **Name**                    | Firecrawl                                                              |
| **Description**             | Busca, realiza extracción de datos web y procesa contenido web con Firecrawl.            |
| **Server type**             | Streamable HTTP                                                        |
| **Server URL**              | `https://mcp.firecrawl.dev/v2/mcp`                                     |
| **Secret Token** (opcional) | `Bearer fc-YOUR_API_KEY`, guardado como secreto del espacio de trabajo |

El MCP sin clave ofrece exactamente Search, extracción de datos web y procesar, con límites compartidos. [Inicia sesión](/es/mcp-server/oauth) o [añade una clave de API](/es/mcp-server/keyless#add-an-api-key) para acceder a un conjunto de herramientas más amplio. Conserva las claves de API en una variable de entorno o almacén de secretos, nunca en una URL.

<Note>
  Debes seleccionar **Streamable HTTP** como tipo de servidor. La opción predeterminada SSE no funciona con el endpoint MCP de Firecrawl.
</Note>

3. En **Tool Approval Mode**, selecciona un nivel de aprobación:
   * **No Approval** — el agente usa las herramientas libremente. Adecuado para extracción de datos web de solo lectura.
   * **Fine-Grained Tool Approval** — te permite preseleccionar qué herramientas pueden ejecutarse automáticamente y cuáles requieren aprobación.
   * **Always Ask** (predeterminado) — el agente solicita permiso antes de cada llamada de herramienta.

4. Haz clic en **Add Integration**. ElevenLabs guarda el servidor y comprueba la conexión.

ElevenLabs se conectará al servidor sin clave y mostrará Search, extracción de datos web y procesar. Si configuras un Secret Token, mostrará el conjunto de herramientas completo de Firecrawl MCP.

### Añádelo a un agente {#attach-it-to-an-agent}

1. Crea o abre un agente en el [panel de ElevenAgents](https://elevenlabs.io/app/agents/agents).
2. Ve a la pestaña **Tools** y, a continuación, selecciona la subpestaña **MCP**.
3. Haz clic en **Add server** y selecciona la integración de **Firecrawl** en el menú desplegable.

### Actualiza el prompt del sistema {#update-the-system-prompt}

En la pestaña **Agent**, agrega instrucciones al **System prompt** para que el agente sepa cuándo usar Firecrawl. Por ejemplo:

```text
Eres un asistente de investigación útil. Cuando el usuario pregunte sobre un sitio web,
una empresa o cualquier tema que requiera información actualizada, usa las
herramientas de Firecrawl para buscar en la web o hacer scraping de la página relevante y, luego,
resume los resultados.
```

### Pruébalo {#test-it}

Haz clic en **Preview** en la barra de navegación superior. Puedes probarlo usando el campo de chat de texto o iniciando una llamada de voz. Prueba un prompt como:

> &quot;¿Qué hace firecrawl.dev? Ve al sitio y resúmelo.&quot;

El agente llamará a la herramienta MCP `firecrawl_scrape` de Firecrawl, recibirá el markdown de la página y responderá con un resumen.

## Opción 2: Herramienta de Webhook del servidor {#option-2-server-webhook-tool}

Usa este enfoque cuando necesites un control preciso sobre los parámetros de la solicitud (formats, encabezados, timeouts, etc.) o quieras invocar un endpoint específico de Firecrawl sin exponer todo el conjunto de herramientas de MCP.

### Herramienta de scraping {#scrape-tool}

Crea una herramienta que haga scraping de una única URL y devuelva su contenido en markdown.

1. Abre tu agente y ve a la pestaña **Tools**.
2. Haz clic en **Add tool** y selecciona **Webhook**.
3. Configura la herramienta:

| Campo           | Valor                                                                    |
| --------------- | ------------------------------------------------------------------------ |
| **Name**        | scrape&#95;website                                                       |
| **Description** | Haz scraping del contenido de una URL y devuélvelo como markdown limpio. |
| **Método**      | POST                                                                     |
| **URL**         | `https://api.firecrawl.dev/v2/scrape`                                    |

<Note>
  El campo **Método** usa GET de forma predeterminada; asegúrate de cambiarlo a **POST**.
</Note>

4. Desplázate hasta la sección **Headers** y haz clic en **Add header** para configurar la autenticación:

| Encabezado      | Valor                           |
| --------------- | ------------------------------- |
| `Authorization` | `Bearer YOUR_FIRECRAWL_API_KEY` |

Como alternativa, si tienes configuradas conexiones de autenticación del espacio de trabajo, puedes usar el menú desplegable **Authentication**.

5. Agrega **parámetros en el body**:

| Parámetro     | Tipo   | Descripción                                                                                                                                | Obligatorio |
| ------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------ | ----------- |
| `url`         | string | La URL de la que se hará scraping                                                                                                          | Sí          |
| `integration` | string | Valor constante `_elevenlabs`. Defínelo como constante para que el LLM nunca lo rellene. Indica que la solicitud proviene de ElevenAgents. | No          |

6. Haz clic en **Add tool**.

La API de Firecrawl devuelve el contenido de la página en markdown de forma predeterminada. El agente recibe la respuesta JSON y puede usar el campo `markdown` para responder preguntas.

### Herramienta de búsqueda {#search-tool}

Crea una herramienta para buscar en la web y devolver el título, la URL y la descripción de cada resultado.

1. Haz clic en **Add tool** → **Webhook** de nuevo y configura:

| Campo           | Valor                                                                                         |
| --------------- | --------------------------------------------------------------------------------------------- |
| **Nombre**      | search&#95;web                                                                                |
| **Descripción** | Busca en la web una consulta y devuelve el título, la URL y la descripción de cada resultado. |
| **Método**      | POST                                                                                          |
| **URL**         | `https://api.firecrawl.dev/v2/search`                                                         |

2. Añade el mismo encabezado `Authorization` que antes.

3. Añade **parámetros en el body**:

| Parámetro     | Tipo   | Descripción                                                                                                                                   | Obligatorio |
| ------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| `query`       | string | La consulta de búsqueda                                                                                                                       | Sí          |
| `limit`       | number | Número máximo de resultados que se devolverán (predeterminado: 10)                                                                            | No          |
| `integration` | string | Valor constante `_elevenlabs`. Configúralo como constante para que el LLM nunca lo rellene. Indica que la solicitud proviene de ElevenAgents. | No          |

4. Haz clic en **Add tool**.

### Actualiza las Instrucciones del sistema {#update-the-system-prompt-2}

En la pestaña **Agent**, actualiza las **Instrucciones del sistema**:

```text
Eres un asistente experto con acceso a herramientas web.

- Usa `scrape_website` cuando el usuario te proporcione una URL específica para leer.
- Usa `search_web` cuando el usuario haga una pregunta general que requiera
  buscar información en línea. Luego llama a `scrape_website` con la URL
  del resultado más relevante para leer la página completa.

Siempre resume la información de forma concisa y cita la URL de origen.
```

### Pruébalo {#test-it-2}

Haz clic en **Preview** y prueba a preguntar:

> &quot;Busca las últimas novedades de Next.js y dame un resumen.&quot;

El agente llamará a `search_web`, recibirá resultados de Firecrawl y responderá con un resumen de lo encontrado.

## Consejos {#tips}

* **Selección de modelo**: Para una llamada de herramienta fiable, usa un modelo de alta capacidad como GPT-4o, Claude Sonnet 5 o Gemini 2.5 Flash. Los modelos más pequeños pueden tener dificultades para extraer los parámetros correctos.
* **Mantén los prompts específicos**: Indica al agente exactamente cuándo usar cada herramienta. Las instrucciones vagas provocan llamadas de herramientas omitidas o incorrectas.
* **Limita el tamaño de la respuesta**: En los agentes de voz, las páginas largas extraídas mediante extracción de datos web pueden saturar el contexto del LLM. La extracción de datos web ya devuelve de forma predeterminada solo el contenido principal (`onlyMainContent: true`), así que indícale también al agente que resuma de forma agresiva para mantener las respuestas concisas.
* **Sonidos de llamada de herramienta**: En la configuración de herramientas de Webhook o MCP, puedes configurar un **sonido de llamada de herramienta** para reproducir audio ambiental mientras se ejecuta una herramienta. Esto le indica al usuario que el agente está trabajando.
