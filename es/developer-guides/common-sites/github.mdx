Aprende a usar las funciones principales de Firecrawl para hacer scraping de repositorios, issues y documentación de GitHub.

<Info>
  Hay dos formas de obtener datos de GitHub con Firecrawl. Puedes **hacer scraping, mapeo o crawling** de una URL específica de `github.com` (que es lo que se explica en el resto de esta página), o usar [Developer Index](/es/features/developer) para descubrir de forma semántica issues, pull requests fusionadas y README relevantes en todo GitHub sin conocer la URL exacta.
</Info>

<div id="setup">
  ## Configuración
</div>

```bash
npm install firecrawl zod
```

<div id="scrape-with-json-mode">
  ## Scrape con modo JSON
</div>

Extrae datos estructurados de repositorios mediante esquemas de Zod.

```typescript
import { Firecrawl } from 'firecrawl';
import { z } from 'zod';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const result = await firecrawl.scrape('https://github.com/firecrawl/firecrawl', {
    formats: [{
        type: 'json',
        schema: z.object({
            name: z.string(),
            description: z.string(),
            stars: z.number(),
            forks: z.number(),
            language: z.string(),
            topics: z.array(z.string())
        })
    }]
});

console.log(result.json);
```

<div id="search">
  ## Search
</div>

Busca repositorios, issues o documentación en GitHub.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const searchResult = await firecrawl.search('machine learning site:github.com', {
    limit: 10,
    sources: [{ type: 'web' }], // { type: 'news' }, { type: 'images' }
    scrapeOptions: {
        formats: ['markdown']
    }
});

console.log(searchResult);
```

<div id="search-github-with-the-developer-index">
  ## Busca en GitHub con el Developer Index
</div>

El [Developer Index](/es/features/developer) de Firecrawl realiza búsquedas semánticas en issues públicos indexados de GitHub, pull requests fusionadas y archivos README de repositorios, además de sitios de documentación seleccionados. Resulta útil para encontrar detalles de implementación y soluciones de ingeniería previas cuando no conoces el repositorio ni la URL exactos, y devuelve los pasajes coincidentes en lugar de un simple fragmento.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const result = await firecrawl.search(
    'how to handle rate limit retries with exponential backoff',
    { categories: ['developer'], limit: 10 }
);

console.log(result.developer);
```

Para obtener resultados ordenados con los pasajes coincidentes y aplicar filtros por repositorio y tipo de resultado, llama al endpoint específico:

```bash
# No necesitas una API key para empezar; añade -H "Authorization: Bearer $FIRECRAWL_API_KEY" para obtener límites de tasa más altos:
curl -s "https://api.firecrawl.dev/v2/search/developer?query=how%20to%20handle%20rate%20limit%20retries%20with%20exponential%20backoff&types=issue,pull_request&k=10"
```

También puedes buscar en GitHub mediante resultados web convencionales usando el endpoint general [`/search`](/es/features/search) con la categoría `github`, que limita la búsqueda web al sitio en lugar de consultar el índice.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const searchResult = await firecrawl.search('exponential backoff retry', {
    categories: ['github'],
    limit: 10
});

console.log(searchResult);
```

Consulta la [guía de Developer Index](/es/features/developer) para usarlo con Python, cURL, la CLI y MCP.

<div id="scrape">
  ## Scrape
</div>

Extrae una sola página de GitHub: un repositorio, un issue o un archivo.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const result = await firecrawl.scrape('https://github.com/firecrawl/firecrawl', {
    formats: ['markdown'] // p. ej. html, links, etc.
});

console.log(result);
```

<div id="map">
  ## Map
</div>

Descubre todas las URL disponibles en un repositorio o sitio de documentación. Nota: Map devuelve únicamente las URL, sin contenido.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const mapResult = await firecrawl.map('https://github.com/vercel/next.js/tree/canary/docs');

console.log(mapResult.links);
// Devuelve un array de URLs sin contenido
```

<div id="crawl">
  ## Crawl
</div>

Rastrea varias páginas de un repositorio o de la documentación.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const crawlResult = await firecrawl.crawl('https://github.com/facebook/react/wiki', {
    limit: 10,
    scrapeOptions: {
        formats: ['markdown']
    }
});

console.log(crawlResult.data);
```

<div id="batch-scrape">
  ## extracción por lotes
</div>

Extrae varias URL de GitHub simultáneamente.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

// Esperar a que finalice
const job = await firecrawl.batchScrape([
    'https://github.com/vercel/next.js',
    'https://github.com/facebook/react',
    'https://github.com/microsoft/typescript'],
    {
        options: {
            formats: ['markdown']
        },
        pollInterval: 2,
        timeout: 120
    }
);


console.log(job.status, job.completed, job.total);

console.log(job);
```

<div id="batch-scrape-with-json-mode">
  ## extracción por lotes con modo JSON
</div>

Extrae datos estructurados de múltiples repositorios a la vez.

```typescript
import { Firecrawl } from 'firecrawl';
import { z } from 'zod';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

// Esperar a que finalice
const job = await firecrawl.batchScrape([
    'https://github.com/vercel/next.js',
    'https://github.com/facebook/react'],
    {
        options: {
            formats: [{
                type: 'json',
                schema: z.object({
                    name: z.string(),
                    description: z.string(),
                    stars: z.number(),
                    language: z.string()
                })
            }]
        },
        pollInterval: 2,
        timeout: 120
    }
);


console.log(job.status, job.completed, job.total);

console.log(job);
```
