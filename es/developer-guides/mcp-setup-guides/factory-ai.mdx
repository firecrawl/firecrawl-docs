Añade capacidades de scraping y búsqueda web a Factory AI con Firecrawl MCP.

<div id="quick-setup">
  ## Configuración rápida {#quick-setup}
</div>

<div id="1-get-your-api-key">
  ### 1. Obtén tu clave de API {#1-get-your-api-key}
</div>

Regístrate en [firecrawl.dev/app](https://firecrawl.dev/app) y copia tu clave de API.

### 2. Instalar Factory AI CLI {#2-install-factory-ai-cli}

Instala la [Factory Droid CLI](https://docs.factory.ai/droid-cli/quickstart) si aún no lo has hecho:

**macOS/Linux:**

```bash
curl -fsSL https://app.factory.ai/cli | sh
```

**Windows:**

```powershell
irm https://app.factory.ai/cli/windows | iex
```

### 3. Agrega el Firecrawl MCP Server {#3-add-firecrawl-mcp-server}

Desde tu terminal, agrega el servidor MCP de Firecrawl alojado con `droid mcp add`:

```bash
droid mcp add firecrawl https://mcp.firecrawl.dev/v2/mcp --type http \
  --header "Authorization: Bearer your-api-key-here" --no-oauth
```

Sustituye `your-api-key-here` por tu clave de API de Firecrawl.

Si prefieres ejecutar el servidor en local, agrégalo como servidor stdio:

```bash
droid mcp add firecrawl "npx -y firecrawl-mcp@3.33.2" --env FIRECRAWL_API_KEY=your-api-key-here
```

También puedes escribir `/mcp` en Droid para comprobar el estado del servidor y ver sus herramientas.

### 4. ¡Listo! {#4-done}

¡Las herramientas de Firecrawl ya están disponibles en tu sesión de Factory AI!

## Demostración rápida {#quick-demo}

Prueba esto en Factory AI:

**Buscar en la web:**

```
Busca las últimas notas de la versión de Next.js
```

**Extraer una página:**

```
Extrae datos de firecrawl.dev y dime qué hace
```

**Obtener la documentación:**

```
Encuentra y extrae la documentación de la API de Stripe sobre intenciones de pago
```

Factory utilizará automáticamente las herramientas de búsqueda y extracción de Firecrawl para obtener la información.
