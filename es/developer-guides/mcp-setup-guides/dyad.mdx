Añade Firecrawl a [Dyad](https://www.dyad.sh) para que la IA de tu creador de aplicaciones pueda buscar, hacer scraping e interactuar con la web.

<Note>
  Necesitas Dyad v0.25 o una versión posterior para usar los enlaces «Add to Dyad».
</Note>

## 1. Obtén tu clave de API {#1-get-your-api-key}

Crea una clave en [firecrawl.dev/app/api-keys](https://www.firecrawl.dev/app/api-keys). Deberás introducirla en Dyad, no en el enlace.

## 2. Añade Firecrawl a Dyad {#2-add-firecrawl-to-dyad}

Elige un transporte.

El enlace abre Dyad en la página **Plugins** con el formulario ya rellenado. Haz clic en **Add** y luego completa el paso de la clave correspondiente a tu transporte.

### Alojado (HTTP) {#hosted-http}

1. En el formulario, desactiva **Use OAuth**.
2. Una vez añadido, abre el nuevo plugin y agrega esta cabecera:

   | Cabecera        | Valor                           |
   | --------------- | ------------------------------- |
   | `Authorization` | `Bearer YOUR_FIRECRAWL_API_KEY` |

### Local (npx) {#local-npx}

Una vez añadido, abre el nuevo plugin y agrega esta variable de entorno:

| Variable            | Valor                    |
| ------------------- | ------------------------ |
| `FIRECRAWL_API_KEY` | `YOUR_FIRECRAWL_API_KEY` |

## 3. Pruébalo {#3-try-it}

En un chat de Dyad, prueba con:

```text
Busca en la web las notas de la versión más recientes de Next.js y resume las fuentes.
```

```text
Haz scraping de https://firecrawl.dev y describe lo que ofrece la página.
```

## Añádelo manualmente {#add-it-by-hand}

Abre **Plugins**, haz clic en **Add Plugin** y rellena uno de los dos conjuntos de valores.

| Transporte | Campos                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------- |
| `http`     | URL `https://mcp.firecrawl.dev/v2/mcp`, cabecera `Authorization: Bearer YOUR_FIRECRAWL_API_KEY`               |
| `stdio`    | Comando `npx`, argumentos `-y firecrawl-mcp`, variables de entorno `FIRECRAWL_API_KEY=YOUR_FIRECRAWL_API_KEY` |

Consulta la [referencia del servidor MCP](/es/mcp-server) para ver la lista completa de herramientas.
