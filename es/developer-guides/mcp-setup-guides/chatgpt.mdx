description: "Añade Firecrawl a ChatGPT con el conector nativo"
---

Añade Firecrawl a ChatGPT con la aplicación nativa de Firecrawl. No necesitas crear un conector MCP personalizado ni introducir la URL de un servidor.

<div id="add-to-chatgpt">
  ## Añadir a ChatGPT
</div>

<Card title="Añadir a ChatGPT" icon="/images/agent-clients/chatgpt.svg" href="https://chatgpt.com/plugins?q=firecrawl" cta="Abrir en ChatGPT" arrow>
  Abre la aplicación de Firecrawl en ChatGPT y conéctala.
</Card>

1. Abre la [aplicación de Firecrawl en ChatGPT](https://chatgpt.com/plugins?q=firecrawl).
2. Selecciona **Firecrawl** y conéctala. Cuando ChatGPT abra Firecrawl en el navegador, inicia sesión, selecciona un equipo y autoriza el acceso.
3. En un chat, abre el menú **+** y activa **Firecrawl** antes de enviar un prompt. El conector debe estar vinculado a la conversación.

No incluyas una clave de API de Firecrawl en la URL de un servidor. Para revocar el acceso más adelante, usa la [configuración de MCP](https://www.firecrawl.dev/app/settings?tab=mcp).

<div id="try">
  ## Prueba
</div>

Con Firecrawl habilitado, prueba:

```text
Search the web for the latest Firecrawl release notes and summarize the sources.
```

```text
Scrape firecrawl.dev and tell me what it does
```
