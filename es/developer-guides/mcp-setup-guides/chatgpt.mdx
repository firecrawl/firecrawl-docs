Añade Firecrawl a ChatGPT con el plugin nativo de Firecrawl para hacer búsquedas, extraer datos web, rastrear sitios, interactuar con la web y supervisarla desde tus chats. No necesitas crear un conector MCP personalizado ni introducir la URL de un servidor.

## Añadir a ChatGPT {#add-to-chatgpt}

<Card title="Añadir a ChatGPT" icon="/images/agent-clients/chatgpt.svg" href="https://chatgpt.com/plugins/plugin_asdk_app_6a314a73f8ac819195b0d55e36b9c609?q=firecrawl" cta="Abrir en ChatGPT" arrow>
  Abre el plugin de Firecrawl en ChatGPT e instálalo.
</Card>

1. Abre el [plugin de Firecrawl en ChatGPT](https://chatgpt.com/plugins/plugin_asdk_app_6a314a73f8ac819195b0d55e36b9c609?q=firecrawl) o ve a **Plugins** en ChatGPT y busca **Firecrawl**.
2. Selecciona **Install**. Cuando ChatGPT abra Firecrawl en tu navegador, inicia sesión, selecciona un equipo y aprueba el acceso.
3. Inicia un chat nuevo para que ChatGPT cargue el plugin y, después, pídele que use Firecrawl.

El mismo plugin funciona en Codex. Consulta [ChatGPT y Codex](/es/integrations/chatgpt-codex) para ver más detalles y cómo solucionar problemas.

No incluyas tu clave de API de Firecrawl en una URL de servidor. Para revocar el acceso más adelante, ve a la [configuración de MCP](https://www.firecrawl.dev/app/settings?tab=mcp).

## Prueba {#try}

Con Firecrawl habilitado, prueba:

```text
Search the web for the latest Firecrawl release notes and summarize the sources.
```

```text
Scrape firecrawl.dev and tell me what it does
```
