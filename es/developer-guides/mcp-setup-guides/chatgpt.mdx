<Note>
  La compatibilidad con MCP en ChatGPT se encuentra actualmente en fase beta. La interfaz y la disponibilidad pueden cambiar a medida que OpenAI continúe su desarrollo.
</Note>

<Warning>
  **Disponibilidad:** El Developer mode con conectores MCP no está disponible en el plan Free y requiere una suscripción de pago a ChatGPT. La disponibilidad y las funciones varían según el plan y la región. En los espacios de trabajo Team, Enterprise y Edu, un administrador o propietario del espacio de trabajo debe habilitar el Developer mode para el espacio de trabajo antes de que los miembros puedan activarlo individualmente. Consulta la [documentación de OpenAI sobre el Developer mode](https://help.openai.com/en/articles/12584461-developer-mode-apps-and-full-mcp-connectors-in-chatgpt-beta) para ver la disponibilidad actual y las instrucciones de configuración.
</Warning>

Agrega capacidades de scraping web y búsqueda a ChatGPT con Firecrawl MCP.

<div id="quick-setup">
  ## Configuración rápida
</div>

<div id="1-enable-developer-mode">
  ### 1. Activa el modo desarrollador
</div>

Abre la configuración de ChatGPT haciendo clic en tu nombre de usuario en la esquina inferior izquierda, o ve directamente a [chatgpt.com/#settings](https://chatgpt.com/#settings).

En la ventana de configuración, desplázate hasta la parte inferior y selecciona **Advanced Settings**. Activa **Developer mode**.

<Frame>
  <img src="/images/integrations/mcp/chatgpt/enable-developer-mode.gif" alt="Configuración de ChatGPT que muestra Advanced Settings con el interruptor de Developer mode" />
</Frame>

<div id="2-create-the-connector">
  ### 2. Crear el conector
</div>

Con el modo Developer mode habilitado, ve a la pestaña **Apps &amp; Connectors** en el mismo modal de configuración.

Haz clic en el botón **Create** en la esquina superior derecha.

<Frame>
  <img src="/images/integrations/mcp/chatgpt/apps-connectors-create.png" alt="Pestaña Apps & Connectors con el botón Create resaltado" />
</Frame>

Completa los detalles del conector:

* **Name:** `Firecrawl MCP`
* **Description:** `Web scraping, crawling, search, and content extraction` (opcional)
* **MCP Server URL:** `https://mcp.firecrawl.dev/v2/mcp-oauth`
* **Authentication:** `OAuth`

Cuando ChatGPT abra Firecrawl en tu navegador, inicia sesión, selecciona el equipo que quieres usar y aprueba el acceso. No incluyas una clave de API de Firecrawl en la URL del servidor. Consulta la [guía de OAuth](/es/mcp-server/oauth) para conocer el contrato del endpoint y otros modos compatibles.

Marca la casilla **&quot;I understand and want to continue&quot;** y luego haz clic en **Create**.

<div id="3-verify-setup">
  ### 3. Verificar la configuración
</div>

Vuelve a la interfaz principal de ChatGPT. Deberías ver **Developer mode** en pantalla, lo que indica que los conectores MCP están activos.

Si no ves **Developer mode**, recarga la página. Si aún no aparece, abre la configuración de nuevo y verifica que **Developer mode** esté activado en la sección **Advanced Settings**.

<div id="4-access-firecrawl-tools">
  ### 4. Accede a las herramientas de Firecrawl
</div>

Para usar Firecrawl en una conversación, haz clic en el botón **+** en el campo de entrada del chat, luego selecciona **More** y elige **Firecrawl MCP**.

<Frame>
  <img src="/images/integrations/mcp/chatgpt/select-firecrawl-mcp.png" alt="Campo de entrada del chat de ChatGPT que muestra el menú + expandido con el submenú More y la opción Firecrawl MCP" />
</Frame>

<div id="quick-demo">
  ## Demostración rápida
</div>

Con Firecrawl MCP seleccionado, prueba con estos prompts:

**Búsqueda:**

```
Search for the latest React Server Components updates
```

**Scrape:**

```
Scrape firecrawl.dev and tell me what it does
```

**Obtener documentos:**

```
Extrae la documentación de Vercel sobre funciones edge y resúmela
```

<div id="tool-confirmation">
  ## Confirmación de herramienta
</div>

Cuando ChatGPT use las herramientas MCP de Firecrawl, es posible que veas un mensaje de confirmación solicitando tu aprobación. Algunas versiones de ChatGPT Desktop aprueban automáticamente las llamadas a herramientas sin mostrar este cuadro de diálogo. Si no aparece ningún mensaje, puedes verificar que la herramienta se invocó buscando una sección &quot;Called tool&quot; en la respuesta o revisando tu uso en [firecrawl.dev/app/usage](https://www.firecrawl.dev/app/usage).

<Tip>
  **¿No aparece ningún mensaje de confirmación?** Si ChatGPT responde a tu pregunta sin mostrar un cuadro de diálogo de confirmación, lo más probable es que el conector Firecrawl MCP no esté conectado a la conversación. Vuelve al [Paso 4](#4-access-firecrawl-tools) y asegúrate de hacer clic en el botón **+**, seleccionar **More** y elegir **Firecrawl MCP** antes de enviar tu prompt. El conector debe añadirse a cada conversación nueva.
</Tip>

<Frame>
  <img src="/images/integrations/mcp/chatgpt/tool-confirmation.png" alt="Diálogo de confirmación de herramienta de ChatGPT que muestra una solicitud de Firecrawl MCP" />
</Frame>

Puedes marcar **&quot;Remember for this conversation&quot;** para evitar confirmaciones repetidas durante la misma sesión de chat. Esta medida de seguridad la implementa OpenAI para garantizar que las herramientas MCP no realicen acciones no deseadas.

Una vez confirmes, ChatGPT ejecutará la solicitud y devolverá los resultados.
