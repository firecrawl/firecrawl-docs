<div id="sign-in">
  ## Iniciar sesión
</div>

Apunta tu cliente a la URL de servidor OAuth. Tu cliente abrirá una ventana del navegador en la que inicias sesión en Firecrawl y autorizas un equipo:

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

No se necesita clave de API ni cabeceras. Revisa y revoca las conexiones desde la [configuración de MCP](https://www.firecrawl.dev/app/settings?tab=mcp).

<Note>
  Esta es una URL de servidor para tu cliente MCP, no una página para abrir directamente en un navegador. En cambio, las conexiones con clave de API usan `https://mcp.firecrawl.dev/v2/mcp` con un bearer token; consulta [Agregar una clave de API](/es/mcp-server/keyless#add-an-api-key).
</Note>
