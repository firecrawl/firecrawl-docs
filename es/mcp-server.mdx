Firecrawl MCP ofrece a los clientes de IA acceso a datos web en tiempo real a través del Model Context Protocol. Está disponible como servicio alojado o como servidor local de código abierto.

<div id="start-here">
  ## Empieza aquí
</div>

Selecciona el modo de conexión según dónde se ejecute Firecrawl. Las rutas alojadas son URL sin credenciales: las credenciales deben incluirse en el flujo de OAuth o en una cabecera Authorization, nunca en la propia URL.

<CardGroup cols={3}>
  <Card title="Conectar una cuenta" icon="user" href="/es/mcp-server/connect">
    Usa OAuth en el navegador para un cliente MCP interactivo y acceso a todas las herramientas de Firecrawl.
  </Card>

  <Card title="Ejecutar sin supervisión" icon="server" href="/es/mcp-server/connect#run-unattended">
    Usa `/v2/mcp` con una clave de API de Firecrawl en una cabecera Authorization para CI, servidores y scripts.
  </Card>

  <Card title="Probar MCP sin clave" icon="sparkles" href="/es/mcp-server/connect#try-keyless">
    Empieza sin una clave de API con acceso limitado por tasa a Search, Scrape y Parse.
  </Card>
</CardGroup>
