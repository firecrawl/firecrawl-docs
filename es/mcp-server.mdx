<div id="add-an-api-key">
  ## Añade una clave de API
</div>

[Crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys) y envíala como token de portador:

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

Configura la clave mediante una variable de entorno o el almacenamiento seguro de tu cliente, nunca en la URL de MCP.

<Note>
  Esta es la URL de un servidor para tu cliente MCP, no una página que debas abrir directamente en un navegador. Para las conexiones de inicio de sesión, usa `https://mcp.firecrawl.dev/v2/mcp-oauth`; tu cliente iniciará el flujo en el navegador.
</Note>
