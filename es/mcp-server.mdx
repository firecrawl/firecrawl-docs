La URL del servidor alojado sin clave y con clave de API es:

```text
https://mcp.firecrawl.dev/v2/mcp
```

<Note>
  Esta es la URL del servidor para tu cliente MCP, no una página para abrir directamente en un navegador. OAuth utiliza una URL de servidor diferente y tu cliente inicia el flujo de inicio de sesión en el navegador.
</Note>

Si seleccionas una clave de API, nunca la incluyas en una URL de MCP, una conversación con un agente ni un archivo de proyecto confirmado. Configúrala mediante una variable de entorno o el almacenamiento de secretos de tu cliente.

<div id="fix-a-broken-connection">
  ## Corregir una conexión dañada
</div>

Usa esta sección cuando un error de Firecrawl mencione `KEYLESS_QUOTA_EXHAUSTED`, `KEYLESS_TOOL_NOT_AVAILABLE`, `KEYLESS_ACCESS_NOT_AVAILABLE`, `KEYLESS_ELIGIBILITY_UNAVAILABLE`, `CREDENTIAL_INVALID`, `OAUTH_CONNECTION_INVALID` o indique que una credencial es «no válida o revocada».

* **Se alcanzó el límite sin clave:** espera los `retry_after_seconds` indicados en el error (si están presentes) o pide a la persona operadora que se conecte mediante OAuth o configure una clave de API. Search, Scrape y Parse seguirán disponibles cuando se restablezca el límite.
* **Acceso sin clave no disponible:** para `KEYLESS_ELIGIBILITY_UNAVAILABLE`, vuelve a intentarlo tras el intervalo indicado. Si el problema persiste o el error es `KEYLESS_ACCESS_NOT_AVAILABLE`, pide a la persona operadora que se conecte mediante OAuth o configure una clave de API.
* **Herramienta no disponible sin clave (`KEYLESS_TOOL_NOT_AVAILABLE`):** la herramienta existe, pero no está disponible en el modo sin clave. Conéctate mediante OAuth o configura una clave de API para usarla; Search, Scrape y Parse seguirán funcionando sin clave.
* **Clave de API no válida o revocada:** la persona operadora o el sistema deben reemplazar la clave en la configuración del servidor existente, fuera de la conversación con el agente.
* **Conexión OAuth no válida en `/v2/mcp`:** añade una clave de API a ese servidor existente o cambia su URL a `https://mcp.firecrawl.dev/v2/mcp-oauth` e inicia sesión desde el cliente. No abras esa URL directamente en un navegador.
* **Conexión OAuth no válida en `/v2/mcp-oauth`:** vuelve a iniciar sesión mediante el flujo de conexión de cuentas del cliente.

Después de cambiar credenciales o la URL del servidor, conserva una sola entrada de servidor `firecrawl`, inicia una nueva sesión de cliente y vuelve a intentarlo. Consulta [Conexión OAuth](/es/mcp-server/oauth#switch-an-existing-keyless-connection) o [configuración de la clave de API](/es/mcp-server/keyless-api-key#add-an-api-key) para conocer los pasos exactos.
