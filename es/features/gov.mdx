El Government Index de Firecrawl busca en leyes, reglamentos, códigos, sentencias judiciales y otras publicaciones gubernamentales federales, estatales y locales de EE. UU. Ayuda a un agente a encontrar el texto legal o normativo que hay detrás de una pregunta. Los resultados clasificados por relevancia también pueden incluir versiones históricas, textos de proyectos de ley, guías de organismos y reproducciones de terceros; que haya una coincidencia no garantiza que se trate de la legislación vigente.

* Encuentra el reglamento que establece un requisito de etiquetado, notificación o licencia
* Consulta la ley o la sección del código en la que se basa una pregunta de cumplimiento normativo
* Localiza una sentencia judicial que interprete una norma
* Obtén la publicación oficial que un organismo ha emitido sobre un tema

## Seleccionar y verificar fuentes {#choose-and-verify-sources}

Incluye la jurisdicción, el organismo o la cita, y la fecha pertinente cuando se conozcan. Si falta la jurisdicción, pídela antes de identificar la norma aplicable. Si el usuario proporciona la URL de una fuente, léela directamente con [`scrape`](/es/features/scrape) en lugar de volver a buscar.

Antes de responder una pregunta sobre la legislación vigente, verifica el emisor de la fuente, su jurisdicción, si está promulgada o en vigor, y su versión. Lee la fuente que hay detrás de una coincidencia cuando el fragmento no baste para establecer la norma. Comprueba el estado y la fecha de entrada en vigor de un proyecto de ley en lugar de deducirlos de su título o de su resumen. Cita la sección determinante y el pasaje que la respalda, y proporciona únicamente los detalles de página, sección o fecha de entrada en vigor que respalde la evidencia.

El índice se centra en material de EE. UU. Usa la búsqueda general para otras jurisdicciones o cuando falte cobertura; que no haya resultados no demuestra que no exista legislación aplicable.

## Buscar en el Government Index {#search-the-government-index}

Envía una pregunta en lenguaje natural y recibe resultados ordenados por relevancia procedentes de fuentes legales y regulatorias. Los resultados se devuelven en el grupo estándar `web`, cada uno con `url`, `title`, `description` y `position`, con la misma estructura que un resultado web de [`/search`](/es/features/search).

Las búsquedas en el Government Index son gratuitas y no consumen créditos, con o sin retención de datos cero. No necesitas una clave de API para empezar; añade una para disfrutar de límites de tasa más altos.

Los ejemplos de SDK usan los métodos Gov disponibles en `firecrawl@4.44.1` y `firecrawl-py==4.49.2`. Define `FIRECRAWL_API_KEY` para los ejemplos de SDK autenticados; usa los ejemplos HTTP para solicitudes sin clave. Si el cliente instalado no incluye el método, actualiza el SDK. En Python, llama a `gov_search` sobre la instancia ya inicializada del cliente; la reflexión basada solo en la clase puede no mostrar los métodos asignados durante la inicialización.

<CodeGroup>
  ```bash cURL
  # No necesitas una clave de API para empezar; añade -H "Authorization: Bearer $FIRECRAWL_API_KEY" para obtener límites de tasa más altos:
  curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
  ```

  ```bash CLI
  firecrawl gov "food labeling requirements for allergens" --limit 10
  ```

  ```python Python
  import os
  from firecrawl import Firecrawl

  client = Firecrawl(api_key=os.environ["FIRECRAWL_API_KEY"])

  result = client.gov_search("food labeling requirements for allergens", k=10)
  print(result)
  ```

  ```js Node
  import { Firecrawl } from "firecrawl";

  const client = new Firecrawl({
    apiKey: process.env.FIRECRAWL_API_KEY,
  });

  const result = await client.govSearch(
    "food labeling requirements for allergens",
    {
      k: 10,
    },
  );
  console.log(result);
  ```
</CodeGroup>

`POST` también está disponible en la misma ruta, con los mismos campos enviados en un cuerpo JSON:

```bash cURL
# No se necesita clave de API para empezar; añade -H "Authorization: Bearer $FIRECRAWL_API_KEY" para obtener límites de tasa más altos:
curl -X POST https://api.firecrawl.dev/v2/search/gov \
  -H "Content-Type: application/json" \
  -d '{
    "query": "food labeling requirements for allergens",
    "k": 10
  }'
```

`query` es obligatorio. `k` define cuántos resultados se devuelven, entre 1 y 100 (10 de forma predeterminada). Los campos desconocidos se rechazan con un `400`. Consulta la [referencia de búsqueda del Government Index](/es/api-reference/endpoint/gov-search) para ver el esquema completo de la solicitud y la respuesta.

La misma búsqueda también está disponible en [`/search`](/es/features/search#gov-category-search) mediante `categories: ["gov"]`, con los resultados en `data.web`.
