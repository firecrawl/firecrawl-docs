<div id="connect-with-oauth">
  ## Conectarse con OAuth
</div>

<Visibility for="humans">
  <McpClientSelector variant="human" showSeeAll={false} showHeader={false} />
</Visibility>

<Visibility for="agents">
  URL del servidor OAuth (Streamable HTTP; el cliente inicia el inicio de sesión en el navegador): `https://mcp.firecrawl.dev/v2/mcp-oauth`

  * ChatGPT: configuración &gt; habilita Developer mode &gt; Apps &amp; Connectors &gt; Create &gt; Authentication: OAuth &gt; pega la URL del servidor.
  * Claude.ai: Settings &gt; Connectors &gt; Add custom connector &gt; pega la URL del servidor y deja Client ID y Secret en blanco.
  * Codex: `codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth` y después `codex mcp login firecrawl`
  * Claude Code: `claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth` y después completa el inicio de sesión mediante `/mcp`
  * Cursor o cualquier cliente con configuración JSON: `{"mcpServers": {"firecrawl": {"url": "https://mcp.firecrawl.dev/v2/mcp-oauth"}}}`
  * OpenCode (`opencode.json`): `{"mcp": {"firecrawl": {"type": "remote", "url": "https://mcp.firecrawl.dev/v2/mcp-oauth", "enabled": true}}}`

  Una persona debe completar el inicio de sesión en el navegador y aprobar un equipo. No abras directamente la URL del servidor en un navegador.
</Visibility>

<Note>
  `https://mcp.firecrawl.dev/v2/mcp-oauth` es una URL de servidor para tu cliente MCP. No es una página que debas abrir directamente en un navegador. Tu cliente inicia el flujo de inicio de sesión en el navegador.
</Note>

Usa OAuth cuando haya una persona disponible para iniciar sesión, seleccionar un equipo de Firecrawl y aprobar el acceso. El cliente recibe tokens para esa conexión en lugar de pedirte que copies una clave de la API de Firecrawl en la conversación.

La página de inicio de sesión te pide que selecciones un equipo y apruebes la conexión. Si el cliente solicita un OAuth Client ID o Client Secret, deja ambos en blanco. Los clientes compatibles se identifican automáticamente.

Las solicitudes realizadas mediante esta conexión usan el equipo seleccionado. Puedes revisar o revocar la conexión desde [configuración de MCP](https://www.firecrawl.dev/app/settings?tab=mcp).

¿Necesitas una conexión sin supervisión? Usa la [configuración con clave de API](/es/mcp-server/keyless-api-key#add-an-api-key). No pegues la clave en una conversación con un agente ni la incluyas en la URL de MCP.

<div id="verify-the-connection">
  ## Verifica la conexión
</div>

Inicia una nueva sesión de cliente y, a continuación, prueba:

```text
Busca en la web las notas de la última release de Firecrawl y resume las fuentes.
```

Si no aparece ninguna herramienta de Firecrawl, abre el estado de MCP del cliente, confirma que `firecrawl` esté autenticado y verifica que solo haya una entrada de servidor Firecrawl activa.

<div id="switch-an-existing-keyless-connection">
  ## Cambia una conexión sin clave existente
</div>

Actualiza o reemplaza el servidor `firecrawl` existente por la URL del servidor OAuth. No añadas una segunda entrada de Firecrawl. Después del cambio, inicia una nueva sesión de cliente antes de volver a intentar la solicitud.

<div id="codex">
  ### Codex
</div>

Ejecuta:

```bash
codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth
codex mcp login firecrawl
```

Codex reemplaza el servidor existente con el mismo nombre. Escribe `/mcp` y confirma que `firecrawl` esté conectado.

<div id="claude-code">
  ### Claude Code
</div>

Claude Code no sobrescribe un servidor existente con el mismo nombre. Elimina la entrada actual y, a continuación, añade la entrada de OAuth:

```bash
claude mcp remove firecrawl
claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

Abre `/mcp` en Claude Code y completa el inicio de sesión en el navegador.

<div id="other-clients">
  ### Otros clientes
</div>

Edita el servidor `firecrawl` existente y configura su URL como sigue:

```text
https://mcp.firecrawl.dev/v2/mcp-oauth
```

Guarda la configuración, completa el inicio de sesión iniciado por el cliente y abre una nueva sesión de cliente.

<div id="compatibility-and-security-details">
  ## Detalles de compatibilidad y seguridad
</div>

<AccordionGroup>
  <Accordion title="Compatibilidad durante la migración">
    Los tokens OAuth existentes emitidos para `/v2/mcp` siguen siendo compatibles con ese endpoint. Las nuevas conexiones interactivas usan `/v2/mcp-oauth`, y los tokens emitidos para ese recurso de cuenta no se aceptan en `/v2/mcp`.
  </Accordion>

  <Accordion title="Compatibilidad con clientes OAuth y redireccionamientos">
    Firecrawl utiliza el Código de autorización de OAuth con PKCE. Los clientes compatibles pueden identificarse mediante un documento de metadatos de ID de cliente o el Registro dinámico de clientes, por lo que no necesitan un secreto de cliente.

    Firecrawl acepta URI de redireccionamiento HTTPS y redireccionamientos de loopback en `localhost`, `127.0.0.1` o `[::1]`. En el caso de un cliente nativo que use un redireccionamiento de loopback, el puerto puede cambiar entre ejecuciones. El resto de la URI de redireccionamiento registrada debe coincidir exactamente.
  </Accordion>

  <Accordion title="Alcance y duración de los tokens">
    Los tokens de acceso caducan al cabo de una hora. Los tokens de actualización rotan tras una actualización correcta. Cada conexión está vinculada a su cliente OAuth, usuario, equipo, alcance y recurso MCP.

    Un token nuevo emitido para `/v2/mcp-oauth` no se acepta en `/v2/mcp`. Los tokens con una audiencia ausente o ambigua se rechazan de forma segura.
  </Accordion>

  <Accordion title="Revocar una conexión">
    Abre **MCP** en la [configuración de Firecrawl](https://www.firecrawl.dev/app/settings?tab=mcp) y revoca la conexión. La revocación invalida sus tokens de acceso y actualización. Vuelve a conectarte desde el cliente para autorizarla de nuevo.
  </Accordion>

  <Accordion title="Facturación y acceso del equipo">
    Las solicitudes realizadas mediante una conexión consumen los créditos del equipo seleccionado durante el inicio de sesión, conforme al plan de ese equipo. Cada conexión aparece en la [configuración de MCP](https://www.firecrawl.dev/app/settings?tab=mcp), donde puede revisarse y revocarse en cualquier momento. Para controles de SSO y para toda la organización, consulta [Enterprise](/es/enterprise).
  </Accordion>
</AccordionGroup>
