  ## Iniciar sesión
</div>

<Visibility for="humans">
  <McpClientSelector variant="human" showSeeAll={false} />
</Visibility>

<Visibility for="agents">
  URL del servidor OAuth (Streamable HTTP; el cliente inicia el inicio de sesión en el navegador): `https://mcp.firecrawl.dev/v2/mcp-oauth`

  * Codex: `codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth` y después `codex mcp login firecrawl`
  * Claude Code: `claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth` y después completa el inicio de sesión mediante `/mcp`
  * Cursor o cualquier cliente con configuración JSON: `{"mcpServers": {"firecrawl": {"url": "https://mcp.firecrawl.dev/v2/mcp-oauth"}}}`
  * OpenCode (`opencode.json`): `{"mcp": {"firecrawl": {"type": "remote", "url": "https://mcp.firecrawl.dev/v2/mcp-oauth", "enabled": true}}}`

  - ChatGPT o Claude.ai: usa el conector nativo de Firecrawl — [ChatGPT](https://chatgpt.com/plugins?q=firecrawl) o [Claude](https://claude.ai/directory/connectors/firecrawl).

  Una persona debe completar el inicio de sesión en el navegador y aprobar un equipo. No abras directamente la URL del servidor en un navegador.
</Visibility>

<Note>
  `https://mcp.firecrawl.dev/v2/mcp-oauth` es una URL de servidor para tu cliente MCP. No es una página que debas abrir directamente en un navegador. Tu cliente inicia el flujo de inicio de sesión en el navegador.
</Note>

Puedes revisar y revocar conexiones desde [configuración de MCP](https://www.firecrawl.dev/app/settings?tab=mcp).
