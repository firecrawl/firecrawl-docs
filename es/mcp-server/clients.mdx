Comienza con [Conectar Firecrawl MCP](/es/mcp-server/connect) para seleccionar OAuth de cuenta, acceso desatendido mediante clave de API o acceso sin clave. Estos ejemplos específicos de cada cliente usan el mismo contrato adaptado al modo.

<div id="running-on-cursor">
  ## Ejecutar en Cursor
</div>

Instala el servidor alojado sin clave con un solo clic (no requiere clave de API):

<a href="cursor://anysphere.cursor-deeplink/mcp/install?name=firecrawl&config=eyJ1cmwiOiJodHRwczovL21jcC5maXJlY3Jhd2wuZGV2L3YyL21jcCJ9">
  <img src="https://cursor.com/deeplink/mcp-install-dark.png" alt="Añadir Firecrawl MCP Server a Cursor" style={{ maxHeight: 32 }} />

  <span className="fc-sr-only">Instalar Firecrawl MCP en Cursor</span>
</a>

O añádelo manualmente a `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

<div id="running-locally-with-an-api-key">
  ### Ejecución local con una clave de API
</div>

Nota: Requiere Cursor versión 0.45.6 o posterior.
Para consultar las instrucciones de configuración más actualizadas, consulta la documentación oficial de Cursor sobre cómo configurar MCP Servers:
[Guía de configuración de MCP Server de Cursor](https://cursor.com/docs/context/mcp)

Para configurar Firecrawl MCP en Cursor **v0.48.6**

1. Abre la configuración de Cursor
2. Ve a Features &gt; MCP Servers
3. Haz clic en &quot;+ Add new global MCP server&quot;
4. Introduce el siguiente código:
   ```json
   {
     "mcpServers": {
       "firecrawl-mcp": {
         "command": "npx",
         "args": ["-y", "firecrawl-mcp"],
         "env": {
           "FIRECRAWL_API_KEY": "YOUR-API-KEY"
         }
       }
     }
   }
   ```

Para configurar Firecrawl MCP en Cursor **v0.45.6**

1. Abre la configuración de Cursor
2. Ve a Features &gt; MCP Servers
3. Haz clic en &quot;+ Add New MCP Server&quot;
4. Introduce lo siguiente:
   * Nombre: &quot;firecrawl-mcp&quot; (o el nombre que prefieras)
   * Tipo: &quot;command&quot;
   * Comando: `env FIRECRAWL_API_KEY=your-api-key npx -y firecrawl-mcp@3.23.0`

> Si usas Windows y tienes problemas, prueba con `cmd /c "set FIRECRAWL_API_KEY=your-api-key && npx -y firecrawl-mcp@3.23.0"`

Sustituye `your-api-key` por tu clave de API de Firecrawl. Si aún no tienes una, puedes crear una cuenta y obtenerla en https://www.firecrawl.dev/app/api-keys

Después de añadirlo, actualiza la lista de MCP Servers para ver las nuevas herramientas. El agente Composer usará Firecrawl MCP automáticamente cuando corresponda, pero puedes solicitarlo explícitamente describiendo tus necesidades de datos web. Accede a Composer con Command+L (Mac), selecciona &quot;Agent&quot; junto al botón de envío e introduce tu consulta.

<div id="running-with-streamable-http-mode">
  ## Ejecución en modo Streamable HTTP
</div>

Para ejecutar el servidor localmente mediante el transporte HTTP Streamable en lugar del transporte stdio predeterminado:

```bash
env HTTP_STREAMABLE_SERVER=true FIRECRAWL_API_KEY=fc-YOUR_API_KEY npx -y firecrawl-mcp@3.23.0
```

Usa `http://localhost:3000/mcp` para el servidor local. La ruta `/v2/mcp` corresponde al servicio alojado en `https://mcp.firecrawl.dev/v2/mcp`.

Confirma que el proceso local esté listo antes de conectar un cliente:

```bash
curl http://localhost:3000/health
```

La comprobación de estado devuelve `ok`. Consulta [Ejecutar Firecrawl MCP localmente](/es/mcp-server/local#run-with-streamable-http) para conocer los requisitos previos y la configuración.

<div id="running-on-vs-code">
  ## Ejecutar en VS Code
</div>

Para instalar con un solo clic, haz clic en uno de los botones de instalación a continuación...

Para instalar manualmente, añade el siguiente bloque JSON al archivo de configuración de usuario (JSON) de VS Code. Para ello, pulsa `Ctrl + Shift + P` y escribe `Preferences: Open User Settings (JSON)`.

```json
{
  "mcp": {
    "inputs": [
      {
        "type": "promptString",
        "id": "apiKey",
        "description": "Firecrawl API Key",
        "password": true
      }
    ],
    "servers": {
      "firecrawl": {
        "command": "npx",
        "args": ["-y", "firecrawl-mcp"],
        "env": {
          "FIRECRAWL_API_KEY": "${input:apiKey}"
        }
      }
    }
  }
}
```

También puedes añadirlo a un archivo llamado `.vscode/mcp.json` en tu espacio de trabajo. Esto te permitirá compartir la configuración con otras personas:

```json
{
  "inputs": [
    {
      "type": "promptString",
      "id": "apiKey",
      "description": "Firecrawl API Key",
      "password": true
    }
  ],
  "servers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "${input:apiKey}"
      }
    }
  }
}
```

**Nota:** Algunos usuarios han reportado problemas al añadir el MCP Server a VS Code debido a cómo valida JSON con un formato de esquema obsoleto ([microsoft/vscode#155379](https://github.com/microsoft/vscode/issues/155379)).
Esto afecta a varias herramientas MCP, incluido Firecrawl.

**Solución alternativa:** Deshabilite la validación de JSON en VS Code para que el MCP Server se cargue correctamente.
Consulte la referencia: [directus/directus#25906 (comentario)](https://github.com/directus/directus/issues/25906#issuecomment-3369169513).

El MCP Server sigue funcionando correctamente cuando se invoca mediante otras extensiones, pero el problema ocurre específicamente al registrarlo directamente en la lista de servidores MCP. Añadiremos instrucciones cuando VS Code actualice la validación de esquemas.

<div id="running-on-claude-desktop">
  ## Ejecutar en Claude Desktop
</div>

Para una conexión de cuenta interactiva, añade el endpoint de la cuenta y completa el flujo OAuth en el navegador:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

Para una configuración desatendida o basada en una clave de API, usa `https://mcp.firecrawl.dev/v2/mcp` con la cabecera `Authorization: Bearer <FIRECRAWL_API_KEY>`.

Si aparece el error &quot;No se pudo conectar con el MCP Server&quot;, es posible que tu versión de Claude Desktop no sea compatible con el transporte HTTP Streamable. Usa en su lugar el enfoque local con npx (requiere [Node.js](https://nodejs.org)):

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "YOUR_API_KEY"
      }
    }
  }
}
```

Si aparece el error `spawn npx ENOENT`, Node.js no está instalado o no se encuentra en el PATH del sistema. Instala Node.js desde [nodejs.org](https://nodejs.org) (versión LTS) y reinicia por completo Claude Desktop. En Windows, también puedes ejecutar `where npx` en el Símbolo del sistema y usar la ruta completa (por ejemplo, `C:\\Program Files\\nodejs\\npx.cmd`) como valor de `command`.

<div id="running-on-claude-code">
  ## Ejecutar en Claude Code
</div>

Añade el Firecrawl MCP Server con la CLI de Claude Code. Puedes usar la URL alojada remotamente o ejecutarlo de forma local:

```bash
# Conexión interactiva de la cuenta (recomendada)
claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth

# Para una configuración desatendida con clave de API, usa una cabecera Authorization
claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp --header "Authorization: Bearer <FIRECRAWL_API_KEY>"

# O ejecútalo localmente con npx
claude mcp add firecrawl -e FIRECRAWL_API_KEY=fc-your-api-key -- npx -y firecrawl-mcp@3.23.0
```

<div id="running-on-google-antigravity">
  ## Ejecutar en Google Antigravity
</div>

Google Antigravity permite configurar servidores MCP directamente desde su interfaz de Agent.

<img src="/images/guides/mcp/antigravity-mcp-installation.gif" alt="Instalación de MCP de Antigravity" />

1. Abre la barra lateral de Agent en el Editor o la vista de Agent Manager
2. Haz clic en el menú &quot;...&quot; (Más acciones) y selecciona **MCP Servers**
3. Selecciona **Ver configuración sin procesar** para abrir el archivo local `mcp_config.json`
4. Añade la siguiente configuración:

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "YOUR_FIRECRAWL_API_KEY"
      }
    }
  }
}
```

5. Guarda el archivo y haz clic en **Actualizar** en la interfaz MCP de Antigravity para ver las nuevas herramientas.

Reemplaza `YOUR_FIRECRAWL_API_KEY` por tu clave de API de [https://firecrawl.dev/app/api-keys](https://www.firecrawl.dev/app/api-keys).

<div id="running-on-n8n">
  ## Ejecutar en n8n
</div>

Para conectar el Firecrawl MCP Server en n8n:

1. Obtén tu clave de API de Firecrawl en [https://firecrawl.dev/app/api-keys](https://www.firecrawl.dev/app/api-keys)
2. En tu flujo de trabajo de n8n, añade un nodo **AI Agent**
3. En la configuración de AI Agent, añade una nueva **Tool**
4. Selecciona **MCP Client Tool** como tipo de herramienta
5. Introduce el endpoint del Firecrawl MCP Server:

```
  https://mcp.firecrawl.dev/v2/mcp
```

6. Configura **Server Transport** como **HTTP Streamable**
7. Selecciona la autenticación:
   * Configura **Authentication** como **Bearer** y pega tu clave de API de Firecrawl para acceder a todas las herramientas de MCP.
   * Deja **Authentication** en **None** para el nivel Free sin clave, que solo expone Search, Scrape y Parse.
8. En **Tools to include**, selecciona **All**, **Selected** o **All Except** entre las herramientas disponibles para tu modo de autenticación.

Para implementaciones autogestionadas, ejecuta el Firecrawl MCP Server con npx y habilita el modo de transporte HTTP:

```bash
env HTTP_STREAMABLE_SERVER=true \
    FIRECRAWL_API_KEY=fc-YOUR_API_KEY \
    FIRECRAWL_API_URL=YOUR_FIRECRAWL_INSTANCE \
    npx -y firecrawl-mcp@3.23.0
```

Esto iniciará el servidor en `http://localhost:3000/mcp`, que puedes usar como endpoint en tu flujo de trabajo de n8n. La variable de entorno `HTTP_STREAMABLE_SERVER=true` es obligatoria, ya que n8n necesita transporte HTTP.
