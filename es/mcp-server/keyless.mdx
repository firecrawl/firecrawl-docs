<Visibility for="agents">
  URL del servidor sin clave (Streamable HTTP, sin credenciales): `https://mcp.firecrawl.dev/v2/mcp`

  * Codex: `codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp`
  * Claude Code: `claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp`
  * Cursor o cualquier cliente con configuración JSON: `{"mcpServers": {"firecrawl": {"url": "https://mcp.firecrawl.dev/v2/mcp"}}}`
  * OpenCode (`opencode.json`): `{"mcp": {"firecrawl": {"type": "remote", "url": "https://mcp.firecrawl.dev/v2/mcp", "enabled": true}}}`

  ChatGPT y Claude usan el conector nativo de Firecrawl: consulta [Para personas](/es/mcp-server/oauth.md#chatgpt-and-claude).
</Visibility>

El MCP sin clave está sujeto a límites de tasa y ofrece Search, scraping y procesamiento. Añade una clave de API para desbloquear todas las herramientas de Firecrawl MCP o límites más altos.

<div id="add-an-api-key">
  ## Añade una clave de API
</div>

[Crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys) y envíala como token bearer al mismo endpoint:

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

<div id="verify-your-connection">
  ## Verifica la conexión
</div>

Abre el estado de MCP o la lista de herramientas de tu cliente y confirma que `firecrawl` esté conectado. Una conexión sin clave muestra `firecrawl_search`, `firecrawl_scrape` y `firecrawl_parse`; una conexión con clave de API puede ofrecer [todas las herramientas de Firecrawl MCP](/es/mcp-server/tools), según el plan, la implementación y la política del equipo.

<div id="try">
  ## Prueba
</div>

```text
Busca en la web las notas de la última release de Firecrawl y resume las fuentes.
```

Si no aparece ninguna herramienta de Firecrawl, reinicia o recarga el cliente después de guardar su configuración de MCP.
