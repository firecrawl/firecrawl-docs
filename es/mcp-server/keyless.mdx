El MCP sin clave está sujeto a límites de tasa y ofrece Search, scraping y procesamiento. Añade una clave de API para desbloquear todas las herramientas de Firecrawl MCP o límites más altos.

## Añade una clave de API {#add-an-api-key}

[Crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys) y añádela como token bearer en el mismo endpoint dentro de la configuración de tu cliente:

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

## Verifica la conexión {#verify-your-connection}

Abre el estado de MCP o la lista de herramientas de tu cliente y confirma que `firecrawl` esté conectado. Una conexión sin clave muestra `firecrawl_search`, `firecrawl_scrape` y `firecrawl_parse`; una conexión con clave de API puede ofrecer [todas las herramientas de Firecrawl MCP](/es/mcp-server/tools), según el plan, la implementación y la política del equipo.

## Prueba {#try}

```text
Busca en la web las notas de la última release de Firecrawl y resume las fuentes.
```

Si no aparece ninguna herramienta de Firecrawl, reinicia o recarga el cliente después de guardar su configuración de MCP.
