Puedes revisar y revocar las conexiones desde la [configuración de MCP](https://www.firecrawl.dev/app/settings?tab=mcp).

¿Necesitas ChatGPT o Claude.ai? Consulta las guías de [ChatGPT](/es/developer-guides/mcp-setup-guides/chatgpt) y [Claude.ai](/es/developer-guides/mcp-setup-guides/claude-ai).

<div id="add-an-api-key">
  ## Añade una clave de API
</div>

[Crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys) y envíala como token de portador:

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

<div id="try">
  ## Prueba
</div>

```text
Busca en la web las notas de la última release de Firecrawl y resume las fuentes.
```

Si no aparece ninguna herramienta de Firecrawl, reinicia o vuelve a cargar el cliente después de guardar la configuración de MCP.
