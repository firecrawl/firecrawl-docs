---
title: Conectar Firecrawl MCP
description: "Selecciona la configuración de Firecrawl MCP con OAuth de cuenta, clave de API para uso desatendido o sin clave."
sidebarTitle: 'Conectar'
---

Usa el servicio Firecrawl MCP alojado en uno de estos tres modos. Elige según si una persona puede iniciar sesión y si el cliente puede almacenar de forma segura una clave de API.

<div id="connect-an-account">
  ## Conectar una cuenta
</div>

Usa este modo para un cliente interactivo compatible con OAuth, como Claude o Codex. Añade esta URL al cliente; detectará los metadatos de autorización de Firecrawl&#39;, abrirá el navegador y te pedirá que apruebes el equipo que debe usar.

```text
https://mcp.firecrawl.dev/v2/mcp-oauth
```

El cliente recibe tokens de corta duración vinculados a recursos, en lugar de tu clave de API de Firecrawl. Puedes revisar y revocar el acceso desde la [configuración de MCP](https://www.firecrawl.dev/app/settings?tab=mcp).

<Tip>
  Si el cliente solicita un ID de cliente OAuth o un secreto de cliente, deja ambos campos en blanco. Los clientes compatibles utilizan documentos de metadatos del ID de cliente o el registro dinámico de clientes.
</Tip>

<div id="run-unattended">
  ## Ejecutar de forma desatendida
</div>

Usa este modo para CI, servidores, scripts o cualquier entorno de ejecución sin navegador. Guarda la clave de API en una variable de entorno o un almacén de secretos y envíala en una cabecera Authorization.

```text
https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

Esto utiliza todas las herramientas de Firecrawl MCP. Las nuevas configuraciones no deben incluir una clave de API en la URL ni confirmarla en un archivo de configuración del proyecto.

<div id="try-keyless">
  ## Prueba sin clave de API
</div>

Usa este modo para probar Firecrawl sin necesidad de tener una cuenta ni una clave de API:

```text
https://mcp.firecrawl.dev/v2/mcp
```

El MCP sin clave está sujeto a límites de frecuencia por IP y, mientras cumplas los requisitos, ofrece exactamente **Search, Scrape y Parse**. Conecta una cuenta o usa una clave de API cuando necesites todas las herramientas o límites más altos.

<div id="pick-the-right-mode">
  ## Elige el modo adecuado
</div>

| Modo        | Endpoint        | Ideal para                                                       | Credenciales                                |
| ----------- | --------------- | ---------------------------------------------------------------- | ------------------------------------------- |
| Cuenta      | `/v2/mcp-oauth` | Clientes interactivos que pueden completar OAuth en el navegador | Tokens OAuth gestionados por el cliente     |
| Desatendido | `/v2/mcp`       | CI, servidores y scripts                                         | `Authorization: Bearer <FIRECRAWL_API_KEY>` |
| Sin clave   | `/v2/mcp`       | Una prueba limitada                                              | Ninguna                                     |

<div id="client-specific-help">
  ## Ayuda específica para cada cliente
</div>

Consulta la [configuración del cliente](/es/mcp-server/clients) para ver ejemplos de configuración. Si tu cliente no puede completar un flujo de OAuth remoto, usa la configuración desatendida basada en cabeceras o el modo sin clave. Si tampoco puede enviar cabeceras personalizadas, consulta la alternativa heredada que se indica a continuación.

<div id="legacy-api-key-url-support">
  ## Compatibilidad heredada con URL con clave de API
</div>

<Warning>
  Esta modalidad heredada solo existe para configuraciones y clientes existentes que no pueden completar OAuth ni enviar una cabecera Authorization personalizada. No es la configuración recomendada para nuevas integraciones.
</Warning>

```text
https://mcp.firecrawl.dev/<FIRECRAWL_API_KEY>/v2/mcp
```

La clave de API forma parte de la URL, así que trata la URL completa como si fuera una contraseña. Siempre que el cliente admita alguna de las dos opciones, utiliza OAuth de cuenta o una cabecera `Authorization: Bearer` basada en variables de entorno. Si esta URL queda expuesta, rota la clave de API. No la pegues nunca en chats, capturas de pantalla, incidencias ni configuraciones compartidas.

Esta alternativa solo se aplica a toda la superficie de `/v2/mcp`. No funciona con el recurso de búsqueda exclusivo de OAuth.

<div id="compatibility-during-migration">
  ## Compatibilidad durante la migración
</div>

Las conexiones OAuth existentes de `/v2/mcp` seguirán siendo compatibles durante la migración al endpoint de cuenta específico. Las nuevas conexiones interactivas de cuenta deben usar `/v2/mcp-oauth`; `/v2/mcp` no acepta nuevos tokens para ese recurso de cuenta.
