<div id="prerequisites">
  ## Requisitos previos
</div>

* Node.js 22 o una versión posterior
* npm y `npx`, incluidos con Node.js
* Una clave de API de Firecrawl para la API en la nube o una URL de una API de Firecrawl autogestionada

Confirma la versión de Node.js instalada:

```bash
node --version
```

<div id="run-over-stdio">
  ## Ejecutar mediante stdio
</div>

```bash
env FIRECRAWL_API_KEY=fc-YOUR_API_KEY npx -y firecrawl-mcp@3.23.0
```

Este es el transporte predeterminado para los clientes que ejecutan el MCP Server como proceso local.

<div id="run-with-streamable-http">
  ## Ejecutar con Streamable HTTP
</div>

Usa el transporte HTTP para clientes como n8n que se conectan a un MCP Server que ya está en ejecución:

```bash
env HTTP_STREAMABLE_SERVER=true \
  FIRECRAWL_API_KEY=fc-YOUR_API_KEY \
  npx -y firecrawl-mcp@3.23.0
```

Conecta el cliente a:

```text
http://localhost:3000/mcp
```

Confirma que el servidor esté listo:

```bash
curl http://localhost:3000/health
```

La comprobación de estado devuelve `ok`. La ruta local es `/mcp`; `/v2/mcp` es la ruta alojada de Firecrawl.

<div id="install-globally">
  ## Instalar globalmente
</div>

```bash
npm install -g firecrawl-mcp@3.23.0
```

A continuación, ejecuta:

```bash
env FIRECRAWL_API_KEY=fc-YOUR_API_KEY firecrawl-mcp
```

<div id="configuration">
  ## Configuración
</div>

<div id="environment-variables">
  ### Variables de entorno
</div>

<div id="cloud-and-self-hosted-api">
  #### API en la nube y autogestionada
</div>

* `FIRECRAWL_API_KEY`: Tu clave de API de Firecrawl
  * Obligatoria al utilizar la API en la nube (predeterminada)
  * Opcional al utilizar una instancia autogestionada con `FIRECRAWL_API_URL`
* `FIRECRAWL_API_URL` (Opcional): Endpoint de API personalizado para instancias autogestionadas
  * Ejemplo: `https://firecrawl.your-domain.com`
  * Si no se proporciona, se utilizará la API en la nube (requiere una clave de API)

<div id="configuration-examples">
  ### Ejemplos de configuración
</div>

Para usar la API en la nube:

```bash
export FIRECRAWL_API_KEY=your-api-key
```

Para instancias autogestionadas:

```bash
export FIRECRAWL_API_URL=https://firecrawl.your-domain.com
export FIRECRAWL_API_KEY=your-api-key  # Si tu instancia requiere autenticación
```

<div id="custom-configuration-with-claude-desktop">
  ### Configuración personalizada con Claude Desktop
</div>

Añade lo siguiente a tu `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "mcp-server-firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "YOUR_API_KEY_HERE"
      }
    }
  }
}
```

<div id="hosted-mcp-vs-local-mcp">
  ### MCP alojado frente a MCP local
</div>

El MCP Server alojado está optimizado para un uso remoto seguro. Algunas opciones disponibles al ejecutar el MCP Server localmente son más limitadas o no están disponibles de forma remota:

* El modo alojado sin clave expone únicamente Search, Scrape y Parse y está sujeto a límites de tasa por IP.
* La lectura de archivos locales solo está disponible al ejecutar el MCP Server localmente.
* Los Webhooks y las rutas de archivos locales deben configurarse desde un MCP Server local o autogestionado cuando el agent necesite acceder a recursos locales.

<Note>
  El procesamiento directo de archivos locales con `firecrawl_parse` requiere que `FIRECRAWL_API_URL` apunte a una API de Firecrawl autogestionada. Un MCP Server local configurado únicamente con una clave de API en la nube no puede cargar un archivo local mediante esa herramienta.
</Note>

<div id="rate-limiting">
  ### Límites de tasa
</div>

Firecrawl aplica límites de tasa. Usa una clave de API para obtener límites más altos y acceder al conjunto completo de herramientas.
