---

Ejecuta Firecrawl MCP localmente cuando un cliente necesite iniciar un proceso local, cuando necesites un transporte HTTP local o cuando el MCP Server deba conectarse a una API de Firecrawl autogestionada. Para el servicio gestionado, comienza con [Primeros pasos](/es/mcp-server).

<div id="prerequisites">
  ## Requisitos previos
</div>

* Node.js 22 o una versión posterior
* npm y `npx`, incluidos con Node.js
* Una clave de API de Firecrawl para la API en la nube o una URL de una API de Firecrawl autogestionada

Confirma la versión de Node.js instalada:

```bash
node --version
```

<div id="start-the-server">
  ## Inicia el servidor
</div>

<Tabs>
  <Tab title="stdio">
    Usa stdio cuando el cliente MCP inicie Firecrawl como proceso local:

    ```bash
    env FIRECRAWL_API_KEY=fc-YOUR-API-KEY \
      npx -y firecrawl-mcp@3.23.7
    ```

    Configura el cliente para ejecutar `npx -y firecrawl-mcp@3.23.7` y proporciona `FIRECRAWL_API_KEY` mediante el entorno protegido o el mecanismo de secretos del cliente.
  </Tab>

  <Tab title="Streamable HTTP">
    Usa HTTP cuando un cliente como n8n se conecte a un servidor que ya está en ejecución:

    ```bash
    env HTTP_STREAMABLE_SERVER=true \
      FIRECRAWL_API_KEY=fc-YOUR-API-KEY \
      npx -y firecrawl-mcp@3.23.7
    ```

    Conecta el cliente a:

    ```text
    http://localhost:3000/mcp
    ```

    Confirma que el servidor esté listo:

    ```bash
    curl http://localhost:3000/health
    ```

    La comprobación de estado devuelve `ok`. La ruta local es `/mcp`; `/v2/mcp` corresponde al servicio alojado de Firecrawl.
  </Tab>
</Tabs>

<div id="configure-the-firecrawl-api">
  ## Configura la API de Firecrawl
</div>

| Variable de entorno      | Finalidad                                                                                                          |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| `FIRECRAWL_API_KEY`      | Autentica en la API en la nube de Firecrawl. Solo es opcional si una API autogestionada no requiere autenticación. |
| `FIRECRAWL_API_URL`      | Envía solicitudes a una API de Firecrawl autogestionada en lugar de a la API en la nube.                           |
| `HTTP_STREAMABLE_SERVER` | Establécela en `true` para iniciar el transporte HTTP Streamable local en lugar de stdio.                          |

<CodeGroup>
  ```bash API en la nube
  export FIRECRAWL_API_KEY=fc-YOUR-API-KEY
  npx -y firecrawl-mcp@3.23.7
  ```

  ```bash API autogestionada
  export FIRECRAWL_API_URL=https://firecrawl.your-domain.com
  export FIRECRAWL_API_KEY=your-api-key # Omite esta línea si la instancia no requiere autenticación
  npx -y firecrawl-mcp@3.23.7
  ```
</CodeGroup>

<Note>
  El procesamiento directo de archivos locales con `firecrawl_parse` requiere que `FIRECRAWL_API_URL` apunte a una API de Firecrawl autogestionada. Un MCP Server local conectado únicamente a la API en la nube no puede cargar un archivo local mediante esa herramienta; en su lugar, el [servidor alojado usa una transferencia de carga firmada](/es/mcp-server/tools#important-behavior).
</Note>

<div id="install-globally">
  ## Instalar globalmente
</div>

Usa `npx` para una configuración más rápida. Para instalar globalmente la misma versión revisada:

```bash
npm install -g firecrawl-mcp@3.23.7
```

A continuación, ejecuta:

```bash
env FIRECRAWL_API_KEY=fc-YOUR-API-KEY firecrawl-mcp
```

<div id="troubleshooting">
  ## Solución de problemas
</div>

<AccordionGroup>
  <Accordion title="El cliente muestra el error spawn npx ENOENT">
    Instala Node.js 22 o una versión posterior, confirma que `npx` esté en el `PATH` del cliente y reinícialo por completo. En Windows, ejecuta `where npx` en el símbolo del sistema y configura el cliente para que use la ruta devuelta de `npx.cmd`.
  </Accordion>

  <Accordion title="El cliente HTTP no puede conectarse">
    Confirma que `HTTP_STREAMABLE_SERVER=true` y, a continuación, llama a `http://localhost:3000/health`. Usa `http://localhost:3000/mcp` como endpoint del cliente, no la ruta alojada `/v2/mcp`.
  </Accordion>

  <Accordion title="Una herramienta no está disponible">
    La disponibilidad de las herramientas depende de los servicios de Firecrawl habilitados en la implementación de destino. Compara la conexión en [Herramientas](/es/mcp-server/tools) y revisa la salida del proceso local en busca de errores de registro o autenticación.
  </Accordion>

  <Accordion title="El servidor está sujeto a límites de tasa">
    Los límites de tasa los aplica la API de Firecrawl conectada. Revisa los [límites de tasa](/es/rate-limits) actuales y los límites configurados para una implementación autogestionada.
  </Accordion>
</AccordionGroup>
