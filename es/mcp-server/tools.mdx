Firecrawl MCP ofrece herramientas para encontrar, extraer, interactuar con y supervisar contenido web. Tu cliente MCP recibe el esquema de entrada exacto de cada herramienta disponible al conectarse.

<div id="tool-availability">
  ## Disponibilidad de herramientas
</div>

| Modo de conexión                              | Herramientas disponibles                                                                          |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| OAuth alojado                                 | Conjunto completo de herramientas, sujeto al plan y a la política del equipo                      |
| clave de API alojada                          | Conjunto completo de herramientas, sujeto al plan y a la política del equipo                      |
| Sin clave alojado                             | `firecrawl_search`, `firecrawl_scrape` y `firecrawl_parse`                                        |
| Local con la API en la nube de Firecrawl      | Herramientas respaldadas por API; el procesamiento directo de archivos locales no está disponible |
| Local con una API de Firecrawl autogestionada | Herramientas compatibles con los servicios habilitados en esa implementación                      |

Comienza con [Primeros pasos](/es/mcp-server) y elige [Para agentes](/es/mcp-server/keyless) o [Para personas](/es/mcp-server/oauth). Algunas herramientas opcionales pueden deshabilitarse mediante el entorno o la política del equipo.

<div id="choose-a-tool">
  ## Selecciona una herramienta
</div>

| Trabajo                                | Herramienta                                        | Úsala cuando                                                                                                                                                             |
| -------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Leer una página                        | `firecrawl_scrape`                                 | Conoces la URL y necesitas el contenido de la página o campos estructurados.                                                                                             |
| Extraer datos estructurados            | `firecrawl_scrape` con formato JSON                | Tienes la URL y quieres datos que coincidan con un prompt o esquema JSON.                                                                                                |
| Descubrir las URL de un sitio          | `firecrawl_map`                                    | Necesitas encontrar páginas antes de decidir qué extraer.                                                                                                                |
| Buscar en la web                       | `firecrawl_search`                                 | Tienes una consulta en lugar de una URL conocida.                                                                                                                        |
| Procesar un archivo                    | `firecrawl_parse`                                  | Necesitas contenido de un PDF, documento, hoja de cálculo o archivo HTML.                                                                                                |
| Extraer varias páginas                 | `firecrawl_crawl` y `firecrawl_check_crawl_status` | Necesitas recorrer un sitio o una sección. La herramienta de rastreo consulta el estado del trabajo hasta que alcanza un estado terminal antes de devolver el resultado. |
| Realizar investigación autónoma        | `firecrawl_agent` y `firecrawl_agent_status`       | La tarea abarca varias fuentes y se desconocen las páginas exactas.                                                                                                      |
| Interactuar con una página activa      | `firecrawl_interact` y `firecrawl_interact_stop`   | Necesitas hacer clic, completar formularios, navegar o extraer contenido de páginas dinámicas.                                                                           |
| Investigar artículos y repositorios    | `firecrawl_research_*`                             | Necesitas descubrir o leer artículos, buscar trabajos relacionados o repositorios públicos.                                                                              |
| Responder una pregunta de programación | `firecrawl_developer_search`                       | Necesitas respuestas de fuentes primarias procedentes de issues, pull requests fusionadas, archivos README y documentación seleccionada.                                 |
| Supervisar cambios                     | `firecrawl_monitor_*`                              | Necesitas comprobaciones recurrentes, diffs y notificaciones por webhook o correo electrónico.                                                                           |
| Enviar feedback sobre el producto      | `firecrawl_search_feedback` y `firecrawl_feedback` | Quieres valorar resultados de búsqueda o informar sobre la calidad de un endpoint.                                                                                       |

<Note>
  La antigua herramienta MCP Extract está obsoleta y no forma parte del conjunto actual de herramientas. Usa Scrape con formato JSON para una página conocida, o Agent cuando Firecrawl deba descubrir las fuentes. Consulta [Elegir el extractor de datos](/es/developer-guides/usage-guides/choosing-the-data-extractor) para ver la comparación completa.
</Note>

<div id="important-behavior">
  ## Comportamiento importante
</div>

<AccordionGroup>
  <Accordion title="Procesar un archivo local">
    Un MCP Server local conectado a una API de Firecrawl autogestionada puede leer `filePath` directamente. El servidor alojado no puede leer archivos de tu máquina, por lo que utiliza un proceso de dos llamadas:

    1. Llama a `firecrawl_parse` con `filePath` para recibir un comando de carga y `uploadRef`.
    2. Ejecuta el comando de carga en la máquina que puede leer el archivo.
    3. Vuelve a llamar a `firecrawl_parse` con el `uploadRef` devuelto.

    El comando de carga usa un objetivo firmado de corta duración y no contiene tu clave de API de Firecrawl. Usa `firecrawl_scrape` para una URL de documento pública.
  </Accordion>

  <Accordion title="Comprobar un rastreo en ejecución">
    `firecrawl_crawl` normalmente inicia un rastreo y consulta su estado hasta que alcanza un estado terminal antes de responder. Si se agota el tiempo de espera, reanuda el trabajo con `firecrawl_check_crawl_status` y el ID del rastreo. Usa la misma herramienta de estado para un rastreo creado fuera de la llamada MCP actual.

    `firecrawl_agent` es asíncrono: devuelve un ID de trabajo y `firecrawl_agent_status` comprueba ese trabajo hasta que se complete o falle.
  </Accordion>

  <Accordion title="Cerrar sesiones de Interact">
    Comienza con una `url` o reutiliza el `scrapeId` de una llamada a Scrape anterior. Cuando finalice el flujo de trabajo, llama a `firecrawl_interact_stop` con el `scrapeId` para liberar la sesión.
  </Accordion>

  <Accordion title="Gestionar monitores de forma segura">
    La familia `firecrawl_monitor_*` crea, enumera, actualiza, ejecuta e inspecciona monitores recurrentes. `firecrawl_monitor_delete` elimina permanentemente un monitor y solo debe llamarse cuando el usuario tenga la intención explícita de eliminarlo.
  </Accordion>

  <Accordion title="Habilitar herramientas de feedback opcionales">
    Establece `FIRECRAWL_NO_SEARCH_FEEDBACK=1` para evitar que se registre `firecrawl_search_feedback`. Establece `FIRECRAWL_NO_ENDPOINT_FEEDBACK=1` para evitar que se registre `firecrawl_feedback`.
  </Accordion>
</AccordionGroup>

<div id="troubleshooting">
  ## Solución de problemas
</div>

* **Falta una herramienta:** confirme el modo de conexión en [Primeros pasos](/es/mcp-server), vuelva a conectarse o reinicie el cliente y compruebe si la política del equipo deshabilita herramientas opcionales.
* **El cliente devuelve `401`:** primero compruebe la URL del servidor configurada.
  * Si la URL configurada es `/v2/mcp-oauth`, vuelva a iniciar sesión a través del cliente.
  * Si es `/v2/mcp`, reemplace la clave de API en ese servidor o actualice la URL del servidor existente a `/v2/mcp-oauth` y complete el inicio de sesión.
  * Inicie una nueva sesión de cliente después de cualquiera de los cambios.

- **El cliente ha alcanzado el límite de tasa:** consulte los [límites de tasa](/es/rate-limits) actuales, espere el intervalo antes de reintentar o cambie del acceso sin clave al acceso autenticado.
