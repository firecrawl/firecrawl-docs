  ## Prueba el acceso sin clave
</div>

<McpClientSelector variant="agent" showSeeAll={false} />

El MCP sin clave está sujeto a un límite de tasa y ofrece Search, Scrape y Parse. Añade una clave de API para desbloquear todas las herramientas de Firecrawl MCP o límites más altos.

<div id="add-an-api-key">
  ## Añade una clave de API
</div>

[Crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys) y envíala como un token de portador al mismo endpoint:

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

<Warning>
La persona o el sistema operador debe configurar la clave fuera de la conversación del agente. Nunca pegues la clave en el chat, en la URL de MCP ni en un archivo del proyecto.
</Warning>

<div id="verify-your-connection">
  ## Verifica tu conexión
</div>

Abre el estado de MCP o la lista de herramientas de tu cliente y confirma que `firecrawl` esté conectado. Una conexión sin clave muestra `firecrawl_search`, `firecrawl_scrape` y `firecrawl_parse`; una conexión con clave de API puede ofrecer [todas las herramientas de Firecrawl MCP](/es/mcp-server/tools), según el plan, la implementación y las políticas del equipo.

<div id="try">
  ## Prueba
</div>

```text
Busca en la web las notas de la última versión de Firecrawl y resume las fuentes.
```

Si no aparecen herramientas de Firecrawl, reinicia o recarga el cliente después de guardar la configuración de MCP.
