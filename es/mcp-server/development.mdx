<div id="development">
  ## Desarrollo
</div>

```bash
# Instalar dependencias
npm install

# Compilar
npm run build

# Ejecutar las pruebas
npm test
```

<div id="contributing">
  ### Contribuir
</div>

1. Haz un fork del repositorio
2. Crea una rama para tu funcionalidad
3. Ejecuta las pruebas: `npm test`
4. Envía un pull request
