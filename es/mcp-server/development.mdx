<div id="prerequisites">
  ## Requisitos previos
</div>

* [Git](https://git-scm.com/downloads)
* Node.js 22 o una versión posterior
* npm, incluido con Node.js

Comprueba la versión de Node.js antes de instalar las dependencias:

```bash
node --version
```

<div id="clone-and-test-the-server">
  ## Clona y prueba el servidor
</div>

```bash
git clone https://github.com/firecrawl/firecrawl-mcp-server.git
cd firecrawl-mcp-server
npm install
npm run build
npm test
```

Ejecuta el linter antes de enviar un cambio:

```bash
npm run lint
```

<div id="contributing">
  ## Contribuir
</div>

1. Haz un fork del [repositorio de Firecrawl MCP Server](https://github.com/firecrawl/firecrawl-mcp-server).
2. Clona tu fork y crea una rama para la funcionalidad.
3. Ejecuta `npm run lint` y `npm test`.
4. Envía un pull request con el comportamiento y las evidencias de verificación.
