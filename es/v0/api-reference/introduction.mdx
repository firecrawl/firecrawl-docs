<div id="base-url">
  ## URL base {#base-url}
</div>

Todas las solicitudes usan la siguiente URL base:

```bash
https://api.firecrawl.dev 
```

## Authentication {#authentication}

Para la authentication, es necesario incluir una cabecera de Authorization. La cabecera debe contener `Bearer fc_123456789`, donde `fc_123456789` representa tu API Key.

```bash
Authorization: Bearer fc_123456789
```

​

## Códigos de respuesta {#response-codes}

Firecrawl emplea códigos de estado HTTP convencionales para indicar el resultado de tus solicitudes.

Por lo general, los códigos 2xx indican éxito, los 4xx representan fallos atribuibles al usuario y los 5xx señalan problemas de infraestructura.

| Estado | Descripción                                 |
| ------ | ------------------------------------------- |
| 200    | La solicitud se realizó correctamente.      |
| 400    | Verifica que los parámetros sean correctos. |
| 401    | No se proporcionó la API key.               |
| 402    | Pago requerido                              |
| 404    | No se pudo encontrar el recurso solicitado. |
| 429    | Se ha superado el límite de tasa.           |
| 5xx    | Indica un error del servidor de Firecrawl.  |

Consulta la sección Códigos de error para ver una explicación detallada de todos los posibles errores de la API.

​

<div id="rate-limit">
  ## Límite de tasa {#rate-limit}
</div>

La API de Firecrawl tiene un límite de tasa para garantizar la estabilidad y la confiabilidad del servicio. Este límite se aplica a todos los puntos de conexión y se basa en la cantidad de solicitudes realizadas dentro de un periodo de tiempo específico.

Si excedes el límite de tasa, recibirás un código de respuesta 429.
