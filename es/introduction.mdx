Firecrawl es la API de datos web para agentes de IA. Busca, haz scraping e interactúa con la web en vivo para obtener Markdown limpio o datos estructurados.

## Primeros pasos {#get-started}

<Visibility for="humans">
  <McpClientSelector variant="human" />
</Visibility>

<Visibility for="agents">
  Conéctate a través de Streamable HTTP. La URL del servidor sin clave (Búsqueda, scraping y procesar; no requiere credenciales) es `https://mcp.firecrawl.dev/v2/mcp`.

  * Codex: `codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp`
  * Claude Code: `claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp`
  * Cursor o cualquier cliente con configuración JSON: `{"mcpServers": {"firecrawl": {"url": "https://mcp.firecrawl.dev/v2/mcp"}}}`
  * OpenCode (`opencode.json`): `{"mcp": {"firecrawl": {"type": "remote", "url": "https://mcp.firecrawl.dev/v2/mcp", "enabled": true}}}`
  * ChatGPT o Claude.ai: usa el conector nativo de Firecrawl — [ChatGPT](https://chatgpt.com/plugins?q=firecrawl) o [Claude](https://claude.ai/directory/connectors/firecrawl).

  Ambas rutas de configuración y la configuración de la clave de API: [Primeros pasos con MCP](/es/mcp-server.md), [Para agentes](/es/mcp-server/keyless.md) y [Para personas](/es/mcp-server/oauth.md).
</Visibility>

### Crea directamente con la API {#build-directly-with-the-api}

Haz scraping de tu primera página. No necesitas una cuenta ni una clave de API para esta solicitud.

<ScrapeCURL />

Añade una [clave de API](https://www.firecrawl.dev/app/api-keys) cuando necesites límites más altos. Consulta el [Python SDK](/es/sdks/python), el [Node SDK](/es/sdks/node) o la [referencia de la API](/es/api-reference/endpoint/scrape) para integrarlo en tu aplicación.

## Otras formas de empezar {#other-ways-to-get-started}

### Instala la CLI de Firecrawl {#install-the-firecrawl-cli}

Un solo comando instala la CLI de Firecrawl, autentica en tu navegador y añade skills a todos los agentes de programación detectados.

```bash
npx -y firecrawl-cli@latest init --all --browser
```

<Note>
  Reinicia tu agente de programación después de la configuración para que pueda descubrir las nuevas skills. Consulta
  [CLI](/es/sdks/cli) para ver la configuración completa.
</Note>

### Configúralo con un agente {#set-up-with-an-agent}

Dale a tu agente este prompt de configuración de Firecrawl o consulta [todas las opciones de configuración de MCP](/es/mcp-server).

### ¿Por qué Firecrawl? {#why-firecrawl}

* **Salida lista para LLM**: Markdown limpio, JSON estructurado, capturas de pantalla y más.
* **Se encarga de lo difícil**: Proxies, protección anti-bots, renderizado de JavaScript y contenido dinámico.
* **Fiable**: Diseñado para producción, con alta disponibilidad y resultados consistentes.
* **Rápido**: Resultados en segundos, optimizado para un alto rendimiento.
* **MCP Server**: Conecta Firecrawl a cualquier herramienta de IA mediante [Model Context Protocol](/es/mcp-server).
