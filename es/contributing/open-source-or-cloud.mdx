Elige el código abierto cuando necesites controlar el código fuente o la infraestructura. Elige Firecrawl Cloud cuando quieras empezar a hacer scraping sin tener que operar la pila. Ambas opciones exponen las API principales de Firecrawl; la diferencia es quién configura, protege y opera los servicios de soporte.

<Note>
  Ejecutar Firecrawl para el desarrollo de productos y operar una implementación
  autogestionada son tareas distintas. Usa [Ejecutar en](/es/contributing/guide)
  cuando modifiques el código de Firecrawl. Usa la [guía de
  autogestión](/es/contributing/self-host) cuando quieras ejecutar una API en una infraestructura
  que controles.
</Note>

<div id="choose-your-firecrawl-deployment">
  ## Selecciona tu implementación de Firecrawl
</div>

<div id="use-open-source-when">
  ### Usa código abierto cuando
</div>

* **Necesitas controlar el código fuente o la infraestructura.** Puedes inspeccionar el código, elegir dónde se ejecuta la pila y conectar tus propios proveedores.
* **Estás preparado para operarlo.** Tu equipo se encarga de la autenticación, TLS, persistencia, supervisión, capacidad, actualizaciones y recuperación.
* **Puedes añadir funcionalidades de forma deliberada.** El scraping básico funciona en la pila predeterminada; los formatos basados en LLM, los servicios avanzados de scraping y las vías de extracción especializadas requieren configuración adicional.

<div id="use-firecrawl-cloud-when">
  ### Usa Firecrawl Cloud cuando
</div>

* **Quieres la forma más rápida y con soporte de llegar a producción.** Firecrawl opera la infraestructura y los servicios gestionados.
* **Necesitas funcionalidades exclusivas de Cloud.** Agent, Browser, dashboards gestionados, rutas de proxy mejorado y controles empresariales se ofrecen a través de Cloud.
* **Quieres una única cuenta para el uso y el soporte.** Las claves de API, los créditos, los límites y el soporte operativo se mantienen en el servicio gestionado.

**Nuestra recomendación:** empieza con Firecrawl Cloud, salvo que el acceso al código fuente o el control de la infraestructura justifiquen el esfuerzo operativo. Si optas por el autoalojamiento, prueba primero un scraping y añade servicios solo cuando tu caso de uso lo requiera.

<div id="compare-the-operating-model">
  ## Compare el modelo operativo
</div>

| Decisión                                                         | Código abierto                                         | Firecrawl Cloud                                          |
| ---------------------------------------------------------------- | ------------------------------------------------------ | -------------------------------------------------------- |
| API principales de scraping, rastreo, mapeo y búsqueda           | Incluidas                                              | Incluidas y administradas                                |
| Procesamiento con Fetch y Playwright                             | Incluido en la pila predeterminada                     | Administrado                                             |
| Extracción y formatos basados en LLM                             | Conecte un proveedor compatible con OpenAI u Ollama    | Proveedor administrado                                   |
| Servicios avanzados antibots o de extracción especializada       | Ejecute y configure el servicio necesario por separado | Administrado cuando el producto Cloud lo admite          |
| Controles de Agent, Browser, Interact, dashboard y empresariales | No incluidos en la pila predeterminada                 | Incluidos según la disponibilidad del producto y el plan |
| Seguridad, persistencia, disponibilidad y actualizaciones        | Usted se encarga de ellos                              | Firecrawl se encarga de ellos                            |
| Uso, límites y facturación                                       | Sus costos de infraestructura y proveedores            | Modelo de planes y créditos de Firecrawl                 |

<div id="start-with-the-path-you-chose">
  ## Empieza por la opción que elijas
</div>

* **Autoalojar Firecrawl:** sigue la [guía para autoalojar con Docker Compose](/es/contributing/self-host), desde una versión específica hasta un scraping verificado.
* **Modificar el código de Firecrawl:** usa [Ejecutar en](/es/contributing/guide) para configurar el entorno de desarrollo para colaboradores.
* **Usar Firecrawl Cloud:** [crea una cuenta](https://firecrawl.dev) y sigue el [inicio rápido](/es/quickstart).

El código abierto permite inspeccionar y adaptar el motor principal. Firecrawl Cloud financia ese trabajo y ofrece a los desarrolladores una opción gestionada con capacidades adicionales de producto e infraestructura.
