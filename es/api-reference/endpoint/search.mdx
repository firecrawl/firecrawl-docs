El endpoint de búsqueda combina la búsqueda web con las capacidades de scraping de Firecrawl para devolver el contenido completo de la página para cualquier consulta.

Incluye `scrapeOptions` con `formats: [{"type": "markdown"}]` para obtener el contenido completo en markdown de cada resultado de búsqueda; de lo contrario, por defecto solo obtendrás los resultados (url, title, description). También puedes usar otros formatos como `{"type": "summary"}` para obtener contenido condensado.

<div id="supported-query-operators">
  ## Operadores de consulta admitidos {#supported-query-operators}
</div>

Admitimos una variedad de operadores de consulta que te permiten filtrar mejor tus búsquedas.

| Operador | Funcionalidad | Ejemplos |
---|-|-|
| `""` | Coincidencia exacta de una cadena de texto (no difusa) | `"Firecrawl"`
| `-` | Excluye ciertas palabras clave o niega otros operadores | `-bad`, `-site:firecrawl.dev`
| `site:` | Devuelve solo resultados de un sitio web específico | `site:firecrawl.dev`
| `filetype:` | Devuelve solo resultados con una extensión de archivo específica | `filetype:pdf`, `-filetype:pdf`
| `inurl:` | Devuelve solo resultados que incluyan una palabra en la URL | `inurl:firecrawl`
| `allinurl:` | Devuelve solo resultados que incluyan varias palabras en la URL | `allinurl:git firecrawl`
| `intitle:` | Devuelve solo resultados que incluyan una palabra en el título de la página | `intitle:Firecrawl`
| `allintitle:` | Devuelve solo resultados que incluyan varias palabras en el título de la página | `allintitle:firecrawl playground`
| `related:` | Devuelve solo resultados relacionados con un dominio específico | `related:firecrawl.dev`
| `imagesize:` | Devuelve solo imágenes con dimensiones exactas | `imagesize:1920x1080`
| `larger:` | Devuelve solo imágenes más grandes que las dimensiones especificadas | `larger:1920x1080`

<div id="location-parameter">
  ## Parámetro de ubicación {#location-parameter}
</div>

Usa el parámetro `location` para obtener resultados de búsqueda geodirigidos. Formato: `"string"`. Ejemplos: `"Germany"`, `"San Francisco,California,United States"`.

Consulta la [lista completa de ubicaciones compatibles](https://firecrawl.dev/search_locations.json) para ver todos los países e idiomas disponibles.

<div id="country-parameter">
  ## Parámetro country {#country-parameter}
</div>

Usa el parámetro `country` para especificar el país de los resultados de búsqueda usando códigos de país ISO. Valor predeterminado: `"US"`.

Ejemplos: `"US"`, `"DE"`, `"FR"`, `"JP"`, `"UK"`, `"CA"`.

```json
{
  "query": "restaurantes",
  "country": "DE"
}
```

## Parámetro Categories {#categories-parameter}

Filtra los resultados de búsqueda por categorías específicas mediante el parámetro `categories`:

* **`research`**: Restringe la búsqueda web a sitios académicos y de investigación (arxiv.org, nature.com, pubmed.ncbi.nlm.nih.gov y similares). A partir del 2026-11-16 buscará en el [Research Index](/es/features/research) y devolverá registros de artículos; consulta la advertencia más abajo
* **`pdf`**: Busca PDFs
* **`developer`**: Busca en el [Developer Index](/es/features/developer): issues, pull requests fusionados y archivos README de repositorios de código públicos, además de sitios de documentación seleccionados

<Warning>
  **La categoría `research` cambia el 2026-11-16.** Buscará en el [Research Index](/es/features/research) (PubMed, bioRxiv, medRxiv, arXiv) en lugar de limitar los resultados web a 14 sitios académicos. Los resultados pasarán de `data.web` a `data.research` y se devolverán como registros de artículos: `paperId`, `primaryId`, `ids`, `title`, `abstract`, `score`. Hasta entonces, cada respuesta que la utilice incluirá una entrada `warnings`.

  Si necesitas registros de artículos, actualiza tu parsing antes de esa fecha o llama hoy mismo a [`GET /search/research/papers`](/es/api-reference/endpoint/research-search-papers). Si necesitas páginas web de sitios académicos, cambia a [`includeDomains`](#domain-filters).
</Warning>

### Ejemplo de uso {#example-usage}

```json
{
  "query": "aprendizaje automático",
  "categories": ["research", "pdf"],
  "limit": 10
}
```

## Filtros de dominio {#domain-filters}

Usa `includeDomains` para limitar los resultados a dominios específicos, o `excludeDomains` para excluir dominios específicos de la búsqueda. Los dominios deben ser únicamente nombres de host, sin protocolo ni ruta.

`includeDomains` y `excludeDomains` son mutuamente excluyentes.

### Ejemplo de inclusión de dominios {#include-domains-example}

```json
{
  "query": "web scraping",
  "includeDomains": ["firecrawl.dev", "docs.firecrawl.dev"],
  "limit": 10
}
```

### Ejemplo de exclusión de dominios {#exclude-domains-example}

```json
{
  "query": "web scraping tools",
  "excludeDomains": ["example.com"],
  "limit": 10
}
```

### Respuesta de categoría {#category-response}

Cada resultado incluye un campo `category` que indica su origen:

```json
{
  "success": true,
  "data": {
    "web": [
      {
        "url": "https://arxiv.org/abs/2024.12345",
        "title": "ML Research Paper",
        "description": "Latest advances in machine learning",
        "category": "research"
      },
      {
        "url": "https://example.com/ml-survey.pdf",
        "title": "ML Survey",
        "description": "A survey of machine learning methods",
        "category": "pdf"
      }
    ]
  }
}
```

## Búsqueda por tiempo {#time-based-search}

Usa el parámetro `tbs` para filtrar los resultados por períodos de tiempo, incluidos rangos de fechas personalizados. Consulta la [documentación de la funcionalidad de búsqueda](https://docs.firecrawl.dev/features/search#time-based-search) para ver ejemplos detallados y formatos compatibles.
