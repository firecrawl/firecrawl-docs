---
title: "Buscar en el Government Index"
openapi: "/es/api-reference/v2-openapi.json GET /search/gov"
---

Busca legislación primaria y normativa de fuentes gubernamentales federales, estatales y locales de EE. UU.: leyes, reglamentos, códigos, sentencias judiciales y otras publicaciones oficiales. Los resultados se devuelven en el grupo estándar `web`, con la misma estructura que un resultado web de [`/search`](/es/api-reference/endpoint/search).

También puedes usar `POST` en la misma ruta, enviando los mismos campos en un cuerpo JSON. Los campos desconocidos y los valores de filtro no válidos se rechazan con un `400`, y el error indica qué valor debes corregir.

`query` es obligatorio. Incluye la jurisdicción, el organismo o la cita, y la fecha relevante si la conoces. `k` indica el número de resultados, de 1 a 100, con 10 como valor predeterminado; el punto de conexión general `/search` usa `limit` en su lugar.

Los resultados son fragmentos coincidentes y pueden incluir versiones históricas, textos de proyectos de ley, guías o reproducciones de terceros. Verifica el emisor, la jurisdicción, el estado de promulgación/vigencia y la versión antes de citar legislación vigente. Consulta la fuente original de una coincidencia cuando el fragmento no sea suficiente. El índice se centra en material de EE. UU.; la ausencia de resultados no demuestra que no exista legislación aplicable.

## Filtros {#filters}

Todos los filtros son opcionales y se combinan con semántica AND.

| Campo          | Conserva solo las páginas que                                                                                                                                                                                                                    |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `jurisdiction` | pertenecen a una jurisdicción: `us` para la federal, o `us-` seguido de un código de estado o territorio de dos letras, como `us-ca` o `us-dc`.                                                                                                  |
| `court`        | están etiquetadas con un tribunal concreto, según el id de tribunal de CourtListener, como `scotus`, `ca9` o `nysd`.                                                                                                                             |
| `courtType`    | proceden de un tipo de tribunal: `federal-supreme`, `federal-appellate`, `federal-district`, `federal-bankruptcy`, `federal-special`, `military`, `state-supreme`, `state-appellate`, `state-trial`, `state-special` o `state-attorney-general`. |
| `cites`        | citan una ley o un caso concreto, ya sea con una cita impresa, como `42 U.S.C. § 1983` o `5 U.S. 137`, o con un id de cita, como `us:usc:42:1983`.                                                                                               |
| `domain`       | proceden de un sitio concreto, como `irs.gov`.                                                                                                                                                                                                   |

Los filtros conservan solo las páginas que el índice ha etiquetado, por lo que una búsqueda filtrada puede omitir páginas relevantes, y la ausencia de resultados no significa que no existan. Las etiquetas de tribunales son más completas en el caso de los tribunales federales y las colecciones de jurisprudencia.

<CodeGroup>
  ```bash cURL
  # No se necesita clave de API para empezar; añade -H "Authorization: Bearer $FIRECRAWL_API_KEY" para obtener límites de tasa más altos:
  curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
  ```

  ```bash cURL (POST)
  curl -X POST https://api.firecrawl.dev/v2/search/gov \
    -H "Authorization: Bearer $FIRECRAWL_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "query": "food labeling requirements for allergens",
      "k": 10
    }'
  ```
</CodeGroup>
