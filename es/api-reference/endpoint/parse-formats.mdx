---
title: 'Formatos de Parse'
openapi: '/es/api-reference/v2-openapi.json GET /parse/formats'
---

Enumera todos los formatos de archivo que acepta [`/parse`](/es/api-reference/endpoint/parse), junto con sus extensiones de archivo y tipos MIME. La lista se genera a partir de las mismas reglas que usa `/parse` para validar los archivos subidos, así que puedes comprobar un archivo antes de enviarlo sin tener que mantener tu propia lista de tipos admitidos.

Cada entrada tiene un `kind` con valor `document` o `image`. Los formatos de imagen se procesan con OCR e incluyen `available: false` cuando el OCR de imágenes no está habilitado; en ese caso, los archivos de esos formatos se rechazan con `UNSUPPORTED_FILE_TYPE` hasta que se habilite.

La lista cambia con poca frecuencia. Las respuestas incluyen `Cache-Control: private, max-age=3600`, por lo que puedes almacenarlas en caché de forma segura durante un máximo de una hora.
