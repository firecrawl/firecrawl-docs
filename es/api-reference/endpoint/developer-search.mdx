---
title: "Buscar en el índice de desarrolladores"
openapi: "/es/api-reference/v2-openapi.json GET /search/developer"
---

Busca issues de GitHub, pull requests fusionadas, README de repositorios y sitios de documentación seleccionados. Los resultados se clasifican e incluyen los pasajes coincidentes en markdown.

`POST` está disponible en la misma ruta si quieres pasar filtros de tipo array como JSON.

Para ver una descripción general del flujo de trabajo, consulta la [guía del índice de desarrolladores](/es/features/developer).
