<div id="overview">
  ## Descripción general
</div>

La facturación de Firecrawl se basa en **créditos**. Cada llamada a la API que haces consume créditos. La cantidad de créditos depende del endpoint y de las opciones que utilices. Tu plan te proporciona una asignación mensual de créditos. pago por uso agrega más créditos cuando se agota la asignación.

Para ver los precios de los planes vigentes, visita la [página de precios de Firecrawl](https://www.firecrawl.dev/pricing).

<Note>
  Todas las facturas de Firecrawl se emiten en **dólares estadounidenses (USD)**, independientemente de tu dirección de facturación o método de pago.
</Note>

<div id="credits">
  ## Créditos
</div>

Los créditos son la unidad de consumo en Firecrawl. Cada plan incluye una cuota mensual de créditos que se reinicia al comienzo de cada ciclo de facturación. Los distintos endpoints de la API consumen diferentes cantidades de créditos.

<div id="credit-costs-per-endpoint">
  ### Costo de créditos por endpoint
</div>

| Endpoint     | Credit Cost                        | Notes                                                                                                                                                                                                                                                                                                                                  |
| ------------ | ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Scrape**   | 1 crédito / página                 | Convierte una única URL en markdown limpio, HTML o datos estructurados. Se aplican créditos adicionales al usar opciones de extracción (ver más abajo).                                                                                                                                                                                |
| **Crawl**    | 1 crédito / página                 | Extrae un sitio web completo siguiendo enlaces desde una URL inicial. Los mismos costos por página de las opciones de extracción se aplican a cada página rastreada.                                                                                                                                                                   |
| **Map**      | 1 crédito / llamada                | Descubre todas las URL de un sitio web sin extraer su contenido.                                                                                                                                                                                                                                                                       |
| **Search**   | 2 créditos / 10 resultados         | Busca en la web y, opcionalmente, extrae los resultados. Redondeado hacia arriba por cada 10 resultados (p. ej., 11 resultados = 4 créditos). Se aplican costos adicionales de extracción por página a cada resultado que se extrae. Consulta [aquí](/es/features/search#zero-data-retention-zdr) los precios de búsqueda ZDR Enterprise. |
| **Interact** | 2–7 créditos / minuto de navegador | Sesión interactiva de navegador en sandbox, facturada por minuto de navegador con un mínimo de un minuto. Las sesiones que usan un `prompt` se facturan a 7 créditos / minuto de navegador; las sesiones sin un prompt (solo `code` de Playwright) se facturan a 2 créditos / minuto de navegador.                                     |
| **Agent**    | Dinámico                           | Agente autónomo de investigación web. 5 ejecuciones diarias gratuitas; precios basados en uso a partir de ese límite.                                                                                                                                                                                                                  |

<div id="additional-credit-costs-for-scrape-options">
  ### Costos de crédito adicionales para las opciones de scraping
</div>

Ciertas opciones de scraping añaden créditos sobre el costo base por página:

| Option                                                 | Additional Cost         | Description                                                                                                                                                                                                                                                                                                                           |
| ------------------------------------------------------ | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PDF parsing                                            | +1 crédito / página PDF | Extrae contenido de documentos PDF                                                                                                                                                                                                                                                                                                    |
| formato JSON (extracción con LLM)                      | +4 créditos / página    | Usa un LLM para extraer datos JSON estructurados de la página                                                                                                                                                                                                                                                                         |
| Comprobación de inyección de prompts                   | +4 créditos / página    | Protección opcional `checkPromptInjection` para el formato JSON (consulta [Detección de inyección de prompts](/es/features/llm-extract#prompt-injection-detection)). Si el scraping falla después de que se haya ejecutado la comprobación, se facturan 5 créditos. Consulta [Cuándo se cobran los créditos](#when-credits-are-charged). |
| retención de datos cero (ZDR)                          | +1 crédito / página     | Garantiza que no se conserve ningún dato más allá de la solicitud (consulta [Scrape ZDR](/es/features/scrape#zero-data-retention-zdr))                                                                                                                                                                                                   |
| formato `question` o `query`                           | +4 créditos / página    | Respuesta generada por un LLM a una pregunta sobre la página (consulta [Scrape](/es/features/scrape))                                                                                                                                                                                                                                    |
| formato `highlights`                                   | +4 créditos / página    | Pasajes relevantes de la página seleccionados por un LLM (consulta [Scrape](/es/features/scrape))                                                                                                                                                                                                                                        |
| formato `audio`                                        | +4 créditos / página    | Transcribe el audio encontrado en la página (consulta [Scrape](/es/features/scrape))                                                                                                                                                                                                                                                     |
| formato `video`                                        | +4 créditos / página    | Transcribe el video encontrado en la página (consulta [Scrape](/es/features/scrape))                                                                                                                                                                                                                                                     |
| Redacción de PII (`redactPII`)                         | +4 créditos / página    | Redacta datos personales del markdown devuelto. Cada página PDF adicional añade otros +4 además de su costo de +1 por parsing (consulta [Redacción de PII](/es/features/pii-redaction))                                                                                                                                                  |
| `lockdown` (cache hit)                                 | +4 créditos / página    | Sirve únicamente desde la caché, sin consultar nunca el objetivo. Un cache miss no devuelve ningún documento y factura 1 crédito (consulta [Lockdown](/es/features/lockdown) y la tabla siguiente)                                                                                                                                       |
| Proxy enhanced (`proxy: "enhanced"` o escalado `auto`) | +0                      | Se factura al mismo 1 crédito que una solicitud basic. Un reintento escalado no se cobra por separado (consulta [Enhanced Mode](/es/features/enhanced-mode))                                                                                                                                                                             |

Estos modificadores se acumulan. Por ejemplo, hacer scraping de una página con formato JSON (extracción con LLM) y retención de datos cero cuesta **1 + 4 + 1 = 6 créditos** por página, y el formato JSON con redacción de PII cuesta **1 + 4 + 4 = 9 créditos**. Estos mismos modificadores se aplican a los endpoints Crawl y Search, ya que usan scrape internamente para cada página.

Las solicitudes a `x.com` y otras URL de X/Twitter usan la API de Grok y tienen precios independientes. Consulta [facturación de X (x.com)](#x-xcom-billing) al final de esta página.

<div id="when-credits-are-charged">
  ### Cuándo se cobran créditos
</div>

Lo que determina el cobro es si Firecrawl devolvió un documento, no si el sitio de destino devolvió un código de estado HTTP exitoso.

* **Firecrawl devolvió un documento: 1 crédito por página**, más cualquiera de los costos de opciones indicados arriba. Esto incluye las páginas que regresan con un estado de error como 403 Forbidden o 404 Not Found. El destino respondió, Firecrawl capturó esa respuesta y tú la recibes como documento. Revisa el campo `metadata.statusCode` en la respuesta para detectar estos casos y dejar de reintentar URLs que se bloquean de forma constante.
* **Firecrawl no devolvió ningún documento: 0 créditos.** Un scraping que falla por completo, por ejemplo porque el sitio nunca respondió o todos los intentos de renderizado fallaron, no se cobra.

Algunos casos sí se cobran aunque no se devuelva ningún documento. Corresponden al trabajo que Firecrawl ya realizó en tu nombre antes de que terminara el scraping.

| Caso                                  | Qué se cobra                                                                                                     |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Escaneo de protección contra amenazas | 2 créditos por URL analizada, incluido un scraping que el propio escaneo bloqueó                                 |
| Comprobación de inyección de prompts  | 5 créditos, una vez que se ha ejecutado la protección `checkPromptInjection`                                     |
| Agente FIRE-1                         | Según el uso, por la navegación que el agente ya realizó                                                         |
| Cache miss de `lockdown`              | 1 crédito                                                                                                        |
| Monitor check                         | Una página que da error durante una verificación se cobra al costo base de 1 crédito por página                  |
| Sesiones de Interact y Browser        | Se cobran por minuto de navegador de tiempo de sesión, con un mínimo de un minuto, obtengas o no lo que buscabas |

Para trabajos de **extracción por lotes** y **crawl**, los créditos se cobran de forma asíncrona a medida que cada página termina de procesarse, no cuando se envía el trabajo. Esto significa que puede haber un retraso entre el envío de un trabajo y el momento en que se refleja el costo total en créditos en tu cuenta. Si un lote contiene muchas URLs o las páginas se ponen en cola durante períodos de alto tráfico, los créditos pueden seguir registrándose minutos u horas después del envío. Hacer *polling* o comprobar el estado del lote no consume créditos.

<Note>
  **Verificación previa de créditos para crawl:** Cuando pasas un `limit` explícito, Firecrawl comprueba si la solicitud está permitida para esa cantidad. Si está permitida, incluso mediante consumo excedente, el límite no se reduce a tu saldo restante. Si se deniega, Firecrawl intenta bajar el límite al saldo restante y vuelve a comprobar la solicitud ajustada. Se devuelve un 402 si no se puede usar ningún límite positivo o si la solicitud ajustada se deniega, incluso por un límite de gasto por clave de API.

  Omitir `limit` no requiere **10,000** créditos por adelantado. La verificación inicial de créditos usa **1 crédito**; no reserva créditos para el crawl completo. Si la solicitud se permite, el límite predeterminado de **10,000** no se reduce para ajustarse al saldo, aunque otras opciones de crawl pueden cambiar el límite efectivo. Las páginas se cobran a medida que se procesan. Pasa un `limit` explícito cuando quieras establecer un número máximo de páginas (por ejemplo, `limit: 100`).
</Note>

<div id="plans">
  ## Planes
</div>

Los planes de suscripción se facturan de forma mensual o anual. Los planes de autoservicio de pago también pueden usar el pago por uso. El pago por uso añade créditos cuando se agota la asignación de tu plan. Consulta [Pago por uso](#pay-as-you-go).

<div id="paid-plans">
  ### Planes de pago
</div>

| Plan         | Créditos mensuales | Navegadores concurrentes |
| ------------ | ------------------ | -----------------------: |
| **Hobby**    | 5,000              |                        5 |
| **Standard** | 100,000            |                       25 |
| **Growth**   | 500,000            |                       50 |
| **escala**   | 1,000,000          |                      100 |

<Note>
  Para necesidades más allá del plan escala, Firecrawl ofrece planes **Enterprise** con créditos personalizados, soporte dedicado, SLAs, descuentos por volumen, retención de datos cero y SSO. Visita la [página Enterprise](https://www.firecrawl.dev/enterprise) para más detalles.
</Note>

Todos los planes de pago están disponibles con facturación **mensual** o **anual**. La facturación anual ofrece un descuento frente a pagar mes a mes. Para ver los precios actuales de cada plan, visita la [página de precios](https://www.firecrawl.dev/pricing).

<div id="free-plan">
  ### Free plan
</div>

Las cuentas nuevas comienzan en el plan Free. No tiene costo y no requiere tarjeta. Esto es lo que incluye:

* **1.000 créditos por mes.** La asignación se reinicia al comienzo de cada ciclo mensual. Los créditos gratuitos sin usar no se acumulan para el siguiente periodo.
* **2 navegadores concurrentes**, con el mismo máximo de 50.000 trabajos en cola que los planes de autoservicio pagos.
* **Límites de tasa de 10 solicitudes por minuto** en `/scrape`, `/map` y `/search`, y **2 solicitudes por minuto** en `/crawl`, `/agent` e `/interact`. La extracción por lotes comparte el límite de scraping y extract comparte el límite de agent. Consulta [Límite de tasa](/es/rate-limits) para ver la tabla completa.
* **Todos los endpoints principales del producto.** Scrape, crawl, map, search, extract, batch scrape, interact y monitor funcionan en el plan Free. Algunas funciones de administración de equipos y empresariales se habilitan por equipo y no por plan, entre ellas la protección contra amenazas, el registro SIEM y search con retención de datos cero. Los costos en créditos son iguales en todos los planes, por lo que la tabla de [costos en créditos por endpoint](#credit-costs-per-endpoint) anterior se aplica sin cambios.

El plan Free no incluye pago por uso, así que las solicitudes devuelven un HTTP 402 en cuanto se agota la asignación mensual. Consulta [Sin créditos](#running-out-of-credits). Tampoco incluye acumulación de créditos, un Acuerdo de Procesamiento de Datos ni soporte por Slack: el soporte es comunitario.

Scrape, Search e Interact también funcionan sin ninguna API key, a través del keyless free tier, cuyo tope es por dirección IP y por día en lugar de una asignación de créditos. Consulta [Keyless (no API key)](/es/rate-limits#keyless-no-api-key).

<div id="billing-cycle">
  ### Ciclo de facturación
</div>

* **Planes mensuales**: Los créditos se restablecen en tu fecha de renovación mensual
* **Planes anuales**: Se te factura anualmente, pero los créditos igual se restablecen cada mes en tu fecha de renovación mensual virtual
* **Los créditos del plan no utilizados no se acumulan de forma predeterminada**: tu asignación mensual se restablece cada mes. **Los planes anuales Escala permiten acumular los créditos del plan no utilizados durante 1 mes**, y **los planes anuales Enterprise permiten acumularlos durante 2 meses**.

<div id="concurrent-browsers">
  ### Navegadores concurrentes
</div>

Los navegadores concurrentes representan cuántas páginas web puede procesar Firecrawl simultáneamente para ti. Tu plan determina este límite. Si lo superas, los trabajos adicionales esperarán en una cola hasta que se libere un cupo. Consulta [Límites de tasa](/es/rate-limits) para obtener todos los detalles sobre concurrencia y límites de tasa de la API.

<a id="auto-reload" />

## Pago por uso {#pay-as-you-go}

El pago por uso mantiene tus solicitudes en curso cuando se agotan los créditos de tu plan. Añade créditos a tu cuenta automáticamente.

Compras créditos en incrementos de 5 USD. Cuando tu saldo de créditos llega a cero, añadimos un incremento a tu cuenta y realizamos el cargo en la tarjeta registrada.

El pago por uso requiere un plan de autoservicio de pago. No puedes usarlo con el plan Free.

También puedes comprar créditos manualmente en cualquier momento. Usa **Cargar más créditos** en tu [configuración de facturación](https://www.firecrawl.dev/app/settings?tab=billing). Introduce un múltiplo de 5 USD y paga con la tarjeta registrada. Esto funciona tanto si el pago por uso está activado como desactivado.

### Créditos por incremento {#credits-in-a-batch}

Los créditos por incremento dependen de tu plan. El pago por uso y las compras manuales usan la misma tarifa.

| Plan         | Créditos por 5 USD |
| ------------ | ------------------ |
| **Hobby**    | 1,000              |
| **Standard** | 2,000              |
| **Growth**   | 2,500              |
| **escala**   | 5,000              |

### Establece el límite mensual de pago por uso {#set-the-monthly-auto-reload-limit}

Establece tu **límite mensual de pago por uso** en uno de estos dos lugares:

* En tu [configuración de facturación](https://www.firecrawl.dev/app/settings?tab=billing), en la pestaña **Facturación**.
* En la [página de precios](https://www.firecrawl.dev/pricing), al elegir un plan.

<div id="how-the-limit-caps-your-monthly-spend">
  ### Cómo el límite restringe tu gasto mensual
</div>

Tu límite es el importe máximo que el pago por uso puede gastar en un mes. Se redondea hacia abajo a incrementos de 5 USD completos.

Por ejemplo, un límite de 25 USD permite cinco incrementos al mes. Un límite de 22 USD permite cuatro incrementos, ya que 22 USD se redondean hacia abajo a 20 USD.

Los créditos que compras manualmente no cuentan para este límite.

## Límites de gasto de la clave de API {#api-key-spend-limits}

Un límite de gasto restringe los créditos que puede usar una clave de API. El límite se aplica únicamente a esa clave, independientemente del saldo de tu equipo. Úsalo para evitar que una sola clave consuma todo el saldo del equipo.

También puedes renombrar cualquier clave de API, incluida la clave llamada **Default** que Firecrawl crea junto con tu equipo.

Tanto el propietario de la clave como un administrador del equipo pueden hacer ambas cosas. Abre la [página de claves de API](https://www.firecrawl.dev/app/api-keys) en el Dashboard y luego abre el menú de la clave.

* Haz clic en **Rename** para cambiar el **Key Name**.
* Haz clic en **Set limit** para abrir **Set a spend limit**. Introduce un **Credit limit**, elige **per day**, **per week** o **per month** y luego haz clic en **Save**.

Un límite es una cantidad de créditos, no un importe en dinero. Un límite de `1` significa un crédito por periodo. Haz clic en **Remove limit** para eliminar el límite.

<div id="upgrading-and-downgrading">
  ## Actualizar o bajar de plan
</div>

* **Las actualizaciones de plan** surten efecto de inmediato. Hoy se te cobra el precio completo del nuevo plan (sin prorrateo) y tu ciclo de facturación se restablece. Tu próxima renovación será un mes o un año después de la fecha de actualización. Los créditos no usados de tu plan anterior se transfieren, y tu nueva asignación de créditos y tus límites de concurrencia se aplican al instante.
* **Los cambios a un plan inferior** se programan para entrar en vigor en tu próxima fecha de renovación. Mantienes los créditos y límites de tu plan actual hasta entonces. El tiempo no usado de tu plan actual no se acredita ni se reembolsa. Puedes deshacer un cambio programado a un plan inferior desde tu [configuración de facturación](https://www.firecrawl.dev/app/settings?tab=billing) en cualquier momento antes de la fecha de entrada en vigor.

<div id="switching-between-monthly-and-yearly-billing">
  ### Cambio entre facturación mensual y anual
</div>

* **Mensual → Anual** en el mismo nivel de créditos o en uno superior se considera una mejora inmediata.
* **Anual → Mensual** se considera una mejora inmediata solo si cambias a un nivel de créditos estrictamente superior.

<div id="running-out-of-credits">
  ## Sin créditos
</div>

Lo que ocurre cuando tu saldo llega a cero depende de tu plan y de tu configuración de pago por uso.

| Plan                               | Pago por uso                | Con saldo cero                                                                                                                                                                                                                                                                     |
| ---------------------------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Free**                           | No disponible               | Las solicitudes que consumen créditos devuelven **HTTP 402 (Payment Required)** hasta el reinicio mensual.                                                                                                                                                                         |
| **Hobby, Standard, Growth, escala** | Desactivado (límite en `0`) | Las solicitudes que consumen créditos devuelven **HTTP 402**. No se realiza ningún cargo a tu tarjeta.                                                                                                                                                                             |
| **Hobby, Standard, Growth, escala** | Activado                    | Firecrawl cobra a tu tarjeta un incremento de 5 USD y añade los créditos correspondientes. Tus solicitudes continúan. Esto se repite cada vez que el saldo llega a cero, hasta alcanzar tu **límite mensual de pago por uso**. Deja el límite en blanco para no fijar ningún tope. |

Mientras el pago por uso está activado, las solicitudes no se cortan justo al llegar a cero. Tu plan incluye un margen de excedente para que una ráfaga de solicitudes siga ejecutándose mientras se procesa la recarga: **1.500 créditos en Hobby, 30.000 en Standard, 150.000 en Growth y 600.000 en escala**. Una vez alcanzado el límite mensual y agotado ese margen, las solicitudes devuelven **HTTP 402** hasta el siguiente ciclo de facturación. El margen es un colchón temporal, no créditos adicionales que se acumulen.

Los créditos comprados manualmente (**Load more credits**) se consumen antes de que aplique todo lo anterior y no cuentan para el límite mensual de pago por uso.

Para reanudar el uso tras una interrupción total, puedes:

1. Establecer un **límite mensual de pago por uso** para comprar créditos automáticamente. Consulta [Pago por uso](#pay-as-you-go).
2. Cambiar manualmente a un plan superior
3. Esperar a que tus créditos se reinicien en el siguiente ciclo de facturación

<div id="coupons">
  ## Cupones
</div>

Firecrawl admite dos tipos de cupones:

* Los **cupones de suscripción** aplican un descuento a la suscripción de tu plan (p. ej., un porcentaje de descuento en el precio mensual o anual). Estos **solo** se pueden aplicar durante el proceso de pago de Stripe, cuando te suscribes por primera vez a un plan de pago o cambias de plan. No puedes aplicar un cupón de suscripción una vez completado el pago.
* Los **cupones de créditos** añaden créditos extra a tu cuenta. Estos se pueden canjear desde la sección de **Facturación** de tu panel de control en [firecrawl.dev/app/billing](https://www.firecrawl.dev/app/billing). Busca el campo de cupón en la página de facturación para aplicar tu código. Los créditos extra de los cupones de créditos son independientes de la asignación mensual de tu plan y se conservan aunque cambies a un plan superior o inferior.

<div id="faqs">
  ## Preguntas frecuentes
</div>

<AccordionGroup>
  <Accordion title="¿Los créditos no utilizados se trasladan al mes siguiente?">
    Los **créditos del plan** no se acumulan de forma predeterminada: tu asignación mensual se restablece cada mes. **Los planes anuales escala acumulan los créditos del plan no utilizados durante 1 mes**, y **los planes Enterprise anuales los acumulan durante 2 meses**.
  </Accordion>

  <Accordion title="¿Los créditos de pago por uso caducan?">
    Los créditos que compras permanecen en tu cuenta hasta que los uses. Caducan si cancelas tu suscripción, así que úsalos antes de irte. La caducidad ocurre al final de tu período de facturación actual, y una renovación no los afecta.
  </Accordion>

  <Accordion title="¿Cómo funciona el límite mensual de pago por uso?">
    Tu límite restringe lo que el pago por uso gasta cada mes. Se redondea hacia abajo a incrementos completos de 5 USD. Un límite de 25 USD permite cinco incrementos cada mes. Deja el límite en blanco y el pago por uso no tendrá límite mensual. Establece el límite en `0` y el pago por uso se desactivará.
  </Accordion>

  <Accordion title="¿Cómo sé cuántos créditos me quedan?">
    Consulta el Dashboard en [firecrawl.dev/app](https://www.firecrawl.dev/app), o invoca de forma programática el [endpoint de la API de Credit Usage](/es/api-reference/endpoint/credit-usage).
  </Accordion>

  <Accordion title="¿Dónde aplico un código de cupón?">
    Depende del tipo de cupón. Aplica un **cupón de créditos** en la sección facturación de tu panel. Solo puedes aplicar un **cupón de suscripción** (un descuento en el precio de tu plan) en la página de pago de Stripe al suscribirte o cambiar de plan.
  </Accordion>

  <Accordion title="Necesito más concurrencia o un plan personalizado. ¿Con quién me contacto?">
    Ponte en contacto con [help@firecrawl.dev](mailto:help@firecrawl.dev), o visita la [página Enterprise](https://www.firecrawl.dev/enterprise) para obtener más información sobre planes personalizados.
  </Accordion>

  <Accordion title="¿En qué moneda se emiten las facturas?">
    Todas las facturas de Firecrawl se emiten en **dólares estadounidenses (USD)**, independientemente de tu dirección de facturación o método de pago.
  </Accordion>

  <Accordion title="¿Cómo gestiono mi suscripción, cambio de plan o cancelo?">
    Ve a tu [configuración de facturación](https://www.firecrawl.dev/app/settings?tab=billing). Los administradores del equipo pueden gestionar todo allí. <div id="x-xcom-billing">
  ## Facturación de X (x.com)
</div>

Firecrawl usa la **API oficial de Grok** de [xAI](https://x.ai/) para ofrecer resúmenes con IA, extracción estructurada y acceso en tiempo real al contenido público de X. Las solicitudes a las URL de perfiles y publicaciones de `x.com`, `twitter.com` y `mobile.twitter.com` se procesan mediante las herramientas internas autorizadas de Grok (`x_search`, recuperación de hilos y búsqueda web restringida a x.com), en lugar del web scraping tradicional.

<div id="credit-costs">
  ### Costos de créditos
</div>

| Componente       | Costo en créditos        | Descripción                                                     |
| ---------------- | ------------------------ | --------------------------------------------------------------- |
| **Costo base**   | 1 crédito / solicitud    | Procesamiento estándar de solicitudes de scraping               |
| **Grok X Query** | +29 créditos / solicitud | Uso de la API de Grok (tokens + tool calls) para contenido de X |

Por ejemplo, procesar una solicitud típica de publicación o hilo cuesta **30 créditos** (`1` base + `29` Grok X Query) y devuelve datos estructurados generados por Grok, contexto del hilo y resúmenes. Si también está habilitado el formato JSON (extracción con LLM), el total es de **34 créditos** por solicitud.

Este método cumple con las interfaces publicadas de X a través de la asociación con xAI y proporciona una salida razonada y de mayor calidad, en lugar de hacer scraping directo de la página.

<Note>
  **Las capacidades difieren del scraping estándar.** Grok devuelve resultados procesados por IA, que pueden incluir resúmenes, métricas clave, contexto del hilo y más. Para obtener datos estructurados sin procesar a escala, usa la [API oficial X Enterprise](https://developer.x.com/).
</Note>
