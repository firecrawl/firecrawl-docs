Conecta Firecrawl a los agentes locales de Warp mediante el servidor MCP alojado y, después, inicia sesión con tu cuenta de Firecrawl.

## Configuración rápida {#quick-setup}

1. En Warp, abre **Settings**, luego **Agents** y, por último, **Servidores MCP**. También puedes buscar **Open MCP Servers** en la paleta de comandos.
2. Selecciona **+ Add** y pega esta configuración:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

3. Inicia el servidor. Warp abre una página en el navegador para el sign-in de Firecrawl. Aprueba el acceso y Warp guardará las credenciales en tu dispositivo.
4. Comprueba que `firecrawl` aparece como en ejecución en la lista de servidores MCP y luego pide a un agente que haga una búsqueda o una extracción de datos web.

<Accordion title="¿Prefieres una configuración basada en archivos?">
  Warp también carga servidores desde `~/.warp/.mcp.json` para todos los proyectos, o desde `.warp/.mcp.json` en la raíz de un proyecto. Usa el mismo JSON de arriba. Los servidores definidos en el archivo del proyecto requieren tu aprobación antes de iniciarse.
</Accordion>

<Accordion title="¿Prefieres una clave de API?">
  Warp admite cabeceras personalizadas en servidores basados en URL. Usa `https://mcp.firecrawl.dev/v2/mcp` como URL y añade `"headers": { "Authorization": "Bearer fc-YOUR-API-KEY" }`. Consulta [Configurar una clave de API](/es/mcp-server/keyless#add-an-api-key).
</Accordion>

Consulta la [guía de conexión OAuth](/es/mcp-server/oauth) para obtener más información.

## Solución de problemas {#troubleshooting}

* **La página de sign-in no se abre:** vuelve a iniciar el servidor desde la página de servidores MCP.
* **El sign-in falla una y otra vez:** ejecuta `rm -rf ~/.mcp-auth` para borrar los tokens de MCP almacenados y, luego, vuelve a iniciar el servidor. Esto elimina los tokens de todos los servidores MCP.
* **El servidor no se inicia:** selecciona **View Logs** en el servidor para ver el error.
* **No se usan las herramientas:** algunos modelos llaman a las herramientas MCP de forma más fiable que otros. Prueba con otro modelo en el selector de agentes.
