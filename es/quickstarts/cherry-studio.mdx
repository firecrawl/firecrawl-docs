Añade la búsqueda, el scraping y otras herramientas web de Firecrawl a [Cherry Studio](https://cherry-ai.com) a través del servidor MCP alojado.

Cherry Studio admite servidores remotos Streamable HTTP con cabeceras personalizadas, así que puedes conectarte con tu clave de API de Firecrawl.

## Configuración rápida {#quick-setup}

1. [Crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys).
2. En Cherry Studio, abre **Settings → MCP → MCP Servers** y haz clic en **Add**.
3. Selecciona **Import from JSON** y pega lo siguiente, sustituyendo `<FIRECRAWL_API_KEY>` por tu clave:

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "streamableHttp",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

4. Habilita el servidor, espera a que su estado cambie a saludable y, después, abre sus detalles y comprueba que aparecen `firecrawl_search` y `firecrawl_scrape`.
5. Abre **Work**, edita tu Agente, ve a **MCP** y habilita el servidor de Firecrawl para que el Agente pueda usarlo.

También puedes usar **Quick Create** y establecer el tipo en **Streamable HTTP**, la URL en `https://mcp.firecrawl.dev/v2/mcp` y la cabecera `Authorization=Bearer <FIRECRAWL_API_KEY>`.

Si prefieres un servidor local, usa el tipo `stdio` con el comando `npx`, los argumentos `-y` y `firecrawl-mcp`, y la variable de entorno `FIRECRAWL_API_KEY`. Consulta la [guía del servidor MCP local](/es/mcp-server/local).

Cherry Studio también puede iniciar sesión en servidores remotos mediante OAuth si no se ha configurado ninguna cabecera `Authorization`. Consulta [Para personas](/es/mcp-server/oauth) para obtener el punto de conexión OAuth de Firecrawl.

## Solución de problemas {#troubleshooting}

* **El servidor no se conecta:** confirma que el tipo sea Streamable HTTP, que la URL sea exactamente `https://mcp.firecrawl.dev/v2/mcp` y que la cabecera sea `Authorization: Bearer <FIRECRAWL_API_KEY>`. Revisa el registro del servidor en su página de detalles.
* **Las herramientas no aparecen en un chat:** el servidor debe estar en ejecución y habilitado para el Agente. Revisa **Work → Agent → Edit → MCP**.
* **Falta una herramienta:** abre los detalles del servidor para ver qué herramientas expone y confirma que tu clave de API sea válida.
