Añade las herramientas de búsqueda, scraping y rastreo de Firecrawl a [LM Studio](https://lmstudio.ai) a través del servidor MCP alojado para que tus modelos locales puedan acceder a la web en tiempo real.

A partir de la versión 0.3.17, LM Studio funciona como host MCP y lee los servidores desde un archivo `mcp.json` con la misma notación que usa Cursor.

## Configuración rápida {#quick-setup}

1. [Crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys).
2. En LM Studio, abre la pestaña **Program** en la barra lateral derecha y selecciona **Install &gt; Edit mcp.json**.
3. Agrega Firecrawl dentro de `mcpServers` y guarda los cambios:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

Si `mcp.json` ya incluye otros servidores, copia solo la entrada `"firecrawl": { ... }` dentro del objeto `mcpServers` existente.

LM Studio carga el servidor en cuanto guardas el archivo. Abre un chat con un modelo compatible con el uso de herramientas y comprueba que `firecrawl_search` y `firecrawl_scrape` aparecen en la lista de herramientas del chat.

No expongas la clave de API en capturas de pantalla compartidas ni en el control de versiones. LM Studio guarda `mcp.json` en su carpeta de datos, dentro de tu directorio personal (`~/.lmstudio/mcp.json`).

## Iniciar sesión en lugar de utilizar una clave {#sign-in-instead-of-using-a-key}

LM Studio admite MCP OAuth para servidores remotos. Añade `https://mcp.firecrawl.dev/v2/mcp-oauth` como `url` del servidor sin `headers` y, a continuación, completa el sign-in en el navegador. Consulta [Para personas](/es/mcp-server/oauth).

## Ejecutar el servidor localmente {#run-the-local-server-instead}

Para ejecutar Firecrawl en tu propia máquina, agrega una entrada `command` que inicie el paquete de npm en lugar de la entrada `url`. Consulta la [guía del servidor MCP local](/es/mcp-server/local) para ver el comando y las opciones actuales.

## Solución de problemas {#troubleshooting}

* **No aparecen las herramientas:** asegúrate de que el modelo admita el uso de herramientas y, después, comprueba que `mcp.json` sea un JSON válido y que la entrada `firecrawl` esté dentro de `mcpServers`.
* **Falla la autenticación:** confirma que la cabecera contenga `Bearer` seguido de tu clave, separados por un solo espacio, y que la clave esté activa en tu [panel de control de Firecrawl](https://www.firecrawl.dev/app/api-keys).
* **El modelo se ralentiza o se queda sin contexto:** las herramientas de Firecrawl pueden devolver páginas largas. Pide URLs concretas, usa un modelo con una ventana de contexto más amplia o habilita solo las herramientas que necesites.
* **Revisa las llamadas a herramientas:** de forma predeterminada, LM Studio pide confirmación antes de ejecutar herramientas MCP. Instala únicamente servidores MCP de fuentes de confianza.
