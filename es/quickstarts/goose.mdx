Conecta Firecrawl a Goose como extensión remota para que Goose pueda buscar en la web y leer páginas a través del servidor MCP alojado.

## Requisitos {#requirements}

* Goose 1.55 o posterior.
* Una [clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys), exportada como `FIRECRAWL_API_KEY`.

## Configuración rápida {#quick-setup}

1. Exporta tu clave de API en el shell desde el que inicias Goose:

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

2. Agrega la extensión a la sección `extensions` de `~/.config/goose/config.yaml`:

```yaml
extensions:
  firecrawl:
    type: streamable_http
    name: firecrawl
    enabled: true
    uri: https://mcp.firecrawl.dev/v2/mcp
    headers:
      Authorization: "Bearer $FIRECRAWL_API_KEY"
    env_keys:
      - FIRECRAWL_API_KEY
    timeout: 300
```

3. Inicia una sesión y pídele a Goose que haga una búsqueda o una extracción de datos web:

```bash
goose session
```

<Warning>
  Escribe la cabecera como `$FIRECRAWL_API_KEY`, sin llaves, y no elimines `env_keys`. Si usas llaves, Goose envía `${FIRECRAWL_API_KEY}` como texto literal y el servidor rechaza la solicitud.
</Warning>

Consulta [Configurar una clave de API](/es/mcp-server/keyless#add-an-api-key) para obtener más información sobre las claves.

## Solución de problemas {#troubleshooting}

* **La clave aparece como no válida o revocada:** comprueba que la cabecera usa `$FIRECRAWL_API_KEY` sin llaves y que `FIRECRAWL_API_KEY` está exportada en el shell desde el que se inicia Goose.
* **No aparece la extensión:** vuelve a ejecutar `goose session` después de guardar el archivo y confirma que tiene `enabled: true`.
* **Se agota el tiempo de espera de las llamadas:** aumenta `timeout`. El scraping de una página grande puede tardar más que el valor predeterminado.
* **No se usan las herramientas:** algunos modelos llaman a las herramientas MCP de forma más fiable que otros. Prueba con otro modelo.
