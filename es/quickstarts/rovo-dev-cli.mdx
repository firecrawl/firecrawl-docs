Agrega Firecrawl a Rovo Dev CLI mediante el servidor MCP alojado. Rovo Dev CLI se conecta a servidores remotos mediante cabeceras de solicitud, por lo que esta configuración usa una clave de API de Firecrawl.

## Requisitos {#requirements}

* Rovo Dev CLI, instalado como extensión de Atlassian CLI (`acli`) y con la sesión iniciada mediante `acli rovodev auth login`.
* Una [clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys).

## Configuración rápida {#quick-setup}

1. Ejecuta `acli rovodev mcp` para abrir `~/.rovodev/mcp.json` en tu editor predeterminado.
2. Añade Firecrawl, reemplaza la clave y guarda los cambios:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "transport": "http",
      "headers": {
        "Authorization": "Bearer fc-YOUR-API-KEY"
      }
    }
  }
}
```

3. Inicia Rovo Dev con `acli rovodev run`, escribe `/mcp` y comprueba que `firecrawl` aparece en la lista junto con sus herramientas.

<Accordion title="¿Prefieres un servidor local?">
  Rovo Dev CLI también puede iniciar servidores stdio. Sigue [Ejecutar MCP localmente](/es/mcp-server/local) y define el comando en el mismo archivo:

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "command": "npx",
        "args": ["-y", "firecrawl-mcp@3.33.2"],
        "env": {
          "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
        },
        "transport": "stdio"
      }
    }
  }
  ```
</Accordion>

No compartas el archivo, ya que contiene tu clave. Consulta [Configurar una clave de API](/es/mcp-server/keyless#add-an-api-key) para obtener más información sobre las conexiones con clave.

## Solución de problemas {#troubleshooting}

* **`/mcp` no muestra Firecrawl:** comprueba que el JSON sea válido y que `transport` sea `"http"` para la URL alojada.
* **El servidor muestra `401`:** reemplaza la clave en `mcp.json` y reinicia `acli rovodev run`.
* **Firecrawl aparece en la lista, pero deshabilitado:** abre `/mcp` y habilítalo. Comprueba también que no figure en `disabledMcpServers` dentro de `~/.rovodev/config.yml`.
* **No quieres usar las instrucciones del servidor:** establece `"enable_instructions": false` en la entrada de Firecrawl.
