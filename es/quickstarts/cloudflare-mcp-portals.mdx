Añade el servidor MCP alojado de Firecrawl a un [portal de servidores MCP de Cloudflare One](https://developers.cloudflare.com/cloudflare-one/access-controls/ai-controls/mcp-portals/) para que tu equipo acceda a las herramientas de búsqueda y scraping de Firecrawl desde una única URL de portal, protegida por tus políticas de Access.

## Configuración rápida {#quick-setup}

[Crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys). Luego, agrega Firecrawl como servidor MCP en Cloudflare Access mediante la API del portal, utilizando la clave como credencial de tipo bearer:

```bash
export CLOUDFLARE_ACCOUNT_ID=your-cloudflare-account-id
export CLOUDFLARE_API_TOKEN=your-cloudflare-api-token
export FIRECRAWL_API_KEY=fc-YOUR_API_KEY

curl -X POST "https://api.cloudflare.com/client/v4/accounts/$CLOUDFLARE_ACCOUNT_ID/access/ai-controls/mcp/servers" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Firecrawl",
    "hostname": "https://mcp.firecrawl.dev/v2/mcp",
    "auth_type": "bearer",
    "auth_credentials": "'"$FIRECRAWL_API_KEY"'"
  }'
```

El portal envía `auth_credentials` a Firecrawl como `Authorization: Bearer <key>`. También puedes agregar el servidor desde el Dashboard de Cloudflare, en **Zero Trust** &gt; **Access controls** &gt; **MCP Portals** &gt; **MCP servers** &gt; **Add MCP server**, utilizando la misma URL.

A continuación, agrega el servidor a un portal, asocia políticas de Access que determinen quién puede verlo y selecciona las herramientas que quieres exponer. La [guía de portales de servidores MCP](https://developers.cloudflare.com/cloudflare-one/access-controls/ai-controls/mcp-portals/) de Cloudflare explica cómo crear el portal.

## Pruébalo {#try-it}

Conecta un cliente MCP a la URL de tu portal (`https://<subdomain>.<domain>/mcp`) y luego pregúntale:

```text
Busca en la web las notas de la versión más recientes de Cloudflare Workers y resume las fuentes.
```

```text
Haz scraping de https://firecrawl.dev y explica qué hace.
```

## Solución de problemas {#troubleshooting}

* **El servidor muestra un error de sincronización o de autenticación:** comprueba que la clave sea válida y que `auth_type` sea `bearer`; si rotaste la clave, actualiza las credenciales del servidor.
* **Las herramientas de Firecrawl no aparecen en el portal:** el portal solo expone las herramientas que un administrador seleccionó para él, así que revisa su lista de herramientas.
* **Los usuarios no ven Firecrawl:** el enlace del servidor solo aparece a los usuarios que cumplen una política Allow del servidor.
