Añade las herramientas sin clave Search, extracción de datos web y Parse de Firecrawl a [Amp](https://ampcode.com) mediante el MCP Server alojado.

## Configuración rápida {#quick-setup}

Añade esto a tu archivo de configuración de Amp (`~/.config/amp/settings.json`; puedes abrirlo con `amp config edit`):

```json
{
  "amp.mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

O deja que la CLI lo escriba por ti:

```bash
amp mcp add firecrawl https://mcp.firecrawl.dev/v2/mcp
```

Reinicia Amp y confirma que `firecrawl_search`, `firecrawl_scrape` y `firecrawl_parse` están disponibles.

El acceso sin clave tiene límites compartidos entre los usuarios con la misma IP pública. Inicia sesión desde un cliente interactivo con [For Humans](/es/mcp-server/oauth) o [añade una clave de API](/es/mcp-server/keyless#add-an-api-key) para uso desatendido.

## Pruébalo {#try-it}

```text
Busca en la web las notas de la versión más recientes de Amp y resume las fuentes.
```

```text
Scrape https://docs.firecrawl.dev and list the core endpoints.
```

## Solución de problemas {#troubleshooting}

* **El servidor no se conecta:** confirma que la URL sea exactamente `https://mcp.firecrawl.dev/v2/mcp` y ejecuta `amp mcp doctor` para comprobar el estado del servidor.
* **No aparece Crawl u otra herramienta:** el acceso sin clave solo incluye Search, extracción de datos web y Parse. Conéctate con OAuth o una clave de API para acceder a más herramientas.
