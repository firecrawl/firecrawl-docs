Conecta Firecrawl a Cursor mediante el Servidor MCP alojado y luego inicia sesión con tu cuenta de Firecrawl para que el agente de IA de Cursor disponga de Search, Scrape, Parse, Crawl, Map, Interact, Agent y Monitor, y obtenga contexto limpio de la web.

<CursorInstallButton />

## Configuración rápida {#quick-setup}

1. Haz clic en **Add to Cursor** arriba para abrir el cuadro de diálogo de instalación en Cursor.
2. Confirma la instalación del Servidor MCP de Firecrawl.
3. Usa la opción de inicio de sesión del servidor en Cursor para conectar tu cuenta de Firecrawl y autorizar el acceso.
4. Comprueba que las herramientas de Firecrawl estén disponibles en Cursor.

<Accordion title="¿Prefieres añadir la configuración manualmente?">
  Añade esto a `~/.cursor/mcp.json` o a `.cursor/mcp.json` en tu proyecto:

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
      }
    }
  }
  ```

  Guarda el archivo y, después, completa el inicio de sesión en el navegador desde Cursor.
</Accordion>

La CLI de Cursor lee el mismo `mcp.json`. Ejecuta `agent mcp login firecrawl` para iniciar sesión desde la terminal.

Consulta la [guía de conexión OAuth](/es/mcp-server/oauth) para obtener más información. Para un uso desatendido, [configura una clave de API](/es/mcp-server/keyless#add-an-api-key).

## Solución de problemas {#troubleshooting}

* **El servidor no se conecta:** confirma que la URL sea exactamente `https://mcp.firecrawl.dev/v2/mcp-oauth` y comprueba el estado del servidor en **Customize** o en la salida de **MCP Logs**.
* **Se solicita iniciar sesión o la sesión caduca:** vuelve a iniciar la autenticación desde la lista de servidores MCP de Cursor en **Customize**.
* **Ya existe otra conexión de Firecrawl:** actualiza el servidor existente a la URL de OAuth e inicia sesión para que solo haya un servidor de Firecrawl activo.
