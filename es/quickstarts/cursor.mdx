Añade las herramientas Search, scraping y Parse sin clave de Firecrawl a Cursor mediante el MCP Server alojado.

<div id="quick-setup">
  ## Configuración rápida
</div>

Abre la configuración de Cursor, selecciona **MCP** y añade:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Reinicia Cursor y confirma que `firecrawl_search`, `firecrawl_scrape` y `firecrawl_parse` estén disponibles.

El acceso sin clave está sujeto a límites compartidos entre los usuarios de la misma IP pública. Usa [OAuth](/es/mcp-server/oauth) para acceder a la cuenta de forma interactiva o la [guía de clave de API](/es/mcp-server/keyless-api-key#add-an-api-key) para uso no interactivo.

<div id="troubleshooting">
  ## Solución de problemas
</div>

* **El servidor no se conecta:** confirma que la URL sea exactamente `https://mcp.firecrawl.dev/v2/mcp` e inspecciona el estado de MCP en Cursor.
* **Falta Crawl u otra herramienta:** sin clave expone únicamente Search, scraping y Parse. Conéctate con OAuth o una clave de API para acceder a un conjunto más amplio de herramientas.
