Conecta Firecrawl a Kiro mediante el servidor MCP alojado. Kiro se encarga del sign-in en el navegador por ti, así que no tienes que registrar nada manualmente. Kiro IDE y Kiro CLI usan el mismo archivo de configuración.

<Note>
  Kiro CLI sustituye a Amazon Q Developer CLI. Si antes usabas `q`, esta página también es para ti.
</Note>

## Configuración rápida {#quick-setup}

1. Abre el archivo de configuración de usuario `~/.kiro/settings/mcp.json`. En el IDE, ejecuta **Kiro: Open user MCP config (JSON)** desde la paleta de comandos. Para un solo proyecto, usa en su lugar el archivo `.kiro/settings/mcp.json` del espacio de trabajo.
2. Agrega Firecrawl y guarda el archivo:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

3. Al guardar, Kiro se vuelve a conectar y abre la página de autorización de Firecrawl en tu navegador. Inicia sesión y aprueba el acceso.
4. Abre la pestaña de servidores MCP en el panel de Kiro, o ejecuta `kiro-cli mcp status --name firecrawl`, y comprueba que las herramientas de Firecrawl están disponibles.

<Accordion title="¿Prefieres una clave de API?">
  Los servidores remotos de Kiro admiten cabeceras. Exporta `FIRECRAWL_API_KEY` en tu shell y luego usa:

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp",
        "headers": {
          "Authorization": "Bearer ${FIRECRAWL_API_KEY}"
        }
      }
    }
  }
  ```

  Kiro solo expande las variables de entorno que hayas aprobado. Cuando muestre la advertencia de seguridad para `FIRECRAWL_API_KEY`, apruébala o añádela en **Mcp Approved Env Vars** dentro de la configuración.
</Accordion>

<Accordion title="¿Prefieres la CLI?">
  ```bash
  kiro-cli mcp add --name firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth --scope global
  ```
</Accordion>

Consulta la [guía de conexión OAuth](/es/mcp-server/oauth) para más detalles. Para un uso desatendido, [configura una clave de API](/es/mcp-server/keyless#add-an-api-key).

## Solución de problemas {#troubleshooting}

* **La compatibilidad con MCP está desactivada:** en el IDE, abre la configuración con `Cmd/Ctrl + ,`, busca «MCP» y actívala.
* **El servidor no se conecta:** comprueba que la URL sea exactamente `https://mcp.firecrawl.dev/v2/mcp-oauth` y vuelve a guardar el archivo para forzar la reconexión.
* **Aparece un error de alcance de OAuth:** añade `"oauth": { "oauthScopes": [] }` a la entrada del servidor.
* **Tanto el archivo del espacio de trabajo como el del usuario definen `firecrawl`:** Kiro los combina y prevalece el del espacio de trabajo. Conserva solo una entrada.
