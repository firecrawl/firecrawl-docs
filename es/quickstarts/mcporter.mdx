Conecta [MCPorter](https://mcporter.sh), un entorno de ejecución y CLI para servidores MCP escrito en TypeScript, con Firecrawl a través del servidor MCP alojado.

## Configuración rápida {#quick-setup}

[Crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys) y expórtala:

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

Agrega Firecrawl a `config/mcporter.json` en tu proyecto, o a `~/.mcporter/mcporter.json` para usarlo de forma global:

```json
{
  "mcpServers": {
    "firecrawl": {
      "baseUrl": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": { "Authorization": "Bearer ${FIRECRAWL_API_KEY}" }
    }
  }
}
```

MCPorter sustituye `${FIRECRAWL_API_KEY}` por el valor de tu entorno, así la clave no queda guardada en el archivo. Confirma la conexión:

```bash
npx mcporter list firecrawl
```

¿Prefieres un proceso local? Usa en su lugar la variante stdio:

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": { "FIRECRAWL_API_KEY": "${FIRECRAWL_API_KEY}" }
    }
  }
}
```

## Pruébalo {#try-it}

```bash
npx mcporter call firecrawl.firecrawl_scrape url=https://firecrawl.dev 'formats=["markdown"]'
```

El comando muestra la página en formato markdown. Usa la misma entrada desde el código con `createRuntime` (consulta la [documentación de MCPorter](https://mcporter.sh)).

## Solución de problemas {#troubleshooting}

* **No se encuentra el servidor:** ejecuta `npx mcporter config list` para ver qué archivo de configuración cargó MCPorter; `--config <file>` o `MCPORTER_CONFIG` seleccionan un solo archivo.
* **Errores de autenticación:** MCPorter no admite la forma `${env:VAR}`; escribe el marcador de posición como `${FIRECRAWL_API_KEY}` y comprueba que la variable esté exportada en el mismo shell.
* **Se rechazan los argumentos de la herramienta:** pasa los valores JSON entre comillas adecuadas para tu shell, como en el ejemplo de `formats` anterior.
