Añade a [Kimi Code CLI](https://www.kimi.com/code/docs/en/kimi-code-cli/getting-started.html) las herramientas de búsqueda, scraping y otras funciones web de Firecrawl a través del servidor MCP alojado.

## Configuración rápida {#quick-setup}

[Crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys) y luego agrega lo siguiente a `~/.kimi-code/mcp.json` (o a `.kimi-code/mcp.json` dentro de un proyecto):

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

Para no dejar la clave en el archivo, expórtala y haz referencia a la variable en lugar de usar `headers`:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "bearerTokenEnvVar": "FIRECRAWL_API_KEY"
    }
  }
}
```

También puedes añadir el servidor de forma interactiva con `/mcp-config`. Inicia una nueva sesión de Kimi Code, ejecuta `/mcp` y comprueba que `firecrawl` está conectado y que sus herramientas, como `firecrawl_search` y `firecrawl_scrape`, aparecen en la lista.

Para iniciar sesión con tu navegador en lugar de con una clave de API, usa `https://mcp.firecrawl.dev/v2/mcp-oauth` como URL, sin `headers`, y luego ejecuta `/mcp-config login firecrawl`. Consulta [Para personas](/es/mcp-server/oauth).

## Solución de problemas {#troubleshooting}

* **Las herramientas no aparecen:** los servidores MCP se cargan al iniciar una sesión, así que abre una sesión nueva después de editar `mcp.json`. Un servidor añadido durante una sesión solo estará disponible en las sesiones posteriores.
* **El servidor no se conecta:** ejecuta `/mcp` para ver el estado y, a continuación, comprueba la URL y que la clave de API sea correcta. Si usas `bearerTokenEnvVar`, la variable debe estar definida en el shell desde el que se inicia `kimi`.
* **Se ignora la configuración del proyecto:** en las carpetas que no son de confianza, los servidores definidos en el archivo `.kimi-code/mcp.json` del proyecto permanecen deshabilitados. Marca la carpeta como de confianza o define `KIMI_CODE_TRUST_WORKSPACE=1` para ejecuciones headless.
* **Si prefieres un servidor local:** Kimi Code también puede ejecutar `npx -y firecrawl-mcp` con `FIRECRAWL_API_KEY` en `env`. Consulta [Ejecutar localmente](/es/mcp-server/local).
