Añade las herramientas keyless búsqueda, scraping y Parse de Firecrawl a Windsurf mediante el Servidor MCP alojado.

Windsurf ahora se llama [Devin Desktop](https://devin.ai/desktop). Tanto su agente Devin Local como el agente heredado Cascade leen los Servidores MCP del mismo archivo de configuración.

## Configuración rápida {#quick-setup}

Edita `~/.config/devin/mcp_config.json` (`%APPDATA%\devin\mcp_config.json` en Windows):

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

O añádelo con la CLI de Devin:

```bash
devin mcp add -s user firecrawl https://mcp.firecrawl.dev/v2/mcp
```

Reinicia Devin Desktop y confirma que `firecrawl_search`, `firecrawl_scrape` y `firecrawl_parse` estén disponibles.

El acceso keyless tiene límites compartidos entre los usuarios con la misma IP pública. Inicia sesión desde un cliente interactivo con [For Humans](/es/mcp-server/oauth) o [añade una clave de API](/es/mcp-server/keyless#add-an-api-key) para uso desatendido.

## Solución de problemas {#troubleshooting}

* **El servidor no se conecta:** confirma la URL alojada y luego comprueba el servidor en la lista de MCP del agente o ejecuta `devin mcp list`.
* **Falta Crawl u otra herramienta:** el modo keyless expone únicamente búsqueda, scraping y Parse. Conéctate mediante OAuth o una clave de API para acceder a un conjunto más amplio de herramientas.
