Añade las herramientas keyless Search, scraping y Parse de Firecrawl a Windsurf mediante el MCP Server alojado.

<div id="quick-setup">
  ## Configuración rápida
</div>

Abre **Configuración → Herramientas → Configuración de Windsurf → Añadir servidor** o edita `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Reinicia Windsurf y confirma que `firecrawl_search`, `firecrawl_scrape` y `firecrawl_parse` estén disponibles.

El acceso keyless tiene límites compartidos entre los usuarios con la misma IP pública. Inicia sesión desde un cliente interactivo con [For Humans](/es/mcp-server/oauth) o [añade una clave de API](/es/mcp-server/keyless#add-an-api-key) para uso desatendido.

<div id="try-it">
  ## Pruébalo
</div>

```text
Busca las notas de la última release de Tailwind CSS y resume las fuentes.
```

```text
Haz scraping de https://firecrawl.dev y explica qué hace.
```

<div id="troubleshooting">
  ## Solución de problemas
</div>

* **El servidor no se conecta:** confirma la URL alojada e inspecciona el estado de MCP en Windsurf.
* **Falta Crawl u otra herramienta:** el modo keyless expone únicamente Search, scraping y Parse. Conéctate mediante OAuth o una clave de API para acceder a un conjunto más amplio de herramientas.
