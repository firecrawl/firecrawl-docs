Añade el servidor MCP alojado de Firecrawl a [Executor](https://executor.sh) para que todos los agentes conectados a Executor puedan buscar en la web y realizar una extracción de datos web de ella desde un único punto de conexión.

<Note>
  Estos pasos son para Executor 1.x (`npm install -g executor`). Executor 2 (beta) organiza los servidores MCP como apps y cuentas; consulta la [documentación de Executor](https://executor.sh/docs) para ese flujo.
</Note>

## Configuración rápida {#quick-setup}

[Crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys) y luego inicia Executor:

```bash
npm install -g executor
executor web
```

En la interfaz de usuario web, añade una integración y selecciona **Firecrawl** en el catálogo, o introduce manualmente la URL de MCP:

```text
https://mcp.firecrawl.dev/v2/mcp
```

Executor detecta el servidor MCP e indexa sus herramientas. Cuando te pida las credenciales, introduce tu clave de API de Firecrawl para que las solicitudes incluyan una cabecera `Authorization: Bearer <key>`.

Si quieres, primero puedes comprobar el servidor desde la línea de comandos:

```bash
executor call executor mcp probeEndpoint '{"endpoint":"https://mcp.firecrawl.dev/v2/mcp","headers":{"Authorization":"Bearer '"$FIRECRAWL_API_KEY"'"}}'
```

Después, conecta tu agente al punto de conexión MCP propio de Executor (`http://127.0.0.1:4788/mcp` si usas un servidor local):

```bash
npx add-mcp http://127.0.0.1:4788/mcp --transport http --name executor
```

Ejecuta `executor tools integrations` y comprueba que `firecrawl` aparece en la lista con un número de herramientas mayor que cero.

## Solución de problemas {#troubleshooting}

* **El número de herramientas es 0:** Executor crea las herramientas por cuenta, así que termina de conectar la cuenta de Firecrawl con tu clave de API y luego actualiza la fuente.
* **El comando para añadir el servidor se queda en pausa:** Executor te pide que apruebes la adición de un servidor MCP; acéptala con `executor resume --execution-id <id> --action accept --content '{}'`.
* **Tu agente no ve las herramientas:** la mayoría de los clientes cargan los servidores MCP al iniciarse, así que reinicia el cliente o abre una nueva sesión después de añadir Executor.
