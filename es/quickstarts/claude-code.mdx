---
title: "Búsqueda y scraping web con MCP en Claude Code"
description: "Añade scraping y búsqueda web a Claude Code en 2 minutos"
---

Conecta Claude Code a Firecrawl mediante el MCP Server alojado. OAuth es la configuración interactiva recomendada porque la clave nunca se introduce en la línea de comandos, los archivos del proyecto ni la conversación.

<div id="quick-setup">
  ## Configuración rápida
</div>

<div id="1-add-firecrawl">
  ### 1. Añade Firecrawl
</div>

Ejecuta:

```bash
claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

`https://mcp.firecrawl.dev/v2/mcp-oauth` es un valor de configuración del cliente, no una página que debas abrir directamente en un navegador.

<div id="2-sign-in-and-verify">
  ### 2. Inicia sesión y verifica
</div>

Introduce `/mcp` en Claude Code, selecciona `firecrawl` y completa el inicio de sesión en el navegador. Si modificaste una conexión existente de Firecrawl, inicia una nueva sesión de Claude Code.

Confirma que solo haya un servidor `firecrawl` activo y, a continuación, prueba lo siguiente:

```text
Busca las notas de la última release de Next.js y resume las fuentes.
```

```text
Haz scraping de https://firecrawl.dev y explica qué hace.
```

<div id="other-connection-modes">
  ## Otros modos de conexión
</div>

* [Prueba MCP sin clave](/es/mcp-server/keyless#try-keyless) para Search, Scrape y Parse sin necesidad de una cuenta ni una clave.
* [Configura una clave de API](/es/mcp-server/keyless#add-an-api-key) para usos desatendidos. Mantén el secreto fuera del chat del agente y usa una referencia a una variable de entorno.
* [Ejecuta MCP localmente](/es/mcp-server/local) solo si necesitas un proceso local o una API de Firecrawl autogestionada. El paquete local requiere Node.js 22 o una versión posterior.

<div id="troubleshooting">
  ## Solución de problemas
</div>

* **Ya existe un servidor de Firecrawl:** ejecuta `claude mcp remove firecrawl`, añade una vez la conexión deseada y luego inicia una nueva sesión.
* **El navegador no se abre:** introduce `/mcp`, selecciona `firecrawl` e inicia la autenticación desde el cliente.
* **El servidor muestra `401`:** vuelve a iniciar sesión mediante `/mcp`; no pegues una clave de API en la conversación ni en la URL de OAuth.
