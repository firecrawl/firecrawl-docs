Añade Firecrawl a Zencoder en los IDE de JetBrains y en VS Code. JetBrains admite servidores remotos con OAuth2, así que inicias sesión con tu cuenta de Firecrawl. VS Code inicia el servidor en local con una clave de API.

## Requisitos {#requirements}

* El plugin de Zencoder para un IDE de JetBrains o para VS Code.
* Para la configuración en VS Code: Node.js 22 o posterior y una [clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys).

## Configuración rápida {#quick-setup}

<Tabs>
  <Tab title="JetBrains">
    1. Abre **Configuración** y ve a **Tools** &gt; **Zencoder** &gt; **Servidores MCP**.
    2. Agrega este servidor y aplica el cambio:

    ```json
    {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth",
        "auth": "oauth2"
      }
    }
    ```

    3. Completa el sign-in de Firecrawl en tu navegador y comprueba que las herramientas aparecen en la lista de herramientas del agente.
  </Tab>

  <Tab title="VS Code">
    1. Abre el archivo `settings.json` de usuario o del espacio de trabajo.
    2. Agrega Firecrawl en `zencoder.mcpServers`:

    ```json
    {
      "zencoder.mcpServers": {
        "firecrawl": {
          "command": "npx",
          "args": ["-y", "firecrawl-mcp@3.33.2"],
          "env": {
            "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
          }
        }
      }
    }
    ```

    3. Reinicia VS Code y comprueba que las herramientas de Firecrawl aparecen en **Herramientas de agente**.
  </Tab>
</Tabs>

Según la documentación de Zencoder, la compatibilidad con servidores HTTP y OAuth2 en VS Code se está implementando de forma gradual, así que usa la configuración local hasta que tu versión la incluya. Para más detalles, consulta la [guía de conexión OAuth](/es/mcp-server/oauth) y [Ejecutar MCP localmente](/es/mcp-server/local).

## Solución de problemas {#troubleshooting}

* **El servidor no aparece en las herramientas de agentes:** comprueba la sintaxis del JSON y reinicia el IDE. Los servidores MCP se cargan al iniciarse.
* **Falla el sign-in en JetBrains:** borra el token en caché del servidor y vuelve a iniciar el sign-in.
* **VS Code indica que falta un comando:** comprueba que `npx` funciona en una terminal y que `node --version` devuelve 22 o superior.
* **Las herramientas no se ejecutan:** Zencoder solicita permiso antes de cada llamada de herramienta. Selecciona **Allow once** o **Always allow** para las herramientas de Firecrawl.
