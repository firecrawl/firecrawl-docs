Conecta Firecrawl a Qwen Code como servidor MCP HTTP remoto para que Qwen Code pueda buscar en la web y leer páginas.

## Requisitos {#requirements}

* Qwen Code 0.25 o posterior.
* Una [clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys), exportada como `FIRECRAWL_API_KEY`.

## Configuración rápida {#quick-setup}

1. Exporta tu clave de API en la shell desde la que inicias Qwen Code:

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

2. Agrega el servidor. Las comillas simples impiden que el shell expanda la variable, así que el archivo de configuración guarda la referencia y no tu clave:

```bash
qwen mcp add --scope user --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp \
  --header 'Authorization: Bearer $FIRECRAWL_API_KEY'
```

3. Comprueba que el servidor se conecta:

```bash
qwen mcp list
```

4. Inicia Qwen Code, ejecuta `/mcp` para ver las herramientas de Firecrawl y pídele que realice una búsqueda o una extracción de datos web.

<Accordion title="¿Prefieres editar el archivo de configuración?">
  Añade el servidor a `~/.qwen/settings.json` o a `.qwen/settings.json` dentro de un proyecto:

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "httpUrl": "https://mcp.firecrawl.dev/v2/mcp",
        "headers": {
          "Authorization": "Bearer $FIRECRAWL_API_KEY"
        }
      }
    }
  }
  ```
</Accordion>

Consulta [Configurar una clave de API](/es/mcp-server/keyless#add-an-api-key) para obtener más información sobre las claves.

## Solución de problemas {#troubleshooting}

* **El servidor no aparece en una sesión en curso:** reinicia Qwen Code en el mismo proyecto después de añadirlo.
* **El servidor aparece como desconectado:** ejecuta `qwen mcp list` y comprueba que `FIRECRAWL_API_KEY` esté exportada en la shell desde la que se inicia Qwen Code.
* **Las llamadas a herramientas se rechazan por una clave no válida:** confirma que el valor de la cabecera sea `Bearer $FIRECRAWL_API_KEY` y que la variable contenga una clave válida.
* **No se usan las herramientas:** algunos modelos llaman a las herramientas MCP de forma más fiable que otros. Prueba con otro modelo.
