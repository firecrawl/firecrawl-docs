Conecta Firecrawl a Amazon Q Developer en VS Code, JetBrains y otros IDE compatibles a través del servidor MCP alojado. Q Developer abre un navegador para que inicies sesión con tu cuenta de Firecrawl.

<Note>
  La CLI de Amazon Q Developer ahora se llama Kiro CLI. Para usarla desde la terminal, sigue la [configuración de Kiro](/es/quickstarts/kiro).
</Note>

## Configuración rápida {#quick-setup}

1. Abre tu IDE, luego el panel de Q Developer y, por último, el panel **Chat**.
2. Selecciona el icono de herramientas y, a continuación, el botón más (+).
3. Selecciona un ámbito: **global** guarda el servidor en `~/.aws/amazonq/default.json` y **local** lo guarda en `.amazonq/default.json` dentro del proyecto.
4. Introduce `firecrawl` como nombre, selecciona **http** como transporte e introduce esta URL:

```text
https://mcp.firecrawl.dev/v2/mcp-oauth
```

5. Selecciona **Save**. Q Developer abre una página en el navegador para que autorices el acceso. Inicia sesión en Firecrawl y aprueba la conexión.
6. Revisa el permiso de cada herramienta (**Ask**, **Always allow** o **Deny**) en el panel que aparece después de guardar.

<Accordion title="¿Prefieres editar el archivo de configuración?">
  Q Developer también lee los servidores MCP de `~/.aws/amazonq/mcp.json` (global) y `.amazonq/mcp.json` (proyecto):

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
      }
    }
  }
  ```

  La compatibilidad con los archivos `mcp.json` se controla con el campo `useLegacyMcpJson` de `default.json`, cuyo valor predeterminado es `true`.
</Accordion>

<Accordion title="¿Prefieres usar una clave de API?">
  En el mismo cuadro de diálogo, añade una cabecera llamada `Authorization` con el valor `Bearer fc-YOUR-API-KEY` y usa `https://mcp.firecrawl.dev/v2/mcp` como URL. Consulta [Configurar una clave de API](/es/mcp-server/keyless#add-an-api-key).
</Accordion>

Consulta la [guía de conexión OAuth](/es/mcp-server/oauth) para obtener más información.

## Solución de problemas {#troubleshooting}

* **Aparece una alerta «Fix Configuration»:** selecciónala para volver al formulario y comprobar la URL.
* **No se abre la página del navegador:** selecciona **Edit setup** en el servidor, vuelve a guardar y completa la autorización cuando se abra la página.
* **El servidor aparece en la lista, pero sus herramientas no se ejecutan:** abre el servidor en el panel MCP Servers y comprueba que esté habilitado y que las herramientas no estén configuradas como **Deny**.
* **Hay dos entradas de Firecrawl:** un servidor definido en `.amazonq/default.json` tiene prioridad sobre el global. Elimina el duplicado que no quieras conservar.
