Combina [OpenRouter](https://openrouter.ai), una API unificada para cientos de LLM, con Firecrawl, la API de contexto para agentes de IA, para que cualquier modelo tenga búsqueda web y scraping en tiempo real.

La API de OpenRouter es compatible con OpenAI, por lo que puedes usar el SDK de OpenAI configurado para apuntar a la URL base de OpenRouter, junto con el SDK de Python o JavaScript de Firecrawl como herramienta.

## Configuración {#setup}

```bash
npm install firecrawl openai zod
```

```bash
export FIRECRAWL_API_KEY=fc-YOUR-API-KEY
export OPENROUTER_API_KEY=sk-or-YOUR-OPENROUTER-KEY
```

## Scraping + resumen con cualquier modelo de OpenRouter {#scrape-summarize-with-any-openrouter-model}

Esto hace scraping de una página con Firecrawl y la resume con el modelo de OpenRouter que elijas, en este caso Claude Haiku 4.5.

```typescript
import { Firecrawl } from 'firecrawl';
import OpenAI from 'openai';

const firecrawl = new Firecrawl();

const openrouter = new OpenAI({
  apiKey: process.env.OPENROUTER_API_KEY,
  baseURL: 'https://openrouter.ai/api/v1',
});

const scraped = await firecrawl.scrape('https://docs.firecrawl.dev', {
  formats: ['markdown'],
});

const completion = await openrouter.chat.completions.create({
  model: 'anthropic/claude-haiku-4.5',
  messages: [
    { role: 'user', content: `Summarize in 5 bullets: ${scraped.markdown}` },
  ],
});

console.log(completion.choices[0]?.message.content);
```

Reemplaza la cadena `model` por cualquier [modelo compatible con OpenRouter](https://openrouter.ai/models), como `openai/gpt-5`, `google/gemini-2.5-pro`, `meta-llama/llama-4-maverick`, etc.

## Llamadas a herramientas: el modelo decide cuándo hacer scraping {#tool-calling-model-decides-when-to-scrape}

OpenRouter admite llamadas a herramientas al estilo de OpenAI, por lo que Firecrawl se integra como una función que el modelo puede invocar.

```typescript
import { Firecrawl } from 'firecrawl';
import OpenAI from 'openai';
import { z } from 'zod';

const firecrawl = new Firecrawl();
const openrouter = new OpenAI({
  apiKey: process.env.OPENROUTER_API_KEY,
  baseURL: 'https://openrouter.ai/api/v1',
});

const ScrapeArgs = z.object({
  url: z.string().describe('The URL to scrape'),
});

const tools = [
  {
    type: 'function' as const,
    function: {
      name: 'scrape_website',
      description: 'Scrape the markdown content of any URL via Firecrawl',
      parameters: z.toJSONSchema(ScrapeArgs),
    },
  },
];

const response = await openrouter.chat.completions.create({
  model: 'anthropic/claude-haiku-4.5',
  tools,
  messages: [
    {
      role: 'user',
      content: 'What is Firecrawl? Visit firecrawl.dev and tell me.',
    },
  ],
});

const call = response.choices[0]?.message.tool_calls?.[0];
if (call?.type === 'function' && call?.function.name === 'scrape_website') {
  const { url } = ScrapeArgs.parse(JSON.parse(call.function.arguments));
  const page = await firecrawl.scrape(url, { formats: ['markdown'] });
  console.log(page.markdown);
}
```

## Python {#python}

```bash
pip install firecrawl-py openai
```

```python
import os
from firecrawl import Firecrawl
from openai import OpenAI

firecrawl = Firecrawl()

openrouter = OpenAI(
    api_key=os.environ["OPENROUTER_API_KEY"],
    base_url="https://openrouter.ai/api/v1",
)

page = firecrawl.scrape("https://docs.firecrawl.dev", formats=["markdown"])

completion = openrouter.chat.completions.create(
    model="anthropic/claude-haiku-4.5",
    messages=[{"role": "user", "content": f"Summarize: {page.markdown}"}],
)

print(completion.choices[0].message.content)
```

## Firecrawl como motor de búsqueda web de OpenRouter {#firecrawl-as-openrouters-web-search-engine}

OpenRouter también puede realizar búsquedas web con Firecrawl por su cuenta. Agrega la herramienta de servidor `openrouter:web_search` y establece `engine` en `firecrawl`: el modelo decide cuándo buscar y OpenRouter le devuelve los resultados.

```bash
curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer sk-or-YOUR-OPENROUTER-KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-haiku-4.5",
    "messages": [
      { "role": "user", "content": "What changed in the latest Next.js release?" }
    ],
    "tools": [
      { "type": "openrouter:web_search", "parameters": { "engine": "firecrawl", "max_results": 5 } }
    ]
  }'
```

OpenRouter factura estas búsquedas a tu cuenta de OpenRouter. Consulta la [documentación de búsqueda web](https://openrouter.ai/docs/guides/features/server-tools/web-search) de OpenRouter para ver los demás parámetros y los precios.

## Notas {#notes}

* Firecrawl es totalmente agnóstico respecto al modelo, así que puedes elegir cualquier modelo de OpenRouter sin cambiar el código de scraping.
* Muchas de las principales aplicaciones de OpenRouter (Cline, Roo Code, Kilo, Cursor, Continue) son entornos de agentes que pueden usar el MCP de Firecrawl. Comienza con el [selector de configuración de MCP](/es/mcp-server) para conectar una.
* Para trabajos de gran volumen, usa [extracción por lotes](/es/features/batch-scrape) para mantenerte dentro de los límites de contexto del LLM.
