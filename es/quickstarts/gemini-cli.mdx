Añade las herramientas de búsqueda, scraping y Parse sin clave de Firecrawl a [Google Gemini CLI](https://github.com/google-gemini/gemini-cli) mediante el MCP Server alojado.

<div id="quick-setup">
  ## Configuración rápida
</div>

Añade esto a `~/.gemini/settings.json` o a `.gemini/settings.json` de tu proyecto:

```json
{
  "mcpServers": {
    "firecrawl": {
      "httpUrl": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Reinicia Gemini CLI, ejecuta `/mcp list` y confirma que `firecrawl_search`, `firecrawl_scrape` y `firecrawl_parse` estén disponibles.

El acceso sin clave tiene límites compartidos por los usuarios que utilizan la misma IP pública. Inicia sesión desde un cliente interactivo con [For Humans](/es/mcp-server/oauth) o [añade una clave de API](/es/mcp-server/keyless#add-an-api-key) para uso sin supervisión.

<div id="try-it">
  ## Pruébalo
</div>

```text
Use Firecrawl to search the web for "Gemini context window" and summarize the sources.
```

```text
Scrape https://ai.google.dev/gemini-api/docs and outline the sections.
```

<div id="troubleshooting">
  ## Solución de problemas
</div>

* **Las herramientas no aparecen:** reinicia Gemini CLI después de editar `settings.json`; los servidores MCP Server se cargan al iniciarse.
* **Falta Crawl u otra herramienta:** sin clave expone exactamente búsqueda, scraping y Parse. Conéctate con OAuth o una clave de API para acceder a una superficie de herramientas más amplia.
