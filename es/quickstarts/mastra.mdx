## Requisitos previos {#prerequisites}

* Node.js 22.13+
* Una clave de API de Firecrawl — [obtén una gratis](https://www.firecrawl.dev/app/api-keys)
* Una clave de API de un [proveedor de modelos compatible con Mastra](https://mastra.ai/models)
* Un proyecto de Mastra existente — sigue el [inicio rápido de Mastra](https://mastra.ai/guides/getting-started/quickstart) para configurarlo

## Instala el SDK {#install-the-sdk}

```bash
npm install firecrawl
```

## Configura tu clave de API {#set-your-api-key}

Añade tu clave de API a `.env`:

```bash
FIRECRAWL_API_KEY=fc-YOUR-API-KEY
```

## Crea las herramientas de Firecrawl {#build-the-firecrawl-tools}

Crea `src/mastra/tools/firecrawl.ts` para exponer la búsqueda y el scraping como herramientas de Mastra:

```typescript
import { Firecrawl } from "firecrawl";
import { createTool } from "@mastra/core/tools";
import { z } from "zod";

const firecrawl = new Firecrawl();

export const firecrawlSearch = createTool({
  id: "firecrawl-search",
  description: "Search the web and return top results.",
  inputSchema: z.object({ query: z.string().min(1) }),
  outputSchema: z.object({
    results: z.array(
      z.object({
        title: z.string().nullable(),
        url: z.string(),
      }),
    ),
  }),
  execute: async ({ query }) => {
    const results = await firecrawl.search(query, { limit: 3 });
    return {
      results: (results.web ?? []).flatMap((item) =>
        "url" in item ? [{ title: item.title ?? null, url: item.url }] : [],
      ),
    };
  },
});

export const firecrawlScrape = createTool({
  id: "firecrawl-scrape",
  description: "Scrape a URL and return markdown content.",
  inputSchema: z.object({ url: z.string().url() }),
  outputSchema: z.object({ markdown: z.string() }),
  execute: async ({ url }) => {
    const result = await firecrawl.scrape(url, {
      formats: ["markdown"],
      onlyMainContent: true,
    });
    return { markdown: result.markdown ?? "" };
  },
});
```

## Crea el agente {#create-the-agent}

Crea `src/mastra/agents/web-agent.ts` y añade las herramientas de Firecrawl:

```typescript
import { Agent } from "@mastra/core/agent";
import { firecrawlSearch, firecrawlScrape } from "../tools/firecrawl";

export const webAgent = new Agent({
  id: "web-agent",
  name: "Web Agent",
  instructions:
    "Use Firecrawl tools to search and scrape web pages, then summarize the results.",
  model: "openai/gpt-5.4",
  tools: { firecrawlSearch, firecrawlScrape },
});
```

## Registrar el agente {#register-the-agent}

Registra el agente en tu instancia de Mastra, en `src/mastra/index.ts`:

```typescript
import { Mastra } from "@mastra/core";
import { webAgent } from "./agents/web-agent";

export const mastra = new Mastra({
  agents: { webAgent },
});
```

## Pruebas en Studio {#test-in-studio}

Inicia el servidor de desarrollo y abre [Mastra Studio](https://mastra.ai/docs/studio/overview) en `http://localhost:4111`:

```bash
npm run dev
```

Abre el **Agente web** y prueba prompts como:

* &quot;Encuentra el registro de cambios más reciente de Firecrawl y resume el último release.&quot;
* &quot;Busca los precios de Firecrawl y extrae los niveles de sus planes.&quot;

## Proporciona al agente un navegador alojado {#give-the-agent-a-hosted-browser}

Para páginas que requieren hacer clic, escribir o desplazarse, el paquete [`@mastra/browser-firecrawl`](https://mastra.ai/integrations/browsers/firecrawl) de Mastra ejecuta las herramientas de navegador del agente en una sesión del navegador de Firecrawl, así que no necesitas instalar Chromium en local.

```bash
npm install @mastra/browser-firecrawl agent-browser@0.19.0
```

<Note>
  Fija `agent-browser` en la versión 0.19.0. Las releases posteriores solo incluyen la CLI, por lo que `@mastra/browser-firecrawl` no se puede importar y falla con `Cannot find package .../agent-browser/index.js`.
</Note>

Crea `src/mastra/agents/browser-agent.ts` y luego registra `browserAgent` en tu instancia de Mastra igual que `webAgent`:

```typescript
import { Agent } from "@mastra/core/agent";
import { FirecrawlBrowser } from "@mastra/browser-firecrawl";

export const browserAgent = new Agent({
  id: "browser-agent",
  name: "Browser Agent",
  instructions:
    "Use the browser tools to open pages, click, and type. Take a snapshot after each action to check the result.",
  model: "openai/gpt-5.4",
  browser: new FirecrawlBrowser({ apiKey: process.env.FIRECRAWL_API_KEY }),
});
```

De forma predeterminada, cada hilo de conversación tiene su propia sesión del navegador. Consulta la [documentación del navegador de Firecrawl en Mastra](https://mastra.ai/integrations/browsers/firecrawl) para obtener más información sobre sesiones compartidas, tiempos de espera de sesión y perfiles guardados.

## Firecrawl autogestionado {#self-hosted-firecrawl}

Si ejecutas Firecrawl por tu cuenta, añade `FIRECRAWL_API_URL` a `.env`. El SDK la lee del entorno, así que las herramientas anteriores no necesitan cambios:

```bash
FIRECRAWL_API_URL=http://localhost:3002
```
