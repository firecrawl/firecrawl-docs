Agrega Firecrawl a Qodo Command para que tus agentes de Qodo puedan buscar en la web y leer páginas. Qodo Command inicia el servidor MCP de Firecrawl como un proceso local con tu clave de API.

<Note>
  Qodo retirará su plugin para IDE el 30 de octubre de 2026 y trasladará los flujos de trabajo locales a los agentes de programación que ya usas. Esta página trata sobre Qodo Command, que lee los servidores MCP desde un archivo del proyecto.
</Note>

## Requisitos {#requirements}

* Qodo Command, instalado con `npm install -g @qodo/command` y con la sesión iniciada mediante `qodo login`.
* Node.js 22 o una versión posterior.
* Una [clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys).

## Configuración rápida {#quick-setup}

1. En la raíz de tu proyecto, crea el archivo `mcp.json`:

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp@3.33.2"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
      }
    }
  }
}
```

2. Crea `agents/research.toml` y da al agente acceso al servidor indicando su nombre:

```toml
version = "1.0"

[commands.research]
description = "Research a topic on the web with Firecrawl"
instructions = """
Use the Firecrawl tools to search the web and read pages, then summarize the sources.
"""
tools = ["firecrawl"]
execution_strategy = "act"
```

3. Importa el agente desde `agent.toml`, ubicado en la raíz del proyecto:

```toml
version = "1.0"

imports = ["agents/research.toml"]
```

4. Ejecuta el agente y muestra la lista de herramientas disponibles:

```bash
qodo list-mcp
qodo research "Find the latest release notes for Node.js"
```

No incluyas `mcp.json` en el control de versiones, ya que contiene tu clave. Consulta [Ejecutar MCP localmente](/es/mcp-server/local) para ver la lista completa de variables de entorno.

## Solución de problemas {#troubleshooting}

* **`list-mcp` no muestra ninguna entrada de Firecrawl:** verifica que `mcp.json` esté en la raíz del proyecto o pasa `--mcp-file=path`.
* **El agente nunca llama a Firecrawl:** comprueba que `tools` en el archivo del agente contenga `"firecrawl"`, que debe coincidir con la clave en `mcp.json`.
* **El servidor no se inicia:** ejecuta `node --version` y confirma que muestra la versión 22 o superior.
* **El servidor devuelve `401`:** reemplaza el valor de `FIRECRAWL_API_KEY` en `mcp.json`.
