Añade a [OpenCode](https://opencode.ai) las herramientas sin clave de Search, Scrape y Parse de Firecrawl mediante el MCP Server alojado.

<div id="quick-setup">
  ## Configuración rápida
</div>

Añade esto a `~/.config/opencode/opencode.json` o al archivo `opencode.json` de tu proyecto:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "firecrawl": {
      "type": "remote",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "enabled": true
    }
  }
}
```

Reinicia OpenCode, introduce `/mcp` y confirma que `firecrawl_search`, `firecrawl_scrape` y `firecrawl_parse` estén disponibles.

El acceso sin clave tiene límites que se comparten entre los usuarios de la misma IP pública. Inicia sesión desde un cliente interactivo con [Para personas](/es/mcp-server/oauth) o [añade una clave de API](/es/mcp-server/keyless#add-an-api-key) para usar sin supervisión.

<div id="try-it">
  ## Pruébalo
</div>

```text
Search the web for the latest Bun release notes and summarize the sources.
```

```text
Scrape https://docs.firecrawl.dev/introduction and list the code examples.
```

<div id="troubleshooting">
  ## Solución de problemas
</div>

* **El servidor no se conecta:** ejecuta `opencode doctor` y confirma la URL remota.
* **No aparece Crawl u otra herramienta:** sin clave solo ofrece Search, Scrape y Parse. Conéctate con OAuth o una clave de API para acceder a un conjunto más amplio de herramientas.
