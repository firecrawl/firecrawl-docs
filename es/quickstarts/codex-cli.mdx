Conecta [OpenAI Codex CLI](https://github.com/openai/codex) a Firecrawl mediante el servidor MCP alojado con OAuth.

<div id="quick-setup">
  ## Configuración rápida
</div>

<div id="1-add-firecrawl">
  ### 1. Añade Firecrawl
</div>

```bash
codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth
codex mcp login firecrawl
```

La URL es un valor de configuración del cliente, no una página que se abra directamente en un navegador. Codex abre el flujo de inicio de sesión de Firecrawl, donde seleccionas un equipo y autorizas la conexión.

<div id="2-start-codex-and-verify">
  ### 2. Inicia Codex y verifica
</div>

```bash
codex
```

Introduce `/mcp` y confirma que `firecrawl` está conectado. Si modificaste una conexión existente de Firecrawl, inicia una nueva sesión de Codex antes de volver a intentarlo.

Prueba:

```text
Busca en la web las notas de la versión más reciente de Next.js App Router y resume las fuentes.
```

```text
Haz scraping de https://docs.firecrawl.dev y enumera las secciones de nivel superior.
```

<div id="other-connection-modes">
  ## Otros modos de conexión
</div>

* [Prueba MCP sin clave](/es/mcp-server/keyless#try-keyless) para búsqueda, scraping y procesar sin cuenta ni clave.
* [Configura una clave de API](/es/mcp-server/keyless#add-an-api-key) con `bearer_token_env_var` para uso desatendido. Mantén el secreto fuera del chat del agente y del control de versiones.
* [Ejecuta MCP localmente](/es/mcp-server/local) solo si necesitas un proceso local o una API de Firecrawl autogestionada. El paquete local requiere Node.js 22 o una versión posterior.

<div id="troubleshooting">
  ## Solución de problemas
</div>

* **Codex no ve las herramientas:** ejecuta `codex mcp list`, confirma que solo haya una entrada de `firecrawl` y reinicia Codex.
* **OAuth devuelve `401`:** ejecuta `codex mcp login firecrawl` e inicia sesión. Es normal que una solicitud sin credenciales al servidor OAuth devuelva `401` antes de la autenticación.
* **Una conexión mediante clave de API devuelve `401`:** reemplaza la clave en el entorno desde el que se inicia Codex y, luego, inicia una nueva sesión.
