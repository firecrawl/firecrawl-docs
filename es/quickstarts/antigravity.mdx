Conecta Firecrawl a [Google Antigravity](https://antigravity.google/) mediante el MCP Server alojado y, después, inicia sesión con tu cuenta de Firecrawl.

## Configuración rápida {#quick-setup}

1. En Antigravity, haz clic en **…** en la parte superior del panel lateral del agente y selecciona **MCP Servers**.
2. Haz clic en **Manage MCP Servers** y luego en **View raw config** para abrir `mcp_config.json` (global, en `~/.gemini/config/mcp_config.json`, o `.agents/mcp_config.json` en tu espacio de trabajo).
3. Añade el servidor de Firecrawl y guarda los cambios:

```json
{
  "mcpServers": {
    "firecrawl": {
      "serverUrl": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

4. Abre la configuración del Agente (`Cmd/Ctrl + ,`), ve a **Customizations** y haz clic en **Authenticate** junto a `firecrawl`.
5. Inicia sesión en Firecrawl desde tu navegador y aprueba un equipo; después, pega el código de autorización en Antigravity y haz clic en **Submit**.
6. Comprueba que las herramientas de Firecrawl, como `firecrawl_search` y `firecrawl_scrape`, están disponibles.

Antigravity requiere la clave `serverUrl` para los servidores remotos. Las entradas que usan `url` o `httpUrl` no se registran. Antigravity CLI lee el mismo archivo; escribe `/mcp` en la CLI para comprobar el estado del servidor.

<Accordion title="¿Prefieres usar una clave de API?">
  Para un uso desatendido, [crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys) y envíala como cabecera en lugar de iniciar sesión. Consulta [Añadir una clave de API](/es/mcp-server/keyless#add-an-api-key) para más detalles.

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "serverUrl": "https://mcp.firecrawl.dev/v2/mcp",
        "headers": {
          "Authorization": "Bearer fc-YOUR-API-KEY"
        }
      }
    }
  }
  ```
</Accordion>

Consulta la [guía de conexión OAuth](/es/mcp-server/oauth) para más detalles.

```

Search with Firecrawl for the official docs of three popular Python HTTP client libraries, scrape each docs homepage, and compare their async support in a table.
```

## Solución de problemas {#troubleshooting}

* **El servidor aparece con error:** confirma que la entrada usa `serverUrl` con el valor exacto `https://mcp.firecrawl.dev/v2/mcp-oauth` y, después, vuelve a cargar el servidor desde **Manage MCP Servers** o desde el gestor `/mcp` de la CLI.
* **Se requiere iniciar sesión o la sesión caduca:** vuelve a hacer clic en **Authenticate** junto a `firecrawl` en **Customizations**.
* **Ya existe otra conexión de Firecrawl:** actualiza el servidor existente con la URL de OAuth e inicia sesión para que solo haya un servidor de Firecrawl activo.
