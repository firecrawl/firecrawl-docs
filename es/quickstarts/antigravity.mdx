Añade las herramientas de búsqueda, scraping y Parse sin clave de Firecrawl a [Google Antigravity](https://antigravity.google/) mediante el MCP Server alojado.

<div id="quick-setup">
  ## Configuración rápida
</div>

Abre la configuración de Antigravity (`Cmd/Ctrl + ,`), busca **MCP Servers** y añade:

```json
{
  "mcpServers": {
    "firecrawl": {
      "serverUrl": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Recarga la ventana y confirma que `firecrawl_search`, `firecrawl_scrape` y `firecrawl_parse` estén disponibles.

El acceso sin clave tiene límites que se comparten entre los usuarios de la misma IP pública. Inicia sesión desde un cliente interactivo con [Para personas](/es/mcp-server/oauth) o [añade una clave de API](/es/mcp-server/keyless#add-an-api-key) para usos sin supervisión.

<div id="try-it">
  ## Pruébalo
</div>

```text
Use Firecrawl to search for the latest Vercel AI SDK release notes and summarize the sources.
```

```text
Scrape https://docs.firecrawl.dev/ai-onboarding and list the linked guides.
```

<div id="troubleshooting">
  ## Solución de problemas
</div>

* **El servidor aparece como fallido:** confirma la URL alojada e inspecciona el panel de salida de MCP.
* **Falta Crawl u otra herramienta:** sin clave solo ofrece búsqueda, scraping y Parse. Conéctate mediante OAuth o una clave de API para acceder a un conjunto de herramientas más amplio.
