Añade las herramientas de búsqueda, scraping, rastreo y mapeo de Firecrawl a [Pi](https://pi.dev) a través del servidor MCP alojado.

## Configuración rápida {#quick-setup}

[Crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys) y luego expórtala para que Pi pueda leerla:

```bash
export FIRECRAWL_API_KEY=fc-YOUR_API_KEY
```

Añade el servidor con el comando MCP integrado de Pi:

```bash
pi mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp --bearer-token-env-var FIRECRAWL_API_KEY
```

Esto añade la entrada a `~/.pi/agent/mcp.json`. También puedes pegarla manualmente o colocarla en `.pi/mcp.json` para usarla en un solo proyecto:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer ${FIRECRAWL_API_KEY}"
      }
    }
  }
}
```

Ejecuta `pi mcp list` y confirma que `firecrawl` aparece como conectado junto con sus herramientas, como `firecrawl_search` y `firecrawl_scrape`. Después, inicia `pi`; si ya tenías una sesión abierta, ejecuta `/reload`.

Si usas [pi-mcp-adapter](https://github.com/nicobailon/pi-mcp-adapter), añade la misma entrada en `~/.config/mcp/mcp.json` (o en `.mcp.json` dentro de un proyecto) y ejecuta `pi-mcp-adapter doctor` para comprobar la conexión.

### Ejecútalo en local {#run-it-locally-instead}

Para ejecutar el servidor MCP en tu equipo, agrégalo como servidor stdio:

```bash
pi mcp add firecrawl --env FIRECRAWL_API_KEY='${FIRECRAWL_API_KEY}' -- npx -y firecrawl-mcp
```

## Solución de problemas {#troubleshooting}

* **El servidor aparece como fallido:** ejecuta `pi mcp list` y comprueba que `FIRECRAWL_API_KEY` esté exportada en la misma shell desde la que inicias Pi.
* **Las herramientas no aparecen en una sesión abierta:** ejecuta `/reload` después de añadir o modificar un servidor fuera de la sesión.
* **No aparece el comando MCP de Pi:** actualiza Pi a una release reciente o usa pi-mcp-adapter con la configuración anterior.
