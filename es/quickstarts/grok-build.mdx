Conecta [Grok Build](https://docs.x.ai/build/overview), la CLI del agente de programación de xAI (`grok`), con Firecrawl mediante el servidor MCP alojado. OAuth es la configuración interactiva recomendada. Con OAuth, la clave no aparece en la línea de comandos, en los archivos del proyecto ni en la conversación.

## Configuración rápida {#quick-setup}

### 1. Añade Firecrawl {#1-add-firecrawl}

Ejecuta:

```bash
grok mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

`https://mcp.firecrawl.dev/v2/mcp-oauth` es un valor de configuración del cliente, no una página que debas abrir directamente en el navegador.

### 2. Inicia sesión y verifica {#2-sign-in-and-verify}

Inicia Grok Build:

```bash
grok
```

Escribe `/mcps`, selecciona `firecrawl` y pulsa `i` para iniciar el sign-in en el navegador. Selecciona un equipo y aprueba la conexión. Grok guarda los tokens de OAuth en `~/.grok/mcp_credentials.json`.

Comprueba que solo haya un servidor `firecrawl` activo y, a continuación, prueba:

```text
Busca en la web las notas de la versión más recientes de Next.js y resume las fuentes.
```

```text
Haz scraping de https://docs.firecrawl.dev y enumera sus secciones principales.
```

## MCP local con una clave de API {#local-mcp-with-an-api-key}

Usa el servidor local solo si necesitas un proceso local o una API de Firecrawl autoalojada. El paquete local requiere Node.js 22 o superior.

Define `FIRECRAWL_API_KEY` en el entorno desde el que se inicia Grok. Después, añade este bloque a `~/.grok/config.toml`:

```toml
[mcp_servers.firecrawl]
command = "npx"
args = ["-y", "firecrawl-mcp@3.33.2"]
env = { FIRECRAWL_API_KEY = "${FIRECRAWL_API_KEY}" }
startup_timeout_sec = 60
```

Grok expande `${FIRECRAWL_API_KEY}` al cargar la configuración, así que la clave no queda guardada en el archivo. Mantén el secreto fuera del chat del agente y del control de versiones. Usa una sola entrada `firecrawl`: antes, elimina el servidor alojado con `grok mcp remove firecrawl`.

Para la configuración autogestionada, consulta [Ejecutar MCP localmente](/es/mcp-server/local).

## Otros modos de conexión {#other-connection-modes}

* [Prueba MCP sin clave](/es/mcp-server/keyless#try-keyless) para usar Search, extracción de datos web y Parse sin cuenta ni clave.
* [Configura una clave de API](/es/mcp-server/keyless#add-an-api-key) para usar el servidor alojado de forma desatendida. No incluyas el secreto en el chat del agente; usa una referencia a una variable de entorno.

## Solución de problemas {#troubleshooting}

* **Ya existe un servidor de Firecrawl:** ejecuta `grok mcp remove firecrawl`, añade la conexión que quieras una sola vez y luego inicia una nueva sesión.
* **Grok muestra un segundo servidor `firecrawl`:** Grok también carga servidores MCP desde `~/.claude.json`, `.cursor/mcp.json` y los archivos `.mcp.json` del proyecto. Ejecuta `grok inspect` para ver de dónde procede cada servidor y luego elimina el duplicado.
* **El servidor muestra `401`:** escribe `/mcps`, selecciona `firecrawl` y pulsa `i` para volver a iniciar sesión. No pegues ninguna clave de API en la conversación ni en la URL de OAuth.
* **El servidor local no se conecta:** ejecuta `grok mcp doctor firecrawl`. Grok guarda los errores del servidor en `~/.grok/logs/mcp/firecrawl.stderr.log`. Si `npx` descarga el paquete la primera vez que se inicia, aumenta `startup_timeout_sec`.
