Conecta Firecrawl a Crush como servidor MCP HTTP remoto para que Crush pueda buscar en la web y leer páginas.

## Requisitos {#requirements}

* Crush 0.98 o posterior.
* Una [clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys) exportada como `FIRECRAWL_API_KEY`.

## Configuración rápida {#quick-setup}

1. Exporta tu clave de API en la shell desde la que inicias Crush:

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

2. Agrega el servidor a `crush.json` en tu proyecto, o a `~/.config/crush/crush.json` para usarlo en todos tus proyectos:

```json
{
  "$schema": "https://charm.land/crush.json",
  "mcp": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer $FIRECRAWL_API_KEY"
      }
    }
  }
}
```

3. Inicia Crush y pídele que haga una búsqueda o un scraping.

<Accordion title="¿Usas un archivo crushrc?">
  Las releases más recientes de Crush pueden leer un archivo `crushrc` de estilo Bash, en el que un servidor MCP se define con un solo comando:

  ```bash
  mcp add firecrawl \
    --type http \
    --url "https://mcp.firecrawl.dev/v2/mcp" \
    --header Authorization "Bearer $FIRECRAWL_API_KEY"
  ```

  Ejecuta `crush dirs` para ver dónde busca Crush la configuración en tu equipo.
</Accordion>

Consulta [Configurar una clave de API](/es/mcp-server/keyless#add-an-api-key) para obtener más información sobre las claves.

## Solución de problemas {#troubleshooting}

* **El servidor no se inicia:** comprueba que `FIRECRAWL_API_KEY` esté exportada en el shell desde el que se inicia Crush y que la URL sea exactamente `https://mcp.firecrawl.dev/v2/mcp`.
* **Se descarta la cabecera:** Crush elimina cualquier cabecera cuyo valor se resuelva en un string vacío. Esto ocurre si `FIRECRAWL_API_KEY` no está definida.
* **No se usan las herramientas:** algunos modelos invocan las herramientas MCP de forma más fiable que otros. Prueba con otro modelo.
