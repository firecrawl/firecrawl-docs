Integra Firecrawl con OpenClaw para darles a tus agentes la capacidad de realizar extracción de datos web, búsquedas, rastreo e interactuar con la web, así como ejecutar trabajos del agente, todo a través de la [CLI de Firecrawl](/es/sdks/cli).

## Por qué Firecrawl + OpenClaw {#why-firecrawl-openclaw}

* **No necesitas un navegador local** — cada sesión se ejecuta en un sandbox remoto y aislado. Sin instalaciones de Chromium, sin conflictos de controladores, sin presión de RAM en tu máquina.
* **Paralelismo real** — ejecuta muchas sesiones de navegador a la vez sin contención por recursos locales. Los agentes pueden navegar en lotes a través de varios sitios simultáneamente.
* **Seguro por defecto** — la navegación, la evaluación del DOM y la extracción suceden dentro de sandboxes desechables, no en tu estación de trabajo.
* **Mejor eficiencia en el uso de tokens** — los agentes reciben artefactos limpios (snapshots, campos extraídos) en lugar de arrastrar DOMs gigantes y logs de controladores dentro de la ventana de contexto.
* **Kit completo para la web** — scraping, búsqueda y automatización del navegador, todo a través de una sola CLI que tu agente ya sabe usar.

## Configuración {#setup}

Indica a tu agente que instale la CLI de Firecrawl, se autentique e inicialice la skill con este comando:

```bash
npx -y firecrawl-cli init --browser --all
```

* `--all` omite la selección de agentes e inicializa todos los agentes detectados
* `--browser` abre el navegador automáticamente para la autenticación de Firecrawl

o instala todo por separado:

```bash
npm install -g firecrawl-cli
firecrawl setup skills
firecrawl login --browser
# O bien, omite el navegador y proporciona tu clave de API directamente:
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

Comprueba que todo esté configurado correctamente:

```bash
firecrawl --status
```

<Tip>
  Una vez instalada la skill, tu agente de OpenClaw descubrirá y utilizará automáticamente los comandos de Firecrawl, sin necesidad de configuración adicional.
</Tip>

## Extracción de datos web {#scrape}

Realiza la extracción de datos web del contenido de una sola página:

```bash
firecrawl https://example.com --only-main-content
```

Obtener formatos específicos:

```bash
firecrawl https://example.com --format markdown,links --pretty
```

## Búsqueda {#search}

Busca en la web y, opcionalmente, realiza extracción de datos web de los resultados:

```bash
firecrawl search "latest AI funding rounds" --limit 10

# Buscar y extraer los resultados
firecrawl search "OpenClaw documentation" --scrape --scrape-formats markdown
```

## Interactuar {#interact}

Extrae datos de una página y sigue trabajando con ella en una sesión del navegador en vivo. Cada sesión se ejecuta de forma remota en un entorno aislado, así que no hace falta instalar Chromium localmente. De forma predeterminada, `interact` usa la extracción de datos web más reciente.

```bash
firecrawl scrape https://news.ycombinator.com
firecrawl interact "What are the titles of the top 3 stories?"
firecrawl interact "Click the More link at the bottom of the page and list the first 3 story titles"
firecrawl interact stop
```

Ejecuta código directamente en la página en vivo en lugar de usar un prompt:

```bash
firecrawl interact -c "await page.title()"
firecrawl interact -c "print(await page.title())" --python
```

<Note>
  Tu agente envía prompts que expresan la intención, o breves fragmentos de código de Playwright, en lugar de gestionar un navegador local. Cuando termine, ejecuta `firecrawl interact stop` para liberar la sesión. El antiguo comando `firecrawl browser` está obsoleto; en su lugar, usa `scrape` seguido de `interact`.
</Note>
