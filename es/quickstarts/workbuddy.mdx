Agrega las herramientas de búsqueda, scraping, rastreo y mapeo de Firecrawl a [Tencent WorkBuddy](https://www.workbuddy.ai) a través del servidor MCP alojado.

## Configuración rápida {#quick-setup}

[Crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys) y, después, agrega el servidor en WorkBuddy:

1. Abre **Experts · Skills · Connectors**, cambia a la pestaña **Connectors** y selecciona **Custom connectors**.
2. Selecciona **Configure MCP** para abrir el editor de configuración de MCP.
3. Agrega Firecrawl a `mcpServers` y guarda los cambios:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

Reemplaza `<FIRECRAWL_API_KEY>` por tu clave. Si ya tienes otros servidores, añade solo la entrada `firecrawl` y conserva el resto.

WorkBuddy guarda esta configuración en `~/.workbuddy/mcp.json`. Si solo quieres usarla en un proyecto concreto, usa `<project>/.workbuddy/mcp.json`.

De nuevo en la lista de MCP, activa **firecrawl** y márcalo como de confianza si WorkBuddy te lo pide. Si el estado aparece en verde, está conectado y tienes disponibles herramientas como `firecrawl_search` y `firecrawl_scrape`.

WorkBuddy también admite MCP OAuth. Para iniciar sesión en lugar de utilizar una clave, consulta [Para personas](/es/mcp-server/oauth).

## Solución de problemas {#troubleshooting}

* **El estado aparece en rojo:** comprueba que el JSON sea válido y que la URL sea exactamente `https://mcp.firecrawl.dev/v2/mcp`.
* **401 No autorizado:** verifica la clave y conserva el prefijo `Bearer ` en la cabecera `Authorization`.
* **Las herramientas no aparecen:** desactiva el servidor y vuelve a activarlo para que WorkBuddy actualice la lista de herramientas.
