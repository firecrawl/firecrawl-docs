Conecta Firecrawl al modo agente de GitHub Copilot en Visual Studio mediante el servidor MCP alojado y, luego, inicia sesión con tu cuenta de Firecrawl.

## Requisitos {#requirements}

* Visual Studio 2022 versión 17.14 o posterior, o Visual Studio 2026.
* Sesión iniciada en GitHub Copilot y Copilot Chat en modo **agente**.

## Configuración rápida {#quick-setup}

1. Crea `%USERPROFILE%\.mcp.json` para que Firecrawl esté disponible en todas las soluciones, o `<SOLUTIONDIR>\.mcp.json` para limitarlo a una sola solución y compartirlo a través del control de código fuente.
2. Añade esta configuración y guarda el archivo:

```json
{
  "servers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

3. En el archivo, selecciona **Authentication Required** en el CodeLens que aparece sobre el servidor y, a continuación, completa el sign-in de Firecrawl en tu navegador. Si no ves el CodeLens, habilítalo en **Tools**, **Options**, **Text Editor**, **CodeLens**.
4. En Copilot Chat, cambia al modo **agente**, abre **Tools** y habilita las herramientas de Firecrawl. Visual Studio deshabilita las nuevas herramientas MCP hasta que las actives.

<Accordion title="¿Prefieres añadir el servidor desde el chat?">
  En Copilot Chat, cambia al modo **agente**, abre **Tools**, selecciona el botón de más (+) y luego **Add custom MCP server**. Introduce `firecrawl` como nombre y `https://mcp.firecrawl.dev/v2/mcp-oauth` como URL.
</Accordion>

<Accordion title="¿Prefieres un servidor local con una clave de API?">
  Visual Studio también admite servidores locales. Sigue [Ejecutar MCP localmente](/es/mcp-server/local) y define el comando en el mismo archivo:

  ```json
  {
    "servers": {
      "firecrawl": {
        "command": "npx",
        "args": ["-y", "firecrawl-mcp@3.33.2"],
        "env": {
          "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
        }
      }
    }
  }
  ```
</Accordion>

Consulta la [guía de conexión OAuth](/es/mcp-server/oauth) para obtener más información. Para un uso desatendido, [configura una clave de API](/es/mcp-server/keyless#add-an-api-key).

## Solución de problemas {#troubleshooting}

* **No aparecen herramientas de Firecrawl en el selector:** abre el selector de herramientas y actívalas. Visual Studio restablece las aprobaciones de herramientas cada vez que cambia la lista de herramientas de un servidor.
* **Vuelve a pedirse el sign-in:** en `.mcp.json`, selecciona **Manage Authentication** en el CodeLens del servidor `firecrawl`.
* **Se ignora el archivo:** en los archivos de Visual Studio, la clave de nivel superior es `servers`, no `mcpServers`.
* **Existe otra definición de `firecrawl`:** Visual Studio también lee `.vscode\mcp.json` y `.cursor\mcp.json` en la carpeta de la solución. Deja solo una entrada de Firecrawl.
