Agrega Firecrawl a AI Assistant en IntelliJ IDEA, PyCharm, WebStorm y el resto de IDE de JetBrains. AI Assistant inicia el servidor MCP de Firecrawl como un proceso local con tu clave de API.

## Requisitos {#requirements}

* Un IDE de JetBrains con AI Assistant 2025.1 o posterior. La compatibilidad con clientes MCP se incorporó en esa release.
* Node.js 22 o posterior en tu `PATH`, ya que el servidor se ejecuta mediante `npx`.
* Una [clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys).

## Configuración rápida {#quick-setup}

1. Abre **Configuración**, luego **Tools**, después **AI Assistant** y, por último, **Model Context Protocol (MCP)**.
2. Selecciona **Add**.
3. Pega este JSON, reemplaza la clave y establece **Server level** en global o en el proyecto actual:

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp@3.33.2"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
      }
    }
  }
}
```

4. Selecciona **OK** y luego **Apply**. La columna **Status** muestra la conexión, y su icono de herramientas muestra las herramientas de Firecrawl.
5. Activa **Automatically enable new and changed MCP servers** si quieres que el servidor se inicie automáticamente.

<Accordion title="Usar una conexión remota">
  La documentación actual de AI Assistant también admite servidores Streamable HTTP, que se configuran con una entrada `url` en el mismo JSON. Como no documenta cabeceras de solicitud ni un flujo de sign-in en el navegador, usa la configuración local anterior para Firecrawl, salvo que tu IDE muestre esas opciones.
</Accordion>

Consulta [Ejecutar MCP localmente](/es/mcp-server/local) para ver la lista completa de variables de entorno.

## Solución de problemas {#troubleshooting}

* **El estado sigue en rojo:** ejecuta `node --version` en una terminal y comprueba que muestra la versión 22 o posterior. Reinicia el IDE después de instalar Node.js para que detecte el nuevo `PATH`.
* **`spawn npx ENOENT`:** el IDE no encuentra `npx`. Inicia el IDE desde un shell donde `npx` funcione o usa la ruta completa de `npx` como comando.
* **El servidor muestra `401`:** reemplaza el valor de `FIRECRAWL_API_KEY` y vuelve a seleccionar **Apply**.
* **Registros:** la página de configuración de MCP incluye un enlace a la carpeta de registros, que contiene un registro por servidor.
