Conecta [GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli) o [Copilot en VS Code](https://code.visualstudio.com/docs/copilot/overview) a Firecrawl mediante el servidor MCP alojado y, después, inicia sesión con tu cuenta de Firecrawl. El [agente de programación de Copilot](#copilot-coding-agent) se conecta con una clave de API.

Las URL de servidor que se indican a continuación son valores de configuración del cliente, no páginas que debas abrir directamente en un navegador.

## Copilot CLI {#copilot-cli}

### 1. Añade Firecrawl {#1-add-firecrawl}

```bash
copilot mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

Esto añade el servidor a `~/.copilot/mcp-config.json`. También puedes ejecutar `/mcp add` dentro de una sesión interactiva y seleccionar el tipo **HTTP**, o editar el archivo directamente:

```json ~/.copilot/mcp-config.json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth",
      "tools": ["*"]
    }
  }
}
```

### 2. Inicia sesión y verifica {#2-sign-in-and-verify}

```bash
copilot
```

La primera vez que te conectes, Copilot CLI abrirá el flujo de sign-in de Firecrawl en tu navegador, donde podrás seleccionar un equipo y aprobar la conexión. Introduce `/mcp` para confirmar que `firecrawl` está conectado.

### Usar una clave de API en su lugar {#use-an-api-key-instead}

Para un uso desatendido, [crea una clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys), expórtala como `FIRECRAWL_API_KEY` y añade el punto de conexión con clave de API con una cabecera bearer:

```bash
copilot mcp add --transport http \
  --header "Authorization: Bearer $FIRECRAWL_API_KEY" \
  firecrawl https://mcp.firecrawl.dev/v2/mcp
```

La clave se almacena en `~/.copilot/mcp-config.json`, así que no incluyas ese archivo en el control de versiones.

## VS Code {#vs-code}

### 1. Agrega Firecrawl {#1-add-firecrawl-2}

Ejecuta **MCP: Add Server** desde la paleta de comandos y selecciona **HTTP**, o crea `.vscode/mcp.json` en tu espacio de trabajo:

```json .vscode/mcp.json
{
  "servers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

Para que el servidor esté disponible en todos los espacios de trabajo, ejecuta **MCP: Open User Configuration** y añade allí la misma entrada.

### 2. Inicia sesión y verifica {#2-sign-in-and-verify-2}

Inicia el servidor desde el editor de `mcp.json` o con **MCP: List Servers**. Cuando VS Code solicite autenticación, permítela y completa el sign-in de Firecrawl en tu navegador. Después, abre Copilot Chat en modo **Agente** y selecciona el icono de herramientas para comprobar que aparecen las herramientas de Firecrawl.

### Usar una clave de API en su lugar {#use-an-api-key-instead-2}

Usa el punto de conexión con clave de API y deja que VS Code te pida la clave, para que se guarde de forma segura en lugar de quedar escrita en el archivo:

```json .vscode/mcp.json
{
  "inputs": [
    {
      "type": "promptString",
      "id": "firecrawl-api-key",
      "description": "Firecrawl API key",
      "password": true
    }
  ],
  "servers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer ${input:firecrawl-api-key}"
      }
    }
  }
}
```

## Agente de programación de Copilot {#copilot-coding-agent}

El agente de programación de Copilot (también llamado agente en la nube de Copilot) trabaja con incidencias y solicitudes de incorporación de cambios en GitHub. La configuración de MCP del repositorio no admite servidores remotos que usen OAuth, así que esta configuración guarda una clave de API de Firecrawl como secreto de Agents y la envía como cabecera.

### Requisitos {#requirements}

* Un plan de pago de GitHub Copilot con el agente de programación habilitado en el repositorio.
* Acceso de administrador al repositorio, necesario para editar la configuración de MCP y los secretos de Agents.
* Una [clave de API de Firecrawl](https://www.firecrawl.dev/app/api-keys).

### Configúralo {#set-it-up}

1. En tu repositorio, abre **Settings**, luego **Secrets and variables** y después **Agents**.
2. Selecciona **New repository secret**, asígnale el nombre `COPILOT_MCP_FIRECRAWL_API_KEY`, pega tu clave de API de Firecrawl y guárdalo. Copilot solo pasa a los servidores MCP los secretos de Agents cuyos nombres empiezan por `COPILOT_MCP_`.
3. Abre **Settings**, luego **Copilot** y después **MCP servers**.
4. Pega esta configuración en **MCP configuration** y selecciona **Save MCP configuration**:

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer $COPILOT_MCP_FIRECRAWL_API_KEY"
      },
      "tools": ["firecrawl_search", "firecrawl_scrape", "firecrawl_map"]
    }
  }
}
```

5. Asigna una incidencia a Copilot. Cuando aparezca su solicitud de incorporación de cambios, selecciona **View session**, abre el paso **Start MCP Servers** en los registros y comprueba que aparecen las herramientas de Firecrawl.

<Warning>
  Copilot usa las herramientas de la lista `tools` sin pedir aprobación. Incluye en la lista solo las herramientas que necesita el agente. Usa `"*"` únicamente si quieres que estén disponibles todas las herramientas de Firecrawl.
</Warning>

## Solución de problemas {#troubleshooting}

* **Las herramientas no aparecen:** comprueba que solo haya un servidor `firecrawl` configurado y luego reinicia Copilot CLI, o ejecuta **MCP: List Servers** en VS Code y reinicia el servidor.
* **Se vuelve a pedir el sign-in o se devuelve `401`:** reinicia el servidor y completa el sign-in en el navegador. Es normal que una solicitud sin autenticar al servidor OAuth devuelva `401` antes de la autenticación.
* **Una conexión con clave de API devuelve `401`:** comprueba que la URL sea `https://mcp.firecrawl.dev/v2/mcp` (no `/v2/mcp-oauth`) y que la cabecera sea `Authorization: Bearer <FIRECRAWL_API_KEY>`.
* **Política de la organización:** si tu organización de GitHub restringe los servidores MCP en Copilot, un administrador debe permitir Firecrawl para que pueda conectarse.
* **Agente de programación: las herramientas de Firecrawl no aparecen en el registro de la sesión:** comprueba que el nombre del secreto sea exactamente `COPILOT_MCP_FIRECRAWL_API_KEY` y que se trate de un secreto de Agents, no de Actions.
