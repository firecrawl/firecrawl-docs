title: "Use Firecrawl MCP in Dyad"

---

Add Firecrawl to [Dyad](https://www.dyad.sh) so the AI in your app builder can search, scrape, and interact with the web.

<Note>
You need Dyad v0.25 or later for the Add to Dyad links.
</Note>

## 1. Get your API key

Create a key at [firecrawl.dev/app/api-keys](https://www.firecrawl.dev/app/api-keys). You enter it in Dyad, not in the link.

## 2. Add Firecrawl to Dyad

Pick one transport.

The link opens Dyad on the **Plugins** page with the form filled in. Click **Add**, then finish the key step for your transport.

### Hosted (HTTP)

1. In the form, turn **Use OAuth** off.
2. After adding, open the new plugin and add this header:

   | Header | Value |
   | --- | --- |
   | `Authorization` | `Bearer YOUR_FIRECRAWL_API_KEY` |

### Local (npx)

After adding, open the new plugin and add this environment variable:

| Variable | Value |
| --- | --- |
| `FIRECRAWL_API_KEY` | `YOUR_FIRECRAWL_API_KEY` |

## 3. Try it

In a Dyad chat, try:

```text
Search the web for the latest Next.js release notes and summarize the sources.
```

```text
Scrape https://firecrawl.dev and describe what the page offers.
```

## Add it by hand

Open **Plugins**, click **Add Plugin**, and fill in either set of values.

| Transport | Fields |
| --- | --- |
| `http` | URL `https://mcp.firecrawl.dev/v2/mcp`, header `Authorization: Bearer YOUR_FIRECRAWL_API_KEY` |
| `stdio` | Command `npx`, args `-y firecrawl-mcp`, env `FIRECRAWL_API_KEY=YOUR_FIRECRAWL_API_KEY` |

See the [MCP server reference](/mcp-server) for the full tool list.
