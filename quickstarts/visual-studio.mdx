Connect Firecrawl to GitHub Copilot agent mode in Visual Studio through the hosted MCP server, then sign in with your Firecrawl account.

## Requirements

- Visual Studio 2022 version 17.14 or newer, or Visual Studio 2026.
- GitHub Copilot signed in, with Copilot Chat in **Agent** mode.

## Quick setup

1. Create `%USERPROFILE%\.mcp.json` to make Firecrawl available in every solution, or `<SOLUTIONDIR>\.mcp.json` to scope it to one solution and share it through source control.
2. Add this configuration and save the file:

```json
{
  "servers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

3. In the file, select **Authentication Required** in the CodeLens above the server, then complete the Firecrawl sign-in in your browser. If you do not see the CodeLens, enable it in **Tools**, **Options**, **Text Editor**, **CodeLens**.
4. In Copilot Chat, switch to **Agent** mode, open **Tools**, and enable the Firecrawl tools. Visual Studio disables new MCP tools until you turn them on.

<Accordion title="Prefer to add the server from chat?">
In Copilot Chat, switch to **Agent** mode, open **Tools**, select the plus button, then **Add custom MCP server**. Enter `firecrawl` as the name and `https://mcp.firecrawl.dev/v2/mcp-oauth` as the URL.
</Accordion>

<Accordion title="Prefer a local server with an API key?">
Visual Studio also runs local servers. Use [Run MCP locally](/mcp-server/local) and define the command in the same file:

```json
{
  "servers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp@3.23.7"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
      }
    }
  }
}
```
</Accordion>

See the [OAuth connection guide](/mcp-server/oauth) for more details. For unattended use, [configure an API key](/mcp-server/keyless#add-an-api-key).

## Troubleshooting

- **No Firecrawl tools in the picker:** open the tool picker and enable them. Visual Studio resets tool approvals whenever a server's tool list changes.
- **Sign-in is required again:** in `.mcp.json`, select **Manage Authentication** in the CodeLens for the `firecrawl` server.
- **The file is ignored:** the top-level key in Visual Studio files is `servers`, not `mcpServers`.
- **Another definition of `firecrawl` exists:** Visual Studio also reads `.vscode\mcp.json` and `.cursor\mcp.json` in the solution folder. Keep one Firecrawl entry.
