## Install Firecrawl

<Steps>
  <Step title="Open the Firecrawl plugin">
    Click **Add to Grok Bot** above to open Firecrawl's plugin listing, then select **Add to Grok Bot** there. The Grok Bot desktop app opens to finish the install. You can also open **Connect apps** from the Grok Bot sidebar and search for **Firecrawl**.
  </Step>
  <Step title="Sign in to Firecrawl">
    When Grok Bot asks you to authorize the plugin, finish the Firecrawl sign-in in your browser, choose a team, and approve access. Grok Bot shows the connection once sign-in completes.
  </Step>
  <Step title="Start a task">
    Confirm Firecrawl appears under **Installed** in **Connect apps**. In a chat, type `@` and choose Firecrawl to attach it to the task, or ask your Bot to use Firecrawl with the prompt below.
  </Step>
</Steps>

The plugin connects to Firecrawl's hosted MCP server with browser sign-in and includes Firecrawl skills. You do not need to configure an MCP server, copy an API key, or install skills separately. Connected apps are account-wide, so every Bot on your Grok Bot account can use Firecrawl.

## If Firecrawl does not appear

- **The plugin shows Needs auth or Disconnected:** open Firecrawl in **Connect apps** and choose **Authenticate**, or **Reconnect**, to bring the sign-in page back.
- **Sign-in did not finish:** start it again from the plugin and complete the Firecrawl sign-in in your browser.
- **The Bot says Firecrawl is missing:** check that Firecrawl is listed under **Installed** in **Connect apps**, then start a new message.

Review or revoke the connection under [Connected apps in Settings](https://www.firecrawl.dev/app/settings?tab=mcp). For other clients, see the [For Humans sign-in guide](/mcp-server/oauth). Using xAI's coding CLI instead? Follow the [Grok Build guide](/quickstarts/grok-build).
