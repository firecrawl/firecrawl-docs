Add Firecrawl's Search, Scrape, Crawl, and Map tools to [Tencent WorkBuddy](https://www.workbuddy.ai) through the hosted MCP server.

## Quick setup

[Create a Firecrawl API key](https://www.firecrawl.dev/app/api-keys), then add the server in WorkBuddy:

1. Open **Experts · Skills · Connectors**, switch to the **Connectors** tab, and select **Custom connectors**.
2. Select **Configure MCP** to open the MCP configuration editor.
3. Add Firecrawl to `mcpServers` and save:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

Replace `<FIRECRAWL_API_KEY>` with your key. If you already have other servers, add only the `firecrawl` entry and keep the rest.

WorkBuddy stores this in `~/.workbuddy/mcp.json`. For a single project, use `<project>/.workbuddy/mcp.json` instead.

Back in the MCP list, turn **firecrawl** on, and trust it if WorkBuddy asks. A green status means it is connected and tools such as `firecrawl_search` and `firecrawl_scrape` are available.

WorkBuddy also supports MCP OAuth. To sign in instead of using a key, see [For Humans](/mcp-server/oauth).

## Try it

```text
Search the web for the latest Tencent Cloud announcements and summarize the sources.
```

```text
Scrape https://firecrawl.dev and explain what it does.
```

## Troubleshooting

- **Status is red:** check that the JSON is valid and the URL is exactly `https://mcp.firecrawl.dev/v2/mcp`.
- **401 Unauthorized:** confirm the key and keep the `Bearer ` prefix in the `Authorization` header.
- **Tools do not appear:** turn the server off and on again so WorkBuddy refreshes the tool list.
