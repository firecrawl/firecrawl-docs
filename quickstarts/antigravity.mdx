Connect Firecrawl to [Google Antigravity](https://antigravity.google/) through the hosted MCP server, then sign in with your Firecrawl account.

## Quick setup

1. In Antigravity, click **…** at the top of the agent side panel and select **MCP Servers**.
2. Click **Manage MCP Servers**, then **View raw config** to open `mcp_config.json`.
3. Add the Firecrawl server and save:

```json
{
  "mcpServers": {
    "firecrawl": {
      "serverUrl": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

4. Open Agent settings (`Cmd/Ctrl + ,`), go to **Customizations**, and click **Authenticate** next to `firecrawl`.
5. Sign in to Firecrawl in your browser and approve a team, then paste the authorization code back into Antigravity and click **Submit**.
6. Confirm that Firecrawl's tools, such as `firecrawl_search` and `firecrawl_scrape`, are available.

Antigravity requires the `serverUrl` key for remote servers. Entries that use `url` or `httpUrl` do not register.

<Accordion title="Prefer an API key?">
For unattended use, [create a Firecrawl API key](https://www.firecrawl.dev/app/api-keys) and send it as a header instead of signing in. See [Add an API key](/mcp-server/keyless#add-an-api-key) for details.

```json
{
  "mcpServers": {
    "firecrawl": {
      "serverUrl": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer fc-YOUR-API-KEY"
      }
    }
  }
}
```
</Accordion>

See the [OAuth connection guide](/mcp-server/oauth) for more details.

## Try it

```text
Use Firecrawl to search for the latest Vercel AI SDK release notes, scrape the two most relevant results, and summarize what changed with a link to each source.
```

```text
Search with Firecrawl for the official docs of three popular Python HTTP client libraries, scrape each docs homepage, and compare their async support in a table.
```

## Troubleshooting

- **Server shows as failed:** confirm the entry uses `serverUrl` with exactly `https://mcp.firecrawl.dev/v2/mcp-oauth`, then reload the window.
- **Sign-in is required or expires:** click **Authenticate** next to `firecrawl` in **Customizations** again.
- **Another Firecrawl connection already exists:** update the existing server to the OAuth URL and sign in so only one Firecrawl server is active.
