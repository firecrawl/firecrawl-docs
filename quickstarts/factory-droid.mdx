Connect [Factory Droid](https://docs.factory.com/droid-cli/overview), Factory's coding agent CLI (`droid`), to Firecrawl through the hosted MCP server, then sign in with your Firecrawl account so Droid can search, scrape, and interact with the web.

## Quick setup

### 1. Add Firecrawl

Install the [Droid CLI](https://docs.factory.com/droid-cli/quickstart) if you haven't already, then run:

```bash
droid mcp add firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth --type http
```

`https://mcp.firecrawl.dev/v2/mcp-oauth` is a client configuration value, not a page to open directly in a browser.

### 2. Sign in and verify

Run:

```bash
droid mcp auth
```

Droid opens the Firecrawl sign-in in your browser, where you choose a team and approve the connection. You can also enter `/mcp` inside Droid, select `firecrawl`, and authenticate from there.

Run `droid mcp list` and confirm that `firecrawl` is connected. Then start Droid from your project's root:

```bash
droid
```

Try:

```text
Search the web for the latest Next.js release notes and summarize the sources.
```

```text
Scrape https://docs.firecrawl.dev and list the top-level sections.
```

## Migrate from v1 to v2 with Droid

The v1 API stops working on December 10, 2026. The [v1 to v2 migration guide](/migrate-to-v2) has a prompt that finds every v1 call in a project and rewrites it for v2. Copy the prompt from that page, then run it with Droid. The migration does not need the MCP server above.

- **Interactive:** run `droid` from your project's root and paste the prompt. By default, Droid asks before it edits files or runs commands.
- **Headless:** save the prompt to a file outside your project, such as `~/firecrawl-v2-migration.txt`. Sign in to Droid or set `FACTORY_API_KEY`, then run this from your project's root:

```bash
droid exec --auto medium -f ~/firecrawl-v2-migration.txt
```

`--auto medium` lets Droid edit files, install the SDK, and run your tests, but not push. If Droid needs a command above that level, it stops and leaves its edits in your working tree.

## Other connection modes

- [Try keyless MCP](/mcp-server/keyless#try-keyless) for Search, Scrape, and Parse without an account or key.
- [Configure an API key](/mcp-server/keyless#add-an-api-key) for unattended use. Keep the secret outside agent chat and source control.
- [Run MCP locally](/mcp-server/local) only when you need a local process or a self-hosted Firecrawl API. The local package requires Node.js 22 or newer.

## Troubleshooting

- **A Firecrawl server already exists:** run `droid mcp remove firecrawl`, add the intended connection once, then start a new session.
- **`droid mcp list` shows `needs authentication`:** run `droid mcp auth`, or enter `/mcp` in Droid, select `firecrawl`, and sign in again. Do not paste an API key into the conversation or the OAuth URL.
- **`droid exec` stops with an authentication error:** sign in to Droid, or set `FACTORY_API_KEY` to a key from your [Factory settings](https://app.factory.ai/settings/api-keys).
- **`droid exec` stops partway through the migration:** Droid needed a command above `--auto medium`. Check `git status`, then finish in an interactive `droid` session.
