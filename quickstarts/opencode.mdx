Add web search to [OpenCode](https://opencode.ai) without an API key by connecting Firecrawl's [keyless MCP server](/mcp-server/keyless). OpenCode gets three tools, Search, Scrape, and Parse, with no account or sign-up, and they work with any model provider you use in OpenCode.

OpenCode's built-in `websearch` tool also runs without a key, but only with the OpenCode or OpenCode Go provider, or after you enable it with an environment variable (see [OpenCode's tools docs](https://opencode.ai/docs/tools/#websearch)). Firecrawl adds full-page scraping and PDF parsing to search.

## Quick setup

Add this to `~/.config/opencode/opencode.json` or your project's `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "firecrawl": {
      "type": "remote",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "enabled": true
    }
  }
}
```

Restart OpenCode, then run `opencode mcp list` and confirm that `firecrawl` shows as connected. Its tools are `firecrawl_search`, `firecrawl_scrape`, and `firecrawl_parse`.

Keyless access has daily limits shared by users on the same public IP, and it isn't available from IP addresses that look like a VPN or proxy. Sign in from an interactive client with [For Humans](/mcp-server/oauth), or add an API key for unattended use.

## Add an API key

Keep the key in an environment variable and reference it from `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "firecrawl": {
      "type": "remote",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "enabled": true,
      "oauth": false,
      "headers": {
        "Authorization": "Bearer {env:FIRECRAWL_API_KEY}"
      }
    }
  }
}
```

With a key, OpenCode can use the [full tool surface](/mcp-server/tools) at your plan's limits.

## Troubleshooting

- **Server does not attach:** run `opencode mcp list` and confirm the remote URL and status.
- **Keyless calls fail on a VPN or office proxy:** keyless access isn't available from IP addresses that look like a VPN or proxy. Add an API key or sign in.
- **Crawl or another tool is missing:** keyless exposes exactly Search, Scrape, and Parse. Connect with OAuth or an API key for the broader tool surface.

## FAQ

<AccordionGroup>
  <Accordion title="Can OpenCode search the web without an API key?">
    Yes. Add Firecrawl's keyless MCP server at `https://mcp.firecrawl.dev/v2/mcp` to `opencode.json`. It needs no account and gives OpenCode Search, Scrape, and Parse within a daily limit per IP address. OpenCode's built-in `websearch` tool is also keyless when you use the OpenCode provider or enable it with an environment variable.
  </Accordion>
  <Accordion title="Which Firecrawl tools work in OpenCode without a key?">
    `firecrawl_search`, `firecrawl_scrape`, and `firecrawl_parse`. Crawl, Map, Interact, Agent, and the other tools need sign-in or an API key.
  </Accordion>
  <Accordion title="Does keyless web search work with any model in OpenCode?">
    Yes. The MCP server runs outside the model call, so the Firecrawl tools work with whichever model provider OpenCode is configured to use.
  </Accordion>
  <Accordion title="What happens when I reach the keyless limit?">
    Keyless requests return a `429` once the daily request or credit cap for your IP address is reached. Add an API key to keep going; a free account includes 1,000 credits. See [Rate limits](/rate-limits#keyless-no-api-key).
  </Accordion>
</AccordionGroup>
