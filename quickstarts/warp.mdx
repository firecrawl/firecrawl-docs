Connect Firecrawl to Warp's local agents through the hosted MCP server, then sign in with your Firecrawl account.

## Quick setup

1. In Warp, open **Settings**, then **Agents**, then **MCP servers**. You can also search for **Open MCP Servers** in the command palette.
2. Select **+ Add** and paste this configuration:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

3. Start the server. Warp opens a browser page for the Firecrawl sign-in. Approve access, and Warp stores the credentials on your device.
4. Confirm that `firecrawl` shows as running in the MCP servers list, then ask an agent to search or scrape.

<Accordion title="Prefer a file-based configuration?">
Warp also loads servers from `~/.warp/.mcp.json` for every project, or `.warp/.mcp.json` at a project root. Use the same JSON as above. Servers from the project file need your approval before they start.
</Accordion>

<Accordion title="Prefer an API key?">
Warp accepts custom headers on URL servers. Use `https://mcp.firecrawl.dev/v2/mcp` as the URL and add `"headers": { "Authorization": "Bearer fc-YOUR-API-KEY" }`. See [Configure an API key](/mcp-server/keyless#add-an-api-key).
</Accordion>

See the [OAuth connection guide](/mcp-server/oauth) for more details.

## Troubleshooting

- **The sign-in page does not open:** start the server again from the MCP servers page.
- **Sign-in keeps failing:** run `rm -rf ~/.mcp-auth` to clear stored MCP tokens, then start the server again. This removes tokens for every MCP server.
- **The server fails to start:** select **View Logs** on the server to read the error.
- **Tools are not used:** some models call MCP tools more reliably than others. Try a different model in the agent picker.
