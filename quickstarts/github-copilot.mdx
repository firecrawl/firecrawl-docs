Connect Firecrawl to the GitHub Copilot coding agent (also called Copilot cloud agent) so it can search the web and read pages while it works on an issue or pull request. Copilot's repository MCP settings do not support remote servers that use OAuth, so this setup stores a Firecrawl API key as an Agents secret and sends it as a header.

## Requirements

- A paid GitHub Copilot plan with the coding agent enabled for the repository.
- Repository administrator access, which is needed to edit MCP settings and Agents secrets.
- A [Firecrawl API key](https://www.firecrawl.dev/app/api-keys).

## Quick setup

1. In your repository, open **Settings**, then **Secrets and variables**, then **Agents**.
2. Select **New repository secret**, name it `COPILOT_MCP_FIRECRAWL_API_KEY`, paste your Firecrawl API key, and save. Copilot only passes Agents secrets whose names start with `COPILOT_MCP_` to MCP servers.
3. Open **Settings**, then **Copilot**, then **MCP servers**.
4. Paste this configuration into **MCP configuration** and select **Save MCP configuration**:

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer $COPILOT_MCP_FIRECRAWL_API_KEY"
      },
      "tools": ["firecrawl_search", "firecrawl_scrape", "firecrawl_map"]
    }
  }
}
```

5. Assign an issue to Copilot. When its pull request appears, choose **View session**, open the **Start MCP Servers** step in the logs, and confirm that the Firecrawl tools are listed.

<Warning>
Copilot uses the tools in the `tools` list without asking for approval. Keep the list to the tools the agent needs. Use `"*"` only if you want every Firecrawl tool available.
</Warning>

<Accordion title="Prefer Copilot CLI?">
Copilot CLI reads MCP servers from `~/.copilot/mcp-config.json`. Add Firecrawl from a terminal:

```bash
copilot mcp add --transport http \
  --header "Authorization: Bearer fc-YOUR-API-KEY" \
  firecrawl https://mcp.firecrawl.dev/v2/mcp
```

Run `copilot mcp list` to confirm the entry, then start `copilot` and enter `/mcp` to check the connection.
</Accordion>

See [Configure an API key](/mcp-server/keyless#add-an-api-key) for more on key-based connections.

## Try it

Create an issue and assign it to Copilot with a description such as:

```text
Use Firecrawl to read the current migration guide for our framework version, then update the deprecated calls in this repository.
```

```text
Search the web for the latest release notes of our HTTP client library and summarize breaking changes before changing the code.
```

## Troubleshooting

- **The Firecrawl tools are missing from the session log:** confirm the secret name is exactly `COPILOT_MCP_FIRECRAWL_API_KEY` and that it is an Agents secret, not an Actions secret.
- **Configuration will not save:** the JSON must be valid. Remove any comments and trailing commas.
- **The server returns `401`:** replace the Agents secret with a current API key and assign a new task, since a running session keeps the old value.
- **A tool is blocked:** add its name to the `tools` list, or use `"*"`.
