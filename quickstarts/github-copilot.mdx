Connect [GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli) or [Copilot in VS Code](https://code.visualstudio.com/docs/copilot/overview) to Firecrawl through the hosted MCP server, then sign in with your Firecrawl account.

The server URLs below are client configuration values, not pages to open directly in a browser.

## Copilot CLI

### 1. Add Firecrawl

```bash
copilot mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

This writes the server to `~/.copilot/mcp-config.json`. You can also run `/mcp add` inside an interactive session and choose the **HTTP** type, or edit the file directly:

```json ~/.copilot/mcp-config.json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth",
      "tools": ["*"]
    }
  }
}
```

### 2. Sign in and verify

```bash
copilot
```

On the first connection, Copilot CLI opens the Firecrawl sign-in flow in your browser, where you choose a team and approve the connection. Enter `/mcp` to confirm that `firecrawl` is connected.

### Use an API key instead

For unattended use, [create a Firecrawl API key](https://www.firecrawl.dev/app/api-keys), export it as `FIRECRAWL_API_KEY`, and add the API-key endpoint with a bearer header:

```bash
copilot mcp add --transport http \
  --header "Authorization: Bearer $FIRECRAWL_API_KEY" \
  firecrawl https://mcp.firecrawl.dev/v2/mcp
```

The key is stored in `~/.copilot/mcp-config.json`, so keep that file out of source control.

## VS Code

### 1. Add Firecrawl

Run **MCP: Add Server** from the Command Palette and choose **HTTP**, or create `.vscode/mcp.json` in your workspace:

```json .vscode/mcp.json
{
  "servers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

To make the server available in every workspace, run **MCP: Open User Configuration** and add the same entry there.

### 2. Sign in and verify

Start the server from the `mcp.json` editor or with **MCP: List Servers**. When VS Code asks to authenticate, allow it and complete the Firecrawl sign-in in your browser. Then open Copilot Chat in **Agent** mode and select the tools icon to confirm that Firecrawl's tools are listed.

### Use an API key instead

Use the API-key endpoint and let VS Code prompt for the key, so it is stored securely instead of written to the file:

```json .vscode/mcp.json
{
  "inputs": [
    {
      "type": "promptString",
      "id": "firecrawl-api-key",
      "description": "Firecrawl API key",
      "password": true
    }
  ],
  "servers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer ${input:firecrawl-api-key}"
      }
    }
  }
}
```

## Try it

```text
Search the web for the latest Next.js App Router release notes and summarize the sources.
```

```text
Scrape https://docs.firecrawl.dev and list the top-level sections.
```

See [choose a tool](/mcp-server/tools) for the full Firecrawl MCP tool list.

## Troubleshooting

- **Tools do not appear:** confirm that only one `firecrawl` server is configured, then restart Copilot CLI, or run **MCP: List Servers** in VS Code and restart the server.
- **Sign-in is required again or returns `401`:** restart the server and complete the browser sign-in. A bare request to the OAuth server is expected to return `401` before authentication.
- **An API-key connection returns `401`:** confirm that the URL is `https://mcp.firecrawl.dev/v2/mcp` (not `/v2/mcp-oauth`) and that the header is `Authorization: Bearer <FIRECRAWL_API_KEY>`.
- **Organization policy:** if your GitHub organization restricts MCP servers in Copilot, an administrator must allow Firecrawl before it can connect.
