Add Firecrawl to Zencoder in JetBrains IDEs and VS Code. JetBrains supports remote servers with OAuth2, so you sign in with your Firecrawl account. VS Code starts the server locally with an API key.

## Requirements

- The Zencoder plugin for a JetBrains IDE or VS Code.
- For the VS Code setup: Node.js 22 or newer and a [Firecrawl API key](https://www.firecrawl.dev/app/api-keys).

## Quick setup

<Tabs>
  <Tab title="JetBrains">
    1. Open **Settings**, then **Tools**, then **Zencoder**, then **MCP Servers**.
    2. Add this server and apply the change:

    ```json
    {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth",
        "auth": "oauth2"
      }
    }
    ```

    3. Complete the Firecrawl sign-in in your browser, then confirm the tools appear in the agent's tool list.
  </Tab>
  <Tab title="VS Code">
    1. Open your user or workspace `settings.json`.
    2. Add Firecrawl under `zencoder.mcpServers`:

    ```json
    {
      "zencoder.mcpServers": {
        "firecrawl": {
          "command": "npx",
          "args": ["-y", "firecrawl-mcp@3.33.2"],
          "env": {
            "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
          }
        }
      }
    }
    ```

    3. Restart VS Code, then confirm the Firecrawl tools appear under **Agent Tools**.
  </Tab>
</Tabs>

Zencoder's documentation lists HTTP and OAuth2 servers for VS Code as being rolled out, so use the local setup there until your version shows them. See the [OAuth connection guide](/mcp-server/oauth) and [Run MCP locally](/mcp-server/local) for more details.

## Troubleshooting

- **The server does not appear in agent tools:** check the JSON syntax, then restart the IDE. MCP servers load at startup.
- **JetBrains sign-in fails:** clear the cached token for the server and start the sign-in again.
- **VS Code reports a missing command:** confirm `npx` works in a terminal and that `node --version` prints 22 or newer.
- **Tools do not run:** Zencoder asks for permission before a tool call. Choose **Allow once** or **Always allow** for the Firecrawl tools.
