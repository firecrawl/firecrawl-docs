Add Firecrawl's Search and Scrape tools to [Cherry Studio](https://cherry-ai.com) through the hosted MCP server, so your agents get clean context from the live web.

Cherry Studio supports remote Streamable HTTP servers with custom headers, so you connect with your Firecrawl API key as a bearer header.

## Quick setup

1. [Create a Firecrawl API key](https://www.firecrawl.dev/app/api-keys).
2. In Cherry Studio, open **Settings → MCP → MCP Servers** and select **Add**.
3. Choose **Import from JSON** and paste the following, replacing `<FIRECRAWL_API_KEY>` with your key:

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "streamableHttp",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

4. Enable the server, wait for its status to turn healthy, then open its details and confirm that `firecrawl_search` and `firecrawl_scrape` are listed.
5. Open **Work**, edit your Agent, go to **MCP**, and enable the Firecrawl server so the Agent can use it.

You can also use **Quick Create** and set the type to **Streamable HTTP**, the URL to `https://mcp.firecrawl.dev/v2/mcp`, and the header `Authorization=Bearer <FIRECRAWL_API_KEY>`.

For a local server instead, use type `stdio` with command `npx`, arguments `-y` and `firecrawl-mcp`, and the environment variable `FIRECRAWL_API_KEY`. See the [local MCP server guide](/mcp-server/local).

Cherry Studio can also sign in to remote servers with OAuth when no `Authorization` header is set. See [For Humans](/mcp-server/oauth) for the Firecrawl OAuth endpoint.


## Troubleshooting

- **Server does not connect:** confirm the type is Streamable HTTP, the URL is exactly `https://mcp.firecrawl.dev/v2/mcp`, and the header is `Authorization: Bearer <FIRECRAWL_API_KEY>`. Check the server log in its details page.
- **Tools do not appear in a chat:** a server must be running and enabled for the Agent. Check **Work → Agent → Edit → MCP**.
- **A tool is missing:** open the server details to see which tools it exposes, and confirm your API key is valid.
