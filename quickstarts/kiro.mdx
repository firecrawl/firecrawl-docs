Add Firecrawl's Search, Scrape, Crawl, and Map tools to [Kiro](https://kiro.dev) through the hosted MCP server.

## Quick setup

[Create a Firecrawl API key](https://www.firecrawl.dev/app/api-keys) and export it in the shell that starts Kiro:

```bash
export FIRECRAWL_API_KEY=fc-YOUR_API_KEY
```

Add this to `~/.kiro/settings/mcp.json` for all workspaces, or to `.kiro/settings/mcp.json` in a project. Kiro IDE and Kiro CLI read the same files.

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer ${FIRECRAWL_API_KEY}"
      }
    }
  }
}
```

In Kiro IDE, run **Kiro: Open user MCP config (JSON)** from the command palette to open the file. Saving it reconnects the server. Kiro only expands environment variables you have approved, so approve `FIRECRAWL_API_KEY` when the prompt appears, or add it under **Settings** > **Mcp Approved Env Vars**.

Confirm that `firecrawl_search` and `firecrawl_scrape` appear in the MCP server list.

If you prefer to sign in with your browser, see [For Humans](/mcp-server/oauth).

### Run it locally instead

To run the MCP server on your machine, use a local server entry:

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "${FIRECRAWL_API_KEY}"
      }
    }
  }
}
```

## Try it

```text
Search the web for the latest Bun release notes and summarize the sources.
```

```text
Scrape https://firecrawl.dev and explain what it does.
```

## Troubleshooting

- **Authorization header is empty:** export `FIRECRAWL_API_KEY` before starting Kiro, and approve it under **Mcp Approved Env Vars**. Project `.env` files are not loaded.
- **Server does not connect:** check the JSON for syntax errors and confirm the URL is `https://mcp.firecrawl.dev/v2/mcp`.
- **Tools do not appear:** save the config file again so Kiro reconnects, or restart Kiro.
