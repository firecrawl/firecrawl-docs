Connect Firecrawl to Kiro through the hosted MCP server. Kiro handles the browser sign-in for you, so there is nothing to register by hand. The same configuration file is used by the Kiro IDE and the Kiro CLI.

<Note>
Kiro CLI replaces the Amazon Q Developer CLI. If you used `q` before, this page applies to you.
</Note>

## Quick setup

1. Open the user-level configuration file `~/.kiro/settings/mcp.json`. In the IDE, run **Kiro: Open user MCP config (JSON)** from the command palette. For a single project, use `.kiro/settings/mcp.json` in the workspace instead.
2. Add Firecrawl and save the file:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

3. Kiro reconnects when you save and opens the Firecrawl authorization page in your browser. Sign in and approve access.
4. Open the MCP servers tab in the Kiro panel, or run `kiro-cli mcp status --name firecrawl`, and confirm that Firecrawl's tools are available.

<Accordion title="Prefer an API key?">
Remote servers in Kiro accept headers. Export `FIRECRAWL_API_KEY` in your shell, then use:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer ${FIRECRAWL_API_KEY}"
      }
    }
  }
}
```

Kiro only expands environment variables you have approved. When it shows the security warning for `FIRECRAWL_API_KEY`, approve it, or add it under **Mcp Approved Env Vars** in settings.
</Accordion>

<Accordion title="Prefer the CLI?">
```bash
kiro-cli mcp add --name firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth --scope global
```
</Accordion>

See the [OAuth connection guide](/mcp-server/oauth) for more details. For unattended use, [configure an API key](/mcp-server/keyless#add-an-api-key).

## Troubleshooting

- **MCP support is off:** in the IDE, open settings with `Cmd/Ctrl + ,`, search for "MCP", and enable it.
- **The server does not connect:** confirm the URL is exactly `https://mcp.firecrawl.dev/v2/mcp-oauth` and save the file again to trigger a reconnect.
- **An OAuth scope error appears:** add `"oauth": { "oauthScopes": [] }` to the server entry.
- **Workspace and user files both define `firecrawl`:** Kiro merges them and the workspace file wins. Keep one entry.
