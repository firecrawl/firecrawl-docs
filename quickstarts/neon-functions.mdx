In this guide, you'll build three Neon Functions that search the web, scrape a page, and interact with a live site using Firecrawl. Then you'll run them locally, deploy them to your Neon branch, and call one over HTTP.

## Prerequisites

Before you start, make sure you have:

- Node.js 24 or later
- A Firecrawl API key — [get one free](https://www.firecrawl.dev/app/api-keys)

## Set up the Neon CLI

You'll use the Neon CLI to link your project, run your functions locally, and deploy them. Install it globally:

```bash
npm install -g neon@latest
```

Then log in to your Neon account:

```bash
neon login
```

This opens a browser window. Approve access there, then head back to your terminal. If you don't have a Neon account yet, you can sign up from that same window.

## Set up your project

Create a new folder for your project and move into it:

```bash
mkdir firecrawl-neon && cd firecrawl-neon
npm init -y
```

Install the Firecrawl SDK and Neon's config package:

```bash
npm install firecrawl @neon/config
```

Create a `.env` file and add your Firecrawl API key:

```bash
FIRECRAWL_API_KEY=fc-YOUR-API-KEY
```

Now link this folder to a Neon project:

```bash
neon link
```

The CLI asks you to pick an organization and a project. Choose an existing project, or select **Create new project** to make one. If the CLI offers to create a `neon.ts` for you, skip it. You'll write your own in the next step.

Once linked, the CLI saves your project details in a `.neon` file and adds `DATABASE_URL` to your `.env`.

Next, create a `neon.ts` file at the root of your project. This is where you tell Neon which functions to deploy and which environment variables each one gets. Keep the function slugs to lowercase letters and digits, since Neon doesn't allow hyphens in them:

```typescript
import { defineConfig } from "@neon/config/v1";

const env = { FIRECRAWL_API_KEY: process.env.FIRECRAWL_API_KEY ?? "" };

export default defineConfig({
  functions: {
    firecrawlsearch: {
      name: "Firecrawl Search",
      source: "./functions/search.ts",
      env,
    },
    firecrawlscrape: {
      name: "Firecrawl Scrape",
      source: "./functions/scrape.ts",
      env,
    },
    firecrawlinteract: {
      name: "Firecrawl Interact",
      source: "./functions/interact.ts",
      env,
    },
  },
});
```

## Search the web

Create a `functions` folder, then add `functions/search.ts`. This function reads a `query` from the request body and returns the top five search results:

```typescript
import { Firecrawl } from "firecrawl";

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

export default {
  async fetch(request: Request) {
    const { query } = await request.json();
    const results = await firecrawl.search(query, { limit: 5 });

    return Response.json(results);
  },
};
```

## Scrape a page

Next, add `functions/scrape.ts`. Send it a `url` and it hands back the page's content:

```typescript
import { Firecrawl } from "firecrawl";

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

export default {
  async fetch(request: Request) {
    const { url } = await request.json();
    const result = await firecrawl.scrape(url);

    return Response.json(result);
  },
};
```

## Interact with a page

Finally, add `functions/interact.ts`. This one opens Amazon, searches for a product, clicks the first result, and tells you the price, all from plain-English prompts:

```typescript
import { Firecrawl } from "firecrawl";

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

export default {
  async fetch(_request: Request) {
    const result = await firecrawl.scrape("https://www.amazon.com", {
      formats: ["markdown"],
    });
    const scrapeId = result.metadata?.scrapeId;

    await firecrawl.interact(scrapeId, {
      prompt: "Search for iPhone 16 Pro Max",
    });
    const response = await firecrawl.interact(scrapeId, {
      prompt: "Click on the first result and tell me the price",
    });
    console.log(response.output);

    await firecrawl.stopInteraction(scrapeId);

    return Response.json({ output: response.output });
  },
};
```

## Run locally

Before you deploy, try your functions out on your machine. Start the dev server:

```bash
neon dev
```

You'll see a local URL for each function in your terminal. Edit any file and the server reloads it for you.

## Deploy

When you're happy with how they work, deploy all three functions to your linked branch:

```bash
neon deploy --env .env
```

The `--env .env` flag loads your `.env` file before Neon reads `neon.ts`, so your `FIRECRAWL_API_KEY` ships with each function. You don't have to set up a database connection yourself: Neon adds `DATABASE_URL` for you, so you can save results straight to Postgres from the same handler.

## Test it

Grab the public URL for your search function:

```bash
neon functions get firecrawlsearch
```

Copy the URL from the output and send it a search query:

```bash
curl -X POST https://<branch-id>-firecrawlsearch.compute.<cell>.<region>.aws.neon.tech/ \
  -H "Content-Type: application/json" \
  -d '{"query": "firecrawl web scraping"}'
```

You should get back a JSON list of search results.

<Note>
  Anyone with the URL can call your Neon Functions. Before you go to production, [add authentication](https://neon.com/docs/compute/functions/authentication) so nobody else can spend your Firecrawl credits.
</Note>
