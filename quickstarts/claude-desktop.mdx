Claude Desktop, Cowork, and the Code tab all read connectors from your Claude account. Connect Firecrawl once, under the server name `firecrawl`, and it is available in every tab.

| Setting | Value |
| --- | --- |
| Server name | `firecrawl` |
| Server URL | `https://mcp.firecrawl.dev/v2/mcp-oauth` |
| Sign-in | Browser sign-in to Firecrawl, then approve a team |

`https://mcp.firecrawl.dev/v2/mcp-oauth` is a client configuration value, not a page to open directly in a browser.

1. Open the [Firecrawl connector](https://claude.ai/directory/connectors/firecrawl) in the Claude connectors directory, or go to **Customize > Connectors** in Claude Desktop and search for Firecrawl.
2. Click **Connect**. Claude opens Firecrawl in your browser.
3. Sign in to Firecrawl, choose a team, and approve access.

On Team or Enterprise plans, an organization Owner may need to allow the connector before members can connect.

<Accordion title="Can't use the directory connector? Add a custom connector">
  1. In Claude Desktop, go to **Customize > Connectors**.
  2. Click **Add**, then add a custom connector.
  3. Enter `firecrawl` as the name and `https://mcp.firecrawl.dev/v2/mcp-oauth` as the remote MCP server URL.
  4. Keep the detected sign-in settings, add the connector, then click **Connect** and complete the browser sign-in.

  Organization Owners add custom connectors from **Organization settings > Connectors** instead.
</Accordion>

## 2. Use it in Cowork and chat

In the Cowork or Chat tab, open the **+** menu next to the prompt box, go to **Connectors**, and make sure Firecrawl is enabled. Then try:

```text
Use Firecrawl to search for the latest Next.js release notes and summarize the sources.
```

```text
Scrape https://firecrawl.dev and explain what it does.
```

## 3. Use it in the Code tab

Local Code tab sessions can use the same connector. Click the **+** button next to the prompt box, select **Connectors**, and enable Firecrawl.

The Code tab also loads MCP servers you added to Claude Code, for example with `claude mcp add`. If you already set up Firecrawl there with the [Claude Code guide](/quickstarts/claude-code), keep the server name `firecrawl` and confirm that only one Firecrawl server is active in the session.

## Troubleshooting

- **Firecrawl tools don't appear.** Start a new conversation or session after connecting, and check that Firecrawl is enabled in the **Connectors** menu.
- **Firecrawl appears more than once.** Remove extra entries so a single connector named `firecrawl` remains. Connectors you add in **Customize > Connectors** work in Cowork; local servers in `claude_desktop_config.json` do not, so prefer the connector.
- **Wrong team.** Review or revoke the connection from [MCP settings](https://www.firecrawl.dev/app/settings?tab=mcp), then connect again and choose the right team.
