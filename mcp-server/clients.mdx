## Codex

Add the hosted server and complete the OAuth sign-in:

```bash
codex mcp add firecrawl \
  --url https://mcp.firecrawl.dev/v2/mcp-oauth
codex mcp login firecrawl
```

Start or restart the Codex app, CLI, or IDE extension. Enter `/mcp` to confirm that `firecrawl` is connected.

For an unattended API-key connection, keep the key in an environment variable:

```bash
export FIRECRAWL_API_KEY=fc-YOUR-API-KEY
codex mcp add firecrawl \
  --url https://mcp.firecrawl.dev/v2/mcp \
  --bearer-token-env-var FIRECRAWL_API_KEY
```

To try the keyless tools instead, add `https://mcp.firecrawl.dev/v2/mcp` without the bearer-token option.

## Claude Desktop

Add Firecrawl as a remote custom connector:

1. Open **Settings > Connectors**.
2. Select **Add custom connector**.
3. Enter `https://mcp.firecrawl.dev/v2/mcp-oauth` as the remote MCP server URL.
4. Select **Connect**, then sign in to Firecrawl and approve access.

<Note>
Remote servers must be added from **Settings > Connectors**. The `claude_desktop_config.json` file is for local MCP servers.
</Note>

If you need a local API-key-backed server instead, follow [Run Firecrawl MCP locally](/mcp-server/local).

## Claude Code

Add the hosted OAuth server:

```bash
claude mcp add --transport http firecrawl \
  https://mcp.firecrawl.dev/v2/mcp-oauth
```

Enter `/mcp` in Claude Code, choose `firecrawl`, and complete the browser sign-in.

For an unattended API-key connection, keep the key in an environment variable. Claude Code expands the variable when it connects:

```bash
export FIRECRAWL_API_KEY=fc-YOUR-API-KEY
claude mcp add --transport http firecrawl \
  https://mcp.firecrawl.dev/v2/mcp \
  --header 'Authorization: Bearer ${FIRECRAWL_API_KEY}'
```

To try keyless MCP, use the same `/v2/mcp` command without the `--header` option.

## Cursor

Add the hosted OAuth server to `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

Save the file, open Cursor's MCP settings, and complete the Firecrawl sign-in. Cursor then makes the Firecrawl tools available to Agent.

```json
{
  "inputs": [
    {
      "type": "promptString",
      "id": "apiKey",
      "description": "Firecrawl API key",
      "password": true
    }
  ],
  "servers": {

      "command": "npx",

  }

```

### Windsurf

Add the hosted OAuth server to `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "firecrawl": {
      "serverUrl": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

Save the file, refresh the MCP list, and complete the browser sign-in.

### Google Antigravity

1. Open the Agent sidebar or Agent Manager.
2. Select **More Actions (...) > MCP Servers > View raw config**.
3. Add Firecrawl to `mcp_config.json`:

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp@3.23.0"],
      "env": {
        "FIRECRAWL_API_KEY": "YOUR_FIRECRAWL_API_KEY"
      }
    }
  }
}
```

Save the file and select **Refresh** in the MCP interface.

### n8n

1. Add an **AI Agent** node to your workflow.
2. Add an **MCP Client Tool** to the agent.
3. Set the endpoint to `https://mcp.firecrawl.dev/v2/mcp`.
4. Set **Server Transport** to **HTTP Streamable**.
5. Choose the connection mode:
   - Set **Authentication** to **Bearer** and add your Firecrawl API key for the full tool surface.
   - Set **Authentication** to **None** for keyless Search, Scrape, and Parse.
6. Choose which advertised tools the node can use.

For a self-hosted n8n connection, follow [Run with Streamable HTTP](/mcp-server/local#run-with-streamable-http) and use `http://localhost:3000/mcp` as the endpoint.

## Legacy Smithery installation

For an existing Claude Desktop setup that still uses Smithery:


For a new Claude Desktop connection, use the hosted OAuth setup above.
