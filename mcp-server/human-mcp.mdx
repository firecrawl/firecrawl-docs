<McpClientSelector variant="human" showSeeAll={false} />

<Tabs>
  <Tab title="Claude Desktop">
    1. Open **Settings > Connectors**.
    2. Select **Add custom connector**.
    3. Enter `https://mcp.firecrawl.dev/v2/mcp-oauth` as the remote MCP server URL.
    4. Select **Connect**, then sign in to Firecrawl and approve access.

    <Note>
    Remote servers must be added from **Settings > Connectors**. The `claude_desktop_config.json` file is for local MCP servers.
    </Note>
  </Tab>

  <Tab title="Other clients">
    Point your client at:

    ```text
    https://mcp.firecrawl.dev/v2/mcp-oauth
    ```

    If the client asks for a Client ID or Client Secret, leave both blank.
  </Tab>
</Tabs>

You can review and revoke connections from [MCP settings](https://www.firecrawl.dev/app/settings?tab=mcp).

Need ChatGPT or Claude.ai? Use the [ChatGPT](/developer-guides/mcp-setup-guides/chatgpt) and [Claude.ai](/developer-guides/mcp-setup-guides/claude-ai) guides.

## Can't sign in?

If your client can't complete browser sign-in, use an API key on [Agent MCP](/mcp-server/agent-mcp) instead. Keep the key in the client's environment or secret store. Never put it in a config file, chat, or URL.
