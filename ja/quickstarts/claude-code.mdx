ホスト型 MCP サーバーを介して Claude Code を Firecrawl に接続します。キーがコマンドライン、プロジェクトファイル、会話に入力されないため、OAuth による対話型セットアップを推奨します。

## クイックセットアップ {#quick-setup}

### 1. Firecrawl の追加 {#1-add-firecrawl}

実行：

```bash
claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

`https://mcp.firecrawl.dev/v2/mcp-oauth` はクライアントの構成値であり、ブラウザで直接開くページではありません。

### 2. サインインして確認する {#2-sign-in-and-verify}

Claude Code で `/mcp` を入力し、`firecrawl` を選択してブラウザでサインインを完了します。既存の Firecrawl 接続を変更した場合は、新しい Claude Code セッションを開始してください。

アクティブな `firecrawl` サーバーが 1 つだけであることを確認してから、次を試してください。

```text
Next.js の最新リリースノートを検索して、ソースを要約してください。
```

```text
https://firecrawl.dev をスクレイピングして、どんなサービスなのか説明してください。
```

## その他の接続方法 {#other-connection-modes}

* アカウントやキーなしで Search、スクレイピング、解析を利用するには、[keyless MCP を試す](/ja/mcp-server/keyless#try-keyless)。
* ユーザー操作なしで使用するには、[API キーを設定](/ja/mcp-server/keyless#add-an-api-key)します。シークレットは Agent チャット外で管理し、環境変数を参照してください。
* ローカルプロセスまたはセルフホスト型 Firecrawl API が必要な場合にのみ、[MCP をローカルで実行](/ja/mcp-server/local)してください。ローカルパッケージには Node.js 22 以降が必要です。

## 任意：文献調査 {#optional-literature-research}

論文や文献を扱う場合、research-index スキルは、一般的なウェブ検索ではなく、これらのクエリを `firecrawl_research_*` ツールと[Research Index](/ja/features/research)に振り分けます：

```bash
npx skills add firecrawl/skills@firecrawl-research-index
```

## トラブルシューティング {#troubleshooting}

* **Firecrawl サーバーがすでに存在する場合：** `claude mcp remove firecrawl` を実行し、目的の接続を一度だけ追加してから、新しいセッションを開始します。
* **ブラウザが開かない場合：** `/mcp` を入力し、`firecrawl` を選択して、クライアント側から認証を開始します。
* **サーバーで `401` が表示される場合：** `/mcp` から再度サインインしてください。会話や OAuth URL に API キーを貼り付けないでください。
