Firecrawl を OpenClaw と統合し、エージェントにスクレイピング、検索、クロール、Web との対話、そして Agent ジョブの実行を行う機能を、すべて [Firecrawl CLI](/ja/sdks/cli) 経由で利用できるようにします。

## なぜ Firecrawl + OpenClaw なのか {#why-firecrawl-openclaw}

* **ローカルブラウザは不要** — すべてのセッションはリモートの分離されたサンドボックス上で実行されます。Chromium のインストールも、ドライバーの競合も、マシン上のメモリ負荷もありません。
* **真の並列処理** — 多数のブラウザセッションを同時に実行してもローカルリソースの取り合いがありません。エージェントは複数サイトをまたいでバッチでブラウズできます。
* **標準でセキュア** — ナビゲーション、DOM の評価、抽出はすべて使い捨てサンドボックス内で行われ、あなたのワークステーション上では実行されません。
* **より良いトークン効率** — エージェントは巨大な DOM やドライバーログをコンテキストウィンドウに持ち込むのではなく、クリーンな成果物 (スナップショットや抽出済みフィールド) だけを受け取ります。
* **Web 向けのフル機能ツールキット** — スクレイピング、検索、ブラウザ自動化を、エージェントがすでに使い方を理解している単一の CLI から実行できます。

## セットアップ {#setup}

エージェントに対して、Firecrawl CLI のインストール、認証、およびスキルの初期化を次のコマンドで実行するよう指示してください。

```bash
npx -y firecrawl-cli init --browser --all
```

* `--all` はエージェントの選択をスキップし、検出されたすべてのエージェントを初期化します
* `--browser` は Firecrawl 認証のためにブラウザーを自動的に開きます

または、すべてを個別にインストールすることもできます：

```bash
npm install -g firecrawl-cli
firecrawl setup skills
firecrawl login --browser
# または、ブラウザを使わずAPIキーを直接指定する:
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

すべてが正しく設定されているか確認します：

```bash
firecrawl --status
```

<Tip>
  スキルをインストールすると、OpenClaw エージェントは追加の設定なしで Firecrawl コマンドを自動的に検出して使用します。
</Tip>

## スクレイピング {#scrape}

単一のページをスクレイピングし、その内容を抽出します：

```bash
firecrawl https://example.com --only-main-content
```

特定のフォーマットを取得する：

```bash
firecrawl https://example.com --format markdown,links --pretty
```

## 検索 {#search}

ウェブを検索し、必要に応じて結果をスクレイピングできます。

```bash
firecrawl search "latest AI funding rounds" --limit 10

# 検索結果をスクレイプする
firecrawl search "OpenClaw documentation" --scrape --scrape-formats markdown
```

## Interact {#interact}

ページをスクレイピングした後、そのままライブのブラウザーセッションで操作を続けられます。各セッションは分離されたサンドボックス内でリモート実行されるため、ローカルに Chromium をインストールする必要はありません。`interact` はデフォルトで直近のスクレイピング結果を使用します。

```bash
firecrawl scrape https://news.ycombinator.com
firecrawl interact "What are the titles of the top 3 stories?"
firecrawl interact "Click the More link at the bottom of the page and list the first 3 story titles"
firecrawl interact stop
```

プロンプトの代わりに、ライブページ上でコードを実行します：

```bash
firecrawl interact -c "await page.title()"
firecrawl interact -c "print(await page.title())" --python
```

<Note>
  エージェントはローカルのブラウザーを管理する必要がなく、意図ベースのプロンプトや短い Playwright のスニペットを送信するだけで操作できます。処理が完了したら `firecrawl interact stop` を実行してセッションを解放してください。従来の `firecrawl browser` コマンドは非推奨です。代わりに `scrape` を実行した後に `interact` を使用してください。
</Note>

## 例: エージェントへの指示 {#example-tell-your-agent}

OpenClaw エージェントに対して、次のようなプロンプトを指示できます:

* *「Firecrawl を使って https://example.com をスクレイピングし、主要なコンテンツを要約してください。」*
* *「最新の OpenAI ニュースを検索して、上位 5 件の結果を要約して教えてください。」*
* *「Firecrawl の interact を使って Hacker News を開き、トップ 5 件の記事と、それぞれの最初の 10 件のコメントを取得してください。」*
* *「https://docs.firecrawl.dev のドキュメントをクロールして、ファイルに保存してください。」*
