Firecrawl をリモート HTTP MCP サーバーとして Qwen Code に接続し、Qwen Code からウェブを検索したりページを読み込んだりできるようにします。

## 必要条件 {#requirements}

* Qwen Code 0.25 以降
* [Firecrawl APIキー](https://www.firecrawl.dev/app/api-keys) (環境変数 `FIRECRAWL_API_KEY` としてエクスポートしておくこと)

## クイックセットアップ {#quick-setup}

1. Qwen Code を起動するシェルで、APIキーをエクスポートします：

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

2. サーバーを追加します。シングルクォートで囲むとシェルが変数を展開しないため、設定ファイルにはキーそのものではなく変数への参照が保存されます：

```bash
qwen mcp add --scope user --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp \
  --header 'Authorization: Bearer $FIRECRAWL_API_KEY'
```

3. サーバーに接続できることを確認します：

```bash
qwen mcp list
```

4. Qwen Code を起動して `/mcp` を実行し、Firecrawl のツールが表示されることを確認したら、検索やスクレイピングを依頼します。

<Accordion title="設定ファイルを直接編集したい場合">
  `~/.qwen/settings.json`、またはプロジェクト内の `.qwen/settings.json` にサーバーを追加します。

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "httpUrl": "https://mcp.firecrawl.dev/v2/mcp",
        "headers": {
          "Authorization": "Bearer $FIRECRAWL_API_KEY"
        }
      }
    }
  }
  ```
</Accordion>

キーの詳細については、[APIキーを設定する](/ja/mcp-server/keyless#add-an-api-key)を参照してください。

## トラブルシューティング {#troubleshooting}

* **実行中のセッションにサーバーが表示されない:** サーバーを追加した後、同じプロジェクトで Qwen Code を再起動してください。
* **サーバーが未接続と表示される:** `qwen mcp list` を実行し、Qwen Code を起動するシェルで `FIRECRAWL_API_KEY` がエクスポートされていることを確認してください。
* **無効なキーのためツール呼び出しが拒否される:** ヘッダーの値が `Bearer $FIRECRAWL_API_KEY` になっていること、および変数に有効なキーが設定されていることを確認してください。
* **ツールが使用されない:** MCP ツールを呼び出す安定性はモデルによって異なります。別のモデルを試してください。
