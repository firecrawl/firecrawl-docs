## 前提条件 {#prerequisites}

* Node.js 22.13+
* Firecrawl APIキー — [無料で取得できます](https://www.firecrawl.dev/app/api-keys)
* 対応している[Mastraモデルプロバイダー](https://mastra.ai/models)のAPIキー
* 既存のMastraプロジェクト — まだない場合は、[Mastraクイックスタート](https://mastra.ai/guides/getting-started/quickstart)に従ってセットアップしてください

## SDKをインストール {#install-the-sdk}

```bash
npm install firecrawl
```

## APIキーを設定する {#set-your-api-key}

`.env`にAPIキーを追加します:

```bash
FIRECRAWL_API_KEY=fc-YOUR-API-KEY
```

## Firecrawl ツールを作成する {#build-the-firecrawl-tools}

search と スクレイピング を Mastra ツールとして利用できるようにするため、`src/mastra/tools/firecrawl.ts` を作成します。

```typescript
import { Firecrawl } from "firecrawl";
import { createTool } from "@mastra/core/tools";
import { z } from "zod";

const firecrawl = new Firecrawl();

export const firecrawlSearch = createTool({
  id: "firecrawl-search",
  description: "Search the web and return top results.",
  inputSchema: z.object({ query: z.string().min(1) }),
  outputSchema: z.object({
    results: z.array(
      z.object({
        title: z.string().nullable(),
        url: z.string(),
      }),
    ),
  }),
  execute: async ({ query }) => {
    const results = await firecrawl.search(query, { limit: 3 });
    return {
      results: (results.web ?? []).flatMap((item) =>
        "url" in item ? [{ title: item.title ?? null, url: item.url }] : [],
      ),
    };
  },
});

export const firecrawlScrape = createTool({
  id: "firecrawl-scrape",
  description: "Scrape a URL and return markdown content.",
  inputSchema: z.object({ url: z.string().url() }),
  outputSchema: z.object({ markdown: z.string() }),
  execute: async ({ url }) => {
    const result = await firecrawl.scrape(url, {
      formats: ["markdown"],
      onlyMainContent: true,
    });
    return { markdown: result.markdown ?? "" };
  },
});
```

## エージェントを作成 {#create-the-agent}

`src/mastra/agents/web-agent.ts` を作成し、Firecrawl のツールを設定します。

```typescript
import { Agent } from "@mastra/core/agent";
import { firecrawlSearch, firecrawlScrape } from "../tools/firecrawl";

export const webAgent = new Agent({
  id: "web-agent",
  name: "Web Agent",
  instructions:
    "Use Firecrawl tools to search and scrape web pages, then summarize the results.",
  model: "openai/gpt-5.4",
  tools: { firecrawlSearch, firecrawlScrape },
});
```

## エージェントを登録する {#register-the-agent}

`src/mastra/index.ts` で、Mastra インスタンスにエージェントを登録します。

```typescript
import { Mastra } from "@mastra/core";
import { webAgent } from "./agents/web-agent";

export const mastra = new Mastra({
  agents: { webAgent },
});
```

## Studioでテストする {#test-in-studio}

開発サーバーを起動し、`http://localhost:4111` で [Mastra Studio](https://mastra.ai/docs/studio/overview)を開きます：

```bash
npm run dev
```

**Web Agent** を開き、次のようなプロンプトを試してください。

* &quot;Firecrawl の最新の変更履歴を見つけて、直近のリリースを要約してください。&quot;
* &quot;Firecrawl の料金を検索し、プランの種類を抽出してください。&quot;

## エージェントにホスト型ブラウザーを提供する {#give-the-agent-a-hosted-browser}

クリック、入力、スクロールなどの操作が必要なページでは、Mastraの[`@mastra/browser-firecrawl`](https://mastra.ai/integrations/browsers/firecrawl)パッケージを使うと、エージェントのブラウザーツールがFirecrawlのブラウザセッション上で実行されます。そのため、ローカルにChromiumをインストールする必要はありません。

```bash
npm install @mastra/browser-firecrawl agent-browser@0.19.0
```

<Note>
  `agent-browser` はバージョン 0.19.0 に固定してください。それ以降のリリースには CLI しか含まれていないため、`@mastra/browser-firecrawl` のインポート時に `Cannot find package .../agent-browser/index.js` というエラーが発生します。
</Note>

`src/mastra/agents/browser-agent.ts` を作成し、`webAgent` と同様に `browserAgent` を Mastra インスタンスに登録します：

```typescript
import { Agent } from "@mastra/core/agent";
import { FirecrawlBrowser } from "@mastra/browser-firecrawl";

export const browserAgent = new Agent({
  id: "browser-agent",
  name: "Browser Agent",
  instructions:
    "Use the browser tools to open pages, click, and type. Take a snapshot after each action to check the result.",
  model: "openai/gpt-5.4",
  browser: new FirecrawlBrowser({ apiKey: process.env.FIRECRAWL_API_KEY }),
});
```

デフォルトでは、会話スレッドごとに専用のブラウザセッションが割り当てられます。共有セッション、セッションのタイムアウト、保存済みプロファイルについては、[Mastra Firecrawl ブラウザードキュメント](https://mastra.ai/integrations/browsers/firecrawl)を参照してください。

## セルフホスト版 Firecrawl {#self-hosted-firecrawl}

Firecrawl を自前で運用している場合は、`.env` に `FIRECRAWL_API_URL` を追加してください。SDK はこの値を環境変数から読み込むため、上記のツールに変更を加える必要はありません:

```bash
FIRECRAWL_API_URL=http://localhost:3002
```
