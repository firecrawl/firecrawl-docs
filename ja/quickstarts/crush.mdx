Firecrawl をリモート HTTP MCP サーバーとして Crush に接続し、Crush からウェブ検索やページの読み取りを行えるようにします。

## 要件 {#requirements}

* Crush 0.98 以降
* [Firecrawl APIキー](https://www.firecrawl.dev/app/api-keys) (環境変数 `FIRECRAWL_API_KEY` としてエクスポートしておくこと)

## クイックセットアップ {#quick-setup}

1. Crush を起動するシェルで、APIキーをエクスポートします：

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

2. プロジェクトの `crush.json` にサーバーを追加します。すべてのプロジェクトで使用する場合は、`~/.config/crush/crush.json` に追加してください。

```json
{
  "$schema": "https://charm.land/crush.json",
  "mcp": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer $FIRECRAWL_API_KEY"
      }
    }
  }
}
```

3. Crush を起動し、検索またはスクレイピングを依頼します。

<Accordion title="crushrc ファイルを使用する場合">
  新しい Crush のリリースでは、Bash 形式の `crushrc` ファイルを読み込めます。このファイルでは、MCP サーバーを 1 つのコマンドで追加できます。

  ```bash
  mcp add firecrawl \
    --type http \
    --url "https://mcp.firecrawl.dev/v2/mcp" \
    --header Authorization "Bearer $FIRECRAWL_API_KEY"
  ```

  `crush dirs` を実行すると、お使いのマシンで Crush が構成ファイルを探す場所を確認できます。
</Accordion>

キーの詳細については、[APIキーを構成する](/ja/mcp-server/keyless#add-an-api-key)を参照してください。

## トラブルシューティング {#troubleshooting}

* **サーバーが起動しない:** Crush を起動するシェルで `FIRECRAWL_API_KEY` がエクスポートされていること、および URL が `https://mcp.firecrawl.dev/v2/mcp` と完全に一致していることを確認してください。
* **ヘッダーが削除される:** Crush は、値が空の string に解決されるヘッダーを削除します。`FIRECRAWL_API_KEY` が設定されていないと、この問題が発生します。
* **ツールが使用されない:** MCP ツールをどれだけ確実に呼び出せるかは、モデルによって異なります。別のモデルを試してください。
