ホスト型MCPサーバー経由で、Rovo Dev CLIにFirecrawlを追加します。Rovo Dev CLIはリクエストヘッダーを使ってリモートサーバーに接続するため、このセットアップではFirecrawl APIキーを使用します。

## 前提条件 {#requirements}

* Rovo Dev CLI (Atlassian CLI (`acli`) の拡張機能としてインストールし、`acli rovodev auth login` でサインインしておくこと)
* [Firecrawl APIキー](https://www.firecrawl.dev/app/api-keys)

## クイックセットアップ {#quick-setup}

1. `acli rovodev mcp` を実行し、デフォルトのエディターで `~/.rovodev/mcp.json` を開きます。
2. Firecrawl の設定を追加し、キーを置き換えて保存します：

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "transport": "http",
      "headers": {
        "Authorization": "Bearer fc-YOUR-API-KEY"
      }
    }
  }
}
```

3. `acli rovodev run` で Rovo Dev を開始して `/mcp` と入力し、`firecrawl` とそのツールが一覧に表示されていることを確認します。

<Accordion title="ローカルサーバーを使用したい場合">
  Rovo Dev CLI は stdio サーバーも起動できます。[MCP をローカルで実行](/ja/mcp-server/local)の手順に従い、同じファイルにコマンドを定義します。

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "command": "npx",
        "args": ["-y", "firecrawl-mcp@3.33.2"],
        "env": {
          "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
        },
        "transport": "stdio"
      }
    }
  }
  ```
</Accordion>

このファイルにはキーが含まれるため、非公開にしておいてください。キーを使用した接続の詳細は、[APIキーを設定する](/ja/mcp-server/keyless#add-an-api-key)を参照してください。

## トラブルシューティング {#troubleshooting}

* **`/mcp` に Firecrawl が表示されない:** JSON が正しい形式であること、およびホスト型URLの場合は `transport` が `"http"` に設定されていることを確認してください。
* **サーバーに `401` が表示される:** `mcp.json` のキーを置き換えてから、`acli rovodev run` を再起動してください。
* **Firecrawl は表示されるが無効化されている:** `/mcp` を開いて有効にしてください。また、`~/.rovodev/config.yml` の `disabledMcpServers` に含まれていないことも確認してください。
* **サーバーの指示を使用しない場合:** Firecrawl のエントリに `"enable_instructions": false` を設定してください。
