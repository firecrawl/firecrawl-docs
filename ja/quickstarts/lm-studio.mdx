ホスト型MCPサーバーを通じて Firecrawl の検索、スクレイピング、クロールの各ツールを [LM Studio](https://lmstudio.ai) に追加すると、ローカルモデルからリアルタイムのウェブ情報を参照できるようになります。

LM Studio 0.3.17 以降は MCP ホストとして動作し、Cursor と同じ記法の `mcp.json` ファイルからサーバー設定を読み込みます。

## クイックセットアップ {#quick-setup}

1. [Firecrawl APIキーを作成します](https://www.firecrawl.dev/app/api-keys)。
2. LM Studio の右サイドバーで **Program** タブを開き、**Install &gt; Edit mcp.json** を選択します。
3. `mcpServers` に Firecrawl を追加して保存します。

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

`mcp.json` にすでに他のサーバーが記載されている場合は、`"firecrawl": { ... }` エントリのみを既存の `mcpServers` オブジェクトに追加してください。

ファイルを保存すると、LM Studio がサーバーを読み込みます。ツール使用に対応したモデルでチャットを開き、チャットのツール一覧に `firecrawl_search` と `firecrawl_scrape` が表示されていることを確認してください。

APIキーが共有するスクリーンショットやソース管理に含まれないよう注意してください。LM Studio は `mcp.json` をホームディレクトリ内のデータフォルダ (`~/.lmstudio/mcp.json`) に保存します。

## キーの代わりにサインインを使用する {#sign-in-instead-of-using-a-key}

LM Studio は、リモートサーバー向けの MCP OAuth をサポートしています。サーバーの `url` に `https://mcp.firecrawl.dev/v2/mcp-oauth` を `headers` なしで追加し、ブラウザーで sign-in の手順に従ってください。詳しくは[人間向け](/ja/mcp-server/oauth)を参照してください。

## ローカルサーバーを実行する場合 {#run-the-local-server-instead}

自分のマシンで Firecrawl を実行するには、`url` エントリの代わりに、npm パッケージを起動する `command` エントリを追加します。最新のコマンドとオプションについては、[ローカル MCP サーバーガイド](/ja/mcp-server/local)を参照してください。

## トラブルシューティング {#troubleshooting}

* **ツールが表示されない:** モデルがツール使用に対応していることを確認したうえで、`mcp.json` が有効な JSON であること、`firecrawl` エントリが `mcpServers` の中にあることを確認してください。
* **認証に失敗する:** ヘッダーが `Bearer` + 半角スペース1つ + キーの形式になっていること、またそのキーが [Firecrawl ダッシュボード](https://www.firecrawl.dev/app/api-keys)で有効になっていることを確認してください。
* **モデルの動作が遅くなる、またはコンテキストが不足する:** Firecrawl のツールは長いページを返すことがあります。特定の URL を指定するか、より大きなコンテキストウィンドウを持つモデルを使用するか、必要なツールのみを有効にしてください。
* **ツール呼び出しを確認する:** LM Studio では、デフォルトで MCP ツールの実行前に確認が求められます。MCP サーバーは信頼できるソースからのみインストールしてください。
