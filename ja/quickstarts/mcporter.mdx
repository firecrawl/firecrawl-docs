MCP サーバー向けの TypeScript ランタイム兼 CLI である [MCPorter](https://mcporter.sh) を、ホスト型MCPサーバー経由で Firecrawl に接続します。

## クイックセットアップ {#quick-setup}

[Firecrawl APIキーを作成](https://www.firecrawl.dev/app/api-keys)し、環境変数としてエクスポートします。

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

Firecrawl をプロジェクト内の `config/mcporter.json` に追加します。すべてのプロジェクトで使用する場合は、`~/.mcporter/mcporter.json` に追加してください。

```json
{
  "mcpServers": {
    "firecrawl": {
      "baseUrl": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": { "Authorization": "Bearer ${FIRECRAWL_API_KEY}" }
    }
  }
}
```

MCPorter は `${FIRECRAWL_API_KEY}` を環境変数の値に置き換えるため、キーをファイルに直接記述せずに済みます。接続を確認します：

```bash
npx mcporter list firecrawl
```

ローカルプロセスで実行したい場合は、代わりに stdio 形式を使用してください：

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": { "FIRECRAWL_API_KEY": "${FIRECRAWL_API_KEY}" }
    }
  }
}
```

## 試してみる {#try-it}

```bash
npx mcporter call firecrawl.firecrawl_scrape url=https://firecrawl.dev 'formats=["markdown"]'
```

このコマンドはページを Markdown 形式で出力します。同じエントリをコードから使用するには `createRuntime` を使います ([MCPorter のドキュメント](https://mcporter.sh)を参照) 。

## トラブルシューティング {#troubleshooting}

* **サーバーが見つからない:** `npx mcporter config list` を実行し、MCPorter がどの設定ファイルを読み込んだかを確認してください。`--config <file>` または `MCPORTER_CONFIG` で指定できるのは 1 つのファイルのみです。
* **認証エラー:** MCPorter は `${env:VAR}` 形式に対応していません。プレースホルダーは `${FIRECRAWL_API_KEY}` の形式で記述し、同じシェルで変数がエクスポートされていることを確認してください。
* **ツールの引数が拒否される:** 上記の `formats` の例のように、JSON の値は使用しているシェルに合わせてクォートして渡してください。
