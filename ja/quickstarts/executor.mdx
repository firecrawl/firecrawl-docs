Firecrawl のホスト型MCPサーバーを [Executor](https://executor.sh) に追加すると、Executor に接続されたすべてのエージェントが、単一のエンドポイントからウェブの検索とスクレイピングを行えるようになります。

<Note>
  この手順は Executor 1.x (`npm install -g executor`) を対象としています。Executor 2 (ベータ版) では、MCP サーバーをアプリおよびアカウントとして管理します。その場合の手順については、[Executor のドキュメント](https://executor.sh/docs)を参照してください。
</Note>

## クイックセットアップ {#quick-setup}

[Firecrawl APIキーを作成](https://www.firecrawl.dev/app/api-keys)したら、Executorを起動します。

```bash
npm install -g executor
executor web
```

ウェブ UI でインテグレーションを追加し、カタログから **Firecrawl** を選択するか、MCP URL を直接入力します。

```text
https://mcp.firecrawl.dev/v2/mcp
```

Executor が MCP サーバーを検出し、そのツールをインデックス化します。認証情報の入力を求められたら、Firecrawl APIキーを入力してください。これにより、リクエストに `Authorization: Bearer <key>` ヘッダーが付与されます。

事前にコマンドラインからサーバーを確認することもできます:

```bash
executor call executor mcp probeEndpoint '{"endpoint":"https://mcp.firecrawl.dev/v2/mcp","headers":{"Authorization":"Bearer '"$FIRECRAWL_API_KEY"'"}}'
```

次に、エージェントを Executor 自体の MCP エンドポイント(ローカルサーバーの場合は `http://127.0.0.1:4788/mcp`)に接続します。

```bash
npx add-mcp http://127.0.0.1:4788/mcp --transport http --name executor
```

`executor tools integrations` を実行し、`firecrawl` が一覧に表示されていて、ツール数が 1 以上であることを確認します。

## トラブルシューティング {#troubleshooting}

* **ツール数が0になる：** Executorはアカウントごとにツールを作成します。APIキーでFirecrawlアカウントの接続を完了してから、ソースを更新してください。
* **サーバー追加コマンドが一時停止する：** ExecutorはMCP サーバーを追加する際に承認を求めます。`executor resume --execution-id <id> --action accept --content '{}'` を実行して承認してください。
* **エージェントがツールを認識しない：** ほとんどのクライアントはMCP サーバーを起動時に読み込みます。Executorを追加したら、クライアントを再起動するか、新しいセッションを開いてください。
