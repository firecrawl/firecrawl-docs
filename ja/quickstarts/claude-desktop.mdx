Claude Desktop、Cowork、Code タブはいずれも Claude アカウントからコネクターを読み込みます。Firecrawl をサーバー名 `firecrawl` で一度接続すれば、すべてのタブで利用できます。

| 設定            | 値                                                                             |
| ------------- | ----------------------------------------------------------------------------- |
| サーバー名         | `firecrawl`                                                                   |
| カスタムコネクタの URL | `https://mcp.firecrawl.dev/v2/mcp-oauth` (ディレクトリのコネクターではなくカスタムコネクタを追加する場合のみ)  |
| sign-in       | ブラウザーで Firecrawl に sign-in し、Team を承認                                         |

`https://mcp.firecrawl.dev/v2/mcp-oauth` はクライアント側で設定する構成値です。ブラウザーで直接開くページではありません。

1. Claude のコネクター名簿で [Firecrawlコネクター](https://claude.ai/directory/connectors/firecrawl) を開くか、Claude Desktop で **Customize &gt; コネクター** に移動して Firecrawl を検索します。
2. **Connect** をクリックします。ブラウザーで Firecrawl が開きます。
3. Firecrawl にサインインし、Team を選択してアクセスを承認します。

Team プランまたはエンタープライズプランでは、メンバーが接続できるようにするために、組織の Owner がコネクターを許可しておく必要がある場合があります。

<Accordion title="名簿のコネクターを使用できない場合は、カスタムコネクタを追加します">
  1. Claude Desktop で **Customize &gt; コネクター** に移動します。
  2. **Add** をクリックし、カスタムコネクタを追加します。
  3. 名前に `firecrawl`、リモート MCP サーバーのサーバーURLに `https://mcp.firecrawl.dev/v2/mcp-oauth` を入力します。
  4. 検出された sign-in 設定は変更せずにコネクターを追加し、**Connect** をクリックしてブラウザーでサインインを完了します。

  組織の Owner の場合は、**Organization settings &gt; コネクター** からカスタムコネクタを追加します。
</Accordion>

## 2. Cowork とチャットで使用する {#2-use-it-in-cowork-and-chat}

Cowork または Chat タブで、プロンプト入力欄の横にある **+** メニューを開き、**コネクター** を選択して、Firecrawl が有効になっていることを確認します。続いて、次のように試してみてください。

```text
Firecrawl を使って Next.js の最新リリースノートを検索し、各ソースの内容を要約してください。
```

```text
https://firecrawl.dev をスクレイピングして、その機能を説明してください。
```

## 3. Codeタブで使用する {#3-use-it-in-the-code-tab}

ローカルのCodeタブのセッションでも、同じコネクターを使用できます。プロンプト入力欄の横にある **+** ボタンをクリックし、**コネクター** を選択して Firecrawl を有効にします。

Codeタブでは、`claude mcp add` などでClaude Codeに追加したMCP サーバーも読み込まれます。[Claude Codeガイド](/ja/quickstarts/claude-code)の手順ですでにClaude CodeにFirecrawlを設定済みの場合は、サーバー名を `firecrawl` のままにし、セッション内で有効なFirecrawlサーバーが1つだけであることを確認してください。

## トラブルシューティング {#troubleshooting}

* **Firecrawl のツールが表示されない。** 接続後に新しい会話またはセッションを開始し、**コネクター** メニューで Firecrawl が有効になっているか確認してください。
* **Firecrawl が複数表示される。** 余分なエントリを削除し、`firecrawl` という名前のコネクターが1つだけ残るようにしてください。**Customize &gt; コネクター** で追加したコネクターは Cowork で利用できますが、`claude_desktop_config.json` に設定したローカルサーバーは利用できません。そのため、コネクターを使用することをおすすめします。
* **別の Team に接続されている。** [MCP設定](https://www.firecrawl.dev/app/settings?tab=mcp)で接続を確認または取り消し、改めて接続して正しい Team を選択してください。
