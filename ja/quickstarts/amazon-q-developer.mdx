ホスト型MCPサーバーを介して、VS Code、JetBrains、その他の対応 IDE の Amazon Q Developer に Firecrawl を接続します。Q Developer がブラウザーを開くので、Firecrawl アカウントでサインインしてください。

<Note>
  Amazon Q Developer CLI は Kiro CLI に名称が変更されました。ターミナルで使用する場合は、[Kiro のセットアップ](/ja/quickstarts/kiro)の手順に従ってください。
</Note>

## クイックセットアップ {#quick-setup}

1. IDE を開き、Q Developer パネルを開いてから **Chat** パネルを開きます。
2. ツールアイコンを選択し、続いてプラス (+) ボタンを選択します。
3. スコープを選択します。**global** を選択するとサーバー設定が `~/.aws/amazonq/default.json` に保存され、**local** を選択するとプロジェクト内の `.amazonq/default.json` に保存されます。
4. 名前に `firecrawl` と入力し、トランスポートに **http** を選択して、次の URL を入力します。

```text
https://mcp.firecrawl.dev/v2/mcp-oauth
```

5. **保存** を選択します。アクセスを承認するためのブラウザーページが Q Developer によって開かれます。Firecrawl にサインインし、接続を承認してください。
6. 保存後に表示されるパネルで、各ツールの権限 (**Ask**、**Always allow**、**Deny**) を確認します。

<Accordion title="構成ファイルを直接編集したい場合">
  Q Developer は、`~/.aws/amazonq/mcp.json` (グローバル) および `.amazonq/mcp.json` (プロジェクト) からも MCP サーバーを読み込みます。

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
      }
    }
  }
  ```

  `mcp.json` ファイルを読み込むかどうかは、`default.json` の `useLegacyMcpJson` フィールドで制御されます。デフォルト値は `true` です。
</Accordion>

<Accordion title="APIキーを使用したい場合">
  同じダイアログで、名前が `Authorization`、値が `Bearer fc-YOUR-API-KEY` のヘッダーを追加し、URL には `https://mcp.firecrawl.dev/v2/mcp` を指定します。詳しくは [APIキーを構成する](/ja/mcp-server/keyless#add-an-api-key) を参照してください。
</Accordion>

詳細は [OAuth 接続ガイド](/ja/mcp-server/oauth) を参照してください。

## トラブルシューティング {#troubleshooting}

* **「Fix Configuration」アラートが表示される場合:** アラートを選択してフォームに戻り、URL を確認してください。
* **ブラウザーのページが開かない場合:** 対象のサーバーで **Edit setup** を選択して再度保存し、ページが開いたら認可を完了してください。
* **サーバーは一覧に表示されるが、ツールが実行されない場合:** MCP サーバー パネルでサーバーを開き、サーバーが有効になっていること、およびツールが **Deny** に設定されていないことを確認してください。
* **Firecrawl のエントリーが 2 つある場合:** `.amazonq/default.json` 内のサーバーはグローバル設定のサーバーより優先されます。不要なほうのエントリーを削除してください。
