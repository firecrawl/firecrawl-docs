ホスト型 MCP サーバーを通じて、Firecrawl のキーレス Search、スクレイピング、Parse ツールを Windsurf に追加します。

Windsurf は [Devin Desktop](https://devin.ai/desktop) に名称が変わりました。Devin Local エージェントと従来の Cascade エージェントは、どちらも同じ設定ファイルから MCP サーバーを読み込みます。

## クイックセットアップ {#quick-setup}

`~/.config/devin/mcp_config.json` (Windows の場合は `%APPDATA%\devin\mcp_config.json`) を編集します。

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

または、Devin CLI で追加することもできます。

```bash
devin mcp add -s user firecrawl https://mcp.firecrawl.dev/v2/mcp
```

Devin Desktop を再起動し、`firecrawl_search`、`firecrawl_scrape`、`firecrawl_parse` が利用可能であることを確認します。

キーレスアクセスには、同じパブリック IP を使用するユーザー間で共有される利用制限があります。対話型クライアントからサインインするには [For Humans](/ja/mcp-server/oauth) を、ユーザー操作なしで利用するには [API キーを追加](/ja/mcp-server/keyless#add-an-api-key) してください。

## 試す {#try-it}


```text
https://firecrawl.dev をスクレイピングして、その機能を説明する。
```

## トラブルシューティング {#troubleshooting}

* **サーバーに接続できない:** hosted URLを確認したうえで、エージェントのMCPリストでサーバーを確認するか、`devin mcp list` を実行してください。
* **クロールや他のツールが見当たらない:** キーレスで利用できるのはSearch、スクレイピング、Parseのみです。より多くのツールを利用するには、OAuthまたはAPIキーで接続してください。
