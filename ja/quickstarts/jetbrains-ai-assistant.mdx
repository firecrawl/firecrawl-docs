IntelliJ IDEA、PyCharm、WebStorm などの JetBrains IDE の AI Assistant に Firecrawl を追加します。AI Assistant は、お使いの APIキーを使用して Firecrawl MCP サーバーをローカルプロセスとして起動します。

## 要件 {#requirements}

* AI Assistant 2025.1 以降を搭載した JetBrains IDE (MCP クライアントのサポートはこのリリースで追加されました) 。
* Node.js 22 以降 (サーバーは `npx` 経由で実行されるため、`PATH` が通っている必要があります) 。
* [Firecrawl APIキー](https://www.firecrawl.dev/app/api-keys)。

## クイックセットアップ {#quick-setup}

1. **Settings**、**Tools**、**AI Assistant**、**Model Context Protocol (MCP)** の順に開きます。
2. **Add** を選択します。
3. 次の JSON を貼り付けてキーを置き換え、**Server level** をグローバルまたは現在のプロジェクトに設定します。

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp@3.33.2"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
      }
    }
  }
}
```

4. **OK** を選択してから **Apply** を選択します。**Status** 列に接続が表示され、ツールアイコンから Firecrawl のツール一覧を確認できます。
5. サーバーを自動で開始したい場合は、**Automatically enable new and changed MCP servers** を有効にします。

<Accordion title="リモート接続を使用する場合">
  現在の AI Assistant のドキュメントには、同じ JSON 内の `url` エントリで設定する Streamable HTTP サーバーも記載されています。ただし、リクエストヘッダーやブラウザーでの sign-in フローについては記載がないため、IDE にこれらのオプションが表示されない限り、Firecrawl では上記のローカルセットアップを使用してください。
</Accordion>

環境変数の一覧については、[MCP をローカルで実行する](/ja/mcp-server/local)を参照してください。

## トラブルシューティング {#troubleshooting}

* **ステータスが赤のまま変わらない:** ターミナルで `node --version` を実行し、22 以上のバージョンが表示されることを確認してください。Node.js のインストール後は、新しい `PATH` が反映されるように IDE を再起動してください。
* **`spawn npx ENOENT`:** IDE が `npx` を見つけられていません。`npx` が動作するシェルから IDE を起動するか、コマンドに `npx` のフルパスを指定してください。
* **サーバーに `401` と表示される:** `FIRECRAWL_API_KEY` の値を正しいものに置き換え、もう一度 **Apply** を選択してください。
* **ログ:** MCP設定ページにログフォルダーへのリンクがあります。ログはサーバーごとに 1 つずつ保存されます。
