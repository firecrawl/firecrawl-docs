ホスト型 MCP サーバーを通じて Firecrawl を Cursor に接続し、Firecrawl アカウントでサインインします。

<CursorInstallButton />

## クイックセットアップ {#quick-setup}

1. 上の **Add to Cursor** をクリックして、Cursor でインストールダイアログを開きます。
2. Firecrawl MCP サーバーのインストールを承認します。
3. Cursor でサーバーのサインインオプションを使って Firecrawl アカウントに接続し、アクセスを承認します。
4. Cursor で Firecrawl のツールが使用できることを確認します。

<Accordion title="構成を手動で追加したい場合">
  Cursor の設定を開き、**MCP** を選択して、以下を追加します。

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
      }
    }
  }
  ```

  構成を保存したら、Cursor からブラウザでのサインインを完了します。
</Accordion>

詳しくは [OAuth 接続ガイド](/ja/mcp-server/oauth)を参照してください。ユーザー操作なしで使用する場合は、[APIキーを設定](/ja/mcp-server/keyless#add-an-api-key)してください。

## トラブルシューティング {#troubleshooting}

* **サーバーに接続できない:** URL が `https://mcp.firecrawl.dev/v2/mcp-oauth` と完全に一致していることを確認し、Cursor の MCP ステータスを確認してください。
* **サインインを求められる、またはセッションが期限切れになる:** Cursor の MCP 設定から認証をやり直してください。
* **別の Firecrawl 接続がすでに存在する:** 既存のサーバーの URL を OAuth 用の URL に変更してサインインし、有効な Firecrawl サーバーが 1 つだけになるようにしてください。
