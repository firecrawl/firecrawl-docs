ホスト型 MCP サーバーを通じて、Firecrawl のキーなしの Search、Scrape、Parse ツールを Cursor に追加します。

<div id="quick-setup">
  ## クイックセットアップ
</div>

Cursorの設定を開き、**MCP** を選択して、以下を追加します。

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Cursorを再起動し、`firecrawl_search`、`firecrawl_scrape`、`firecrawl_parse`が利用できることを確認します。

キーなしアクセスには、同じパブリックIPを使用するユーザー間で共有される制限があります。対話型クライアントから[For Humans](/ja/mcp-server/oauth)でサインインするか、ユーザー操作なしで利用する場合は[APIキーを追加](/ja/mcp-server/keyless#add-an-api-key)してください。

<div id="troubleshooting">
  ## トラブルシューティング
</div>

* **サーバーに接続できない:** URL が `https://mcp.firecrawl.dev/v2/mcp` と完全に一致していることを確認し、Cursor の MCP ステータスを確認してください。
* **クロールなどのツールが表示されない:** キーなしで利用できるのは Search、Scrape、Parse のみです。より幅広いツールを利用するには、OAuth または API キーで接続してください。
