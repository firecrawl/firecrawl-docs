ホスト型MCPサーバー経由で、Firecrawl の検索、スクレイピング、その他のウェブツールを [Cherry Studio](https://cherry-ai.com) に追加できます。

Cherry Studio はカスタムヘッダーを使用したリモート Streamable HTTP サーバーに対応しているため、Firecrawl APIキーで接続できます。

## クイックセットアップ {#quick-setup}

1. [Firecrawl APIキーを作成します](https://www.firecrawl.dev/app/api-keys)。
2. Cherry Studio で **設定 → MCP → MCP サーバー** を開き、**Add** を選択します。
3. **Import from JSON** を選択し、以下を貼り付けます。その際、`<FIRECRAWL_API_KEY>` はご自身のキーに置き換えてください:

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "streamableHttp",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

4. サーバーを有効にし、ステータスが正常 (healthy) になるまで待機します。その後、詳細を開いて `firecrawl_search` と `firecrawl_scrape` が一覧に表示されていることを確認します。
5. **Work** を開いて Agent を編集し、**MCP** に移動して Firecrawl サーバーを有効にします。これで Agent がこのサーバーを使用できるようになります。

**Quick Create** を使用して、型を **Streamable HTTP**、URL を `https://mcp.firecrawl.dev/v2/mcp`、ヘッダーを `Authorization=Bearer <FIRECRAWL_API_KEY>` に設定する方法もあります。

ローカルサーバーを使用する場合は、型に `stdio`、コマンドに `npx`、引数に `-y` と `firecrawl-mcp` を指定し、環境変数 `FIRECRAWL_API_KEY` を設定します。詳しくは [ローカル MCP サーバーガイド](/ja/mcp-server/local)を参照してください。

`Authorization` ヘッダーを設定していない場合は、Cherry Studio から OAuth でリモートサーバーにサインインすることもできます。Firecrawl の OAuth エンドポイントについては、[For Humans](/ja/mcp-server/oauth) を参照してください。

## トラブルシューティング {#troubleshooting}

* **サーバーに接続できない:** 型が Streamable HTTP になっていること、URL が `https://mcp.firecrawl.dev/v2/mcp` と完全に一致していること、ヘッダーが `Authorization: Bearer <FIRECRAWL_API_KEY>` になっていることを確認してください。サーバーログはサーバーの詳細ページで確認できます。
* **チャットにツールが表示されない:** サーバーが起動しており、かつ Agent で有効化されている必要があります。**Work → Agent → Edit → MCP** を確認してください。
* **一部のツールが見つからない:** サーバーの詳細を開いて公開されているツールを確認し、あわせて APIキーが有効かどうかも確認してください。
