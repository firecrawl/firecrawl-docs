ホスト型MCPサーバーを使用して、Firecrawl の検索、スクレイピングなどのウェブツールを [Kimi Code CLI](https://www.kimi.com/code/docs/en/kimi-code-cli/getting-started.html) に追加します。

## クイックセットアップ {#quick-setup}

[Firecrawl APIキーを作成](https://www.firecrawl.dev/app/api-keys)したら、次の内容を `~/.kimi-code/mcp.json` (プロジェクト単位で設定する場合は `.kimi-code/mcp.json`) に追加します。

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

キーをファイルに直接記述しないようにするには、キーを環境変数としてエクスポートし、`headers` の代わりにその変数を参照します：

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "bearerTokenEnvVar": "FIRECRAWL_API_KEY"
    }
  }
}
```

`/mcp-config` を使って、対話形式でサーバーを追加することもできます。新しい Kimi Code セッションを開始して `/mcp` を実行し、`firecrawl` が接続済みであること、および `firecrawl_search` や `firecrawl_scrape` などのツールが一覧に表示されていることを確認してください。

APIキーではなくブラウザーでサインインするには、`headers` を指定せずに URL として `https://mcp.firecrawl.dev/v2/mcp-oauth` を設定し、`/mcp-config login firecrawl` を実行します。詳しくは[人間向け](/ja/mcp-server/oauth)を参照してください。

## トラブルシューティング {#troubleshooting}

* **ツールが表示されない:** MCP サーバーはセッションの開始時に読み込まれるため、`mcp.json` を編集した後は新しいセッションを開いてください。セッションの途中で追加したサーバーは、次回以降のセッションから利用できます。
* **サーバーに接続できない:** `/mcp` を実行してステータスを確認し、URL と APIキーが正しいかを確認してください。`bearerTokenEnvVar` を使用する場合は、`kimi` を起動するシェルでその変数を設定しておく必要があります。
* **プロジェクトレベルの設定が無視される:** 信頼されていないフォルダーでは、プロジェクトの `.kimi-code/mcp.json` に定義されたサーバーは無効化されたままになります。フォルダーを信頼済みにするか、ヘッドレスで実行する場合は `KIMI_CODE_TRUST_WORKSPACE=1` を設定してください。
* **ローカルサーバーを使いたい:** Kimi Code では、`env` に `FIRECRAWL_API_KEY` を設定して `npx -y firecrawl-mcp` を実行することもできます。詳しくは[ローカルで実行](/ja/mcp-server/local)を参照してください。
