JetBrains IDE と VS Code の Zencoder に Firecrawl を追加します。JetBrains は OAuth2 によるリモートサーバーに対応しているため、Firecrawl アカウントでサインインして利用できます。VS Code では、APIキーを使用してサーバーをローカルで起動します。

## 要件 {#requirements}

* JetBrains IDE または VS Code 用の Zencoder プラグイン
* VS Code でセットアップする場合：Node.js 22 以降と [Firecrawl APIキー](https://www.firecrawl.dev/app/api-keys)

## クイックセットアップ {#quick-setup}

<Tabs>
  <Tab title="JetBrains">
    1. **設定** を開き、**Tools** → **Zencoder** → **MCP サーバー** の順に移動します。
    2. 次のサーバーを追加し、変更を適用します。

    ```json
    {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth",
        "auth": "oauth2"
      }
    }
    ```

    3. ブラウザーで Firecrawl の sign-in を完了したら、エージェントのツール一覧にツールが表示されていることを確認します。
  </Tab>

  <Tab title="VS Code">
    1. ユーザーまたはワークスペースの `settings.json` を開きます。
    2. `zencoder.mcpServers` に Firecrawl を追加します。

    ```json
    {
      "zencoder.mcpServers": {
        "firecrawl": {
          "command": "npx",
          "args": ["-y", "firecrawl-mcp@3.33.2"],
          "env": {
            "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
          }
        }
      }
    }
    ```

    3. VS Code を再起動し、**エージェントツール** に Firecrawl のツールが表示されていることを確認します。
  </Tab>
</Tabs>

Zencoder のドキュメントによると、VS Code での HTTP サーバーおよび OAuth2 サーバーのサポートは順次展開中です。お使いのバージョンで利用可能になるまでは、ローカルセットアップを使用してください。詳しくは、[OAuth 接続ガイド](/ja/mcp-server/oauth) と [MCP をローカルで実行する](/ja/mcp-server/local) を参照してください。

## トラブルシューティング {#troubleshooting}

* **サーバーがエージェントツールに表示されない：** JSON の構文を確認し、IDE を再起動してください。MCP サーバーは起動時に読み込まれます。
* **JetBrains で sign-in に失敗する：** サーバーのキャッシュ済みトークンを削除してから、sign-in をやり直してください。
* **VS Code でコマンドが見つからないというエラーが出る：** ターミナルで `npx` が動作すること、また `node --version` の出力が 22 以上であることを確認してください。
* **ツールが実行されない：** Zencoder はツール呼び出しの前に許可を求めます。Firecrawl のツールに対して **Allow once** または **Always allow** を選択してください。
