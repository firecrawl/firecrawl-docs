xAIのコーディングエージェントCLI (`grok`) である[Grok Build](https://docs.x.ai/build/overview)を、ホスト型MCPサーバー経由でFirecrawlに接続します。対話型のセットアップにはOAuthを推奨します。OAuthを使えば、キーをコマンドラインやプロジェクトファイル、会話に含める必要がありません。

## クイックセットアップ {#quick-setup}

### 1. Firecrawl を追加する {#1-add-firecrawl}

次のコマンドを実行します：

```bash
grok mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

`https://mcp.firecrawl.dev/v2/mcp-oauth` はクライアントに設定する構成値です。ブラウザーで直接開くページではありません。

### 2. サインインして確認する {#2-sign-in-and-verify}

Grok Build を開始します：

```bash
grok
```

`/mcps` と入力して `firecrawl` を選択し、`i` を押してブラウザーでの sign-in を開始します。Team を選択し、接続を承認してください。Grok は OAuth トークンを `~/.grok/mcp_credentials.json` に保存します。

有効な `firecrawl` サーバーが 1 つだけであることを確認したら、次を試してください。

```text
Next.js の最新リリースノートをウェブで検索し、参照したソースの内容を要約してください。
```

```text
https://docs.firecrawl.dev をスクレイピングして、トップレベルのセクションを一覧表示してください。
```

## APIキーを使用したローカルMCP {#local-mcp-with-an-api-key}

ローカルサーバーは、ローカルプロセスまたはセルフホスト型 Firecrawl API が必要な場合にのみ使用してください。ローカルパッケージには Node.js 22 以降が必要です。

Grok を開始する環境で `FIRECRAWL_API_KEY` を設定します。次に、以下のブロックを `~/.grok/config.toml` に追加します。

```toml
[mcp_servers.firecrawl]
command = "npx"
args = ["-y", "firecrawl-mcp@3.33.2"]
env = { FIRECRAWL_API_KEY = "${FIRECRAWL_API_KEY}" }
startup_timeout_sec = 60
```

Grok は構成の読み込み時に `${FIRECRAWL_API_KEY}` を展開するため、キーがファイルに書き込まれることはありません。シークレットはエージェントとのチャットやソース管理に含めないようにしてください。`firecrawl` エントリは 1 つだけにする必要があるため、先に `grok mcp remove firecrawl` でホスト型サーバーを削除してください。

セルフホスト型の設定については、[MCP をローカルで実行する](/ja/mcp-server/local)を参照してください。

## その他の接続モード {#other-connection-modes}

* [キーなしMCPを試す](/ja/mcp-server/keyless#try-keyless)：アカウントやキーがなくても、検索、スクレイピング、解析を使用できます。
* [APIキーを設定する](/ja/mcp-server/keyless#add-an-api-key)：ホスト型サーバーをユーザー操作なしで使用する場合に設定します。シークレットはエージェントとのチャットに貼り付けず、環境変数の参照を使用してください。

## トラブルシューティング {#troubleshooting}

* **Firecrawl サーバーがすでに存在する場合:** `grok mcp remove firecrawl` を実行し、使用したい接続を一度だけ追加してから、新しいセッションを開始してください。
* **Grok に `firecrawl` サーバーが 2 つ表示される場合:** Grok は `~/.claude.json`、`.cursor/mcp.json`、およびプロジェクトの `.mcp.json` ファイルからも MCP サーバーを読み込みます。`grok inspect` を実行して各サーバーの読み込み元を確認し、重複している方を削除してください。
* **サーバーに `401` と表示される場合:** `/mcps` と入力して `firecrawl` を選択し、`i` を押して再度サインインしてください。APIキーを会話や OAuth URL に貼り付けないでください。
* **ローカルサーバーが接続されない場合:** `grok mcp doctor firecrawl` を実行してください。サーバーのエラーは `~/.grok/logs/mcp/firecrawl.stderr.log` に出力されます。初回起動時に `npx` がパッケージをダウンロードする場合は、`startup_timeout_sec` の値を大きくしてください。
