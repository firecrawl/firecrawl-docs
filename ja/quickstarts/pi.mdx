ホスト型MCPサーバーを使って、Firecrawl の検索、スクレイピング、クロール、マップの各ツールを [Pi](https://pi.dev) に追加します。

## クイックセットアップ {#quick-setup}

[Firecrawl APIキーを作成](https://www.firecrawl.dev/app/api-keys)し、Pi から読み取れるように環境変数としてエクスポートします。

```bash
export FIRECRAWL_API_KEY=fc-YOUR_API_KEY
```

Pi の組み込み MCP コマンドでサーバーを追加します:

```bash
pi mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp --bearer-token-env-var FIRECRAWL_API_KEY
```

これにより、エントリが `~/.pi/agent/mcp.json` に書き込まれます。手動で貼り付けることもできます。特定のプロジェクトでのみ使用する場合は、`.pi/mcp.json` に記述してください：

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer ${FIRECRAWL_API_KEY}"
      }
    }
  }
}
```

`pi mcp list` を実行し、`firecrawl` が接続済みと表示され、`firecrawl_search` や `firecrawl_scrape` などのツールが一覧に含まれていることを確認します。次に `pi` を開始します。すでにセッションを開いている場合は、`/reload` を実行してください。

[pi-mcp-adapter](https://github.com/nicobailon/pi-mcp-adapter) を使用している場合は、同じエントリを `~/.config/mcp/mcp.json` (プロジェクト単位の場合は `.mcp.json`) に追加し、`pi-mcp-adapter doctor` を実行して接続を確認してください。

### ローカルで実行する場合 {#run-it-locally-instead}

MCP サーバーをローカルマシンで実行するには、stdio サーバーとして追加します。

```bash
pi mcp add firecrawl --env FIRECRAWL_API_KEY='${FIRECRAWL_API_KEY}' -- npx -y firecrawl-mcp
```

## トラブルシューティング {#troubleshooting}

* **サーバーが失敗と表示される：** `pi mcp list` を実行し、Pi を起動するシェルと同じシェルで `FIRECRAWL_API_KEY` がエクスポートされているか確認してください。
* **開いているセッションにツールが表示されない：** セッション外でサーバーを追加・変更した場合は、`/reload` を実行してください。
* **Pi の MCP コマンドが見つからない：** Pi を最新のリリースに更新するか、上記の設定で pi-mcp-adapter を使用してください。
