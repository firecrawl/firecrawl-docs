Qodo Command に Firecrawl を追加すると、Qodo のエージェントでウェブを検索したり、ページを読み取ったりできるようになります。Qodo Command は、お使いのAPIキーを使用して Firecrawl MCP サーバーをローカルプロセスとして起動します。

<Note>
  Qodo は 2026 年 10 月 30 日をもって IDE プラグインの提供を終了し、ローカルのワークフローを、すでにお使いのコーディングエージェントへ移行します。このページでは、プロジェクトファイルから MCP サーバーの設定を読み込む Qodo Command について説明します。
</Note>

## 前提条件 {#requirements}

* Qodo Command (`npm install -g @qodo/command` でインストールし、`qodo login` でサインイン済みであること)
* Node.js 22 以降
* [Firecrawl APIキー](https://www.firecrawl.dev/app/api-keys)

## クイックセットアップ {#quick-setup}

1. プロジェクトのルートに `mcp.json` を作成します：

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp@3.33.2"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
      }
    }
  }
}
```

2. `agents/research.toml` を作成し、サーバー名を指定してエージェントがそのサーバーにアクセスできるようにします：

```toml
version = "1.0"

[commands.research]
description = "Research a topic on the web with Firecrawl"
instructions = """
Use the Firecrawl tools to search the web and read pages, then summarize the sources.
"""
tools = ["firecrawl"]
execution_strategy = "act"
```

3. プロジェクトルートにある `agent.toml` からエージェントをインポートします：

```toml
version = "1.0"

imports = ["agents/research.toml"]
```

4. エージェントを実行し、利用可能なツールを一覧表示します：

```bash
qodo list-mcp
qodo research "Find the latest release notes for Node.js"
```

`mcp.json` には API キーが含まれるため、ソース管理の対象から除外してください。環境変数の全一覧は、[MCP をローカルで実行する](/ja/mcp-server/local)を参照してください。

## トラブルシューティング {#troubleshooting}

* **`list-mcp` に Firecrawl のエントリが表示されない:** `mcp.json` がプロジェクトのルートに配置されていることを確認するか、`--mcp-file=path` を指定してください。
* **エージェントが Firecrawl を呼び出さない:** エージェントファイルの `tools` に `"firecrawl"` が含まれており、`mcp.json` のキーと一致していることを確認してください。
* **サーバーが開始しない:** `node --version` を実行し、バージョンが 22 以上であることを確認してください。
* **サーバーが `401` を返す:** `mcp.json` 内の `FIRECRAWL_API_KEY` の値を正しいものに置き換えてください。
