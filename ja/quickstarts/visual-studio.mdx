ホスト型MCPサーバー経由で Firecrawl を Visual Studio の GitHub Copilot エージェントモードに接続し、Firecrawl アカウントでサインインします。

## 要件 {#requirements}

* Visual Studio 2022 バージョン 17.14 以降、または Visual Studio 2026
* GitHub Copilot にサインイン済みで、Copilot Chat を **エージェント** モードで使用していること

## クイックセットアップ {#quick-setup}

1. すべてのソリューションで Firecrawl を使用できるようにするには、`%USERPROFILE%\.mcp.json` を作成します。特定のソリューションのみに範囲を限定し、ソース管理で共有する場合は、`<SOLUTIONDIR>\.mcp.json` を作成します。
2. 次の構成を追加して、ファイルを保存します。

```json
{
  "servers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

3. ファイル内で、サーバーの上に表示される CodeLens の **Authentication Required** を選択し、ブラウザーで Firecrawl の sign-in を完了します。CodeLens が表示されない場合は、**Tools** &gt; **Options** &gt; **Text Editor** &gt; **CodeLens** で有効にしてください。
4. Copilot Chat で **エージェント** モードに切り替え、**Tools** を開いて Firecrawl のツールを有効にします。Visual Studio では、新しく追加された MCP ツールは手動で有効にするまで無効化されています。

<Accordion title="チャットからサーバーを追加したい場合">
  Copilot Chat で **エージェント** モードに切り替え、**Tools** を開いてプラスボタンを選択し、**Add custom MCP server** を選択します。名前に `firecrawl`、URL に `https://mcp.firecrawl.dev/v2/mcp-oauth` を入力します。
</Accordion>

<Accordion title="APIキーを使ってローカルサーバーを利用したい場合">
  Visual Studio ではローカルサーバーも実行できます。[MCP をローカルで実行](/ja/mcp-server/local)の手順に従い、同じファイルにコマンドを定義します:

  ```json
  {
    "servers": {
      "firecrawl": {
        "command": "npx",
        "args": ["-y", "firecrawl-mcp@3.33.2"],
        "env": {
          "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
        }
      }
    }
  }
  ```
</Accordion>

詳細は [OAuth 接続ガイド](/ja/mcp-server/oauth)を参照してください。ユーザー操作なしで使用する場合は、[APIキーを設定](/ja/mcp-server/keyless#add-an-api-key)してください。

## トラブルシューティング {#troubleshooting}

* **ツールピッカーに Firecrawl のツールが表示されない:** ツールピッカーを開いてツールを有効にしてください。Visual Studio では、サーバーのツール一覧が変更されるたびにツールの承認がリセットされます。
* **再度 sign-in を求められる:** `.mcp.json` を開き、`firecrawl` サーバーの CodeLens で **Manage Authentication** を選択してください。
* **ファイルが無視される:** Visual Studio 用のファイルでは、トップレベルのキーは `mcpServers` ではなく `servers` です。
* **`firecrawl` の定義が重複している:** Visual Studio は、ソリューションフォルダー内の `.vscode\mcp.json` と `.cursor\mcp.json` も読み込みます。Firecrawl のエントリは 1 つだけにしてください。
