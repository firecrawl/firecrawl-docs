ホスト型 MCP サーバー経由で Firecrawl を [Google Antigravity](https://antigravity.google/) に接続し、Firecrawl アカウントでサインインします。

## クイックセットアップ {#quick-setup}

1. Antigravity で、エージェントのサイドパネル上部にある **…** をクリックし、**MCP Servers** を選択します。
2. **Manage MCP Servers** をクリックし、次に **View raw config** をクリックして `mcp_config.json` を開きます (グローバル設定は `~/.gemini/config/mcp_config.json`、ワークスペース単位の設定は `.agents/mcp_config.json` にあります) 。
3. Firecrawl サーバーを追加して保存します。

```json
{
  "mcpServers": {
    "firecrawl": {
      "serverUrl": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

4. Agent の設定(`Cmd/Ctrl + ,`)を開き、**Customizations** に移動して、`firecrawl` の横にある **Authenticate** をクリックします。
5. ブラウザーで Firecrawl にサインインして Team を承認したら、認可コードを Antigravity に貼り付けて **Submit** をクリックします。
6. `firecrawl_search` や `firecrawl_scrape` などの Firecrawl のツールが利用できることを確認します。

Antigravity でリモートサーバーを使用するには、`serverUrl` キーが必要です。`url` または `httpUrl` を使用したエントリは登録されません。Antigravity CLI も同じファイルを読み込みます。CLI で `/mcp` と入力すると、サーバーのステータスを確認できます。

<Accordion title="APIキーを使用したい場合">
  ユーザー操作なしで使用する場合は、サインインの代わりに [Firecrawl APIキーを作成](https://www.firecrawl.dev/app/api-keys)し、ヘッダーで送信してください。詳細は [APIキーを追加する](/ja/mcp-server/keyless#add-an-api-key) を参照してください。

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "serverUrl": "https://mcp.firecrawl.dev/v2/mcp",
        "headers": {
          "Authorization": "Bearer fc-YOUR-API-KEY"
        }
      }
    }
  }
  ```
</Accordion>

詳細は [OAuth 接続ガイド](/ja/mcp-server/oauth) を参照してください。

```text
Use Firecrawl to search for the latest Vercel AI SDK release notes, scrape the two most relevant results, and summarize what changed with a link to each source.
```

```text
Search with Firecrawl for the official docs of three popular Python HTTP client libraries, scrape each docs homepage, and compare their async support in a table.
```

## トラブルシューティング {#troubleshooting}

* **サーバーが失敗と表示される:** エントリで `serverUrl` を使用し、値が `https://mcp.firecrawl.dev/v2/mcp-oauth` と完全に一致していることを確認してください。そのうえで、**Manage MCP Servers** または CLI の `/mcp` マネージャーからサーバーを再読み込みします。
* **サインインを求められる、またはセッションの有効期限が切れた:** **Customizations** で `firecrawl` の横にある **Authenticate** をもう一度クリックしてください。
* **別の Firecrawl 接続がすでに存在する:** 既存のサーバーの URL を OAuth URL に変更してサインインし、有効な Firecrawl サーバーが 1 つだけになるようにしてください。
