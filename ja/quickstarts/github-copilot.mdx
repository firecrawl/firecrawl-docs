[GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli) または [VS Code の Copilot](https://code.visualstudio.com/docs/copilot/overview) をホスト型MCPサーバー経由で Firecrawl に接続し、Firecrawl アカウントでサインインします。[Copilot コーディングエージェント](#copilot-coding-agent)の場合は APIキーで接続します。

以下のサーバーURLはクライアントに設定する構成値です。ブラウザーで直接開くページではありません。

## Copilot CLI {#copilot-cli}

### 1. Firecrawl を追加する {#1-add-firecrawl}

```bash
copilot mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

これにより、サーバーの設定が `~/.copilot/mcp-config.json` に書き込まれます。対話型セッション内で `/mcp add` を実行して **HTTP** 型を選択するか、ファイルを直接編集することもできます。

```json ~/.copilot/mcp-config.json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth",
      "tools": ["*"]
    }
  }
}
```

### 2. サインインして確認する {#2-sign-in-and-verify}

```bash
copilot
```

初回接続時には、Copilot CLI がブラウザーで Firecrawl の sign-in フローを開きます。画面の案内に従って Team を選択し、接続を承認してください。`/mcp` と入力し、`firecrawl` が接続されていることを確認します。

### 代わりにAPIキーを使用する {#use-an-api-key-instead}

ユーザー操作なしで使用する場合は、[Firecrawl APIキーを作成](https://www.firecrawl.dev/app/api-keys)して `FIRECRAWL_API_KEY` としてエクスポートし、Bearerヘッダーを指定してAPIキー用のエンドポイントを追加します。

```bash
copilot mcp add --transport http \
  --header "Authorization: Bearer $FIRECRAWL_API_KEY" \
  firecrawl https://mcp.firecrawl.dev/v2/mcp
```

キーは `~/.copilot/mcp-config.json` に保存されるため、このファイルはバージョン管理に含めないでください。

## VS Code {#vs-code}

### 1. Firecrawl を追加する {#1-add-firecrawl-2}

コマンドパレットから **MCP: Add Server** を実行して **HTTP** を選択するか、ワークスペースに `.vscode/mcp.json` を作成します。

```json .vscode/mcp.json
{
  "servers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

すべてのワークスペースでこのサーバーを使用できるようにするには、**MCP: Open User Configuration** を実行し、そこにも同じエントリを追加します。

### 2. サインインと動作確認 {#2-sign-in-and-verify-2}

`mcp.json` エディター、または **MCP: List Servers** からサーバーを開始します。VS Code から認証を求められたら許可し、ブラウザーで Firecrawl の sign-in を完了します。次に、Copilot Chat を **Agent** モードで開き、ツールアイコンを選択して、Firecrawl のツールが一覧に表示されていることを確認します。

### 代わりにAPIキーを使用する {#use-an-api-key-instead-2}

APIキー用のエンドポイントを使用し、キーの入力はVS Codeのプロンプトに任せます。これにより、キーはファイルに書き込まれることなく安全に保存されます。

```json .vscode/mcp.json
{
  "inputs": [
    {
      "type": "promptString",
      "id": "firecrawl-api-key",
      "description": "Firecrawl API key",
      "password": true
    }
  ],
  "servers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer ${input:firecrawl-api-key}"
      }
    }
  }
}
```

## Copilot コーディングエージェント {#copilot-coding-agent}

Copilot コーディングエージェント (Copilot クラウドエージェントとも呼ばれます) は、GitHub 上のイシューやプルリクエストを処理します。リポジトリのMCP設定は OAuth を使用するリモートサーバーに対応していないため、このセットアップでは Firecrawl APIキーを Agents シークレットとして保存し、ヘッダーで送信します。

### 要件 {#requirements}

* 有料の GitHub Copilot プラン (対象リポジトリでコーディングエージェントが有効になっていること)
* リポジトリの管理者権限 (MCP設定と Agents シークレットの編集に必要)
* [Firecrawl APIキー](https://www.firecrawl.dev/app/api-keys)

### セットアップ {#set-it-up}

1. リポジトリで **Settings**、**Secrets and variables**、**Agents** の順に開きます。
2. **New repository secret** を選択し、名前を `COPILOT_MCP_FIRECRAWL_API_KEY` に設定して Firecrawl APIキーを貼り付け、保存します。Copilot が MCP サーバーに渡すのは、名前が `COPILOT_MCP_` で始まる Agents シークレットだけです。
3. **Settings**、**Copilot**、**MCP servers** の順に開きます。
4. 次の構成を **MCP configuration** に貼り付け、**Save MCP configuration** を選択します。

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer $COPILOT_MCP_FIRECRAWL_API_KEY"
      },
      "tools": ["firecrawl_search", "firecrawl_scrape", "firecrawl_map"]
    }
  }
}
```

5. イシューを Copilot に割り当てます。プルリクエストが作成されたら **View session** を選択し、ログ内の **Start MCP Servers** ステップを開いて、Firecrawl のツールが一覧に表示されていることを確認します。

<Warning>
  Copilot は、`tools` リスト内のツールを承認なしで使用します。リストにはエージェントが必要とするツールだけを含めてください。`"*"` は、Firecrawl のすべてのツールを利用可能にしたい場合にのみ使用してください。
</Warning>

## トラブルシューティング {#troubleshooting}

* **ツールが表示されない:** `firecrawl` サーバーが 1 つだけ設定されていることを確認してから Copilot CLI を再起動してください。VS Code の場合は **MCP: List Servers** を実行し、サーバーを再起動してください。
* **再度 sign-in が求められる、または `401` が返される:** サーバーを再起動し、ブラウザーで sign-in を完了してください。なお、認証前に OAuth サーバーへ単純なリクエストを送ると `401` が返されますが、これは想定どおりの動作です。
* **API キーによる接続で `401` が返される:** URL が `https://mcp.firecrawl.dev/v2/mcp` (`/v2/mcp-oauth` ではありません) であること、およびヘッダーが `Authorization: Bearer <FIRECRAWL_API_KEY>` であることを確認してください。
* **組織のポリシー:** GitHub 組織で Copilot の MCP サーバー利用が制限されている場合、Firecrawl に接続するには管理者による許可が必要です。
* **コーディングエージェント: セッションログに Firecrawl のツールが表示されない:** シークレット名が `COPILOT_MCP_FIRECRAWL_API_KEY` と完全に一致していること、また Actions シークレットではなく Agents シークレットとして登録されていることを確認してください。
