ホスト型MCPサーバー経由で、Firecrawl の検索、スクレイピング、クロール、マップの各ツールを [Tencent WorkBuddy](https://www.workbuddy.ai) に追加します。

## クイックセットアップ {#quick-setup}

[Firecrawl APIキーを作成](https://www.firecrawl.dev/app/api-keys)したら、WorkBuddy にサーバーを追加します。

1. **Experts · Skills · Connectors** を開き、**Connectors** タブに切り替えて **Custom connectors** を選択します。
2. **Configure MCP** を選択して、MCP 構成エディターを開きます。
3. `mcpServers` に Firecrawl を追加して保存します：

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

`<FIRECRAWL_API_KEY>` をお使いのキーに置き換えてください。すでに他のサーバーを設定している場合は、`firecrawl` エントリのみを追加し、既存の設定はそのまま残してください。

WorkBuddy はこの設定を `~/.workbuddy/mcp.json` に保存します。特定のプロジェクトでのみ使用する場合は、代わりに `<project>/.workbuddy/mcp.json` を使用してください。

MCP 一覧に戻り、**firecrawl** をオンにします。WorkBuddy から確認を求められた場合は、信頼を許可してください。ステータスが緑色になれば接続完了です。`firecrawl_search` や `firecrawl_scrape` などのツールが使用できるようになります。

WorkBuddy は MCP OAuth にも対応しています。キーの代わりにサインインで認証する方法については、[For Humans](/ja/mcp-server/oauth) を参照してください。

## トラブルシューティング {#troubleshooting}

* **ステータスが赤色になる:** JSON が有効であること、および URL が `https://mcp.firecrawl.dev/v2/mcp` と完全に一致していることを確認してください。
* **401 未認証:** キーが正しいことを確認し、`Authorization` ヘッダーの `Bearer ` プレフィックスを削除しないでください。
* **ツールが表示されない:** サーバーを一度オフにしてから再度オンにすると、WorkBuddy のツール一覧が更新されます。
