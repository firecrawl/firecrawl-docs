<div id="scraping-with-firecrawl">
  ## Firecrawlでのスクレイピング {#scraping-with-firecrawl}
</div>

FirecrawlはWebページをMarkdownに変換し、LLMアプリケーションに最適です。理由は次のとおりです。

1. **複雑さの吸収:**
   プロキシ、キャッシュ、レート制限、JavaScriptで遮断されるコンテンツまで適切に処理し、安定したスクレイピングを実現します。

2. **動的コンテンツ対応:**
   JavaScriptレンダリングのサイトやPDF、画像などからデータを取得します。

3. **Markdownまたは構造化データへの変換:**
   収集データをクリーンなMarkdownまたは構造化出力に変換し、LLM処理やその他のワークロードに最適化します。

詳細は、[Scrape Endpoint API Reference](https://docs.firecrawl.dev/api-reference/endpoint/scrape)を参照してください。

<div id="usage">
  ### 使い方 {#usage}
</div>

<CodeGroup>
  ```python Python
  from firecrawl import FirecrawlApp

  app = FirecrawlApp(api_key="YOUR_API_KEY")

  content = app.scrape_url("https://mendable.ai")
  ```

  ```JavaScript JavaScript
  import { FirecrawlApp } from 'firecrawl-js';

  const app = new FirecrawlApp({ apiKey: 'YOUR_API_KEY' });

  const content = await app.scrapeUrl('https://mendable.ai');
  ```

  ```go Go
  import (
    "fmt"
    "log"

    "github.com/mendableai/firecrawl-go"
  )

  func main() {
    app, err := firecrawl.NewFirecrawlApp("YOUR_API_KEY")
    if err != nil {
      log.Fatalf("Failed to initialize FirecrawlApp: %v", err)
    }

    content, err := app.ScrapeURL("mendable.ai", nil)
    if err != nil {
      log.Fatalf("Failed to scrape URL: %v", err)
    }
    fmt.Println(content)
  }
  ```

  ```rust Rust
  use firecrawl::FirecrawlApp;

  #[tokio::main]
  async fn main() {
      // APIキーで FirecrawlApp を初期化
      let api_key = "YOUR_API_KEY";
      let api_url = "https://api.firecrawl.dev";
      let app = FirecrawlApp::new(api_key, api_url).expect("Failed to initialize FirecrawlApp");

      // URL をスクレイピング
      let scrape_result = app.scrape_url("https://mendable.ai", None).await;

      // 結果を出力
    match scrape_result {
      Ok(data) => println!("Scrape Result:\n{}", data["markdown"]),
      Err(e) => eprintln!("Scrape failed: {}", e),
    }
  }
  ```

  ```bash cURL
  curl -X POST https://api.firecrawl.dev/v0/scrape \
      -H 'Content-Type: application/json' \
      -H 'Authorization: Bearer YOUR_API_KEY' \
      -d '{
        "url": "https://mendable.ai"
      }'
  ```
</CodeGroup>

<div id="response">
  ### レスポンス {#response}
</div>

SDKはデータオブジェクトを直接返します。cURLは以下のとおり、ペイロードをそのまま返します。

```json
{
  "success": true,
  "data": {
    "content": "Raw Content ",
    "markdown": "# Markdown コンテンツ",
    "provider": "web-scraper",
    "metadata": {
      "title": "Mendable | CX とセールス向けの AI",
      "description": "CX とセールス向けの AI",
      "language": null,
      "sourceURL": "https://www.mendable.ai/"
    }
  }
}
```
