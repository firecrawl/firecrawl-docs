Firecrawl Research は、科学・工学分野の研究エージェント向けに特化して設計されたインデックスです。論文の検索、論文メタデータの確認、関連する本文箇所の閲覧、構造的拡張による関連論文の発見に対応した、研究専用のツールセットを提供します。

このインデックスには約 4,300 万本の論文アブストラクトが収録されています。コーパスの大部分は生物医学および生命科学分野であり、**PubMed**、**bioRxiv**、**medRxiv**に加え、物理学、数学、コンピュータサイエンス分野の**arXiv**も含まれます。論文はソース ID で指定できるため、`pmid:`、`pmcid:`、`doi:` の参照は `arxiv:` と同じように機能します。

* トピック、手法、ベンチマーク、著者、またはカテゴリで論文を探す
* 正規の論文メタデータとソース ID を確認する
* 特定の質問に答える、1 本の論文内の本文箇所を読む
* 有力なシード論文から、関連する論文、シードを引用している論文、またはシードが引用している論文へと広げる

<Note>
  エージェントに Research Index へのアクセスを付与するには、[CLI](/ja/sdks/cli) または [MCP](/ja/mcp-server) を、[**専用の research skill**](https://github.com/firecrawl/skills/blob/main/skills/firecrawl-research-index/SKILL.md) と組み合わせて使うことを強くおすすめします。インストールには次のコマンドを使用します。

  ```bash
  npx skills add firecrawl/skills@firecrawl-research-index
  ```
</Note>

<div id="how-this-relates-to-search">
  ## `/search` との違い
</div>

Firecrawl には「research」という名前の機能が 2 つありますが、同じものではありません。

|                  | Research Index (このページ)                                        | `categories: ["research"]` を指定した `/search`                                          |
| :--------------- | ------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| 検索対象             | PubMed、bioRxiv、medRxiv、arXiv を含む、約 4,300 万件のアブストラクトを収録した論文インデックス   | 約 14 の学術 **Web サイト** (arxiv.org、nature.com、pubmed.ncbi.nlm.nih.gov、…) に限定したオープン Web |
| 返される内容           | ランク付けされた論文レコード: 正規 `paperId`、`primaryId`、ソース ID、タイトル、全文アブストラクト、スコア | 通常の Web 検索結果: URL、タイトル、スニペット                                                        |
| 論文の内容を読めるか       | はい — `GET /search/research/papers/{id}` による本文箇所単位の取得         | いいえ                                                                                 |
| 引用をたどって関連論文を探せるか | はい — `GET /search/research/papers/{id}/similar`               | いいえ                                                                                 |
| エンドポイント          | `GET /search/research/papers`                                 | `POST /search`                                                                      |

論文の検索や閲覧、引用の追跡など、文献調査には Research Index を使用してください。学術ドメイン上の通常の Web ページを検索したい場合は、[`categories: ["research"]`](/ja/features/search#search-categories) を使用してください。

<div id="search-papers">
  ## 論文を検索
</div>

自然言語のクエリで論文のアブストラクトを検索します。レスポンスでは、正規の `paperId`、優先される `primaryId`、ソース ID、タイトル、アブストラクト、スコア、任意のランキングシグナルを含む、順位付けされた論文が返されます。

<CodeGroup>
  ```bash cURL
  # 利用開始に API key は不要です。より高いレート制限が必要な場合は -H "Authorization: Bearer $FIRECRAWL_API_KEY" を追加してください:
  curl -s "https://api.firecrawl.dev/v2/search/research/papers?query=diffusion%20image%20synthesis&k=20"
  ```

  ```bash CLI
  firecrawl research search-papers "diffusion image synthesis" --limit 20
  ```

  ```python Python
  from firecrawl import Firecrawl

  firecrawl = Firecrawl(
    # 利用開始に API key は不要です。より高いレート制限が必要な場合は追加してください:
    # api_key="fc-YOUR-API-KEY",
  )

  result = firecrawl.v2.search_papers("diffusion image synthesis", k=20)
  print(result)
  ```

  ```js Node
  import { Firecrawl } from "firecrawl";

  const firecrawl = new Firecrawl({
    // 利用開始に API key は不要です。より高いレート制限が必要な場合は追加してください:
    // apiKey: "fc-YOUR-API-KEY",
  });

  const result = await firecrawl.research.searchPapers("diffusion image synthesis", {
    k: 20,
  });
  console.log(result);
  ```
</CodeGroup>

任意のフィルタ:

* `authors`: 著者名の部分文字列で絞り込みます。すべてのフィルタ条件に一致する必要があります
* `categories`: `cs.LG` などの論文カテゴリで絞り込みます
* `from`: 作成日/更新日の下限 (この日付を含む) 。`YYYY-MM-DD`
* `to`: 作成日/更新日の上限 (この日付を含む) 。`YYYY-MM-DD`

<div id="biomedical-example">
  ### 生物医学の例
</div>

インデックスの大半はライフサイエンス分野を対象としているため、臨床および分子生物学に関するqueryも同様に機能します。

<CodeGroup>
  ```bash cURL

  ```

  ```bash CLI
  firecrawl research search-papers "CRISPR base editing off-target effects in primary human T cells" --limit 20
  ```

  ```python Python
  from firecrawl import Firecrawl

  firecrawl = Firecrawl(
    # 開始時にAPIキーは不要です。より高いレート制限を利用するには追加してください:
    # api_key="fc-YOUR-API-KEY",
  )

  result = firecrawl.v2.search_papers(
    "CRISPR base editing off-target effects in primary human T cells",
    k=20,
  )
  print(result)
  ```

  ```js Node
  import { Firecrawl } from "firecrawl";

  const firecrawl = new Firecrawl({
    // 開始時にAPIキーは不要です。より高いレート制限を利用するには追加してください:
    // apiKey: "fc-YOUR-API-KEY",
  });

  ```
</CodeGroup>

結果には、ソースで使用されている名前空間の`primaryId`が含まれます。そのため、生物医学の検索結果は`pmid:<id>`、`pmcid:<id>`、または`doi:<doi>`として返されます。この値をそのまま、以下のinspect、read、relatedエンドポイントに渡してください。

<div id="inspect-a-paper">
  ## 論文を確認する
</div>

正規の `paperId` またはソース固有の `primaryId` を使用します。使用可能な `primaryId` の形式は `arxiv:<id>`、`pmid:<id>`、`pmcid:<id>`、`doi:<doi>` です。たとえば、PubMed レコードの場合は `curl -s ".../v2/search/research/papers/pmid:<id>"` を使用します。

<CodeGroup>
  ```bash cURL
  # 開始時に API キーは不要です。より高いレート制限を利用するには、-H "Authorization: Bearer $FIRECRAWL_API_KEY" を追加してください:
  curl -s "https://api.firecrawl.dev/v2/search/research/papers/arxiv:1706.03762"
  ```

  ```bash CLI
  firecrawl research inspect-paper arxiv:1706.03762
  ```

  ```python Python
  from firecrawl import Firecrawl

  firecrawl = Firecrawl(
    # 開始時に API キーは不要です。より高いレート制限を利用するには追加してください:
    # api_key="fc-YOUR-API-KEY",
  )

  paper = firecrawl.v2.inspect_paper("arxiv:1706.03762")
  print(paper)
  ```

  ```js Node
  import { Firecrawl } from "firecrawl";

  const firecrawl = new Firecrawl({
    // 開始時に API キーは不要です。より高いレート制限を利用するには追加してください:
    // apiKey: "fc-YOUR-API-KEY",
  });

  const paper = await firecrawl.research.getPaper("arxiv:1706.03762");
  console.log(paper);
  ```
</CodeGroup>

<div id="read-paper-passages">
  ## 論文の該当箇所を読む
</div>

同じ論文パスに `query` を追加すると、質問に対する本文中の関連度が高い本文箇所を取得できます。これは、候補の論文を含める前に、その論文に手法、データセット、制約、または結果が実際に記載されているかを確認するのに役立ちます。

<CodeGroup>
  ```bash cURL
  # 利用開始に API key は不要です。より高いレート制限を利用するには -H "Authorization: Bearer $FIRECRAWL_API_KEY" を追加してください:
  curl -s "https://api.firecrawl.dev/v2/search/research/papers/arxiv:1706.03762?query=what%20is%20the%20attention%20mechanism&k=4"
  ```

  ```bash CLI
  firecrawl research read-paper arxiv:1706.03762 --question "What is the attention mechanism?" --limit 4
  ```

  ```python Python
  from firecrawl import Firecrawl

  firecrawl = Firecrawl(
    # 利用開始に API key は不要です。より高いレート制限を利用するには追加してください:
    # api_key="fc-YOUR-API-KEY",
  )

  passages = firecrawl.v2.read_paper(
      "arxiv:1706.03762",
      "What is the attention mechanism?",
      k=4,
  )
  print(passages)
  ```

  ```js Node
  import { Firecrawl } from "firecrawl";

  const firecrawl = new Firecrawl({
    // 利用開始に API key は不要です。より高いレート制限を利用するには追加してください:
    // apiKey: "fc-YOUR-API-KEY",
  });

  const passages = await firecrawl.research.getPaper("arxiv:1706.03762", {
    query: "What is the attention mechanism?",
    k: 4,
  });
  console.log(passages);
  ```
</CodeGroup>

<div id="find-related-papers">
  ## 関連する論文を見つける
</div>

1本以上のシード論文を起点にセマンティック拡張し、自然言語の`intent`に基づいて候補を順位付けします。

<CodeGroup>
  ```bash cURL
  # 開始するのに API key は不要です。より高いレート制限が必要な場合は、-H "Authorization: Bearer $FIRECRAWL_API_KEY" を追加してください:
  curl -s "https://api.firecrawl.dev/v2/search/research/papers/arxiv:1706.03762/similar?intent=efficient%20transformers&mode=similar&k=20"
  ```

  ```bash CLI
  firecrawl research related-papers arxiv:1706.03762 --intent "efficient transformers" --limit 20
  ```

  ```python Python
  from firecrawl import Firecrawl

  firecrawl = Firecrawl(
    # 開始するのに API key は不要です。より高いレート制限が必要な場合は追加してください:
    # api_key="fc-YOUR-API-KEY",
  )

  papers = firecrawl.v2.related_papers(
      "arxiv:1706.03762",
      "efficient transformers",
      mode="similar",
      k=20,
  )
  print(papers)
  ```

  ```js Node
  import { Firecrawl } from "firecrawl";

  const firecrawl = new Firecrawl({
    // 開始するのに API key は不要です。より高いレート制限が必要な場合は追加してください:
    // apiKey: "fc-YOUR-API-KEY",
  });

  const papers = await firecrawl.research.similarPapers("arxiv:1706.03762", {
    intent: "efficient transformers",
    mode: "similar",
    k: 20,
  });
  console.log(papers);
  ```
</CodeGroup>

モード:

* `similar`: 共引用および書誌結合による近傍
* `citers`: シードを引用している論文
* `references`: シードが引用している論文

<div id="search-github-history">
  ## GitHubの履歴を検索
</div>

Issue、マージ済みのプルリクエスト、リポジトリのREADMEは、[Developer Index](/ja/features/developer)に収録されています。一致した本文箇所とともにランク付けされ、厳選されたドキュメントソースも追加されています。[`GET` または `POST /search/developer`](/ja/api-reference/endpoint/developer-search) を使用するか、`categories: ["developer"]` を指定して `/search` を使用してください。
