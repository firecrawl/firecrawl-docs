Firecrawl Government Index は、米国の連邦・州・地方の制定法、規則、条例、裁判所の判決、その他の政府刊行物を検索します。Agent は、質問の根拠となる法令や規制の条文を見つけられます。ランク付けされた検索結果には、過去の版、法案の条文、行政機関のガイダンス、第三者による転載が含まれることもあります。検索結果に含まれていても、それが現行の有効な法令であるとは限りません。

* 表示、報告、許認可の要件を定める規則を見つける
* コンプライアンス上の質問の根拠となる制定法や条例の条項を確認する
* 規則を解釈した裁判所の判決を探す
* 特定のトピックについて行政機関が発行した政府刊行物を取得する

## ソースの選択と検証 {#choose-and-verify-sources}

判明している場合は、法域、機関または引用元、関連する日付を含めてください。適用されるルールを特定する前に、法域が不明であればユーザーに確認してください。ユーザーがソースURLを提示した場合は、再検索せずに [`scrape`](/ja/features/scrape) で直接読み取ってください。

現行法に関する質問に回答する前に、ソースの発行元、法域、制定・施行状況、バージョンを確認してください。スニペットだけではルールを確定できない場合は、ヒットした結果の元となるソースを読んでください。法案の状況や施行日は、タイトルや要約から推測せず、実際に確認してください。根拠となる条項と裏付けとなる本文箇所を引用し、ページ、条項、施行日などの詳細は、証拠で裏付けられるものだけを示してください。

このインデックスは主に米国の資料を対象としています。その他の法域や、インデックスでカバーされていない情報には一般検索を使用してください。ヒットしないからといって、適用される法律が存在しないとは限りません。

## Government Index を検索する {#search-the-government-index}

自然言語で質問を送信すると、法律・規制関連のソースからランク付け済み結果が返されます。結果は標準の `web` グループに含まれ、各結果には `url`、`title`、`description`、`position` が含まれます。これは [`/search`](/ja/features/search) の web 結果と同じ形式です。

Government Index の検索は無料です。ゼロデータ保持の有無にかかわらず、クレジットは消費されません。APIキーなしですぐに利用を開始でき、APIキーを追加するとレート制限が引き上げられます。

SDK の例では、`firecrawl@4.44.1` および `firecrawl-py==4.49.2` で利用できる Gov メソッドを使用しています。認証付きの SDK の例を実行するには `FIRECRAWL_API_KEY` を設定してください。キーなしでリクエストする場合は HTTP の例を使用してください。インストール済みのクライアントにメソッドがない場合は、SDK をアップグレードしてください。Python では、初期化済みのクライアントインスタンスで `gov_search` を呼び出してください。初期化時に割り当てられるメソッドは、クラスのみを対象としたリフレクションでは一覧に表示されない場合があります。

<CodeGroup>
  ```bash cURL
  # APIキーなしで利用を開始できます。より高いレート制限が必要な場合は -H "Authorization: Bearer $FIRECRAWL_API_KEY" を追加してください:
  curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
  ```

  ```bash CLI
  firecrawl gov "food labeling requirements for allergens" --limit 10
  ```

  ```python Python
  import os
  from firecrawl import Firecrawl

  client = Firecrawl(api_key=os.environ["FIRECRAWL_API_KEY"])

  result = client.gov_search("food labeling requirements for allergens", k=10)
  print(result)
  ```

  ```js Node
  import { Firecrawl } from "firecrawl";

  const client = new Firecrawl({
    apiKey: process.env.FIRECRAWL_API_KEY,
  });

  const result = await client.govSearch(
    "food labeling requirements for allergens",
    {
      k: 10,
    },
  );
  console.log(result);
  ```
</CodeGroup>

同じパスに対して `POST` も使用でき、その場合は同じフィールドを JSON ボディで送信します:

```bash cURL
# APIキーなしで利用を開始できます。レート制限を引き上げるには -H "Authorization: Bearer $FIRECRAWL_API_KEY" を追加してください:
curl -X POST https://api.firecrawl.dev/v2/search/gov \
  -H "Content-Type: application/json" \
  -d '{
    "query": "food labeling requirements for allergens",
    "k": 10
  }'
```

`query` は必須です。`k` は返される結果の件数を 1〜100 の範囲で指定します (デフォルトは 10) 。未定義のフィールドを指定すると `400` エラーが返されます。リクエストとレスポンスの完全なスキーマについては、[Government Index 検索リファレンス](/ja/api-reference/endpoint/gov-search)を参照してください。

同じ検索は [`/search`](/ja/features/search#gov-category-search) でも `categories: ["gov"]` を指定して利用でき、結果は `data.web` に返されます。
