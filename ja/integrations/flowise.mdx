  ## Flowise のワークフローで Web データを同期する {#sync-web-data-in-flowise-workflows}
</div>

Firecrawl は [Flowise（チャットフロー・ビルダー）](https://flowiseai.com/) 内で利用できます。このページでは、Flowise 内での Firecrawl ブロックの設定と使い方を紹介します。

  className="block"
  src="/images/fc_flowise_block.png"
  alt="Firecrawl Flowise ブロック"
/>

### Firecrawl ブロックでのクロール {#crawling-with-firecrawl-blocks}

1. Firecrawl アカウントにログインして API キーを取得し、**FireCrawl API** 認証情報としてブロックに追加します。
2.  (任意) Text Splitter を接続します。
3. **Type** を **Crawl** に設定し、対象 URL 配下のページを取得します。
4. クロール対象の URL を入力します。**Limit**、**Include Paths**、**Exclude Paths** を使用して、クロールの範囲を小さく抑えます。
5. 生成されたドキュメントをワークフローで利用します。

<div id="scraping-with-firecrawl-blocks">
  ### Firecrawl ブロックでのスクレイピング {#scraping-with-firecrawl-blocks}
</div>

1. Firecrawl アカウントにログインして API キーを取得し、**FireCrawl API** 認証情報としてブロックに追加します。
2.  (任意) Text Splitter を接続します。
3. 単一ページを取得するには、**Type** を **スクレイピング** に設定します。
4. スクレイピング対象のURLを入力します。
5. 取得したドキュメントをワークフローで使用します。

### Firecrawl ブロックを使用した検索と抽出 {#searching-and-extracting-with-firecrawl-blocks}

**Type** を **Search** に設定すると、**Query** に対するウェブ検索結果をドキュメントに変換できます。**Extract** に設定すると、**Schema** と **Prompt** を使用して URL から構造化データを取得できます。
