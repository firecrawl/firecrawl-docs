  Composioツールキットを使用して、Firecrawlをエージェントやアプリに接続
</Note>

<div id="overview">
  ## 概要
</div>

Composio は Firecrawl をツールキットとして提供しており、エージェントはカスタム API 連携を実装することなく、検索、スクレイピング、クロール、マップ、抽出を行えます。このツールキットは Firecrawl APIキーで認証されます。

<div id="quick-start">
  ## クイックスタート
</div>

1. [Composio ダッシュボード](https://dashboard.composio.dev)で Firecrawl APIキーを使って Firecrawl を接続します
2. [Firecrawl ツールキットのドキュメント](https://docs.composio.dev/toolkits/firecrawl)で利用可能なツールを確認します
3. Composio を活用したエージェントやワークフローから Firecrawl ツールを呼び出します

<div id="what-you-can-do">
  ## できること
</div>

| 機能           | ユースケース                       |
| ------------ | ---------------------------- |
| **検索**       | 抽出前にソースを見つける                 |
| **スクレイピング**  | エージェントのコンテキスト用にページコンテンツを取得する |
| **バッチスクレイプ** | 1つのジョブで多数のURLを取得する           |
| **クロール**     | 複数ページにわたるサイトデータを収集する         |
| **マップ**      | 取得対象を決める前にサイトのURLを一覧表示する     |
| **抽出**       | 生テキストではなく構造化されたフィールドを返す      |
