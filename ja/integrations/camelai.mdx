<Note>
  **公式 CAMEL ドキュメント:** [docs.camel-ai.org/key&#95;modules/loaders](https://docs.camel-ai.org/key_modules/loaders)

  Firecrawl は CAMEL ローダーとして提供され、あらゆるサイトをエージェント向けの LLM 対応 Markdown に変換します
</Note>

## インストール {#installation}

```bash
pip install "camel-ai[web-tools]"
```

`web-tools` エクストラを指定すると、ローダーが対応しているバージョンの Firecrawl SDK がインストールされます。通常の `pip install camel-ai` では SDK はインストールされません。また、現在の CAMEL リリースは `firecrawl-py` 4.x では動作しないため、同じ環境で `firecrawl-py` を個別にアップグレードしないでください。

ローダーが自動的に読み取れるよう、Firecrawl キーを設定します：

```bash
export FIRECRAWL_API_KEY="fc-your-api-key"
```

<div id="usage">
  ## 使用方法 {#usage}
</div>

Camel AI と Firecrawl を使うことで、ウェブ上のデータを活用するマルチエージェントシステムを迅速に構築できます。

### Firecrawl を使用して Web サイト全体を収集する {#using-firecrawl-to-gather-an-entire-website}

`crawl` はジョブの完了後に戻ります。`status` を確認し、`data` から Markdown を読み取ります。

```python
from camel.loaders import Firecrawl

firecrawl = Firecrawl()

response = firecrawl.crawl(url="https://www.camel-ai.org/about")
print(response["status"])  # クロールが完了すると "completed" になる

print(response["data"][0]["markdown"])
```

### Firecrawl を使って1ページを取得する {#using-firecrawl-to-gather-a-single-page}

```python
from camel.loaders import Firecrawl

firecrawl = Firecrawl()

response = firecrawl.scrape(url="https://www.camel-ai.org/about")
print(response["markdown"])
```

### サイトをマッピングして構造化データを抽出する {#mapping-a-site-and-extracting-structured-data}

`map_site` はサイト内の URL を一覧で取得し、`structured_scrape` は Pydantic モデルに沿ったフィールドを返します。

```python
from pydantic import BaseModel
from camel.loaders import Firecrawl


class About(BaseModel):
    mission: str


firecrawl = Firecrawl()

print(firecrawl.map_site(url="https://www.camel-ai.org")["links"][:5])
print(firecrawl.structured_scrape(url="https://www.camel-ai.org/about", response_format=About))
```

<Tip>
  `Firecrawl()` は環境変数から `FIRECRAWL_API_KEY` を読み取ります。`api_key=...` を渡すと上書きでき、`api_url=...` を渡すと[セルフホスト](/ja/contributing/self-host)インスタンスを指定できます。
</Tip>
