<Note>
  **Stripe 公式ドキュメント:** [docs.stripe.com/projects](https://docs.stripe.com/projects) · [プロバイダーディレクトリの Firecrawl](https://projects.dev/providers/)

  Firecrawl は Stripe Projects のプロバイダーです。`stripe projects add firecrawl/api` で任意のプロジェクトに追加できます。
</Note>

<div id="overview">
  ## 概要
</div>

[Stripe Projects](https://projects.dev) は、ターミナルからサードパーティのサービスをプロビジョニングし、その認証情報を `.env` に同期します。Firecrawl も対応プロバイダーの一つで、コマンド1つで Firecrawl アカウントの作成、APIキーのプロジェクトへの書き込み、プランの選択までを行えます。有料プランは、Stripe アカウントに登録された支払い方法で課金されます。

| 得られるもの      | 詳細                                                                                  |
| ----------- | ----------------------------------------------------------------------------------- |
| **アカウント**   | Stripe アカウントのメールアドレスに紐づく Firecrawl アカウント。そのメールアドレスで既に Firecrawl アカウントがある場合は再利用されます。 |
| **APIキー**   | `.env` に書き込まれるワークスペースのAPIキー。1つのキーですべての Firecrawl エンドポイントに利用できます。                    |
| **プラン**     | デフォルトは Free。CLI から Hobby、Standard、Growth へ、月額または年額でアップグレードできます。                     |
| **ダッシュボード** | `stripe projects open firecrawl` を実行すると Firecrawl ダッシュボードにサインインできます。                |

<div id="quick-start">
  ## クイックスタート
</div>

```bash
stripe plugin install projects
stripe projects init
stripe projects add firecrawl/api --name firecrawl
stripe projects env --pull
```

`--name firecrawl` はローカルのリソース名を設定し、これが CLI が書き込む変数の接頭辞になります。これを指定すると、キーは `FIRECRAWL_API_KEY` に書き込まれ、Firecrawl の [SDKs](/ja/sdks/overview) と [CLI](/ja/sdks/cli) が自動的に読み取ります。指定しない場合、リソース名は `firecrawl-api` となり、キーは `FIRECRAWL_API_API_KEY` に書き込まれます。

CLI は `FIRECRAWL_API_BASE_URL` と `FIRECRAWL_DOCUMENTATION_URL` も書き込みます。どちらも参考情報です。SDKs が読み取るのは `FIRECRAWL_API_URL` で、これはセルフホスト環境の場合のみです。Stripe でプロビジョニングされたアカウントはデフォルトのホスト版 API を使用するため、`FIRECRAWL_API_URL` は未設定のままにしてください。

ここからは、[Node.js](/ja/quickstarts/nodejs) または [Python](/ja/quickstarts/python) のクイックスタートに進んでください。他の言語の場合は [SDK の概要](/ja/sdks/overview) を参照してください。このキーはすべてのエンドポイントで利用できます: [search](/ja/features/search)、[scrape](/ja/features/scrape)、[crawl](/ja/features/crawl)、[map](/ja/features/map)、[extract](/ja/features/extract)、[interact](/ja/features/interact)、[parse](/ja/features/parse)、[monitor](/ja/features/monitoring)。

<div id="catalog">
  ## カタログ
</div>

最新の一覧は `stripe projects catalog firecrawl` を実行して確認してください。CLI は確定前に最終的な価格を表示します。

| スラッグ                 | 種別      | 内容                                                           |
| -------------------- | ------- | ------------------------------------------------------------ |
| `firecrawl/api`      | Service | Firecrawl API。アカウントと APIキー をプロビジョニングします。デフォルトは Free tier です。 |
| `firecrawl/free`     | Plan    | Free プラン。カード不要です。                                            |
| `firecrawl/hobby`    | Plan    | Hobby プラン。`Monthly` または `Yearly` の選択を求められます。                 |
| `firecrawl/standard` | Plan    | Standard プラン。`Monthly` または `Yearly` の選択を求められます。              |
| `firecrawl/growth`   | Plan    | Growth プラン。`Monthly` または `Yearly` の選択を求められます。                |

プランと価格は [firecrawl.dev/pricing](https://www.firecrawl.dev/pricing) と同じです。Scale と Enterprise は Stripe Projects 経由では提供していません。ご希望の場合は [お問い合わせください](https://www.firecrawl.dev/enterprise)。

<div id="manage-the-resource">
  ## リソースを管理する
</div>

```bash
# Stripeアカウントに支払い方法を一度だけ追加する
stripe projects billing add

# 有料プランに移行する。CLIがプランと課金間隔を尋ねます
stripe projects upgrade firecrawl

# APIキーをローテーションし、新しい値を.envに取り込む
stripe projects rotate firecrawl
stripe projects env --pull

# このプロジェクトからFirecrawlを削除する。有料プランも同時に解約されます
stripe projects remove firecrawl
```

アップグレードには Stripe の [Shared Payment Token](https://docs.stripe.com/agentic-commerce/concepts/shared-payment-tokens) を使用するため、Firecrawl がカード情報を参照することはありません。プランは他のサブスクリプションと同様に Firecrawl ダッシュボードに表示されます。Free に戻すには、`stripe projects upgrade firecrawl` を実行して `free` を選択するか、ダッシュボードの [課金](https://www.firecrawl.dev/app/settings?tab=billing) からプランを変更してください。

リソースを削除すると有料プランは即座に解約されるため、リソースがなくなった後に課金が続くことはありません。Firecrawl のアカウント、そのTeam、APIキーはそのまま残ります。引き続き利用するにはリソースを再度追加し、必要であればプランを選び直してください。

<div id="accounts-and-billing">
  ## アカウントと課金
</div>

* **1つのStripeアカウントにつき、1つのFirecrawlアカウント。** Firecrawlは、お使いのStripeアカウントのメールアドレスを参照します。未登録のメールアドレスであれば、検証済みの新しいFirecrawlアカウントが作成され、TeamとデフォルトのAPIキーが付与されます。すでにFirecrawlアカウントがあるメールアドレスの場合は、以前Stripe経由で紐付けたTeamがそのまま再利用されます。初回は独自の組織内に `via stripe` という名前のTeamが新規作成されるため、Stripeでの課金は他のFirecrawl Teamと分離されます。
* **Stripeアカウントに属する全員が、Projectsを通じて紐付けられたFirecrawlアカウントを操作できます。** これはStripeのモデルに沿った動作です。Firecrawl ダッシュボードでは、当該アカウントがStripeアカウントのメールアドレスの下に表示されます。
* **有料プランはFirecrawlのサブスクリプションです。** 支払いはShared Payment Tokenで行われ、`stripe projects spend` で利用状況が報告されます。クレジット、レート制限、機能は、firecrawl.devで同じプランを購入した場合と同一です。
* **リソースを削除するとプランも解約されます。** `stripe projects remove firecrawl` を実行すると、サブスクリプションとプランが即座に解約されます。残りの課金期間が消化されることはありません。`stripe projects upgrade firecrawl` でFreeにダウングレードした場合も同様ですが、リソースは削除されません。

<div id="coding-agents">
  ## コーディングエージェント
</div>

Stripe Projects は、人だけでなくエージェントのためにも設計されています。Stripe は、Claude Code、Cursor、Codex をはじめとするエージェントに Projects CLI の使い方を教える [skill](https://docs.stripe.com/projects#coding-agent) を公開しています。また、`stripe projects llm-context` を使うと、このページとプロジェクト内の他のすべてのプロバイダーのガイダンスがまとめて取得できます。

```bash
npx skills add https://docs.stripe.com --skill stripe-projects -g -y
```

Agent が Firecrawl をプロビジョニングする場合: slug は推測せず `stripe projects catalog firecrawl --json` からコピーし、`--name firecrawl` を渡し、`stripe projects env --pull` を実行して、`.env` を編集するのではなく環境変数の `FIRECRAWL_API_KEY` を使用してください。有料プランへのアップグレードは Stripe アカウントのカードに請求が発生するため、人間に任せてください。`--accept-tos` は人間に代わって [Firecrawl 利用規約](https://www.firecrawl.dev/terms-of-service) に同意するものなので、事前に必ず本人へ確認してください。Agent のセットアップの残りの手順は [Build with AI](/ja/ai-onboarding) を参照してください。

<div id="troubleshooting">
  ## トラブルシューティング
</div>

| 表示される内容                                          | 対処方法                                                                                                       |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| `Provider connection requires re-authentication` | `stripe projects link firecrawl` を実行してからリトライしてください。                                                        |
| `Unknown provider or category: firecrawl`        | `stripe plugin upgrade projects` を実行し、続けて `stripe projects catalog firecrawl --refresh` を実行してください。         |
| 有料プランのプロビジョニングが失敗する                              | `stripe projects billing add` を実行して支払い方法を確認してください。Firecrawl アカウントですでに有料プランをご利用中の場合は、ダッシュボードから変更してください。     |
| キーが `FIRECRAWL_API_API_KEY` に設定されてしまう            | `--name` を指定せずにプロビジョニングしています。`FIRECRAWL_API_KEY` としてエクスポートするか、リソースを削除して `--name firecrawl` を付けて追加し直してください。 |

それでも解決しない場合は、エラーに含まれる Stripe の request ID を添えて [help@firecrawl.com](mailto:help@firecrawl.com) までメールでご連絡ください。
