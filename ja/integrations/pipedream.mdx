<Note>
  **Pipedream 公式アプリ:** [pipedream.com/apps/firecrawl](https://pipedream.com/apps/firecrawl/)

  スケジュール、webhook、または他のアプリをトリガーとして実行される Pipedream ワークフローに Firecrawl ステップを追加
</Note>

<div id="overview">
  ## 概要
</div>

Firecrawl の Pipedream アプリを使用すると、ワークフロー内のアクションとして、ページのスクレイピング、サイトのクロール、ウェブ検索、URL のマップ、構造化データの抽出を実行できます。

<div id="quick-start">
  ## クイックスタート
</div>

1. [Pipedream の Firecrawl アプリ](https://pipedream.com/apps/firecrawl/)を開きます
2. Firecrawl APIキーを接続します
3. 新規または既存のワークフローに Firecrawl アクションを追加します

<div id="what-you-can-do">
  ## できること
</div>

| 機能          | ユースケース                                         |
| ----------- | ---------------------------------------------- |
| **スクレイピング** | webhook またはスケジュールの実行時にページコンテンツを取得              |
| **クロール**    | 複数ページを対象とするクロールジョブを開始 (Get Crawl Data でポーリング)  |
| **検索**      | 後続の処理に備えてソースを検出                                |
| **マップ**     | サイト内の URL を一覧表示し、必要に応じて検索語で絞り込み                |
| **抽出**      | 1 つ以上の URL から構造化データを取得                         |
