<Note>
  **公式パッケージ:** [`langchain-firecrawl`](https://pypi.org/project/langchain-firecrawl/) · [ソース](https://github.com/firecrawl/langchain-firecrawl)

  LangChain から、ドキュメントローダーやエージェントツールとしてスクレイピング、クロール、マッピング、抽出、検索を実行できます
</Note>

## インストール {#install}

```bash
pip install langchain-firecrawl
```

[firecrawl.dev](https://www.firecrawl.dev/app/api-keys) からキーを取得し、環境変数に設定するか、`api_key=...` として渡します：

```bash
export FIRECRAWL_API_KEY="fc-your-api-key"
```

## ドキュメントローダー {#document-loader}

`FirecrawlLoader` は LangChain の `Document` を返します。`mode` を選択します。

| モード       | 読み込む内容    |
| --------- | --------- |
| `scrape`  | 1 ページ     |
| `crawl`   | サイト全体     |
| `map`     | 検出された URL |
| `extract` | 構造化データ    |
| `search`  | Web 検索結果  |

```python
from langchain_firecrawl import FirecrawlLoader

loader = FirecrawlLoader(url="https://www.firecrawl.dev", mode="scrape")
docs = loader.load()

print(docs[0].page_content[:200])
print(docs[0].metadata)
```

## エージェントツール {#agent-tools}

各機能は、エージェントにバインドできる `BaseTool` としても使用できます。

```python
from langchain_firecrawl import (
    FirecrawlScrape,
    FirecrawlCrawl,
    FirecrawlMap,
    FirecrawlExtract,
    FirecrawlSearch,
)

scrape = FirecrawlScrape()
result = scrape.invoke({"url": "https://www.firecrawl.dev"})
print(result["markdown"])

search = FirecrawlSearch()
print(search.invoke({"query": "best web scraping libraries", "limit": 5}))
```

## LangChain JS {#langchain-js}

`@langchain/community` の `FireCrawlLoader` は現在も v1 SDK のメソッドを呼び出しているため、現行の Firecrawl JS SDK では動作しません。対応版がリリースされるまでは、[Firecrawl Node SDK](/ja/sdks/node) を直接呼び出し、結果を LangChain の `Document` でラップしてください。

```bash
npm install firecrawl @langchain/core
```

```typescript
import Firecrawl from "firecrawl";
import { Document } from "@langchain/core/documents";

const firecrawl = new Firecrawl(); // FIRECRAWL_API_KEY を自動で読み込みます

const crawl = await firecrawl.crawl("https://firecrawl.dev", { limit: 5 });

const docs = crawl.data.map(
  (page) => new Document({ pageContent: page.markdown ?? "", metadata: page.metadata ?? {} })
);
```
