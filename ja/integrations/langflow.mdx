  ## Langflow のワークフローでウェブデータを同期する {#sync-web-data-in-langflow-workflows}

Firecrawl は、[Langflow（AI ワークフロー構築ツール）](https://www.langflow.org/) 内で利用できます。このページでは、Langflow 内の Firecrawl ブロックの設定方法と使い方を紹介します。

### Firecrawl バンドルのインストール {#installing-the-firecrawl-bundle}

Firecrawl ブロックは `lfx-firecrawl` バンドルで提供されていますが、このバンドルは Langflow のデフォルトのインストールには含まれていません。Langflow と同じ環境にインストールしてから、Langflow を再起動してください。

```bash
uv pip install lfx-firecrawl
```

このバンドルでは、**Firecrawl Scrape API**、**Firecrawl Crawl API**、**Firecrawl Map API**、**Firecrawl Search API** の4つのブロックが追加されます。各ブロックは Firecrawl API のレスポンスを `Data` として返します。各パラメータの詳細については、[Langflow Firecrawl バンドルのドキュメント](https://docs.langflow.org/bundles-firecrawl)を参照してください。

### Firecrawl ブロックでのスクレイピング {#scraping-with-firecrawl-blocks}

1. Firecrawl アカウントにログインして API キーを取得し、ブロックに入力するか、ワークフローの別の箇所から渡します。
2. 単一ページを取得するには、**Firecrawl Scrape API** ブロックを追加します。
3. スクレイピング対象の URL を入力するか、ワークフローの別の箇所から渡します。
4. 取得したい Web サイトやデータに応じて、出力フォーマットやメインコンテンツのみを返すかどうかなどのスクレイピングのオプションを設定します。これらはワークフローの別の箇所から渡すこともできます。
5. (任意) ページから構造化 JSON を取得するには、**抽出オプション** を設定します。
6. データをワークフローで活用します。

### クローリング、マッピング、検索 {#crawling-mapping-and-searching}

* **Firecrawl Crawl API** は、指定した URL とそのサブページをクロールします。上限やパスは **Crawler Options** で、ページごとの設定は **スクレイピングのオプション** で指定します。
* **Firecrawl Map API** は、1 つ以上のサイトの URL 一覧を返します。
* **Firecrawl Search API** は、クエリに基づいてウェブを検索します。任意で、結果の件数上限 (**Limit**) とロケーション (**Location**) を指定できます。
