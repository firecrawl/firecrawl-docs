<Note>
  **Lovable 公式ドキュメント:** [docs.lovable.dev/integrations/firecrawl](https://docs.lovable.dev/integrations/firecrawl)

  Firecrawl のリアルタイムなウェブデータを活用して、Lovable でアプリを構築
</Note>

<div id="overview">
  ## 概要
</div>

Lovable アプリでは、構築中のチャットや公開済みアプリで Firecrawl を使用し、Web サイトをスクレイピング・クロールして、クリーンで構造化されたコンテンツに変換できます。Firecrawl はアプリおよびチャットコネクタとして利用できます。

<div id="quick-start">
  ## クイックスタート
</div>

1. Lovable で **Connectors** を開き、**Firecrawl** を選択します
2. **Managed by Lovable** (Firecrawl アカウントは不要) で接続を追加するか、自分の Firecrawl APIキーを使用して **Use your own credentials** を選択します
3. 接続をプロジェクトにリンクし、Lovable に Firecrawl を使ったスクレイピングまたはクロールを依頼します

<div id="what-you-can-build">
  ## 構築できること
</div>

| 機能          | ユースケース                              |
| ----------- | ----------------------------------- |
| **スクレイピング** | URL をクリーンな Markdown または構造化 JSON に変換 |
| **クロール**    | サブページを含むサイト全体のページを収集                |
| **抽出**      | 商品詳細、表、メタデータなどのフィールドを抽出             |
