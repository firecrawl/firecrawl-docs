## 概要 {#overview}

Lovable アプリでは、構築中のチャットや公開済みアプリで Firecrawl を使用し、Web サイトをスクレイピング・クロールして、クリーンな Markdown や構造化データに変換できます。Firecrawl はアプリおよびチャットコネクタとして利用できます。

## クイックスタート {#quick-start}

1. Lovable で **Connectors** を開き、**Firecrawl** を選択します
2. **Managed by Lovable** (Firecrawl アカウントは不要) で接続を追加するか、自分の Firecrawl APIキーを使用して **Use your own credentials** を選択します
3. 接続をプロジェクトにリンクし、Lovable に Firecrawl を使ったスクレイピングまたはクロールを依頼します

## 構築できること {#what-you-can-build}

| 機能          | ユースケース                                        |
| ----------- | --------------------------------------------- |
| **検索**      | ウェブを検索し、ヒットしたページのコンテンツを取得                     |
| **マップ**     | クロール前にサイト上のすべての URL を一覧表示                     |
| **スクレイピング** | URL をクリーンな Markdown または構造化 JSON に変換           |
| **クロール**    | サブページを含むサイト全体のページを収集                          |
| **構造化データ**  | スクレイピングの JSON 形式を使用して、商品詳細、表、メタデータなどのフィールドを抽出 |
