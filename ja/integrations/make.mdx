<div id="firecrawl-modules-in-make">
  ## Make の Firecrawl モジュール
</div>

<AccordionGroup>
  <Accordion title="アクション（7 モジュール）" icon="bolt">
    ### Web サイトをクロール

    URL をクロールし、複数ページのコンテンツを取得します

    ***

    ### Web サイトから抽出

    LLM を使用してページから構造化データを抽出します

    ***

    ### Web サイトをスクレイピング

    URL をスクレイピングし、単一ページのコンテンツを取得します

    ***

    ### Web サイトをマップ

    オプションに基づいて複数の URL をマップします

    ***

    ### Web サイトを検索

    Firecrawl のスクレイピング機能を使用して Web 検索を実行します

    ***

    ### クロールのステータスを取得

    指定したクロールイベント ID のステータスを取得します

    ***

    ### 抽出のステータスを取得

    指定した抽出イベント ID のステータスを取得します
  </Accordion>

  <Accordion title="検索（1 モジュール）" icon="magnifying-glass">
    ### Web サイトを検索

    任意の検索クエリに対してページ全体のコンテンツを取得します
  </Accordion>

  <Accordion title="詳細設定" icon="code">
    ### API 呼び出しを実行

    カスタムユースケース向けに、認可済みの API 呼び出しを実行します
  </Accordion>
</AccordionGroup>

</div>

| ------------------- | ----------------- | ------------- |

| **Web サイトをマップ**     | URL の検出           | SEO 分析        |

  ## ベストプラクティス
</div>

<CardGroup cols={2}>
  <Card title="パフォーマンス" icon="gauge-high">

    * 戦略的にスケジュールする (毎時／毎日／毎週) 
    * 不要な実行を避けるためにフィルターを使用する
    * API使用量を管理するためにクロールの上限を設定する
    * まずFirecrawl Playgroundでテストする
  </Card>
</CardGroup>

<div id="make-vs-zapier-vs-n8n">
  ## Make vs Zapier vs n8n
</div>

| 機能         | Make              | Zapier      | n8n              |
| ---------- | ----------------- | ----------- | ---------------- |
| **セットアップ** | ビジュアルビルダー、クラウド    | ノーコード、クラウド  | セルフホストまたはクラウド    |
| **料金体系**   | オペレーションベース        | タスクごとの料金体系  | 実行回数ベース          |
| **連携**     | 3,000以上のアプリ       | 9,000以上のアプリ | 1,000以上のアプリとサービス |
| **複雑さ**    | 高度なワークフロー         | シンプルなワークフロー | 複雑なワークフロー        |
| **最適な用途**  | ビジュアルな自動化、中程度の複雑さ | 迅速な自動化      | 開発者による制御         |
| **学習曲線**   | 中程度               | 簡単          | 中程度〜高度           |

<Tip>
  **プロのヒント：** Makeは、ビジュアルなワークフロー設計と複雑な自動化に優れています。Zapier以上の制御性が必要で、n8nのコードファーストなアプローチよりもビジュアルな構築を好むチームに最適です。
</Tip>
