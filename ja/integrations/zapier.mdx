<div id="firecrawl-actions">
  ## Firecrawl アクション
</div>

| アクション              | ユースケース                        |
| ------------------ | ----------------------------- |
| **/Scrape Page**   | 単一ページのデータをすばやく取得              |
| **/Crawl Website** | 複数ページを対象とした Web サイト全体のスクレイピング |
| **/Extract Data**  | カスタムスキーマを用いた AI によるデータ抽出      |
| **/Search Data**   | 検索とスクレイピングによるリサーチの自動化         |
| **/Map Data**      | SEO 分析とサイト構造のマッピング            |

  ## クイックリファレンス
</div>

<CardGroup cols={2}>
  <Card title="はじめに" icon="play">
    1. [firecrawl.dev](https://firecrawl.dev) でアカウントを作成する
    2. APIキーを取得する
    3. Zapier でZapを作成する
    4. APIキーを使用してFirecrawlに接続する
    5. ワークフローを選択して有効化する
  </Card>

  <Card title="ベストプラクティス" icon="lightbulb">
    * 単一ページには`/Scrape Page`を使用する (高速)
    * 戦略的にスケジュールする (毎時／毎日／毎週)
    * まずFirecrawl Playgroundでテストする
    * スクレイピングの失敗に備えてエラーハンドリングを追加する
    * 不要な実行を防ぐためにフィルターを使用する
  </Card>
</CardGroup>

<div id="zapier-vs-n8n">
  ## Zapier vs n8n
</div>

| 機能         | Zapier        | n8n              |
| ---------- | ------------- | ---------------- |
| **セットアップ** | ノーコード、クラウド型   | セルフホストまたはクラウド型   |
| **価格設定**   | タスクごとの料金体系    | 実行回数ベース          |
| **連携**     | 9,000以上のアプリ   | 1,000以上のアプリとサービス |
| **最適な用途**  | 手軽な自動化、非技術者向け | カスタムロジック、開発者向け   |

<Tip>
  **プロのヒント：** まずはZapierの事前構築済みテンプレートを使い、必要に応じてカスタマイズしましょう。手軽なノーコード自動化に最適です！
</Tip>
