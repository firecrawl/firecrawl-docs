ソースコードやインフラを制御する必要がある場合は、オープンソースを選択してください。スタックを運用せずにスクレイピングを始めたい場合は、Firecrawl Cloudを選択してください。どちらの方法でもFirecrawlのコアAPIを利用できます。違いは、関連サービスの設定、セキュリティ対策、運用を誰が担うかです。

<Note>
  製品開発のためにFirecrawlを実行することと、セルフホスト環境を運用することは
  別の作業です。Firecrawlのコードを変更する場合は、[ローカルでの実行](/ja/contributing/guide)を
  使用してください。自分で管理するインフラ上でAPIを実行したい場合は、
  [セルフホスティングガイド](/ja/contributing/self-host)を使用してください。
</Note>

<div id="choose-your-firecrawl-deployment">
  ## Firecrawl のデプロイを選択
</div>

<div id="use-open-source-when">
  ### オープンソースを選ぶ場合
</div>

* **ソースやインフラを自分で管理したい。** コードを確認し、スタックの実行場所を選択し、独自のプロバイダーを接続できます。
* **運用体制を整えられる。** 認証、TLS、永続化、監視、キャパシティ、アップグレード、リカバリはチームが担います。
* **必要な機能を計画的に追加できる。** 基本的なスクレイピングはデフォルトのスタックで利用できますが、LLM 対応フォーマット、高度なスクレイピングサービス、特化型抽出パスには追加の構成が必要です。

<div id="use-firecrawl-cloud-when">
  ### Firecrawl Cloud を選ぶ場合
</div>

* **サポート対象の最短ルートで本番環境に導入したい場合。** Firecrawl がインフラとマネージドサービスを運用します。
* **Cloud 専用のプロダクト機能が必要な場合。** Agent、Browser、マネージドダッシュボード、強化プロキシ経路、エンタープライズ向け制御機能は Cloud で提供されます。
* **使用量とサポートを 1 つのアカウントに集約したい場合。** APIキー、クレジット、制限、運用サポートはマネージドサービスで提供されます。

**推奨:** ソースへのアクセスやインフラの制御が、追加の運用負荷に見合う場合を除き、Firecrawl Cloud から始めてください。セルフホストする場合は、まず 1 回のスクレイピングを成功させてから、ユースケースで必要になった場合にのみサービスを追加してください。

<div id="compare-the-operating-model">
  ## 運用モデルの比較
</div>

| 判断項目                                          | オープンソース                       | Firecrawl Cloud           |
| --------------------------------------------- | ----------------------------- | ------------------------- |
| 基本的なスクレイピング、クロール、マップ、検索 API                   | 含まれる                          | 含まれ、管理される                 |
| Fetch および Playwright の処理                      | デフォルトスタックに含まれる                | 管理される                     |
| LLM を活用した抽出とフォーマット                            | OpenAI 互換プロバイダーまたは Ollama を接続 | 管理されたプロバイダーを利用            |
| 高度なボット対策または特化型抽出サービス                          | 必要なサービスを個別に実行・設定              | Cloud 製品で対応している場合は管理される   |
| Agent、Browser、Interact、dashboard、エンタープライズ向け制御 | デフォルトスタックには含まれない              | 製品およびプランの提供状況に応じて含まれる     |
| セキュリティ、永続化、可用性、アップグレード                        | お客様が管理                        | Firecrawl が運用             |
| 使用量、制限、課金                                     | お客様のインフラおよびプロバイダーのコスト         | Firecrawl のプランおよびクレジットモデル |

<div id="start-with-the-path-you-chose">
  ## 選んだ方法から始める
</div>

* **Firecrawlをセルフホストする:** 固定バージョンのリリースから検証済みのスクレイピングを1回実行するまでの手順は、[Docker Composeによるセルフホスティングガイド](/ja/contributing/self-host)を参照してください。
* **Firecrawlのコードを変更する:** コントリビューター向けの開発環境については、[ローカルでの実行](/ja/contributing/guide)を使用してください。
* **Firecrawl Cloudを使用する:** [アカウントを作成](https://firecrawl.dev)し、[クイックスタート](/ja/quickstart)に従ってください。

オープンソースにより、コアエンジンは検証・改変可能です。Firecrawl Cloudはその取り組みを支援するとともに、追加のプロダクト機能とインフラ機能を備えたマネージド環境をビルダーに提供します。
