<div id="connect-with-oauth">
  ## OAuth で接続する
</div>

<Visibility for="humans">
  <McpClientSelector variant="human" showSeeAll={false} showHeader={false} />
</Visibility>

<Visibility for="agents">
  OAuth サーバーURL (Streamable HTTP。クライアントがブラウザでのサインインを開始します) : `https://mcp.firecrawl.dev/v2/mcp-oauth`

  * ChatGPT: 設定 &gt; Developer mode を有効化 &gt; Apps &amp; Connectors &gt; Create &gt; Authentication: OAuth &gt; サーバーURLを貼り付けます。
  * Claude.ai: 設定 &gt; Connectors &gt; カスタムコネクタを追加 &gt; サーバーURLを貼り付け、クライアントIDとクライアントシークレットは空欄のままにします。
  * Codex: `codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth` を実行後、`codex mcp login firecrawl` を実行します。
  * Claude Code: `claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth` を実行後、`/mcp` でサインインを完了します。
  * Cursor または任意のJSON設定対応クライアント: `{"mcpServers": {"firecrawl": {"url": "https://mcp.firecrawl.dev/v2/mcp-oauth"}}}`
  * OpenCode (`opencode.json`) : `{"mcp": {"firecrawl": {"type": "remote", "url": "https://mcp.firecrawl.dev/v2/mcp-oauth", "enabled": true}}}`

  人間がブラウザでのサインインを完了し、チームを承認する必要があります。サーバーURLをブラウザで直接開かないでください。
</Visibility>

<Note>
  `https://mcp.firecrawl.dev/v2/mcp-oauth` はMCPクライアント用のサーバーURLです。ブラウザで直接開くページではありません。クライアントがブラウザでのサインインフローを開始します。
</Note>

ユーザーがサインインし、Firecrawlチームを選択してアクセスを承認できる場合は、OAuthを使用します。クライアントは、Firecrawl APIキーを会話にコピーするよう求める代わりに、その接続用のトークンを受け取ります。

サインインページでチームを選択し、接続を承認します。クライアントがOAuthのクライアントIDまたはクライアントシークレットを求めた場合は、どちらも空欄のままにしてください。対応クライアントは自動的に自身を識別します。

この接続を介したリクエストには、選択したチームが使用されます。[MCP設定](https://www.firecrawl.dev/app/settings?tab=mcp)から接続を確認または取り消すことができます。

ユーザー操作なしの接続が必要な場合は、[APIキーの設定](/ja/mcp-server/keyless-api-key#add-an-api-key)を使用してください。キーをエージェントとの会話に貼り付けたり、MCP URLに含めたりしないでください。

<div id="verify-the-connection">
  ## 接続を確認する
</div>

新しいクライアントセッションを開始し、次を試してください。

```text
最新のFirecrawlのリリースノートをWebで検索し、そのソースを要約してください。
```

Firecrawl ツールが表示されない場合は、クライアントの MCP ステータスを開き、`firecrawl` が認証済みであること、および有効な Firecrawl サーバーエントリが 1 つだけであることを確認してください。

<div id="switch-an-existing-keyless-connection">
  ## 既存のキーなし接続を切り替える
</div>

既存の `firecrawl` サーバーをOAuth サーバーURLに更新または置き換えます。Firecrawlのエントリを2つ追加しないでください。変更後は、リクエストを再試行する前に新しいクライアントセッションを開始してください。

<div id="codex">
  ### Codex
</div>

以下を実行します：

```bash
codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth
codex mcp login firecrawl
```

Codex は同名の既存サーバーを置き換えます。`/mcp` を入力し、`firecrawl` が接続済みであることを確認します。

<div id="claude-code">
  ### Claude Code
</div>

Claude Code では、同じ名前の既存のサーバーは上書きされません。現在のエントリを削除してから、OAuth エントリを追加してください。

```bash
claude mcp remove firecrawl
claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

Claude Code で `/mcp` を開き、ブラウザでサインインを完了します。

<div id="other-clients">
  ### その他のクライアント
</div>

既存の`firecrawl`サーバーを編集し、URLを次のように設定します。

```text
https://mcp.firecrawl.dev/v2/mcp-oauth
```

構成を保存し、クライアントが開始したサインインを完了してから、新しいクライアントセッションを開始します。

<div id="compatibility-and-security-details">
  ## 互換性とセキュリティの詳細
</div>

<AccordionGroup>
  <Accordion title="移行中の互換性">
    `/v2/mcp` 用に発行された既存のOAuthトークンは、引き続き `/v2/mcp` で使用できます。新しい対話型接続では `/v2/mcp-oauth` を使用します。このアカウントリソース用に発行されたトークンは `/v2/mcp` では使用できません。
  </Accordion>

  <Accordion title="OAuthクライアントとリダイレクトのサポート">
    Firecrawl は、PKCEを使用するOAuth認可コードフローを採用しています。互換性のあるクライアントは、クライアントIDメタデータドキュメントまたは動的クライアント登録によって自身を識別できるため、クライアントシークレットは必要ありません。

    Firecrawl はHTTPSリダイレクトURIと、`localhost`、`127.0.0.1`、または `[::1]` を使用するループバックリダイレクトを受け付けます。ループバックリダイレクトを使用するネイティブクライアントでは、実行ごとにポートが変わる場合があります。登録済みリダイレクトURIのそれ以外の部分は完全に一致している必要があります。
  </Accordion>

  <Accordion title="トークンのスコープと有効期間">
    アクセストークンは1時間で失効します。リフレッシュトークンは、正常にリフレッシュされるとローテーションされます。各接続は、OAuthクライアント、ユーザー、チーム、スコープ、およびMCPリソースに紐付けられます。

    `/v2/mcp-oauth` 用に新たに発行されたトークンは `/v2/mcp` では使用できません。audienceが欠落している、または曖昧なトークンは拒否されます。
  </Accordion>

  <Accordion title="接続を取り消す">
    [Firecrawl 設定](https://www.firecrawl.dev/app/settings?tab=mcp)で **MCP** を開き、接続を取り消します。取り消すと、アクセストークンとリフレッシュトークンが無効になります。再度認可するには、クライアントから再接続してください。
  </Accordion>

  <Accordion title="チームの課金とアクセス">
    接続を介したリクエストでは、サインイン時に選択したチームのプランに基づき、そのチームのクレジットが消費されます。各接続は [MCP設定](https://www.firecrawl.dev/app/settings?tab=mcp)に表示され、いつでも確認や取り消しができます。SSOおよび組織全体の管理については、[Enterprise](/ja/enterprise)を参照してください。
  </Accordion>
</AccordionGroup>
