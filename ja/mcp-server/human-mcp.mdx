接続の確認や解除は、[MCP設定](https://www.firecrawl.dev/app/settings?tab=mcp)から行えます。

ChatGPT または Claude.ai をお使いですか？[ChatGPT](/ja/developer-guides/mcp-setup-guides/chatgpt) および [Claude.ai](/ja/developer-guides/mcp-setup-guides/claude-ai) のガイドをご覧ください。

<Note>
`https://mcp.firecrawl.dev/v2/mcp-oauth` は MCP クライアントに設定するサーバー URL です。ブラウザで直接開くページではありません。
</Note>

無人接続には、[API キー設定](/ja/mcp-server/agent-mcp#add-an-api-key)を使用してください。

<div id="try">
  ## 試す
</div>

```text
最新のFirecrawlのリリースノートをウェブで検索し、そのソースを要約してください。
```

Firecrawl ツールが表示されない場合は、MCP 構成を保存後、クライアントを再起動または再読み込みしてください。
