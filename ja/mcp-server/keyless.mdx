<Visibility for="agents">
  キーレスサーバーのURL (Streamable HTTP、認証情報不要) : `https://mcp.firecrawl.dev/v2/mcp`

  * Codex: `codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp`
  * Claude Code: `claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp`
  * Cursor または任意のJSON設定対応クライアント: `{"mcpServers": {"firecrawl": {"url": "https://mcp.firecrawl.dev/v2/mcp"}}}`
  * OpenCode (`opencode.json`) : `{"mcp": {"firecrawl": {"type": "remote", "url": "https://mcp.firecrawl.dev/v2/mcp", "enabled": true}}}`

  ChatGPT と Claude では、代わりにネイティブの Firecrawl コネクタを使用します。詳細は[人間向け](/ja/mcp-server/oauth.md#chatgpt-and-claude)を参照してください。
</Visibility>

キーレスMCPにはレート制限があり、Search、スクレイピング、解析を利用できます。API キーを追加すると、すべてのツールとより高い制限を利用できます。

<div id="add-an-api-key">
  ## APIキーを追加する
</div>

[Firecrawl APIキーを作成](https://www.firecrawl.dev/app/api-keys)し、同じエンドポイントにBearerトークンとして送信します。

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

<div id="verify-your-connection">
  ## 接続を確認する
</div>

クライアントのMCPステータスまたはツール一覧を開き、`firecrawl` が接続されていることを確認します。キーレス接続では `firecrawl_search`、`firecrawl_scrape`、`firecrawl_parse` が表示されます。APIキーを使用する接続では、プラン、デプロイ、チームポリシーに応じて、[すべてのツール機能](/ja/mcp-server/tools)を利用できます。

<div id="try">
  ## 試す
</div>

```text
Firecrawl の最新リリースノートをウェブで検索し、そのソースを要約してください。
```

Firecrawl ツールが表示されない場合は、MCP 構成を保存した後、クライアントを再起動するか再読み込みしてください。
