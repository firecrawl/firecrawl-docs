<div id="development">
  ## 開発
</div>

```bash
# 依存関係をインストール
npm install

# ビルド
npm run build

# テストを実行
npm test
```

<div id="contributing">
  ### コントリビューション
</div>

1. リポジトリをフォークする
2. 機能ブランチを作成する
3. テストを実行する：`npm test`
4. プルリクエストを作成する
