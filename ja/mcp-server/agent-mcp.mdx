<div id="try-keyless">
  ## キーなしで試す
</div>

<McpClientSelector variant="agent" showSeeAll={false} />

キーなしのMCPはレート制限があり、Search、Scrape、Parseを利用できます。APIキーを追加すると、すべてのツールとより高い制限を利用できます。

<div id="add-an-api-key">
  ## APIキーを追加する
</div>

[Firecrawl APIキーを作成](https://www.firecrawl.dev/app/api-keys)し、同じエンドポイントにベアラートークンとして送信します。

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

<div id="verify-your-connection">
  ## 接続を確認する
</div>

クライアントのMCPステータスまたはツール一覧を開き、`firecrawl`が接続されていることを確認します。キーなし接続では、`firecrawl_search`、`firecrawl_scrape`、`firecrawl_parse`が表示されます。APIキー接続では、プラン、デプロイ環境、チームポリシーに応じて、[すべてのツール](/ja/mcp-server/tools)を利用できます。

<div id="try">
  ## 試す
</div>

```text
最新のFirecrawlのリリースノートをウェブで検索し、ソースを要約してください。
```

Firecrawl ツールが表示されない場合は、MCP 構成を保存した後、クライアントを再起動するか再読み込みしてください。
