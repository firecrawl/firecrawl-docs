---
title: "Developer Index を検索"
openapi: "/ja/api-reference/v2-openapi.json GET /search/developer"
---

GitHub issue、マージ済みのプルリクエスト、リポジトリの README、厳選されたドキュメントサイトを検索します。結果は関連度順に表示され、一致した本文箇所が Markdown 形式で含まれます。

配列フィルターを JSON として渡す場合は、同じパスで `POST` を使用できます。

ワークフローの概要については、[Developer Index ガイド](/ja/features/developer)を参照してください。
