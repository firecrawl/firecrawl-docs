この search エンドポイントは、Web 検索と Firecrawl のスクレイピング機能を組み合わせることで、あらゆるクエリに対してページ全体のコンテンツを返します。

各検索結果の Markdown 形式の完全なコンテンツを取得するには、`scrapeOptions` に `formats: [{"type": "markdown"}]` を指定してください。指定しない場合は、結果 (url、title、description) がデフォルトで返されます。要約されたコンテンツが必要な場合は、`{"type": "summary"}` など他のフォーマットも使用できます。

<div id="supported-query-operators">
  ## サポートされているクエリ演算子 {#supported-query-operators}
</div>

検索をより的確に絞り込むための各種クエリ演算子をサポートしています。

| 演算子 | 機能 | 例 |
---|-|-|
| `""` | テキストを厳密一致で検索する | `"Firecrawl"`
| `-` | 特定のキーワードを除外、または他の演算子を否定する | `-bad`, `-site:firecrawl.dev`
| `site:` | 指定したサイトの結果のみを返す | `site:firecrawl.dev`
| `filetype:` | 特定のファイル拡張子を持つ結果のみを返す | `filetype:pdf`, `-filetype:pdf`
| `inurl:` | URL に特定の語を含む結果のみを返す | `inurl:firecrawl`
| `allinurl:` | URL に複数の語を含む結果のみを返す | `allinurl:git firecrawl`
| `intitle:` | ページタイトルに特定の語を含む結果のみを返す | `intitle:Firecrawl`
| `allintitle:` | ページタイトルに複数の語を含む結果のみを返す | `allintitle:firecrawl playground`
| `related:` | 特定のドメインに関連する結果のみを返す | `related:firecrawl.dev`
| `imagesize:` | 指定した寸法と完全一致の画像のみを返す | `imagesize:1920x1080`
| `larger:` | 指定した寸法より大きい画像のみを返す | `larger:1920x1080`

<div id="location-parameter">
  ## Location パラメータ {#location-parameter}
</div>

`location` パラメータで地域ターゲットの検索結果を取得します。形式: `"string"`。例: `"Germany"`、`"San Francisco,California,United States"`。

利用可能な国と言語の一覧は、[サポート対象ロケーションの全リスト](https://firecrawl.dev/search_locations.json)をご覧ください。

<div id="country-parameter">
  ## Country パラメータ {#country-parameter}
</div>

`country` パラメータで、ISO の国コードを用いて検索結果の対象国を指定します。既定値: `"US"`。

例: `"US"`, `"DE"`, `"FR"`, `"JP"`, `"UK"`, `"CA"`。

```json
{
  "query": "レストラン",
  "country": "DE"
}
```

## Categories Parameter {#categories-parameter}

`categories` パラメータを使うと、search results を特定のカテゴリで絞り込めます。

* **`research`**: web search を学術・研究 Web サイト (arxiv.org、nature.com、pubmed.ncbi.nlm.nih.gov など) に限定します。2026-11-16 より [Research Index](/ja/features/research) を検索して paper レコードを返す仕様に変わります。詳細は以下の警告を参照してください
* **`pdf`**: PDF を検索します
* **`developer`**: [Developer Index](/ja/features/developer) を検索します — 公開コードリポジトリの issues、マージ済みのプルリクエスト、README に加え、厳選されたドキュメントサイトが対象です

<Warning>
  **`research` カテゴリは 2026-11-16 に変更されます。** web の結果を 14 の学術 Web サイトに絞り込むのではなく、[Research Index](/ja/features/research) (PubMed、bioRxiv、medRxiv、arXiv) を検索するようになります。結果は `data.web` から `data.research` へ移り、paper レコードとして返されます: `paperId`、`primaryId`、`ids`、`title`、`abstract`、`score`。それまでの間、このカテゴリを使用するレスポンスにはすべて `warnings` エントリが含まれます。

  paper レコードが必要な場合は、この日付までに parsing を更新するか、今すぐ [`GET /search/research/papers`](/ja/api-reference/endpoint/research-search-papers) を呼び出してください。学術サイトの Web ページが必要な場合は、[`includeDomains`](#domain-filters) に切り替えてください。
</Warning>

### 使い方の例 {#example-usage}

```json
{
  "query": "機械学習",
  "categories": ["research", "pdf"],
  "limit": 10
}
```

## ドメインフィルター {#domain-filters}

`includeDomains` を使うと結果を特定のドメインに限定でき、`excludeDomains` を使うと検索結果から特定のドメインを除外できます。ドメインには、プロトコルやパスを含めず、ホスト名のみを指定してください。

`includeDomains` と `excludeDomains` は同時に使用できません。

### 含めるドメインの例 {#include-domains-example}

```json
{
  "query": "web scraping",
  "includeDomains": ["firecrawl.dev", "docs.firecrawl.dev"],
  "limit": 10
}
```

### 除外ドメインの例 {#exclude-domains-example}

```json
{
  "query": "web scraping tools",
  "excludeDomains": ["example.com"],
  "limit": 10
}
```

### カテゴリレスポンス {#category-response}

各結果には、どのソースからのものかを示す `category` フィールドが含まれます。

```json
{
  "success": true,
  "data": {
    "web": [
      {
        "url": "https://arxiv.org/abs/2024.12345",
        "title": "ML Research Paper",
        "description": "Latest advances in machine learning",
        "category": "research"
      },
      {
        "url": "https://example.com/ml-survey.pdf",
        "title": "ML Survey",
        "description": "A survey of machine learning methods",
        "category": "pdf"
      }
    ]
  }
}
```

## 時間ベースの検索 {#time-based-search}

`tbs` パラメータを使用すると、カスタム日付範囲を含む期間で検索結果を時間別に絞り込むことができます。詳細な例とサポートされている形式については、[検索機能のドキュメント](https://docs.firecrawl.dev/features/search#time-based-search)を参照してください。

> Firecrawl API key が必要な AI agent ですか？自動オンボーディング手順については、[firecrawl.dev/agent-onboarding/SKILL.md](https://www.firecrawl.dev/agent-onboarding/SKILL.md)を参照してください。
