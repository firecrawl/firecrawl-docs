---
title: '解析フォーマット'
openapi: '/ja/api-reference/v2-openapi.json GET /parse/formats'
---

[`/parse`](/ja/api-reference/endpoint/parse) が受け付けるすべてのファイルフォーマットを、ファイル拡張子と MIME タイプとあわせて一覧表示します。この一覧は `/parse` がアップロードの検証に使用するルールと同じルールから生成されます。そのため、サポートされているファイル形式の一覧を独自に管理しなくても、送信前にファイルをチェックできます。

各エントリの `kind` は `document` または `image` のいずれかです。画像フォーマットは OCR で処理されます。画像 OCR が有効になっていない環境では、画像フォーマットに `available: false` が設定され、OCR が有効になるまでそれらのフォーマットのアップロードは `UNSUPPORTED_FILE_TYPE` で拒否されます。

この一覧が変更されることはほとんどありません。レスポンスには `Cache-Control: private, max-age=3600` が付与されるため、最大 1 時間キャッシュしても問題ありません。
