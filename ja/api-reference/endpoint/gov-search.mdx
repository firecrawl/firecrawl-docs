---
title: "Government Index を検索する"
openapi: "/ja/api-reference/v2-openapi.json GET /search/gov"
---

米国の連邦・州・地方自治体のソースから、法令、規則、法典、裁判所の判決、その他の政府刊行物などの一次法源や規制資料を検索します。結果は標準の `web` グループで返され、[`/search`](/ja/api-reference/endpoint/search) の web 結果と同じ形式です。

同じパスで `POST` も使用でき、同じフィールドを JSON ボディで指定します。未定義のフィールドや絞り込むための無効な値を指定すると `400` エラーが返され、修正が必要な値がエラーメッセージに示されます。

`query` は必須です。わかっている場合は、管轄区域、機関名または法令の引用番号、関連する日付を含めてください。`k` は取得する結果の件数で、1〜100 の範囲で指定します (デフォルトは 10) 。通常の `/search` では、代わりに `limit` を使用します。

結果は一致した抜粋であり、過去のバージョン、法案本文、ガイダンス、第三者による転載が含まれる場合があります。現行の適用法として引用する前に、発行元、管轄区域、制定・施行状況、バージョンを必ず確認してください。スニペットだけでは情報が不十分な場合は、該当する結果の元となるソースを確認してください。このインデックスは米国の資料が中心です。ヒットしなかった場合でも、適用される法律が存在しないとは限りません。

## フィルター {#filters}

すべてのフィルターは任意で、AND 条件で組み合わされます。

| フィールド          | 次の条件を満たすページのみを残します                                                                                                                                                                                                               |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `jurisdiction` | 1 つの管轄区域に属するページ。連邦の場合は `us`、州または準州の場合は `us-` に 2 文字のコードを付けたもの (例: `us-ca`、`us-dc`) を指定します。                                                                                                                                       |
| `court`        | 特定の 1 つの裁判所のラベルが付いたページ。CourtListener の裁判所 ID (例: `scotus`、`ca9`、`nysd`) で指定します。                                                                                                                                                  |
| `courtType`    | 特定の種類の裁判所によるページ。`federal-supreme`、`federal-appellate`、`federal-district`、`federal-bankruptcy`、`federal-special`、`military`、`state-supreme`、`state-appellate`、`state-trial`、`state-special`、`state-attorney-general` のいずれかを指定します。 |
| `cites`        | 特定の 1 つの法律または判例を引用しているページ。`42 U.S.C. § 1983` や `5 U.S. 137` のような表記どおりの引用、または `us:usc:42:1983` のような引用 ID で指定します。                                                                                                                  |
| `domain`       | 特定の 1 つのサイト (例: `irs.gov`) のページ。                                                                                                                                                                                                 |

フィルターはインデックスでラベル付けされたページのみを残すため、フィルターを適用した検索では関連するページが除外される場合があります。結果がない場合でも、該当するページが存在しないとは限りません。裁判所のラベルは、連邦裁判所と判例法コレクションで最も網羅されています。

<CodeGroup>
  ```bash cURL
  # APIキーなしですぐに試せます。より高いレート制限を利用するには -H "Authorization: Bearer $FIRECRAWL_API_KEY" を追加してください:
  curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
  ```

  ```bash cURL (POST)
  curl -X POST https://api.firecrawl.dev/v2/search/gov \
    -H "Authorization: Bearer $FIRECRAWL_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "query": "food labeling requirements for allergens",
      "k": 10
    }'
  ```
</CodeGroup>

ワークフローの概要については、[Government Index ガイド](/ja/features/gov)を参照してください。
