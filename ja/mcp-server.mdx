<div id="add-an-api-key">
  ## APIキーを追加する
</div>

[Firecrawl APIキーを作成](https://www.firecrawl.dev/app/api-keys)し、Bearerトークンとして送信します。

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

キーは MCP URL ではなく、環境変数またはクライアントのシークレットストレージで設定してください。

<Note>
  これは MCP クライアント用のサーバー URL であり、ブラウザで直接開くページではありません。サインイン接続には代わりに `https://mcp.firecrawl.dev/v2/mcp-oauth` を使用します。クライアントがブラウザフローを開始します。
</Note>
