接続の実行方法に合わせて設定を選んでください。人間かエージェントかを先に分類する必要はありません。

<Card title="すぐに試す" icon="bolt" href="/ja/mcp-server/agent-mcp">
  アカウントやキーなしで Search、Scrape、Parse を利用できます。上限は同じ公開 IP の利用者間で共有されます。
</Card>

<Card title="OAuth で接続" icon="right-to-bracket" href="/ja/mcp-server/human-mcp">
  対話型クライアントからサインインし、チームを選択して接続を承認します。
</Card>

<Card title="API キーを使用" icon="key" href="/ja/mcp-server/agent-mcp">
  シークレットをチャットやソースコードに置かず、エージェント、CI、バックエンド向けの安定した接続を設定します。
</Card>

[利用可能なツール](/ja/mcp-server/tools)を確認するか、[MCP をローカルで実行](/ja/mcp-server/local)してください。
