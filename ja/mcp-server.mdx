Firecrawl MCPは、Model Context Protocol (MCP) を通じてAIクライアントにリアルタイムのWebデータへのアクセスを提供します。ホスト型サービスまたはオープンソースのローカルサーバーとして利用できます。

<div id="start-here">
  ## まずはこちら
</div>

Firecrawl の実行環境に応じて接続モードを選択します。ホスト型エンドポイントの URL には認証情報は不要です。認証情報は OAuth フローまたは Authorization ヘッダーで指定し、URL 自体には決して含めないでください。

<CardGroup cols={3}>
  <Card title="アカウントに接続" icon="user" href="/ja/mcp-server/connect">
    インタラクティブな MCP クライアントで Firecrawl のすべてのツールを利用するには、ブラウザベースの OAuth を使用します。

  <Card title="無人実行" icon="server" href="/ja/mcp-server/connect#run-unattended">
    CI、サーバー、スクリプトでは、Authorization ヘッダーに Firecrawl APIキーを指定して `/v2/mcp` を使用します。
  </Card>

  <Card title="キーなしで MCP を試す" icon="sparkles" href="/ja/mcp-server/connect#try-keyless">

  </Card>
</CardGroup>
