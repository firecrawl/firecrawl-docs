<div id="sign-in">
  ## サインイン
</div>

クライアントの接続先を OAuth サーバーURL に設定します。クライアントがブラウザウィンドウを開くので、そこで Firecrawl にサインインし、Team を承認します。

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

APIキーやヘッダーは不要です。接続の確認や取り消しは[MCP設定](https://www.firecrawl.dev/app/settings?tab=mcp)から行えます。

<Note>
  これはMCPクライアントに設定するサーバーURLであり、ブラウザで直接開くためのページではありません。APIキーを使う接続では、代わりに`https://mcp.firecrawl.dev/v2/mcp`をbearer tokenとともに使用します。[APIキーを追加する](/ja/mcp-server/keyless#add-an-api-key)を参照してください。
</Note>
