接続の実行方法に合った設定を選択してください。人間かエージェントかを選ぶ必要はありません。

  <Card title="アカウントでサインイン" icon="right-to-bracket" href="/ja/mcp-server/oauth" cta="アカウントを接続" arrow>

  </Card>

ホスト型のキー不要サーバーおよび API キーサーバーの URL は次のとおりです。

```text
https://mcp.firecrawl.dev/v2/mcp
```

<Note>
  これはMCPクライアント用のサーバーURLであり、ブラウザで直接開くページではありません。OAuthでは別のサーバーURLを使用し、クライアント側でブラウザによるサインインフローが開始されます。
</Note>

APIキーを使用する場合は、MCP URL、エージェントとの会話、コミット済みのプロジェクトファイルに絶対に含めないでください。環境変数またはクライアントのシークレットストレージで設定してください。

<div id="fix-a-broken-connection">
  ## 切断された接続を修復する
</div>

Firecrawl のエラーに `KEYLESS_QUOTA_EXHAUSTED`、`KEYLESS_TOOL_NOT_AVAILABLE`、`KEYLESS_ACCESS_NOT_AVAILABLE`、`KEYLESS_ELIGIBILITY_UNAVAILABLE`、`CREDENTIAL_INVALID`、`OAUTH_CONNECTION_INVALID`、または認証情報が「無効または失効している」と表示された場合は、このセクションを参照してください。

* **キー不要の上限に到達:** エラーに `retry_after_seconds` がある場合はその秒数だけ待つか、人間のオペレーターに OAuth 接続または API キーの設定を依頼してください。上限がリセットされると、Search、Scrape、Parse は引き続き利用できます。
* **キー不要アクセスを利用できない:** `KEYLESS_ELIGIBILITY_UNAVAILABLE` の場合は、示された時間が経過してから再試行してください。問題が解消しない場合、またはエラーが `KEYLESS_ACCESS_NOT_AVAILABLE` の場合は、人間のオペレーターに OAuth 接続または API キーの設定を依頼してください。
* **キー不要ではツールを利用できない (`KEYLESS_TOOL_NOT_AVAILABLE`) :** ツール自体は存在しますが、キー不要で利用可能な機能には含まれていません。使用するには OAuth に接続するか、API キーを設定してください。Search、Scrape、Parse はキー不要でも引き続き使用できます。
* **API キーが無効または失効している:** 人間またはシステムのオペレーターが、エージェントとの会話外で既存のサーバー構成にあるキーを置き換える必要があります。
* **`/v2/mcp` の OAuth 接続が無効:** 既存のサーバーに API キーを追加するか、URL を `https://mcp.firecrawl.dev/v2/mcp-oauth` に変更してクライアントからサインインしてください。この URL をブラウザーで直接開かないでください。
* **`/v2/mcp-oauth` の OAuth 接続が無効:** クライアントのアカウント接続フローから再度サインインしてください。

認証情報またはサーバー URL を変更した後は、`firecrawl` サーバーエントリを 1 つだけ残し、新しいクライアントセッションを開始してから再試行してください。具体的な手順については、[OAuth 接続](/ja/mcp-server/oauth#switch-an-existing-keyless-connection) または [API キーのセットアップ](/ja/mcp-server/keyless-api-key#add-an-api-key) を参照してください。
