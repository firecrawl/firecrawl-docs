Firecrawl の MCP を使って、Factory AI にウェブスクレイピングと検索機能を追加します。

<div id="quick-setup">
  ## クイックセットアップ {#quick-setup}
</div>

<div id="1-get-your-api-key">
  ### 1. APIキーを取得する {#1-get-your-api-key}
</div>

[firecrawl.dev/app](https://firecrawl.dev/app) に登録し、APIキーをコピーします。

### 2. Factory AI CLI をインストールする {#2-install-factory-ai-cli}

まだインストールしていない場合は、[Factory Droid CLI](https://docs.factory.ai/droid-cli/quickstart) をインストールしてください：

**macOS/Linux:**

```bash
curl -fsSL https://app.factory.ai/cli | sh
```

**Windows (ウィンドウズ) :**

```powershell
irm https://app.factory.ai/cli/windows | iex
```

### 3. Firecrawl MCP サーバーを追加する {#3-add-firecrawl-mcp-server}

ターミナルで `droid mcp add` を実行し、ホスト型の Firecrawl MCP サーバーを追加します。

```bash
droid mcp add firecrawl https://mcp.firecrawl.dev/v2/mcp --type http \
  --header "Authorization: Bearer your-api-key-here" --no-oauth
```

`your-api-key-here` を実際のFirecrawl APIキーに置き換えてください。

サーバーをローカルで実行する場合は、代わりに stdio サーバーとして追加します：

```bash
droid mcp add firecrawl "npx -y firecrawl-mcp@3.33.2" --env FIRECRAWL_API_KEY=your-api-key-here
```

Droid 内で `/mcp` と入力すると、サーバーのステータスを確認したり、利用可能なツールを参照したりすることもできます。

### 4. 完了！ {#4-done}

Firecrawl ツールが Factory AI セッションで利用できるようになりました！
