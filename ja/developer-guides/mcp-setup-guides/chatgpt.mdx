---
title: "ChatGPT で Firecrawl MCP を使用する"
description: "ネイティブコネクタで Firecrawl を ChatGPT に追加する"
---

ネイティブの Firecrawl アプリを使って、Firecrawl を ChatGPT に追加できます。カスタム MCP コネクタを作成したり、サーバー URL を貼り付けたりする必要はありません。

## ChatGPTに追加 {#add-to-chatgpt}

<Card title="ChatGPTに追加" icon="/images/agent-clients/chatgpt.svg" href="https://chatgpt.com/plugins?q=firecrawl" cta="ChatGPTで開く" arrow>
  ChatGPTでFirecrawlアプリを開いて接続します。
</Card>

1. [ChatGPTのFirecrawlアプリ](https://chatgpt.com/plugins?q=firecrawl)を開きます。
2. **Firecrawl** を選択して接続します。ChatGPTがブラウザでFirecrawlを開いたら、サインインし、チームを選択してアクセスを承認します。
3. チャットで **+** メニューを開き、プロンプトを送信する前に **Firecrawl** を有効にします。コネクタは会話に追加されている必要があります。

Firecrawl APIキーをサーバーURLに入力しないでください。後でアクセスを取り消すには、[MCP設定](https://www.firecrawl.dev/app/settings?tab=mcp)を使用します。

## 試す {#try}

Firecrawl を有効にして、次を試してください:

```text
Search the web for the latest Firecrawl release notes and summarize the sources.
```

```text
Scrape firecrawl.dev and tell me what it does
```
