---
title: "ChatGPT で Firecrawl MCP を使用する"
description: "ネイティブプラグインで Firecrawl を ChatGPT に追加する"
---

ネイティブの Firecrawl プラグインを使って Firecrawl を ChatGPT に追加すると、チャットからウェブの検索、スクレイピング、クロール、操作、監視を行えます。カスタム MCP コネクタを作成したり、サーバー URL を貼り付けたりする必要はありません。

## ChatGPTに追加する {#add-to-chatgpt}

<Card title="ChatGPTに追加" icon="/images/agent-clients/chatgpt.svg" href="https://chatgpt.com/plugins/plugin_asdk_app_6a314a73f8ac819195b0d55e36b9c609?q=firecrawl" cta="ChatGPTで開く" arrow>
  ChatGPTでFirecrawlプラグインを開いてインストールします。
</Card>

1. [ChatGPTのFirecrawlプラグイン](https://chatgpt.com/plugins/plugin_asdk_app_6a314a73f8ac819195b0d55e36b9c609?q=firecrawl)を開くか、ChatGPTで **Plugins** を開いて **Firecrawl** を検索します。
2. **Install** を選択します。ChatGPTがブラウザーでFirecrawlを開いたら、サインインしてチームを選択し、アクセスを承認します。
3. 新しいチャットを開始してChatGPTにプラグインを読み込ませ、Firecrawlを使用するよう指示します。

同じプラグインはCodexでも使用できます。詳細とトラブルシューティングについては、[ChatGPT &amp; Codex](/ja/integrations/chatgpt-codex) を参照してください。

サーバーURLにFirecrawl APIキーを含めないでください。後からアクセスを取り消すには、[MCP設定](https://www.firecrawl.dev/app/settings?tab=mcp)を使用します。

## 試す {#try}

Firecrawl を有効にして、次を試してください:

```text
Search the web for the latest Firecrawl release notes and summarize the sources.
```

```text
Scrape firecrawl.dev and tell me what it does
```
