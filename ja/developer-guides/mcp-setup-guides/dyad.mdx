---

[Dyad](https://www.dyad.sh) に Firecrawl を追加すると、アプリビルダーの AI がウェブを検索・スクレイピングし、ウェブと対話的にやり取りできるようになります。

<Note>
  「Add to Dyad」リンクを使用するには、Dyad v0.25 以降が必要です。
</Note>

## 1. APIキーを取得する {#1-get-your-api-key}

[firecrawl.dev/app/api-keys](https://www.firecrawl.dev/app/api-keys) でキーを作成します。キーはリンクに含めるのではなく、Dyad 上で入力します。

## 2. Dyad に Firecrawl を追加する {#2-add-firecrawl-to-dyad}

トランスポートを1つ選択します。

    `https://mcp.firecrawl.dev/v2/mcp` に接続します。インストールは不要です。

  <Card title="ローカル（npx）" icon="terminal" href="dyad://add-mcp-server?name=Firecrawl&config=eyJjb21tYW5kIjoibnB4IC15IGZpcmVjcmF3bC1tY3AiLCJ1cmwiOm51bGwsInR5cGUiOiJzdGRpbyJ9">

</CardGroup>

リンクをクリックすると Dyad が起動し、フォームに入力済みの状態で **Plugins** ページが開きます。**Add** をクリックしたら、選択したトランスポートに応じたキーの設定を完了してください。

### ホスト型 (HTTP) {#hosted-http}

1. フォームで **Use OAuth** をオフにします。
2. 追加したら、新しいプラグインを開いて次のヘッダーを追加します。

   | ヘッダー            | 値                               |
   | --------------- | ------------------------------- |
   | `Authorization` | `Bearer YOUR_FIRECRAWL_API_KEY` |

### ローカル (npx) {#local-npx}

追加したら、新しいプラグインを開いて次の環境変数を設定します。

| 変数                  | 値                        |
| ------------------- | ------------------------ |
| `FIRECRAWL_API_KEY` | `YOUR_FIRECRAWL_API_KEY` |

## 3. 試してみる {#3-try-it}

Dyad のチャットで、次のように入力してみてください：

```text
ウェブを検索して最新の Next.js のリリースノートを探し、ソースを要約してください。
```

```text
https://firecrawl.dev をスクレイピングして、このページで提供されている内容を説明してください。
```

## 手動で追加する {#add-it-by-hand}

**Plugins** を開いて **Add Plugin** をクリックし、以下のいずれかの値を入力します。

| トランスポート | フィールド                                                                                      |
| ------- | ------------------------------------------------------------------------------------------ |
| `http`  | URL `https://mcp.firecrawl.dev/v2/mcp`、ヘッダー `Authorization: Bearer YOUR_FIRECRAWL_API_KEY` |
| `stdio` | コマンド `npx`、引数 `-y firecrawl-mcp`、環境変数 `FIRECRAWL_API_KEY=YOUR_FIRECRAWL_API_KEY`           |

ツールの全一覧については、[MCP サーバーリファレンス](/ja/mcp-server)を参照してください。
