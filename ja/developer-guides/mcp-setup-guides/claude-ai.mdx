ネイティブのFirecrawlコネクタを使って、Claude.aiにFirecrawlを追加します。カスタムコネクタを追加したり、サーバーURLを貼り付けたりする必要はありません。

<Note>
  Claude Codeのセットアップをお探しですか？代わりに[Claude Code
  ガイド](/ja/quickstarts/claude-code)をご覧ください。
</Note>

## Claude に追加 {#add-to-claude}

<Card title="Claude に追加" icon="/images/agent-clients/claude-ai.svg" href="https://claude.ai/directory/connectors/firecrawl" cta="Claude で開く" arrow>
  Claude.ai で Firecrawl コネクタを開き、接続します。
</Card>

1. [Claude.ai の Firecrawl コネクタ](https://claude.ai/directory/connectors/firecrawl)を開きます。
2. Firecrawl に接続します。Claude がブラウザで Firecrawl を開いたら、サインインし、チームを選択してアクセスを承認します。
3. 会話で **+** メニューを開き、**Connectors** に移動して Firecrawl を有効にします。

Team または Enterprise プランでは、メンバーが接続する前に組織の Owner がコネクタを許可する必要がある場合があります。

このコネクタ経由のリクエストでは、サインイン時に選択したチームのクレジットとプランが使用されます。[MCP settings](https://www.firecrawl.dev/app/settings?tab=mcp)から、いつでも接続を確認または取り消せます。

## 試す {#try}

Firecrawlを有効にした状態で、次を試してください。

```text
Search the web for the latest Firecrawl release notes and summarize the sources.
```

```text
Scrape firecrawl.dev and tell me what it does
```
