<Visibility for="agents">
  Streamable HTTP 経由で接続します。キーなしで利用できるサーバー URL (Search、スクレイピング、解析 用、認証情報不要) は `https://mcp.firecrawl.dev/v2/mcp` です。

  * Codex: `codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp`
  * Claude Code: `claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp`
  * Cursor または任意の JSON 設定対応クライアント: `{"mcpServers": {"firecrawl": {"url": "https://mcp.firecrawl.dev/v2/mcp"}}}`
  * OpenCode (`opencode.json`) : `{"mcp": {"firecrawl": {"type": "remote", "url": "https://mcp.firecrawl.dev/v2/mcp", "enabled": true}}}`
  * ChatGPT または Claude.ai: 標準の Firecrawl コネクタを使用します — [ChatGPT](https://chatgpt.com/plugins?q=firecrawl) または [Claude](https://claude.ai/directory/connectors/firecrawl)。

  両方のセットアップ方法と API キーの設定については、[MCP Get Started](/ja/mcp-server.md)、[For Agents](/ja/mcp-server/keyless.md)、および [For Humans](/ja/mcp-server/oauth.md)を参照してください。
</Visibility>

<div id="install-the-firecrawl-cli">
  ### Firecrawl CLIをインストールする
</div>

1 つのコマンドで、Firecrawl CLIをインストールし、ブラウザで認証して、検出されたすべてのコーディングエージェントにスキルを追加できます。

```bash
npx -y firecrawl-cli@latest init --all --browser
```

<Note>
  セットアップ後に、コーディングエージェントを再起動して、新しいスキルを認識できるようにしてください。セットアップ方法の詳細は
  [CLI](/ja/sdks/cli) を参照してください。
</Note>

<div id="why-firecrawl">
  ### なぜ Firecrawl なのか？
</div>

* **LLM対応の出力**: クリーンなMarkdown、構造化 JSON、スクリーンショットなどを出力できます。
* **複雑なケースにも対応**: プロキシ、アンチボット、JavaScriptレンダリング、動的コンテンツに対応します。
* **高い信頼性**: 高い稼働率と安定した結果を実現し、本番運用向けに設計されています。
* **高速**: 数秒で結果を返し、高スループット向けに最適化されています。
* **MCP Server**: [Model Context Protocol (MCP) ](/ja/mcp-server) を介して、FirecrawlをあらゆるAIツールに接続できます。
