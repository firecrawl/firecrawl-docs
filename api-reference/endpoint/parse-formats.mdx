---
title: 'Parse Formats'
openapi: '/api-reference/v2-openapi.json GET /parse/formats'
---

Lists every file format [`/parse`](/api-reference/endpoint/parse) accepts, with its file extensions and MIME types. The list is built from the same rules `/parse` uses to validate uploads, so you can check a file before sending it instead of keeping your own copy of the supported types.

Each entry has a `kind` of `document` or `image`. Image formats are OCR'd and carry `available: false` where image OCR is not enabled; uploads of those formats are rejected with `UNSUPPORTED_FILE_TYPE` until it is.

The list changes rarely. Responses carry `Cache-Control: private, max-age=3600`, so caching them for up to an hour is safe.
