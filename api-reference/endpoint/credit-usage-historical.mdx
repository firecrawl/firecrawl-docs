---
title: 'Historical Credit Usage'
openapi: '/api-reference/v2-openapi.json GET /team/credit-usage/historical'
---

Returns your team's credit usage over the last 90 days, one period per calendar month by default. Set `bin=day` to get one period per UTC day instead.

To see where credits went, break usage down with `byApiKey=true` (by API key) or `byEndpoint=true` (by the endpoint that billed it, such as `scrape`, `search` or `crawl`). You can combine either breakdown with `bin`, but not with each other: passing both returns a `400`.

The `byEndpoint` breakdown includes search usage, which the totals and the `byApiKey` breakdown do not count. A period's `byEndpoint` rows can therefore add up to more than its total.
