---
title: "Search the Government Index"
openapi: "/api-reference/v2-openapi.json GET /search/gov"
---

Search primary law and regulatory material from US federal, state, and local government sources: statutes, regulations, codes, court opinions, and other government publications. Results come back in the standard `web` group, the same shape as a web result from [`/search`](/api-reference/endpoint/search).

`POST` is available on the same path with the same fields as a JSON body. Unknown fields and invalid filter values are rejected with `400`, and the error says which value to fix.

`query` is required. Include the jurisdiction, agency or citation, and relevant date when known. `k` is the result count, from 1 to 100, defaulting to 10; general `/search` uses `limit` instead.

Each team can make up to 500 Government Index calls per day, shared with the `gov` category on `/search` and the Government Index provider. The count resets at 00:00 UTC; past it, this endpoint returns `429` with a `Retry-After` header. See [rate limits](/rate-limits#government-index).

Results are matched excerpts and may include historical versions, bill text, guidance, or third-party reproductions. Verify the issuer, jurisdiction, enacted/effective status, and version before citing current governing law. Read the source behind a match when the snippet is insufficient. The index focuses on US material; no hits does not establish that no applicable law exists.

## Filters

All filters are optional and combine with AND semantics.

| Field | Keeps only pages that |
| --- | --- |
| `jurisdiction` | belong to one jurisdiction: `us` for federal, or `us-` plus a two-letter state or territory code, such as `us-ca` or `us-dc`. |
| `court` | are labeled for one court, by CourtListener court id, such as `scotus`, `ca9` or `nysd`. |
| `courtType` | come from one type of court: `federal-supreme`, `federal-appellate`, `federal-district`, `federal-bankruptcy`, `federal-special`, `military`, `state-supreme`, `state-appellate`, `state-trial`, `state-special`, or `state-attorney-general`. |
| `cites` | cite one law or case, as a printed citation such as `42 U.S.C. § 1983` or `5 U.S. 137`, or a citation id such as `us:usc:42:1983`. |
| `domain` | come from one site, such as `irs.gov`. |

Filters keep only pages the index has labeled, so a filtered search can leave out relevant pages, and no results does not mean none exist. Court labels are most complete for federal courts and case-law collections.

<CodeGroup>

```bash cURL
# No API key needed to get started; add -H "Authorization: Bearer $FIRECRAWL_API_KEY" for higher rate limits:
curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
```

```bash cURL (POST)
curl -X POST https://api.firecrawl.dev/v2/search/gov \
  -H "Authorization: Bearer $FIRECRAWL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "food labeling requirements for allergens",
    "k": 10
  }'
```

</CodeGroup>
