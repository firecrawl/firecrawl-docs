---
title: "Search the Firecrawl Government Index"
openapi: "/api-reference/v2-openapi.json GET /search/gov"
---

Search primary law and regulatory material from US federal, state, and local government sources: statutes, regulations, codes, court opinions, and other government publications. Results come back in the standard `web` group, the same shape as a web result from [`/search`](/api-reference/endpoint/search).

`POST` is available on the same path with the same fields as a JSON body. Unknown fields are rejected with `400`.

`query` is required. Include the jurisdiction, agency or citation, and relevant date when known. `k` is the result count, from 1 to 100, defaulting to 10; general `/search` uses `limit` instead.

Results are matched excerpts and may include historical versions, bill text, guidance, or third-party reproductions. Verify the issuer, jurisdiction, enacted/effective status, and version before citing current governing law. Read the source behind a match when the snippet is insufficient. The index focuses on US material; no hits does not establish that no applicable law exists.

<CodeGroup>

```bash cURL
# No API key needed to get started; add -H "Authorization: Bearer $FIRECRAWL_API_KEY" for higher rate limits:
curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
```

```bash cURL (POST)
curl -X POST https://api.firecrawl.dev/v2/search/gov \
  -H "Authorization: Bearer $FIRECRAWL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "food labeling requirements for allergens",
    "k": 10
  }'
```

</CodeGroup>
