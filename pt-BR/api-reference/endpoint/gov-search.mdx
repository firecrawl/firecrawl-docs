---
title: "Buscar no Government Index do Firecrawl"
openapi: "/pt-BR/api-reference/v2-openapi.json GET /search/gov"
---

Busque legislação primária e material regulatório de fontes governamentais federais, estaduais e locais dos EUA: leis, regulamentos, códigos, decisões judiciais e outras publicações governamentais. Os resultados são retornados no grupo padrão `web`, com o mesmo formato de um resultado web de [`/search`](/pt-BR/api-reference/endpoint/search).

O método `POST` está disponível no mesmo caminho, aceitando os mesmos campos em um corpo JSON. Campos desconhecidos são rejeitados com erro `400`.

<CodeGroup>
  ```bash cURL
  # Não é necessária uma API key para começar; adicione -H "Authorization: Bearer $FIRECRAWL_API_KEY" para ter limites de taxa mais altos:
  curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
  ```

  ```bash cURL (POST)
  curl -X POST https://api.firecrawl.dev/v2/search/gov \
    -H "Authorization: Bearer $FIRECRAWL_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "query": "food labeling requirements for allergens",
      "k": 10
    }'
  ```
</CodeGroup>

Para uma visão geral do fluxo de trabalho, consulte o [guia do Government Index](/pt-BR/features/gov).
