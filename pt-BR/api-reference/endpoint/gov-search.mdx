Busque legislação primária e material regulatório de fontes governamentais federais, estaduais e locais dos EUA: leis, regulamentos, códigos, decisões judiciais e outras publicações governamentais. Os resultados são retornados no grupo padrão `web`, com o mesmo formato de um resultado web de [`/search`](/pt-BR/api-reference/endpoint/search).

O método `POST` está disponível no mesmo caminho, aceitando os mesmos campos em um corpo JSON. Campos desconhecidos e valores de filtro inválidos são rejeitados com erro `400`, e a mensagem de erro indica qual valor deve ser corrigido.

`query` é obrigatório. Inclua a jurisdição, o órgão ou a citação e a data relevante, quando souber. `k` define a quantidade de resultados, de 1 a 100, com padrão 10; no `/search` geral, use `limit`.

Os resultados são trechos correspondentes e podem incluir versões históricas, textos de projetos de lei, orientações ou reproduções de terceiros. Verifique o emissor, a jurisdição, o status de promulgação/vigência e a versão antes de citar a legislação em vigor. Quando o snippet não for suficiente, leia a fonte do trecho correspondente. O índice se concentra em material dos EUA; a ausência de resultados não comprova que não exista legislação aplicável.

## Filtros {#filters}

Todos os filtros são opcionais e são combinados com semântica AND.

| Campo          | Mantém apenas páginas que                                                                                                                                                                                                                    |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `jurisdiction` | pertencem a uma jurisdição: `us` para a esfera federal, ou `us-` seguido do código de duas letras de um estado ou território, como `us-ca` ou `us-dc`.                                                                                       |
| `court`        | estão rotuladas com um tribunal específico, pelo id de tribunal do CourtListener, como `scotus`, `ca9` ou `nysd`.                                                                                                                            |
| `courtType`    | vêm de um tipo de tribunal: `federal-supreme`, `federal-appellate`, `federal-district`, `federal-bankruptcy`, `federal-special`, `military`, `state-supreme`, `state-appellate`, `state-trial`, `state-special` ou `state-attorney-general`. |
| `cites`        | citam uma lei ou um caso, na forma de citação impressa, como `42 U.S.C. § 1983` ou `5 U.S. 137`, ou de id de citação, como `us:usc:42:1983`.                                                                                                 |
| `domain`       | vêm de um site específico, como `irs.gov`.                                                                                                                                                                                                   |

Os filtros mantêm apenas páginas que o índice rotulou; por isso, uma busca filtrada pode deixar de fora páginas relevantes, e a ausência de resultados não significa que elas não existam. Os rótulos de tribunais são mais completos para tribunais federais e coleções de jurisprudência.

<CodeGroup>
  ```bash cURL
  # Não é necessária uma API key para começar; adicione -H "Authorization: Bearer $FIRECRAWL_API_KEY" para ter limites de taxa mais altos:
  curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
  ```

  ```bash cURL (POST)
  curl -X POST https://api.firecrawl.dev/v2/search/gov \
    -H "Authorization: Bearer $FIRECRAWL_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "query": "food labeling requirements for allergens",
      "k": 10
    }'
  ```
</CodeGroup>
