title: "Pesquise no índice para desenvolvedores"
openapi: "/pt-BR/api-reference/v2-openapi.json GET /search/developer"
---

Pesquise issues do GitHub, pull requests mesclados, READMEs de repositórios e sites de documentação selecionados. Os resultados são ranqueados e incluem as passagens correspondentes em Markdown.

`POST` está disponível no mesmo caminho para passar filtros de array como JSON.

Para uma visão geral do fluxo de trabalho, consulte o [guia do índice para desenvolvedores](/pt-BR/features/developer).
