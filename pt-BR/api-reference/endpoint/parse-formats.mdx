---
title: 'Formatos do Parse'
openapi: '/pt-BR/api-reference/v2-openapi.json GET /parse/formats'
---

Lista todos os formatos de arquivo aceitos pelo [`/parse`](/pt-BR/api-reference/endpoint/parse), com suas extensões e tipos MIME. A lista é gerada a partir das mesmas regras que o `/parse` usa para validar uploads, então você pode verificar um arquivo antes de enviá-lo, sem precisar manter sua própria cópia dos tipos suportados.

Cada entrada tem um `kind` igual a `document` ou `image`. Formatos de imagem passam por OCR e retornam `available: false` quando o OCR de imagens não está habilitado; uploads desses formatos são rejeitados com `UNSUPPORTED_FILE_TYPE` até que ele seja habilitado.

A lista raramente sofre mudanças. As respostas incluem `Cache-Control: private, max-age=3600`, então é seguro armazená-las em cache por até uma hora.
