  ## Apresentando o /extract (Beta) {#introducing-extract-beta}
</div>

<Warning>
  [Use a nova documentação do Open Beta do /extract clicando aqui 🔥](/pt-BR/features/extract)

Extraia dados estruturados de uma única URL, de várias URLs ou de sites inteiros usando Large Language Models (LLMs). Nosso novo endpoint `/extract` permite:

* Extrair dados estruturados de sites inteiros de uma só vez
* Conectar ou criar aplicações de enriquecimento de dados que precisam de dados estruturados de sites
* Desenvolver aplicações de IA que precisam de dados limpos de vários sites

<div id="considerations">
  ## Considerações {#considerations}
</div>

O endpoint `/extract` oferece extração de dados flexível com esquemas personalizáveis. Os resultados podem ser aprimorados por meio de ajuste de prompt. Atualmente em beta — seu feedback é bem-vindo.

<div id="extract-endpoint">
  ### endpoint /extract {#extract-endpoint}
</div>

Usado para extrair dados estruturados de sites inteiros.

Ao especificar URLs, você pode adicionar `/*` à URL para extrair informações de todo o caminho do site, em vez de apenas uma única página.

Por exemplo, `https://firecrawl.dev/*` tentará extrair dados de todas as páginas no domínio firecrawl.dev. O `/*` ainda está em fase de testes, portanto, avise-nos se tiver algum problema enviando um e-mail para help@firecrawl.com.

  ### Verificando o status da extração {#checking-extract-status}
</div>

Você pode usar o endpoint `/extract/ID` para verificar o status de um job de extração.

<Note>Este endpoint só funciona para jobs de extração que estejam em andamento ou que tenham sido concluídos recentemente (nas últimas 24 horas).</Note>

<div id="pending-response">
  #### Resposta pendente {#pending-response}
</div>

Jobs de extração podem ter um dos seguintes estados:

* `completed`: o job de extração foi concluído com sucesso.
* `processing`: o job de extração ainda está em andamento.
* `failed`: o job de extração encontrou um erro e não foi concluído.
* `cancelled`: o job de extração foi cancelado pelo usuário.

<div id="improving-results-with-web-search-external-links">
  ### Melhorando os resultados com busca na web e links externos {#improving-results-with-web-search-external-links}
</div>

Para melhorar os resultados da extração, você pode enviar o parâmetro `enableWebSearch` ao endpoint. Isso permite tentar localizar os dados em links externos — fora do escopo das URLs fornecidas.

<div id="billing">
  ### Cobrança {#billing}
</div>

Enquanto o endpoint `/extract` estiver em beta, cobramos 5 créditos por URL coletada usada para compor a resposta final. Isso serve para prevenir abusos. Isso poderá mudar no futuro.
