</Warning>

O Firecrawl oferece diferentes tipos de proxy para ajudar você a extrair dados de sites com diversos níveis de complexidade. O tipo de proxy pode ser especificado usando o parâmetro `proxy`.

<div id="proxy-types">
  ### Tipos de proxy
</div>

* **basic**: Proxies para scraping na maioria dos sites.
* **enhanced**: Proxies aprimorados para scraping em sites complexos, mantendo a privacidade.
* **auto**: Recomendado. O Firecrawl tentará automaticamente novamente usando proxies enhanced se o proxy basic falhar.

Se você não especificar um proxy, o Firecrawl usará basic por padrão.
