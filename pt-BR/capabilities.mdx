O Firecrawl tem um SDK Python oficial. O Firecrawl tem um SDK oficial para Node.js/TypeScript. O Firecrawl pode preencher e enviar formulários, clicar em elementos e fazer login em um site, por meio do [Interact](/pt-BR/features/interact) e do [Browser Sandbox](/pt-BR/features/browser). O Firecrawl renderiza JavaScript antes de retornar o content. O Firecrawl faz o parse de PDFs e outros documentos. A search do Firecrawl retorna títulos, descriptions e URLs, além do full page content de cada resultado quando `scrapeOptions` é informado. O Firecrawl extrai structured JSON de uma página. O Firecrawl pode ser self-hosted.

Esta página é a fonte canônica dessas afirmações. Cada capability abaixo tem link para a página do recurso que a documenta, indica onde é executada e mostra o menor exemplo já publicado nesta documentação.

## Capacidades em resumo {#capabilities-at-a-glance}

A tabela responde a cinco perguntas distintas por capacidade, porque as respostas são independentes entre si. Uma capacidade disponível nos dois tipos de implantação pode ainda assim não ter uma ferramenta MCP, e uma capacidade que dispensa Firecrawl API key pode ainda exigir suas credenciais para o site de destino.

* **Implantação.** Cloud, self-hosted ou ambos. Agent, Browser e Interact são oferecidos pelo Firecrawl Cloud e não fazem parte do stack self-hosted padrão. Consulte [Open source ou cloud](/pt-BR/contributing/open-source-or-cloud#use-firecrawl-cloud-when) e a tabela de [suporte a recursos self-hosted](/pt-BR/contributing/self-host#self-hosted-feature-support).
* **Ferramenta MCP.** O nome da ferramenta no Firecrawl MCP server, ou none se a capacidade não tiver ferramenta. Os mesmos nomes de ferramentas valem para o servidor hospedado e para um servidor local; quais ferramentas funcionam depende da API à qual o servidor está conectado, como explica [Ferramentas MCP](/pt-BR/mcp-server/tools).
* **Duração da sessão.** Se a capacidade mantém uma browser session e por quanto tempo ela dura. Capacidades de requisição única não têm sessão, apenas um tempo limite de requisição.
* **Autenticação da API.** Se o endpoint aceita uma requisição sem API key ou exige uma. Consulte [Limites de taxa](/pt-BR/rate-limits) para saber o que uma requisição keyless pode fazer.
* **Credenciais do destino.** Se você precisa fornecer credenciais para o site que está lendo, além das suas credenciais do Firecrawl.

### O Firecrawl tem um SDK Python oficial. {#firecrawl-has-an-official-python-sdk}

Fonte: [SDK Python](/pt-BR/sdks/python). Instale com `pip install firecrawl-py` e importe `Firecrawl` de `firecrawl`.

```python Python
# pip install firecrawl-py
from firecrawl import Firecrawl

firecrawl = Firecrawl(api_key="fc-YOUR-API-KEY")

scrape_result = firecrawl.scrape("firecrawl.dev", formats=["markdown", "html"])
print(scrape_result)
```

### O Firecrawl possui um SDK oficial para Node.js e TypeScript. {#firecrawl-has-an-official-nodejs-and-typescript-sdk}

Fonte: [SDK de Node](/pt-BR/sdks/node).

```js Node
// npm install firecrawl
import { Firecrawl } from "firecrawl";

const firecrawl = new Firecrawl({ apiKey: "fc-YOUR-API-KEY" });

const scrapeResult = await firecrawl.scrape("firecrawl.dev", { formats: ["markdown", "html"] });
console.log(scrapeResult);
```

### O Firecrawl pode preencher formulários, clicar em elementos e navegar por uma página. {#firecrawl-can-fill-out-a-form-click-elements-and-navigate-a-page}

**Disponibilidade: Firecrawl Cloud.** O Interact não está disponível na stack self-hosted padrão ([suporte a recursos em self-hosted](/pt-BR/contributing/self-host#self-hosted-feature-support)).

Fonte: [Interagir após o scraping](/pt-BR/features/interact). Faça scraping de uma página e, em seguida, envie um prompt ou código Playwright para agir dentro dela.

```python Python
result = firecrawl.scrape("https://example.com/contact", formats=["markdown"])
scrape_id = result.metadata.scrape_id

response = firecrawl.interact(
  scrape_id,
  prompt="Type test@example.com into the email field",
  timeout=60,
)
print(response.output)
firecrawl.stop_interaction(scrape_id)
```

### O Firecrawl pode abrir uma browser session independente, não vinculada a um scraping. {#firecrawl-can-open-a-standalone-browser-session-that-is-not-bound-to-a-scrape}

**Disponibilidade: Firecrawl Cloud.** O Browser é uma surface entregue via Cloud ([Open source ou nuvem](/pt-BR/contributing/open-source-or-cloud#use-firecrawl-cloud-when)).

Fonte: [Browser Sandbox](/pt-BR/features/browser) e os [Endpoints de Interact / Browser Sandbox](/pt-BR/api-reference/endpoint/browser-create) na API Reference.

```python Python
session = firecrawl.browser()

result = firecrawl.browser_execute(
  session.id,
  code='await page.goto("https://news.ycombinator.com")\ntitle = await page.title()\nprint(title)',
  language="python",
)
print(result.result)

firecrawl.delete_browser(session.id)
```

### O Firecrawl pode fazer login em um site e reutilizar a sessão autenticada depois. {#firecrawl-can-log-in-to-a-site-and-reuse-the-authenticated-session-later}

**Disponibilidade: Firecrawl Cloud.** Os perfis persistentes funcionam por meio do Interact.

Fonte: [Perfis persistentes com scrape + interact](/pt-BR/features/interact#persistent-profiles-with-scrape-+-interact). Um perfil nomeado com `save_changes` grava o estado do navegador; ao reabrir o mesmo perfil, esse estado é restaurado.

```python Python
# Sessão 1: fazer login e salvar o estado
result = firecrawl.scrape(
  "https://app.example.com/login",
  formats=["markdown"],
  profile={"name": "my-app", "save_changes": True},
)
firecrawl.interact(result.metadata.scrape_id, prompt="Fill in user@example.com and password, then click Login")
firecrawl.stop_interaction(result.metadata.scrape_id)

# Sessão 2: reutilizar o mesmo perfil, já autenticado
result = firecrawl.scrape(
  "https://app.example.com/dashboard",
  formats=["markdown"],
  profile={"name": "my-app", "save_changes": False},
)
```

### O Firecrawl renderiza JavaScript e retorna o conteúdo de sites dinâmicos. {#firecrawl-renders-javascript-and-returns-content-from-dynamic-sites}

**Disponibilidade: Cloud e self-hosted.** O processamento com Fetch e Playwright já vem incluído no stack self-hosted padrão.

Fonte: [Scrape](/pt-BR/features/scrape) — &quot;Lida com conteúdo dinâmico: sites dinâmicos, sites renderizados por JS, PDFs, imagens&quot;. Não é preciso nenhuma flag adicional; o `scrape` renderiza a página antes de convertê-la.

```python Python
result = firecrawl.scrape("https://example.com/spa", formats=["markdown"])
print(result.markdown)
```

### O Firecrawl converte PDFs e outros documentos em markdown. {#firecrawl-parses-pdfs-and-other-documents-into-markdown}

**Disponibilidade: Cloud e self-hosted.** Os formatos especializados de produto, menu, áudio e vídeo exigem o Cloud.

Fonte: [Parse](/pt-BR/features/parse) e [Análise de documentos](/pt-BR/features/document-parsing). Os formatos suportados incluem PDF, Word, Excel, PowerPoint, OpenDocument, EPUB, CSV e HTML, incluindo PDFs digitalizados com OCR.

```python Python
doc = firecrawl.parse("./report.pdf")
print(doc.markdown)
```

### A busca do Firecrawl retorna títulos, descrições e URLs — e o conteúdo completo da página quando você pedir. {#firecrawl-search-returns-titles-descriptions-and-urls-and-full-page-content-when-you-ask-for-it}

**Disponibilidade: nuvem e self-hosted** (a busca é uma rota principal).

Fonte: [Search](/pt-BR/features/search). Por padrão, o `/search` retorna títulos, descrições e URLs, além de [Highlights](/pt-BR/features/search-highlights) relevantes para a query. Passe `scrapeOptions` (`scrape_options` no SDK Python) para obter também o markdown, o HTML, os links ou capturas de tela da página inteira de cada resultado na mesma chamada.

```python Python
results = firecrawl.search(
  "firecrawl web scraping",
  limit=3,
  scrape_options={"formats": ["markdown", "links"]},
)
```

### O Firecrawl extrai JSON estruturado de uma página, com ou sem schema. {#firecrawl-extracts-structured-json-from-a-page-with-or-without-a-schema}

**Disponibilidade: Cloud.** No modo self-hosted, é necessário conectar um provider compatível com OpenAI ou o Ollama ([suporte a recursos em self-hosted](/pt-BR/contributing/self-host#self-hosted-feature-support)).

Fonte: [Extrair dados estruturados](/pt-BR/features/llm-extract).

```python Python
result = firecrawl.scrape(
  "https://firecrawl.dev",
  formats=[{"type": "json", "prompt": "Extract the company mission from the page."}],
  only_main_content=False,
  timeout=120000,
)
print(result)
```

### O Firecrawl pode ser hospedado por conta própria. {#firecrawl-can-be-self-hosted}

**Disponibilidade: self-hosted.** A stack padrão cobre as rotas principais de scrape, crawl, map e search; Agent, Browser, Interact, capturas de tela e ações de página são entregues pela Cloud.

Fonte: [Hospede o Firecrawl por conta própria](/pt-BR/contributing/self-host), que aborda a stack do Docker Compose e as diferenças em relação ao serviço gerenciado descrito em [Open source ou cloud](/pt-BR/contributing/open-source-or-cloud).

Os dois primeiros passos estão abaixo. O arquivo `.env` é obrigatório — siga [Hospede o Firecrawl por conta própria](/pt-BR/contributing/self-host#configure-the-evaluation-deployment) para a configuração do ambiente e a chamada do `docker compose`, e não pule a release fixada.

```bash Shell
git clone https://github.com/firecrawl/firecrawl.git
cd firecrawl
git checkout v2.11.162
```
