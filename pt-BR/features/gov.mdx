O Firecrawl Government Index busca leis, regulamentos, códigos, decisões judiciais e outras publicações governamentais federais, estaduais e locais dos EUA. Com ele, um agente pode encontrar o texto jurídico ou regulatório por trás de uma pergunta. Os resultados ranqueados também podem incluir versões históricas, textos de projetos de lei, orientações de órgãos governamentais e reproduções de terceiros; um resultado não garante que se trate da legislação vigente.

* Encontre o regulamento que estabelece um requisito de rotulagem, de reporte ou de licenciamento
* Leia a lei ou a seção do código por trás de uma questão de conformidade
* Localize uma decisão judicial que interpreta uma norma
* Obtenha a publicação governamental que um órgão emitiu sobre um tema

## Escolha e verifique as fontes {#choose-and-verify-sources}

Inclua a jurisdição, o órgão ou a citação e a data relevante, quando conhecidos. Se a jurisdição não for informada, pergunte ao usuário antes de identificar a norma aplicável. Se o usuário fornecer a URL de uma fonte, leia-a diretamente com [`scrape`](/pt-BR/features/scrape) em vez de fazer uma nova busca.

Antes de responder a uma pergunta sobre a legislação vigente, verifique o emissor, a jurisdição, o status de promulgação/vigência e a versão da fonte. Leia a fonte por trás de um resultado quando o snippet não for suficiente para estabelecer a norma. Verifique o status e a data de vigência de um projeto de lei em vez de deduzi-los a partir do título ou do resumo. Cite a seção determinante e o trecho que a fundamenta, e só informe detalhes de página, seção ou data de vigência que as evidências sustentem.

O índice se concentra em material dos EUA. Use a busca geral para outras jurisdições ou quando a cobertura for insuficiente. A ausência de resultados não comprova que não exista legislação aplicável.

## Buscar no Government Index {#search-the-government-index}

Envie uma pergunta em linguagem natural e receba resultados ranqueados de fontes jurídicas e regulatórias. Os resultados vêm no grupo padrão `web`, cada um com `url`, `title`, `description` e `position`, no mesmo formato de um resultado web de [`/search`](/pt-BR/features/search).

As buscas no Government Index são gratuitas e não consomem créditos, com ou sem retenção zero de dados. Você não precisa de uma API key para começar; adicione uma para ter limites de taxa mais altos.

Os exemplos de SDK usam os métodos Gov disponíveis em `firecrawl@4.44.1` e `firecrawl-py==4.49.2`. Defina `FIRECRAWL_API_KEY` para os exemplos de SDK autenticados; use os exemplos HTTP para requests sem API key. Se o cliente instalado não tiver o método, atualize o SDK. Em Python, chame `gov_search` na instância já inicializada do cliente; a reflexão feita apenas sobre a classe pode não listar os métodos atribuídos durante a inicialização.

<CodeGroup>
  ```bash cURL
  # Não é preciso API key para começar; adicione -H "Authorization: Bearer $FIRECRAWL_API_KEY" para ter limites de taxa mais altos:
  curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
  ```

  ```bash CLI
  firecrawl gov "food labeling requirements for allergens" --limit 10
  ```

  ```python Python
  import os
  from firecrawl import Firecrawl

  client = Firecrawl(api_key=os.environ["FIRECRAWL_API_KEY"])

  result = client.gov_search("food labeling requirements for allergens", k=10)
  print(result)
  ```

  ```js Node
  import { Firecrawl } from "firecrawl";

  const client = new Firecrawl({
    apiKey: process.env.FIRECRAWL_API_KEY,
  });

  const result = await client.govSearch(
    "food labeling requirements for allergens",
    {
      k: 10,
    },
  );
  console.log(result);
  ```
</CodeGroup>

`POST` também está disponível no mesmo caminho, com os mesmos campos enviados em um corpo JSON:

```bash cURL
# Não é preciso API key para começar; adicione -H "Authorization: Bearer $FIRECRAWL_API_KEY" para obter limites de taxa maiores:
curl -X POST https://api.firecrawl.dev/v2/search/gov \
  -H "Content-Type: application/json" \
  -d '{
    "query": "food labeling requirements for allergens",
    "k": 10
  }'
```

`query` é obrigatório. `k` define quantos resultados são retornados, de 1 a 100 (padrão: 10). Campos desconhecidos são rejeitados com erro `400`. Consulte a [referência de busca do Government Index](/pt-BR/api-reference/endpoint/gov-search) para ver o schema completo da request e da resposta.

A mesma busca também está disponível em [`/search`](/pt-BR/features/search#gov-category-search) com `categories: ["gov"]`, e os resultados vêm em `data.web`.

<Note>
  O [servidor MCP](/pt-BR/mcp-server) hospedado expõe este índice como
  `firecrawl_gov_search`, e a [CLI](/pt-BR/sdks/cli#government), como `firecrawl
        gov`. Nenhum dos dois grava dados.
</Note>
