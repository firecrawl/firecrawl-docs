O Firecrawl Government Index é um índice de legislação primária e material regulatório de fontes governamentais federais, estaduais e locais dos EUA: leis, regulamentos, códigos, decisões judiciais e outras publicações governamentais. Com ele, um agente pode responder a uma pergunta jurídica ou de conformidade com base na própria fonte governamental, e não em uma página web genérica.

* Encontre o regulamento que estabelece um requisito de rotulagem, de reporte ou de licenciamento
* Leia a lei ou a seção do código por trás de uma questão de conformidade
* Localize uma decisão judicial que interpreta uma norma
* Obtenha a publicação governamental que um órgão emitiu sobre um tema

## Endpoints {#endpoints}

| Tarefa                     | Endpoint                                                          |
| -------------------------- | ----------------------------------------------------------------- |
| Buscar no Government Index | [`GET` ou `POST /search/gov`](/pt-BR/api-reference/endpoint/gov-search) |

## Buscar no Government Index {#search-the-government-index}

Envie uma pergunta em linguagem natural e receba resultados ranqueados de fontes jurídicas e regulatórias. Os resultados vêm no grupo padrão `web`, cada um com `url`, `title`, `description` e `position`, no mesmo formato de um resultado web de [`/search`](/pt-BR/features/search).

As buscas no Government Index são gratuitas e não consomem créditos, com ou sem retenção zero de dados. Você não precisa de uma API key para começar; adicione uma para ter limites de taxa mais altos.

<CodeGroup>
  ```bash cURL
  # Não é preciso API key para começar; adicione -H "Authorization: Bearer $FIRECRAWL_API_KEY" para ter limites de taxa mais altos:
  curl -s "https://api.firecrawl.dev/v2/search/gov?query=food%20labeling%20requirements%20for%20allergens&k=10"
  ```

  ```bash CLI
  firecrawl gov "food labeling requirements for allergens" --limit 10
  ```

  ```python Python
  from firecrawl import Firecrawl

  firecrawl = Firecrawl(
    # Não é preciso API key para começar; adicione uma para ter limites de taxa mais altos:
    # api_key="fc-YOUR-API-KEY",
  )

  result = firecrawl.gov_search("food labeling requirements for allergens", k=10)
  print(result)
  ```

  ```js Node
  import { Firecrawl } from "firecrawl";

  const firecrawl = new Firecrawl({
    // Não é preciso API key para começar; adicione uma para ter limites de taxa mais altos:
    // apiKey: "fc-YOUR-API-KEY",
  });

  const result = await firecrawl.govSearch(
    "food labeling requirements for allergens",
    {
      k: 10,
    },
  );
  console.log(result);
  ```
</CodeGroup>

`POST` também está disponível no mesmo caminho, com os mesmos campos enviados em um corpo JSON:

```bash cURL
# Não é preciso API key para começar; adicione -H "Authorization: Bearer $FIRECRAWL_API_KEY" para obter limites de taxa maiores:
curl -X POST https://api.firecrawl.dev/v2/search/gov \
  -H "Content-Type: application/json" \
  -d '{
    "query": "food labeling requirements for allergens",
    "k": 10
  }'
```

`query` é obrigatório. `k` define quantos resultados são retornados, de 1 a 100 (padrão: 10). Campos desconhecidos são rejeitados com erro `400`. Consulte a [referência de busca do Government Index](/pt-BR/api-reference/endpoint/gov-search) para ver o schema completo da requisição e da resposta.

A mesma busca também está disponível em [`/search`](/pt-BR/features/search#gov-category-search) com `categories: ["gov"]`, e os resultados vêm em `data.web`.

<Note>
  O [servidor MCP](/pt-BR/mcp-server) hospedado expõe este índice como
  `firecrawl_gov_search`, e a [CLI](/pt-BR/sdks/cli#government), como `firecrawl
        gov`. Nenhum dos dois grava dados.
</Note>
