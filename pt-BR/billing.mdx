<div id="overview">
  ## Visão geral
</div>

A cobrança do Firecrawl é **baseada em créditos**. Cada chamada de API que você faz consome créditos. A quantidade de créditos depende do endpoint e das opções que você utiliza. Seu plano oferece uma cota mensal de créditos. O pagamento por uso adiciona mais créditos quando a cota se esgota.

Para ver os preços atuais dos planos, visite a [página de preços do Firecrawl](https://www.firecrawl.dev/pricing).

<Note>
  Todas as faturas do Firecrawl são emitidas em **dólares americanos (USD)**, independentemente do seu endereço de cobrança ou método de pagamento.
</Note>

<div id="credits">
  ## Créditos
</div>

Créditos são a unidade de consumo no Firecrawl. Cada plano inclui uma cota mensal de créditos que é renovada no início de cada ciclo de cobrança. Diferentes endpoints da API consomem quantidades diferentes de créditos.

<div id="credit-costs-per-endpoint">
  ### Custos de crédito por endpoint
</div>

| Endpoint     | custo em crédito                   | Observações                                                                                                                                                                                                                                                                                                                                                 |
| ------------ | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Scrape**   | 1 crédito / página                 | Converte uma única URL em markdown limpo, HTML ou dados estruturados. Créditos adicionais se aplicam ao usar opções de scraping (consulte abaixo).                                                                                                                                                                                                          |
| **rastreamento**    | 1 crédito / página                 | Faz o scraping de um site inteiro seguindo links a partir de uma URL inicial. Os mesmos custos das opções de scraping por página se aplicam a cada página rastreada.                                                                                                                                                                                        |
| **Map**      | 1 crédito / chamada                | Descobre todas as URLs em um site sem fazer scraping do conteúdo.                                                                                                                                                                                                                                                                                           |
| **Search**   | 2 créditos / 10 resultados         | Faz uma busca na web e, opcionalmente, realiza o scraping dos resultados. Arredondado para cima a cada 10 resultados (por exemplo, 11 resultados = 4 créditos). Custos adicionais de scraping por página se aplicam a cada resultado que for raspado. Consulte [aqui](/pt-BR/features/search#zero-data-retention-zdr) para ver os preços da busca ZDR Enterprise. |
| **Interact** | 2–7 créditos / minuto de navegador | Sessão interativa de sandbox de navegador, cobrada por minuto de navegador, com mínimo de um minuto. Sessões que usam um `prompt` são cobradas a 7 créditos / minuto de navegador; sessões sem prompt (somente `code` do Playwright) são cobradas a 2 créditos / minuto de navegador.                                                                       |
| **Agent**    | Dinâmico                           | Agente autônomo de pesquisa na web. 5 execuções diárias gratuitas; cobrança baseada em uso após isso.                                                                                                                                                                                                                                                       |

<div id="additional-credit-costs-for-scrape-options">
  ### Custos adicionais de crédito para opções de scraping
</div>

Certas opções de scraping adicionam créditos além do custo base por página:

| Opção                                                          | Custo adicional            | Descrição                                                                                                                                                                                                                                                                                               |
| -------------------------------------------------------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PDF parsing                                                    | +1 crédito / página de PDF | Extrair conteúdo de documentos PDF                                                                                                                                                                                                                                                                      |
| formato JSON (extração com LLM)                                | +4 créditos / página       | Usar um LLM para extrair dados JSON estruturados da página                                                                                                                                                                                                                                              |
| Verificação de injeção de prompt                               | +4 créditos / página       | Proteção opcional `checkPromptInjection` para formato JSON (veja [Detecção de injeção de prompt](/pt-BR/features/llm-extract#prompt-injection-detection)). Se o scraping falhar após a execução da verificação, serão cobrados 5 créditos. Veja [Quando os créditos são cobrados](#when-credits-are-charged). |
| sem retenção de dados (ZDR)                                    | +1 crédito / página        | Garante que nenhum dado seja persistido além da requisição (veja [Scrape ZDR](/pt-BR/features/scrape#zero-data-retention-zdr))                                                                                                                                                                                |
| formato `question` ou `query`                                  | +4 créditos / página       | Resposta gerada por LLM a uma pergunta sobre a página (veja [Scrape](/pt-BR/features/scrape))                                                                                                                                                                                                                 |
| formato `highlights`                                           | +4 créditos / página       | Trechos relevantes da página selecionados por LLM (veja [Scrape](/pt-BR/features/scrape))                                                                                                                                                                                                                     |
| formato `audio`                                                | +4 créditos / página       | Transcrever áudio encontrado na página (veja [Scrape](/pt-BR/features/scrape))                                                                                                                                                                                                                                |
| formato `video`                                                | +4 créditos / página       | Transcrever vídeo encontrado na página (veja [Scrape](/pt-BR/features/scrape))                                                                                                                                                                                                                                |
| Ocultação de PII (`redactPII`)                                 | +4 créditos / página       | Ocultar dados pessoais do markdown retornado. Cada página adicional de PDF soma mais +4 além do custo de +1 de parsing (veja [Ocultação de PII](/pt-BR/features/pii-redaction))                                                                                                                               |
| `lockdown` (cache hit)                                         | +4 créditos / página       | Servir somente a partir do cache, sem nunca acessar o alvo. Um cache miss não retorna documento e cobra 1 crédito (veja [Lockdown](/pt-BR/features/lockdown) e a tabela abaixo)                                                                                                                               |
| Proxy aprimorado (`proxy: "enhanced"` ou escalonamento `auto`) | +0                         | Cobrado com o mesmo 1 crédito de uma requisição basic. Uma nova tentativa escalada não é cobrada separadamente (veja [Modo aprimorado](/pt-BR/features/enhanced-mode))                                                                                                                                        |

Esses modificadores se acumulam. Por exemplo, fazer scraping de uma página com formato JSON e sem retenção de dados custa **1 + 4 + 1 = 6 créditos** por página, e formato JSON com ocultação de PII custa **1 + 4 + 4 = 9 créditos**. Esses mesmos modificadores se aplicam aos endpoints rastreamento e Search, já que eles usam scraping internamente para cada página.

Requisições para `x.com` e outras URLs do X/Twitter usam a API do Grok e têm preços separados. Veja [cobrança do X (x.com)](#x-xcom-billing) no final desta página.

<div id="when-credits-are-charged">
  ### Quando os créditos são debitados
</div>

O que determina a cobrança é se o Firecrawl retornou um documento, não se o site de destino retornou um código de status HTTP de sucesso.

* **O Firecrawl retornou um documento: 1 crédito por página**, mais qualquer um dos custos de opções acima. Isso inclui páginas que retornam com um status de erro, como 403 Forbidden ou 404 Not Found. O destino respondeu, o Firecrawl capturou essa resposta e você a recebe de volta como um documento. Verifique o campo `metadata.statusCode` na resposta para identificar esses casos e parar de tentar novamente URLs que são bloqueadas de forma consistente.
* **O Firecrawl não retornou documento: 0 créditos.** Um scraping que falha por completo, por exemplo porque o site nunca respondeu ou todas as tentativas de renderização falharam, não é cobrado.

Alguns casos ainda geram cobrança mesmo quando nenhum documento é retornado. Eles cobrem o trabalho que o Firecrawl já realizou em seu nome antes de o scraping terminar.

| Caso                                   | O que é cobrado                                                                                                                                    |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Verificação de proteção contra ameaças | 2 créditos por URL verificada, incluindo um scraping que a própria verificação bloqueou                                                            |
| Verificação de injeção de prompt       | 5 créditos, uma vez que a proteção `checkPromptInjection` tenha sido executada                                                                     |
| FIRE-1 (Agente)                        | Baseado em uso, pela navegação que o agente já realizou                                                                                            |
| Cache miss de `lockdown`               | 1 crédito                                                                                                                                          |
| Monitor check                          | Uma página que apresenta erro durante uma verificação é cobrada pelo valor base de 1 crédito por página                                            |
| Sessões de Interact e navegador        | Cobradas por minuto de navegador de tempo de sessão, com mínimo de um minuto, independentemente de a sessão ter obtido ou não o resultado esperado |

Para jobs de **extração em lote** e **rastreamento**, os créditos são debitados de forma assíncrona à medida que cada página conclui o processamento, não quando o job é submetido. Isso significa que pode haver um atraso entre a submissão de um job e ver o custo total de créditos refletido na sua conta. Se um batch contiver muitas URLs ou se as páginas forem enfileiradas durante períodos de alto tráfego, os créditos podem continuar aparecendo minutos ou horas após a submissão. Realizar polling ou verificar o status do batch não consome créditos.

<Note>
  **Verificação prévia de créditos do rastreamento:** Quando você passa um `limit` explícito, o Firecrawl verifica se a request é permitida para aquela quantidade. Se for permitida, inclusive por meio de excedente, o limite não é reduzido ao seu saldo restante. Se for negada, o Firecrawl tenta reduzir o limite ao saldo restante e verifica novamente a request ajustada. Um 402 é retornado se nenhum limite positivo puder ser usado ou se a request ajustada for negada, inclusive por um limite de gastos por chave de API.

  Omitir o `limit` não exige **10.000** créditos antecipadamente. A verificação inicial de créditos usa **1 crédito**; ela não reserva créditos para o rastreamento completo. Se a request for permitida, o limite padrão de **10.000** não é reduzido para caber no saldo, embora outras opções de rastreamento possam alterar o limite efetivo. As páginas são cobradas à medida que são processadas. Passe um `limit` explícito quando quiser definir um número máximo de páginas (por exemplo, `limit: 100`).
</Note>

<div id="plans">
  ## Planos
</div>

Os planos de assinatura são cobrados mensalmente ou anualmente. Os planos pagos de autoatendimento também podem usar o pagamento por uso. O pagamento por uso adiciona créditos quando a franquia do seu plano se esgota. Consulte [Pagamento por uso](#pay-as-you-go).

<div id="paid-plans">
  ### Planos pagos
</div>

| Plano        | Créditos mensais | Navegadores concorrentes |
| ------------ | ---------------- | -----------------------: |
| **Hobby**    | 5,000            |                        5 |
| **Standard** | 100,000          |                       25 |
| **Growth**   | 500,000          |                       50 |
| **Scale**    | 1,000,000        |                      100 |

<Note>
  Para necessidades além do plano Scale, Firecrawl oferece planos **Enterprise** com créditos personalizados, suporte dedicado, SLAs, descontos em volume, sem retenção de dados e SSO. Visite a [página Enterprise](https://www.firecrawl.dev/enterprise) para mais detalhes.
</Note>

Todos os planos pagos estão disponíveis com cobrança **mensal** ou **anual**. A cobrança anual oferece um desconto em comparação ao pagamento mês a mês. Para preços atualizados de cada plano, visite a [página de preços](https://www.firecrawl.dev/pricing).

<div id="free-plan">
  ### Free plan
</div>

Novas contas começam no plano gratuito. Ele não tem custo e não exige cartão. Veja o que está incluído:

* **1.000 credits por mês.** A cota é reiniciada no início de cada ciclo mensal. Credits gratuitos não utilizados não são transferidos.
* **2 navegadores concorrentes**, com o mesmo limite de 50.000 jobs em fila dos planos de autoatendimento pagos.
* **Limites de taxa de 10 requisições por minuto** em `/scrape`, `/map` e `/search`, e **2 requisições por minuto** em `/crawl`, `/agent` e `/interact`. A extração em lote compartilha o limite de scraping, e o extract compartilha o limite do agente. Veja [limite de taxa](/pt-BR/rate-limits) para a tabela completa.
* **Todos os endpoints principais do produto.** Scrape, rastreamento, map, search, extract, batch scrape, interact e monitor funcionam no plano gratuito. Alguns recursos de administração de equipe e corporativos são habilitados por equipe, e não por plano, como proteção contra ameaças, logging SIEM e busca sem retenção de dados. Os credit costs são iguais em todos os planos, portanto a tabela de [credit costs por endpoint](#credit-costs-per-endpoint) acima se aplica sem alterações.

O plano gratuito não inclui pagamento por uso, então as requisições retornam HTTP 402 quando a cota mensal se esgota. Veja [crédito esgotado](#running-out-of-credits). Ele também não inclui transferência de credits, Contrato de Processamento de Dados nem suporte via Slack. O suporte é feito pela comunidade.

Scrape, Search e Interact também funcionam sem nenhuma API key, pelo keyless free tier, que é limitado por endereço IP por dia, e não por uma cota de credits. Veja [Keyless (sem API key)](/pt-BR/rate-limits#keyless-no-api-key).

<div id="billing-cycle">
  ### Ciclo de cobrança
</div>

* **Planos mensais**: Os créditos são restaurados na sua data de renovação mensal
* **Planos anuais**: A cobrança é anual, mas os créditos ainda são restaurados todo mês na sua data de renovação mensal virtual
* **Créditos do plano não utilizados não são transferidos por padrão**: sua cota mensal é restaurada a cada mês. **Planos anuais Scale transferem créditos do plano não utilizados por 1 mês**, e **planos anuais Enterprise os transferem por 2 meses**.

<div id="concurrent-browsers">
  ### Navegadores concorrentes
</div>

Navegadores concorrentes representam quantas páginas da web o Firecrawl pode processar para você ao mesmo tempo. Seu plano determina esse limite. Se você o exceder, tarefas adicionais ficam em uma fila de espera até que uma vaga seja liberada. Consulte [Limites de Taxa](/pt-BR/rate-limits) para ver todos os detalhes sobre concorrência e limites de taxa da API.

<a id="auto-reload" />

## Pagamento por uso {#pay-as-you-go}

O pagamento por uso mantém suas solicitações em execução quando os créditos do seu plano se esgotam. Ele adiciona créditos à sua conta automaticamente.

Você compra créditos em incrementos de US$ 5. Quando seu saldo de créditos chega a zero, adicionamos um incremento à sua conta e cobramos o cartão cadastrado.

O pagamento por uso exige um plano pago de autoatendimento. Não é possível usar o pagamento por uso no plano gratuito.

Você também pode comprar créditos a qualquer momento. Use **Carregar mais créditos** nas [configurações de cobrança](https://www.firecrawl.dev/app/settings?tab=billing). Insira um múltiplo de US$ 5 e pague com o cartão cadastrado. Isso funciona independentemente de o pagamento por uso estar ativado ou desativado.

### Créditos por incremento {#credits-in-a-batch}

A quantidade de créditos por incremento depende do seu plano. O pagamento por uso e as compras manuais usam a mesma taxa.

| Plano        | Créditos por US$ 5 |
| ------------ | ------------------ |
| **Hobby**    | 1.000              |
| **Standard** | 2.000              |
| **Growth**   | 2.500              |
| **Scale**    | 5.000              |

### Defina o limite mensal de pagamento por uso {#set-the-monthly-auto-reload-limit}

Defina seu **Limite mensal de pagamento por uso** em um destes dois locais:

* Nas suas [configurações de cobrança](https://www.firecrawl.dev/app/settings?tab=billing), na aba **Cobrança**.
* Na [página de preços](https://www.firecrawl.dev/pricing), ao escolher um plano.

<div id="how-the-limit-caps-your-monthly-spend">
  ### Como o limite restringe seus gastos mensais
</div>

Seu limite é o valor máximo que o pagamento por uso pode gastar em um mês. Ele é arredondado para baixo para incrementos inteiros de 5 USD.

Por exemplo, um limite de 25 USD permite cinco incrementos por mês. Um limite de 22 USD permite quatro incrementos, pois é arredondado para baixo para 20 USD.

Os créditos comprados manualmente não contam para esse limite.

<div id="upgrading-and-downgrading">
  ## Upgrades e downgrades de plano
</div>

* **Upgrades** entram em vigor imediatamente. O valor integral do novo plano é cobrado hoje (sem cobrança proporcional), e seu ciclo de cobrança é reiniciado. Sua próxima renovação será em um mês ou um ano a partir da data do upgrade. Quaisquer créditos não utilizados do seu plano anterior são transferidos, e sua nova franquia de créditos e limites de concorrência se aplicam na hora.
* **Downgrades** são agendados para entrar em vigor na sua próxima data de renovação. Você mantém os créditos e limites do seu plano atual até lá, e o tempo não utilizado do seu plano atual não gera créditos nem reembolso. Você pode desfazer um downgrade agendado nas suas [configurações de cobrança](https://www.firecrawl.dev/app/settings?tab=billing) a qualquer momento antes da data de vigência.

<div id="switching-between-monthly-and-yearly-billing">
  ### Alternar entre cobrança mensal e anual
</div>

* **Mensal → Anual** no mesmo nível de créditos ou em um nível superior é considerado um upgrade imediato.
* **Anual → Mensal** é considerado um upgrade imediato apenas se você mudar para um nível de créditos estritamente superior.

<div id="running-out-of-credits">
  ## Crédito esgotado
</div>

O que acontece quando seu saldo chega a zero depende do seu plano e da sua configuração de pagamento por uso.

| Plano                              | Pagamento por uso                     | Com saldo zerado                                                                                                                                                                                                                                                                                   |
| ---------------------------------- | ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Free**                           | Não disponível                        | As requisições que consomem créditos retornam **HTTP 402 (Payment Required)** até a renovação mensal.                                                                                                                                                                                              |
| **Hobby, Standard, Growth, Scale** | Desativado (limite definido como `0`) | As requisições que consomem créditos retornam **HTTP 402**. Seu cartão não é cobrado.                                                                                                                                                                                                              |
| **Hobby, Standard, Growth, Scale** | Ativado                               | O Firecrawl cobra um incremento de 5 USD no seu cartão e adiciona os créditos correspondentes. Suas requisições continuam funcionando. Isso se repete sempre que o saldo chega a zero, até que o **limite mensal de pagamento por uso** seja atingido. Deixe o limite em branco para não ter teto. |

Com o pagamento por uso ativado, as requisições não são cortadas exatamente no zero. Seu plano conta com uma margem de excedente para que um pico de requisições continue rodando enquanto a recarga é processada: **1.500 créditos no Hobby, 30.000 no Standard, 150.000 no Growth e 600.000 no Scale**. Assim que o limite mensal é atingido e a margem é consumida, as requisições retornam **HTTP 402** até o próximo ciclo de cobrança. Essa margem é apenas uma folga, não créditos extras que ficam com você.

Os créditos comprados manualmente (**Load more credits**) são gastos antes de qualquer uma dessas regras valer e não contam para o limite mensal de pagamento por uso.

Para retomar o uso após uma interrupção total, você pode:

1. Definir um **limite mensal de pagamento por uso** para comprar créditos automaticamente. Veja [Pagamento por uso](#pay-as-you-go).
2. Fazer upgrade manualmente para um plano superior
3. Aguardar a renovação dos seus créditos no próximo ciclo de cobrança

<div id="coupons">
  ## Cupons
</div>

A Firecrawl oferece dois tipos de cupons:

* **Cupons de assinatura** aplicam um desconto à assinatura do seu plano (por exemplo, uma porcentagem de desconto no valor mensal ou anual). Eles **só** podem ser aplicados durante o fluxo de checkout do Stripe, quando você assina um plano pago pela primeira vez ou muda de plano. Não é possível aplicar um cupom de assinatura depois que o checkout for concluído.
* **Cupons de crédito** adicionam créditos bônus à sua conta. Eles podem ser resgatados na seção **cobrança** do seu painel em [firecrawl.dev/app/billing](https://www.firecrawl.dev/app/billing). Procure o campo de cupom na página de cobrança para aplicar seu código. Os créditos bônus de cupons de crédito são separados da cota mensal do seu plano e permanecem mesmo se você fizer upgrade ou downgrade do seu plano.

<div id="faqs">
  ## Perguntas frequentes
</div>

<AccordionGroup>
  <Accordion title="Créditos não utilizados são transferidos para o próximo mês?">
    **Créditos do plano** não são transferidos por padrão: sua cota mensal é redefinida a cada mês. **Planos anuais Scale transferem créditos do plano não utilizados por 1 mês**, e **planos anuais Enterprise os transferem por 2 meses**.
  </Accordion>

  <Accordion title="Os créditos de pagamento por uso expiram?">
    Os créditos que você compra permanecem na sua conta até que você os utilize. Eles expiram se você cancelar sua assinatura, então use-os antes de sair. A expiração ocorre no fim do seu período de cobrança atual, e uma renovação não os afeta.
  </Accordion>

  <Accordion title="Como funciona o limite mensal de pagamento por uso?">
    Seu limite restringe quanto o pagamento por uso gasta a cada mês. Ele é arredondado para baixo em incrementos inteiros de 5 USD. Um limite de 25 USD permite cinco incrementos por mês. Deixe seu limite em branco, e o pagamento por uso não terá limite mensal. Defina seu limite como `0`, e o pagamento por uso será desativado.
  </Accordion>

  <Accordion title="Como eu sei quantos créditos ainda tenho?">
    Verifique o painel em [firecrawl.dev/app](https://www.firecrawl.dev/app), ou acesse o [endpoint da API de Credit Usage](/pt-BR/api-reference/endpoint/credit-usage) programaticamente.
  </Accordion>

  <Accordion title="Onde aplico um código de cupom?">
    Depende do tipo de cupom. Aplique um **cupom de crédito** na seção cobrança do seu painel. Você pode aplicar um **cupom de assinatura** (um desconto no preço do seu plano) apenas na página de checkout do Stripe, ao assinar ou mudar de plano.
  </Accordion>

  <Accordion title="Preciso de mais concorrência ou de um plano personalizado. Com quem eu falo?">
    Entre em contato pelo e-mail [help@firecrawl.dev](mailto:help@firecrawl.dev), ou visite a [página Enterprise](https://www.firecrawl.dev/enterprise) para saber mais sobre planos personalizados.
  </Accordion>

  <Accordion title="Em qual moeda as faturas são cobradas?">
    Todas as faturas do Firecrawl são cobradas em **dólares americanos (USD)**, independentemente do seu endereço de cobrança ou método de pagamento.
  </Accordion>

  <Accordion title="Como gerencio minha assinatura, mudo de plano ou cancelo?">
    Acesse suas [configurações de cobrança](https://www.firecrawl.dev/app/settings?tab=billing). Administradores da equipe podem gerenciar tudo lá. Clique em **Manage Subscription** para abrir o portal de cobrança e atualizar seu método de pagamento, endereço de cobrança, nome da empresa ou número de VAT.

    Para mudar de plano, clique em **Change Plan** e escolha um novo nível. Os upgrades entram em vigor imediatamente. Os downgrades entram em vigor no fim do seu período de cobrança atual, e você pode desfazer um até lá. Veja [Upgrades e downgrades de plano](#upgrading-and-downgrading).

    Para cancelar, clique em **Cancel Subscription**. Seu plano permanece ativo até o fim do seu período de cobrança atual, e você pode retomá-lo antes disso. Quando seu plano termina, os créditos que você comprou expiram junto com ele, então use-os antes de sair.
  </Accordion>

  <Accordion title="Como adiciono um número de VAT, nome da empresa ou endereço de cobrança às minhas faturas?">
    Acesse suas [configurações de cobrança](https://www.firecrawl.dev/app/settings?tab=billing), clique em **Manage Subscriptions** e atualize seu endereço de cobrança, nome da empresa e número de VAT no portal da Stripe. As próximas faturas incluirão automaticamente as informações atualizadas.

    Para reemitir uma fatura paga anterior com as novas informações:

    1. Atualize primeiro seus dados de cobrança no portal da Stripe (veja acima).
    2. Abra a aba **Invoice history** no portal da Stripe e baixe o PDF da fatura desejada; a Stripe a renderiza novamente com base nas suas informações de cobrança atuais.
    3. Se alguma fatura não refletir os dados atualizados, envie um e-mail para [help@firecrawl.dev](mailto:help@firecrawl.dev) com os números das faturas e nós as reemitiremos para você.

<div id="x-xcom-billing">
  ## Cobrança do X (x.com)
</div>

O Firecrawl usa a **API oficial do Grok** da [xAI](https://x.ai/) para oferecer resumos com IA, extração estruturada e acesso em tempo real a conteúdo público do X. As requisições para URLs de perfis e publicações de `x.com`, `twitter.com` e `mobile.twitter.com` são processadas por meio das ferramentas internas autorizadas do Grok (`x_search`, obtenção de threads e busca na web restrita a x.com), em vez do scraping tradicional da web.

<div id="credit-costs">
  ### Custos em créditos
</div>

| Componente       | Custo em créditos         | Descrição                                                               |
| ---------------- | ------------------------- | ----------------------------------------------------------------------- |
| **Custo base**   | 1 crédito / requisição    | Processamento padrão de requisição de scraping                          |
| **Grok X Query** | +29 créditos / requisição | Uso da API do Grok (tokens + chamadas de ferramenta) para conteúdo do X |

Por exemplo, processar uma requisição típica de post ou thread custa **30 créditos** (`1` base + `29` Grok X Query) e retorna dados estruturados gerados pelo Grok, contexto da thread e resumos. Se o formato JSON (extração com LLM) também estiver habilitado, o total será de **34 créditos** por requisição.

Esse método está em conformidade com as interfaces publicadas pelo X por meio da parceria com a xAI e fornece resultados de maior qualidade e com raciocínio, em vez de fazer scraping bruto da página.

<Note>
  **Os recursos diferem do scraping padrão.** O Grok retorna resultados processados por IA, que podem incluir resumos, métricas importantes, contexto da thread e muito mais. Para dados estruturados brutos em escala, use a [API oficial X Enterprise](https://developer.x.com/).
</Note>
