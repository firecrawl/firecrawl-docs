Integre o Firecrawl ao Agent Development Kit (ADK) do Google para criar agentes de IA avançados com recursos de web scraping por meio do Model Context Protocol (MCP).

<div id="overview">
  ## Visão geral
</div>

O Firecrawl oferece um servidor MCP que se integra perfeitamente ao ADK do Google, permitindo que seus agentes façam scraping, crawling e extraiam dados estruturados de qualquer site com eficiência. A integração é compatível tanto com instâncias do Firecrawl em nuvem quanto auto-hospedadas, com HTTP transmissível (streaming) para desempenho ideal.

<div id="features">
  ## Funcionalidades
</div>

* web scraping, rastreamento e descoberta de conteúdo eficientes em qualquer site
* Busca avançada e extração inteligente de conteúdo
* Pesquisa aprofundada
* Implantação flexível (na nuvem ou auto-hospedada)
* Otimizado para a web moderna com suporte a HTTP por streaming

<div id="prerequisites">
  ## Pré-requisitos
</div>

- Obtenha uma chave de API do Firecrawl em [firecrawl.dev](https://firecrawl.dev)
- Instale o Google SDK

<div id="configuration">
  ## Configuração
</div>

<CodeGroup>
  ```python Remote servidor MCP
  import os

  from google.adk.agents.llm_agent import Agent
  from google.adk.tools.mcp_tool.mcp_session_manager import StreamableHTTPServerParams
  from google.adk.tools.mcp_tool.mcp_toolset import MCPToolset

  FIRECRAWL_API_KEY = os.environ["FIRECRAWL_API_KEY"]

  root_agent = Agent(
      model="gemini-2.5-pro",
      name="firecrawl_agent",
      description='Um assistente útil para fazer scraping de sites com o Firecrawl',
      instruction='Ajude o usuário a buscar conteúdo de sites',
      tools=[
          MCPToolset(
              connection_params=StreamableHTTPServerParams(
                  url="https://mcp.firecrawl.dev/v2/mcp",
                  headers={"Authorization": f"Bearer {FIRECRAWL_API_KEY}"},
              ),
          )
      ],
  )
  ```

  ```python Local servidor MCP
  import os

  from google.adk.agents.llm_agent import Agent
  from google.adk.tools.mcp_tool.mcp_session_manager import StdioConnectionParams
  from google.adk.tools.mcp_tool.mcp_toolset import MCPToolset
  from mcp import StdioServerParameters

  root_agent = Agent(
      model='gemini-2.5-pro',
      name='firecrawl_agent',
      description='Um assistente útil para fazer scraping de sites com o Firecrawl',
      instruction='Ajude o usuário a buscar conteúdo de sites',
      tools=[
          MCPToolset(
              connection_params=StdioConnectionParams(
                  server_params = StdioServerParameters(
                      command='npx',
                      args=[
                          "-y",
                          "firecrawl-mcp@3.23.7",
                      ],
                      env={
                          "FIRECRAWL_API_KEY": os.environ["FIRECRAWL_API_KEY"],
                      }
                  ),
                  timeout=30,
              ),
          )
      ],
  )
  ```
</CodeGroup>

Defina `FIRECRAWL_API_KEY` no ambiente que inicia o ADK. Não inclua seu valor em prompts de agentes, no controle de versão nem na URL do MCP. O pacote MCP local exige Node.js 22 ou mais recente.

<div id="available-tools">
  ## Ferramentas disponíveis
</div>

| Ferramenta         | Nome                           | Descrição                                                                      |
| ------------------ | ------------------------------ | ------------------------------------------------------------------------------ |
| Scrape Tool        | `firecrawl_scrape`             | Extrair conteúdo de uma única URL com opções avançadas                         |
| Map Tool           | `firecrawl_map`                | Mapear um site para descobrir todas as URLs indexadas                          |
| Search Tool        | `firecrawl_search`             | Pesquisar na web e, opcionalmente, extrair conteúdo dos resultados de pesquisa |
| Ferramenta de rastreamento | `firecrawl_crawl`              | Iniciar um rastreamento assíncrono com opções avançadas                        |
| Verificar o status do rastreamento | `firecrawl_check_crawl_status` | Verificar o status de um trabalho de rastreamento                              |

  ## Configuração
</div>

<div id="required-configuration">
  ### Configuração obrigatória
</div>

**FIRECRAWL_API_KEY**: Sua chave de API do Firecrawl

- Obrigatório ao usar a API em nuvem (padrão)
- Opcional ao usar uma instância auto-hospedada com FIRECRAWL_API_URL

<div id="optional-configuration">
  ### Configuração opcional
</div>

**URL da API do Firecrawl (para instâncias auto-hospedadas)**:

* `FIRECRAWL_API_URL`: Endpoint de API personalizado
* Exemplo: `https://firecrawl.your-domain.com`
* Se não for informada, a API em nuvem será utilizada

<div id="example-web-research-agent">
  ## Exemplo: Agente de pesquisa na web
</div>

```python
from google.adk.agents.llm_agent import Agent
from google.adk.tools.mcp_tool.mcp_session_manager import StreamableHTTPServerParams
from google.adk.tools.mcp_tool.mcp_toolset import MCPToolset

FIRECRAWL_API_KEY = "YOUR-API-KEY"

# Criar um agente de pesquisa
research_agent = Agent(
    model="gemini-2.5-pro",
    name="research_agent",
    description='An AI agent that researches topics by scraping and analyzing web content',
    instruction='''You are a research assistant. When given a topic or question:
    1. Use the search tool to find relevant websites
    2. Scrape the most relevant pages for detailed information
    3. Extract structured data when needed
    4. Provide comprehensive, well-sourced answers''',
    tools=[
        MCPToolset(
            connection_params=StreamableHTTPServerParams(
                url="https://mcp.firecrawl.dev/v2/mcp",
                headers={"Authorization": f"Bearer {FIRECRAWL_API_KEY}"},
            ),
        )
    ],
)

# Usar o agente
response = research_agent.run("What are the latest features in Python 3.13?")
print(response)
```

<div id="best-practices">
  ## Boas práticas
</div>

1. **Use a ferramenta certa para a tarefa**:
   * `firecrawl_search` quando você precisar encontrar primeiro as páginas relevantes
   * `firecrawl_scrape` para páginas individuais
   * `firecrawl_crawl` para descobrir e extrair sites inteiros
   * chamadas repetidas de `firecrawl_scrape` quando você já tiver uma pequena lista de URLs conhecidas

2. **Monitore seu uso**: Use seu painel do Firecrawl e as respostas da API para acompanhar o uso de créditos.

3. **Lide com erros de forma adequada**: Exiba erros de MCP/API ao usuário e tente novamente apenas quando o fluxo de trabalho do seu agente puder fazer isso com segurança.

4. **Otimize o desempenho**: Use `firecrawl_map` antes do scraping quando o agente precisar descobrir URLs relevantes.
