Aprenda a usar os principais recursos do Firecrawl para fazer scraping de repositórios, issues e documentação do GitHub.

<Info>
  Há duas maneiras de obter dados do GitHub com o Firecrawl. Você pode **fazer scraping, mapear ou fazer rastreamento** uma URL específica do `github.com` (abordado no restante desta página) ou usar o [índice para desenvolvedores](/pt-BR/features/developer) para descobrir semanticamente issues, pull requests mesclados e READMEs relevantes em todo o GitHub sem conhecer a URL exata.
</Info>

<div id="setup">
  ## Configuração
</div>

```bash
npm install firecrawl zod
```

<div id="scrape-with-json-mode">
  ## Scraping com o modo JSON
</div>

Extraia dados estruturados de repositórios usando esquemas Zod.

```typescript
import { Firecrawl } from 'firecrawl';
import { z } from 'zod';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const result = await firecrawl.scrape('https://github.com/firecrawl/firecrawl', {
    formats: [{
        type: 'json',
        schema: z.object({
            name: z.string(),
            description: z.string(),
            stars: z.number(),
            forks: z.number(),
            language: z.string(),
            topics: z.array(z.string())
        })
    }]
});

console.log(result.json);
```

<div id="search">
  ## Search
</div>

Pesquise repositórios, issues ou documentação no GitHub.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const searchResult = await firecrawl.search('machine learning site:github.com', {
    limit: 10,
    sources: [{ type: 'web' }], // { type: 'news' }, { type: 'images' }
    scrapeOptions: {
        formats: ['markdown']
    }
});

console.log(searchResult);
```

<div id="search-github-with-the-developer-index">
  ## Pesquise no GitHub com o índice para desenvolvedores
</div>

O [índice para desenvolvedores](/pt-BR/features/developer) do Firecrawl realiza buscas semânticas em issues públicas indexadas do GitHub, pull requests mescladas e READMEs de repositórios, além de sites de documentação selecionados. Ele é útil para encontrar detalhes de implementação e soluções de engenharia existentes quando você não sabe o repositório ou a URL exata, e retorna as passagens correspondentes em vez de apenas um snippet.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const result = await firecrawl.search(
    'how to handle rate limit retries with exponential backoff',
    { categories: ['developer'], limit: 10 }
);

console.log(result.developer);
```

Para obter resultados ranqueados com as passagens correspondentes e usar os filtros de repositório e tipo de resultado, chame o endpoint dedicado:

```bash
# Não é preciso API key para começar; adicione -H "Authorization: Bearer $FIRECRAWL_API_KEY" para obter limites de taxa maiores:
curl -s "https://api.firecrawl.dev/v2/search/developer?query=how%20to%20handle%20rate%20limit%20retries%20with%20exponential%20backoff&types=issue,pull_request&k=10"
```

Você também pode pesquisar no GitHub usando resultados comuns da web, por meio do endpoint geral [`/search`](/pt-BR/features/search) com a categoria `github`, que limita a busca na web ao site em vez de consultar o índice.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const searchResult = await firecrawl.search('exponential backoff retry', {
    categories: ['github'],
    limit: 10
});

console.log(searchResult);
```

Consulte o [guia do índice para desenvolvedores](/pt-BR/features/developer) para saber como usá-lo com Python, cURL, CLI e MCP.

<div id="scrape">
  ## Scraping
</div>

Fazer scraping de uma única página do GitHub — repositório, issue ou arquivo.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const result = await firecrawl.scrape('https://github.com/firecrawl/firecrawl', {
    formats: ['markdown'] // ex.: html, links, etc.
});

console.log(result);
```

<div id="map">
  ## Map
</div>

Descubra todas as URLs disponíveis em um repositório ou site de documentação. Nota: Map retorna somente URLs, sem conteúdo.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const mapResult = await firecrawl.map('https://github.com/vercel/next.js/tree/canary/docs');

console.log(mapResult.links);
// Retorna array de URLs sem conteúdo
```

<div id="crawl">
  ## Crawl
</div>

Fazer crawling de várias páginas de um repositório ou documentação.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

const crawlResult = await firecrawl.crawl('https://github.com/facebook/react/wiki', {
    limit: 10,
    scrapeOptions: {
        formats: ['markdown']
    }
});

console.log(crawlResult.data);
```

<div id="batch-scrape">
  ## Extração em lote
</div>

Fazer scraping de várias URLs do GitHub simultaneamente.

```typescript
import { Firecrawl } from 'firecrawl';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

// Aguardar a conclusão
const job = await firecrawl.batchScrape([
    'https://github.com/vercel/next.js',
    'https://github.com/facebook/react',
    'https://github.com/microsoft/typescript'],
    {
        options: {
            formats: ['markdown']
        },
        pollInterval: 2,
        timeout: 120
    }
);


console.log(job.status, job.completed, job.total);

console.log(job);
```

<div id="batch-scrape-with-json-mode">
  ## Extração em lote com o modo JSON
</div>

Extraia dados estruturados de vários repositórios de uma só vez.

```typescript
import { Firecrawl } from 'firecrawl';
import { z } from 'zod';

const firecrawl = new Firecrawl({ apiKey: process.env.FIRECRAWL_API_KEY });

// Aguardar conclusão
const job = await firecrawl.batchScrape([
    'https://github.com/vercel/next.js',
    'https://github.com/facebook/react'],
    {
        options: {
            formats: [{
                type: 'json',
                schema: z.object({
                    name: z.string(),
                    description: z.string(),
                    stars: z.number(),
                    language: z.string()
                })
            }]
        },
        pollInterval: 2,
        timeout: 120
    }
);


console.log(job.status, job.completed, job.total);

console.log(job);
```
