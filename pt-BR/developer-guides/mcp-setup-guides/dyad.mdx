Adicione o Firecrawl ao [Dyad](https://www.dyad.sh) para que a IA do seu construtor de apps possa pesquisar, fazer scraping e interagir com a web.

<Note>
  Os links Add to Dyad exigem o Dyad v0.25 ou superior.
</Note>

## 1. Obtenha sua API key {#1-get-your-api-key}

Crie uma chave em [firecrawl.dev/app/api-keys](https://www.firecrawl.dev/app/api-keys). Ela deve ser inserida no Dyad, não no link.

## 2. Adicione o Firecrawl ao Dyad {#2-add-firecrawl-to-dyad}

Escolha um transporte.

O link abre o Dyad na página **Plugins** com o formulário já preenchido. Clique em **Add** e conclua a etapa de configuração da chave correspondente ao transporte escolhido.

### Hospedado (HTTP) {#hosted-http}

1. No formulário, desative a opção **Use OAuth**.
2. Depois de adicioná-lo, abra o novo plugin e adicione este cabeçalho:

   | Cabeçalho       | Valor                           |
   | --------------- | ------------------------------- |
   | `Authorization` | `Bearer YOUR_FIRECRAWL_API_KEY` |

### Local (npx) {#local-npx}

Depois de adicioná-lo, abra o novo plugin e adicione esta variável de ambiente:

| Variável            | Valor                    |
| ------------------- | ------------------------ |
| `FIRECRAWL_API_KEY` | `YOUR_FIRECRAWL_API_KEY` |

## 3. Experimente {#3-try-it}

Em um chat do Dyad, teste:

```text
Faça uma busca na web pelas notas de versão mais recentes do Next.js e resuma as fontes.
```

```text
Raspe https://firecrawl.dev e descreva o que a página oferece.
```

## Adicionar manualmente {#add-it-by-hand}

Abra **Plugins**, clique em **Add Plugin** e preencha um dos conjuntos de valores abaixo.

| Transporte | Campos                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------- |
| `http`     | URL `https://mcp.firecrawl.dev/v2/mcp`, cabeçalho `Authorization: Bearer YOUR_FIRECRAWL_API_KEY`              |
| `stdio`    | Comando `npx`, argumentos `-y firecrawl-mcp`, variável de ambiente `FIRECRAWL_API_KEY=YOUR_FIRECRAWL_API_KEY` |

Veja a [referência do servidor MCP](/pt-BR/mcp-server) para conferir a lista completa de ferramentas.
