Adicione o Firecrawl ao ChatGPT usando o plugin nativo do Firecrawl para fazer buscas, scraping, rastreamento, interagir com a web e monitorá-la diretamente das suas conversas. Não é necessário criar um conector MCP personalizado nem inserir a URL de um servidor.

## Adicionar ao ChatGPT {#add-to-chatgpt}

<Card title="Adicionar ao ChatGPT" icon="/images/agent-clients/chatgpt.svg" href="https://chatgpt.com/plugins/plugin_asdk_app_6a314a73f8ac819195b0d55e36b9c609?q=firecrawl" cta="Abrir no ChatGPT" arrow>
  Abra o plugin do Firecrawl no ChatGPT e instale-o.
</Card>

1. Abra o [plugin do Firecrawl no ChatGPT](https://chatgpt.com/plugins/plugin_asdk_app_6a314a73f8ac819195b0d55e36b9c609?q=firecrawl) ou acesse **Plugins** no ChatGPT e busque por **Firecrawl**.
2. Selecione **Install**. Quando o ChatGPT abrir o Firecrawl no seu navegador, faça login, escolha uma equipe e aprove o acesso.
3. Inicie um novo chat para que o ChatGPT carregue o plugin e, em seguida, peça a ele que use o Firecrawl.

O mesmo plugin funciona no Codex. Veja [ChatGPT e Codex](/pt-BR/integrations/chatgpt-codex) para mais detalhes e solução de problemas.

Não coloque a chave de API do Firecrawl na URL do servidor. Para revogar o acesso depois, use as [configurações do MCP](https://www.firecrawl.dev/app/settings?tab=mcp).

## Experimente {#try}

Com o Firecrawl ativado, experimente:

```text
Faça uma busca na web pelas notas de release mais recentes do Firecrawl e resuma as fontes.
```

```text
Scrape firecrawl.dev and tell me what it does
```
