---
title: "Use o Firecrawl MCP no ChatGPT"
description: "Adicione o Firecrawl ao ChatGPT com o conector nativo"
---

Adicione o Firecrawl ao ChatGPT usando o app nativo do Firecrawl. Não é necessário criar um conector MCP personalizado nem inserir a URL de um servidor.

<div id="add-to-chatgpt">
  ## Adicionar ao ChatGPT
</div>

<Card title="Adicionar ao ChatGPT" icon="/images/agent-clients/chatgpt.svg" href="https://chatgpt.com/plugins?q=firecrawl" cta="Abrir no ChatGPT" arrow>
  Abra o app Firecrawl no ChatGPT e conecte-o.
</Card>

1. Abra o [app Firecrawl no ChatGPT](https://chatgpt.com/plugins?q=firecrawl).
2. Selecione **Firecrawl** e conecte-o. Quando o ChatGPT abrir o Firecrawl no navegador, faça login, escolha uma equipe e autorize o acesso.
3. Em uma conversa, abra o menu **+** e ative o **Firecrawl** antes de enviar um prompt. O conector precisa estar vinculado à conversa.

Não inclua uma chave de API do Firecrawl em uma URL de servidor. Para revogar o acesso posteriormente, use as [configurações do MCP](https://www.firecrawl.dev/app/settings?tab=mcp).

<div id="try">
  ## Experimente
</div>

Com o Firecrawl ativado, experimente:

```text
Faça uma busca na web pelas notas de release mais recentes do Firecrawl e resuma as fontes.
```

```text
Scrape firecrawl.dev and tell me what it does
```
