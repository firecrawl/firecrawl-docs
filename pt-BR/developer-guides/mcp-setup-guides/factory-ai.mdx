Adicione recursos de raspagem e pesquisa ao Factory AI com o Firecrawl MCP.

<div id="quick-setup">
  ## Configuração rápida {#quick-setup}
</div>

<div id="1-get-your-api-key">
  ### 1. Obtenha sua chave de API {#1-get-your-api-key}
</div>

Cadastre-se em [firecrawl.dev/app](https://firecrawl.dev/app) e copie sua chave de API.

<div id="2-install-factory-ai-cli">
  ### 2. Instalar o Factory AI CLI {#2-install-factory-ai-cli}
</div>

Instale o [Factory Droid CLI](https://docs.factory.ai/droid-cli/quickstart) se ainda não o fez:

**macOS/Linux:**

```bash
curl -fsSL https://app.factory.ai/cli | sh
```

**Windows:**

```powershell
irm https://app.factory.ai/cli/windows | iex
```

### 3. Adicione o Servidor MCP do Firecrawl {#3-add-firecrawl-mcp-server}

No terminal, adicione o servidor MCP hospedado do Firecrawl com `droid mcp add`:

```bash
droid mcp add firecrawl https://mcp.firecrawl.dev/v2/mcp --type http \
  --header "Authorization: Bearer your-api-key-here" --no-oauth
```

Substitua `your-api-key-here` pela sua chave de API do Firecrawl.

Para executar o servidor localmente, adicione-o como um servidor stdio:

```bash
droid mcp add firecrawl "npx -y firecrawl-mcp@3.33.2" --env FIRECRAWL_API_KEY=your-api-key-here
```

Você também pode digitar `/mcp` no Droid para verificar o status do servidor e ver as ferramentas disponíveis.

### 4. Pronto! {#4-done}

As ferramentas do Firecrawl agora estão disponíveis na sua sessão do Factory AI!

## Demonstração rápida {#quick-demo}

Experimente isto no Factory AI:

**Pesquisar na web:**

```
Busque as notas de versão mais recentes do Next.js
```

**Fazer scraping de uma página:**

```
Faça scraping do firecrawl.dev e me diga o que ele faz
```

**Acessar a documentação:**

```
Encontre e extraia a documentação da API do Stripe sobre intenções de pagamento
```

A Factory utilizará automaticamente as ferramentas de busca e scraping do Firecrawl para obter as informações.
