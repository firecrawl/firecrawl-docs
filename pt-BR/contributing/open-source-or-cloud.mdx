Escolha o código aberto quando precisar controlar o código-fonte ou a infraestrutura. Escolha o Firecrawl Cloud quando quiser começar a fazer scraping sem precisar operar a stack. Ambas as opções expõem as APIs principais do Firecrawl; a diferença é quem configura, protege e executa os serviços de suporte.

<Note>
  Executar o Firecrawl para desenvolvimento de produtos e operar uma implantação
  auto-hospedada são jobs distintos. Use [Executar localmente](/pt-BR/contributing/guide)
  quando estiver alterando o código do Firecrawl. Use o [guia de auto-hospedagem
  própria](/pt-BR/contributing/self-host) quando quiser uma API em execução na infraestrutura
  sob seu controle.
</Note>

<div id="choose-your-firecrawl-deployment">
  ## Escolha sua implantação do Firecrawl
</div>

<div id="use-open-source-when">
  ### Use código aberto quando
</div>

* **Você precisa controlar o código-fonte ou a infraestrutura.** Pode inspecionar o código, escolher onde a stack será executada e conectar seus próprios provedores.
* **Você está preparado para operá-lo.** Sua equipe é responsável pela autenticação, TLS, persistência, monitoramento, capacidade, atualizações e recuperação.
* **Você pode adicionar recursos de forma planejada.** O scraping básico funciona na stack padrão; formatos com suporte de LLM, serviços avançados de scraping e fluxos de extração especializados exigem configuração adicional.

<div id="use-firecrawl-cloud-when">
  ### Use o Firecrawl Cloud quando
</div>

* **Você quer o caminho mais rápido e com suporte para produção.** O Firecrawl opera a infraestrutura e os serviços gerenciados.
* **Você precisa de recursos exclusivos do Firecrawl Cloud.** Agente, navegador, painéis gerenciados, rotas de proxy aprimorado e controles empresariais são disponibilizados pelo Cloud.
* **Você quer uma única conta para uso e suporte.** Chaves de API, créditos, limites e suporte operacional ficam no serviço gerenciado.

**Nossa recomendação:** comece com o Firecrawl Cloud, a menos que o acesso ao código-fonte ou o controle da infraestrutura justifiquem o esforço operacional. Se optar pela auto-hospedagem, valide primeiro um scraping e adicione serviços somente quando seu caso de uso exigir.

<div id="compare-the-operating-model">
  ## Compare o modelo operacional
</div>

| Decisão                                                               | Código aberto                                          | Firecrawl Cloud                                            |
| --------------------------------------------------------------------- | ------------------------------------------------------ | ---------------------------------------------------------- |
| APIs principais de scraping, rastreamento, mapeamento e busca         | Incluídas                                              | Incluídas e gerenciadas                                    |
| Processamento com Fetch e Playwright                                  | Incluído na stack padrão                               | Gerenciado                                                 |
| Extração e formatos com LLM                                           | Conecte um provedor compatível com OpenAI ou o Ollama  | Provedor gerenciado                                        |
| Serviços avançados anti-bot ou de extração especializada              | Execute e configure separadamente o serviço necessário | Gerenciado quando houver suporte no produto Cloud          |
| Controles de agente, navegador, Interact, painel e recursos empresariais | Não incluídos na stack padrão                          | Incluídos conforme a disponibilidade do produto e do plano |
| Segurança, persistência, disponibilidade e atualizações               | Você é responsável por eles                            | A Firecrawl os opera                                       |
| Uso, limites e cobrança                                               | Custos da sua infraestrutura e dos seus provedores     | Modelo de planos e créditos da Firecrawl                   |

<div id="start-with-the-path-you-chose">
  ## Comece pelo caminho que você escolheu
</div>

* **Hospede o Firecrawl por conta própria:** siga o [guia de auto-hospedagem com Docker Compose](/pt-BR/contributing/self-host), desde uma versão fixada até um scraping verificado.
* **Altere o código do Firecrawl:** use [Executando localmente](/pt-BR/contributing/guide) para configurar o ambiente de desenvolvimento para contribuidores.
* **Use o Firecrawl Cloud:** [crie uma conta](https://firecrawl.dev) e siga o [guia de início rápido](/pt-BR/quickstart).

O código aberto mantém o mecanismo central inspecionável e adaptável. O Firecrawl Cloud financia esse trabalho e oferece aos desenvolvedores um caminho gerenciado, com recursos adicionais de produto e infraestrutura.
