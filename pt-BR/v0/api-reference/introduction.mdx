<div id="base-url">
  ## URL base {#base-url}
</div>

Todas as solicitações usam a seguinte URL base:

```bash
https://api.firecrawl.dev 
```

## Autenticação {#authentication}

Para a autenticação, é necessário incluir um header Authorization. O header deve conter `Bearer fc_123456789`, onde `fc_123456789` representa sua API Key.

```bash
Authorization: Bearer fc_123456789
```

​

## Response codes {#response-codes}

O Firecrawl utiliza códigos de HTTP status convencionais para indicar o resultado das suas requests.

Em geral, códigos de HTTP status 2xx indicam sucesso, códigos 4xx representam falhas relacionadas ao usuário e códigos 5xx sinalizam problemas de infraestrutura.

| Status | Description                                       |
| ------ | ------------------------------------------------- |
| 200    | A request foi bem-sucedida.                       |
| 400    | Verifique se os parameters estão corretos.        |
| 401    | A API key não foi fornecida.                      |
| 402    | Payment required                                  |
| 404    | Não foi possível localizar o resource solicitado. |
| 429    | O limite de taxa foi excedido.                    |
| 5xx    | Indica um erro de server no Firecrawl.            |

Consulte a seção Error Codes para uma explicação detalhada de todos os possíveis erros da API.

​

<div id="rate-limit">
  ## Limite de taxa {#rate-limit}
</div>

A API do Firecrawl possui um limite de taxa para garantir a estabilidade e a confiabilidade do serviço. Esse limite é aplicado a todos os endpoints e se baseia no número de solicitações feitas em um intervalo de tempo específico.

Ao exceder o limite de taxa, você receberá o código de status 429.
