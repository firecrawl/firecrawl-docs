<div id="scraping-with-firecrawl">
  ## Coleta com o Firecrawl {#scraping-with-firecrawl}
</div>

O Firecrawl converte páginas da web em markdown, ideal para aplicações com LLMs. Veja por que:

1. **Complexidades sob controle:**
   Gerencia proxies, cache, limites de taxa e conteúdo bloqueado por JavaScript para uma raspagem sem atritos.

2. **Conteúdo dinâmico:**
   Captura dados de sites renderizados em JavaScript, PDFs, imagens etc.

3. **Conversão para Markdown ou dados estruturados:**
   Transforma os dados coletados em markdown limpo ou saída estruturada, ideal para processamento por LLMs ou outras tarefas.

Para mais detalhes, consulte a [referência da API do endpoint /scrape](https://docs.firecrawl.dev/api-reference/endpoint/scrape).

<div id="usage">
  ### Uso {#usage}
</div>

<CodeGroup>
  ```python Python
  from firecrawl import FirecrawlApp

  app = FirecrawlApp(api_key="YOUR_API_KEY")

  content = app.scrape_url("https://mendable.ai")
  ```

  ```JavaScript JavaScript
  import { FirecrawlApp } from 'firecrawl-js';

  const app = new FirecrawlApp({ apiKey: 'YOUR_API_KEY' });

  const content = await app.scrapeUrl('https://mendable.ai');
  ```

  ```go Go
  import (
    "fmt"
    "log"

    "github.com/mendableai/firecrawl-go"
  )

  func main() {
    app, err := firecrawl.NewFirecrawlApp("YOUR_API_KEY")
    if err != nil {
      log.Fatalf("Falha ao inicializar o FirecrawlApp: %v", err)
    }

    content, err := app.ScrapeURL("mendable.ai", nil)
    if err != nil {
      log.Fatalf("Falha ao fazer o scrape da URL: %v", err)
    }
    fmt.Println(content)
  }
  ```

  ```rust Rust
  use firecrawl::FirecrawlApp;

  #[tokio::main]
  async fn main() {
      // Inicialize o FirecrawlApp com a chave de API
      let api_key = "YOUR_API_KEY";
      let api_url = "https://api.firecrawl.dev";
      let app = FirecrawlApp::new(api_key, api_url).expect("Falha ao inicializar o FirecrawlApp");

      // Faça o scrape da URL
      let scrape_result = app.scrape_url("https://mendable.ai", None).await;

      // Imprima o resultado do scrape
    match scrape_result {
      Ok(data) => println!("Resultado do scrape:\n{}", data["markdown"]),
      Err(e) => eprintln!("Falha no scrape: {}", e),
    }
  }
  ```

  ```bash cURL
  curl -X POST https://api.firecrawl.dev/v0/scrape \
      -H 'Content-Type: application/json' \
      -H 'Authorization: Bearer YOUR_API_KEY' \
      -d '{
        "url": "https://mendable.ai"
      }'
  ```
</CodeGroup>

<div id="response">
  ### Resposta {#response}
</div>

Os SDKs retornarão o objeto de dados diretamente. O cURL retornará o payload exatamente como mostrado abaixo.

```json
{
  "success": true,
  "data": {
    "content": "Conteúdo bruto ",
    "markdown": "# Conteúdo em Markdown",
    "provider": "web-scraper",
    "metadata": {
      "title": "Mendable | IA para CX e Vendas",
      "description": "IA para CX e Vendas",
      "language": null,
      "sourceURL": "https://www.mendable.ai/"
    }
  }
}
```
