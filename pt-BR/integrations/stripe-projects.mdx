## Visão geral {#overview}

O [Stripe Projects](https://projects.dev) provisiona serviços de terceiros pelo terminal e sincroniza suas credenciais com o seu `.env`. O Firecrawl é um dos providers, então um único comando cria uma conta no Firecrawl, grava uma API key no seu projeto e permite escolher um plano. Os planos pagos são cobrados no método de pagamento da sua conta Stripe.

| O que você recebe | Detalhe                                                                                                                      |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **Conta**         | Uma conta Firecrawl vinculada ao email da sua conta Stripe. Se esse email já tiver uma conta Firecrawl, ela é reaproveitada. |
| **API key**       | Uma API key do espaço de trabalho gravada no seu `.env`. Uma única key cobre todos os endpoints do Firecrawl.                |
| **Plano**         | Free por padrão. Faça upgrade para Hobby, Standard ou Growth, mensal ou anual, pela CLI.                                     |
| **Painel**        | `stripe projects open firecrawl` conecta você ao painel do Firecrawl.                                                        |

## Início rápido {#quick-start}

```bash
stripe plugin install projects
stripe projects init
stripe projects add firecrawl/api --name firecrawl
stripe projects env --pull
```

`--name firecrawl` define o nome do recurso local, que se torna o prefixo das variáveis gravadas pela CLI. Com ele, a key vai para `FIRECRAWL_API_KEY`, que os [SDKs](/pt-BR/sdks/overview) e a [CLI](/pt-BR/sdks/cli) do Firecrawl leem automaticamente. Sem ele, o recurso passa a se chamar `firecrawl-api` e a key vai para `FIRECRAWL_API_API_KEY`.

A CLI também grava `FIRECRAWL_API_BASE_URL` e `FIRECRAWL_DOCUMENTATION_URL`. Ambas são apenas informativas. Os SDKs leem `FIRECRAWL_API_URL` somente em implantações self-hosted; uma account provisionada pelo Stripe usa a API hospedada, que é o padrão, então deixe `FIRECRAWL_API_URL` sem definição.

Daqui em diante, siga o guia de início rápido de [Node.js](/pt-BR/quickstarts/nodejs) ou [Python](/pt-BR/quickstarts/python), ou a [visão geral dos SDKs](/pt-BR/sdks/overview) para outras linguagens. A key funciona com todos os endpoints: [search](/pt-BR/features/search), [scrape](/pt-BR/features/scrape), [crawl](/pt-BR/features/crawl), [map](/pt-BR/features/map), [extract](/pt-BR/features/extract), [interact](/pt-BR/features/interact), [parse](/pt-BR/features/parse) e [monitor](/pt-BR/features/monitoring).

## Catálogo {#catalog}

Execute `stripe projects catalog firecrawl` para ver a lista atualizada. A CLI mostra o preço final antes de você confirmar qualquer coisa.

| Slug                 | Tipo    | O que é                                                                   |
| -------------------- | ------- | ------------------------------------------------------------------------- |
| `firecrawl/api`      | Serviço | A API do Firecrawl. Provisiona a conta e a API key. Tier Free por padrão. |
| `firecrawl/free`     | Plano   | O plano Free. Não precisa de cartão.                                      |
| `firecrawl/hobby`    | Plano   | O plano Hobby. Pergunta se é `Monthly` ou `Yearly`.                       |
| `firecrawl/standard` | Plano   | O plano Standard. Pergunta se é `Monthly` ou `Yearly`.                    |
| `firecrawl/growth`   | Plano   | O plano Growth. Pergunta se é `Monthly` ou `Yearly`.                      |

Os planos e preços são os mesmos de [firecrawl.dev/pricing](https://www.firecrawl.dev/pricing). Scale e Enterprise não são oferecidos via Stripe Projects; nesses casos, [fale com a gente](https://www.firecrawl.dev/enterprise).

## Gerenciar o recurso {#manage-the-resource}

```bash
# Adicione um método de pagamento à sua conta Stripe uma única vez
stripe projects billing add

# Mude para um plano pago; a CLI pergunta qual plano e qual intervalo de cobrança
stripe projects upgrade firecrawl

# Rotacione a API key e depois traga o novo valor para o .env
stripe projects rotate firecrawl
stripe projects env --pull

# Remova o Firecrawl deste projeto
stripe projects remove firecrawl
```

Os upgrades usam um [Shared Payment Token](https://docs.stripe.com/agentic-commerce/concepts/shared-payment-tokens) da Stripe, ou seja, a Firecrawl nunca tem acesso aos dados do seu cartão. O plano aparece no seu painel da Firecrawl como qualquer outra assinatura. Para voltar ao Free, execute `stripe projects upgrade firecrawl` e escolha `free`, ou altere o plano em [Billing](https://www.firecrawl.dev/app/settings?tab=billing) no painel.

## Contas e cobrança {#accounts-and-billing}

* **Uma conta Stripe, uma conta Firecrawl.** O Firecrawl consulta o e-mail da sua conta Stripe. Um e-mail novo recebe uma nova conta Firecrawl, já verificada, com uma equipe e uma API key padrão. Um e-mail que já possui uma conta Firecrawl reutiliza a equipe que ele vinculou anteriormente via Stripe; na primeira vez, é criada uma nova equipe chamada `via stripe` em uma organização própria, para que a cobrança do Stripe fique separada das suas outras equipes Firecrawl.
* **Todos na conta Stripe podem atuar na conta Firecrawl vinculada** por meio dos Projects, seguindo o modelo do Stripe. O painel do Firecrawl exibe a conta sob o e-mail da conta Stripe.
* **Os planos pagos são assinaturas do Firecrawl**, pagas com seu Shared Payment Token e informadas por `stripe projects spend`. Créditos, limites de taxa e recursos são os mesmos do plano equivalente adquirido em firecrawl.dev.
* **Remover o recurso cancela o plano dele.** A conta e a API key permanecem.

## Coding agents {#coding-agents}

O Stripe Projects foi criado tanto para agentes quanto para pessoas. A Stripe publica uma [skill](https://docs.stripe.com/projects#coding-agent) que ensina a CLI do Projects ao Claude Code, Cursor, Codex e outros agentes, e o `stripe projects llm-context` reúne esta página com as orientações de todos os outros providers do projeto.

```bash
npx skills add https://docs.stripe.com --skill stripe-projects -g -y
```

Quando um agente provisiona o Firecrawl: copie o slug de `stripe projects catalog firecrawl --json` em vez de adivinhá-lo, passe `--name firecrawl`, execute `stripe projects env --pull` e use a `FIRECRAWL_API_KEY` do ambiente em vez de editar o `.env`, e deixe os upgrades pagos para o humano, já que eles geram cobrança no cartão da conta Stripe. O `--accept-tos` aceita os [Termos de Serviço do Firecrawl](https://www.firecrawl.dev/terms-of-service) em nome do humano, portanto confirme com ele antes. O restante da configuração do agente está em [Desenvolva com IA](/pt-BR/ai-onboarding).

## Solução de problemas {#troubleshooting}

| O que você vê                                    | O que fazer                                                                                                                                         |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Provider connection requires re-authentication` | Execute `stripe projects link firecrawl` e tente novamente.                                                                                         |
| `Unknown provider or category: firecrawl`        | Execute `stripe plugin upgrade projects` e, em seguida, `stripe projects catalog firecrawl --refresh`.                                              |
| O provisionamento pago falha                     | Execute `stripe projects billing add` para confirmar um método de pagamento. Se a sua conta Firecrawl já tiver um plano pago, altere-o pelo painel. |
| A chave vai parar em `FIRECRAWL_API_API_KEY`     | Você fez o provisionamento sem `--name`. Exporte-a como `FIRECRAWL_API_KEY` ou remova o recurso e adicione-o novamente com `--name firecrawl`.      |

Ainda com problemas? Envie um e-mail para [help@firecrawl.com](mailto:help@firecrawl.com) com o request id da Stripe exibido no erro.
