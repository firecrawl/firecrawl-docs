<div id="firecrawl-actions">
  ## Ações do Firecrawl
</div>

| Ação               | Caso de uso                                      |
| ------------------ | ------------------------------------------------ |
| **/Scrape Page**   | Captura rápida de dados de uma única página      |
| **/Crawl Website** | Scraping completo de sites com várias páginas    |
| **/Extract Data**  | Extração com IA usando schemas personalizados    |
| **/Search Data**   | Automação de pesquisa com busca + scraping       |
| **/Map Data**      | Análise de SEO e mapeamento da estrutura do site |

<div id="quick-reference">
  ## Referência rápida
</div>

<CardGroup cols={2}>
  <Card title="Primeiros passos" icon="play">
    1. Cadastre-se em [firecrawl.dev](https://firecrawl.dev)
    2. Obtenha sua chave de API
    3. Crie um Zap no Zapier
    4. Conecte o Firecrawl usando sua chave de API
    5. Escolha seu fluxo de trabalho e ative-o
  </Card>

  <Card title="Boas práticas" icon="lightbulb">
    * Use `/Scrape Page` para páginas individuais (mais rápido)
    * Configure o agendamento estrategicamente (de hora em hora/diariamente/semanalmente)
    * Primeiro, teste no playground do Firecrawl
    * Adicione tratamento de erros para scrapes que falharem
    * Use filtros para evitar execuções desnecessárias
  </Card>
</CardGroup>

<div id="zapier-vs-n8n">
  ## Zapier vs n8n
</div>

| Recurso          | Zapier                                  | n8n                                   |
| ---------------- | --------------------------------------- | ------------------------------------- |
| **Configuração** | Sem código, baseado na nuvem            | Auto-hospedado ou na nuvem            |
| **Preços**       | Por tarefa                              | Por execução                          |
| **Integrações**  | Mais de 9.000 apps                      | Mais de 1.000 apps e serviços         |
| **Ideal para**   | Automação rápida, usuários não técnicos | Lógica personalizada, desenvolvedores |

<Tip>
  **Dica:** Comece com os modelos prontos do Zapier e personalize conforme necessário. Ideal para automações rápidas sem código!
</Tip>
