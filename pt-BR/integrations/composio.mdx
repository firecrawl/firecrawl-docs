<div id="overview">
  ## Visão geral
</div>

O Composio disponibiliza o Firecrawl como um toolkit para que seus agentes possam fazer buscas, scraping, rastreamento, mapeamento e extração sem integração personalizada com a API. O toolkit é autenticado com uma chave de API do Firecrawl.

<div id="quick-start">
  ## Início rápido
</div>

1. Conecte o Firecrawl no [painel da Composio](https://dashboard.composio.dev) usando sua chave de API do Firecrawl
2. Confira as ferramentas disponíveis na [documentação do toolkit do Firecrawl](https://docs.composio.dev/toolkits/firecrawl)
3. Chame ferramentas do Firecrawl em seus agentes ou fluxos de trabalho desenvolvidos com a Composio

<div id="what-you-can-do">
  ## O que você pode fazer
</div>

| Recurso              | Caso de uso                                             |
| -------------------- | ------------------------------------------------------- |
| **Busca**            | Encontre fontes antes da extração                       |
| **Scraping**         | Obtenha o conteúdo da página para o contexto do agente  |
| **Extração em lote** | Extraia várias URLs em um único job                     |
| **Rastreamento**     | Colete dados de sites com várias páginas                |
| **Map**              | Liste as URLs de um site antes de decidir o que extrair |
| **Extract**          | Retorne campos estruturados em vez de texto bruto       |
