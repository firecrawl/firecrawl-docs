## Visão geral {#overview}

Os stories do Tines podem chamar qualquer API REST com a action HTTP Request. Ao apontar essa action para a API do Firecrawl, um story pode fazer uma busca na web, fazer scraping de uma página e convertê-la em markdown, extrair dados estruturados, mapear um site ou rastreá-lo e repassar o resultado para a próxima action do story.

## Início rápido {#quick-start}

1. [Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys)
2. No Tines, abra **Credenciais**, crie uma credencial do tipo **Text** chamada `firecrawl` e cole a chave como valor
3. Adicione uma action **HTTP Request** à sua story e configure-a conforme mostrado abaixo

Ao referenciar a chave como `<<CREDENTIAL.firecrawl>>`, você a mantém fora da configuração da action.

## Fazer scraping de uma página {#scrape-a-page}

Esta action envia uma solicitação de raspagem e retorna a página em markdown:

```json
{
  "url": "https://api.firecrawl.dev/v2/scrape",
  "method": "post",
  "content_type": "json",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  },
  "payload": {
    "url": "https://example.com",
    "formats": ["markdown"],
    "integration": "_tines"
  }
}
```

Substitua `https://example.com` por uma URL vinda de um evento upstream, por exemplo, `<<receive_event.body.url>>`. O campo opcional `integration` identifica as requisições originadas do Tines.

## O que você pode fazer {#what-you-can-do}

| Capacidade    | Endpoint                               | Caso de uso                                                                  |
| ------------- | -------------------------------------- | ---------------------------------------------------------------------------- |
| **Pesquisar** | `POST /v2/search`                      | Encontrar fontes para uma pergunta ou alerta antes de executar outras actions  |
| **Raspar**    | `POST /v2/scrape`                      | Transformar uma URL em markdown ou JSON estruturado                          |
| **Extrair**   | `POST /v2/scrape` com o formato `json` | Obter campos como título ou detalhes de produto usando um prompt e um schema |
| **Mapear**    | `POST /v2/map`                         | Listar as URLs de um site                                                    |
| **Rastrear**  | `POST /v2/crawl`                       | Coletar páginas de todo um site e depois consultar o resultado               |

Todos os endpoints usam a URL base `https://api.firecrawl.dev`, o mesmo cabeçalho `Authorization` e um corpo JSON.

## Fazer uma busca na web {#search-the-web}

```json
{
  "url": "https://api.firecrawl.dev/v2/search",
  "method": "post",
  "content_type": "json",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  },
  "payload": {
    "query": "firecrawl web scraping",
    "limit": 5,
    "sources": ["web"],
    "integration": "_tines"
  }
}
```

## Extrair dados estruturados {#extract-structured-data}

Defina a entrada de `formats` com o tipo `json`, junto com um prompt e um schema JSON:

```json
{
  "url": "https://api.firecrawl.dev/v2/scrape",
  "method": "post",
  "content_type": "json",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  },
  "payload": {
    "url": "https://example.com",
    "formats": [
      {
        "type": "json",
        "prompt": "Extract the page title",
        "schema": {
          "type": "object",
          "properties": { "title": { "type": "string" } }
        }
      }
    ],
    "integration": "_tines"
  }
}
```

## Rastrear um site {#crawl-a-site}

O rastreamento é executado de forma assíncrona. Use uma action para iniciá-lo e outra para ler o resultado.

**Inicie o rastreamento** com `POST /v2/crawl`:

```json
{
  "url": "https://api.firecrawl.dev/v2/crawl",
  "method": "post",
  "content_type": "json",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  },
  "payload": {
    "url": "https://example.com",
    "limit": 10,
    "integration": "_tines"
  }
}
```

A resposta inclui um `id`. **Verifique o status** com uma segunda action HTTP Request que consulta o rastreamento por esse `id` e repita-a até que o `status` seja `completed`:

```json
{
  "url": "https://api.firecrawl.dev/v2/crawl/<<start_crawl.body.id>>",
  "method": "get",
  "headers": {
    "Authorization": "Bearer <<CREDENTIAL.firecrawl>>"
  }
}
```

Aqui, `start_crawl` é o nome da action que iniciou o rastreamento.
