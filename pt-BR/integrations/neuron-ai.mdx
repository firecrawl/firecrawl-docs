## Visão geral {#overview}

[Neuron AI](https://neuron-ai.dev) é um framework agêntico para PHP. Ele já vem com um toolkit do Firecrawl, permitindo que um agente Neuron faça uma busca na web e leia qualquer página como Markdown limpo durante uma execução.

## Início rápido {#quick-start}

1. Instale o Neuron AI 4.1.3 ou superior:

```bash
composer require neuron-core/neuron-ai:^4.1.3
```

2. Obtenha uma API key no seu [painel do Firecrawl](https://www.firecrawl.dev/app/api-keys) e configure-a como `FIRECRAWL_API_KEY`
3. Adicione o toolkit ao seu agente:

```php
namespace App\Neuron;

use NeuronAI\Agent\Agent;
use NeuronAI\Tools\Toolkits\Firecrawl\FirecrawlToolkit;

class ResearchAgent extends Agent
{
    ...

    protected function tools(): array
    {
        return [
            FirecrawlToolkit::make(
                key: getenv('FIRECRAWL_API_KEY')
            ),
        ];
    }
}
```

## Ferramentas {#tools}

| Ferramenta            | Nome visto pelo agente | O que faz                                                                                       |
| --------------------- | ---------------------- | ----------------------------------------------------------------------------------------------- |
| `FirecrawlSearchTool` | `web_search`           | Faz buscas na web, ou em notícias quando o agente solicitar, com um intervalo de tempo opcional |
| `FirecrawlScrapeTool` | `url_reader`           | Retorna o conteúdo principal de uma página em Markdown                                          |

Você também pode adicionar cada ferramenta separadamente, por exemplo: `FirecrawlSearchTool::make(key: getenv('FIRECRAWL_API_KEY'))`.

## Obtenha o conteúdo da página com cada resultado de busca {#get-page-content-with-each-search-result}

Por padrão, uma busca retorna o título, a URL e a descrição de cada resultado. Ao passar `scrapeOptions`, cada resultado também inclui a página completa em Markdown, assim o agente não precisa fazer uma segunda chamada para lê-la:

```php
use NeuronAI\Tools\Toolkits\Firecrawl\FirecrawlSearchTool;

FirecrawlSearchTool::make(key: getenv('FIRECRAWL_API_KEY'))->withOptions([
    'limit' => 5,
    'scrapeOptions' => [
        'formats' => ['markdown'],
        'onlyMainContent' => true,
    ],
]);
```

`withOptions()` substitui os valores padrão e aceita qualquer [parâmetro de busca](/pt-BR/api-reference/endpoint/search). O termo de busca é sempre fornecido pelo agente.
