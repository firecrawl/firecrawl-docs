## Instalar o Firecrawl {#install-firecrawl}

<Steps>
  <Step title="Abra o plugin do Firecrawl">
    Clique em **Add to ChatGPT &amp; Codex** acima para abrir a listagem oficial do Firecrawl no diretório compartilhado de plugins. No ChatGPT &amp; Codex, você também pode abrir **Plugins** e buscar por **Firecrawl**.
  </Step>

  <Step title="Instale e conecte">
    Selecione **Install**, faça login no Firecrawl e aprove a conexão quando solicitado.
  </Step>

  <Step title="Inicie um novo chat">
    Inicie um novo chat no ChatGPT &amp; Codex para que o plugin seja carregado. Depois, peça para ele usar o Firecrawl com o prompt abaixo.
  </Step>
</Steps>

O plugin já inclui as ferramentas e skills do Firecrawl. Não é necessário configurar um servidor MCP nem instalar skills separadamente.

## Experimente no ChatGPT e no Codex {#try-it-in-chatgpt-codex}

Peça ao Firecrawl para encontrar e ler fontes atualizadas:

```text
Use o Firecrawl para encontrar as notas de versão mais recentes do Next.js.
Leia as fontes oficiais e resuma o que mudou, incluindo os links.
```

## Se o Firecrawl não aparecer {#if-firecrawl-does-not-appear}

* Inicie um novo chat ou reinicie o ChatGPT e o Codex depois de instalar o plugin.
* Verifique se o Firecrawl está instalado e ativado em **Plugins**.
* Se o login não tiver sido concluído, abra o plugin e conecte novamente sua conta do Firecrawl.
