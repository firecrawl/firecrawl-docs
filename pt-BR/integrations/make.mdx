<Steps>

  </Step>

  <Step title="Conecte-se usando a chave de API">
    Adicione sua chave de API do Firecrawl para autenticar
  </Step>

  <Step title="Configure e teste">
    Configure os parâmetros do fluxo de trabalho e execute um teste
  </Step>
</Steps>

<div id="firecrawl-actions-overview">
  ## Visão geral das ações do Firecrawl
</div>

| Módulo                        | Caso de uso                           | Ideal para                      |
| ----------------------------- | ------------------------------------- | ------------------------------- |
| **Fazer scraping de um site** | Extração de dados de uma única página | Captura rápida de dados         |
| **Rastreamento de um site**   | Coleta de conteúdo de várias páginas  | Scraping de todo o site         |
| **Extrair de um site**        | Extração estruturada com IA           | Necessidades complexas de dados |

| **Mapear um site**            | Descoberta de URLs                    | Análise de SEO                  |

<div id="best-practices">
  ## Práticas recomendadas
</div>

<CardGroup cols={2}>
  <Card title="Desempenho" icon="gauge-high">
    * Use **scraping** para páginas individuais (mais rápido)
    * Use **rastreamento** com limites para sites grandes
    * Configure o agendamento adequadamente para evitar limites de taxa
    * Adicione módulos de tratamento de erros
  </Card>

  <Card title="Otimização de custos" icon="piggy-bank">
    * Programe estrategicamente (a cada hora/diariamente/semanalmente)
    * Use filtros para evitar execuções desnecessárias
    * Defina limites de rastreamento para controlar o uso da API
    * Teste primeiro no playground do Firecrawl
  </Card>
</CardGroup>

<div id="make-vs-zapier-vs-n8n">
  ## Make vs Zapier vs n8n
</div>

| Recurso                  | Make                                 | Zapier                     | n8n                           |
| ------------------------ | ------------------------------------ | -------------------------- | ----------------------------- |
| **Configuração**         | Construtor visual, na nuvem          | Sem código, na nuvem       | Auto-hospedado ou na nuvem    |
| **Preços**               | Por operação                         | Por tarefa                 | Por execução                  |
| **Integrações**          | Mais de 3.000 apps                   | Mais de 9.000 apps         | Mais de 1.000 apps e serviços |
| **Complexidade**         | Fluxos de trabalho avançados         | Fluxos de trabalho simples | Fluxos de trabalho complexos  |
| **Ideal para**           | Automação visual, complexidade média | Automação rápida           | Controle para desenvolvedores |
| **Curva de aprendizado** | Moderada                             | Fácil                      | Moderada a avançada           |

<Tip>
  **Dica:** O Make se destaca no design visual de fluxos de trabalho e em automações complexas. É perfeito para equipes que precisam de mais controle do que o Zapier oferece, mas preferem a criação visual à abordagem centrada em código do n8n.
</Tip>
