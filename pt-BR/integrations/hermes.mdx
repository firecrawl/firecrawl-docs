</Note>

## Visão geral {#overview}

O Agente Hermes é um agente de terminal e desktop de código aberto da Nous Research. Ele vem com ferramentas web:

| Ferramenta        | O que faz                                            |
| ----------------- | ---------------------------------------------------- |
| **`web_search`**  | Faz uma busca na web e retorna resultados ranqueados |
| **`web_extract`** | Obtém e extrai conteúdo legível de URLs              |

O Firecrawl é o provedor **padrão** para busca e extração. Defina `FIRECRAWL_API_KEY`, use uma `FIRECRAWL_API_URL` auto-hospedada ou o Nous Tool Gateway. Se você tiver credenciais para vários provedores, selecione o Firecrawl em `hermes tools` ou `config.yaml`. A automação do navegador pelo modo de nuvem do Firecrawl é opcional.

## Início rápido {#quick-start}

1. Instale o Agente Hermes em [hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com/)
2. Adicione sua chave da Firecrawl:

```bash
# ~/.hermes/.env
FIRECRAWL_API_KEY=fc-your-key-here
```

Obtenha uma chave em [firecrawl.dev](https://www.firecrawl.dev/app/api-keys).

3. Ou faça a configuração de forma interativa:

```bash
hermes tools
```

Escolha **Busca na Web e Extração** → **Firecrawl**.

4. Verifique:

```bash
hermes setup
```

## Recursos {#capabilities}

| Recurso                 | No Hermes                                            |
| ----------------------- | ---------------------------------------------------- |
| **Busca**               | Backend `web_search` padrão                          |
| **Extração / scraping** | Backend `web_extract` padrão                         |
| **Navegador**           | Provedor opcional do navegador em nuvem da Firecrawl |

### Use o Firecrawl em apenas uma capacidade {#use-firecrawl-for-one-capability-only}

O Hermes permite escolher os backends de busca e extração de forma independente, para que você possa combinar um backend de busca gratuito com a extração do Firecrawl (ou vice-versa):

```yaml
# ~/.hermes/config.yaml
web:
  search_backend: "searxng"
  extract_backend: "firecrawl"
```

Quando essas chaves estão vazias, ambas usam `web.backend`, e o Hermes detecta automaticamente as credenciais disponíveis. As credenciais de outros provedores podem ter prioridade sobre as do Firecrawl durante a detecção automática. Portanto, defina explicitamente `search_backend`, `extract_backend` ou `web.backend` para garantir o uso do Firecrawl.

### Modo de navegador na nuvem {#browser-cloud-mode}

Para usar o Firecrawl na automação de navegadores:

```bash
# ~/.hermes/.env
FIRECRAWL_API_KEY=fc-your-key-here
```

```bash
hermes setup tools
# → Automação de navegador → Firecrawl
```

Opcional:

```bash
# Firecrawl auto-hospedado (caso contrário, usa a API em nuvem por padrão)
FIRECRAWL_API_URL=http://localhost:3002

# TTL da sessão em segundos (padrão: 300)
FIRECRAWL_BROWSER_TTL=600
```

## Nous Portal (Firecrawl gerenciado) {#nous-portal-managed-firecrawl}

Com uma assinatura paga do [Nous Portal](https://portal.nousresearch.com/), é possível realizar buscas na web e extrações pelo **Tool Gateway** do Hermes com o Firecrawl gerenciado. Não é necessária uma chave separada do Firecrawl:

```bash
hermes setup --portal
```

Instalações existentes podem ativar ferramentas web com `hermes tools`.

## Firecrawl auto-hospedado {#self-hosted-firecrawl}

```bash
# ~/.hermes/.env
FIRECRAWL_API_URL=http://localhost:3002
```

Quando `FIRECRAWL_API_URL` é definida, a chave de API é opcional se a autenticação do servidor Firecrawl estiver desativada (`USE_DB_AUTHENTICATION=false` na instância do Firecrawl).
