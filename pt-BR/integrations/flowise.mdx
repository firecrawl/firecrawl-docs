  ## Sincronize dados da web em fluxos de trabalho do Flowise {#sync-web-data-in-flowise-workflows}
</div>

O Firecrawl pode ser usado dentro do [Flowise, o construtor de Chatflows](https://flowiseai.com/). Esta página explica como configurar e usar um bloco do Firecrawl no Flowise.

<img
  className="block"
  src="/images/fc_flowise_block.png"
  alt="Bloco do Firecrawl no Flowise"
/>

### Rastreamento com blocos do Firecrawl {#crawling-with-firecrawl-blocks}

1. Faça login na sua conta Firecrawl, obtenha sua chave de API e adicione-a ao bloco como uma credencial **FireCrawl API**.
2. (Opcional) Conecte o Text Splitter.
3. Defina **Type** como **Crawl** para coletar as páginas abaixo da URL de destino.
4. Insira a URL de destino a ser rastreada. Use **Limit**, **Include Paths** e **Exclude Paths** para manter o rastreamento enxuto.
5. Use os documentos resultantes nos seus fluxos de trabalho.

### Extraindo com blocos do Firecrawl {#scraping-with-firecrawl-blocks}

1. Faça login na sua conta do Firecrawl, obtenha sua chave de API e adicione-a ao bloco como uma credencial **FireCrawl API**.
2. (Opcional) Conecte o Text Splitter.
3. Defina **Type** como **Scrape** para processar uma única página.
4. Insira a URL de destino a ser extraída.
5. Use os documentos resultantes nos seus fluxos de trabalho.

### Pesquisa e extração com blocos do Firecrawl {#searching-and-extracting-with-firecrawl-blocks}

Defina **Type** como **Search** para transformar os resultados de pesquisa na web de uma **Query** em documentos, ou como **Extract** para retornar dados estruturados de uma URL usando um **Schema** e um **Prompt**.
