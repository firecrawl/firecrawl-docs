## Usando o Firecrawl com o CrewAI {#using-firecrawl-with-crewai}

O Firecrawl é a API de contexto para agentes de IA, e o [CrewAI, o framework para orquestração de agentes de IA](https://www.crewai.com/), inclui três ferramentas do Firecrawl: FirecrawlSearchTool, FirecrawlScrapeWebsiteTool e Ferramenta FirecrawlCrawlWebsite. Use-as para que suas crews possam fazer busca, scraping e rastreamento na web e obter contexto limpo.

### Instalando as ferramentas do Firecrawl no CrewAI {#installing-firecrawl-tools-inside-of-crewai}

* Obtenha uma chave de API no seu [painel do firecrawl.dev](https://www.firecrawl.dev/app/api-keys) e defina-a nas variáveis de ambiente (`FIRECRAWL_API_KEY`).
* Instale o [SDK do Firecrawl](https://github.com/firecrawl/firecrawl) junto com o pacote `crewai[tools]`:

```
pip install firecrawl-py 'crewai[tools]'
```

Cada ferramenta recebe suas opções do Firecrawl em um dicionário `config` ao ser instanciada. A URL ou a consulta é fornecida pelo agente quando ele chama a ferramenta, então você só precisa passar as opções de antemão.

<div id="firecrawlcrawlwebsitetool">
  ### Ferramenta FirecrawlCrawlWebsite {#firecrawlcrawlwebsitetool}
</div>

#### Exemplo {#example}

Use a Ferramenta FirecrawlCrawlWebsite da seguinte forma para permitir que seu agente rastreie sites:

```python
from crewai_tools import FirecrawlCrawlWebsiteTool

tool = FirecrawlCrawlWebsiteTool(config={"limit": 5})

# Os agentes chamam a ferramenta com uma URL. Você também pode executá-la diretamente:
result = tool.run(url="https://firecrawl.dev")
print(result.status, len(result.data))
```

#### Argumentos {#arguments}

* `api_key`: Opcional. Especifica a chave de API do Firecrawl. O padrão é a variável de ambiente `FIRECRAWL_API_KEY`.
* `config`: Opcional. [Parâmetros de rastreamento](/pt-BR/api-reference/endpoint/crawl-post) em snake&#95;case. Ao passar `config`, os padrões abaixo são substituídos.
  * `limit`: Número máximo de páginas a rastrear. Padrão: `10`.
  * `max_discovery_depth`: Profundidade máxima para descoberta de páginas. Padrão: `2`.
  * `ignore_sitemap`: Define se o mapa do site deve ser ignorado. Padrão: `True`.
  * `allow_external_links`: Permite rastrear links externos. Padrão: `False`.
  * `allow_subdomains`: Permite rastrear subdomínios. Padrão: `False`.
  * `delay`: Intervalo entre requisições, em milissegundos. Padrão: `None`.
  * `scrape_options`: Opções para cada página rastreada. Padrão: `{"formats": ["markdown"], "only_main_content": True, "timeout": 10000}`.

<div id="firecrawlscrapewebsitetool">
  ### FirecrawlScrapeWebsiteTool {#firecrawlscrapewebsitetool}
</div>

#### Exemplo {#example-2}

Use o FirecrawlScrapeWebsiteTool da seguinte forma para permitir que seu agente carregue sites:

```python
from crewai_tools import FirecrawlScrapeWebsiteTool

tool = FirecrawlScrapeWebsiteTool(config={"formats": ["markdown"], "only_main_content": True})

result = tool.run(url="https://firecrawl.dev")
print(result.markdown)
```

#### Argumentos {#arguments-2}

* `api_key`: Opcional. Especifica a chave de API do Firecrawl. O padrão é a variável de ambiente `FIRECRAWL_API_KEY`.
* `config`: Opcional. [Parâmetros de scraping](/pt-BR/api-reference/endpoint/scrape) em snake&#95;case. Ao passar `config`, os padrões abaixo são substituídos.
  * `formats`: Formatos de saída, como `"markdown"`, `"html"`, `"links"` ou um objeto de formato JSON para extração estruturada. Padrão: `["markdown"]`.
  * `only_main_content`: Retorna apenas o conteúdo principal da página, excluindo cabeçalhos, barras de navegação, rodapés etc. Padrão: `True`.
  * `include_tags` / `exclude_tags`: Tags HTML a incluir ou excluir. Padrão: `[]`.
  * `max_age`: Retorna uma versão em cache se ela for mais recente que esse número de milissegundos. Padrão: `172800000` (2 dias).
  * `wait_for`: Tempo de espera, em milissegundos, antes de buscar o conteúdo. Padrão: `0`.
  * `mobile`: Emula um dispositivo móvel. Padrão: `False`.
  * `timeout`: Tempo limite do request, em milissegundos. Padrão: `None`.

<div id="firecrawlsearchtool">
  ### FirecrawlSearchTool {#firecrawlsearchtool}
</div>

#### Exemplo {#example-3}

Use o FirecrawlSearchTool da seguinte maneira para permitir que seu agente faça uma busca na web:

```python
from crewai_tools import FirecrawlSearchTool

tool = FirecrawlSearchTool(config={"limit": 3})

result = tool.run(query="what is firecrawl?")
print([item.url for item in result.web])
```

#### Argumentos {#arguments-3}

* `api_key`: Opcional. Especifica a Chave de API do Firecrawl. O padrão é a variável de ambiente `FIRECRAWL_API_KEY`.
* `config`: Opcional. [Parâmetros de busca](/pt-BR/api-reference/endpoint/search) em snake&#95;case. Ao passar `config`, os padrões abaixo são substituídos.
  * `limit`: Número máximo de resultados de busca retornados. Padrão: `5`.
  * `tbs`: Filtro de busca por período, por exemplo, `"qdr:d"` para o último dia. Padrão: `None`.
  * `location`: Localização dos resultados de busca. Padrão: `None`.
  * `timeout`: Tempo limite da request, em milissegundos. Padrão: `None`.
  * `scrape_options`: Faz scraping de cada resultado e retorna o conteúdo. Padrão: `{"formats": ["markdown"], "only_main_content": True}`. Omita-o para obter apenas títulos, URLs e descrições.
