## Instalação {#install}

```bash
pip install langchain-firecrawl
```

Obtenha uma chave em [firecrawl.dev](https://www.firecrawl.dev/app/api-keys) e configure-a no seu ambiente (ou passe `api_key=...`):

```bash
export FIRECRAWL_API_KEY="fc-your-api-key"
```

## Carregador de documentos {#document-loader}

`FirecrawlLoader` retorna `Document`s do LangChain. Escolha um `mode`:

| Modo      | O que carrega              |
| --------- | -------------------------- |
| `scrape`  | Uma página                 |
| `crawl`   | Um site inteiro            |
| `map`     | URLs descobertas           |
| `extract` | Dados estruturados         |
| `search`  | Resultados da busca na web |

```python
from langchain_firecrawl import FirecrawlLoader

loader = FirecrawlLoader(url="https://www.firecrawl.dev", mode="scrape")
docs = loader.load()

print(docs[0].page_content[:200])
print(docs[0].metadata)
```

## Ferramentas de agente {#agent-tools}

Cada recurso também é uma `BaseTool` que você pode associar a um agente:

```python
from langchain_firecrawl import (
    FirecrawlScrape,
    FirecrawlCrawl,
    FirecrawlMap,
    FirecrawlExtract,
    FirecrawlSearch,
)

scrape = FirecrawlScrape()
result = scrape.invoke({"url": "https://www.firecrawl.dev"})
print(result["markdown"])

search = FirecrawlSearch()
print(search.invoke({"query": "best web scraping libraries", "limit": 5}))
```

## LangChain JS {#langchain-js}

O `FireCrawlLoader` do `@langchain/community` ainda chama métodos do SDK v1 e, por isso, falha com o SDK JS atual do Firecrawl. Até que ele seja atualizado, chame diretamente o [SDK Node do Firecrawl](/pt-BR/sdks/node) e encapsule os resultados em objetos `Document` do LangChain:

```bash
npm install firecrawl @langchain/core
```

```typescript
import Firecrawl from "firecrawl";
import { Document } from "@langchain/core/documents";

const firecrawl = new Firecrawl(); // lê a variável FIRECRAWL_API_KEY

const crawl = await firecrawl.crawl("https://firecrawl.dev", { limit: 5 });

const docs = crawl.data.map(
  (page) => new Document({ pageContent: page.markdown ?? "", metadata: page.metadata ?? {} })
);
```
