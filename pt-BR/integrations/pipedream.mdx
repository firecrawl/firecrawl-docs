## Visão geral {#overview}

Use o app Firecrawl no Pipedream para fazer scraping de páginas, fazer rastreamento de sites, fazer buscas na web, mapear URLs e extrair dados estruturados como ações nos seus fluxos de trabalho.

## Início rápido {#quick-start}

1. Abra o [app do Firecrawl no Pipedream](https://pipedream.com/apps/firecrawl/)
2. Conecte sua chave de API do Firecrawl
3. Adicione ações do Firecrawl a um fluxo de trabalho novo ou existente

## O que você pode fazer {#what-you-can-do}

| Ação              | Caso de uso                                                                                                     |
| ----------------- | --------------------------------------------------------------------------------------------------------------- |
| **Raspar Página** | Obter o conteúdo da página quando um webhook ou agendamento for acionado                                        |
| **Rastrear URL**  | Iniciar uma tarefa de rastreamento de várias páginas (consulte o andamento com **Obter Dados do Rastreamento**) |
| **Pesquisar**     | Descobrir fontes antes das etapas seguintes                                                                     |
| **Mapear URL**    | Listar as URLs de um site, com filtro opcional por termo de busca                                               |
| **Extrair Dados** | Obter dados estruturados de uma ou mais URLs (verifique um job em andamento com **Obter Status da Extração**)   |
