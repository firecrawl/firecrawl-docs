</Note>

<div id="overview">
  ## Visão geral
</div>

Use o app Firecrawl no Pipedream para fazer scraping de páginas, fazer rastreamento de sites, fazer buscas na web, mapear URLs e extrair dados estruturados como ações nos seus fluxos de trabalho.

<div id="quick-start">
  ## Início rápido
</div>

1. Abra o [app do Firecrawl no Pipedream](https://pipedream.com/apps/firecrawl/)
2. Conecte sua chave de API do Firecrawl
3. Adicione ações do Firecrawl a um fluxo de trabalho novo ou existente

<div id="what-you-can-do">
  ## O que você pode fazer
</div>

| Recurso     | Caso de uso                                                                                            |
| ----------- | ------------------------------------------------------------------------------------------------------ |
| **Scrape**  | Obtenha o conteúdo da página quando um webhook ou agendamento for acionado                             |
| **Crawl**   | Inicie um job de rastreamento de várias páginas (consulte os dados do rastreamento com Get Crawl Data) |
| **Search**  | Descubra fontes antes das etapas subsequentes                                                          |
| **Map**     | Liste URLs de um site, opcionalmente filtradas por um termo de busca                                   |
| **Extract** | Obtenha dados estruturados de uma ou mais URLs                                                         |
