## Visão geral {#overview}

Os aplicativos Lovable podem usar o Firecrawl para fazer scraping e rastreamento de websites, convertendo-os em Markdown limpo ou dados estruturados no chat durante o desenvolvimento e em aplicativos publicados. O Firecrawl está disponível como aplicativo e conector de chat.

## Início rápido {#quick-start}

1. Abra **Connectors** no Lovable e selecione **Firecrawl**
2. Adicione uma conexão com **Managed by Lovable** (não é necessário ter uma conta do Firecrawl) ou **Use your own credentials** usando sua própria chave de API do Firecrawl
3. Vincule a conexão ao seu projeto e peça ao Lovable para fazer scraping ou rastreamento com o Firecrawl

## O que você pode criar {#what-you-can-build}

| Capacidade             | Caso de uso                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------------ |
| **Busca**              | Faça uma busca na web e obtenha o conteúdo das páginas encontradas                         |
| **Map**                | Liste todas as URLs de um site antes de rastreá-lo                                         |
| **Scraping**           | Converta URLs em markdown limpo ou JSON estruturado                                        |
| **Rastreamento**       | Colete páginas de um site, incluindo subpáginas                                            |
| **Dados estruturados** | Extraia campos como detalhes de produtos, tabelas e metadados com o formato JSON do scraping |
