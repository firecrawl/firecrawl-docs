O Firecrawl MCP dá aos clientes de IA acesso a dados da web em tempo real por meio do Model Context Protocol. Use o servidor hospedado para uma configuração mais rápida ou [execute o servidor de código aberto localmente](/pt-BR/mcp-server/local) quando precisar de um processo local ou de uma API do Firecrawl auto-hospedada.

Esta página é o guia de configuração oficial do Firecrawl MCP hospedado.

<div id="setup-firecrawl-mcp-server">
  ## Configurar o Firecrawl MCP Server
</div>

Para um cliente interativo, conecte-se via OAuth. O cliente abre o Firecrawl no navegador para que você possa fazer login, escolher uma equipe e aprovar o acesso sem copiar uma chave de API.

<Tabs>
  <Tab title="Codex">
    Adicione o servidor hospedado e conclua o login via OAuth:

    ```bash
    codex mcp add firecrawl \
      --url https://mcp.firecrawl.dev/v2/mcp-oauth
    codex mcp login firecrawl
    ```

    Inicie ou reinicie o aplicativo, a CLI ou a extensão de IDE do Codex. Digite `/mcp` para confirmar que `firecrawl` está conectado.
  </Tab>

  <Tab title="Claude Desktop">
    1. Abra **Configuração &gt; Connectors**.
    2. Selecione **Add custom connector**.
    3. Insira `https://mcp.firecrawl.dev/v2/mcp-oauth` como URL do servidor MCP remoto.
    4. Selecione **Connect**, faça login no Firecrawl e aprove o acesso.

    <Note>
      Servidores remotos devem ser adicionados em **Configuração &gt; Connectors**. O arquivo `claude_desktop_config.json` é destinado a servidores MCP locais.
    </Note>
  </Tab>

  <Tab title="Claude Code">
    Adicione o servidor hospedado:

    ```bash
    claude mcp add --transport http firecrawl \
      https://mcp.firecrawl.dev/v2/mcp-oauth
    ```

    Digite `/mcp` no Claude Code, escolha `firecrawl` e conclua o login no navegador.
  </Tab>

  <Tab title="Cursor">
    Adicione o servidor hospedado a `~/.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "firecrawl": {
          "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
        }
      }
    }
    ```

    Salve o arquivo, abra as configurações de MCP do Cursor e conclua o login no Firecrawl. Em seguida, o Cursor disponibilizará as ferramentas do Firecrawl para o Agent.
  </Tab>

  <Tab title="Outros clientes">
    Configure um cliente MCP remoto compatível com OAuth para usar:

    ```text
    https://mcp.firecrawl.dev/v2/mcp-oauth
    ```

    Se o cliente solicitar um Client ID ou Client Secret do OAuth, deixe ambos em branco. Clientes compatíveis usam documentos de metadados de Client ID ou Dynamic Client Registration.

    Se o cliente não conseguir concluir o OAuth remoto, use a configuração com chave de API abaixo. Se não puder enviar cabeçalhos de solicitação, [execute o Firecrawl MCP localmente](/pt-BR/mcp-server/local).
  </Tab>
</Tabs>

Conexões OAuth recebem tokens de curta duração vinculados a recursos, em vez da sua chave de API do Firecrawl. Você pode analisá-los e revogá-los nas [configurações de MCP](https://www.firecrawl.dev/app/settings?tab=mcp).

<div id="set-up-with-an-api-key">
  ## Configure com uma chave de API
</div>

Use uma chave de API em CI, servidores, scripts ou outro cliente que não possa concluir o OAuth no navegador. [Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys), mantenha-a em uma variável de ambiente ou gerenciador de segredos e conecte-se ao endpoint MCP hospedado completo.

<Tabs>
  <Tab title="Codex">
    ```bash
    export FIRECRAWL_API_KEY=fc-YOUR-API-KEY
    codex mcp add firecrawl \
      --url https://mcp.firecrawl.dev/v2/mcp \
      --bearer-token-env-var FIRECRAWL_API_KEY
    ```
  </Tab>

  <Tab title="Claude Code">
    O Claude Code expande a variável de ambiente ao se conectar:

    ```bash
    export FIRECRAWL_API_KEY=fc-YOUR-API-KEY
    claude mcp add --transport http firecrawl \
      https://mcp.firecrawl.dev/v2/mcp \
      --header 'Authorization: Bearer ${FIRECRAWL_API_KEY}'
    ```
  </Tab>

  <Tab title="Outros clientes">
    Configure o cliente para enviar a chave de API como um token de portador:

    ```text
    URL: https://mcp.firecrawl.dev/v2/mcp
    Authorization: Bearer <FIRECRAWL_API_KEY>
    ```

    A configuração do header varia conforme o cliente. Mantenha a chave no ambiente do cliente ou em um armazenamento protegido de segredos.
  </Tab>
</Tabs>

<Warning>
  Nunca coloque uma chave de API em um arquivo de configuração do projeto, cole-a em um chat ou compartilhe-a em uma captura de tela ou issue. Novas configurações devem usar OAuth ou um cabeçalho Authorization com base em variável de ambiente, nunca uma URL que contenha credenciais.
</Warning>

<div id="try-without-an-api-key">
  ## Teste sem uma chave de API
</div>

Para testar o Firecrawl sem criar uma conta, adicione o endpoint sem chave a qualquer cliente compatível com MCP remoto:

```text
https://mcp.firecrawl.dev/v2/mcp
```

O MCP sem chave tem limite de taxa por rede e disponibiliza exatamente **Busca, Scrape e Parse** enquanto você for elegível. Conecte-se via OAuth ou com uma chave de API quando precisar do conjunto completo de ferramentas ou de limites mais altos.

<Accordion title="O que acontece quando atinjo o limite sem chave?">
  Quando disponível, o erro do MCP informa o tempo atual de nova tentativa. Aguarde esse intervalo para continuar usando o MCP sem chave ou conecte-se imediatamente via OAuth ou com uma chave de API.
</Accordion>

<div id="verify-your-connection">
  ## Verifique sua conexão
</div>

Abra o status do MCP ou a lista de ferramentas do cliente e confirme que `firecrawl` está conectado. Uma conexão sem chave exibe `firecrawl_search`, `firecrawl_scrape` e `firecrawl_parse`; uma conexão autenticada pode disponibilizar o [conjunto completo de ferramentas](/pt-BR/mcp-server/tools), conforme o plano, a implantação e a política da equipe.

Tente uma solicitação somente leitura:

```text
Faça uma busca na web pelas notas da última release do Firecrawl e resuma as fontes.
```

Se nenhuma ferramenta do Firecrawl aparecer, reinicie ou recarregue o cliente após salvar a configuração do MCP. Em caso de erro de processo local, como `spawn npx ENOENT`, consulte [Executar o Firecrawl MCP localmente](/pt-BR/mcp-server/local#troubleshooting).

<div id="compatibility-and-legacy-setup">
  ## Compatibilidade e configuração legada
</div>

<AccordionGroup>
  <Accordion title="Suporte a URL legada com chave de API">
    <Warning>
      Este formato legado existe apenas para configurações e clientes existentes que não conseguem concluir o OAuth ou enviar um cabeçalho Authorization personalizado. Não é a configuração recomendada para novas integrações.
    </Warning>

    ```text
    https://mcp.firecrawl.dev/<FIRECRAWL_API_KEY>/v2/mcp
    ```

    A chave de API faz parte da URL; portanto, trate a URL completa como uma senha. Se ela for exposta, faça a rotação da chave. Esse fallback se aplica apenas a toda a superfície do `/v2/mcp`. Ele não funciona para o recurso de busca exclusivo do OAuth.
  </Accordion>

  <Accordion title="Conexões OAuth existentes">
    As conexões OAuth existentes do `/v2/mcp` continuam compatíveis durante a migração para o endpoint dedicado da conta. Novas conexões interativas de conta devem usar `/v2/mcp-oauth`; novos tokens para esse recurso de conta não são aceitos pelo `/v2/mcp`.
  </Accordion>
</AccordionGroup>
