A URL do servidor hospedado sem chave e com chave de API é:

```text
https://mcp.firecrawl.dev/v2/mcp
```

<Note>
  Esta é uma URL de servidor para seu cliente MCP, não uma página para abrir diretamente no navegador. O OAuth usa uma URL de servidor diferente, e seu cliente inicia o fluxo de login no navegador.
</Note>

Se você optar por usar uma chave de API, nunca a inclua em uma URL do MCP, em uma conversa com um agente ou em um arquivo de projeto submetido ao controle de versão. Configure-a por meio de uma variável de ambiente ou do armazenamento de segredos do seu cliente.

<div id="fix-a-broken-connection">
  ## Corrija uma conexão com falha
</div>

Use esta seção quando um erro do Firecrawl mencionar `KEYLESS_QUOTA_EXHAUSTED`, `KEYLESS_TOOL_NOT_AVAILABLE`, `KEYLESS_ACCESS_NOT_AVAILABLE`, `KEYLESS_ELIGIBILITY_UNAVAILABLE`, `CREDENTIAL_INVALID`, `OAUTH_CONNECTION_INVALID` ou uma credencial &quot;inválida ou revogada&quot;.

* **Limite sem chave atingido:** aguarde o `retry_after_seconds` do erro (quando presente) ou peça ao operador humano para se conectar via OAuth ou configurar uma chave de API. busca, scraping e Parse permanecem disponíveis após a redefinição do limite.
* **Acesso sem chave indisponível:** para `KEYLESS_ELIGIBILITY_UNAVAILABLE`, tente novamente após o intervalo indicado. Se o problema persistir ou o erro for `KEYLESS_ACCESS_NOT_AVAILABLE`, peça ao operador humano para se conectar via OAuth ou configurar uma chave de API.
* **Ferramenta não disponível sem chave (`KEYLESS_TOOL_NOT_AVAILABLE`):** a ferramenta existe, mas não está disponível no modo sem chave. Conecte-se via OAuth ou configure uma chave de API para usá-la; busca, scraping e Parse continuam funcionando sem chave.
* **chave de API inválida ou revogada:** o operador humano ou do sistema deve substituir a chave na configuração existente do servidor, fora da conversa com o agente.
* **Conexão OAuth inválida em `/v2/mcp`:** adicione uma chave de API a esse servidor existente ou altere sua URL para `https://mcp.firecrawl.dev/v2/mcp-oauth` e faça login pelo cliente. Não abra essa URL diretamente em um navegador.
* **Conexão OAuth inválida em `/v2/mcp-oauth`:** faça login novamente pelo fluxo de conexão de conta do cliente.

Após qualquer alteração na credencial ou URL do servidor, mantenha uma única entrada de servidor `firecrawl`, inicie uma nova sessão do cliente e tente novamente. Consulte [Conexão OAuth](/pt-BR/mcp-server/oauth#switch-an-existing-keyless-connection) ou [configuração de chave de API](/pt-BR/mcp-server/keyless-api-key#add-an-api-key) para obter as etapas exatas.
