<div id="add-an-api-key">
  ## Adicione uma chave de API
</div>

[Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys) e envie-a como um token bearer:

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

Configure a chave usando uma variável de ambiente ou o armazenamento de segredos do cliente, nunca na URL do MCP.

<Note>
  Esta é uma URL de servidor para seu cliente MCP, não uma página para abrir diretamente no navegador. As conexões de login usam `https://mcp.firecrawl.dev/v2/mcp-oauth`, e seu cliente inicia o fluxo no navegador.
</Note>
