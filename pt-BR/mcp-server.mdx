Escolha a configuração de acordo com a forma como a conexão será executada. Você não precisa decidir se é uma pessoa ou um agente.

<Card title="Testar agora" icon="bolt" href="/pt-BR/mcp-server/agent-mcp">
  Use Search, Scrape e Parse sem conta nem chave. Os limites são compartilhados por endereço IP público.
</Card>

<Card title="Conectar com OAuth" icon="right-to-bracket" href="/pt-BR/mcp-server/human-mcp">
  Entre por um cliente interativo, escolha uma equipe e aprove a conexão.
</Card>

<Card title="Usar uma chave de API" icon="key" href="/pt-BR/mcp-server/agent-mcp">
  Configure acesso estável para agentes, CI e serviços backend sem colocar o segredo no chat ou no código-fonte.
</Card>
