O Firecrawl MCP permite que clientes de IA acessem dados da web em tempo real por meio do Model Context Protocol. Ele está disponível como serviço hospedado ou servidor local de código aberto.

<div id="start-here">
  ## Comece por aqui
</div>

Escolha o modo de conexão adequado ao ambiente em que o Firecrawl será executado. As rotas hospedadas são URLs sem credenciais: as credenciais devem ser usadas no fluxo OAuth ou em um cabeçalho Authorization, nunca na própria URL.

<CardGroup cols={3}>
  <Card title="Conecte uma conta" icon="user" href="/pt-BR/mcp-server/connect">
    Use OAuth baseado em navegador para um cliente MCP interativo e acesso completo às ferramentas do Firecrawl.
  </Card>

  <Card title="Execute sem supervisão" icon="server" href="/pt-BR/mcp-server/connect#run-unattended">
    Use `/v2/mcp` com uma chave de API do Firecrawl em um cabeçalho Authorization para CI, servidores e scripts.
  </Card>

  <Card title="Experimente o MCP sem chave" icon="sparkles" href="/pt-BR/mcp-server/connect#try-keyless">
    Comece sem uma chave de API, com acesso limitado por taxa a busca, scraping e parse.
  </Card>
</CardGroup>
