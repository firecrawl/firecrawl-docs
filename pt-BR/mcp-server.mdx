<div id="sign-in">
  ## fazer login
</div>

Aponte seu cliente para a OAuth servidor URL. O cliente abrirá uma janela do navegador para você fazer login no Firecrawl e aprovar uma equipe:

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

Não é necessária nenhuma API key nem headers. Revise e revogue conexões nas [MCP settings](https://www.firecrawl.dev/app/settings?tab=mcp).

<Note>
  Esta é uma URL de servidor para o seu cliente MCP, não uma página para abrir diretamente no navegador. Conexões com API key usam `https://mcp.firecrawl.dev/v2/mcp` com um bearer token; consulte [Adicionar uma API key](/pt-BR/mcp-server/keyless#add-an-api-key).
</Note>
