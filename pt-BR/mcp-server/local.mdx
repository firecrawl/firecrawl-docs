<div id="prerequisites">
  ## Pré-requisitos
</div>

* Node.js 22 ou posterior
* npm e `npx`, incluídos no Node.js
* Uma chave de API do Firecrawl para a API em nuvem ou uma URL de API do Firecrawl auto-hospedada

Confirme a versão do Node.js instalada:

```bash
node --version
```

<div id="run-over-stdio">
  ## Execute via stdio
</div>

```bash
env FIRECRAWL_API_KEY=fc-YOUR_API_KEY npx -y firecrawl-mcp@3.23.0
```

Este é o transporte padrão para clientes que iniciam o servidor MCP como um processo local.

<div id="run-with-streamable-http">
  ## Executar com Streamable HTTP
</div>

Use o transporte HTTP para clientes como o n8n que se conectam a um servidor MCP já em execução:

```bash
env HTTP_STREAMABLE_SERVER=true \
  FIRECRAWL_API_KEY=fc-YOUR_API_KEY \
  npx -y firecrawl-mcp@3.23.0
```

Conecte o cliente a:

```text
http://localhost:3000/mcp
```

Confirme se o servidor está pronto:

```bash
curl http://localhost:3000/health
```

A verificação de integridade retorna `ok`. A rota local é `/mcp`; `/v2/mcp` é a rota do Firecrawl hospedada.

<div id="install-globally">
  ## Instale globalmente
</div>

```bash
npm install -g firecrawl-mcp@3.23.0
```

Em seguida, execute:

```bash
env FIRECRAWL_API_KEY=fc-YOUR_API_KEY firecrawl-mcp
```

  ## Configuração
</div>

<div id="environment-variables">
  ### Variáveis de ambiente
</div>

<div id="cloud-and-self-hosted-api">
  #### API em nuvem e auto-hospedada
</div>

* `FIRECRAWL_API_KEY`: Sua chave de API do Firecrawl
  * Obrigatória ao usar a API em nuvem (padrão)
  * Opcional ao usar uma instância auto-hospedada com `FIRECRAWL_API_URL`
* `FIRECRAWL_API_URL` (Opcional): Endpoint de API personalizado para instâncias auto-hospedadas
  * Exemplo: `https://firecrawl.your-domain.com`
  * Se não for fornecida, a API em nuvem será usada (requer uma chave de API)

<div id="configuration-examples">
  ### Exemplos de configuração
</div>

Para usar a API na nuvem:

```bash
export FIRECRAWL_API_KEY=your-api-key
```

Para uma instância auto-hospedada:

```bash
export FIRECRAWL_API_URL=https://firecrawl.your-domain.com
export FIRECRAWL_API_KEY=your-api-key  # Se sua instância exigir autenticação
```

<div id="custom-configuration-with-claude-desktop">
  ### Configuração personalizada com o Claude Desktop
</div>

Adicione o seguinte ao seu `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "mcp-server-firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "YOUR_API_KEY_HERE"
      }
    }
  }
}
```

<div id="hosted-mcp-vs-local-mcp">
  ### MCP hospedado vs. MCP local
</div>

O servidor MCP hospedado é otimizado para uso remoto seguro. Algumas opções disponíveis ao executar o servidor MCP localmente são restritas ou indisponíveis remotamente:

* O modo hospedado sem chave expõe apenas Search, Scrape e Parse e tem limite de taxa por IP.
* A leitura de arquivos locais está disponível apenas quando você executa o servidor MCP localmente.
* Webhooks e caminhos de arquivos locais devem ser configurados em um servidor MCP local ou auto-hospedado quando o agente precisar acessar recursos locais.

<Note>
  A análise direta de arquivos locais com `firecrawl_parse` exige que `FIRECRAWL_API_URL` aponte para uma API do Firecrawl auto-hospedada. Um servidor MCP local configurado apenas com uma API em nuvem não pode enviar um arquivo local por essa ferramenta.
</Note>

<div id="rate-limiting">
  ### Limites de taxa
</div>

Os limites de taxa são aplicados pelo Firecrawl. Use uma chave de API para obter limites mais altos e acesso ao conjunto completo de ferramentas.
