  ## Experimente o acesso sem chave
</div>

<McpClientSelector variant="agent" showSeeAll={false} />

O MCP sem chave tem limites de taxa e disponibiliza Busca, scraping e Parse. Adicione uma chave de API para desbloquear o conjunto completo de ferramentas ou limites mais altos.

<div id="add-an-api-key">
  ## Adicione uma chave de API
</div>

[Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys) e envie-a como um token de autenticação para o mesmo endpoint:

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

<Warning>
A pessoa ou o sistema responsável deve configurar a chave fora da conversa do agente. Nunca cole a chave no chat, na URL do MCP ou em um arquivo do projeto.
</Warning>

<div id="verify-your-connection">
  ## Verifique sua conexão
</div>

Abra o status do MCP ou a lista de ferramentas do seu cliente e confirme que o `firecrawl` está conectado. Uma conexão sem chave exibe `firecrawl_search`, `firecrawl_scrape` e `firecrawl_parse`; uma conexão com chave de API pode disponibilizar o [conjunto completo de ferramentas](/pt-BR/mcp-server/tools), conforme o plano, a implantação e as políticas da equipe.

<div id="try">
  ## Experimente
</div>

```text
Faça uma busca na web pelas notas da última release do Firecrawl e resuma as fontes.
```

Se nenhuma ferramenta do Firecrawl aparecer, reinicie ou recarregue o cliente depois de salvar a configuração do MCP.
