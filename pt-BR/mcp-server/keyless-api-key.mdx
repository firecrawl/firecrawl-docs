<Visibility for="agents">
  URL do servidor sem chave (Streamable HTTP, sem credencial): `https://mcp.firecrawl.dev/v2/mcp`

  * Codex: `codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp`
  * Claude Code: `claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp`
  * Cursor ou qualquer cliente configurado com JSON: `{"mcpServers": {"firecrawl": {"url": "https://mcp.firecrawl.dev/v2/mcp"}}}`
  * OpenCode (`opencode.json`): `{"mcp": {"firecrawl": {"type": "remote", "url": "https://mcp.firecrawl.dev/v2/mcp", "enabled": true}}}`

  O ChatGPT e o Claude.ai usam login na conta: consulte [OAuth](/pt-BR/mcp-server/oauth.md).
</Visibility>

Este é o modo sem chave do Firecrawl: conecte-se sem conta nem chave de API. Use-o para testes rápidos e use uma chave de API quando a conexão precisar funcionar de forma confiável sem a presença de uma pessoa. Se quiser fazer login pelo navegador — inclusive no ChatGPT ou Claude.ai — use o [OAuth](/pt-BR/mcp-server/oauth).

O MCP sem chave expõe apenas Search, Scrape e Parse. Ele tem limites diários de solicitações e créditos, compartilhados entre usuários com o mesmo endereço IP público. Outra pessoa ou processo na mesma rede pode consumir parte dessa cota.

Use o acesso sem chave para avaliar a conexão, não como identidade ou credencial de produção. Para ver a cota atual, consulte [Limites de taxa do modo sem chave](/pt-BR/rate-limits#keyless-no-api-key).

<div id="add-an-api-key">
  ## Adicione uma chave de API
</div>

Use uma chave de API para CI, serviços de backend e outras conexões não assistidas. [Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys) e disponibilize-a ao cliente MCP como `FIRECRAWL_API_KEY`.

<Warning>
  O operador humano ou do sistema deve configurar a chave fora da conversa com o agente. Nunca cole a chave no chat do agente, inclua-a na URL do MCP nem faça commit do valor dela em um arquivo do projeto. Uma referência a uma variável de ambiente em um arquivo de configuração é segura; o valor secreto não.
</Warning>

<div id="codex">
  ### Codex
</div>

Exporte a chave no ambiente em que o Codex é iniciado:

```bash
export FIRECRAWL_API_KEY=fc-YOUR-API-KEY
```

Adicione o seguinte a `~/.codex/config.toml`:

```toml
[mcp_servers.firecrawl]
url = "https://mcp.firecrawl.dev/v2/mcp"
bearer_token_env_var = "FIRECRAWL_API_KEY"
```

<div id="claude-code">
  ### Claude Code
</div>

Exporte a chave antes de iniciar o Claude Code:

```bash
export FIRECRAWL_API_KEY=fc-YOUR-API-KEY
```

Adicione uma referência a uma variável de ambiente em `.mcp.json`. Não substitua `${FIRECRAWL_API_KEY}` pela chave em si.

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer ${FIRECRAWL_API_KEY}"
      }
    }
  }
}
```

<div id="other-clients">
  ### Outros clientes
</div>

Aponte o cliente para:

```text
https://mcp.firecrawl.dev/v2/mcp
```

Configure este cabeçalho no ambiente ou no armazenamento de segredos do cliente:

```text
Authorization: Bearer <FIRECRAWL_API_KEY>
```

Inicie uma nova sessão no cliente após salvar a configuração. Abra o status do MCP ou a lista de ferramentas e confirme se o `firecrawl` está conectado.

<div id="verify-the-connection">
  ## Verifique a conexão
</div>

Tente:

```text
Faça uma busca na web pelas notas da última release do Firecrawl e resuma as fontes.
```

Uma conexão sem chave exibe `firecrawl_search`, `firecrawl_scrape` e `firecrawl_parse`. Uma conexão com chave de API pode disponibilizar o [conjunto completo de ferramentas](/pt-BR/mcp-server/tools), dependendo do plano, da implantação e da política da equipe.

Se as ferramentas não corresponderem ao modo configurado, remova entradas duplicadas do Firecrawl, reinicie o cliente e verifique o URL do servidor ativo e a origem da credencial.

<div id="run-in-ci-or-a-backend">
  ## Execute em CI ou em um backend
</div>

Armazene `FIRECRAWL_API_KEY` no gerenciador de segredos da plataforma e injete-a nas variáveis de ambiente do processo. Mantenha apenas a referência à variável de ambiente na configuração do MCP:

```json
{
  "url": "https://mcp.firecrawl.dev/v2/mcp",
  "headers": {
    "Authorization": "Bearer ${FIRECRAWL_API_KEY}"
  }
}
```

Não inclua o valor no controle de versão, nos logs de build, em prompts ou em configurações geradas. Inicie um novo processo após alterar o segredo, verifique a lista de ferramentas do `firecrawl` e faça a rotação da chave caso ela possa ter sido exposta.

<div id="legacy-api-key-url-support">
  ## Suporte legado a URL com chave de API
</div>

<Warning>
  O formato de chave na URL existe apenas para configurações e clientes existentes que não podem enviar um cabeçalho de autorização. Não o utilize em uma nova conexão.
</Warning>

As configurações existentes podem usar `https://mcp.firecrawl.dev/<FIRECRAWL_API_KEY>/v2/mcp`. A URL completa é uma credencial: nunca a cole em chats, capturas de tela, issues, logs ou configurações compartilhadas. Sempre que possível, migre para um cabeçalho `Authorization: Bearer` com base em variável de ambiente e faça a rotação da chave caso a URL tenha sido exposta.

Essa rota de compatibilidade se aplica apenas a toda a superfície de `/v2/mcp`. Ela não funciona para o recurso de busca exclusivo do OAuth.
