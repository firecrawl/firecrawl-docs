O Firecrawl MCP disponibiliza ferramentas para encontrar, extrair, interagir com e monitorar conteúdo da web. Ao se conectar, seu cliente MCP recebe o esquema de entrada exato de cada ferramenta disponível.

<div id="tool-availability">
  ## Disponibilidade de ferramentas
</div>

| Modo de conexão                               | Ferramentas disponíveis                                                            |
| --------------------------------------------- | ---------------------------------------------------------------------------------- |
| OAuth hospedado                               | Conjunto completo de ferramentas, sujeito ao plano e às políticas da equipe        |
| Chave de API hospedada                        | Conjunto completo de ferramentas, sujeito ao plano e às políticas da equipe        |
| Hospedado sem chave                           | `firecrawl_search`, `firecrawl_scrape` e `firecrawl_parse`                         |
| Local com a API em nuvem do Firecrawl         | Ferramentas baseadas em API; o Parse direto de arquivos locais não está disponível |
| Local com uma API do Firecrawl auto-hospedada | Ferramentas compatíveis com os serviços habilitados nessa implantação              |

Comece pelos [Primeiros passos](/pt-BR/mcp-server) e escolha [Para agentes](/pt-BR/mcp-server/keyless) ou [Para humanos](/pt-BR/mcp-server/oauth). Algumas ferramentas opcionais podem ser desativadas pelo ambiente ou pelas políticas da equipe.

<div id="choose-a-tool">
  ## Escolha uma ferramenta
</div>

| Tarefa                                  | Ferramenta                                         | Use quando                                                                                                                                  |
| --------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Ler uma página                          | `firecrawl_scrape`                                 | Você conhece a URL e precisa do conteúdo da página ou de campos estruturados.                                                               |
| Extrair dados estruturados              | `firecrawl_scrape` com formato JSON                | Você tem a URL e quer dados que correspondam a um prompt ou schema JSON.                                                                    |
| Descobrir URLs de um site               | `firecrawl_map`                                    | Você precisa encontrar páginas antes de decidir o que extrair.                                                                              |
| Fazer uma busca na web                  | `firecrawl_search`                                 | Você tem uma consulta, não uma URL conhecida.                                                                                               |
| Analisar um arquivo                     | `firecrawl_parse`                                  | Você precisa de conteúdo de um PDF, documento, planilha ou arquivo HTML.                                                                    |
| Extrair várias páginas                  | `firecrawl_crawl` e `firecrawl_check_crawl_status` | Você precisa percorrer um site ou uma seção. A ferramenta de rastreamento consulta o job até ele atingir um estado final antes de retornar. |
| Realizar pesquisa autônoma              | `firecrawl_agent` e `firecrawl_agent_status`       | A tarefa abrange várias fontes, e as páginas exatas são desconhecidas.                                                                      |
| Interagir com uma página ativa          | `firecrawl_interact` e `firecrawl_interact_stop`   | Você precisa clicar, preencher formulários, navegar ou extrair dados de páginas dinâmicas.                                                  |
| Pesquisar papers e repositórios         | `firecrawl_research_*`                             | Você precisa descobrir ou ler papers, encontrar trabalhos relacionados ou buscar repositórios públicos.                                     |
| Responder a uma pergunta de programação | `firecrawl_developer_search`                       | Você precisa de respostas de fontes primárias, como issues, pull requests mesclados, READMEs e documentação selecionada.                    |
| Monitorar mudanças                      | `firecrawl_monitor_*`                              | Você precisa de verificações recorrentes, diffs e notificações por webhook ou email.                                                        |
| Enviar feedback sobre o produto         | `firecrawl_search_feedback` e `firecrawl_feedback` | Você quer avaliar resultados de busca ou informar a qualidade de um endpoint.                                                               |

<Note>
  A antiga ferramenta Extract do MCP está descontinuada e não faz parte do conjunto de ferramentas atual. Use Scrape com formato JSON para uma página conhecida ou Agent quando o Firecrawl precisar descobrir as fontes. Consulte [Escolhendo o Extrator de Dados](/pt-BR/developer-guides/usage-guides/choosing-the-data-extractor) para ver a comparação completa.
</Note>

<div id="important-behavior">
  ## Comportamento importante
</div>

<AccordionGroup>
  <Accordion title="Analisar um arquivo local">
    Um servidor MCP local conectado a uma API do Firecrawl auto-hospedada pode ler `filePath` diretamente. O servidor hospedado não pode ler arquivos da sua máquina, por isso usa uma transferência em duas chamadas:

    1. Chame `firecrawl_parse` com `filePath` para receber um comando de upload e `uploadRef`.
    2. Execute o comando de upload na máquina que pode ler o arquivo.
    3. Chame `firecrawl_parse` novamente com o `uploadRef` retornado.

    O comando de upload usa um destino assinado de curta duração e não contém sua chave de API do Firecrawl. Use `firecrawl_scrape` para um URL de documento público.
  </Accordion>

  <Accordion title="Verificar um rastreamento em execução">
    `firecrawl_crawl` normalmente inicia um rastreamento e o consulta até atingir um estado terminal antes de retornar. Se essa espera atingir o tempo limite, retome o job com `firecrawl_check_crawl_status` e o ID do rastreamento. Use a mesma ferramenta de status para um rastreamento criado fora da chamada MCP atual.

    `firecrawl_agent` é assíncrono: retorna um ID de job, e `firecrawl_agent_status` verifica esse job até que seja concluído ou falhe.
  </Accordion>

  <Accordion title="Encerrar sessões de interação">
    Comece com uma `url` ou reutilize o `scrapeId` de uma chamada de Scrape anterior. Quando o fluxo de trabalho for concluído, chame `firecrawl_interact_stop` com o `scrapeId` para liberar a sessão.
  </Accordion>

  <Accordion title="Gerenciar monitores com segurança">
    A família `firecrawl_monitor_*` cria, lista, atualiza, executa e inspeciona monitores recorrentes. `firecrawl_monitor_delete` remove permanentemente um monitor e só deve ser chamado quando o usuário expressamente quiser excluí-lo.
  </Accordion>

  <Accordion title="Habilitar ferramentas opcionais de feedback">
    Defina `FIRECRAWL_NO_SEARCH_FEEDBACK=1` para impedir o registro de `firecrawl_search_feedback`. Defina `FIRECRAWL_NO_ENDPOINT_FEEDBACK=1` para impedir o registro de `firecrawl_feedback`.
  </Accordion>
</AccordionGroup>

<div id="troubleshooting">
  ## Solução de problemas
</div>

* **Uma ferramenta está ausente:** confirme o modo de conexão em [Primeiros passos](/pt-BR/mcp-server), reconecte ou reinicie o cliente e verifique se a política da equipe desativa ferramentas opcionais.
* **O cliente retorna `401`:** primeiro, verifique a URL do servidor configurada.
  * Se a URL configurada for `/v2/mcp-oauth`, faça login novamente pelo cliente.
  * Se for `/v2/mcp`, substitua a chave de API nesse servidor ou atualize a URL do servidor existente para `/v2/mcp-oauth` e conclua o login.
  * Inicie uma nova sessão do cliente após qualquer uma das alterações.
* **O cliente foi limitado por taxa:** consulte os [limites de taxa](/pt-BR/rate-limits) atuais, aguarde o intervalo para nova tentativa ou mude do acesso sem chave para o acesso autenticado.
