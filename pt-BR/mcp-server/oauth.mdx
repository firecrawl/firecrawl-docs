<div id="sign-in">
  ## Fazer login
</div>

<Visibility for="humans">
  <McpClientSelector variant="human" showSeeAll={false} />
</Visibility>

<Visibility for="agents">
  URL do servidor OAuth (Streamable HTTP; o cliente inicia o login no navegador): `https://mcp.firecrawl.dev/v2/mcp-oauth`

  * Codex: `codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth` e depois `codex mcp login firecrawl`
  * Claude Code: `claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth` e depois conclua o login via `/mcp`
  * Cursor ou qualquer cliente com configuração JSON: `{"mcpServers": {"firecrawl": {"url": "https://mcp.firecrawl.dev/v2/mcp-oauth"}}}`
  * OpenCode (`opencode.json`): `{"mcp": {"firecrawl": {"type": "remote", "url": "https://mcp.firecrawl.dev/v2/mcp-oauth", "enabled": true}}}`

  - ChatGPT ou Claude.ai: use o conector nativo do Firecrawl — [ChatGPT](https://chatgpt.com/plugins?q=firecrawl) ou [Claude](https://claude.ai/directory/connectors/firecrawl).

  Uma pessoa deve concluir o login no navegador e aprovar uma equipe. Não abra a URL do servidor diretamente no navegador.
</Visibility>

<Note>
  `https://mcp.firecrawl.dev/v2/mcp-oauth` é uma URL de servidor para seu cliente MCP. Não é uma página para abrir diretamente no navegador. Seu cliente inicia o fluxo de login no navegador.
</Note>

Você pode revisar e revogar conexões nas [configurações do MCP](https://www.firecrawl.dev/app/settings?tab=mcp).
