<Visibility for="agents">
  URL do servidor sem chave (Streamable HTTP, sem credenciais): `https://mcp.firecrawl.dev/v2/mcp`

  * Codex: `codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp`
  * Claude Code: `claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp`
  * Cursor ou qualquer cliente configurado com JSON: `{"mcpServers": {"firecrawl": {"url": "https://mcp.firecrawl.dev/v2/mcp"}}}`
  * OpenCode (`opencode.json`): `{"mcp": {"firecrawl": {"type": "remote", "url": "https://mcp.firecrawl.dev/v2/mcp", "enabled": true}}}`

  Em vez disso, o ChatGPT e o Claude usam o conector nativo do Firecrawl: consulte [Para humanos](/pt-BR/mcp-server/oauth.md#chatgpt-and-claude).
</Visibility>

O MCP sem chave tem limite de taxa e disponibiliza Busca, scraping e análise. Adicione uma chave de API para desbloquear o conjunto completo de ferramentas ou limites mais altos.

<div id="add-an-api-key">
  ## Adicione uma chave de API
</div>

[Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys) e envie-a como token de portador ao mesmo endpoint:

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

<div id="verify-your-connection">
  ## Verifique sua conexão
</div>

Abra o status do MCP ou a lista de ferramentas do seu cliente e confirme se o `firecrawl` está conectado. Uma conexão sem chave exibe `firecrawl_search`, `firecrawl_scrape` e `firecrawl_parse`; uma conexão com chave de API pode disponibilizar o [conjunto completo de ferramentas](/pt-BR/mcp-server/tools), dependendo do plano, da implantação e da política da equipe.

<div id="try">
  ## Experimente
</div>

```text
Faça uma busca na web pelas notas da última release do Firecrawl e resuma as fontes.
```

Se nenhuma ferramenta do Firecrawl for exibida, reinicie ou recarregue o cliente após salvar a configuração do MCP.
