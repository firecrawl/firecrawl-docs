<div id="development">
  ## Desenvolvimento
</div>

```bash
# Instalar dependências
npm install

# compilar
npm run build

# Executar testes
npm test
```

<div id="contributing">
  ### Como contribuir
</div>

1. Faça um fork do repositório
2. Crie uma branch para sua funcionalidade
3. Execute os testes: `npm test`
4. Envie um pull request
