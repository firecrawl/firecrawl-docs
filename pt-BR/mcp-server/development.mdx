<div id="prerequisites">
  ## Pré-requisitos
</div>

* [Git](https://git-scm.com/downloads)
* Node.js 22 ou versão mais recente
* npm, incluído no Node.js

Confirme a versão do Node.js antes de instalar as dependências:

```bash
node --version
```

<div id="clone-and-test-the-server">
  ## Clone e teste o servidor
</div>

```bash
git clone https://github.com/firecrawl/firecrawl-mcp-server.git
cd firecrawl-mcp-server
npm install
npm run build
npm test
```

Execute o linter antes de enviar uma alteração:

```bash
npm run lint
```

<div id="contributing">
  ## Como contribuir
</div>

1. Faça um fork do [repositório do servidor MCP do Firecrawl](https://github.com/firecrawl/firecrawl-mcp-server).
2. Clone seu fork e crie uma branch para a funcionalidade.
3. Execute `npm run lint` e `npm test`.
4. Envie um pull request com a descrição do comportamento e evidências de verificação.
