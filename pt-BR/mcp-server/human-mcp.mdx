Você pode revisar e revogar conexões nas [configurações de MCP](https://www.firecrawl.dev/app/settings?tab=mcp).

Precisa do ChatGPT ou do Claude.ai? Consulte os guias do [ChatGPT](/pt-BR/developer-guides/mcp-setup-guides/chatgpt) e do [Claude.ai](/pt-BR/developer-guides/mcp-setup-guides/claude-ai).

<div id="add-an-api-key">
  ## Adicione uma chave de API
</div>

[Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys) e envie-a como um token bearer:

```text
URL: https://mcp.firecrawl.dev/v2/mcp
Authorization: Bearer <FIRECRAWL_API_KEY>
```

<div id="try">
  ## Experimente
</div>

```text
Faça uma busca na web pelas notas da última release do Firecrawl e resuma as fontes.
```

Se nenhuma ferramenta do Firecrawl for exibida, reinicie ou recarregue o cliente após salvar a configuração do MCP.
