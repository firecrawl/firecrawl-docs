Conecte o Firecrawl ao [Google Antigravity](https://antigravity.google/) por meio do servidor MCP hospedado e, em seguida, faça login com sua conta do Firecrawl.

## Configuração rápida {#quick-setup}

1. No Antigravity, clique em **…** na parte superior do painel lateral do agente e selecione **MCP Servers**.
2. Clique em **Manage MCP Servers** e, em seguida, em **View raw config** para abrir o `mcp_config.json` (global em `~/.gemini/config/mcp_config.json` ou `.agents/mcp_config.json` no seu espaço de trabalho).
3. Adicione o servidor do Firecrawl e salve:

```json
{
  "mcpServers": {
    "firecrawl": {
      "serverUrl": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

4. Abra as configurações do Agent (`Cmd/Ctrl + ,`), vá até **Customizations** e clique em **Authenticate** ao lado de `firecrawl`.
5. Faça login no Firecrawl pelo navegador e aprove uma equipe; depois, cole o código de autorização no Antigravity e clique em **Submit**.
6. Confirme que as ferramentas do Firecrawl, como `firecrawl_search` e `firecrawl_scrape`, estão disponíveis.

O Antigravity exige a chave `serverUrl` para servidores remotos. Entradas que usam `url` ou `httpUrl` não são registradas. O Antigravity CLI lê o mesmo arquivo; digite `/mcp` no CLI para verificar o status do servidor.

<Accordion title="Prefere usar uma API key?">
  Para uso não assistido, [crie uma Chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys) e envie-a como cabeçalho em vez de fazer login. Veja [Adicionar uma API key](/pt-BR/mcp-server/keyless#add-an-api-key) para mais detalhes.

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "serverUrl": "https://mcp.firecrawl.dev/v2/mcp",
        "headers": {
          "Authorization": "Bearer fc-YOUR-API-KEY"
        }
      }
    }
  }
  ```
</Accordion>

Veja o [guia de conexão OAuth](/pt-BR/mcp-server/oauth) para mais detalhes.

## Solução de problemas {#troubleshooting}

* **O servidor aparece com falha:** confirme que a entrada usa `serverUrl` com o valor exato `https://mcp.firecrawl.dev/v2/mcp-oauth` e, em seguida, recarregue o servidor em **Manage MCP Servers** ou no gerenciador `/mcp` da CLI.
* **O login é solicitado ou expira:** clique novamente em **Authenticate** ao lado de `firecrawl` em **Customizations**.
* **Já existe outra conexão do Firecrawl:** atualize o servidor existente para a URL OAuth e faça login, para que apenas um servidor do Firecrawl fique ativo.
