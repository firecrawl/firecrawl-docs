Adicione as ferramentas de busca, scraping e Parse sem chave do Firecrawl ao [Google Antigravity](https://antigravity.google/) por meio do servidor MCP hospedado.

<div id="quick-setup">
  ## Configuração rápida
</div>

Abra as configurações do Antigravity (`Cmd/Ctrl + ,`), pesquise por **MCP Servers** e adicione:

```json
{
  "mcpServers": {
    "firecrawl": {
      "serverUrl": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Recarregue a janela e confirme que `firecrawl_search`, `firecrawl_scrape` e `firecrawl_parse` estão disponíveis.

O acesso sem chave tem limites compartilhados por usuários no mesmo IP público. Use o [OAuth](/pt-BR/mcp-server/oauth) para acesso interativo à conta ou o [guia de chave de API](/pt-BR/mcp-server/keyless-api-key#add-an-api-key) para uso não assistido.

<div id="try-it">
  ## Experimente
</div>

```text
Use Firecrawl to search for the latest Vercel AI SDK release notes and summarize the sources.
```

```text
Scrape https://docs.firecrawl.dev/ai-onboarding and list the linked guides.
```

<div id="troubleshooting">
  ## Solução de problemas
</div>

* **O servidor aparece como falho:** confirme a URL hospedada e inspecione o painel de resultados do MCP.
* **O rastreamento ou outra ferramenta está ausente:** o modo sem chave oferece exatamente Busca, Scraping e Parse. Conecte-se com OAuth ou uma chave de API para acessar um conjunto de ferramentas mais amplo.
