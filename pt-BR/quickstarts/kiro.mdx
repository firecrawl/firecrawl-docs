Conecte o Firecrawl ao Kiro por meio do servidor MCP hospedado. O Kiro cuida do login pelo navegador para você, então não é preciso registrar nada manualmente. O Kiro IDE e o Kiro CLI usam o mesmo arquivo de configuração.

<Note>
  O Kiro CLI substitui o Amazon Q Developer CLI. Se você já usava o `q`, esta página também se aplica a você.
</Note>

## Configuração rápida {#quick-setup}

1. Abra o arquivo de configuração do usuário `~/.kiro/settings/mcp.json`. Na IDE, execute **Kiro: Open user MCP config (JSON)** na paleta de comandos. Para um único projeto, use `.kiro/settings/mcp.json` no espaço de trabalho.
2. Adicione o Firecrawl e salve o arquivo:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

3. Ao salvar, o Kiro se reconecta e abre a página de autorização do Firecrawl no seu navegador. Faça login e aprove o acesso.
4. Abra a aba de servidores MCP no painel do Kiro ou execute `kiro-cli mcp status --name firecrawl` e confirme se as ferramentas do Firecrawl estão disponíveis.

<Accordion title="Prefere usar uma API key?">
  No Kiro, servidores remotos aceitam cabeçalhos. Exporte `FIRECRAWL_API_KEY` no seu shell e use:

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp",
        "headers": {
          "Authorization": "Bearer ${FIRECRAWL_API_KEY}"
        }
      }
    }
  }
  ```

  O Kiro só expande as variáveis de ambiente que você aprovou. Quando ele exibir o aviso de segurança para `FIRECRAWL_API_KEY`, aprove-a ou adicione-a em **Mcp Approved Env Vars** nas configurações.
</Accordion>

<Accordion title="Prefere usar a CLI?">
  ```bash
  kiro-cli mcp add --name firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth --scope global
  ```
</Accordion>

Veja o [guia de conexão OAuth](/pt-BR/mcp-server/oauth) para mais detalhes. Para uso não assistido, [configure uma API key](/pt-BR/mcp-server/keyless#add-an-api-key).

## Solução de problemas {#troubleshooting}

* **O suporte a MCP está desativado:** na IDE, abra as configurações com `Cmd/Ctrl + ,`, pesquise por &quot;MCP&quot; e ative a opção.
* **O servidor não conecta:** confirme se a URL é exatamente `https://mcp.firecrawl.dev/v2/mcp-oauth` e salve o arquivo novamente para forçar a reconexão.
* **Aparece um erro de escopo do OAuth:** adicione `"oauth": { "oauthScopes": [] }` à entrada do servidor.
* **Os arquivos do espaço de trabalho e do usuário definem `firecrawl` ao mesmo tempo:** o Kiro mescla os dois, e o arquivo do espaço de trabalho prevalece. Mantenha apenas uma entrada.
