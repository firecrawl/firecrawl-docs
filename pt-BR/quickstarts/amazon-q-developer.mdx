Conecte o Firecrawl ao Amazon Q Developer no VS Code, no JetBrains e em outras IDEs compatíveis por meio do servidor MCP hospedado. O Q Developer abre um navegador para você fazer login com sua conta do Firecrawl.

<Note>
  O Amazon Q Developer CLI agora se chama Kiro CLI. Para usar no terminal, siga a [configuração do Kiro](/pt-BR/quickstarts/kiro).
</Note>

## Configuração rápida {#quick-setup}

1. Abra sua IDE, depois o painel do Q Developer e, em seguida, o painel **Chat**.
2. Selecione o ícone de ferramentas e, em seguida, o botão de adição (+).
3. Escolha um escopo: **global** armazena o servidor em `~/.aws/amazonq/default.json`, e **local** o armazena em `.amazonq/default.json`, dentro do projeto.
4. Informe `firecrawl` como nome, escolha **http** como transporte e insira esta URL:

```text
https://mcp.firecrawl.dev/v2/mcp-oauth
```

5. Selecione **Save**. O Q Developer abre uma página no navegador para você autorizar o acesso. Faça login no Firecrawl e aprove a conexão.
6. No painel exibido após salvar, revise a permissão de cada ferramenta (**Ask**, **Always allow** ou **Deny**).

<Accordion title="Prefere editar o arquivo de configuração?">
  O Q Developer também lê servidores MCP de `~/.aws/amazonq/mcp.json` (global) e `.amazonq/mcp.json` (projeto):

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
      }
    }
  }
  ```

  O suporte aos arquivos `mcp.json` é controlado pelo campo `useLegacyMcpJson` em `default.json`, que é `true` por padrão.
</Accordion>

<Accordion title="Prefere usar uma API key?">
  Na mesma caixa de diálogo, adicione um cabeçalho chamado `Authorization` com o valor `Bearer fc-YOUR-API-KEY` e use `https://mcp.firecrawl.dev/v2/mcp` como URL. Veja [Configurar uma API key](/pt-BR/mcp-server/keyless#add-an-api-key).
</Accordion>

Veja o [guia de conexão OAuth](/pt-BR/mcp-server/oauth) para mais detalhes.

## Solução de problemas {#troubleshooting}

* **Aparece um alerta &quot;Fix Configuration&quot;:** selecione-o para voltar ao formulário e verificar a URL.
* **A página do navegador não abre:** escolha **Edit setup** no servidor, salve novamente e conclua a autorização quando a página abrir.
* **O servidor aparece na lista, mas as ferramentas dele não são executadas:** abra o servidor no painel Servidores MCP e confirme que ele está habilitado e que as ferramentas não estão definidas como **Deny**.
* **Duas entradas do Firecrawl:** um servidor em `.amazonq/default.json` tem precedência sobre o global. Remova a entrada duplicada que você não quer manter.
