Adicione as ferramentas Search, Scrape, Crawl e Map do Firecrawl ao [Tencent WorkBuddy](https://www.workbuddy.ai) usando o servidor MCP hospedado.

## Configuração rápida {#quick-setup}

[Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys) e depois adicione o servidor no WorkBuddy:

1. Abra **Experts · Skills · Connectors**, acesse a aba **Connectors** e selecione **Custom connectors**.
2. Selecione **Configure MCP** para abrir o editor de configuração do MCP.
3. Adicione o Firecrawl a `mcpServers` e salve:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

Substitua `<FIRECRAWL_API_KEY>` pela sua chave. Se você já tiver outros servidores, adicione apenas a entrada `firecrawl` e mantenha os demais.

O WorkBuddy armazena essa configuração em `~/.workbuddy/mcp.json`. Para um único projeto, use `<project>/.workbuddy/mcp.json`.

De volta à lista de MCPs, ative **firecrawl** e marque-o como confiável se o WorkBuddy pedir. O status verde indica que ele está conectado e que ferramentas como `firecrawl_search` e `firecrawl_scrape` estão disponíveis.

O WorkBuddy também oferece suporte a MCP OAuth. Para fazer login em vez de usar uma chave, veja [Para humanos](/pt-BR/mcp-server/oauth).

## Solução de problemas {#troubleshooting}

* **O status está vermelho:** verifique se o JSON é válido e se a URL é exatamente `https://mcp.firecrawl.dev/v2/mcp`.
* **401 Não autorizado:** confirme a chave e mantenha o prefixo `Bearer ` no cabeçalho `Authorization`.
* **As ferramentas não aparecem:** desative e reative o servidor para que o WorkBuddy atualize a lista de ferramentas.
