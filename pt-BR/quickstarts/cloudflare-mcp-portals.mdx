Adicione o servidor MCP hospedado do Firecrawl a um [portal de servidores MCP do Cloudflare One](https://developers.cloudflare.com/cloudflare-one/access-controls/ai-controls/mcp-portals/) para que sua equipe acesse as ferramentas de busca e raspagem do Firecrawl por uma única URL de portal, protegida pelas suas políticas do Access.

## Configuração rápida {#quick-setup}

[Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys). Em seguida, adicione o Firecrawl como servidor MCP no Cloudflare Access pela API do portal, usando a chave como credencial bearer:

```bash
export CLOUDFLARE_ACCOUNT_ID=your-cloudflare-account-id
export CLOUDFLARE_API_TOKEN=your-cloudflare-api-token
export FIRECRAWL_API_KEY=fc-YOUR_API_KEY

curl -X POST "https://api.cloudflare.com/client/v4/accounts/$CLOUDFLARE_ACCOUNT_ID/access/ai-controls/mcp/servers" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Firecrawl",
    "hostname": "https://mcp.firecrawl.dev/v2/mcp",
    "auth_type": "bearer",
    "auth_credentials": "'"$FIRECRAWL_API_KEY"'"
  }'
```

O portal envia `auth_credentials` ao Firecrawl como `Authorization: Bearer <key>`. Você também pode adicionar o servidor no painel da Cloudflare em **Zero Trust** &gt; **Access controls** &gt; **MCP Portals** &gt; **MCP servers** &gt; **Add MCP server**, usando a mesma URL.

Em seguida, adicione o servidor a um portal, vincule as políticas de Access que definem quem pode vê-lo e escolha as ferramentas que serão expostas. O [guia de portais de servidores MCP](https://developers.cloudflare.com/cloudflare-one/access-controls/ai-controls/mcp-portals/) da Cloudflare explica como criar o portal.

## Experimente {#try-it}

Conecte um cliente MCP à URL do seu portal (`https://<subdomain>.<domain>/mcp`) e depois pergunte:

```text
Faça uma busca na web pelas notas de versão mais recentes do Cloudflare Workers e resuma as fontes.
```

```text
Faça scraping de https://firecrawl.dev e explique o que ele faz.
```

## Solução de problemas {#troubleshooting}

* **O servidor exibe um erro de sincronização ou de autenticação:** verifique se a chave é válida e se `auth_type` está definido como `bearer`; atualize as credenciais do servidor caso tenha rotacionado a chave.
* **As ferramentas do Firecrawl não aparecem no portal:** o portal expõe apenas as ferramentas selecionadas por um administrador, então revise a lista de ferramentas do portal.
* **Os usuários não conseguem ver o Firecrawl:** o link do servidor só aparece para usuários que atendem a uma política Allow no servidor.
