Conecte o Firecrawl aos agentes locais do Warp pelo servidor MCP hospedado e depois faça login com sua conta do Firecrawl.

## Configuração rápida {#quick-setup}

1. No Warp, abra **Settings**, depois **Agents** e, em seguida, **Servidores MCP**. Você também pode buscar por **Open Servidores MCP** na paleta de comandos.
2. Selecione **+ Add** e cole esta configuração:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

3. Inicie o servidor. O Warp abre uma página no navegador para fazer login no Firecrawl. Aprove o acesso, e o Warp armazena as credenciais no seu dispositivo.
4. Confirme que `firecrawl` aparece como em execução na lista de servidores MCP e, em seguida, peça a um agente para fazer uma busca ou um scraping.

<Accordion title="Prefere uma configuração baseada em arquivo?">
  O Warp também carrega servidores de `~/.warp/.mcp.json` para todos os projetos, ou de `.warp/.mcp.json` na raiz de um projeto. Use o mesmo JSON mostrado acima. Servidores definidos no arquivo do projeto precisam da sua aprovação antes de serem iniciados.
</Accordion>

<Accordion title="Prefere usar uma API key?">
  O Warp aceita cabeçalhos personalizados em servidores por URL. Use `https://mcp.firecrawl.dev/v2/mcp` como URL e adicione `"headers": { "Authorization": "Bearer fc-YOUR-API-KEY" }`. Veja [Configurar uma API key](/pt-BR/mcp-server/keyless#add-an-api-key).
</Accordion>

Veja o [guia de conexão OAuth](/pt-BR/mcp-server/oauth) para mais detalhes.

## Solução de problemas {#troubleshooting}

* **A página de login não abre:** inicie o servidor novamente na página de servidores MCP.
* **O login continua falhando:** execute `rm -rf ~/.mcp-auth` para apagar os tokens MCP armazenados e inicie o servidor novamente. Isso remove os tokens de todos os servidores MCP.
* **O servidor não inicia:** selecione **View Logs** no servidor para ver o erro.
* **As ferramentas não são usadas:** alguns modelos chamam ferramentas MCP de forma mais confiável que outros. Experimente outro modelo no seletor de agentes.
