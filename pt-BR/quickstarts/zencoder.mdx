Adicione o Firecrawl ao Zencoder nas IDEs JetBrains e no VS Code. As IDEs JetBrains oferecem suporte a servidores remotos com OAuth2, então você faz login com sua conta do Firecrawl. No VS Code, o servidor é iniciado localmente com uma API key.

## Requisitos {#requirements}

* O plugin do Zencoder para uma IDE JetBrains ou para o VS Code.
* Para a configuração no VS Code: Node.js 22 ou superior e uma [chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys).

## Configuração rápida {#quick-setup}

<Tabs>
  <Tab title="JetBrains">
    1. Abra **Settings**, depois **Tools**, depois **Zencoder** e, por fim, **MCP Servers**.
    2. Adicione este servidor e aplique a alteração:

    ```json
    {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth",
        "auth": "oauth2"
      }
    }
    ```

    3. Conclua o login no Firecrawl pelo navegador e verifique se as ferramentas aparecem na lista de ferramentas do agente.
  </Tab>

  <Tab title="VS Code">
    1. Abra o `settings.json` do usuário ou do espaço de trabalho.
    2. Adicione o Firecrawl em `zencoder.mcpServers`:

    ```json
    {
      "zencoder.mcpServers": {
        "firecrawl": {
          "command": "npx",
          "args": ["-y", "firecrawl-mcp@3.33.2"],
          "env": {
            "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
          }
        }
      }
    }
    ```

    3. Reinicie o VS Code e verifique se as ferramentas do Firecrawl aparecem em **Agent Tools**.
  </Tab>
</Tabs>

Segundo a documentação do Zencoder, os servidores HTTP e OAuth2 para VS Code ainda estão sendo liberados gradualmente. Por isso, use a configuração local até que eles apareçam na sua versão. Veja o [guia de conexão OAuth](/pt-BR/mcp-server/oauth) e [Executar o MCP localmente](/pt-BR/mcp-server/local) para mais detalhes.

## Solução de problemas {#troubleshooting}

* **O servidor não aparece nas ferramentas de agente:** verifique a sintaxe do JSON e reinicie o IDE. Os servidores MCP são carregados na inicialização.
* **O login no JetBrains falha:** limpe o token em cache do servidor e inicie o login novamente.
* **O VS Code informa que um comando não foi encontrado:** confirme que o `npx` funciona no terminal e que `node --version` exibe 22 ou superior.
* **As ferramentas não são executadas:** o Zencoder pede permissão antes de cada chamada de ferramenta. Escolha **Allow once** ou **Always allow** para as ferramentas do Firecrawl.
