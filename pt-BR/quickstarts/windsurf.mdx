Adicione as ferramentas Search, Scrape e Parse sem chave do Firecrawl ao Windsurf por meio do servidor MCP hospedado.

## Configuração rápida {#quick-setup}

Abra **Configurações → Ferramentas → Configurações do Windsurf → Adicionar servidor** ou edite `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Reinicie o Windsurf e confirme que `firecrawl_search`, `firecrawl_scrape` e `firecrawl_parse` estão disponíveis.

O acesso sem chave está sujeito a limites compartilhados entre usuários do mesmo IP público. Faça login em um cliente interativo com o [For Humans](/pt-BR/mcp-server/oauth) ou [adicione uma chave de API](/pt-BR/mcp-server/keyless#add-an-api-key) para uso não assistido.

```

Faça scraping de https://firecrawl.dev e explique o que ele faz.
```

## Solução de problemas {#troubleshooting}

* **O servidor não se conecta:** confirme a URL hospedada e verifique o status do MCP no Windsurf.
* **Crawl ou outra ferramenta não está disponível:** o modo sem chave expõe apenas Search, Scrape e Parse. Conecte-se com OAuth ou uma chave de API para acessar um conjunto de ferramentas mais amplo.
