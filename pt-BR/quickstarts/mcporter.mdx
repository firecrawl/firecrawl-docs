Conecte o [MCPorter](https://mcporter.sh), um runtime e CLI em TypeScript para servidores MCP, ao Firecrawl usando o servidor MCP hospedado.

## Configuração rápida {#quick-setup}

[Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys) e exporte-a:

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

Adicione o Firecrawl ao `config/mcporter.json` do seu projeto ou ao `~/.mcporter/mcporter.json` para usá-lo em todos os projetos:

```json
{
  "mcpServers": {
    "firecrawl": {
      "baseUrl": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": { "Authorization": "Bearer ${FIRECRAWL_API_KEY}" }
    }
  }
}
```

O MCPorter substitui `${FIRECRAWL_API_KEY}` pelo valor definido no seu ambiente, então a chave não fica gravada no arquivo. Confirme a conexão:

```bash
npx mcporter list firecrawl
```

Prefere um processo local? Use o formato stdio:

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": { "FIRECRAWL_API_KEY": "${FIRECRAWL_API_KEY}" }
    }
  }
}
```

## Experimente {#try-it}

```bash
npx mcporter call firecrawl.firecrawl_scrape url=https://firecrawl.dev 'formats=["markdown"]'
```

O comando exibe a página em markdown. Use a mesma entrada no código com `createRuntime` (veja a [documentação do MCPorter](https://mcporter.sh)).

## Solução de problemas {#troubleshooting}

* **Servidor não encontrado:** execute `npx mcporter config list` para ver qual arquivo de configuração o MCPorter carregou; `--config <file>` ou `MCPORTER_CONFIG` seleciona apenas um arquivo.
* **Erros de autenticação:** o MCPorter rejeita a forma `${env:VAR}`; escreva o placeholder como `${FIRECRAWL_API_KEY}` e verifique se a variável foi exportada no mesmo shell.
* **Argumentos da ferramenta rejeitados:** passe os valores JSON com as aspas adequadas ao seu shell, como no exemplo de `formats` acima.
