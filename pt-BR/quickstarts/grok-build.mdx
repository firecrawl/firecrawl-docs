Conecte o [Grok Build](https://docs.x.ai/build/overview), a CLI de agente de programação da xAI (`grok`), ao Firecrawl por meio do servidor MCP hospedado. O OAuth é a configuração interativa recomendada. Com o OAuth, a chave não precisa ser inserida na linha de comando, nos arquivos do projeto nem na conversa.

## Configuração rápida {#quick-setup}

### 1. Adicione o Firecrawl {#1-add-firecrawl}

Execute:

```bash
grok mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

`https://mcp.firecrawl.dev/v2/mcp-oauth` é um valor de configuração do cliente, e não uma página para abrir diretamente no navegador.

### 2. Faça login e verifique {#2-sign-in-and-verify}

Inicie o Grok Build:

```bash
grok
```

Digite `/mcps`, selecione `firecrawl` e pressione `i` para iniciar o login pelo navegador. Escolha uma equipe e aprove a conexão. O Grok armazena os tokens OAuth em `~/.grok/mcp_credentials.json`.

Verifique se há apenas um servidor `firecrawl` ativo e, em seguida, experimente:

```text
Faça uma busca na web pelas notas de versão mais recentes do Next.js e resuma as fontes.
```

```text
Faça scraping de https://docs.firecrawl.dev e liste as seções principais.
```

## MCP local com uma API key {#local-mcp-with-an-api-key}

Use o servidor local somente quando precisar de um processo local ou de uma API do Firecrawl auto-hospedada. O pacote local requer Node.js 22 ou superior.

Defina `FIRECRAWL_API_KEY` no ambiente que inicia o Grok. Em seguida, adicione este bloco ao `~/.grok/config.toml`:

```toml
[mcp_servers.firecrawl]
command = "npx"
args = ["-y", "firecrawl-mcp@3.33.2"]
env = { FIRECRAWL_API_KEY = "${FIRECRAWL_API_KEY}" }
startup_timeout_sec = 60
```

O Grok expande `${FIRECRAWL_API_KEY}` ao carregar a configuração, então a chave não fica gravada no arquivo. Mantenha o segredo fora do chat com o agente e do controle de versão. Use apenas uma entrada `firecrawl`: antes, remova o servidor hospedado com `grok mcp remove firecrawl`.

Para configurações self-hosted, veja [Executar o MCP localmente](/pt-BR/mcp-server/local).

## Solução de problemas {#troubleshooting}

* **Já existe um servidor do Firecrawl:** execute `grok mcp remove firecrawl`, adicione a conexão desejada uma única vez e inicie uma nova sessão.
* **O Grok mostra um segundo servidor `firecrawl`:** o Grok também carrega servidores MCP de `~/.claude.json`, `.cursor/mcp.json` e de arquivos `.mcp.json` do projeto. Execute `grok inspect` para ver a origem de cada servidor e remova o duplicado.
* **O servidor mostra `401`:** digite `/mcps`, selecione `firecrawl` e pressione `i` para fazer login novamente. Não cole uma API key na conversa nem na URL do OAuth.
* **O servidor local não conecta:** execute `grok mcp doctor firecrawl`. O Grok grava os erros do servidor em `~/.grok/logs/mcp/firecrawl.stderr.log`. Se o `npx` baixar o pacote na primeira inicialização, aumente o valor de `startup_timeout_sec`.
