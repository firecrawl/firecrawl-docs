Integre o Firecrawl com o OpenClaw para dar aos seus agentes a capacidade de fazer scraping, busca, crawling e interação com a web, além de executar tarefas do agente, tudo por meio da [CLI do Firecrawl](/pt-BR/sdks/cli).

## Por que Firecrawl + OpenClaw {#why-firecrawl-openclaw}

* **Nenhum navegador local necessário** — cada sessão é executada em um sandbox remoto e isolado. Sem instalações de Chromium, sem conflitos de drivers, sem pressão de RAM na sua máquina.
* **Paralelismo de verdade** — execute muitas sessões de navegador ao mesmo tempo, sem disputa por recursos locais. Os agentes podem navegar em lotes por vários sites simultaneamente.
* **Seguro por padrão** — navegação, avaliação do DOM e extração acontecem dentro de sandboxes descartáveis, não na sua estação de trabalho.
* **Melhor economia de tokens** — os agentes recebem artefatos limpos (snapshots, campos extraídos) em vez de arrastar DOMs gigantes e logs de drivers para dentro da janela de contexto.
* **Kit de ferramentas web completo** — scraping, busca e automação de navegador, tudo por meio de uma única CLI que seu agente já sabe usar.

## Configuração {#setup}

Peça ao seu agente para instalar a CLI do Firecrawl, fazer a autenticação e inicializar a skill com este comando:

```bash
npx -y firecrawl-cli init --browser --all
```

* `--all` pula a seleção de agentes e inicializa todos os agentes detectados
* `--browser` abre o navegador automaticamente para autenticação do Firecrawl

ou instale tudo separadamente:

```bash
npm install -g firecrawl-cli
firecrawl setup skills
firecrawl login --browser
# Ou, pule o navegador e forneça sua chave de API diretamente:
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

Verifique se tudo está configurado corretamente:

```bash
firecrawl --status
```

<Tip>
  Após instalar a skill, seu agente OpenClaw descobre e usa automaticamente os comandos do Firecrawl — sem precisar de configuração extra.
</Tip>

## Scrape {#scrape}

Faça o scraping de uma única página e extraia seu conteúdo:

```bash
firecrawl https://example.com --only-main-content
```

Obtenha formatos específicos:

```bash
firecrawl https://example.com --format markdown,links --pretty
```

## Busca {#search}

Pesquise na web e, opcionalmente, faça scraping dos resultados:

```bash
firecrawl search "latest AI funding rounds" --limit 10

# Pesquisar e extrair os resultados
firecrawl search "OpenClaw documentation" --scrape --scrape-formats markdown
```

## Interagir {#interact}

Faça scraping de uma página e continue trabalhando com ela em uma sessão do navegador em tempo real. Cada sessão é executada remotamente em um sandbox isolado, então não é necessário instalar o Chromium localmente. Por padrão, `interact` usa o scraping mais recente.

```bash
firecrawl scrape https://news.ycombinator.com
firecrawl interact "What are the titles of the top 3 stories?"
firecrawl interact "Click the More link at the bottom of the page and list the first 3 story titles"
firecrawl interact stop
```

Execute código diretamente na página em tempo real, em vez de usar um prompt:

```bash
firecrawl interact -c "await page.title()"
firecrawl interact -c "print(await page.title())" --python
```

<Note>
  Seu agente envia prompts de alto nível, descrevendo a intenção, ou pequenos trechos de código Playwright, em vez de gerenciar um navegador local. Execute `firecrawl interact stop` ao terminar para liberar a sessão. O comando antigo `firecrawl browser` está descontinuado; em vez dele, use `scrape` seguido de `interact`.
</Note>

## Exemplo: diga ao seu agente {#example-tell-your-agent}

Aqui estão alguns prompts que você pode dar ao seu agente OpenClaw:

* *&quot;Use Firecrawl para fazer scraping de https://example.com e resuma o conteúdo principal.&quot;*
* *&quot;Busque as notícias mais recentes sobre a OpenAI e me dê um resumo dos 5 principais resultados.&quot;*
* *&quot;Use o Firecrawl para abrir o Hacker News com interagir, obter os 5 principais posts e os primeiros 10 comentários de cada um.&quot;*
* *&quot;Rastreie a documentação em https://docs.firecrawl.dev e salve tudo em um arquivo.&quot;*
