Conecte o Firecrawl ao Crush como um servidor MCP HTTP remoto para que o Crush possa fazer buscas na web e ler páginas.

## Requisitos {#requirements}

* Crush 0.98 ou superior.
* Uma [chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys), exportada como `FIRECRAWL_API_KEY`.

## Configuração rápida {#quick-setup}

1. Exporte sua API key no shell em que você inicia o Crush:

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

2. Adicione o servidor ao `crush.json` do seu projeto ou ao `~/.config/crush/crush.json` para usá-lo em todos os projetos:

```json
{
  "$schema": "https://charm.land/crush.json",
  "mcp": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer $FIRECRAWL_API_KEY"
      }
    }
  }
}
```

3. Inicie o Crush e peça que ele faça uma busca ou um scraping.

<Accordion title="Usando um arquivo crushrc?">
  Versões mais recentes do Crush conseguem ler um arquivo `crushrc` no estilo Bash, no qual um servidor MCP é configurado com um único comando:

  ```bash
  mcp add firecrawl \
    --type http \
    --url "https://mcp.firecrawl.dev/v2/mcp" \
    --header Authorization "Bearer $FIRECRAWL_API_KEY"
  ```

  Execute `crush dirs` para ver onde o Crush procura a configuração na sua máquina.
</Accordion>

Veja [Configurar uma API key](/pt-BR/mcp-server/keyless#add-an-api-key) para saber mais sobre chaves.

## Solução de problemas {#troubleshooting}

* **O servidor não inicia:** verifique se `FIRECRAWL_API_KEY` está exportada no shell que inicia o Crush e se a URL é exatamente `https://mcp.firecrawl.dev/v2/mcp`.
* **O cabeçalho é descartado:** o Crush remove cabeçalhos cujo valor resulta em uma string vazia. Isso acontece quando `FIRECRAWL_API_KEY` não está definida.
* **As ferramentas não são usadas:** alguns modelos chamam ferramentas MCP de forma mais confiável que outros. Experimente outro modelo.
