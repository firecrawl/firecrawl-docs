Conecte o Firecrawl ao Qwen Code como um servidor MCP HTTP remoto para que o Qwen Code possa fazer buscas na web e ler páginas.

## Requisitos {#requirements}

* Qwen Code 0.25 ou superior.
* Uma [chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys), exportada como `FIRECRAWL_API_KEY`.

## Configuração rápida {#quick-setup}

1. Exporte sua API key no shell em que você inicia o Qwen Code:

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

2. Adicione o servidor. As aspas simples impedem que o shell expanda a variável, assim o arquivo de configurações armazena a referência, e não a sua chave:

```bash
qwen mcp add --scope user --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp \
  --header 'Authorization: Bearer $FIRECRAWL_API_KEY'
```

3. Verifique se o servidor se conecta:

```bash
qwen mcp list
```

4. Inicie o Qwen Code, execute `/mcp` para ver as ferramentas do Firecrawl e peça que ele faça uma busca ou um scraping.

<Accordion title="Prefere editar o arquivo de configuração?">
  Adicione o servidor ao arquivo `~/.qwen/settings.json` ou ao `.qwen/settings.json` de um projeto:

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "httpUrl": "https://mcp.firecrawl.dev/v2/mcp",
        "headers": {
          "Authorization": "Bearer $FIRECRAWL_API_KEY"
        }
      }
    }
  }
  ```
</Accordion>

Veja [Configurar uma API key](/pt-BR/mcp-server/keyless#add-an-api-key) para saber mais sobre chaves.

## Solução de problemas {#troubleshooting}

* **O servidor não aparece em uma sessão em andamento:** depois de adicioná-lo, reinicie o Qwen Code no mesmo projeto.
* **O servidor aparece como desconectado:** execute `qwen mcp list` e verifique se `FIRECRAWL_API_KEY` foi exportada no shell que inicia o Qwen Code.
* **As chamadas de ferramenta são rejeitadas por chave inválida:** confirme que o valor do cabeçalho é `Bearer $FIRECRAWL_API_KEY` e que a variável contém uma chave válida.
* **As ferramentas não são usadas:** alguns modelos chamam ferramentas MCP com mais confiabilidade do que outros. Experimente outro modelo.
