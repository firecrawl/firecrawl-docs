Adicione as ferramentas Search, scraping e outras ferramentas web do Firecrawl ao [Kimi Code CLI](https://www.kimi.com/code/docs/en/kimi-code-cli/getting-started.html) usando o servidor MCP hospedado.

## Configuração rápida {#quick-setup}

[Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys) e adicione o seguinte a `~/.kimi-code/mcp.json` (ou a `.kimi-code/mcp.json` em um projeto):

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

Para não deixar a chave no arquivo, exporte-a e faça referência à variável em vez de usar `headers`:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "bearerTokenEnvVar": "FIRECRAWL_API_KEY"
    }
  }
}
```

Você também pode adicionar o servidor de forma interativa com `/mcp-config`. Inicie uma nova sessão do Kimi Code, execute `/mcp` e confirme que `firecrawl` está conectado e que suas ferramentas, como `firecrawl_search` e `firecrawl_scrape`, aparecem na lista.

Para fazer login pelo navegador em vez de usar uma API key, use `https://mcp.firecrawl.dev/v2/mcp-oauth` como URL, sem `headers`, e depois execute `/mcp-config login firecrawl`. Veja [Para humanos](/pt-BR/mcp-server/oauth).

## Solução de problemas {#troubleshooting}

* **As ferramentas não aparecem:** os servidores MCP são carregados quando uma sessão é iniciada, então abra uma nova sessão depois de editar o `mcp.json`. Um servidor adicionado no meio de uma sessão só fica disponível nas sessões seguintes.
* **O servidor não conecta:** execute `/mcp` para ver o status e, em seguida, verifique a URL e se a API key está correta. Com `bearerTokenEnvVar`, a variável precisa estar definida no shell que inicia o `kimi`.
* **A configuração no nível do projeto é ignorada:** em pastas não confiáveis, os servidores do `.kimi-code/mcp.json` do projeto permanecem desativados. Marque a pasta como confiável ou defina `KIMI_CODE_TRUST_WORKSPACE=1` para execuções headless.
* **Prefere um servidor local:** o Kimi Code também pode executar `npx -y firecrawl-mcp` com `FIRECRAWL_API_KEY` em `env`. Veja [Executar localmente](/pt-BR/mcp-server/local).
