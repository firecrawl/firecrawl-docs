Adicione o Firecrawl ao Rovo Dev CLI por meio do servidor MCP hospedado. Como o Rovo Dev CLI lê servidores remotos com cabeçalhos de request, esta configuração usa uma chave de API do Firecrawl.

## Requisitos {#requirements}

* Rovo Dev CLI, instalado como extensão da Atlassian CLI (`acli`) e autenticado com `acli rovodev auth login`.
* Uma [chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys).

## Configuração rápida {#quick-setup}

1. Execute `acli rovodev mcp` para abrir `~/.rovodev/mcp.json` no seu editor padrão.
2. Adicione o Firecrawl, substitua a chave e salve:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "transport": "http",
      "headers": {
        "Authorization": "Bearer fc-YOUR-API-KEY"
      }
    }
  }
}
```

3. Inicie o Rovo Dev com `acli rovodev run`, digite `/mcp` e confirme que `firecrawl` aparece na lista com suas ferramentas.

<Accordion title="Prefere um servidor local?">
  O Rovo Dev CLI também inicia servidores stdio. Siga [Executar o MCP localmente](/pt-BR/mcp-server/local) e defina o comando no mesmo arquivo:

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "command": "npx",
        "args": ["-y", "firecrawl-mcp@3.33.2"],
        "env": {
          "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
        },
        "transport": "stdio"
      }
    }
  }
  ```
</Accordion>

Mantenha o arquivo privado, pois ele contém sua chave. Veja [Configurar uma API key](/pt-BR/mcp-server/keyless#add-an-api-key) para saber mais sobre conexões com chave.

## Solução de problemas {#troubleshooting}

* **`/mcp` não lista o Firecrawl:** verifique se o JSON é válido e se `transport` está definido como `"http"` para a URL hospedada.
* **O servidor retorna `401`:** substitua a chave em `mcp.json` e reinicie o `acli rovodev run`.
* **O Firecrawl aparece na lista, mas está desativado:** abra `/mcp` e ative-o. Verifique também se ele não está listado em `disabledMcpServers` no arquivo `~/.rovodev/config.yml`.
* **Você não quer usar as instruções do servidor:** defina `"enable_instructions": false` na entrada do Firecrawl.
