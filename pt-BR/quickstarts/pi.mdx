Adicione as ferramentas Search, Scrape, Crawl e Map do Firecrawl ao [Pi](https://pi.dev) usando o servidor MCP hospedado.

## Configuração rápida {#quick-setup}

[Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys) e depois exporte-a para que o Pi consiga lê-la:

```bash
export FIRECRAWL_API_KEY=fc-YOUR_API_KEY
```

Adicione o servidor usando o comando MCP integrado do Pi:

```bash
pi mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp --bearer-token-env-var FIRECRAWL_API_KEY
```

Isso grava a entrada em `~/.pi/agent/mcp.json`. Você também pode colá-la manualmente ou colocá-la em `.pi/mcp.json` para usá-la em um único projeto:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer ${FIRECRAWL_API_KEY}"
      }
    }
  }
}
```

Execute `pi mcp list` e confirme que `firecrawl` aparece como conectado, junto com suas ferramentas, como `firecrawl_search` e `firecrawl_scrape`. Em seguida, inicie o `pi`; se já houver uma sessão aberta, execute `/reload`.

Se você usa o [pi-mcp-adapter](https://github.com/nicobailon/pi-mcp-adapter), adicione a mesma entrada em `~/.config/mcp/mcp.json` (ou em `.mcp.json`, no caso de um projeto) e execute `pi-mcp-adapter doctor` para verificar a conexão.

### Executar localmente como alternativa {#run-it-locally-instead}

Para executar o servidor MCP na sua máquina, adicione-o como um servidor stdio:

```bash
pi mcp add firecrawl --env FIRECRAWL_API_KEY='${FIRECRAWL_API_KEY}' -- npx -y firecrawl-mcp
```

## Solução de problemas {#troubleshooting}

* **O servidor aparece com status de falha:** execute `pi mcp list` e verifique se `FIRECRAWL_API_KEY` foi exportada no mesmo shell em que o Pi é iniciado.
* **As ferramentas não aparecem em uma sessão aberta:** execute `/reload` depois de adicionar ou alterar um servidor fora da sessão.
* **O comando MCP do Pi não existe:** atualize o Pi para uma versão recente ou use o pi-mcp-adapter com a configuração acima.
