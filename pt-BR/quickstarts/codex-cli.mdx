Conecte o [OpenAI Codex CLI](https://github.com/openai/codex) ao Firecrawl por meio do servidor MCP hospedado com OAuth.

<div id="quick-setup">
  ## Configuração rápida
</div>

<div id="1-add-firecrawl">
  ### 1. Adicione o Firecrawl
</div>

```bash
codex mcp add firecrawl --url https://mcp.firecrawl.dev/v2/mcp-oauth
codex mcp login firecrawl
```

A URL é um valor de configuração do cliente, não uma página para ser aberta diretamente no navegador. O Codex abre o fluxo de login do Firecrawl, no qual você escolhe uma equipe e aprova a conexão.

<div id="2-start-codex-and-verify">
  ### 2. Inicie o Codex e verifique
</div>

```bash
codex
```

Digite `/mcp` e confirme que `firecrawl` está conectado. Se você alterou uma conexão existente do Firecrawl, inicie uma nova sessão do Codex antes de tentar novamente.

Experimente:

```text
Search the web for the latest Next.js App Router release notes and summarize the sources.
```

```text
Scrape https://docs.firecrawl.dev and list the top-level sections.
```

<div id="other-connection-modes">
  ## Outras formas de conexão
</div>

* [Experimente o MCP sem chave](/pt-BR/mcp-server/keyless#try-keyless) para busca, scraping e parse sem conta nem chave.
* [Configure uma chave de API](/pt-BR/mcp-server/keyless#add-an-api-key) com `bearer_token_env_var` para uso não assistido. Mantenha o segredo fora do chat do agente e do controle de versão.
* [Execute o MCP localmente](/pt-BR/mcp-server/local) apenas se precisar de um processo local ou de uma API do Firecrawl auto-hospedada. O pacote local requer o Node.js 22 ou mais recente.

<div id="troubleshooting">
  ## Solução de problemas
</div>

* **O Codex não detecta as ferramentas:** execute `codex mcp list`, confirme que há apenas uma entrada `firecrawl` e reinicie o Codex.
* **O OAuth retorna `401`:** execute `codex mcp login firecrawl` e faça login. É esperado que uma solicitação sem credenciais ao servidor OAuth retorne `401` antes da autenticação.
* **Uma conexão com chave de API retorna `401`:** substitua a chave no ambiente que inicia o Codex e inicie uma nova sessão.
