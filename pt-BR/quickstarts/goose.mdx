Conecte o Firecrawl ao Goose como uma extensão remota para que o Goose possa fazer uma busca na web e ler páginas pelo servidor MCP hospedado.

## Requisitos {#requirements}

* Goose 1.55 ou superior.
* Uma [chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys), exportada como `FIRECRAWL_API_KEY`.

## Configuração rápida {#quick-setup}

1. Exporte sua API key no shell em que você inicia o Goose:

```bash
export FIRECRAWL_API_KEY="fc-YOUR-API-KEY"
```

2. Adicione a extensão à seção `extensions` do arquivo `~/.config/goose/config.yaml`:

```yaml
extensions:
  firecrawl:
    type: streamable_http
    name: firecrawl
    enabled: true
    uri: https://mcp.firecrawl.dev/v2/mcp
    headers:
      Authorization: "Bearer $FIRECRAWL_API_KEY"
    env_keys:
      - FIRECRAWL_API_KEY
    timeout: 300
```

3. Inicie uma sessão e peça ao Goose para fazer uma busca ou scraping:

```bash
goose session
```

<Warning>
  Escreva o cabeçalho como `$FIRECRAWL_API_KEY`, sem chaves ({ }), e mantenha `env_keys` no lugar. Caso contrário, o Goose envia `${FIRECRAWL_API_KEY}` como texto literal, e o servidor rejeita a request.
</Warning>

Veja [Configurar uma API key](/pt-BR/mcp-server/keyless#add-an-api-key) para saber mais sobre chaves.

## Solução de problemas {#troubleshooting}

* **A chave é apontada como inválida ou revogada:** verifique se o cabeçalho usa `$FIRECRAWL_API_KEY` sem chaves e se `FIRECRAWL_API_KEY` foi exportada no shell que inicia o Goose.
* **A extensão não aparece:** execute `goose session` novamente depois de salvar o arquivo e confirme que `enabled: true` está definido.
* **As chamadas excedem o tempo limite:** aumente o valor de `timeout`. A raspagem de uma página grande pode levar mais tempo que o padrão.
* **As ferramentas não são usadas:** alguns modelos chamam ferramentas MCP de forma mais confiável que outros. Experimente outro modelo.
