Adicione as ferramentas sem chave Search, scraping e Parse do Firecrawl ao Cursor por meio do servidor MCP hospedado.

<div id="quick-setup">
  ## Configuração rápida
</div>

Abra as configurações do Cursor, selecione **MCP** e adicione:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Reinicie o Cursor e confirme que `firecrawl_search`, `firecrawl_scrape` e `firecrawl_parse` estão disponíveis.

O acesso sem chave tem limites compartilhados entre usuários com o mesmo IP público. Faça login em um cliente interativo com o [For Humans](/pt-BR/mcp-server/oauth) ou [adicione uma chave de API](/pt-BR/mcp-server/keyless#add-an-api-key) para uso não assistido.

<div id="troubleshooting">
  ## Solução de problemas
</div>

* **O servidor não se conecta:** confirme se a URL é exatamente `https://mcp.firecrawl.dev/v2/mcp` e verifique o status do MCP no Cursor.
* **O rastreamento ou outra ferramenta está indisponível:** o modo sem chave oferece apenas Busca, Scraping e Parse. Conecte-se via OAuth ou com uma chave de API para acessar um conjunto de ferramentas mais amplo.
