Conecte o Firecrawl ao Cursor por meio do servidor MCP hospedado e, em seguida, faça login com sua conta do Firecrawl.

<CursorInstallButton />

## Configuração rápida {#quick-setup}

1. Clique em **Add to Cursor** acima para abrir a caixa de diálogo de instalação no Cursor.
2. Confirme a instalação do servidor Firecrawl MCP.
3. Use a opção de login do servidor no Cursor para conectar sua conta do Firecrawl e autorizar o acesso.
4. Verifique se as ferramentas do Firecrawl estão disponíveis no Cursor.

<Accordion title="Prefere adicionar a configuração manualmente?">
  Abra as configurações do Cursor (Cursor Settings), selecione **MCP** e adicione:

  ```json
  {
    "mcpServers": {
      "firecrawl": {
        "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
      }
    }
  }
  ```

  Salve a configuração e conclua o login no navegador pelo Cursor.
</Accordion>

Consulte o [guia de conexão OAuth](/pt-BR/mcp-server/oauth) para mais detalhes. Para uso não assistido, [configure uma API key](/pt-BR/mcp-server/keyless#add-an-api-key).

## Solução de problemas {#troubleshooting}

* **O servidor não se conecta:** confirme se a URL é exatamente `https://mcp.firecrawl.dev/v2/mcp-oauth` e verifique o status do MCP no Cursor.
* **O login é solicitado ou expira:** inicie a autenticação novamente nas configurações de MCP do Cursor.
* **Já existe outra conexão com o Firecrawl:** atualize o servidor existente para a URL do OAuth e faça login, para que apenas um servidor do Firecrawl fique ativo.
