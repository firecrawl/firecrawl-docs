O Claude Desktop, o Cowork e a aba Code leem os conectores da sua conta Claude. Conecte o Firecrawl uma única vez, com o nome de servidor `firecrawl`, e ele ficará disponível em todas as abas.

| Configuração                  | Valor                                                                                                                          |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Nome do servidor              | `firecrawl`                                                                                                                    |
| URL do conector personalizado | `https://mcp.firecrawl.dev/v2/mcp-oauth` (somente se você adicionar um conector personalizado em vez do conector do diretório) |
| Login                         | Faça login no Firecrawl pelo navegador e, em seguida, aprove uma equipe                                                        |

`https://mcp.firecrawl.dev/v2/mcp-oauth` é um valor de configuração do cliente, e não uma página para ser aberta diretamente no navegador.

## 1. Adicione o conector do Firecrawl {#1-add-the-firecrawl-connector}

1. Abra o [conector do Firecrawl](https://claude.ai/directory/connectors/firecrawl) no diretório de conectores do Claude ou acesse **Customize &gt; Conectores** no Claude Desktop e pesquise por Firecrawl.
2. Clique em **Connect**. O Claude abrirá o Firecrawl no seu navegador.
3. Faça login no Firecrawl, escolha uma equipe e aprove o acesso.

Nos planos Team ou Enterprise, talvez um Owner da organização precise permitir o conector antes que os membros possam se conectar.

<Accordion title="Não consegue usar o conector do diretório? Adicione um conector personalizado">
  1. No Claude Desktop, acesse **Customize &gt; Conectores**.
  2. Clique em **Add** e adicione um conector personalizado.
  3. Insira `firecrawl` como nome e `https://mcp.firecrawl.dev/v2/mcp-oauth` como URL do servidor MCP remoto.
  4. Mantenha as configurações de login detectadas, adicione o conector e, em seguida, clique em **Connect** e conclua o login no navegador.

  Já os Owners da organização adicionam conectores personalizados em **Organization settings &gt; Conectores**.
</Accordion>

## 2. Use no Cowork e no chat {#2-use-it-in-cowork-and-chat}

Na aba Cowork ou Chat, abra o menu **+** ao lado da caixa de prompt, vá até **Conectores** e verifique se o Firecrawl está ativado. Depois, experimente:

```text
Use o Firecrawl para buscar as notas de versão mais recentes do Next.js e resumir as fontes.
```

```text
Faça scraping de https://firecrawl.dev e explique o que o site faz.
```

## 3. Use-o na aba Code {#3-use-it-in-the-code-tab}

As sessões locais da aba Code podem usar o mesmo conector. Clique no botão **+** ao lado da caixa de prompt, selecione **Conectores** e ative o Firecrawl.

A aba Code também carrega os servidores MCP que você adicionou ao Claude Code, por exemplo, com `claude mcp add`. Se você já configurou o Firecrawl por lá seguindo o [guia do Claude Code](/pt-BR/quickstarts/claude-code), mantenha o nome do servidor como `firecrawl` e verifique se há apenas um servidor do Firecrawl ativo na sessão.

## Solução de problemas {#troubleshooting}

* **As ferramentas do Firecrawl não aparecem.** Inicie uma nova conversa ou sessão depois de se conectar e verifique se o Firecrawl está habilitado no menu **Conectores**.
* **O Firecrawl aparece mais de uma vez.** Remova as entradas duplicadas para manter apenas um conector chamado `firecrawl`. Os conectores adicionados em **Customize &gt; Conectores** funcionam no Cowork; os servidores locais em `claude_desktop_config.json`, não. Por isso, prefira o conector.
* **Equipe errada.** Revise ou revogue a conexão nas [configurações do MCP](https://www.firecrawl.dev/app/settings?tab=mcp), depois conecte novamente e escolha a equipe correta.
