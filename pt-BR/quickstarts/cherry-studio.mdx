Adicione as ferramentas Pesquisar, Raspar e outras ferramentas web do Firecrawl ao [Cherry Studio](https://cherry-ai.com) por meio do servidor MCP hospedado.

O Cherry Studio oferece suporte a servidores remotos Streamable HTTP com cabeçalhos personalizados, então basta se conectar com sua chave de API do Firecrawl.

## Configuração rápida {#quick-setup}

1. [Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys).
2. No Cherry Studio, abra **Settings → MCP → MCP Servers** e selecione **Add**.
3. Escolha **Import from JSON** e cole o conteúdo abaixo, substituindo `<FIRECRAWL_API_KEY>` pela sua chave:

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "streamableHttp",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

4. Ative o servidor, aguarde até que o status fique saudável e, em seguida, abra os detalhes dele e confirme se `firecrawl_search` e `firecrawl_scrape` aparecem na lista.
5. Abra **Work**, edite seu Agente, vá até **MCP** e ative o servidor do Firecrawl para que o Agente possa usá-lo.

Você também pode usar o **Quick Create** e definir o tipo como **Streamable HTTP**, a URL como `https://mcp.firecrawl.dev/v2/mcp` e o cabeçalho como `Authorization=Bearer <FIRECRAWL_API_KEY>`.

Para usar um servidor local, use o tipo `stdio` com o comando `npx`, os argumentos `-y` e `firecrawl-mcp` e a variável de ambiente `FIRECRAWL_API_KEY`. Veja o [guia do servidor MCP local](/pt-BR/mcp-server/local).

O Cherry Studio também consegue fazer login em servidores remotos via OAuth quando nenhum cabeçalho `Authorization` está definido. Veja [Para humanos](/pt-BR/mcp-server/oauth) para saber qual é o endpoint OAuth do Firecrawl.

## Solução de problemas {#troubleshooting}

* **O servidor não conecta:** confirme se o tipo é Streamable HTTP, se a URL é exatamente `https://mcp.firecrawl.dev/v2/mcp` e se o cabeçalho é `Authorization: Bearer <FIRECRAWL_API_KEY>`. Verifique o log do servidor na página de detalhes dele.
* **As ferramentas não aparecem no chat:** o servidor precisa estar em execução e habilitado para o Agente. Verifique em **Work → Agent → Edit → MCP**.
* **Uma ferramenta não aparece:** abra os detalhes do servidor para ver quais ferramentas ele expõe e confirme se a sua API key é válida.
