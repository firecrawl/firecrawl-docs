Conecte o Claude Code ao Firecrawl pelo servidor MCP hospedado. OAuth é a configuração interativa recomendada porque a chave nunca é inserida na linha de comando, nos arquivos do projeto ou na conversa.

<div id="quick-setup">
  ## Configuração rápida
</div>

<div id="1-add-firecrawl">
  ### 1. Adicione o Firecrawl
</div>

Execute:

```bash
claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

`https://mcp.firecrawl.dev/v2/mcp-oauth` é um valor de configuração do cliente, não uma página para ser aberta diretamente no navegador.

<div id="2-sign-in-and-verify">
  ### 2. Faça login e verifique
</div>

Digite `/mcp` no Claude Code, escolha `firecrawl` e conclua o login no navegador. Inicie uma nova sessão do Claude Code se tiver alterado uma conexão existente do Firecrawl.

Confirme que há apenas um servidor `firecrawl` ativo e tente:

```text
Busque as notas da versão mais recente do Next.js e resuma as fontes.
```

```text

```

<div id="other-connection-modes">
  ## Outros modos de conexão
</div>

* [Experimente o MCP sem chave](/pt-BR/mcp-server/keyless#try-keyless) para busca, scraping e parse sem conta ou chave.
* [Configure uma chave de API](/pt-BR/mcp-server/keyless#add-an-api-key) para uso não assistido. Mantenha o segredo fora do chat do agente e use uma referência a variável de ambiente.
* [Execute o MCP localmente](/pt-BR/mcp-server/local) somente se precisar de um processo local ou de uma API do Firecrawl auto-hospedada. O pacote local requer o Node.js 22 ou versão posterior.

<div id="troubleshooting">
  ## Solução de problemas
</div>

* **Já existe um servidor Firecrawl:** execute `claude mcp remove firecrawl`, adicione a conexão desejada uma única vez e inicie uma nova sessão.
* **O navegador não abre:** digite `/mcp`, selecione `firecrawl` e inicie a autenticação no cliente.
* **O servidor exibe `401`:** faça login novamente por meio de `/mcp`; não cole uma chave de API na conversa nem na URL de OAuth.
