## Opcional: configurar o Claude Code {#optional-set-up-claude-code}

Conecte o Claude Code pelo servidor MCP hospedado. Execute o comando abaixo e, em seguida, faça login pelo navegador.

### 1. Adicione o Firecrawl {#1-add-firecrawl}

Execute:

```bash
claude mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

`https://mcp.firecrawl.dev/v2/mcp-oauth` é um valor de configuração do cliente, não uma página para ser aberta diretamente no navegador.

### 2. Faça login e verifique {#2-sign-in-and-verify}

Digite `/mcp` no Claude Code, escolha `firecrawl` e conclua o login no navegador. Inicie uma nova sessão do Claude Code se tiver alterado uma conexão existente do Firecrawl.

Confirme que há apenas um servidor `firecrawl` ativo e tente:

```text
Busque as notas da versão mais recente do Next.js e resuma as fontes.
```

## Opcional: pesquisa bibliográfica {#optional-literature-research}

Para trabalhos com artigos científicos e literatura, a skill research-index direciona essas queries para as ferramentas `firecrawl_research_*` e o [Research Index](/pt-BR/features/research), em vez da busca geral na web:

```bash
npx skills add firecrawl/skills@firecrawl-research-index
```

## Solução de problemas {#troubleshooting}

* **Já existe um servidor Firecrawl:** execute `claude mcp remove firecrawl`, adicione a conexão desejada uma única vez e inicie uma nova sessão.
* **O navegador não abre:** digite `/mcp`, selecione `firecrawl` e inicie a autenticação no cliente.
* **O servidor exibe `401`:** faça login novamente por meio de `/mcp`; não cole uma chave de API na conversa nem na URL de OAuth.
