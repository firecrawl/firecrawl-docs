## Pré-requisitos {#prerequisites}

* Node.js 22.13+
* Uma chave de API do Firecrawl — [obtenha uma grátis](https://www.firecrawl.dev/app/api-keys)
* Uma chave de API de um [provedor de modelos do Mastra](https://mastra.ai/models) compatível
* Um projeto Mastra existente — siga o [guia de início rápido do Mastra](https://mastra.ai/guides/getting-started/quickstart) para configurar o seu

## Instale o SDK {#install-the-sdk}

```bash
npm install firecrawl
```

## Defina sua chave de API {#set-your-api-key}

Adicione sua chave de API ao arquivo `.env`:

```bash
FIRECRAWL_API_KEY=fc-YOUR-API-KEY
```

## Crie as ferramentas do Firecrawl {#build-the-firecrawl-tools}

Crie `src/mastra/tools/firecrawl.ts` para disponibilizar a busca e o scraping como ferramentas no Mastra:

```typescript
import { Firecrawl } from "firecrawl";
import { createTool } from "@mastra/core/tools";
import { z } from "zod";

const firecrawl = new Firecrawl();

export const firecrawlSearch = createTool({
  id: "firecrawl-search",
  description: "Search the web and return top results.",
  inputSchema: z.object({ query: z.string().min(1) }),
  outputSchema: z.object({
    results: z.array(
      z.object({
        title: z.string().nullable(),
        url: z.string(),
      }),
    ),
  }),
  execute: async ({ query }) => {
    const results = await firecrawl.search(query, { limit: 3 });
    return {
      results: (results.web ?? []).flatMap((item) =>
        "url" in item ? [{ title: item.title ?? null, url: item.url }] : [],
      ),
    };
  },
});

export const firecrawlScrape = createTool({
  id: "firecrawl-scrape",
  description: "Scrape a URL and return markdown content.",
  inputSchema: z.object({ url: z.string().url() }),
  outputSchema: z.object({ markdown: z.string() }),
  execute: async ({ url }) => {
    const result = await firecrawl.scrape(url, {
      formats: ["markdown"],
      onlyMainContent: true,
    });
    return { markdown: result.markdown ?? "" };
  },
});
```

## Crie o agente {#create-the-agent}

Crie `src/mastra/agents/web-agent.ts` e adicione as ferramentas do Firecrawl a ele:

```typescript
import { Agent } from "@mastra/core/agent";
import { firecrawlSearch, firecrawlScrape } from "../tools/firecrawl";

export const webAgent = new Agent({
  id: "web-agent",
  name: "Web Agent",
  instructions:
    "Use Firecrawl tools to search and scrape web pages, then summarize the results.",
  model: "openai/gpt-5.4",
  tools: { firecrawlSearch, firecrawlScrape },
});
```

## Registrar o agente {#register-the-agent}

Registre o agente na sua instância do Mastra em `src/mastra/index.ts`:

```typescript
import { Mastra } from "@mastra/core";
import { webAgent } from "./agents/web-agent";

export const mastra = new Mastra({
  agents: { webAgent },
});
```

## Teste no Studio {#test-in-studio}

Inicie o servidor de desenvolvimento e abra o [Mastra Studio](https://mastra.ai/docs/studio/overview) em `http://localhost:4111`:

```bash
npm run dev
```

Abra o **Web Agent** e experimente prompts como:

* &quot;Encontre o changelog mais recente do Firecrawl e resuma a versão mais recente.&quot;
* &quot;Pesquise os preços do Firecrawl e extraia as categorias de plano.&quot;

## Dê ao agente um navegador hospedado {#give-the-agent-a-hosted-browser}

Para páginas que exigem cliques, digitação ou rolagem, o pacote [`@mastra/browser-firecrawl`](https://mastra.ai/integrations/browsers/firecrawl) do Mastra executa as ferramentas de navegador do agente em uma sessão do navegador do Firecrawl, dispensando a instalação local do Chromium.

```bash
npm install @mastra/browser-firecrawl agent-browser@0.19.0
```

<Note>
  Fixe o `agent-browser` na versão 0.19.0. As versões posteriores trazem apenas a CLI, o que faz a importação de `@mastra/browser-firecrawl` falhar com `Cannot find package .../agent-browser/index.js`.
</Note>

Crie `src/mastra/agents/browser-agent.ts` e, em seguida, registre o `browserAgent` na sua instância do Mastra da mesma forma que o `webAgent`:

```typescript
import { Agent } from "@mastra/core/agent";
import { FirecrawlBrowser } from "@mastra/browser-firecrawl";

export const browserAgent = new Agent({
  id: "browser-agent",
  name: "Browser Agent",
  instructions:
    "Use the browser tools to open pages, click, and type. Take a snapshot after each action to check the result.",
  model: "openai/gpt-5.4",
  browser: new FirecrawlBrowser({ apiKey: process.env.FIRECRAWL_API_KEY }),
});
```

Por padrão, cada thread de conversa recebe sua própria sessão do navegador. Veja a [documentação do navegador Firecrawl no Mastra](https://mastra.ai/integrations/browsers/firecrawl) para saber mais sobre sessões compartilhadas, tempo limite de sessão e perfis salvos.

## Firecrawl self-hosted {#self-hosted-firecrawl}

Se você hospeda o Firecrawl por conta própria, adicione `FIRECRAWL_API_URL` ao `.env`. O SDK lê essa variável do ambiente, então as ferramentas acima não precisam de nenhuma mudança:

```bash
FIRECRAWL_API_URL=http://localhost:3002
```
