Adicione o Firecrawl ao AI Assistant no IntelliJ IDEA, PyCharm, WebStorm e nas demais IDEs da JetBrains. O AI Assistant inicia o servidor MCP do Firecrawl como um processo local, usando sua API key.

## Requisitos {#requirements}

* Uma IDE da JetBrains com o AI Assistant 2025.1 ou posterior. O suporte a clientes MCP foi introduzido nessa versão.
* Node.js 22 ou posterior no seu `PATH`, já que o servidor é executado via `npx`.
* Uma [chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys).

## Configuração rápida {#quick-setup}

1. Abra **Settings**, depois **Tools**, depois **AI Assistant** e, por fim, **Model Context Protocol (MCP)**.
2. Selecione **Add**.
3. Cole este JSON, substitua a chave e defina **Server level** como global ou como o projeto atual:

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp@3.33.2"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
      }
    }
  }
}
```

4. Selecione **OK** e depois **Apply**. A coluna **Status** mostra a conexão, e o ícone de ferramentas lista as ferramentas do Firecrawl.
5. Ative **Automatically enable new and changed MCP servers** se quiser que o servidor seja iniciado automaticamente.

<Accordion title="Usar uma conexão remota">
  A documentação atual do AI Assistant também lista servidores Streamable HTTP, configurados com uma entrada `url` no mesmo JSON. Como ela não documenta cabeçalhos de request nem um fluxo de login pelo navegador, use a configuração local acima para o Firecrawl, a menos que sua IDE exiba essas opções.
</Accordion>

Veja [Executar o MCP localmente](/pt-BR/mcp-server/local) para conferir a lista completa de variáveis de ambiente.

## Solução de problemas {#troubleshooting}

* **O status continua vermelho:** execute `node --version` em um terminal e confirme que a versão exibida é 22 ou mais recente. Depois de instalar o Node.js, reinicie o IDE para que ele reconheça o novo `PATH`.
* **`spawn npx ENOENT`:** o IDE não consegue encontrar o `npx`. Inicie o IDE a partir de um shell em que o `npx` funcione ou use o caminho completo do `npx` como comando.
* **O servidor exibe `401`:** substitua o valor de `FIRECRAWL_API_KEY` e selecione **Apply** novamente.
* **Logs:** a página de configurações do MCP tem um link para a pasta de logs, que contém um log por servidor.
