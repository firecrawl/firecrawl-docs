Adicione o servidor MCP hospedado do Firecrawl ao [Executor](https://executor.sh) para que todos os agentes conectados ao Executor possam pesquisar e fazer scraping na web por meio de um único endpoint.

<Note>
  Estas etapas valem para o Executor 1.x (`npm install -g executor`). O Executor 2 (beta) organiza os servidores MCP como apps e contas; veja a [documentação do Executor](https://executor.sh/docs) para esse fluxo.
</Note>

## Configuração rápida {#quick-setup}

[Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys) e depois inicie o Executor:

```bash
npm install -g executor
executor web
```

Na UI web, adicione uma integração e escolha **Firecrawl** no catálogo ou informe manualmente a URL do MCP:

```text
https://mcp.firecrawl.dev/v2/mcp
```

O Executor detecta o servidor MCP e indexa suas ferramentas. Quando ele solicitar as credenciais, informe sua chave de API do Firecrawl para que as requisições incluam o cabeçalho `Authorization: Bearer <key>`.

Antes disso, você pode verificar o servidor pela linha de comando:

```bash
executor call executor mcp probeEndpoint '{"endpoint":"https://mcp.firecrawl.dev/v2/mcp","headers":{"Authorization":"Bearer '"$FIRECRAWL_API_KEY"'"}}'
```

Em seguida, conecte seu agente ao endpoint MCP do próprio Executor (`http://127.0.0.1:4788/mcp` para um servidor local):

```bash
npx add-mcp http://127.0.0.1:4788/mcp --transport http --name executor
```

Execute `executor tools integrations` e confirme que `firecrawl` aparece na lista com uma contagem de ferramentas maior que zero.

## Solução de problemas {#troubleshooting}

* **A contagem de ferramentas está em 0:** o Executor cria ferramentas por conta, então termine de conectar a conta do Firecrawl com sua API key e depois atualize a fonte.
* **O comando de adicionar servidor fica pausado:** o Executor pede sua aprovação para adicionar um servidor MCP; aceite com `executor resume --execution-id <id> --action accept --content '{}'`.
* **Seu agente não vê as ferramentas:** a maioria dos clientes carrega os servidores MCP na inicialização, então reinicie o cliente ou abra uma nova sessão depois de adicionar o Executor.
