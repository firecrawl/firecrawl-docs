Adicione as ferramentas sem chave de busca, scraping e Parse do Firecrawl ao [OpenCode](https://opencode.ai) por meio do servidor MCP hospedado.

<div id="quick-setup">
  ## Configuração rápida
</div>

Adicione o seguinte a `~/.config/opencode/opencode.json` ou ao `opencode.json` do seu projeto:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "firecrawl": {
      "type": "remote",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "enabled": true
    }
  }
}
```

Reinicie o OpenCode, digite `/mcp` e confirme que `firecrawl_search`, `firecrawl_scrape` e `firecrawl_parse` estão disponíveis.

O acesso sem chave tem limites compartilhados entre usuários com o mesmo IP público. Faça login em um cliente interativo com [Para humanos](/pt-BR/mcp-server/oauth) ou [adicione uma chave de API](/pt-BR/mcp-server/keyless#add-an-api-key) para uso não assistido.

<div id="try-it">
  ## Experimente
</div>

```text
busca the web for the latest Bun release notes and summarize the sources.
```

```text
scraping https://docs.firecrawl.dev/introduction and list the code examples.
```

<div id="troubleshooting">
  ## Solução de problemas
</div>

* **O servidor não se conecta:** execute `opencode doctor` e confirme a URL remota.
* **Crawl ou outra ferramenta está indisponível:** o modo sem chave expõe apenas busca, scraping e Parse. Conecte-se com OAuth ou uma chave de API para acessar um conjunto de ferramentas mais amplo.
