Adicione as ferramentas Search, scraping e Crawl do Firecrawl ao [LM Studio](https://lmstudio.ai) por meio do servidor MCP hospedado, para que seus modelos locais possam acessar a web em tempo real.

O LM Studio 0.3.17 e versões posteriores funcionam como host MCP e leem os servidores de um arquivo `mcp.json`, com a mesma notação usada pelo Cursor.

## Configuração rápida {#quick-setup}

1. [Crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys).
2. No LM Studio, abra a aba **Program** na barra lateral direita e escolha **Install &gt; Edit mcp.json**.
3. Adicione o Firecrawl em `mcpServers` e salve:

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer <FIRECRAWL_API_KEY>"
      }
    }
  }
}
```

Se o `mcp.json` já listar outros servidores, copie apenas a entrada `"firecrawl": { ... }` para dentro do object `mcpServers` existente.

O LM Studio carrega o servidor assim que você salva o arquivo. Abra um chat com um modelo compatível com uso de ferramentas e confirme que `firecrawl_search` e `firecrawl_scrape` aparecem na lista de ferramentas do chat.

Não exponha a API key em capturas de tela compartilhadas nem no controle de versão. O LM Studio armazena o `mcp.json` na pasta de dados dentro do seu diretório pessoal (`~/.lmstudio/mcp.json`).

## Faça login em vez de usar uma chave {#sign-in-instead-of-using-a-key}

O LM Studio oferece suporte a MCP OAuth para servidores remotos. Adicione `https://mcp.firecrawl.dev/v2/mcp-oauth` como `url` do servidor, sem `headers`, e depois conclua o login no navegador. Veja [Para humanos](/pt-BR/mcp-server/oauth).

## Executar o servidor local {#run-the-local-server-instead}

Para executar o Firecrawl na sua própria máquina, adicione uma entrada `command` que inicie o pacote npm, no lugar da entrada `url`. Veja o [guia do servidor MCP local](/pt-BR/mcp-server/local) para conferir o comando e as opções atuais.

## Solução de problemas {#troubleshooting}

* **As ferramentas não aparecem:** verifique se o modelo oferece suporte a uso de ferramentas e, em seguida, confirme que o `mcp.json` é um JSON válido e que a entrada `firecrawl` está dentro de `mcpServers`.
* **Falha na autenticação:** confirme que o cabeçalho contém `Bearer` seguido da sua chave, separados por um único espaço, e que a chave está ativa no seu [Painel do Firecrawl](https://www.firecrawl.dev/app/api-keys).
* **O modelo fica lento ou esgota o contexto:** as ferramentas do Firecrawl podem retornar páginas longas. Peça URLs específicas, use um modelo com uma janela de contexto maior ou habilite apenas as ferramentas de que você precisa.
* **Revise as chamadas de ferramenta:** por padrão, o LM Studio pede confirmação antes de executar ferramentas MCP. Instale apenas servidores MCP de fontes confiáveis.
