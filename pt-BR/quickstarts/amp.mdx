Adicione as ferramentas Search, scraping e Parse sem chave do Firecrawl ao [Sourcegraph Amp](https://ampcode.com) por meio do servidor MCP hospedado.

<div id="quick-setup">
  ## Configuração rápida
</div>

Abra as configurações do Amp e adicione este servidor MCP remoto:

```json
{
  "amp.mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Recarregue o Amp e confirme que `firecrawl_search`, `firecrawl_scrape` e `firecrawl_parse` estão disponíveis.

O acesso sem chave tem limites compartilhados entre usuários do mesmo IP público. Use o [OAuth](/pt-BR/mcp-server/oauth) para acesso interativo à conta ou o [guia de chave de API](/pt-BR/mcp-server/keyless-api-key#add-an-api-key) para uso não assistido.

<div id="troubleshooting">
  ## Solução de problemas
</div>

* **O servidor não se conecta:** confirme se a URL é exatamente `https://mcp.firecrawl.dev/v2/mcp` e verifique os logs do MCP no Amp.
* **O rastreamento ou outra ferramenta não está disponível:** o modo sem chave oferece apenas Search, scraping e Parse. Conecte-se usando OAuth ou uma chave de API para acessar um conjunto de ferramentas mais amplo.
