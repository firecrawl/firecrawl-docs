Adicione as ferramentas Search, scraping e Parse sem chave do Firecrawl ao [Amp](https://ampcode.com) por meio do servidor MCP hospedado.

## Configuração rápida {#quick-setup}

Adicione isto ao arquivo de configurações do Amp (`~/.config/amp/settings.json`; o comando `amp config edit` abre esse arquivo):

```json
{
  "amp.mcpServers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp"
    }
  }
}
```

Ou deixe que a CLI escreva isso para você:

```bash
amp mcp add firecrawl https://mcp.firecrawl.dev/v2/mcp
```

Reinicie o Amp e confirme que `firecrawl_search`, `firecrawl_scrape` e `firecrawl_parse` estão disponíveis.

O acesso sem chave tem limites compartilhados entre usuários do mesmo IP público. Faça login em um cliente interativo com [For Humans](/pt-BR/mcp-server/oauth) ou [adicione uma chave de API](/pt-BR/mcp-server/keyless#add-an-api-key) para uso não assistido.

## Experimente {#try-it}

```text
Faça uma busca na web pelas notas de versão mais recentes do Amp e resuma as fontes.
```

```text
Scraping https://docs.firecrawl.dev and list the core endpoints.
```

## Solução de problemas {#troubleshooting}

* **O servidor não se conecta:** confirme se a URL é exatamente `https://mcp.firecrawl.dev/v2/mcp` e execute `amp mcp doctor` para verificar o status do servidor.
* **O rastreamento ou outra ferramenta não está disponível:** o modo sem chave oferece apenas Search, scraping e Parse. Conecte-se usando OAuth ou uma chave de API para acessar um conjunto de ferramentas mais amplo.
