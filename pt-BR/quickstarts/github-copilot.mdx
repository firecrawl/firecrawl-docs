Conecte o [GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli) ou o [Copilot no VS Code](https://code.visualstudio.com/docs/copilot/overview) ao Firecrawl pelo servidor MCP hospedado e depois faça login com sua conta do Firecrawl. O [agente de programação do Copilot](#copilot-coding-agent) se conecta usando uma API key.

As URLs do servidor abaixo são valores de configuração do cliente, não páginas para abrir diretamente no navegador.

## Copilot CLI {#copilot-cli}

### 1. Adicione o Firecrawl {#1-add-firecrawl}

```bash
copilot mcp add --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth
```

Isso grava o servidor em `~/.copilot/mcp-config.json`. Você também pode executar `/mcp add` em uma sessão interativa e escolher o tipo **HTTP**, ou editar o arquivo diretamente:

```json ~/.copilot/mcp-config.json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth",
      "tools": ["*"]
    }
  }
}
```

### 2. Faça login e verifique {#2-sign-in-and-verify}

```bash
copilot
```

Na primeira conexão, o Copilot CLI abre o fluxo de login do Firecrawl no seu navegador, onde você escolhe uma equipe e aprova a conexão. Digite `/mcp` para confirmar que o `firecrawl` está conectado.

### Usar uma API key como alternativa {#use-an-api-key-instead}

Para uso não assistido, [crie uma chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys), exporte-a como `FIRECRAWL_API_KEY` e adicione o endpoint de API key com um cabeçalho bearer:

```bash
copilot mcp add --transport http \
  --header "Authorization: Bearer $FIRECRAWL_API_KEY" \
  firecrawl https://mcp.firecrawl.dev/v2/mcp
```

A chave fica armazenada em `~/.copilot/mcp-config.json`, então não inclua esse arquivo no controle de versão.

## VS Code {#vs-code}

### 1. Adicione o Firecrawl {#1-add-firecrawl-2}

Execute **MCP: Add Server** na Paleta de Comandos e escolha **HTTP**, ou crie `.vscode/mcp.json` no seu espaço de trabalho:

```json .vscode/mcp.json
{
  "servers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

Para disponibilizar o servidor em todos os espaços de trabalho, execute **MCP: Open User Configuration** e adicione a mesma entrada nesse arquivo.

### 2. Faça login e verifique {#2-sign-in-and-verify-2}

Inicie o servidor pelo editor do `mcp.json` ou com **MCP: List Servers**. Quando o VS Code solicitar autenticação, permita e conclua o login no Firecrawl pelo navegador. Em seguida, abra o Copilot Chat no modo **Agente** e clique no ícone de ferramentas para confirmar que as ferramentas do Firecrawl aparecem na lista.

### Usar uma API key como alternativa {#use-an-api-key-instead-2}

Use o endpoint com API key e deixe o VS Code solicitar a chave, para que ela seja armazenada com segurança em vez de ficar gravada no arquivo:

```json .vscode/mcp.json
{
  "inputs": [
    {
      "type": "promptString",
      "id": "firecrawl-api-key",
      "description": "Firecrawl API key",
      "password": true
    }
  ],
  "servers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer ${input:firecrawl-api-key}"
      }
    }
  }
}
```

## Agente de programação do Copilot {#copilot-coding-agent}

O agente de programação do Copilot (também chamado de agente de nuvem do Copilot) trabalha em issues e pull requests no GitHub. As configurações do MCP do repositório não têm suporte a servidores remotos que usam OAuth, por isso esta configuração armazena uma chave de API do Firecrawl como um segredo de Agents e a envia em um cabeçalho.

### Requisitos {#requirements}

* Um plano pago do GitHub Copilot com o agente de programação habilitado no repositório.
* Acesso de administrador ao repositório, necessário para editar as configurações do MCP e os segredos de Agents.
* Uma [chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys).

### Configuração {#set-it-up}

1. No seu repositório, abra **Settings**, depois **Secrets and variables** e, em seguida, **Agents**.
2. Selecione **New repository secret**, dê a ele o nome `COPILOT_MCP_FIRECRAWL_API_KEY`, cole sua chave de API do Firecrawl e salve. O Copilot só repassa aos servidores MCP os segredos de Agents cujos nomes começam com `COPILOT_MCP_`.
3. Abra **Settings**, depois **Copilot** e, em seguida, **MCP servers**.
4. Cole esta configuração em **MCP configuration** e selecione **Save MCP configuration**:

```json
{
  "mcpServers": {
    "firecrawl": {
      "type": "http",
      "url": "https://mcp.firecrawl.dev/v2/mcp",
      "headers": {
        "Authorization": "Bearer $COPILOT_MCP_FIRECRAWL_API_KEY"
      },
      "tools": ["firecrawl_search", "firecrawl_scrape", "firecrawl_map"]
    }
  }
}
```

5. Atribua uma issue ao Copilot. Quando o pull request dele aparecer, escolha **View session**, abra a etapa **Start MCP Servers** nos logs e confirme que as ferramentas do Firecrawl aparecem na lista.

<Warning>
  O Copilot usa as ferramentas da lista `tools` sem pedir aprovação. Mantenha na lista apenas as ferramentas de que o agente precisa. Use `"*"` somente se quiser disponibilizar todas as ferramentas do Firecrawl.
</Warning>

## Solução de problemas {#troubleshooting}

* **As ferramentas não aparecem:** confirme que há apenas um servidor `firecrawl` configurado e reinicie o Copilot CLI, ou execute **MCP: List Servers** no VS Code e reinicie o servidor.
* **O login é solicitado novamente ou retorna `401`:** reinicie o servidor e conclua o login no navegador. É esperado que uma request simples ao servidor OAuth retorne `401` antes da autenticação.
* **Uma conexão com API key retorna `401`:** confirme que a URL é `https://mcp.firecrawl.dev/v2/mcp` (e não `/v2/mcp-oauth`) e que o cabeçalho é `Authorization: Bearer <FIRECRAWL_API_KEY>`.
* **Política da organização:** se a sua organização no GitHub restringir servidores MCP no Copilot, um administrador precisará permitir o Firecrawl para que ele possa se conectar.
* **Agente de programação: as ferramentas do Firecrawl não aparecem no log da sessão:** confirme que o nome do segredo é exatamente `COPILOT_MCP_FIRECRAWL_API_KEY` e que ele é um segredo de Agents, e não de Actions.
