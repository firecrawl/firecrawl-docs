Conecte o Firecrawl ao modo agente do GitHub Copilot no Visual Studio pelo servidor MCP hospedado e, em seguida, faça login com sua conta do Firecrawl.

## Requisitos {#requirements}

* Visual Studio 2022 versão 17.14 ou posterior, ou Visual Studio 2026.
* Sessão iniciada no GitHub Copilot, com o Copilot Chat no modo **agente**.

## Configuração rápida {#quick-setup}

1. Crie `%USERPROFILE%\.mcp.json` para disponibilizar o Firecrawl em todas as soluções, ou `<SOLUTIONDIR>\.mcp.json` para restringi-lo a uma única solução e compartilhá-lo via controle de versão.
2. Adicione esta configuração e salve o arquivo:

```json
{
  "servers": {
    "firecrawl": {
      "url": "https://mcp.firecrawl.dev/v2/mcp-oauth"
    }
  }
}
```

3. No arquivo, selecione **Authentication Required** no CodeLens acima do servidor e conclua o login no Firecrawl pelo navegador. Se o CodeLens não aparecer, ative-o em **Tools**, **Options**, **Text Editor**, **CodeLens**.
4. No Copilot Chat, mude para o modo **agente**, abra **Tools** e ative as ferramentas do Firecrawl. O Visual Studio mantém novas ferramentas MCP desativadas até que você as ative.

<Accordion title="Prefere adicionar o servidor pelo chat?">
  No Copilot Chat, mude para o modo **agente**, abra **Tools**, selecione o botão de adição (+) e depois **Add custom MCP server**. Informe `firecrawl` como nome e `https://mcp.firecrawl.dev/v2/mcp-oauth` como URL.
</Accordion>

<Accordion title="Prefere um servidor local com uma API key?">
  O Visual Studio também executa servidores locais. Consulte [Executar o MCP localmente](/pt-BR/mcp-server/local) e defina o comando no mesmo arquivo:

  ```json
  {
    "servers": {
      "firecrawl": {
        "command": "npx",
        "args": ["-y", "firecrawl-mcp@3.33.2"],
        "env": {
          "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
        }
      }
    }
  }
  ```
</Accordion>

Veja o [guia de conexão OAuth](/pt-BR/mcp-server/oauth) para mais detalhes. Para uso não assistido, [configure uma API key](/pt-BR/mcp-server/keyless#add-an-api-key).

## Solução de problemas {#troubleshooting}

* **Nenhuma ferramenta do Firecrawl aparece no seletor:** abra o seletor de ferramentas e habilite-as. O Visual Studio redefine as aprovações de ferramentas sempre que a lista de ferramentas de um servidor muda.
* **O login é solicitado novamente:** no `.mcp.json`, selecione **Manage Authentication** no CodeLens do servidor `firecrawl`.
* **O arquivo é ignorado:** nos arquivos do Visual Studio, a chave de nível superior é `servers`, e não `mcpServers`.
* **Já existe outra definição de `firecrawl`:** o Visual Studio também lê `.vscode\mcp.json` e `.cursor\mcp.json` na pasta da solução. Mantenha apenas uma entrada do Firecrawl.
