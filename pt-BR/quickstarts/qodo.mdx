Adicione o Firecrawl ao Qodo Command para que seus agentes do Qodo possam fazer buscas na web e ler páginas. O Qodo Command inicia o Servidor MCP do Firecrawl como um processo local, usando sua API key.

<Note>
  O Qodo vai descontinuar seu plugin para IDE em 30 de outubro de 2026 e levar os fluxos de trabalho locais para os agentes de programação que você já usa. Esta página trata do Qodo Command, que lê os servidores MCP de um arquivo do projeto.
</Note>

## Requisitos {#requirements}

* Qodo Command, instalado com `npm install -g @qodo/command` e autenticado com `qodo login`.
* Node.js 22 ou superior.
* Uma [chave de API do Firecrawl](https://www.firecrawl.dev/app/api-keys).

## Configuração rápida {#quick-setup}

1. Na raiz do seu projeto, crie o arquivo `mcp.json`:

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp@3.33.2"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-YOUR-API-KEY"
      }
    }
  }
}
```

2. Crie o arquivo `agents/research.toml` e dê ao agente acesso ao servidor pelo nome:

```toml
version = "1.0"

[commands.research]
description = "Research a topic on the web with Firecrawl"
instructions = """
Use the Firecrawl tools to search the web and read pages, then summarize the sources.
"""
tools = ["firecrawl"]
execution_strategy = "act"
```

3. Importe o agente do arquivo `agent.toml` na raiz do projeto:

```toml
version = "1.0"

imports = ["agents/research.toml"]
```

4. Execute o agente e liste as ferramentas disponíveis:

```bash
qodo list-mcp
qodo research "Find the latest release notes for Node.js"
```

Mantenha o `mcp.json` fora do controle de versão, pois ele contém sua chave. Veja [Executar o MCP localmente](/pt-BR/mcp-server/local) para conferir a lista completa de variáveis de ambiente.

## Solução de problemas {#troubleshooting}

* **`list-mcp` não mostra nenhuma entrada do Firecrawl:** confirme que o `mcp.json` está na raiz do projeto ou passe `--mcp-file=path`.
* **O agente nunca chama o Firecrawl:** verifique se o campo `tools` no arquivo do agente contém `"firecrawl"`, correspondendo à chave em `mcp.json`.
* **O servidor não inicia:** execute `node --version` e confirme que a versão exibida é 22 ou superior.
* **O servidor retorna `401`:** substitua o valor de `FIRECRAWL_API_KEY` em `mcp.json`.
